# Dialog and control bug audit

Each numbered entry is one underlying defect, reached through ordinary editor
controls. Repeated symptoms in several formats or controls are counted once.
No entry depends on modifying application internals or a malformed input file.

| ID | Ordinary reproduction | Expected / observed before the fix | Fix and regression |
| --- | --- | --- | --- |
| D01 | Edit → Preferences → Keyboard shortcuts. Set Sort commands to Alphabetical. Focus it and press Enter twice. | Reopening and accepting the current choice preserves Alphabetical; it changed to By category. | Initialize the dropdown's active row from its selected value. Browser: `reopening a preferences dropdown preserves the selected keyboard option`. |
| D02 | Open the same Sort commands dropdown and press Tab. | The list closes while focus proceeds to the next control; its portal remained open after focus left it. | Close the list on Tab and restore the trigger before native tab navigation. Browser: `Tab dismisses a preferences dropdown before moving to the next field`. |
| D03 | Use a 1100 × 600 browser window. Edit → Preferences → Editing. Scroll Zoom state 2 into view and open it. | Every choice remains reachable inside the viewport; the list extended to y=629.5, below the 600-pixel window. | Position the list in the available space above or below the control, constrain its height, and scroll the active row into view when opening or using the keyboard. Ignore the menu's own scroll events and pointer highlighting when scrolling the active row, preserving ordinary wheel navigation in long preset/format lists. Browser: `preferences dropdown choices stay inside a short viewport` and `audio-editor-dropdown-wheel-regressions.spec.js`. The wheel correction supports this original fix and adds no count. |
| D04 | Edit → Preferences → Track display. Set minimum frequency to 1000 Hz. Select the maximum frequency's contents and type 8000. Also Preferences → Editing → clear Mouse zoom precision, type 3 and press Tab. | Intermediate drafts below the minimum were discarded: maximum frequency stayed 20000 Hz, and the cleared Zoom precision immediately restored 2 before typing 3. | Keep a local text draft and validate the completed number on blur or Enter. Apply the same bounded draft to integer Zoom precision and reject fractions at commit. Browsers: `spectrogram frequency settings accept a typed multi-digit maximum above the minimum` and `editing Zoom precision permits clearing and replacing its saved integer`; Node: `audio-editor-dialog-number-input.test.tsx` and `audio-editor-editing-preferences-page.test.tsx`. The Zoom follow-up passed in all three engines and adds no count. |
| D05 | Focus Search commands and media, type `track`, press Home, and type `mono `. Then press End and append ` extra`. | Home and End move the text caret; they navigated search results, producing `trackmono ` instead of `mono track`. | Reserve Alt+Home and Alt+End for result navigation. Browser: `search Home and End leave query editing to the text input`. |
| D06 | Generate → Tone. Click the duration's format button and choose samples. | Changing presentation leaves the dialog open for explicit Generate; clicking the format button submitted the containing form and generated audio. | Give the format button an explicit button type. The shared Knob receives the same default to avoid the same underlying HTML form defect. Browser: `the duration format button leaves generation to the Generate button`; Node checks the button type. |
| D07 | Generate → Tone. Click an individual duration digit. | The digit receives focus for editing; its enclosing label also activated the format button, opening the format menu. | Cancel the enclosing label's default activation when clicking the digit display. Browser: `clicking a timecode digit edits it without activating its enclosing label`. |
| D08 | Generate → Tone. Enter 0.001 seconds, switch duration to samples, and attempt to replace 48 samples with 48000 samples using its digits. | The editor provides enough editable leading digits for the new value; total-unit displays had only as many digits as the old value, preventing a larger entry. | Give total samples and total frames twelve editable digits, and seconds-plus-milliseconds six whole-second digits. One root defect across these formats. Browser: `sample timecode permits replacing a small duration with a larger sample count`; Node checks zero-value widths and existing frame boundary tests retain their numeric assertions. |
| D09 | Generate → Tone. Set the fractional milliseconds to 015, switch to whole seconds, and increase the last second digit. | The duration increases by exactly one second and retains its hidden 15 milliseconds; rebuilding the value solely from visible digits discarded the fraction. | Apply the difference between old and new visible values to the underlying value. Browser: `editing whole seconds preserves undisplayed fractional time`. |
| D10 | File → Open a normal 44.1-kHz Audacity project containing audio. Switch the playhead display to samples and enter sample 15. | The display continues to show sample 15; converting 15/44100 seconds back to samples truncated the floating result 14.999999999999998 to 14. | Allow floating-point round-trip tolerance when extracting whole display units. Browser: `an exact sample entered in the playhead stays exact after its seconds conversion`; Node: exact 15-sample regression. |
| D11 | File → Open a normal 44.1-kHz Audacity project. Generate → Tone. Switch duration from seconds to samples. | The count uses the project's 44100 samples per second; seconds-based inputs used a fixed 48000-Hz display rate. | Let the time-input adapter receive display sample/frame rates and pass the generator's project sample rate. Browser: `duration sample display uses the rate of a normally opened Audacity project`; Node: supplied 44100-Hz display rate. Generator-specific wiring supports this same defect and is not counted separately. |
| D12 | Edit → Preferences → Keyboard shortcuts. Search New mono track. Type `Ctrl+Backspacee` in its binding field. | An impossible key name is rejected before assignment; the editor accepted the spelling and saved a shortcut no keyboard could trigger. | Validate the key against Unicode characters, named keyboard keys, and the editor's supported aliases before enabling Assign. Browser: `shortcut preferences reject a misspelled key instead of assigning an unusable binding`; Node tests preserve valid native, Unicode, mouse, and media keys. |
| D13 | Generate a tone, Select → Select all, then Effect → Volume and compression → Amplify. Enter -6 dB and leave the field. Clear the numeric field and leave it again. | An empty entry is rejected and retains -6 dB; `Number('')` silently changed the amplification to 0 dB. | Require a nonblank numeric draft before conversion. Browser: `clearing an effect number refuses the empty value instead of changing it to zero`; Node: `an empty effect number never commits zero`. |
| D14 | In the same Amplify dialog, enter 1000 dB and leave the field while using a screen reader. | The rejected out-of-range entry is announced as invalid; only a visual error class distinguished it, leaving assistive technology with an apparently valid field. | Expose the TextInput's existing error state with `aria-invalid` on its input or textarea. Browser: `rejected effect numbers expose their error to assistive technology`; Node: `a rejected numeric effect draft is exposed as invalid`. |
| D15 | Record options → Timed recording. Choose End date and time. Focus the start date and press Tab through its date segments. | Tab proceeds to the selected end-mode radio; the disabled duration still had tabindex 0 and intercepted keyboard focus. | Remove disabled TimeCode controls from the tab order. Browser: `timed recording skips its disabled duration when tabbing from the start date`; Node checks the disabled tab index. The fix was included in the first commit; this independently accessible reproduction establishes its distinct defect. |
| D16 | Generate a tone, open the track's Effects rack, and add Reverb. Drag its title toward the browser's top-left edge. | Its title and Close control remain inside the window; the header moved to y=-12.5 and clipped the controls. | Constrain drag offsets using the title bounds and current browser viewport. Browser: `a realtime effect header remains reachable after dragging toward the window edge`; Node covers all window edges and a subsequent drag of an already moved dialog. |
| D17 | Switch to the Music workspace. Generate a tone, change Project tempo to 60 BPM, seek the playhead to two seconds, and choose its beats:bars format. Then set the signature to 3/8. | The musical display and edits follow the project's tempo/signature; they always used 120 BPM and four beats per bar, displaying bar 1 / beat 1 instead of bar 0 / beat 3 at 60 BPM. | Supply the project's authoritative tempo and signature conversions to every nested TimeCode through a focused context provider. Browser: `beats and bars timecode follows the project tempo and time signature`, including an inverse beat edit; Node covers secondary tempo/signature events and sample-locked tempo maps. Tempo and signature symptoms count as one hardcoded-conversion defect. |
| D18 | Switch to the Music workspace. Type 3 into Time signature: denominator and press Enter. Also try a numerator of 0 or 1001. | A rejected final draft restores the saved 4; the controller rejected the value, but the toolbar kept displaying the unsaved invalid number and retried it on blur. | Validate the declared numeric bounds and the denominator's power-of-two requirement before issuing the command. Browser: `unusable musical signature drafts restore the saved value`; Node: `invalid time signature drafts restore the authoritative value without issuing a command`. These rejected final drafts are distinct from D04's refusal of intermediate keystrokes while typing a valid value. |
| D19 | Generate a tone, Select → Select all, turn on Spectrogram, and open Spectrogram options → Select spectral frequency range. Type `1e3` into Minimum frequency (Hz) and click its Increase value arrow. | A valid 1000-Hz scientific entry increases to 1010; the stepper parsed 1 and treated `e3` as a unit, producing the invalid text `11 e3`. | Parse the entire signed decimal/scientific numeric prefix before retaining any optional display unit. Browser: `frequency step arrows preserve the value of scientific numeric input`; Node also covers `.5` and signed/unit-bearing values. |
| D20 | In that spectral-selection dialog, type -100 into Minimum frequency (Hz) and click Increase value. Alternatively, enter 25000 into Maximum frequency (Hz) and click Decrease value. | Stepping restores the draft to the declared 0–24000-Hz bounds; it produced -90 or 24990 because Increase enforced only the maximum and Decrease only the minimum. | Apply both bounds to every step direction. Browser: `frequency step arrows recover an out-of-range draft to the declared bounds`; Node verifies recovery and stepping across both endpoints. Both directions count as one incomplete-bounds defect. |
| D21 | Generate and select a tone. Effect → Delay and reverb → Reverb. More options → About. Focus the About dialog's Close button and press Tab. | Tab reaches the About dialog's resize control, then wraps to Close; the underlying effect dialog's still-active trap forced focus back to Close on every Tab. | Assign modal focus containment to the newest open dialog, restoring the preceding owner when it closes. Browser: `a nested effect details dialog owns Tab navigation through its controls`; Node covers ownership release and separate documents. |
| D22 | Generate a tone and open Export audio. Save a WAV delivery preset as Favorite, then a FLAC delivery preset with the same name. Change Format to MP3 and select the second Favorite (custom) preset. | The second preset restores its saved FLAC format; selection looked up the display label and applied the first preset's WAV settings. | Pass stable preset IDs and labels separately through the shared preset header. Browser: `each same-name delivery preset selects its own saved format`; Node: `same-name delivery presets preserve distinct selection identities`. Effect presets already disambiguate their names and are not counted as an extra defect. |
| D23 | Generate a tone. Edit → Manage labels → New label. Click the last whole-second digit of Selection end, type 1, and press Enter. | Enter confirms the one-second region immediately; only the local display changed, while the project kept a point label until focus left the entire field. | Connect the TimeCode's Enter confirmation to the adapter's commit callback, deduplicating the later blur for the same edit. Browser: `Enter commits an edited label end time before leaving the time field`; Node verifies confirmation and a subsequent blur issue only one command. |
| D24 | Switch to the Music workspace. Focus Time signature: numerator and press ArrowUp. | The native number input steps from 4 to 5 and retains focus; toolbar navigation captured the arrow first and moved focus to another control without editing. | Both toolbar navigation layers defer to editable widgets that own arrow/Home/End keys. Browser: `toolbar number fields retain native arrow stepping instead of moving focus`; Node checks ownership for native inputs, selects, text areas, and sliders while preserving action-button navigation. All affected toolbar editing keys count as one focus-navigation ownership defect. |
| D25 | Generate a tone. Window → Mixer. Focus the track's Pan slider and press Home, then End. | The slider moves to its advertised -100 and 100 endpoints; these keys did nothing, leaving the value at 0. | Implement Home/End in the shared Knob with the existing start/change/end gesture lifecycle. Browser: `mixer pan slider reaches either endpoint with Home and End`; Node checks both endpoint values and exactly one completed gesture per press. The required keys follow the [W3C slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/). |
| D26 | Generate and select a tone, turn on Spectrogram, and open Spectrogram options → Select spectral frequency range. Type 100 or -100 into Gain (dB). | Spectral Amplify refuses values outside the field's advertised -60–60-dB range; it stayed enabled and submitted these values to the engine, whose broader domain permits them. | Share the dialog's gain bounds between its stepper and submission admission. Browser: `spectral amplification requires a gain inside its displayed bounds`, including a valid -60-dB submission; Node checks rejected outside values and accepted endpoints. This submission-validation defect is separate from D20's opposite-direction step-button bounds. |
| D27 | Generate and select a tone. Open Reverb, focus More options, press Enter, then Shift+Tab. | The options menu closes and focus moves back to Save preset; the menu closed but its document handler suppressed native Tab and discarded the focused menu item, leaving focus outside the dialog. | Restore the context-menu trigger before allowing native forward/backward Tab. Browser: `Shift Tab from effect preset options closes the menu and reaches the preceding control`; Node verifies trigger restoration and an unprevented Tab while retaining Escape focus protections. This already-dismissed context menu's lost focus is distinct from D02's dropdown staying open. |
| D28 | Generate and select a tone. Open Reverb and click More options. Press the More options trigger again, drag the pointer away before releasing to cancel that click, then press Enter on the trigger. | Enter reopens the menu; the canceled pointer press left a dismissal marker behind, so the next keyboard activation was silently discarded. | Clear the pointer-dismissal marker on a release outside the trigger or pointer cancellation, while retaining it for an ordinary completed trigger click. Browser: `a cancelled effect options trigger press does not swallow its next keyboard activation`; Node verifies both cancellation paths and one-time consumption of a completed click. |

Browser setup uses menus and visible controls. The AUP3 fixture is an ordinary
valid Audacity recording opened through File → Open; it exists to exercise a
normal project sample rate, without injecting editor state. Hidden direct-entry
fields are read only as an observation of duration commits, never manipulated.

Disabled dropdown-row handling is a support change and is not counted as a
separate defect without an independent user reproduction.

These UI, browser, test, and documentation changes use the existing assistance
runtime closure. A manual **Update AI assets** run is not required.
