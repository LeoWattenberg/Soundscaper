# Editing bug audit

Each entry has ordinary user steps. Browser setup imports normal PCM WAV recordings
through the file picker and uses menus, keyboard shortcuts, and existing clip
controls. Tests do not inject editor state or manufacture malicious documents.
Multiple symptoms of one cause are counted once.

## Implemented fixes

| ID | User steps | Actual before the fix | Expected and correction | Regression |
| --- | --- | --- | --- | --- |
| EDIT-001 | Import two audio files onto tracks A and B. Select A's clip, Edit → Copy; select B's clip, Edit → Paste → Paste. | The copy appears on A although B is selected. | Anchor the first pasted lane on the selected compatible track; use following compatible lanes for additional copied tracks. | Browser: `Paste puts copied audio on the selected destination track`. |
| EDIT-002 | Import a 0.8-second recording and press Jump to project end. | The playhead jumps to 30 seconds, into the empty editing workspace. | Seek to the end of project content, 0.8 seconds. | Node and browser: project-end regression. |
| EDIT-003 | Place two 1-second clips at 0 and 0.5 seconds on one track, and another at 2 seconds. Select the first two; Edit → Delete → Delete and close gap per track. | The later clip moves to 0 seconds because the shared half-second is removed twice. | Merge removed clip spans before computing the ripple. The later clip moves to 0.5 seconds. | Node: `ripple removing overlapping clips closes each timeline frame once`; browser: `per-track ripple closes overlapping selected clips once` uses 0.8-second clips with the same overlap. |
| EDIT-004 | Import audio; select it and extend Looped clip length by one repeat. Edit → Copy, then Edit → Paste → Paste. | The copy has no repeat boundaries and plays one stretched source span. Duplicate has the same underlying data loss. | Carry clip extension metadata through the clipboard and scale the loop period and phase when project sample rates differ. | Node: loop period/phase; browser: `copy and paste retain loop repetitions`. |
| EDIT-005 | Import a recording containing an internal pause, loop it for several repetitions, and choose Edit → Audio clips → Split clips at silences. | The source's one pause is incorrectly mapped as one enlarged pause across the whole repeated clip. | Scan the repeated source with its period and phase, finding each actual pause. | Node: repeated-silence mapping; browser: repeated silent intervals. |
| EDIT-006 | Import a recording with an internal pause and choose Edit → Audio clips → Split clips at silences. | The command reports no silences when source PCM is streamed rather than present in the short-source cache. | Read stored PCM through the existing derived-source reader when the buffer cache has no entry. Fence completion against project changes. Labeled detach uses the same reader. | Node: streamed imported audio; browser: repeated silent intervals. |
| EDIT-007 | Import 0.8-second audio, Select → Select all, enable Snap, and Select → Tracks → Select all tracks. Also try Select → Region → Track start to end. | The exact 0.8-second endpoint becomes 1 second. | Preserve existing time boundaries when changing track scope, and select real content bounds exactly. Both paths share the incorrect reapplication of the snap grid and count once. | Two Node and two browser selection regressions. |
| EDIT-008 | Import audio onto two tracks. With Snap off, move the first clip 0.1 seconds using Ctrl+Right. Enable Snap and move it to the next track using Ctrl+Down. | The vertical move also moves the clip's start back to 0 seconds. | Pass the existing preserve-time option for keyboard track moves. | Browser: `keyboard track moves preserve the existing clip position with Snap enabled`. |
| EDIT-009 | Put clips at 0–0.8 and 2–2.8 seconds on A, and a clip at 2–2.8 seconds on B. Select only A's first clip and B's clip. Edit → Remove special → Trim audio outside selection. | A's unselected clip at 2–2.8 seconds survives because B's selected range is also treated as kept on A. | Keep each selected track's own selected clip ranges; batch identical ranges to preserve linked lanes. | Browser: `trim outside selected clips keeps independent ranges on each selected track`. |
| EDIT-010 | Import two recordings, Select → Select all, Select → Tracks → No tracks, Edit → Delete → Delete. | Every recording is deleted because the dispatcher interprets empty track selection as all tracks. | Resolve the existing selection authority and refuse scoped edits with no selected tracks. Explicit all-track ripple commands retain their explicit scope. | Browser: `No tracks prevents Delete from acting on the whole project`. |
| EDIT-011 | Import a normal WAV, open its clip properties, expand Normalize, press Normalize to −1 dBFS. | The gain stays at 0 dB because the clip-property normalization service only checks the buffer cache. | That distinct operation now reads stored PCM when needed, preserving task and clip ownership through the read and analysis. Peak and loudness normalization share this fix and count once. | Node: stored clip normalization; browser: `clip peak normalization reads an ordinary imported recording`. |
| EDIT-012 | Open clip properties, set independent pitch to 6 semitones, enable Link pitch and tempo, press Reset, and disable linkage. | The old 6-semitone shift returns: Reset ignored the explicit pitch reset while linked. | Honor an explicitly supplied independent pitch when speed is supplied too, preserving normal link toggles and the linkage setting. | Node and browser: linked Reset regression. |
| EDIT-013 | In Editing preferences, disable Always paste audio as a new clip. Import a recording with a pause at 0.2–0.3 seconds, extend its loop by one repeat, copy it, and paste into another clip at 0.4 seconds. | The joined audio stretches the recording once; the repeated pauses at 0.6–0.7 and 1.4–1.5 seconds disappear. | The independent paste-into-existing PCM renderer now evaluates the clip's loop period and phase. | Node: copied loop phase; browser: UI-created joined clip exported as WAV, checking actual pause samples. |
| EDIT-014 | Enable Snap, open clip properties → Media settings, enter start frame 19200, and press Tab. | The input shows 19200 but the clip remains at frame 0 because the start value is snapped. | Pass the existing exact-frame option for an explicit numeric clip position. | Browser: `clip properties apply the exact entered start frame when Snap is enabled`, checks the actual clip position as well as the field. |

These browser regressions were observed failing against the pre-fix production
build with only the user interactions above. Focused Node regressions also
failed before their corresponding fixes.

No manual **Update AI assets** run is required: these changes leave the assistance
runtime sources, recipes, dependencies, archives, signing, and target inventories
unchanged.
