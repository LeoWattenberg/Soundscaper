# Second dialog and control bug audit

Each numbered entry is a new, distinct underlying defect, beyond the first
round's 102 fixes. Reproductions use ordinary menus, pointer interaction, and
keyboard input. No entry requires modified application state or malformed files.

| ID | Ordinary reproduction | Before / expected behavior | Fix and regression |
| --- | --- | --- | --- |
| R2-DIALOG-001 | Window → Markers → Add marker at playhead. With the new marker focused, press F2 and type its name. | F2 entered rename state but left focus on the marker button, so typing could not edit its name. Focus should enter the Name field. | Focus and select the docked rename input when editing begins. Browser: `F2 in the docked Markers list focuses the annotation name for renaming` failed on the original build and passed after the fix. |
| R2-DIALOG-002 | Import ordinary audio, open its Clip properties, expand Media settings, type a new Clip name and press Enter. Then edit the name again and press Escape before leaving it. | Enter left the draft uncommitted; Escape did not cancel it. Single-line inspector fields should commit on Enter and restore the saved value on Escape without the following blur committing the canceled draft. | Add the existing guarded draft lifecycle to the shared inspector CommitField. Browser: `Enter commits an inspector name and Escape discards a later rename draft` failed at the unchanged clip title on the original build and passed after the fix; Node: `audio-editor-inspector-draft-keyboard.test.tsx`. Commit/cancel are one underlying lifecycle defect, counted once. |
| R2-DIALOG-003 | In Framescaper, File → Project management → Project properties → Sequence timing. Rename Main sequence to Changed sequence, press Tab, then click Undo. | Undo restored the document's Main sequence but the open field still displayed Changed sequence. | Keep the sequence-name draft synchronized with the saved name. Browser: `Undo restores the sequence name in the open Project properties panel`; Node: `the sequence name refreshes when the authoritative saved name changes`. The original browser build failed; the rebuilt Framescaper passed. |
| R2-DIALOG-004 | Customize toolbar → enable Snap. Enable snapping, open Snap interval, click Seconds and samples, then press ArrowRight. | The pointer had opened the submenu, so ArrowRight left focus on its parent instead of entering Seconds. | Run keyboard entry even for an already-open submenu, clear the pointer departure timer, and share entry with Enter/Space. Browser: `ArrowRight enters a snap submenu that the pointer has already opened`; Node: `keyboard entry enters a submenu already opened by a pointer click`. |
| R2-DIALOG-005 | Open that Snap submenu with ArrowRight, then press Escape on Seconds. | The whole Snap menu closed; Escape should close the child and return focus to Seconds and samples. Home/End were also intercepted by the ancestor level. | Delegate child-level keys from the root menu and let each submenu navigate only its direct items. Browser: `Escape from a snap submenu returns to its parent without dismissing the menu`; Node: `submenu Escape returns to its parent and Home and End stay inside its level`. The keys share one menu-level ownership defect. |
| R2-DIALOG-006 | Import audio → Clip properties → Normalize. Enter Clip gain 25 dB and press Enter while using a screen reader. | The editor rejected the gain and showed an alert, but the field still reported no invalid state. The parent swallowed the rejection, so the shared field treated it as success. | Return accepted/rejected status from clip-field commits and expose rejection through the shared field's existing error state. Browser: `a rejected clip gain is identified as invalid on its field`; Node: `a rejected inspector commit reports its invalid field state`. This is rejection-result plumbing, separate from the first round's missing TextInput ARIA attribute, which already exists. |
| R2-DIALOG-007 | Import audio → Clip properties → Fading. Drag Fade in shape across several values, release, then click Undo once. Repeat a drag and press Escape before releasing. | Undo restored only the last intermediate value; Escape left the draft persisted. One completed drag should be one edit, and cancellation should publish none. | Extract a fade-shape gesture draft, commit only on completion, and discard canceled pointer events, including Firefox's release input. Browser: `one Undo restores a complete Clip properties fade-shape drag` and `Escape cancels a Clip properties fade-shape drag before mouse release`; Node: `fade-shape previews publish one completed edit and cancellation publishes none`. Count the missing fade gesture lifecycle once. |
| R2-DIALOG-008 | Import audio → Effect → Pitch and tempo → Audio warp and transients. Create an identity map, add a marker, edit Marker 1 positions, focus Move marker 1 and press Enter. | The move succeeded but focus fell out of the controls, so the next keyboard action lost its position. | Keep marker rows stable across coordinate changes and recover the operation's focused control after temporary disabling, only when focus was lost to the document body and the owner is unchanged. Browser: `moving an Audio warp marker retains keyboard focus on its action`; Node focus recovery checks owner changes and explicitly chosen replacement focus. This dialog's operation focus lifecycle is counted once. |
| R2-DIALOG-009 | Framescaper → File → Project management → Project properties → Sequence timing. Choose 29.97, save start timecode 00:00:01:00, enter bad and Tab, then enable Drop frame. | The invalid draft was replaced with the valid saved 00:00:01;00, but the field still reported invalid and showed the obsolete error. | Clear validation when the saved timecode display replaces its input. Browser: `changing drop-frame clears an invalid draft replaced by the saved start timecode`; Node: `replacing a rejected timecode draft clears its obsolete validation state`. This stale validation belongs to the start-timecode field, separate from R2-DIALOG-003's stale sequence-name value. |
| R2-DIALOG-010 | Import audio, select it, enable Spectrogram → Spectrogram options → Select spectral frequency range. Clear Minimum frequency. | Select range, Spectral Delete, and Spectral Amplify remained enabled because an empty endpoint was converted to zero. | Require nonempty numeric frequency endpoint drafts and check the range again at submission. Browser: `spectral selection requires both frequency endpoints to contain a number`; Node range admission retains valid zero and scientific notation. This frequency-range admission is separate from the first round's spectral gain bounds and shared effect-number draft handling. |

All ten numbered fixes passed their browser regressions in Chromium, Firefox, and WebKit against the
production builds. UI, tests, and documentation retain the existing assistance runtime
closure; a manual **Update AI assets** run is not required.
