# Second editing bug audit

Only distinct failures reached through ordinary editor controls are counted.
Browser regressions import normal PCM WAV recordings through the file picker,
then use menus, keyboard navigation, and existing clip controls. They do not
inject editor state or use malicious documents. Each accepted entry failed in
the browser before its corresponding source fix.

| ID | Ordinary user steps | Actual before the fix | Expected and correction | Regression |
| --- | --- | --- | --- | --- |
| R2-EDIT-001 | Import a short recording and a longer recording. Select the short recording's header, jump to project end, Select → Region → Cursor to track end, then View → Skip to → Selection start. | Selection starts at the short track's start, frame 0. | Select between its end and the later cursor. Always anchor this command at the selected track's end, including when the cursor is beyond it. | Strict TypeScript controller test covers cursors before, at, and after the track end. Browser: `Cursor to track end selects from the end when the cursor is beyond the selected track`, also verifies the other endpoint. |
| R2-EDIT-002 | Import two recordings. On the first track, open its menu → Track visualization → Spectrogram. | Both tracks become spectrograms. | Change only the requested track. Stop rewriting the global timeline visualization as a side effect of a track command. | Updated strict TypeScript visualization test; browser: `changing one track visualization leaves other tracks in their existing view`, including Undo and the global Spectrogram toggle. |
| R2-EDIT-003 | Move a track into a new folder, right-click that folder → New folder, select the child folder, and collapse its parent. | Every visible folder has tabindex −1, so Tab cannot reach the tree. | Give the nearest visible ancestor the active tab stop. When the active folder no longer exists, recover the first visible folder. | Strict TypeScript folder-plan tests cover hidden and removed active folders. Browser: `collapsing a parent keeps its visible folder in the keyboard tab order`, including actual Shift+Tab navigation. |
| R2-EDIT-004 | Move a track into a new folder. Focus its row, press F2, type a name, and press Enter. Enter commits and Escape cancels; ordinary Tab and outside-click behavior remain available. | Strict TypeScript keyboard-lifecycle tests cover Enter, Escape, Tab, and removed rows. Browser: `committing a folder rename keeps keyboard navigation on the folder row`. |
| R2-EDIT-005 | Import a short recording, use its Looped clip length control to extend it to two repetitions, View → Zoom → Zoom to selection, and draw on a sample in the second repetition. Interpolate strokes across repeated boundaries without altering unrelated source samples. | Strict TypeScript tests cover forward and reversed loops, boundary crossing, split offsets, and stretched periods. | R2-EDIT-006 | Import a short recording, zoom to its samples, draw a sample, and Undo. Keep logarithmic conversion consistent with its existing display. | Strict TypeScript tests cover both linear formats at three zoom levels. Browser: `sample pencil honors the waveform vertical magnification`, checks decoded exported sample amplitude before and after the ruler command. |
| R2-EDIT-007 | Import a recording, track menu → Move selection into new folder, then track menu → Duplicate track. Alternatively, select a clip with the playhead inside it or draw a time range, then Edit → Audio clips → Split into new track. Share the existing hierarchy-position calculation with track replacement and both Split planners. | Three strict TypeScript controller tests check folder membership, sibling order, Undo, and Redo. Three browser workflows verify derived tracks disappear when their folder collapses. |
| R2-EDIT-008 | Import a recording, move its track into a folder, mute that folder, then Tracks → Unmute all tracks. | The folder stays muted, so its recording remains silent. | Clear authoritative folder mute together with leaf-track mute in one undoable operation. The corresponding Mute all command also addresses folders. | Two strict TypeScript tests check both command plans and controller Undo/Redo. Browser: `Unmute all tracks clears folder mute as well as leaf-track mute`. |
| R2-EDIT-009 | Import a short recording, extend Looped clip length to two repetitions, open Clip properties, select part of its second repetition in the source waveform, then Effect → Special → Invert. Export the result. | A different source phase is inverted; the highlighted audio stays unchanged. | Project the source editor's effect range through the loop period and offset. For disjoint source ranges, broaden the visible selection to match the contiguous audio that will be processed. | Three strict TypeScript tests cover either direction, boundary crossing, split offsets, and unused source. | R2-EDIT-010 | Import a recording with initial silence followed by sound. In Clip properties, trim Source start past the silence; the unused source waveform contains sound. Close properties, extend Looped clip length, and reopen properties. | The unused-source waveform becomes flat although its audio is unchanged. | Render unused source at native speed instead of inheriting the active clip's loop metadata. | R2-EDIT-011 | Track menu → Add automation, focus its insertion curve and press Enter. Focus an automation point, Delete it, then press an arrow key to edit the surviving point. | Focus remains on a removed element or falls to the document, so keyboard editing stops. | Restore focus after React publishes the replacement lane, choosing the next surviving point or the insertion curve when the lane was deleted. | Two strict TypeScript React lifecycle tests cover point and lane deletion; seven existing overlay cases also pass. Browser: `deleting an automation point keeps keyboard editing on a surviving point`, also checks Shift+Delete and subsequent Enter insertion. |

Initial four fixes: 12 browser cases passed across Chromium, Firefox, and WebKit.

browser cases across Chromium, Firefox, and WebKit, with focused TypeScript
coverage for the waveform projection and both deletion lifecycles.
