# Import and export bug regressions

Only ordinary UI workflows count here. Each row names a distinct root cause;
the two halves of custom-channel preset conversion count together as one bug.
No case depends on corrupt media, malicious input, or injected application state.

| ID | Ordinary steps to reproduce | Before | Expected and fixed behavior | Regression |
| --- | --- | --- | --- | --- |
| IO-001 | File → Import, use the native chooser's All files filter, and choose a normal legacy Audacity `.aup` project. | The workspace classified it as audio and attempted to import it without requesting the associated blocks. | Route it through the legacy project opener, which asks for the matching `_data` directory. | `a legacy AUP chosen through File Import asks for its data directory` |
| IO-002 | Import audio, open Edit → Metadata editor, clear Title, then open Export audio → Metadata. | The cleared title reappeared as the project name. | Preserve the deliberately empty metadata title. | `clearing the project metadata title keeps the export title empty` |
| IO-003 | Import labels, rename the project to `Episode 1.2` through File → Project management, then File → Export other → Export labels. | The download was named `Episode 1.txt`. | Preserve the project title's period: `Episode 1.2.txt`. Recognized media, project, and label-file extensions continue to be replaced. | `a dotted project title is retained in the label download name` |
| IO-004 | Add a label with Ctrl+B, type `Intro --> Verse`, then File → Export other → Export labels → As SubRip (SRT). | Export failed with a timing-arrow error even though the text is a legal SRT payload. | Export and reopen the label text successfully. | `a user-authored label containing an arrow exports as SubRip` |
| IO-005 | Export audio → Custom channel mapping → Edit mapping; route input 2 to output 1, save a delivery preset, close/reopen Export audio, and apply that preset. | Saving kept only the dialog sentinel `custom`; the matrix was lost. Structured preset mappings also failed to select the WAV mapping control on restore. | Save the actual matrix and restore the Custom control and its routing together. | `custom channel routing survives saving and reopening a delivery preset` |
| IO-006 | Import audio and labels, add a timeline marker through Window → Markers, choose Chapters (split by markers) in Export audio, save a preset, close/reopen the dialog, and apply it. Also save/reapply a browser MP3 preset after enabling Embed labels as chapters. | Chapter delivery settings were omitted: split presets restored labels as the chapter source, and single-file presets disabled embedded chapters. | Retain chapter settings, with labels and disabled embedding as the backward-compatible defaults for older presets. These settings omitted by the same chapter-preset whitelist/converter count together. | `a saved marker chapter preset keeps its marker source`, `a saved delivery preset keeps embedded label chapters enabled`, and `delivery presets retain and reset the embedded label chapter option` |
| IO-007 | Import an ordinary video, save a custom MP4 delivery preset, choose Web 1080p (WebM) as Delivery target, then apply the MP4 preset or choose MP4 video directly through Format. | The old platform target remained and could override the explicitly selected container in the export request. | Applying the saved preset or directly choosing a format clears the old target and uses the MP4 settings. Both explicit choices share the stale target bug and count together. | `applying a video preset replaces the previous platform target` and `choosing a video format replaces the previous platform target` |
| IO-008 | Add a label reading `5 < 10 & 20 > 15`, then File → Export other → Export labels → As WebVTT; view the downloaded cue in a WebVTT reader. | Literal label text was interpreted as cue markup, dropping the comparison. Escaped character references in ordinary imported VTT labels also appeared as entity source text. | Encode plain label punctuation in WebVTT payloads and decode the format's six named character references on import. The browser regression reads the actual download using Chromium's native `VTTCue` text reader. | `WebVTT readers display literal punctuation from a user-authored label` |
| IO-009 | Tools → Import raw data; choose an ordinary six-minute mono 16-bit PCM recording, click Import, then click the still-enabled Cancel button while import is running. | Cancel closed the dialog, but the recording still appeared as a new clip when import finished. Its late completion could also close a subsequently opened surface. | Abort the conversion and project import when Cancel, Close, or dialog unmount occurs; completion cannot close another surface. | `Cancel in the raw PCM import dialog stops a pending ordinary recording import` and `Cancel aborts the in-progress import and completion does not close a later surface` |
| IO-010 | Import audio and labels, open Export audio, select Streaming loudness normalization, then change Output to Chapters (split by labels) or Stems and click Export. The same route occurs after enabling ADM through Edit → Metadata editor and selecting Render for headphones before changing Output to Stems. | The mix rendering controls disappeared but their hidden options still reached the exporter, which refused split output. A hidden binaural choice could also distort the codec capability query's channel count. | Split output clears the mix rendering choices and only mix requests carry them. Chapters, stems, normalization, and binaural variants share one hidden-option root cause and count together. | `switching from a normalized mix to label chapters exports after normalization hides`, `switching from a headphone mix to stems exports after its binaural control hides`, and `chapter and stem requests omit the mix rendering options hidden by their output selection` |
| IO-011 | In the desktop application, Help → Diagnostics → Generate local diagnostic report → Export local diagnostic report, then click Cancel in the operating system's save dialog. | The dialog announced “The local diagnostic report was exported” even though no file was written. | Keep the generated report ready for another export and announce success only after saving. The native picker returns `null` on Cancel (`desktop/main-file-capability-ipc.mjs`), which the real editor file service translates into `{ cancelled: true }`. | `cancelling the desktop diagnostic report save leaves the report ready for retry` exercises the mounted dialog with the real file service, checks that Cancel starts no write, then verifies a successful retry. |
| IO-012 | Import audio, focus the Playhead slider, press Ctrl+B and name the point label, then File → Export other → Export labels → As WebVTT. Open the downloaded file in a subtitle reader. | The cue started and ended at the same instant and had no playable duration. Positive ranges shorter than a millisecond also collapsed during timestamp rounding. | Timed SRT/VTT exports use a minimum duration of one millisecond, their smallest supported quantum; project labels retain their original point or range. [WebVTT cue timings require the end to follow the start](https://www.w3.org/TR/webvtt1/#webvtt-cue-timings). Both timed-format variants share one timestamp-quantization root cause and count together. | `a point label exports as a WebVTT cue with a playable duration` loads the actual download through Chromium's native `<track>` parser; `timed label exports give points and submillisecond ranges the minimum cue duration` covers SRT and VTT without mutating input. |
| IO-013 | Import a normal landscape video, open Export audio → Format → MP4 video, select Delivery target → Vertical 1080x1920, then change Fit from Fill and crop to Fit inside (letterbox) and export. | The request omitted `contain` as a default, so the target's `cover` continued to crop the delivered picture despite the visible letterbox selection. | A default fit selected after a target is an explicit override. The regression uses a small portrait canvas to encode quickly, then decodes the actual video at 0.1 seconds and verifies coloured content at the center and black letterbox margins. | `choosing letterbox after a vertical delivery target keeps the source visible` and `the explicit letterbox choice overrides a vertical delivery target crop` |
| IO-014 | Import audio, Edit → Metadata editor → ADM → Enable ADM → Add object; select the Azimuth value and type `-45` character by character, then leave the field and reopen Metadata. | Rejecting the incomplete minus sign restored the old numeric value while typing; `-45` became positive `045` and was persisted as 45, placing the object on the wrong side. | Retain incomplete numeric drafts while committing valid values. Coordinates, distance, and gains share the draft handling; invalid drafts revert on blur. | `typing a negative ADM object angle keeps its sign` checks ordinary typing and persistence after reopening; `ADM numeric fields ignore invalid typed values before committing` also checks transient input and invalid blur recovery. |
| IO-015 | In Audacity, enable the extended label export style, make a spectral selection whose low or high bound reaches the track edge, add a label, and export TXT. In Soundscaper choose File → Import and select that ordinary TXT file. | An [Audacity-documented undefined bound](https://manual.audacityteam.org/man/importing_and_exporting_labels.html) (`-1`) caused the entire label import to fail, although the label times and frequency selection are valid. | Admit Audacity's exact `-1` sentinel in either frequency bound and preserve it on TXT export; continue refusing other negative bounds and reversed defined ranges. | `Audacity extended labels with an undefined spectral bound import and export` imports through the menu and reads both sentinel directions back from the actual download. Node regression also checks unchanged rejection of invalid ranges. |
| IO-016 | Import audio, open Edit → Metadata editor → ADM, enable ADM, set an imported source channel's bed channel to None, then change Bed layout from Stereo to 5.1. | The source was silently assigned to L again, undoing its explicit exclusion from the bed. | Layout changes remap assigned channels while preserving channels assigned to None; their separate object assignments remain independent. | `changing the ADM bed layout preserves a source channel deliberately assigned to None` uses ordinary selectors; `ADM editor layout and routing updates remain normalized` covers the domain change. |

| IO-017 | In a browser using the supported download fallback (for example Firefox or Safari), import audio, enable ADM through Edit → Metadata editor, save a BW64 / ADM export preset, then File → Delivery queue, select that preset and Queue batch. | The member was marked Delivered, but no file downloaded: buffered publication only prepared an object URL, and the export dialog that starts it was closed. | Queued buffered audio/video exports publish the file through the file service themselves; direct export dialogs retain their prepared download link. | `a buffered BW64 delivery queue job downloads the file it marks delivered` checks the actual BW64 download; the service regression verifies file publication, and queue tests verify the publication request. The browser helper models the ordinary no-File-System-Access browser capability, without modifying project state. |

Focused domain regressions live in `tests/audio-editor-io-user-regressions.test.ts`;
the menu/picker/drop workflows live in
`tests/browser/audio-editor-io-user-regressions.spec.js`.
The native desktop Cancel regression lives in
`tests/audio-editor-local-diagnostics-surface.test.tsx`; existing
`tests/browser/audio-editor-local-diagnostics.spec.js` covers both products'
ordinary report generation and successful export.
The actual encoded-video margin regression lives in
`tests/browser/audio-editor-io-video-default-regressions.spec.js`.
The ADM typing regression lives in
`tests/browser/audio-editor-io-metadata-regressions.spec.js`.
The delivery queue's normalization-to-stems variant of IO-010 lives in
`tests/browser/audio-editor-io-queue-regressions.spec.js`. Save a Streaming WAV
preset from Export audio, then choose Delivery queue → Output → Individual stems,
select the saved preset and Queue batch. It previously failed because the preset's
hidden mix normalization still reached the exporter. Stems batch members now
omit it while the saved preset and mix batch members retain it.

These changes do not alter the assistance runtime closure. A manual **Update AI
assets** run is **not required**.
