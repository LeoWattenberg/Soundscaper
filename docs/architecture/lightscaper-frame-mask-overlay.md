# Temporary Frame image mask presentation

The existing Effect → Image masks menu opens the selected static image's mask
manager. Source1, Source2 and Source3 use the same selected-store authority;
none acquires a Photo identity or another writer. The opted-in dialog shows its
local rendered draft. Mask coverage starts off and requires an explicit bound
adjustment; color and grayscale are presentation choices, never recipe fields.

The manager can rename, duplicate, remove, combine and rebind its local masks.
These changes render without publishing. Apply joins presentation work before
using the existing `image-source/set` command. An unchanged recipe preserves the
exact source, provenance and history. A changed recipe retains the immutable
pack and Original and records the actual Frame origin. Close discards the draft.
Direct Frame brush-body installation remains a subsequent authoring slice.

## Native draft authority

`withDraftFrame` captures the complete normalized recipe and the two retained
mask/effect IDs synchronously, inside the already registered operation, before
its optional renderer import can yield. The captured project, selected clip,
read-only state and complete project snapshot fence every borrow and delivery.
Raw Original and rendered draft work share one exclusive operation slot.

The private renderer prepares an ephemeral source with the existing command
preparer. It closes the complete next project resource namespace and
independently authenticates every retained LUT and brush body for each request,
including disabled effects and unused inputs. The open-time authentication of
the saved source does not authorize new draft declarations. Invalid bindings,
metadata and quotas fail before acquiring the canonical frame.

The existing native pack owner lends the authenticated raw canonical frame.
`withImageDevelopFrameV3` performs repairs and the full develop pipeline and
observes the selected adjustment's actual input coverage. Range masks therefore
see preceding repairs and effects, including geometry at that stage. The shared
renderer projects coverage through the remaining geometry to the final frame;
coverage is not recomputed from Original or from final After pixels. Disabled
bound adjustments remain observable without enabling them.

## Bounds and retirement

| Owned work | Bound |
| --- | --- |
| Canonical and render frame | 8192 per side; 16,777,216 pixels; 64 MiB RGBA |
| Mask evaluation and coverage projection | Existing 64 MiB working quota |
| Encoded snapshots, repair/render/resources and fitted presentation | Existing 512 MiB combined preflight |
| Fitted After and overlay | 2048 per side; 4,194,304 pixels; 16 MiB each |
| Persistent display targets | At most two fitted native canvases |

Preflight charges real canonical/render planes for Source1 as well as editable
sources. It includes the actual fitted display planes and their corresponding
canvas storage while the native render remains borrowed. No ceiling is raised.

The neutral presenter keeps at most one native render/display scope and one
replacement scalar request. Replacement aborts and joins its predecessor before
another Original borrow. Painting happens within the display callback; no JS
pixel plane survives that callback. Ready is published only after native frame,
coverage and resource scopes have retired. Apply and Close join the presenter,
and registered child retirement precedes the selected native owner's Close and
preview-suspension release.

A failed preview blocks Apply and keeps its exact failure in registered
retirement. User Close still joins the selected owner and forwards dismissal
once retirement settles, with the bounded diagnostic retained. A replacement
queued during pause regains its canvas targets before painting, so later Close
also clears both replacement planes.

Session Close seals admission, aborts its owned signal and joins accepted work.
Native and shared owners wipe every owned backing. Process1/2 delivery also
certifies physical frame and coverage retirement: transfer or detachment is a
failure even when the exposed view appears empty. Opaque primary errors and
independent retirement failures retain their identities.

## Qualification scope

Owning tests use actual selected Frame command owners and native Blob packs for
literal coverage, synchronous request capture, fresh resource authentication,
quota refusal, stale projects, exclusivity, cancellation and physical retirement.
Their deliberately enlarged scalar quota fixtures make no large-body or codec
claim. Presenter/dialog tests cover temporary choices and joined generations.

Native browser workflows author the Photo recipe and hand it to Frame through
real menus. Literal stage-specific coverage distinguishes repaired input,
preceding exposure, crop/flip suffix transport and boolean brush composition.
Native Save/reopen checks project, pack, Original and resource custody. The
headless Firefox timeline fallback is admitted only when a real WebGL2 probe is
unavailable; the dialog's 2D canvas still must paint the exact pixels.

WebKit, desktop and final broad inter-slice qualification remain outside this
bounded slice. No assistance runtime bytes or inventories change, so no manual
**Update AI assets** run is required.
