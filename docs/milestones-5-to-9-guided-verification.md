# Milestones 5–9 guided local verification

This is the checked-in local sign-off record for the work that milestones 5
through 9 still owe a person. It is the companion to the
[milestones 1–4 record](milestones-1-to-4-guided-verification.md), and it
covers only what a human must run, look at, listen to, operate with assistive
technology, or decide. Numbers a machine can produce are not here: the nightly
`Qualification metrics` workflow generates those, and
[quality budgets](quality-budgets.md) governs what they mean.

Do not replace an observed failure with `not-applicable`. Fix the defect, link
the issue, rebuild, and repeat the affected check. Do not fill a row in from a
neighbouring target, a neighbouring profile, or from intended rather than
observed hardware. A local sign-off is complete only when every required row
records `pass` against one build and commit.

Many rows below name an environment that is not provisioned today — the
owner-designated fixed-GPU host, the native OS lab matrix, the capture device
lab, and the release qualification matrix are all `unprovisioned` in
`config/quality-budgets.json`. Those rows are recorded as `blocked` with the
missing environment named in Notes, never as `pass` and never as
`not-applicable`.
