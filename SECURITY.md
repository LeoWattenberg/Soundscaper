# Security Policy

## Supported Versions

Versions before 1.0 are not hardened and not considered secure. For versions past that, only the latest version is considered supported.

## Reporting a Vulnerability

Contact support@soundscaper.org to report security vulnerabilities, a PGP key is available. Note that, since this for the most part an offline tool (for the downloads) / a static website (for the website), common vulnerabilities in used libraries are generally not applicable to this project. Before reporting, verify that you actually could attack a different user with your vulnerability.

Standard responsible disclosure terms apply. There are no bug bounties or rewards, but you may earn my eternal gratitude.
