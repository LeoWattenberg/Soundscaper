# Creative Commons license badges

The 80 × 15 SVG badges in this directory are from the official [Creative Commons downloads page](https://creativecommons.org/mission/downloads/):

| File | Source |
| --- | --- |
| `cc-zero.svg` | https://mirrors.creativecommons.org/presskit/buttons/80x15/svg/cc-zero.svg |
| `cc-by.svg` | https://mirrors.creativecommons.org/presskit/buttons/80x15/svg/by.svg |
| `cc-by-nc.svg` | https://mirrors.creativecommons.org/presskit/buttons/80x15/svg/by-nc.svg |

Only XML declarations, a generator comment, and the external DTD declaration were removed. The artwork is unchanged. Creative Commons' [trademark policy](https://creativecommons.org/policies/) permits these badges to describe the applicable CC legal tool when linked to its deed.
