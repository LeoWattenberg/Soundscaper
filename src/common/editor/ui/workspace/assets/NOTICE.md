# Creative Commons license icons

The 64 × 64 SVG icons in this directory are from the official [Creative Commons downloads page](https://creativecommons.org/mission/downloads/):

| File | Source |
| --- | --- |
| `cc-zero-icon.svg` | https://mirrors.creativecommons.org/presskit/icons/zero.svg |
| `cc-by-icon.svg` | https://mirrors.creativecommons.org/presskit/icons/by.svg |
| `cc-nc-icon.svg` | https://mirrors.creativecommons.org/presskit/icons/nc.svg |

Only XML declarations, a generator comment, and the external DTD declaration were removed, and line endings were normalized. The artwork is unchanged. Creative Commons' [trademark policy](https://creativecommons.org/policies/) permits these icons to describe the applicable CC legal tool when linked to its deed.
