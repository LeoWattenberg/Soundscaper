When a long recording contains one good take, it is quicker to select the take and throw away the rest than to delete the surroundings in pieces. Trim keeps the selection and removes the audio on both sides of it.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Remove Special → Trim Audio**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Drag in the ruler above the clip, from the quarter point to the three-quarter point of the clip, to select that range. Select the passage you want to keep.
4. Choose **Edit → Remove special → Trim audio outside selection**.
5. The project now shows 1 clip.
   *You should see:* Only the selected passage remains on the track.

## Tips

- The trimmed clip stays where it was on the timeline. Drag it to the start if you want it to begin at zero.
- Trim is an edit like any other; **Edit → Undo** restores what was outside the selection.
