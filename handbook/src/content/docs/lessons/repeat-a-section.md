A two-bar loop, a background bed that needs to run under a longer voice-over, a sound effect that should go on: Repeat copies the selection straight after itself as many times as you ask.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Special → Repeat**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Special → Repeat**. In the **Repeat** dialog, set **Number of repeats** to `2`, then press **Apply to selection**. Two repeats give three copies in a row.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop plays three times without a gap.

## Tips

- For a seamless loop, make sure the selection starts and ends on silence or at a zero crossing (**Select → At zero crossings**).
- The effect changes the length of the clip, so anything after it on the same track is pushed along.
