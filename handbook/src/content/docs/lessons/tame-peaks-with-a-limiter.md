A limiter is a compressor with a very high ratio: below the threshold it does nothing, and above it nothing gets through. It is the tool for catching a few stray peaks before export, or for raising the overall level of a mix without the peaks clipping.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Volume and Compression → Limiter**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Volume and compression → Limiter (Audacity)**. In the **Limiter (Audacity)** dialog, set **Threshold** to `-6`, then press **Apply to selection**. Nothing will exceed −6 dB. The make-up target then lifts the result so the ceiling sits near full scale.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loudest moments are held down; the rest is unchanged.

## Tips

- Use a limiter for peaks and a [compressor](/lessons/even-out-volume-with-a-compressor/) for overall evenness; they are not the same job.
- Heavy limiting makes everything feel loud and flat. If you need more than a few decibels, the mix itself is probably too hot.
