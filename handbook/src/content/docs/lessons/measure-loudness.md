Before you normalize or export, it helps to know where you are. The EBU R 128 analyzer measures the programme the way streaming platforms and broadcasters do — integrated loudness in LUFS, loudness range, and true peak — so you can compare against a target instead of guessing from the meter.

:::note[Coming from Audacity?]
This is Audacity's **Analyze → Measure RMS, or Loudness Normalization’s measurement**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyze → EBU R 128**. The **EBU R 128** panel opens with the result.
   *You should see:* Integrated loudness, loudness range and true peak for the selection.

## Tips

- Podcast platforms commonly ask for −16 LUFS stereo or −19 LUFS mono with true peaks below −1 dBTP; check the platform’s own guidance.
- If the numbers are far from the target, run [Loudness Normalization](/lessons/normalize-loudness-for-podcasts/) and measure again.
