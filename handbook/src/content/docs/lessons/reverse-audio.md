Reverse flips the selection in time. It is an effect for sound design — reversed cymbals, swelling pre-echoes — and occasionally for checking whether a room’s reverb tail hides anything.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Special → Reverse**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Special → Reverse**. The effect applies to the selection straight away.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop plays backwards.

## Tips

- Apply Reverse twice and you are back where you started, sample for sample.
- Reverse a short selection at the start of a clip to build a swell that leads into it.
