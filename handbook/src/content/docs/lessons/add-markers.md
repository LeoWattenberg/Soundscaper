Markers are notes on the timeline: where a chapter starts, where a mistake needs fixing, where the good take begins. They do not change the audio, they travel with the project, and they can be exported as a label file for other tools.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Labels → Add Label at Selection (Ctrl+B)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **View → Show markers**. This adds a marker lane above the tracks. Markers exist without it, but the lane is where you see and edit them.
4. Click the waveform halfway through to put the cursor there. The marker goes where the cursor is.
5. Choose **View → Panels → Markers** to show the Markers panel, then press **Add marker at playhead**. Press Enter on the new marker, type `Chorus` and press Enter again to name it.
   *You should see:* The marker shows in the lane above the tracks and in the panel’s list, with the name you typed.

## Tips

- With a time range selected, the same button adds a named region instead of a single point.
- **File → Export other → Export labels** writes the markers as a text file that Audacity and other editors can read.
