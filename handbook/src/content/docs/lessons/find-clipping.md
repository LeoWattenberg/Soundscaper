A recording made too hot flattens against the top of the range and distorts. The damage is easy to hear but hard to find by eye in a long take. Find Clipping scans the selection and lists every run of samples that sits at full scale, so you can decide whether to repair, redo or live with each one.

:::note[Coming from Audacity?]
This is Audacity's **Analyze → Find Clipping**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-clicky-take.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyze → Find clipping**. The **Find clipping** panel opens with the result.
   *You should see:* A list of the clipped runs, or a note that none were found.

## Tips

- Turning a clipped recording down does not repair it; the flattened peaks stay flattened. **Effect → Noise removal and repair → Repair** can rebuild a very short clipped run.
- To avoid clipping next time, record with peaks around −12 dB and raise the level afterwards.
