Echo plays the selection again after a delay, then again, each repeat quieter than the last. It is the classic slap-back on a vocal or the canyon effect on a shout.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Delay and Reverb → Echo**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Delay and reverb → Echo**. In the **Echo** dialog, set **Decay factor** to `0.4`, then press **Apply to selection**. Each repeat is 0.4 times as loud as the one before it, so the echo dies away after a few repeats. **Delay time** sets the gap between them.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop is followed by fading repeats of itself.

## Tips

- Add a second or two of silence after the clip first (**Generate → Silence**) so the last repeats have room to sound.
- For a room rather than distinct repeats, use [Reverb](/lessons/add-reverb/).
