Once a bed of tracks is balanced, mixing them down to one makes the project lighter to work with and gives you a single clip to export or take elsewhere. The mix uses each track’s gain, pan, mute and effects, exactly as playback does.

:::note[Coming from Audacity?]
This is Audacity's **Tracks → Mix → Mix and Render**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-second-loop.wav`. The file lands as a clip on its own track.
4. Click the name bar of the `lesson-music-loop.wav` clip, then hold Shift and click the name bar of `lesson-second-loop.wav`, so both are selected. Every track with a selected clip goes into the mix.
5. Choose **Tracks → Mix → Mix-down to**.
6. The project now shows a clip named **Mix**.
   *You should see:* One track holds a clip named Mix; the source tracks are gone.

## Tips

- **Edit → Undo** brings the original tracks back if you need to change the balance.
- You do not have to mix down to export. **File → Export audio** renders the whole project on its own.
