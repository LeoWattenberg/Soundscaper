Beat Finder is one of the bundled Nyquist analyzers. It listens for sudden rises in level above a threshold and writes a label at each one, which is a quick way to mark the beats of a loop or the hits in a drum take before you cut it up.

:::note[Coming from Audacity?]
This is Audacity's **Analyze → Beat Finder**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This lesson uses `lesson-gapped-take.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyze → Nyquist → Beat Finder**. In the **Beat Finder** dialog, set **Threshold Percentage** to `60`, then press **Apply**. The dialog reports what it found; press **Close** to dismiss it. A lower percentage finds quieter beats as well; raise it if it marks too much.
5. The project now shows a track named **Beat Finder**.
   *You should see:* A new label track named Beat Finder under the audio, with one label at each beat.

## Tips

- The labels land on a new label track under the audio. Rename or delete any the analyzer got wrong.
- **Analyze → Nyquist → Label Sounds** does a similar job for whole sounds separated by silence.
