## À quoi sert ce guide {#what-this-guide-is-for}

AIFF est un format PCM non compressé souvent utilisé dans les flux de travail audio sur les systèmes Apple. Exportez dans ce format si l’application destinataire ou les spécifications de livraison l’exigent.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **File → Export Audio → Other uncompressed files → AIFF (Audacity 3)**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez l’enregistrement ou le mixage à livrer. Il apparaît sous forme de clip sur sa propre piste.
3. Choisissez **Fichier → Exporter l'audio**, réglez **Format** sur **AIFF**, puis cliquez sur **Exporter**. Le fichier est téléchargé dès que le rendu est terminé et son lien reste dans la boîte de dialogue.
   *Vous devriez voir :* La boîte de dialogue d’exportation propose un fichier `.aiff` à télécharger.

## Conseils

- AIFF est sans perte, mais prend plus de place que les formats compressés tels que [FLAC](/guides/tracks-and-export/export-a-flac/).
- Choisissez un format d’échantillonnage et une fréquence d’échantillonnage conformes aux exigences de livraison.
