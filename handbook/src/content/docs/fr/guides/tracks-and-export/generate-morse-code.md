## À quoi sert ce guide {#what-this-guide-is-for}

Le Morse encode un message en points, traits et espaces temporisés. Le générateur prévisualise le code et calcule la durée du clip selon le texte et la vitesse.

:::note[Vous venez d'Audacity ?]
Dans Audacity, cela correspond à **No directly matching built-in Morse code generator**. Les noms ci-dessous sont propres à Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un projet vide est prêt dès le chargement de l’éditeur.
2. Choisissez **Générer → Générateur Morse**. Dans **Générateur Morse**, réglez **Message** sur `SOS`, **Vitesse (mots par minute)** sur `20`, **Fréquence (Hz)** sur `600` et **Amplitude** sur `0.2`, puis cliquez sur **Générer**. Remplacez l’exemple par votre texte et vérifiez l’aperçu ; les caractères non pris en charge bloquent la génération.
3. Le projet contient maintenant 1 clip.
   *Vous devriez voir :* Le clip Morse contient le message ; sa durée dépend de la vitesse choisie.

## Conseils

- Une vitesse plus faible allonge les points, traits et espaces sans changer la hauteur du ton.
- Duration est en lecture seule. Modifiez le message ou la vitesse pour changer la durée.
