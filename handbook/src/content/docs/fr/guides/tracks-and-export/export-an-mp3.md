Un MP3 est petit, se lit partout et est le format attendu par la plupart des hôtes de podcasts et des applications de messagerie. L'exportation rend l'intégralité du projet — chaque piste, effet et édition — dans un seul fichier.

:::note[Venez-vous d'Audacity ?]
C'est l'équivalent de **Fichier → Exporter l'audio → MP3** dans Audacity. Les noms ci-dessous sont ceux de Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l'éditeur se charge.
2. Choisissez **Fichier → Importer l'audio** et sélectionnez l'enregistrement à publier. Le fichier apparaît comme un clip sur sa propre piste.
3. Choisissez **Fichier → Exporter l'audio**, définissez le **Format** sur **MP3** et appuyez sur **Exporter**. Le fichier est téléchargé dès que le rendu est terminé, et son lien reste dans la boîte de dialogue. Le fichier est encodé dans le navigateur ; rien ne quitte votre ordinateur.

## Conseils

- Un MP3 est une copie de livraison, pas une sauvegarde. Conservez le projet ou exportez également un WAV si vous pourriez rééditer.
- Des pics juste à l'échelle maximale peuvent être rognés après encodage. Normalisez à −1 dB ou moins avant l'exportation.
- Le mode de débit binaire détermine comment l'encodeur utilise les bits. Le préréglage Standard varie le débit pour s'adapter au matériel et est la bonne réponse pour la plupart des livraisons ; choisissez Constant si un hôte ou un lecteur matériel plus ancien exige un débit fixe unique.
