Avec une douzaine de pistes, les couper une par une pour écouter une nouvelle partie est fastidieux, et les réactiver ensuite l'est encore plus. Couper le son de toutes les pistes silencie l'ensemble du projet en une seule commande et Réactiver toutes les pistes le restaure, sans toucher les boutons solo. Audacity 3 possédait ces deux commandes; Audacity 4 ne les a pas réintroduites.

:::note[Venant d'Audacity ?]
Ceci correspond à **Pistes → Mute/Unmute → Couper le son de toutes les pistes et Réactiver toutes les pistes (Audacity 3 ; non disponible dans Audacity 4)**. Les noms ci-dessous sont propres à Soundscaper et peuvent parfois différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez le premier enregistrement. Le fichier s'ajoute en tant que clip sur sa propre piste.
3. Choisissez **Fichier → Importer audio** et sélectionnez le deuxième enregistrement. Le fichier s'ajoute en tant que clip sur sa propre piste.
4. Choisissez **Pistes → Couper le son de toutes les pistes**.
5. Le projet affiche désormais le bouton **Couper le son** allumé pour chaque piste.
   *Vous devriez voir :* La lecture est silencieuse.
6. Choisissez **Pistes → Réactiver toutes les pistes**.
7. Le projet affiche désormais aucune piste coupée.
   *Vous devriez voir :* Tout se joue à nouveau.

## Conseils

- Coupez le son de tout, puis réactivez une ou deux pistes que vous souhaitez entendre — plus rapide que le solo lorsque la sélection change fréquemment.
- Pour entendre une piste seule sans toucher les autres, [mettez-la en solo](/guides/tracks-and-export/mute-and-solo-tracks/) à la place.
