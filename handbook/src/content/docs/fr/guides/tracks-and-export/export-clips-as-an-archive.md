## À quoi sert ce guide {#what-this-guide-is-for}

L’export de clips individuels conserve chaque montage dans un fichier audio distinct et rassemble les fichiers dans une seule archive. Découpez d’abord le passage en clips, puis choisissez le mode de sortie par clips dans la boîte de dialogue d’exportation.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **File → Export Audio → Multiple Files (répartis par pistes ou étiquettes, Audacity 3)**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez l’enregistrement dont vous souhaitez exporter séparément les clips. Il apparaît sous forme de clip sur sa propre piste.
3. Faites glisser le curseur dans la règle au-dessus du clip pour sélectionner le passage à exporter comme clip distinct.
4. Choisissez **Édition → Clips audio → Diviser**.
5. Choisissez **Fichier → Exporter l'audio**, réglez **Format** sur **WAV**, **Sortie** sur **Clips individuels (séparés par clip)**, puis cliquez sur **Exporter**. Le fichier est téléchargé dès que le rendu est terminé et son lien reste dans la boîte de dialogue. Chaque clip est rendu sous forme de WAV distinct dans une seule archive ZIP.

## Conseils

- Donnez des noms explicites aux clips avant l’exportation pour identifier les fichiers dans l’archive.
- Choisissez **Projet entier** pour obtenir un mixage unique plutôt que des fichiers séparés par clip.
