Le détecteur de rythme est l'un des analyseurs Nyquist inclus. Il écoute les augmentations soudaines du niveau au-dessus d'un seuil et écrit une étiquette à chaque fois, ce qui permet de marquer rapidement les rythmes d'une boucle ou les coups dans une prise de batterie avant de la découper.

:::note[Venant d'Audacity ?]
Il s'agit de **Analyse → Détecteur de rythme** d'Audacity. Les noms ci-dessous sont propres à Soundscaper et peuvent parfois différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer** et sélectionnez l'enregistrement que vous souhaitez marquer. Il apparaît sous forme de clip sur sa propre piste.
3. Choisissez **Sélection → Sélectionner tout**.
4. Choisissez **Analyser → Nyquist → Détecteur de rythme**. Dans la boîte de dialogue **Détecteur de rythme**, définissez le **Seuil en pourcentage** à `60`, puis appuyez sur **Appliquer**. La boîte de dialogue affiche ce qu'elle a trouvé ; appuyez sur **Fermer** pour l'dismissr. Un pourcentage plus bas détecte également les rythmes plus calmes ; augmentez-le si trop d'éléments sont marqués.
5. Le projet affiche désormais une piste nommée **Détecteur de rythme**.
   *Vous devriez voir :* Une nouvelle piste d'étiquettes nommée Détecteur de rythme sous l'audio, avec une étiquette à chaque rythme.

## Conseils

- Les étiquettes apparaissent sur une nouvelle piste d'étiquettes sous l'audio. Renommez ou supprimez celles que l'analyseur a mal placées.
- **Analyser → Nyquist → Étiqueter les sons** effectue une tâche similaire pour les sons entiers séparés par des silences.
