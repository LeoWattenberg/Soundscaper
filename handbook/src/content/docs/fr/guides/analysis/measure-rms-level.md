## À quoi sert ce guide {#what-this-guide-is-for}

Le RMS est une mesure moyenne du niveau du signal au fil du temps. Utilisez l’analyseur Measure RMS pour comparer des sections ou vérifier le niveau d’un passage avant de le régler.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **Analyze → Measure RMS (Nyquist)**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez le passage dont vous souhaitez mesurer le niveau moyen. Il apparaît sous forme de clip sur sa propre piste.
3. Choisissez **Sélectionner → Tout sélectionner**.
4. Choisissez **Analyser → Nyquist → Measure RMS**. Dans la boîte de dialogue **Measure RMS**, cliquez sur **Appliquer**. Le rapport affiche les résultats ; cliquez sur **Fermer** pour fermer la boîte de dialogue.
   *Vous devriez voir :* Le rapport indique le niveau RMS en dB de chaque canal et du signal stéréo.

## Conseils

- Le RMS décrit le niveau moyen ; utilisez [peak normalization](/guides/volume/normalize-peaks/) lorsque vous devez régler l’échantillon le plus élevé sur une cible.
- Ne sélectionnez que la section à comparer afin que les sons sans rapport n’influencent pas la mesure.
