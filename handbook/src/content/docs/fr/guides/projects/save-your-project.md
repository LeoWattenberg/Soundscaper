Un projet est plus que l'audio : ce sont les pistes, les clips, les effets, les marqueurs et l'historique. L'enregistrement conserve tout cela dans la bibliothèque de projets locaux du navigateur sur cet ordinateur, où il peut être rouvert à partir du menu Fichier. Soundscaper enregistre également en continu, donc c'est surtout une façon de se rassurer.

:::note[Venant d'Audacity ?]
Il s'agit de **Fichier → Enregistrer le projet** d'Audacity. Les noms ci-dessous sont propres à Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez quelque chose sur lequel travailler. Le fichier atterrit en tant que clip sur sa propre piste.
3. Choisissez **Fichier → Enregistrer le projet**. L'indicateur d'enregistrement dans la barre d'état indique que le projet est enregistré.

## Conseils

- Pour déplacer un projet vers un autre ordinateur ou conserver une copie en dehors du navigateur, voir [Déplacer un projet entre les ordinateurs](/guides/projects/move-a-project-between-computers/).
- Une exportation audio est une copie d'écoute, pas un projet. Conservez le projet si vous devez à nouveau l'éditer.
