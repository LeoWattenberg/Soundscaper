Les projets créés dans Audacity 3 (.aup3) et Audacity 4 (.aup4) s'ouvrent directement. Les pistes, les clips, les noms et les positions sont conservés ; les effets dont Soundscaper ne dispose pas sont listés afin que vous sachiez quoi vérifier. Le fichier d'origine n'est pas modifié.

:::note[Vous venez d'Audacity ?]
Il s'agit de la commande **Fichier → Ouvrir** d'Audacity. Les noms ci-dessous sont ceux de Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l'éditeur se charge.
2. Choisissez **Fichier → Ouvrir** et sélectionnez le projet. Ses pistes et ses clips apparaissent tels qu'ils étaient dans Audacity.
3. Le projet affiche désormais un clip nommé **Audio 1** et une piste nommée **Fixture track**.
   *Vous devriez voir :* La piste et le clip du projet Audacity, avec leurs noms.

## Conseils

- Un projet ancien de type `.aup` nécessite son dossier `_data` à côté de lui ; sélectionnez les deux lorsqu'on vous le demande.
- **Fichier → Exporter autre → Exporter AUP4** va dans l'autre sens, pour rendre un projet à Audacity.
