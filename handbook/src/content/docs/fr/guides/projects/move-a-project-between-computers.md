La bibliothèque de projets se trouve dans un seul navigateur sur un seul ordinateur. Pour transporter un projet ailleurs — sur une autre machine, chez un collègue, sur un disque de sauvegarde — exportez-le en tant que fichier de projet. Le fichier `.sscape` contient l'audio et toutes les modifications, et s'ouvre dans n'importe quel Soundscaper.

:::note[Venez d'Audacity ?]
C'est l'équivalent d'**Fichier → Enregistrer le projet → Sauvegarder le projet, puis Fichier → Ouvrir** dans Audacity. Les noms ci-dessous sont ceux de Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l'éditeur se charge.
2. Choisissez **Fichier → Importer l'audio** et sélectionnez le matériel du projet. Le fichier apparaît en tant que clip sur sa propre piste.
3. Choisissez **Fichier → Exporter le fichier de projet (.sscape)**. L'ensemble du projet est téléchargé en tant que fichier `.sscape`. Conservez le fichier dans un endroit sûr ; c'est le projet complet.
4. Choisissez **Fichier → Ouvrir le fichier de projet Scape (.sscape)** et sélectionnez le fichier. Sur un ordinateur qui n'a pas encore le projet, il s'ouvre directement ; ici, où la bibliothèque le contient déjà, Soundscaper propose **Ouvrir en copie en lecture seule** — appuyez dessus.
   *Vous devriez voir :* Le projet s'ouvre avec sa piste et son clip exactement comme exporté.

## Conseils

- Une copie en lecture seule ne peut pas être modifiée tant que vous ne l'avez pas enregistrée en tant que projet distinct depuis le menu Fichier.
- Le fichier est une archive ZIP contenant l'audio ; ne la décompressez pas manuellement.
