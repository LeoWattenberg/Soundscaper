Copier un bon refrain pour remplacer un mauvais, répéter une mesure, déplacer une phrase à la fin : le copier-coller fonctionne sur l'audio de la même manière que sur le texte. Sélectionnez un passage, copiez-le, placez le curseur à l'endroit souhaité, puis collez-le.

:::note[Venez d'Audacity ?]
C'est l'équivalent de **Édition → Copier, puis Édition → Coller (Ctrl+C, Ctrl+V)** dans Audacity. Les noms ci-dessous sont spécifiques à Soundscaper et peuvent parfois différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l'éditeur se charge.
2. Choisissez **Fichier → Importer l'audio** et sélectionnez l'enregistrement contenant le passage que vous souhaitez copier. Le fichier apparaît sous forme de clip sur sa propre piste.
3. Faites glisser la règle au-dessus du clip pour sélectionner le passage à copier.
4. Choisissez **Édition → Copier**.
5. Cliquez sur la forme d'onde à l'endroit où la copie doit se trouver pour y placer le curseur. Le collage se fait à l'emplacement du curseur ; la fin du clip est l'endroit habituel.
6. Choisissez **Édition → Coller → Coller**.
7. Le projet affiche désormais 2 clips.
   *Vous devriez voir :* Le passage copié est un nouveau clip après l'original.

## Conseils

- **Édition → Coller → Insérer** décale l'audio ultérieur au lieu de superposer le collage dessus.
- Le presse-papiers fonctionne entre les onglets de projet, ce qui permet de copier un passage d'un projet vers un autre.
