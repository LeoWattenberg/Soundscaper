Une boucle de deux mesures, un lit de fond qui doit fonctionner sous un voice-over plus long, un effet sonore qui doit continuer : Répéter copie la sélection juste après elle-même autant de fois que vous le demandez.

:::note[Venant d'Audacity ?]
C'est l'effet **Effet → Spécial → Répéter** d'Audacity. Les noms ci-dessous sont propres à Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez le son que vous souhaitez répéter. Le fichier atterrit sous forme de clip sur sa propre piste.
3. Choisissez **Sélection → Sélectionner tout**.
4. Choisissez **Effet → Spécial → Répéter**. Dans la boîte de dialogue **Répéter**, définissez le **Nombre de répétitions** sur `2`, puis appuyez sur **Appliquer à la sélection**. Deux répétitions donnent trois copies consécutives.
5. Appuyez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez voir :* Le passage joue trois fois sans interruption.

## Conseils

- Pour une boucle sans couture, assurez-vous que la sélection commence et se termine sur un silence ou à un croisement nul (**Sélection → Aux croisements nuls**).
- L'effet modifie la longueur du clip, donc tout ce qui se trouve après celui-ci sur la même piste est décalé.
