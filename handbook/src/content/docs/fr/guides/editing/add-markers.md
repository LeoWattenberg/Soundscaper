Les marqueurs sont des notes sur la ligne de temps : où commence un chapitre, où une erreur doit être corrigée, où commence la bonne prise. Ils n'altèrent pas l'audio, ils accompagnent le projet et peuvent être exportés sous forme de fichier d'étiquettes pour d'autres outils.

:::note[Venant d'Audacity ?]
C'est l'équivalent de **Édition → Étiquettes → Ajouter une étiquette à la sélection (Ctrl+B)** dans Audacity. Les noms utilisés ci-dessous sont propres à Soundscaper et parfois différents.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez l'enregistrement que vous souhaitez annoter. Le fichier est placé sous forme de clip sur sa propre piste.
3. Choisissez **Vue → Afficher les marqueurs**. Cela ajoute une piste de marqueurs au-dessus des pistes. Les marqueurs existent sans elle, mais c'est dans cette piste que vous les voyez et les modifiez.
4. Cliquez sur la forme d'onde à l'endroit où le marqueur doit être placé pour positionner le curseur. Le marqueur sera placé à l'emplacement du curseur.
5. Avec le panneau Marqueurs ouvert (**Vue → Panneaux → Marqueurs**), appuyez sur **Ajouter un marqueur à la tête de lecture**. Appuyez sur Entrée sur le nouveau marqueur, tapez `Chorus` et appuyez à nouveau sur Entrée pour le nommer. 
   *Vous devriez voir :* Le marqueur apparaît dans la piste au-dessus des pistes et dans la liste du panneau, avec le nom que vous avez tapé.

## Conseils

- Avec une plage horaire sélectionnée, le même bouton ajoute une région nommée au lieu d'un seul point.
- **Fichier → Exporter autre → Exporter les étiquettes** enregistre les marqueurs dans un fichier texte lisible par Audacity et d'autres éditeurs.
