La fonction Dupliquer copie la sélection sur une nouvelle piste directement en dessous, à la même position dans le temps. C'est généralement la première étape pour le traitement parallèle — une copie fortement compressée mélangée sous l'original, une piste uniquement avec réverbération, un chant doublé, etc.

:::note[Venant d'Audacity ?]
C'est le **Édition → Dupliquer (Ctrl+D)** d'Audacity. Les noms ci-dessous sont propres à Soundscaper et peuvent parfois différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez l'enregistrement avec le passage à dupliquer. Le fichier s'ajoute en tant que clip sur sa propre piste.
3. Faites glisser le curseur au-dessus du clip pour sélectionner le passage à dupliquer.
4. Choisissez **Édition → Dupliquer**.
5. Le projet affiche maintenant 2 clips.
   *Vous devriez voir :* Un deuxième clip contenant uniquement la sélection, sur une nouvelle piste sous la première, alignée dans le temps.

## Conseils

- Mutez l'une des deux pistes pour entendre l'autre seule pendant que vous la façonnez.
- Lorsque vous êtes satisfait du mélange, [mixez les pistes](/guides/tracks-and-export/mix-tracks-into-one/).
