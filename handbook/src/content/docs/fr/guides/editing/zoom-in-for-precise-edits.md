Au zoom par défaut, une chanson entière s'affiche à l'écran et un seul mot occupe quelques pixels de large. En zoomant, vous pouvez placer le curseur exactement sur un temps ou dans l'espace entre deux mots ; le zoom sur la sélection encadre uniquement le passage sur lequel vous travaillez.

:::note[Provenant d'Audacity ?]
Il s'agit de **Vue → Zoom (Ctrl+1, Ctrl+2, Ctrl+3)** dans Audacity. Les noms ci-dessous sont propres à Soundscaper et parfois différents.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez l'enregistrement que vous souhaitez éditer en détail. Le fichier est placé sous forme de clip sur sa propre piste.
3. Choisissez **Vue → Zoom → Zoomer**. Chaque étape double la largeur d'une seconde. Ctrl+1 produit le même effet.
4. Choisissez **Vue → Zoom → Zoomer**.
5. Faites glisser dans la règle au-dessus du clip pour sélectionner le passage sur lequel vous souhaitez travailler.
6. Choisissez **Vue → Zoom → Zoom sur la sélection**. La sélection remplit désormais la chronologie.
7. Choisissez **Vue → Zoom → Zoom normal**. Ctrl+2 rétablit le zoom par défaut.

## Conseils

- Ctrl et la molette de la souris permettent de zoomer autour du pointeur, ce qui est le moyen le plus rapide de se concentrer sur un point précis.
- Le zoom ne modifie en rien le projet ; il ne concerne que votre vue.
