## À quoi sert ce guide {#what-this-guide-is-for}

Spectral Amplify augmente une bande de fréquences uniquement dans la plage temporelle sélectionnée. Une légère amplification peut faire ressortir un son ou un détail discret sans augmenter tout l’enregistrement.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **Effect → Spectral Tools → Amplify selection (Audacity 4)**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez l’enregistrement contenant un détail discret à mettre en évidence. Il apparaît sous forme de clip sur sa propre piste.
3. Ouvrez le menu de la piste à examiner avec le bouton **Options de piste** de son en-tête, puis choisissez **Visualisation de piste → Spectrogramme**.
4. Faites glisser le curseur dans la règle au-dessus du clip pour sélectionner le passage contenant le détail.
5. Choisissez **Effet → Modification spectrale → Sélectionner la plage de fréquences spectrales**. Réglez **Fréquence minimale (Hz)** sur `200` et **Fréquence maximale (Hz)** sur `320`, réglez **Gain (dB)** sur `4`, puis cliquez sur **Amplification spectrale**. Une amplification modérée de 4 dB relève uniquement la bande choisie pendant ce passage.
6. Cliquez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez constater :* Le détail sélectionné ressort davantage dans ce passage, tandis que le niveau du reste reste inchangé.

## Conseils

- Resserrez les limites fréquentielles autour du détail recherché ; une bande plus large amplifie aussi les sons voisins.
- Réduisez le gain si le passage amplifié devient agressif ou plus fort que le reste.
