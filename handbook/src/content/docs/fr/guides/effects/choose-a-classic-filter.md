## À quoi sert ce guide {#what-this-guide-is-for}

Classic Filters propose des modèles Butterworth et Chebyshev, avec un ordre et une coupure explicites. Le passe-bas Butterworth conserve une bande passante régulière et convient pour réduire les bruits aigus.

:::note[Vous venez d'Audacity ?]
Dans Audacity, cela correspond à **Effect → Legacy → Classic Filters (Audacity 3.6.2 and later)**. Les noms ci-dessous sont propres à Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un projet vide est prêt dès le chargement de l’éditeur.
2. Choisissez **Fichier → Importer** et sélectionnez l’enregistrement dont vous voulez réduire les hautes fréquences. Le clip apparaît sur sa propre piste.
3. Choisissez **Sélectionner → Tout sélectionner**.
4. Choisissez **Effet → Effets obsolètes → Filtres classiques**. Dans **Filtres classiques**, choisissez **Butterworth** pour **Famille de filtres** et **Passe-bas** pour **Type de filtre**. Réglez **Ordre** sur `4` et **Fréquence de coupure** sur `5000`, puis cliquez sur **Appliquer sur la sélection**. Butterworth garde une bande passante régulière ; l’ordre quatre coupe plus vite que l’ordre un.
5. Appuyez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez voir :* Les hautes fréquences au-dessus de la coupure sont réduites, tandis que les graves restent dans la bande passante.

## Conseils

- Augmentez **Ordre** pour une transition plus raide ; un ordre élevé peut faire résonner les transitoires.
- Dans les manuels Audacity actuels, Classic Filters se trouve dans Legacy effects. Activez-le dans Plugin Manager s’il manque.
