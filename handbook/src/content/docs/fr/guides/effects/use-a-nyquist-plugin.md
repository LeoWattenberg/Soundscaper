Les plug-ins Nyquist d'Audacity sont de petits scripts qui ajoutent des effets, des générateurs et des analyseurs. Soundscaper regroupe les mêmes sous un sous-menu Nyquist dans chaque menu. Tremolo est un bon premier choix : il fait varier le volume à une fréquence donnée.

:::note[Venant d'Audacity ?]
Il s'agit de **Effet → Tremolo (un plug-in Nyquist)** d'Audacity. Les noms ci-dessous sont propres à Soundscaper et peuvent parfois différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès le chargement de l'éditeur.
2. Choisissez **Fichier → Importer audio** et sélectionnez l'enregistrement sur lequel vous souhaitez tester le plug-in. Le fichier est placé sous forme de clip sur sa propre piste.
3. Choisissez **Sélection → Sélectionner tout**.
4. Choisissez **Effet → Nyquist → Tremolo**. Dans la boîte de dialogue **Tremolo**, définissez la **Fréquence (Hz)** à `6`, puis appuyez sur **Appliquer**. Six wobbles par seconde est un tremolo d'ampli classique.
5. Appuyez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez voir :* L'enregistrement varie en volume.

## Conseils

- Les menus Générer et Analyser ont également leurs propres sous-menus Nyquist, avec des plug-ins tels que Pluck et Beat Finder.
- **Outils → Invite Nyquist** exécute un script que vous tapez vous-même.
