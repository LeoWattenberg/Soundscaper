## À quoi sert ce guide {#what-this-guide-is-for}

Un sifflement régulier ou un son électronique peut occuper une petite bande de fréquences pendant une partie seulement de l’enregistrement. Spectral Delete supprime cette bande dans la sélection temporelle tout en préservant les fréquences voisines.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **Effect → Spectral Tools → Delete selection (Audacity 4)**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez l’enregistrement qui contient un bref son tonal. Il apparaît sous forme de clip sur sa propre piste.
3. Ouvrez le menu de la piste à examiner avec le bouton **Options de piste** de son en-tête, puis choisissez **Visualisation de piste → Spectrogramme**.
4. Faites glisser le curseur dans la règle au-dessus du clip pour sélectionner la période pendant laquelle le son est audible.
5. Choisissez **Effet → Modification spectrale → Sélectionner la plage de fréquences spectrales**. Réglez **Fréquence minimale (Hz)** sur `200` et **Fréquence maximale (Hz)** sur `320`, puis cliquez sur **Suppression spectrale**. Cela réduit le ton de 261,6 Hz de la boucle uniquement pendant la période choisie.
6. Cliquez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez voir :* Le son tonal est atténué dans ce passage, tandis que le reste de l’enregistrement demeure inchangé.

## Conseils

- Repérez le ton dans le spectrogramme, puis resserrez les limites temporelles et fréquentielles autour de lui avant de le supprimer.
- Spectral Delete agit uniquement sur la plage temporelle et fréquentielle sélectionnée ; la commande Delete ordinaire supprime tout le passage sélectionné.
