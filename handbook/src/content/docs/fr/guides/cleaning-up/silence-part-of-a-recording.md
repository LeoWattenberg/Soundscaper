## À quoi sert ce guide {#what-this-guide-is-for}

Parfois, vous souhaitez supprimer un passage, mais pas le temps qu'il occupe — un téléphone qui sonne pendant une pause, un nom que vous devez biper. Le silencieux maintient l'enregistrement exactement aussi long qu'il était et ne fait que plate la partie sélectionnée.

:::note[Venant d'Audacity?]
C'est **Édition → Supprimer spécial → Silencer l'audio** d'Audacity. Les noms ci-dessous sont propres à Soundscaper, qui diffèrent parfois.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l'éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez l'enregistrement avec le passage à couper. Il atterrit en tant que clip sur sa propre piste.
3. Faites glisser la règle au-dessus du clip pour sélectionner uniquement la partie que vous souhaitez couper.
4. Choisissez **Édition → Supprimer spécial → Silencer l'audio**.
5. Le projet affiche maintenant 3 clips.
   *Vous devriez voir :* La forme d'onde est plate dans le nouveau clip central, entre l'audio inchangé de chaque côté.

## Conseils

- Le silence est une édition normale : **Édition → Annuler** rétablit l'audio.
- Pour supprimer le temps ainsi que le son, voir [Couper une erreur dans un enregistrement](/guides/editing/cut-out-a-mistake/).
