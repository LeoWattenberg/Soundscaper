## À quoi sert ce guide {#what-this-guide-is-for}

De longues pauses peuvent ralentir un discours, tandis que supprimer toutes les pauses peut le rendre difficile à suivre. Truncate Silence ne compresse que la partie excédentaire des pauses qui dépassent une durée minimale.

:::note[Vous venez d'Audacity ?]
Dans Audacity, l’équivalent est **Effect → Special → Truncate Silence**. Les noms ci-dessous sont ceux de Soundscaper et peuvent différer.
:::

## Étapes

1. Ouvrez Soundscaper. Un nouveau projet vide est prêt dès que l’éditeur se charge.
2. Choisissez **Fichier → Importer** et sélectionnez un enregistrement dont les pauses vous semblent trop longues. Il apparaît sous forme de clip sur sa propre piste.
3. Choisissez **Sélectionner → Tout sélectionner**.
4. Choisissez **Effet → Spécial → Couper le silence**. Dans la boîte de dialogue **Couper le silence**, réglez **Seuil** sur `-40`, **Silence minimal** sur `0.5`, choisissez **Compresser le silence excédentaire** pour **Action**, puis réglez **Compresser à** sur `50` et cliquez sur **Appliquer sur la sélection**. Les silences de plus de 0,5 seconde sont réduits de moitié pour leur durée excédentaire, tout en laissant une pause entre les phrases.
5. Cliquez sur **Lecture** pour écouter, puis sur **Arrêt**.
   *Vous devriez constater :* Les longues pauses sont raccourcies, mais il reste du silence entre les phrases.

## Conseils

- Augmentez **Silence minimal** pour laisser intactes les pauses plus courtes, ou réduisez **Compresser à** pour resserrer davantage les longues pauses.
- Vérifiez que les respirations et les fins de phrase ne sont pas coupées ; annulez si le rythme devient artificiel.
