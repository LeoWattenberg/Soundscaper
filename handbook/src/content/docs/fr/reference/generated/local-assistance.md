L'assistance locale est disponible dans Soundscaper et Framescaper. Les modèles sont stockés dans un répertoire que vous choisissez sur votre propre système de fichiers, et chaque exécution se produit sur votre appareil ; aucune information concernant vos médias n'est envoyée nulle part.

Un flux de travail est un graphe fixe d'étapes. Une étape qui nomme une opération exécute un modèle ; une étape qui n'en nomme aucune est déterministe et n'exécute aucun modèle. Une étape facultative est ignorée si son modèle n'est pas installé, et le flux de travail produit toujours un résultat à partir des étapes qui ont été exécutées.
