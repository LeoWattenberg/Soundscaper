Il s'agit des formats concrets enregistrés par l'environnement d'exportation actuel. La disponibilité des produits provient des profils de produits.

« Intégré » signifie que l'application dispose d'un écrivain natif pour ce format. « Runtime FFmpeg requis » est conditionnel : le tableau ne garantit pas que le runtime FFmpeg puisse être chargé dans chaque construction ou environnement, ni que un runtime de remplacement arbitraire contient l'encodeur et le multiplexeur répertoriés.

Les fichiers de projet et les fichiers d'étiquette sont répertoriés séparément dans [Fichiers de projet et d'étiquette](/reference/generated/project-files/).
