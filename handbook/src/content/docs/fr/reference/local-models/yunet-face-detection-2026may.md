## Objectif et cas d’utilisation {#purpose-and-use-case}

Localisez les visages et les objets dans les images vidéo échantillonnées pour proposer un nouveau cadrage.

YuNet détecte les visages et leurs emplacements. L'opération de détection de sujet combine ces résultats avec les détections d'objets D-FINE.

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur onnxruntime-node 1.29.0 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques. Il n’existe pas de moteur téléchargeable pour macOS x64, bien que les poids du modèle soient répertoriés pour cette plateforme.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Framescaper : Effet → Effets vidéo → Recadrage** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez une séquence vidéo dans Framescaper.
2. Installez YuNet et D-FINE pour la détection de sujets. La tâche Recadrage guidée utilise également la détection de salience U²-Net-P.
3. Exécutez-le localement et examinez le recadrage proposé. Outils → Traitement local avancé peut exécuter la détection de sujets indépendamment.

Cette opération nécessite également [D-FINE Nano détection d'objets](/reference/local-models/dfine-nano-coco/).

<summary>Ce que vérifie le test de bureau</summary>

Cas : `subject-detection` ; opération : `subject-detection`.

Entrée : Deux photographies : le portrait public de l'astronaute Eileen Collins de la NASA et la photographie de chat Chelsea CC0. Chacune est intégrée dans un cadre distinct avec un chronométrage de cadre source explicite, donnant aux détecteurs un visage humain et un objet clair.

Les résultats des visages et des objets doivent avoir un chronométrage de cadre source valide, des scores de confiance finis et des boîtes délimitées. Le dispositif de sujet doit produire des détections à partir des deux modèles.

Le package nightly-with-tests télécharge les vrais artefacts du modèle et les runtimes vérifiés avant l’inférence. Un modèle requis absent du catalogue fait échouer son cas. ## Examinez le résultat {#review-the-result}

- Les visages et les objets peuvent être manqués ou mal classés. La détection est échantillonnée et ne garantit pas qu'un sujet en mouvement reste à l'intérieur de chaque recadrage proposé.
- L'opération exécute les deux modèles ensemble ; aucun des modèles n'est un système de reconnaissance faciale pour identifier les personnes.
