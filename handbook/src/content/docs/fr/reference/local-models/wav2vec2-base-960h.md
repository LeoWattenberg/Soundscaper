## Objectif et cas d’utilisation {#purpose-and-use-case}

Alignez une transcription anglaise existante aux mots prononcés dans un enregistrement.

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur onnxruntime-node 1.29.0 requis pour macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Analyser → Parole → Transcrire & Sous-titres, ou Outils → Traitement local avancé → Alignement des mots** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez la parole et préparez ou révisez sa transcription anglaise.
2. Installez le modèle d'alignement via le Gestionnaire de modèles.
3. Exécutez l'alignement, puis écoutez tout en révisant les limites de mots proposées avant de les accepter.

## Téléchargement et exigences {#download-and-requirements}

Identité du modèle : `wav2vec2-base-960h`, version **1.0.0**.

Taille approximative du téléchargement de l’artefact du modèle : **360.38 MiB**. Le runtime requis s’ajoute au premier téléchargement s’il n’est pas déjà installé. Mémoire système minimale : **4 GiB**. Cette exigence du catalogue concerne la mémoire totale, et non la mémoire libre actuelle. L’inférence nécessite également suffisamment de mémoire libre et l’installation de l’espace disque ; la mémoire ne garantit pas la vitesse.

Plateformes publiées : macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Un runtime téléchargeable correspondant est également requis.

Sous Windows, installez le dernier [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) pris en charge et correspondant à l’application de bureau : **x64** pour une version x64 ou **ARM64** pour une version ARM64. Les moteurs ONNX et Sherpa natifs nécessitent ces bibliothèques ; les téléchargements du modèle et du runtime ne les incluent pas. Visual Studio lui-même n’est pas nécessaire pour utiliser l’application.

Outils → Gestionnaire de modèles télécharge les artefacts publiés du modèle et le runtime requis lors de la première installation, puis vérifie leurs empreintes SHA-256 enregistrées. Le traitement utilise les fichiers installés localement. Ouvrez Stockage et vérification dans le Gestionnaire de modèles pour consulter les avis, réparer une installation ou modifier l’emplacement de stockage.

<summary>Ce que vérifie le test de bureau</summary>

Cas : `wav2vec2-word-alignment` ; opération : `word-alignment`.

Entrée : Le discours de Kennedy du domaine public à 16 kHz, ainsi que sa transcription anglaise connue en tant qu'entrée authentifiée distincte.

Chaque mot fourni doit être représenté avec un horodatage valide et ordonné à l'intérieur de l'audio ; les horodatages d'alignement exacts ne sont pas prescrits.

Le package nightly-with-tests télécharge les vrais artefacts du modèle et les runtimes vérifiés avant l’inférence. Un modèle requis absent du catalogue fait échouer son cas. L’absence de moteurs natifs entraîne un échec sur les plateformes prises en charge par le catalogue. Ces vérifications coûteuses s’exécutent séparément de la suite de navigateurs normale. Une exécution réussie confirme le fonctionnement de base du modèle et une structure de sortie utilisable ; elle n’établit ni la qualité perceptuelle ni la précision sur votre enregistrement.

## Révisez le résultat {#review-the-result}

- Ce modèle aligne les mots anglais fournis ; il ne traduit pas ni ne répare une transcription incorrecte.
- Les mots répétés, la parole en arrière-plan et les mots manquants dans la transcription peuvent entraîner des limites incorrectes. Le test vérifie les horodatages de mots ordonnés et en plage contre le vocabulaire fourni, et non une correspondance de timing parfaite.
