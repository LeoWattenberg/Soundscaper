## Objectif et cas d’utilisation {#purpose-and-use-case}

Transcrire localement le discours sélectionné grâce au moteur whisper.cpp intégré. 

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur whisper-cpp v1.9.3 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques. Il n’existe pas de moteur téléchargeable pour macOS x64, bien que les poids du modèle soient répertoriés pour cette plateforme.

## Utiliser ce modèle {#use-this-model}

Ouvrez **Analyser → Parole → Transcrire & Sous-titres** sur une plateforme disposant du runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez le discours et installez Whisper large-v3 turbo via Gestionnaire de modèles.
2. Choisissez ce modèle de reconnaissance vocale sous Outils → Traitement local avancé lorsque vous souhaitez sélectionner explicitement Whisper.
3. Exécutez localement et examinez à la fois le texte et les limites de segment avant de l'accepter.

## Examiner le résultat {#review-the-result}

- Whisper peut produire un texte incorrect, en particulier sur du bruit ou du matériel sans discours clair. Écoutez pendant la révision.
- Le test vérifie que le runtime réel renvoie une transcription chronométrée non vide ; il ne garantit pas une orthographe particulière ou un score de reconnaissance.
