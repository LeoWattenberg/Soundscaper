Détecte les visages et les objets dans les images vidéo échantillonnées pour proposer un nouveau cadrage.

D-FINE détecte les catégories d'objets et leurs emplacements. L'opération de détection de sujet combine ces résultats avec les détections de visages YuNet.

## Disponibilité actuelle {#current-availability}

Les versions de bureau incluent le moteur onnxruntime-node 1.29.0 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64 et Windows x64. Installez les poids de ce modèle via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats sur un package et une machine particuliers. La version de bureau ne comprend pas ce moteur pour macOS x64, même si les poids du modèle sont répertoriés pour ces plateformes.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Framescaper : Effet → Effets vidéo → Recadrage** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez une séquence vidéo dans Framescaper.
2. Installez YuNet et D-FINE pour la détection de sujets. La tâche de recadrage guidée utilise également la détection de salience U²-Net-P.
3. Exécutez-le localement et examinez le recadrage proposé. Outils → Traitement local avancé peut exécuter la détection de sujets seul.

Cette opération nécessite également [la détection de visages YuNet](/reference/local-models/yunet-face-detection-2026may/).

## Ce que le test empaqueté vérifie {#what-the-packaged-test-checks}

Cas : `subject-detection` ; opération : `subject-detection`.

Entrée : Deux photographies : le portrait de l'astronaute Eileen Collins du domaine public de la NASA et la photographie du chat Chelsea sous licence CC0. Chacune est insérée dans un cadre distinct avec un horodatage de cadre source explicite, donnant aux détecteurs un visage humain et un objet clair.

Les résultats des visages et des objets doivent avoir un horodatage de cadre source valide, des scores de confiance finis et des boîtes délimitées. Le dispositif de sujet doit produire des détections à partir des deux modèles.

Le package nocturne-avec-tests télécharge les artefacts de modèle réels et demande une inférence via le runtime empaqueté. Un modèle requis manquant du catalogue échoue dans son cas. Les moteurs natifs manquants échouent sur les plateformes prises en charge par le catalogue. Ces contrôles coûteux s'exécutent séparément de la suite de navigateurs normale. Une exécution réussie confirme l'exécution de base du modèle et la structure de sortie utilisable ; elle n'établit pas la qualité perceptuelle ou la précision sur votre enregistrement.

## Examinez le résultat {#review-the-result}

- Les visages et les objets peuvent être manqués ou mal classés. La détection est échantillonnée et ne garantit pas qu'un sujet en mouvement reste à l'intérieur de chaque recadrage proposé.
- L'opération exécute les deux modèles ensemble ; aucun des modèles n'est un système de reconnaissance faciale pour identifier les personnes.
