## Objectif et cas d’utilisation {#purpose-and-use-case}

Convertissez le discours sélectionné en une transcription chronométrée pour les sous-titres et l'édition de transcriptions.

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur sherpa-onnx-node 1.13.5 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques. Il n’existe pas de moteur téléchargeable pour macOS x64, bien que les poids du modèle soient répertoriés pour cette plateforme.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Analyser → Parole → Transcrire & Sous-titres** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez le discours à transcrire.
2. Utilisez le Gestionnaire de modèles pour installer ce modèle. Outils → Traitement local avancé vous permet de choisir un modèle de reconnaissance vocale spécifique.
3. Exécutez localement, puis examinez le texte et le chronométrage avant d'accepter la transcription.

## Téléchargement et exigences {#download-and-requirements}

Identité du modèle : `parakeet-tdt-0.6b-v2`, version **2.0.0**.

Taille approximative du téléchargement de l’artefact du modèle : **630.56 MiB**. Le runtime requis s’ajoute au premier téléchargement s’il n’est pas déjà installé. Mémoire système minimale : **4 GiB**. Cette exigence du catalogue concerne la mémoire totale, et non la mémoire libre actuelle. L’inférence nécessite également suffisamment de mémoire libre et l’installation de l’espace disque ; la mémoire ne garantit pas la vitesse.

Plateformes publiées : macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Un runtime téléchargeable correspondant est également requis.

Sous Windows, installez le dernier [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) pris en charge et correspondant à l’application de bureau : **x64** pour une version x64 ou **ARM64** pour une version ARM64. Les moteurs ONNX et Sherpa natifs nécessitent ces bibliothèques ; les téléchargements du modèle et du runtime ne les incluent pas. Visual Studio lui-même n’est pas nécessaire pour utiliser l’application.

Outils → Gestionnaire de modèles télécharge les artefacts publiés du modèle et le runtime requis lors de la première installation, puis vérifie leurs empreintes SHA-256 enregistrées. Le traitement utilise les fichiers installés localement. Ouvrez Stockage et vérification dans le Gestionnaire de modèles pour consulter les avis, réparer une installation ou modifier l’emplacement de stockage.

## Examinez le résultat {#review-the-result}

- Vérifiez les noms, la ponctuation, les nombres et le chronométrage par rapport à l'enregistrement.
- Un test réussi nécessite un texte lisible et un chronométrage valide, pas une transcription de référence exacte. Il ne mesure pas la précision de reconnaissance à travers les langues ou les conditions d'enregistrement.
