Convertissez le discours sélectionné en une transcription chronométrée pour les sous-titres et l'édition de transcriptions.

## Disponibilité actuelle {#current-availability}

Les versions de bureau incluent le moteur sherpa-onnx-node 1.13.5 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64 et Windows x64. Installez les poids de ce modèle via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats sur un package et une machine spécifiques. La version de bureau ne prend pas en charge macOS x64 même si les poids du modèle sont répertoriés pour ces plateformes.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Analyser → Parole → Transcrire & Sous-titres** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez le discours à transcrire.
2. Utilisez le Gestionnaire de modèles pour installer ce modèle. Outils → Traitement local avancé vous permet de choisir un modèle de reconnaissance vocale spécifique.
3. Exécutez localement, puis examinez le texte et le chronométrage avant d'accepter la transcription.

Taille de téléchargement approximative : **630,56 Mo**. Mémoire système minimale : **4 Go**. Cette exigence de catalogue fait référence à la mémoire totale, et non à la mémoire libre actuelle. L'inférence nécessite également une mémoire libre suffisante, et l'installation nécessite de l'espace de travail ; la mémoire ne garantit pas la vitesse.

Plateformes publiées : macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Un runtime empaqueté correspondant est également requis.

Sous Windows, installez la dernière version prise en charge de [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) correspondant à l'application de bureau : **x64** pour une version x64 ou **ARM64** pour une version ARM64. Les moteurs natifs ONNX et Sherpa nécessitent ces bibliothèques ; les téléchargements de modèles ne les incluent pas. Visual Studio lui-même n'est pas requis pour utiliser l'application.

## Ce que le test empaqueté vérifie {#what-the-packaged-test-checks}

Cas : `parakeet-v2-transcript` ; opération : `speech-recognition`.

Entrée : Un extrait du domaine public du discours d'investiture de John F. Kennedy, avec une seconde de silence ajoutée au début et à la fin, préparé en audio mono à 16 kHz.

La transcription doit contenir un texte non vide avec un chronométrage valide à l'intérieur de l'audio d'entrée. La formulation exacte n'est pas comparée.

Le package nightly-with-tests télécharge les artefacts de modèle réels et demande une inférence via le runtime empaqueté. Un modèle requis manquant du catalogue échoue dans son cas. Les moteurs natifs manquants échouent sur les plateformes prises en charge par le catalogue. Ces vérifications coûteuses s'exécutent séparément de la suite de navigateurs normale. Une exécution réussie confirme l'exécution de base du modèle et la structure de sortie utilisable ; elle n'établit pas la qualité ou la précision perceptuelle sur votre enregistrement.

## Examinez le résultat {#review-the-result}

- Vérifiez les noms, la ponctuation, les nombres et le chronométrage par rapport à l'enregistrement.
- Un test réussi nécessite un texte lisible et un chronométrage valide, pas une transcription de référence exacte. Il ne mesure pas la précision de reconnaissance à travers les langues ou les conditions d'enregistrement.
