## Objectif et cas d’utilisation {#purpose-and-use-case}

Localisez les positions des battements dans la musique à l'aide du modèle Beat This plus petit.

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur onnxruntime-node 1.29.0 requis pour macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Outils → Traitement local avancé → Suivi des battements** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez un passage de musique rythmique.
2. Installez Beat This petit via le Gestionnaire de modèles et sélectionnez ce modèle exact pour le suivi des battements.
3. Écoutez la grille de battements proposée avant d'accepter les marqueurs de battements ou une proposition de tempo.

## Téléchargement et exigences {#download-and-requirements}

Identité du modèle : `beat-this-small0`, version **1.1.0**.

Taille approximative du téléchargement de l’artefact du modèle : **10.08 MiB**. Le runtime requis s’ajoute au premier téléchargement s’il n’est pas déjà installé. Mémoire système minimale : **2 GiB**. Cette exigence du catalogue concerne la mémoire totale, et non la mémoire libre actuelle. L’inférence nécessite également suffisamment de mémoire libre et l’installation de l’espace disque ; la mémoire ne garantit pas la vitesse.

Plateformes publiées : macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Un runtime téléchargeable correspondant est également requis.

Sous Windows, installez le dernier [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) pris en charge et correspondant à l’application de bureau : **x64** pour une version x64 ou **ARM64** pour une version ARM64. Les moteurs ONNX et Sherpa natifs nécessitent ces bibliothèques ; les téléchargements du modèle et du runtime ne les incluent pas. Visual Studio lui-même n’est pas nécessaire pour utiliser l’application.

Outils → Gestionnaire de modèles télécharge les artefacts publiés du modèle et le runtime requis lors de la première installation, puis vérifie leurs empreintes SHA-256 enregistrées. Le traitement utilise les fichiers installés localement. Ouvrez Stockage et vérification dans le Gestionnaire de modèles pour consulter les avis, réparer une installation ou modifier l’emplacement de stockage.

<summary>Ce que vérifie le test de bureau</summary>

Cas : `beat-this-small-beats` ; opération : `beat-tracking`.

Entrée : Seize secondes de percussion synthétisée reproductible et de tons changeants à 22,05 kHz, avec un battement régulier.

Les positions des battements doivent être non vides, ordonnées et à l'intérieur de l'audio ; les données de tempo doivent être finies et positives.

Le package nightly-with-tests télécharge les vrais artefacts du modèle et les runtimes vérifiés avant l’inférence. Un modèle requis absent du catalogue fait échouer son cas. ## Examinez le résultat {#review-the-result}

- Le suivi des battements peut suivre des motifs en demi-temps ou en double-temps, et la musique irrégulière peut entraîner des battements manquants.
- Le test distinct du petit modèle vérifie les positions de battements ordonnées à l'intérieur de l'audio et les données de tempo finies et positives, sans exiger de temps de battement exact.
