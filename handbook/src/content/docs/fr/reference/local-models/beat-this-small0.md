Localisez les positions des battements dans la musique à l'aide du modèle Beat This plus petit.

## Disponibilité actuelle {#current-availability}

Les builds de bureau incluent le moteur onnxruntime-node 1.29.0 requis pour macOS arm64, Linux x64, Linux arm64, Windows x64 et Windows arm64. Installez les poids de ce modèle via le Gestionnaire de modèles, puis exécutez sa tâche localement. Ce sont les cibles de build prises en charge ; consultez le rapport de test nocturne pour les résultats sur un package et une machine particuliers.

## Utilisez ce modèle {#use-this-model}

Ouvrez **Outils → Traitement local avancé → Suivi des battements** sur une plateforme avec le runtime natif requis. L'assistance locale s'exécute dans l'éditeur de bureau.

1. Sélectionnez un passage de musique rythmique.
2. Installez Beat This petit via le Gestionnaire de modèles et sélectionnez ce modèle exact pour le suivi des battements.
3. Écoutez la grille de battements proposée avant d'accepter les marqueurs de battements ou une proposition de tempo.

## Ce que le test empaqueté vérifie {#what-the-packaged-test-checks}

Cas : `beat-this-small-beats` ; opération : `beat-tracking`.

Entrée : Seize secondes de percussion synthétisée reproductible et de tons changeants à 22,05 kHz, avec un battement régulier.

Les positions des battements doivent être non vides, ordonnées et à l'intérieur de l'audio ; les données de tempo doivent être finies et positives.

Le package nightly-with-tests télécharge les véritables artefacts de modèle et demande une inférence via le runtime empaqueté. Un modèle requis manquant du catalogue fait échouer son cas. Les moteurs natifs manquants échouent sur les plateformes prises en charge par le catalogue. Ces contrôles coûteux s'exécutent séparément de la suite de navigateurs normale. Une exécution réussie confirme l'exécution de base du modèle et la structure de sortie utilisable ; elle n'établit pas la qualité perceptuelle ou la précision sur votre enregistrement.

## Examinez le résultat {#review-the-result}

- Le suivi des battements peut suivre des motifs en demi-temps ou en double-temps, et la musique irrégulière peut entraîner des battements manquants.
- Le test distinct du petit modèle vérifie les positions de battements ordonnées à l'intérieur de l'audio et les données de tempo finies et positives, sans exiger de temps de battement exact.
