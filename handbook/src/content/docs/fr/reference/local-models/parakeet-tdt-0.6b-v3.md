## Objectif et cas d’utilisation {#purpose-and-use-case}

Fournit un autre modèle local de reconnaissance vocale pour les transcriptions et les sous-titres.

## Disponibilité actuelle {#current-availability}

Les versions de bureau peuvent télécharger et vérifier le moteur sherpa-onnx-node 1.13.5 requis pour macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installez ce modèle et son runtime requis via le Gestionnaire de modèles, puis exécutez la tâche localement. Ce sont les cibles de construction prises en charge ; consultez le rapport de test nocturne pour les résultats d’un package et d’une machine spécifiques. Il n’existe pas de moteur téléchargeable pour macOS x64, bien que les poids du modèle soient répertoriés pour cette plateforme.

## Utiliser ce modèle {#use-this-model}

Ouvrez **Analyze → Speech → Transcribe & Captions** sur une plateforme disposant du runtime natif requis. L'assistance locale s'exécute dans l'éditeur desktop.

1. Sélectionnez une région contenant de la parole.
2. Installez Parakeet v3 via Manage Models. Choisissez son identité exacte dans Tools → Advanced Local Processing pour comparer les modèles.
3. Exécutez localement et examinez la transcription proposée avant de l'appliquer.

## Téléchargement et prérequis {#download-and-requirements}

Identité du modèle : `parakeet-tdt-0.6b-v3`, version **3.0.0**.

Taille approximative du téléchargement de l’artefact du modèle : **639.42 MiB**. Le runtime requis s’ajoute au premier téléchargement s’il n’est pas déjà installé. Mémoire système minimale : **4 GiB**. Cette exigence du catalogue concerne la mémoire totale, et non la mémoire libre actuelle. L’inférence nécessite également suffisamment de mémoire libre et l’installation de l’espace disque ; la mémoire ne garantit pas la vitesse.

Plateformes publiées : macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Un runtime téléchargeable correspondant est également requis.

Sous Windows, installez le dernier [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) pris en charge et correspondant à l’application de bureau : **x64** pour une version x64 ou **ARM64** pour une version ARM64. Les moteurs ONNX et Sherpa natifs nécessitent ces bibliothèques ; les téléchargements du modèle et du runtime ne les incluent pas. Visual Studio lui-même n’est pas nécessaire pour utiliser l’application.

Outils → Gestionnaire de modèles télécharge les artefacts publiés du modèle et le runtime requis lors de la première installation, puis vérifie leurs empreintes SHA-256 enregistrées. Le traitement utilise les fichiers installés localement. Ouvrez Stockage et vérification dans le Gestionnaire de modèles pour consulter les avis, réparer une installation ou modifier l’emplacement de stockage.

Cas : `parakeet-v3-transcript` ; opération : `speech-recognition`.

Entrée : un extrait du discours inaugural de John F. Kennedy appartenant au domaine public, avec une seconde de silence ajoutée à chaque extrémité, préparé en audio mono à 16 kHz.

La transcription doit contenir un texte non vide avec un minutage valide dans l'audio d'entrée. La formulation exacte n'est pas comparée.

Le package nightly-with-tests télécharge les vrais artefacts du modèle et les runtimes vérifiés avant l’inférence. Un modèle requis absent du catalogue fait échouer son cas. L’absence de moteurs natifs entraîne un échec sur les plateformes prises en charge par le catalogue. Ces vérifications coûteuses s’exécutent séparément de la suite de navigateurs normale. Une exécution réussie confirme le fonctionnement de base du modèle et une structure de sortie utilisable ; elle n’établit ni la qualité perceptuelle ni la précision sur votre enregistrement.
