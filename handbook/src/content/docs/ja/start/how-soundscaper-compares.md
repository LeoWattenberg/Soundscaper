Soundscaper は Audacity 4 をウェブ上に再実装し、制作機能を追加しています。Adobe Audition は、通常この 2 つと比較される商用ポストプロダクションツールです。このページでは Soundscaper Web／Desktop、Audacity 4、Audition を比較し、必要な作業をすでに実行できるエディションを確認できます。

## このページの読み方

各セルは色付きの記号から始まり、その評価を補足する説明が続きます。

- <span class="verdict verdict--yes" role="img" aria-label="Supported">+</span> — 対応または該当
- <span class="verdict verdict--partial" role="img" aria-label="Limited">~</span> — 範囲が限定的、プラットフォームに依存、または回避策が必要
- <span class="verdict verdict--no" role="img" aria-label="Unavailable">/</span> — 利用不可または該当しない

記号とあわせて注記を確認してください。オプションのプラグイン、モデル、コーデックをインストールするだけで、Desktop の対応機能が制限付きになるわけではありません。必要なインストール内容は注記に記載しています。Web と Desktop は別々の列なので、ブラウザーの制限が Desktop の評価に影響することはありません。

行は機能を記述しており、メニューコマンドではありません。正確なコマンド一覧については[コマンドとショートカット](/reference/generated/commands/)を、各プロダクトが有効にする内容については
[製品の機能](/reference/generated/product-capabilities/)を参照してください。

### これらの主張の出所

- **Soundscaper** の行は、このリポジトリの製品機能プロファイル、実行時アクションマニフェスト、書き出し形式レジストリ、ブラウザーおよびデスクトップのコーデック機能ゲートに基づいています。
  デスクトップネイティブのターゲットペイロードは、リポジトリの CI またはターゲットのパッケージングによって生成されます。パッケージは、正確に一致する結果をステージングして検証した後に機能を有効にします。ペイロードが必要な場合は表に記載しています。
- **Audacity 4** の行は、このリポジトリで固定された upstream インベントリ、バージョン `4.0.0` の commit `4c177d43` を基準とし、公式 [`4.0.1` リリース](https://github.com/audacity/audacity/blob/Audacity-4.0.1/CHANGELOG.txt)の commit `d82386ce` までのユーザー向け変更を含みます。upstream に登録されていても無効化されている機能や、メニューからコメントアウトされている機能はそのように記録しています。監査対象のインベントリとリリースノートにない機能は、恒久的に存在しないとはせず、そこには記載されていないとしています。サンプル描画、クリップゲインエンベロープ、旧プロジェクトの読み込みは、公式の[4.0 変更履歴](https://www.audacityteam.org/changelog/)と[クリップゲインマニュアル](https://www.audacityteam.org/manual/clips/clip-gain/)にも記載されています。
- **Audition**の行は、Adobeが現在のリリース用に公開したドキュメントに基づいています。実行中のビルドに対して検証されていません。

## 違いがもたらすもの

Audacity 4 はシングルパスのエディターです。固定されたビルドにはバス、センド、トラックやエフェクトのオートメーションレーン、マクロはありません。クリップゲインエンベロープを使うと、クリップ内の音量を自動化できます。Soundscaper はこの編集モデルを保ちつつ、トラック／エフェクトのオートメーション、ミキシング、納品と、Audacity が扱わない録音、ビデオ、データ交換機能を追加します。

Audition は修復機能の幅、Premiere Pro との連携、アンビソニックス音声で引き続き優れています。Soundscaper は没入型の納品、プロジェクト管理、他の 2 つが対応しないハードウェア上でブラウザーから実行できる点が強みです。

すでに Audacity をお使いの場合は、プロジェクトの移行方法について[プロジェクトファイルと Audacity とのデータ交換](/projects-and-data/project-files/)を参照してください。
