両方のエディションはプロジェクトをローカルで処理します。ストレージとファイルアクセスは異なります。

## Web エディター

ブラウザ版エディションは、プロジェクト、録音、およびインポートされたメディアをオリジンプライベートなブラウザストレージに保持します。プロジェクトを Soundscaper アカウントにアップロードすることはなく、アカウントも必要ありません。

アプリをインストールせずにすぐにアクセスしたい場合は、Web エディターを使用してください。ブラウザストレージは、ブラウザのクォータおよび削除ルールに従うことに注意してください。サイトデータをクリアすると、ローカルのプロジェクトライブラリが削除されます。

## デスクトッププレビュー

パッケージ化されたデスクトッププレビューは、デスクトップアプリケーション内に自動保存されたローカルライブラリを保持します。オフライン編集のために、エディターランタイムとリリースされた翻訳がバンドルされています。

デスクトップパッケージは署名されていません。macOS は、Electron とネイティブバイナリを実行するためにローダーが必要とするアイデンティティなしのアドホックコードシールのみを適用します。このシールは、パブリッシャーや信頼性に関する主張を行いません。そのため、Windows SmartScreen または macOS Gatekeeper は、プレビューおよび安定版パッケージに対して、不明な開発者に関する警告を表示する可能性があります。

`.aup4` ファイルを開くと、独立したプロジェクトがデスクトップライブラリにインポートされます。その後の編集では、開いたファイルは書き換えられません。**保存** はライブラリ内のコピーを更新し、**名前を付けて保存** は新しい Audacity 相互運用ファイルを作成します。

## スマートフォンとタブレット

Web エディターはすべての画面でデスクトップレイアウトを維持しますが、幅 900px 未満（スマートフォン、または縦持ちのタブレット）の場合、タイムラインに十分なスペースを確保するために、クロームをドロワーに折りたたみます：

- 左上の **メニュー** ボタンを押すと、完全なアプリケーションメニュー、プロジェクトタブ、アクションバー、ツールツールバーを含むドロワーが開きます。再生、停止、録音、検索はバー内に残ります。コマンドを選択するとドロワーが閉じます。
- タイムラインの左上隅にある **トラックヘッダー** ハンドル、または **表示 › トラックヘッダー** から、トラックヘッダーがレーン上にスライドインします。レーンをタップするか、Escape キーを押すと、それらが再び隠れます。
- 狭い画面では、エディターの上にある導入部がデフォルトで折りたたまれています。**導入部を表示** で復元できます。

**編集 › 環境設定 › 外観 › レイアウト** で、自動、コンパクト、デスクトップの切り替えが可能になり、デスクトップ上の小さなウィンドウでデスクトップクロームを維持したり、広いタブレットでドロワーを使用したりできます。

## プロジェクトは自動的に移動しません

ブラウザとデスクトップのライブラリは別個です。プロジェクトを意図的に移動してください：

- 完全なプロジェクトには、Scape プロジェクトファイルを使用してください — Soundscaper からの `.sscape`、Framescaper からの `.fscape`。
- Audacity との音声相互運用を特に必要とする場合は、AUP4 を使用してください。
- 永続的な再生コピーとして、レンダリングされたオーディオまたはビデオをエクスポートします。

ブラウザのサイトデータまたはデスクトップアプリケーションデータを削除する前に、[プロジェクトファイル](/projects-and-data/project-files/) を参照してください。
