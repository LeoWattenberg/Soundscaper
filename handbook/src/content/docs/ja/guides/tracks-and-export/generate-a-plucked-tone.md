## このガイドの目的 {#what-this-guide-is-for}

Pluckは短い音程音を作り、簡単な音符やサウンドデザインのアクセントとして使えます。MIDI音高フィールドを使えば、周波数を計算せずに音符を選べます。

:::note[Audacityから移行する場合]
Audacity では **Generate → Pluck (Nyquist)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **生成 → Nyquist → Pluck** を選びます。**Pluck** ダイアログで **Pluck MIDI pitch** を `60`、**Duration (60s max)** を `2` に設定して **適用** を押します。MIDI音高60は中央のCにあたり、2秒あれば音が減衰します。
3. プロジェクトには1つのクリップが表示されます。
   *確認できること：* タイムラインに2秒の音があるプラック音が表示されます。

## ヒント

- 高い音にするには **Pluck MIDI pitch** を上げ、低い音にするには下げます。
- 短く引き締まったアクセントにするには **Duration (60s max)** を短くします。
