## このガイドの目的 {#what-this-guide-is-for}

複数のテイクがあるプロジェクトでは、関連するトラック名が並んでいると見つけやすくなります。Sort by nameはトラックを名前順に並べ替えますが、タイムライン上のクリップの開始位置は変えません。

:::note[Audacityから移行する場合]
Audacity では **Tracks → Sort Tracks → Sort by Name** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、名前順で後になる録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **ファイル → ファイルをインポート** を選び、名前順で先になる録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
4. **トラック → トラックをソート → 名前でソート** を選びます。トラック名がアルファベット順に並び替わります。
5. プロジェクトには2つのクリップが表示されます。
   *確認できること：* 2つの録音はプロジェクトに残り、トラック名がアルファベット順に並びます。

## ヒント

- 並べ替えで変わるのはトラックの順番であり、クリップのタイミングやオーディオの内容ではありません。
- クリップの開始時間に沿って並べるには **トラック → トラックをソート → 時間でソート** を選びます。
