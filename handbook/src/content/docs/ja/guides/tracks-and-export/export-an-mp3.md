MP3はファイルサイズが小さく、どこでも再生でき、ほとんどのポッドキャストホストやメッセージングアプリが期待する形式です。エクスポートでは、プロジェクト全体（すべてのトラック、エフェクト、編集）が1つのファイルとしてレンダリングされます。

:::note[Audacityから移行する場合]
これはAudacityの**ファイル → 音声の書き出し → MP3**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了となります。
2. **ファイル → 音声のインポート**を選択し、公開する録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **ファイル → 音声のエクスポート**を選択し、**形式**を**MP3**に設定して**エクスポート**を押します。レンダリングが完了するとすぐにファイルがダウンロードされ、そのリンクはダイアログ内に保持されます。ファイルはブラウザ内でエンコードされ、コンピュータの外に送信されることはありません。

## ヒント

- MP3は納品用のコピーであり、バックアップではありません。再度編集する可能性がある場合は、プロジェクトを保持するか、WAV形式でもエクスポートしてください。
- フルスケールに近いピークは、エンコード後にクリップ（破音）する可能性があります。エクスポート前に−1 dB以下に正規化してください。
- ビットレートモードは、エンコーダーがビットをどのように配分するかを決定します。標準プリセットは素材に応じてレートを変動させ、ほとんどの納品に適切です。ホストや古いハードウェアプレーヤーが固定レートのみを要求する場合にConstant（一定）を選択してください。
