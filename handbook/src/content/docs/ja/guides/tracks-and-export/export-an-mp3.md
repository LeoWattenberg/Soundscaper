MP3は小さく、どこでも再生でき、ほとんどのポッドキャストホストやメッセージングアプリが期待する形式です。エクスポートは、プロジェクト全体（すべてのトラック、エフェクト、編集）を1つのファイルにレンダリングします。

:::note[Audacityから移行する場合]
これはAudacityの**ファイル → エクスポートオーディオ → MP3**です。以下の名前はSoundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、公開する録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → オーディオのエクスポート**を選択し、**フォーマット**を**MP3**に設定して、**エクスポート**をクリックします。レンダリングが完了すると、ファイルがダウンロードされ、ダイアログにリンクが残ります。ファイルはブラウザでエンコードされ、コンピュータ外には何も送信されません。

## ヒント

- MP3はバックアップではなく配信コピーです。再度編集する可能性がある場合は、プロジェクトを保持するか、WAVもエクスポートしてください。
- フルスケール直前のピークはエンコード後にクリップされる可能性があります。エクスポート前に−1 dB以下に正規化してください。
- ビットレートモードは、エンコーダがビットをどのように使用するかを決定します。標準プリセットは、素材に合わせてレートを変動させ、ほとんどの配信に適しています。古いハードウェアプレーヤーやホストが固定レートを要求する場合は、定数を選択してください。
