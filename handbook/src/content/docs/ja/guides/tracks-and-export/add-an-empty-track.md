## このガイドの目的 {#what-this-guide-is-for}

ファイルのインポートではトラックが作成されますが、録音や貼り付けには配置先が必要です。トラックリスト上部の「トラックを追加」ボタンで空のオーディオトラックを作成できます。ラベルトラックには音ではなく、マーカーやテキストが保持されます。

:::note[Audacityから移行する方へ]
これはAudacityの**トラック → 新規追加 → モノラルトラック**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了です。
2. トラックリスト上部の「トラックを追加」を押して、「オーディオトラック」を選択します。
3. プロジェクトに2つのトラックが表示されます。
   *確認事項:* 最初のトラックの下に、2番目の空のオーディオトラックが表示されること。

## ヒント

- トラックのメニューから名前を変更し、多くのトラックを含むセッションでも読みやすく保ちます。
- ヘッダーをドラッグしてトラックの順序を変更できます。
