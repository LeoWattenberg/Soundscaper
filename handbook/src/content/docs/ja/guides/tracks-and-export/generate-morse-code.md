## このガイドの目的 {#what-this-guide-is-for}

モールス信号はメッセージを時間指定された短点、長点、間隔に変換します。ジェネレーターは符号化をプレビューし、メッセージと速度からクリップの長さを算出します。

:::note[Audacityから移行する場合]
Audacityには **No directly matching built-in Morse code generator** はありません。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **生成 → モルセコード** を選びます。**モルセコード** ダイアログで **メッセージ** を `SOS`、**速度（分あたりの単語数）** を `20`、**周波数（Hz）** を `600`、**振幅** を `0.2` にしてから **生成** を押します。例の代わりに任意の文を入力します。符号プレビューを確認してください。未対応文字があると生成できません。
3. プロジェクトにクリップが1つ表示されます。
   *表示される結果:* メッセージを含むモールス信号クリップが作られ、長さは指定した速度に応じます。

## ヒント

- 速度を下げると音の周波数はそのままに、短点、長点、間隔が長くなります。
- Durationは読み取り専用で、結果として表示されます。メッセージまたは速度を変えるとクリップの長さが変わります。
