## このガイドの目的 {#what-this-guide-is-for}

クリップごとに書き出すと、それぞれの編集内容を別ファイルに保ったまま、すべてを1つのアーカイブにまとめられます。先に範囲をクリップに分割し、書き出しダイアログでクリップ出力モードを選びます。

:::note[Audacityから移行する場合]
Audacity では **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、クリップを個別に書き出す録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. クリップ上部のルーラーをドラッグして、別のクリップとして書き出す範囲を選びます。
4. **編集 → オーディオクリップ → 分割** を選びます。
5. **ファイル → オーディオをエクスポート** を選び、**フォーマット** を **WAV**、**出力** を **個別のクリップ（クリップごとに分割）** に設定して **書き出し** を押します。レンダリングが完了するとファイルがダウンロードされ、リンクはダイアログに残ります。各クリップは1つのZIPアーカイブ内に個別のWAVとして書き出されます。

## ヒント

- アーカイブ内でファイルを見分けられるよう、書き出す前にクリップへ分かりやすい名前を付けます。
- クリップごとのファイルではなく1つのミックスが必要な場合は **プロジェクト全体** を選びます。
