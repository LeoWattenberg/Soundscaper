## このガイドの目的 {#what-this-guide-is-for}

Remove tracks は、選択したトラックとその中のすべてのクリップをプロジェクトから削除します。使わないテイクや、編集結果を比較した後の予備コピーを取り除くときに便利です。クリップを 1 つ選ぶとトラック全体が対象になるため、削除する前に選択内容を確認してください。

:::note[Audacityから移行する場合]
これは Audacity の **Tracks → Remove tracks (Audacity 4)** に相当します。以下の名前は Soundscaper での名称で、異なる場合があります。
:::

## 手順

1. Soundscaper を開きます。エディターが読み込まれると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート** を選び、残す録音を選択します。録音は専用のトラックにクリップとして追加されます。
3. **ファイル → ファイルをインポート** を選び、別のトラックにある不要な録音を選択します。録音は専用のトラックにクリップとして追加されます。
4. **Tab** で削除するトラック内のクリップにフォーカスし、**Enter** を押して選択します。
5. **トラックメニュー → トラックを削除** を選びます。
6. 残した録音は元の位置にあります。
   *表示される内容:* 不要なトラックがなくなり、ほかの録音は変更されていません。

## ヒント

- **編集 → 取り消す** で削除したトラックとクリップを復元できます。
- トラックではなく録音の一部だけを削除するには、[間を空けて一部分を削除](/guides/editing/delete-a-passage-and-leave-a-gap/)します。
- プロジェクトからトラックを削除しても、コンピューターから読み込んだ元のファイルは削除されません。
- リンクされたレーンのグループ内にあるトラックは一緒に削除されます。
