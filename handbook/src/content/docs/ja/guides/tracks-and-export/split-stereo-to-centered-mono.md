## このガイドの目的 {#what-this-guide-is-for}

2 チャンネルのレコーダーで、話者を左右に分けて録音した場合、チャンネルを分離すると、それぞれの声を個別に編集して音量バランスを調整できます。Split stereo to centered mono は、どちらも中央にパンした 2 つのモノラルトラックを作成します。タイムライン上の位置と長さはそのまま保たれ、各チャンネルは独立した録音として残ります。

:::note[Audacityから移行する場合]
これは Audacity の **Track menu → Split stereo to center mono (Audacity 4)** に相当します。以下の名前は Soundscaper での名称で、異なる場合があります。
:::

## 手順

1. Soundscaper を開きます。エディターが読み込まれると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート** を選び、チャンネルを分けたいステレオ録音を選択します。録音は専用のトラックにクリップとして追加されます。
3. トラックヘッダーの **トラックオプション** ボタンからトラックメニューを開き、**トラックチャンネル → ステレオを中央に合わせたモノラルに分割** を選びます。
4. プロジェクトに 2 つのクリップと 3 つのトラックが表示されます。
   *表示される内容:* 分離された Left と Right のトラックに元の各チャンネルが入り、どちらのパンコントロールも中央になります。

## ヒント

- 元のステレオ定位を保つには、代わりに[left/right のモノラルトラックに分割](/guides/tracks-and-export/split-stereo-into-mono-tracks/)します。
- この操作では 2 つのモノラルトラックが作成されます。音を 1 つのモノラルチャンネルにまとめるには、[トラックをミックスダウン](/guides/tracks-and-export/mix-tracks-into-one/)して Mono を選びます。
- **編集 → 取り消す** でステレオトラックに戻せます。
