## このガイドの目的 {#what-this-guide-is-for}

トラックを上下に移動するとプロジェクト内の縦位置が変わりますが、クリップの開始時間は変わりません。Move track to topは、声や重要なパートをほかのトラックの上に表示するのに便利です。

:::note[Audacityから移行する場合]
Audacity では **Track menu → Move track → Move track to top** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、下に残しておく録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **ファイル → ファイルをインポート** を選び、一番上に置く録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
4. 一番上に移動したいトラックのヘッダーにある **トラックオプション** ボタンからメニューを開き、**トラックを移動 → トラックを最上段に移動** を選びます。このコマンドはクリップのタイミングを保ったままトラックの縦位置を変えます。
5. プロジェクトには2つのクリップが表示されます。
   *確認できること：* 選択したトラックがもう一方の上に移動し、両方のクリップはタイムライン上の位置を保ちます。

## ヒント

- 順番を逆にするにはトラックメニューから **トラックを移動 → トラックを下に移動** を選びます。
- トラックの順番はプロジェクトでどのオーディオが上に表示されるかを変えますが、ミックスやパンは変わりません。
