12のトラックがあり、1つの新しいパートを試すために毎回1つのヘッダーをミュートして聴くのは面倒ですし、その後にすべてをミュート解除するのはもっと面倒です。すべてのトラックをミュートするとプロジェクト全体が1つのコマンドでサイレントになり、すべてのトラックをミュート解除すると復元され、どちらもソロボタンは影響を受けません。Audacity 3には両方のコマンドがありましたが、Audacity 4では復活していません。

:::note[Audacityから移行する場合]
これはAudacityの**トラック → ミュート/ミュート解除 → すべてのトラックをミュート、すべてのトラックをミュート解除（Audacity 3；Audacity 4にはありません）**です。以下の名前はSoundscaper独自のもので、時折異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、最初の録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → インポート**を選択し、2番目の録音を選択します。それは独自のトラック上のクリップとして配置されます。
4. **トラック → すべてのトラックをミュート**を選択します。
5. プロジェクトはすべてのトラックの**ミュート**ボタンが点灯していることを示します。
   *表示されるはずのもの:* 再生は静音になります。
6. **トラック → すべてのトラックをミュート解除**を選択します。
7. プロジェクトはどのトラックもミュートされていないことを示します。
   *表示されるはずのもの:* すべてが再び再生されます。

## ヒント

- すべてをミュートし、聴きたい1つまたは2つのトラックをミュート解除する — 選択肢が頻繁に変わる場合、ソロよりも速い。
- 他のトラックに影響を与えずに1つのトラックを単独で聴きたい場合は、[ソロ](/guides/tracks-and-export/mute-and-solo-tracks/)を選択してください。
