12トラックある場合、1トラックずつミュートして新しいパートを聴き比べるのは面倒で、後にミュートを解除するのはさらに手間がかかります。すべてのトラックをミュートすると1つのコマンドでプロジェクト全体を無音にし、すべてのトラックのミュートを解除すると元に戻せます。どちらのコマンドもソロボタンには影響しません。Audacity 3には両方のコマンドがありましたが、Audacity 4では復活していません。

:::note[Audacityから移行される方へ]
これはAudacityの**トラック → ミュート/ミュート解除 → すべてのトラックをミュートおよびすべてのトラックのミュートを解除（Audacity 3; Audacity 4にはなし）**です。以下に示す名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了です。
2. **ファイル → オーディオのインポート**を選択し、最初の録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **ファイル → オーディオのインポート**を選択し、2番目の録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
4. **トラック → すべてのトラックをミュート**を選択します。
5. プロジェクトのすべてのトラックの**ミュート**ボタンが点灯していることが表示されます。
   *確認事項:* 再生音が無音になります。
6. **トラック → すべてのトラックのミュートを解除**を選択します。
7. プロジェクトのどのトラックもミュートされていないことが表示されます。
   *確認事項:* すべてが再び再生されます。

## ヒント

- すべてをミュートしてから、聴きたい1、2トラックのみをミュート解除します — 選択が頻繁に変わる場合、ソロよりも迅速です。
- 他のトラックに触れずに1トラックのみを聴くには、代わりに[ソロにする](/guides/tracks-and-export/mute-and-solo-tracks/)を使用してください。
