## このガイドの目的 {#what-this-guide-is-for}

Make stereo track は 2 つのモノラルトラックを 1 つのステレオクリップにレンダリングし、元のトラックを置き換えます。メニューを開いたトラックが左チャンネルになり、その下にある最初の互換性のあるモノラルトラックが右チャンネルになります。下に該当するトラックがない場合は、プロジェクト内の別の場所にある最初の互換性のあるモノラルトラックを Soundscaper が使用します。結合する前に、右チャンネルにするトラックを左チャンネルのトラックのすぐ下に置いてください。

:::note[Audacityから移行する場合]
これは Audacity の **Upper mono track menu → Make stereo track (Audacity 4)** に相当します。以下の名前は Soundscaper での名称で、異なる場合があります。
:::

## 手順

1. Soundscaper を開きます。エディターが読み込まれると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート** を選び、左チャンネルにするモノラル録音を選択します。録音は専用のトラックにクリップとして追加されます。
3. **ファイル → ファイルをインポート** を選び、右チャンネルにするモノラル録音を選択します。録音は専用のトラックにクリップとして追加され、最初の録音の下のトラックに表示されます。再生したい時刻に合わせてクリップを配置します。
4. トラックヘッダーの **トラックオプション** ボタンから左チャンネルの録音のメニューを開き、**トラックチャンネル → ステレオトラックを作成** を選びます。
5. プロジェクトに 1 つのクリップと 2 つのトラックが表示されます。
   *表示される内容:* 2 つのモノラル録音が 1 つのステレオクリップに置き換わり、各チャンネルに意図した音が入ります。

## ヒント

- 新しいクリップはプロジェクトのサンプルレートで両方のトラックの内容を含みます。どちらかのトラックにある空白部分は、そのチャンネルでは無音になります。
- 録音の開始時刻をそろえる必要がある場合は、結合する前に[トラックの開始位置をそろえる](/guides/editing/align-track-starts-together/)を行います。
- 後で個別のクリップを編集する必要がある場合に備え、プロジェクトのコピーを保存してください。**編集 → 取り消す** で 2 つのモノラルトラックに戻せます。
