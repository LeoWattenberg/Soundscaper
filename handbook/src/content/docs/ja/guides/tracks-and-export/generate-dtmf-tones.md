## このガイドの目的 {#what-this-guide-is-for}

電話のキーパッドでは各記号に2つの音を同時に使うDTMF方式が使われます。電話効果音に必要な並びを、記号間の休止を含めて生成します。

:::note[Audacityから移行する場合]
これはAudacity 3の **Generate → DTMF Tones** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **生成 → DTMFトーン** を選びます。**DTMFトーン** ダイアログで **DTMFシーケンス** を `123`、**振幅** を `0.2`、**持続時間（秒）** を `2` にしてから **生成** を押します。記号を順番に入力してください。全体の長さには音と休止の両方が含まれます。
3. プロジェクトにクリップが1つ表示されます。
   *表示される結果:* 入力した順のキーパッド音が1つのクリップに含まれます。

## ヒント

- デューティサイクルで、音と無音が占める割合を調整します。
- 生成前にタイミング概要で各音と休止の長さを確認できます。
