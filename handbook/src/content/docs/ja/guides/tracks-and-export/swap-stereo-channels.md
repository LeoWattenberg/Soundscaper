## このガイドの目的 {#what-this-guide-is-for}

Swap stereo channelsはステレオトラックの左右の音声を交換します。マイクやレコーダーの接続が逆だった場合でも、録音のタイミングを保ったまま修正できます。

:::note[Audacityから移行する場合]
これはAudacity 3の **Audio Track Dropdown Menu → Swap Stereo Channels** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、チャンネルが逆のステレオ録音を選びます。録音は専用トラックのクリップとして表示されます。
3. トラックヘッダーの **トラックオプション** ボタンからメニューを開き、**トラックチャンネル → ステレオチャンネルの入れ替え** を選びます。
4. プロジェクトにクリップが1つ、トラックが2本表示されます。
   *表示される結果:* 1つのステレオクリップのまま位置は変わらず、左右のチャンネルが入れ替わります。

## ヒント

- これはチャンネルの内容を交換します。パンは聞こえる位置を変えるだけで、チャンネル自体は交換しません。
- **編集 → 取り消す** で元のチャンネル順に戻せます。
