## このガイドの目的 {#what-this-guide-is-for}

Ogg Vorbisは音声情報の一部を捨てて、小さな再生用コピーを作ります。受け取り側のプレーヤーやサービスが対応している場合に、この形式でミックスを書き出します。

:::note[Audacityから移行する場合]
これはAudacity 3の **File → Export Audio → Ogg Vorbis** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、共有する録音またはミックスを選びます。音声は専用トラックのクリップとして表示されます。
3. **ファイル → オーディオをエクスポート** を選び、**フォーマット** を **Ogg Vorbis** にしてから **書き出し** を押します。レンダリングが終わるとファイルがダウンロードされ、リンクはダイアログに残ります。
   *表示される結果:* 書き出しダイアログにダウンロード可能なOggファイルが表示されます。

## ヒント

- Qualityでファイルサイズとエンコード品質のバランスを調整します。
- 録音を再編集または再エンコードする可能性がある場合は、[可逆マスター](/guides/tracks-and-export/export-a-flac/)を残します。
