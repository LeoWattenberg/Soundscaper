## このガイドの目的 {#what-this-guide-is-for}

一度トラックのベッドがバランスよく整ったら、それらを1つにミックスダウンすることで、プロジェクトを扱いやすくし、エクスポートしたり他の場所に持ち出したりするための単一のクリップを得ることができます。ミックスは、選択された各トラックのゲイン、パン、オートメーション、エフェクトを使用します。ミュートとソロは、この操作中に選択されたトラックでは無視され、マスター処理はライブのままです。

:::note[Audacityから移行する場合]
これはAudacityの**トラック → ミックス → ミックスとレンダリング**です。以下に示す名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、最初のパートを選択します。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → インポート**を選択し、2番目のパートを選択します。それは独自のトラック上のクリップとして配置されます。
4. 最初のクリップの名前バーをクリックし、シフトキーを押しながら2番目のクリップの名前バーをクリックして、両方を選択します。選択されたクリップを持つすべてのトラックがミックスに含まれます。
5. **トラック → ミックス＆レンダリング**を選択します。**ミックス＆レンダリング**ダイアログで、**ミックスダウン**、**エフェクトのレンダリング**、**オリジナルの置き換え**をオンにしたまま、**ミックスダウン先**を**ステレオ**に設定し、**ミックス＆レンダリング**を押します。
6. プロジェクトには、**ミックス**という名前のクリップが表示されます。
   *表示されるはずのもの:* 1つのトラックに**ミックス**という名前のクリップが含まれ、ソーストラックは削除されます。

## ヒント

- **ミックスダウン先**で**モノラル**、**ステレオ**、またはプロジェクトの設定されたマルチチャンネルレイアウトを選択してからレンダリングします。
- **編集 → 元に戻す**を選択すると、バランスを調整する必要がある場合に元のトラックが戻ります。
- エクスポートするためにミックスダウンする必要はありません。**ファイル → オーディオのエクスポート**は、プロジェクト全体を単独でレンダリングします。
