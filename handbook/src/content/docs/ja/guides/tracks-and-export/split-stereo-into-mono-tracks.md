## このガイドの目的 {#what-this-guide-is-for}

ステレオ録音は、1トラックに2つのチャンネルを持つものです。チャンネルが異なる内容を保持している場合（左にインタビュアー、右にゲスト、または2チャンネルレコーダーからのギターとクリックトラックなど）、それらを独自のレベルとエフェクトを持つ別々のトラックに配置したいものです。

:::note[Audacityから移行する場合]
これはAudacityの**トラックドロップダウン → ステレオトラックを分割**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ステレオ録音ファイルを選択します。ファイルは独自のトラック上のクリップとして配置されます。
3. ヘッダーの**トラックメニュー**ボタンからトラックのメニューを開き、**トラックチャンネル → ステレオをleft/rightモノに分割**を選択します。各チャンネルが独自のモノラルトラックになり、ハード左とハード右にパンニングされるため、ミックスは同じように聞こえます。
4. プロジェクトには2つのクリップが表示されます。
   *確認事項:* 2つのモノラルクリップが、それぞれの側面名で命名された2つのトラック上に1つずつ表示されるはずです。

## ヒント

- 両方のトラックを選択し、トラックメニューから**トラックチャンネル → ステレオトラックを作成**を選択して、再び結合できます。
- **ステレオを中央モノに分割**は同じことをしますが、両方のトラックを中央に配置します。これは、チャンネルが同じ音を持っていた場合に適切です。
