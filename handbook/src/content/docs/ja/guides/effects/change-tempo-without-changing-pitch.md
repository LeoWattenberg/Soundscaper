フレーズをゆっくりして練習したり、ナレーションを限られた時間内に収めたりする場合、従来は速度の変化に伴ってピッチも変化していました。Change Tempo（テンポ変更）はピッチを維持したまま、素材の再生速度のみを変更します。

:::note[Audacityからの移行について]
これはAudacityの**Effect → Pitch and Tempo → Change Tempo**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、速くしたり遅くしたりする録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Effect → Pitch and tempo → Change tempo**を選択します。**Change tempo**ダイアログで、**Percent change**を`10`に設定し、**Apply to selection**を押します。正の値は選択範囲を速くします。10パーセントは約1/10短縮します。負の値は遅くします。
5. **Play**を押して聴き、次に**Stop**を押します。
   *確認事項:* 録音は少し速くなり、ピッチは同じように聞こえます。

## ヒント

- 大きな変更（約30パーセント以上）は、処理されたような音に聞こえ始めます。結果が重要であれば、大きな変更を2つの小さなステップに分けて適用してください。
- クリップは短くなったり長くなったりするため、トラック上の後続の要素も移動します。
