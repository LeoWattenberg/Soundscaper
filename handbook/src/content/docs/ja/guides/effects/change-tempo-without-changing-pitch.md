## このガイドの目的 {#what-this-guide-is-for}

学習するためにパスを遅くしたり、持っている時間にボイスオーバーを押し込んだりすると、ピッチが速度に合わせて変わることがありました。**テンポの変更**は、ピッチはそのままで、素材が通過する速度だけを変更します。

:::note[Audacityから来た場合？]
これはAudacityの**効果 → ピッチとテンポ → テンポの変更**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、スピードアップまたはスローダウンしたい録音を選択します。これは、独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ピッチとテンポ → テンポの変更**を選択します。**テンポの変更**ダイアログで、**パーセント変更**を`10`に設定し、**選択範囲に適用**を押します。正の値は選択範囲を速め、ピッチは同じままです。10パーセントの値は約1/10に短縮されます。負の値はそれを遅くします。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音は少し速くなり、ピッチは変わりません。

## ヒント

- 大きな変更（約30パーセント以上）は、処理されたように聞こえ始めます。結果が重要であれば、大きな変更を2つの小さなステップで適用してください。
- クリップは短くなったり長くなったりするので、トラック上のその後に続くものは移動します。
