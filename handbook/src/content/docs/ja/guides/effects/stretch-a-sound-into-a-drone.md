ポールストレッチは、スロー化されたポップソングを音の大聖堂に変える効果です。これは、普通のテンポ変更ではできないように、選択肢を大きな係数で伸ばしながら、詳細を滑らかな洗浄にぼかします。ドローン、パッド、雰囲気に使用してください。

:::note[Audacityから来た場合]
これはAudacityの**効果 → ピッチとテンポ → ポールストレッチ**です。以下の名前はSoundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、伸ばしたい音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ピッチとテンポ → ポールストレッチ**を選択します。**ポールストレッチ**ダイアログで、**ストレッチ係数**を`4`に設定し、**選択範囲に適用**を押します。4に設定すると、選択範囲が4倍長くなります。10以上の係数は夢のような効果を生み出しますが、レンダリングに比例して時間がかかります。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 音はゆっくりで滑らかな洗浄になり、4倍長くなります。

## ヒント

- **時間解像度**を大きくすると、結果がさらに滑らかになり、リズムが失われます。小さくすると、より攻撃的な音が保たれます。
- 出力は長いです。必要な部分をトリミングし、エンドをフェードアウトさせてください。
