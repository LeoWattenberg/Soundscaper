時には、昔ながらのエフェクトが望ましい場合があります。録音を遅くするとピッチが下がり、速くするとピッチが上がります。これは、間違った速度で再生されているレコードのようなものです。Change speed and pitch はまさにこれを行い、ピッチと時間を分離する必要がないため、速度エフェクトの中で最もクリーンなものです。

:::note[Audacityから移行する場合]
これは Audacity の **Effect → Pitch and Tempo → Change Speed** に相当します。以下の名称は Soundscaper 独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaper を開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio** を選択し、速くしたり遅くしたりする録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all** を選択します。
4. **Effect → Pitch and tempo → Change speed and pitch** を選択します。**Change speed and pitch** ダイアログで、**Speed change** を `25` に設定し、**Apply to selection** を押します。正のパーセンテージは選択範囲を速くしピッチを上げ、−50 は速度を半分にしピッチをオクターブ下げます。
5. **Play** を押して聴き、その後 **Stop** を押します。
   *確認事項:* 録音が以前より速く、高く、短くなっているはずです。

## ヒント

- 間違ったサンプルレートで録音されたものを修正する場合（44.1 kHz の素材を 48 kHz として再生すると、約 9% 速く聞こえる）— 正確な補正値は −8.16% です。
- ピッチを変えずに速度を変更するには、代わりに [Change tempo](/guides/effects/change-tempo-without-changing-pitch/) を使用します。
