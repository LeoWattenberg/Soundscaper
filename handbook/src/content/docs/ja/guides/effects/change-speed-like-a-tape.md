古いスタイルのエフェクトが欲しい時があります：録音を遅くするとピッチが下がり、早くするとピッチが上がります。これはレコードを間違った速度で再生したような効果です。**ピッチとテンポの変更**は、ピッチと時間を分離する必要がないため、最もクリーンなスピードエフェクトです。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → ピッチとテンポ → ピッチとテンポの変更**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、スピードアップまたはスローダウンしたい録音を選択します。録音は独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **エフェクト → ピッチとテンポ → ピッチとテンポの変更**を選択します。**ピッチとテンポの変更**ダイアログで、**スピード変更**を`25`に設定し、**選択範囲に適用**を押します。正のパーセンテージは選択範囲を速くし、ピッチを上げます。-50は速度を半分にし、1オクターブ下げます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音は速くなり、ピッチが高くなり、短くなります。

## ヒント

- サンプルレートが間違った録音を修正するには、44.1 kHzの素材を48 kHzで再生すると、約9パーセント速くなります。正確な修正は-8.16パーセントです。
- ピッチを変えずにスピードを変更するには、[テンポの変更](/guides/effects/change-tempo-without-changing-pitch/)を使用してください。
