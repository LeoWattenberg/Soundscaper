フェイザーは、サウンドをそのコピーと混合し、移動全通関数を通過させたものと混合します。これにより、ノッチが遅いオシレーターに合わせてスペクトルを上下にスウィープします。ギター、エレクトリックピアノ、またはパッドでは、数多くのレコードで聞かれる渦巻きの音が得られます。Audacity 3にはフェイザーが搭載されていましたが、Audacity 4には搭載されていないため、ここで使用するにはこれが最適です。

:::note[Audacityから来た場合]
これはAudacityの**効果 → フェイザー（Audacity 3；Audacity 4にはフェイザーがありません）**です。以下の名前はSoundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、処理するサウンドを選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 歪みと変調 → フェイザー**を選択します。**フェイザー**ダイアログで、**ステージ**を`4`に、**LFO周波数**を`0.6`に設定し、**選択範囲に適用**を押します。ステージが多いほどノッチが深くなります。4はクラシックなペダルの数です。LFO周波数はスウィープの速度を決定します。0.6 Hzは遅く、音楽的な渦巻きになります。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* サウンドがゆっくりと渦巻き、ノッチがそれを通してスウィープします。

## ヒント

- **フィードバック**はノッチを鋭くし、より金属的で共鳴するスウィープにします。微妙な効果を得るには、ゼロに近い値に保ちます。
- フェイザーは、トラックのラックでリアルタイムエフェクトとしても実行できるため、調整しながらスウィープの音を聴くことができます: [トラックにリアルタイムエフェクトを追加する](/guides/effects/add-a-realtime-effect-to-a-track/)。
