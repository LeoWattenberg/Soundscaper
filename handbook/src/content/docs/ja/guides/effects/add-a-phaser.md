フェイザーは、音そのものと、移動するオールパスステージを通過したそのコピーを混合します。これにより、ノッチがゆっくりしたオシレーターに同期してスペクトラムの上と下を掃引します。ギター、エレクトリックピアノ、パッドに適用すると、無数のレコードで聴かれるあの渦巻きのようなサウンドが得られます。Audacity 3にはフェイザーが搭載されていましたが、Audacity 4には搭載されていないため、ここではこのエフェクトが役立ちます。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → フェイザー（Audacity 3用。Audacity 4にはフェイザーなし）**です。以下に記載されている名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、処理するサウンドを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 歪みとモジュレーション → フェイザー**を選択します。**フェイザー**ダイアログで、**ステージ数**を`4`に設定し、**LFO周波数**を`0.6`に設定してから、**選択範囲に適用**を押します。ステージ数が多いほどノッチが深くなります。4はクラシックなペダルです。LFO周波数は掃引の移動速度です — 0.6 Hzはゆっくりとした音楽的な渦巻きになります。
5. **再生**を押して聴き、次に**停止**を押します。
   *確認すべきこと:* ノッチがサウンドを掃引するにつれて、サウンドがゆっくりと渦を巻きます。

## ヒント

- **フィードバック**はノッチをより金属的で共鳴する掃引に鋭くします。控えめな効果にする場合はゼロ付近に保ちます。
- フェイザーはトラックのラック内でリアルタイムエフェクトとしても動作するため、調整しながら掃引を聴くことができます：[トラックにリアルタイムエフェクトを追加](/guides/effects/add-a-realtime-effect-to-a-track/)。
