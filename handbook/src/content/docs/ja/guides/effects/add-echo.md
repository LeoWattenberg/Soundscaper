Echoは、遅延後に選択範囲を再生し、さらに再生します。各繰り返しは前のものより小さくなります。これはボーカルにおけるクラシックなスラップバックや、叫び声における峡谷効果です。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → 遅延と残響 → Echo**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、エコーさせたいサウンドを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 遅延と残響 → Echo**を選択します。**Echo**ダイアログで、**減衰係数**を`0.4`に設定し、**選択範囲に適用**を押します。各繰り返しは前のものの0.4倍の音量になるため、エコーは数回の繰り返しで消えていきます。**遅延時間**はそれらの間隔を設定します。
5. **再生**を押して聞き、次に**停止**を押します。
   *確認すべきこと:* サウンドの後に、その反復がフェードアウトしながら続きます。

## ヒント

- クリップの後に1〜2秒の無音を追加します（**生成 → 無音**）。これにより、最後の反復が鳴るための余裕が生まれます。
- 明確な反復ではなく、ルーム感を求める場合は、[Reverb](/guides/effects/add-reverb/)を使用します。
