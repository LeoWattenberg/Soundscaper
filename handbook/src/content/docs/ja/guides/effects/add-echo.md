エコーが選択した音声を遅延後に再度再生し、その後さらに繰り返し再生します。各繰り返しは前回よりも静かになります。これは、ボーカルのクラシックなスラップバックや、叫び声のキャニオンエフェクトです。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → ディレイとリバーブ → エコー**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、エコーをかけたい音声を選択します。その音声は独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **エフェクト → ディレイとリバーブ → エコー**を選択します。**エコー**ダイアログで、**減衰係数**を`0.4`に設定し、**選択範囲に適用**を押します。各繰り返しは前の繰り返しの0.4倍の音量になるため、エコーは数回の繰り返し後に消えていきます。**ディレイ時間**は繰り返し間の間隔を設定します。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 音声が自分自身を繰り返し、徐々に消えていくのが見えます。

## ヒント

- クリップの後に数秒の無音を追加する (**生成 → 無音**) ことで、最後の繰り返しが響く余地ができます。
- 個別の繰り返しではなく、部屋の響きが欲しい場合は、[リバーブ](/guides/effects/add-reverb/)を使用します。
