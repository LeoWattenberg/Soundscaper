## このガイドの目的 {#what-this-guide-is-for}

Effectメニュー内のエフェクトは、オーディオに一度だけ恒久的な変更を加えます。リアルタイムエフェクトはトラック上に配置されます。再生およびエクスポート中に動作し、設定はいつでも変更可能で、元のオーディオデータは変更されません。ミックスの進行に合わせて調整を続けたいリバーブ、イコライザー、コンプレッションには、これが適切な選択です。

:::note[Audacityからの移行について]
これはAudacityの**Effect → Add Realtime Effects**に相当します。以下の名称はSoundscaper独自のものです。場合によってはAudacityの名称と異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、エフェクトを適用したい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. トラックヘッダーの**Effects**を押してエフェクトパネルを開き、トラックのラック内の**Effects**を押して**Reverb**を選択します。設定ウィンドウが開きます。操作が完了したら**Close**を押します。トラックのラックにReverbがリスト表示されます。設定ウィンドウは、調整したいときにいつでもラックから利用可能です。
4. **Play**を押して聴き、その後**Stop**を押します。
   *確認事項:* トラックがリバーブを介して再生されます。

## ヒント

- ラックに複数のエフェクトを追加し、ドラッグして順序を変更できます。各エフェクトは次のエフェクトに信号を伝達します。
- エフェクトパネルの下部にあるマスターラックは、ミックス全体を処理します。
- ラックにはディレイ、ハイパス／ローパスフィルター、ノイズゲート、ノッチフィルター、シェルフフィルター、トレモロ、ボコーダーも用意されています。基本的な選択方法とラックの操作は共通です。
- [オーディオエフェクトのリファレンス](/reference/generated/audio-effects/)では、ディレイ、ノイズゲート、ボコーダーの動作と、再生中のボコーダーの正規化について説明しています。
