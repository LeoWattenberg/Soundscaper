バックトラックを歌手のキーに転調させたり、少しフラットにチューニングされた楽器を微調整したりすることは、長さを改变してはならないピッチの変更です。Change Pitch（ピッチ変更）は、選択範囲を半音単位でシフトし、タイミングには一切影響を与えません。

:::note[Audacityから移行される方へ]
これはAudacityの**Effect → Pitch and Tempo → Change Pitch**（効果 → ピッチとテンポ → ピッチ変更）に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了となります。
2. **File → Import audio**（ファイル → オーディオのインポート）を選択し、転調する録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**（選択 → すべて選択）を選択します。
4. **Effect → Pitch and tempo → Change pitch**（効果 → ピッチとテンポ → ピッチ変更）を選択します。**Change pitch**（ピッチ変更）ダイアログで、**Semitones**（半音）を`2`に設定し、**Apply to selection**（選択範囲に適用）を押します。2半音は1全音の上昇です。負の値は下降します。
5. **Play**（再生）を押して聴き、その後**Stop**（停止）を押します。
   *確認事項:* 録音は高くなり、以前とまったく同じ長さであるはずです。

## ヒント

- **Preserve formants**（フォルマント保持）をオンにすると、ピッチをシフトしても声が同じ人物のように聞こえるように保たれます。結果が鼻にかかったように聞こえる場合は、楽器に対してはオフにしてください。
- テープのようにピッチと速度を同時に変更するには、同じサブメニュー内の**Change speed and pitch**（速度とピッチの変更）を使用します。
