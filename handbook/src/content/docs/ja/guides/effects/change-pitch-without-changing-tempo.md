バックトラックを歌手のキーにトランスポーズしたり、少しフラットにチューニングされた楽器を調整したりするには、ピッチを変更する必要がありますが、長さは変えてはなりません。ピッチ変更は、選択範囲を全音階でシフトし、タイミングはそのままにします。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ピッチとテンポ → ピッチ変更**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、トランスポーズしたい録音を選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ピッチとテンポ → ピッチ変更**を選択します。**ピッチ変更**ダイアログで**半音**を`2`に設定し、**選択範囲に適用**を押します。半音2つは1つの全音上です。負の値は下がります。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音は高くなり、長さは以前と同じままです。

## ヒント

- **フォーマントを保持**は、声がシフトしても同じ人物のように聞こえるようにします。楽器の場合は、結果が鼻にかかった音になるため、オフにします。
- テープのようにピッチと速度を同時に変更するには、同じサブメニューの**速度とピッチの変更**を使用します。
