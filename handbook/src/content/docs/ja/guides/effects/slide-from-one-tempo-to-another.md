テンポの変更は、選択範囲全体に1つの変更を適用します。スライディング・ストレッチは、変更を移動させます：元のテンポから始まり、四分音符速く終わる、またはフレーズ全体でピッチをテープストップや上昇するドローンにするために上げます。テンポとピッチのスライドは別々に設定されるため、片方が動いている間にもう片方は静止しています。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ピッチとテンポ → スライディング・ストレッチ**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ストレッチするフレーズを選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ピッチとテンポ → スライディング・ストレッチ**を選択します。**スライディング・ストレッチ**ダイアログで、**最終テンポ変更**を`25`に設定し、**選択範囲に適用**を押します。初期テンポ変更はゼロのままなので、フレーズは自分の速度で始まり、終わりには四分音符速くなります。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* フレーズは進行するにつれて速度が上がります。

## ヒント

- **初期ピッチシフト**と**最終ピッチシフト**を設定して、ピッチもスライドさせます。正の最終値は、終わりに向かって上昇します。
- 他のテンポ効果と同様に、これはクリップの長さを変更するため、トラックの後のすべてが移動します。
