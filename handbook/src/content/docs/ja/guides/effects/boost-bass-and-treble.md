ベースとトレブルは、ハイファイアンプのトーンコントロールです。低域用と高域用の2つのノブがあり、それぞれデシベルで調整できます。これは、イコライザー全体を学習することなく、薄い声を温かくしたり、退屈な録音に空気感を加えたりする最も迅速な方法です。

:::note[Audacityから来た場合？]
これはAudacityの**効果 → EQとフィルター → ベースとトレブル**です。以下に記載されている名前は、Soundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、温めたり明るくしたりしたい録音を選択します。これは、独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → EQとフィルター → ベースとトレブル**を選択します。**ベースとトレブル**ダイアログで、**ベース**を`4`に、**トレブル**を`2`に設定し、**選択範囲に適用**を押します。小さなブーストでも効果は大きいです。ベースを4デシベル上げるだけで明確に聞こえるようになり、8デシベルを超えるとブーミーな音になります。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音は下部がより豊かになり、上が少し明るくなります。

## ヒント

- ブーストはレベルを上げます。波形がその後天井に触れる場合は、同じダイアログの**ボリューム**を下げたり、正規化します。
- 特定の周波数に対する正確なコントロールが必要な場合は、同じサブメニューの**フィルターカーブEQ**または**グラフィックEQ**を使用してください。
