## このガイドの目的 {#what-this-guide-is-for}

Vocoderは声の変化を別の音の制御に使い、話し声を音楽的またはロボット風にします。Soundscaperではモノラルの声の選択範囲に適用し、キャリアレベルで結果を調整します。

:::note[Audacityから移行する場合]
これはAudacity 4.0.1の **Effect → Distortion and Modulation → Vocoder** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、エフェクトを制御するモノラルの声などを選びます。音は専用トラックのクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → ディストーションとモジュレーション → ボコーダー** を選びます。**ボコーダー** ダイアログで **ボコーダーのバンド数** を `24` にし、**ボコーダー処理音声** に **出力** を選んでから **選択範囲に適用** を押します。バンド数で声の形を分割する細かさが決まり、**音声キャリアレベル** はモノラル選択時の内蔵キャリアを調整します。
5. **再生** を押して聴き、次に **停止** を押します。
   *表示される結果:* 声が合成音のようなハーモニー感を帯びます。

## ヒント

- 安定した音程のキャリアはより音楽的になり、ホワイトノイズやレーダーの脈動は声を機械的にします。
- Audacityのステレオ手順では、Vocoderを適用する前に声を左チャンネル、キャリアを右チャンネルに置きます。
