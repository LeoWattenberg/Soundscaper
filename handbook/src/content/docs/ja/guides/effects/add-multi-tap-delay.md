## このガイドの目的 {#what-this-guide-is-for}

Delayは指定した間隔の後に音を繰り返し、さらに小さくなるエコーを連続して加えます。このマルチタップ効果はフレーズ、音符、選択した部分にリズムのある反復を作るのに便利です。

:::note[Audacityから移行する場合]
これはAudacity 4.0.1の **Effect → Delay and Reverb → Delay** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、繰り返したいフレーズや音を選びます。音は専用トラックのクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → ディレイとリバーブ → ディレイ** を選びます。**ディレイ** ダイアログで **ディレイ時間** を `0.3`、**エコー数** を `4` にし、**エコー全体を含める** に **エコーの長さ** を選んでから **選択範囲に適用** を押します。Delay timeは反復間隔、エコー数は反復回数です。エコーの余韻を残すため、選択範囲が長くなることがあります。
5. **再生** を押して聴き、次に **停止** を押します。
   *表示される結果:* 選択した音の後に、徐々に小さくなるエコーが続きます。

## ヒント

- 密度の高い響きには **ディレイ時間** を短くし、各反復をはっきり聞かせるには長くします。
- 反復が大きくなりすぎたり元音を覆ったりする場合は **エコーごとのゲイン** を下げます。
