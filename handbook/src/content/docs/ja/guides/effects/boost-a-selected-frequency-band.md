## このガイドの目的 {#what-this-guide-is-for}

Spectral Amplifyは選択した時間範囲内の周波数帯だけを増幅します。小さく持ち上げると、録音全体のレベルを上げずに小さな音や細部を際立たせることができます。

:::note[Audacityから移行する場合]
Audacity では **Effect → Spectral Tools → Amplify selection (Audacity 4)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、強調したい小さな音が含まれる録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. 調べたいトラックのヘッダーにある **トラックオプション** ボタンからメニューを開き、**トラック表示 → スペクトログラム** を選びます。
4. クリップ上部のルーラーをドラッグして、細部を含む範囲を選択します。
5. **エフェクト → スペクトル編集 → スペクトルの周波数範囲を選択** を選びます。**最小周波数（Hz）** を `200`、**最大周波数 (Hz)** を `320`、**ゲイン（dB）** を `4` に設定し、**スペクトル増幅** を押します。適度な4 dBの増幅により、この範囲内で選択した帯域だけが大きくなります。
6. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* 選択した細部がその範囲で目立ち、ほかの部分のレベルは変わりません。

## ヒント

- 強調したい音の近くに周波数範囲を絞ってください。広い範囲を選ぶと周囲の音も大きくなります。
- 増幅した範囲が耳障りになったり周囲より大きくなったりした場合は、ゲインを下げてください。
