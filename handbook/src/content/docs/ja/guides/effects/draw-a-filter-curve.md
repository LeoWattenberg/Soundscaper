## このガイドの目的 {#what-this-guide-is-for}

Filter Curve EQでは固定のバンドやシェルフを選ぶ代わりに、好みの音色バランスを描けます。点を追加して低域のこもりを抑え、中域を保ち、高域を和らげます。

:::note[Audacityから移行する場合]
これはAudacityの **Effect → EQ and Filters → Filter Curve EQ** です。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、周波数バランスを調整したい録音を選びます。録音は専用トラックのクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → EQとフィルター → フィルターカーブ EQ** を選びます。**フィルターカーブ EQ** ダイアログで **カーブポイント（Hz:dB）** を開き、**カーブポイント（Hz:dB）** を `20:-12, 60:-12, 100:0, 1000:0, 8000:-3, 20000:-3` にしてから **選択範囲に適用** を押します。このカーブは最低域のこもりを抑え、高域を和らげながら中域のレベルを保ちます。
5. **再生** を押して聴き、次に **停止** を押します。
   *表示される結果:* 中域を保ったまま、低域のこもりと最も高い周波数が抑えられます。

## ヒント

- 特に録音の低域が強い場合は、カーブの変化を控えめにします。
- 横軸は周波数、縦軸はゲインです。点を下げるとその周波数帯が小さくなります。
