ディストーションは、波形をクリップまたは曲げることで、ハーモニック（倍音）を発生させます。少しのソフト・オーバードライブはベースやシンセサイザーに温かみを加え、強くかけるとギターを音の壁に変えます。タイプはカーブの形状を選択し、しきい値は信号のどの程度がそのカーブに到達するかを設定します。

:::note[Audacityから移行する方へ]
これはAudacityの**エフェクト → ディストーション**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ディストーションをかける音を選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → ディストーションとモジュレーション → ディストーション**を選択します。**ディストーション**ダイアログで、**ディストーションタイプ**に**ソフト・オーバードライブ**を選択し、**しきい値**を`-12`に設定してから、**選択範囲に適用**を押します。ソフト・オーバードライブは、ピークを切り落とすのではなく丸めます。しきい値を下げると、信号のより多くの部分がカーブに駆動されます。
5. **再生**を押して聴き、次に**停止**を押します。
   *確認すべきこと:* 音が粗くなり、ピークが丸くなっているはずです。

## ヒント

- 結果が波形内で中心からずれている場合は、**DCブロック**をオンにします。
- ディストーションはレベルを追加します。ピークが上限に達している場合は、その後で正規化します。
