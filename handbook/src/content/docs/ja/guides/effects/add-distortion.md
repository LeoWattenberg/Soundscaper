波形をクリップまたは曲げて高調波を得るディストーション。少量のソフトオーバードライブはベースやシンセを温かくし、大量のディストーションはギターを壁に変える。タイプは曲線の形状を選択し、しきい値は信号のどの程度が到達するかを設定する。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ディストーション**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開く。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ディストーションをかけたいサウンドを選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ディストーションとモジュレーション → ディストーション**を選択します。**ディストーション**ダイアログで、**ディストーションタイプ**として**ソフトオーバードライブ**を選択し、**しきい値**を`-12`に設定して、**選択範囲に適用**を押します。ソフトオーバードライブはピークを切り落とすのではなく、丸くします。しきい値を低く設定すると、より多くの信号が曲線にドライブされます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはず:* サウンドはざらつき、ピークが丸くなります。

## ヒント

- 結果が波形の中心からずれている場合は、**DCブロック**を有効にします。
- ディストーションはレベルを追加します。ピークが上限に達している場合は、後で正規化してください。
