ワウペダルは共鳴フィルタをスペクトラム上で上下に掃引します。Wahwahエフェクトは、あなたが設定したレートでこの掃引を自動的に行います。ギター、キーボード、または持続音のあるあらゆる音源に適しています。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → Wahwah**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ワウエフェクトを適用したい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 歪みとモジュレーション → Wahwah**を選択します。**Wahwah**ダイアログで、**LFO周波数**を`2`に設定し、**Depth**を`80`に設定してから、**選択範囲に適用**を押します。LFO周波数は1秒あたりの掃引回数、Depthはフィルタが移動する距離です。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべきこと:* 録音音が、母音のような掃引トーンで揺れます。

## ヒント

- **Resonance**はフィルタのピークを鋭くします。高い値では甲高い音になります。
- 同じサブメニューにある**Phaser**は、より穏やかで渦を巻くような動きを与えます。
