## このガイドの目的 {#what-this-guide-is-for}

ワウペダルは、共鳴フィルターをスペクトルの上下にスウィープします。ワウワウエフェクトは、設定した速度でスウィープを自動的に行います。これは、ギター、キーボード、または持続的な音を持つあらゆる楽器に適しています。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → ワウワウ**です。以下に示す名前は、Soundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ワウエフェクトを適用したい録音を選択します。録音は独自のトラックにクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **エフェクト → ディストーションとモジュレーション → ワウワウ**を選択します。**ワウワウ**ダイアログで、**LFO周波数**を`2`に、**ディプ**を`80`に設定し、**選択範囲に適用**を押します。LFO周波数は1秒間に行われるスウィープの回数、ディプはフィルターが移動する距離を示します。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはず:* 録音が、スウィープする母音のような音で揺れ動きます。

## ヒント

- **共鳴**はフィルターのピークを鋭くします。値が高いと、音が鳴きます。
- 同じサブメニューの**フェイザー**は、より穏やかで、渦巻くような動きを与えます。
