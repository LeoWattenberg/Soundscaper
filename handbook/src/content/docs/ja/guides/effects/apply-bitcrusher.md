## このガイドの目的 {#what-this-guide-is-for}

Bitcrusherは音の表現に使う情報量を意図的に減らし、粒立ちやデジタルの粗さを加えます。きれいすぎるシンセ、ドラム音、短いボーカルフレーズに向いています。

:::note[Audacityから移行する場合]
Audacityの現在のエフェクト一覧に **No direct built-in equivalent in Audacity’s current effect list.** はありません。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、粗い質感にしたい音を選びます。音は専用トラックのクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → ディストーションとモジュレーション → ビットクラッシャー** を選びます。**ビットクラッシャー** ダイアログで **ビット深度** を `6`、**サンプルレート削減** を `4` にしてから **選択範囲に適用** を押します。ビット数を減らすと振幅の段差が目立ち、サンプルレートを下げると時間方向の細部が減ります。
5. **再生** を押して聴き、次に **停止** を押します。
   *表示される結果:* 音に粗く段階的なデジタル感が加わります。

## ヒント

- 振幅の段差とサンプルの粗さのどちらが効いているか分かるよう、コントロールは一度に1つずつ変えます。
- 効果が強すぎる場合は **ミックス** を下げ、粗くした音と元の音を混ぜます。
