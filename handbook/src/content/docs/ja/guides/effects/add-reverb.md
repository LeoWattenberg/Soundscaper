処理された部屋の近接マイクは、乾燥して親密な音を与えますが、単独では生命を感じさせないことがあります。リバーブは、小さなブースからホールまで、部屋が寄与する何千もの微妙な反射を追加します。

:::note[Audacityから？]
これはAudacityの**効果 → ディレイとリバーブ → リバーブ**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、乾燥した音に聞こえる録音を選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ディレイとリバーブ → リバーブ**を選択します。**リバーブ**ダイアログで、**部屋のサイズ**を`40`に、**リバーブ時間**を`60`に設定し、**選択範囲に適用**を押します。部屋のサイズは空間の大きさを設定し、リバーブ時間は余韻の長さを設定します。音声の場合はどちらも適度に設定してください。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音は直接耳に届くのではなく、空間の中に存在します。

## ヒント

- **ウェットゲイン**を下げたり、**ドライゲイン**を上げたりすると、効果が元の音を圧倒することがあります。
- ミックス全体にリバーブをかけることはめったに効果的ではありません。必要な部分にのみ適用し、残りは乾燥したままにしておきましょう。
