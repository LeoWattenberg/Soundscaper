処理済みルームで近い位置にマイクを配置すると、ドライで親密なサウンドが得られますが、それだけでは生命力に欠けるように感じられることがあります。リバーブは、小規模なブースからホールに至るまで、ルームが本来もたらしていた無数の微小な反射音を補います。

:::note[Audacityから移行される方へ]
これはAudacityの**エフェクト → 遅延とリバーブ → リバーブ**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ドライすぎる録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 遅延とリバーブ → リバーブ**を選択します。**リバーブ**ダイアログで、**ルームサイズ**を`40`に設定し、**残響度**を`60`に設定してから、**選択範囲に適用**を押します。ルームサイズは空間の広さの感覚を設定し、残響度は残響の持続時間を設定します。話し言葉には、両方を適度な値に保ちます。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべきこと:* 録音が耳のすぐ前ではなく、空間の中に置かれているように聞こえるはずです。

## ヒント

- エフェクトが元の音に埋もれてしまう場合は、**ウェットゲイン**を下げたり、**ドライゲイン**を上げたりしてください。
- ミックス全体にリバーブをかけることは、ほとんど機能しません。必要な部分にのみ適用し、残りはドライのままにしてください。
