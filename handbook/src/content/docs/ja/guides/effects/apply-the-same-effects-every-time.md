各エピソードは同じ処理を受けます：正規化、終了フェード。マクロはそのシーケンスを1回記録し、リクエストがあるたびに実行します。設定は選択したままなので、10ステップのルーチンは1つのコマンドになります。Audacity 3にはこれ用のマクロマネージャーがありましたが、Audacity 4ではマクロは復活していません。

:::note[Audacityからの移行]
これはAudacityの**ツール → マクロ → マクロの管理と適用（Audacity 3; Audacity 4にはマクロはありません）**です。以下の名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、処理する録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。マクロは選択肢に対して実行されます。各エフェクトが個別に実行されるのと同じです。
4. **ツール → マクロマネージャー**を選択し、**新規マクロ**を押します。`Episode finish`を**マクロ名**に入力します。**エフェクトの追加**を押して**正規化**と**フェードアウト**を選択し、それぞれ**エフェクトの追加**を押します。**マクロの実行**を押すと、ダイアログにマクロが適用されたと表示されます。**閉じる**を押します。各ステップはデフォルト設定を保持します。実行前に各ステップの**エフェクトの選択**ボタンを押して変更できます。
   *表示されるはずのもの:* 録音は正規化され、最後に無音にフェードアウトします。
5. **再生**を押して聴き、**停止**を押します。

## 注意点

- マクロはエディタと一緒に保存されるので、次の録音を待機して**ツール → マクロマネージャー**にあります。
- **マクロのエクスポート**はチェーンをAudacityのマクロテキストファイルとして書き出し、**マクロのインポート**はそれを読み込みます。そのため、ルーチンは両方のプログラム間で移動できます。
