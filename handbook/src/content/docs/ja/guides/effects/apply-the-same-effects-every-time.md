すべてのエピソードに同じ処理を行います：正規化、フェードアウト。マクロはそのシーケンスを一度記録し、あなたが要求するたびに、あなたが選んだ設定で実行します。これにより、10ステップの手順が1つのコマンドになります。Audacity 3にはまさにこの目的のためのマクロマネージャーがありましたが、Audacity 4ではマクロは復活していません。

:::note[Audacityから移行する場合]
これはAudacityの**ツール → マクロ → マクロの管理とマクロの適用（Audacity 3；Audacity 4にはマクロなし）**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されています。
2. **ファイル → オーディオのインポート**を選択し、処理する録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。マクロは選択範囲に対して実行されます。各エフェクトが個別に実行されるのと同じです。
4. **ツール → マクロマネージャー**を選択し、**新しいマクロ**を押します。`Episode finish`を**マクロ名**に入力します。**エフェクトの追加**を押して**正規化**と**フェードアウト**を選択し、それぞれについて**エフェクトの追加**を再度押します。**マクロの実行**を押します；ダイアログはマクロが適用されたことを報告します。**閉じる**を押します。ここでは各ステップがデフォルトの設定を保持しています；実行前に変更するには、ステップの**エフェクトの選択**ボタンを押します。
   *確認すべきこと:* 録音は正規化され、最後に無音へフェードアウトします。
5. **再生**を押して聞き、その後**停止**を押します。

## ヒント

- マクロはエディタとともに保存されるため、次の録音のために**ツール → マクロマネージャー**の下で待機しています。
- **マクロのエクスポート**はチェーンをAudacityマクロテキストファイルとして書き出し、**マクロのインポート**はそれを読み取ります。これにより、ルーティンが2つのプログラム間で移動できます。
