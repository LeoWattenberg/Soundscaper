## このガイドの目的 {#what-this-guide-is-for}

同一で時間的に揃った2つの録音は、一方の極性を反転して同時に再生すると互いに打ち消し合います。この確認によって、編集や処理でコピーが元音と異なったかどうかを調べられます。

:::note[Audacityから移行する場合]
Audacity では **Effect → Special → Invert** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、コピーと比較したい録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. 比較するトラックのヘッダーにある **トラックオプション** ボタンからメニューを開き、**トラックを複製** を選びます。
5. **エフェクト → 特殊効果 → 反転** を選びます。エフェクトはすぐに選択範囲へ適用されます。コピーの極性を反転すると一致するサンプルの極性が逆になりますが、元の録音は変わりません。
6. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* 2つのトラックが一致して揃っていれば互いに打ち消し合い、残った音から違いが分かります。

## ヒント

- 打ち消すには時間とレベルが一致している必要があります。少しずれているだけでも残った音が聞こえます。
- 両方のトラックをミュート解除し、Soloをオフにして一緒に聴けるようにします。「元に戻す」操作で、極性のテスト前の複製トラックに戻せます。
