AudacityのNyquistプラグインは、エフェクト、ジェネレーター、アナライザーを追加する小さなスクリプトです。Soundscaperでは、これらを各メニューのNyquistサブメニューにまとめて提供しています。Tremolo（トレモロ）は最初の試行として最適です。設定したレートで音量を揺らします。

:::note[Audacityから移行する場合]
これはAudacityの**Effect → Tremolo (a Nyquist plug-in)**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、プラグインを試す録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Effect → Nyquist → Tremolo**を選択します。**Tremolo**ダイアログで、**Frequency (Hz)**を`6`に設定し、**Apply**を押します。1秒6回の揺れは、クラシックなアンプのトレモロです。Nyquistのダイアログでは、Apply to selectionではなく**Apply**を使用します。
5. **Play**を押して聴き、その後**Stop**を押します。
   *確認すべきこと:* 録音が音量で脈動します。

## ヒント

- GenerateとAnalyzeメニューには、それぞれ独自のNyquistサブメニューがあり、PluckやBeat Finderなどのプラグインが含まれています。
- **Tools → Nyquist prompt**は、自分で入力したスクリプトを実行します。
