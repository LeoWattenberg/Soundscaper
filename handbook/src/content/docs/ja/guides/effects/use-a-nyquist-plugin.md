AudacityのNyquistプラグインは、効果、ジェネレータ、アナライザを追加する小さなスクリプトです。Soundscaperは、選択処理を必要とするバンドルスクリプトをNyquistサブメニューの下に保持します。Adjustable Fadeは、録音のフェードインまたはフェードアウトの形状を調整します。

:::note[Audacityから来た場合]
これはAudacityの**効果 → 調整可能なフェード（Nyquistプラグイン）**です。以下の名前はSoundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれると、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、プラグインを試す録音を選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → Nyquist → 調整可能なフェード**を選択します。**調整可能なフェード**ダイアログで、**中間のフェード調整（%）**を`25`に設定し、**適用**を押します。正の調整はフェードを丸くします。Nyquistダイアログでは**適用**ではなく**選択への適用**が使用されます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはず:* 録音がフェードインします。

## ヒント

- GenerateおよびAnalyzeメニューには、PluckやBeat Finderなどのプラグインを含む独自のNyquistサブメニューがあります。
- **ツール → Nyquistプロンプト**は、自分で入力したスクリプトを実行します。
- Delay、ハイパスおよびローパスフィルタ、ノイズゲート、ノッチフィルタ、シェルフフィルタ、トレモロ、およびボコーダは、[リアルタイムラック](/guides/effects/add-a-realtime-effect-to-a-track/)内で実行される効果メニューカテゴリの通常の効果です。
