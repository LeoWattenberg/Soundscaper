プロジェクトはオーディオ以上のものです。それはトラック、クリップ、エフェクト、マーカー、そして履歴です。保存することで、それらはすべてこのコンピュータのブラウザのローカルプロジェクトライブラリに保存され、ファイルメニューから再オープンできます。Soundscaperは作業中に自動的に保存するので、これは主に確実に保存するための方法です。

:::note[Audacityから移行する場合]
これはAudacityの**ファイル → プロジェクトを保存**です。以下の名前はSoundscaper独自のもので、時折異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、作業するものを選びます。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → プロジェクトを保存**を選択します。ステータスバーの保存インジケータがプロジェクトが保存されたことを示します。

## ヒント

- プロジェクトを別のコンピュータに移動するか、ブラウザ外にコピーを保存するには、[コンピュータ間でのプロジェクトの移動](/guides/projects/move-a-project-between-computers/)を参照してください。
- オーディオエクスポートは、編集を再度行う可能性がある場合は、プロジェクト自体を保持しておくべき聴取コピーです。
