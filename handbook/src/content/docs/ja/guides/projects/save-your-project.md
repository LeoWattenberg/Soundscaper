プロジェクトとは、オーディオ以上のものです。トラック、クリップ、エフェクト、マーカー、履歴を含みます。保存すると、これらはすべてこのコンピューター上のブラウザのローカルプロジェクトライブラリに保持され、[ファイル]メニューから再オープンできます。Soundscaperは作業中に自動保存も行いますが、これは主に確実性を確保するための操作です。

:::note[Audacityから移行する場合]
これはAudacityの**[ファイル] → [プロジェクトの保存]**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了です。
2. **[ファイル] → [オーディオのインポート]**を選択し、作業対象を選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **[ファイル] → [プロジェクトの保存]**を選択します。ステータスバーの保存インジケーターが、プロジェクトが保存されたことを示します。

## ヒント

- プロジェクトを別のコンピューターに移動したり、ブラウザ外にコピーを保持したりするには、[コンピューター間でプロジェクトを移動](/guides/projects/move-a-project-between-computers/)を参照してください。
- オーディオのエクスポートは聴取用のコピーであり、プロジェクトではありません。再度編集する可能性がある場合は、プロジェクトを保持してください。
