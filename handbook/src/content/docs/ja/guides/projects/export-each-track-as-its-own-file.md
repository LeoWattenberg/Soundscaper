ミキシングエンジニア、ビデオ編集者、または他のプログラムの共同作業者は、通常、ミックスではなく各パートを必要とします。ステムエクスポートでは、すべてのトラックが個別のファイルとしてレンダリングされ、すべて同じ長さでプロジェクトの開始位置に整列し、1つのアーカイブにまとめられます。

:::note[Audacityから移行する場合]
これはAudacityの**ファイル → オーディオの書き出し → 複数を書き出し、トラックごとに分割**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオの読み込み**を選択し、最初のトラックを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **ファイル → オーディオの読み込み**を選択し、2番目のトラックを選択します。ファイルは独自のトラック上にクリップとして配置されます。
4. **ファイル → オーディオの書き出し**を選択し、**形式**を**WAV**に設定し、**出力**を**個別ステム（トラックごとに分割）**に設定し、**書き出し**を押します。レンダリングが完了するとすぐにファイルがダウンロードされ、そのリンクはダイアログ内に残ります。各トラックはZIP内のWAVとなり、他の場所で読み込んだ際に整列するように同じ長さにトリミングされます。

## ヒント

- ミュートとソロはステムに影響しません。すべてのトラックがレンダリングされます。
- 書き出し前にトラックに名前を付けます — ステムファイルはそれらの名前を継承します。
