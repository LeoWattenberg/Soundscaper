ミキシングエンジニア、ビデオエディター、または他のプログラムとの共同作業者は、ミックスではなく各パートを必要とする場合が多いです。ステムエクスポートは、各トラックを個別のファイルにレンダリングし、プロジェクトの開始に合わせて同じ長さに揃え、1つのアーカイブにまとめます。

:::note[Audacityから移行する場合]
これはAudacityの**ファイル → エクスポートオーディオ → トラックごとに分割して複数エクスポート**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、最初のトラックを選択します。それは単独のトラック上のクリップとして配置されます。
3. **ファイル → インポート**を選択し、2番目のトラックを選択します。それは単独のトラック上のクリップとして配置されます。
4. **ファイル → オーディオのエクスポート**を選択し、**フォーマット**を**WAV**に、**出力**を**個々のステム（トラックごとに分割）**に設定し、**エクスポート**を押します。レンダリングが完了するとファイルがすぐにダウンロードされ、ダイアログにそのリンクが残ります。各トラックはZIP内のWAVとして、他の場所でインポートしたときに揃うように同じ長さにトリムされます。

## 注意点

- ミュートとソロはステムに影響しません。すべてのトラックがレンダリングされます。
- エクスポート前にトラックに名前を付けてください。ステムファイルはそれらから名前を取得します。
