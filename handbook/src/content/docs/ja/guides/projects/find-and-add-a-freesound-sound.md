Freesoundパネルを使うと、Soundscaperを離れずにサウンドを探せます。必要なものを検索し、各結果に表示される作成者とライセンスを確認して、タイムライン上の好きな場所にサウンドを挿入します。Soundscaperは高音質プレビューをプロジェクトのクリップとしてインポートします。

:::note[Audacityから移行する場合]
これはAudacityの **ファイル → インポート → オーディオ（Freesoundからサウンドをダウンロードした後）** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトがすぐに用意されます。
2. **表示 → パネル → Freesound** を選択します。
3. **Freesound** パネルの **Freesoundを検索** に、探したいサウンドを説明する単語やフレーズを入力し、**検索** を押します。一致するサウンドが **Freesoundの検索結果** に表示されます。
4. **Freesoundの検索結果** で、目的の結果の横にある **再生ヘッドに挿入** を押します。サウンドが再生ヘッド位置のクリップとして表示されます。
5. プロジェクトに1つのクリップが表示されます。
   *確認できること:* タイムラインにインポートされたサウンドが表示され、プロジェクトの他の部分と一緒に編集できます。

## ヒント

- 共有する作品でサウンドを使う前に、結果の横にある作成者とライセンスのリンクを確認してください。
- **再生ヘッドに挿入** はサウンドをタイムラインに配置します。クリップを後から開始したい場合は、先に再生ヘッドを移動してください。
