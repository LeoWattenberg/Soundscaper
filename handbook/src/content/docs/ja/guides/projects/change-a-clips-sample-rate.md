44.1 kHzで録音されたクリップは、48 kHzのプロジェクトでも正しく再生されます。Soundscaperはリアルタイムに変換します。しかし、特定のレートでなければならない配信物や、特定の効果を適用する前に、クリップ自体を変換することができます。リサンプリングは、新しいレートですべてのサンプルを再計算し、タイミングを正確に保ちます。

:::note[Audacityから移行する場合]
これはAudacityの**トラック → リサンプリング**です。以下の名前はSoundscaper独自のものであることに注意してください。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、間違ったレートのクリップを選択します。それは独自のトラック上のクリップとして配置されます。
3. クリップ名のバーにある**クリップメニュー**ボタンからクリップのメニューを開き、**クリッププロパティ**を選択します。**リサンプリング**を押して、レートを`44100`に設定し、**リサンプリング**を再度押します。クリップのプロパティは現在のレートを表示します。CD規格は44100 Hzです。
4. **再生**を押して聴き、**停止**を押します。
   *確認できること:* クリップは以前と全く同じように聞こえます。保存されているレートのみが変更されています。

## 注意点

- リサンプリングは編集操作であり、元に戻すことができます。
- レートを下げることで、最も高い周波数が失われます。レートを上げることは何も追加しませんが、無害です。
