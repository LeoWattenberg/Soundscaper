プロジェクトライブラリは、1つのコンピュータの1つのブラウザ内に存在します。プロジェクトを他の場所に持ち運ぶには（別のマシン、同僚、バックアップドライブなど）、プロジェクトファイルとしてエクスポートします。`.sscape` ファイルにはオーディオとすべての編集が含まれており、どの Soundscaper でも開くことができます。

:::note[Audacity から移行する場合]
これは Audacity の **ファイル → プロジェクトの保存 → プロジェクトのバックアップ**、次に **ファイル → 開く** と同じ操作です。以下の名前は Soundscaper 独自のものであることに注意してください。
:::

## 手順

1. Soundscaper を開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート** を選択し、プロジェクトの素材を選択します。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → プロジェクトファイルのエクスポート (.sscape)** を選択します。プロジェクト全体が 1 つの `.sscape` ファイルとしてダウンロードされます。このファイルを安全な場所に保存してください。それが完全なプロジェクトです。
4. **ファイル → 開く** を選択し、ファイルを選択します。このコンピュータにまだプロジェクトがない場合は、直接開きます。ライブラリにすでにプロジェクトがある場合は、Soundscaper は **読み取り専用コピーとして開く** を提供します。それをクリックしてください。
   *表示されるはずのもの:* プロジェクトは、エクスポートしたときと同じトラックとクリップで開きます。

## ヒント

- 読み取り専用コピーを編集するには、ファイルメニューからプロジェクトとして保存する必要があります。
- ファイルはオーディオを含む ZIP アーカイブです。手動で解凍しないでください。
