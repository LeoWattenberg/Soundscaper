Audacity 3 (.aup3) と Audacity 4 (.aup4) で作成されたプロジェクトは直接開くことができます。トラック、クリップ、名前、位置がそのまま移行されます。Soundscaperでサポートされていないエフェクトはリストアップされるので、確認することができます。元のファイルは変更されません。

:::note[Audacityから移行する場合]
これはAudacityの **ファイル → 開く** です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → 開く** を選択し、プロジェクトを選択します。Audacityで設定されていたトラックとクリップがそのまま表示されます。
3. プロジェクトには **オーディオ 1** という名前のクリップと **フィクスト トラック** という名前のトラックが表示されます。
   *確認できること:* Audacityプロジェクトからのトラックとクリップが名前と共に表示されます。

## 注意点

- 古い形式の `.aup` プロジェクトは、その `_data` フォルダを隣に置く必要があります。選択を求められたら、両方を選択してください。
- **ファイル → 他の形式で書き出し → AUP4として書き出し** は逆の操作で、Audacityにプロジェクトを戻す際に使用します。
