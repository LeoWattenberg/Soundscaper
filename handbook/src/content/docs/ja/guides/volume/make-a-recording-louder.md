ゲインが低すぎると、録音は静かですが、通常はクリーンです。Amplify（増幅）はすべてをデシベル単位で同じ量だけ上げますので、録音内のバランスはそのまま維持されます。クリッピングをオフにしておくと、エフェクトはピークをフルスケールを超えて押し上げようとしません。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → 音量と圧縮 → Amplify**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、静かな録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 音量と圧縮 → Amplify**を選択します。**Amplify**ダイアログで、**増幅量**を`6`に設定し、**選択範囲に適用**を押します。6デシベルは概ね音量を2倍にします。**クリッピングを許可**はオフのままなので、エフェクトはピークを歪ませません。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべきこと:* 録音が明らかに大きくなり、波形が高くなっているはずです。

## ヒント

- 結果がまだ静かすぎる場合は、Amplifyを再度実行してください。ゲインは加算されます。
- 固定量を加えるのではなく、ピークを正確なレベルに合わせたい場合は、代わりに[Normalize](/guides/volume/normalize-peaks/)を使用してください。
