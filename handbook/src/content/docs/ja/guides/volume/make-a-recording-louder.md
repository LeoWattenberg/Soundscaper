録音ゲインが低すぎる場合、音量は小さいが通常はクリーンです。アンプライクはデシベル単位ですべてを同じだけ増幅するので、録音内のバランスはそのまま維持されます。クリッピングをオフのままにすると、効果はピークをフルスケール以上に押し上げません。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → 音量と圧縮 → アンプライク**です。以下に示す名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、静かな録音を選択します。それは単独のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 音量と圧縮 → アンプライク**を選択します。**アンプライク**ダイアログで**増幅**を`6`に設定し、**選択範囲に適用**を押します。6デシベルはおおよそ音量を2倍にします。**クリッピングを許可**はオフのままなので、効果はピークを歪ませません。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音が明らかに大きくなり、波形が高くなります。

## ヒント

- 結果がまだ静かな場合は、アンプライクを再度実行してください。ゲインは加算されます。
- ピークを正確なレベルに設定するのではなく、固定量を追加したい場合は、[正規化](/guides/volume/normalize-peaks/)を使用してください。
