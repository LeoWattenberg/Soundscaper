ポッドキャストやストリーミングプラットフォームでは、LUFSでラウドネスを測定します。これはピークの大きさではなく、番組がどれだけ大きく聞こえるかを基準とします。Loudness Normalization（ラウドネス正規化）は選択範囲全体を測定し、目標値に調整するため、公開するすべてのエピソードが同じレベルになります。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → 音量と圧縮 → ラウドネス正規化**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、音量が小さい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 音量と圧縮 → ラウドネス正規化**を選択します。**Loudness Normalization**ダイアログで、**目標ラウドネス**を`-16`に設定し、**選択範囲に適用**を押します。ステレオポッドキャストでは一般的に−16 LUFSが目標値として使用されます。モノラルでは−19 LUFSが使用されることがよくあります。プラットフォームのガイドラインを確認してください。
5. **再生**を押して聴き、次に**停止**を押します。
   *確認すべきこと:* 録音が快適で一定のレベルで再生されること。

## ヒント

- 非常にダイナミックな素材では、Loudness Normalizationがピークをフルスケールを超えて押し上げる可能性があります。波形が上部に触れている場合は、リミッターまたはピークNormalizeを−1 dBに適用してください。
- 編集や他のエフェクトの後に、完成したミックスに対して実行してください。これにより、測定値がリスナーが聞くものと一致します。
