ポッドキャストやストリーミングプラットフォームは、ピークの高さではなく、プログラムがどれほど大きく感じるかに応じて、LUFSで音量を測定します。音量正規化は全体を測定し、ターゲットに合わせて調整するので、公開するすべてのエピソードが同じレベルになります。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → 音量と圧縮 → 音量正規化**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、静かな録音を選択します。それは単独のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 音量と圧縮 → 音量正規化**を選択します。**音量正規化**ダイアログで、**ターゲット音量**を`-16`に設定し、**選択範囲に適用**を押します。ステレオポッドキャストの一般的なターゲットは-16 LUFS、モノは-19 LUFSです。プラットフォームのガイドラインを確認してください。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音が快適で一貫したレベルで再生されます。

## ヒント

- 音量正規化は、非常にダイナミックな素材のピークをフルスケール以上に押し上げることがあります。その後にリミッターまたはピーク正規化を実行し、波形がトップに達する場合は-1 dBに正規化します。
- 編集やその他のエフェクトを完了した後の最終ミックスに実行して、測定値がリスナーが聞くものと一致するようにします。
