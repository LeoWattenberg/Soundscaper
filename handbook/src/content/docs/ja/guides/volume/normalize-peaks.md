Normalizeは選択範囲内で最も大きなピークを測定し、そのピークが指定した位置に正確に収まるようにすべてをスケーリングします。これはエクスポート前の通常の最終ステップです。ファイルはクリッピングを起こすことなく、そのフルレンジを使用します。また、一部のサウンドカードが追加するわずかな垂直方向のシフトであるDCオフセットも除去します。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → 音量と圧縮 → Normalize**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、静かな録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 音量と圧縮 → Normalize**を選択します。**Normalize**ダイアログで、**ピーク振幅**を`-3`に設定し、**選択範囲に適用**を押します。マイナス3デシベルに設定すると、後でMP3にエクスポートする場合、エンコーダーのための少しのヘッドルームを残せます。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべきこと:* 最も大きな瞬間が、フルスケールのすぐ下にあるはずです。

## ヒント

- Normalizeはピークを見ており、録音がどれだけ大きく聞こえるかは見ていません。2つの正規化されたファイルでも、まだ非常に異なるように聞こえる可能性があります。その場合は、[ポッドキャストのラウドネスを正規化](/guides/volume/normalize-loudness-for-podcasts/)を参照してください。
- ステレオチャンネルは、**ステレオチャンネルを独立して正規化**をオンにしない限り、一緒に正規化されます。これによりステレオイメージがシフトする可能性があります。
