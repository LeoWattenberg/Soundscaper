ポッドキャストや動画では、話し声が聞こえるたびに音楽の音量を下げて、間隙で元に戻すことで、音楽を話し声の下で再生し続けます。Auto Duck はコントロールトラックからこれを行います。コントロールトラックがしきい値より大きい場所では、選択されたトラックの音量が下げられ、端にはフェードが適用されます。

:::note[Audacity から移行する場合]
これは Audacity の **Effect → Volume and Compression → Auto Duck** です。以下の名称は Soundscaper 独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaper を開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio** を選択し、音楽を選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **File → Import audio** を選択し、音声を選択します。ファイルは独自のトラック上にクリップとして配置されます。
4. 音楽クリップの名前バーをクリックして選択します。選択したクリップがダッキングされる対象です。音楽であり、音声ではありません。
5. **Effect → Volume and compression → Auto Duck** を選択します。**Auto Duck** ダイアログで、**Control track** として音声トラックを選択し、**Duck amount** を `-12` に設定してから、**Apply to selection** を押します。コントロールトラックはダッキングをトリガーするトラックです。12デシベル下げることで、話し声が明確に前面に出るように十分です。
6. **Play** を押して聞き、その後 **Stop** を押します。
   *確認すべきこと:* 他のトラックが再生されている間、音楽が音量を下げ、静かな場所では元に戻ります。

## ヒント

- 単語の間に音楽が速く上下する場合は、**Outer fade** の時間を長くしてください。
- トラックリストで音声トラックを音楽の上に配置し、関係を明確にしてください。
