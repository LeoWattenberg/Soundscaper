リミッターは非常に高い比率を持つコンプレッサーです。しきい値以下では何もしませんが、それを超えると音が一切通りません。エクスポート前にわずかに飛び出しているピークをキャッチしたり、ピークがクリップしないようにミックス全体のレベルを上げたりするためのツールです。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → 音量と圧縮 → リミッター**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、飛び出しているピークがある録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 音量と圧縮 → リミッター (Audacity)**を選択します。**リミッター (Audacity)** ダイアログで、**しきい値**を`-6`に設定し、**選択範囲に適用**を押します。−6 dBを超える音は発生しません。その後、メイクアップターゲットが結果を上げ、上限がフルスケール付近に位置するようにします。
5. **再生**を押して聴き、**停止**を押します。
   *確認すべき点:* 最も大きな瞬間は抑えられ、それ以外は変化しません。

## ヒント

- ピークにはリミッターを、全体の均一性には[コンプレッサー](/guides/volume/even-out-volume-with-a-compressor/)を使用してください。これらは同じ役割ではありません。
- 強力なリミッティングは、すべてがうるさく平坦に感じさせます。数dB以上必要であれば、ミックス自体が熱すぎる可能性があります。
