## このガイドの目的 {#what-this-guide-is-for}

RMSノーマライズはピーク上限ではなく、選択範囲の平均信号レベルを目標値に近づけます。複数の録音のレベルをそろえるときに便利です。元音の音量差が大きい場合は、後からピークを確認してください。

:::note[Audacityから移行する場合]
Audacity では **Effect → Volume and Compression → Loudness Normalization** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、平均レベルを設定したい録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → ボリュームと圧縮 → ラウドネス正規化** を選びます。**ラウドネス正規化** ダイアログで **RMS** に **正規化** を選び、**目標RMS** を `-20` に設定し、**ステレオチャンネルを独立して正規化** をオフにして **選択範囲に適用** を押します。ステレオチャンネルを連動させると、左右のバランスを保ちながら−20 dB RMSを目指します。
5. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* 録音のレベルが−20 dB RMSの目標に近づき、ステレオバランスが保たれています。

## ヒント

- 平均レベルをそろえて比較したい録音には、同じRMS目標値を使います。
- RMSノーマライズはピーク上限を保証しません。クリッピングがないか確認し、必要に応じてヘッドルームを残してください。
