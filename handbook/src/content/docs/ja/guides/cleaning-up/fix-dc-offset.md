一部のサウンドカードや安価なインターフェースは、録音に一定の電圧を加えるため、波形全体が中心線よりわずかに上または下に位置してしまいます。直接は聞こえませんが、ヘッドルームを無駄にし、編集のたびにクリックノイズが発生します。Remove DC Offset（直流オフセットの除去）により、波形を再び中央に合わせます。

:::note[Audacityから移行される方へ]
これはAudacityの**エフェクト → 音量と圧縮 → 直流オフセットの除去**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、中心からずれている録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 音量と圧縮 → Remove DC Offset**を選択します。エフェクトは選択範囲に即座に適用されます。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認事項:* 波形がゼロライン上に中央揃えになっています。

## ヒント

- [Normalize](/guides/volume/normalize-peaks/) はその処理の一部として直流オフセットを除去するため、Normalizeを実行する場合は追加の操作は不要です。
- 録音中に変化しているオフセットは直流ではありません。代わりに[ハイパスフィルター](/guides/cleaning-up/remove-low-rumble/)を使用してください。
