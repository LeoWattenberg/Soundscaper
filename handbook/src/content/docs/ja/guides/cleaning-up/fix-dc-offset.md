## このガイドの目的 {#what-this-guide-is-for}

一部のサウンドカードや安価なインターフェースは、録音に定電圧を追加するため、全体の波形がセンター線より少し上または下に位置します。直接聞くことはできませんが、ヘッドルームを無駄にし、編集ごとにクリック音が発生します。DCオフセットの除去は、波形を再びセンターに戻します。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ボリュームと圧縮 → DCオフセットの除去**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、センターからずれた録音を選択します。それは単独のクリップとしてトラックに配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ボリュームと圧縮 → DCオフセットの除去**を選択します。効果は選択範囲にすぐに適用されます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはず:* 波形がゼロ線にセンターに配置されます。

## 注意点

- [正規化](/guides/volume/normalize-peaks/)は、その役割の一部としてDCオフセットを除去するので、正規化を実行する場合は特に追加の操作は必要ありません。
- 録音中に変化するオフセットはDCではありません。[ハイパスフィルター](/guides/cleaning-up/remove-low-rumble/)を使用してください。
