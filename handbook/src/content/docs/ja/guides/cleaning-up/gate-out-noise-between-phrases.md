ノイズリダクションは録音全体からノイズを取り除きますが、ゲートは異なるアプローチをとります。レベルがしきい値を下回ったとき（文と文の間、ポーズ中など）、ゲートはオーディオを下げ、声が戻った瞬間に再び開きます。言葉の下にあるノイズを除去することはできませんが、言葉の間の隙間をクリーンにし、設定も迅速です。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → ノイズ除去と修復 → ノイズゲート**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ノイジーなポーズを含むテイクを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → Nyquist → ノイズゲート**を選択します。**ノイズゲート**ダイアログで、**ゲートしきい値 (dB)** を `-35` に設定し、**レベル低減 (dB)** を `-30` に設定してから、**適用**を押します。しきい値はノイズより上、最も静かな音声より下に設定する必要があります。-35 dB がほとんどの音声録音に適しています。低減は、隙間がどの程度下げられるかを設定します — 完全にゼロにするのではなく、それは不自然に聞こえます。
5. **再生**を押して聞き、その後 **停止**を押します。
   *確認すべきこと:* ポーズは静かで、すべてのフレーズがそのまま聞こえます。

## ヒント

- 単語の終わりがカットされている場合は、ゲートがよりゆっくり閉じるように **ホールド (ms)** または **ディケイ (ms)** を上げてください。
- 音声の下に続くノイズには、代わりに [ノイズリダクション](/guides/cleaning-up/remove-background-noise/) を使用するか、両方を一緒に使用してください。
