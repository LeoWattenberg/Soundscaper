ノイズリダクションは録音全体からノイズを取り除きますが、ゲートは異なるアプローチを取ります。レベルがしきい値を下回るたび（文と文の間、休憩中）、ゲートはオーディオの音量を下げ、声が戻った瞬間に再び開きます。言葉の下のノイズをきれいにすることはできませんが、言葉間のギャップをきれいにし、設定は簡単です。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ノイズ除去と修復 → ノイズゲート**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ノイズの入った休憩のあるテイクを選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ノイズ除去と修復 → ノイズゲート**を選択します。**ノイズゲート**ダイアログで、**しきい値**を`-35`に、**レベルリダクション**を`-30`に設定し、**選択範囲に適用**を押します。しきい値はノイズよりも上、最も静かなスピーチよりも下である必要があります。−35 dBはほとんどの声の録音に適しています。リダクションはギャップがどれだけ下がるかを設定しますが、すべてを下げることはありません。これは不自然に聞こえます。
5. **再生**を押して聴き、**停止**を押します。
*表示されるはず:* 休憩は静かで、各フレーズは変更されずに通ります。

## ヒント

- 単語の端がカットされている場合は、**ホールド**または**リリース**を上げて、ゲートがよりゆっくりと閉じるようにします。これらのコントロールは秒単位で設定します。
- 声の下に継続するノイズがある場合は、[ノイズリダクション](/guides/cleaning-up/remove-background-noise/)を使用するか、両方を一緒に使用します。
