時には、パスを消したいけれど、その占める時間は残しておきたい場合があります。電話が鳴っている間のポーズ、消音したい名前などです。サイレンシングは、クリップの長さをそのままに保ち、選択した部分だけを平らにしてくれます。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → 特別な削除 → 音声の消音**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → 音声のインポート**を選択し、消音したいパスのある録音を選択します。ファイルは独自のトラック上のクリップとして配置されます。
3. クリップの上にあるスケールをドラッグして、消音したい部分だけを選択します。
4. **編集 → 特別な削除 → 音声の消音**を選択します。
5. プロジェクトには1つのクリップが表示されます。
   *確認できること:* 選択範囲全体にわたって波形が平らになり、クリップは1つにまとまります。

## ヒント

- 消音は通常の編集です:**編集 → 元に戻す**で音声を復元できます。
- 時間と音の両方を削除するには、[録音からミスをカットする](/guides/editing/cut-out-a-mistake/)を参照してください。
