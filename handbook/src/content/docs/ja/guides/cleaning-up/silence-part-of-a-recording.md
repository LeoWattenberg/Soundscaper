時には、パスを消したいけれど、占める時間は残しておきたい場合があります。電話が鳴っている間のポーズ、消音したい名前などです。サイレンシングは、録音の長さをそのままに保ち、選択した部分だけをフラットにします。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → 特別な削除 → 音声の消音**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、消音したいパスを含む録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. クリップの上にあるスケールをドラッグして、消音したい部分だけを選択します。
4. **編集 → 特別な削除 → 音声の消音**を選択します。
5. プロジェクトには3つのクリップが表示されます。
   *表示されるはずのもの:* 新しい中央のクリップの波形は、両側の変更されていない音声の間に平らになっています。

## ヒント

- 消音は通常の編集です：**編集 → 元に戻す**で音声を復元できます。
- 時間と音の両方を取り除きたい場合は、[録音からミスを削除する](/guides/editing/cut-out-a-mistake/)を参照してください。
