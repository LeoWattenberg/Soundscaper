## このガイドの目的 {#what-this-guide-is-for}

Clip Fixは、周囲の波形をもとに短くクリッピングしたピークの欠けた頂点を推定します。録音のコピーに適用して注意深く聴いてください。長く続くクリッピングは復元できません。

:::note[Audacityから移行する場合]
Audacity では **Effect → Noise Removal and Repair → Clip Fix (Audacity 3 and 4)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、修復したい短いクリッピングピークを含む録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → Nyquist → Clip Fix** を選びます。**Clip Fix** ダイアログで **Threshold of Clipping (%)** を `95`、**Reduce amplitude to allow for restored peaks (dB)** を `-9` に設定し、**適用** を押します。しきい値が平らになったピークを見つけ、ヘッドルームが推定された形状を戻す余地を作ります。
5. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* 修復したピークは耳障りさが弱まります。変更を残す前に、手を加えていない元音と比較してください。

## ヒント

- Clip Fixは短く軽度にクリッピングしたピークに適しています。長く続く歪みで失われた細部は復元できません。
- 修復したトランジェントを比較できるよう、元のコピーを残しておきます。波形が不自然に聞こえる場合は変更を元に戻してください。
