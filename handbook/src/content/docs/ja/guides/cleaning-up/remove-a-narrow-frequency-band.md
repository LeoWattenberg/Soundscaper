## このガイドの目的 {#what-this-guide-is-for}

一定の口笛のような音や電子音は、録音の一部で狭い周波数帯にだけ現れることがあります。Spectral Delete は時間範囲内のその帯域を削除し、周囲の周波数はそのまま残します。

:::note[Audacityから移行する場合]
Audacity では **Effect → Spectral Tools → Delete selection (Audacity 4)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、短い音程音が含まれる録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. 調べたいトラックのヘッダーにある **トラックオプション** ボタンからメニューを開き、**トラック表示 → スペクトログラム** を選びます。
4. クリップ上部のルーラーをドラッグして、音が聞こえる時間範囲を選択します。
5. **エフェクト → スペクトル編集 → スペクトルの周波数範囲を選択** を選びます。**最小周波数（Hz）** を `200`、**最大周波数 (Hz)** を `320` に設定し、**スペクトル削除** を押します。これにより、選択した時間範囲だけでループの261.6 Hzの音が小さくなります。
6. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* その部分の音程音が弱まり、録音のほかの部分は変わりません。

## ヒント

- スペクトログラムで音を見つけ、削除する前にその周囲の時間範囲と周波数範囲を狭めます。
- Spectral Delete は選択した時間と周波数の範囲だけに作用します。通常の Delete は選択範囲全体を削除します。
