## このガイドの目的 {#what-this-guide-is-for}

長い間は話のテンポを遅くしますが、すべての間を切り取ると内容を追いにくくなることがあります。Truncate Silenceは、最小長を超えた間の余分な部分だけを圧縮します。

:::note[Audacityから移行する場合]
Audacity では **Effect → Special → Truncate Silence** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、間が長すぎると感じる録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → 特殊効果 → 無音を切り詰める** を選びます。**無音を切り詰める** ダイアログで **しきい値** を `-40`、**最小サイレンス** を `0.5` に設定し、**余分な無音を圧縮** で **アクション** を選び、**圧縮先** を `50` にしてから **選択範囲に適用** を押します。0.5秒を超える無音は超過分の半分の長さに短縮され、フレーズの間には間が残ります。
5. **再生** を押して再生し、次に **停止** を押します。
   *確認できること：* 長い間は短くなりますが、フレーズ間には少し無音が残ります。

## ヒント

- 短い間をそのまま残すには **最小サイレンス** を大きくし、長い間をさらに詰めるには **圧縮先** を小さくします。
- 息継ぎやフレーズの終わりが切れていないか確認します。テンポが不自然になった場合は変更を元に戻してください。
