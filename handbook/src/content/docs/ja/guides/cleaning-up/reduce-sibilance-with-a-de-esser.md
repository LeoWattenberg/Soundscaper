## このガイドの目的 {#what-this-guide-is-for}

De-esserは声全体をほぼ保ったまま、強い歯擦音を抑えます。S音やSH音が周囲の言葉より目立つ声の部分に使います。

:::note[Audacityから移行する場合]
Audacityの現在のエフェクト一覧に **No direct built-in equivalent in Audacity’s current effect list.** はありません。以下の名称はSoundscaper独自のもので、一部異なります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが終わると、新しい空のプロジェクトが使えます。
2. **ファイル → ファイルをインポート** を選び、気になるS音を含む声の部分を選びます。音は専用トラックのクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **エフェクト → ノイズ除去と修復 → ディエッサー** を選びます。**ディエッサー** ダイアログで **周波数** を `6000`、**最大低減量** を `6` にしてから **選択範囲に適用** を押します。Frequencyは歯擦音の帯域を狙い、maximum reductionはその部分を下げる上限を決めます。
5. **再生** を押して聴き、次に **停止** を押します。
   *表示される結果:* 声の他の部分を保ちながら歯擦音が柔らかくなります。

## ヒント

- **周波数** を調整しながらS音を確認します。低すぎると子音や明るさが鈍ることがあります。
- まず **最大低減量** を控えめにし、鋭い歯擦音が残る場合だけ強めます。
