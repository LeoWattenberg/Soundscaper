ケーブル、マウス、またはレコードからのクリック音は、わずか数サンプルの長さしかありません。Click Removal（クリック除去）は、周囲と比べて際立っているスパイクを検出し、それらを滑らかに処理します。これは、1つずつ手動で切り取るよりもはるかに迅速です。

:::note[Audacityから移行される方へ]
これはAudacityの**Effect → Noise Removal and Repair → Click Removal**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、クリック音が含まれている録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Effect → Noise removal and repair → Click Removal**を選択します。**Click Removal**ダイアログで、**Threshold**を`150`に設定し、**Apply to selection**を押します。しきい値を下げると、より静かなクリック音も検出できます。デフォルトの200は保守的な設定ですが、150にすると音楽に影響を与えることなく、より多くのクリック音を検出できます。
5. **Play**を押して聴き、その後**Stop**を押します。
   *確認事項:* クリック音は消え、その周囲の素材は変更されていません。

## ヒント

- クリック音が残っている場合は、その瞬間の前後のみを選択し、より低い**Threshold**で効果を再度実行してください。
- 数ミリ秒より広いクリック音は、この効果ではクリック音として扱われません。代わりに切り取ってください。
