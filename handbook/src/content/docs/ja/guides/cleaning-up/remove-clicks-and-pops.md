ケーブルからのクリック音、マウスのクリック、古いレコードのポップ音などは、ほんの一例です。クリック除去は、周囲と比較して目立つスパイクを検出し、それを滑らかにします。これは、一つ一つ手動でカットするよりもはるかに速いです。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → ノイズ除去と修復 → クリック除去**です。以下に示す名前は、Soundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、クリック音が含まれる録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → ノイズ除去と修復 → クリック除去**を選択します。**クリック除去**ダイアログで、**しきい値**を`150`に設定し、**選択範囲に適用**を押します。低いしきい値は、静かなクリックをキャッチします。デフォルトの200は保守的ですが、150に設定すると、音楽に干渉することなく、より多くのクリックをキャッチできます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* クリック音が削除され、周囲の素材は変更されていません。

## ヒント

- クリック音が残っている場合は、その周囲の瞬間だけを選択し、**しきい値**を低くして効果を再度実行します。
- 数ミリ秒より広いクリック音は、この効果ではクリック音とは見なされません。代わりにカットしてください。
