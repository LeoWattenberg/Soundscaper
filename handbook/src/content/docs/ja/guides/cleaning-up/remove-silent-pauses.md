長いテイクで文の間でゆっくりとしたポーズがあると、聞くのが疲れます。無音の切り取りは、しきい値を下回るすべての区間を検出し、最小長より長くなっているものを短くします。これにより、ペースが速くなりますが、言葉はカットされません。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → 特殊 → 無音の切り取り**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、長いポーズのあるテイクを選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 特殊 → 無音の切り取り**を選択します。**無音の切り取り**ダイアログで、**しきい値**を`-40`に設定し、**選択範囲に適用**を押します。-40 dB未満のものは無音とみなされます。最小無音長より長いポーズは、切り取り長に短縮されます。どちらもここでデフォルトの0.5秒に設定されます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* ポーズが短くなり、すべてのフレーズがまだ完全です。

## ヒント

- フレーズの頭にある言葉が切り取られる場合は、最小無音長を上げたり、しきい値を下げたりしてください。
- この効果は選択範囲の長さを変更するため、他のものと揃える前に実行してください。
