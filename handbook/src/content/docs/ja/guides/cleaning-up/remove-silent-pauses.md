文と文の間に長い間がある録音は、聞いていて疲れます。Truncate Silence は、閾値を下回って一定の最小長さ以上続くすべての区間を見つけ、それを短縮します。これにより、言葉を切り落とすことなく、テンポが引き締まります。

:::note[Audacity から移行する場合]
これは Audacity の **Effect → Special → Truncate Silence** です。以下の名称は Soundscaper 独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaper を開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio** を選択し、長い間があるテイクを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all** を選択します。
4. **Effect → Special → Truncate Silence** を選択します。**Truncate Silence** ダイアログで、**Threshold** を `-40` に設定し、**Apply to selection** を押します。−40 dB より静かなものは無音として扱われます。最小無音長さより長い間隔は、短縮長まで切り詰められます。ここでは、両方ともデフォルトの 0.5 秒が維持されます。
5. **Play** を押して聞き、その後 **Stop** を押します。
   *確認すべき点:* 間隔が短くなり、すべてのフレーズが完全に保たれているはずです。

## ヒント

- フレーズの先頭の単語が切り取られる場合は、最小無音長さを上げたり、閾値を下げたりしてください。
- このエフェクトは選択範囲の長さを変更するため、他のものとテイクを揃える前に実行してください。
