交通騒音、エアコンの音、マイクへの風、デスクの振動はすべて音声の下、つまり小さなスピーカーでは再生すらできない周波数帯に存在しています。ハイパスフィルターはカットオフ周波数より上を通過させ、それ以下を減衰させることで、音声に影響を与えずに低域をクリーンアップします。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → ハイパスフィルター**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ラッブル（低域の唸り音）が含まれる録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → レガシーエフェクト → クラシックフィルター**を選択します。**クラシックフィルター**ダイアログで、**フィルタータイプ**に**ハイパス**を選択し、**カットオフ周波数**を`100`に設定してから、**選択範囲に適用**を押します。100 Hzは音声に対して安全な値です。より急峻な減衰特性にするには、オーダー（次数）を上げてください。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべき点:* 低域のラッブルが消え、音声は同じように聞こえるはずです。

## ヒント

- 音楽の場合、ベース楽器が薄くならないよう、40 Hzあたりから始めることをお勧めします。
- トラックのエフェクトラックにあるリアルタイム**ハイパスフィルター**は、レンダリングなしで再生中に同じ処理を行います。
