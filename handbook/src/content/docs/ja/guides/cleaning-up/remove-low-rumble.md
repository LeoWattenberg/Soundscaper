交通、エアコン、マイクにかかる風、デスクの振動など、声の下にあるノイズは、小型スピーカーでは再現できない周波数帯に存在します。ハイパスフィルターは、カットオフ周波数以上のすべてを通し、それ以下をロールオフさせ、低域をきれいにし、声には影響を与えません。

:::note[Audacityから来た場合？]
これはAudacityの**効果 → ハイパスフィルター**です。以下に示す名前は、Soundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ノイズの入った録音を選択します。それは独自のトラックにクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → レガシー効果 → クラシックフィルター**を選択します。**クラシックフィルター**ダイアログで、**フィルタータイプ**を**ハイパス**に設定し、**カットオフ周波数**を`100`に設定して、**選択範囲に適用**を押します。音声には100 Hzが安全です。より急なロールオフが必要な場合は、オーダーを上げます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 低域のノイズは削除され、声は同じに聞こえます。

## ヒント

- 音楽の場合は、ベース楽器が薄くならないように、40 Hz程度から始めます。
- リアルタイムの**ハイパスフィルター**は、再生中にトラックのエフェクトラックで同じ役割を果たし、レンダリングは必要ありません。
