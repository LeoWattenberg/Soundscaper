商用電源のハムノイズは1つの周波数に位置します。世界の大部分では50 Hz、南北アメリカでは60 Hzで、その2倍の周波数に高調波が現れることもあります。ノッチフィルターは1つの周波数の周りに狭い帯域をカットし、それ以外はそのまま残します。ハムノイズがローパスフィルタで除去できるほど低い周波数でない場合、ハイパスフィルタよりも穏やかな処理になります。周波数がわかれば、同じツールでモニターのホイッスル音や共鳴音も除去できます。

:::note[Audacityから移行する場合]
これはAudacityの**エフェクト → EQとフィルター → ノッチフィルター**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ハムノイズが入った録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → Nyquist → ノッチフィルター**を選択します。**ノッチフィルター**ダイアログで、**周波数 (Hz)** を `50` に設定し、**Q (値が高いほど幅が狭くなる)** を `4` に設定してから、**適用**を押します。商用電源が60 Hzの場合は60を使用します。Qが4の場合は狭いノッチになります。ハムノイズが変動する場合は下げ、カットが声に聞こえる場合は上げてください。
5. **再生**を押して聞き、その後**停止**を押します。
   *確認すべきこと:* ハムノイズが消え、声の音は同じように聞こえるはずです。

## ヒント

- 周波数が不明ですか？ 静かな部分の[スペクトルプロット](/guides/analysis/plot-a-spectrum/)を作成し、ピークを読み取ってください。
- ハムノイズには、周波数の2倍に高調波があることが多いです。残っている場合は、100 Hzまたは120 Hzでフィルターを再度実行してください。
