メインハムは、世界の大半では50Hz、アメリカでは60Hzの1つの周波数で座っています。これは、その2倍の調和を持つこともあります。ノッチフィルターは、1つの周波数帯を切り取り、それ以外はすべてそのまま残すことで、ハイパスフィルターよりもはるかに優しくハムを取り除きます。同じツールを使用して、モニターのホイッスルや共鳴を一度に削除できます。

:::note[Audacityから来た場合？]
これはAudacityの**効果 → EQとフィルター → ノッチフィルター**です。以下に示す名前は、Soundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、ハムを含む録音を選択します。これは、独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → EQとフィルター → ノッチフィルター**を選択します。**ノッチフィルター**ダイアログで、**ノッチ周波数**を`50`に、**Q**を`4`に設定し、**選択範囲に適用**を押します。あなたのメインハムが60Hzの場合は60を使用してください。Q値4は狭いノッチです。ハムが移動する場合、値を下げ、カットが声に聞こえる場合は値を上げてください。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* ハムは消え、声は同じに聞こえます。

## ヒント

- 周波数が不明な場合は、[静かなパスのスペクトルをプロット](/guides/analysis/plot-a-spectrum/)し、ピークを読み取ります。
- ハムには、多くの場合、2倍の周波数に調和があります。残っている場合は、100または120Hzでフィルターを再度実行します。
