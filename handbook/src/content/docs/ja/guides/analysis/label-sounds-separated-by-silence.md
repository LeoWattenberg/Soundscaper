## このガイドの目的 {#what-this-guide-is-for}

Label Soundsは無音で分かれた音を範囲内から探し、検出した音ごとにラベルを付けます。話し言葉のフレーズ、単発の打撃音など、後で編集する個別のイベントをマークできます。

:::note[Audacityから移行する場合]
Audacity では **Analyze → Label Sounds (Nyquist)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、音の間に間がある録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **分析 → Nyquist → Label Sounds** を選びます。**Label Sounds** ダイアログで **Threshold level (dB)** を `-30`、**Minimum silence duration** を `0.5`、**Minimum label interval** を `0.5` に設定して **適用** を押します。ダイアログに結果が表示されます。閉じるには **閉じる** を押します。0.5秒の無音があると、アナライザーはフレーズを分けられます。しきい値は音として判定するために必要な音量を設定します。
5. プロジェクトに **Label Sounds** という名前のトラックが表示されます。
   *確認できること：* Label Soundsトラックが表示され、検出されたフレーズの周囲にラベルが付きます。

## ヒント

- 小さい音を含めるには **Threshold level (dB)** を下げ、背景ノイズを無視するには上げます。
- 短い間で1つのフレーズが複数のラベルに分かれないようにするには **Minimum silence duration** を長くします。
