正規化やエクスポートを行う前に、現在の状態を知っておくと役立ちます。EBU R 128アナライザーは、ストリーミングプラットフォームや放送局が行うのと同じ方法でプログラムを測定します。つまり、統合ラウドネス（LUFS）、ラウドネスレンジ、トゥルーピークです。これにより、メーターから推測するのではなく、ターゲット値と比較できます。

:::note[Audacityから移行する場合]
これはAudacityの**分析 → RMS測定、またはラウドネス正規化の測定**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、測定したいミックスを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **分析 → EBU R 128**を選択します。**EBU R 128**パネルが開きます。
   *確認すべきこと:* 選択範囲の統合ラウドネス、ラウドネスレンジ、トゥルーピーク。

## ヒント

- ポッドキャストプラットフォームでは、通常、ステレオで−16 LUFS、モノラルで−19 LUFS、トゥルーピークが−1 dBTP未満であることを求められます。プラットフォーム独自のガイドラインを確認してください。
- 数値がターゲットから大きく乖離している場合は、[ラウドネス正規化](/guides/volume/normalize-loudness-for-podcasts/)を実行し、再度測定してください。
