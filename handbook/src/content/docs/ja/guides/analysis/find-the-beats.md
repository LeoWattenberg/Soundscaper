Beat Finderは、バンドルされているNyquistアナライザーの一つです。閾値を超えるレベルの急激な上昇を検出し、それぞれにラベルを書き込みます。これにより、ループのビートやドラムテイクのヒットを、カットする前に素早くマークできます。

:::note[Audacityから移行される方へ]
これはAudacityの**Analyze → Beat Finder**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、マークしたい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Analyze → Nyquist → Beat Finder**を選択します。**Beat Finder**ダイアログで、**Threshold Percentage**を`60`に設定し、**Apply**を押します。ダイアログは検出結果を報告します。**Close**を押して閉じます。パーセンテージを下げると、より静かなビートも検出されます。マークしすぎる場合は上げてください。
5. プロジェクトには、**Beat Finder**という名前のトラックが表示されます。
   *確認すべきこと:* オーディオの下に、各ビートに1つずつラベルが付いた、Beat Finderという名前の新しいラベルトラックが表示されるはずです。

## ヒント

- ラベルは、オーディオの下にある新しいラベルトラックに配置されます。アナライザーが誤って検出したものは、名前を変更するか削除してください。
- **Analyze → Nyquist → Label Sounds**は、無音で区切られた音全体に対して同様の処理を行います。
