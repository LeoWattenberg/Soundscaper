ビートファインダーは、バンドルされているNyquistアナライザーの1つです。突然レベルがしきい値を超えた上昇を検知し、それごとにラベルを書き込みます。これは、ループのビートを素早くマークしたり、ドラムテイクを切り取る前にヒットをマークする方法です。

:::note[Audacityから移行する場合]
これはAudacityの**分析 → ビートファインダー**です。以下の名前はSoundscaper独自のものであるため、Audacityと異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、マークしたい録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **分析 → Nyquist → ビートファインダー**を選択します。**ビートファインダー**ダイアログで、**しきい値パーセンテージ**を`60`に設定し、**適用**を押します。ダイアログは発見した内容を報告します。**閉じる**を押してダイアログを閉じます。パーセンテージが低いと静かなビートも検出されます。多すぎる場合は値を上げてください。
5. プロジェクトには**ビートファインダー**という名前のトラックが表示されます。
   *表示されるはずのもの:* オーディオの下に新しいラベルトラック**ビートファインダー**があり、各ビートに1つのラベルが付いています。

## ヒント

- ラベルはオーディオの下の新しいラベルトラックに配置されます。アナライザーが間違ったラベルはリネームまたは削除してください。
- **分析 → Nyquist → サウンドラベル**は、静寂で区切られた全体のサウンドに同様の作業を行います。
