波形は音の大きさが時間とともにどのように変化するかを示し、スペクトルはそれがどの周波数で構成されているかを示します。問題のあるパッセージのスペクトルをプロットすることは、50または60 Hzのハム音、モニターからのホイッスル音、または部屋が共鳴している周波数を見つける最も速い方法であり、その後イコライザーをどこに向けるべきかを知ることができます。

:::note[Audacityから移行する方へ]
これはAudacityの**Analyze → Plot Spectrum**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、問題のある録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Analyze → Plot spectrum**を選択します。**Plot spectrum**パネルが開きます。
   *確認すべきこと:* 選択範囲の周波数に対するレベルのグラフ。

## ヒント

- 問題のあるパッセージのみを選択します。例えば、ハム音の区間だけを単独で選択するなどすることで、周囲の音楽や話し声によってスペクトルが支配されないようにします。
- 高く狭いスパイクはトーン（単音）を、広い台地状の形状はノイズを示します。トーンは狭いEQカットに、ノイズは[Noise Reduction](/guides/cleaning-up/remove-background-noise/)に反応します。
