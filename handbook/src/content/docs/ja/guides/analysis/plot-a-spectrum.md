## このガイドの目的 {#what-this-guide-is-for}

波形は、時間の経過に伴う音の大きさを示し、スペクトラムはその音を構成する周波数を示します。問題のあるパッセージのスペクトラムをプロットするのは、50または60 Hzのハム音、モニターからのホイッスル音、または部屋の共鳴周波数を見つける最も迅速な方法であり、次にイコライザーをどこに調整するかを把握できます。

:::note[Audacityから移行する場合]
これはAudacityの**分析 → スペクトラムプロット**です。以下の名前はSoundscaper独自のものであるため、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、問題のある部分を含む録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **分析 → スペクトラムプロット**. 選択範囲のレポートを含む**スペクトラムプロット**ダイアログが開きます。
   *表示されるはずのもの:* 選択範囲のレベルと周波数のグラフ。

## ヒント

- 問題のある部分のみを選択してください（例えば、単独のハム音の部分）。これにより、周囲の音楽や音声にスペクトラムが支配されることを防ぎます。
- 高くて狭いスパイクは音調を示し、広い高原はノイズを示します。音調は狭いEQカットに反応し、ノイズは[ノイズリダクション](/guides/cleaning-up/remove-background-noise/)に反応します。
