## このガイドの目的 {#what-this-guide-is-for}

RMSは時間経過に伴う信号レベルの平均値です。Measure RMSアナライザーでセクションを比較したり、調整前に範囲の強さを確認したりできます。

:::note[Audacityから移行する場合]
Audacity では **Analyze → Measure RMS (Nyquist)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、平均レベルを測定したい範囲を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. **選択 → すべてを選択** を選びます。
4. **分析 → Nyquist → Measure RMS** を選びます。**Measure RMS** ダイアログで **適用** を押します。ダイアログに結果が表示されます。閉じるには **閉じる** を押します。
   *確認できること：* レポートに各チャンネルとステレオ信号のRMSレベルがdBで表示されます。

## ヒント

- RMSは平均レベルを表します。最も高いサンプルを目標値にする場合は[ピークノーマライズ](/guides/volume/normalize-peaks/)を使います。
- 比較する部分だけを選ぶと、関係のないオーディオが測定結果に影響しません。
