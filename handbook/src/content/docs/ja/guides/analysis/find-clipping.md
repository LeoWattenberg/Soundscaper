録音が熱すぎると、レンジの上限に押しつぶされて歪みます。この損傷は耳で気づきやすいですが、長いテイクの中で目視で発見するのは困難です。Find Clipping は選択範囲をスキャンし、フルスケールで固定されているサンプルの連続をすべてリスト表示するため、各箇所を修復するか、やり直すか、そのままにするか判断できます。

:::note[Audacityから移行する場合]
これはAudacityの**Analyze → Find Clipping**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio** を選択し、チェックしたい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all** を選択します。
4. **Analyze → Find clipping** を選択します。**Find clipping** パネルが開きます。
   *確認すべきこと:* クリップされた連続のリスト、または見つからなかった旨の通知。

## ヒント

- クリップされた録音を小さくしても修復はできません。平坦になったピークは平坦なままです。**Effect → Noise removal and repair → Repair** を使用すると、非常に短いクリップされた連続を再構築できます。
- 次回クリッピングを避けるには、ピークが約 −12 dB になるように録音し、後でレベルを上げてください。
