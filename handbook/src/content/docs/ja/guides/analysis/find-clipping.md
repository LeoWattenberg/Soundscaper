## このガイドの目的 {#what-this-guide-is-for}

録音が過大に設定されると、音は範囲の上限に押しつぶされ、歪みが発生します。この損傷は耳で簡単にわかりますが、長いテイクでは目視で見つけるのは難しいです。Find Clippingは選択範囲をスキャンし、フルスケールで再生されているサンプルのすべての区間をリストアップします。これにより、それぞれを修復するか、やり直すか、そのままにするかを判断できます。

:::note[Audacityから移行する場合]
これはAudacityの**Analyze → Find Clipping**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import**を選択し、確認したい録音を選択します。これは独自のクリップとしてトラックに配置されます。
3. **Select → Select all**を選択します。
4. **Analyze → Find clipping**. 選択範囲のレポートを含む**Find clipping**ダイアログが開きます。
   *表示されるべきもの:* クリップされた区間のリスト、またはクリップされた区間が見つからなかったというメモ。

## 注意点

- クリップされた録音の音量を下げるだけでは修復されません。フラットになったピークはフラットのままです。**Effect → Noise removal and repair → Repair**を使用すると、非常に短いクリップ区間を再構築できます。
- 次回クリッピングを避けるには、ピークが約-12 dBの状態で録音し、その後音量を上げます。
