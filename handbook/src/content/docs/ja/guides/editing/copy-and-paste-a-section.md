良いコーラスをコピーして弱いコーラスを置き換えたり、小節を繰り返したり、文を末尾に移動したりする操作は、テキストでのコピー＆ペーストと同様にオーディオでも機能します。パッセージを選択し、コピーし、カーソルを配置したい場所に移動させて、ペーストします。

:::note[Audacityから移行される方へ]
これはAudacityの**編集 → コピー、次に編集 → ペースト (Ctrl+C, Ctrl+V)** に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート** を選択し、コピーしたいパッセージを含む録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップ上部のルーラーをドラッグして、コピーするパッセージを選択します。
4. **編集 → コピー** を選択します。
5. コピーを配置したい箇所の波形をクリックして、カーソルをそこに配置します。ペーストはカーソル位置に行われます。クリップの末尾が一般的な配置場所です。
6. **編集 → ペースト → ペースト** を選択します。
7. プロジェクトには2つのクリップが表示されます。
   *確認事項:* コピーされたパッセージは、元のクリップの後に新しいクリップとして表示されます。

## ヒント

- **編集 → ペースト → 挿入** を使用すると、後続のオーディオを押し出す形で挿入され、上書きされません。
- クリップボードはプロジェクトタブ間で機能するため、あるプロジェクトから別のプロジェクトへパッセージをコピーできます。
