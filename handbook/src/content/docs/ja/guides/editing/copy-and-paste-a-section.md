弱いコーラスを良いコーラスに置き換えるために良いコーラスをコピーしたり、バーを繰り返したり、文を最後に持っていくなど、オーディオに対するコピー＆ペーストはテキストに対して行うものと同じように機能します。パスを選択し、コピーし、カーソルを配置すべき場所に置き、ペーストします。

:::note[Audacityから来た場合]
これはAudacityの**編集 → コピー**、そして**編集 → ペースト（Ctrl+C、Ctrl+V）**です。以下に示す名前はSoundscaper独自のもので、時折異なります。
:::

## 手順

1. Soundscaperを開きます。エディタがロードされるとすぐに、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、コピーしたいパスを含む録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. クリップの上にあるスケールをドラッグして、コピーしたいパスを選択します。
4. **編集 → コピー**を選択します。
5. コピーを配置すべき場所にカーソルを置くために、波形をクリックします。ペーストはカーソルに配置されます。通常、クリップの最後が適切な場所です。
6. **編集 → ペースト → ペースト**を選択します。
7. プロジェクトには2つのクリップが表示されます。
   *確認できること:* コピーされたパスは元のクリップの後に新しいクリップとして表示されます。

## 注意

- **編集 → ペースト → 挿入**は、ペーストを後ろのオーディオの上に配置する代わりに、後ろのオーディオを押しやります。
- クリップボードはプロジェクトタブ間で動作するので、一つのプロジェクトから別のプロジェクトにパスをコピーすることが可能です。
