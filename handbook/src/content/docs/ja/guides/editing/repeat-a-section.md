2小節のループ、長いボイスオーバーの下に実行する必要があるバックグラウンドベッド、継続すべきサウンドエフェクト: Repeatは、選択した内容を指定した回数だけそのまま後ろにコピーします。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → 特殊 → 繰り返し**です。以下の名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、繰り返したいサウンドを選択します。それは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 特殊 → 繰り返し**を選択します。**繰り返し**ダイアログで**繰り返し回数**を`2`に設定し、**選択範囲に適用**を押します。2回繰り返すと、3つのコピーが連続して配置されます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはず:* パスが3回ギャップなしで再生されます。

## 注意点

- シームレスなループのために、選択範囲の開始と終了が静音またはゼロクロッシング（**選択 → ゼロクロッシングで選択**）になるようにしてください。
- この効果はクリップの長さを変更するため、同じトラック上のその後にあるものは押し出されます。
