2小節のループ、長いナレーションの下で再生する必要があるバックグラウンドベッド、オンにするべき効果音：Repeatは、要求した回数だけ選択範囲をそのままその後にコピーします。

:::note[Audacityから移行する場合]
これはAudacityの**Effect → Special → Repeat**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、繰り返し処理したいサウンドを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **Select → Select all**を選択します。
4. **Effect → Special → Repeat**を選択します。**Repeat**ダイアログで、**Number of repeats**を`2`に設定し、**Apply to selection**を押します。2回の繰り返しで、3つのコピーが連続して生成されます。
5. **Play**を押して聴き、その後**Stop**を押します。
   *確認事項:* 区切りなく3回再生されます。

## ヒント

- シームレスなループにするには、選択範囲の開始と終了が沈黙またはゼロクロス点にあることを確認してください（**Select → At zero crossings**）。
- このエフェクトはクリップの長さを変更するため、同じトラック上の後続の部分は後ろに押し出されます。
