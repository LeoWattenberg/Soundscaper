最も一般的な編集は、誤った開始、咳、リテイクです。不要な部分を選択し、削除して、トラックの残りの部分が左にスライドして隙間を閉じるようにします。

:::note[Audacityから移行する場合]
これはAudacityの**領域を選択し、編集 → 削除（またはCtrl+K）**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、ミスが含まれている録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップの上にあるルーラーをドラッグして、削除したい部分を正確に選択します。ミスが短い場合は、**表示 → ズーム → ズームイン**で拡大します。
4. **編集 → 切り取り → トラックごとに切り取り、隙間を閉じる**を選択します。選択部分が削除され、その後のすべてが左に移動するため、無音は残されません。
5. プロジェクトには現在2つのクリップが表示されます。
   *確認事項:* 選択部分が2つのクリップが端から端まで接している状態になり、トラックはちょうどその分短くなっているはずです。接合部を再生して確認してください。

## ヒント

- **切り取り、隙間を残す**は音声を削除しますが時間を保持します。トラックが動画や他のトラックと同期を維持する必要がある場合に適切です。
- 接合部に満足できない場合は、**編集 → 元に戻す**で選択範囲を調整して再試行してください。
