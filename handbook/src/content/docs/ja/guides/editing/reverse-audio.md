## このガイドの目的 {#what-this-guide-is-for}

逆方向反転は、時間の選択を逆方向に反転させます。これは、サウンドデザイン用のエフェクト（逆方向のシンバル、膨らむプリエコーなど）であり、時折、部屋のリバーブテールが何かを隠しているかどうかを確認するためにも使用されます。

:::note[Audacityから移行する場合]
これはAudacityの**効果 → 特殊 → 逆方向反転**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、逆方向反転する録音を選択します。これは独自のトラック上のクリップとして配置されます。
3. **選択 → すべてを選択**を選択します。
4. **効果 → 特殊 → 逆方向反転**を選択します。この効果は選択範囲にすぐに適用されます。
5. **再生**を押して聴き、**停止**を押します。
   *表示されるはずのもの:* 録音が逆方向に再生されます。

## ヒント

- 逆方向反転を2回適用すると、サンプルごとに元の位置に戻ります。
- クリップの先頭にある短い選択範囲を逆方向反転して、それに続くスウェルを構築します。
