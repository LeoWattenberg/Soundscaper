Reverse（リバーブ）は、選択範囲を時間軸上で反転します。これはサウンドデザイン用のエフェクトであり、逆再生されたシンバルや、膨らみを持つプリエコーなどに使用されます。また、ルームリバーブのテールが何かを隠していないかを確認するためにも、時折使用されます。

:::note[Audacityから移行される方へ]
これはAudacityの**エフェクト → 特殊 → 逆再生**に相当します。以下に記載されている名称はSoundscaper独自のものです。場合によっては名称が異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、反転する録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **選択 → すべて選択**を選択します。
4. **エフェクト → 特殊 → 逆再生**を選択します。エフェクトは選択範囲に即座に適用されます。
5. **再生**を押して聴き、その後**停止**を押します。
   *確認すべきこと:* 録音が逆再生されます。

## ヒント

- Reverseを2回適用すると、サンプル単位で完全に元の状態に戻ります。
- クリップの先頭の短い選択範囲にReverseを適用すると、そのクリップへ繋がるスウェル（膨らみ）を作成できます。
