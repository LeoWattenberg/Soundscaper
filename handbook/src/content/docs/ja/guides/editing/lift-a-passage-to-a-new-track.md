## このガイドの目的 {#what-this-guide-is-for}

フレーズやテイクだけ別の音量、パン、エフェクトにしたい場合も、録音の残りをそのまま保てます。Split into new trackは選択範囲の端で分割し、その範囲だけを同じ時間位置の新しいトラックに移します。

:::note[Audacityから移行する場合]
Audacity では **Edit → Clip → Split New** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、別のトラックに移したい範囲を含む録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. クリップ上部のルーラーをドラッグして、別のトラックに移す範囲を選択します。
4. **編集 → オーディオクリップ → 新規トラックに分割** を選びます。選択範囲は新しいトラックに移り、その前後のオーディオは元のトラックに残ります。
5. プロジェクトには3つのクリップが表示されます。
   *確認できること：* 元のトラックには選択範囲の前後に1つずつクリップが残り、新しいトラックにはその間の範囲が表示されます。

## ヒント

- 選択範囲は新しいトラックでも元の時間位置を保ちます。
- この録音だけを移動したい場合は、ほかの素材が入っていないトラックを使います。
