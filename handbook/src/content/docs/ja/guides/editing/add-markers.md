マーカーはタイムライン上のメモです。章の開始位置、修正が必要なミス、良いテイクの開始位置などを示します。マーカーはオーディオを変更せず、プロジェクトとともに移動し、他のツールで使えるラベルファイルとしてエクスポートできます。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → ラベル → 選択範囲にラベルを追加 (Ctrl+B)** に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート** を選択し、マークアップしたい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **表示 → マーカーの表示** を選択します。これにより、トラックの上にマーカーレーンが追加されます。マーカーはレーンなしでも存在しますが、レーンはそれらを表示・編集するための場所です。
4. マーカーを配置したい波形の場所をクリックして、カーソルをそこに移動します。マーカーはカーソルがある位置に配置されます。
5. マーカーパネルを開いた状態で（**表示 → パネル → マーカー** で表示されます）、**再生ヘッド位置にマーカーを追加** を押します。新しいマーカーでEnterキーを押し、`Chorus` を入力して、もう一度Enterキーを押して名前を付けます。
   *確認事項:* 入力した名前とともに、トラックの上のレーンとパネルのリストにマーカーが表示されるはずです。

## ヒント

- 時間範囲が選択されている場合、同じボタンで単一のポイントではなく、名前付きの領域が追加されます。
- **ファイル → その他をエクスポート → ラベルのエクスポート** を使用すると、Audacityや他のエディタが読み取れるテキストファイルとしてマーカーを書き出せます。
