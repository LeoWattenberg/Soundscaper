リフの練習、編集ポイントの確認、エフェクト設定の試聴：すべてが、ユーザーが再開せずにパスが繰り返し再生されることで速くなります。ループ領域を選択範囲に設定すると、ループをオフにするまで再生は選択範囲内に留まります。

:::note[Audacityから移行する場合]
これはAudacityの**Transport → Looping → Set Loop to Selection**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、練習したいパスを含む録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップの上にあるルーラーをドラッグして、繰り返し再生したいパスを選択します。
4. **Select → Loop region → Set loop to selection**を選択します。
5. プロジェクトに**Loop selection**ボタンが点灯していることが表示されます。
   *確認事項:* 輸送バーのループボタンが点灯し、ルーラーの上にループ領域が表示されます。
6. **Play**を押して聴き、次に**Stop**を押します。
   *確認事項:* 再生が選択されたパスを周回します。

## ヒント

- **L**キーまたは輸送バーのループボタンを押すことで、領域を失うことなくループをオン/オフに切り替えられます。
- ルーラー上のループ領域の端をドラッグして調整します。
