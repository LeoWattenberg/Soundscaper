リフを学んだり、編集ポイントを確認したり、エフェクト設定を試したりする際、毎回手動で再生をスタートさせることなく、ループで再生できると作業がはかどります。ループ領域を選択範囲に設定すると、ループをオフにするまで再生は選択範囲内で繰り返されます。

:::note[Audacityから移行する場合]
これはAudacityの**再生 → ループ → 選択範囲をループに設定**に相当します。以下に示す名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、練習したいパスの録音を選択します。録音は単独のクリップとしてトラックに配置されます。
3. クリップ上のルーラーをドラッグして、繰り返したいパスを選択します。
4. **選択 → ループ領域 → 選択範囲をループに設定**を選択します。
5. プロジェクトに**ループ選択**ボタンが点灯します。
   *確認できること:* 輸送バーにループボタンが点灯し、ルーラー上にループ領域が表示されます。
6. **再生**を押して聴き、**停止**を押します。
   *確認できること:* 再生は選択されたパスをループします。

## 注意点

- **L**キーを押すか、輸送バーのループボタンをクリックして、ループをオン/オフに切り替えることができます。ループ領域は保持されます。
- ルーラーのループ領域の端をドラッグして調整できます。
