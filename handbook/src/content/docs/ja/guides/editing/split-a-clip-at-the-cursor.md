分割は、何も削除しません。1つのクリップを2つに切り分けて、それらを端と端で接続した状態にします。これにより、片方を別の場所へドラッグしたり、削除したり、1つだけにエフェクトを適用したりできます。最も簡単な方法は分割ツールです。このツールが有効な間、クリップをクリックするたびに、その位置で切り分けられます。

:::note[Audacityから移行される方へ]
これはAudacityの**編集 → クリップ境界 → 分割 (Ctrl+I)**に相当します。以下に記載されている名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、分割したい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. ツールバーの**分割ツール**ボタンを押します。ポインターは選択ではなく、切り分けを行うようになります。キーボードからツールを切り替えるには**S**キーを押します。
4. 切り分けたい位置の波形をクリックして、カーソルをそこに配置します。分割ツールが有効な場合、クリックするとその位置でクリップが切り分けられます。
5. プロジェクトには2つのクリップが表示されます。
   *確認事項:* 1つだった場所に2つのクリップが配置されているはずです。
6. ツールバーの**分割ツール**ボタンを押します。もう一度押すと、通常のポインターに戻ります。

## ヒント

- プレイヘッド位置で分割するには、クリップを選択し、**編集 → オーディオクリップ → 分割**を選択します。時間範囲が選択されている場合、範囲の両端で分割されます。
- 両方の半分を選択し、**編集 → オーディオクリップ → 選択したクリップを結合**を選択すると、再び1つのクリップになります。
