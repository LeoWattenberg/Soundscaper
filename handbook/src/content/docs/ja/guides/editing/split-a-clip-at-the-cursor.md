## このガイドの目的 {#what-this-guide-is-for}

分割は何も削除しません。1つのクリップを2つに分割し、端から端まで並べるので、クリップの1部分を別の場所にドラッグしたり、削除したり、単独でエフェクトを適用したりできます。最も簡単な方法は分割ツールです。アクティブな状態でクリップをクリックするたびに、その地点で切ります。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → クリップ境界 → 分割（Ctrl+I）**です。以下の名前はSoundscaper独自のもので、場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、分割したい録音を選択します。これは独自のトラック上のクリップとして配置されます。
3. ツールバーにある**分割ツール**ボタンをクリックします。ポインターは選択ではなく切り取りを行います。キーボードから**S**を押してツールを切り替えることもできます。
4. 波形をクリックして切り取りたい場所にカーソルを配置します。分割ツールがアクティブな状態でクリックすると、クリップがその地点で切り取られます。
5. プロジェクトには2つのクリップが表示されます。
   *表示されるはずのもの:* 1つのクリップが2つのクリップに分割されて表示されます。
6. ツールバーにある**分割ツール**ボタンをクリックします。もう一度クリックすると、通常のポインターに戻ります。

## ヒント

- プレイヘッドで分割するには、クリップを選択し、**編集 → オーディオクリップ → 分割**を選択します。時間範囲を選択すると、範囲の両端で分割されます。
- 両方の半分を選択し、**編集 → オーディオクリップ → 選択したクリップを結合**を選択して、再び1つのクリップにします。
