Duplicate（複製）は、選択範囲を同じ時間位置で、その直下の新しいトラックにコピーします。これは並列処理の一般的な最初のステップです。例えば、元の音源の下にミックスする強く圧縮されたコピー、リバーブ専用のトラック、ダブルボーカルなどです。

:::note[Audacityから移行する方へ]
これはAudacityの**編集 → 複製 (Ctrl+D)**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了です。
2. **ファイル → オーディオのインポート**を選択し、複製したい部分を含む録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップの上にあるルーラーをドラッグして、複製したい部分を選択します。
4. **編集 → 複製**を選択します。
5. プロジェクトには2つのクリップが表示されます。
   *確認事項:* 選択範囲のみを含む2番目のクリップが、最初のクリップの下にある新しいトラック上に、時間軸に沿って整列して表示されるはずです。

## ヒント

- 2つのトラックのうちの1つをミュートにすると、もう1つを単独で聴きながら調整できます。
- ブレンドに満足したら、[トラックをミックスダウン](/guides/tracks-and-export/mix-tracks-into-one/)します。
