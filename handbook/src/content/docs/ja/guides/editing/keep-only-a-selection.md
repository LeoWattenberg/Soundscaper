長い録音に良いテイクが1つある場合、選択して残りを破棄する方が、周囲を部分的に削除するよりも速いです。トリムは選択を保持し、その両側のオーディオを削除します。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → 特殊削除 → オーディオのトリム**です。以下の名前はSoundscaper独自のもので、時折異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、テイクを含む録音を選択します。それは独自のトラック上のクリップとして配置されます。
3. クリップの上にあるルールをドラッグして、保持したいパスを選択します。それ以外のすべてが削除されます。
4. **編集 → 特殊削除 → 選択外のオーディオのトリム**を選択します。
5. プロジェクトには1つのクリップが表示されます。
   *表示されるはずのもの:* 選択されたパスのみがトラック上に残ります。

## ヒント

- トリムされたクリップはタイムライン上の元の位置に残ります。先頭から始めたい場合は、それを先頭までドラッグします。
- トリムは他の編集と同じです；**編集 → 元に戻す**は選択外のオーディオを復元します。
