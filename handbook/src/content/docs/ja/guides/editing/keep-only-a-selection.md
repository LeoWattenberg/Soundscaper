長い録音の中に1つの良いテイクが含まれている場合、周囲を少しずつ削除するよりも、そのテイクを選択して残りを破棄する方が迅速です。トリムは選択範囲を保持し、その両側のオーディオを削除します。

:::note[Audacityから移行する場合]
これはAudacityの**編集 → 特殊な削除 → オーディオのトリム**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、テイクを含む録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップの上にあるルーラーをドラッグして、保持したい箇所を選択します。選択範囲外のすべてが削除される予定です。
4. **編集 → 特殊な削除 → 選択範囲外のオーディオをトリム**を選択します。
5. プロジェクトには1つのクリップが表示されます。
   *確認事項:* トラック上には選択された箇所のみが残っているはずです。

## ヒント

- トリムされたクリップは、タイムライン上の元の位置に留まります。ゼロから開始させたい場合は、先頭にドラッグしてください。
- トリムは他の編集と同様です。**編集 → 元に戻す**で、選択範囲外だった部分を復元できます。
