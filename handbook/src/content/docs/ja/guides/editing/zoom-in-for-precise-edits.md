## このガイドの目的 {#what-this-guide-is-for}

デフォルトのズームでは、1曲の全体が画面に収まり、単語1つが数ピクセルの幅になります。ズームインすることで、カーソルを正確にビートや2つの単語の間の隙間に配置することができます。ズームインして選択範囲をフレームに収めることで、作業中のパスだけを表示することができます。

:::note[Audacityから移行する場合]
これはAudacityの**表示 → ズーム（Ctrl+1、Ctrl+2、Ctrl+3）**です。以下の名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、編集したい録音を選択します。録音は独自のトラックにクリップとして配置されます。
3. **表示 → ズーム → ズームイン**を選択します。各ステップで1秒あたりの幅が2倍になります。Ctrl+1でも同じ操作ができます。
4. **表示 → ズーム → ズームイン**を選択します。
5. クリップの上にあるルーラーをドラッグして、作業したいパスを選択します。
6. **表示 → ズーム → 選択範囲にズーム**を選択します。選択範囲がタイムライン全体に収まります。
7. **表示 → ズーム → 通常ズーム**を選択します。Ctrl+2でデフォルトのズームに戻ります。

## ヒント

- Ctrlキーとマウスホイールで、ポインタの周りを素早くズームできます。
- 垂直ルーラーの上では、Ctrlキーとマウスホイールで波形振幅またはスペクトログラム周波数範囲をズームできます。右クリックしても同じズームコントロールが表示されます。
- ズームはプロジェクト自体に影響を与えず、表示方法のみを変更します。
