デフォルトのズームでは、1曲全体が画面に収まり、1語は数ピクセルの幅しかありません。ズームインすると、カーソルをビート上や2つの単語の間の隙間に正確に配置できます。選択範囲にズームすると、作業中のパッセージだけがフレームに収まります。

:::note[Audacityから移行する場合]
これはAudacityの**表示 → ズーム (Ctrl+1, Ctrl+2, Ctrl+3)**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備完了です。
2. **ファイル → オーディオのインポート**を選択し、詳細に編集したい録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. **表示 → ズーム → ズームイン**を選択します。各ステップで1秒の幅が2倍になります。Ctrl+1でも同じ動作を行います。
4. **表示 → ズーム → ズームイン**を選択します。
5. クリップ上部のルーラーをドラッグして、作業したいパッセージを選択します。
6. **表示 → ズーム → 選択範囲にズーム**を選択します。選択範囲がタイムラインを埋め尽くします。
7. **表示 → ズーム → 通常ズーム**を選択します。Ctrl+2でデフォルトのズームに戻ります。

## ヒント

- Ctrlキーとマウスホイールで、ポインタを中心にズームできます。これは1つの場所に深く掘り下げるための最速の方法です。
- ズームはプロジェクトの内容を変更しません。表示のみが変わります。
