## このガイドの目的 {#what-this-guide-is-for}

Align together は選択したトラックを、内容の開始時刻の平均にあたる共通の開始位置へ移動します。各トラックの内容をひとまとまりとして移動するため、そのトラック内のクリップ間隔は保たれます。録音だけをそろえたい場合は、1 つのトラックに録音を 1 つずつ置いて使います。

:::note[Audacityから移行しましたか？]
これは Audacity の **Tracks → Align content → Align together** に相当します。以下の名前は Soundscaper での名称で、異なる場合があります。
:::

## 手順

1. Soundscaper を開きます。エディターが読み込まれると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート** を選び、最初の録音を選びます。録音は専用のトラックにクリップとして追加されます。
3. **ファイル → ファイルをインポート** を選び、2 つ目の録音を選びます。録音は専用のトラックにクリップとして追加されます。
4. クリップの名前バーをドラッグして後ろへ移動し、2 つの録音の開始時刻をずらします。
5. **Tab** で最初の録音にフォーカスし、**Enter** を押して選択します。次に 2 つ目の録音にフォーカスし、**Shift+Enter** を押して選択に追加します。選択したクリップを含むトラックが位置合わせの対象になります。
6. **トラック → コンテンツを整列 → 一緒に合わせる** を選びます。
7. 最初の録音が共通の時刻から始まります。
8. 2 つ目の録音も同じ時刻から始まります。
   *表示される内容:* 左端がそろい、どちらの録音も元の長さを保ちます。

## ヒント

- 共通の開始時刻が必ずしも 0 とは限りません。プロジェクトの先頭から始めるには、[録音を 0 にそろえる](/guides/editing/align-a-recording-to-zero/)方法を使います。
- **編集 → 取り消す** を使うと、各トラックを元の位置に戻せます。
