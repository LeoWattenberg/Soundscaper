エコーやリバーブなどの効果には、音が鳴り響くための空間が必要です。また、ポッドキャストではセグメント間に息継ぎが必要です。Silenceジェネレーターは、カーソル位置に、入力した長さに正確に一致する間隔を挿入します。これは、目測でクリップを離すよりも正確です。

:::note[Audacityから移行する場合]
これはAudacityの**Generate → Silence**です。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **File → Import audio**を選択し、その後ろに間隔が必要な録音ファイルを選択します。ファイルは独自のトラック上にクリップとして配置されます。
3. クリップの末尾の波形をクリックして、カーソルをそこに配置します。無音はカーソル位置に挿入されます。
4. **Generate → Silence**を選択します。**Silence**ダイアログで、**Duration (seconds)**を`1`に設定し、**Generate**を押します。
5. プロジェクトには現在2つのクリップが表示されます。
   *確認事項:* ループの後に1秒間の無音クリップが続いているはずです。

## ヒント

- 時間範囲が選択されている場合、ジェネレーターはカーソル位置に挿入するのではなく、選択範囲を置き換えます。
- 時間を追加するのではなく、既存のオーディオを無音にする場合は、[録音の一部を無音にする](/guides/cleaning-up/silence-part-of-a-recording/)を参照してください。
