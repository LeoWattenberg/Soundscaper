エコーやリバーブなどの効果には、余韻が残るためのスペースが必要であり、ポッドキャストではセグメント間の息継ぎが必要です。サイレンスジェネレーターは、カーソルの位置に正確に指定した長さのギャップを挿入します。これは、クリップを手動でドラッグして離すよりも正確です。

:::note[Audacityから移行する場合]
これはAudacityの**生成 → サイレンス**です。以下の名前はSoundscaper独自のものであるため、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、その後にギャップが必要な録音を選択します。録音は単独のトラック上にクリップとして配置されます。
3. クリップの終端の波形をクリックして、カーソルをそこに置きます。サイレンスはカーソルの位置に挿入されます。
4. **生成 → サイレンス**を選択します。**サイレンス**ダイアログで**期間（秒）**を`1`に設定し、**生成**を押します。
5. プロジェクトには2つのクリップが表示されます。
   *表示されるはずのもの:* 1秒の無音クリップがループの後に続きます。

## ヒント

- 時間範囲を選択している場合、ジェネレーターはカーソルでの挿入ではなく、選択範囲を置き換えます。
- すでにあるオーディオを沈黙させるのではなく、時間を追加する場合は、[録音の一部を沈黙させる](/guides/cleaning-up/silence-part-of-a-recording/)を参照してください。
