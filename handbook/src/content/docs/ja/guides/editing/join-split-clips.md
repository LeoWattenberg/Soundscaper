## このガイドの目的 {#what-this-guide-is-for}

Joinは同じ録音の隣接する部分を結合するため、再び1つのクリップとして移動や編集ができます。元の領域が一致し、結合箇所にフェードがないことが必要です。この手順では、録音を分割する前に自動フェードをオフにし、その後レンダリングせずに各部分を結合します。

:::note[Audacityから移行しましたか？]
Audacityの **Edit → Clip → Join selected clips (Ctrl+J)** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが完了すると、新しい空のプロジェクトが用意されています。
2. **編集 → 設定**を選択し、**編集**タブを開いて、**新しいクリップに 2 ms のフェードを適用**をオフにし、**閉じる**を押します。分割位置の自動フェードによってJoinが使えなくなるためです。
3. **ファイル → ファイルをインポート**を選択し、分割してから再結合する録音を選びます。録音は専用トラック上のクリップとして追加されます。
4. 分割したい位置の波形をクリックして、そこにカーソルを置きます。
5. **編集 → オーディオクリップ → 分割**を選択します。
6. プロジェクトに2つのクリップが表示されます。
   *次のように表示されます：* 2つの部分が分割位置で接しています。
7. **Tab**で最初の部分にフォーカスし、**Enter**を押して選択します。次に2つ目の部分にフォーカスし、**Shift+Enter**を押して選択に追加します。結合するには両方を選択する必要があります。
8. **編集 → オーディオクリップ → 選択したクリップを結合**を選択します。
9. プロジェクトに1つのクリップが表示されます。
   *次のように表示されます：* 分割前の録音と同じ時間を1つのクリップが占めています。

## ヒント

- この設定は今後の分割に適用されます。普段この設定を使う場合は、作業後に**新しいクリップに 2 ms のフェードを適用**をオンに戻してください。
- 既存の部分でJoinが使えない場合は、間隔や内部フェード、異なる元素材がないか確認してください。この設定をオフにしても、クリップにすでに付いているフェードは削除されません。
- **編集 → 取り消す**を使うと部分が分離した状態に戻り、それぞれを個別に編集できます。
