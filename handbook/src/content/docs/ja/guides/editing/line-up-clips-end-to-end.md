別々に録音された2つのテイクは、それぞれ独自のトラックに配置され、両方ともゼロから始まります。一方をもう一方の後に再生するには、2つ目を1つ目の終了位置に移動する必要があります。トラック順に選択されたすべてのクリップに対して、この計算を行うのが「端を揃える（Align end to end）」です。

:::note[Audacityから移行する場合]
これはAudacityの**トラック → トラックの整列 → 端を揃える**に相当します。以下の名称はSoundscaper独自のものです。場合によっては異なります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → オーディオのインポート**を選択し、最初のテイクを選択します。ファイルは独自のトラック上のクリップとして配置されます。
3. **ファイル → オーディオのインポート**を選択し、2番目のテイクを選択します。ファイルは独自のトラック上のクリップとして配置されます。
4. 最初のクリップの名前バーをクリックし、Shiftキーを押しながら2番目のクリップの名前バーをクリックして、両方を選択します。
5. **トラック → コンテンツの整列 → 端を揃える**を選択します。
6. 2番目のクリップは、1番目のクリップが終了する位置から始まります。
   *確認事項:* クリップは重複も隙間もなく、連続して再生されるはずです。

## ヒント

- **一緒に揃える**は逆の動作を行います：選択されたクリップを同じ時刻に開始するように移動します。
- クリップの名前バーをドラッグして手動で配置します。Shiftキーを押すと、同じトラック上に保たれます。
