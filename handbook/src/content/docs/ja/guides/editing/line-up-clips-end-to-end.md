別々に録音された2つのテイクは、それぞれ独自のトラックに配置され、どちらもゼロから始まります。1つを続けて再生するには、2つ目のテイクを1つ目の終了位置に移動する必要があります。**エンドを揃える**は、選択されたすべてのクリップについて、トラック順にこの計算を実行します。

:::note[Audacityから移行する場合]
これはAudacityの**トラック → トラックを揃える → エンドを揃える**です。以下の名前はSoundscaper独自のもので、Audacityのものとは異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディタが読み込まれた時点で、新しい空のプロジェクトが準備されます。
2. **ファイル → インポート**を選択し、最初のテイクを選択します。それは独自のトラック上のクリップとして配置されます。
3. **ファイル → インポート**を選択し、2つ目のテイクを選択します。それも独自のトラック上のクリップとして配置されます。
4. 1つ目のクリップの名前バーをクリックし、シフトキーを押しながら2つ目のクリップの名前バーをクリックして、両方を選択します。
5. **トラック → 内容を揃える → エンドを揃える**を選択します。
6. 2つ目のクリップは、1つ目のクリップの終了位置から始まります。
   *確認できること:* クリップは重なることなく、ギャップもなく順番に再生されます。

## 注意点

- **一緒に揃える**は逆の操作を行います。選択されたクリップを同じタイミングで開始するように移動します。
- クリップの名前バーをドラッグして手動で配置することもできます。シフトキーを押すと、そのトラック上のすべてのクリップを一緒に移動できます。
