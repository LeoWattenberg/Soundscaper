## このガイドの目的 {#what-this-guide-is-for}

タイムライン上で遅れて始まる録音は、整列コマンドでプロジェクトの開始位置に戻せます。Align start to zeroは選択したトラックの内容を移動し、最も早いクリップの開始位置をゼロにします。この手順では録音をいったん後ろへ移動し、開始位置に戻して整列します。

:::note[Audacityから移行しましたか？]
Audacityの **トラック → コンテンツを整列 → 始まりをゼロに揃える** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターの読み込みが完了すると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート**を選択し、位置を合わせる録音を選びます。録音は専用トラック上のクリップとして追加されます。
3. クリップの名前バーをドラッグして、タイムライン上の後ろの位置へ移動します。
4. クリップがプロジェクトの開始位置より後ろから始まる状態になります。
5. **トラック → コンテンツを整列 → 始まりをゼロに揃える**を選択します。
6. 録音が時間ゼロから始まります。
   *次のように表示されます：* クリップの左端がルーラーの開始位置と揃います。

## ヒント

- 整列コマンドは選択したトラックの内容を移動します。この録音だけを移動する場合は、その録音だけが含まれるトラックを使ってください。
- **編集 → 取り消す**で前の位置に戻ります。
