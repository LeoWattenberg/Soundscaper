## このガイドの目的 {#what-this-guide-is-for}

グループ化したクリップは別々のオーディオのまま、ひとまとまりとして選択して移動できます。Ungroupはクリップを個別に選択できる状態に戻します。クリップ同士を結合したり、1つのクリップにしたりはしません。

:::note[Audacityから移行する場合]
Audacity では **Edit → Clip → Ungroup Clips** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、分けたいクリップを含む録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. クリップを2つに分ける位置で波形をクリックし、そこにカーソルを置きます。
4. **編集 → オーディオクリップ → 分割** を選びます。
5. 最初の部分の名前バーをクリックし、Shiftを押しながら2つ目の名前バーをクリックして、両方を選択します。
6. **編集 → オーディオクリップ → クリップをグループ化** を選びます。グループ化すると、2つの選択部分をオーディオとして結合せずに一緒に移動できます。
7. **編集 → オーディオクリップ → クリップグループを解除** を選びます。グループ解除すると、2つの部分を個別に選択できるようになります。
8. プロジェクトには2つのクリップが表示されます。
   *確認できること：* 録音は分割位置で接する2つの別々のクリップのままです。

## ヒント

- 別々のクリップを移動するときに相対位置を保ちたい場合、グループ化が便利です。
- 隣接する部分を1つのクリップにするには **編集 → オーディオクリップ → 選択したクリップを結合** を選びます。
