## このガイドの目的 {#what-this-guide-is-for}

録音を特定の合図位置から始めるとき、目分量でドラッグすると正確さに欠けることがあります。Align start to playheadは選択したトラックの内容を移動し、録音の長さを保ったまま先頭をカーソル位置に合わせます。

:::note[Audacityから移行する場合]
Audacity では **Tracks → Align Tracks → Align Start to Playhead** に相当します。以下の名称はSoundscaper独自のもので、異なる場合があります。
:::

## 手順

1. Soundscaperを開きます。エディターが読み込まれると、新しい空のプロジェクトをすぐに使えます。
2. **ファイル → ファイルをインポート** を選び、合図位置に配置したい録音を読み込みます。ファイルは専用のトラックにクリップとして表示されます。
3. クリップの名前バーをドラッグし、タイムラインの後方に移動します。先にクリップを移動しておくと、カーソルで別の開始位置を指定できます。
4. 録音を開始したい位置で波形をクリックし、そこにカーソルを置きます。
5. **トラック → コンテンツを整列 → 始まりを再生ヘッドに揃える** を選びます。選択したトラック内で最も早いクリップがカーソル位置に移動します。
6. 録音の先頭が再生位置に揃いました。
   *確認できること：* クリップは合図位置から始まり、元の長さを保っています。

## ヒント

- この操作は選択した各トラック上のすべてのクリップを移動します。録音1つだけを動かすには、その録音だけが入ったトラックを使います。
- 選択したトラックをプロジェクトの先頭に戻すには **トラック → コンテンツを整列 → 始まりをゼロに揃える** を選びます。
