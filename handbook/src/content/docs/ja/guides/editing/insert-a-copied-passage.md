## このガイドの目的 {#what-this-guide-is-for}

Insert は既存の音声に重ねず、コピーした音声を入れる場所を作ります。挿入先のトラックでは、後続の音声がコピーした範囲の長さ分だけ右へ移動します。録音の途中にフレーズの繰り返しや追加の一文を入れるときに使います。

:::note[Audacityから移行しましたか？]
これは Audacity の **Edit → Copy, then Edit → Paste** に相当します。以下の名前は Soundscaper での名称で、異なる場合があります。
:::

## 手順

1. Soundscaper を開きます。エディターが読み込まれると、新しい空のプロジェクトが用意されています。
2. **ファイル → ファイルをインポート** を選び、コピーしたい範囲を含む録音を選びます。録音は専用のトラックにクリップとして追加されます。
3. クリップ上部のルーラーをドラッグし、別の場所に挿入する範囲を選択します。
4. **編集 → コピー** を選びます。
5. 挿入先のクリップで、コピーした音声の開始位置になる波形をクリックしてカーソルを置きます。クリックすると時間範囲の選択が解除され、挿入位置が設定されます。
6. **編集 → 貼り付け → 挿入** を選びます。
7. プロジェクトにクリップが 3 つ表示されます。
   *表示される内容:* 挿入した範囲が元のクリップの 2 つの部分の間に入ります。後ろの部分は右へ移動し、前の部分は元の位置に残ります。

## ヒント

- Insert は挿入先トラックの後続音声を移動します。複数トラックのタイミングを保ったまま場所を空けるには、**編集 → 貼り付け → 挿入して同期を維持** を使います。
- **編集 → 取り消す** を使うと、挿入を取り消して後続音声を元の位置に戻せます。
