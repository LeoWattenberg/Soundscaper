Soundscaper と Framescaper の Electron 版では、**ファイル → ファイル名を上書き**を選ぶと、編集済みのプロジェクト全体を元の読み込み済みメディアファイルに書き出します。元のファイルが対応している書き出し設定を使い、書き出しダイアログやファイル選択画面を開かずにすぐ保存します。音声は元の形式、サンプルレート、チャンネル数を維持します。対応する MP4 と WebM の動画は、元のコンテナ、寸法、フレームレートを維持します。

**ファイル → インポート**からメディアファイルを 1 つ読み込み、編集してから **ファイル → ファイル名を上書き**を選びます。さらに編集した後も同じ操作を繰り返せます。時間範囲を選択しても上書き範囲は限定されず、常にプロジェクト全体を書き出します。読み込んだメディアと編集履歴はプロジェクトに保持されます。

対応する元ファイルがプロジェクトにない場合、複数の元ファイルを読み込んでいる場合、または読み込み、録音、処理中は、このコマンドを使用できません。ブラウザー版では通常の書き出しダイアログを使います。

別の保存先を選ぶ場合や出力設定を変更する場合は、Soundscaper では **ファイル → 音声を書き出し**、Framescaper では **ファイル → 動画を書き出し**を選びます。上書きすると元ファイルの内容が置き換わります。未編集の録音が必要なら、別のコピーを保存してください。
