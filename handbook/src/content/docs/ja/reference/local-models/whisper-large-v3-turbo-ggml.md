## 目的と使用例 {#purpose-and-use-case}

選択した音声を、パッケージ化されたwhisper.cppランタイムを介してローカルに書き起こします。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンwhisper-cpp v1.9.3をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムが搭載されているプラットフォームで、**Analyze → Speech → Transcribe & Captions**を開きます。ローカルアシスタンスはデスクトップエディタで実行されます。

1. 音声を選択し、モデルマネージャーを介してWhisper large-v3 turboをインストールします。
2. ツール → 高度なローカル処理で、この音声認識モデルを選択します。
3. ローカルで実行し、テキストとセグメント境界を確認してから受け入れます。
