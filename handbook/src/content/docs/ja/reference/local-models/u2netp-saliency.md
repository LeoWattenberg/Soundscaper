## 目的と使用例 {#purpose-and-use-case}

サンプルのフレームの視覚的に目立つ領域を推定して、リフレーミングを支援します。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンonnxruntime-node 1.29.0をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムを備えたプラットフォームで **Framescaper: エフェクト → ビデオエフェクト → リフレーム** を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. ビデオクリップを選択し、U²-Net-P をモデルマネージャーを通じてインストールします。
2. ガイド付きのリフレームタスクには、YuNet と D-FINE も必要です。ツール → 高度なローカル処理は、独立して注目度検出を実行できます。
3. ローカルで実行し、適用する前に提案されたフレームを確認します。

## ダウンロードと要件 {#download-and-requirements}

モデル識別子: `u2netp-saliency`、バージョン **1.0.0**。

モデルアーティファクトのおおよそのダウンロードサイズ：**4.36 MiB**。必要なランタイムが未インストールの場合、初回ダウンロードに追加されます。最小システムメモリ：**2 GiB**。このカタログ要件は現在の空きメモリではなく総メモリを指します。推論にも十分な空きメモリが必要で、インストールにも作業領域が必要です。メモリ容量は速度を保証しません。

公開プラットフォーム：macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64。対応するダウンロード可能なランタイムも必要です。

Windowsでは、デスクトップアプリに合った最新のサポート対象[Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)をインストールしてください。x64ビルドには**x64**、ARM64ビルドには**ARM64**を使用します。ネイティブのONNXおよびSherpaエンジンにはこれらのライブラリが必要ですが、モデルとランタイムのダウンロードには含まれません。アプリの使用にVisual Studioは不要です。

ツール → モデルマネージャーは初回インストール時に公開モデルのアーティファクトと必要なランタイムをダウンロードし、記録されたSHA-256ダイジェストを検証します。処理にはローカルにインストールされたファイルを使用します。通知の確認、インストールの修復、保存先の変更は、モデルマネージャーの「ストレージと検証」から行えます。

入力: 公共の場にある NASA の宇宙飛行士 Eileen Collins の肖像写真と、CC0 の Chelsea 猫の写真の 2 枚。それぞれは、検出器に人間の顔と明確なオブジェクトを与える別々のフレームに明示的なソースフレームタイミングで収められています。

## 結果を確認する {#review-the-result}

- 視覚的に目立つ領域は、保持したい被写体と必ずしも一致しません。全体的な選択を確認してください。
- テストは有限で境界付けられた注目度結果とソースフレームタイミングを検証しますが、クロップの芸術的な品質は検証しません。
