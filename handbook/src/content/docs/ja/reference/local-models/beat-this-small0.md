## 目的と使用例 {#purpose-and-use-case}

音楽内のビート位置を、より小さなBeat Thisモデルを使用して検出します。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64向けの必須エンジンonnxruntime-node 1.29.0をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムが搭載されているプラットフォームで、**ツール → 高度なローカル処理 → ビートトラッキング**を開きます。ローカルアシスタンスはデスクトップエディター内で実行されます。

1. リズミカルな音楽のセクションを選択します。
2. モデルマネージャーを通じてBeat This小をインストールし、ビートトラッキングにそのモデルを選択します。
3. ビートマーカーやテンポ提案を受け入れる前に、提案されたビートグリッドを聴きます。

## ダウンロードと要件 {#download-and-requirements}

モデル識別子: `beat-this-small0`、バージョン**1.1.0**。

モデルアーティファクトのおおよそのダウンロードサイズ：**10.08 MiB**。必要なランタイムが未インストールの場合、初回ダウンロードに追加されます。最小システムメモリ：**2 GiB**。このカタログ要件は現在の空きメモリではなく総メモリを指します。推論にも十分な空きメモリが必要で、インストールにも作業領域が必要です。メモリ容量は速度を保証しません。

公開プラットフォーム：macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64。対応するダウンロード可能なランタイムも必要です。

Windowsでは、デスクトップアプリに合った最新のサポート対象[Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)をインストールしてください。x64ビルドには**x64**、ARM64ビルドには**ARM64**を使用します。ネイティブのONNXおよびSherpaエンジンにはこれらのライブラリが必要ですが、モデルとランタイムのダウンロードには含まれません。アプリの使用にVisual Studioは不要です。

ツール → モデルマネージャーは初回インストール時に公開モデルのアーティファクトと必要なランタイムをダウンロードし、記録されたSHA-256ダイジェストを検証します。処理にはローカルにインストールされたファイルを使用します。通知の確認、インストールの修復、保存先の変更は、モデルマネージャーの「ストレージと検証」から行えます。

## 結果を確認する {#review-the-result}

- ビートトラッキングはハーフタイムまたはダブルタイムのパターンに従うことができ、不規則な音楽はビートを見逃す可能性があります。
- 別個の小型モデルテストは、オーディオ内での順序付けられたビート位置と有限な正のテンポデータを確認しますが、正確なビート時間は必要としません。
