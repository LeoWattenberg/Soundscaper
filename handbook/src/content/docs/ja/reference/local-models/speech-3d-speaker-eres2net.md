## 目的と使用例 {#purpose-and-use-case}

話し言葉を話者ターンにまとめ、誰がいつ話しているかを確認できます。

ERes2Netは、音声セグメントを数値的な話者表現に変換します。ダイアリゼーションの実行時は、これらをPyannoteセグメンテーションと組み合わせ、録音を話者ターンにグループ化します。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンsherpa-onnx-node 1.13.5をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムが搭載されているプラットフォームで、**分析 → 話し言葉 → 話者を特定する**を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. 分析する会話を選択します。
2. PyannoteセグメンテーションとERes2Net話者埋め込みの両方をモデルマネージャーからインストールします。この操作では、このペアが使用されます。
3. ローカルで実行し、提案された話者ターンを確認し、必要な結果を適用します。

この操作には、[Pyannoteセグメンテーション 3.0](/reference/local-models/pyannote-segmentation-3.0/)も必要です。

## 結果を確認する {#review-the-result}

- 話者IDは、録音から推論されたグループであり、検証された実世界のアイデンティティではありません。
- 短い発話、重なる声、似た声は誤ってグループ化される可能性があります。テストは有効な非空のターン、正確な話者数を確認するのではなく、チェックします。
