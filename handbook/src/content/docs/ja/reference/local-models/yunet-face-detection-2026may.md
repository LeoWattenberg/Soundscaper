## 目的と使用例 {#purpose-and-use-case}

サンプルのビデオフレーム内で顔とオブジェクトを検出し、新しいフレームを提案するのに役立ちます。

YuNetは顔とそれらの位置を検出します。サブジェクト検出操作は、これらの結果をD-FINEオブジェクト検出と組み合わせます。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンonnxruntime-node 1.29.0をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムを備えたプラットフォームで**フレームスカパー：エフェクト→ビデオエフェクト→リフレーム**を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. フレームスカパーでビデオクリップを選択します。
2. サブジェクト検出のためにYuNetとD-FINEの両方をインストールします。ガイド付きのリフレームタスクは、U²-Net-Pの注目度検出も使用します。
3. ローカルで実行し、提案されたトリミングを確認します。ツール→高度なローカル処理は、サブジェクト検出を単独で実行できます。

この操作には、[D-FINE Nanoオブジェクト検出](/reference/local-models/dfine-nano-coco/)も必要です。

## 結果を確認する {#review-the-result}

- 顔やオブジェクトが見落とされたり、誤って分類されることがあります。検出はサンプリングされるため、移動する被写体が提案されたすべてのトリミング内に留まることを保証するものではありません。
- この操作は両方のモデルを同時に実行します。どちらのモデルも、人を識別するための顔認識システムではありません。
