## 目的と使用例 {#purpose-and-use-case}

選択した音声をタイム付きのトランスクリプトに変換し、字幕やトランスクリプトの編集を行います。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンsherpa-onnx-node 1.13.5をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムが搭載されているプラットフォームで **分析 → 音声 → トランスクリプトと字幕** を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. トランスクリプトを作成する音声を選択します。
2. モデルマネージャーを使用してこのモデルをインストールします。ツール → 高度なローカル処理では、特定の音声認識モデルを選択できます。
3. ローカルで実行し、テキストとタイミングを確認してからトランスクリプトを受け入れます。

モデルアーティファクトのおおよそのダウンロードサイズ：**630.56 MiB**。必要なランタイムが未インストールの場合、初回ダウンロードに追加されます。最小システムメモリ：**4 GiB**。このカタログ要件は現在の空きメモリではなく総メモリを指します。推論にも十分な空きメモリが必要で、インストールにも作業領域が必要です。メモリ容量は速度を保証しません。

公開プラットフォーム：macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64。対応するダウンロード可能なランタイムも必要です。

## 結果を確認する {#review-the-result}

- 名前、句読点、数字、タイミングが録音と一致しているか確認します。
- 成功したテストには、読みやすいテキストと有効なタイミングが必要ですが、正確なリファレンストランスクリプトではありません。言語間や録音条件にわたる認識の正確性を測定するものではありません。
