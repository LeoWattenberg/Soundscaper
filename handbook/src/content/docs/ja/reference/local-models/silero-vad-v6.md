## 目的と使用例 {#purpose-and-use-case}

音声領域を転写または長時間の静音を削除する前に見つけます。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64向けの必須エンジンsherpa-onnx-node 1.13.5をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。 モデルの重みは掲載されていますが、macOS x64向けにダウンロードできるエンジンはありません。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムが搭載されているプラットフォームで、**効果 → ノイズ除去と修復 → クリーン フィラー & 静音**または **分析 → 音声 → 転写 & キャプション** を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. 音声と静音を含むオーディオ領域を選択します。
2. タスクを開き、モデルマネージャーを通じて Silero VAD をインストールします。
3. ローカルで実行し、変更を適用する前に検出された領域またはクリーンアップ提案を確認します。

## ダウンロードと要件 {#download-and-requirements}

モデル識別子: `silero-vad-v6`、バージョン **6.2.1**。

モデルアーティファクトのおおよそのダウンロードサイズ：**2.22 MiB**。必要なランタイムが未インストールの場合、初回ダウンロードに追加されます。最小システムメモリ：**2 GiB**。このカタログ要件は現在の空きメモリではなく総メモリを指します。推論にも十分な空きメモリが必要で、インストールにも作業領域が必要です。メモリ容量は速度を保証しません。

公開プラットフォーム：macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64。対応するダウンロード可能なランタイムも必要です。

Windowsでは、デスクトップアプリに合った最新のサポート対象[Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)をインストールしてください。x64ビルドには**x64**、ARM64ビルドには**ARM64**を使用します。ネイティブのONNXおよびSherpaエンジンにはこれらのライブラリが必要ですが、モデルとランタイムのダウンロードには含まれません。アプリの使用にVisual Studioは不要です。

ツール → モデルマネージャーは初回インストール時に公開モデルのアーティファクトと必要なランタイムをダウンロードし、記録されたSHA-256ダイジェストを検証します。処理にはローカルにインストールされたファイルを使用します。通知の確認、インストールの修復、保存先の変更は、モデルマネージャーの「ストレージと検証」から行えます。

## 結果を確認する {#review-the-result}

- 音声アクティビティ検出は、音声が発生するタイミングを特定します。単語を転写したり、ノイズを修復したり、話者を特定したりはしません。
- 音楽やバックグラウンドボイスは提案された境界に影響を与える可能性があります。カットを適用する前に確認してください。
