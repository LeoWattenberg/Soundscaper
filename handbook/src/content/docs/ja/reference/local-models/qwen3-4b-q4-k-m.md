## 目的と使用例 {#purpose-and-use-case}

既存のハイライト候補に対するタイトル、フック、章、説明の提案を行います。

## 現在の利用可能性 {#current-availability}

デスクトップビルドでは、macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64向けの必須エンジンllama-cpp b10509をダウンロードして検証できます。モデルと必要なランタイムをモデルマネージャーからインストールし、タスクをローカルで実行します。これらはサポート対象のビルド先です。特定のパッケージやマシンの結果は夜間テストレポートを確認してください。

## このモデルを使用する {#use-this-model}

必要なネイティブランタイムがインストールされているプラットフォームで **Framescaper: ツール → 高度なローカル処理 → 編集生成** を開きます。ローカルアシスタンスはデスクトップエディターで実行されます。

1. 選択したメディアからハイライト候補を準備および確認します。
2. モデルマネージャーを通じて Qwen をインストールし、編集生成のオプションを有効にします。
3. 受け入れる前に、すべてのテキスト提案を確認します。承認されるのは、承認された候補者のみです。

## 結果を確認する {#review-the-result}

- 生成された言葉遣いは、誤解を招いたり、繰り返しになったりすることがあります。これは、供給された証拠に基づいた提案であり、検証された事実分析ではありません。
- モデルはローカルで CPU 上で実行され、少なくとも 16 GiB の総システムメモリと十分な空きメモリを必要とします。短い要求でも数分かかることがあります。
- テストでは、厳密な JSON、承認された候補者を正確に1回ずつ、および読みやすい要求されたフィールドが必要です。コマンド、パス、マークアップ、新しいタイミング、外部の候補者、および破損した出力ではなく、それらを拒否します。
