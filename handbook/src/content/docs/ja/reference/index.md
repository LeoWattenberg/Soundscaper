リファレンスページは、レビュー済みのランタイムレジストリから生成され、リポジトリにコミットされます。これらは実装された動作を記述しており、ロードマップの項目やソースファイルおよびテストの単なる存在を示すものではありません。

このセクションを使用して、次のような質問に答えてください。

- どのデフォルトのショートカットがコマンドを呼び出すか？
- コマンドは Soundscaper、Framescaper、またはその両方で利用可能か？
- どのオーディオおよびビデオ形式をエクスポートできるか？
- エフェクトのパラメータのデフォルト値は何か、またどの値を受け入れるか？
- オーディオ再生中に実行できるエフェクトは何か、また選択が必要なエフェクトは何か？
- どのローカル支援ワークフローが存在し、それらはどのモデルを必要とするか？
- 各ワークスペースはどのパネルを表示するか？
- どの言語、ブラウザ、デスクトップパッケージがビルドおよびテストされているか？
- どの機能がプロダクト、プラットフォーム、または FFmpeg ランタイムに依存しているか？

生成されたページにはソースの出所が含まれており、リポジトリの品質ゲートでドリフトがチェックされます。

[マクロプログラム](/reference/macro-programs/) は、ここで手作業で書かれた唯一のページです。これは、マクロプログラムが実行する JavaScript API を文書化しており、その主張はエディタ自身のテストがサンドボックスに課しているものです。
