デバイス上でローカル支援が実行されます。サウンドスケーパーおよびフレームスケーパーのデスクトップエディター。メディアを選択し、そのメニューからタスクを選択します。ダイアログには、選択内容、タスク設定、およびそのモデルがインストールされているかどうかが表示されます。

デスクトップ用パッケージには、オプションのネイティブ処理エンジンやモデルの重みは含まれていません。モデルマネージャーからモデルをインストールすると、必要なエンジンと重みがダウンロードされます。その後、選択したメディアに対してタスクを実行します。初回のインストールにはネットワーク接続が必要ですが、以降の処理はローカルで実行されます。対応プラットフォーム、メニュー項目、要件については各モデルのガイドを参照してください。

詳しくは [各モデルのガイド](/reference/local-models/).

## タスクの検索 {#find-a-task}

| メニュー | タスク |
| --- | --- |
| エフェクト → ノイズ除去と修復 | ダイアログの強化、リバーブの低減、フィラーと無音のクリーニング |
| エフェクト → ソース分離 | ダイアログ/音楽/エフェクトの分離 |
| 分析 → スピーチ | トランスクリプトとキャプション、スピーカーの特定、リアクションのマーク |
| 分析 → 音楽 | ビートとテンポの検出 |
| 分析 → ビデオ | カットのマーク |
| エフェクト → ビデオエフェクト | リフレーム |
| 編集 | ハイライトの作成 |
| 生成 | 編集テキストの生成 |
| ツール → 検索 | インデックス検索、トランスクリプトのインデックス付け、ビデオのインデックス付け |

ビデオタスクはフレームスケーパーに属します。利用可能なコマンドは、デスクトップの実行時と製品の機能によって異なります。サウンドスケーパーのアルファベット順のエフェクトメニューオプションは、ローカル処理エフェクトを名前でソートします。

**ローカルで実行**を選択して処理を開始し、ローカルの同意プロンプトに応答します。処理中にキャンセルすることができます。**結果を確認**を選択し、適用したい結果を選択し、**選択したものを適用**を選択します。受け入れられたプロジェクトの編集は元に戻すことができます。タスクを閉じるだけでは、その提案が適用されるわけではありません。

**ツール → 高度なローカル処理**では、個々の操作とモデルの選択が保持されます。タスクダイアログの技術詳細では、必要に応じてアンダーレイヤーの手順と正確な設定が表示されます。

## モデルの管理 {#manage-models}

**ツール → モデルマネージャー**を開き、またはタスク内の**モデルを管理**を使用します。タスクリンクは、互換性のあるモデルIDにリストをフィルタリングし、**すべてのモデルを表示**はその制限をクリアします。名前またはタスクで検索し、インストール状態別にフィルタリングします。

モデルは明示的にインストールしてください。初回のインストールでは、そのモデルが必要とする未取得の共有ネイティブランタイムもダウンロードされます。ダウンロードの進行状況が表示され、キャンセルできます。タスクに戻ると設定は保持され、モデルの利用状況が更新されますが、処理は開始されません。修復、クリーンアップ、ストレージの移動、ライセンス通知、フォルダーからのオフラインインストールについては、**ストレージと検証**を展開してください。オフラインファイルからインストールしたモデルも、初回使用前に対応するランタイムが必要です。

公開済みの各モデルの目的、メニューエントリ、ダウンロードサイズ、要件、制限、およびナイトリーワイテストデスクトップパッケージによって実行される実際の推論チェックについては、[個々のモデルガイド](/reference/local-models/)を参照してください。

## プラグインとデバイスの管理 {#manage-plugins-and-devices}

**エフェクト → プラグインマネージャー**には、サウンドスケーパーのオーディオプラグインとフレームスケーパーのOpenFXプラグインが表示されます。リストを検索またはフィルタリングし、プラグインを選択してバージョン、許可、および復旧制御を確認します。**スキャン＆設定**には、検出設定が含まれます。処理が無効になっている場合でも、管理機能にアクセスできます。

**エフェクト → オーディオプラグイン**を介してオーディオプラグインを使用します。フレームスケーパーのビデオエフェクトの追加/編集コマンドは、**エフェクト → ビデオエフェクト**の下にあります。

**編集 → 環境設定 → オーディオ設定**で、ネイティブオーディオデバイスとヘルパー制御を開きます。**メディア**にはネイティブメディア設定が、**エフェクト**にはプラグインマネージャーへのリンクとプラグイン検出スイッチが含まれます。プラグインの許可と検疫の復旧は、依然として明示的な操作を必要とします。
