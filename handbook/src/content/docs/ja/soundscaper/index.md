Soundscaperは、オーディオに特化したエディターです。Audacity準拠のメニューと編集モデルを、プロジェクトビン、非破壊的なマルチトラックアレンジ、録音、リアルタイムエフェクト、ラウドネスおよび周波数解析、ポータブルなプロジェクト交換機能と組み合わせています。

## 推奨される手順

1. チュートリアル[最初のSoundscaperプロジェクト](/tutorials/your-first-project/)に従ってください。
2. 新しい素材が必要な場合は、[録音の設定](/soundscaper/recording/)を行ってください。
3. [編集、ミックス、エクスポート](/soundscaper/edit-mix-and-export/)を行ってください。
4. [ストレージとバックアップの動作](/projects-and-data/storage-backups-and-privacy/)を確認してください。
5. 目の前のタスク（ノイズ除去、フェード、ラウドネス、エクスポートなど）に適した[ハウツーガイド](/guides/)を選択してください。

ブラウザエディターを[soundscaper.org/en](https://soundscaper.org/en/)で開いてください。
