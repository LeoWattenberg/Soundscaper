サウンドスケーパーは、オーディオに特化したエディターです。Audacityに準拠したメニューと編集モデルを、プロジェクトビン、非破壊的なマルチトラックアレンジメント、レコーディング、リアルタイムエフェクト、ラウドネスと周波数分析、ポータブルプロジェクト交換と組み合わせます。

## 推奨パス

1. [最初のサウンドスケーパー プロジェクト](/tutorials/your-first-project/) のチュートリアルに従ってください。
2. [レコーディングの設定](/soundscaper/recording/) を行い、新しい素材が必要な場合はそれを使用します。
3. [編集、ミキシング、エクスポート](/soundscaper/edit-mix-and-export/) を行います。
4. [ストレージとバックアップの動作](/projects-and-data/storage-backups-and-privacy/) を確認します。
5. 目の前のタスクに適した [ハウツー ガイド](/guides/) を選択します。

ブラウザー エディターは、[soundscaper.org/en](https://soundscaper.org/en/) で開きます。

デスクトップ アシスタンスについては、[ローカル処理、モデル、プラグイン](/help/local-processing/) を参照してください。
