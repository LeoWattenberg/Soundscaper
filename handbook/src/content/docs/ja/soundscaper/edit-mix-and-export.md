## クリップの配置

編集コマンドを選択する前に、クリップまたは時間範囲を選択してください。Split（分割）は、再生ヘッドの位置に編集境界を作成します。Gap-preserving（ギャップ保持）およびripple（リップル）のバリアントは、後続の素材がその場で保持されるか、削除された領域を閉じるために移動するかを決定します。

トラックフォルダ、クリップグループ、およびProject Bin（プロジェクトビン）を使用して、大規模なプロジェクトを整理してください。

### クリップのフェードを調整 {#clip-fades}

オーディオクリップを選択すると、クリップヘッダーの直下、波形の上部に沿って小さな三角形のハンドルが表示されます。
左の三角形を内側にドラッグするとフェードイン、右の三角形を内側にドラッグするとフェードアウトになります。ドラッグするにつれて波形が変化し、フェード曲線の上の領域が暗くなります。三角形はフェードの境界に従います。三角形を角に戻してドラッグすると、そのフェードが削除されます。複数のクリップが選択されている場合でも、ドラッグしたクリップのみが変更されます。

クリップの選択を解除するとハンドルは消えますが、フェードが適用された波形とシェーディングは残ります。これらのフェードは元のオーディオを保持し、プロジェクトを保存して再オープンした後も調整可能です。リリースするとフェードが確定し、ドラッグ中に**Escape**キーを押すとキャンセルされます。**Undo**（元に戻す）は、1回の完全なドラッグ操作を元に戻します。
再生およびエクスポートでは、確定されたフェード設定が使用されます。

選択されたクリップにフォーカスがある状態で、**Tab**キーを押すとそのフェードハンドルに到達できます。矢印キーで10ミリ秒単位で長さを調整でき、**Shift**キーと組み合わせて100ミリ秒単位で調整できます。**Home**キーでフェードを削除し、**End**キーでクリップ全体にわたって拡張します。
数値を入力するには、**Edit → Audio clips → Clip properties**（編集 → オーディオクリップ → クリッププロパティ）を選択し、**Fading**（フェーディング）を使用してください。

## ミックスの構築

トラックゲイン、パン、ミュート、ソロコントロールを使用してプロジェクトのバランスを調整します。Mixer（ミキサー）パネルは、同じプロジェクト状態をミックス向けのレイアウトで表示します。リアルタイムエフェクトは調整可能ですが、破壊的またはレンダリングされた操作は、履歴が利用可能な間、元に戻すことができるプロジェクトの変更を作成します。

再生メーターとラウドネス解析を使用して結果を確認してください。メーターの目標値を、完全なエクスポートを聴くことへの代替手段として扱うことは避けてください。

### サイバンスを軽減する {#reduce-sibilance}

**Effect → Noise removal and repair → De-esser**（エフェクト → ノイズ除去と修復 → ディエッサー）を選択します。**Frequency**（周波数）を声の刺耳な部分付近に設定し、サイバントが柔らかくなるまで**Threshold**（しきい値）を下げます。
**Maximum reduction**（最大減衰）はカットを制限します。6〜9 dB程度から開始してください。短い**Attack**（アタック）は子音の開始を捉え、**Release**（リリース）は高周波数が回復する速さを制御します。上帯域のみが減衰されます。

### 個別の周波数帯域を圧縮する {#multiband-compression}

**Effect → Volume and compression → Multiband compressor**（エフェクト → ボリュームと圧縮 → マルチバンドコンプレッサー）を選択します。2つのクロスオーバーが信号を低域、中域、高域の帯域に分割します。各帯域には独自のしきい値、比率、出力ゲインがあります。比率が1の場合、その帯域のダイナミクスは変更されません。アタックとリリースは3つの帯域すべてに適用されます。クロスオーバーは穏やかで重なり合う6 dB/オクターブのスロープを持ちます。すべての比率が1で、帯域ゲインが0 dBの場合、元の信号は変更なしで通過します。

両方のエフェクトはステレオバランスを保持するためにチャンネルをリンクしており、トラックおよびマスターエフェックラックでも利用可能です。ラック設定はプロジェクトと保存され、再生中に調整できます。**Apply to selection**（選択範囲に適用）は、選択されたオーディオにエフェクトをレンダリングし、Undo（元に戻す）をサポートします。これら2つのエフェクトにはタイムラインオートメーションは利用できません。

## エクスポート

ミックスされた成果物のエクスポートには**File → Export audio**（ファイル → オーディオをエクスポート）、選択範囲のみをレンダリングする場合は**Export selected audio**（選択されたオーディオをエクスポート）を選択します。Soundscaperはステムとラベルのエクスポートも可能です。

圧縮形式はFFmpegランタイムを使用します。正確な形式と条件付きの利用可能性は、[生成された形式リファレンス](/reference/)に記載されています。

納品またはソース素材を削除する前に、別のアプリケーションでエクスポートされたファイルを再生してください。

映像作業（シーケンスの構成、ビデオエフェクト、およびMP4またはWebMでの納品）については、プロジェクトを[Framescaper](/framescaper/)に引き継ぎ、[ビデオのエクスポート](/framescaper/video-export/)を参照してください。
