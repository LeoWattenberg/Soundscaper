## クリップを配置する

編集コマンドを選ぶ前に、クリップまたは時間範囲を選択します。Split は再生ヘッド位置に編集境界を作ります。ギャップ保持型とリップル型のバリエーションによって、後続の素材をその位置に残すか、削除した領域を詰めるために移動するかが決まります。

トラックフォルダー、クリップグループ、Project Bin を使って、大きなプロジェクトを整理します。

### クリップのフェードを調整する {#clip-fades}

オーディオクリップを選択すると、クリップヘッダーのすぐ下にある波形上部に、小さな三角形のハンドルが表示されます。
左の三角形を内側へドラッグするとフェードインになり、右の三角形を内側へドラッグするとフェードアウトになります。ドラッグ中は波形が変化し、フェード曲線の上の領域が暗くなります。三角形はフェード境界に沿って移動します。三角形を角まで戻すと、そのフェードは削除されます。複数のクリップを選択していても、変更されるのはドラッグしたクリップだけです。

クリップの選択を解除するとハンドルは消えますが、フェードした波形と陰影は残ります。これらのフェードは元のオーディオを保持し、プロジェクトを保存して開き直した後も調整できます。ドラッグを離すとフェードが確定します。ドラッグ中に **Escape** を押すとキャンセルできます。**Undo** は1回のドラッグ操作全体を元に戻します。
再生とエクスポートには、確定済みのフェード設定が使われます。

クリップを選択してフォーカスした状態で **Tab** を押すと、フェードハンドルに移動できます。矢印キーで長さを10ミリ秒単位で調整し、**Shift** を併用すると100ミリ秒単位で調整できます。**Home** はフェードを削除し、**End** はクリップ全体に広げます。数値を入力するには、**Edit → Audio clips → Clip properties** を選び、**Fading** を使います。

### クリップのソースを編集する {#clip-source-properties}

**編集 → オーディオクリップ → クリップのプロパティ**を選択してソースエディターを開きます。クリップの背後に録音全体が表示されます。クリップの開始位置をプロジェクトのタイムライン上に保ったまま、端をドラッグしてソースの開始位置と長さを変更できます。**ノーマライズ**パネルにはクリップゲインとピーク、ラウドネスの操作があります。

**ピッチとテンポ**を開き、**ピッチとテンポをリンク**をオンにすると、速度とピッチを同時に変更できます。速度比が`1`でピッチ変更が`0%`なら音は変わりません。比率`2`は2倍速で1オクターブ高く、`0.5`は半分の速度で1オクターブ低く再生します。リンクされた一方のコントロールを編集すると、もう一方も更新されます。リンクを解除するとピッチを個別に設定でき、現在の速度比は維持されます。

波形を**Ctrl+クリック**すると、そのソースサンプルに関連付けられたストレッチマーカーを追加できます。ドラッグすると両側のタイミングが変わり、オーバーレイに両方の再生速度が表示されます。クリップのコントロールは引き続きクリップごとに適用されます。ソース音声を選択してエフェクトを適用すると、そのソースを使うすべてのクリップが更新されます。

### スプレッドシートでクリップを編集する {#clip-spreadsheet}

**表示 → パネル → クリップスプレッドシート**を選択すると、プロジェクト内のすべてのクリップを表示できます。パネルはタイムラインの下に開きます。パネルメニューから別のドックへ移動、フローティング表示、または閉じることができます。サイズと位置はワークスペースに保存されます。各行にはトラック、タイムライン位置、ソースファイル、ソースオフセット、長さ、ピッチ、速度、ゲイン、フェード、再生オプションが表示されます。時間は秒、ピッチは半音、速度は比率で表し、`1`が通常、`2`が2倍速です。

セルをダブルクリックするか、選択して**Enter**を押すと値を編集できます。**Enter**で適用し、**Escape**で取り消します。トラックとソースのセルには実際のIDが表示されます。トラックIDを変更すると既存のオーディオトラックへクリップを移動できます。ソースIDを変更するかローカルファイルパスを入力すると、タイムライン位置、長さ、速度、秒単位のソースオフセットを保ったまま音声を置き換えます。新しいファイルには指定したソース範囲が含まれている必要があります。**逆再生**と**反転**はチェックボックスです。セルを選択して**スペース**を押すと切り替わります。ロックされたトラック上のクリップとビデオクリップは読み取り専用です。

長さを変更すると、現在のオフセットからソース範囲を短縮または延長します。速度の変更では、長さも一緒に貼り付けない限りソース範囲が維持されます。ここでタイミングを変更する前にクリップのグループ化またはリンクを解除してください。伸縮されたクリップのタイミングはソースエディターで編集します。

セルを選択し、範囲をドラッグするか、別のセルを**Shift+クリック**して選択範囲を広げます。行番号または列見出しをクリックすると行全体または列全体を選択できます。**Ctrl+C**と**Ctrl+V**（macOSでは**Cmd+C**と**Cmd+V**）で選択範囲をスプレッドシートとやり取りします。列はタブ、行は改行で区切られます。貼り付けは選択セルから始まり、既存のクリップを更新します。既存の行を超える貼り付けは拒否されます。選択中に**Escape**を押すか、表の下の空白部分をクリックすると選択を解除します。選択なしで貼り付けると、空のプロジェクトでも新しい行が挿入されます。再生オプションは`true`または`false`としてコピーされ、貼り付け時もこの値を使います。新しい行は表の列順に従い、ソースファイル名またはソースIDが必要です。一意の既存トラック名を指定するとそのトラックに配置され、新しい名前ならオーディオトラックが作成されます。空のトラック名にはソース名が使われます。空の数値セルは既定値を使います。位置とオフセットは`0`、速度は`1`、ピッチとゲインは`0`で、フェードはありません。長さが空の場合は要求した速度で残りの音声を使います。

パネルはまずプロジェクト内（プロジェクトビンを含む）でソースを探します。見つからない場合は**参照ファイルを読み込む**を選び、ダイアログに表示されたオーディオファイルを選択します。ディスク上のパスもファイル選択が必要です。パスを貼り付けてもアプリにファイルアクセス権は与えられません。選択したファイルは参照名に一意に対応する必要があります。パネルは音声を読み込み、ソース範囲とクリップのプロパティを検証し、指定位置に新しいクリップを配置します。**Ctrl+Z**（macOSでは**Cmd+Z**）で貼り付け全体を1回で元に戻し、**Ctrl+Shift+Z**（**Cmd+Shift+Z**）でやり直します。無効な値を含む貼り付けではクリップは変更されません。

## ミックスを構築する

トラックのゲイン、パン、ミュート、ソロの各コントロールでプロジェクトのバランスを調整します。Mixer パネルでは、同じプロジェクトの状態をミックス向けのレイアウトで確認できます。リアルタイムエフェクトは調整を続けられます。破壊的な操作やレンダリング操作はプロジェクトを変更しますが、履歴が残っている間は元に戻せます。

再生メーターとラウドネス分析で結果を確認します。メーターの目標値を、完成したエクスポートを聴くことの代わりにしないでください。

### 選択した周波数を聴く {#listen-to-selected-frequencies}

聴きたい範囲を選択します。トラックメニューから**トラック表示 → スペクトログラム**を選び、**スペクトログラムのオプション → スペクトル周波数範囲を選択**を開きます。最小周波数と最大周波数を入力して**範囲を選択**を選ぶか、スペクトログラム上の選択ハンドルを調整します。

**再生オプション → 選択した周波数を再生**、または**選択 → スペクトル → 選択した周波数を再生**を選びます。以前に別の再生速度やループ再生を選択していても、選択した時間範囲を通常速度で1回再生します。フィルターは現在のミックスに適用され、ミュート、ソロ、ゲイン、エフェクトの設定も反映されます。スペクトルの四角形は周波数帯と時間範囲を示しますが、トラックをソロにはしません。再生中にコマンドを選ぶと一時停止し、もう一度選ぶと周波数の試聴が始まります。

リアルタイム周波数フィルターは境界がなだらかです。帯域外の周波数や境界付近の周波数は小さくなることがあります。**一時停止**または**停止**でフィルターが解除され、次の通常再生では全周波数帯域が使われます。音声、選択範囲、取り消し履歴、書き出し済みファイルは変化しません。

### 歯擦音を抑える {#reduce-sibilance}

**Effect → Noise removal and repair → De-esser** を選択します。**Frequency** を声の耳障りな部分付近に設定し、歯擦音が和らぐまで **Threshold** を下げます。**Maximum reduction** でカット量の上限を決めます。まずは6〜9 dB程度から始めてください。短い **Attack** は子音の立ち上がりを捉え、**Release** は高域が回復する速さを制御します。低減されるのは高域だけです。

### 周波数帯域ごとに圧縮する {#multiband-compression}

**Effect → Volume and compression → Multiband compressor** を選択します。2つのクロスオーバーで信号を低域、中域、高域の3帯域に分けます。各帯域には独自のスレッショルド、レシオ、出力ゲインがあります。レシオを1にすると、その帯域のダイナミクスは変わりません。アタックとリリースは3帯域すべてに適用されます。クロスオーバーは緩やかに重なり合う6 dB/オクターブの傾斜です。すべてのレシオが1で帯域ゲインが0 dBなら、元の信号は変わらず通過します。

この2つのエフェクトはステレオバランスを保つためにチャンネルをリンクし、トラックラックとマスターエフェクトラックでも利用できます。ラック設定はプロジェクトと一緒に保存され、再生中に調整できます。**Apply to selection** は選択したオーディオにエフェクトをレンダリングし、Undo に対応します。この2つのエフェクトではタイムラインオートメーションは利用できません。

### LADSPAエフェクトとVampアナライザーを使う {#native-audio-plugins}

デスクトップアプリがサードパーティ製プラグインをスキャンできるのは、**Effect → Plugin Manager** で形式とそのフォルダーの1つを許可した後だけです。スキャンは自動では行われません。検出されたインストールは、使う前にそれぞれ許可してください。また、信頼できるプラグインだけをインストールします。ネイティブプラグインは、Soundscaperが監視下のヘルパープロセスでホストしていても実行可能コードを動かすためです。

LADSPAエフェクトはLinuxで利用できます。マネージャーで有効にした後、**Effect → Audio Plugins** から開きます。この形式にはベンダーインターフェースがないため、SoundscaperはLADSPAポートからコントロールを構築します。これらのコントロール値と、エフェクトの有効またはバイパス状態はプロジェクトと一緒に保存されます。

Vampプラグインはオーディオを変更せずに分析します。Vampのインストールを有効にしたら、分析するオーディオトラックを選択するか、マスターミックスを分析する場合はオーディオトラックを選択しないでください。時間範囲を選択すると分析対象を絞れます。選択しなければSoundscaperはプロジェクト全体を使います。**Analyze → Vamp Plugins** を選び、アナライザーの出力と設定を選択して実行します。Soundscaperは分析が完全に成功した後にだけ、返されたタイムスタンプを新しいラベルトラックとして追加します。そのため、キャンセルやプロジェクトの変更で途中までのラベルが残ることはありません。

## エクスポート

ミックスした納品ファイルには **File → Export audio** を、選択範囲だけをレンダリングする場合は **Export selected audio** を選びます。Soundscaperではステムとラベルもエクスポートできます。

### クリップを個別のファイルとして書き出す {#export-clips}

**ファイル → オーディオを書き出す**を選び、**出力**を**個別のクリップ（クリップごとに分割）**に設定します。オーディオ形式を選び、**書き出し**を押すと、プロジェクト内のオーディオトラックにある各オーディオクリップを1ファイルずつ含むアーカイブをダウンロードできます。各ファイルはクリップの聞こえる開始位置から始まり、聞こえる終端で終わります。プロジェクトのタイムラインまで無音を追加したり、エフェクトの余韻を加えたりしません。トリム、クリップゲイン、フェード、速度とピッチの変更が反映されます。重なったクリップは別々のままです。

ファイル名にはクリップ名と番号付きの接頭辞が使われます。未対応のファイル名文字は置き換えられ、番号で同名のクリップを区別します。トラックエフェクトは含まれますが、マスターエフェクト、ミュート、ソロはこの書き出しに影響しません。編集可能なクリップを個別に書き出す前に、凍結したトラックを解除してください。

圧縮形式にはFFmpegランタイムが使われます。利用できる正確な形式と条件付きの可否は、[生成された形式リファレンス](/reference/)に記載されています。

### チャプターラベルを埋め込む {#embedded-chapters}

ブラウザーエディターで**ファイル → オーディオを書き出す**を選び、**MP3**または**AAC / M4A**を選択して、**オーディオオプション**の**ラベルをチャプターとして埋め込む**を有効にします。初期状態ではオフで、ラベルのタイトルと時刻を1つのミックスファイルに含めます。書き出す前にラベルを追加してください。ステム、チャプター分割、マスタリングシーケンスにはこのオプションはありません。

納品範囲と重なるラベルだけが含まれます。選択範囲を書き出すと、チャプター時刻は生成ファイルの先頭に合わせて移動します。MP3は範囲ラベルの終了時刻を保持します。ポイントラベルは次のチャプターまたはファイル末尾で終了します。M4Aはチャプター開始時刻を保存し、各チャプターは次の開始時刻またはファイル末尾まで続きます。M4Aは最大255チャプター、タイトルあたり255 UTF-8バイトに対応します。埋め込みチャプターが表示されるかはプレーヤーによって異なります。

納品したり元の素材を削除したりする前に、別のアプリケーションでエクスポートしたファイルを再生してください。
