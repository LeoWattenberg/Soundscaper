## 作成してレイヤーを追加する {#create-and-add-a-layer}

1. **ファイル → 新規コンポジション**を選択し、名前、寸法、フレームレート、
   フレーム単位のデュレーションを入力します。
2. **レイヤー → 新規テキスト**または**レイヤー → 新規平面**を選択します。プロジェクトに複数の
   コンポジションがある場合は、対象のコンポジションを選択します。
3. **レイヤー → テキストと外観**を開くと、既存のテキストレイヤーや
   シェイプの塗りと線を編集できます。ここで読み込んだフォントはプロジェクトに保持されます。

画像、動画、音声ソースには**ファイル → メディアを読み込む**を使用します。現在のデコーダー
またはメモリの上限を超える読み込みは、説明とともに拒否されます。
元のソースファイルは変更されません。

## アニメーションとプレビュー {#animate-and-preview}

**レイヤー → プロパティとキーフレーム**を開き、レイヤーのプロパティを選択して、
正確なフレーム位置にキーを追加します。カーブコントロールは補間を変更し、空間
編集は位置のパスを変更します。**表示 → タイムライン**では、レイヤーのタイミング、
順序、グループ化、ワークエリアのコントロールを開きます。

**表示 → コンポジションキャンバス**を開くと、静的な2Dレイヤーを選択して移動できます。
四角で拡大縮小し、円で設定したアンカーを中心に回転します。完了した
ドラッグは1回の取り消し操作にまとまります。Escapeはドラッグをキャンセルします。アニメーションや
式による変形は、引き続きプロパティとキーフレームで編集します。

**表示 → コンポジションプレビュー**を開き、コンポジション内のシークや再生を行います。プレビューは
保持されたソースメディアを使用します。未対応または不正なシーン設定は、代替画像ではなく
エラーになります。プレビューを閉じると、アクティブな
レンダリングリソースが解放されます。

## 持ち運べるコピーを保存する {#save-a-portable-copy}

**ファイル → 保存**で現在のリビジョンを公開し、**ファイル → コピーを保存**で
`.mscape`アーカイブをダウンロードします。アーカイブには、プロジェクトと再度開くために必要な
元メディアが含まれます。別のデバイスや新しいブラウザーライブラリから、
**ファイル → 開く**で開けます。

## レンダリング {#render}

**ファイル → レンダリング**を選択します。コンポジション、出力形式、
フレーム範囲を選択してください。終了フレームは含まれません。フレーム0～29の範囲は
`0`から`30`です。分数のワークエリアは、その範囲内の整数サンプル時刻を選択します。
出力サンプルのない範囲は、レンダリング前に変更する必要があります。

アルファには**透過PNGシーケンス（.tar）**を使用します。TARアーカイブを展開すると、
通常のPNG画像とタイミングメタデータを取得できます。MP4とWebMは、ダイアログで選択した
背景色を使用します。レンダリングでは送信したリビジョンが固定されるため、その後の編集は
進行中の出力を変更しません。レンダリングダイアログを閉じても
ジョブは続行します。**ファイル → レンダーキュー**では、進行状況、キャンセル、
送信したリビジョンの再試行、完了したダウンロードを確認できます。エディターを閉じると
未完了のジョブはキャンセルされます。
