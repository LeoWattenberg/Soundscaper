## Przeglądarki

„Automatycznie testowane” oznacza, że pakiet przeglądarki jest uruchamiany przeciwko temu silnikowi w każdej prośbie o ściągnięcie. Silnik, który nie jest wymieniony, nie jest testowany i nie jest gwarantowany jako działający.

## Gdzie może działać możliwość

Możliwości są grupowane według tego, czego potrzebują od platformy. Zobacz [Możliwości produktu](/reference/generated/product-capabilities/), aby sprawdzić, które możliwości umożliwia każdy produkt.

| Poziom | Oznacza to |
| --- | --- |
| `web-core` | Działa w każdej obsługiwanej przeglądarce, bez wymaganych opcjonalnych funkcji platformy. |
| `web-enhanced` | Działa w przeglądarce, która zapewnia nowsze funkcje pamięci masowej i multimediów, których wymaga możliwość. |
| `electron-enhanced` | Działa w przeglądarce, a aplikacja pulpitu robi z nią więcej. |
| `electron-only` | Wymaga aplikacji pulpitu, ponieważ przeglądarka nie może dotrzeć do tego, co wykorzystuje możliwość. |
