## Cel i zastosowanie {#purpose-and-use-case}

Przekształć wybrany mowę w transkrypcję z oznaczeniem czasu dla napisów i edycji transkrypcji.

## Aktualna dostępność {#current-availability}

Wersje desktopowe mogą pobrać i zweryfikować wymagany silnik sherpa-onnx-node 1.13.5 dla platform macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Zainstaluj ten model i wymagane środowisko wykonawcze w Menedżerze modeli, a następnie uruchom zadanie lokalnie. Są to obsługiwane cele kompilacji; wyniki dla konkretnego pakietu i urządzenia znajdziesz w raporcie z testów nocnych. Dla macOS x64 nie ma silnika do pobrania, mimo że wagi modelu są wymienione dla tej platformy.

## Użyj tego modelu {#use-this-model}

Otwórz **Analiza → Mowa → Transkrypcja i napisy** na platformie z wymaganym natywnym środowiskiem uruchomieniowym. Lokalna pomoc działa w edytorze desktopowym.

1. Wybierz mowę do transkrypcji.
2. Użyj Menedżera Modeli, aby zainstalować ten model. Opcja Narzędzia → Zaawansowana Obsługa Lokalna pozwala wybrać konkretny model rozpoznawania mowy.
3. Uruchom lokalnie, a następnie przejrzyj tekst i czas trwania przed zaakceptowaniem transkrypcji.

Wnioskowanie także potrzebuje wystarczającej ilości wolnej pamięci, a instalacja przestrzeni roboczej; pamięć nie gwarantuje szybkości.

Opublikowane platformy: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Wymagane jest także zgodne środowisko wykonawcze dostępne do pobrania.

W systemie Windows zainstaluj najnowszy obsługiwany [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) zgodny z aplikacją desktopową: **x64** dla kompilacji x64 lub **ARM64** dla kompilacji ARM64.
