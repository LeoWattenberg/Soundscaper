## Cel i zastosowanie {#purpose-and-use-case}

Odczytuj widoczny tekst z próbkowych klatek wideo do przeglądania i indeksowania.

## Aktualna dostępność {#current-availability}

Wersje desktopowe mogą pobrać i zweryfikować wymagany silnik onnxruntime-node 1.29.0 dla platform macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Zainstaluj ten model i wymagane środowisko wykonawcze w Menedżerze modeli, a następnie uruchom zadanie lokalnie. Są to obsługiwane cele kompilacji; wyniki dla konkretnego pakietu i urządzenia znajdziesz w raporcie z testów nocnych. Dla macOS x64 nie ma silnika do pobrania, mimo że wagi modelu są wymienione dla tej platformy.

## Użyj tego modelu {#use-this-model}

Otwórz **Framescaper: Narzędzia → Wyszukiwanie → Indeksuj Wideo** lub **Narzędzia → Zaawansowana Obsługa Lokalna → Rozpoznawanie znaków** na platformie z wymaganym natywnym środowiskiem uruchomieniowym. Lokalna pomoc działa w edytorze desktopowym.

1. Wybierz wideo zawierające czytelny tekst na ekranie.
2. Zainstaluj opcjonalny model PP-OCRv4 mobile za pomocą Menedżera Modeli. Jest to opcjonalny krok w procesie Indeksuj Wideo, który używa również SigLIP2.
3. Uruchom lokalnie i przejrzyj rozpoznany tekst oraz jego lokalizacje klatek przed zaakceptowaniem wyników.

## Pobieranie i wymagania {#download-and-requirements}

Tożsamość modelu: `ppocr-v4-mobile`, wersja **4.0.0**.

Przybliżony rozmiar pobieranego artefaktu modelu: **15.46 MiB**. Wymagane środowisko wykonawcze zostanie dodane do pierwszego pobrania, jeśli nie jest jeszcze zainstalowane. Minimalna pamięć systemowa: **2 GiB**. Wymóg katalogu dotyczy całej pamięci, a nie aktualnie wolnej. Wnioskowanie także potrzebuje wystarczającej ilości wolnej pamięci, a instalacja przestrzeni roboczej; pamięć nie gwarantuje szybkości.

Opublikowane platformy: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Wymagane jest także zgodne środowisko wykonawcze dostępne do pobrania.

W systemie Windows zainstaluj najnowszy obsługiwany [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) zgodny z aplikacją desktopową: **x64** dla kompilacji x64 lub **ARM64** dla kompilacji ARM64. Natywne silniki ONNX i Sherpa wymagają tych bibliotek; pobierane pliki modelu i środowiska wykonawczego ich nie zawierają. Visual Studio nie jest potrzebne do korzystania z aplikacji.

Narzędzia → Menedżer modeli podczas pierwszej instalacji pobiera opublikowane artefakty modelu i wymagane środowisko wykonawcze oraz weryfikuje zapisane skróty SHA-256. Przetwarzanie używa plików zainstalowanych lokalnie. Otwórz Magazyn i weryfikację w Menedżerze modeli, aby sprawdzić powiadomienia, naprawić instalację lub zmienić lokalizację danych.
