## Cel i zastosowanie {#purpose-and-use-case}

Ogranicz pogłos pomieszczenia w nagranej mowie za pomocą lokalnego modelu usuwającego pogłos.

## Dostępność {#current-availability}

Wersje desktopowe mogą pobrać i zweryfikować wymagany silnik onnxruntime-node 1.29.0 dla platform macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Zainstaluj ten model i wymagane środowisko wykonawcze w Menedżerze modeli, a następnie uruchom zadanie lokalnie. Są to obsługiwane cele kompilacji; wyniki dla konkretnego pakietu i urządzenia znajdziesz w raporcie z testów nocnych.

## Korzystanie z modelu {#use-this-model}

W systemie z wymaganym natywnym silnikiem otwórz **Narzędzia → Zaawansowane przetwarzanie lokalne → Usuwanie pogłosu**. Lokalna pomoc działa w edytorze desktopowym.

1. Zaznacz mowę z pogłosem pomieszczenia.
2. Zainstaluj model za pomocą Menedżera modeli i uruchom usuwanie pogłosu.
3. Porównaj wynik z oryginałem i zaakceptuj go tylko wtedy, gdy mowa brzmi lepiej.

## Pobieranie i wymagania {#download-and-requirements}

Identyfikator modelu: `dereverb-room`, wersja **1.0.0**.

Przybliżony rozmiar pobieranego artefaktu modelu: **114.57 MiB**. Wymagane środowisko wykonawcze zostanie dodane do pierwszego pobrania, jeśli nie jest jeszcze zainstalowane. Minimalna pamięć systemowa: **2 GiB**. Wymóg katalogu dotyczy całej pamięci, a nie aktualnie wolnej. Wnioskowanie także potrzebuje wystarczającej ilości wolnej pamięci, a instalacja przestrzeni roboczej; pamięć nie gwarantuje szybkości.

Opublikowane platformy: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Wymagane jest także zgodne środowisko wykonawcze dostępne do pobrania.

W systemie Windows zainstaluj najnowszy obsługiwany [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) zgodny z aplikacją desktopową: **x64** dla kompilacji x64 lub **ARM64** dla kompilacji ARM64. Natywne silniki ONNX i Sherpa wymagają tych bibliotek; pobierane pliki modelu i środowiska wykonawczego ich nie zawierają. Visual Studio nie jest potrzebne do korzystania z aplikacji.
