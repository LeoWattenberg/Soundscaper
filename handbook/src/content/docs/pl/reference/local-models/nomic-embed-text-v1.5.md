## Cel i zastosowanie {#purpose-and-use-case}

Tworzenie lokalnych reprezentacji numerycznych fragmentów transkrypcji i zapytań wyszukiwania do wyszukiwania semantycznego.

## Aktualna dostępność {#current-availability}

Wersje desktopowe mogą pobrać i zweryfikować wymagany silnik onnxruntime-node 1.29.0 dla platform macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Zainstaluj ten model i wymagane środowisko wykonawcze w Menedżerze modeli, a następnie uruchom zadanie lokalnie. Są to obsługiwane cele kompilacji; wyniki dla konkretnego pakietu i urządzenia znajdziesz w raporcie z testów nocnych. Dla macOS x64 nie ma silnika do pobrania, mimo że wagi modelu są wymienione dla tej platformy.

## Użyj tego modelu {#use-this-model}

Otwórz **Narzędzia → Wyszukiwanie → Indeksuj transkrypcję, a następnie Narzędzia → Wyszukiwanie → Wyszukiwanie indeksowane** na platformie z wymaganym natywnym środowiskiem uruchomieniowym. Lokalna pomoc działa w edytorze desktopowym.

1. Utwórz lub zaimportuj transkrypcję, a następnie zainstaluj Nomic Embed Text za pomocą Menedżera modeli.
2. Uruchom Indeksuj transkrypcję, aby przygotować tekst do wyszukiwania semantycznego.
3. Użyj Wyszukiwania indeksowanego i przejrzyj dopasowane fragmenty w kontekście. Zaawansowane przetwarzanie lokalne również udostępnia operację wstawiania.

Wnioskowanie także potrzebuje wystarczającej ilości wolnej pamięci, a instalacja przestrzeni roboczej; pamięć nie gwarantuje szybkości.

Opublikowane platformy: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Wymagane jest także zgodne środowisko wykonawcze dostępne do pobrania.

W systemie Windows zainstaluj najnowszy obsługiwany [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) zgodny z aplikacją desktopową: **x64** dla kompilacji x64 lub **ARM64** dla kompilacji ARM64. ## Przejrzyj wynik {#review-the-result}

- Wektory wstawiania są danymi wyszukiwania numerycznego, a nie przepisanym transkrypcją ani wygenerowaną odpowiedzią.
- Powiązane fragmenty mogą mieć różne rankingi w różnych przebiegach lub nagraniach. Skończone, różne od zera wektory potwierdzają wykonanie, a nie istotność każdego dopasowania.
