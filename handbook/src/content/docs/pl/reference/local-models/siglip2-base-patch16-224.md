## Cel i zastosowanie {#purpose-and-use-case}

Odwzorowuj próbki klatek wideo i tekst we wspólnej przestrzeni liczbowej, aby umożliwić lokalne wyszukiwanie wizualne.

## Dostępność {#current-availability}

Wersje desktopowe mogą pobrać i zweryfikować wymagany silnik onnxruntime-node 1.29.0 dla platform macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Zainstaluj ten model i wymagane środowisko wykonawcze w Menedżerze modeli, a następnie uruchom zadanie lokalnie. Są to obsługiwane cele kompilacji; wyniki dla konkretnego pakietu i urządzenia znajdziesz w raporcie z testów nocnych. Dla macOS x64 nie ma silnika do pobrania, mimo że wagi modelu są wymienione dla tej platformy.

## Użycie modelu {#use-this-model}

Na platformie z wymaganym natywnym środowiskiem uruchomieniowym otwórz **Framescaper: Narzędzia → Wyszukiwanie → Indeksuj wideo**, a następnie **Narzędzia → Wyszukiwanie → Wyszukiwanie indeksowane**. Lokalna pomoc działa w edytorze desktopowym.

1. Wybierz wideo i zainstaluj SigLIP2 za pomocą Menedżera modeli.
2. Uruchom funkcję Indeksuj wideo, aby przeanalizować próbki klatek. Jeśli chcesz użyć opcjonalnego odczytywania tekstu, zainstaluj również PP-OCRv4.
3. Użyj funkcji Wyszukiwanie indeksowane i sprawdź dopasowane momenty wideo, zanim zdecydujesz, jak je wykorzystać.
