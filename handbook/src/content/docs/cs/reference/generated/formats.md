Toto jsou konkrétní formáty registrované aktuálním exportním runtime. Dostupnost produktů pochází z produktových profilů.

„Vestavěný“ znamená, že aplikace má nativní zapisovač pro tento formát. „Vyžaduje se runtime FFmpeg“ je podmíněné: tabulka nezaručuje, že runtime FFmpeg lze načíst v každém sestavení nebo prostředí, ani že libovolný náhradní runtime obsahuje uvedený kódkovač a multiplexor.

Soubory projektu a soubory štítků jsou uvedeny samostatně v [Soubory projektu a štítků](/reference/generated/project-files/).
