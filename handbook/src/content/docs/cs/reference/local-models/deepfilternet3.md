## Účel a případ použití {#purpose-and-use-case}

Snižte pozadí šumu v dialogu pomocí místního modelu vylepšení řeči.

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine onnxruntime-node 1.29.0 pro platformy macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu. Pro macOS x64 není k dispozici engine ke stažení, přestože jsou pro tuto platformu uvedeny váhy modelu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Účinek → Odstranění a oprava šumu → Vylepšit dialog** na platformě s požadovaným nativním runtime. Místní pomoc funguje v desktopovém editoru.

1. Vyberte dialog, který chcete vylepšit.
2. Nainstalujte DeepFilterNet3 prostřednictvím Správce modelů a zvolte Spustit lokálně.
3. Před použitím porovnejte navrhovaný výsledek s původním. Zrušení obnoví přijatý projekt.
