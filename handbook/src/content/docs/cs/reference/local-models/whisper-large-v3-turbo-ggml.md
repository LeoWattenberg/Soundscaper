## Účel a případ použití {#purpose-and-use-case}

Přepisujte vybranou řeč lokálně prostřednictvím zabaleného whisper.cpp runtime. 

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine whisper-cpp v1.9.3 pro platformy macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu. Pro macOS x64 není k dispozici engine ke stažení, přestože jsou pro tuto platformu uvedeny váhy modelu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Analyzovat → Řeč → Přepis a titulky** na platformě s požadovaným nativním runtime. Místní pomoc běží v desktopovém editoru.

1. Vyberte řeč a nainstalujte Whisper large-v3 turbo prostřednictvím Správce modelů.
2. Vyberte tento model rozpoznávání řeči v nabídce Nástroje → Pokročilé místní zpracování, pokud chcete explicitně vybrat Whisper.
3. Spusťte lokálně a zkontrolujte jak text, tak hranice segmentů, než jej přijmete.
