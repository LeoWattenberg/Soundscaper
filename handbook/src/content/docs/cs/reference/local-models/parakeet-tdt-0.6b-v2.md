## Účel a případ použití {#purpose-and-use-case}

Převést vybraný řečový záznam na časovaný přepis pro titulky a úpravu přepisu.

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine sherpa-onnx-node 1.13.5 pro platformy macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu. Pro macOS x64 není k dispozici engine ke stažení, přestože jsou pro tuto platformu uvedeny váhy modelu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Analyzovat → Řeč → Přepisovat & Titulky** na platformě s požadovaným nativním prostředím. Místní pomoc funguje v editoru pro stolní počítače.

1. Vyberte řečový záznam, který chcete přepsat.
2. Nainstalujte tento model pomocí Správce modelů. Nástroj → Pokročilé místní zpracování vám umožní vybrat konkrétní model rozpoznávání řeči.
3. Spusťte lokálně, poté zkontrolujte text a časování, než přijmete přepis.
