Identifikujte tváře a objekty ve vzorkovaných snímcích videa, aby bylo možné navrhnout nové zarámování.

YuNet detekuje tváře a jejich umístění. Operace detekce subjektu kombinuje tyto výsledky s detekcemi objektů D-FINE.

## Aktuální dostupnost {#current-availability}

Verze pro stolní počítače obsahují požadovaný motor onnxruntime-node 1.29.0 pro macOS arm64, Linux arm64, Linux x64, Windows arm64 a Windows x64. Nainstalujte váhy tohoto modelu pomocí Správce modelů a poté spusťte jeho úlohu lokálně. Tyto cíle sestavení jsou podporovány; konzultujte zprávu o nočních testech pro výsledky konkrétního balíčku a počítače. Verze pro stolní počítače neobsahuje tento motor pro macOS x64, i když jsou váhy modelu uvedeny pro tyto platformy.

## Použití tohoto modelu {#use-this-model}

Otevřete **Framescaper: Efekt → Video efekty → Přezarámování** na platformě s požadovaným nativním runtime. Místní pomoc běží v editoru pro stolní počítače.

1. Vyberte video klip v Framescaperu.
2. Nainstalujte YuNet a D-FINE pro detekci subjektu. Úloha řízeného přezerámování také používá detekci salience U²-Net-P.
3. Spusťte lokálně a zkontrolujte navrhovaný oříznutí. Nástroje → Pokročilé místní zpracování mohou spustit detekci subjektu samostatně.

Tato operace také vyžaduje [detekci objektů D-FINE Nano](/reference/local-models/dfine-nano-coco/).
