## Účel a případ použití {#purpose-and-use-case}

Navrhněte kategorie zvukových událostí pro indexování a značkování reakcí.

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine onnxruntime-node 1.29.0 pro platformy macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Nástroje → Pokročilé místní zpracování → Označování zvuku** na platformě s požadovaným nativním runtime. Místní pomoc běží v desktopovém editoru.

1. Vyberte zvuk, který chcete analyzovat.
2. Nainstalujte PANNs prostřednictvím Správce modelů a poté spusťte označování zvuku.
3. Před přijetím značek nebo jejich použitím pro vyhledávání zkontrolujte navrhované štítky a jejich časová rozsahy.

## Stažení a požadavky {#download-and-requirements}

Identita modelu: `panns-cnn10`, verze **1.0.0**.

Přibližná velikost stažení souboru modelu: **24.05 MiB**. Požadované běhové prostředí se přidá k prvnímu stažení, pokud ještě není nainstalováno. Minimální systémová paměť: **2 GiB**. Tento katalogový požadavek se vztahuje na celkovou, nikoli právě volnou paměť. Inference potřebuje také dostatek volné paměti a instalace pracovní prostor; velikost paměti nezaručuje rychlost.

Publikované platformy: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Je také nutné odpovídající běhové prostředí ke stažení.

Ve Windows nainstalujte nejnovější podporovaný [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) odpovídající desktopové aplikaci: **x64** pro sestavení x64 nebo **ARM64** pro sestavení ARM64. Nativní enginy ONNX a Sherpa tyto knihovny potřebují; stažení modelu ani běhového prostředí je neobsahuje. Visual Studio k používání aplikace nepotřebujete.

Nástroje → Správce modelů při první instalaci stáhne publikované soubory modelu a požadované běhové prostředí a ověří jejich zaznamenané kontrolní součty SHA-256.
