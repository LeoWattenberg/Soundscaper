## Účel a případ použití {#purpose-and-use-case}

Najděte řečové oblasti před transkripcí nebo odstraněním dlouhých pauz.

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine sherpa-onnx-node 1.13.5 pro platformy macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu. Pro macOS x64 není k dispozici engine ke stažení, přestože jsou pro tuto platformu uvedeny váhy modelu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Účinek → Odstranění a oprava šumu → Vyčištění výplně a ticha, nebo Analyzovat → Řeč → Transkripce a titulky** na platformě s požadovaným nativním prostředím. Místní pomoc běží v editoru pro pracovní stanice.

1. Vyberte oblast zvuku obsahující řeč a pauzy.
2. Otevřete úlohu a nainstalujte Silero VAD prostřednictvím Správce modelů.
3. Spusťte lokálně a poté zkontrolujte zjištěné oblasti nebo návrhy na vyčištění, než použijete změny.

## Stažení a požadavky {#download-and-requirements}

Identita modelu: `silero-vad-v6`, verze **6.2.1**.

Přibližná velikost stažení souboru modelu: **2.22 MiB**. Požadované běhové prostředí se přidá k prvnímu stažení, pokud ještě není nainstalováno. Minimální systémová paměť: **2 GiB**. Tento katalogový požadavek se vztahuje na celkovou, nikoli právě volnou paměť. Inference potřebuje také dostatek volné paměti a instalace pracovní prostor; velikost paměti nezaručuje rychlost.

Publikované platformy: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Je také nutné odpovídající běhové prostředí ke stažení.

Ve Windows nainstalujte nejnovější podporovaný [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) odpovídající desktopové aplikaci: **x64** pro sestavení x64 nebo **ARM64** pro sestavení ARM64. Nativní enginy ONNX a Sherpa tyto knihovny potřebují; stažení modelu ani běhového prostředí je neobsahuje. Visual Studio k používání aplikace nepotřebujete.

Nástroje → Správce modelů při první instalaci stáhne publikované soubory modelu a požadované běhové prostředí a ověří jejich zaznamenané kontrolní součty SHA-256. Zpracování používá místně nainstalované soubory. Ve Správci modelů otevřete Úložiště a ověření, chcete-li zobrazit oznámení, opravit instalaci nebo změnit umístění úložiště.
