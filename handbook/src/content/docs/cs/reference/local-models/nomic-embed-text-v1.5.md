Vytvářejte místní číselné reprezentace pasáží přepisu a vyhledávacích dotazů pro sémantické vyhledávání.

## Aktuální dostupnost {#current-availability}

Sestavení pro desktop balí požadovaný motor onnxruntime-node 1.29.0 pro macOS arm64, Linux arm64, Linux x64, Windows arm64 a Windows x64. Nainstalujte váhy tohoto modelu prostřednictvím Správce modelů a poté spusťte jeho úlohu lokálně. Toto jsou podporované cíle sestavení; konzultujte zprávu o nočních testech pro výsledky konkrétního balíčku a počítače. Sestavení pro desktop nebalí tento motor pro macOS x64, i když jsou váhy modelu uvedeny pro tyto platformy.

## Použití tohoto modelu {#use-this-model}

Otevřete **Nástroje → Vyhledávání → Indexovat přepis** a poté **Nástroje → Vyhledávání → Indexované vyhledávání** na platformě s požadovaným nativním runtime. Místní pomoc běží v editoru pro desktop.

1. Vytvořte nebo importujte přepis a poté nainstalujte Nomic Embed Text prostřednictvím Správce modelů.
2. Spusťte Indexovat přepis pro přípravu textu na sémantické vyhledávání.
3. Použijte Indexované vyhledávání a prohlédněte si odpovídající pasáže v kontextu. Pokročilé místní zpracování také zpřístupňuje operaci vložení.
