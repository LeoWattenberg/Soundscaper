## Účel a případ použití {#purpose-and-use-case}

Načtěte viditelný text ze vzorkovaných snímků videa pro kontrolu a indexování.

## Aktuální dostupnost {#current-availability}

Desktopové sestavení mohou stáhnout a ověřit požadovaný engine onnxruntime-node 1.29.0 pro platformy macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Nainstalujte tento model a požadované běhové prostředí přes Správce modelů a poté úlohu spusťte místně. Jde o podporované cíle sestavení; výsledky konkrétního balíčku a počítače najdete v nočním testovacím protokolu. Pro macOS x64 není k dispozici engine ke stažení, přestože jsou pro tuto platformu uvedeny váhy modelu.

## Použití tohoto modelu {#use-this-model}

Otevřete **Framescaper: Nástroje → Hledání → Indexovat video, nebo Nástroje → Pokročilé lokální zpracování → Optická rozpoznávání znaků** na platformě s požadovaným nativním runtime. Lokální pomoc běží v editoru pro pracovní stanice.

1. Vyberte video obsahující čitelný text na obrazovce.
2. Nainstalujte PP-OCRv4 mobilní prostřednictvím Správce modelů. Jedná se o volitelný krok Indexovat video, který také používá SigLIP2.
3. Spusťte lokálně a zkontrolujte rozpoznaný text a jeho umístění snímků, než přijmete výsledky.

## Stažení a požadavky {#download-and-requirements}

Identita modelu: `ppocr-v4-mobile`, verze **4.0.0**.

Přibližná velikost stažení souboru modelu: **15.46 MiB**. Požadované běhové prostředí se přidá k prvnímu stažení, pokud ještě není nainstalováno. Minimální systémová paměť: **2 GiB**. Tento katalogový požadavek se vztahuje na celkovou, nikoli právě volnou paměť. Inference potřebuje také dostatek volné paměti a instalace pracovní prostor; velikost paměti nezaručuje rychlost.

Publikované platformy: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Je také nutné odpovídající běhové prostředí ke stažení.

Ve Windows nainstalujte nejnovější podporovaný [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) odpovídající desktopové aplikaci: **x64** pro sestavení x64 nebo **ARM64** pro sestavení ARM64. Nativní enginy ONNX a Sherpa tyto knihovny potřebují; stažení modelu ani běhového prostředí je neobsahuje. Visual Studio k používání aplikace nepotřebujete.

Nástroje → Správce modelů při první instalaci stáhne publikované soubory modelu a požadované běhové prostředí a ověří jejich zaznamenané kontrolní součty SHA-256. Zpracování používá místně nainstalované soubory. Ve Správci modelů otevřete Úložiště a ověření, chcete-li zobrazit oznámení, opravit instalaci nebo změnit umístění úložiště.

## Kontrola výsledku {#review-the-result}

- Malý, rozmazaný, otočený, stylizovaný nebo částečně skrytý text může být přehlédnut nebo špatně přečten.
- Zabalený test vyžaduje textové oblasti, takže detektor, model orientace a rozpoznávač všechny spustí. Nevyžaduje znakovou shodu.
