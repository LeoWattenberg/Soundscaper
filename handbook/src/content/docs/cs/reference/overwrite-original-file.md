V elektronových verzích Soundscaperu a Framescaperu příkaz **Soubor → Přepsat název souboru** exportuje celý upravený projekt do původního importovaného mediálního souboru. Použije nastavení exportu podporovaná původním souborem a uloží jej ihned, aniž otevře dialog exportu nebo výběr souborů. Zvuk zachová zdrojový formát, vzorkovací frekvenci a počet kanálů. Podporované video MP4 a WebM zachová původní kontejner, rozměry a snímkovou frekvenci.

Importujte jeden mediální soubor pomocí **Soubor → Importovat**, proveďte úpravy a zvolte **Soubor → Přepsat název souboru**. Po dalších úpravách můžete postup zopakovat. Výběr času rozsah přepsání neomezuje: vždy se vykreslí celý projekt. Projekt si ponechá importovaná média a historii úprav.

Příkaz není dostupný, pokud projekt nemá podporovaný původní soubor, pokud bylo importováno více původních souborů nebo během importu, nahrávání či zpracování. Verze v prohlížeči používají běžný dialog exportu.

Chcete-li zvolit jiné umístění nebo změnit nastavení výstupu, vyberte v Soundscaperu **Soubor → Exportovat zvuk** nebo ve Framescaperu **Soubor → Exportovat video**. Přepsáním se nahradí obsah původního souboru; pokud potřebujete neupravenou nahrávku, uchovejte samostatnou kopii.
