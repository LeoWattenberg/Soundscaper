Projekty vytvořené v Audacity 3 (.aup3) a Audacity 4 (.aup4) se otevírají přímo. Stopky, klipy, názvy a pozice se přenesou; efekty, které Soundscaper nemá, jsou uvedeny, abyste věděli, co zkontrolovat. Původní soubor se nemění.

:::note[Přecházíte z Audacity?]
To je **Soubor → Otevřít** v Audacity. Názvy níže jsou vlastní názvy Soundscaperu, které se někdy liší.
:::

## Postup

1. Otevřete Soundscaper. Nový, prázdný projekt je připraven hned, jakmile se načte editor.
2. Vyberte **Soubor → Otevřít** a vyberte projekt. Jeho stopky a klipy se zobrazí tak, jak byly v Audacity.
3. Projekt nyní zobrazuje klip s názvem **Audio 1** a stopku s názvem **Fixture track**.
   *Měli byste vidět:* Stopku a klip z projektu Audacity se svými názvy.

## Tipy

- Starší styl projektu `.aup` vyžaduje, aby vedle něj byla složka `_data`; při dotazu vyberte oba.
- **Soubor → Projekty Audacity → Export AUP4** funguje opačně, pro vrácení projektu do Audacity.
