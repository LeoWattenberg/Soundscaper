Inženýr mixu, editor videa nebo spolupracovník na jiném programu obvykle chce části, nikoli mix. Export kmenů vykreslí každou dráhu do vlastního souboru, všechny stejné délky a zarovnané k začátku projektu, a zabalí je do jednoho archivu.

:::note[Přicházíte z Audacity?]
Toto je **Soubor → Export zvuku → Export více, rozdělené podle tratí** v Audacity. Názvy níže jsou vlastní názvy Soundscaperu, které se někdy liší.
:::

## Kroky

1. Otevřete Soundscaper. Nové, prázdné projekt je připravené, jakmile se načte editor.
2. Zvolte **Soubor → Import** a vyberte první stopu. Přistane jako klip na vlastní dráze.
3. Zvolte **Soubor → Import** a vyberte druhou stopu. Přistane jako klip na vlastní dráze.
4. Zvolte **Soubor → Export zvuku**, nastavte **Formát** na **WAV**, nastavte **Výstup** na **Jednotlivé kmeny (rozdělené podle tratí)** a stiskněte **Export**. Soubor se stáhne, jakmile se dokončí vykreslení, a jeho odkaz zůstane v dialogu. Každá dráha se stane WAV uvnitř ZIP, oříznutým na stejnou délku, takže se zarovnají, když budou importovány jinde.

## Tipy

- Tlumení a sólo neovlivňují kmeny; každá dráha je vykreslena.
- Pojmenujte dráhy před exportem – soubory kmenů přebírají jejich názvy.
