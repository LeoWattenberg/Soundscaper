Zvukový inženýr, videoredaktor nebo spolupracovník na jiném programu obvykle chce části, nikoli mix. Export kmenů vykreslí každou dráhu do vlastního souboru, všechny stejné délky a zarovnané k začátku projektu, a zabalí je do jednoho archivu.

:::poznámka[Přicházíte z Audacity?]
Toto je **Soubor → Export zvuku → Export více, rozdělené podle drah** v Audacity. Názvy níže jsou vlastní názvy Soundscaperu, které se někdy liší.
:::

## Kroky

1. Otevřete Soundscaper. Nový prázdný projekt je připraven ihned po načtení editoru.
2. Zvolte **Soubor → Import zvuku** a vyberte první stopu. Soubor přistane jako klip na vlastní dráze.
3. Zvolte **Soubor → Import zvuku** a vyberte druhou stopu. Soubor přistane jako klip na vlastní dráze.
4. Zvolte **Soubor → Export zvuku**, nastavte **Formát** na **WAV**, nastavte **Výstup** na **Jednotlivé kmeny (rozdělené podle drah)**, a stiskněte **Export**. Soubor se stáhne, jakmile se dokončí vykreslení, a jeho odkaz zůstane v dialogu. Každá dráha se stane WAV uvnitř ZIP, oříznutým na stejnou délku, takže se zarovnají, když budou importovány jinde.

## Tipy

- Tlumení a sólo neovlivňují kmeny; každá dráha je vykreslena.
- Pojmenujte dráhy před exportem – soubory kmenů přebírají jejich názvy.
