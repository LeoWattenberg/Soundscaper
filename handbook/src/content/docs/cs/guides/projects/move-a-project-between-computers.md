Knihovna projektů se nachází v jednom prohlížeči na jednom počítači. Pokud chcete projekt přenést jinam — na jiný stroj, kolegovi, na záložní disk — exportujte jej jako soubor projektu. Soubor `.sscape` obsahuje zvuk a všechny úpravy a lze jej otevřít v jakémkoli Soundscaperu.

:::note[Přecházíte z Audacity?]
To je ekvivalent **Soubor → Uložit projekt → Zálohovat projekt, poté Soubor → Otevřít** v Audacity. Názvy níže jsou specifické pro Soundscaper a mohou se lišit.
:::

## Postup

1. Otevřete Soundscaper. Nový, prázdný projekt je připraven hned po načtení editoru.
2. Vyberte **Soubor → Importovat zvuk** a vyberte materiál projektu. Soubor se objeví jako klip na vlastní stopě.
3. Vyberte **Soubor → Exportovat soubor projektu (.sscape)**. Celý projekt se stáhne jako jeden soubor `.sscape`. Soubor si uložte na bezpečné místo; jde o kompletní projekt.
4. Vyberte **Soubor → Otevřít soubor projektu Scape (.sscape)** a vyberte soubor. Na počítači, který projekt ještě nemá, se otevře přímo; zde, kde ho knihovna již obsahuje, Soundscaper nabízí možnost **Otevřít jako kopii pro čtení** — stiskněte ji.
   *Měli byste vidět:* Projekt se otevře se svou stopou a klipem přesně tak, jak byl exportován.

## Tipy

- Kopii pro čtení nelze upravovat, dokud ji neuložíte jako vlastní projekt z nabídky Soubor.
- Soubor je ZIP archiv se zvukem uvnitř; nerozbalujte jej ručně.
