Záznam provedený příliš hlasitě se zploští na horní hranici rozsahu a zkreslí. Poškození je snadno slyšet, ale těžko najít okem v dlouhém záznamu. Nástroj Find Clipping prohledá výběr a vypsuje všechny úseky vzorků, které jsou na plné stupnici, takže si můžete rozhodnout, zda opravit, předělat nebo se s každým z nich smířit.

:::poznámka[Přecházíte z Audacity?]
Toto je **Analyzovat → Najít zkreslení** v Audacity. Názvy níže jsou vlastní pro Soundscaper, které se někdy liší.
:::

## Postup

1. Otevřete Soundscaper. Nový prázdný projekt je připraven ihned po načtení editoru.
2. Zvolte **Soubor → Importovat** a vyberte záznam, který chcete zkontrolovat. Umístí se jako klip na vlastní stopu.
3. Zvolte **Vybrat → Vše vybrat**.
4. Zvolte **Analyzovat → Najít zkreslení**. Otevře se panel **Najít zkreslení**.
   *Měl byste vidět:* Seznam zkreslených úseků, nebo poznámku, že žádné nebyly nalezeny.

## Tipy

- Snížení hlasitosti zkresleného záznamu ho neopraví; zploštělé vrcholy zůstanou zploštělé. **Efekt → Odstranění a oprava šumu → Oprava** může obnovit velmi krátký zkreslený úsek.
- Aby se zkreslení příště vyhnulo, nahrávejte s vrcholy kolem −12 dB a hlasitost zvyšte později.
