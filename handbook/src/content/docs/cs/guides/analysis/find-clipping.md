Nahrávka provedená příliš hlasitě se plochne u horního okraje rozsahu a zkresluje. Poškození je snadno slyšet, ale v dlouhém záběru je obtížné najít pouhým okem. Nástroj Najít zkreslení (Find Clipping) prohledá výběr a vypíše každou sekvenci vzorků, která dosahuje plného rozsahu, takže můžete rozhodnout, zda každou z nich opravíte, znovu nahrajete nebo s ní budete žít.

:::note[Přecházíte z Audacity?]
Tohle je funkce **Analyzovat → Najít zkreslení** v Audacity. Názvy níže jsou specifické pro Soundscaper a mohou se lišit.
:::

## Postup

1. Otevřete Soundscaper. Nový, prázdný projekt je připraven hned po načtení editoru.
2. Vyberte **Soubor → Importovat audio** a vyberte nahrávku, kterou chcete zkontrolovat. Soubor se objeví jako klip na vlastní stopě.
3. Vyberte **Vybrat → Vybrat vše**.
4. Vyberte **Analyzovat → Najít zkreslení**. Otevře se panel **Najít zkreslení**.
   *Měli byste vidět:* Seznam sekvencí se zkreslením, nebo poznámku, že žádné nebyly nalezeny.

## Tipy

- Ztišení nahrávky se zkreslením ji neopraví; zploštělé vrcholy zůstanou zploštělé. **Efekt → Odstranění šumu a oprava → Opravit** může obnovit velmi krátkou sekvenci se zkreslením.
- Aby se vám příště zkreslení vyhnulo, nahrávejte s vrcholy kolem −12 dB a úroveň poté zvýšte.
