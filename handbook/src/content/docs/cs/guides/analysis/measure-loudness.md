Před normalizací nebo exportem je užitečné vědět, kde se nacházíte. Analyzér EBU R 128 měří program tak, jak to dělají streamovací platformy a vysílatelé — integrovaná hlasitost v LUFS, rozsah hlasitosti a skutečný špičkový signál — takže můžete srovnávat s cílovou hodnotou místo odhadování podle měřiče.

:::note[Přecházíte z Audacity?]
To je **Analyzovat → Změřit RMS, nebo měření v Normalizaci hlasitosti** v Audacity. Názvy níže jsou vlastní Soundscaper a někdy se liší.
:::

## Postup

1. Otevřete Soundscaper. Nový, prázdný projekt je připraven hned po načtení editoru.
2. Vyberte **Soubor → Importovat audio** a vyberte mix, který chcete změřit. Soubor se objeví jako klip na vlastní stopě.
3. Vyberte **Vybrat → Vybrat vše**.
4. Vyberte **Analyzovat → EBU R 128**. Otevře se panel **EBU R 128**.
   *Měli byste vidět:* Integrovanou hlasitost, rozsah hlasitosti a skutečný špičkový signál pro výběr.

## Tipy

- Platformy pro podcasty obvykle požadují −16 LUFS stereo nebo −19 LUFS mono se skutečnými špičkami pod −1 dBTP; zkontrolujte vlastní pokyny platformy.
- Pokud jsou hodnoty daleko od cíle, spusťte [Normalizaci hlasitosti](/guides/volume/normalize-loudness-for-podcasts/) a změřte znovu.
