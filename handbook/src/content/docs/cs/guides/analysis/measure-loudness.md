Než začnete normalizovat nebo exportovat, je užitečné vědět, kde se nacházíte. Analyzátor EBU R 128 měří program způsobem, jakým to dělají streamovací platformy a vysílači – integrovaná hlasitost v LUFS, rozsah hlasitosti a skutečný vrchol – takže můžete porovnat s cílovou hodnotou, namísto hádání z měřiče.

:::poznámka[Přecházíte z Audacity?]
Toto je **Analýza → Měření RMS, nebo Normalizace hlasitosti** v Audacity. Názvy níže jsou vlastní pro Soundscaper, které se někdy liší.
:::

## Kroky

1. Otevřete Soundscaper. Nové, prázdné projekt se připraví, jakmile se načte editor.
2. Zvolte **Soubor → Importovat** a vyberte mix, který chcete změřit. Umístí se jako klip na vlastní stopu.
3. Zvolte **Vybrat → Vybrat vše**.
4. Zvolte **Analýza → EBU R 128**. Otevře se panel **EBU R 128**.
   *Měli byste vidět:* Integrovanou hlasitost, rozsah hlasitosti a skutečný vrchol pro vybraný úsek.

## Tipy

- Podcastové platformy obvykle požadují −16 LUFS stereo nebo −19 LUFS mono se skutečnými vrcholy pod −1 dBTP; zkontrolujte pokyny samotné platformy.
- Pokud jsou čísla daleko od cíle, spusťte [Normalizaci hlasitosti](/guides/volume/normalize-loudness-for-podcasts/) a změříte znovu.
