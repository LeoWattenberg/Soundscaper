## 1. ייבוא וידאו

בחר ב- **קובץ → ייבוא** ובחר בווידאו נתמך. הווידאו המיובא והקול המופק ממנו נכנסים ל-Project Bin כפריט מדיה אחד וממוקמים בדרך כלל במסלולים מקושרים סמוכים.

הווידאו המקורי מאוחסן כמדיה של הפרויקט. פוסטרים ותמונות סרט הם תצוגות מקדימות הניתנות להחלפה וניתן ליצור אותן מחדש.

## 2. סקירת מקור ורצף

השתמש ב-Source Monitor כדי לבדוק את החומר לפני מיקומו או התאמתו. השתמש ב-Video Preview כדי לבדוק את הרצף המורכב.

עריכות תמונה וקול מקושרות מזיזות, מחלקות, מקצרות וממתחות יחד אלא אם תנתק אותן במפורש. נגן על כל עריכה כדי לאמת הן את התמונה והן את הקול.

## 3. סידור וסיום

השתמש בפקודות עריכת ציר הזמן עבור גזירות ותנועות רגילות. Framescaper גם חושף אפקטים וידאו, גאומטריה, קומפוזיציה, רצפים מקוננים ופקודות רב-מצלמה כאשר הבחירה הנוכחית תומכת בהם.

שמור את הפרויקט המקומי, ואז המשך ל-[ייצוא וידאו](/framescaper/video-export/).
