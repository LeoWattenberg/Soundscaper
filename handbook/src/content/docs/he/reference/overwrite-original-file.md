בגרסאות Electron של Soundscaper ושל Framescaper, הפקודה **קובץ → החלפת שם הקובץ** מייצאת את הפרויקט הערוך במלואו אל קובץ המדיה שיובא במקור. היא משתמשת בהגדרות הייצוא שבהן הקובץ המקורי תומך ושומרת מיד, בלי לפתוח את תיבת הדו־שיח לייצוא או בוחר קבצים. האודיו שומר על הפורמט, קצב הדגימה ומספר הערוצים של המקור. סרטוני MP4 ו-WebM נתמכים שומרים על המכולה, המידות וקצב הפריימים של המקור.

ייבאו קובץ מדיה אחד דרך **קובץ → ייבוא**, בצעו את העריכות ובחרו **קובץ → החלפת שם הקובץ**. אפשר לחזור על הפעולה לאחר עריכות נוספות. בחירת טווח זמן אינה מגבילה את ההחלפה: הפרויקט כולו עובר רינדור בכל פעם. הפרויקט שומר את המדיה שיובאה ואת היסטוריית העריכה.

הפקודה אינה זמינה אם אין בפרויקט קובץ מקור נתמך, אם יובאו כמה קובצי מקור, או בזמן ייבוא, הקלטה או עיבוד. בגרסאות הדפדפן משתמשים בתיבת הדו־שיח הרגילה לייצוא.

בחרו **קובץ → ייצוא אודיו** ב-Soundscaper או **קובץ → ייצוא וידאו** ב-Framescaper אם ברצונכם לבחור יעד אחר או לשנות את הגדרות המסירה. ההחלפה מחליפה את תוכן הקובץ המקורי; שמרו עותק נפרד אם דרושה לכם ההקלטה ללא עריכה.
