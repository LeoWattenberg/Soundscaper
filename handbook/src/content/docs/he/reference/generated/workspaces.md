פתחו חלוניות אופציונליות מתוך **חלון**. **שעון**, **מד עוצמת השמע בהשמעה** ומד **מד עוצמת השמע בהקלטה** של Soundscaper מוסתרים בתחילה. בחרו **ניתוק קוד זמן** בתפריט קוד הזמן של סרגל הכלים כדי להעביר את התצוגה לחלונית השעון; **החזרה לסרגל הכלים** בתפריט השעון מחזירה אותה.

פתחו **חלון > מאפייני קטע** כדי לבדוק את בחירת הקליפים הנוכחית לצד ציר הזמן. החלונית עוקבת אחר הבחירה ומתעדכנת כשהקליפים משתנים. כשנבחרו כמה קליפים, בחרו בכרטיסייה של קליפ כדי לערוך את מאפייניו. החלונית מוסתרת בתחילה ותומכת בעגינה, בכרטיסיות משותפות ובשינוי גודל.

השתמשו ב**תפריט החלונית** כדי להעביר אותה שמאלה, ימינה, למעלה, למטה או לחלון צף. לשיתוף מסגרת, בחרו **סידור חלונית**, חלונית יעד ואז **ככרטיסייה**. הכרטיסיות חולקות את המסגרת המלאה ורק חלונית אחת מוצגת בכל פעם. גררו את ידית החלונית לשליש האמצעי של חלונית אחרת כדי ליצור כרטיסיות; השליש הראשון או האחרון מציב אותה לפני המסגרת או אחריה.

שנו גודל של עגינה צדדית באמצעות גרירת הקצה הפנימי שלה; בעגינה עליונה או תחתונה גררו את הקצה שליד ציר הזמן. חלוניות צפות משתנות מהקצוות הימני והתחתון. השעון מגדיל את קוד הזמן כדי להתאים למסגרת, ומדי העוצמה מרחיבים את הסרגלים כדי שיהיו קריאים מרחוק.
