## היכן שיכולה לרוץ יכולת

יכולות מקובצות לפי מה שהן דורשות מהפלטפורמה. ראה [יכולות מוצר](/reference/generated/product-capabilities/) עבור יכולות שכל מוצר מפעיל.

| שכבה | המשמעות |
| --- | --- |
| `web-core` | פועל בכל דפדפן נתמך, ללא תכונה אופציונלית של הפלטפורמה הנדרשת. |
| `web-enhanced` | פועל בדפדפן שמספק את תכונות האחסון והמדיה החדשות שהכישרון זקוק להן. |
| `electron-enhanced` | פועל בדפדפן, והיישום השולחני עושה יותר איתו. |
| `electron-only` | דורש את היישום השולחני, מכיוון שדפדפן לא יכול להגיע למה שהכישרון משתמש בו. |
