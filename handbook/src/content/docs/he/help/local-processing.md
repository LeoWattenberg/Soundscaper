סיוע מקומי פועל במכשיר שלך בעורכי שולחן העבודה Soundscaper ו-Framescaper. בחר מדיה, ואז בחר את המשימה מהתפריט שלה. התיבה הדו-שיחית מציגה את הבחירה, הגדרות המשימה, והאם הדגמים שלה מותקנים.

חבילות שולחן העבודה אינן כוללות את מנועי העיבוד המקוריים האופציונליים או את משקלי המודלים. התקינו מודל דרך מנהל המודלים כדי להוריד את המנוע והמשקלים הדרושים לו, ואז הפעילו את המשימה על המדיה שבחרתם. ההתקנה הראשונה דורשת חיבור לרשת; עיבוד מאוחר יותר מתבצע מקומית. עיינו במדריך של כל מודל לפלטפורמות נתמכות, לפריט התפריט ולדרישות.

לעיון נוסף, עיינו ב [מדריכי מודלים](/reference/local-models/).

## מציאת משימה {#find-a-task}

| תפריט | משימות |
| --- | --- |
| אפקט → הסרת רעש ותיקון | שיפור דיאלוג, הפחתת ריברב, ניקוי מילוי ושקט |
| אפקט → הפרדת מקורות | הפרדת דיאלוג / מוזיקה / אפקטים |
| ניתוח → דיבור | תמלול וכתוביות, זיהוי דוברים, סימון תגובות |
| ניתוח → מוזיקה | זיהוי פעימות ומהירות |
| ניתוח → וידאו | סימון חיתוכים |
| אפקט → אפקטים בווידאו | עיצוב מחדש |
| עריכה | יצירת קטעים בולטים |
| יצירה | יצירת טקסט עריכה |
| כלים → חיפוש | חיפוש ממוין, אינדקס תמליל, אינדקס וידאו |

משימות וידאו שייכות ל-Framescaper. הפקודות הזמינות תלויות בסביבת הריצה של שולחן העבודה וביכולות המוצר. אפשרות התפריט האלפביתית של אפקטים ב-Soundscaper גם מסדרת את אפקטי העיבוד המקומיים לפי שם.

בחר **הפעל מקומית** כדי להתחיל בעיבוד ולהגיב לבקשת ההסכמה המקומית. ניתן לבטל בזמן העיבוד. בחר **סקור תוצאה**, בחר את התוצאות הרצויות, ואז בחר **החל את הנבחר**. עריכות פרויקט מקובלות ניתן לבטל. סגירת משימה לא מפעילה את הצעותיה.

**כלים → עיבוד מקומי מתקדם** שומר על בחירת הפעולות והדגמים. פרטים טכניים בתיבות דו-שיח של משימות מציגים את השלבים הבסיסיים ואת ההגדרות המדויקות לפי הצורך.

## ניהול דגמים {#manage-models}

פתח **כלים → מנהל דגמים**, או השתמש ב**ניהול דגמים** בתוך משימה. הקישור של המשימה מסנן את הרשימה לזהויות דגם תואמות; **הצג את כל הדגמים** מסיר את המגבלה הזו. חפש לפי שם או משימה וסנן לפי מצב ההתקנה.

התקינו מודלים במפורש. ההתקנה הראשונה מורידה גם סביבת ריצה מקורית משותפת שחסרה ונדרשת למודל. ההורדות מציגות התקדמות וניתן לבטל אותן. בחזרה למשימה, ההגדרות שלה נשמרות וזמינות המודלים מתעדכנת; העיבוד אינו מתחיל. הרחיבו את **אחסון ואימות** לתיקון, ניקוי, העברת אחסון, הודעות רישוי והתקנה לא מקוונת מתיקייה. מודל שהותקן מקבצים לא מקוונים עדיין זקוק לסביבת הריצה התואמת לפני השימוש הראשון.

עיין במדריכים של כל דגם [כאן](/reference/local-models/) עבור מטרת כל דגם שפורסם, כניסת התפריט, גודל ההורדה, דרישות, מגבלות, ובדיקות ההסקה האמיתיות שמבצע חבילת שולחן העבודה היומית-עם-בדיקות.

## ניהול תוספים ומכשירים {#manage-plugins-and-devices}

**אפקט → מנהל תוספים** מציג את תוספי האודיו ב-Soundscaper ואת תוספי OpenFX ב-Framescaper. חפש או סנן את הרשימה, ואז בחר תוסף עבור גרסתו, הרשאותיו, ובקרות ההחלמה שלו. **סריקה והגדרות** מכיל הגדרות גילוי.

השתמש בתוספי אודיו באמצעות **אפקט → תוספי אודיו**. הפקודות להוספת/עריכת אפקטים בווידאו של Framescaper נותרות תחת **אפקט → אפקטים בווידאו**.

פתח **עריכה → העדפות → הגדרות אודיו** עבור הגדרות מכשירי אודיו מקומיים ובקרות עזר. **מדיה** מכיל הגדרות מדיה מקומיות; **אפקטים** מקשר למנהל התוספים ומכיל את מתג גילוי התוספים. הרשאות תוספים והחלמת סגר עדיין דורשות פעולות מפורשות.
