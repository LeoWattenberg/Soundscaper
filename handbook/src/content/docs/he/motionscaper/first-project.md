## יצירה והוספת שכבה {#create-and-add-a-layer}

1. יש לבחור **קובץ ← קומפוזיציה חדשה** ולהזין כותרת, מידות, קצב פריימים
   ומשך בפריימים.
2. יש לבחור **שכבה ← טקסט חדש** או **שכבה ← צבע אחיד חדש**. יש לבחור את קומפוזיציית
   היעד כאשר המיזם מכיל כמה קומפוזיציות.
3. יש לפתוח **שכבה ← טקסט ומראה** כדי לערוך שכבת טקסט קיימת או
   מילויים וקווי מתאר של צורה. גופנים שיובאו כאן נשמרים עם המיזם.

יש להשתמש ב־**קובץ ← ייבא מדיה** למקורות תמונה, וידאו או שמע. ייבוא שחורג
ממגבלות המפענח או הזיכרון הנוכחיות נדחה עם הסבר;
קובץ המקור נשאר ללא שינוי.

## הנפשה ותצוגה מקדימה {#animate-and-preview}

יש לפתוח **שכבה ← מאפיינים ופריימי מפתח** כדי לבחור מאפיין שכבה ולהוסיף
מפתחות במיקומי פריים מדויקים. פקדי עקומה משנים אינטרפולציה; עריכה
מרחבית משנה נתיבי מיקום. **תצוגה ← ציר הזמן** פותח פקדים לתזמון שכבות,
לסדר, לקיבוץ ולאזור העבודה.

יש לפתוח **תצוגה ← קנבס הקומפוזיציה** כדי לבחור ולהזיז שכבת 2D קבועה.
הריבוע משנה את קנה המידה והעיגול מסובב סביב העוגן שהוגדר. כל
גרירה שהושלמה היא צעד ביטול־ביצוע אחד; Escape מבטל גרירה. התמרות מונפשות
או מונעות ביטוי נשארות במאפיינים ופריימי מפתח.

יש לפתוח **תצוגה ← תצוגה מקדימה של הקומפוזיציה** כדי לדלג לזמן או לנגן את הקומפוזיציה. התצוגה המקדימה
משתמשת במדיית המקור השמורה. הגדרות סצנה שאינן נתמכות או אינן תקינות מפיקות
שגיאה במקום תמונה חלופית. יש לסגור את התצוגה המקדימה כדי לשחרר את משאבי
הרינדור הפעילים שלה.

## שמירת עותק נייד {#save-a-portable-copy}

יש לבחור **קובץ ← שמור** כדי לפרסם את הגרסה הנוכחית ואז **קובץ ← שמור עותק**
כדי להוריד ארכיון `.mscape`. הארכיון כולל את המיזם ואת המדיה
המקורית הדרושה לפתיחתו מחדש. ניתן לפתוח אותו דרך **קובץ ← פתח** במכשיר אחר או
מספריית דפדפן חדשה.

## רינדור {#render}

יש לבחור **קובץ ← רנדר**. יש לבחור קומפוזיציה, פורמט פלט
וטווח פריימים. פריים הסיום אינו נכלל: פריימים 0 עד 29 משתמשים בטווח
`0` עד `30`. אזור עבודה שברי בוחר את זמני הדגימה השלמים הכלולים בו;
יש לשנות אזור ללא דגימות פלט לפני רינדור.

יש להשתמש ב־**רצף PNG שקוף (.tar)** לאלפא. יש לחלץ את ארכיון TAR כדי
לקבל תמונות PNG רגילות ומטא־נתוני תזמון. MP4 ו־WebM משתמשים בצבע
הרקע שנבחר בתיבה. הרינדור מקבע את הגרסה שנשלחה, כך שעריכות
מאוחרות אינן משנות פלט שכבר מתבצע. סגירת תיבת הרינדור
משאירה את המשימה פעילה. **קובץ ← תור רינדור** מציג התקדמות, ביטול,
ניסיון חוזר של הגרסה שנשלחה והורדות שהושלמו. סגירת העורך
מבטלת משימות שלא הושלמו.
