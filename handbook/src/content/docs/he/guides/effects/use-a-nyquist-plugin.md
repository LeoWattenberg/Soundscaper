תוספי Nyquist של Audacity הם סקריפטים קטנים שמוסיפים אפקטים, מחוללי צלילים ומנתחים. Soundscaper כולל את התוספים שמחייבים בחירה בתפריט משנה של Nyquist. התוסף Adjustable Fade מאפשר לעצב את הדעיכה בכניסה או ביציאה של ההקלטה.

:::note[מגיעים מ-Audacity?]
זהו אפקט **Effect → Adjustable Fade (a Nyquist plug-in)** של Audacity. השמות להלן הם של Soundscaper, ולעיתים הם שונים.
:::

## צעדים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד לאחר שהעורך נטען.
2. בחרו **File → Import audio** ובחרו את ההקלטה שבה תרצו לנסות את התוסף. הקובץ יופיע כקליפ בערוץ נפרד.
3. בחרו **Select → Select all**.
4. בחרו **Effect → Nyquist → Adjustable Fade**. בחלון **Adjustable Fade**, הגדירו את **Mid-fade Adjust (%)** ל-`25`, ואז לחצו **Apply**. ערך חיובי מעגל את צורת הדעיכה. בתיבות הדו־שיח של Nyquist משתמשים ב-**Apply** ולא ב-Apply to selection.
5. לחצו **Play** להאזנה, ואז **Stop**.
   *מה אמור להופיע:* ההקלטה דועכת בהדרגה פנימה.

## טיפים

- לתפריטי Generate ו-Analyze יש תפריטי משנה של Nyquist משלהם, עם תוספים כמו Pluck ו-Beat Finder.
- **Tools → Nyquist prompt** מריץ סקריפט שאתם כותבים בעצמכם.
- ל-Delay, למסנני high-pass ו-low-pass, ל-Noise gate, ל-Notch filter, ל-Shelf filter, ל-Tremolo ול-Vocoder יש אפקטים רגילים בקטגוריות המתאימות בתפריט Effect, ואפשר להשתמש בהם ב[מארזי אפקטים בזמן אמת](/guides/effects/add-a-realtime-effect-to-a-track/).
