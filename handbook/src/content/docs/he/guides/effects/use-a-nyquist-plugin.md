תוספי Nyquist של Audacity הם סקריפטים קטנים המוסיפים אפקטים, מחוללי קול ומנתחי קול, ו-Soundscaper כולל את אותם תוספים תחת תפריט משנה של Nyquist בכל תפריט. Tremolo הוא תוסף ראשון מצוין: הוא גורם לעוצמת הקול לרעוד בקצב קבוע.

:::note[מגיעים מ-Audacity?]
זהו אפקט **Effect → Tremolo (תוסף Nyquist)** של Audacity. השמות להלן הם של Soundscaper, והם עשויים להיות שונים לעיתים.
:::

## צעדים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד לאחר שהעורך נטען.
2. בחרו **File → Import audio** ובחרו את ההקלטה שבה תרצו לנסות את התוסף. הקובץ יופיע כקליפ בערוץ נפרד.
3. בחרו **Select → Select all**.
4. בחרו **Effect → Nyquist → Tremolo**. בחלון הדיאלוג **Tremolo**, הגדירו את **Frequency (Hz)** ל-`6`, ואז לחצו **Apply**. שישה רעידות בשנייה הן אפקט tremolo קלאסי של מגבר. חלונות הדיאלוג של Nyquist משתמשים ב-**Apply** ולא ב-Apply to selection.
5. לחצו **Play** להאזנה, ואז **Stop**.
   *מה שתראו:* ההקלטה פועמת בעוצמה.

## טיפים

- לתפריטי Generate ו-Analyze יש תפריטי משנה של Nyquist משלהם, עם תוספים כמו Pluck ו-Beat Finder.
- **Tools → Nyquist prompt** מריץ סקריפט שאתם כותבים בעצמכם.
