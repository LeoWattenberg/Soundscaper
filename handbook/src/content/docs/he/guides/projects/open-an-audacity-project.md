## למה המדריך הזה מיועד {#what-this-guide-is-for}

אפשר לפתוח ישירות פרויקטים שנוצרו ב-Audacity. המסלולים, הקליפים, השמות והמיקומים נשמרים; אפקטים שאינם קיימים ב-Soundscaper מופיעים ברשימה כדי שתדעו לבדוק אותם. הקובץ המקורי נשאר ללא שינוי.

:::note[מגיעים מ-Audacity?]
זהו הפקוד **File → Open** של Audacity. השמות להלן הם של Soundscaper, והם עשויים להיות שונים לעיתים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן כשהעורך נטען.
2. בחר **File → Audacity projects → Open Audacity project (.aup3, .aup4)** ובחר את הפרויקט. המסלולים והקליפים שלו מופיעים כפי שהיו ב-Audacity.
3. הפרויקט מציג כעת קליפ בשם **Audio 1** ומסלול בשם **Fixture track**.
   *מה שצריך להופיע:* המסלול והקליפ מפרויקט Audacity, יחד עם שמותיהם.

## טיפים

- פרויקט בסגנון ישן `.aup` דורש את תיקיית `_data` לצדו; בחר בשניהם כשנשאל.
- **File → Audacity projects → Export AUP4** פועל בכיוון ההפוך, להחזרת פרויקט ל-Audacity.
