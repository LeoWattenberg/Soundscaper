מהנדס מיקס, עורך וידאו או משתף פעולה בתוכנית אחרת בדרך כלל רוצה את החלקים, לא את המיקס. ייצוא סטמס מייצא כל מסלול לקובץ נפרד, באותו אורך ומתוזמן לתחילת הפרויקט, ומארז אותם בארכיון אחד.

:::note[מגיע מ-Audacity?]
זהו **קובץ → ייצוא אודיו → ייצוא מרובה, חלוקה לפי מסלולים** של Audacity. השמות למטה הם של Soundscaper, שלפעמים שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **קובץ → ייבוא אודיו** ובחר את המסלול הראשון. הקובץ נוחת כקליפ במסלול שלו.
3. בחר **קובץ → ייבוא אודיו** ובחר את המסלול השני. הקובץ נוחת כקליפ במסלול שלו.
4. בחר **קובץ → ייצוא אודיו**, קבע את **פורמט** ל-**WAV**, קבע את **פלט** ל-**סטמס בודדים (חלוקה לפי מסלולים)**, ולחץ על **ייצוא**. הקובץ יורד ברגע שהעיבוד מסתיים, וקישור אליו נשאר בדיאלוג. כל מסלול הופך ל-WAV בתוך ה-ZIP, מקוצץ לאותו אורך כך שהם מתיישרים כאשר מיובאים במקום אחר.

## טיפים

- השתקה וסולו אינם משפיעים על הסטמס; כל מסלול מופק.
- תן שם למסלולים לפני הייצוא — קבצי הסטמס לוקחים את שמותיהם מהם.
