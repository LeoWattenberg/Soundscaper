מהנדס מיקס, עורך וידאו או משתף פעולה בתוכנית אחרת בדרך כלל רוצה את החלקים, לא את המיקס. ייצוא סטים מייצא כל מסלול לקובץ נפרד, באותו אורך ומתוזמן להתחלת הפרויקט, ומארז אותם בארכיון אחד.

:::note[מגיע מ-Audacity?]
זהו **קובץ → ייצוא אודיו → ייצוא מרובה, פיצול לפי מסלולים** של Audacity. השמות למטה הם של Soundscaper, שיכולים להיות שונים לפעמים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **קובץ → ייבוא** ובחר את המסלול הראשון. הוא נוחת כקליפ במסלול שלו.
3. בחר **קובץ → ייבוא** ובחר את המסלול השני. הוא נוחת כקליפ במסלול שלו.
4. בחר **קובץ → ייצוא אודיו**, הגדר את **פורמט** ל-**WAV**, הגדר את **פלט** ל-**סטים בודדים (פיצול לפי מסלולים)**, ולחץ על **ייצוא**. הקובץ הורד ברגע שההדמיה מסתיימת, וקישורו נשאר בדיאלוג. כל מסלול הופך ל-WAV בתוך ה-ZIP, מעוצב לאותו אורך כך שהם מתיישרים כאשר מיובאים במקום אחר.

## טיפים

- השתקה וסולו אינם משפיעים על הסטים; כל מסלול מודגם.
- תן שם למסלולים לפני הייצוא — קבצי הסט לוקחים את שמותיהם מהם.
