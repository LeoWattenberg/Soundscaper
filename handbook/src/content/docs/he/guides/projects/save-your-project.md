פרויקט הוא יותר מאשר האודיו: הוא כולל את המסלולים, הקליפים, האפקטים, הסימניות וההיסטוריה. שמירה שומרת את כל אלה בספריית הפרויקטים המקומית של הדפדפן במחשב זה, שם ניתן לפתוח אותם מחדש מתפריט הקובץ. Soundscaper שומר גם במהלך העבודה, ולכן שמירה ידנית היא בעיקר דרך לוודא.

:::note[מגיעים מ-Audacity?]
זהו **File → Save Project** של Audacity. השמות להלן הם של Soundscaper, והם לעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחרו **File → Import audio** ובחרו משהו לעבוד עליו. הקובץ ייחתם כקליפ במסלול משלו.
3. בחרו **File → Save project**. אינדיקטור השמירה בשורת המצב מראה שהפרויקט נשמר.

## טיפים

- כדי להעביר פרויקט למחשב אחר או לשמור עותק מחוץ לדפדפן, ראו [העברת פרויקט בין מחשבים](/guides/projects/move-a-project-between-computers/).
- ייצוא אודיו הוא עותק להאזנה, לא פרויקט. שמרו את הפרויקט אם ייתכן שתעריכו שוב.
