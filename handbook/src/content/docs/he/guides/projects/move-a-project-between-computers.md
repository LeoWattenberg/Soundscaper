הספרייה של הפרויקט קיימת בדפדפן אחד במחשב אחד. כדי לשאת את הפרויקט למקום אחר - מכונה אחרת, עמית, כונן גיבוי - יש לייצא אותו כקובץ פרויקט. קובץ `.sscape` מכיל את האודיו וכל העריכה, וניתן לפתוח אותו בכל Soundscaper.

:::note[מגיעים מ-Audacity?]
זהו **קובץ → שמור פרויקט → גיבוי פרויקט, ואז קובץ → פתח** ב-Audacity. השמות למטה הם של Soundscaper, אשר לפעמים שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **קובץ → יבוא** ובחר את חומר הפרויקט. הוא נוחת כקליפ על מסלול משלו.
3. בחר **קובץ → ייצוא קובץ פרויקט (.sscape)**. כל הפרויקט מורד כקובץ `.sscape` אחד. שמור את הקובץ במקום בטוח; זהו הפרויקט המלא.
4. בחר **קובץ → פתח** ובחר את הקובץ. במחשב שאינו מכיל את הפרויקט עדיין הוא נפתח ישירות; כאן, שבו הספרייה כבר מחזיקה אותו, Soundscaper מציע **פתח כעותק רק לקריאה** - לחץ עליו.
   *צריך לראות:* הפרויקט נפתח עם המסלול והקליפ בדיוק כפי שיוצא.

## טיפים

- עותק רק לקריאה לא ניתן לעריכה עד שתשמור אותו כפרויקט משלו מהתפריט קובץ.
- הקובץ הוא ארכיון ZIP עם האודיו בפנים; אל תפרק אותו ידנית.
