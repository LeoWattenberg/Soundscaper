ספריית הפרויקט נמצאת בדפדפן אחד במחשב אחד. כדי להעביר פרויקט לכל מקום אחר — מחשב אחר, עמית, כונן גיבוי — יש לייצא אותו כקובץ פרויקט. קובץ `.sscape` מכיל את הקול וכל העריכות, ונפתח בכל Soundscaper.

:::note[מגיעים מ-Audacity?]
זהו **File → Save Project → Backup Project, ואז File → Open** של Audacity. השמות להלן הם של Soundscaper, והם לעיתים שונים.
:::

## צעדים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **File → Import audio** ובחרו את חומרי הפרויקט. הקובץ ייחתם כקליפ על מסלול נפרד.
3. בחרו **File → Export project file (.sscape)**. כל הפרויקט יורד כקובץ `.sscape` אחד. שמרו את הקובץ במקום בטוח; הוא הפרויקט המלא.
4. בחרו **File → Open Scape project file (.sscape)** ובחרו את הקובץ. במחשב שאין בו עדיין את הפרויקט הוא ייפתח ישירות; כאן, שם הספרייה כבר מכילה אותו, Soundscaper מציע **Open as read-only copy** — לחצו עליו.
   *מה שצריך להיראות:* הפרויקט נפתח עם המסלול והקליפ בדיוק כפי שיוצאו.

## טיפים

- העתקת-קריאה-בלבד אינה ניתנת לעריכה עד שתשמרו אותה כפרויקט עצמאי מתפריט File.
- הקובץ הוא ארכיון ZIP עם הקול בתוכו; אל תפרקו אותו ידנית.
