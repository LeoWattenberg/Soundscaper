לוח Freesound מאפשר למצוא צלילים בלי לצאת מ-Soundscaper. חפשו את הצליל שאתם צריכים, בדקו את שם היוצר ואת הרישיון המוצגים לצד כל תוצאה, והוסיפו את הצליל במקום הרצוי בציר הזמן. Soundscaper מייבא את גרסת התצוגה המקדימה באיכות הגבוהה כקליפ בפרויקט.

:::note[עוברים מ-Audacity?]
הפעולה המקבילה ב-Audacity היא **File → Import → Audio**, לאחר הורדת צליל מ-Freesound. שמות הפקודות של Soundscaper מופיעים בהמשך וייתכן שהם שונים.
:::

## שלבים

1. פתחו את Soundscaper. עם טעינת העורך מוכן פרויקט חדש וריק.
2. בחרו **View → Panels → Freesound**.
3. בלוח **Freesound**, הקלידו בשדה **Search Freesound** מילה או ביטוי שמתארים את הצליל המבוקש, ולחצו על **Search**. הצלילים התואמים יופיעו בתוצאות של **Freesound results**.
4. ליד התוצאה הרצויה, לחצו על **Insert at playhead**. הצליל יופיע כקליפ בנקודת ההפעלה.
5. כעת מופיע בפרויקט קליפ אחד.
   *מה אמור להופיע:* הצליל המיובא בציר הזמן, מוכן לעריכה יחד עם שאר הפרויקט.

## טיפים

- לפני שימוש בצליל בפרסום או בתוכן שאתם משתפים, בדקו את שם היוצר ואת פרטי הרישיון שלצד התוצאה.
- **Insert at playhead** מוסיף את הצליל לציר הזמן. הזיזו תחילה את נקודת ההפעלה אם ברצונכם שהקליפ יתחיל מאוחר יותר.
