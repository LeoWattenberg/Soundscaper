קליפ שנרשם בתדר 44.1 kHz ימשיך להשמיע נכון בפרויקט של 48 kHz — Soundscaper מבצע המרה בזמן אמת — אך עבור אספקה שחייבת להיות בתדר אחד, או לפני אפקט שמצפה לתדר זה, ניתן להמיר את הקליפ עצמו. Resampling מחשב מחדש את כל הדגימה (sample) בתדר החדש ושומר על הטיימינג בדיוק.

:::note[מגיעים מ-Audacity?]
זהו הפעולה **Tracks → Resample** ב-Audacity. השמות להלן הם של Soundscaper, והם לעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **File → Import audio** ובחרו את הקליפ בתדר הלא נכון. הקובץ ייחתם כקליפ על מסלול משלו.
3. פתחו את תפריט הקליפ דרך כפתור **Clip menu** על פס השם שלו ובחרו **Clip properties**. לחצו **Resample**, הגדירו את התדר ל-`44100` ולחצו **Resample** שוב. תכונות הקליפ מציגות את התדר הנוכחי שלו; 44100 Hz הוא התקן CD.
4. לחצו **Play** להאזנה, ואז **Stop**.
   *מה שצריך להיראות:* הקליפ נשמע בדיוק כמו קודם; רק התדר השמור השתנה.

## טיפים

- Resampling הוא עריכה וניתן לבטל אותו.
- ירידה בתדר מוותרת על התדרים הגבוהים ביותר; עלייה בתדר לא מוסיפה דבר אך היא חסרת נזק.
