גל קול מציג כמה רועש קול לאורך זמן; ספקטרום מציג אילו תדרים הוא מורכב מהם. עיצוב הספקטרום של קטע בעייתי הוא הדרך המהירה ביותר למצוא רעש רקע של 50 או 60 הרץ, ציוץ ממסך, או את התדר שבו החדר רועש — ואז לדעת לאן להפנות את השוויון (equalizer).

:::note[מגיעים מ-Audacity?]
זהו הפקודה **Analyze → Plot Spectrum** של Audacity. השמות להלן הם של Soundscaper בלבד, ולעיתים הם שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן מיד לאחר שהעורך נטען.
2. בחר **File → Import audio** ובחר את הקלטת עם הבעיה. הקובץ נחת כקליפ על מסלול משלו.
3. בחר **Select → Select all**.
4. בחר **Analyze → Plot spectrum**. פאנל **Plot spectrum** נפתח.
   *מה שצריך להיראות:* גרף של רמה מול תדר עבור הבחירה.

## טיפים

- בחר רק את הקטע הבעייתי — למשל, מתיחה של רעש רקע לבד — כדי שהספקטרום לא יושפע מהמוזיקה או מהדיבור סביבו.
- שיפוד גבוה וצר הוא טון; מישור רחב הוא רעש. טונים מגיבים לחיתוך EQ צר, רעש ל[Noise Reduction](/guides/cleaning-up/remove-background-noise/).
