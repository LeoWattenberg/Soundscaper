## למה המדריך הזה מיועד {#what-this-guide-is-for}

הקלטה שנעשתה ברמה גבוהה מדי מתשטחת בחלק העליון של הטווח ומתעוותת. הנזק קל לשמיעה אך קשה לזיהוי בעין בהקלטה ארוכה. Find Clipping סורק את הבחירה ומפרט כל סדרה של דוגמאות שנמצאות ברמה מלאה, כך שתוכל להחליט אם לתקן, לעשות מחדש או לחיות עם כל אחת מהן.

:::note[מגיע מ-Audacity?]
זהו **Analyze → Find Clipping** של Audacity. השמות למטה הם של Soundscaper, שלפעמים שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **File → Import** ובחר את ההקלטה שברצונך לבדוק. היא נוחתת כקליפ במסלול משלה.
3. בחר **Select → Select all**.
4. בחר **Analyze → Find clipping**. תיבת הדו־שיח **Find clipping** נפתחת עם דוח הבחירה.
   *אתה אמור לראות:* רשימה של הריצות המעוקלות, או הערה שלא נמצאו כאלה.

## טיפים

- הורדת רמת הקול של הקלטה מעוקלת לא מתקנת אותה; הפסגות השטוחות נשארות שטוחות. **Effect → Noise removal and repair → Repair** יכול לבנות מחדש ריצת מעוקלת קצרה מאוד.
- כדי להימנע מעיקום בפעם הבאה, הקלט עם פסגות סביב −12 dB והעלה את הרמה לאחר מכן.
