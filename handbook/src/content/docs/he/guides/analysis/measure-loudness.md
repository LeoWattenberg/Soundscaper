לפני שתבצעו נרמול או ייצוא, כדאי לדעת איפה אתם נמצאים. מנתח EBU R 128 מודד את התוכן בדיוק כמו שפלטפורמות סטרימינג ושידור עושים זאת — רמות צלוליות משולבות ב-LUFS, טווח צלוליות ושיא אמיתי — כך שתוכלו להשוות למטרה במקום לנחש מהמד.

:::note[מגיעים מ-Audacity?]
זהו **Analyze → Measure RMS, או מדידת Loudness Normalization** של Audacity. השמות להלן הם של Soundscaper בלבד, והם עשויים להיות שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **File → Import audio** ובחרו את המיקס שתרצו למדוד. הקובץ יופיע כקליפ על מסלול נפרד.
3. בחרו **Select → Select all**.
4. בחרו **Analyze → EBU R 128**. פאנל **EBU R 128** ייפתח.
   *מה שצריך להופיע:* רמות צלוליות משולבות, טווח צלוליות ושיא אמיתי עבור הבחירה.

## טיפים

- פלטפורמות פודקאסט דורשות בדרך כלל −16 LUFS סטריאו או −19 LUFS מונו עם שיאים אמיתיים מתחת ל−1 dBTP; בדקו את ההנחיות של הפלטפורמה עצמה.
- אם המספרים רחוקים מהמטרה, הרצו [Loudness Normalization](/guides/volume/normalize-loudness-for-podcasts/) ומדדו שוב.
