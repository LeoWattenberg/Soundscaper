לפני שמנרמלים או מייצאים, כדאי לבדוק מהי עוצמת הקול של המיקס. מנתח EBU R 128 מודד את התוכנית כמו בפלטפורמות סטרימינג ובשידור: עוצמת קול משולבת ביחידות LUFS, טווח עוצמת הקול ושיא אמיתי. כך אפשר להשוות ליעד במקום להעריך לפי המד בלבד.

:::note[מגיעים מ-Audacity?]
זהו **Analyze → Measure RMS, או מדידת Loudness Normalization** של Audacity. השמות להלן הם של Soundscaper בלבד, והם עשויים להיות שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **File → Import** ובחרו את המיקס שתרצו למדוד. הוא יופיע כקליפ במסלול משלו.
3. בחרו **Select → Select all**.
4. בחרו **Analyze → EBU R 128**. פאנל **EBU R 128** ייפתח.
   *מה אמור להופיע:* עוצמת הקול המשולבת, טווח עוצמת הקול והשיא האמיתי של הבחירה.

## טיפים

- פלטפורמות פודקאסט דורשות בדרך כלל −16 LUFS סטריאו או −19 LUFS מונו עם שיאים אמיתיים מתחת ל−1 dBTP; בדקו את ההנחיות של הפלטפורמה עצמה.
- אם המדידות רחוקות מהיעד, השתמשו ב[נרמול עוצמת הקול](/guides/volume/normalize-loudness-for-podcasts/) ומדדו שוב.
