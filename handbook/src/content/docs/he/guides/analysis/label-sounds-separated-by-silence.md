## למה המדריך הזה מיועד {#what-this-guide-is-for}

Label Sounds סורק קטע לאיתור צלילים המופרדים בשקט ומציב תווית סביב כל צליל שזוהה. כך אפשר לסמן משפטים מדוברים, מכות בודדות או אירועים ברורים אחרים לעריכה בהמשך.

:::note[מגיעים מ־Audacity?]
המקבילה ב-Audacity היא **Analyze → Label Sounds (Nyquist)**. השמות שלהלן הם של Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא** ובחרו הקלטה שבה הפסקות בין צלילים. היא תופיע כקליפ ברצועה משלה.
3. בחרו **בחירה → הכול**.
4. בחרו **ניתוח → Nyquist → Label Sounds**. בחלון **Label Sounds**, הגדירו **Threshold level (dB)** ל-`-30`, את **Minimum silence duration** ל-`0.5` ואת **Minimum label interval** ל-`0.5`, ואז לחצו על **החל**. החלון מציג את התוצאות; לחצו על **סגירה** כדי לסגור אותו. חצי שנייה של שקט מאפשרת למנתח להפריד בין משפטים. הסף קובע עד כמה צליל צריך להיות חזק כדי להיחשב.
5. כעת הפרויקט מציג רצועה בשם **Label Sounds**.
   *מה אמורים לראות:* רצועת Label Sounds מופיעה ובה תוויות סביב המשפטים שזוהו.

## טיפים

- הנמיכו את **Threshold level (dB)** כדי לכלול צלילים חלשים יותר; העלו אותו כדי להתעלם מרעש רקע.
- הגדילו את **Minimum silence duration** כאשר הפסקות קצרות לא אמורות לפצל משפט אחד לכמה תוויות.
