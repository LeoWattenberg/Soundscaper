לכל רצועה יש כפתור Mute וכפתור Solo בכותרת שלה. Mute משתיק את הרצועה הזו; Solo משתיק את כל הרצועות האחרות כדי שתשמע רק את הרצועה הזו. שניהם הם כלי האזנה בלבד — הם משנים את מה שאתה שומע בזמן העבודה, והייצוא עדיין מייצר את כל הרצועות שלא הושתיקו.

:::note[מגיעים מ-Audacity?]
זהו **The Mute and Solo buttons in the track control panel** של Audacity. השמות להלן הם של Soundscaper, ולעיתים הם שונים.
:::

## צעדים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן מיד לאחר שהעורך נטען.
2. בחר **File → Import audio** ובחר רצועה אחת. הקובץ נחת כקליפ על רצועה משלו.
3. בחר **File → Import audio** ובחר רצועה נוספת. הקובץ נחת כקליפ על רצועה משלו.
4. לחץ על **Mute** בכותרת הרצועה. הרצועה השנייה יוצאת מהניגון.
5. לחץ על **Solo** בכותרת הרצועה. Solo דוחה את mute ברצועה הזו ומשתיק את כל הרצועות האחרות, כך שאתה שומע את הרצועה הזו לבד.

## טיפים

- לחץ על הכפתור שוב כדי לשחרר אותו. **Tracks → Mute all tracks** מנקה את כל הרצועות בבת אחת.
- בחר Solo במספר רצועות כדי להאזין לקבוצה יחד; אז השתיקה נדרשת רק עבור הרצועה החריגה.
