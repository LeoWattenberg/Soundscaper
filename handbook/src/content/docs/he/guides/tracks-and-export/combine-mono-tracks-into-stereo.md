## למה המדריך הזה מיועד {#what-this-guide-is-for}

Make stereo track מרנדר שתי רצועות מונו לקליפ סטריאו אחד ומחליף את רצועות המקור. הרצועה שאת התפריט שלה פותחים מספקת את הערוץ השמאלי; רצועת המונו התואמת הראשונה שמתחתיה מספקת את הערוץ הימני. אם אין רצועה כזאת מתחתיה, Soundscaper משתמש ברצועת המונו התואמת הראשונה במקום אחר בפרויקט. לפני השילוב, הציבו את הרצועה המיועדת לערוץ הימני ישירות מתחת לרצועה השמאלית.

:::note[מגיעים מ־Audacity?]
ב-Audacity הפעולה המקבילה היא **Upper mono track menu → Make stereo track (Audacity 4)**. השמות שלמטה שייכים ל-Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. עם טעינת העורך, פרויקט חדש וריק כבר מוכן.
2. בחרו **קובץ → ייבוא** ובחרו את הקלטת המונו המיועדת לערוץ השמאלי. היא תופיע כקליפ ברצועה משלה.
3. בחרו **קובץ → ייבוא** ובחרו את הקלטת המונו המיועדת לערוץ הימני. היא תופיע כקליפ ברצועה משלה, מתחת לרצועה הראשונה. מקמו את הקליפים בזמנים שבהם הם אמורים להתנגן.
4. פתחו את תפריט הרצועה של הערוץ השמאלי באמצעות הלחצן **אפשרויות רצועה** בכותרת שלה ובחרו **ערוצי רצועה → יצירת רצועת סטריאו**.
5. כעת הפרויקט מציג קליפ אחד ו-2 רצועות.
   *אתם אמורים לראות:* קליפ סטריאו אחד החליף את שתי הקלטות המונו, והצליל המיועד נמצא בכל ערוץ.

## טיפים

- הקליפ החדש משתרע על פני התוכן של שתי הרצועות בקצב הדגימה של הפרויקט. פערים בכל רצועה הופכים לשקט בערוץ שלה.
- אם ההקלטות צריכות להתחיל יחד, [יישרו את תחילות הרצועות](/guides/editing/align-track-starts-together/) לפני השילוב.
- שמרו עותק של הפרויקט אם תצטרכו לערוך בהמשך את הקליפים הנפרדים. **עריכה → ביטול־ביצוע** מחזיר את שתי רצועות המונו.
