עם תריסר רצועות, השתקה של כל אחת מהן בנפרד כדי להאזין לחלק חדש אחד היא מעייפת, והבטלה של ההשתקה לאחר מכן גרועה עוד יותר. הפקודה "השתקת כל הרצועות" משתיקה את כל הפרויקט בפקודה אחת, והפקודה "ביטול השתקת כל הרצועות" מחזירה אותו, ושום אחת מהן לא נוגעת בכפתורי הסולו. ב-Audacity 3 היו שתי הפקודות; Audacity 4 לא החזיר אותן.

:::note[מגיעים מ-Audacity?]
זוהי הפקודה **Tracks → Mute/Unmute → Mute All Tracks and Unmute All Tracks (Audacity 3; לא נמצאת ב-Audacity 4)** של Audacity. השמות להלן הם של Soundscaper, והם לעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **File → Import audio** ובחרו את ההקלטה הראשונה. הקובץ נחת כקליפ על רצועה משלו.
3. בחרו **File → Import audio** ובחרו את ההקלטה השנייה. הקובץ נחת כקליפ על רצועה משלו.
4. בחרו **Tracks → Mute all tracks**.
5. הפרויקט מציג כעת את כפתור **Mute** של כל הרצועות דולק.
   *מה שצריך להיראות:* ההשמעה שקטה.
6. בחרו **Tracks → Unmute all tracks**.
7. הפרויקט מציג כעת שאין רצועה משתקת.
   *מה שצריך להיראות:* הכל נשמע שוב.

## טיפים

- השתקו הכל, ואז בטלו את ההשתקה של הרצועה או שתי הרצועות שאתם רוצים לשמוע — מהיר יותר מסולו כאשר הבחירה משתנה לעיתים קרובות.
- כדי לשמוע רצועה אחת לבד ללא נגיעה באחרות, [עשו לה סולו](/guides/tracks-and-export/mute-and-solo-tracks/) במקום.
