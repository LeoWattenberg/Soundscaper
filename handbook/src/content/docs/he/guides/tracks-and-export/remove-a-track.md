## למה המדריך הזה מיועד {#what-this-guide-is-for}

Remove tracks מוחק מהפרויקט את הרצועה שנבחרה ואת כל הקליפים שבה. הוא שימושי להסרת טייק שאינו נחוץ או עותק מיותר לאחר השוואת עריכות. בחירת קליפ אחד מכוונת לרצועה כולה, לכן בדקו את הבחירה לפני ההסרה.

:::note[מגיעים מ־Audacity?]
ב-Audacity הפעולה המקבילה היא **Tracks → Remove tracks (Audacity 4)**. השמות שלמטה שייכים ל-Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. עם טעינת העורך, פרויקט חדש וריק כבר מוכן.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שברצונכם לשמור. היא תופיע כקליפ ברצועה משלה.
3. בחרו **קובץ → ייבוא** ובחרו את ההקלטה הלא רצויה שברצועה אחרת. היא תופיע כקליפ ברצועה משלה.
4. השתמשו ב-**Tab** כדי להעביר את המיקוד לקליפ ברצועה שברצונכם להסיר ולחצו על **Enter** כדי לבחור אותו.
5. בחרו **רצועות → הסר רצועות**.
6. ההקלטה שהשארתם נשארת במיקומה המקורי.
   *אתם אמורים לראות:* הרצועה הלא רצויה נעלמה, וההקלטה האחרת לא השתנתה.

## טיפים

- **עריכה → ביטול־ביצוע** משחזר את הרצועה שהוסרה ואת הקליפים שבה.
- כדי להסיר רק חלק מההקלטה, [מחקו קטע והשאירו פער](/guides/editing/delete-a-passage-and-leave-a-gap/) במקום למחוק את הרצועה.
- הסרת רצועה מהפרויקט אינה מוחקת את הקובץ המקורי שייבאתם מהמחשב.
- רצועות בקבוצת רצועות מקושרת מוסרות יחד.
