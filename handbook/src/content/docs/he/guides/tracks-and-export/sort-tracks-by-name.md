## למה המדריך הזה מיועד {#what-this-guide-is-for}

קל יותר לנווט בפרויקט עם כמה טייקים כאשר שמות רצועות קשורות מופיעים יחד. Sort by name מסדר מחדש את הרצועות לפי האלף-בית בלי לשנות את נקודת ההתחלה של הקליפים בציר הזמן.

:::note[מגיעים מ־Audacity?]
המקבילה ב-Audacity היא **Tracks → Sort Tracks → Sort by Name**. השמות שלהלן הם של Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שאמורה להופיע אחרונה לפי שמה. היא תופיע כקליפ ברצועה משלה.
3. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שאמורה להופיע לפניה לפי שמה. היא תופיע כקליפ ברצועה משלה.
4. בחרו **רצועות → מיון רצועות → מיון לפי שם**. שמות הרצועות ממוינים לפי האלף-בית.
5. כעת הפרויקט מציג 2 קליפים.
   *מה אמורים לראות:* שתי ההקלטות נשארות בפרויקט ושמות הרצועות מופיעים לפי האלף-בית.

## טיפים

- המיון משנה את סדר הרצועות, לא את תזמון הקליפים או את תוכן השמע.
- השתמשו ב-**רצועות → מיון רצועות → מיון לפי זמן** אם ברצונכם שסדר הרצועות יתאים לזמני תחילת הקליפים.
