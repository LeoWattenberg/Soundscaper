## למה המדריך הזה מיועד {#what-this-guide-is-for}

קוד מורס ממיר הודעה לנקודות, קווים ורווחים מתוזמנים. המחולל מציג תצוגה מקדימה ומחשב את אורך הקטע לפי ההודעה והמהירות.

:::note[מגיעים מ־Audacity?]
הנתיב ב־Audacity הוא **No directly matching built-in Morse code generator**. השמות הבאים הם של Soundscaper ועשויים להיות שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **יצירה → קוד מורס**. בתיבת **קוד מורס**, הגדירו **הודעה** ל־`SOS`, את **מהירות (מילים לדקה)** ל־`20`, את **תדירות (הרץ)** ל־`600` ואת **משרעת** ל־`0.2`, ואז לחצו **יצירה**. החליפו את הודעת הדוגמה בטקסט משלכם ובדקו את תצוגת הקידוד; תווים לא נתמכים מונעים יצירה.
3. הפרויקט מציג כעת קליפ אחד.
   *מה אמור להופיע:* הקליפ מכיל הודעת מורס ואורכו תואם למהירות שנבחרה.

## טיפים

- מהירות נמוכה יותר מאריכה נקודות, קווים ורווחים בלי להנמיך את תדר הצליל.
- משך הזמן כאן לקריאה בלבד. שנו את ההודעה או המהירות כדי לשנות את אורך הקטע.
