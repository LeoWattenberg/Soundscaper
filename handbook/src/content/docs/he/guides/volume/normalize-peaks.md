Normalize מודד את השיא החזק ביותר בבחירה ומקנה לכל האותיות כך שהשיא יגיע בדיוק למקום שאתה מבקש. זהו השלב האחרון הרגיל לפני ייצוא: הקובץ משתמש בטווח המלא שלו ללא חיתוך (clipping). הוא גם מסיר כל סטיית DC, שהיא הזזה אנכית קלה שחלק מכרטיסי הקול מוסיפים.

:::note[מגיעים מ-Audacity?]
זהו הפעולה **Effect → Volume and Compression → Normalize** ב-Audacity. השמות להלן הם של Soundscaper בלבד, ולעיתים הם שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחר **File → Import audio** ובחר את ההקלטה השקטה. הקובץ יופיע כקליפ על מסלול נפרד.
3. בחר **Select → Select all**.
4. בחר **Effect → Volume and compression → Normalize**. בחלון הדיאלוג **Normalize**, הגדר את **Peak amplitude** ל-`-3`, ואז לחץ על **Apply to selection**. מינוס שלושה דציבלים משאירים מעט מרווח (headroom) לקודק אם תייצא ל-MP3 מאוחר יותר.
5. לחץ על **Play** להאזנה, ואז **Stop**.
   *מה שצריך להיראות:* הרגע החזק ביותר נמצא כעת מעט מתחת למקסימום.

## טיפים

- Normalize בודק שיאים, ולא את עוצמת ההקלטה המורגשת. שני קבצים מנורמלים עדיין יכולים להישמע שונים מאוד; לכך, ראו [Normalize loudness for a podcast](/guides/volume/normalize-loudness-for-podcasts/).
- ערוצי סטריאו מנורמלים יחד אלא אם כן אתה מפעיל את **Normalize stereo channels independently**, מה שעשוי להזיז את הדמות הסטריאו.
