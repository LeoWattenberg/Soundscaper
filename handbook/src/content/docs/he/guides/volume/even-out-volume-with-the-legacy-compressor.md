Audacity 3 הוציא שני דחיסנים: המודרני עם knee, lookahead ומדידים חיים, והמקורי הפשוט יותר שהותיר כ-Legacy Compressor. העיצוב המורשית כולל רצע רעש (noise floor) מתחתיו הוא מפסיק לפעול — ולכן הוא מעולם לא מעלה רעש רקע במהלך הפסקות — והוא מגדיל את התוצאה עד 0 dB כברירת מחדל. Audacity 4 ביטל אותו; Soundscaper שומר עליו עבור פרויקטים ואוזניים שרגילות אליו.

:::note[מגיעים מ-Audacity?]
זהו **Effect → Volume and Compression → Legacy Compressor (Audacity 3; ב-Audacity 4 יש רק את ה-Compressor החדש)** של Audacity. השמות להלן הם של Soundscaper עצמו, ולעיתים הם שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחרו **File → Import audio** ובחרו את ההקלטה שתרצו לאזן. הקובץ נחת כקליפ על מסלול נפרד.
3. בחרו **Select → Select all**.
4. בחרו **Effect → Legacy effects → Legacy Compressor**. בחלון ה-**Legacy Compressor**, הגדירו **Threshold** ל-`-20` והגדירו **Ratio** ל-`4`, ואז לחצו **Apply to selection**. כל מה שמעל −20 dB יורד לפי היחס, כאן 4:1. תגבור תיקון (Make-up gain) מרים אז את כל התוצאה כך שהשיא יהיה 0 dB.
5. לחצו **Play** להאזנה, ואז **Stop**.
   *מה שצריך להיות נראה:* קטעים חזקים ושקטים נמצאים קרוב יותר זה לזה וההקלטה כולה חזקה יותר.

## טיפים

- הגבירו את **Noise floor** אם הדחיסן מעלה רעש (hiss) בהפסקות; האפקט מתעלם מכל מה שקטן ממנו.
- לדחיסן שניתן לשמוע אותו פועל בזמן ההגדרה, השתמשו במודרני: [איזון עוצמה עם דחיסן](/guides/volume/even-out-volume-with-a-compressor/).
