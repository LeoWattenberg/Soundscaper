## למה המדריך הזה מיועד {#what-this-guide-is-for}

כשהקלטה צריכה להתחיל בנקודת סימון מסוימת, גרירה לפי העין עלולה להיות לא מדויקת. Align start to playhead מזיז את תוכן הרצועה שנבחרה כך שההתחלה שלה תפגוש את הסמן, תוך שמירה על אורך ההקלטה.

:::note[מגיעים מ־Audacity?]
המקבילה ב-Audacity היא **Tracks → Align Tracks → Align Start to Playhead**. השמות שלהלן הם של Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שברצונכם למקם בנקודת סימון. היא תופיע כקליפ ברצועה משלה.
3. גררו את הקליפ באמצעות פס השם שלו לנקודה מאוחרת יותר בציר הזמן. הזיזו אותו תחילה כדי שהסמן יוכל לסמן מיקום התחלה אחר.
4. לחצו על צורת הגל בנקודה שבה ההקלטה אמורה להתחיל כדי להציב שם את הסמן.
5. בחרו **רצועות → יישור תוכן → יישור התחלה למיקום הניגון**. הקליפ המוקדם ביותר ברצועה שנבחרה מועבר למיקום הסמן.
6. כעת ההקלטה מתחילה בסמן ההשמעה.
   *מה אמורים לראות:* הקליפ מתחיל בנקודת הסימון ושומר על אורכו המקורי.

## טיפים

- היישור מזיז את כל הקליפים בכל רצועה שנבחרה. השתמשו ברצועה שמכילה רק את ההקלטה שברצונכם להזיז.
- השתמשו ב-**רצועות → יישור תוכן → יישור התחלה לאפס** כדי להחזיר רצועה שנבחרה לתחילת הפרויקט.
