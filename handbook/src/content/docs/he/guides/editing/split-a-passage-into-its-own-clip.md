## למה המדריך הזה מיועד {#what-this-guide-is-for}

מילה, משפט מוזיקלי או טייק נוסף יכולים להפוך לקליפ נפרד בלי לשנות את אורך ההקלטה. לאחר בחירת טווח זמן, Split חותך בשני גבולות הבחירה. לאחר מכן אפשר להזיז או לעבד את החלק האמצעי בנפרד.

:::note[עברתם מ־Audacity?]
ב-Audacity הפעולה המקבילה היא **Edit → Clip → Split (Ctrl+I)**. השמות שלמטה שייכים ל-Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. עם טעינת העורך, פרויקט חדש וריק כבר מוכן.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שמכילה את הקטע. היא תופיע כקליפ ברצועה משלה.
3. גררו בסרגל שמעל הקליפ כדי לבחור את הקטע שברצונכם להפריד. השאירו מעט צליל לפני הבחירה ואחריה, כך ששני הגבולות יהיו בתוך הקליפ.
4. בחרו **עריכה → קליפי שמע → פיצול**.
5. כעת הפרויקט מציג 3 קליפים.
   *אתם אמורים לראות:* הקטע שנבחר הוא קליפ נפרד בין הצליל שקדם לו לזה שבא אחריו. שלושת החלקים שומרים על מיקומיהם המקוריים בציר הזמן.

## טיפים

- כדי לבצע חיתוך אחד בלבד, [פצלו את הקליפ במיקום הסמן](/guides/editing/split-a-clip-at-the-cursor/) במקום לבחור טווח.
- **עריכה → ביטול־ביצוע** משחזר את הקליפ המקורי אם צריך לכוונן אחד מהגבולות.
- כדי להשליך את הצליל שמסביב, [השאירו רק את החלק הרצוי](/guides/editing/keep-only-a-selection/).
