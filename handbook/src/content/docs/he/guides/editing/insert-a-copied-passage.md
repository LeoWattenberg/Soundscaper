## למה המדריך הזה מיועד {#what-this-guide-is-for}

Insert מפנה מקום לצליל שהועתק במקום להציב אותו מעל צליל קיים. הצליל המאוחר יותר ברצועת היעד נע ימינה למשך הקטע שהועתק. השתמשו בכך כדי להוסיף משפט מוזיקלי חוזר או משפט נוסף בתוך הקלטה.

:::note[עברתם מ־Audacity?]
ב-Audacity הפעולות המקבילות הן **Edit → Copy, then Edit → Paste**. השמות שלמטה שייכים ל-Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. עם טעינת העורך, פרויקט חדש וריק כבר מוכן.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שמכילה את הקטע שברצונכם להעתיק. היא תופיע כקליפ ברצועה משלה.
3. גררו בסרגל שמעל הקליפ כדי לבחור את הקטע שברצונכם להוסיף במקום אחר.
4. בחרו **עריכה → העתקה**.
5. לחצו על צורת הגל בתוך קליפ היעד, במקום שבו העותק אמור להתחיל, כדי להציב שם את הסמן. הלחיצה מבטלת את טווח הזמן ומגדירה את נקודת ההוספה.
6. בחרו **עריכה → הדבקה → הוסף**.
7. כעת הפרויקט מציג 3 קליפים.
   *אתם אמורים לראות:* הקטע שהוכנס נמצא בין שני חלקים של הקליפ המקורי. החלק המאוחר יותר זז ימינה, והחלק המוקדם יותר נשאר במקומו.

## טיפים

- Insert מזיז את הצליל המאוחר יותר ברצועת היעד. **עריכה → הדבקה → הוסף ושמור על סנכרון** מפנה מקום בכל הרצועות כשצריך לשמור על תזמון מתואם ביניהן.
- **עריכה → ביטול־ביצוע** מסיר את ההוספה ומחזיר את הצליל המאוחר יותר למקומו הקודם.
