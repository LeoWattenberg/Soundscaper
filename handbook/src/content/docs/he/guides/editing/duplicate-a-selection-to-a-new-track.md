כפילות מעתיקה את הבחירה למסלול חדש ישירות מתחת, באותה עמדה בזמן. זוהי בדרך כלל הצעד הראשון לעיבוד מקביל — עותק דחוס כבד מעורבב מתחת למקורי, מסלול רק אקו, קול כפול.

:::note[מגיע מ-Audacity?]
זהו **עריכה → כפיל (Ctrl+D)** ב-Audacity. השמות למטה הם של Soundscaper, שלפעמים שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **קובץ → יבא אודיו** ובחר את ההקלטה עם המעבר לכפיל. הקובץ נוחת כקליפ על מסלול משלו.
3. גרור בשליט מעל הקליפ כדי לבחור את המעבר לכפיל.
4. בחר **עריכה → כפיל**.
5. הפרויקט כעת מציג 2 קליפים.
   *עליך לראות:* קליפ שני המכיל רק את הבחירה, על מסלול חדש מתחת לראשון, מסודר בזמן.

## טיפים

- השתק אחד משני המסלולים כדי לשמוע את השני לבד בזמן שאתה מעצב אותו.
- כאשר אתה מרוצה מהשילוב, [ערבב את המסלולים למטה](/guides/tracks-and-export/mix-tracks-into-one/).
