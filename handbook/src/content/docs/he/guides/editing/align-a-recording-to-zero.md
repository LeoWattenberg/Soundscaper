## למה המדריך הזה מיועד {#what-this-guide-is-for}

אפשר להחזיר לתחילת הפרויקט הקלטה שמתחילה מאוחר בציר הזמן באמצעות פקודת יישור. Align start to zero מזיזה את תוכן הרצועה שנבחרה כך שהקליפ המוקדם ביותר בה יתחיל באפס. בהליך הזה מזיזים תחילה הקלטה למועד מאוחר יותר ואז מיישרים אותה בחזרה להתחלה.

:::note[עברתם מ־Audacity?]
הפקודה המקבילה ב־Audacity היא **רצועות → יישור תוכן → יישור התחלה לאפס**. השמות שלהלן הם השמות של Soundscaper, שעשויים להיות שונים לפעמים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד כשהעורך נטען.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שברצונכם ליישר. היא מתווספת כקליפ ברצועה משלה.
3. גררו את הקליפ לפי שורת השם שלו למיקום מאוחר יותר בציר הזמן.
4. כעת הקליפ מתחיל אחרי תחילת הפרויקט.
5. בחרו **רצועות → יישור תוכן → יישור התחלה לאפס**.
6. כעת ההקלטה מתחילה בזמן אפס.
   *אתם אמורים לראות:* הקצה השמאלי של הקליפ מיושר עם תחילת הסרגל.

## טיפים

- היישור מזיז את תוכן הרצועה שנבחרה. אם ברצונכם להזיז רק את ההקלטה הזו, השתמשו ברצועה שמכילה רק אותה.
- **עריכה → ביטול־ביצוע** משחזר את המיקום הקודם.
