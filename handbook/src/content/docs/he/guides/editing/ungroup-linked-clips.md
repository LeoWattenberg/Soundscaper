## למה המדריך הזה מיועד {#what-this-guide-is-for}

אפשר לבחור ולהזיז קליפים מקובצים כיחידה, אף שהם נשארים חלקי שמע נפרדים. Ungroup מחזיר את האפשרות לבחור כל קליפ בנפרד; הוא אינו מחבר את החלקים ואינו מרנדר אותם לקליפ אחד.

:::note[מגיעים מ־Audacity?]
המקבילה ב-Audacity היא **Edit → Clip → Ungroup Clips**. השמות שלהלן הם של Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא** ובחרו הקלטה עם קליפים שברצונכם להפריד. היא תופיע כקליפ ברצועה משלה.
3. לחצו על צורת הגל במקום שבו ברצונכם לחלק את הקליפ לשני חלקים, כדי להציב שם את הסמן.
4. בחרו **עריכה → קליפי שמע → פיצול**.
5. לחצו על פס השם של החלק הראשון, החזיקו Shift ולחצו על פס השם של החלק השני כדי לבחור את שניהם.
6. בחרו **עריכה → קליפי שמע → קיבוץ קטעים**. הקיבוץ מאפשר להזיז את שני החלקים יחד בלי לחבר את השמע שלהם.
7. בחרו **עריכה → קליפי שמע → בטל קיבוץ קליפים**. ביטול הקיבוץ מחזיר את שני החלקים כקליפים שאפשר לבחור בנפרד.
8. כעת הפרויקט מציג 2 קליפים.
   *מה אמורים לראות:* ההקלטה עדיין מורכבת משני קליפים נפרדים שנפגשים בנקודת הפיצול.

## טיפים

- קיבוץ שימושי כאשר קליפים נפרדים צריכים לשמור על התזמון היחסי שלהם בזמן הזזה.
- בחרו **עריכה → קליפי שמע → חיבור הקטעים הנבחרים** אם ברצונכם להפוך חלקים סמוכים לקליפ אחד.
