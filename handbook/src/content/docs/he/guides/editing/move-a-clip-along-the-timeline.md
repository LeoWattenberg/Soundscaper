קליפים יכולים לנוע בחופשיות. גרירת קליפ דרך סרגל השם שלו מזיזה אותו לאורך המסלול — כדי להשאיר רווח בהתחלה, כדי להציב אותו אחרי קליפ אחר, או כדי ליישר אותו עם רמז (cue) בסרטון. גרירה כלפי מעלה או כלפי מטה מזיזה אותו למסלול אחר.

:::note[מגיעים מ-Audacity?]
זהו כלי הזזת הזמן (The Time Shift tool) (F5) ב-Audacity, או גרירת סרגל הקליפ ב-Audacity 3.1 ומעלה. השמות להלן הם של Soundscaper בלבד, והם עשויים להיות שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא שמע** ובחרו את ההקלטה שברצונכם להזיז. הקובץ יופיע כקליפ במסלול משלו.
3. גררו את הקליפ דרך סרגל השם שלו למקום שבו הוא צריך להתחיל. הקליפ עוקב אחרי המצביע; זמן ההתחלה החדש שלו מוצג בסרגל הבחירה בזמן הגרירה.
4. הקליפ מתחיל כעת במקום שבו שחררתם אותו.
   *מה שצריך להיות נראה:* המסלול שקט עד שהקליפ מתחיל.

## טיפים

- הפעילו הצמדה (snapping) מסרגל ההפעלה כך שקליפ שנגרר יתנעל לספרות, למקצבים או לפריימים.
- החזיקו את Shift בזמן הגרירה כדי להשאיר את הקליפ במסלול שלו.
