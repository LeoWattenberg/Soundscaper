למידת ריף, בדיקת נקודת עריכה, בדיקת הגדרת אפקט: הכל מהיר יותר כאשר המעבר מתנגן שוב ושוב בלי שתצטרך להתחיל אותו מחדש. הגדר את אזור הלולאה לבחירה והנגן יישאר בתוכו עד שתכבה את הלולאה.

:::note[מגיע מ-Audacity?]
זהו **Transport → Looping → Set Loop to Selection** של Audacity. השמות למטה הם של Soundscaper, ולפעמים הם שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **File → Import** ובחר את ההקלטה עם המעבר לתרגול. היא נוחתת כקליפ על מסלול משלה.
3. גרור את הסרגל מעל הקליפ כדי לבחור את המעבר לחזרה.
4. בחר **Select → Loop region → Set loop to selection**.
5. הפרויקט כעת מציג את כפתור **Loop selection** דולק.
   *אתה אמור לראות:* כפתור הלולאה בסרגל התחבורה נדלק ואזור הלולאה מוצג מעל הסרגל.
6. לחץ על **Play** כדי להאזין, ואז על **Stop**.
   *אתה אמור לראות:* הנגן עובר שוב ושוב על המעבר הנבחר.

## טיפים

- לחץ על **L** או על כפתור הלולאה בסרגל התחבורה כדי להדליק ולכבות את הלולאה בלי לאבד את האזור.
- גרור את קצות אזור הלולאה בסרגל כדי להתאים אותו.
