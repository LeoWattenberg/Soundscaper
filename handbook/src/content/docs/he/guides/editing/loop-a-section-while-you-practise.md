למידת ריף, בדיקת נקודת עריכה, האזנה להגדרת אפקט: הכל מהיר יותר כאשר הקטע נשמע שוב ושוב ללא צורך בהפעלה מחדש. הגדר את אזור הלולאה לבחירה, והנגנה תישאר בתוכה עד שתכבה את הלולאה.

:::note[מגיעים מ-Audacity?]
זהו הפקודה **Transport → Looping → Set Loop to Selection** ב-Audacity. השמות להלן הם של Soundscaper, והם עשויים להיות שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחר **File → Import audio** ובחר את ההקלטה עם הקטע לתרגול. הקובץ יופיע כקליפ על מסלול נפרד.
3. גרור את הסרגל מעל הקליפ כדי לבחור את הקטע לחזרה.
4. בחר **Select → Loop region → Set loop to selection**.
5. הפרויקט מציג כעת את כפתור **Loop selection** דולק.
   *מה שצריך להיראות:* כפתור הלולאה בסרגל ההפעלה דולק ואזור הלולאה מוצג מעל הסרגל.
6. לחץ **Play** להאזנה, ואז **Stop**.
   *מה שצריך להיראות:* ההנגנה עוברת על פני הקטע הנבחר.

## טיפים

- לחץ **L** או על כפתור הלולאה בסרגל ההפעלה כדי לכבות ולהדליק את הלולאה בלי לאבד את האזור.
- גרור את קצוות אזור הלולאה בסרגל כדי לכוונן אותו.
