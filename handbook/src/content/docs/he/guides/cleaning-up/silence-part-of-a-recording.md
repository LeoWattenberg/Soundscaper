לפעמים תרצה להסיר קטע אך לא את הזמן שהוא תופס — טלפון מצלצל מתחת להפסקה, שם שאתה צריך לצנזר. השתקה משאירה את הקליפ בדיוק באורכו המקורי ומשטיחה רק את החלק הנבחר.

:::note[מגיע מ-Audacity?]
זהו **עריכה → הסר מיוחד → שקט אודיו** של Audacity. השמות למטה הם של Soundscaper, שלפעמים שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן ברגע שהעורך נטען.
2. בחר **קובץ → יבא אודיו** ובחר את ההקלטה עם הקטע להשתיקה. הקובץ נוחת כקליפ על מסלול משלו.
3. גרור בשליט מעל הקליפ כדי לבחור רק את החלק שאתה רוצה להשתיק.
4. בחר **עריכה → הסר מיוחד → שקט אודיו**.
5. הפרויקט כעת מציג 1 קליפ.
   *אתה אמור לראות:* הגלישה שטוחה לרוחב הבחירה והקליפ עדיין שלם.

## טיפים

- שקט הוא עריכה רגילה: **עריכה → בטל** מחזיר את האודיו.
- כדי להסיר את הזמן יחד עם הצליל, ראה [חותך טעות מהקלטה](/guides/editing/cut-out-a-mistake/).
