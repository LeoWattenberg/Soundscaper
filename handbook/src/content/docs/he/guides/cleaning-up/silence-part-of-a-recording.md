לפעמים אתה רוצה להסיר קטע מסוים מהקלטה, אך לשמור על הזמן שהוא תפס - למשל, טלפון מצלצל במהלך הפסקה, או שם שצריך לצנזר. השתקה משאירה את ההקלטה באורכה המקורי ומשטיחה רק את החלק הנבחר.

:::note[מגיעים מ-Audacity?]
זהו **עריכה → הסר מיוחד → שקט אודיו** ב-Audacity. השמות למטה הם של Soundscaper, ולפעמים הם שונים.
:::

## שלבים

1. פתח את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחר **קובץ → יבוא** ובחר את ההקלטה עם הקטע שאתה רוצה להשתיק. היא נוחתת כקליפ על מסלול משלה.
3. גרור את הסרגל מעל הקליפ כדי לבחור רק את החלק שאתה רוצה להשתיק.
4. בחר **עריכה → הסר מיוחד → שקט אודיו**. 
5. הפרויקט כעת מציג 3 קליפים.
   *אתה אמור לראות:* הגלומה שטוחה בקליפ האמצעי החדש, בין האודיו הלא משתנה משני הצדדים.

## טיפים

- שקט הוא עריכה רגילה: **עריכה → ביטול** מחזיר את האודיו.
- כדי להסיר את הזמן יחד עם הצליל, ראה [חותך טעות מהקלטה](/guides/editing/cut-out-a-mistake/).
