## למה המדריך הזה מיועד {#what-this-guide-is-for}

שריקה יציבה או צליל אלקטרוני עשויים להופיע בתחום תדרים קטן רק בחלק מההקלטה. Spectral Delete מסיר את התחום הזה בתוך בחירת זמן ומשאיר את התדרים שמסביב ללא שינוי.

:::note[מגיעים מ־Audacity?]
המקבילה ב-Audacity היא **Effect → Spectral Tools → Delete selection (Audacity 4)**. השמות שלהלן הם של Soundscaper ולעיתים שונים.
:::

## שלבים

1. פתחו את Soundscaper. פרויקט חדש וריק מוכן מיד עם טעינת העורך.
2. בחרו **קובץ → ייבוא** ובחרו את ההקלטה שבה מופיע הצליל הטונלי הקצר. היא תופיע כקליפ ברצועה משלה.
3. פתחו את התפריט של הרצועה שברצונכם לבדוק באמצעות הלחצן **אפשרויות רצועה** בכותרת שלה, ובחרו **תצוגת רצועה → ספקטרוגרמה**.
4. גררו בסרגל שמעל הקליפ כדי לבחור את פרק הזמן שבו נשמע הצליל.
5. בחרו **אפקט → עריכה ספקטרלית → בחירת טווח תדרים ספקטרלי**. הגדירו **תדירות מזערית (הרץ)** ל-`200` ואת **תדירות מרבית (הרץ)** ל-`320`, ואז לחצו על **מחיקה ספקטרלית**. הפעולה מסירה את הצליל בתדר 261.6 Hz מהלולאה רק בפרק הזמן שנבחר.
6. לחצו על **השמע** כדי להאזין, ואז על **עצור**.
   *מה אמורים לראות:* הצליל הטונלי נחלש באותו קטע, בעוד ששאר ההקלטה נשארת ללא שינוי.

## טיפים

- השתמשו בספקטרוגרמה כדי לאתר את הצליל, ואז צמצמו את גבולות הזמן והתדר סביבו לפני המחיקה.
- Spectral Delete משפיע על תחום הזמן והתדר שנבחר; Delete רגיל מסיר את כל הקטע שנבחר.
