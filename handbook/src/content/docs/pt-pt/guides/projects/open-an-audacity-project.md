Os projetos criados no Audacity 3 (.aup3) e no Audacity 4 (.aup4) abrem
diretamente. As faixas, os clipes, os nomes e as posições são preservados; os
efeitos que o Soundscaper não inclui são listados para que saiba o que deve
verificar. O ficheiro original não é alterado.

:::note[Já utiliza o Audacity?]
Esta ferramenta corresponde a **Ficheiro → Abrir** no Audacity. Os nomes abaixo
são os usados pelo Soundscaper e, por vezes, são diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um projeto novo e vazio.
2. Escolha **Ficheiro → Abrir** e selecione o projeto. As faixas e os clipes aparecem como estavam no Audacity.
3. O projeto mostra agora um clipe com o nome **Audio 1** e uma faixa com o nome **Fixture track**.
   *Deverá ver:* A faixa e o clipe do projeto do Audacity, com os respetivos nomes.

## Sugestões

- Um projeto antigo `.aup` precisa da respetiva pasta `_data` ao lado do ficheiro; selecione ambos quando lhe for pedido.
- **Ficheiro → Exportar outro → Exportar AUP4** permite fazer o percurso inverso e entregar um projeto ao Audacity.
