Um projeto é mais do que o áudio: são as faixas, clipes, efeitos, marcadores e histórico. Guardar mantém tudo isso na biblioteca local do projeto do navegador neste computador, onde pode ser reaberto a partir do menu Ficheiro. O Soundscaper também guarda à medida que avança, por isso isto é principalmente uma forma de ter a certeza.

:::nota[Vindo do Audacity?]
Isto é o **Ficheiro → Guardar Projeto** do Audacity. Os nomes abaixo são os próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e escolha algo em que trabalhar. O ficheiro cai como um clipe na sua própria faixa.
3. Escolha **Ficheiro → Guardar projeto**. O indicador de guardado na barra de estado mostra que o projeto está guardado.

## Dicas

- Para mover um projeto para outro computador ou manter uma cópia fora do navegador, consulte [Mover um projeto entre computadores](/guides/projects/move-a-project-between-computers/).
- Uma exportação de áudio é uma cópia de audição, não um projeto. Mantenha o projeto se puder editar novamente.
