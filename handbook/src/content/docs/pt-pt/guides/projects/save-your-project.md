## Para que serve este guia {#what-this-guide-is-for}

Um projeto é mais do que o áudio: são as faixas, clipes, efeitos, marcadores e histórico. Guardar mantém tudo isso na biblioteca local do projeto no navegador deste computador, onde pode ser reaberta a partir do menu Ficheiro. O Soundscaper também guarda à medida que avança, por isso isto é principalmente uma forma de ter a certeza.

:::note[Vindo do Audacity?]
Isto é o **Ficheiro → Guardar Projeto** do Audacity. Os nomes abaixo são os próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e escolha algo para trabalhar. Aterrissa como um clipe na sua própria faixa.
3. Escolha **Ficheiro → Guardar projeto**. O indicador de guardado na barra de estado mostra que o projeto está guardado.

## Dicas

- Para mover um projeto para outro computador ou manter uma cópia fora do navegador, consulte [Mover um projeto entre computadores](/guides/projects/move-a-project-between-computers/).
- Uma exportação de áudio é uma cópia para audição, não um projeto. Mantenha o projeto se puder editar novamente.
