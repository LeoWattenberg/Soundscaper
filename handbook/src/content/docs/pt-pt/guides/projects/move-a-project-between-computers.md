A biblioteca do projeto reside num único navegador num único computador. Para levar um projeto em qualquer outro lugar — outra máquina, um colega, uma unidade de backup — exporte-o como um arquivo de projeto. O arquivo `.sscape` contém o áudio e cada edição, e abre-se em qualquer Soundscaper.

:::nota[Vindo do Audacity?]
Isto é o **Arquivo → Salvar Projeto → Fazer Cópia de Segurança do Projeto, seguido de Arquivo → Abrir** do Audacity. Os nomes abaixo são os próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione o material do projeto. Ele é colocado como um clipe na sua própria faixa.
3. Escolha **Arquivo → Exportar arquivo de projeto (.sscape)**. Todo o projeto é descarregado como um único arquivo `.sscape`. Guarde o arquivo num local seguro; é o projeto completo.
4. Escolha **Arquivo → Abrir** e selecione o arquivo. Num computador que ainda não tem o projeto, ele abre diretamente; aqui, onde a biblioteca já o contém, o Soundscaper oferece **Abrir como cópia de só leitura** — pressione-o.
   *Deverá ver:* O projeto abre com a sua faixa e clipe exatamente como exportado.

## Dicas

- Uma cópia de só leitura não pode ser editada até ser salva como um projeto próprio a partir do menu Arquivo.
- O arquivo é um arquivo ZIP com o áudio dentro; não o descompacte manualmente.
