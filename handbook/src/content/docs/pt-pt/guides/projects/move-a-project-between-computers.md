A biblioteca do projeto reside num único navegador num único computador. Para levar um projeto em qualquer outro lugar — outra máquina, um colega, uma unidade de backup — exporte-o como um arquivo de projeto. O `.sscape` arquivo contém o áudio e cada edição, e abre em qualquer Soundscaper.

:::nota[Vindo do Audacity?]
Isto é o **Arquivo → Salvar Projeto → Backup do Projeto, depois Arquivo → Abrir** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar áudio** e selecione o material do projeto. O arquivo cai como um clipe na sua própria faixa.
3. Escolha **Arquivo → Exportar arquivo de projeto (.sscape)**. Todo o projeto é baixado como um único arquivo `.sscape`. Guarde o arquivo em um local seguro; é o projeto completo.
4. Escolha **Arquivo → Abrir arquivo de projeto (.sscape)** e selecione o arquivo. Num computador que ainda não tem o projeto, ele abre diretamente; aqui, onde a biblioteca já o contém, o Soundscaper oferece **Abrir como cópia de apenas leitura** — pressione-o.
   *Você deve ver:* O projeto abre com sua faixa e clipe exatamente como exportado.

## Dicas

- Uma cópia de apenas leitura não pode ser editada até que você a salve como um projeto próprio a partir do menu Arquivo.
- O arquivo é um arquivo ZIP com o áudio dentro; não o descompacte manualmente.
