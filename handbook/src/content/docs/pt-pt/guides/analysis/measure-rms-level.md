## Para que serve este guia {#what-this-guide-is-for}

RMS é uma medida média do nível do sinal ao longo do tempo. Use o analisador Measure RMS para comparar secções ou verificar a intensidade de um trecho antes de o ajustar.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Analyze → Measure RMS (Nyquist)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione o trecho cujo nível médio pretende medir. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Selecionar → Tudo**.
4. Escolha **Analisar → Nyquist → Measure RMS**. Na janela **Measure RMS**, prima **Aplicar**. A janela apresenta os resultados; prima **Fechar** para a fechar.
   *Deverá ver:* O relatório apresenta um nível RMS em dB para cada canal e para o sinal estéreo.

## Sugestões

- RMS descreve o nível médio; use [peak normalization](/guides/volume/normalize-peaks/) quando precisar de definir um valor-alvo para a amostra mais alta.
- Selecione apenas a secção que pretende comparar para que o áudio não relacionado não afete a medição.
