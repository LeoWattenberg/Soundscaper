## Para que serve este guia {#what-this-guide-is-for}

Label Sounds procura num trecho sons separados por silêncio e coloca uma etiqueta à volta de cada som detetado. Pode assinalar frases faladas, impactos isolados ou outros eventos distintos para editar mais tarde.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Analyze → Label Sounds (Nyquist)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação com pausas entre sons. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Selecionar → Tudo**.
4. Escolha **Analisar → Nyquist → Label Sounds**. Na janela **Label Sounds**, defina **Threshold level (dB)** como `-30`, **Minimum silence duration** como `0.5` e **Minimum label interval** como `0.5`; em seguida, prima **Aplicar**. A janela apresenta os resultados; prima **Fechar** para a fechar. Meio segundo de silêncio permite ao analisador separar frases. O limiar define o volume que um som tem de atingir para ser considerado.
5. O projeto passa a mostrar uma pista com o nome **Label Sounds**.
   *Deverá ver:* Surge uma pista Label Sounds com etiquetas à volta das frases detetadas.

## Sugestões

- Reduza **Threshold level (dB)** para incluir sons mais baixos; aumente-o para ignorar o ruído de fundo.
- Aumente **Minimum silence duration** se não pretender que pausas curtas dividam uma frase em várias etiquetas.
