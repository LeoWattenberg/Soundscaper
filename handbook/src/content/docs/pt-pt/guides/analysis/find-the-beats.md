## Para que serve este guia {#what-this-guide-is-for}

O Beat Finder é um dos analisadores Nyquist incluídos. Ele ouve aumentos repentinos no nível acima de um limiar e escreve um rótulo em cada um deles, o que é uma forma rápida de marcar os batidos de um loop ou os golpes em uma tomada de bateria antes de cortá-la.

:::note[Vindo do Audacity?]
Isto é o **Analisar → Beat Finder** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deseja marcar. Ela cai como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Nyquist → Beat Finder**. No diálogo **Beat Finder**, defina o **Limiar Percentual** para `60`, depois pressione **Aplicar**. O diálogo relata o que encontrou; pressione **Fechar** para descartá-lo. Um percentual mais baixo encontra batidas mais silenciosas também; aumente-o se marcar demais.
5. O projeto agora mostra uma faixa chamada **Beat Finder**.
   *Você deve ver:* Uma nova faixa de rótulo chamada Beat Finder abaixo do áudio, com um rótulo em cada batida.

## Dicas

- Os rótulos caem em uma nova faixa de rótulo abaixo do áudio. Renomeie ou exclua qualquer um que o analisador tenha errado.
- **Analisar → Nyquist → Label Sounds** faz um trabalho semelhante para sons inteiros separados por silêncio.
