Uma gravação feita com um nível demasiado alto fica achatada no limite superior
da escala e distorcida. É fácil ouvir o dano, mas difícil localizá-lo à vista
numa gravação longa. A ferramenta Encontrar clipping analisa a seleção e lista
cada sequência de amostras no nível máximo, para que possa decidir se deve
repará-la, voltar a gravá-la ou deixá-la como está.

:::note[Já utiliza o Audacity?]
Esta ferramenta corresponde a **Analisar → Encontrar clipping** no Audacity. Os
nomes abaixo são os usados pelo Soundscaper e, por vezes, são diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um projeto novo e vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação que pretende verificar. É adicionada como um clipe numa faixa própria.
3. Escolha **Seleção → Selecionar tudo**.
4. Escolha **Analisar → Encontrar clipping**. Abre-se o painel **Encontrar clipping**.
   *Deverá ver:* Uma lista das sequências com clipping ou uma indicação de que não foi encontrada nenhuma.

## Sugestões

- Baixar o volume de uma gravação com clipping não a repara: os picos achatados continuam achatados. **Efeito → Remoção de ruído e reparação → Reparar** pode reconstruir uma sequência muito curta com clipping.
- Para evitar clipping na próxima gravação, grave com picos próximos de −12 dB e aumente o nível depois.
