## Para que serve este guia {#what-this-guide-is-for}

Uma frase ou tomada pode precisar do seu próprio nível, panorâmica ou efeitos, enquanto o resto da gravação permanece intacto. Split into new track corta nos limites da seleção e move apenas o trecho selecionado para uma nova pista, na mesma posição da linha temporal.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Edit → Clip → Split New**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação com o trecho que pretende isolar. O ficheiro surge como um clip na sua própria pista.
3. Arraste o cursor na régua acima do clip para selecionar o trecho que pretende mover para uma pista própria.
4. Escolha **Editar → Clipes de áudio → Dividir em nova pista**. A seleção passa para uma nova pista, enquanto o áudio antes e depois permanece na pista original.
5. O projeto passa a mostrar 3 clips.
   *Deverá ver:* A pista original tem um clip de cada lado da seleção, e uma nova pista contém o trecho selecionado.

## Sugestões

- O trecho selecionado mantém a posição original na linha temporal quando passa para a nova pista.
- Se pretender mover apenas esse trecho, use uma pista que contenha apenas esta gravação.
