Copiar um bom coro para substituir um fraco, repetir uma barra, mover uma frase para o fim: o copiar e colar funciona no áudio da mesma forma que no texto. Selecione uma passagem, copie-a, coloque o cursor onde deve ir e cole.

:::nota[Vindo do Audacity?]
Isto é o **Editar → Copiar, depois Editar → Colar (Ctrl+C, Ctrl+V)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione a gravação com a passagem que deseja copiar. O ficheiro é colocado como um clip na sua própria pista.
3. Arraste na régua acima do clip para selecionar a passagem a copiar.
4. Escolha **Editar → Copiar**.
5. Clique na forma de onda onde a cópia deve ir para colocar o cursor lá. A colagem é colocada no cursor; o fim do clip é o local habitual.
6. Escolha **Editar → Colar → Colar**.
7. O projeto agora mostra 2 clips.
   *Deverá ver:* A passagem copiada é um novo clip depois do original.

## Dicas

- **Editar → Colar → Inserir** empurra o áudio posterior em vez de sobrepor a colagem.
- O clipboard funciona entre as abas do projeto, permitindo copiar uma passagem de um projeto para outro.
