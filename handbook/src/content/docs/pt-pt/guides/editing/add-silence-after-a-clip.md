Efeitos como eco e reverb precisam de espaço para ressoar, e um podcast precisa de uma pausa entre segmentos. O gerador de Silêncio insere um intervalo exatamente do comprimento que você digita no cursor, o que é mais preciso do que arrastar clipes separadamente com os olhos.

:::nota[Vindo do Audacity?]
Isto é o **Gerar → Silêncio** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação que precisa de um intervalo depois dela. O arquivo é colocado como um clipe em sua própria faixa.
3. Clique na forma de onda no final do clipe para colocar o cursor lá. O silêncio é inserido no cursor.
4. Escolha **Gerar → Silêncio**. No diálogo **Silêncio**, defina a **Duração (segundos)** para `1`, depois pressione **Gerar**.
5. O projeto agora mostra 2 clipes.
   *Você deve ver:* Um clipe silencioso de um segundo segue o loop.

## Dicas

- Com um intervalo de tempo selecionado, o gerador substitui a seleção em vez de inserir no cursor.
- Para silenciar áudio que já existe em vez de adicionar tempo, veja [Silenciar parte de uma gravação](/guides/cleaning-up/silence-part-of-a-recording/).
