## Para que serve este guia {#what-this-guide-is-for}

Uma divisão não remove nada. Transforma um clipe em dois que ficam um ao lado do outro, permitindo arrastar uma parte para outro local, apagá-la ou aplicar um efeito apenas a ela. A forma mais rápida é usar a ferramenta de divisão: enquanto estiver ativa, cada clique num clipe corta-o nesse ponto.

:::note[Vindo do Audacity?]
Isto é o **Editar → Limites do Clipe → Dividir (Ctrl+I)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione a gravação que deseja dividir. Esta é colocada como um clipe na sua própria pista.
3. Pressione o botão da **Ferramenta de Divisão** na barra de ferramentas. O ponteiro agora corta em vez de selecionar. Pressione **S** para alternar a ferramenta a partir do teclado.
4. Clique na forma de onda onde deseja que o corte seja colocado para posicionar o cursor nesse local. Com a ferramenta de divisão ativa, o clique corta o clipe nesse ponto.
5. O projeto agora mostra 2 clipes.
   *Deverá ver:* Dois clipes estão agora onde havia um.
6. Pressione o botão da **Ferramenta de Divisão** na barra de ferramentas. Pressione-o novamente para voltar ao ponteiro normal.

## Dicas

- Para dividir no ponto de reprodução em vez disso, selecione o clipe e escolha **Editar → Clipes de Áudio → Dividir**; com um intervalo de tempo selecionado, divide em ambos os extremos do intervalo.
- Selecione ambas as metades e escolha **Editar → Clipes de Áudio → Juntar clipes selecionados** para torná-los novamente num único clipe.
