## Para que serve este guia {#what-this-guide-is-for}

Os marcadores são notas na linha do tempo: onde começa um capítulo, onde é necessário corrigir um erro, onde começa a boa tomada. Eles não alteram o áudio, acompanham o projeto e podem ser exportados como um ficheiro de etiquetas para outras ferramentas.

:::note[Vindo do Audacity?]
Isto é o **Editar → Etiquetas → Adicionar Etiqueta na Seleção (Ctrl+B)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione a gravação que deseja marcar. Ela é colocada como um clipe na sua própria faixa.
3. Escolha **Ver → Marcadores**. Isto adiciona uma faixa de marcadores acima das faixas. Os marcadores existem sem ela, mas a faixa é onde você os vê e edita.
4. Clique na forma de onda onde o marcador deve ir para colocar o cursor lá. O marcador é colocado onde o cursor está.
5. Com o painel de Marcadores aberto (**Janela → Marcadores** mostra-o), pressione **Adicionar marcador na cabeça de reprodução**. Pressione Enter no novo marcador, digite `Chorus` e pressione Enter novamente para nomeá-lo.
   *Você deve ver:* O marcador aparece na faixa acima das faixas e na lista do painel, com o nome que você digitou.

## Dicas

- Com um intervalo de tempo selecionado, o mesmo botão adiciona uma região nomeada em vez de um único ponto.
- **Ficheiro → Exportar outros → Exportar etiquetas** grava os marcadores como um ficheiro de texto que o Audacity e outros editores podem ler.
