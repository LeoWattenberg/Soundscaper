## Para que serve este guia {#what-this-guide-is-for}

Inserir abre espaço para o áudio copiado em vez de o colocar sobre o som existente. O áudio posterior na faixa de destino é deslocado para a direita pela duração da passagem copiada. Use esta opção para repetir uma frase ou acrescentar uma fala no meio de uma gravação.

:::note[Veio do Audacity?]
No Audacity, isto corresponde a **Edit → Copy, then Edit → Paste**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica pronto um projeto novo e vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação com a passagem que pretende copiar. Será inserida como um clip numa faixa própria.
3. Arraste na régua acima do clip para selecionar a passagem que pretende inserir noutro local.
4. Escolha **Editar → Copiar**.
5. Clique na forma de onda do clip de destino, no ponto onde a cópia deve começar, para colocar aí o cursor. O clique remove o intervalo selecionado e define o ponto de inserção.
6. Escolha **Editar → Colar → Inserir**.
7. O projeto mostra agora 3 clips.
   *Deverá ver:* A passagem inserida fica entre dois segmentos do clip original. O segmento posterior foi deslocado para a direita e o anterior manteve a posição.

## Sugestões

- Inserir desloca o áudio posterior na faixa de destino. **Editar → Colar → Inserir e manter a sincronização** abre espaço em todas as faixas quando é necessário manter a sincronização.
- **Editar → Desfazer** remove a inserção e restaura a posição do áudio posterior.
