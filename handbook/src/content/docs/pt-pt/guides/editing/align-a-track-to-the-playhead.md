## Para que serve este guia {#what-this-guide-is-for}

Quando uma gravação tem de começar num ponto de referência específico, arrastá-la a olho pode ser impreciso. Align start to playhead move o conteúdo da pista selecionada até o início coincidir com o cursor, preservando a duração da gravação.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Tracks → Align Tracks → Align Start to Playhead**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação que pretende colocar num ponto de referência. O ficheiro surge como um clip na sua própria pista.
3. Arraste o clip pela barra de nome para um ponto mais à frente na linha temporal. Mova primeiro o clip para que o cursor possa marcar uma posição inicial diferente.
4. Clique na forma de onda no ponto em que a gravação deve começar para aí colocar o cursor.
5. Escolha **Faixas → Alinhar conteúdo → Alinhar início à posição de reprodução**. O clip mais antigo da pista selecionada é movido para a posição do cursor.
6. A gravação começa agora no cursor de reprodução.
   *Deverá ver:* O clip começa no ponto de referência e mantém a duração original.

## Sugestões

- O alinhamento move todos os clips de cada pista selecionada. Para mover apenas uma gravação, use uma pista que contenha apenas essa gravação.
- Escolha **Faixas → Alinhar conteúdo → Alinhar início a zero** para voltar a colocar uma pista selecionada no início do projeto.
