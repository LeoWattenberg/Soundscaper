## Para que serve este guia {#what-this-guide-is-for}

A edição mais comum é: um falso início, uma tosse, uma nova tentativa. Selecione a parte que não deseja, remova-a e deixe o resto da faixa deslizar para a esquerda para fechar o espaço.

:::note[Vindo do Audacity?]
Isto é o **Selecionar a região, depois Editar → Apagar (ou Ctrl+K)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação com o erro. Ela é colocada como um clipe em sua própria faixa.
3. Arraste na régua acima do clipe para selecionar exatamente a parte que deseja remover. Aumente o zoom com **Visualizar → Zoom → Aumentar Zoom** se o erro for curto.
4. Escolha **Editar → Recortar → Recortar e fechar espaço por faixa**. A seleção é removida e tudo depois dela move-se para a esquerda, então nenhum silêncio é deixado para trás.
5. O projeto agora mostra 2 clipes.
   *Você deve ver:* Dois clipes estão lado a lado onde a seleção estava, e a faixa é mais curta exatamente por esse valor. Reproduza através da junção para verificar.

## Dicas

- **Recortar e deixar espaço** remove o som, mas mantém o tempo, o que é correto quando a faixa precisa permanecer sincronizada com um vídeo ou outra faixa.
- Não está satisfeito com a junção? **Editar → Desfazer**, ajuste a seleção e tente novamente.
