## Para que serve este guia {#what-this-guide-is-for}

As pausas longas tornam uma tomada falada mais fácil de editar quando cada frase é um clip próprio. Split clips at silences remove os trechos silenciosos e deixa as frases separadas no mesmo lugar, sem alterar as respetivas posições na linha temporal.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Edit → Audio Clips → Detach at Silences (Audacity 3)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a tomada com pausas entre as frases. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Editar → Clipes de áudio → Dividir clipes nos silêncios**. Cada trecho silencioso detetado é removido do clip e as frases de cada lado passam a clips separados.
4. As frases são agora clips separados nas posições originais.
   *Deverá ver:* Cada frase mantém o seu lugar na gravação.

## Sugestões

- Este comando separa um clip nos pontos de silêncio; não encurta os intervalos entre as frases.
- Para manter as pausas, mas encurtá-las, use antes [Remove silent pauses](/guides/cleaning-up/remove-silent-pauses/).
