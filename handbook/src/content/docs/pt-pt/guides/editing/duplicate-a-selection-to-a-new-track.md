Duplicar copia a seleção para uma nova faixa diretamente abaixo, na mesma posição no tempo. É o primeiro passo habitual para o processamento paralelo — uma cópia fortemente comprimida misturada sob a original, uma faixa apenas com reverb, um vocal duplicado.

:::nota[Vindo do Audacity?]
Isto é o **Editar → Duplicar (Ctrl+D)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione o ficheiro de gravação com a passagem a duplicar. O ficheiro é colocado como um clipe na sua própria faixa.
3. Arraste na régua acima do clipe para selecionar a passagem a duplicar.
4. Escolha **Editar → Duplicar**.
5. O projeto agora mostra 2 clipes.
   *Deverá ver:* Um segundo clipe contendo apenas a seleção, numa nova faixa abaixo da primeira, alinhada no tempo.

## Dicas

- Silencie uma das duas faixas para ouvir a outra sozinha enquanto a molda.
- Quando estiver satisfeito com a mistura, [misture as faixas](/guides/tracks-and-export/mix-tracks-into-one/).
