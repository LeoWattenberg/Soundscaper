## Para que serve este guia {#what-this-guide-is-for}

Quando uma gravação tem de permanecer sincronizada com outra faixa ou com um vídeo, fechar um espaço deslocaria todas as referências posteriores. Eliminar e deixar espaço remove o áudio selecionado e deixa um espaço vazio entre as partes restantes. O áudio após a seleção mantém-se no momento original.

:::note[Veio do Audacity?]
Isto corresponde a **Editar → Eliminar → Eliminar e deixar espaço** do Audacity. Os nomes abaixo são os do Soundscaper e, por vezes, podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione a gravação com o excerto que pretende remover. É inserida como um clip na sua própria faixa.
3. Arraste na régua acima do clip para selecionar o excerto indesejado dentro do clip.
4. Escolha **Editar → Eliminar → Eliminar e deixar intervalo**.
5. O projeto apresenta agora 2 clips.
   *Deverá ver:* As partes restantes ficam separadas por um espaço no local onde estava o excerto. A parte posterior não foi deslocada para a esquerda.

## Sugestões

- Para fechar o espaço, siga [Remover um erro de uma gravação](/guides/editing/cut-out-a-mistake/).
- **Editar → Desfazer** restaura o excerto eliminado para que possa ajustar a seleção e tentar novamente.
