Os clipes são livres para se mover. Arrastar um clipe pela sua barra de nome desliza-o ao longo da faixa — para deixar um espaço no início, para se sentar depois de outro clipe, ou para alinhar com uma dica no vídeo. Arrastar para cima ou para baixo move-o para outra faixa.

:::nota[Vindo do Audacity?]
Isto é o **Ferramenta de Deslocamento no Tempo (F5) do Audacity**, ou arrastar a barra do clipe no Audacity 3.1 e posterior. Os nomes abaixo são os próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação que deseja mover. O arquivo cai como um clipe em sua própria faixa.
3. Arraste o clipe pela sua barra de nome para onde deve começar. O clipe segue o ponteiro; o seu novo tempo de início é exibido na barra de seleção enquanto arrasta.
4. O clipe agora começa onde você o deixou cair.
   *Você deve ver:* A faixa está silenciosa até o clipe começar.

## Dicas

- Ative o encaixe da barra de transporte para que um clipe arrastado se trave em segundos, batidas ou quadros.
- Mantenha Shift enquanto arrasta para manter o clipe em sua própria faixa.
