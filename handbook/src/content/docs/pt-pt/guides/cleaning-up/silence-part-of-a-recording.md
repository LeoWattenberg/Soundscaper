Às vezes, quer eliminar uma passagem, mas não o tempo que ocupa — um telefone a tocar durante uma pausa, um nome que precisa de ser censurado. O silenciamento mantém a gravação com a mesma duração e apenas atenua a parte selecionada.

:::nota[Vindo do Audacity?]
Isto é o **Editar → Remover Especial → Silenciar Áudio** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione a gravação com a passagem a silenciar. Esta aparece como um clipe na sua própria pista.
3. Arraste a régua acima do clipe para selecionar apenas a parte que pretende silenciar.
4. Escolha **Editar → Remover especial → Silenciar áudio**.
5. O projeto agora mostra 3 clipes.
   *Deve ver:* A forma de onda está plana no novo clipe do meio, entre o áudio inalterado de ambos os lados.

## Dicas

- O silêncio é uma edição normal: **Editar → Desfazer** traz o áudio de volta.
- Para remover o tempo, bem como o som, consulte [Cortar um erro de uma gravação](/guides/editing/cut-out-a-mistake/).
