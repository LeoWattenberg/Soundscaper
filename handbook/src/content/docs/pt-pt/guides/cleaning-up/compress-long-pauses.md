## Para que serve este guia {#what-this-guide-is-for}

As pausas longas podem tornar a fala lenta, mas cortar todas as pausas pode dificultar a compreensão. Truncate Silence comprime apenas a parte excedente das pausas que ultrapassem uma duração mínima.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Effect → Special → Truncate Silence**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione uma gravação com pausas que lhe pareçam demasiado longas. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Selecionar → Tudo**.
4. Escolha **Efeito → Especial → Truncar silêncio**. Na janela **Truncar silêncio**, defina **Limiar** como `-40` e **Silêncio mínimo** como `0.5`, escolha **Comprimir silêncio em excesso** em **Ação** e defina **Comprimir para** como `50`; em seguida, prima **Aplicar à seleção**. O silêncio superior a 0,5 segundos é encurtado para metade da duração excedente, mantendo uma pausa entre as frases.
5. Prima **Reproduzir** para ouvir e, em seguida, **Parar**.
   *Deverá ouvir:* As pausas longas são mais curtas, mas continua a haver algum silêncio entre as frases.

## Sugestões

- Aumente **Silêncio mínimo** para deixar intactas as pausas mais curtas, ou reduza **Comprimir para** para encurtar ainda mais as pausas longas.
- Esteja atento a respirações ou finais de frase cortados; anule a alteração se o ritmo ficar pouco natural.
