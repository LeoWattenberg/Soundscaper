## Para que serve este guia {#what-this-guide-is-for}

Duplicar faixa copia a faixa inteira, incluindo todos os clips e as respetivas posições na linha temporal. Utilize a cópia para experimentar outra edição ou um efeito sem perder o original. Selecionar um clip identifica a faixa a duplicar; o comando também copia os restantes clips dessa faixa.

:::note[Já utiliza o Audacity?]
No Audacity, isto corresponde a **Tracks → Duplicate (Audacity 4)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica pronto um projeto novo e vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação na faixa que pretende duplicar. Será inserida como um clip numa faixa própria.
3. Clique na forma de onda no ponto em que pretende dividir a gravação em duas partes editáveis de forma independente, colocando aí o cursor. Ignore esta colocação do cursor e o passo Split seguinte se a faixa já tiver vários clips ou se pretender mantê-la como um único clip.
4. Escolha **Editar → Clipes de áudio → Dividir**.
5. O projeto mostra agora 2 clips.
   *Deverá ver:* A faixa contém dois clips, prontos para serem copiados em conjunto.
6. Prima **Tab** para focar um clip da faixa e prima **Enter** para o selecionar.
7. Escolha **Faixas → Duplicar faixa**.
8. O projeto mostra agora 4 clips e 3 faixas.
   *Deverá ver:* O original e a cópia contêm ambos os clips nas mesmas posições na linha temporal.

## Sugestões

- O original e a cópia são reproduzidos em simultâneo. [Silencie uma faixa ou coloque-a em solo](/guides/tracks-and-export/mute-and-solo-tracks/) para ouvir uma versão de cada vez durante a comparação.
- Para copiar apenas uma passagem, [duplique uma seleção para uma nova faixa](/guides/editing/duplicate-a-selection-to-a-new-track/).
- **Editar → Desfazer** remove a faixa duplicada.
