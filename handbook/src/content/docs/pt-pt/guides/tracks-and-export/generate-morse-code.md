## Para que serve este guia {#what-this-guide-is-for}

O código Morse transforma uma mensagem em pontos, traços e espaços cronometrados. O gerador mostra uma prévia da codificação e calcula a duração do clip com base na mensagem e na velocidade.

:::note[Já utiliza o Audacity?]
O Audacity não tem um equivalente integrado diretamente correspondente: **No directly matching built-in Morse code generator**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, um projeto novo e vazio estará pronto.
2. Escolha **Gerar → Código Morse**. Na janela **Código Morse**, defina **Mensagem** como `SOS`, **Velocidade (palavras por minuto)** como `20`, **Frequência (Hz)** como `600` e **Amplitude** como `0.2`; depois, prima **Gerar**. Troque a mensagem de exemplo pelo seu texto e confira a prévia da codificação; caracteres não aceitos impedem a geração.
3. O projeto agora mostra 1 clip.
   *Você deverá ver:* O clip contém a mensagem em Morse; sua duração depende da velocidade escolhida.

## Sugestões

- Uma velocidade menor aumenta a duração dos pontos, traços e espaços sem alterar a frequência do tom.
- Duration é um resultado somente para leitura. Altere a mensagem ou a velocidade para mudar a duração do clip.
