## Para que serve este guia {#what-this-guide-is-for}

Risset Drum combina um tom decrescente com uma banda de ruído para criar um golpe de percussão sintético. Ajuste o decaimento para obter um acento curto ou um som mais longo e ressonante.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Generate → Risset Drum (Nyquist)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Gerar → Nyquist → Risset Drum**. Na janela **Risset Drum**, defina **Frequency (Hz)** como `100`, **Decay (seconds)** como `1.5` e **Amplitude (0 - 1)** como `0.5`; em seguida, prima **Aplicar**. Um decaimento de 1,5 segundos mantém o golpe compacto; a amplitude moderada deixa margem para o misturar com outros sons.
3. O projeto passa a mostrar 1 clip.
   *Deverá ouvir:* Surge na linha temporal um clip percussivo não silencioso com cerca de 1,5 segundos.

## Sugestões

- Reduza **Frequency (Hz)** para um golpe mais grave; aumente-a para um som mais agudo e brilhante.
- Aumente **Amount of noise in mix (percent)** para obter um ataque com mais ruído.
