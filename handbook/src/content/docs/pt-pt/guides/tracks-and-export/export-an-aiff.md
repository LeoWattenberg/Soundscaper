## Para que serve este guia {#what-this-guide-is-for}

AIFF é um formato PCM sem compressão, frequentemente utilizado em fluxos de trabalho áudio nos sistemas Apple. Exporte neste formato quando uma aplicação de destino ou especificação de entrega o exigir.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **File → Export Audio → Other uncompressed files → AIFF (Audacity 3)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação ou mistura a entregar. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Ficheiro → Exportar áudio**, defina **Formato** como **AIFF** e prima **Exportar**. O ficheiro é transferido quando a conversão terminar, e a ligação permanece na janela.
   *Deverá ver:* A janela de exportação disponibiliza um ficheiro `.aiff` para transferir.

## Sugestões

- AIFF não tem perdas, mas ocupa mais espaço do que formatos comprimidos como [FLAC](/guides/tracks-and-export/export-a-flac/).
- Escolha um formato e uma frequência de amostragem que correspondam aos requisitos de entrega.
