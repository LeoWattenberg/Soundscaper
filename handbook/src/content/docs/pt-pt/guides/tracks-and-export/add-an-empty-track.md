## Para que serve este guia {#what-this-guide-is-for}

A importação de um ficheiro cria uma faixa para si, mas uma gravação ou um colar precisam de um local para aterrar. O botão Adicionar faixa acima da lista de faixas cria uma faixa de áudio vazia; uma faixa de etiqueta contém marcadores e texto em vez de som.

:::note[Vindo do Audacity?]
Isto é o **Faixas → Adicionar Nova → Faixa Mono** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carregar.
2. Pressione **Adicionar faixa** acima da lista de faixas e escolha **Faixa de áudio**.
3. O projeto agora mostra 2 faixas.
   *Deverá ver:* Uma segunda faixa de áudio vazia abaixo da primeira.

## Dicas

- Renomeie a faixa a partir do seu menu para que uma sessão com muitas faixas permaneça legível.
- Arraste uma faixa pelo seu cabeçalho para a reordenar.
