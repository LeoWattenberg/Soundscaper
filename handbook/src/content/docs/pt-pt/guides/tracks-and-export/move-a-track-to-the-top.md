## Para que serve este guia {#what-this-guide-is-for}

Mover uma pista para cima ou para baixo altera a sua posição vertical no projeto, não as horas de início dos clips. Move track to top é útil para trazer uma voz ou outra parte importante para cima das restantes.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Track menu → Move track → Move track to top**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação que deve ficar por baixo. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Ficheiro → Importar** e selecione a gravação que pretende colocar no topo. O ficheiro surge como um clip na sua própria pista.
4. Abra o menu da pista que pretende colocar no topo através do botão **Opções de faixa** no respetivo cabeçalho e escolha **Mover faixa → Mover faixa para o topo**. O comando altera a posição vertical da pista, preservando o tempo dos clips.
5. O projeto passa a mostrar 2 clips.
   *Deverá ver:* A pista selecionada fica acima da outra e os dois clips mantêm as posições na linha temporal.

## Sugestões

- Use **Mover faixa → Mover faixa para baixo** no menu da pista para inverter a ordem.
- A ordem das pistas determina qual o áudio que aparece acima dos outros no projeto; não altera a mistura nem a panorâmica.
