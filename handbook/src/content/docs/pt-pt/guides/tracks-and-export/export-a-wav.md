## Para que serve este guia {#what-this-guide-is-for}

O WAV mantém cada amostra exatamente como o editor a tem. Utilize-o para masters, para entregar áudio a um editor de vídeo ou outro DAW, e para qualquer coisa que possa querer processar novamente.

:::note[Vindo do Audacity?]
Isto é o **Arquivo → Exportar Áudio → WAV** do Audacity. Os nomes abaixo são os próprios da Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação a entregar. Ela cai como um clipe na sua própria faixa.
3. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **WAV**, e pressione **Exportar**. O arquivo é baixado assim que a renderização termina, e seu link permanece no diálogo.

## Dicas

- Os arquivos WAV são grandes: cerca de dez megabytes por minuto para estéreo em qualidade de CD.
- Para exportar cada faixa como seu próprio arquivo, defina **Modo** no diálogo de exportação para caules individuais.
