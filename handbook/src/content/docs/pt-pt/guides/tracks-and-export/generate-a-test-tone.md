Um tom com frequência e nível conhecidos é a primeira opção a considerar ao
verificar uma cadeia de sinal, calibrar um nível ou criar um sinal sonoro para
cobrir uma palavra. Os geradores criam áudio na posição do cursor ou substituem
a seleção, se houver uma.

:::note[Já utiliza o Audacity?]
Esta ferramenta corresponde a **Gerar → Tom** no Audacity. Os nomes abaixo são
os usados pelo Soundscaper e, por vezes, são diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um projeto novo e vazio.
2. Escolha **Gerar → Tom**. Na caixa de diálogo **Tom**, defina **Frequência (Hz)** como `440` e **Duração (segundos)** como `2`; em seguida, prima **Gerar**. 440 Hz é o lá de afinação, a referência padrão de afinação.
3. O projeto mostra agora 1 clipe.
   *Deverá ver:* Um novo clipe com dois segundos de tom.

## Sugestões

- Se for misturar o tom com outros sons, defina **Amplitude** como `0.5` ou menos.
- **Gerar → Silêncio** funciona da mesma forma e é a maneira mais fácil de acrescentar um intervalo entre clipes.
