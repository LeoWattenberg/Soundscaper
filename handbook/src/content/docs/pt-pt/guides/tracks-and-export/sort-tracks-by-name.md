## Para que serve este guia {#what-this-guide-is-for}

Num projeto com várias tomadas, é mais fácil encontrar conteúdos relacionados quando os nomes das pistas ficam juntos. Sort by name reordena as pistas alfabeticamente sem alterar o ponto inicial de nenhum clip na linha temporal.

:::note[Já utiliza o Audacity?]
No Audacity, o equivalente é **Tracks → Sort Tracks → Sort by Name**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, fica disponível um novo projeto vazio.
2. Escolha **Ficheiro → Importar** e selecione a gravação que pretende colocar depois da outra, por ordem de nome. O ficheiro surge como um clip na sua própria pista.
3. Escolha **Ficheiro → Importar** e selecione a gravação que pretende colocar antes da outra, por ordem de nome. O ficheiro surge como um clip na sua própria pista.
4. Escolha **Faixas → Ordenar pistas → Ordenar por nome**. Os nomes das pistas são ordenados alfabeticamente.
5. O projeto passa a mostrar 2 clips.
   *Deverá ver:* As duas gravações continuam no projeto e os nomes das pistas estão por ordem alfabética.

## Sugestões

- A ordenação altera a ordem das pistas, não o tempo dos clips nem o conteúdo áudio.
- Use **Faixas → Ordenar pistas → Ordenar por tempo** quando pretender que a ordem das pistas siga as horas de início dos clips.
