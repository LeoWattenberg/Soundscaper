## Para que serve este guia {#what-this-guide-is-for}

Um ficheiro MP3 é pequeno, reproduz em qualquer lugar e é o formato esperado pela maioria dos anfitriões de podcasts e aplicações de mensagens. A exportação renderiza todo o projeto — cada faixa, efeito e edição — num único ficheiro.

:::note[Vindo do Audacity?]
Isto é o **Arquivo → Exportar Áudio → MP3** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação a publicar. Esta é colocada como um clipe na sua própria faixa.
3. Escolha **Arquivo → Exportar áudio**, defina o **Formato** como **MP3** e pressione **Exportar**. O ficheiro é descarregado assim que a renderização terminar, e o seu link permanece no diálogo. O ficheiro é codificado no navegador; nada sai do seu computador.

## Dicas

- Um MP3 é uma cópia de entrega, não um backup. Mantenha o projeto ou exporte um WAV também se puder editar novamente.
- Picos exatamente no limite máximo podem ser cortados após a codificação. Normalize para -1 dB ou menos antes de exportar.
- O Modo de Taxa de Bits decide como o codificador gasta os bits. O preset Padrão varia a taxa para se adequar ao material e é a resposta certa para a maioria das entregas; escolha Constante quando um anfitrião ou um reprodutor de hardware mais antigo solicitarem uma taxa fixa.
