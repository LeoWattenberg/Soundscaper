Cada episódio recebe o mesmo tratamento: normalizar, desvanecer o final. Uma macro grava essa sequência uma vez e executa-a sempre que solicitado, com as definições escolhidas, de modo que uma rotina de dez passos se torna um único comando. O Audacity 3 tinha um Gestor de Macros para exatamente isto; o Audacity 4 ainda não trouxe de volta as macros.

:::nota[Vindo do Audacity?]
Isto é **Ferramentas → Macros → Gerir Macros e Aplicar Macro (Audacity 3; o Audacity 4 não tem macros)**. Os nomes abaixo são os próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione uma gravação para processar. O ficheiro é colocado como um clipe na sua própria pista.
3. Escolha **Selecionar → Selecionar tudo**. Uma macro é executada na seleção, tal como cada efeito seria executado individualmente.
4. Escolha **Ferramentas → Gestor de Macros** e pressione **Nova macro**. Digite `Episode finish` em **Nome da Macro**. Pressione **Adicionar efeito** e escolha **Normalizar** e **Desvanecer para fora**, pressionando **Adicionar efeito** novamente para cada um. Pressione **Executar macro**; a caixa de diálogo relata que a macro foi aplicada. Pressione **Fechar**. Cada passo mantém as suas definições padrão aqui; pressione o botão **Selecionar efeito** de um passo para alterá-lo antes de executar.
   *Deverá ver:* A gravação é normalizada e desvanecer-se para o silêncio no final.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.

## Dicas

- A macro é salva com o editor, então está à espera em **Ferramentas → Gestor de Macros** para a próxima gravação.
- **Exportar macro** escreve a cadeia como um ficheiro de texto de macro do Audacity, e **Importar macro** lê um, então uma rotina pode mover-se entre os dois programas.
