A transposição de uma faixa de acompanhamento para a tonalidade de um cantor ou o ajuste de um instrumento que estava ligeiramente desafinado é uma alteração de altura que não deve alterar o comprimento. A Alterar Altura desloca a seleção por semitons inteiros e deixa o tempo inalterado.

:::nota[Vindo do Audacity?]
Isto é o **Efeito → Altura e Tempo → Alterar Altura** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione o ficheiro de gravação a transpor. O ficheiro é colocado como um clipe na sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Altura e tempo → Alterar altura**. No diálogo **Alterar altura**, defina **Semitons** para `2`, depois pressione **Aplicar à seleção**. Dois semitons é um tom inteiro para cima. Valores negativos descem.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* A gravação está mais alta e exatamente com o mesmo comprimento de antes.

## Dicas

- **Preservar formantes** mantém uma voz soando como a mesma pessoa quando é deslocada; desligue-a para instrumentos se o resultado soar nasal.
- Para alterar a altura e a velocidade ao mesmo tempo, como uma fita, use **Alterar velocidade e altura** no mesmo submenu.
