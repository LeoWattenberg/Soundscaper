## Para que serve este guia {#what-this-guide-is-for}

Um phaser mistura um som com uma cópia de si mesmo passada através de estágios de passagem total móveis, de modo que as entalhes varrem o espectro para cima e para baixo no ritmo de um oscilador lento. Num guitarra, um piano elétrico ou um pad, ele dá o efeito de rotação ouvido em inúmeros discos. O Audacity 3 veio com um phaser e o Audacity 4 não, por isso este é um a ter em conta aqui.

:::note[Vindo do Audacity?]
Este é o **Efeito → Phaser (Audacity 3; o Audacity 4 não tem Phaser)**. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione o som a tratar. Ele é colocado como um clipe na sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Phaser**. No diálogo **Phaser**, defina **Estágios** para `4` e **Frequência LFO** para `0.6`, depois pressione **Aplicar à seleção**. Mais estágios criam entalhes mais profundos; quatro é um pedal clássico. A frequência LFO é a velocidade com que a varredura se move — 0,6 Hz é uma rotação lenta e musical.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O som gira lentamente à medida que os entalhes varrem através dele.

## Dicas

- **Feedback** afia os entalhes num efeito de varredura mais metálico e ressonante; mantenha-o perto de zero para um efeito sutil.
- O phaser também funciona como um efeito em tempo real no rack de uma faixa, para que você possa ouvir a varredura enquanto a ajusta: [Adicionar um efeito em tempo real a uma faixa](/guides/effects/add-a-realtime-effect-to-a-track/).
