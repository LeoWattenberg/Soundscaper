Um pedal wah varre um filtro ressonante para cima e para baixo no espectro; o efeito Wahwah faz o varredura por si a uma taxa que define. É adequado para guitarras, teclados e qualquer coisa com sustentação constante.

:::nota[Vindo do Audacity?]
Este é o **Efeito → Wahwah** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione a gravação para aplicar o wah. Esta é colocada como um clipe na sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Wahwah**. No diálogo **Wahwah**, defina a **Frequência LFO** para `2` e a **Profundidade** para `80`, depois pressione **Aplicar à seleção**. A frequência LFO é o número de varreduras por segundo; a profundidade é a distância que o filtro percorre.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Deverá ver:* A gravação oscila com um tom que se assemelha a uma vogal.

## Dicas

- **Ressonância** afia o pico do filtro; valores elevados fazem ruído.
- O **Phaser** no mesmo submenu dá um movimento mais suave e giratório.
