## Para que serve este guia {#what-this-guide-is-for}

A distorção corta ou dobra a forma de onda para que ganhe harmónicos. Um pouco de sobrealimentação suave aquece um baixo ou um sintetizador; muito transforma uma guitarra numa parede. O tipo escolhe a forma da curva; o limiar define quanto do sinal o atinge.

:::note[Vindo do Audacity?]
Isto é o **Efeito → Distorção** do Audacity. Os nomes abaixo são os próprios da Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar** e selecione o som a distorcer. Ele cai como um clipe na sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Distorção**. No diálogo **Distorção**, escolha **Sobrealimentação Suave** para **Tipo de Distorção** e defina o **Limiar** para `-12`, depois pressione **Aplicar à seleção**. A Sobrealimentação Suave arredonda os picos em vez de os cortar. Um limiar mais baixo impulsiona mais do sinal para a curva.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O som é mais áspero e seus picos são arredondados.

## Dicas

- Ative o **Bloco DC** se o resultado estiver deslocado do centro na forma de onda.
- A distorção adiciona nível. Normalizar depois se os picos atingirem o topo.
