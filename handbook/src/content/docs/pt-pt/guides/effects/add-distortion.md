A distorção corta ou dobra a forma de onda para que ganhe harmónicos. Um pouco de sobrealimentação suave aquece um baixo ou um sintetizador; muito transforma uma guitarra numa parede. O tipo escolhe a forma da curva; o limiar define quanto do sinal o atinge.

:::nota[Vindo do Audacity?]
Isto é o **Efeito → Distorção** do Audacity. Os nomes abaixo são os próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione o som que deseja distorcer. O ficheiro é colocado como um clipe na sua própria pista.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Distorção**. No diálogo **Distorção**, escolha **Sobrealimentação Suave** para **Tipo de distorção** e defina o **Limiar** para `-12`, depois pressione **Aplicar à seleção**. A Sobrealimentação Suave arreda os picos em vez de os cortar. Um limiar mais baixo impulsiona mais do sinal para a curva.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O som é mais áspero e os seus picos são arredondados.

## Dicas

- Ative o **Bloco DC** se o resultado estiver deslocado para o centro na forma de onda.
- A distorção adiciona nível. Normalize depois se os picos atingirem o topo.
