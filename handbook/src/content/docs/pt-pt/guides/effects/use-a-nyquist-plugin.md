Os plug-ins Nyquist do Audacity são pequenos scripts que adicionam efeitos, geradores e analisadores, e o Soundscaper agrupa os mesmos sob um submenu Nyquist em cada menu. O Tremolo é um bom primeiro exemplo: ele faz com que o volume oscile a uma taxa definida.

:::nota[Vindo do Audacity?]
Este é o **Efeito → Tremolo (um plug-in Nyquist)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que por vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação na qual deseja experimentar o plug-in. O ficheiro é colocado como um clipe na sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Nyquist → Tremolo**. No diálogo **Tremolo**, defina a **Frequência (Hz)** para `6` e pressione **Aplicar**. Seis oscilações por segundo é um tremolo de amplificador clássico.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* A gravação varia em volume.

## Dicas

- Os menus Gerar e Analisar também têm submenus Nyquist próprios, com plug-ins como Pluck e Beat Finder.
- **Ferramentas → Prompt Nyquist** executa um script que você mesmo digita.
