Este tutorial guia-o numa passagem completa do editor num loop musical de dois segundos: trazendo um ficheiro, ouvindo-o, alterando-o com um efeito, cortando-o em dois, renderizando um ficheiro que pode ser reproduzido em qualquer lugar e salvando o projeto para poder voltar a ele. Não é necessário ter qualquer conhecimento de áudio; é um passeio pelos locais onde as coisas estão.

:::dica[O que precisará]
- Baixe [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) — um loop estéreo de dois segundos.

Todos os passos abaixo funcionam nestes ficheiros exatamente como estão, então o que vê deve corresponder ao que o tutorial diz. O Soundscaper funciona no navegador; não é necessário instalar nada.
:::

## O que aprenderá

- Como um ficheiro se torna um clipe numa faixa e como reproduzi-lo.
- Como dividir um clipe com a ferramenta de divisão.
- Como selecionar áudio e aplicar um efeito à seleção.
- A diferença entre exportar um ficheiro e salvar um projeto.

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Ficheiro → Importar áudio** e selecione `guide-music-loop.wav` — um loop estéreo de dois segundos. O ficheiro cai como um clipe na sua própria faixa.
3. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Deverá ver:* O cursor de reprodução percorre o clipe e o loop reproduz uma vez.
4. Pressione o botão **Ferramenta de Divisão** na barra de ferramentas. Enquanto a ferramenta de divisão estiver ativa, um clique num clipe corta-o nesse ponto em vez de selecionar.
5. Clique na forma de onda a meio para colocar o cursor nesse local.
6. Pressione o botão **Ferramenta de Divisão** na barra de ferramentas. Pressione-o novamente para voltar ao ponteiro normal.
7. O projeto agora mostra 2 clipes.
   *Deverá ver:* Dois clipes estão lado a lado onde havia um, cada um com a sua própria barra de nome.
8. Escolha **Selecionar → Selecionar tudo**. Um efeito aplica-se a qualquer coisa selecionada. Selecionar tudo leva todo o projeto, incluindo ambos os clipes.
9. Escolha **Efeito → Desvanecimento → Desvanecer para fora**. O efeito aplica-se à seleção imediatamente.
   *Deverá ver:* A forma de onda diminui até nada até o final do segundo clipe.
10. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Deverá ver:* O loop atenua em vez de parar abruptamente.
11. Escolha **Ficheiro → Exportar áudio**, defina **Formato** como **WAV** e pressione **Exportar**. O ficheiro é descarregado assim que o renderizar terminar, e o seu link permanece no diálogo. Uma exportação renderiza o que ouve num ficheiro para outros programas. Não altera o projeto.
12. Escolha **Ficheiro → Salvar projeto**. O indicador de salvamento na barra de estado mostra que o projeto está salvo. O projeto — clipes, edições, histórico — vive na biblioteca de projetos do navegador neste computador. Salvar mantém-no lá.
