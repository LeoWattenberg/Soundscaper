Reduza as reflexões da sala em discursos gravados com um modelo local de desreverberação.

## Disponibilidade atual {#current-availability}

As compilações de ambiente de trabalho embalam o motor onnxruntime-node 1.29.0 necessário para macOS arm64, Linux x64, Linux arm64, Windows x64 e Windows arm64. Instale os pesos deste modelo através do Gestor de Modelos e execute a sua tarefa localmente. Estes são os alvos de compilação suportados; consulte o relatório de teste noturno para resultados sobre um pacote e máquina específicos.

## Utilize este modelo {#use-this-model}

Abra **Ferramentas → Processamento Local Avançado → Desreverberação** numa plataforma com o tempo de execução nativo necessário. A assistência local funciona no editor de ambiente de trabalho.

1. Selecione o discurso afetado pelas reflexões da sala.
2. Instale o modelo através do Gestor de Modelos e execute a desreverberação.
3. Compare o resultado com o original e aceite-o apenas se o discurso soar melhor.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Também é necessário um tempo de execução embalado correspondente.

## O que o teste embalado verifica {#what-the-packaged-test-checks}

Caso: `dereverb-room-speech`; operação: `dereverberation`.

Entrada: O discurso de Kennedy ressamplerado para 44,1 kHz com quatro reflexões atrasadas reproduzíveis.

O áudio decodificado deve conter amostras finitas, preservar a geometria de áudio esperada, diferir das amostras de entrada e ter um sinal audível não nulo. Cabeçalhos de ficheiro diferentes por si só não contam como uma alteração.

O pacote noturno-com-testes transfere artefatos de modelo reais e solicita inferência através do tempo de execução embalado. Um modelo necessário ausente do catálogo falha no seu caso. Motores nativos ausentes falham em plataformas suportadas pelo catálogo. Estas verificações dispendiosas são executadas separadamente do conjunto de navegadores normal. Uma execução bem-sucedida confirma a execução básica do modelo e a estrutura de saída utilizável; não estabelece qualidade perceptual ou precisão no seu registo.

## Revise o resultado {#review-the-result}

- Reflexões fortes, música e salas desconhecidas podem produzir artefatos ou remover detalhes desejados.
- Áudio alterado, não silencioso, confirma o processamento, não a remoção completa de reverb ou a melhoria perceptual.
