## Finalidade e caso de utilização {#purpose-and-use-case}

Reduza as reflexões da sala em discursos gravados com um modelo local de desreverberação.

## Disponibilidade atual {#current-availability}

As compilações para computador podem transferir e autenticar o motor onnxruntime-node 1.29.0 necessário para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instale este modelo e o respetivo runtime necessário através do Gestor de modelos e execute a tarefa localmente. Estes são os destinos de compilação suportados; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos.

## Utilize este modelo {#use-this-model}

Abra **Ferramentas → Processamento Local Avançado → Desreverberação** numa plataforma com o tempo de execução nativo necessário. A assistência local funciona no editor de ambiente de trabalho.

1. Selecione o discurso afetado pelas reflexões da sala.
2. Instale o modelo através do Gestor de Modelos e execute a desreverberação.
3. Compare o resultado com o original e aceite-o apenas se o discurso soar melhor.

## Transferência e requisitos {#download-and-requirements}

Identidade do modelo: `dereverb-room`, versão **1.0.0**.

Tamanho aproximado da transferência do artefacto do modelo: **114.57 MiB**. O runtime necessário é acrescentado à primeira transferência se ainda não estiver instalado. Memória mínima do sistema: **2 GiB**. Este requisito do catálogo refere-se à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; a memória não garante velocidade.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Também é necessário um runtime correspondente transferível.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) suportado mais recente que corresponda à aplicação para computador: **x64** para uma compilação x64 ou **ARM64** para uma compilação ARM64. Os motores nativos ONNX e Sherpa precisam destas bibliotecas; as transferências do modelo e do runtime não as incluem. O Visual Studio não é necessário para utilizar a aplicação.

Ferramentas → Gestor de modelos transfere os artefactos publicados do modelo e o runtime necessário na primeira instalação e verifica os resumos SHA-256 registados. O processamento utiliza os ficheiros instalados localmente. Abra Armazenamento e verificação no Gestor de modelos para consultar avisos, reparar uma instalação ou alterar a localização de armazenamento.

<summary>O que o teste para computador verifica</summary>

Caso: `dereverb-room-speech`; operação: `dereverberation`.

Entrada: O discurso de Kennedy ressamplerado para 44,1 kHz com quatro reflexões atrasadas reproduzíveis.

O áudio decodificado deve conter amostras finitas, preservar a geometria de áudio esperada, diferir das amostras de entrada e ter um sinal audível não nulo. Cabeçalhos de ficheiro diferentes por si só não contam como uma alteração.

O pacote nightly-with-tests transfere os artefactos reais do modelo e runtimes verificados antes da inferência. A ausência no catálogo de um modelo necessário faz falhar o respetivo caso. A ausência de motores nativos provoca falhas nas plataformas suportadas pelo catálogo. Estas verificações dispendiosas são executadas separadamente da suite normal do navegador. Uma execução bem-sucedida confirma o funcionamento básico do modelo e uma estrutura de saída utilizável; não comprova a qualidade percetiva nem a precisão na sua gravação.

## Revise o resultado {#review-the-result}

- Reflexões fortes, música e salas desconhecidas podem produzir artefatos ou remover detalhes desejados.
- Áudio alterado, não silencioso, confirma o processamento, não a remoção completa de reverb ou a melhoria perceptual.
