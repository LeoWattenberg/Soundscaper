## Finalidade e caso de utilização {#purpose-and-use-case}

Forneça outro modelo de reconhecimento de voz local para transcrições e legendas.

## Disponibilidade atual {#current-availability}

As compilações para computador podem transferir e autenticar o motor sherpa-onnx-node 1.13.5 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o respetivo runtime necessário através do Gestor de modelos e execute a tarefa localmente. Estes são os destinos de compilação suportados; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A compilação para computador não disponibiliza um motor transferível para macOS x64, apesar de os pesos do modelo estarem listados para essa plataforma.

## Utilize este modelo {#use-this-model}

Abra **Analisar → Voz → Transcrever & Legendas** numa plataforma com o tempo de execução nativo necessário. A assistência local funciona no editor de ambiente de trabalho.

1. Selecione uma região com fala.
2. Instale o Parakeet v3 através do Gestor de Modelos. Escolha a identidade do modelo exata em Ferramentas → Processamento Local Avançado ao comparar modelos.
3. Execute localmente e reveja a transcrição proposta antes de aplicá-la.

## Transferência e requisitos {#download-and-requirements}

Identidade do modelo: `parakeet-tdt-0.6b-v3`, versão **3.0.0**.

Tamanho aproximado da transferência do artefacto do modelo: **639.42 MiB**. O runtime necessário é acrescentado à primeira transferência se ainda não estiver instalado. Memória mínima do sistema: **4 GiB**. Este requisito do catálogo refere-se à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; a memória não garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Também é necessário um runtime correspondente transferível.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) suportado mais recente que corresponda à aplicação para computador: **x64** para uma compilação x64 ou **ARM64** para uma compilação ARM64. Os motores nativos ONNX e Sherpa precisam destas bibliotecas; as transferências do modelo e do runtime não as incluem. O Visual Studio não é necessário para utilizar a aplicação.

Ferramentas → Gestor de modelos transfere os artefactos publicados do modelo e o runtime necessário na primeira instalação e verifica os resumos SHA-256 registados. O processamento utiliza os ficheiros instalados localmente. Abra Armazenamento e verificação no Gestor de modelos para consultar avisos, reparar uma instalação ou alterar a localização de armazenamento.
