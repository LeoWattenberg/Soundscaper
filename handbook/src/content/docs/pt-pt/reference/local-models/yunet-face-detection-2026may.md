## Finalidade e caso de utilização {#purpose-and-use-case}

Deteta rostos e objetos em frames de vídeo amostrados para ajudar a propor um novo enquadramento.

O YuNet deteta rostos e as suas localizações. A operação de deteção de sujeitos combina estes resultados com as deteções de objetos D-FINE.

## Disponibilidade atual {#current-availability}

As compilações para computador podem transferir e autenticar o motor onnxruntime-node 1.29.0 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o respetivo runtime necessário através do Gestor de modelos e execute a tarefa localmente. Estes são os destinos de compilação suportados; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A compilação para computador não disponibiliza um motor transferível para macOS x64, apesar de os pesos do modelo estarem listados para essa plataforma.

## Utilize este modelo {#use-this-model}

Abra **Framescaper: Efeito → Efeitos de vídeo → Reframar** numa plataforma com o tempo de execução nativo necessário. A assistência local executa-se no editor de ambiente de trabalho.

1. Selecione um clipe de vídeo no Framescaper.
2. Instale o YuNet e o D-FINE para a deteção de sujeitos. A tarefa Reframar guiada também utiliza a deteção de saliência U²-Net-P.
3. Execute localmente e reveja a cultura proposta. Ferramentas → Processamento Local Avançado pode executar a deteção de sujeitos por si só.

Esta operação também requer [D-FINE Nano deteção de objetos](/reference/local-models/dfine-nano-coco/).

## Revisão do resultado {#review-the-result}

- Os rostos e objetos podem ser omitidos ou classificados incorretamente. A deteção é amostrada e não garante que um sujeito em movimento permaneça dentro de cada cultura proposta.
- A operação executa ambos os modelos em conjunto; nenhum dos modelos é um sistema de reconhecimento facial para identificar pessoas.
