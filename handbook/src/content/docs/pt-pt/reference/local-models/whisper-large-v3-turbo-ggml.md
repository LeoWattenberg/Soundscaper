## Finalidade e caso de utilização {#purpose-and-use-case}

Transcreva localmente a fala selecionada através do tempo de execução empacotado whisper.cpp.

## Disponibilidade atual {#current-availability}

As compilações para computador podem transferir e autenticar o motor whisper-cpp v1.9.3 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o respetivo runtime necessário através do Gestor de modelos e execute a tarefa localmente. Estes são os destinos de compilação suportados; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A compilação para computador não disponibiliza um motor transferível para macOS x64, apesar de os pesos do modelo estarem listados para essa plataforma.

## Utilize este modelo {#use-this-model}

Abra **Analisar → Fala → Transcrever & Legendas** numa plataforma com o tempo de execução nativo necessário. A assistência local funciona no editor de desktop.

1. Selecione a fala e instale o Whisper large-v3 turbo através do Gestor de Modelos.
2. Escolha este modelo de reconhecimento de fala em Ferramentas → Processamento Local Avançado quando quiser selecionar explicitamente o Whisper.
3. Execute localmente e reveja tanto o texto como os limites de segmento antes de aceitar.
