A assistência local está disponível no Soundscaper e no Framescaper. Os modelos são armazenados num diretório que escolhe no seu próprio sistema de ficheiros e cada execução ocorre no seu dispositivo; nada dos seus meios é enviado para qualquer lado.

Um fluxo de trabalho é um gráfico fixo de etapas. Uma etapa que nomeia uma operação executa um modelo; uma etapa que não nomeia nenhuma é determinística e não executa nenhum modelo. Uma etapa opcional é ignorada quando o seu modelo não está instalado e o fluxo de trabalho ainda produz um resultado das etapas que foram executadas.

## Modelos publicados

Os pesos do modelo e os motores nativos são requisitos separados. Consulte os [guias de modelo individuais e a disponibilidade nativa atual](/reference/local-models/) antes de confiar num download de modelo para permitir uma tarefa.

Os modelos são publicados a partir de `https://assets.soundscaper.org/models/` e verificados contra um digest SHA-256 gravado antes do uso. A “memória mínima” é a memória do sistema total necessária para a disponibilidade do catálogo. A inferência também necessita de memória livre suficiente; nenhum dos valores é uma afirmação sobre a velocidade de execução.
