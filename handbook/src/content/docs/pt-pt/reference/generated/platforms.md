## Navegadores

“Testado automaticamente” significa que o conjunto de testes do navegador é executado contra este motor em cada solicitação de extração. Um motor que não está listado não é testado e não é garantido que funcione.

| Motor do navegador | Testado automaticamente |
| --- | --- |
| Chromium (Chrome, Edge) | Sim |
| Firefox | Sim |
| WebKit (Safari) | Sim |

## Onde uma capacidade pode ser executada

As capacidades são agrupadas pelo que precisam da plataforma. Consulte [Capacidades do produto](/reference/generated/product-capabilities/) para ver quais capacidades cada produto permite.

| Nível | O que significa |
| --- | --- |
| `web-core` | Funciona em todos os navegadores suportados, sem recursos opcionais da plataforma necessários. |
| `web-enhanced` | Funciona num navegador que fornece os recursos de armazenamento e mídia mais recentes necessários pela capacidade. |
| `electron-enhanced` | Funciona no navegador e a aplicação de ambiente de trabalho faz mais com ele. |
| `electron-only` | Requer a aplicação de ambiente de trabalho, porque um navegador não consegue aceder ao que a capacidade utiliza. |
