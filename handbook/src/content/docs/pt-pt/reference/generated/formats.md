Estes são os formatos concretos registados pela atual runtime de exportação. A disponibilidade do produto provém dos perfis do produto.

“Integrado” significa que a aplicação tem um escritor nativo para esse formato. “Requer runtime FFmpeg” é condicional: a tabela não promete que o runtime FFmpeg possa ser carregado em cada construção ou ambiente, ou que uma runtime de substituição arbitrária contenha o encoder e o muxer listados.

Os ficheiros de projeto e os ficheiros de etiqueta são listados separadamente em [Ficheiros de projeto e de etiqueta](/reference/generated/project-files/).
