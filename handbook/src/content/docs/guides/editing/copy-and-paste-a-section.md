Copying a good chorus to replace a weak one, repeating a bar, moving a sentence to the end: copy and paste work on audio the way they do on text. Select a passage, copy it, put the cursor where it should go, and paste.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Copy, then Edit → Paste (Ctrl+C, Ctrl+V)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording with the passage you want to copy. The file lands as a clip on its own track.
3. Drag in the ruler above the clip to select the passage to copy.
4. Choose **Edit → Copy**.
5. Click the waveform where the copy should go to put the cursor there. The paste lands at the cursor; the end of the clip is the usual place.
6. Choose **Edit → Paste → Paste**.
7. The project now shows 2 clips.
   *You should see:* The copied passage is a new clip after the original.

## Tips

- **Edit → Paste → Insert** pushes later audio along instead of laying the paste over it.
- The clipboard works across project tabs, so a passage can be copied from one project into another.
