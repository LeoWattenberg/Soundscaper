Learning a riff, checking an edit point, auditioning an effect setting: all go faster when the passage plays round and round without you restarting it. Set the loop region to the selection and playback stays inside it until you turn the loop off.

:::note[Coming from Audacity?]
This is Audacity's **Transport → Looping → Set Loop to Selection**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording with the passage to practise. The file lands as a clip on its own track.
3. Drag in the ruler above the clip to select the passage to repeat.
4. Choose **Select → Loop region → Set loop to selection**.
5. The project now shows the **Loop selection** button lit.
   *You should see:* The loop button in the transport bar lights up and the loop region shows above the ruler.
6. Press **Play** to listen, then **Stop**.
   *You should see:* Playback runs round the selected passage.

## Tips

- Press **L** or the transport bar’s loop button to turn the loop off and on without losing the region.
- Drag the ends of the loop region in the ruler to adjust it.
