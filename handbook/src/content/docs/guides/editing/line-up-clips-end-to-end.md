Two takes recorded separately land on their own tracks, both starting at zero. To play one after the other, the second has to move to where the first ends. Align end to end does that arithmetic for every selected clip in track order.

:::note[Coming from Audacity?]
This is Audacity's **Tracks → Align Tracks → Align End to End**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This guide uses `guide-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **File → Import audio** and pick your recording. This guide uses `guide-second-loop.wav`. The file lands as a clip on its own track.
4. Click the name bar of the `guide-music-loop.wav` clip, then hold Shift and click the name bar of `guide-second-loop.wav`, so both are selected.
5. Choose **Tracks → Align content → Align end to end**.
6. The project now shows the `guide-second-loop.wav` clip starting at 2 s.
   *You should see:* The second clip now starts where the first one ends.

## Tips

- **Align together** does the opposite: it moves the selected clips to start at the same time.
- Drag a clip by its name bar to place it by hand; hold Shift to keep it on the same track.
