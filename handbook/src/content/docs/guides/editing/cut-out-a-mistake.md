The most common edit there is: a false start, a cough, a retake. Select the part you do not want, remove it, and let the rest of the track slide left to close the gap.

:::note[Coming from Audacity?]
This is Audacity's **Select the region, then Edit → Delete (or Ctrl+K)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording with the mistake in it. The file lands as a clip on its own track.
3. Drag in the ruler above the clip to select exactly the part you want gone. Zoom in with **View → Zoom → Zoom in** if the mistake is short.
4. Choose **Edit → Cut → Cut and close gap per track**. The selection is removed and everything after it moves left, so no silence is left behind.
5. The project now shows 2 clips.
   *You should see:* Two clips sit end to end where the selection was, and the track is shorter by exactly that much. Play across the join to check it.

## Tips

- **Cut and leave gap** removes the sound but keeps the time, which is right when the track has to stay in sync with a video or another track.
- Not happy with the join? **Edit → Undo**, adjust the selection and try again.
