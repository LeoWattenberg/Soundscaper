A split does not remove anything. It turns one clip into two that sit end to end, so you can drag one part elsewhere, delete it, or apply an effect to it alone. The quickest way is the split tool: while it is active, every click on a clip cuts it at that point.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Clip Boundaries → Split (Ctrl+I)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording you want to split. The file lands as a clip on its own track.
3. Press the **Split tool** button in the toolbar. The pointer now cuts instead of selecting. Press **S** to toggle the tool from the keyboard.
4. Click the waveform where you want the cut to put the cursor there. With the split tool active, the click cuts the clip here.
5. The project now shows 2 clips.
   *You should see:* Two clips now sit where there was one.
6. Press the **Split tool** button in the toolbar. Press it again to return to the normal pointer.

## Tips

- To split at the playhead instead, select the clip and choose **Edit → Audio clips → Split**; with a time range selected, it splits at both ends of the range.
- Select both halves and choose **Edit → Audio clips → Join selected clips** to make them one clip again.
