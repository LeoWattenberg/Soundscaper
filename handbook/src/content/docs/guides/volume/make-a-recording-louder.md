A recording made with the gain too low is quiet but usually clean. Amplify raises everything by the same amount, in decibels, so the balance inside the recording stays exactly as it was. Leave clipping off and the effect refuses to push peaks past full scale.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Volume and Compression → Amplify**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the quiet recording. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Volume and compression → Amplify**. In the **Amplify** dialog, set **Amplification** to `6`, then press **Apply to selection**. Six decibels roughly doubles the loudness. **Allow clipping** stays off, so the effect will not distort the peaks.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The recording is noticeably louder and the waveform is taller.

## Tips

- If the result is still too quiet, run Amplify again; the gains add up.
- To bring peaks to an exact level rather than add a fixed amount, use [Normalize](/guides/volume/normalize-peaks/) instead.
