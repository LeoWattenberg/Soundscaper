Audacity 3 shipped two compressors: the modern one with a knee, lookahead and live meters, and the original, simpler one it kept as Legacy Compressor. The legacy design has a noise floor below which it stops working — so it never pumps room noise up during pauses — and it makes the result up to 0 dB by default. Audacity 4 dropped it; Soundscaper keeps it for projects and ears that are used to it.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Volume and Compression → Legacy Compressor (Audacity 3; Audacity 4 has only the new Compressor)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording to even out. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Legacy effects → Legacy Compressor**. In the **Legacy Compressor** dialog, set **Threshold** to `-20` and set **Ratio** to `4`, then press **Apply to selection**. Anything above −20 dB is turned down by the ratio, 4:1 here. Make-up gain then raises the whole result to peak at 0 dB.
5. Press **Play** to listen, then **Stop**.
   *You should see:* Loud and quiet passages sit closer together and the whole take is louder.

## Tips

- Raise **Noise floor** if the compressor is bringing up hiss in the pauses; the effect ignores anything quieter than it.
- For a compressor you can hear working while you set it, use the modern one: [Even out volume with a compressor](/guides/volume/even-out-volume-with-a-compressor/).
