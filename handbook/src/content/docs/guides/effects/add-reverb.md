A close microphone in a treated room gives a dry, intimate sound that can feel lifeless on its own. Reverb adds the thousands of tiny reflections a room would have contributed, from a small booth to a hall.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Delay and Reverb → Reverb**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This guide uses `guide-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Delay and reverb → Reverb**. In the **Reverb** dialog, set **Room size** to `40` and set **Reverberance** to `60`, then press **Apply to selection**. Room size sets how big the space feels; reverberance sets how long it rings. Keep both moderate for speech.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop sits in a space instead of directly at the ear.

## Tips

- Lower **Wet gain** or raise **Dry gain** if the effect swamps the original.
- Reverb on the whole mix rarely works. Apply it to the parts that need it and leave the rest dry.
