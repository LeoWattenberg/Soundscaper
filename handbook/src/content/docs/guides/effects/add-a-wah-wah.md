A wah pedal sweeps a resonant filter up and down the spectrum; the Wahwah effect does the sweep for you at a rate you set. It suits guitars, keyboards and anything with steady sustain.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Wahwah**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This guide uses `guide-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Distortion and modulation → Wahwah**. In the **Wahwah** dialog, set **LFO frequency** to `2` and set **Depth** to `80`, then press **Apply to selection**. The LFO frequency is how many sweeps happen a second; depth is how far the filter travels.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop wobbles with a sweeping, vowel-like tone.

## Tips

- **Resonance** sharpens the peak of the filter; high values squeal.
- The **Phaser** in the same submenu gives a gentler, swirling movement.
