## What this guide is for {#what-this-guide-is-for}

Parametric EQ gives each band a frequency, gain and Q control, so you can make a focused cut for a resonant tone or a small boost for presence. Select a band in the graph, then adjust its frequency and Q to choose where and how wide the change is.

:::note[Coming from Audacity?]
This is Audacity's **Spectral Edit Parametric EQ, a spectrogram-only feature with no equivalent to Soundscaper’s track-wide effect**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording whose tone you want to adjust. It lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → EQ and filters → Parametric EQ**. In the **Parametric EQ** dialog, set **Frequency (Hz)** to `500`, set **Gain (dB)** to `-3` and set **Q** to `1.2`, then press **Apply to selection**. The selected band makes a modest, focused cut around 500 Hz.
5. Press **Play** to listen, then **Stop**.
   *You should see:* There is a focused cut around 500 Hz, with the other bands unchanged.

## Tips

- A narrower band has a higher **Q**. Start with a small gain change and increase it only if the problem remains.
- Soundscaper’s track-wide Parametric EQ is not the same as Audacity’s spectrogram-only Spectral Edit Parametric EQ.
