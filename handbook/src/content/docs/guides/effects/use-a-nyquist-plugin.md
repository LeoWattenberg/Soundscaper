Audacity’s Nyquist plug-ins are small scripts that add effects, generators and analyzers, and Soundscaper bundles the same ones under a Nyquist submenu of each menu. Tremolo is a good first one: it wobbles the volume at a set rate.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Tremolo (a Nyquist plug-in)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick your recording. This guide uses `guide-music-loop.wav`. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Nyquist → Tremolo**. In the **Tremolo** dialog, set **Frequency (Hz)** to `6`, then press **Apply**. Six wobbles a second is a classic amp tremolo. Nyquist dialogs use **Apply** rather than Apply to selection.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The loop pulses in volume.

## Tips

- The Generate and Analyze menus have Nyquist submenus of their own, with plug-ins such as Pluck and Beat Finder.
- **Tools → Nyquist prompt** runs a script you type yourself.
