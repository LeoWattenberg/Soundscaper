A phaser mixes a sound with a copy of itself passed through moving all-pass stages, so notches sweep up and down the spectrum in time with a slow oscillator. On a guitar, an electric piano or a pad it gives the swirl heard on countless records. Audacity 3 shipped a phaser and Audacity 4 does not, so this is one to reach for here.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Phaser (Audacity 3; Audacity 4 has no Phaser)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the sound to treat. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Distortion and modulation → Phaser**. In the **Phaser** dialog, set **Stages** to `4` and set **LFO frequency** to `0.6`, then press **Apply to selection**. More stages make deeper notches; four is a classic pedal. The LFO frequency is how fast the sweep moves — 0.6 Hz is a slow, musical swirl.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The sound swirls slowly as the notches sweep through it.

## Tips

- **Feedback** sharpens the notches into a more metallic, resonant sweep; keep it near zero for a subtle effect.
- Phaser also runs as a realtime effect in a track’s rack, so you can hear the sweep while you adjust it: [Add a realtime effect to a track](/guides/effects/add-a-realtime-effect-to-a-track/).
