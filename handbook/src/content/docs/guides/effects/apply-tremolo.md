## What this guide is for {#what-this-guide-is-for}

Tremolo moves the volume up and down in a repeating pattern, like a rhythmic swell. Use it on a sustained instrument, pad, or voice when a static sound needs motion.

:::note[Coming from Audacity?]
This is Audacity's **Audacity 4.0.1: Effect → Distortion and Modulation → Tremolo**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the sustained sound you want to give a pulse. It lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Distortion and modulation → Tremolo**. In the **Tremolo** dialog, set **Depth** to `60` and set **Frequency** to `4`, then press **Apply to selection**. Depth sets how far the volume falls on each cycle; frequency sets how many pulses happen each second.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The selected sound rises and falls in a steady pulse.

## Tips

- Use a lower **Frequency** for a slow swell and a higher one for a faster, more obvious pulse.
- Keep **Depth** modest when the sound must remain audible through the quiet part of each cycle.
