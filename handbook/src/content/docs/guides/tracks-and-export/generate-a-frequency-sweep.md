## What this guide is for {#what-this-guide-is-for}

Chirp creates a tone whose frequency changes across its length. Use a gentle sweep for an electronic sound effect or to hear how a signal chain responds across a range.

:::note[Coming from Audacity?]
This is Audacity's **Generate → Chirp (Audacity 3)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **Generate → Chirp**. In the **Chirp** dialog, set **Start frequency (Hz)** to `220`, set **End frequency (Hz)** to `880`, set **Start amplitude (0–1)** to `0.1`, set **End amplitude (0–1)** to `0.1` and set **Duration (seconds)** to `2`, then press **Generate**. This rises by two octaves while keeping a low, constant amplitude.
3. The project now shows 1 clip.
   *You should see:* A two-second sweep appears on the timeline.

## Tips

- Put the higher frequency first to make a downward sweep.
- Waveform and Interpolation change the sweep’s tone and the way it moves between the endpoints.
