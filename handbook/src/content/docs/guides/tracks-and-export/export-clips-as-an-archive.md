## What this guide is for {#what-this-guide-is-for}

Exporting individual clips keeps each edit as a separate audio file while collecting the files in one archive. Split a passage into clips first, then choose the clips output mode in the export dialog.

:::note[Coming from Audacity?]
This is Audacity's **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording whose clips you want to export separately. It lands as a clip on its own track.
3. Drag in the ruler above the clip to select a passage to export as its own clip.
4. Choose **Edit → Audio clips → Split**.
5. Choose **File → Export audio**, set **Format** to **WAV**, set **Output** to **Individual clips (split by clips)**, and press **Export**. The file downloads as soon as the render finishes, and its link stays in the dialog. Each clip is rendered as a separate WAV inside one ZIP archive.

## Tips

- Use descriptive clip names before exporting so you can identify the files in the archive.
- Choose **Entire project** when you want a single mix instead of separate clip files.
