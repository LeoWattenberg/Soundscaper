Some sound cards and cheap interfaces add a constant voltage to a recording, so the whole waveform sits slightly above or below the centre line. You cannot hear it directly, but it wastes headroom and produces a click at every edit. Remove DC Offset centres the waveform again.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Volume and Compression → Remove DC offset**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording that sits off centre. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Volume and compression → Remove DC Offset**. The effect applies to the selection straight away.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The waveform is centred on the zero line.

## Tips

- [Normalize](/guides/volume/normalize-peaks/) removes DC offset as part of its job, so if you normalize anyway there is nothing extra to do.
- An offset that changes over the recording is not DC; use a [high-pass filter](/guides/cleaning-up/remove-low-rumble/) instead.
