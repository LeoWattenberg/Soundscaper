Mains hum sits at one frequency: 50 Hz in most of the world, 60 Hz in the Americas, sometimes with a harmonic at twice that. A notch filter cuts a narrow band around one frequency and leaves everything else alone, which is far gentler than a high-pass filter when the hum is not low enough to roll off. The same tool takes out a monitor whistle or a ringing resonance once you know its frequency.

:::note[Coming from Audacity?]
This is Audacity's **Effect → EQ and Filters → Notch Filter**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording with the hum. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Nyquist → Notch Filter**. In the **Notch Filter** dialog, set **Frequency (Hz)** to `50` and set **Q (higher value reduces width)** to `4`, then press **Apply**. Use 60 if your mains is 60 Hz. A Q of 4 is a narrow notch; lower it if the hum wanders, raise it if the cut is audible on the voice.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The hum is gone and the voice sounds the same.

## Tips

- Not sure of the frequency? [Plot the spectrum](/guides/analysis/plot-a-spectrum/) of a quiet passage and read the peak.
- Hum often has a harmonic at double the frequency. Run the filter again at 100 or 120 Hz if some remains.
