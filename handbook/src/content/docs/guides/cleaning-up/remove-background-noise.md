Steady background noise — a fan, a fridge, mains hum — can be removed in two passes. First you show Noise Reduction a stretch of noise on its own so it can build a profile; then you apply the effect to everything. The profile is what makes this work, so pick a part of the recording where nobody is speaking.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Noise Removal and Repair → Noise Reduction, in two passes**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording you want to clean up. The file lands as a clip on its own track.
3. Drag in the ruler above the clip to select a stretch that contains only the noise — usually the lead-in before anyone speaks. The profile should contain nothing but the noise you want gone.
4. Choose **Effect → Noise removal and repair → Noise Reduction** and press **Get noise profile**. The status line reports that the profile is ready. Press **Close** to leave the dialog for now.
5. Choose **Select → Select all**. The profile is kept; now the effect needs to know what to clean.
6. Choose **Effect → Noise removal and repair → Noise Reduction**. In the **Noise Reduction** dialog, set **Noise reduction** to `12`, then press **Apply to selection**. Around 12 dB is a good first try. Higher values remove more noise but start to make voices sound hollow.
7. Press **Play** to listen, then **Stop**.
   *You should see:* The lead-in is much quieter and the voice is untouched.

## Tips

- If the result sounds watery or metallic, undo and try a lower **Noise reduction** value or a lower **Sensitivity**.
- Noise Reduction only works on noise that stays the same throughout the recording. For a single cough or click, cut it out or use Click Removal instead.
