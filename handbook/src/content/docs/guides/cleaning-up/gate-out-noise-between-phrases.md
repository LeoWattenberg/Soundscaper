Noise Reduction takes noise out of the whole recording; a gate takes a different approach. Whenever the level drops below a threshold — between sentences, in pauses — the gate turns the audio down, and it opens again the moment the voice returns. It cannot clean noise from under the words, but it makes the gaps between them clean, and it is quick to set.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Noise Removal and Repair → Noise Gate**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the take with noisy pauses. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Effect → Nyquist → Noise Gate**. In the **Noise Gate** dialog, set **Gate threshold (dB)** to `-35` and set **Level reduction (dB)** to `-30`, then press **Apply**. The threshold should sit above the noise and below the quietest speech; −35 dB suits most voice recordings. The reduction sets how far the gaps are turned down — not all the way, which sounds unnatural.
5. Press **Play** to listen, then **Stop**.
   *You should see:* The pauses are quiet and every phrase comes through untouched.

## Tips

- If the ends of words are being cut off, raise **Hold (ms)** or **Decay (ms)** so the gate closes more slowly.
- For noise that continues under the voice, use [Noise Reduction](/guides/cleaning-up/remove-background-noise/) instead, or both together.
