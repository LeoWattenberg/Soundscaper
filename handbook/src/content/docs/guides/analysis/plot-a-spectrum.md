A waveform shows how loud a sound is over time; a spectrum shows which frequencies it is made of. Plotting the spectrum of a problem passage is the fastest way to find a 50 or 60 Hz hum, a whistle from a monitor, or the frequency a room is ringing at — and then to know where to point an equalizer.

:::note[Coming from Audacity?]
This is Audacity's **Analyze → Plot Spectrum**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick the recording with the problem in it. The file lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyze → Plot spectrum**. The **Plot spectrum** panel opens with the result.
   *You should see:* A graph of level against frequency for the selection.

## Tips

- Select only the problem passage — a stretch of hum on its own, say — so the spectrum is not dominated by the music or speech around it.
- A tall narrow spike is a tone; a broad plateau is noise. Tones respond to a narrow EQ cut, noise to [Noise Reduction](/guides/cleaning-up/remove-background-noise/).
