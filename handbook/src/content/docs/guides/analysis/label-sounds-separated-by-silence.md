## What this guide is for {#what-this-guide-is-for}

Label Sounds scans a passage for sound separated by silence and places a label around each detected sound. It can mark spoken phrases, isolated hits or other distinct events for later editing.

:::note[Coming from Audacity?]
This is Audacity's **Analyze → Label Sounds (Nyquist)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording with pauses between sounds. It lands as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyze → Nyquist → Label Sounds**. In the **Label Sounds** dialog, set **Threshold level (dB)** to `-30`, set **Minimum silence duration** to `0.5` and set **Minimum label interval** to `0.5`, then press **Apply**. The dialog reports what it found; press **Close** to dismiss it. A half-second of silence lets the analyzer separate phrases. The threshold sets how loud a sound must be to count.
5. The project now shows a track named **Label Sounds**.
   *You should see:* A Label Sounds track appears with labels around the detected phrases.

## Tips

- Lower **Threshold level (dB)** to include quieter sounds; raise it to ignore background noise.
- Increase **Minimum silence duration** when short pauses should not split one phrase into several labels.
