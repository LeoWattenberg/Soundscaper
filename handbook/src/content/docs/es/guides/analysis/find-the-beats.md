## Para qué sirve esta guía {#what-this-guide-is-for}

Beat Finder es uno de los analizadores Nyquist incluidos. Escucha los aumentos repentinos de nivel por encima de un umbral y escribe una etiqueta en cada uno, lo cual es una forma rápida de marcar los golpes de un bucle o los impactos en una toma de batería antes de cortarla.

:::note[¿Vienes de Audacity?]
Esto es **Analizar → Beat Finder** de Audacity. Los nombres a continuación son propios de Soundscaper y a veces difieren.
:::

## Pasos

1. Abre Soundscaper. Un nuevo proyecto vacío está listo en cuanto se carga el editor.
2. Elige **Archivo → Importar audio** y selecciona la grabación que deseas marcar. El archivo aparece como un clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Analizar → Nyquist → Beat Finder**. En el diálogo **Beat Finder**, establece **Porcentaje de umbral** en `60`, luego presiona **Aplicar**. El diálogo informa lo que encontró; presiona **Cerrar** para descartarlo. Un porcentaje más bajo encuentra golpes más suaves; súbelo si marca demasiado.
5. El proyecto ahora muestra una pista llamada **Beat Finder**.
   *Deberías ver:* Una nueva pista de etiquetas llamada Beat Finder debajo del audio, con una etiqueta en cada golpe.

## Consejos

- Las etiquetas se colocan en una nueva pista de etiquetas debajo del audio. Renombra o elimina cualquiera que el analizador haya marcado incorrectamente.
- **Analizar → Nyquist → Label Sounds** realiza una función similar para sonidos completos separados por silencio.
