## Para qué sirve esta guía {#what-this-guide-is-for}

RMS es una medida del nivel medio de señal a lo largo del tiempo. Usa el analizador Measure RMS para comparar secciones o comprobar la intensidad de un fragmento antes de ajustarlo.

:::note[¿Vienes de Audacity?]
Esta es la ruta de Audacity: **Analyze → Measure RMS (Nyquist)**. Los nombres que siguen son los de Soundscaper y a veces difieren.
:::

## Pasos

1. Abre Soundscaper. El proyecto aparece vacío en cuanto carga el editor.
2. Elige **Archivo → Importar** y selecciona el fragmento cuyo nivel medio quieres medir. Se añade como clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Analizar → Nyquist → Measure RMS**. En el cuadro de diálogo **Measure RMS**, pulsa **Aplicar**. El diálogo muestra el resultado; pulsa **Cerrar** para cerrarlo.
   *Deberías ver:* El informe muestra un nivel RMS en dB para cada canal y para la señal estéreo.

## Consejos

- RMS describe el nivel medio; usa la [normalización de picos](/guides/volume/normalize-peaks/) si necesitas fijar un objetivo para la muestra más alta.
- Selecciona solo la sección que quieres comparar para que el audio ajeno a ella no influya en la medición.
