## Para qué sirve esta guía {#what-this-guide-is-for}

Una grabación realizada con un nivel demasiado alto se aplasta contra el tope del rango y se distorsiona. El daño es fácil de escuchar, pero difícil de encontrar a simple vista en una toma larga. Find Clipping analiza la selección y enumera cada secuencia de muestras que se encuentra a escala completa, para que puedas decidir si reparar, rehacer o aceptar cada una de ellas.

:::note[¿Vienes de Audacity?]
Esto es **Analizar → Buscar recorte** de Audacity. Los nombres a continuación son propios de Soundscaper y a veces difieren.
:::

## Pasos

1. Abre Soundscaper. Un proyecto nuevo y vacío está listo en cuanto se carga el editor.
2. Elige **Archivo → Importar audio** y selecciona la grabación que deseas revisar. El archivo se coloca como un clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Analizar → Buscar recorte**. Se abre el cuadro de diálogo **Buscar recorte** con el informe de la selección.
   *Deberías ver:* Una lista de las secuencias recortadas, o una nota indicando que no se encontraron.

## Consejos

- Bajar el volumen de una grabación recortada no la repara; los picos aplanados permanecen aplanados. **Efecto → Eliminación y reparación de ruido → Reparar** puede reconstruir una secuencia recortada muy corta.
- Para evitar el recorte la próxima vez, graba con picos alrededor de −12 dB y sube el nivel después.
