## Para qué sirve esta guía {#what-this-guide-is-for}

Label Sounds busca sonidos separados por silencio en un fragmento y coloca una etiqueta alrededor de cada sonido detectado. Puede marcar frases habladas, golpes aislados u otros eventos diferenciados para editarlos más adelante.

:::note[¿Vienes de Audacity?]
Esta es la ruta de Audacity: **Analyze → Label Sounds (Nyquist)**. Los nombres que siguen son los de Soundscaper y a veces difieren.
:::

## Pasos

1. Abre Soundscaper. El proyecto aparece vacío en cuanto carga el editor.
2. Elige **Archivo → Importar** y selecciona la grabación que tiene pausas entre sonidos. Se añade como clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Analizar → Nyquist → Label Sounds**. En el cuadro de diálogo **Label Sounds**, establece **Threshold level (dB)** en `-30`, **Minimum silence duration** en `0.5` y **Minimum label interval** en `0.5`; después pulsa **Aplicar**. El diálogo muestra el resultado; pulsa **Cerrar** para cerrarlo. Medio segundo de silencio permite separar las frases. El umbral determina el volumen mínimo para contar un sonido.
5. El proyecto muestra ahora una pista llamada **Label Sounds**.
   *Deberías ver:* Aparece una pista Label Sounds con etiquetas alrededor de las frases detectadas.

## Consejos

- Reduce **Threshold level (dB)** para incluir sonidos más tenues; súbelo para ignorar el ruido de fondo.
- Aumenta **Minimum silence duration** si las pausas breves no deben dividir una frase en varias etiquetas.
