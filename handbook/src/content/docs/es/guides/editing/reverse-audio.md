La función **Invertir** invierte la selección en el tiempo. Es un efecto para el diseño de sonido —címbalos invertidos, ecos previos que crecen— y ocasionalmente para comprobar si la cola de reverberación de una sala oculta algo.

:::nota[¿Vienes de Audacity?]
Esta es la función **Efecto → Especial → Invertir** de Audacity. Los nombres que aparecen a continuación son propios de Soundscaper y, a veces, son diferentes.
:::

## Pasos

1. Abre Soundscaper. Un nuevo proyecto vacío estará listo tan pronto como se cargue el editor.
2. Elige **Archivo → Importar audio** y selecciona la grabación que deseas invertir. El archivo se colocará como un clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Efecto → Especial → Invertir**. El efecto se aplicará a la selección inmediatamente.
5. Presiona **Reproducir** para escuchar, luego **Detener**.
   *Deberías ver:* La grabación se reproduce al revés.

## Consejos

- Aplicar **Invertir** dos veces te devuelve al punto de partida, muestra por muestra.
- Invierte una selección corta al principio de un clip para crear un efecto de crecimiento que conduzca a él.
