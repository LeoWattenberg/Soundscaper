A veces quieres eliminar un pasaje, pero no el tiempo que ocupa: un teléfono que suena durante una pausa, un nombre que necesitas censurar. Silenciar mantiene la grabación exactamente igual de larga y solo aplanar la parte seleccionada.

:::nota[¿Vienes de Audacity?]
Esto es **Editar → Eliminar especial → Silenciar audio** de Audacity. Los nombres que aparecen a continuación son propios de Soundscaper, que a veces difieren.
:::

## Pasos

1. Abre Soundscaper. Un nuevo proyecto vacío está listo tan pronto como se carga el editor.
2. Elige **Archivo → Importar** y selecciona la grabación con el pasaje que deseas silenciar. Se coloca como un clip en su propia pista.
3. Arrastra el regla sobre el clip para seleccionar solo la parte que deseas silenciar.
4. Elige **Editar → Eliminar especial → Silenciar audio**.
5. Ahora el proyecto muestra 3 clips.
   *Deberías ver:* La forma de onda está plana en el nuevo clip central, entre el audio sin cambios en ambos lados.

## Consejos

- El silencio es una edición normal: **Editar → Deshacer** devuelve el audio.
- Para eliminar el tiempo y el sonido, consulta [Cortar un error de una grabación](/guides/editing/cut-out-a-mistake/).
