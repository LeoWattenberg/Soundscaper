## Para qué sirve esta guía {#what-this-guide-is-for}

Cada episodio recibe el mismo tratamiento: normalizar, desvanecer el final. Una macro registra esa secuencia una vez y la ejecuta cada vez que lo solicites, con los ajustes que hayas elegido, por lo que una rutina de diez pasos se convierte en un solo comando. Audacity 3 tenía un Administrador de Macros para esto exactamente; Audacity 4 aún no ha restaurado las macros.

:::note[Procedente de Audacity?]
Esto es **Herramientas → Macros → Administrar Macros y Aplicar Macro (Audacity 3; Audacity 4 no tiene macros)**. Los nombres que aparecen a continuación son propios de Soundscaper, que a veces difieren.
:::

## Pasos

1. Abre Soundscaper. Un nuevo proyecto vacío está listo tan pronto como se carga el editor.
2. Elige **Archivo → Importar** y selecciona una grabación para procesar. Se coloca como un clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**. Una macro se ejecuta en la selección, al igual que cada efecto se aplicaría individualmente.
4. Elige **Herramientas → Paleta de macros** y presiona **Nueva macro**. Escribe `Episode finish` en **Nombre de la macro**. Presiona **Agregar efecto** y elige **Normalizar** y **Desvanecer**, presionando **Agregar efecto** nuevamente para cada uno. Presiona **Ejecutar macro**; el cuadro de diálogo informa que la macro se aplicó. Presiona **Cerrar**. Cada paso mantiene sus ajustes predeterminados aquí; presiona el botón **Seleccionar efecto** de un paso para cambiarlos antes de ejecutar.
   *Deberías ver:* La grabación se normaliza y se desvanece hasta el silencio al final.
5. Presiona **Reproducir** para escuchar, luego **Detener**.

## Consejos

- La macro se guarda con el editor, por lo que está esperando en **Herramientas → Paleta de macros** para la siguiente grabación.
- **Exportar macro** escribe la cadena como un archivo de texto de macro de Audacity, y **Importar macro** lee uno, por lo que una rutina puede moverse entre los dos programas.
