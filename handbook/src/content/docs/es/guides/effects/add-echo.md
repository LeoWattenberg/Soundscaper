Eco reproduce la selección nuevamente después de una demora, y así sucesivamente, cada repetición más silenciosa que la anterior. Es el clásico efecto de eco en una voz o el efecto de cañón en un grito.

:::nota[¿Vienes de Audacity?]
Este es el **Efecto → Retraso y Reverb → Eco** de Audacity. Los nombres que aparecen a continuación son propios de Soundscaper, que a veces difieren.
:::

## Pasos

1. Abre Soundscaper. Un nuevo proyecto vacío está listo tan pronto como se carga el editor.
2. Elige **Archivo → Importar audio** y selecciona el sonido que debe tener eco. El archivo se coloca como un clip en su propia pista.
3. Elige **Seleccionar → Seleccionar todo**.
4. Elige **Efecto → Retraso y reverberación → Eco**. En el diálogo **Eco**, establece el **Factor de decaimiento** en `0.4`, luego presiona **Aplicar a la selección**. Cada repetición es 0.4 veces más silenciosa que la anterior, por lo que el eco se desvanece después de algunas repeticiones. **Tiempo de retraso** establece la brecha entre ellas.
5. Presiona **Reproducir** para escuchar, luego **Detener**.
   *Deberías ver:* El sonido va seguido de repeticiones que se desvanecen.

## Consejos

- Agrega uno o dos segundos de silencio después del clip primero (**Generar → Silencio**) para que las últimas repeticiones tengan espacio para sonar.
- Para obtener una sensación de habitación en lugar de repeticiones distintas, usa [Reverb](/guides/effects/add-reverb/).
