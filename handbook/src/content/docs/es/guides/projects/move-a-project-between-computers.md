La biblioteca del proyecto reside en un navegador en una sola computadora. Para llevar un proyecto a cualquier otro lugar: otra máquina, un colega, una unidad de copia de seguridad, exporte el proyecto como un archivo de proyecto. El archivo `.sscape` contiene el audio y cada edición, y se abre en cualquier Soundscaper.

:::nota[¿Viniendo de Audacity?]
Esto es **Archivo → Guardar proyecto → Copia de seguridad del proyecto, luego Archivo → Abrir** en Audacity. Los nombres que aparecen a continuación son propios de Soundscaper, que a veces difieren.
:::

## Pasos

1. Abra Soundscaper. Un nuevo proyecto vacío está listo tan pronto como se carga el editor.
2. Elija **Archivo → Importar audio** y seleccione el material del proyecto. El archivo se coloca como un clip en su propia pista.
3. Elija **Archivo → Exportar archivo de proyecto (.sscape)**. Todo el proyecto se descarga como un solo archivo `.sscape`. Guarde el archivo en un lugar seguro; es el proyecto completo.
4. Elija **Archivo → Abrir archivo de proyecto Scape (.sscape)** y seleccione el archivo. En una computadora que aún no tiene el proyecto, se abre directamente; aquí, donde la biblioteca ya lo contiene, Soundscaper ofrece **Abrir como copia de solo lectura** — presione.
   *Debería ver:* El proyecto se abre con su pista y clip exactamente como se exportó.

## Consejos

- Una copia de solo lectura no se puede editar hasta que se guarde como un proyecto propio desde el menú Archivo.
- El archivo es un archivo ZIP con el audio dentro; no lo descomprima manualmente.
