Los efectos cuyo ID comienza con `audacity-` se adaptan de Audacity 3.7.7 en [`5ef610ed2326`](https://github.com/audacity/audacity/tree/Audacity-3.7.7); los efectos de tono y tempo utilizan la biblioteca de tiempo y tono de StaffPad fijada en Audacity 4.0.0 en [`4c177d436e48`](https://github.com/audacity/audacity/tree/4c177d436e48c1d20f231eada44035593cb26292). Todos los demás efectos están escritos para este repositorio.

«Rack en tiempo real» significa que el efecto puede colocarse en un rack de pista o maestro y procesar el audio mientras se reproduce. «Selección» significa que el efecto puede previsualizarse y aplicarse de forma destructiva a un rango seleccionado. Un efecto puede hacer ambas cosas.

## Por qué algunos efectos son solo de selección

Estos efectos no pueden ser una inserción en tiempo real, porque cada uno necesita más de la selección de lo que un bloque en vivo le proporciona.

| Efecto | ID del efecto | Motivo |
| --- | --- | --- |
| Amplificar | `audacity-amplify` | La ganancia sin recorte depende del pico de la selección completa. |
| Cambiar tono | `audacity-change-pitch` | Este efecto requiere procesamiento de selección anticipado. |
| Cambiar velocidad y tono | `audacity-change-speed-pitch` | Este efecto requiere procesamiento de selección anticipado. |
| Cambiar tempo | `audacity-change-tempo` | Este efecto requiere procesamiento de selección anticipado. |
| Fundido de entrada | `audacity-fade-in` | La curva de ganancia depende de la posición y la longitud de la selección. |
| Fundido de salida | `audacity-fade-out` | La curva de ganancia depende del límite futuro de la selección. |
| Compresor heredado | `audacity-legacy-compressor` | El algoritmo realiza pasadas de selección completa y hacia atrás. |
| Normalización de sonoridad | `audacity-loudness-normalization` | La ganancia depende de la sonoridad del programa completo. |
| Normalizar | `audacity-normalize` | El desplazamiento de CC y la ganancia de pico dependen de las estadísticas de la selección completa. |
| Paulstretch | `audacity-paulstretch` | El efecto cambia la duración y no puede ser una inserción de one-in/one-out. |
| Eliminar desplazamiento de CC | `audacity-remove-dc-offset` | Este efecto requiere procesamiento de selección anticipado. |
| Reparar | `audacity-repair` | La reparación requiere una selección dañada corta marcada explícitamente y el contexto circundante. |
| Repetir | `audacity-repeat` | El efecto cambia la duración y no puede ser una inserción de one-in/one-out. |
| Reverb (Audacity) | `audacity-reverb` | Este efecto requiere procesamiento de selección anticipado. |
| Invertir | `audacity-reverse` | La primera muestra de salida depende del final de la selección completa. |
| Estiramiento deslizante | `audacity-sliding-stretch` | Este efecto requiere procesamiento de selección anticipado. |
| Truncar silencio | `audacity-truncate-silence` | El efecto elimina tiempo y no puede ser una inserción de one-in/one-out. |
