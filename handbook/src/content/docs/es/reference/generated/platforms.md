## Dónde puede ejecutarse una capacidad

Las capacidades se agrupan según lo que necesitan de la plataforma. Consulte [Capacidades del producto](/reference/generated/product-capabilities/) para ver qué capacidades habilita cada producto.

| Nivel | Lo que significa |
| --- | --- |
| `web-core` | Funciona en cada navegador compatible, sin necesidad de ninguna característica de plataforma opcional. |
| `web-enhanced` | Funciona en un navegador que proporciona las características de almacenamiento y medios más nuevas que requiere la capacidad. |
| `electron-enhanced` | Funciona en el navegador, y la aplicación de escritorio hace más con él. |
| `electron-only` | Requiere la aplicación de escritorio, ya que un navegador no puede acceder a lo que utiliza la capacidad. |
