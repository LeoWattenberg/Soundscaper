Estos son los formatos concretos registrados por el entorno de exportación actual. La disponibilidad del producto proviene de los perfiles del producto.

“Integrado” significa que la aplicación tiene un escritor nativo para ese formato. “Se requiere el entorno de ejecución FFmpeg” es condicional: la tabla no promete que el entorno de ejecución FFmpeg pueda cargarse en cada compilación o entorno, ni que un entorno de ejecución de reemplazo arbitrario contenga el codificador y el multiplexor enumerados.

Los archivos de proyecto y los archivos de etiquetas se enumeran por separado en [Archivos de proyecto y etiquetas](/reference/generated/project-files/).
