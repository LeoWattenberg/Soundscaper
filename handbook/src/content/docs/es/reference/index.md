Las páginas de referencia se generan a partir de registros de ejecución revisados y se incorporan al
repositorio. Describen el comportamiento implementado, no las entradas de la hoja de ruta o la
simple presencia de archivos de origen y pruebas.

Utilice esta sección para responder a preguntas como:

- ¿Qué atajo predeterminado invoca un comando?
- ¿Está disponible un comando en Soundscaper, Framescaper o en ambos?
- ¿Qué formatos de audio y video se pueden exportar?
- ¿A qué valor predeterminado se asigna el parámetro de un efecto y qué valores aceptará?
- ¿Qué efectos se pueden ejecutar mientras se reproduce el audio y cuáles requieren una selección?
- ¿Qué flujos de trabajo de asistencia local existen y qué modelos necesitan?
- ¿Qué paneles muestra cada espacio de trabajo?
- ¿Qué idiomas, navegadores y paquetes de escritorio se compilan y prueban?
- ¿Qué características dependen de un producto, plataforma o tiempo de ejecución de FFmpeg?

Las páginas generadas incluyen su origen y se verifican en busca de desviaciones en
la puerta de calidad del repositorio.

[Programas macro](/reference/macro-programs/) es la única página aquí escrita a mano.
Documenta la API de JavaScript que un programa macro ejecuta y sus
reclamos son aquellos a los que las propias pruebas del editor mantienen el sandbox.
