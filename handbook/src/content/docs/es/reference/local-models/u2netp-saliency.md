## Propósito y caso de uso {#purpose-and-use-case}

Estimar el área visualmente prominente de los fotogramas muestreados para ayudar con el reenfuque.

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos. La compilación de escritorio no dispone de un motor descargable para macOS x64, aunque los pesos del modelo aparezcan para esa plataforma.

## Utilice este modelo {#use-this-model}

Abra **Framescaper: Efecto → Efectos de video → Reenfocar** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Seleccione un clip de video e instale U²-Net-P a través de Administrar Modelos.
2. La tarea Reenfocar guiada también necesita YuNet y D-FINE; Herramientas → Procesamiento Local Avanzado puede ejecutar la detección de saliencia por separado.
3. Ejecute localmente y revise el reenfuque propuesto antes de aplicarlo.

## Descarga y requisitos {#download-and-requirements}

Identidad del modelo: `u2netp-saliency`, versión **1.0.0**.

Tamaño aproximado de descarga del artefacto del modelo: **4.36 MiB**. El entorno de ejecución necesario se añade a la primera descarga si aún no está instalado. Memoria mínima del sistema: **2 GiB**. Este requisito del catálogo se refiere a la memoria total, no a la memoria libre actual. La inferencia también necesita suficiente memoria libre y la instalación requiere espacio de trabajo; la memoria no garantiza velocidad.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. También se requiere un entorno de ejecución descargable compatible.

En Windows, instala el [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatible más reciente que corresponda a la aplicación de escritorio: **x64** para una compilación x64 o **ARM64** para una ARM64. Los motores nativos ONNX y Sherpa necesitan estas bibliotecas; las descargas del modelo y del entorno de ejecución no las incluyen. No hace falta Visual Studio para usar la aplicación.

Herramientas → Administrador de modelos descarga los artefactos publicados del modelo y el entorno de ejecución necesario durante la primera instalación, y verifica sus resúmenes SHA-256 registrados. ## Revise el resultado {#review-the-result}

- Una región visualmente prominente no es necesariamente el sujeto que desea conservar. Revise la selección completa.
- La prueba valida resultados de saliencia finitos y acotados y sincronización de fotogramas de origen, no la calidad artística de un cultivo.
