## Propósito y caso de uso {#purpose-and-use-case}

Alinea una transcripción en inglés existente a las palabras habladas en una grabación.

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos.

## Usa este modelo {#use-this-model}

Abre **Analizar → Voz → Transcribir y subtítulos, o Herramientas → Procesamiento local avanzado → Alineación de palabras** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Selecciona el discurso y prepara o revisa su transcripción en inglés.
2. Instala el modelo de alineación a través del Administrador de Modelos.
3. Ejecuta la alineación y escucha mientras revisas los límites de palabras propuestos antes de aceptarlos.

## Descarga y requisitos {#download-and-requirements}

Identidad del modelo: `wav2vec2-base-960h`, versión **1.0.0**.

Tamaño aproximado de descarga del artefacto del modelo: **360.38 MiB**. El entorno de ejecución necesario se añade a la primera descarga si aún no está instalado. Memoria mínima del sistema: **4 GiB**. Este requisito del catálogo se refiere a la memoria total, no a la memoria libre actual. La inferencia también necesita suficiente memoria libre y la instalación requiere espacio de trabajo; la memoria no garantiza velocidad.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. También se requiere un entorno de ejecución descargable compatible.

En Windows, instala el [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatible más reciente que corresponda a la aplicación de escritorio: **x64** para una compilación x64 o **ARM64** para una ARM64. Los motores nativos ONNX y Sherpa necesitan estas bibliotecas; las descargas del modelo y del entorno de ejecución no las incluyen. No hace falta Visual Studio para usar la aplicación.

Herramientas → Administrador de modelos descarga los artefactos publicados del modelo y el entorno de ejecución necesario durante la primera instalación, y verifica sus resúmenes SHA-256 registrados. ## Revisa el resultado {#review-the-result}

- Este modelo alinea palabras en inglés proporcionadas; no traduce ni repara una transcripción incorrecta.
- Las palabras repetidas, el discurso de fondo y las palabras que faltan en la transcripción pueden producir límites incorrectos. La prueba comprueba tiempos de palabra ordenados dentro del rango contra el inventario de palabras suministrado, no una coincidencia de tiempo perfecta.
