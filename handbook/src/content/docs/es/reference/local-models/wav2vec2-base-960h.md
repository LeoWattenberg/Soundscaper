Alinea una transcripción en inglés existente a las palabras habladas en una grabación.

## Disponibilidad actual {#current-availability}

Las compilaciones de escritorio empaquetan el motor onnxruntime-node 1.29.0 requerido para macOS arm64, Linux x64, Linux arm64, Windows x64 y Windows arm64. Instala los pesos de este modelo a través del Administrador de Modelos y luego ejecuta la tarea localmente. Estos son los objetivos de compilación admitidos; consulta el informe de prueba nocturno para obtener resultados sobre un paquete y una máquina específicos.

## Usa este modelo {#use-this-model}

Abre **Analizar → Voz → Transcribir y subtítulos, o Herramientas → Procesamiento local avanzado → Alineación de palabras** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Selecciona el discurso y prepara o revisa su transcripción en inglés.
2. Instala el modelo de alineación a través del Administrador de Modelos.
3. Ejecuta la alineación y escucha mientras revisas los límites de palabras propuestos antes de aceptarlos.

## Descarga y requisitos {#download-and-requirements}

Identidad del modelo: `wav2vec2-base-960h`, versión **1.0.0**.

Tamaño de descarga aproximado: **360,38 MiB**. Memoria mínima del sistema: **4 GiB**. Este requisito de catálogo se refiere a la memoria total, no a la memoria libre actual. La inferencia también requiere suficiente memoria libre y espacio de trabajo para la instalación; la memoria no es una garantía de velocidad.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. También se requiere un tiempo de ejecución empaquetado coincidente.

En Windows, instala la última versión compatible de [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) que coincida con la aplicación de escritorio: **x64** para una compilación x64 o **ARM64** para una compilación ARM64. Los motores nativos ONNX y Sherpa requieren estas bibliotecas; las descargas del modelo no las incluyen. Visual Studio en sí no es necesario para usar la aplicación.

Herramientas → Administrador de Modelos descarga los artefactos publicados y verifica sus hashes SHA-256 grabados. El procesamiento utiliza los archivos instalados localmente. Abre Almacenamiento y verificación en el Administrador de Modelos para inspeccionar avisos, reparar una instalación o cambiar la ubicación de almacenamiento.

## Lo que comprueba la prueba empaquetada {#what-the-packaged-test-checks}

Caso: `wav2vec2-word-alignment`; operación: `word-alignment`.

Entrada: El discurso de Kennedy de dominio público a 16 kHz, junto con su transcripción en inglés conocida como una entrada autenticada separada.

Cada palabra proporcionada debe estar representada con un tiempo válido y ordenado dentro del audio; no se prescriben tiempos de alineación exactos.

El paquete nocturno-con-pruebas descarga artefactos del modelo real y solicita inferencia a través del tiempo de ejecución empaquetado. Un modelo requerido que falta en el catálogo falla en su caso. Los motores nativos faltantes fallan en plataformas admitidas por el catálogo. Estas costosas comprobaciones se ejecutan por separado de la suite de navegadores normal. Una ejecución aprobada confirma la ejecución básica del modelo y la estructura de salida utilizable; no establece la calidad perceptual o la precisión en su grabación.

## Revisa el resultado {#review-the-result}

- Este modelo alinea palabras en inglés proporcionadas; no traduce ni repara una transcripción incorrecta.
- Las palabras repetidas, el discurso de fondo y las palabras que faltan en la transcripción pueden producir límites incorrectos. La prueba comprueba tiempos de palabra ordenados dentro del rango contra el inventario de palabras suministrado, no una coincidencia de tiempo perfecta.
