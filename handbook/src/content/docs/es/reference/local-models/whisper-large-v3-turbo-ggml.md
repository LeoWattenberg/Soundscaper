## Propósito y caso de uso {#purpose-and-use-case}

Transcribir el discurso seleccionado localmente a través del tiempo de ejecución empaquetado whisper.cpp local. 

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor whisper-cpp v1.9.3 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos. La compilación de escritorio no dispone de un motor descargable para macOS x64, aunque los pesos del modelo aparezcan para esa plataforma.

## Utilice este modelo {#use-this-model}

Abra **Analizar → Discurso → Transcribir y subtítulos** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Seleccione el discurso e instale Whisper large-v3 turbo a través de Administrar Modelos.
2. Elija este modelo de reconocimiento de voz bajo Herramientas → Procesamiento Local Avanzado cuando desee seleccionar Whisper explícitamente.
3. Ejecute localmente y revise tanto el texto como los límites de segmento antes de aceptarlo.
