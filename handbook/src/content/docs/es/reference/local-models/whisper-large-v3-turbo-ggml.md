## Disponibilidad actual {#current-availability}

Las compilaciones de escritorio empaquetan el motor whisper-cpp v1.9.3 requerido para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale los pesos de este modelo a través del Administrador de Modelos, y luego ejecute la tarea localmente. Estos son los objetivos de compilación admitidos; consulte el informe de prueba nocturno para los resultados en un paquete y máquina específicos. ## Utilice este modelo {#use-this-model}

Abra **Analizar → Discurso → Transcribir y subtítulos** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Seleccione el discurso e instale Whisper large-v3 turbo a través de Administrar Modelos.
2. Elija este modelo de reconocimiento de voz bajo Herramientas → Procesamiento Local Avanzado cuando desee seleccionar Whisper explícitamente.
3. Ejecute localmente y revise tanto el texto como los límites de segmento antes de aceptarlo.
