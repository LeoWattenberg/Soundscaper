## Propósito y caso de uso {#purpose-and-use-case}

Agrupa el habla en turnos de oradores para que puedas revisar quién habla cuándo.

ERes2Net convierte los segmentos de habla en representaciones numéricas de oradores. El tiempo de ejecución de la diarización los combina con la segmentación Pyannote para agrupar la grabación en turnos de oradores.

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos. La compilación de escritorio no dispone de un motor descargable para macOS x64, aunque los pesos del modelo aparezcan para esa plataforma.

## Utilice este modelo {#use-this-model}

Abra **Analizar → Habla → Identificar oradores** en una plataforma con el tiempo de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Seleccione la conversación a analizar.
2. Instale tanto la segmentación Pyannote como la incrustación del orador ERes2Net a través del Administrador de Modelos; la operación utiliza la pareja.
3. Ejecute localmente, revise los turnos de oradores propuestos y aplique los resultados deseados.

Esta operación también requiere [Segmentación Pyannote 3.0](/reference/local-models/pyannote-segmentation-3.0/).

## Revise el resultado {#review-the-result}

- Los IDs de oradores son grupos inferidos a partir de la grabación, no identidades reales verificadas.
- Las palabras cortas, las voces superpuestas y las voces similares pueden agruparse incorrectamente. La prueba comprueba turnos no vacíos válidos, no un recuento exacto de oradores.
