## Propósito y caso de uso {#purpose-and-use-case}

Reduce las reflexiones de sala en voz grabada con un modelo local de reducción de reverberación.

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos.

## Usar este modelo {#use-this-model}

Abre **Herramientas → Procesamiento local avanzado → Reducción de reverberación** en una plataforma con el entorno de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Selecciona voz afectada por las reflexiones de la sala.
2. Instala el modelo con Model Manager y ejecuta la reducción de reverberación.
3. Compara el resultado con el original y acéptalo solo si la voz suena mejor.

## Revisar el resultado {#review-the-result}

- Las reflexiones fuertes, la música y las salas poco habituales pueden producir artefactos o eliminar detalles deseados.
- Un audio modificado y no silencioso confirma que hubo procesamiento, no que se eliminara toda la reverberación ni que el resultado se perciba como una mejora.
