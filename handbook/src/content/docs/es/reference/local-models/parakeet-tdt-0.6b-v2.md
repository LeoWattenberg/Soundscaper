## Propósito y caso de uso {#purpose-and-use-case}

Convierte el habla seleccionada en una transcripción con marcas de tiempo para subtítulos y edición de transcripciones.

## Disponibilidad actual {#current-availability}

Las versiones de escritorio pueden descargar y verificar el motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo y su entorno de ejecución necesario mediante el Administrador de modelos y ejecuta la tarea localmente. Estos son los destinos de compilación admitidos; consulta el informe de pruebas nocturnas para ver los resultados de un paquete y equipo concretos. La compilación de escritorio no dispone de un motor descargable para macOS x64, aunque los pesos del modelo aparezcan para esa plataforma.

## Usar este modelo {#use-this-model}

Abre **Analizar → Voz → Transcribir y subtitular** en una plataforma con el entorno de ejecución nativo requerido. La asistencia local se ejecuta en el editor de escritorio.

1. Selecciona el fragmento de voz que quieres transcribir.
2. Usa Administrar modelos para instalar este modelo. Herramientas → Procesamiento local avanzado te permite elegir un modelo de reconocimiento de voz concreto.
3. Ejecútalo localmente y revisa el texto y la temporización antes de aceptar la transcripción.

## Descarga y requisitos {#download-and-requirements}

Identidad del modelo: `parakeet-tdt-0.6b-v2`, versión **2.0.0**.

Tamaño aproximado de descarga del artefacto del modelo: **630.56 MiB**. El entorno de ejecución necesario se añade a la primera descarga si aún no está instalado. Memoria mínima del sistema: **4 GiB**. Este requisito del catálogo se refiere a la memoria total, no a la memoria libre actual. La inferencia también necesita suficiente memoria libre y la instalación requiere espacio de trabajo; la memoria no garantiza velocidad.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. También se requiere un entorno de ejecución descargable compatible.

En Windows, instala el [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatible más reciente que corresponda a la aplicación de escritorio: **x64** para una compilación x64 o **ARM64** para una ARM64. Los motores nativos ONNX y Sherpa necesitan estas bibliotecas; las descargas del modelo y del entorno de ejecución no las incluyen. No hace falta Visual Studio para usar la aplicación.

Herramientas → Administrador de modelos descarga los artefactos publicados del modelo y el entorno de ejecución necesario durante la primera instalación, y verifica sus resúmenes SHA-256 registrados. El procesamiento usa los archivos instalados localmente. Abre Almacenamiento y verificación en el Administrador de modelos para consultar avisos, reparar una instalación o cambiar la ubicación de almacenamiento.
