Տեղային օգնությունը աշխատում է ձեր սարքում Soundscaper և Framescaper սեղանի խմբագրիչներում։ Ընտրեք մեդիա, ապա ընտրեք խնդիրը նրա ընտրացանկից։ Դիալոգային պատուհանը ցույց է տալիս ընտրությունը, խնդրի կարգավորումները և արդյոք նրա մոդելները տեղադրված են։

Սեղանադիր փաթեթներում ընտրովի բնիկ մշակման շարժիչներն ու մոդելների կշիռները ներառված չեն։ Մոդելների կառավարիչով տեղադրեք մոդելը՝ ներբեռնելով անհրաժեշտ շարժիչն ու կշիռները, ապա առաջադրանքը գործարկեք ընտրված մեդիայի վրա։ Առաջին տեղադրման համար անհրաժեշտ է ցանցային կապ, հետագա մշակումը կատարվում է տեղում։ Աջակցվող հարթակների, ընտրացանկի հրամանի և պահանջների համար տեսեք յուրաքանչյուր մոդելի ուղեցույցը։

Լրացուցիչ տեղեկությունների համար տեսեք [ուղեցույցներ առանձին մոդելների համար](/reference/local-models/).

## Գտեք խնդիրը {#find-a-task}

| Ընտրացանկ | Խնդիրներ |
| --- | --- |
| Էֆեկտ → Շփոթի հեռացում և վերականգնում | Դիալոգի բարելավում, Էխոի նվազեցում, Ուղեկցիչ խոսքերի և լռության մաքրում |
| Էֆեկտ → Բաղադրիչների բաժանում | Դիալոգի / Երաժշտության / Էֆեկտների բաժանում |
| Վերլուծություն → Մարդախոսություն | Տեքստային տարբերակի ստեղծում և ենթատեքստեր, Ձայնային խոսողների նույնականացում, Ռեակցիաների նշում |
| Վերլուծություն → Երաժշտություն | Ռիթմի և տեմպի հայտնաբերում |
| Վերլուծություն → Տեսանյութ | Կտրվածքների նշում |
| Էֆեկտ → Տեսանյութի էֆեկտներ | Վերաֆորմատավորում |
| Խմբագրում | Լավագույն պահերի ստեղծում |
| Գեներացում | Խմբագրական տեքստի գեներացում |
| Գործիքներ → Որոնում | Ինդեքսավորված որոնում, Տեքստային տարբերակի ինդեքսավորում, Տեսանյութի ինդեքսավորում |

Տեսանյութի խնդիրները պատկանում են Framescaper-ին։ Կարգադրությունների հասանելիությունը կախված է սեղանի ռաունթայմից և արտադրանքի հնարավորություններից։ Soundscaper-ի այբբենական կարգով դասավորված էֆեկտների ընտրացանկի տարբերակը նույնպես անվանմամբ է դասավորում տեղային մշակման էֆեկտները։

Ընտրեք **Գործարկել տեղային**՝ մշակումը սկսելու և տեղային համաձայնության հարցմանը պատասխանելու համար։ Կարող եք չեղարկել մշակման ընթացքում։ Ընտրեք **Արդյունքի անցում**, ընտրեք ցանկալի արդյունքները և ընտրեք **Կիրառել ընտրվածը**։ Ստացված նախագծի խմբագրումները կարող են անվերադարձվել։ Խնդրի փակելը չի կիրառում նրա առաջարկները։

**Գործիքներ → Մանրամասն տեղային մշակում** պահպանում է առանձին գործողության և մոդելի ընտրիչները։ Խնդրի դիալոգային պատուհաններում տեխնիկական մանրամասները անհրաժեշտության դեպքում ցույց են տալիս հիմնարար քայլերը և ճշգրիտ կարգավորումները։

## Մոդելների կառավարում {#manage-models}

Բացեք **Գործիքներ → Model Manager**-ը կամ օգտագործեք **Մոդելների կառավարումը** խնդրի ներսում։ Խնդրի հղումը ֆիլտրավորում է ցանկը համատեղելի մոդելների նույնականացումների համար. **Ցուցադրել բոլոր մոդելները** հեռացնում է այդ սահմանափակումը։ Որոնեք անվանմամբ կամ խնդրով և ֆիլտրավորեք տեղադրման կարգավիճակով։

Տեղադրեք մոդելները հստակորեն։ Առաջին տեղադրումը նաև ներբեռնում է մոդելին անհրաժեշտ բացակայող ընդհանուր բնիկ գործարկման միջավայրը։ Ներբեռնումների ընթացքը ցուցադրվում է, և դրանք կարելի է չեղարկել։ Գործին վերադառնալիս կարգավորումները պահպանվում են, իսկ մոդելի հասանելիությունը թարմացվում է․ մշակումը չի սկսվում։ Վերանորոգման, մաքրման, պահեստի տեղափոխման, լիցենզիայի ծանուցումների և պանակից անցանց տեղադրման համար բացեք **Պահեստավորում և ստուգում**։ Անցանց ֆայլերից տեղադրված մոդելին նույնպես առաջին օգտագործումից առաջ պետք է համապատասխան գործարկման միջավայրը։

Տեսեք [անհատական մոդելների հանգուցադրությունները](/reference/local-models/) յուրաքանչյուր հրապարակված մոդելի նպատակի, ընտրացանկի մուտքի, ներբեռնման չափի, պահանջների, սահմանափակումների և ամենաշնորհիվ-վերլուծական ստուգումների համար, որոնք կատարվում են ամենաշնորհիվ-վերլուծական ստուգումներով սեղանի փաթեթի կողմից։

## Պլագինների և սարքերի կառավարում {#manage-plugins-and-devices}

**Էֆեկտ → Plugin Manager**-ը ցուցադրում է ձայնային պլագինները Soundscaper-ում և OpenFX պլագինները Framescaper-ում։ Որոնեք կամ ֆիլտրավորեք ցանկը, ապա ընտրեք պլագինը նրա տարբերակի, թույլատրության և վերականգնման վերահսկիչների համար։ **Սկանավորում և կարգավորումներ** բաժինը պարունակում է հայտնաբերման կարգավորումները։ Կառավարումը մնում է հասանելի, երբ մշակումը անջատված է։

Օգտագործեք ձայնային պլագինները **Էֆեկտ → Ձայնային պլագիններ** միջոցով։ Framescaper-ի Ավելացնել/Խմբագրել տեսանյութի էֆեկտի կարգադրությունները մնում են **Էֆեկտ → Տեսանյութի էֆեկտներ**-ի տակ։

Բացեք **Խմբագրում → Կարգավորումներ → Ձայնային կարգավորումներ** բնօրինակ ձայնային սարքերի և օգնական վերահսկիչների համար։ **Մեդիա** բաժինը պահպանում է բնօրինակ մեդիայի կարգավորումները. **Էֆեկտներ** բաժինը հղում է տալիս Plugin Manager-ին և պարունակում է պլագինների հայտնաբերման փոխակերպիչը։ Պլագինների թույլատրությունները և քարանձավի վերականգնումը դեռևս պահանջում են ակտիվ գործողություններ։
