2. Թույլատրեք միկրոֆոնի կամ գրանցման իրավունքը, երբ դիտարկիչը հարցնի։
3. Միացրեք մուտքի մոնիտորինգը, եթե անհրաժեշտ է ստուգել մուտքի մակարդակը ձայնագրումից առաջ։
4. Ստուգեք ձայնագրման ցուցիչը և կարգավորեք սարքի կամ մուտքի մակարդակը՝ խուսափելու կլիպինգից։
