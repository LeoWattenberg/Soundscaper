Soundscaper-ը և Framescaper-ը կիսում են նախագծի ձևաչափը և, վեբում, նույն տեղային նախագծերի գրադարանը։ Ընտրեք խմբագիրը՝ հիմնվելով խնդրի վրա, այլ ոչ թե ստեղծելով նախագծի երկրորդ պատճենը։

## Ընտրեք Soundscaper՝ ձայնի համար

Soundscaper-ը լրիվ ձայնային վարչական կայանն է։ Օգտագործեք այն՝

- Ձայնագրել մեկ կամ ավելի մուտքեր։
- Խմբագրել, դասավորել, խառնել և վերլուծել ձայնը։
- Կիրառել ձայնային էֆեկտներ և գեներատորներ։
- Երկարաձգել թվային նշումներ, սպեկտրալ ընտրություններ, մակրոներ և մաստերինգի գործիքներ։
- Արտահանել ձայն, ստեմներ, նախագծի ֆայլեր կամ համատեղի Audacity փոխանակման ֆայլեր։

[Սկսել Soundscaper նախագիծ](/tutorials/your-first-project/)

## Ընտրեք Framescaper՝ տեսանյութի համար

Framescaper-ը կենտրոնացնում է աշխատանքային տարածքը՝ պատկերի խմբագրման վրա։ Օգտագործեք այն՝

- Իմպորտել տեսանյութը և դրա հետ կապված ձայնը։
- Դասավորել կլիպեր, թափանցիկ հաջորդականություններ և բազմակամերային նյութեր։
- Կարգավորել տեսաէֆեկտները, երկրաչափությունը և կոմպոզիտինգը։
- Առաքել MP4 կամ WebM տեսանյութ։

[Սկսել Framescaper նախագիծ](/framescaper/first-project/)

## Շարժվել դրանց միջև

`soundscaper.org`-ում երկու արտադրանքներն էլ օգտագործում են նույն ծագումը և տեղային նախագծերի գրադարանը։ Օգտագործեք **File → Edit in Framescaper** կամ **File → Edit in Soundscaper** հրամանները, երբ հրամանը հասանելի է։ Ձեռքի փոխանցումը պահպանում է նախագիծը՝ առանց դրա մեդիայի պատճենելու։

Որոշ հատկանիշներ իմաստավորված կերպով հայտնվում են միայն մեկ արտադրանքում։ Կոնկրետ, Soundscaper-ը սեփականատերն է ձայնագրման և ձայնային արտադրության գործիքների, մինչդեռ Framescaper-ը սեփականատերն է լրիվ տեսաէֆեկտների և կոմպոզիտինգի աշխատանքային տարածքի։
