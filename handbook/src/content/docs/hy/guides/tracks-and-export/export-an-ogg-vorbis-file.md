## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Ogg Vorbis-ը ձայնային տեղեկության մի մասը հեռացնելով ստեղծում է ավելի փոքր օրինակ։ Արտահանեք այս ձևաչափով, երբ այն աջակցում է ստացող նվագարկիչը կամ ծառայությունը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի ուղին է՝ **File → Export Audio → Ogg Vorbis (Audacity 3)**։ Ստորև նշված անունները Soundscaper-ինն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Խմբագրիչը բեռնելուց հետո պատրաստ է նոր, դատարկ նախագիծ։
2. Ընտրեք **Ֆայլ → Ներմուծել** և ընտրեք այն ձայնագրությունը կամ միքսը, որը ցանկանում եք կիսվել։ Այն կտեղադրվի որպես հոլովակ՝ իր առանձին ուղու վրա։
3. Ընտրեք **Ֆայլ → Արտածել աուդիոն**, **Ձևաչափ**-ի համար ընտրեք **Ogg Vorbis** և սեղմեք **Արտածել**։ Ֆայլը ներբեռնվում է արտապատկերման ավարտից հետո, իսկ դրա հղումը մնում է երկխոսության մեջ։
   *Ինչ պետք է նկատեք․* արտահանման երկխոսությունն առաջարկում է ներբեռնվող Ogg ֆայլ։

## Խորհուրդներ

- Quality-ը կարգավորում է ֆայլի չափի և կոդավորման որակի փոխզիջումը։
- Պահպանեք [կորստազուրկ master-ը](/guides/tracks-and-export/export-a-flac/), եթե նախատեսում եք նորից խմբագրել կամ կոդավորել ձայնագրությունը։
