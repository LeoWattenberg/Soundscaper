## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Մի քանի վերցված հատվածներով նախագիծն ավելի հեշտ է դիտարկել, երբ հարակից ուղիների անունները կողք կողքի են։ Sort by name-ը ուղիները դասավորում է այբբենական կարգով՝ առանց ժամանակագծի վրա հոլովակների մեկնարկները փոխելու։

:::note[Եթե գալիս եք Audacity-ից]
Audacity-ում դրան համապատասխանում է այս ուղին՝ **Tracks → Sort Tracks → Sort by Name**։ Ստորև նշված անունները Soundscaper-ի սեփական անուններն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Խմբագրիչը բեռնվելուն պես պատրաստ է նոր, դատարկ նախագիծը։
2. Ընտրեք **Ֆայլ → Ներմուծել** և նշեք այն ձայնագրությունը, որը ըստ անվան պետք է դասվի մյուսից հետո։ Այն կավելանա որպես առանձին ուղու հոլովակ։
3. Ընտրեք **Ֆայլ → Ներմուծել** և նշեք այն ձայնագրությունը, որը ըստ անվան ցանկանում եք դասել դրանից առաջ։ Այն կավելանա որպես առանձին ուղու հոլովակ։
4. Ընտրեք **Թրեքեր → Դասավորել թրեքերը → Դասավորել ըստ անվան**։ Ուղիների անունները դասավորվում են այբբենական կարգով։
5. Նախագիծն այժմ ունի 2 հոլովակ։
   *Արդյունքում պետք է տեսնել․* Երկու ձայնագրություններն էլ մնում են նախագծում, իսկ ուղիների անունները այբբենական կարգով են։

## Խորհուրդներ

- Տեսակավորումը փոխում է ուղիների հերթականությունը, ոչ թե հոլովակների ժամանակավորումը կամ ձայնային բովանդակությունը։
- Ընտրեք **Թրեքեր → Դասավորել թրեքերը → Դասավորել ըստ ժամանակի**, եթե ցանկանում եք ուղիները դասավորել ըստ հոլովակների մեկնարկային ժամանակների։
