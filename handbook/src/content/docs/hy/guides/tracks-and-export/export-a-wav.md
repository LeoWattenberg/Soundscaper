WAV-ը պահում է յուրաքանչյուր նմուշը ճիշտ այնպես, ինչպես այն կազմակերպված է խմբագրիչում։ Օգտագործեք այն մաստերների համար, ձայնային ֆայլերը տեսահոլովակային խմբագիրին կամ այլ DAW-ի փոխանցելու համար, ինչպես նաև ցանկացած բանի համար, որը կարող եք ցանկանալ նորից մշակել։

:::note[Եկել եք Audacity-ից]
Սա Audacity-ի **File → Export Audio → WAV**-ն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, քանի որ խմբագրիչը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք առաքման համար նախատեսված ձայնագրությունը։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսքում։
3. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը **WAV** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է, քանի որ ռենդերինգը ավարտվում է, և դրա հղումը մնում է երկխոսության պատուհանում։

## Խորհուրդներ

- WAV ֆայլերը մեծ են. մոտ տասը մեգաբայտ մեկ րոպեի համար ստերեոյի դեպքում CD որակով։
- Յուրաքանչյուր հոսքը առանձին ֆայլ արտահանելու համար կարգավորեք **Mode**-ը արտահանման երկխոսության պատուհանում որպես առանձին ստեմեր։
