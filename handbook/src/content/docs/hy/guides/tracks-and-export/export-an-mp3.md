MP3-ը փոքր է, խաղում է ամենուր և այն է, ինչ սպասում են մեծամասնության պոդկաստի հեղինակներն ու հաղորդագրության հավելվածները։ Էքսպորտը ամբողջ նախագիծը՝ յուրաքանչյուր հոսանքը, էֆեկտը և խմբագրումը, մեկ ֆայլի մեջ է փոխակերպում։

:::note[Եթե Audacity-ից եք գալիս]
Սա Audacity-ի **File → Export Audio → MP3**-ն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչինչ չի պետք սպասել, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import audio** և ընտրեք հրապարակման համար նախատեսված ձայնագրությունը։ Ֆայլը որպես կլիպ տեղադրվում է իր առանձին հոսանքի վրա։
3. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը **MP3** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է, ոչինչ չի պետք սպասել, երբ փոխակերպումն ավարտվի, և դրա հղումը մնում է երկխոսության պատուհանում։ Ֆայլը կոդավորվում է բրաուզերում։ Ինչ-որ բան չի թողնում ձեր համակարգիչը։

## Խորհուրդներ

- MP3-ը փոխանցման պատճեն է, ոչ թե պահուստ։ Եթե կարող եք նորից խմբագրել, պահեք նախագիծը կամ արդյունավետեք նաև WAV։
- Փորձանքները, որոնք ճիշտ ամբողջ մասշտաբի վրա են, կարող են կտրվել կոդավորումից հետո։ Նորմալացրեք −1 dB կամ ավելի ցածր արժեքի, մինչև էքսպորտը։
- Bit Rate Mode-ը որոշում է, թե ինչպես է կոդավորիչը ծախսում բիթերը։ Standard նախապատվությունը փոփոխում է արագությունը՝ համապատասխանելու նյութին, և ճիշտ պատասխանն է մեծամասնության փոխանցումների համար։ Ընտրեք Constant, եթե հոստինգ կամ հին արդյունավետ սարք պահանջում է մեկ ֆիքսված արագություն։
