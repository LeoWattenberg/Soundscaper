## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Մորզեի կոդը հաղորդագրությունը փոխում է ժամանակավորված կետերի, գծերի և բացատների։ Գեներատորը նախադիտում է կոդավորումը և հաղորդագրության ու արագության հիման վրա հաշվում հոլովակի տևողությունը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի ուղին է՝ **No directly matching built-in Morse code generator**։ Ստորև նշված անունները Soundscaper-ինն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Խմբագրիչը բեռնելուց հետո պատրաստ է նոր, դատարկ նախագիծ։
2. Ընտրեք **Ստեղծել → Մորզեի կոդ**։ **Մորզեի կոդ** երկխոսության մեջ **Հաղորդագրություն**-ը սահմանեք `SOS`, **Արագություն (բառ/րոպե)**-ը՝ `20`, **Հաճախականութ․ (Հց)**-ը՝ `600`, իսկ **Ամպլիտուդ**-ը՝ `0.2`, ապա սեղմեք **Ստեղծել**։ Օրինակային հաղորդագրությունը փոխարինեք ձեր տեքստով։ Ստուգեք կոդավորման նախադիտումը․ չաջակցվող նիշերը թույլ չեն տալիս գեներացնել։
3. Նախագիծն այժմ ունի 1 հոլովակ։
   *Ինչ պետք է նկատեք․* Մորզեի հոլովակը պարունակում է հաղորդագրությունը, իսկ երկարությունը կախված է ընտրված արագությունից։

## Խորհուրդներ

- Ավելի ցածր արագությունը երկարացնում է կետերը, գծերն ու բացատները՝ առանց տոնի հաճախականությունը իջեցնելու։
- Տևողությունն այստեղ միայն ընթերցման համար է։ Հոլովակի երկարությունը փոխելու համար փոխեք հաղորդագրությունը կամ արագությունը։
