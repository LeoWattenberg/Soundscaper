Եթե ունեք տասնյակ ձայնային հոսքեր, ապա նոր մասի լսումը մեկ մեկ զրկելով դրանց գլխամասերը ժամանակատար է, իսկ հետագա վերականգնումը՝ ավելի վատ։ «Զրկել բոլոր հոսքերը» հրամանը մեկ քայլով լռեցնում է ամբողջ նախագիծը, իսկ «Վերականգնել բոլոր հոսքերը» հրամանը վերականգնում է այն, և երկուսն էլ չեն դիպչում սոլո կոճակներին։ Audacity 3-ը ունեցել է երկուսն էլ, իսկ Audacity 4-ը դրանք չի վերադարձրել։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Tracks → Mute/Unmute → Mute All Tracks and Unmute All Tracks (Audacity 3; not in Audacity 4)** հրամանն է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք առաջին ձայնագրությունը։ Ֆայլը տեղակայվում է որպես կլիպ իր հոսքի վրա։
3. Ընտրեք **File → Import audio** և ընտրեք երկրորդ ձայնագրությունը։ Ֆայլը տեղակայվում է որպես կլիպ իր հոսքի վրա։
4. Ընտրեք **Tracks → Mute all tracks**։
5. Նախագիծը հիմա ցույց է տալիս, որ բոլոր հոսքերի **Mute** կոճակները վառված են։
   *Դուք պետք է տեսնեք.* Նվագարկումը լռակյաց է։
6. Ընտրեք **Tracks → Unmute all tracks**։
7. Նախագիծը հիմա ցույց է տալիս, որ ոչ մի հոսք չի զրկված։
   *Դուք պետք է տեսնեք.* Բոլորը նորից նվագարկվում են։

## Խորհուրդներ

- Զրկեք ամեն ինչ, ապա վերականգնեք այն մեկ կամ երկու հոսքը, որոնք ցանկանում եք լսել, — ավելի արագ է, քան սոլոն, երբ ընտրությունը հաճախ է փոխվում։
