Reverse-ը (Հակադարձում) հակադարձում է ընտրված հատվածը ժամանակի մեջ։ Այն ձայնային դիզայնի էֆեկտ է՝ հակադարձված սիմբալներ, աճող նախաէխոներ, և երբեմն՝ ստուգելու համար, թե սենյակի ռեվերբի ավարտը թաքցնում է փոքր-ինչ։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → Special → Reverse** էֆեկտն է։ Ցուցված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչինչ չի պետք սպասել, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import audio** և ընտրեք այն ձայնագրությունը, որը ցանկանում եք հակադարձել։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսքի վրա։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Special → Reverse**։ Էֆեկտը անմիջապես կիրառվում է ընտրված հատվածին։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Ձայնագրությունը նվագարկվում է հակադարձ ուղղությամբ։

## Խորհուրդներ

- Կիրառեք Reverse-ը երկու անգամ, և դուք կվերադառնաք սկզբնական կետ, նմուշ առ նմուշ։
- Հակադարձեք կլիպի սկզբում գտնվող կարճ ընտրված հատված՝ ստեղծելու համար աճ, որը հանգեցնում է դրան։
