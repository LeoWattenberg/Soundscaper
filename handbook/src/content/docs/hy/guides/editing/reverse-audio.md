Reverse-ը (Հակադարձում) ժամանակի ընտրությունը հակադարձում է։ Այն ձայնային դիզայնի էֆեկտ է՝ հակադարձված ջնջերներ, աճող նախաէխոներ, և երբեմն՝ ստուգելու համար, թե սենյակի ռեվերբի ավարտը թաքցնում է փոքր-ինչ։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → Special → Reverse**-ն է։ Ցանկում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import** և ընտրեք այն ձայնագրությունը, որը ցանկանում եք հակադարձել։ Այն կհայտնվի որպես կլիպ իր սեփական հոսանքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Special → Reverse**։ Էֆեկտը անմիջապես կիրառվում է ընտրությանը։
5. Սեղմեք **Play**-ը՝ լսելու համար, ապա **Stop**-ը։
   *Դուք պետք է տեսնեք.* Ձայնագրությունը նվագարկվում է հակադարձ ուղղությամբ։

## Խորհուրդներ

- Կիրառեք Reverse-ը երկու անգամ, և դուք կվերադառնաք այնտեղ, որտեղ սկսել էիք, նմուշ առ նմուշ։
- Հակադարձեք կլիպի սկզբում գտնվող կարճ ընտրություն՝ ստեղծելու համար աճ, որը հանգեցնում է դրան։
