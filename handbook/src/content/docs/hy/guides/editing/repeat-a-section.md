Երկու բարանից կազմված լուպ, ֆոնային շերտ, որը պետք է ձայնային հաղորդագրության տակ շարունակվի, կամ ձայնային էֆեկտ, որը պետք է ավելացվի. Repeat-ը ընտրված հատվածը անմիջապես իրենից հետո կրկնում է այնքան անգամ, որքան խնդրում եք։

:::note[Եթե Audacity-ից եք գալիս]
Սա Audacity-ի **Effect → Special → Repeat** ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, երբեն խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք այն ձայնը, որը ցանկանում եք կրկնել։ Ֆայլը որպես կլիպ տեղադրվում է առանձին հոսքի վրա։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Special → Repeat**։ **Repeat** երկխոսության պատուհանում **Number of repeats** դաշտում նշեք `2` արժեքը, ապա սեղմեք **Apply to selection**։ Երկու կրկնությունը տալիս են երեք հաջորդական պատճեն։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Հատվածը երեք անգամ է խաղարկվում առանց ընդհատումների։

## Խորհուրդներ

- Անխզկապ լուպի համոզվեք, որ ընտրությունը սկսվում և ավարտվում է լռության կամ զրոյական անցման կետում (**Select → At zero crossings**)։
- Էֆեկտը փոխում է կլիպի երկարությունը, ուստի նույն հոսքի վրա դրանից հետո գտնվող ամեն ինչ տեղաշարժվում է առաջ։
