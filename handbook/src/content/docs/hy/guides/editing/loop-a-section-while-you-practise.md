Ռիֆ սովորելը, խմբագրման կետի ստուգումը, էֆեկտի կարգավորման փորձարկումը. բոլորը ավելի արագ են անցնում, երբ հատվածը նվագարկվում է անընդհատ, առանց ձեր կողմից նորից սկսելու։ Կարգավորեք լուպի տիրույթը ընտրված մասին, և նվագարկումը կմնա նրա ներսում, մինչև ձեզ լուպը անջատելը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Transport → Looping → Set Loop to Selection** հրամանն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք ձայնագրությունը, որի հատվածը պետք է վարժեք։ Այն տեղադրվում է որպես կլիպ իր առանձին հոսքում։
3. Քաշեք կլիպի վերևում գտնվող չափական գծի վրա՝ ընտրելու համար կրկնվող հատվածը։
4. Ընտրեք **Select → Loop region → Set loop to selection**։
5. Նախագիծը հիմա ցույց է տալիս **Loop selection** կոճակը վառված վիճակում։
   *Դուք պետք է տեսնեք.* Նվագարկման վահանակի լուպի կոճակը վառվում է, և լուպի տիրույթը ցուցադրվում է չափական գծի վերևում։
6. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Նվագարկումը անցնում է ընտրված հատվածով։

## Խորհուրդներ

- Սեղմեք **L** կամ նվագարկման վահանակի լուպի կոճակը՝ լուպը անջատելու և միացնելու համար՝ առանց տիրույթը կորցնելու։
- Քաշեք լուպի տիրույթի ծայրերը չափական գծի վրա՝ դրանք կարգավորելու համար։
