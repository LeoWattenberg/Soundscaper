Նորմալացնելու կամ արտահանելուց առաջ օգտակար է գիտենալ, որտեղ եք գտնվում։ EBU R 128 վերլուծիչը չափում է ծրագիրը նույն կերպ, ինչպես դա անում են հեռարձակման հարթակներն ու հեռուստաընկերությունները՝ ինտեգրված լարվածություն LUFS-ով, լարվածության տիրույթ և իրական գագաթներ, որպեսզի կարողանաք համեմատել նպատակի հետ՝ չխաղցրելուց ցուցիչից։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Analyze → Measure RMS, կամ Loudness Normalization-ի չափումն է**։ Ցածքի անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց որ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import audio** և ընտրեք խառնուրդը, որը ցանկանում եք չափել։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → EBU R 128**։ Բացվում է **EBU R 128** վահանակը։
   *Դուք պետք է տեսնեք.* Ընտրված մասի ինտեգրված լարվածությունը, լարվածության տիրույթը և իրական գագաթները։

## Խորհուրդներ

- Պոդկաստի հարթակները սովորաբար պահանջում են −16 LUFS ստերեո կամ −19 LUFS մոնո՝ իրական գագաթները −1 dBTP-ից ցածր։ Ստուգեք հարթակի սեփական ուղեցույցը։
- Եթե թվերը հեռու են նպատակից, կատարեք [Loudness Normalization](/guides/volume/normalize-loudness-for-podcasts/) և նորից չափեք։
