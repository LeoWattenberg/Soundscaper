## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Նորմալացնելուց կամ արտահանումից առաջ օգտակար է իմանալ ընթացիկ վիճակը։ «Չափել ձայնի բարձրությունը» գործիքը վերլուծում է ընտրված հատվածը այնպես, ինչպես հոսքային հարթակներն ու հեռարձակողները․ չափում է ինտեգրված բարձրությունը LUFS-ով, բարձրության միջակայքն ու իրական գագաթը, որպեսզի կարողանաք համեմատել այն նպատակային արժեքի հետ՝ չափիչից գուշակելու փոխարեն։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Analyze → Measure RMS կամ Loudness Normalization-ի չափումն** է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import** և ընտրեք այն խառնուրդը, որը ցանկանում եք չափել։ Այն տեղակայվում է որպես կլիպ իր առանձին հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Վերլուծել → Չափել ձայնի բարձրությունը**։ **Առաքման հաշվետվություն** երկխոսությունը բացվում է ընտրված հատվածի հաշվետվությամբ։
   *Դուք պետք է տեսնեք.* Ընտրված մասի ինտեգրված լարվածությունը, լարվածության տիրույթը և իրական գագաթները։

## Խորհուրդներ

- Պոդկաստային հարթակները սովորաբար պահանջում են −16 LUFS ստերեո կամ −19 LUFS մոնո՝ իրական գագաթները −1 dBTP-ից ցածր։ Ստուգեք հարթակի սեփական ուղեցույցը։
- Եթե թվերը հեռու են նպատակից, կատարեք [Loudness Normalization](/guides/volume/normalize-loudness-for-podcasts/) և նորից չափեք։

- [Ստուգեք, որ խոսքը առանձնանում է ֆոնից](/guides/analysis/check-speech-contrast/) — Չափեք, թե որքան բարձր է ձայնը իր հետևում գտնվող աղմուկից, ինչպես պահանջում են հասանելիության ուղեցույցները։
