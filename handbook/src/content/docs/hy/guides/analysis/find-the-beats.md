Beat Finder-ը ներառված Nyquist վերլուծիչներից մեկն է։ Այն լսում է մակարդակի կտրուկ բարձրացումները շեմքից բարձր և յուրաքանչյուր դեպքում գրում է պիտակ, ինչը արագ եղանակ է՝ խաչմերուկի բիթերը կամ թմբուկի ընդունման հարվածները նշելու համար, մինչև դրանք կտրելը։

:::note[Coming from Audacity?]
Սա Audacity-ի **Analyze → Beat Finder** ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչ ոքի խմբագրիչը բացվելուց հետո։
2. Ընտրեք **File → Import audio** և ընտրեք այն ձայնագրությունը, որը ցանկանում եք նշել։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → Nyquist → Beat Finder**։ **Beat Finder** երկխոսության պատուհանում կարգավորեք **Threshold Percentage**-ը `60` արժեքի, ապա սեղմեք **Apply**։ Երկխոսության պատուհանը հաղորդում է գտածը։ Սեղմեք **Close**՝ փակելու համար։ Ավելի ցածր տոկոսը գտնում է նաև ավելի թույլ բիթերը։ Բարձրացրեք այն, եթե չափազանց շատ բան է նշվում։
5. Նախագիծը հիմա ցուցադրում է **Beat Finder** անվանված հոսք։
   *Դուք պետք է տեսնեք.* Նոր պիտակների հոսք Beat Finder անվամբ ձայնային տվյալների տակ, մեկ պիտակով յուրաքանչյուր բիթի համար։

## Խորհուրդներ

- Պիտակները տեղակայվում են ձայնային տվյալների տակ նոր պիտակների հոսքում։ Վերանվանեք կամ ջնջեք այն, ինչը վերլուծիչը սխալ է գտել։
- **Analyze → Nyquist → Label Sounds**-ը կատարում է նմանատիպ աշխատանք ամբողջական ձայների համար, որոնք բաժանված են լռությամբ։
