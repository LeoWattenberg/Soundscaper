Beat Finder-ը ներառված Nyquist վերլուծիչներից մեկն է։ Այն լսում է մակարդակի կտրուկ բարձրացումները շեմքից բարձր և յուրաքանչյուրի դեպքում գրում է պիտակ, ինչը արագ եղանակ է՝ խոստովանելու լուպի բիթերը կամ թմբուկային ընդունման հարվածները, մինչև դրանք կտրելը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Analyze → Beat Finder**-ն է։ Ցածքի անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք այն ձայնագրությունը, որը ցանկանում եք նշել։ Այն տեղակայվում է որպես կլիպ իր սեփական հոսանքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → Nyquist → Beat Finder**։ **Beat Finder** երկխոսության պատուհանում կարգավորեք **Threshold Percentage**-ը `60` արժեքի, ապա սեղմեք **Apply**։ Երկխոսության պատուհանը հաղորդում է, թե ինչ է գտել. սեղմեք **Close**՝ փակելու համար։ Ավելի ցածր տոկոսը գտնում է նաև ավելի թույլ բիթեր. բարձրացրեք այն, եթե չափազանց շատ բան է նշում։
5. Նախագիծը հիմա ցույց է տալիս **Beat Finder** անվանված հոսանք։
   *Դուք պետք է տեսնեք.* Ձայնային տվյալների տակ Beat Finder անվանված նոր պիտակային հոսանք, որտեղ յուրաքանչյուր բիթի համար կա մեկ պիտակ։

## Խորհուրդներ

- Պիտակները տեղակայվում են ձայնային տվյալների տակ նոր պիտակային հոսանքում։ Վերանվանեք կամ ջնջեք ցանկացածը, որը վերլուծիչը սխալ է գտել։
- **Analyze → Nyquist → Label Sounds**-ը կատարում է նմանատիպ աշխատանք ամբողջական ձայների համար, որոնք բաժանված են լռությամբ։
