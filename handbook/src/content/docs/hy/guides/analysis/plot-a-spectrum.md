## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Կիլվանդակը ցույց է տալիս, թե ինչպես է ձայնի ձայնարկությունը փոխվում ըստ ժամանակի, իսկ սպեկտրը՝ որ հաճախություններից է այն բաղկացած։ Մի խնդրային հատվածի սպեկտրի գծապատկերումը ամենարագ արագությամբ գտնելու 50 կամ 60 Հց թրթռում, մոնիտորից եկող փչոց կամ այն հաճախությունը, որի վրա սենյակը թրթռում է, և հետո՝ հասկանալու, թե որտեղ ուղղել հավասարեցուցիչը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Analyze → Plot Spectrum**-ն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչինչ չի պետք սպասել, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import** և ընտրեք այն ձայնագրությունը, որտեղ խնդիրն առկա է։ Այն կդառնա կլիպ իր սեփական հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → Plot spectrum**։ **Plot spectrum** երկխոսությունը բացվում է ընտրված հատվածի հաշվետվությամբ։
   *Դուք պետք է տեսնեք.* Ընտրված հատվածի մակարդակի և հաճախության գծապատկեր։

## Խորհուրդներ

- Ընտրեք միայն խնդրային հատվածը՝ օրինակ՝ միայն թրթռումը, որպեսզի սպեկտրը չգերի շրջակա երաժշտությունը կամ խոսքը։
- Բարձր, նեղ սուրը ձայն է, լայն դաշտը՝ աղմուկ։ Զայնը պատասխանում է նեղ EQ կտրմանը, աղմուկը՝ [Noise Reduction](/guides/cleaning-up/remove-background-noise/)-ին։

## Կապված ուղեցույցներ

Ավելի շատ [լուծարար](/guides/analysis/) ուղեցույցներ.

- [Հեռացնել ֆոնային աղմուկը](/guides/cleaning-up/remove-background-noise/) — Մեծացրեք Noise Reduction-ը, որպեսզի այն ճանաչի թրթռումը, և հետո հեռացրեք այն ամբողջ ձայնագրությունից։
- [Գնահատել ձեր խառնուրդի ձայնարկությունը](/guides/analysis/measure-loudness/) — Կարդացեք ընտրված հատվածի ինտեգրված բարձրությունը, միջակայքն ու իրական գագաթը՝ հեռարձակողների նման։
- [Գտնել, որտեղ ձայնագրությունը կտրվել է](/guides/analysis/find-clipping/) — Գտեք այն վայրերը, որտեղ ձայնագրությունը հասել է առավելագույն մակարդակի և աղավաղվել։
- [Գտնել շրջանակի բիթերը](/guides/analysis/find-the-beats/) — Ձգեք Beat Finder-ի վերլուծիչը, որպեսզի այն նշանակի բոլոր բիթերը, որոնք այն լսում է։
- [Ստուգել, որ խոսքը առանձնանում է ֆոնից](/guides/analysis/check-speech-contrast/) — Չափեք, թե որքան բարձր է ձայնը աղմուկից, որի հետևում է այն, ինչպես պահանջում են հասանելիության ուղեցույցները։
- [Չափել ընտրության RMS մակարդակը](/guides/analysis/measure-rms-level/) — Ներկառուցված RMS վերլուծիչով կարդացեք ընտրված հատվածի միջին ազդանշանի մակարդակը։
- [Պիտակավորել լռությամբ բաժանված ձայները](/guides/analysis/label-sounds-separated-by-silence/) — Դադարից հետո շեմը գերազանցող ձայների շուրջ պիտակներ ստեղծեք։
