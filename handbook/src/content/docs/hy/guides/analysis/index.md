Չափեք ձայնի ուժգնությունը, ուսումնասիրեք հաճախությունները և գտեք ձայնագրության խնդիրները։

## Ներածական ուղեցույցեր այս կատեգորիայում

- [Չափեք ձեր խառնուրդի ձայնի ուժգնությունը](/guides/analysis/measure-loudness/) — Կարդացեք նախագծի ընդհանուր ձայնի ուժգնությունը, տիրույթը և իրական գագաթնակետը՝ հեռարձակողների նման։
- [Տեսեք, թե որ հաճախություններ է պարունակում ձայնը](/guides/analysis/plot-a-spectrum/) — Կառուցեք ընտրված հատվածի սպեկտրը՝ ճարճատյուն, շշուկ կամ ռեզոնանսներ գտնելու համար։
- [Գտեք, թե որտեղ է ձայնագրությունը կտրվել](/guides/analysis/find-clipping/) — Գտեք այն վայրերը, որտեղ ձայնագրությունը հասել է առավելագույն մակարդակի և աղավաղվել։
- [Գտեք շրջանակի ռիթմերը](/guides/analysis/find-the-beats/) — Ցույց տվեք ռիթմերի գտնիչի վերլուծիչը՝ նշելու համար յուրաքանչյուր ռիթմ, որն այն լսում է։
- [Ստուգեք, թե խոսքը առանձնանում է ֆոնից](/guides/analysis/check-speech-contrast/) — Չափեք, թե որքան բարձր է ձայնը իր ֆոնային աղմուկից, ինչպես պահանջում են հասանելիության ուղեցույցները։
