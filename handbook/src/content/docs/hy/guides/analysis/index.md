- [Տեսեք, թե որ հաճախություններ է պարունակում ձայնը](/guides/analysis/plot-a-spectrum/) — Կառուցեք ընտրված հատվածի սպեկտրը՝ ճարճատյուն, շշուկ կամ ռեզոնանսներ գտնելու համար։
- [Գտեք, թե որտեղ է ձայնագրությունը կտրվել](/guides/analysis/find-clipping/) — Գտեք այն վայրերը, որտեղ ձայնագրությունը հասել է առավելագույն մակարդակի և աղավաղվել։
