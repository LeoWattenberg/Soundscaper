Եթե ձայնագրությունը շատ բարձր է, այն հարթվում է սահմանի վերին մասին և աղավաղվում։ Աղավաղումը հեշտ է լսել, բայց երկար ձայնագրության մեջ դժվար է աչքով գտնել։ Find Clipping-ը սկանավում է ընտրված մասը և ցուցում է ամեն լրիվ մասշտաբով նմուշների հաջորդականությունը, որպեսզի դուք կարողանաք որոշել՝ թե ինչպես վերանորոգել, նորից ձայնագրել, թե՞ ընդունել յուրաքանչյուր դեպքը։

:::note[Եթե Audacity-ից եք գալիս]
Սա Audacity-ի **Analyze → Find Clipping** գործառույթն է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք այն ձայնագրությունը, որը ցանկանում եք ստուգել։ Այն տեղադրվում է որպես կլիպ իր սեփական հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → Find clipping**։ Բացվում է **Find clipping** վահանակը։
   *Դուք պետք է տեսնեք.* Աղավաղված հաջորդականությունների ցանկ կամ նշում, որ ոչինչ չի գտնվել։

## Խորհուրդներ

- Աղավաղված ձայնագրության ձայնի ցածրացումը այն չի վերանորոգում. հարթված գագաթները մնում են հարթ։ **Effect → Noise removal and repair → Repair** գործառույթը կարող է վերականգնել շատ կարճ աղավաղված հաջորդականությունը։
- Ապագայում աղավաղումից խուսափելու համար ձայնագրեք −12 դեցիբելի շուրջ գագաթներով և հետո բարձրացրեք մակարդակը։
