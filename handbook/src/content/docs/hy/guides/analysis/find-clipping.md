Թերմանդրված ձայնագրությունը հարվածում է սանդղակի վերին սահմանին և աղավաղվում։ Աղավաղումը հեշտ է լսել, բայց դժվար է գտնել աչքով երկար ձայնագրության մեջ։ Find Clipping-ը սկանավում է ընտրված հատվածը և ցուցում է ամեն լիցքավորված նմուշների հաջորդականությունը, որպեսզի դուք կարողանաք որոշել՝ թե արդյոք վերականգնել, նորից ձայնագրել, թե ընդունել յուրաքանչյուր դեպքը։

:::note[Աուդացիից եկողներու համար]
Սա Audacity-ի **Analyze → Find Clipping** ֆունկցիան է։ Ցուցված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք ձայնագրությունը, որը ցանկանում եք ստուգել։ Ֆայլը տեղադրվում է որպես կլիպ իր անկախ հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Analyze → Find clipping**։ **Find clipping** վահանակը բացվում է։
   *Դուք պետք է տեսնեք.* Լիցքավորված հատվածների ցուցակ կամ նշում, որ ոչինչ չի գտնվել։

## Խորհուրդներ

- Լիցքավորված ձայնագրության ձայնի փոքրացումը այն չի վերականգնում. հարթված գագաթները մնում են հարթ։ **Effect → Noise removal and repair → Repair**-ը կարող է վերակառուցել շատ կարճ լիցքավորված հատվածը։
- Լիցքավորումից խուսափելու համար հաջորդ անգամ ձայնագրեք −12 դեցիբելի շուրջ գագաթներով և հետո բարձրացրեք մակարդակը։
