## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

Label Sounds-ը զննում է հատվածը լռությամբ բաժանված ձայների համար և յուրաքանչյուր հայտնաբերված ձայնի շուրջ պիտակ է տեղադրում։ Այն կարող է նշել խոսքային արտահայտությունները, առանձին հարվածները կամ այլ հստակ իրադարձություններ՝ հետագա խմբագրման համար։

:::note[Եթե գալիս եք Audacity-ից]
Audacity-ում դրան համապատասխանում է այս ուղին՝ **Analyze → Label Sounds (Nyquist)**։ Ստորև նշված անունները Soundscaper-ի սեփական անուններն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Խմբագրիչը բեռնվելուն պես պատրաստ է նոր, դատարկ նախագիծը։
2. Ընտրեք **Ֆայլ → Ներմուծել** և նշեք ձայների միջև դադարներ ունեցող ձայնագրությունը։ Այն կավելանա որպես առանձին ուղու հոլովակ։
3. Ընտրեք **Ընտրել → Ընտրել բոլորը**։
4. Ընտրեք **Վերլուծել → Nyquist → Label Sounds**։ **Label Sounds** երկխոսության մեջ **Threshold level (dB)**-ի համար սահմանեք `-30`, **Minimum silence duration**-ի համար՝ `0.5`, իսկ **Minimum label interval**-ի համար՝ `0.5`, ապա սեղմեք **Կիրառել**։ Երկխոսությունը ցույց է տալիս արդյունքը․ փակելու համար սեղմեք **Փակել**։ Կես վայրկյան լռությունը թույլ է տալիս վերլուծիչին բաժանել արտահայտությունները։ Շեմը որոշում է, թե որքան բարձր պետք է լինի ձայնը հաշվառվելու համար։
5. Նախագիծն այժմ ունի **Label Sounds** անունով ուղի։
   *Արդյունքում պետք է տեսնել․* Հայտնվում է Label Sounds ուղին՝ հայտնաբերված արտահայտությունների շուրջ պիտակներով։

## Խորհուրդներ

- Նվազեցրեք **Threshold level (dB)**-ը՝ ավելի թույլ ձայներն ընդգրկելու համար, կամ բարձրացրեք՝ ֆոնային աղմուկը անտեսելու համար։
- Բարձրացրեք **Minimum silence duration**-ը, եթե կարճ դադարները չպետք է մեկ արտահայտությունը բաժանեն մի քանի պիտակի։

- [Ստուգեք, որ ձայնը առանձնանում է ֆոնից](/guides/analysis/check-speech-contrast/) — Չափեք, թե որքան բարձր է ձայնը իր հետևում գտնվող աղմուկից, ինչպես պահանջում են հասանելիության ուղեցույցները։
