## Ինչի համար է այս ուղեցույցը {#what-this-guide-is-for}

RMS-ը ժամանակի ընթացքում ազդանշանի մակարդակի միջին չափն է։ Օգտագործեք Measure RMS վերլուծիչը՝ հատվածները համեմատելու կամ ճշգրտումից առաջ հատվածի ուժգնությունը ստուգելու համար։

:::note[Եթե գալիս եք Audacity-ից]
Audacity-ում դրան համապատասխանում է այս ուղին՝ **Analyze → Measure RMS (Nyquist)**։ Ստորև նշված անունները Soundscaper-ի սեփական անուններն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Խմբագրիչը բեռնվելուն պես պատրաստ է նոր, դատարկ նախագիծը։
2. Ընտրեք **Ֆայլ → Ներմուծել** և նշեք այն հատվածը, որի միջին մակարդակը ցանկանում եք չափել։ Այն կավելանա որպես առանձին ուղու հոլովակ։
3. Ընտրեք **Ընտրել → Ընտրել բոլորը**։
4. Ընտրեք **Վերլուծել → Nyquist → Measure RMS**։ **Measure RMS** երկխոսության մեջ սեղմեք **Կիրառել**։ Երկխոսությունը ցույց է տալիս արդյունքը․ փակելու համար սեղմեք **Փակել**։
   *Արդյունքում պետք է տեսնել․* Հաշվետվությունը ցույց է տալիս յուրաքանչյուր ալիքի և ստերեո ազդանշանի RMS մակարդակը՝ dB-ով։

## Խորհուրդներ

- RMS-ը նկարագրում է միջին մակարդակը․ եթե ցանկանում եք առավելագույն նմուշի համար թիրախ սահմանել, օգտագործեք [գագաթների նորմալացումը](/guides/volume/normalize-peaks/)։
- Ընտրեք միայն համեմատվող հատվածը, որպեսզի կապ չունեցող ձայնը չազդի չափման վրա։

- [Գտնել ռիթմերը շրջանակում](/guides/analysis/find-the-beats/) — Թույլ տվեք Beat Finder վերլուծիչը նշել յուրաքանչյուր ռիթմ, որը այն լսում է։
- [Ստուգեք, որ ձայնը առանձնանում է ֆոնից](/guides/analysis/check-speech-contrast/) — Չափեք, թե որքան բարձր է ձայնը իր հետևում գտնվող աղմուկից, ինչպես պահանջում են հասանելիության ուղեցույցները։
- [Պիտակավորել լռությամբ բաժանված ձայները](/guides/analysis/label-sounds-separated-by-silence/) — Դադարից հետո շեմը գերազանցող ձայների շուրջ պիտակներ ստեղծեք։
