Ձայնի զրկումը (Noise Reduction) հեռացնում է շաղաղը ամբողջ ձայնագրությունից, իսկ դարպասը (gate) կիրառում է այլ մոտեցում։ Ամեն անգամ, երբ մակարդակը իջնում է շեմքից ցածր՝ անկանաչների միջև, դադարների ժամանակ, դարպասը նվազեցնում է ձայնը և նորից բացվում է ակնթարթորեն, երբ ձայնը վերադառնում է։ Այն չի կարող մաքրել շաղաղը բառերի տակից, բայց մաքուր է դարձնում դրանց միջև եղած զրկանքները և արագ է կարգավորելը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → Noise Removal and Repair → Noise Gate** ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք ձայնագրությունը՝ աղմուկային դադարներով։ Ֆայլը տեղակայվում է որպես կլիպ իր անկախ հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Nyquist → Noise Gate**։ **Noise Gate** երկխոսության պատուհանում կարգավորեք **Gate threshold (dB)**-ը `-35` և **Level reduction (dB)**-ը `-30`, ապա սեղմեք **Apply**։ Շեմքը պետք է լինի շաղաղից բարձր և ամենալուռ խոսքից ցածր։ −35 dB-ը հարմար է մեծամասնության ձայնագրությունների համար։ Նվազեցումը սահմանում է, թե որքանով են դադարները նվազեցվում՝ ոչ թե ամբողջությամբ, քանի որ դա անբնական է հնչում։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Դադարները լուռ են, և յուրաքանչյուր արտահայտություն անպատճառ է անցնում։

## Խորհուրդներ

- Եթե բառերի վերջերը կտրվում են, բարձրացրեք **Hold (ms)**-ը կամ **Decay (ms)**-ը, որպեսզի դարպասը ավելի դանդաղ փակվի։
- Շաղաղի համար, որը շարունակվում է ձայնի տակ, օգտագործեք [Ձայնի զրկում](/guides/cleaning-up/remove-background-noise/)-ը, կամ երկուսը միասին։
