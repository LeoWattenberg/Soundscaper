Կայանքային շշուկը գտնվում է մեկ հաճախության վրա. աշխարհի մեծ մասում՝ 50 Հց, Ամերիկայում՝ 60 Հց, երբեմն՝ նաև երկու անգամ ավելի մեծ հարմոնիկայով։ Նոչ-ֆիլտրը (notch filter) հեռացնում է նեղ շերտ մեկ հաճախության շուրջ և թողնում է ամեն ինչ մյուսը, ինչը շատ ավելի փափուկ է, քան բարձր անցուցիչ ֆիլտրը, երբ շշուկը բավականաչափ ցածր չէ՝ ինքնուրույն մարելու համար։ Նույն գործիքը հեռացնում է մոնիտորի փչոցը կամ թնդացող ռեզոնանսը, երբ գիտեք դրա հաճախությունը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → EQ and Filters → Notch Filter**-ն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import audio** և ընտրեք շշուկ ունեցող ձայնագրությունը։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսանքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Nyquist → Notch Filter**։ **Notch Filter** երկխոսության պատուհանում կարգավորեք **Frequency (Hz)**-ը՝ `50` և **Q (higher value reduces width)**-ը՝ `4`, ապա սեղմեք **Apply**։ Եթե ձեր կայանքը 60 Հց է, օգտագործեք 60։ Q = 4-ը նեղ նոչ է. նվազեցրեք այն, եթե շշուկը տատանվում է, և բարձրացրեք, եթե հեռացումը լսելի է ձայնի վրա։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Շշուկը հեռացված է, և ձայնը հնչում է նույնը։
