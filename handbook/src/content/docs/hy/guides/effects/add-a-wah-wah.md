Վահ պեդալը շարժվող ռեզոնանսային ֆիլտր է սպեկտրի վրայով, իսկ Վահվահ էֆեկտը կատարում է այդ շարժումը ձեր կողմից սահմանված արագությամբ։ Այն հարմար է կիթառների, կլավիշային գործիքների և ցանկացած այլ բանի համար, որն ունի կայուն շարունակականություն։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → Wahwah**-ն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք ձայնագրությունը, որի վրա կիրառելու եք վահ էֆեկտը։ Ֆայլը տեղակայվում է որպես կլիպ իր առանձին հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Distortion and modulation → Wahwah**։ **Wahwah** երկխոսության պատուհանում սահմանեք **LFO frequency**-ը՝ `2` և **Depth**-ը՝ `80`, ապա սեղմեք **Apply to selection**։ LFO հաճախությունը ցույց է տալիս, թե քանի շարժում է տեղի ունենում վայրկյանում, իսկ խորությունը՝ ֆիլտրի շարժման հեռավորությունը։
5. Սեղմեք **Play**-ը՝ լսելու համար, ապա **Stop**-ը։
   *Դուք պետք է տեսնեք.* Ձայնագրությունը տատանվում է շարժվող, ձայնավոր նման ձայնով։

## Խորհուրդներ

- **Resonance**-ը սրում է ֆիլտրի գագաթը. բարձր արժեքները սուր ձայն են տալիս։
- Նույն ենթամենյուում գտնվող **Phaser**-ը տալիս է ավելի չափավոր, պտտվող շարժում։
