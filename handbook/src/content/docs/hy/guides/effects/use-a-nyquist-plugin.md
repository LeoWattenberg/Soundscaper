Audacity-ի Nyquist խմբադրվածքները փոքր սկրիպտներ են, որոնք ավելացնում են էֆեկտներ, գեներատորներ և վերլուծիչներ։ Soundscaper-ը պահպանում է խմբադրված սկրիպտները, որոնք պահանջում են ընտրության մշակում, Nyquist ենթամենյուի տակ։ Adjustable Fade-ը որոշում է, թե ինչպես է ձայնագրությունը մեղմացնում մուտքը կամ ելքը։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **Effect → Adjustable Fade (Nyquist խմբադրվածք)** է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք ձայնագրությունը, որի վրա փորձելու եք խմբադրվածքը։ Այն տեղակայվում է որպես կլիպ իր սեփական հոսանքի վրա։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Nyquist → Adjustable Fade**։ **Adjustable Fade** երկխոսության պատուհանում կարգավորեք **Mid-fade Adjust (%)**-ը `25` արժեքի, ապա սեղմեք **Apply**։ Դրական կարգավորումը կլորացնում է մեղմացումը։ Nyquist-ի երկխոսության պատուհանները օգտագործում են **Apply**՝ ոչ թե Apply to selection։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Ձայնագրությունը մեղմացնում է մուտքը։

## Խորհուրդներ

- Generate և Analyze մենյուները ունեն իրենց Nyquist ենթամենյուները, խմբադրվածքներով, ինչպիսիք են Pluck-ը և Beat Finder-ը։
- **Tools → Nyquist prompt** կատարում է սկրիպտ, որը դուք ինքներդ եք գրում։
- Delay, high-pass և low-pass ֆիլտրերը, Noise gate-ը, Notch filter-ը, Shelf filter-ը, Tremolo-ն և Vocoder-ը ունեն սովորական էֆեկտներ իրենց Effect մենյուի կատեգորիաներում և աշխատում են [realtime racks](/guides/effects/add-a-realtime-effect-to-a-track/)-ում։

- [Change tempo without changing pitch](/guides/effects/change-tempo-without-changing-pitch/) — Արագացրեք կամ դանդաղեցրեք ձայնագրությունը, միաժամանակ բոլոր նոտաները պահելով նույն բարձրության վրա։
- [Change pitch without changing tempo](/guides/effects/change-pitch-without-changing-tempo/) — Տեղափոխեք ձայնագրությունը վերև կամ ներքև ըստ կիսատոնների քանակի և պահեք դրա ժամանակացույցը։
- [Add an echo](/guides/effects/add-echo/) — Կրկնեք ձայնը ֆիքսված միջակայքով, ավելի թույլ յուրաքանչյուր անգամ։

- [Boost bass and treble](/guides/effects/boost-bass-and-treble/) — Տաքացրեք կամ պայծառացրեք ձայնագրությունը երկու պարզ ձայնային կարգավորիչներով։
- [Change speed like a tape machine](/guides/effects/change-speed-like-a-tape/) — Արագացրեք կամ դանդաղեցրեք ձայնագրությունը՝ բարձրությունը հետևելով, ինչպես անում է ժապավենը։
- [Stretch a sound into a drone](/guides/effects/stretch-a-sound-into-a-drone/) — Չափազանց դանդաղեցրեք կարճ ձայնը Paulstretch-ով՝ ստեղծելու համար շրջակա միջավայրի տեքստուրաներ։
- [Add distortion](/guides/effects/add-distortion/) — Գերբեռնեք ձայնը՝ թեթև ջերմությունից մինչև ամբողջական fuzz։
- [Add a wah-wah](/guides/effects/add-a-wah-wah/) — Ուղեկցեք ռեզոնանսային ֆիլտր ձայնի վրայով՝ դասական funk էֆեկտի համար։
- [Add a phaser](/guides/effects/add-a-phaser/) — Ուղեկցեք փոսերի հավաքածու ձայնի միջով՝ դասական պտտվող կիթառային և կլավիշային էֆեկտի համար։
- [Apply the same chain of effects every time](/guides/effects/apply-the-same-effects-every-time/) — Պահպանեք էֆեկտների հաջորդականությունը որպես մակրո և կատարեք այն ցանկացած ընտրության վրա մեկ հրամանով։
- [Slide from one tempo to another](/guides/effects/slide-from-one-tempo-to-another/) — Արագացրեք կամ դանդաղեցրեք հատվածը աստիճանաբար ըստ դրա երկարության՝ բարձրության սահմանափակումով կամ առանց դրա։
