Audacity-ի Nyquist խմբադրվածքները փոքր սկրիպտներ են, որոնք ավելացնում են էֆեկտներ, գեներատորներ և վերլուծիչներ, իսկ Soundscaper-ը նույնը ներառում է Nyquist ենթամենյուի տակ յուրաքանչյուր մենյուում։ Tremolo-ն լավ առաջին քայլն է. այն տատանում է ձայնի ուժը որոշակի արագությամբ։

:::note[Coming from Audacity?]
Սա Audacity-ի **Effect → Tremolo (Nyquist խմբադրվածք)** է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Steps

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, երբեն խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք ձայնագրությունը, որի վրա փորձելու եք խմբադրվածքը։ Ֆայլը տեղակայվում է որպես կլիպ իր առանձին հոսանքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Nyquist → Tremolo**։ **Tremolo** երկխոսության պատուհանում կարգավորեք **Frequency (Hz)**-ը `6` արժեքի, ապա սեղմեք **Apply**։ Վեց տատանում վայրկյանում դասական ապարատային tremolo է։ Nyquist-ի երկխոսության պատուհանները օգտագործում են **Apply**-ն, ոչ թե Apply to selection։
5. Սեղմեք **Play**՝ լսելու համար, ապա **Stop**։
   *Դուք պետք է տեսնեք.* Ձայնագրությունը պուլսավորում է ձայնի ուժով։

## Tips
