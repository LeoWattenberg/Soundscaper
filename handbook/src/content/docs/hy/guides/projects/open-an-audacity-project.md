Audacity 3-ում (.aup3) և Audacity 4-ում (.aup4) ստեղծված նախագծերը բացվում են ուղղակիորեն։ Տրակները, կլիպերը, անունները և դիրքերը փոխանցվում են. Soundscaper-ի չունեցած էֆեկտները ցուցակավորվում են, որպեսզի գիտեք, թե ինչ պետք է ստուգեք։ Վերջնական ֆայլը չի փոխվում։

:::note[Վերապահված եք Audacity-ից]
Սա Audacity-ի **File → Open** (Ֆայլ → Բացել) ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Audacity projects → Open Audacity project (.aup3, .aup4)** (Ֆայլ → Audacity նախագծեր → Բացել Audacity նախագիծ) և ընտրեք նախագիծը։ Այն իր տրակներն ու կլիպերը հայտնվում են այնպես, ինչպես եղել են Audacity-ում։
3. Նախագիծը հիմա ցույց է տալիս **Audio 1** անունով կլիպ և **Fixture track** անունով տրակ։
   *Դուք պետք է տեսնեք.* Audacity նախագծի տրակն ու կլիպը՝ իրենց անուններով։

## Խորհուրդներ

- Հին ոճի `.aup` նախագիծը պահանջում է, որ `_data` ֆոլդերը գտնվի նրա կողքին. խնդրի դեպքում ընտրեք երկուսն էլ։
- **File → Audacity projects → Export AUP4** (Ֆայլ → Audacity նախագծեր → Էքսպորտ AUP4) հակառակ ուղղությամբ է, Audacity-ին նախագիծ վերադարձնելու համար։
