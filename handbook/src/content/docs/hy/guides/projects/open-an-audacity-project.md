Audacity 3-ում (.aup3) և Audacity 4-ում (.aup4) ստեղծված նախագծերը բացվում են ուղղակիորեն։ Տրեքները, կլիպերը, անունները և դիրքերը փոխանցվում են։ Soundscaper-ի չունեցած էֆեկտները ցուցակավորված են, որպեսզի գիտեք, թե ինչ պետք է ստուգեք։ Վերջնական ֆայլը չի փոխվում։

:::note[Միգուցե Audacity-ից եք գալիս]
Սա Audacity-ի **File → Open** (Ֆայլ → Բացել) ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ին են պատկանում և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչինչ չի պետք սպասել, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Open** (Ֆայլ → Բացել) և ընտրեք նախագիծը։ Այն իր տրեքներն ու կլիպերը հայտնվում են այնպես, ինչպես դրանք եղել են Audacity-ում։
3. Նախագիծը հիմա ցույց է տալիս **Audio 1** անունով կլիպ և **Fixture track** անունով տրեք։
   *Դուք պետք է տեսնեք.* Audacity նախագծի տրեքն ու կլիպը՝ իրենց անուններով։

## Խորհուրդներ

- Հին ոճի `.aup` նախագիծը պահանջում է, որ `_data` ֆոլդերը գտնվի դրա կողքին։ Երբ խնդրեն, ընտրեք երկուսն էլ։
- **File → Export other → Export AUP4** (Ֆայլ → Էքսպորտ արտաքին → Էքսպորտ AUP4) ֆունկցիան գործում է հակառակ ուղղությամբ՝ նախագիծը Audacity-ին վերադարձնելու համար։
