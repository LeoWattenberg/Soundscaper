Կարգավորումը ավելին է, քան ձայնային տվյալները. այն ներառում է հոսանքները, կտորները, էֆեկտները, նշանները և պատմությունը։ Պահպանելը բոլորը պահում է դիտարկիչի տեղական կարգավորումների գրադարանում այս համակարգչում, որտեղ այն կարելի է նորից բացել Ֆայլ մենյուից։ Soundscaper-ը նաև պահպանում է ընթացքում, ուստի դա հիմնականում համոզված լինելու միջոց է։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Save Project** (Ֆայլ → Պահպանել կարգավորումը) գործողությունն է։ Ցանկացած անունները ներքևում Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ կարգավորումը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** (Ֆայլ → Իմպորտել ձայն) և ընտրեք ինչ-որ մի բան աշխատելու համար։ Ֆայլը ձևավորվում է որպես կտոր իր սեփական հոսանքում։
3. Ընտրեք **File → Save project** (Ֆայլ → Պահպանել կարգավորումը)։ Կարգավորման վիճակի գծի պահպանման ցուցիչը ցույց է տալիս, որ կարգավորումը պահպանված է։

## Խորհուրդներ

- Կարգավորումը տեղափոխելու համար մեկ այլ համակարգիչ կամ պահպանելու համար դիտարկիչի արտաքին պահեստ, տե՛ս [Move a project between computers](/guides/projects/move-a-project-between-computers/)։
- Իքսպորտված ձայնը լսելու պատճեն է, ոչ թե կարգավորում։ Պահպանեք կարգավորումը, եթե կարող եք նորից խմբագրել։

## Կապված ուղեցույցներ

Ավելի շատ [projects and files](/guides/projects/) ուղեցույցներ.

- [Move a project between computers](/guides/projects/move-a-project-between-computers/) — Իքսպորտեք ամբողջ կարգավորումը որպես մեկ ֆայլ, ապա բացեք այդ ֆայլը այլուր։
- [Open an Audacity project](/guides/projects/open-an-audacity-project/) — Բերեք գոյություն ունեցող .aup3 կամ .aup4 կարգավորում Soundscaper, պահելով նրա հոսանքները անվնաս։
- [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/) — Ռենդերեք հոսանքները առանձին, որպես ստեմներ, մեկ ներբեռնման մեջ։
- [Change a clip’s sample rate](/guides/projects/change-a-clips-sample-rate/) — Վերափոխեք կտորի նմուշավորման հաճախականությունը, որպեսզի այն համապատասխանի կարգավորման մնացած մասի օգտագործած հաճախականությանը։
- [Export each chapter as its own file](/guides/projects/export-each-chapter-as-its-own-file/) — Բաժանեք մեկ երկար ձայնագրություն ֆայլերի ըստ ձեր դրած նշանների։

## Այս ուղեցույցի մասին
