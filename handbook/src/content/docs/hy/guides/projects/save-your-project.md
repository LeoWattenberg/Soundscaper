Կարգավորումը ավելին է, քան ձայնային տվյալները. այն ներառում է հոսանքները, կտորները, էֆեկտները, նշանները և պատմությունը։ Պահպանելիս բոլորը պահպանվում են այս համակարգչի դիտարկիչի տեղային կարգավորումների գրադարանում, որտեղ դրանք կարելի է նորից բացել Գործիքներ մենյուից։ Soundscaper-ը նաև պահպանում է ձեր աշխատանքը ընթացքում, ուստի դա հիմնականում համոզվածության միջոց է։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Save Project** գործողությունն է։ Ցանկացած անվանումները ներքևում Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ կարգավորումը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք մի բան, որի վրա աշխատելու եք։ Այն տեղակայվում է որպես կտոր իր սեփական հոսանքում։
3. Ընտրեք **File → Save project**։ Կարգավորման վիճակի գծի պահպանման ցուցիչը ցույց է տալիս, որ կարգավորումը պահպանված է։

## Խորհուրդներ

- Կարգավորումը տեղափոխելու համար մեկ այլ համակարգիչ կամ պահպանելու համար դիտարկիչի արտաքին պահեստ, տե՛ս [Կարգավորումը տեղափոխել համակարգիչների միջև](/guides/projects/move-a-project-between-computers/)։
- Ինչպես նաև, ձայնային արտահանումը լսելու պատճեն է, ոչ թե կարգավորում։ Պահպանեք կարգավորումը, եթե կարող եք նորից խմբագրել։
