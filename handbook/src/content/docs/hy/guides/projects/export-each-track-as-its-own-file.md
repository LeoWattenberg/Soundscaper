Խառնարարի ինժեները, տեսահոլովակի խմբագիրը կամ մեկ այլ ծրագրի համագործակիցը սովորաբար ցանկանում է առանձին հատվածները, ոչ թե խառնուրդը։ Stems արտահանումը յուրաքանչյուր հոսքը արտադրում է իր անհատական ֆայլում, բոլորը նույն երկարությամբ և հավասարեցված նախագծի սկզբին, և դրանք փաթեթավորում է մեկ արխիվի մեջ։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Export Audio → Export multiple, split by tracks** ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք առաջին հոսքը։ Ֆայլը տեղակայվում է որպես կլիպ իր անհատական հոսքում։
3. Ընտրեք **File → Import audio** և ընտրեք երկրորդ հոսքը։ Ֆայլը տեղակայվում է որպես կլիպ իր անհատական հոսքում։
4. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը որպես **WAV**, կարգավորեք **Output**-ը որպես **Individual stems (split by tracks)** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է անմիջապես, երբ արտադրումն ավարտվում է, և դրա հղումը մնում է երկխոսության պատուհանում։ Յուրաքանչյուր հոսքը դառնում է WAV ZIP-ի ներսում, կրճատված մինչև նույն երկարությունը, որպեսզի դրանք հավասարեցվեն այլուր ներմուծելիս։

## Խորհուրդներ

- Լռացնելը և միայնակ խաղացնելը (mute and solo) ազդեցություն չեն ունենում stems-երի վրա. յուրաքանչյուր հոսք արտադրվում է։
- Անվանեք հոսքերը արտահանումից առաջ — stem ֆայլերը իրենց անունները վերցնում են դրանցից։
