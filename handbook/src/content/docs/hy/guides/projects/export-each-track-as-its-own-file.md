Խառնարար, տեսահոլովակի խմբագիր կամ այլ ծրագրի համագործակից սովորաբար ցանկանում է առանձին հատվածները, ոչ թե խառնուրդը։ Stems արտահանումը յուրաքանչյուր հոսքը արտադրում է իր անհատական ֆայլում, բոլորը նույն երկարությամբ և հավասարեցված նախագծի սկզբին, և դրանք փաթեթավորում է մեկ արխիվի մեջ։

:::note[Աուդացիայից եկողներու համար]
Սա Audacity-ի **File → Export Audio → Export multiple, split by tracks** գործառույթն է։ Ցանկացած անունները ներքևում Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import** և ընտրեք առաջին հոսքը։ Այն տեղակայվում է որպես կլիպ իր անհատական հոսքի վրա։
3. Ընտրեք **File → Import** և ընտրեք երկրորդ հոսքը։ Այն տեղակայվում է որպես կլիպ իր անհատական հոսքի վրա։
4. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը **WAV**, կարգավորեք **Output**-ը **Individual stems (split by tracks)** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է, հենց երբ արտադրումն ավարտվում է, և դրա հղումը մնում է երկխոսության պատուհանում։ Յուրաքանչյուր հոսքը դառնում է WAV ZIP-ի ներսում, կտրված նույն երկարությամբ, որպեսզի դրանք հավասարեցվեն այլուր ներմուծելիս։

## Խորհուրդներ

- Լռացնելը և մենակ արտադրելը (mute and solo) չեն ազդում stems-երի վրա. յուրաքանչյուր հոսք արտադրվում է։
- Անվանեք հոսքերը արտահանումից առաջ — stem ֆայլերը վերցնում են իրենց անունները դրանցից։
