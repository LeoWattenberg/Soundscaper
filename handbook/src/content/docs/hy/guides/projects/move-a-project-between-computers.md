Կարգավորումների գրադարանը գտնվում է մեկ բրաուզերում՝ մեկ համակարգչի վրա։ Կարգավորումը ցանկացած այլ վայր տեղափոխելու համար՝ մեկ այլ մեքենա, գործընկեր, պահուստային սկավառակ՝ արտահանեք այն որպես կարգավորման ֆայլ։ `.sscape` ֆայլը պարունակում է ձայնային տվյալները և բոլոր խմբագրումները, և բացվում է ցանկացած Soundscaper-ում։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Save Project → Backup Project, ապա File → Open** գործողությունն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ կարգավորումը պատրաստ է, հենց որ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import** և ընտրեք կարգավորման նյութը։ Այն տեղակայվում է որպես կլիպ՝ առանձին հոսքի վրա։
3. Ընտրեք **File → Export project file (.sscape)**։ Ամբողջ կարգավորումը բեռնվում է որպես մեկ `.sscape` ֆայլ։ Պահպանեք ֆայլը անվտանգ վայրում. այն ամբողջական կարգավորումն է։
4. Ընտրեք **File → Open** և ընտրեք ֆայլը։ Համակարգչի վրա, որտեղ դեռ կարգավորումը չկա, այն ուղղակի բացվում է. այստեղ, որտեղ գրադարանը արդեն պարունակում է այն, Soundscaper-ը առաջարկում է **Open as read-only copy**՝ սեղմեք այն։
   *Դուք պետք է տեսնեք.* Կարգավորումը բացվում է իր հոսքով և կլիպով՝ ճիշտ այնպես, ինչպես արտահանված է։

## Խորհուրդներ

- Միայն կարդալու պատճենը չի կարելի խմբագրել, մինչև որ դուք այն պահպանեք որպես իր սեփական կարգավորում File մենյուից։
- Ֆայլը ZIP արխիվ է՝ ձայնային տվյալներով ներսում. ձեռքով չբացեք այն։

## Կապված ուղեցույցներ

Ավելի [projects and files](/guides/projects/) ուղեցույցներ.

- [Save your project](/guides/projects/save-your-project/) — Պահպանեք կարգավորումը՝ բոլոր հոսքերով և խմբագրումներով, տեղական կարգավորումների գրադարանում։

- [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/) — Ռենդերեք հոսքերը առանձին, որպես ստեմներ, մեկ բեռնման մեջ։
- [Change a clip’s sample rate](/guides/projects/change-a-clips-sample-rate/) — Վերափոխեք կլիպի նմուշավորման հաճախությունը, որպեսզի այն համապատասխանի կարգավորման մնացած մասի օգտագործած հաճախությանը։
- [Export each chapter as its own file](/guides/projects/export-each-chapter-as-its-own-file/) — Բաժանեք մեկ երկար ձայնագրություն ֆայլերի՝ ձեր դրած նշանների հիման վրա։
