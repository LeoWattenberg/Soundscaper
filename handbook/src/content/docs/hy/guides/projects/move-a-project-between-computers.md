Ծրագրի գրադարանը գտնվում է մեկ բրաուզերում՝ մեկ համակարգչի վրա։ Ծրագիրը տեղափոխելու համար այլուր՝ մեկ այլ մեքենա, գործընկեր կամ պահուստային սկավառակ, անհրաժեշտ է այն արտահանել որպես ծրագրային ֆայլ։ `.sscape` ֆայլը պարունակում է ձայնային տվյալները և բոլոր խմբագրումները, և բացվում է ցանկացած Soundscaper-ում։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Save Project → Backup Project, ապա File → Open** գործողությունն է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ ծրագիրը պատրաստ է անմիջապես, երբ խմբագիրը բեռնվում է։
2. Ընտրեք **File → Import audio** և ընտրեք ծրագրի նյութը։ Ֆայլը տեղակայվում է որպես կլիպ՝ առանձին հոսքի վրա։
3. Ընտրեք **File → Export project file (.sscape)**։ Ամբողջ ծրագիրը բեռնվում է որպես մեկ `.sscape` ֆայլ։ Պահպանեք ֆայլը անվտանգ վայրում. այն ամբողջական ծրագիրն է։
4. Ընտրեք **File → Open Scape project file (.sscape)** և ընտրեք ֆայլը։ Համակարգչի վրա, որտեղ դեռ ծրագիրը չկա, այն բացվում է ուղղակիորեն. այստեղ, որտեղ գրադարանը արդեն պարունակում է այն, Soundscaper-ը առաջարկում է **Open as read-only copy**՝ սեղմեք այն։
   *Դուք պետք է տեսնեք.* Ծրագիրը բացվում է իր հոսքով և կլիպով՝ ճիշտ այնպես, ինչպես արտահանված է։

## Խորհուրդներ

- Միայն կարդալու պատճենը չի կարելի խմբագրել, մինչև որ դուք այն պահպանեք որպես իր սեփական ծրագիր՝ File մենյուից։
- Ֆայլը ZIP արխիվ է՝ ձայնային տվյալներով ներսում. ձեռքով չպետք է անհատուցել այն։

## Կապված ուղեցույցներ

Ավելի շատ [projects and files](/guides/projects/) ուղեցույցներ.

- [Save your project](/guides/projects/save-your-project/) — Պահպանեք ծրագիրը՝ բոլոր հոսքերով և խմբագրումներով, տեղական ծրագրային գրադարանում։
- [Open an Audacity project](/guides/projects/open-an-audacity-project/) — Ընդունեք գոյություն ունեցող .aup3 կամ .aup4 ծրագիր Soundscaper-ում՝ իր հոսքերի ամբողջականությամբ։
- [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/) — Արտադրեք հոսքերը առանձին, որպես stems, մեկ բեռնման մեջ։
- [Change a clip’s sample rate](/guides/projects/change-a-clips-sample-rate/) — Վերափոխեք կլիպի նմուշավորման հաճախությունը, որպեսզի այն համապատասխանի ծրագրի մնացած մասի օգտագործած հաճախությանը։
- [Export each chapter as its own file](/guides/projects/export-each-chapter-as-its-own-file/) — Բաժանեք մեկ երկար ձայնագրություն ֆայլերի՝ ձեր դրած նշանների հիման վրա։
