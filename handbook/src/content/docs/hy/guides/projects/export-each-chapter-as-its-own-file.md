Լեկցիա, որը պետք է դառնա մեկ թեմայի համար մեկ ֆայլ, ալբոմի կողմ, որը պետք է կտրվի հատվածների, օդիոգիրք՝ գլուխների համար մեկ ֆայլով. դրեք նշան ամեն մի մասի սկզբում և արտահանեք մեկ անգամ։ Յուրաքանչյուր նշանը բացում է գլուխ, որը շարունակվում է մինչև հաջորդը, և յուրաքանչյուր գլուխ գրվում է որպես իր անկախ ֆայլ, անվանված նշանի համաձայն, մեկ արխիվի ներսում։ Audacity 3-ը դա անում էր Export Multiple-ի միջոցով, իսկ Audacity 4-ը դա չի վերադարձրել։

:::note[Եկել եք Audacity-ից]
Սա Audacity-ի **File → Export Audio → Export Multiple, split by labels (Audacity 3; Audacity 4-ը չունի Export Multiple)** ֆունկցիան է։ Ցածքում նշված անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, հենց որ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import** և ընտրեք կտրման համար նախատեսված ձայնագրությունը։ Այն տեղադրվում է որպես կլիպ իր անկախ հոսքի վրա։
3. Ընտրեք **View → Panels → Project bin**։ Ձայնագրությունը հիմա ժամանակային սանդղակի վրա է, ուստի bin-ի թաքցնելը տեղ է ազատում Markers վահանակի համար։
4. Ընտրեք **View → Show markers**։ Նշանների շարքը այն տեղն է, որտեղ ցուցադրվում և անվանվում են գլուխների սկզբնակետերը։
5. Սեղմեք գործիքների վահանակի **Jump to project start** կոճակը։ Առաջին գլուխը պետք է սկսվի շատ սկզբում, ուստի առաջին նշանը դրվում է զրոյի վրա։
6. Markers վահանակը բաց լինելիս (**View → Panels → Markers** ցույց է տալիս այն), սեղմեք **Add marker at playhead**։ Սեղմեք Enter նոր նշանի վրա, թվագրեք `Part one` և նորից սեղմեք Enter՝ անվանելու համար։
7. Սեղմեք ալիքի գծի վրա այնտեղ, որտեղ սկսվում է երկրորդ մասը, որպեսզի դրեք կուրսորը այնտեղ։
8. Markers վահանակը բաց լինելիս (**View → Panels → Markers** ցույց է տալիս այն), սեղմեք **Add marker at playhead**։ Սեղմեք Enter նոր նշանի վրա, թվագրեք `Part two` և նորից սեղմեք Enter՝ անվանելու համար։
9. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը **MP3**, կարգավորեք **Output**-ը **Chapters (split by markers)** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է, հենց որ արտադրումն ավարտվում է, և նրա հղումը մնում է երկխոսության պատուհանում։ Յուրաքանչյուր գլուխ դառնում է MP3 արխիվի ներսում, համարակալված հերթականությամբ և անվանված իր նշանի համաձայն։

## Խորհուրդներ

- Անվանված տիրույթը արտահանում է ճիշտ իր սեփական տիրույթը, ուստի օգտագործեք տիրույթներ նշանների փոխարեն, երբ մասերի միջև ընդհատումներ կան։
- Լեյբլային հոսքի վրա գտնվող լեյբլները կտրվում են նույն կերպ. ընտրեք **Chapters (split by labels)**, որպեսզի կտրեք դրանցով՝ նշանների փոխարեն։
- Հոսքերի ըստ կտրելու համար՝ նշանների փոխարեն, տե՛ս [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/)։
