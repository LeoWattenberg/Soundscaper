Լեկցիա, որը պետք է դառնա մեկ թեմայի համար մեկ ֆայլ, ալբոմի կողմ, որը պետք է կտրվի հատվածների, օդիոգիրք՝ գլուխների համար մեկ ֆայլով. դրեք նշան ամեն մի մասի սկզբում և արտահանեք մեկ անգամ։ Յուրաքանչյուր նշանը բացում է գլուխ, որը շարունակվում է մինչև հաջորդը, և յուրաքանչյուր գլուխը գրվում է որպես իր օժանդակ ֆայլ, անվանված նշանի համաձայն, մեկ արխիվի մեջ։ Audacity 3-ը դա անում էր Export Multiple-ի միջոցով, իսկ Audacity 4-ը դա չի վերադարձրել։

:::note[Եթե գալիս եք Audacity-ից]
Սա Audacity-ի **File → Export Audio → Export Multiple, split by labels (Audacity 3; Audacity 4-ը չունի Export Multiple)** ֆունկցիան է։ Ցուցված անունները Soundscaper-ի սեփականն են և երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, քանի որ խմբագիրը բացվում է։
2. Ընտրեք **File → Import audio** և ընտրեք կտրելիս ձայնագրությունը։ Ֆայլը տեղակայվում է որպես կլիպ իր օժանդակ հոսքի վրա։
3. Ընտրեք **View → Show markers**։ Նշանների շարքը այն տեղն է, որտեղ ցուցադրվում և անվանվում են գլուխների սկզբնակետերը։
4. Սեղմեք գործիքների վահանակի **Jump to project start** կոճակը։ Առաջին գլուխը պետք է սկսվի շատ սկզբում, ուստի առաջին նշանը դրվում է զրոյի վրա։
5. Երբ Նշանների վահանակը բաց է (**View → Panels → Markers** ցույց է տալիս այն), սեղմեք **Add marker at playhead**։ Սեղմեք Enter նոր նշանի վրա, թվացրեք `Part one` և նորից սեղմեք Enter՝ անվանելու համար։
6. Կտտացրեք ալիքի ձևի վրա, որտեղ սկսվում է երկրորդ մասը, որպեսզի դնեք կուրսորը այնտեղ։
7. Երբ Նշանների վահանակը բաց է (**View → Panels → Markers** ցույց է տալիս այն), սեղմեք **Add marker at playhead**։ Սեղմեք Enter նոր նշանի վրա, թվացրեք `Part two` և նորից սեղմեք Enter՝ անվանելու համար։
8. Ընտրեք **File → Export audio**, կարգավորեք **Format**-ը **MP3**, կարգավորեք **Output**-ը **Chapters (split by markers)** և սեղմեք **Export**։ Ֆայլը ներբեռնվում է, քանի որ ռենդերինգը ավարտվում է, և նրա հղումը մնում է երկխոսության պատուհանում։ Յուրաքանչյուր գլուխը դառնում է MP3 արխիվի մեջ, համարակալված հերթականությամբ և անվանված իր նշանի համաձայն։

## Խորհուրդներ

- Անվանված տիրույթը արտահանում է ճիշտ իր սեփական տիրույթը, ուստի օգտագործեք տիրույթներ նշանների փոխարեն, երբ մասերի միջև ընդհատումներ կան։
- Եթե նշանների հոսքի վրա կան պիտակներ, դրանք նույն կերպ են կտրվում. ընտրեք **Chapters (split by labels)**, որպեսզի կտրեք դրանցով՝ նշանների փոխարեն։
- Եթե ցանկանում եք կտրել հոսքերով՝ նշանների փոխարեն, տեսեք [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/)։
