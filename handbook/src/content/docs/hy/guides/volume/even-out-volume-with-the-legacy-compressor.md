Audacity 3-ը թողարկել է երկու սեղմող. ժամանակակիցը՝ ունենալով ծնկան մաս, նախադիտում և ուղիղ չափիչներ, և բնօրինակ, ավելի պարզը, որը պահել է որպես Legacy Compressor (Ժառանգված սեղմող)։ Ժառանգված դիզայնն ունի աղմուկի հատակ, որից ցածր այն դադարում է աշխատել՝ այդպիսով երբեք չբարձրացնելով սենյակի աղմուկը դադարների ընթացքում, և ըստ լռության արդյունքը բերում է մինչև 0 դԲ։ Audacity 4-ը հեռացրել է այն, իսկ Soundscaper-ը պահում է այն նախագծերի և ականջների համար, որոնք սովորած են դրան։

:::note[Եկեք Audacity-ից]
Սա Audacity-ի **Effect → Volume and Compression → Legacy Compressor (Audacity 3; Audacity 4-ը ունի միայն նոր Compressor-ը)** է։ Ցածրև անունները Soundscaper-ի սեփականն են, որոնք երբեմն տարբերվում են։
:::

## Քայլեր

1. Բացեք Soundscaper-ը։ Նոր, դատարկ նախագիծը պատրաստ է, ոչ ոքից հետո, երբ խմբագիրը բեռնվի։
2. Ընտրեք **File → Import audio** և ընտրեք ձայնագրությունը, որը պետք է հավասարեցնել։ Ֆայլը տեղակայվում է որպես կլիպ իր սեփական հոսքում։
3. Ընտրեք **Select → Select all**։
4. Ընտրեք **Effect → Legacy effects → Legacy Compressor**։ **Legacy Compressor** երկխոսության պատուհանում կարգավորեք **Threshold**-ը `-20` և **Ratio**-ը `4`, ապա սեղմեք **Apply to selection**։ −20 դԲ-ից բարձր ամեն ինչ նվազեցվում է հարաբերակցությամբ, այստեղ՝ 4:1։ Make-up gain-ը այնուհետև բարձրացնում է ամբողջ արդյունքը՝ գագաթնակետին հասնելով 0 դԲ։
5. Սեղմեք **Play**-ը լսելու համար, ապա **Stop**-ը։
   *Դուք պետք է տեսնեք.* Լուսանկարները և թույլ հատվածները ավելի մոտ են իրար, և ամբողջ ձայնագրությունն ավելի լուսանկար է։

## Խորհուրդներ

- Բարձրացրեք **Noise floor**-ը, եթե սեղմողը բարձրացնում է շշուկը դադարների ընթացքում. էֆեկտն անտեսում է ցանկացած բան, որը ավելի թույլ է, քան այն։
- Սեղմողի համար, որը կարող եք լսել աշխատելիս, երբ կարգավորում եք, օգտագործեք ժամանակակիցը. [Հավասարեցնել ձայնը սեղմողով](/guides/volume/even-out-volume-with-a-compressor/)։
