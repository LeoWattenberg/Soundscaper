## Ինչու՞ր հնարավորություն կարող է գործել

Հնարավորությունները խմբավորված են ըստ նրանից, թե ինչ են դրանք պահանջում հարթակից։ Տեսեք [Արտադրանքի հնարավորություններ](/reference/generated/product-capabilities/)՝ իմանալու, թե որ հնարավորություններն են ակտիվացնում յուրաքանչյուր արտադրանքը։

| Մակարդակ | Ի՞նչ է նշանակում |
| --- | --- |
| `web-core` | Աշխատում է բոլոր աջակցվող զննարկիչներում՝ առանց ընտրովի հարթակային հատկանիշի պահանջի։ |
| `web-enhanced` | Աշխատում է այն զննարկիչում, որը ապահովում է ավելի նոր պահեստավորման և մեդիայի հատկանիշները, որոնք անհրաժեշտ են հնարավորության համար։ |
| `electron-enhanced` | Աշխատում է զննարկիչում, և սեղանի հավելվածը ավելի շատ է անում դրա հետ։ |
| `electron-only` | Անհրաժեշտ է սեղանի հավելվածը, քանի որ զննարկիչը չի կարողանում հասնել նրան, ինչը օգտագործում է հնարավորությունը։ |
