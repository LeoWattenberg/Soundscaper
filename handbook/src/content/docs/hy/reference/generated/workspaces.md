Աշխատանքային տարածքը ժամանակագրության շուրջ տեղակայված վահանակների և գործիքների վահանակների պահպանված դասավորությունն է։ Ընտրելով մեկը՝ փոխարինում եք ընթացիկ դասավորությունը, ապա կարող եք տեղափոխել ցանկացած բան և պահպանել ձեր սեփական աշխատանքային տարածքը, ինչի մասին այս էջը չի նկարագրում։
