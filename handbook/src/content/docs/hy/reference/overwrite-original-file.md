Soundscaper-ի և Framescaper-ի Electron տարբերակներում **Ֆայլ → Վերագրել ֆայլի անունը** հրամանը ամբողջությամբ խմբագրված նախագիծը արտահանում է սկզբնապես ներմուծված մեդիա ֆայլի վրա։ Այն օգտագործում է սկզբնական ֆայլի աջակցվող արտահանման կարգավորումները և անմիջապես պահպանում է՝ առանց արտահանման երկխոսությունը կամ ֆայլի ընտրիչը բացելու։ Ձայնը պահպանում է աղբյուրի ձևաչափը, նմուշառման հաճախականությունը և ալիքների քանակը։ Աջակցվող MP4 և WebM տեսանյութերը պահպանում են աղբյուրի կոնտեյները, չափերն ու կադրերի հաճախականությունը։

Ներմուծեք մեկ մեդիա ֆայլ **Ֆայլ → Ներմուծել** հրամանով, կատարեք խմբագրումները և ընտրեք **Ֆայլ → Վերագրել ֆայլի անունը**։ Կարող եք կրկնել գործողությունը հետագա խմբագրումներից հետո։ Ժամանակային ընտրությունը չի սահմանափակում վերագրումը․ միշտ արտապատկերվում է ամբողջ նախագիծը։ Նախագիծը պահպանում է ներմուծված մեդիան և խմբագրման պատմությունը։

Հրամանն անհասանելի է, եթե նախագծում չկա աջակցվող սկզբնական ֆայլ, ներմուծվել են մի քանի սկզբնական ֆայլեր, կամ ընթանում է ներմուծում, ձայնագրում կամ մշակում։ Բրաուզերի տարբերակներն օգտագործում են արտահանման սովորական երկխոսությունը։

Այլ նպատակակետ ընտրելու կամ արտահանման կարգավորումները փոխելու համար Soundscaper-ում ընտրեք **Ֆայլ → Արտահանել ձայն**, իսկ Framescaper-ում՝ **Ֆայլ → Արտահանել տեսանյութ**։ Վերագրումը փոխարինում է սկզբնական ֆայլի բովանդակությունը․ չխմբագրված ձայնագրությունը պահելու համար առանձին պատճեն պահեք։
