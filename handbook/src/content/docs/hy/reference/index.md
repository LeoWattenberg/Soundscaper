Ծանոթագրող էջերը ստեղծվում են ստուգված ռաունթայմ ռեեստրերից և հանձնվում են պահոցին։ Դրանք նկարագրում են իրականացված վարքագիծը, ոչ թե ծրագրային քարտեզի մուտքերը կամ աղբյուրային ֆայլերի և փորձարկումների պարզապես առկայությունը։

Օգտագործեք այս բաժինը՝ պատասխանելու հետևյալ հարցերին.

- Ի՞նչ լռությունային թեքստային կոճակ է կանչում հրամանը։
- Արդյո՞ք հրամանը հասանելի է Soundscaper-ում, Framescaper-ում, թե՞ երկուսում էլ։
- Ի՞նչ ձայնային և տեսահոլովակային ձևաչափեր կարելի է արտահանել։
- Ի՞նչ է էֆեկտի պարամետրի լռությունային արժեքը, և ի՞նչ արժեքներ կընդունի այն։
- Ի՞նչ էֆեկտներ կարող են գործարկվել՝ ձայնը նվագարկվելիս, և ի՞նչ էֆեկտներ պահանջում են ընտրություն։
- Ի՞նչ տեղային օգնության աշխատանքային գործընթացներ գոյություն ունեն, և ի՞նչ մոդելներ են պահանջում դրանք։
- Ի՞նչ վահանակներ է ցուցադրում յուրաքանչյուր աշխատանքային տարածքը։
- Ի՞նչ լեզուներ, դիտարկիչներ և գրասեղանային փաթեթներ են կառուցվում և փորձարկվում։
- Ի՞նչ հատկանիշներ կախված են արտադրանքից, հարթակից կամ FFmpeg ռաունթայմից։

Կազմված էջերը ներառում են իրենց աղբյուրի ծագումը և ստուգվում են շեղումների համար պահոցի որակի դարպասում։

Ձեռքով գրված [Մակրո ծրագրեր](/reference/macro-programs/) էջը փաստագրում է JavaScript API-ն, որով աշխատում է մակրո ծրագիրը։ [Սեղանի հավելվածում ներմուծված ֆայլի վերագրում
](/reference/overwrite-original-file/) էջը նկարագրում է երկու արտադրանքների ընդհանուր Electron ֆայլի հրամանը։ Խմբագրիչի թեստերը ստուգում են դրանց վարքը։
