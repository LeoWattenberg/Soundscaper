## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

Կարդացեք տեսանյութի նմուշավորված կադրերից երևացող տեքստը՝ վերանայման և ինդեքսավորման համար։

## Ներկայիս հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 հարթակների համար պահանջվող onnxruntime-node 1.29.0 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։ macOS x64-ի համար ներբեռնվող շարժիչ չկա, թեև մոդելի կշիռները նշված են այդ հարթակի համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Framescaper: Tools → Search → Index Video, or Tools → Advanced Local Processing → Optical character recognition** հարթակում, որն ունի անհրաժեշտ native runtime-ը։ Տեղային օգնությունը գործում է desktop editor-ում։

1. Ընտրեք տեսանյութ, որը պարունակում է կարդացվող էկրանային տեքստ։
2. Բեռնեք PP-OCRv4 mobile-ը Manage Models-ի միջոցով։ Դա Index Video-ի ընտրովի քայլ է, որը նաև օգտագործում է SigLIP2-ը։
3. Գործարկեք տեղային և վերանայեք ճանաչված տեքստը և դրա կադրային դիրքերը՝ արդյունքները ընդունելուց առաջ։
