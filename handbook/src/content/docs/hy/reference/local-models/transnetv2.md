## Ներկայիս հասանելիություն {#current-availability}

Դիտակետային կառուցվածքները ներառում են անհրաժեշտ onnxruntime-node 1.29.0 ինժեները macOS arm64, Linux x64, Linux arm64, Windows x64 և Windows arm64 համակարգերի համար։ Տեղադրեք այս մոդելի քաշերը Model Manager-ի միջոցով, ապա կատարեք դրա խնդիրը տեղային մակարդակով։ Այս օժանդակվող կառուցվածքային նպատակներն են. խորհրդակցեք գիշերային փորձարկման հաշվետվության հետ՝ կոնկրետ փաթեթի և մեքենայի արդյունքների համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Framescaper: Tools → Advanced Local Processing → Shot detection** պլատֆորմում, որն ունի անհրաժեշտ բնօրինակ ռաունթայմ։ Տեղական օգնությունը գործում է դիտակետային խմբագրիչում։

1. Ընտրեք վիդեոն Framescaper-ում։
2. Տեղադրեք TransNetV2-ը Model Manager-ի միջոցով և ընտրեք մոդելի հիման վրա նկարահանումների հայտնաբերում։
3. Ստուգեք առաջարկվող նկարահանումների սահմանները՝ նշումներ ավելացնելուց կամ դրանք օգտագործելուց առաջ՝ խմբագրումները ծրագրավորելու համար։
