## Ներկայիս հասանելիություն {#current-availability}

Դեսկտոպի կառուցվածքները ներառնում են անհրաժեշտ onnxruntime-node 1.29.0 ինժեները macOS arm64, Linux x64, Linux arm64, Windows x64 և Windows arm64 համակարգերի համար։ Բեռնեք այս մոդելի քաշերը Model Manager-ի միջոցով, ապա գործարկեք դրա խնդիրը տեղային։ Այս քայլերը աջակցվող կառուցվածքային նպատակներն են. կոնկրետ փաթեթի և մեքենայի արդյունքների համար դիտարկեք ամենաշաբաթյա փորձարկման հաշվետվությունը։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Tools → Advanced Local Processing → Source separation** այն հարթակում, որտեղ առկա է անհրաժեշտ տեղային ռաունթայմը։ Տեղային օգնությունը գործում է դեսկտոպի խմբագրիչում։

1. Ընտրեք քանդվող խառը ձայնը։
2. Բեռնեք TIGER-ը Model Manager-ի միջոցով, ապա գործարկեք աղբյուրի քանդումը։
3. Փորձարկեք յուրաքանչյուր առաջարկված ստեմը, ապա ավելացրեք ցանկալի արդյունքները նախագծին։
