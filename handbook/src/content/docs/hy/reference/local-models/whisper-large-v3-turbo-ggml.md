## Օգտագործեք այս մոդելը {#use-this-model}

2. Երբ ցանկանում եք արդարացիորեն ընտրել Whisper-ը, ընտրեք այս ձայնի ճանաչման մոդելը Tools → Advanced Local Processing-ի տակ։
3. Կատարեք տեղականորեն և ստուգեք թե՛ տեքստը, թե՛ սեգմենտների սահմանները ընդունելուց առաջ։
