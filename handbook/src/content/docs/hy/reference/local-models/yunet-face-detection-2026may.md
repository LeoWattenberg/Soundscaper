## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

Գտեք դեմքեր և առարկաներ փորձանքային տեսահոլովակի կադրերում՝ նոր կադրավորում առաջարկելու համար։

YuNet-ը հայտնաբերում է դեմքերը և դրանց դիրքերը։ Տիրույթի հայտնաբերման գործողությունը միավորում է այս արդյունքները D-FINE առարկաների հայտնաբերումների հետ։

## Ներկայիս հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 հարթակների համար պահանջվող onnxruntime-node 1.29.0 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։ macOS x64-ի համար ներբեռնվող շարժիչ չկա, թեև մոդելի կշիռները նշված են այդ հարթակի համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Framescaper: Effect → Video effects → Reframe** հարթակում, որն ունի անհրաժեշտ բնօրինակ runtime-ը։ Տեղային օգնությունը գործում է desktop redactor-ում։

1. Ընտրեք տեսահոլովակի կտոր Framescaper-ում։
2. Տեղադրեք և YuNet-ը, և D-FINE-ը՝ տիրույթի հայտնաբերման համար։ Ուղղորդված Reframe խնդիրը նաև օգտագործում է U²-Net-P առանձնացման հայտնաբերումը։
3. Գործարկեք տեղային և անցկացրեք առաջարկված կրոպի անցկացումը։ Tools → Advanced Local Processing-ը կարող է գործարկել տիրույթի հայտնաբերումը ինքնուրույն։

Այս գործողությունը նաև պահանջում է [D-FINE Nano առարկաների հայտնաբերում](/reference/local-models/dfine-nano-coco/)։
