## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Tools → Search → Index Transcript, ապա Tools → Search → Indexed Search** այն հարթակում, որտեղ առկա է անհրաժեշտ native runtime-ը։ Տեղային օգնությունը աշխատում է desktop editor-ում։

1. Ստեղծեք կամ ներմուծեք թեքստ, ապա տեղադրեք Nomic Embed Text-ը Manage Models-ի միջոցով։
2. Կատարեք Index Transcript-ը՝ թեքստը իմաստային որոնման համար պատրաստելու համար։
3. Օգտագործեք Indexed Search-ը և ուսումնասիրեք համընկնող հատվածները համատեքստում։ Advanced Local Processing-ը նաև բաց է թողնում embedding օպերացիան։
