## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

Կրճատեք սենյակային արտացոլումները գրանցված ձայնում՝ օգտագործելով տեղական դեռևերբերացիայի մոդել։

## Ներկա հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 հարթակների համար պահանջվող onnxruntime-node 1.29.0 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Tools → Advanced Local Processing → Dereverberation** այն հարթակում, որտեղ առկա է անհրաժեշտ նատիվ ռաունթայմը։ Տեղական օգնությունը գործում է desktop խմբագրիչում։

1. Ընտրեք ձայնը, որը ազդված է սենյակային արտացոլումներից։
2. Բեռնեք մոդելը Model Manager-ի միջոցով և գործարկեք դեռևերբերացիան։
3. Համեմատեք արդյունքը սկզբնականի հետ և ընդունեք այն միայն այն դեպքում, եթե ձայնը լսվում է ավելի լավ։
