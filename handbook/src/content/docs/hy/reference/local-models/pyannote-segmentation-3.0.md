## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

Խմբավորեք խոսքը խոսողների հերթերի ըստ՝ որպեսզի կարողանաք վերանայել, թե ով է երբեմն խոսում։

Pyannote-ը ապահովում է խոսքի սեգմենտացիան, որը օգտագործվում է դիարիզացիայի ռաունթայմում։ ERes2Net-ը ապահովում է խոսողների ներդրումները՝ այդ սեգմենտները խմբավորելու համար։

## Ներկայիս հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 հարթակների համար պահանջվող sherpa-onnx-node 1.13.5 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։ macOS x64-ի համար ներբեռնվող շարժիչ չկա, թեև մոդելի կշիռները նշված են այդ հարթակի համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Analyze → Speech → Identify Speakers**-ը այն հարթակում, որտեղ առկա է անհրաժեշտ նատիվ ռաունթայմը։ Տեղային օգնությունը գործում է desktop խմբագրիչում։

1. Ընտրեք վերլուծության համար նախատեսված զրույցը։
2. Բեռնեք և՛ Pyannote սեգմենտացիան, և՛ ERes2Net խոսողի ներդրումը Manage Models-ի միջոցով։ Գործողությունը օգտագործում է զույգը։
3. Գործարկեք տեղային, վերանայեք առաջարկված խոսողների հերթերը և կիրառեք ցանկալի արդյունքները։

Այս գործողությունը նաև պահանջում է [ERes2Net speaker embedding](/reference/local-models/speech-3d-speaker-eres2net/)։
