## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

## Ներկայիս հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 հարթակների համար պահանջվող llama-cpp b10509 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Framescaper: Tools → Advanced Local Processing → Editorial generation** պլատֆորմի վրա, որն ունի անհրաժեշտ native runtime։ Տեղային օգնությունը կատարվում է desktop editor-ում։

1. Պատրաստեք և ստուգեք ձեր ընտրված մեդիայից հայտնի թեկնածուները։
2. Տեղադրեք Qwen-ը Model Manager-ի միջոցով և ընտրեք editorial generation-ը։
3. Ստուգեք յուրաքանչյուր տեքստային առաջարկը ընդունելուց առաջ։ Միայն լիցենզավորված թեկնածուների նույնականացումները և խնդրված տեքստային դաշտերն են ընդունելի։
