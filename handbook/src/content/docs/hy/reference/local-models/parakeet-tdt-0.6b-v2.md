## Ներկա հասանելիություն {#current-availability}

Desktop build-երը ներառում են անհրաժեշտ sherpa-onnx-node 1.13.5 ինժեները macOS arm64, Linux arm64, Linux x64, Windows arm64 և Windows x64 համակարգերի համար։ Այս մոդելի քաշերը տեղադրեք Model Manager-ի միջոցով, ապա կատարեք դրա խնդիրը տեղային մակարդակով։ Այս օջախները աջակցվող build-եր են. կոնկրետ փաթեթի և մեքենայի արդյունքների համար դիտարկեք ամենաշաբաթյա փորձարկման հաշվետվությունը։ Desktop build-ը չի ներառում այս ինժեները macOS x64-ի համար, չնայած մոդելի քաշերը նշված են այդ հարթակների համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Analyze → Speech → Transcribe & Captions**-ը այն հարթակում, որտեղ առկա է անհրաժեշտ native runtime-ը։ Տեղային օգնությունը գործում է desktop editor-ում։

1. Ընտրեք տեքստավորվող ձայնը։
2. Օգտագործեք Manage Models-ը՝ այս մոդելը տեղադրելու համար։ Tools → Advanced Local Processing-ը թույլ է տալիս ընտրել կոնկրետ ձայնային ճանաչման մոդել։
3. Կատարեք տեղային մակարդակով, ապա ստուգեք տեքստը և ժամանակացույցը՝ տեքստը ընդունելուց առաջ։
