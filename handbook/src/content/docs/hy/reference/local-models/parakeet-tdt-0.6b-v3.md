## Ներկա հասանելիություն {#current-availability}

Desktop build-երը փաթեթավորում են անհրաժեշտ sherpa-onnx-node 1.13.5 ինժեները macOS arm64, Linux arm64, Linux x64, Windows arm64 և Windows x64 համար։ Այս մոդելի կշիռները տեղադրեք Model Manager-ի միջոցով, ապա տեղապես կատարեք դրա խնդիրը։ Այս փաթեթավորման նպատակները աջակցվում են։ Կոնկրետ փաթեթի և մեքենայի արդյունքների համար դիտարկեք ամենաշաբաթյա փորձարկման հաշվետվությունը։ Desktop build-ը չի փաթեթավորում այս ինժեները macOS x64-ի համար, չնայած մոդելի կշիռները նշված են այդ հարթակների համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Analyze → Speech → Transcribe & Captions** հարթակում, որն ունի անհրաժեշտ բնօրինակ runtime-ը։ Տեղական օգնությունը գործում է desktop redaktory-ում։

1. Ընտրեք ձայնի ունեցող տարածք։
2. Տեղադրեք Parakeet v3-ը Manage Models-ի միջոցով։ Ընտրեք դրա ճշգրիտ մոդելի նույնականացումը Tools → Advanced Local Processing-ում՝ մոդելները համեմատելիս։
3. Կատարեք տեղապես և ստուգեք առաջարկված ձայնագրությունը՝ այն կիրառելուց առաջ։
