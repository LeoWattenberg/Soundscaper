## Նպատակ և կիրառման դեպք {#purpose-and-use-case}

Գտեք դեմքեր և օբյեկտներ նմուշավորված տեսահոլովակի կադրերում՝ նոր կադրավորում առաջարկելու համար։

D-FINE-ը հայտնաբերում է օբյեկտների կատեգորիաները և դրանց դիրքերը։ Տիրույթի հայտնաբերման գործողությունը միավորում է այս արդյունքները YuNet դեմքերի հայտնաբերումների հետ։

## Ներկա հասանելիություն {#current-availability}

Սեղանադիր տարբերակները կարող են ներբեռնել և ստուգել macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 հարթակների համար պահանջվող onnxruntime-node 1.29.0 շարժիչը։ Տեղադրեք այս մոդելն ու պահանջվող միջավայրը Մոդելների կառավարիչի միջոցով, ապա առաջադրանքը գործարկեք տեղում։ Սրանք աջակցվող հավաքման նպատակներ են․ կոնկրետ փաթեթի և սարքի արդյունքների համար տեսեք գիշերային թեստերի հաշվետվությունը։ macOS x64-ի համար ներբեռնվող շարժիչ չկա, թեև մոդելի կշիռները նշված են այդ հարթակի համար։

## Օգտագործեք այս մոդելը {#use-this-model}

Բացեք **Framescaper: Effect → Video effects → Reframe** պահանջվող բնօրինակ runtime-ով հարթակում։ Տեղային օգնությունը գործում է desktop redaktoryում։

1. Ընտրեք տեսահոլովակի կտրվածք Framescaper-ում։
2. Բեռնեք և YuNet-ը, և D-FINE-ը տիրույթի հայտնաբերման համար։ Ուղղորդված Reframe խնդիրը նաև օգտագործում է U²-Net-P առանձնահատկության հայտնաբերումը։
3. Գործարկեք տեղային և անցկացրեք առաջարկված կրոպի ակնարկ։ Tools → Advanced Local Processing-ը կարող է գործարկել տիրույթի հայտնաբերումը առանձին։

Այս գործողությունը նաև պահանջում է [YuNet դեմքերի հայտնաբերում](/reference/local-models/yunet-face-detection-2026may/)։
