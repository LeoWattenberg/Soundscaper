## What this guide is for {#what-this-guide-is-for}

Audacity’s Nyquist plug-ins are small scripts that add effects, generators, and analysers. Soundscaper keeps the bundled scripts that need selection processing under a Nyquist submenu. Adjustable Fade shapes how the recording fades in or out.

:::note[Coming from Audacity?]
This is Audacity's **Effect → Adjustable Fade (a Nyquist plug-in)**. The names below are Soundscaper's own, which may differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and select the recording you want to try the plug-in on. It will appear as a clip on its own track.
3. Choose **Select → Select All**.
4. Choose **Effect → Nyquist → Adjustable Fade**. In the **Adjustable Fade** dialog, set **Mid-fade Adjust (%)** to `25`, then press **Apply**. A positive adjustment will create a rounded fade. Note that Nyquist dialogs use **Apply** rather than 'Apply to Selection'.
5. Press **Play** to listen, then **Stop**.
   *You should observe:* The recording will fade in.

## Tips

- The Generate and Analyse menus also have their own Nyquist submenus, featuring plug-ins such as Pluck and Beat Finder.
- **Tools → Nyquist Prompt** allows you to run a script you create yourself.
- Delay, high-pass and low-pass filters, Noise Gate, Notch Filter, Shelf Filter, Tremolo, and Vocoder all have standard effects in their respective Effect menu categories and run in [realtime racks](/guides/effects/add-a-realtime-effect-to-a-track/).
