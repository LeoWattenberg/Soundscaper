## What this guide is for {#what-this-guide-is-for}

A recording that starts late on the timeline can be returned to the project start with an alignment command. Align start to zero shifts the selected track’s content so its earliest clip begins at zero. This procedure moves one recording later, then aligns it back to the start.

:::note[Coming from Audacity?]
This is Audacity’s **Tracks → Align content → Align start to zero**. The names below are Soundscaper’s own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording you want to align. It lands as a clip on its own track.
3. Drag the clip by its name bar to a later point on the timeline.
4. The clip now starts later than the project start.
5. Choose **Tracks → Align content → Align start to zero**.
6. The recording now begins at time zero.
   *You should see:* The clip’s left edge lines up with the start of the ruler.

## Tips

- Alignment moves the selected track’s content. Use a track that holds only this recording when you want to move it on its own.
- **Edit → Undo** restores the previous position.
