Effects like echo and reverb need space to resonate, and a podcast needs a pause between segments. The Silence generator inserts a gap of exactly the length you type at the cursor, which is more accurate than dragging clips apart manually. 

:::note[New to Soundscaper?]
This is similar to Audacity's **Generate → Silence**. The names below are Soundscaper's own, which may differ slightly.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and select the recording that needs a gap after it. It will appear as a clip on its own track.
3. Click the waveform at the end of the clip to place the cursor there. The silence will be inserted at this point.
4. Select **Generate → Silence**. In the **Silence** dialog, set **Duration (seconds)** to `1`, then click **Generate**.
5. The project will now display 2 clips.
   *You should see:* A one-second silent clip following the original loop.

## Tips

- When a time range is selected, the generator replaces the selection instead of inserting at the cursor.
- To silence existing audio rather than add a gap, see [Silence part of a recording](/guides/cleaning-up/silence-part-of-a-recording/).
