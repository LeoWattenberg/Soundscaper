Markers are notes on the timeline: where a chapter starts, where an error needs correcting, or where the best take begins. They don't alter the audio, they travel with the project, and they can be exported as a label file for use in other software. 

:::note[Switching from Audacity?]
This is the equivalent of Audacity's **Edit → Labels → Add Label at Selection (Ctrl+B)**. The terminology below is Soundscaper's own and may differ slightly.
:::

## Instructions

1. Launch Soundscaper. A new, blank project is ready as soon as the editor loads.
2. Select **File → Import** and choose the recording you wish to mark up. It will appear as a clip on its own track.
3. Choose **View → Show markers**. This adds a marker lane above the tracks. Markers exist without it, but this lane allows you to view and edit them.
4. Click on the waveform where you want to place the marker, positioning the cursor accurately. The marker will be placed at the cursor's location.
5. With the Markers panel open (**View → Panels → Markers**), press **Add marker at playhead**. Enter a name for the new marker by pressing Enter, typing `Chorus`, and pressing Enter again.
   *You should see:* The marker appears in the lane above the tracks and in the panel’s list, labelled with the name you assigned.

## Additional Advice

- Selecting a time range and using the same button will create a named region rather than a single point marker.
- **File → Export other → Export labels** saves the markers as a text file compatible with Audacity and other editing software.
