## What this guide is for {#what-this-guide-is-for}

Align together moves the selected tracks to a shared start: the average of their current content start times. It shifts each track’s content as a unit, keeping the spacing between clips on that track. Use one recording per track when you want to line up just those recordings.

:::note[Coming from Audacity?]
This is Audacity’s **Tracks → Align content → Align together**. The names below are Soundscaper’s own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the first recording. It lands as a clip on its own track.
3. Choose **File → Import** and pick the second recording. It lands as a clip on its own track.
4. Drag the clip by its name bar to a later point so the two recordings begin at different times.
5. Use **Tab** to focus the first recording and press **Enter** to select it. Then focus the second recording and press **Shift+Enter** to add it to the selection. Tracks with selected clips are the alignment targets.
6. Choose **Tracks → Align content → Align together**.
7. The first recording now starts at the shared time.
8. The second recording starts at the same time.
   *You should see:* The left edges line up, and both recordings keep their original lengths.

## Tips

- The shared start is not necessarily time zero. To start at the project beginning, [align a recording to zero](/guides/editing/align-a-recording-to-zero/).
- **Edit → Undo** returns each track to its previous position.
