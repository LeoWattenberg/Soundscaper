Learning a riff, checking an edit point, auditioning an effect setting: all are quicker when the audio plays repeatedly without you needing to restart it. Set the loop region to your selected audio and playback will stay within it until you turn the loop off.

:::note[Coming from Audacity?]
This is Audacity's **Transport → Looping → Set Loop to Selection**. The names below are Soundscaper's own, which may differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and select the recording with the passage you want to practise. The file will appear as a clip on its own track.
3. Drag the ruler above the clip to select the passage you want to repeat.
4. Choose **Select → Loop region → Set loop to selection**.
5. The project should now show the **Loop selection** button illuminated.
   *You should see:* The loop button in the transport bar lights up and the loop region is visible above the ruler.
6. Press **Play** to listen, then **Stop**.
   *You should see:* Playback will loop around the selected passage.

## Tips

- Press **L** or the loop button on the transport bar to toggle the loop on and off without losing the region.
- Adjust the loop region by dragging its ends in the ruler.
