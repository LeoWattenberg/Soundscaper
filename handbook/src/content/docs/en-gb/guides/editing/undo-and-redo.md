## What this guide is for {#what-this-guide-is-for}

Every edit and effect goes on the project’s history, so nothing you try is a risk. Undo steps back one change at a time — an effect, a cut, a move — and Redo puts it back. The history survives saving and reopening the project.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Undo and Edit → Redo (Ctrl+Z, Ctrl+Y)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import audio** and pick any recording. The file lands as a clip on its own track.
3. Press the **Split tool** button in the toolbar.
4. Click the waveform anywhere in the clip to put the cursor there. A split is a good edit to practise on because you can see it.
5. Press the **Split tool** button in the toolbar. Back to the normal pointer.
6. The project now shows 2 clips.
7. Press the **Undo** button in the toolbar. The toolbar button and **Edit → Undo** do the same thing.
8. The project now shows 1 clip.
   *You should see:* The split is gone and the clip is whole again.
9. Press the **Redo** button in the toolbar.
10. The project now shows 2 clips.
   *You should see:* The split is back.

## Tips

- **Window → History** lists every step, and clicking one jumps straight to it.
- Undo covers edits to the project, not exports; a file you have already saved stays as it is.
