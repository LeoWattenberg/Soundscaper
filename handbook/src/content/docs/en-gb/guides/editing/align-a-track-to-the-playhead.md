## What this guide is for {#what-this-guide-is-for}

When a recording needs to begin at a particular cue, dragging it by eye can be imprecise. Align start to playhead moves the selected track’s content so its start meets the cursor, while preserving the recording’s length.

:::note[Coming from Audacity?]
This is Audacity's **Tracks → Align Tracks → Align Start to Playhead**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording you want to place at a cue. It lands as a clip on its own track.
3. Drag the clip by its name bar to a later point on the timeline. Move the clip first so the cursor can mark a different start position.
4. Click the waveform the cue where the recording should start to put the cursor there.
5. Choose **Tracks → Align content → Align start to playhead**. The selected track’s earliest clip is moved to the cursor position.
6. The recording now starts at the playhead.
   *You should see:* The clip begins at the cue and keeps its original length.

## Tips

- Alignment moves every clip on each selected track. Use a track that contains only the recording you want to move.
- Use **Tracks → Align content → Align start to zero** to return a selected track to the project start.
