Noise Reduction removes background noise from the entire recording, while a noise gate operates differently. It reduces the volume when the audio level drops below a set threshold, typically during pauses between sentences, and increases it again when the voice returns. Although it doesn't eliminate noise beneath the speech, it ensures clean gaps between phrases and is straightforward to set up.

:::note[Audacity Users]
This functionality is equivalent to Audacity's **Effect → Noise Removal and Repair → Noise Gate**. The names used below are specific to Soundscaper and may vary.
:::

## Steps

1. Launch Soundscaper, which will open a new, empty project.
2. Select **File → Import** and choose the audio take with noisy pauses. It will be added as a clip on its own track.
3. Choose **Select → Select all** to select the entire clip.
4. Go to **Effect → Noise removal and repair → Noise gate**. In the dialog box, set the **Threshold** to `-35` and **Level reduction** to `-30`, then click **Apply to selection**. Adjust the threshold to a level above the background noise but below the quietest speech—around −35 dB is suitable for most voice recordings. The reduction value determines how much the pauses are attenuated, avoiding complete silence for a more natural sound.
5. Press **Play** to preview the results, then **Stop**.
   *Expected Outcome:* The pauses should be quiet, and each phrase should remain unchanged.

## Tips

- If word endings are being cut off, increase the **Hold** or **Release** values to slow down the gating process; these are controlled in seconds.
- For persistent noise that overlaps with the voice, consider using [Noise Reduction](/guides/cleaning-up/remove-background-noise/) or a combination of both techniques.
