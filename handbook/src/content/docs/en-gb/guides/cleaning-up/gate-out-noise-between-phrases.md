Noise Reduction removes noise from the entire recording, whereas a gate operates differently. When the audio level drops below a set threshold – between sentences or during pauses – the gate lowers the volume, and it increases again when the voice returns. While it cannot eliminate noise beneath the spoken words, it effectively silences the gaps between them and is straightforward to configure.

:::note[Migrating from Audacity?]
This functionality corresponds to Audacity's **Effect → Noise Removal and Repair → Noise Gate**. The names used below are specific to Soundscaper and may vary.
:::

## Instructions

1. Launch Soundscaper. A new, blank project will open automatically.
2. Select **File → Import audio** and choose the file containing noisy pauses. It will be added as a clip on its own track.
3. Select **Select → Select all**.
4. Apply the effect by choosing **Effect → Nyquist → Noise Gate**. In the **Noise Gate** dialog, set **Gate threshold (dB)** to `-35` and **Level reduction (dB)** to `-30`, then click **Apply**. The threshold should be set above the noise level but below the quietest speech – around −35 dB is suitable for most voice recordings. The reduction value determines how much the pauses are lowered; avoiding a complete mute ensures a more natural sound.
5. Press **Play** to preview, then **Stop**.
   *Expected outcome:* The pauses should be quiet, with each phrase remaining unaffected.

## Additional Tips

- If word endings are being cut off, increase **Hold (ms)** or **Decay (ms)** to slow down the gate's closing speed.
- For persistent noise underlying the voice, consider using [Noise Reduction](/guides/cleaning-up/remove-background-noise/) instead, or in combination with this method.
