Sometimes you want a passage removed but not the time it occupies – a phone ringing during a pause, a name you need to censor. Silencing keeps the recording the same length and only mutes the selected part.

:::note[Coming from Audacity?]
This is Audacity's **Edit → Remove Special → Silence Audio**. The names below are Soundscaper's own, which may differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and select the recording containing the passage to mute. It appears as a clip on its own track.
3. Drag the ruler above the clip to select only the section you want to mute.
4. Select **Edit → Remove Special → Silence Audio**.
5. The project now displays 3 clips.
   *You should see:* The waveform is flat in the new middle clip, with the original audio unchanged on either side.

## Tips

- Silencing is a reversible edit: **Edit → Undo** restores the audio.
- To remove both the sound and the time, see [Cut a mistake out of a recording](/guides/editing/cut-out-a-mistake/).
