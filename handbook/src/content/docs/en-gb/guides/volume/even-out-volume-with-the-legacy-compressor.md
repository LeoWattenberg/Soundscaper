Audacity 3 included two compressors: the modern one with a knee, lookahead, and live meters, and the original, simpler 'Legacy Compressor' which it retained. The legacy design has a noise floor below which it doesn't operate, preventing it from amplifying room noise during pauses. It also normalises the result up to 0 dB by default. Audacity 4 removed this option, but Soundscaper retains it for users accustomed to it.

:::note[Transitioning from Audacity?]
This is Audacity's **Effect → Volume and Compression → Legacy Compressor (Audacity 3; Audacity 4 only has the new Compressor)**. The names used below are Soundscaper's own, which may differ.
:::

## Instructions

1. Launch Soundscaper. A new, empty project will be ready as soon as the editor loads.
2. Select **File → Import** and choose the recording you wish to normalise. It will be placed as a clip on its own track.
3. Choose **Select → Select all**.
4. Select **Effect → Legacy effects → Legacy Compressor**. In the **Legacy Compressor** dialog, set **Threshold** to `-20` and **Ratio** to `4`, then press **Apply to selection**. Any audio above −20 dB will be reduced by the specified ratio, 4:1 in this case. Make-up gain then raises the entire result so the peak reaches 0 dB.
5. Press **Play** to listen, then **Stop**.
   *You should observe:* Louder and quieter sections are brought closer in volume, and the entire recording is louder overall.

## Additional Advice

- Increase **Noise floor** if the compressor is amplifying background hiss during pauses; it will ignore any sound quieter than the set floor.
- For a compressor that you can hear working in real-time, use the modern one: [Even out volume with a compressor](/guides/volume/even-out-volume-with-a-compressor/).
