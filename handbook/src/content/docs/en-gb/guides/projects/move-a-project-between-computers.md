The project library resides within a single browser on a specific computer. To transfer a project elsewhere – to another machine, a colleague, or a backup drive – export it as a project file. The `.sscape` file contains the audio and all edits, and can be opened in any Soundscaper instance.

:::note[Transitioning from Audacity?]
This process is akin to **File → Save Project → Backup Project, followed by File → Open** in Audacity. The terminology below is Soundscaper's own, which may vary slightly.
:::

## Steps

1. Launch Soundscaper. A new, empty project will be ready as soon as the editor loads.
2. Select **File → Import** and choose the project material. It will be imported as a clip on its own dedicated track.
3. Choose **File → Export project file (.sscape)**. The entire project will be downloaded as a single `.sscape` file. Store this file securely; it encapsulates the complete project.
4. Opt for **File → Open** and select the downloaded file. On a computer where the project is not yet present, it will open directly. However, on the original computer where the library already contains the project, Soundscaper will offer **Open as read-only copy** – click this option.
   *Expected Outcome:* The project should open with its track and clip in the exact state as when it was exported.

## Tips

- A read-only copy cannot be edited until you save it as a new project from the File menu.
- The file is structured as a ZIP archive with the audio embedded within; do not attempt to manually extract its contents.
