The project library is contained within one browser on one computer. To transfer a project elsewhere – to another machine, a colleague, or a backup drive – export it as a project file. The `.sscape` file contains the audio and all edits, and can be opened in any Soundscaper.

:::note[Migrating from Audacity?]
This process is equivalent to **File → Save Project → Backup Project, followed by File → Open** in Audacity. The terminology below is Soundscaper's own and may differ slightly.
:::

## Steps

1. Launch Soundscaper. A new, empty project will be ready as soon as the editor loads.
2. Select **File → Import audio** and choose the project material. The file will be placed as a clip on its own track.
3. Choose **File → Export project file (.sscape)**. The entire project will download as a single `.sscape` file. Store this file securely; it represents the complete project.
4. Select **File → Open Scape project file (.sscape)** and select the downloaded file. On a computer that doesn't already have the project, it will open directly. On the original computer, where the library already contains the project, Soundscaper will offer **Open as read-only copy** – click this option.
   *You should see:* The project opens with its track and clip exactly as exported.

## Tips

- A read-only copy cannot be edited until you save it as a new project from the File menu.
- The file is a ZIP archive containing the audio; do not manually unzip it.
