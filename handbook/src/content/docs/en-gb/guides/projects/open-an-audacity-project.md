Projects made in Audacity 3 (.aup3) and Audacity 4 (.aup4) open directly. The tracks, clips, names and positions are preserved; any effects that Soundscaper does not have are listed for your reference. The original file remains unchanged.

:::note[Importing from Audacity?]
This functionality is equivalent to Audacity's **File → Open**. Please note that the names used here are Soundscaper's own, which may differ from Audacity's.
:::

## Steps

1. Launch Soundscaper. A new, empty project will be ready once the editor loads.
2. Select **File → Audacity projects → Open Audacity project** (.aup3, .aup4) and choose your project. Its tracks and clips will appear as they were arranged in Audacity.
3. The imported project will display a clip named **Audio 1** and a track named **Fixture track**.
   *Expected outcome:* You should see the track and clip from the Audacity project, complete with their original names.

## Tips

- For older `.aup` projects, ensure the `_data` folder is located next to the project file; select both when prompted.
- **File → Audacity projects → Export AUP4** allows you to send the project back to Audacity.
