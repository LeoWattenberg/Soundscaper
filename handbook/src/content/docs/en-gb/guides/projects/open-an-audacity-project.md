Projects made in Audacity 3 (.aup3) and Audacity 4 (.aup4) open directly. The tracks, clips, names, and positions are preserved; effects that Soundscaper does not have are listed for your reference. The original file remains unchanged.

:::note[Importing from Audacity?]
This is Audacity's **File → Open** function. Please note that the names below are Soundscaper's own, which may differ from Audacity's.
:::

## Steps

1. Launch Soundscaper. A new, empty project will be ready once the editor loads.
2. Select **File → Open** and choose the project file. Its tracks and clips will appear as they were arranged in Audacity.
3. The project will now display a clip named **Audio 1** and a track named **Fixture track**.
   *Expected outcome:* You should see the track and clip from the Audacity project, complete with their original names.

## Tips

- For older `.aup` projects, ensure the `_data` folder is located next to the project file when selecting it.
- **File → Export other → Export AUP4** allows you to export the project back to Audacity format.
