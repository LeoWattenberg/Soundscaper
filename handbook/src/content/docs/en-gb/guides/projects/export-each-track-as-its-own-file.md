A mixing engineer, a video editor, or a collaborator on another program usually requires the individual tracks, not the mixed output. A stems export renders each track to its own separate file, all of the same length and aligned to the project's start, and then bundles them into a single archive.

:::note[Transitioning from Audacity?]
This functionality corresponds to **File → Export Audio → Export multiple, split by tracks** in Audacity. The terminology used below is specific to Soundscaper and may vary.
:::

## Procedure

1. Launch Soundscaper. A new, empty project will be ready for use once the editor loads.
2. Select **File → Import** and choose the first track. It will be placed as a clip on its own dedicated track.
3. Repeat the previous step to import the second track, placing it on a separate track.
4. Access **File → Export audio**, set the **Format** to **WAV**, select **Output** as **Individual stems (split by tracks)**, then click **Export**. The file will download automatically upon completion of the rendering process, and the download link will remain available in the dialog. Each track will be saved as a separate WAV file within the ZIP archive, trimmed to the same length to ensure alignment when imported into another project.

## Additional Advice

- Mute and solo functions do not influence the stems; all tracks are rendered.
- Ensure you name the tracks before exporting, as the stem files will adopt their names from the respective tracks.
