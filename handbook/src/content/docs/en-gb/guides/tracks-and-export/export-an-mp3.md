An MP3 is small, plays everywhere, and is what most podcast hosts and messaging apps expect. The export renders the whole project — every track, effect, and edit — into one file.

:::note[Coming from Audacity?]
This is Audacity's **File → Export Audio → MP3**. The names below are Soundscaper's own, which may differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and select the recording to publish. It appears as a clip on its own track.
3. Choose **File → Export Audio**, set **Format** to **MP3**, and click **Export**. The file downloads once the render is complete, and its link remains in the dialog. The file is encoded in the browser; no data leaves your computer.

## Tips

- An MP3 is a delivery copy, not a backup. Keep the project or export a WAV as well if you might need to edit again.
- Peaks at full scale can clip after encoding. Normalise to −1 dB or lower before exporting.
- Bit Rate Mode determines how the encoder allocates bits. The Standard preset adjusts the rate to suit the audio content and is suitable for most deliveries; select Constant when a host or older hardware player requires a fixed rate.
