## What this guide is for {#what-this-guide-is-for}

Make stereo track renders two mono tracks into one stereo clip and replaces the source tracks. The track whose menu you use supplies the left channel; the first compatible mono track below it supplies the right. If there is none below, Soundscaper uses the first compatible mono track elsewhere in the project. Put the intended right-channel track directly below the left-channel track before combining them.

:::note[Coming from Audacity?]
This is Audacity’s **Upper mono track menu → Make stereo track (Audacity 4)**. The names below are Soundscaper’s own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the mono recording intended for the left channel. It lands as a clip on its own track.
3. Choose **File → Import** and pick the mono recording intended for the right channel. It lands as a clip on its own track. It appears on the track below the first recording. Arrange the clips at the times they should play.
4. Open the menu for the left-channel recording from the **Track options** button in its header and choose **Track channels → Make stereo track**.
5. The project now shows 1 clip and 2 tracks.
   *You should see:* One stereo clip replaces the two mono recordings, with the intended sound in each channel.

## Tips

- The new clip spans both tracks’ content at the project sample rate. Gaps on either track become silence in that channel.
- If the recordings should start together, [align their track starts](/guides/editing/align-track-starts-together/) before combining them.
- Keep a project copy if you need the separate clips for later edits. **Edit → Undo** brings the two mono tracks back.
