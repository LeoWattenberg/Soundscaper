WAV preserves every sample precisely as the editor arranges them. Utilise this format for master files, when passing audio to a video editor or another DAW, and for any audio you might wish to process subsequently.

:::note[Transitioning from Audacity?]
This is the equivalent of **File → Export Audio → WAV** in Audacity. The names used below by Soundscaper may differ slightly from Audacity's terminology.
:::

## Procedure

1. Launch Soundscaper. A fresh, empty project will be ready as soon as the editor loads.
2. Select **File → Import audio**, then choose the recording you wish to deliver. The file will be imported as a clip on its own dedicated track.
3. Choose **File → Export audio**, set the **Format** to **WAV**, then press **Export**. The rendered file will automatically download once the process is complete, and its link will remain accessible in the dialog box.

## Additional Advice

- WAV files are substantial in size: approximately ten megabytes per minute for stereo audio at CD quality.
- To export individual tracks as separate files, adjust the **Mode** in the export dialog to 'individual stems'.
