With a dozen tracks, muting them one header at a time to audition a single new part is tedious, and unmuting them all afterwards is even worse. Muting All Tracks silences the entire project with a single command, and Unmuting All Tracks restores it, without affecting the solo buttons. Audacity 3 had both commands; Audacity 4 has not reinstated them.

:::note[Coming from Audacity?]
This corresponds to Audacity's **Tracks → Mute/Unmute → Mute All Tracks and Unmute All Tracks (Audacity 3; not in Audacity 4)**. The names used below are Soundscaper's own, which may differ.
:::

## Steps

1. Open Soundscaper. A new, empty project will be ready as soon as the editor loads.
2. Select **File → Import** and choose the first recording. It will appear as a clip on its own track.
3. Select **File → Import** again and pick the second recording. This will also appear as a clip on a separate track.
4. Choose **Tracks → Mute all tracks**.
5. The project should now show the **Mute** button illuminated for every track.
   *You should observe:* Playback is silent.
6. Select **Tracks → Unmute all tracks**.
7. The project should now have no muted tracks.
   *You should observe:* Everything plays as before.

## Tips

- Mute all tracks, then unmute the one or two you wish to hear — this is quicker than using solo buttons when your selection changes frequently.
- To listen to a single track without affecting the others, consider [soloing it](/guides/tracks-and-export/mute-and-solo-tracks/) instead.
