## What this guide is for {#what-this-guide-is-for}

Ogg Vorbis makes a smaller listening copy by discarding some audio information. Export the mix in this format when the receiving player or service supports it.

:::note[Coming from Audacity?]
This is Audacity's **File → Export Audio → Ogg Vorbis (Audacity 3)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording or mix to share. It lands as a clip on its own track.
3. Choose **File → Export audio**, set **Format** to **Ogg Vorbis**, and press **Export**. The file downloads as soon as the render finishes, and its link stays in the dialog.
   *You should see:* The export dialog offers a downloadable Ogg file.

## Tips

- Quality controls the tradeoff between file size and encoding quality.
- Keep [a lossless master](/guides/tracks-and-export/export-a-flac/) if you expect to edit or encode the recording again.
