## What this guide is for {#what-this-guide-is-for}

Duplicate track copies the whole track, including every clip and its timeline position. Use the copy to try a different edit or effect while keeping the original. Selecting one clip identifies the track to duplicate; the command copies the other clips on that track too.

:::note[Coming from Audacity?]
This is Audacity’s **Tracks → Duplicate (Audacity 4)**. The names below are Soundscaper’s own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and pick the recording on the track you want to duplicate. It lands as a clip on its own track.
3. Click the waveform at the point where you want to split the recording into two independently editable pieces to put the cursor there. Skip this cursor placement and the next Split step if the track already has several clips, or if you want to keep it as one clip.
4. Choose **Edit → Audio clips → Split**.
5. The project now shows 2 clips.
   *You should see:* The track holds two clips, ready to be copied together.
6. Use **Tab** to focus one clip on the track and press **Enter** to select it.
7. Choose **Tracks → Duplicate track**.
8. The project now shows 4 clips and 3 tracks.
   *You should see:* The original and its copy each hold both clips at the same timeline positions.

## Tips

- The original and the copy both play. [Mute or solo a track](/guides/tracks-and-export/mute-and-solo-tracks/) when comparing them so you hear one version at a time.
- To copy just a passage, [duplicate a selection to a new track](/guides/editing/duplicate-a-selection-to-a-new-track/) instead.
- **Edit → Undo** removes the duplicate track.
