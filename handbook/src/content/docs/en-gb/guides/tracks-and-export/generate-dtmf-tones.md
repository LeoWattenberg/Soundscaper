## What this guide is for {#what-this-guide-is-for}

DTMF uses two simultaneous tones for each telephone keypad symbol. Generate the sequence you need for a telephone sound effect, with pauses between its symbols.

:::note[Coming from Audacity?]
This is Audacity's **Generate → DTMF Tones (Audacity 3)**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **Generate → DTMF tones**. In the **DTMF tones** dialog, set **DTMF sequence** to `123`, set **Amplitude** to `0.2` and set **Duration (seconds)** to `2`, then press **Generate**. Enter your keypad symbols in order. The total duration covers both the tones and the pauses.
3. The project now shows 1 clip.
   *You should see:* One clip contains the keypad tones in the order you entered.

## Tips

- Duty cycle controls how much of the sequence is tone rather than silence.
- The timing summary shows each tone and pause length before you generate the clip.
