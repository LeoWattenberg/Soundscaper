## What this guide is for {#what-this-guide-is-for}

Before you normalise or export, it helps to know where you are. Measure loudness analyses the selection the way streaming platforms and broadcasters do — integrated loudness in LUFS, loudness range, and true peak — so you can compare it with a target instead of guessing from the meter.

:::note[Coming from Audacity?]
This is Audacity's **Analyse → Measure RMS, or Loudness Normalisation’s measurement**. The names below are Soundscaper's own, which sometimes differ.
:::

## Steps

1. Open Soundscaper. A new, empty project is ready as soon as the editor loads.
2. Choose **File → Import** and select the mix you want to measure. It appears as a clip on its own track.
3. Choose **Select → Select all**.
4. Choose **Analyse → Measure loudness**. The **Delivery Report** dialogue opens with the selection report.
   *You should see:* Integrated loudness, loudness range and true peak for the selection.

## Tips

- Podcast platforms typically request −16 LUFS stereo or −19 LUFS mono with true peaks below −1 dBTP; check the platform’s specific guidance.
- If the values are significantly off the target, run [Loudness Normalisation](/guides/volume/normalize-loudness-for-podcasts/) and measure again.
