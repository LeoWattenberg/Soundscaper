Soundscaper is the audio-focused editor. It combines an Audacity-aligned menu
and editing model with a project bin, nondestructive multitrack arrangement,
recording, real-time effects, loudness and frequency analysis, and portable
project interchange.

## Recommended path

1. Follow the tutorial [Your first Soundscaper project](/tutorials/your-first-project/).
2. [Set up recording](/soundscaper/recording/), if you need new material.
3. [Edit, mix, and export](/soundscaper/edit-mix-and-export/).
4. Review [storage and backup behaviour](/projects-and-data/storage-backups-and-privacy/).
5. Pick a [how-to guide](/guides/) for the task in front of you — noise removal, fades, loudness, export and more.

Open the browser editor at [soundscaper.org/en](https://soundscaper.org/en/).

For desktop assistance, see [local processing, models, and plugins](/help/local-processing/).
