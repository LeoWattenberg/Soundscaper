## Purpose and use case {#purpose-and-use-case}

Transcribe selected speech locally using the included whisper.cpp runtime.

## Current Availability {#current-availability}

Desktop builds can download and authenticate the required whisper-cpp v1.9.3 engine for macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Install this model and its required runtime through Model Manager, then run its task locally. These are supported build targets; consult the nightly test report for results on a particular package and machine. The desktop build has no downloadable engine for macOS x64 even though model weights are listed for those platforms.

## Using This Model {#use-this-model}

Open **Analyze → Speech → Transcribe & Captions** on a platform with the required native runtime. Local assistance runs within the desktop editor.

1. Select the speech and install Whisper large-v3 turbo through Manage Models.
2. Explicitly select this speech-recognition model under Tools → Advanced Local Processing when required.
3. Run locally and review both the text and segment boundaries before accepting.

## Result Review {#review-the-result}

- Whisper may produce inaccurate text, especially for noisy recordings or material without clear speech. Listening while reviewing is recommended.
