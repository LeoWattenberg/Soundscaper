Soundscaper and Framescaper share a project format and, on the web, the same
local project library. Choose the editor around the task rather than creating a
second copy of the project.

## Choose Soundscaper for audio

Soundscaper is the full audio workstation. Use it to:

- Record one or more inputs.
- Edit, arrange, mix, and analyse audio.
- Apply audio effects and generators.
- Work with labels, spectral selections, macros, and mastering tools.
- Export audio, stems, project files, or compatible Audacity interchange files.

[Start a Soundscaper project](/tutorials/your-first-project/)

## Choose Framescaper for video

Framescaper focuses the workspace on picture editing. Use it to:

- Import video and its linked audio.
- Arrange clips, nested sequences, and multicamera material.
- Adjust video effects, geometry, and compositing.
- Deliver MP4 or WebM video.

[Start a Framescaper project](/framescaper/first-project/)

## Move between them

On `soundscaper.org`, both products use the same origin and local project
library. Use **File → Edit in Framescaper** or **File → Edit in Soundscaper**
when the command is available. The handoff preserves the project rather than
copying its media.

Some features intentionally appear in only one product. In particular,
Soundscaper owns recording and audio-production tools, while Framescaper owns
the complete video effects and compositing workspace.
