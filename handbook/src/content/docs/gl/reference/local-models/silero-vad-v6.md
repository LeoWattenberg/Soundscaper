## Finalidade e caso de uso {#purpose-and-use-case}

Detecta as rexións de fala antes da transcripción ou da eliminación de pausas longas.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Usar este modelo {#use-this-model}

Abre **Efecto → Eliminación e reparación de ruído → Limpar recheos e silencios** ou **Analizar → Fala → Transcribir e subtitular** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona unha rexión de audio que conteña fala e pausas.
2. Abre a tarefa e instala Silero VAD a través de Xestionar modelos.
3. Executa localmente e despois revisa as rexións detectadas ou as propostas de limpeza antes de aplicar cambios.

## Descarga e requisitos {#download-and-requirements}

Identidade do modelo: `silero-vad-v6`, versión **6.2.1**.

Tamaño aproximado da descarga do artefacto do modelo: **2.22 MiB**. O contorno de execución necesario engádese á primeira descarga se aínda non está instalado. Memoria mínima do sistema: **2 GiB**. Este requisito do catálogo refírese á memoria total, non á memoria libre actual. A inferencia tamén precisa memoria libre suficiente e a instalación precisa espazo de traballo; a memoria non garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Tamén se precisa un contorno de execución descargable compatible.

En Windows, instala o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) máis recente que estea admitido e corresponda coa aplicación de escritorio: **x64** para unha compilación x64 ou **ARM64** para unha compilación ARM64. Os motores nativos ONNX e Sherpa precisan estas bibliotecas; as descargas do modelo e do contorno de execución non as inclúen. Non se precisa Visual Studio para usar a aplicación.
