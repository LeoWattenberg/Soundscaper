## Finalidade e caso de uso {#purpose-and-use-case}

Proporciona outro modelo local de recoñecemento de fala para transcritos e subtítulos.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Usar este modelo {#use-this-model}

Abre **Analizar → Fala → Transcribir e subtítulos** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona unha rexión con fala.
2. Instala Parakeet v3 a través de Xestionar modelos. Escolle a súa identidade de modelo exacta en Ferramentas → Procesamento local avanzado ao comparar modelos.
3. Executa localmente e revisa o transcrito proposto antes de aplicalo.

## Descarga e requisitos {#download-and-requirements}

Identidade do modelo: `parakeet-tdt-0.6b-v3`, versión **3.0.0**.

Tamaño aproximado da descarga do artefacto do modelo: **639.42 MiB**. O contorno de execución necesario engádese á primeira descarga se aínda non está instalado. Memoria mínima do sistema: **4 GiB**. Este requisito do catálogo refírese á memoria total, non á memoria libre actual. A inferencia tamén precisa memoria libre suficiente e a instalación precisa espazo de traballo; a memoria non garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Tamén se precisa un contorno de execución descargable compatible.

En Windows, instala o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) máis recente que estea admitido e corresponda coa aplicación de escritorio: **x64** para unha compilación x64 ou **ARM64** para unha compilación ARM64. Os motores nativos ONNX e Sherpa precisan estas bibliotecas; as descargas do modelo e do contorno de execución non as inclúen. Non se precisa Visual Studio para usar a aplicación.

Ferramentas → Xestor de modelos descarga os artefactos publicados do modelo e o contorno de execución necesario na primeira instalación, e verifica as sumas SHA-256 rexistradas. O procesamento usa os ficheiros instalados localmente. Abre Almacenamento e verificación no Xestor de modelos para consultar avisos, reparar unha instalación ou cambiar a localización do almacenamento.
