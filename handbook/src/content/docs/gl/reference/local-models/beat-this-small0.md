## Finalidade e caso de uso {#purpose-and-use-case}

Atopa as posicións do pulso na música usando o modelo máis pequeno Beat This.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos.

## Uso deste modelo {#use-this-model}

Abre **Ferramentas → Procesamento local avanzado → Seguimento do pulso** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona un pasaxe de música rítmica.
2. Instala Beat This small a través do Xestor de modelos e selecciona ese modelo exacto para o seguimento do pulso.
3. Escucha a grella de pulso proposta antes de aceptar os marcadores de pulso ou unha proposta de tempo.

## Descarga e requisitos {#download-and-requirements}

Identidade do modelo: `beat-this-small0`, versión **1.1.0**.

Tamaño aproximado da descarga do artefacto do modelo: **10.08 MiB**. O contorno de execución necesario engádese á primeira descarga se aínda non está instalado. Memoria mínima do sistema: **2 GiB**. Este requisito do catálogo refírese á memoria total, non á memoria libre actual. A inferencia tamén precisa memoria libre suficiente e a instalación precisa espazo de traballo; a memoria non garante velocidade.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Tamén se precisa un contorno de execución descargable compatible.

En Windows, instala o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) máis recente que estea admitido e corresponda coa aplicación de escritorio: **x64** para unha compilación x64 ou **ARM64** para unha compilación ARM64. Os motores nativos ONNX e Sherpa precisan estas bibliotecas; as descargas do modelo e do contorno de execución non as inclúen. Non se precisa Visual Studio para usar a aplicación.

## Revisa o resultado {#review-the-result}

- O seguimento do pulso pode seguir patróns a medio tempo ou dobre tempo, e a música irregular pode producir pulsos perdidos.
- A proba separada do modelo pequeno verifica as posicións ordenadas do pulso dentro do audio e os datos de tempo finitos e positivos, sen requirer tempos de pulso exactos.
