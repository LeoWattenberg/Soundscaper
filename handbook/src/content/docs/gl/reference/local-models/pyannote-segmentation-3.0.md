## Finalidade e caso de uso {#purpose-and-use-case}

Agrupa a fala en intervencións de falantes para que poidas revisar quen fala cando.

Pyannote fornece a segmentación da fala utilizada polo tempo de execución da diarización. ERes2Net fornece as incrustacións de falante utilizadas para agrupar eses segmentos.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Usar este modelo {#use-this-model}

Abre **Analizar → Fala → Identificar falantes** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona a conversa que se vai analizar.
2. Instala tanto a segmentación de Pyannote como a incrustación de falante de ERes2Net a través de Xestionar modelos; a operación utiliza o par.
3. Executa localmente, revisa as intervencións de falante propostas e aplica os resultados desexados.

Esta operación tamén require [incrustación de falante ERes2Net](/reference/local-models/speech-3d-speaker-eres2net/).

## Revisar o resultado {#review-the-result}

- Os IDs de falante son grupos inferidos da gravación, non identidades do mundo real verificadas.
- As frases curtas, as voces solapadas e as voces similares poden agruparse incorrectamente. A proba verifica intervencións non baleiras válidas, non un número exacto de falantes.
