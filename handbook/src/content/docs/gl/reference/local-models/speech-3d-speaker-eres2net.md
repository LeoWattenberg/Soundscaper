## Finalidade e caso de uso {#purpose-and-use-case}

Agrupa a fala en intervencións de falantes para que poidas revisar quen fala cando.

ERes2Net converte os segmentos de fala en representacións numéricas de falantes. O tempo de execución de diarización combínase con Pyannote segmentation para agrupar a gravación en intervencións de falantes.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor sherpa-onnx-node 1.13.5 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Usar este modelo {#use-this-model}

Abre **Analyze → Speech → Identify Speakers** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona a conversa que se vai analizar.
2. Instala tanto Pyannote segmentation como ERes2Net speaker embedding a través de Manage Models; a operación usa o par.
3. Executa localmente, revisa as intervencións de falantes propostas e aplica os resultados desexados.

Esta operación tamén require [Pyannote segmentation 3.0](/reference/local-models/pyannote-segmentation-3.0/).

## Revisar o resultado {#review-the-result}

- Os IDs de falantes son grupos inferidos da gravación, non identidades do mundo real verificadas.
- As alocucións curtas, as voces solapadas e as voces similares poden agruparse incorrectamente. A proba comproba intervencións non baleiras válidas, non un número exacto de falantes.
