Converte a fala seleccionada nun transcrito cronometrado para subtítulos e edición de transcritos.

## Disponibilidade actual {#current-availability}

As versións de escritorio inclúen o motor necesario sherpa-onnx-node 1.13.5 para macOS arm64, Linux arm64, Linux x64, Windows arm64 e Windows x64. Instala os pesos deste modelo a través do Xestor de modelos e despois executa a súa tarefa localmente. Estes son os obxectivos de compilación admitidos; consulta o informe de probas nocturno para obter resultados nun paquete e máquina concretos. A compilación de escritorio non inclúe este motor para macOS x64, aínda que se listan pesos de modelo para esas plataformas.

## Usar este modelo {#use-this-model}

Abre **Analizar → Fala → Transcribir e subtítulos** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona a fala que se vai transcribir.
2. Usa Xestionar modelos para instalar este modelo. Ferramentas → Procesamento local avanzado permítechete escoller un modelo específico de recoñecemento de fala.
3. Executa localmente e despois revisa o texto e a cronometaxe antes de aceptar o transcrito.

## O que verifica a proba empaquetada {#what-the-packaged-test-checks}

Caso: `parakeet-v2-transcript`; operación: `speech-recognition`.

Entrada: Un extracto de dominio público do discurso de toma de posesión de John F. Kennedy, con un segundo de silencio engadido en cada extremo, preparado como audio mono a 16 kHz.

O transcrito debe conter texto non baleiro con cronometaxe válida dentro do audio de entrada. Non se compara a redacción exacta.

O paquete nocturno-con-probas descarga artefactos de modelo reais e solicita inferencia a través do tempo de execución empaquetado. Un modelo necesario ausente do catálogo falla no seu caso. Os motores nativos ausentes fallan nas plataformas admitidas polo catálogo. Estas comprobacións custosas execútanse separadamente da suite de navegador normal. Unha execución superada confirma a execución básica do modelo e a estrutura de saída utilizable; non establece a calidade perceptual nin a precisión na túa gravación.

## Revisar o resultado {#review-the-result}

- Comproba os nomes, a puntuación, os números e a cronometaxe contra a gravación.
- Unha proba superada require texto lexible e cronometaxe válida, non unha transcripción de referencia exacta. Non mide a precisión do recoñecemento entre idiomas nin condicións de gravación.
