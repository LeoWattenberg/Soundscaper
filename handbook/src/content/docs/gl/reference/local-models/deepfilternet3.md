## Finalidade e caso de uso {#purpose-and-use-case}

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. ## Usar este modelo {#use-this-model}

Abra **Efecto → Eliminación e reparación de ruído → Mellorar diálogo** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Seleccione o diálogo que desexe mellorar.
2. Instale DeepFilterNet3 a través de Xestionar modelos e elixa Executar localmente.
3. Escute o resultado proposto en comparación coa orixinal antes de aplicalo. Desfacer restaura unha edición de proxecto aceptada.
