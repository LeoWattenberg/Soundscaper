## Finalidade e caso de uso {#purpose-and-use-case}

Crear representacións numéricas locais de pasaxes de transcritos e consultas de busca para a busca semántica.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Usar este modelo {#use-this-model}

Abra **Ferramentas → Busca → Indexar transcritos, e despois Ferramentas → Busca → Busca indexada** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Cree ou importe un transcrito e despois instale Nomic Embed Text a través de Xestionar modelos.
2. Execute Indexar transcritos para preparar o texto para a busca semántica.
3. Use Busca indexada e revise as pasaxes coincidentes no contexto. O Procesamento local avanzado tamén expón a operación de incrustación.

## Descarga e requisitos {#download-and-requirements}

Identidade do modelo: `nomic-embed-text-v1.5`, versión **1.5.0**.

Tamaño aproximado da descarga do artefacto do modelo: **131.62 MiB**. O contorno de execución necesario engádese á primeira descarga se aínda non está instalado. Memoria mínima do sistema: **4 GiB**. Este requisito do catálogo refírese á memoria total, non á memoria libre actual. A inferencia tamén precisa memoria libre suficiente e a instalación precisa espazo de traballo; a memoria non garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Tamén se precisa un contorno de execución descargable compatible.

En Windows, instala o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) máis recente que estea admitido e corresponda coa aplicación de escritorio: **x64** para unha compilación x64 ou **ARM64** para unha compilación ARM64. Os motores nativos ONNX e Sherpa precisan estas bibliotecas; as descargas do modelo e do contorno de execución non as inclúen. Non se precisa Visual Studio para usar a aplicación.

Ferramentas → Xestor de modelos descarga os artefactos publicados do modelo e o contorno de execución necesario na primeira instalación, e verifica as sumas SHA-256 rexistradas. O procesamento usa os ficheiros instalados localmente.
