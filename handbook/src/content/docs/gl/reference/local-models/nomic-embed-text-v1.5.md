Crear representacións numéricas locais de pasaxes de transcritos e consultas de busca para a busca semántica.

## Disponibilidade actual {#current-availability}

As versións para escritorio inclúen o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64 e Windows x64. Instale os pesos deste modelo a través do Xestor de Modelos e despois execute a súa tarefa localmente. Estes son os obxectivos de compilación admitidos; consulte o informe de probas nocturno para obter resultados nun paquete e máquina concretos. A compilación para escritorio non inclúe este motor para macOS x64, aínda que se listan pesos de modelo para esas plataformas.

## Usar este modelo {#use-this-model}

Abra **Ferramentas → Busca → Indexar transcritos, e despois Ferramentas → Busca → Busca indexada** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Cree ou importe un transcrito e despois instale Nomic Embed Text a través de Xestionar modelos.
2. Execute Indexar transcritos para preparar o texto para a busca semántica.
3. Use Busca indexada e revise as pasaxes coincidentes no contexto. O Procesamento local avanzado tamén expón a operación de incrustación.

## O que verifica a proba empaquetada {#what-the-packaged-test-checks}

Caso: `nomic-text-embedding`; operación: `text-embedding`.

Entrada: Unha pasaxe de texto curta e non baleira proporcionada ao tokenizador real e á rede de incrustación.

Os vectores de incrustación deben ter as dimensións esperadas e conter valores finitos, non nulos e non constantes.

O paquete nocturno-con-probas descarga artefactos de modelo reais e solicita inferencia a través do tempo de execución empaquetado. Un modelo necesario ausente do catálogo falla no seu caso. Os motores nativos ausentes fallan nas plataformas admitidas polo catálogo. Estas comprobacións custosas execútanse separadamente da suite de navegador normal. Unha execución superada confirma a execución básica do modelo e a estrutura de saída utilizable; non establece a calidade perceptiva nin a precisión na súa gravación.

## Revisar o resultado {#review-the-result}

- As incrustacións son datos de busca numéricos, non un transcrito reescrito nin unha resposta xerada.
- As pasaxes relacionadas poden clasificarse de maneira diferente entre execucións ou gravacións. Os vectores finitos e non constantes validan a execución, non a relevancia de cada coincidencia.
