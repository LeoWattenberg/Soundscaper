## Finalidade e caso de uso {#purpose-and-use-case}

Estime a área visualmente prominente dos fotogramas mostrillados para axudar co recuadro.

## Disponibilidade actual {#current-availability}

As versións de escritorio poden descargar e verificar o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instala este modelo e o contorno de execución necesario mediante o Xestor de modelos e executa a tarefa localmente. Estes son os destinos de compilación admitidos; consulta o informe das probas nocturnas para ver os resultados dun paquete e equipo concretos. Non hai un motor descargable para macOS x64, aínda que os pesos do modelo figuran para esa plataforma.

## Uso deste modelo {#use-this-model}

Abre **Framescaper: Efecto → Efectos de vídeo → Recuadro** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona un clip de vídeo e instala U²-Net-P a través de Xestionar modelos.
2. A tarefa guiada de Recuadro tamén require YuNet e D-FINE; Ferramentas → Procesamento local avanzado pode executar a detección de saliencia por separado.
3. Executa localmente e revisa o encuadre proposto antes de aplicalo.
