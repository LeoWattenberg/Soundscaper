Representa imaxes de vídeo muestreadas e texto nun espazo numérico compartido para a busca visual local.

## Disponibilidade actual {#current-availability}

As versións para escritorio inclúen o motor onnxruntime-node 1.29.0 necesario para macOS arm64, Linux arm64, Linux x64, Windows arm64 e Windows x64. Instala os pesos deste modelo a través do Xestor de Modelos e despois executa a súa tarefa localmente. Estes son os obxectivos de compilación admitidos; consulta o informe de probas nocturno para obter resultados sobre un paquete e unha máquina concretos. A compilación para escritorio non inclúe este motor para macOS x64, aínda que se listan pesos de modelo para esas plataformas.

## Uso deste modelo {#use-this-model}

Abre **Framescaper: Ferramentas → Busca → Indexar vídeo, e despois Ferramentas → Busca → Busca indexada** nunha plataforma co tempo de execución nativo necesario. A asistencia local execútase no editor de escritorio.

1. Selecciona o vídeo e instala SigLIP2 a través de Xestionar modelos.
2. Executa Indexar vídeo para analizar os fotogramas muestreados. Instala tamén PP-OCRv4 se desexas o seu paso opcional de lectura de texto.
3. Usa Busca indexada e revisa os momentos do vídeo que coinciden antes de decidir como usalos.

Caso: `siglip-image-text-embedding`; operación: `image-text-embedding`.

Entrada: Dous retratos: o retrato de dominio público da NASA da astronauta Eileen Collins e a fotografía CC0 do gato Chelsea. Cada un adáptase nun fotograma separado con temporización explícita do fotograma de orixe, proporcionando aos detectores unha cara humana e un obxecto claro.

Os vectores de incrustación deben ter as dimensións esperadas e conter valores finitos, non nulos e non constantes.

O paquete nocturno-con-probas descarga artefactos de modelo reais e solicita inferencia a través do tempo de execución empaquetado. Un modelo necesario ausente do catálogo falla no seu caso.
