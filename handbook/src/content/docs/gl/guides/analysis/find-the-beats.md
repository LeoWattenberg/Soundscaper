Beat Finder é un dos analizadores Nyquist incluídos. Escucha os aumentos súbitos de nivel por riba dun limiar e escribe unha etiqueta en cada un deles, o que é unha forma rápida de marcar os compases dun bucle ou os golpes nunha toma de batería antes de cortala.

:::note[Vindos de Audacity?]
Este é o **Analyze → Beat Finder** de Audacity. Os nomes de abaixo son de Soundscaper, que ás veces difiren.
:::

## Pasos

1. Abre Soundscaper. Un proxecto novo e baleiro está listo en canto a editor carga.
2. Escolle **File → Import** e selecciona a gravación que queres marcar. Aparece como un clip na súa propia pista.
3. Escolle **Select → Select all**.
4. Escolle **Analyze → Nyquist → Beat Finder**. No diálogo **Beat Finder**, establece **Threshold Percentage** en `60`, e despois preme **Apply**. O diálogo informa do que atopou; preme **Close** para pecharo. Un porcentaxe máis baixo atopa compases máis silenciosos; súao se marca demasiado.
5. O proxecto amosa agora unha pista chamada **Beat Finder**.
   *Deberías ver:* Unha nova pista de etiquetas chamada Beat Finder baixo o audio, cunha etiqueta en cada compás.

## Consellos

- As etiquetas caen nunha nova pista de etiquetas baixo o audio. Renombra ou elimina calquera que o analizador errase.
- **Analyze → Nyquist → Label Sounds** fai un traballo similar para sons completos separados por silencio.
