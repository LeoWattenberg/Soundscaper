## Para que serve esta guía {#what-this-guide-is-for}

RMS é unha medida media do nivel do sinal ao longo do tempo. Usa o analizador Measure RMS para comparar seccións ou comprobar a intensidade dun fragmento antes de axustalo.

:::note[Vindos de Audacity?]
En Audacity correspóndelle esta ruta: **Analyze → Measure RMS (Nyquist)**. Os nomes seguintes son os propios de Soundscaper e ás veces son distintos.
:::

## Pasos

1. Abre Soundscaper. En canto se carga o editor, queda listo un proxecto novo e baleiro.
2. Escolle **Ficheiro → Importar** e selecciona o fragmento cuxo nivel medio queres medir. Engádese como un clip na súa propia pista.
3. Escolle **Seleccionar → Selecciona todo**.
4. Escolle **Analizar → Nyquist → Measure RMS**. Na caixa de diálogo **Measure RMS**, preme **Aplicar**. O diálogo mostra o resultado; preme **Pechar** para pechalo.
   *Deberías ver:* O informe mostra un nivel RMS en dB para cada canle e para o sinal estéreo.

## Consellos

- RMS describe o nivel medio; usa a [normalización de picos](/guides/volume/normalize-peaks/) cando queiras fixar un obxectivo para a mostra máis alta.
- Selecciona só a sección que queres comparar para que o audio alleo non afecte a medición.
