## Para que serve esta guía {#what-this-guide-is-for}

Echo reproduce a selección despois dun retardo, e despois outra vez, cada repetición máis baixa que a anterior. É o clásico slap-back nunha voz ou o efecto de canón nun grito.

:::note[Vindos de Audacity?]
Este é o **Efecto → Retardo e reverberación → Eco** de Audacity. Os nomes de abaixo son os propios de Soundscaper, que ás veces difiren.
:::

## Pasos

1. Abre Soundscaper. Un novo proxecto baleiro está listo en canto o editor carga.
2. Escolle **Ficheiro → Importar** e escolla o son que debe ecoar. Aparece como un clip na súa propia pista.
3. Escolle **Seleccionar → Seleccionar todo**.
4. Escolle **Efecto → Retardo e reverberación → Eco**. No diálogo **Eco**, establece **Factor de decaemento** en `0.4`, e despois preme **Aplicar á selección**. Cada repetición é 0,4 veces máis baixa que a anterior, polo que o eco desaparece despois de poucas repeticións. **Tempo de retardo** establece a distancia entre elas.
5. Preme **Reproducir** para escoitar, e despois **Deter**.
   *Deberías ver:* O son é seguido de repeticións que se desvanecen a si mesmo.

## Consellos

- Engade dous segundos de silencio despois do clip primeiro (**Xerar → Silencio**) para que as últimas repeticións teñan espazo para sonar.
- Para unha sala en lugar de repeticións distintas, usa [Reverberación](/guides/effects/add-reverb/).
