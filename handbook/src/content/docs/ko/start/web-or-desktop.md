두 에디션 모두 로컬에서 프로젝트를 처리합니다. 저장 및 파일 액세스는 다릅니다.

## 웹 편집기

브라우저 에디션은 프로젝트, 녹음 및 가져온 미디어를 원본 개인 브라우저 저장소에 저장합니다. Soundscaper 계정에 프로젝트를 업로드하지 않으며 계정이 필요하지 않습니다.

앱을 설치하지 않고 즉시 액세스를 원할 때 웹 편집기를 사용하세요. 브라우저 저장소는 브라우저 할당량 및 퇴출 규칙의 대상이 된다는 점을 기억하세요. 사이트 데이터 지우기는 로컬 프로젝트 라이브러리를 제거합니다.

## 데스크톱 미리보기

패키지된 데스크톱 미리보기는 데스크톱 애플리케이션 내부에 자동 저장된 로컬 라이브러리를 유지합니다. 오프라인 편집을 위해 편집 런타임과 출시된 번역을 번들링합니다.

데스크톱 패키지는 서명되지 않습니다. macOS는 Electron 및 네이티브 바이너리를 실행하기 위해 로더가 필요로 하는 ID가 없는 광고 호출 코드 봉인을 적용합니다. 해당 봉인은 게시자 또는 신뢰 주장을 하지 않습니다. 따라서 Windows SmartScreen 또는 macOS Gatekeeper는 미리보기 및 안정 패키지에 대해 알 수 없는 개발자 경고를 표시할 수 있습니다.

`.aup4` 파일을 열면 데스크톱 라이브러리에 독립적인 프로젝트가 가져와집니다. 이후의 편집은 열었던 파일을 다시 작성하지 않습니다. **저장**은 라이브러리 복사본을 업데이트하고 **다른 이름으로 저장**은 새로운 Audacity 교환 파일을 생성합니다.

## 전화 및 태블릿

웹 편집기는 모든 화면에서 데스크톱 레이아웃을 유지하지만 900px 미만(전화기 또는 세로 방향으로 잡은 태블릿)에서는 타임라인이 공간을 확보하도록 크롬을 서랍으로 접습니다.

- 왼쪽 상단의 **메뉴** 버튼은 전체 애플리케이션 메뉴, 프로젝트 탭, 액션 바 및 도구 도구 모음을 포함하는 서랍을 엽니다. 재생, 정지, 녹음 및 검색은 바에 유지됩니다. 명령을 선택하면 서랍이 닫힙니다.
- 트랙 헤더는 타임라인 왼쪽 상단의 **트랙 헤더** 핸들에서 또는 **보기 > 트랙 헤더**에서 슬라이드하여 레인 위로 이동하거나 레인을 탭하거나 Escape를 눌러 다시 넣을 수 있습니다.
- 좁은 화면에서는 편집기 위쪽의 소개가 기본적으로 접혀 있습니다. **소개 표시**를 누르면 다시 나타납니다.

**편집 > 환경설정 > 외관 > 레이아웃**은 자동, 컴팩트 및 데스크톱 간 전환하여 데스크톱에서 작은 창에 데스크톱 크롬을 유지하거나 넓은 태블릿에서 서랍을 선택할 수 있습니다.

## 프로젝트는 자동으로 이동되지 않습니다.

브라우저 및 데스크톱 라이브러리는 별개입니다. 프로젝트를 의도적으로 이동하세요.

- Soundscaper에서 `.sscape`, Framescaper에서 `.fscape`와 같은 Scape 프로젝트 파일을 사용하여 전체 프로젝트를 이동하세요.
- 오디오 교환을 위해 Audacity와 함께 사용할 때 AUP4를 사용하세요.
- 렌더링된 오디오 또는 비디오를 내구성 재생 사본으로 내보내세요.

브라우저 사이트 데이터 또는 데스크톱 애플리케이션 데이터를 삭제하기 전에 [프로젝트 파일](/projects-and-data/project-files/)을 참조하세요.
