## 만들고 레이어 추가하기 {#create-and-add-a-layer}

1. **파일 → 새 컴포지션**을 선택하고 제목, 크기, 프레임 속도,
   프레임 단위 지속 시간을 입력하세요.
2. **레이어 → 새 텍스트** 또는 **레이어 → 새 단색**을 선택하세요. 프로젝트에 여러 컴포지션이
   있으면 대상 컴포지션을 선택하세요.
3. **레이어 → 텍스트와 모양**을 열어 기존 텍스트 레이어나
   도형의 채우기와 획을 편집하세요. 여기에서 가져온 글꼴은 프로젝트에 보존됩니다.

이미지, 비디오, 오디오 소스에는 **파일 → 미디어 가져오기**를 사용하세요. 현재 디코더나
메모리 한도를 초과하는 가져오기는 설명과 함께 거부됩니다.
원본 소스 파일은 변경되지 않습니다.

## 애니메이션과 미리보기 {#animate-and-preview}

**레이어 → 속성과 키프레임**에서 레이어 속성을 선택하고
정확한 프레임 위치에 키를 추가하세요. 곡선 컨트롤은 보간을 변경하고 공간
편집은 위치 경로를 변경합니다. **보기 → 타임라인**은 레이어 타이밍,
순서, 그룹화, 작업 영역 컨트롤을 엽니다.

**보기 → 컴포지션 캔버스**에서 정적 2D 레이어를 선택하고 이동하세요.
사각형은 크기를 조절하고 원은 설정된 기준점 주위로 회전합니다. 완료된 각
드래그는 하나의 되돌리기 단계이며 Escape는 드래그를 취소합니다. 애니메이션이나
표현식으로 구동되는 변형은 속성과 키프레임에서 계속 편집합니다.

**보기 → 컴포지션 미리보기**에서 컴포지션의 위치를 탐색하거나 재생하세요. 미리보기는
보존된 소스 미디어를 사용합니다. 지원되지 않거나 잘못된 장면 설정은 대체 이미지 대신
오류를 발생시킵니다. 미리보기를 닫으면 활성
렌더링 리소스가 해제됩니다.

## 이동 가능한 사본 저장하기 {#save-a-portable-copy}

**파일 → 저장**을 선택하여 현재 리비전을 게시한 다음 **파일 → 사본 저장**으로
`.mscape` 아카이브를 다운로드하세요. 아카이브에는 프로젝트와 다시 여는 데 필요한
원본 미디어가 포함됩니다. 다른 장치나 새 브라우저 라이브러리에서
**파일 → 열기**로 여세요.

## 렌더링 {#render}

**파일 → 렌더링**을 선택하세요. 컴포지션, 출력 형식,
프레임 범위를 선택합니다. 끝 프레임은 제외됩니다. 프레임 0부터 29까지는
`0`에서 `30` 범위를 사용합니다. 분수 작업 영역은 그 안에 포함된 정수 샘플 시각을 선택합니다.
출력 샘플이 없는 영역은 렌더링 전에 바꿔야 합니다.

알파에는 **투명 PNG 시퀀스(.tar)**를 사용하세요. TAR 아카이브의 압축을 풀면
일반 PNG 이미지와 타이밍 메타데이터를 얻을 수 있습니다. MP4와 WebM은 대화상자에서 선택한
배경색을 사용합니다. 렌더링은 제출된 리비전을 고정하므로 이후 편집은
이미 진행 중인 출력에 영향을 주지 않습니다. 렌더링 대화상자를 닫아도
작업은 계속됩니다. **파일 → 렌더링 대기열**은 진행률, 취소,
제출된 리비전 재시도, 완료된 다운로드를 표시합니다. 편집기를 닫으면
미완료 작업이 취소됩니다.
