## 목적 및 사용 사례 {#purpose-and-use-case}

샘플링된 비디오 프레임에서 얼굴과 물체를 감지하여 새로운 프레임 제안을 돕습니다.

YuNet은 얼굴과 그 위치를 감지합니다. 주체 감지 작업은 이러한 결과와 D-FINE 물체 감지를 결합합니다.

## 현재 사용 가능 여부 {#current-availability}

데스크톱 빌드에서 macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64용 필수 onnxruntime-node 1.29.0 엔진을 다운로드하고 확인할 수 있습니다. 모델과 필요한 런타임을 모델 관리자에서 설치한 다음 작업을 로컬에서 실행하세요. 이들은 지원되는 빌드 대상입니다. 특정 패키지와 컴퓨터의 결과는 야간 테스트 보고서를 참조하세요. 모델 가중치가 이 플랫폼에 나열되어 있어도 macOS x64용으로 다운로드할 수 있는 엔진은 없습니다.

## 이 모델 사용하기 {#use-this-model}

필요한 네이티브 런타임을 갖춘 플랫폼에서 **Framescaper: 효과 → 비디오 효과 → 재프레임**을 엽니다. 로컬 지원은 데스크톱 편집기에서 실행됩니다.

1. Framescaper에서 비디오 클립을 선택합니다.
2. 주체 감지를 위해 YuNet과 D-FINE을 모두 설치합니다. 가이드 재프레임 작업은 또한 U²-Net-P 살리언시 감지를 사용합니다.
3. 로컬에서 실행하고 제안된 작물(crop)을 검토합니다. 도구 → 고급 로컬 처리에서는 주체 감지를 자체적으로 실행할 수 있습니다.

이 작업은 또한 [D-FINE Nano 물체 감지](/reference/local-models/dfine-nano-coco/)를 필요로 합니다.
