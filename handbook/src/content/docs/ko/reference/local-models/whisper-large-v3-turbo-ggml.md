## 이 모델 사용하기 {#use-this-model}

필요한 네이티브 런타임을 갖춘 플랫폼에서 **분석 → 음성 → 전사 및 자막**을 엽니다. 로컬 지원은 데스크톱 편집기에서 실행됩니다.

1. 음성을 선택하고 모델 관리자를 통해 Whisper large-v3 turbo를 설치합니다.
2. 도구 → 고급 로컬 처리에서 이 음성 인식 모델을 선택합니다.
3. 로컬에서 실행하고 텍스트와 세그먼트 경계를 확인한 후 승인합니다.
