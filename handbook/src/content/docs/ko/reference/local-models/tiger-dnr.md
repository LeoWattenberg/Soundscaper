## 목적 및 사용 사례 {#purpose-and-use-case}

혼합된 사운드트랙을 대화, 음악, 효과음으로 분리합니다.

## 현재 사용 가능 여부 {#current-availability}

데스크톱 빌드에서 macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64용 필수 onnxruntime-node 1.29.0 엔진을 다운로드하고 확인할 수 있습니다. 모델과 필요한 런타임을 모델 관리자에서 설치한 다음 작업을 로컬에서 실행하세요. 이들은 지원되는 빌드 대상입니다. 특정 패키지와 컴퓨터의 결과는 야간 테스트 보고서를 참조하세요.

## 이 모델 사용하기 {#use-this-model}

필요한 네이티브 런타임을 갖춘 플랫폼에서 **도구 → 고급 로컬 처리 → 소스 분리**를 엽니다. 로컬 지원은 데스크톱 편집기에서 실행됩니다.

1. 분리할 혼합 오디오를 선택합니다.
2. 모델 관리자를 통해 TIGER를 설치한 다음 소스 분리를 실행합니다.
3. 각 제안된 줄기를 청취한 후 프로젝트에 추가할 원하는 결과를 선택합니다.

## 다운로드 및 요구 사항 {#download-and-requirements}

모델 식별자: `tiger-dnr`, 버전 **1.0.0**.

모델 아티팩트의 예상 다운로드 크기: **28.25 MiB**. 필요한 런타임이 아직 설치되지 않았다면 첫 다운로드에 추가됩니다. 최소 시스템 메모리: **4 GiB**. 카탈로그 요구 사항은 현재 여유 메모리가 아니라 전체 메모리를 뜻합니다. 추론에도 충분한 여유 메모리가 필요하고 설치에는 작업 공간이 필요합니다. 메모리 용량이 속도를 보장하지는 않습니다.

게시된 플랫폼: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. 일치하는 다운로드 가능 런타임도 필요합니다.

Windows에서는 데스크톱 앱에 맞는 최신 지원 [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)을 설치하세요. x64 빌드에는 **x64**, ARM64 빌드에는 **ARM64**가 필요합니다. 네이티브 ONNX 및 Sherpa 엔진은 이 라이브러리를 필요로 하며 모델과 런타임 다운로드에는 포함되지 않습니다. 앱을 사용하는 데 Visual Studio는 필요하지 않습니다.

도구 → 모델 관리자는 첫 설치 시 게시된 모델 아티팩트와 필요한 런타임을 다운로드하고 기록된 SHA-256 다이제스트를 확인합니다. 처리는 로컬에 설치된 파일을 사용합니다. 알림을 확인하거나 설치를 복구하거나 저장 위치를 바꾸려면 모델 관리자의 저장소 및 확인을 여세요.

## 결과 검토 {#review-the-result}

- 분리는 누출이나 아티팩트를 남길 수 있으며, 원본 녹음 트랙의 무손실 복구는 아닙니다.
- 혼합 고정 테스트는 세 가지 줄기 모두, 유한하고 올바른 크기의 오디오, 각 줄기에서 변경된 비침묵 샘플을 필요로 합니다. 또한 중복된 줄기를 거부하며 분리 품질을 측정하지 않습니다.
