참조 페이지는 검토된 런타임 레지스트리에서 생성되고 저장소에 커밋됩니다. 이는 로드맵 항목이나 소스 파일 및 테스트의 단순한 존재가 아닌 구현된 동작을 설명합니다.

이 섹션을 사용하여 다음 질문에 대한 답변을 찾으세요:

- 기본 단축키가 어떤 명령을 호출하나요?
- 명령은 Soundscaper, Framescaper 또는 둘 다에서 사용 가능하나요?
- 어떤 오디오 및 비디오 형식으로 내보낼 수 있나요?
- 효과 매개변수의 기본값은 무엇이며, 어떤 값을 허용하나요?
- 오디오 재생 중 실행할 수 있는 효과는 무엇이며, 선택이 필요한 효과는 무엇인가요?
- 어떤 로컬 지원 워크플로우가 존재하며, 어떤 모델이 필요한가요?
- 각 작업 공간은 어떤 패널을 표시하나요?
- 어떤 언어, 브라우저 및 데스크톱 패키지가 빌드되고 테스트되나요?
- 어떤 기능이 제품, 플랫폼 또는 FFmpeg 런타임에 의존하나요?

생성된 페이지에는 소스 출처가 포함되며, 저장소 품질 게이트에서 드리프트가 확인됩니다.

[매크로 프로그램](/reference/macro-programs/)은 여기에서 수동으로 작성된 유일한 페이지입니다. 이는 매크로 프로그램이 실행하는 JavaScript API를 문서화하며, 그 주장은 편집기의 자체 테스트가 샌드박스를 준수하는 것입니다.
