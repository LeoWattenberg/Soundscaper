때로는 통과를 제거하고 싶지만 그 차지하는 시간은 유지하고 싶은 경우가 있습니다. 예를 들어, 일시 중지 아래에서 울리는 전화나 삑 소리를 내야 하는 이름이 있을 수 있습니다. 음소거를 하면 녹음의 길이는 그대로 유지되며 선택한 부분만 평탄해집니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **편집 → 특별 제거 → 오디오 음소거**입니다. 아래의 이름은 Soundscaper의 고유한 이름이며, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 음소거할 통과가 있는 녹음을 선택합니다. 이는 자체 트랙에 클립으로 배치됩니다.
3. 클립 위쪽의 눈금자를 드래그하여 음소거할 부분을 정확히 선택합니다.
4. **편집 → 특별 제거 → 오디오 음소거**를 선택합니다.
5. 프로젝트에는 이제 3개의 클립이 표시됩니다.
   *다음과 같이 보여야 합니다:* 새로운 중간 클립의 파형은 양쪽의 변경되지 않은 오디오 사이에 평탄합니다.

## 팁

- 음소거는 일반적인 편집입니다: **편집 → 되돌리기**는 오디오를 다시 가져옵니다.
- 시간과 소리를 모두 제거하려면 [녹음에서 실수를 잘라내기](/guides/editing/cut-out-a-mistake/)를 참조하세요.

- [DC 오프셋 수정](/guides/cleaning-up/fix-dc-offset/) — 제로 라인 위나 아래에 있는 파형을 재설정합니다.

- [문장 사이 소음 음소거 게이트로](/guides/cleaning-up/gate-out-noise-between-phrases/) — 말할 때 목소리를 통과시키고 아무도 말하지 않을 때 방 소음을 차단합니다.
