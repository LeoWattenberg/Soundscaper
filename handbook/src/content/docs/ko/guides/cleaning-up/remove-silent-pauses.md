긴 테이크와 문장 사이의 느린 정적은 듣기에 피로합니다. 침묵 잘라내기는 임계값 아래의 모든 구간을 찾아 최소 길이보다 긴 구간을 단축하여, 단어에 영향을 주지 않고 리듬을 조입니다. 

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 특별 → 침묵 잘라내기**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 긴 정적이 있는 테이크를 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → 특별 → 침묵 잘라내기**를 선택합니다. **침묵 잘라내기** 대화 상자에서 **임계값**을 `-40`로 설정하고 **선택에 적용**을 누릅니다. -40dB보다 조용한 것은 침묵으로 간주됩니다. 최소 침묵 길이와 잘라내기 길이가 모두 기본값인 0.5초로 유지됩니다.
5. **재생**을 눌러 들어본 후 **중지**합니다.
   *보여야 할 것:* 정적이 짧아지고 모든 구절이 여전히 완전합니다.

## 팁

- 구절 시작 부분의 단어가 잘려지면 최소 침묵 길이를 높이거나 임계값을 낮춥니다.
- 이 효과는 선택의 길이를 변경하므로 다른 것과 정렬하기 전에 실행합니다.
