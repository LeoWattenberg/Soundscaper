메인 험(잡음)은 50Hz(대부분의 국가) 또는 60Hz(미주 지역)와 같은 하나의 주파수에 앉아 있습니다. 노치 필터는 특정 주파수 주변의 좁은 대역을 잘라내고 나머지 부분은 그대로 두어, 험이 충분히 낮지 않아 롤 오프되지 않는 경우 하이패스 필터보다 훨씬 부드럽게 작동합니다. 같은 도구를 사용하여 모니터 휘파람이나 울리는 공명을 제거할 수 있습니다(주파수를 알고 있는 경우).

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → EQ 및 필터 → 노치 필터**입니다. 아래의 이름은 Soundscaper의 고유 이름이며, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 험이 있는 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 표시됩니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → Nyquist → 노치 필터**를 선택합니다. **노치 필터** 대화 상자에서 **주파수(Hz)**를 `50`로 설정하고 **Q(높은 값은 너비를 줄임)**를 `4`로 설정 한 후 **적용**을 누릅니다. 메인 주파수가 60Hz인 경우 60을 사용하십시오. Q 값 4는 좁은 노치입니다. 험이 이동하는 경우 값을 낮추고, 음성에서 잘라낸 것이 들리는 경우 값을 높이십시오.
5. **재생**을 눌러 들어본 후 **중지**를 누릅니다.
   *보여야 할 것:* 험이 제거되고 음성은 그대로입니다.

## 팁

- 주파수가 확실하지 않은가요? 조용한 부분의 [스펙트럼을 그리기](/guides/analysis/plot-a-spectrum/)에서 피크를 읽으십시오.
- 험은 종종 두 배의 주파수에서 조화(harmonic)를 가집니다. 100 또는 120Hz에서 필터를 다시 실행하여 일부 남아 있는 경우 제거하십시오.
