마커는 타임라인에 있는 노트입니다: 장이 시작되는 곳, 수정이 필요한 실수, 좋은 테이크가 시작되는 곳 등입니다. 마커는 오디오를 변경하지 않으며, 프로젝트와 함께 이동하고, 다른 도구에서 사용할 수 있도록 라벨 파일로 내보낼 수 있습니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **편집 → 라벨 → 선택에 라벨 추가 (Ctrl+B)**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 표시하고 싶은 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. **보기 → 마커 표시**를 선택합니다. 이렇게 하면 트랙 위에 마커 레인이 추가됩니다. 마커는 레인이 없더라도 존재하지만, 레인은 마커를 보고 편집할 수 있는 곳입니다.
4. 마커를 배치할 위치의 웨이브폼을 클릭하여 커서를 해당 위치에 배치합니다. 마커는 커서가 있는 곳에 배치됩니다.
5. 마커 패널을 열고 (**보기 → 패널 → 마커**로 표시), **재생 헤드에 마커 추가**를 누릅니다. 새로운 마커에 Enter를 누르고, `Chorus`를 입력한 후 다시 Enter를 눌러 이름을 지정합니다.
   *봐야 할 것:* 마커는 트랙 위의 레인과 패널 목록에 표시되며, 입력한 이름과 함께 표시됩니다.

## 팁

- 시간 범위를 선택하면 같은 버튼이 단일 지점이 아닌 명명된 영역을 추가합니다.
- **파일 → 다른 내보내기 → 라벨 내보내기**는 오디오와 다른 편집기에서 읽을 수 있는 텍스트 파일로 마커를 작성합니다.
