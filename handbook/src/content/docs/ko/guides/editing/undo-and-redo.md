모든 편집 및 효과는 프로젝트의 히스토리에 기록되므로 시도하는 것은 위험하지 않습니다. **Undo**는 한 번에 한 가지 변경 사항씩 되돌립니다. 효과, 잘라내기, 이동 등이고 **Redo**는 그것을 다시 되돌립니다. 히스토리는 프로젝트를 저장하고 다시 열어도 유지됩니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **Edit → Undo 및 Edit → Redo (Ctrl+Z, Ctrl+Y)**입니다. 아래의 이름은 Soundscaper의 자체 이름이며 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **File → Import audio**를 선택하고 어떤 녹음이든 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. 도구 모음에서 **Split 도구** 버튼을 누릅니다.
4. 클립의 웨이브폼 어디든 클릭하여 커서를 그곳에 놓습니다. 스플릿은 연습하기 좋은 편집입니다. 왜냐하면 볼 수 있기 때문입니다.
5. 도구 모음에서 **Split 도구** 버튼을 다시 누릅니다. 정상 포인터로 돌아갑니다.
6. 프로젝트에는 이제 2개의 클립이 표시됩니다.
7. 도구 모음에서 **Undo** 버튼을 누릅니다. 도구 모음 버튼과 **Edit → Undo**는 같은 작업을 수행합니다.
8. 프로젝트에는 이제 1개의 클립이 표시됩니다.
   *봐야 할 것:* 스플릿이 사라지고 클립이 다시 전체가 됩니다.
9. 도구 모음에서 **Redo** 버튼을 누릅니다.
10. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *봐야 할 것:* 스플릿이 다시 나타납니다.

## 팁

- **View → Panels → History**는 모든 단계를 나열하고 하나를 클릭하면 바로 그 단계로 점프합니다.
- **Undo**는 프로젝트에 대한 편집을 처리하지만 내보내기는 처리하지 않습니다. 이미 저장한 파일은 그대로 유지됩니다.
