시간 내에서 선택을 역전시킵니다. 이는 사운드 디자인 효과 — 역전된 심벌즈, 부풀어 오르는 프리 에코 — 와 가끔은 방의 리버브 테일 안에 숨겨진 무언가를 확인하기 위해 사용됩니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 특수 → 역전**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 역전시킬 녹음을 선택합니다. 이는 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → 특수 → 역전**을 선택합니다. 효과는 선택 영역에 즉시 적용됩니다.
5. **재생**을 눌러 들어본 후 **중지**합니다.
   *봐야 할 것:* 녹음이 거꾸로 재생됩니다.

## 팁

- 역전을 두 번 적용하면 샘플 단위로 시작점으로 돌아갑니다.
- 클립의 시작 부분에서 짧은 선택 영역을 역전시켜 그 뒤로 이어지는 스웰을 만듭니다.

## 이 가이드에 대해

이 페이지의 절차 — 모든 메뉴 항목, 대화상자, 필드 및 버튼, 그리고 그것이 생성하는 결과 — 는 브라우저 스위트(`tests/browser/soundscaper-guides.spec.js`)에 의해 Soundscaper의 각 빌드에 대해 재생됩니다. 만약 그것이 편집기와 더 이상 일치하지 않는다면, 가이드가 수정될 때까지 빌드는 실패합니다. 제안된 값은 편집기가 증명된 시작 지점이며, 그것이 녹음에 적합한지는 귀의 판단에 달려 있습니다.
