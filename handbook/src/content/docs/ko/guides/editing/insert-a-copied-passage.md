## 이 가이드의 목적 {#what-this-guide-is-for}

Insert는 기존 오디오 위에 붙여넣는 대신 복사한 오디오가 들어갈 공간을 만듭니다. 대상 트랙에서 뒤에 있는 오디오는 복사한 구간의 길이만큼 오른쪽으로 이동합니다. 녹음 중간에 반복 구절이나 문장을 추가할 때 사용하세요.

:::note[Audacity에서 오셨나요?]
Audacity의 **Edit → Copy, then Edit → Paste**에 해당합니다. 아래 이름은 Soundscaper에서 사용하는 명칭이며 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 복사할 구간이 있는 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 추가됩니다.
3. 클립 위쪽 눈금자를 드래그해 다른 곳에 삽입할 구간을 선택합니다.
4. **편집 → 복사**를 선택합니다.
5. 대상 클립에서 복사본이 시작될 파형을 클릭해 커서를 놓습니다. 클릭하면 시간 범위 선택이 해제되고 삽입 위치가 설정됩니다.
6. **편집 → 붙여넣기 → 삽입**를 선택합니다.
7. 이제 프로젝트에 클립 3개가 표시됩니다.
   *확인할 내용:* 삽입한 구간이 원래 클립의 두 부분 사이에 놓입니다. 뒤쪽 부분은 오른쪽으로 이동하고 앞쪽 부분은 원래 위치를 유지합니다.

## 팁

- Insert는 대상 트랙의 이후 오디오를 이동합니다. 여러 트랙의 타이밍을 유지해야 한다면 **편집 → 붙여넣기 → 삽입 및 동기화 유지**을 사용해 모든 트랙에 공간을 만드세요.
- **편집 → 되돌리기**를 선택하면 삽입이 취소되고 이후 오디오가 원래 위치로 돌아갑니다.
