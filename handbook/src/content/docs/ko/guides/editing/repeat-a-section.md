두 마디 루프, 더 긴 보이스 오버 아래 실행해야 하는 백그라운드 침대, 지속되어야 하는 사운드 효과: Repeat는 요청한 만큼 선택을 그대로 복제합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 특별 → 반복**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 반복하고 싶은 소리를 선택하세요. 파일은 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택하세요.
4. **효과 → 특별 → 반복**을 선택하세요. **반복** 대화 상자에서 **반복 횟수**를 `2`로 설정하고 **선택에 적용**을 누르세요. 두 번의 반복은 세 개의 연속된 복사본을 만듭니다.
5. **재생**을 눌러 들어보세요. 그런 다음 **중지**를 누르세요.
   *보여야 할 것:* 통과가 세 번 재생되며 간격이 없습니다.

## 팁

- 매끄러운 루프를 위해 선택이 시작되고 끝나는 곳이 무음이나 제로 크로싱인지 확인하세요 (**선택 → 제로 크로싱에서**).
- 효과는 클립의 길이를 변경하므로 같은 트랙에 있는 그 이후의 모든 것이 밀립니다.
