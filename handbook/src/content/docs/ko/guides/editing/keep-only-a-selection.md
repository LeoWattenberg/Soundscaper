## 이 가이드의 목적 {#what-this-guide-is-for}

긴 녹음에 좋은 테이크가 하나 있을 때, 주변을 조각조각 삭제하는 것보다 테이크를 선택하고 나머지를 버리는 것이 더 빠릅니다. 자르기는 선택한 부분을 유지하고 그 양쪽의 오디오를 제거합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **편집 → 특별 제거 → 오디오 자르기**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 테이크가 포함된 녹음을 선택하세요. 그것은 자체 트랙에 클립으로 놓입니다.
3. 통치자 위에서 클립을 드래그하여 유지하고 싶은 구절을 선택하세요. 그 외의 모든 것이 곧 사라집니다.
4. **편집 → 특별 제거 → 선택 범위 밖의 오디오 자르기**를 선택하세요.
5. 프로젝트에는 이제 1개의 클립이 표시됩니다.
   *봐야 할 것:* 선택한 구절만 트랙에 남아 있습니다.

## 팁

- 자른 클립은 타임라인에서 원래 위치에 그대로 있습니다. 원하는 경우 시작부터 시작하도록 드래그하세요.
- 자르기는 다른 편집과 동일합니다. **편집 → 되돌리기**는 선택 범위 밖의 것을 복원합니다.
