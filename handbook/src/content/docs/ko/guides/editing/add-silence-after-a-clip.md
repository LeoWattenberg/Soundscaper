에코 및 리버브와 같은 효과는 울려 퍼질 공간이 필요하며, 팟캐스트에는 세그먼트 사이의 숨 쉴 틈이 필요합니다. Silence 생성기는 커서 위치에 정확히 입력한 길이의 간격을 삽입하여, 눈으로 클립을 끌어 당기는 것보다 더 정확합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **Generate → Silence**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **File → Import audio**를 선택하고 간격이 필요한 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. 클립 끝의 웨이브폼을 클릭하여 커서를 그곳에 배치합니다. 침묵은 커서 위치에 삽입됩니다.
4. **Generate → Silence**를 선택하세요. **Silence** 대화 상자에서 **Duration (초)**를 `1`로 설정하고 **Generate**를 누릅니다.
5. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *다음과 같이 보여야 합니다:* 1초의 무음 클립이 루프 후에 따라옵니다.

## 팁

- 시간 범위를 선택하면 생성기는 커서 대신 선택 영역을 대체합니다.
- 이미 있는 오디오를 침묵으로 만들고 시간을 추가하는 것이 아니라면, [녹음의 일부를 침묵으로 만들기](/guides/cleaning-up/silence-part-of-a-recording/)를 참조하세요.
