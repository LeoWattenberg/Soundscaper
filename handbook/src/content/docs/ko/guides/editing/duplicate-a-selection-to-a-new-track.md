중복 기능은 선택한 부분을 시간상 동일한 위치에 새로운 트랙 아래에 직접 복사합니다. 이는 평행 처리의 일반적인 첫 번째 단계입니다. 예를 들어, 압축된 복사본을 원본 아래에 믹싱하거나, 리버브 전용 트랙, 두 배로 겹친 보컬 등을 만들 수 있습니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **편집 → 중복 (Ctrl+D)** 기능입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 중복할 구절이 있는 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 표시됩니다.
3. 클립 위쪽의 눈금자를 드래그하여 중복할 구절을 선택합니다.
4. **편집 → 중복**을 선택합니다.
5. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *다음과 같은 화면을 봐야 합니다:* 첫 번째 트랙 아래에 새로운 트랙에 선택한 부분만 포함된 두 번째 클립이 시간상으로 정렬되어 있습니다.

## 팁

- 두 트랙 중 하나를 음소거하여 다른 트랙을 단독으로 들으면서 조정합니다.
- 혼합이 만족스러우면 [트랙을 혼합](/guides/tracks-and-export/mix-tracks-into-one/)합니다.
