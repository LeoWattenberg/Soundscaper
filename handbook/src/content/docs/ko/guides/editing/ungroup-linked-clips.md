## 이 가이드의 목적 {#what-this-guide-is-for}

그룹 클립은 서로 다른 오디오 조각인 상태로 함께 선택하고 이동할 수 있습니다. Ungroup은 각 클립을 독립적으로 선택할 수 있게 되돌리며, 조각을 합치거나 하나의 클립으로 렌더링하지 않습니다.

:::note[Audacity에서 오신가요?]
Audacity에서 이에 해당하는 기능은 **Edit → Clip → Ungroup Clips**입니다. 아래 이름은 Soundscaper의 이름이며 때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트를 바로 사용할 수 있습니다.
2. **파일 → 파일 가져오기**를 선택하고 분리할 클립이 있는 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
3. 클립을 두 조각으로 나눌 위치의 파형을 클릭해 커서를 놓습니다.
4. **편집 → 오디오 클립 → 분할**을 선택합니다.
5. 첫 번째 조각의 이름 표시줄을 클릭하고 Shift를 누른 채 두 번째 조각의 이름 표시줄을 클릭해 둘 다 선택합니다.
6. **편집 → 오디오 클립 → 클립 그룹화**를 선택합니다. 그룹화하면 오디오를 합치지 않고 선택한 두 조각을 함께 이동할 수 있습니다.
7. **편집 → 오디오 클립 → 클립 그룹 해제**를 선택합니다. 그룹 해제하면 두 조각이 각각 선택 가능한 클립으로 돌아옵니다.
8. 이제 프로젝트에 클립 2개가 표시됩니다.
   *확인할 결과:* 녹음은 분할 지점에서 맞닿은 두 개의 별도 클립으로 남습니다.

## 팁

- 별도 클립을 이동할 때 상대적 타이밍을 유지해야 한다면 그룹화가 유용합니다.
- 인접한 조각을 하나의 클립으로 만들려면 **편집 → 오디오 클립 → 선택한 클립 연결**를 선택하세요.
