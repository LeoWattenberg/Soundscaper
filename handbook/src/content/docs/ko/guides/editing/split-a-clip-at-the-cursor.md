분할은 아무것도 제거하지 않습니다. 하나의 클립을 두 개로 나누어 끝에서 끝까지 놓이게 하므로, 한 부분을 다른 곳으로 드래그하거나 삭제하거나 혼자 효과를 적용할 수 있습니다. 가장 빠른 방법은 분할 도구입니다: 활성화되면, 클립을 클릭할 때마다 그 지점에서 잘라냅니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **편집 → 클립 경계 → 분할 (Ctrl+I)**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 분할하고 싶은 녹음을 선택합니다. 이는 자체 트랙에 클립으로 놓입니다.
3. 도구 모음에서 **분할 도구** 버튼을 누릅니다. 포인터가 이제 선택 대신 자릅니다. 키보드에서 **S**를 눌러 도구를 토글합니다.
4. 웨이브폼에서 잘라내고 싶은 지점을 클릭하여 커서를 그곳에 배치합니다. 분할 도구가 활성화되면 클릭이 클립을 여기서 자릅니다.
5. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *보여야 할 것:* 두 개의 클립이 하나였던 곳에 이제 나란히 놓여 있습니다.
6. 도구 모음에서 **분할 도구** 버튼을 누릅니다. 다시 누르면 일반 포인터로 돌아갑니다.

## 팁

- 재생 헤드 대신 분할하려면, 클립을 선택하고 **편집 → 오디오 클립 → 분할**을 선택하십시오; 시간 범위를 선택하면 범위의 양쪽 끝에서 모두 분할됩니다.
- 두 부분을 모두 선택하고 **편집 → 오디오 클립 → 선택한 클립 연결**을 선택하여 다시 하나의 클립으로 만듭니다.
