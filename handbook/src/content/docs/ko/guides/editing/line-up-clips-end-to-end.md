## 이 가이드의 목적 {#what-this-guide-is-for}

분리된 두 개의 테이크를 각자의 트랙에 기록합니다. 둘을 연속적으로 재생하려면 두 번째 테이크를 첫 번째 테이크의 끝으로 이동해야 합니다. **끝에서 정렬**은 선택된 모든 클립에 대해 트랙 순서로 해당 계산을 수행합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **트랙 → 트랙 정렬 → 끝에서 정렬**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 첫 번째 테이크를 선택합니다. 이는 자체 트랙에 클립으로 착륙합니다.
3. **파일 → 가져오기**를 선택하고 두 번째 테이크를 선택합니다. 이는 자체 트랙에 클립으로 착륙합니다.
4. 첫 번째 클립의 이름 막대를 클릭한 다음 Shift 키를 누르고 두 번째 클립의 이름 막대를 클릭하여 둘 다 선택합니다.
5. **트랙 → 콘텐츠 정렬 → 끝에서 정렬**을 선택합니다.
6. 두 번째 클립은 이제 첫 번째 클립이 끝나는 곳에서 시작합니다.
   *다음과 같은 것을 봐야 합니다:* 클립은 겹치지 않고 간격 없이 연속적으로 재생됩니다.

## 팁

- **함께 정렬**은 반대 작업을 수행합니다: 선택된 클립을 동일한 시간에 시작하도록 이동합니다.
- 클립의 이름 막대를 드래그하여 수동으로 배치할 수 있습니다. Shift 키를 누르면 트랙의 모든 클립이 함께 이동합니다.
