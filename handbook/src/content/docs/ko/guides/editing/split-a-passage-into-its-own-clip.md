## 이 가이드의 목적 {#what-this-guide-is-for}

단어나 음악 구절, 다시 녹음한 부분을 녹음 길이를 바꾸지 않고 별도의 클립으로 만들 수 있습니다. 시간 범위를 선택하고 Split을 실행하면 선택 영역의 양쪽 경계에서 잘립니다. 그런 다음 가운데 부분을 따로 이동하거나 처리할 수 있습니다.

:::note[Audacity에서 오셨나요?]
Audacity의 **Edit → Clip → Split (Ctrl+I)**에 해당합니다. 아래 이름은 Soundscaper에서 사용하는 명칭이며 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 해당 구간이 포함된 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 추가됩니다.
3. 클립 위쪽 눈금자를 드래그해 분리할 구간을 선택합니다. 양쪽 경계가 클립 안에 오도록 선택 영역 앞뒤에 오디오를 남겨 둡니다.
4. **편집 → 오디오 클립 → 분할**을 선택합니다.
5. 이제 프로젝트에 클립 3개가 표시됩니다.
   *확인할 내용:* 선택한 구간이 앞뒤 오디오 사이의 별도 클립이 됩니다. 세 부분 모두 타임라인의 원래 위치를 유지합니다.

## 팁

- 한 곳만 자르려면 범위를 선택하는 대신 [커서 위치에서 분할](/guides/editing/split-a-clip-at-the-cursor/)을 사용하세요.
- 경계를 다시 조정해야 할 때 **편집 → 되돌리기**를 선택하면 원래 클립으로 복원됩니다.
- 주변 오디오를 제거하려면 [원하는 부분만 남기기](/guides/editing/keep-only-a-selection/)를 사용하세요.
