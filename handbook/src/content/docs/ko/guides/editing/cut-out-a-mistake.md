가장 일반적인 편집은 다음과 같습니다: 잘못된 시작, 기침, 재촬영. 원하지 않는 부분을 선택하고 제거한 다음 나머지 트랙을 왼쪽으로 밀어 간격을 닫습니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **영역을 선택한 다음 편집 → 삭제 (또는 Ctrl+K)**입니다. 아래의 이름은 Soundscaper의 고유한 이름이며 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 실수가 포함된 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. 클립 위쪽의 눈금자를 드래그하여 정확히 제거하고 싶은 부분을 선택합니다. 실수가 짧다면 **보기 → 확대 → 확대**로 줌 인하세요.
4. **편집 → 잘라내기 → 트랙당 간격을 닫고 잘라내기**를 선택합니다. 선택한 부분이 제거되고 그 이후의 모든 것이 왼쪽으로 이동하므로 뒤에는 침묵이 남지 않습니다.
5. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *봐야 할 것: 선택했던 부분이 끝에서 끝으로 두 개의 클립이 연결되어 있고 트랙은 정확히 그만큼 짧아집니다. 연결 부위를 재생하여 확인하세요.

## 팁

- **잘라내고 간격 남기기**는 소리를 제거하지만 시간은 유지합니다. 이는 트랙이 비디오 또는 다른 트랙이와 동기화해야 할 때 올바른 선택입니다.
- 연결이 마음에 들지 않나요? **편집 → 되돌리기**, 선택을 조정하고 다시 시도하세요.
