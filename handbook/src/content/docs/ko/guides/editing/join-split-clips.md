## 이 가이드의 목적 {#what-this-guide-is-for}

Join은 같은 녹음에서 서로 맞닿은 조각을 합쳐 다시 하나의 클립처럼 이동하거나 편집할 수 있게 합니다. 원본 구간이 일치해야 하며 연결 지점에 페이드가 없어야 합니다. 이 단계에서는 녹음을 분할하기 전에 자동 페이드를 끄고, 렌더링 없이 조각을 다시 연결합니다.

:::note[Audacity에서 오셨나요?]
Audacity의 **Edit → Clip → Join selected clips (Ctrl+J)**에 해당합니다. 아래 이름은 Soundscaper에서 사용하는 이름이며 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **편집 → 환경설정**를 선택하고 **편집** 탭을 열어 **새 클립에 2 ms 페이드 적용**를 끈 다음 **닫기**를 누릅니다. 분할 지점의 자동 페이드 때문에 Join을 사용할 수 없게 됩니다.
3. **파일 → 파일 가져오기**를 선택하고 분할한 뒤 다시 연결할 녹음을 고릅니다. 녹음은 별도 트랙의 클립으로 들어옵니다.
4. 녹음을 분할할 파형 위치를 클릭해 커서를 놓습니다.
5. **편집 → 오디오 클립 → 분할**을 선택합니다.
6. 프로젝트에 클립 2개가 표시됩니다.
   *다음과 같이 표시됩니다:* 두 조각이 분할 지점에서 맞닿아 있습니다.
7. **Tab**을 눌러 첫 번째 조각에 초점을 맞추고 **Enter**를 눌러 선택합니다. 다음으로 두 번째 조각에 초점을 맞추고 **Shift+Enter**를 눌러 선택에 추가합니다. 연결하려면 두 조각을 모두 선택해야 합니다.
8. **편집 → 오디오 클립 → 선택한 클립 연결**를 선택합니다.
9. 프로젝트에 클립 1개가 표시됩니다.
   *다음과 같이 표시됩니다:* 하나의 클립이 분할 전 녹음과 동일한 시간을 차지합니다.

## 팁

- 이 설정은 이후 분할에 적용됩니다. 평소 이 설정을 사용한다면 작업 후 **새 클립에 2 ms 페이드 적용**를 다시 켜세요.
- 기존 조각에서 Join을 사용할 수 없다면 간격, 내부 페이드, 서로 다른 원본 자료가 있는지 확인하세요. 설정을 꺼도 클립에 이미 적용된 페이드는 제거되지 않습니다.
- **편집 → 되돌리기**를 선택하면 조각이 분리된 상태로 돌아가 각각 계속 편집할 수 있습니다.
