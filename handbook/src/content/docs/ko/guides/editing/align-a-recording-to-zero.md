## 이 가이드의 목적 {#what-this-guide-is-for}

타임라인에서 늦게 시작하는 녹음은 정렬 명령으로 프로젝트 시작으로 되돌릴 수 있습니다. Align start to zero는 선택한 트랙의 콘텐츠를 이동해 가장 이른 클립이 0에서 시작하게 합니다. 이 절차에서는 녹음을 먼저 뒤쪽으로 옮긴 다음 시작점에 다시 맞춥니다.

:::note[Audacity에서 오셨나요?]
Audacity의 **트랙 → 콘텐츠 정렬 → 시작을 0으로 정렬**에 해당합니다. 아래 이름은 Soundscaper에서 사용하는 이름이며 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 정렬할 녹음을 고릅니다. 녹음은 별도 트랙의 클립으로 들어옵니다.
3. 클립의 이름 표시줄을 잡고 타임라인의 뒤쪽으로 끕니다.
4. 이제 클립이 프로젝트 시작보다 늦게 시작합니다.
5. **트랙 → 콘텐츠 정렬 → 시작을 0으로 정렬**를 선택합니다.
6. 이제 녹음이 시간 0에서 시작합니다.
   *다음과 같이 표시됩니다:* 클립의 왼쪽 가장자리가 눈금자의 시작점에 맞춰집니다.

## 팁

- 정렬은 선택한 트랙의 콘텐츠를 이동합니다. 이 녹음만 따로 옮기려면 이 녹음만 들어 있는 트랙을 사용하세요.
- **편집 → 되돌리기**를 선택하면 이전 위치로 돌아갑니다.
