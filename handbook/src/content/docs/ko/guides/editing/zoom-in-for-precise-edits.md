기본 줌에서는 전체 노래가 화면에 맞고 단어는 몇 픽셀 너비입니다. 줌 인을 사용하면 커서를 박자나 두 단어 사이의 간격에 정확하게 놓을 수 있습니다. 선택 범위 줌은 작업 중인 구절만 표시합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **보기 → 줌 (Ctrl+1, Ctrl+2, Ctrl+3)**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 편집하려는 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **보기 → 줌 → 줌 인**을 선택합니다. 각 단계는 초의 너비를 두 배로 늘립니다. Ctrl+1은 동일한 작업을 수행합니다.
4. **보기 → 줌 → 줌 인**을 선택합니다.
5. 클립 위쪽의 눈금자를 드래그하여 작업하려는 구절을 선택합니다.
6. **보기 → 줌 → 선택 범위 줌**을 선택합니다. 선택 항목이 현재 타임라인을 채웁니다.
7. **보기 → 줌 → 기본 줌**을 선택합니다. Ctrl+2는 기본 줌을 다시 설정합니다.

## 팁

- Ctrl과 마우스 휠은 포인터 주변을 줌하여 가장 빠른 방법으로 특정 위치로 이동합니다.
- 줌은 프로젝트에 아무런 변경 사항을 적용하지 않습니다. 이는 단지 귀하의 뷰일 뿐입니다.
