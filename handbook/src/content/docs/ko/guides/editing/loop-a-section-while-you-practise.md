리프를 배우거나, 편집 지점을 확인하거나, 효과 설정을 테스트할 때, 반복해서 재생하지 않고도 더 빠르게 작업할 수 있습니다. 선택한 영역을 루프 영역으로 설정하면 루프를 해제할 때까지 재생이 해당 영역 내에서만 이루어집니다.

:::note[Audacity에서 넘어오셨나요?]
이 기능은 Audacity의 **Transport → Looping → Set Loop to Selection**과 동일합니다. 아래의 이름들은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **File → Import**를 선택하고 연습할 구절이 있는 녹음을 선택합니다. 이 녹음은 자체 트랙에 클립으로 추가됩니다.
3. 클립 위쪽의 눈금자에서 드래그하여 반복할 구절을 선택합니다.
4. **Select → Loop region → Set loop to selection**을 선택합니다.
5. 프로젝트에서 **Loop selection** 버튼이 켜집니다.
   *확인해야 할 사항:* 전송 바의 루프 버튼이 켜지고 눈금자 위에 루프 영역이 표시됩니다.
6. **Play**를 눌러 들어보고 **Stop**을 눌러 멈춥니다.
   *확인해야 할 사항:* 재생이 선택한 구절을 반복합니다.

## 팁

- **L**을 누르거나 전송 바의 루프 버튼을 클릭하여 루프를 켜고 끕니다. 루프 영역은 그대로 유지됩니다.
- 눈금자에서 루프 영역의 끝을 드래그하여 조정합니다.
