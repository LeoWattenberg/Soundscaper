프로젝트 라이브러리는 한 컴퓨터의 한 브라우저에 저장됩니다. 다른 기계, 동료, 백업 드라이브 등 다른 곳으로 프로젝트를 가져가려면 프로젝트 파일로 내보내야 합니다. `.sscape` 파일에는 오디오와 모든 편집이 포함되어 있으며, 모든 Soundscaper에서 열 수 있습니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **파일 → 프로젝트 저장 → 백업 프로젝트, 그 다음 파일 → 열기**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 프로젝트 자료를 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. **파일 → 프로젝트 파일 내보내기 (.sscape)**를 선택합니다. 전체 프로젝트는 하나의 `.sscape` 파일로 다운로드됩니다. 파일을 안전한 곳에 보관하십시오; 이 파일이 완전한 프로젝트입니다.
4. **파일 → Scape 프로젝트 파일 열기 (.sscape)**를 선택하고 파일을 선택합니다. 이 컴퓨터에 프로젝트가 아직 없으면 직접 열립니다; 여기서 라이브러리에 이미 프로젝트가 있는 경우, Soundscaper는 **읽기 전용 사본으로 열기**를 제공합니다. 누르십시오.
   *보여야 할 것:* 프로젝트는 내보낸 것과 정확히 동일한 트랙과 클립으로 열립니다.

## 팁

- 읽기 전용 사본은 파일 메뉴에서 프로젝트로 저장할 때까지 편집할 수 없습니다.
- 이 파일은 오디오가 내장된 ZIP 아카이브입니다; 수동으로 압축을 풀지 마십시오.
