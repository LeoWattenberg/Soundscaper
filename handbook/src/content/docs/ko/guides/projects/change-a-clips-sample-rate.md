44.1 kHz로 녹음된 클립은 48 kHz 프로젝트에서도 정상적으로 재생됩니다. Soundscaper는 실시간으로 변환하지만, 특정 비율로 전달해야 하거나 효과를 적용하기 전에 클립 자체를 변환할 수 있습니다. 리샘플링은 새로운 비율에 맞게 모든 샘플을 재계산하고 타이밍을 정확하게 유지합니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **트랙 → 리샘플링**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 잘못된 비율의 클립을 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. 클립의 메뉴를 열려면 **클립 메뉴** 버튼을 클릭하고 **클립 속성**을 선택합니다. **리샘플링**을 누르고 비율을 `44100`로 설정하고 다시 **리샘플링**을 누릅니다. 클립의 속성에는 현재 비율이 표시됩니다. 44100 Hz는 CD 표준입니다.
4. **재생**을 눌러 듣고 **중지**를 누릅니다.
   *보여야 할 것:* 클립은 이전과 정확히 동일하게 들립니다. 저장된 비율만 변경되었습니다.

## 팁

- 리샘플링은 편집이며 취소할 수 있습니다.
- 비율을 낮추면 가장 높은 주파수가 제거되고, 비율을 높이면 아무것도 추가되지 않지만 무해합니다.
