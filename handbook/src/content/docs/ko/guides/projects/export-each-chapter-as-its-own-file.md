강연은 주제별 파일 하나가 되어야 하고, 앨범 측면은 트랙으로 잘라야 하며, 오디오북은 파일 하나당 장이 하나여야 합니다. 각 부분의 시작에 마커를 넣고 한 번에 내보내세요. 각 마커는 다음 마커까지 이어지는 장을 열고, 각 장은 마커 이름으로 명명된 자체 파일로 작성되어 단일 아카이브 내부에 저장됩니다. Audacity 3에서는 **파일 → 내보내기 오디오 → 여러 개 내보내기**로 이를 수행했으며, Audacity 4에서는 이 기능을 복원하지 않았습니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **파일 → 내보내기 오디오 → 여러 개 내보내기, 레이블로 분할 (Audacity 3; Audacity 4에는 여러 개 내보내기가 없음)**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 분할할 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 표시됩니다.
3. **보기 → 마커 표시**를 선택합니다. 마커 레인은 장 시작을 표시하고 명명하는 곳입니다.
4. 도구 모음에서 **프로젝트 시작으로 이동** 버튼을 누릅니다. 첫 번째 장은 매우 처음에 시작되어야 하므로 첫 번째 마커는 0에 갑니다.
5. 마커 패널을 열고 (**보기 → 패널 → 마커**에서 표시), **재생 헤드에 마커 추가**를 누릅니다. 새 마커에 Enter를 누르고 `Part one`를 입력한 다음 다시 Enter를 눌러 이름을 지정합니다.
6. 두 번째 부분이 시작되는 웨이브폼을 클릭하여 커서를 해당 위치로 이동합니다.
7. 마커 패널을 열고 (**보기 → 패널 → 마커**에서 표시), **재생 헤드에 마커 추가**를 누릅니다. 새 마커에 Enter를 누르고 `Part two`를 입력한 다음 다시 Enter를 눌러 이름을 지정합니다.
8. **파일 → 오디오 내보내기**를 선택하고, **형식**을 **MP3**로, **출력**을 **장 (마커로 분할)**로 설정하고 **내보내기**를 누릅니다. 렌더링이 완료되면 파일이 즉시 다운로드되며, 대화상자에서 링크가 유지됩니다. 각 장은 아카이브 내부의 MP3가 되며, 순서대로 번호가 매겨지고 마커 이름으로 명명됩니다.

## 팁

- 명명된 영역은 자체 범위만 내보내므로, 부분 사이에 간격이 있는 경우 지역 대신 마커를 사용하세요.
- 레이블 트랙의 레이블도 동일한 방식으로 분할됩니다: **장 (레이블로 분할)**을 선택하여 마커 대신 레이블로 자르세요.
- 마커가 아닌 트랙별로 분할하려면 [각 트랙을 별도의 파일로 내보내기](/guides/projects/export-each-track-as-its-own-file/)를 참조하세요.
