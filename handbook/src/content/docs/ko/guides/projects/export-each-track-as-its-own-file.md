믹싱 엔지니어, 비디오 편집자 또는 다른 프로그램의 협업자는 믹스가 아닌 부분이 필요합니다. 스테밍 내보내기는 각 트랙을 별도의 파일로 렌더링하고, 프로젝트 시작에 맞춰 길이를 맞추고, 하나의 아카이브에 담아 제공합니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **파일 → 오디오 내보내기 → 트랙별로 분할하여 여러 개 내보내기**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 첫 번째 트랙을 선택합니다. 이는 자체 트랙에 클립으로 배치됩니다.
3. **파일 → 가져오기**를 선택하고 두 번째 트랙을 선택합니다. 이는 자체 트랙에 클립으로 배치됩니다.
4. **파일 → 오디오 내보내기**를 선택하고, **형식**을 **WAV**로 설정하고, **출력**을 **개별 스테밍 (트랙별로 분할)**로 설정하고, **내보내기**를 누릅니다. 렌더링이 완료되면 파일이 즉시 다운로드되며, 대화상자에서 링크가 유지됩니다. 각 트랙은 ZIP 파일 내의 WAV로 변환되며, 다른 곳에서 가져올 때 맞추기 위해 동일한 길이로 잘립니다.

## 팁

- 뮤트 및 솔로 기능은 스테밍에 영향을 주지 않습니다. 모든 트랙이 렌더링됩니다.
- 내보내기 전에 트랙을 이름 지정하십시오. 스테밍 파일은 그 이름을 트랙에서 가져옵니다.
