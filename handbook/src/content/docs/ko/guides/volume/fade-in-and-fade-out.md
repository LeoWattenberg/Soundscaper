페이드는 클립 시작 부분의 클릭을 피하거나 끝 부분의 갑작스러운 정지를 피하는 가장 간단한 방법입니다. 페이드 인(Fade In)은 선택 영역을 전체 길이에 걸쳐서 침묵에서 점차 증가시킵니다. 페이드 아웃(Fade Out)은 선택 영역을 점차 감소시킵니다. 선택 영역의 길이는 페이드의 길이와 같습니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 페이드 → 페이드 인 및 페이드 아웃**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 시작 또는 종료가 너무 강한 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. 클립 위쪽의 눈금자를 드래그하여 페이드를 지속시키고자 하는 시작 부분의 원하는 만큼을 선택합니다.
4. **효과 → 페이드 → 페이드 인**을 선택합니다. 효과는 선택 영역에 즉시 적용됩니다.
5. 클립 위쪽의 눈금자를 드래그하여 끝부분에서 동일한 양을 선택합니다.
6. **효과 → 페이드 → 페이드 아웃**을 선택합니다. 효과는 선택 영역에 즉시 적용됩니다.
7. **재생**을 눌러서 들어본 후 **정지**합니다.
  *보여야 할 것:* 녹음이 부드럽게 시작되고 사라지는 대신에 갑자기 시작하거나 멈추지 않습니다.

## 팁

- 페이드는 선형입니다. 끝부분에서 더 빠른 페이드를 원한다면 더 짧은 범위를 선택하세요.
- 페이드는 편집이므로 **편집 → 되돌리기**는 다른 어떤 것과 마찬가지로 페이드를 되돌립니다.

## 이 가이드에 대해

이 페이지의 절차 — 모든 메뉴 항목, 대화 상자, 필드 및 버튼, 그리고 그것이 생성하는 결과 —는 브라우저 스위트(`tests/browser/soundscaper-guides.spec.js`)에 의해 Soundscaper의 각 빌드에 대해 재생됩니다. 만약 그것이 편집기와 더 이상 일치하지 않는다면, 가이드가 수정될 때까지 빌드는 실패합니다. 제안된 값은 편집기가 증명된 시작 지점이며, 그것이 귀하의 녹음에 적합한지는 귀의 판단에 달려 있습니다.
