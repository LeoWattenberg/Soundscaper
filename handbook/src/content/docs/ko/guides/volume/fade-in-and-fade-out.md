페이드는 클립 시작 부분의 클릭이나 끝 부분의 갑작스러운 중지를 피하는 가장 간단한 방법입니다. 페이드 인(Fade In)은 선택 영역을 전체 길이에 걸쳐서 침묵에서 점차 증가시키고, 페이드 아웃(Fade Out)은 점차 감소시킵니다. 선택 영역의 길이는 페이드의 길이와 동일합니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **효과 → 페이드 → 페이드 인 및 페이드 아웃**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 시작이나 끝이 너무 갑작스러운 녹음을 선택합니다. 이는 자체 트랙에 클립으로 배치됩니다.
3. 클립 위쪽의 눈금자를 드래그하여 페이드가 지속되기를 원하는 시작 부분의 원하는 만큼을 선택합니다.
4. **효과 → 페이드 → 페이드 인**을 선택합니다. 효과는 선택 영역에 즉시 적용됩니다.
5. 클립 위쪽의 눈금자를 드래그하여 끝부분에서 동일한 양을 선택합니다.
6. **효과 → 페이드 → 페이드 아웃**을 선택합니다. 효과는 선택 영역에 즉시 적용됩니다.
7. **재생**을 눌러서 들어본 후 **중지**합니다.
  *보여질 것:* 녹음이 부드럽게 시작되고 사라지는 대신에 갑자기 시작하거나 멈추지 않습니다.

## 팁

- 페이드는 선형입니다. 끝부분에서 더 빠른 페이드를 원한다면 더 짧은 범위를 선택하세요.
- 페이드는 편집이므로 **편집 → 되돌리기**는 다른 항목과 마찬가지로 페이드를 되돌립니다.
