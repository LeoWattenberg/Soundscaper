## 이 가이드의 목적 {#what-this-guide-is-for}

트랙을 위나 아래로 옮기면 프로젝트에서 세로 위치만 바뀌고 클립의 시작 시간은 바뀌지 않습니다. Move track to top은 음성이나 중요한 파트를 나머지보다 위에 표시할 때 유용합니다.

:::note[Audacity에서 오신가요?]
Audacity에서 이에 해당하는 기능은 **Track menu → Move track → Move track to top**입니다. 아래 이름은 Soundscaper의 이름이며 때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트를 바로 사용할 수 있습니다.
2. **파일 → 파일 가져오기**를 선택하고 아래쪽에 남길 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
3. **파일 → 파일 가져오기**를 선택하고 맨 위로 옮길 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
4. 헤더의 **트랙 옵션** 버튼으로 맨 위에 둘 트랙의 메뉴를 열고 **트랙 이동 → 트랙을 위로 이동**을 선택합니다. 이 명령은 클립 타이밍을 유지하면서 트랙의 세로 순서를 바꿉니다.
5. 이제 프로젝트에 클립 2개가 표시됩니다.
   *확인할 결과:* 선택한 트랙이 다른 트랙 위에 표시되고 두 클립은 타임라인 위치를 유지합니다.

## 팁

- 순서를 되돌리려면 트랙 메뉴에서 **트랙 이동 → 트랙을 아래로 이동**을 사용하세요.
- 트랙 순서는 프로젝트에서 어떤 오디오가 위에 보이는지만 바꿉니다. 믹스나 패닝은 변경하지 않습니다.
