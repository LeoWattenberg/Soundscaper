## 이 가이드의 목적 {#what-this-guide-is-for}

Ogg Vorbis는 일부 오디오 정보를 버려 더 작은 청취용 사본을 만듭니다. 받는 플레이어나 서비스가 지원하는 경우 이 형식으로 믹스를 내보내세요.

:::note[Audacity에서 오신가요?]
Audacity 3의 **File → Export Audio → Ogg Vorbis**에 해당합니다. 아래 이름은 Soundscaper 자체 명칭이라 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 공유할 녹음이나 믹스를 고릅니다. 오디오는 전용 트랙의 클립으로 표시됩니다.
3. **파일 → 오디오 내보내기**를 선택하고 **형식**을 **Ogg Vorbis**로 설정한 다음 **내보내기 시작**를 누릅니다. 렌더링이 끝나면 파일이 다운로드되고 링크는 대화상자에 남습니다.
   *확인할 결과:* 내보내기 대화상자에 다운로드할 수 있는 Ogg 파일이 표시됩니다.

- Quality는 파일 크기와 인코딩 품질 사이의 균형을 조정합니다.
