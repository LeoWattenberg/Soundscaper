## 이 가이드의 목적 {#what-this-guide-is-for}

FLAC은 선택한 내보내기 정밀도에서 샘플을 버리지 않고 PCM 오디오를 압축합니다. 프로젝트에는 편집 가능한 트랙을 남기고 더 작은 청취용 마스터를 만들 때 유용합니다.

:::note[Audacity에서 오신가요?]
Audacity 3의 **File → Export Audio → FLAC**에 해당합니다. 아래 이름은 Soundscaper 자체 명칭이라 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 전달할 녹음이나 믹스를 고릅니다. 오디오는 전용 트랙의 클립으로 표시됩니다.
3. **파일 → 오디오 내보내기**를 선택하고 **형식**을 **FLAC**으로 설정한 다음 **내보내기 시작**를 누릅니다. 렌더링이 끝나면 파일이 다운로드되고 링크는 대화상자에 남습니다.
   *확인할 결과:* 내보내기 대화상자에 다운로드할 수 있는 FLAC 파일이 표시됩니다.

## 팁

- Compression level은 인코딩 작업량과 파일 크기를 바꾸며 디코딩된 오디오 품질은 바꾸지 않습니다.
- 믹스 내보내기 파일에는 개별 트랙이나 실행 취소 기록이 들어 있지 않습니다. 나중에 편집하려면 [프로젝트를 저장하세요](/guides/projects/save-your-project/).
