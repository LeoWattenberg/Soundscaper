## 이 가이드의 목적 {#what-this-guide-is-for}

테이크가 여러 개인 프로젝트는 관련 트랙 이름이 함께 모이면 탐색하기 쉽습니다. Sort by name은 타임라인에서 클립이 시작하는 위치는 바꾸지 않고 트랙을 알파벳순으로 재배치합니다.

:::note[Audacity에서 오신가요?]
Audacity에서 이에 해당하는 기능은 **Tracks → Sort Tracks → Sort by Name**입니다. 아래 이름은 Soundscaper의 이름이며 때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트를 바로 사용할 수 있습니다.
2. **파일 → 파일 가져오기**를 선택하고 이름순으로 다른 녹음 뒤에 와야 할 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
3. **파일 → 파일 가져오기**를 선택하고 이름순으로 앞에 와야 할 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
4. **트랙 → 트랙 정렬 → 이름별로 정렬**을 선택합니다. 트랙 이름이 알파벳순으로 정렬됩니다.
5. 이제 프로젝트에 클립 2개가 표시됩니다.
   *확인할 결과:* 두 녹음은 프로젝트에 남고 트랙 이름은 알파벳순으로 표시됩니다.

## 팁

- 정렬은 트랙 순서만 바꾸며 클립 타이밍이나 오디오 콘텐츠는 변경하지 않습니다.
- 트랙 순서를 클립 시작 시간에 맞추려면 **트랙 → 트랙 정렬 → 시간별로 정렬**을 사용하세요.
