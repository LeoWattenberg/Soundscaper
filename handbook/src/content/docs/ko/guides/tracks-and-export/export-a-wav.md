WAV는 편집기가 가진 샘플을 정확히 그대로 유지합니다. 마스터링, 비디오 편집자나 다른 DAW에 오디오 전달, 다시 처리하고 싶은 모든 경우에 사용하세요.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **파일 → 오디오 내보내기 → WAV**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 전달할 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **파일 → 오디오 내보내기**를 선택하고, **형식**을 **WAV**로 설정하고, **내보내기**를 누릅니다. 렌더링이 완료되면 파일이 다운로드되며, 대화상자에서 링크가 유지됩니다.

## 팁

- WAV 파일은 큽니다: CD 품질의 스테레오로 분당 약 10메가바이트입니다.
- 각 트랙을 개별 파일로 내보내려면 내보내기 대화상자에서 **모드**를 개별 줄기로 설정하세요.
