## 이 가이드의 목적 {#what-this-guide-is-for}

Swap stereo channels는 스테레오 트랙의 왼쪽과 오른쪽 오디오를 맞바꿉니다. 마이크나 레코더 연결이 반대였을 때 녹음의 시간 정렬을 유지하며 고칠 수 있습니다.

:::note[Audacity에서 오신가요?]
Audacity 3의 **Audio Track Dropdown Menu → Swap Stereo Channels**에 해당합니다. 아래 이름은 Soundscaper 자체 명칭이라 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 채널이 뒤바뀐 스테레오 녹음을 고릅니다. 녹음은 전용 트랙의 클립으로 표시됩니다.
3. 트랙 헤더의 **트랙 옵션** 버튼으로 메뉴를 열고 **트랙 채널 → 스テレ로 채널 바꾸기**를 선택합니다.
4. 프로젝트에 클립 1개와 트랙 2개가 표시됩니다.
   *확인할 결과:* 하나의 스테레오 클립으로 제자리에 유지되면서 채널이 서로 바뀝니다.

## 팁

- 이 명령은 채널의 콘텐츠를 맞바꿉니다. 패닝은 들리는 위치만 바꾸며 채널을 바꾸지는 않습니다.
- **편집 → 되돌리기**로 원래 채널 순서를 복원할 수 있습니다.
