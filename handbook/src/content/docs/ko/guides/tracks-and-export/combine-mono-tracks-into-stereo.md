## 이 가이드의 목적 {#what-this-guide-is-for}

Make stereo track은 모노 트랙 두 개를 하나의 스테레오 클립으로 렌더링하고 원본 트랙을 대체합니다. 메뉴를 연 트랙이 왼쪽 채널이 되고, 그 아래에 있는 첫 번째 호환 모노 트랙이 오른쪽 채널이 됩니다. 아래에 해당 트랙이 없으면 Soundscaper가 프로젝트의 다른 위치에서 첫 번째 호환 모노 트랙을 사용합니다. 결합하기 전에 오른쪽 채널로 쓸 트랙을 왼쪽 채널 트랙 바로 아래에 배치하세요.

:::note[Audacity에서 오신가요?]
Audacity의 **Upper mono track menu → Make stereo track (Audacity 4)**에 해당합니다. 아래 이름은 Soundscaper에서 사용하는 명칭이며 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 왼쪽 채널로 사용할 모노 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 추가됩니다.
3. **파일 → 파일 가져오기**를 선택하고 오른쪽 채널로 사용할 모노 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 추가되며 첫 번째 녹음 아래 트랙에 나타납니다. 재생할 시점에 맞춰 클립을 배치합니다.
4. 트랙 헤더의 **트랙 옵션** 버튼으로 왼쪽 채널 녹음의 메뉴를 열고 **트랙 채널 → 스털링 트랙 생성**을 선택합니다.
5. 이제 프로젝트에 클립 1개와 트랙 2개가 표시됩니다.
   *확인할 내용:* 모노 녹음 두 개가 하나의 스테레오 클립으로 대체되고, 각 채널에 의도한 소리가 들어 있습니다.

## 팁

- 새 클립은 프로젝트 샘플 레이트에서 두 트랙의 콘텐츠를 모두 포함합니다. 각 트랙의 빈 부분은 해당 채널에서 무음이 됩니다.
- 두 녹음의 시작을 맞춰야 한다면 결합하기 전에 [트랙 시작 위치를 정렬](/guides/editing/align-track-starts-together/)하세요.
- 나중에 별도 클립을 편집해야 한다면 프로젝트 사본을 보관하세요. **편집 → 되돌리기**를 선택하면 모노 트랙 두 개로 돌아갑니다.
