스테레오 녹음은 두 개의 채널을 가진 하나의 트랙입니다. 채널이 서로 다른 내용을 담고 있을 때 — 예를 들어, 왼쪽의 인터뷰어와 오른쪽의 게스트, 또는 두 채널 레코더에서 온 기타와 클릭 트랙 — 각 채널을 별도의 트랙으로 분리하여 개별적인 레벨과 이펙트를 적용하고 싶습니다.

:::note[Audacity에서 오신가요?]
이 기능은 Audacity의 **트랙 드롭다운 → 스테레오 트랙 분할**입니다. 아래의 이름은 Soundscaper의 고유한 이름이며, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 스테레오 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 가져옵니다.
3. 트랙 헤더의 **트랙 메뉴** 버튼에서 트랙 메뉴를 열고 **트랙 채널 → 스테레오를 left/right 모노로 분할**을 선택합니다. 각 채널은 자체 모노 트랙으로 분리되며, 하드 좌측과 하드 우측으로 팬되어 믹스가 여전히 동일하게 들립니다.
4. 프로젝트에는 이제 2개의 클립이 표시됩니다.
   *보여야 할 것:* 채널당 하나의 모노 클립, 측면 이름을 가진 두 개의 트랙.

## 팁

- 두 트랙을 모두 선택하고 트랙 메뉴에서 **트랙 채널 → 모노 트랙 결합**을 선택하여 다시 결합합니다.
- **스테레오를 중심 모노로 분할**은 채널이 동일한 소리를 담고 있을 때 동일한 작업을 수행하지만, 두 트랙을 중앙에 배치합니다.
