## 이 가이드의 목적 {#what-this-guide-is-for}

모스 부호는 메시지를 시간에 맞춘 점, 대시, 간격으로 바꿉니다. 생성기는 부호 미리보기를 보여주고 메시지와 속도에 따라 클립 길이를 계산합니다.

:::note[Audacity에서 오신가요?]
Audacity에는 **No directly matching built-in Morse code generator**가 없습니다. 아래 이름은 Soundscaper 자체 명칭이라 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **생성 → 모스 코드**를 선택합니다. **모스 코드** 대화상자에서 **메시지**를 `SOS`, **속도 (분당 단어 수)**를 `20`, **주파수(Hz)**를 `600`, **진폭**를 `0.2`로 설정한 뒤 **생성**를 누릅니다. 예시 메시지를 원하는 텍스트로 바꾸세요. 부호 미리보기를 확인합니다. 지원하지 않는 문자가 있으면 생성할 수 없습니다.
3. 프로젝트에 클립 1개가 표시됩니다.
   *확인할 결과:* 메시지를 담은 모스 부호 클립이 만들어지고 길이는 선택한 속도에 따라 달라집니다.

## 팁

- 속도를 낮추면 톤 주파수는 그대로이고 점, 대시, 간격이 길어집니다.
- Duration은 결과값이라 편집할 수 없습니다. 메시지나 속도를 바꿔 클립 길이를 조정하세요.
