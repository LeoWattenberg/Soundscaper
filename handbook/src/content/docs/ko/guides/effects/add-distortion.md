왜곡은 웨이브폼을 클립하거나 구부려서 고조파를 얻습니다. 약간의 소프트 오버드라이브는 베이스나 신디사이저를 따뜻하게 하고, 많은 양은 기타를 벽처럼 만듭니다. 유형은 곡선의 모양을 선택하고, 임계값은 신호 중 얼마나 많은 양이 곡선에 도달하는지 설정합니다.

:::note[Audacity에서 오셨나요?]
이것은 Audacity의 **효과 → 왜곡**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 왜곡할 사운드를 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → 왜곡 및 변조 → 왜곡**을 선택합니다. **왜곡** 대화 상자에서 **왜곡 유형**으로 **소프트 오버드라이브**를 선택하고 **임계값**을 `-12`로 설정하고 **선택 범위에 적용**을 누릅니다. 소프트 오버드라이브는 절단하는 대신 정점을 둥글게 만듭니다. 더 낮은 임계값은 더 많은 신호를 곡선에 전달합니다.
5. **재생**을 눌러서 들어보세요. 그런 다음 **중지**를 누릅니다.
   *보여야 할 것:* 사운드는 더 거칠고 정점은 둥글게 보입니다.

## 팁

- 결과가 웨이브폼의 중심에서 벗어나 있는 경우 **DC 차단**을 켭니다.
- 왜곡은 레벨을 추가합니다. 피크가 상단에 도달하면 정규화하세요.
