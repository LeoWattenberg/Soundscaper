## 이 가이드의 목적 {#what-this-guide-is-for}

Parametric EQ는 각 대역의 주파수, 게인, Q를 조절하므로 공명음을 집중적으로 줄이거나 존재감을 조금 높일 수 있습니다. 그래프에서 대역을 선택한 뒤 주파수와 Q를 조정해 변화의 위치와 폭을 정합니다.

:::note[Audacity에서 오신가요?]
Audacity의 **Spectral Edit Parametric EQ, a spectrogram-only feature with no equivalent to Soundscaper’s track-wide effect**와는 다릅니다. 아래 이름은 Soundscaper 자체 명칭이라 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 파일 가져오기**를 선택하고 음색을 조정할 녹음을 고릅니다. 녹음은 전용 트랙의 클립으로 표시됩니다.
3. **선택 → 모두 선택**을 선택합니다.
4. **이펙트 → 이퀄라이저 및 필터 → 파라메트릭 EQ**를 선택합니다. **파라메트릭 EQ** 대화상자에서 **주파수(Hz)**를 `500`, **게인 (dB)**을 `-3`, **Q**를 `1.2`로 설정한 뒤 **선택에 적용**을 누릅니다. 선택한 대역이 500 Hz 부근을 좁고 약하게 줄입니다.
5. **재생**를 눌러 듣고 **정지**을 누릅니다.
   *확인할 결과:* 다른 대역은 그대로 두고 500 Hz 부근을 집중적으로 줄입니다.

## 팁

- 대역이 좁을수록 **Q**가 높습니다. 게인을 조금만 바꾸고 문제가 남을 때만 더 조정하세요.
- Soundscaper의 전체 트랙용 Parametric EQ는 Audacity의 스펙트로그램 전용 Spectral Edit Parametric EQ와 다릅니다.
