Audacity의 Nyquist 플러그인은 효과, 생성기 및 분석기를 추가하는 작은 스크립트이며, Soundscaper는 각 메뉴 아래의 Nyquist 서브 메뉴에 동일한 것을 번들링합니다. 트레몰로(Tremolo)는 좋은 첫 번째 예시입니다. 이는 일정 속도로 볼륨을 흔들어 줍니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 트레몰로(Nyquist 플러그인)**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 플러그인을 시도해 볼 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → Nyquist → 트레몰로**를 선택합니다. **트레몰로** 대화 상자에서 **주파수(Hz)**를 `6`로 설정하고 **적용**을 누릅니다. 초당 여섯 번의 흔들림은 고전적인 앰프 트레몰로입니다. Nyquist 대화 상자는 **선택에 적용**이 아닌 **적용**을 사용합니다.
5. **재생**을 눌러 들어본 후 **중지**합니다.
   *보여야 할 것:* 녹음이 볼륨으로 펄스칩니다.

## 팁

- 생성 및 분석 메뉴에는 플럭(Pluck)과 비트 파인더(Beat Finder)와 같은 Nyquist 서브 메뉴가 있습니다.
- **도구 → Nyquist 프롬프트**는 직접 입력한 스크립트를 실행합니다.
