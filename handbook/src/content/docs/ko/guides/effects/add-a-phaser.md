페이저는 소리를 이동 올패스 단계를 통과한 자기 복사본과 혼합하여, 노치가 느린 진동자와 함께 스펙트럼을 위아래로 쓸어내립니다. 기타, 일렉트릭 피아노 또는 패드에서 수많은 레코드에서 들을 수 있는 소용돌이 소리를 냅니다. Audacity 3에는 페이저가 내장되어 있었지만 Audacity 4에는 없으므로, 여기서 사용하기에 적합합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **효과 → 페이저 (Audacity 3; Audacity 4에는 페이저가 없습니다)**입니다. 아래의 이름은 Soundscaper의 자체 이름이며, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 처리할 소리를 선택합니다. 파일은 자체 트랙에 클립으로 놓입니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **효과 → 왜곡 및 변조 → 페이저**를 선택합니다. **페이저** 대화 상자에서 **단계**를 `4`로 설정하고 **LFO 주파수**를 `0.6`로 설정 한 다음 **선택 영역에 적용**을 누릅니다. 단계가 많을수록 더 깊은 노치가 만들어지며, 4단계는 클래식 페달입니다. LFO 주파수는 스윕이 얼마나 빠르게 움직이는지를 나타냅니다. 0.6 Hz는 느리고 음악적인 소용돌이를 만듭니다.
5. **재생**을 눌러 들어본 후 **중지**를 누릅니다.
   *보여야 할 것:* 소리가 천천히 소용돌이 치며 노치가 소리를 통과합니다.

## 팁

- **피드백**은 노치를 더 날카롭게 만들어 더 금속적이고 공명하는 스윕을 만듭니다. 미묘한 효과를 위해 0에 가깝게 유지하십시오.
- 페이저는 또한 트랙의 랙에서 실시간 효과로 실행되므로 조정하는 동안 스윕을 들을 수 있습니다: [트랙에 실시간 효과 추가](/guides/effects/add-a-realtime-effect-to-a-track/).

- [Nyquist 플러그인 사용](/guides/effects/use-a-nyquist-plugin/) — 번들된 Nyquist 효과 중 하나를 실행합니다. 여기서는 트레몰로입니다.

- [한 템포에서 다른 템포로 슬라이드하기](/guides/effects/slide-from-one-tempo-to-another/) — 녹음의 속도를 점차적으로 높이거나 낮추면서 피치를 함께 이동시킵니다.
