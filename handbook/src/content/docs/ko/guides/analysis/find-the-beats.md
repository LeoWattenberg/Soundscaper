비트 파인더는 번들된 Nyquist 분석기 중 하나입니다. 갑작스러운 레벨 상승이 임계값을 초과하는지 청취하고 각 상승 위치에 레이블을 작성하여 루프의 비트를 표시하거나 드럼 연주를 잘라내기 전에 히트를 표시하는 빠른 방법을 제공합니다.

:::note[Audacity에서 오신가요?]
이것은 Audacity의 **분석 → 비트 파인더**입니다. 아래의 이름은 Soundscaper의 고유한 이름으로, 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 오디오 가져오기**를 선택하고 표시하려는 녹음을 선택합니다. 파일은 자체 트랙에 클립으로 배치됩니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **분석 → Nyquist → 비트 파인더**를 선택합니다. **비트 파인더** 대화 상자에서 **임계값 백분율**을 `60`로 설정하고 **적용**을 누릅니다. 대화 상자는 찾은 내용을 보고하며, **닫기**를 눌러 대화 상자를 닫습니다. 백분율이 낮을수록 조용한 비트도 찾을 수 있으며, 너무 많이 표시되면 높여야 합니다.
5. 프로젝트에 **비트 파인더**라는 트랙을 표시합니다.
   *보여야 할 것:* 오디오 아래에 새로운 레이블 트랙인 비트 파인더가 각 비트에 하나씩 레이블을 가지고 있습니다.

## 팁

- 레이블은 오디오 아래에 새로운 레이블 트랙에 배치됩니다. 분석기가 잘못한 레이블은 다시 명명하거나 삭제하세요.
- **분석 → Nyquist → 사운드 레이블**은 전체 사운드를 구분하는 유사한 작업을 수행합니다.
