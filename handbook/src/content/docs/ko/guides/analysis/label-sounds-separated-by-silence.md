## 이 가이드의 목적 {#what-this-guide-is-for}

Label Sounds는 무음으로 분리된 소리를 구간에서 찾아 감지한 각 소리 주변에 레이블을 배치합니다. 나중에 편집할 수 있도록 말소리 구절, 단발성 타격음 또는 기타 뚜렷한 이벤트를 표시할 수 있습니다.

:::note[Audacity에서 오신가요?]
Audacity에서 이에 해당하는 기능은 **Analyze → Label Sounds (Nyquist)**입니다. 아래 이름은 Soundscaper의 이름이며 때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트를 바로 사용할 수 있습니다.
2. **파일 → 파일 가져오기**를 선택하고 소리 사이에 무음이 있는 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 나타납니다.
3. **선택 → 모두 선택**을 선택합니다.
4. **분석 → Nyquist → Label Sounds**를 선택합니다. **Label Sounds** 대화상자에서 **Threshold level (dB)**을 `-30`, **Minimum silence duration**을 `0.5`, **Minimum label interval**을 `0.5`로 설정한 다음 **적용**를 누릅니다. 대화상자에 결과가 표시됩니다. **닫기**를 눌러 닫습니다. 0.5초의 무음은 분석기가 구절을 분리하도록 합니다. 임계값은 소리로 인식할 최소 크기를 정합니다.
5. 이제 프로젝트에 **Label Sounds**라는 이름의 트랙이 표시됩니다.
   *확인할 결과:* 감지된 구절 주변에 레이블이 있는 Label Sounds 트랙이 나타납니다.

## 팁

- **Threshold level (dB)**을 낮추면 더 작은 소리도 포함하고, 높이면 배경 노이즈를 무시합니다.
- 짧은 무음으로 한 구절이 여러 레이블로 나뉘면 **Minimum silence duration**을 높이세요.
