입력이 너무 높게 녹음되면 파형이 범위의 위쪽에 납작하게 붙어 왜곡됩니다. 긴 녹음에서는 손상된 소리는 쉽게 들리지만 눈으로 찾기는 어렵습니다. Find Clipping은 선택 영역을 검사하여 풀 스케일에 있는 모든 샘플 구간을 나열하므로, 각각을 복구할지 다시 녹음할지 그대로 둘지 판단할 수 있습니다.

:::note[Audacity에서 오셨나요?]
Audacity의 **분석 → 클리핑 찾기**에 해당합니다. 아래 이름은 Soundscaper 고유의 이름이라 때때로 다릅니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 확인할 녹음을 고릅니다. 녹음은 자체 트랙의 클립으로 들어옵니다.
3. **선택 → 전체 선택**을 선택합니다.
4. **분석 → 클리핑 찾기**를 선택합니다. **클리핑 찾기** 패널이 열립니다.
   *확인할 사항:* 클리핑된 구간 목록 또는 찾은 구간이 없다는 안내가 표시됩니다.

## 팁

- 클리핑된 녹음의 볼륨을 낮춰도 복구되지는 않습니다. 납작해진 피크는 그대로입니다. **효과 → 노이즈 제거 및 복구 → 복구**를 사용하면 아주 짧은 클리핑 구간을 재구성할 수 있습니다.
- 다음에는 클리핑을 피하도록 피크를 약 −12 dB 정도로 녹음한 뒤 나중에 레벨을 높이세요.
