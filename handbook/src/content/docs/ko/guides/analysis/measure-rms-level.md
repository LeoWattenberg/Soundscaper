## 이 가이드의 목적 {#what-this-guide-is-for}

RMS는 시간에 따른 신호 레벨의 평균 측정값입니다. Measure RMS 분석기를 사용해 구간을 비교하거나 조정 전에 특정 부분의 레벨을 확인하세요.

:::note[Audacity에서 오신가요?]
Audacity에서 이에 해당하는 기능은 **Analyze → Measure RMS (Nyquist)**입니다. 아래 이름은 Soundscaper의 이름이며 때로 다를 수 있습니다.
:::

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새 빈 프로젝트를 바로 사용할 수 있습니다.
2. **파일 → 파일 가져오기**를 선택하고 평균 레벨을 측정할 구간을 고릅니다. 해당 구간은 자체 트랙의 클립으로 나타납니다.
3. **선택 → 모두 선택**을 선택합니다.
4. **분석 → Nyquist → Measure RMS**를 선택합니다. **Measure RMS** 대화상자에서 **적용**를 누릅니다. 대화상자에 측정 결과가 표시됩니다. **닫기**를 눌러 닫습니다.
   *확인할 결과:* 보고서에 각 채널과 스테레오 신호의 RMS 레벨이 dB 단위로 표시됩니다.

## 팁

- RMS는 평균 레벨을 나타냅니다. 가장 높은 샘플을 목표값에 맞춰야 한다면 [peak normalization](/guides/volume/normalize-peaks/)을 사용하세요.
- 비교할 부분만 선택해 관련 없는 오디오가 측정에 영향을 주지 않도록 하세요.
