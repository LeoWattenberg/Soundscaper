## 이 카테고리의 가이드

- [믹스의 음량을 측정하기](/guides/analysis/measure-loudness/) — 방송국에서 하는 것처럼 선택 영역의 통합 음량, 음량 범위, 트루 피크를 확인합니다.
- [사운드가 포함하는 주파수 확인하기](/guides/analysis/plot-a-spectrum/) — 선택한 영역의 스펙트럼을 그려서 잡음, 윙윙거림 또는 공명을 찾습니다.
- [녹음에서 클리핑된 부분 찾기](/guides/analysis/find-clipping/) — 녹음이 최대 레벨에 도달하고 왜곡된 부분을 찾습니다.
- [루프에서 박자 찾기](/guides/analysis/find-the-beats/) — 비트 파인더 분석기가 들리는 모든 박자에 표시를 합니다.
- [말소리가 배경에서 얼마나 두드러지는지 확인하기](/guides/analysis/check-speech-contrast/) — 접근성 지침에 따라 목소리가 배경 소음보다 얼마나 높은지 측정합니다.
- [선택 영역의 RMS 레벨 측정](/guides/analysis/measure-rms-level/) — 내장 RMS 분석기로 선택한 구간의 평균 신호 레벨을 확인합니다.
- [무음으로 분리된 소리에 레이블 지정](/guides/analysis/label-sounds-separated-by-silence/) — 무음 뒤에 임계값을 넘는 소리 주변에 레이블을 만듭니다.
