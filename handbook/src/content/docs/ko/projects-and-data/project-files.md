## 로컬 프로젝트 라이브러리

편집기는 로컬 라이브러리에 작업 중인 프로젝트를 저장합니다. 브라우저에서는 원본 개인 정보 저장소이고 데스크톱 에디션에서는 애플리케이션 데이터입니다. 이는 편리한 작업 사본이며 보관해야 할 유일한 사본은 아닙니다.

## 스케프 프로젝트 파일

데스크톱에서 가져온 오디오와 비디오는 기본적으로 원본 파일을 참조합니다. 프로젝트를 다시 열 때 해당 파일을 원래 위치에 두세요. 로컬 라이브러리는 편집 캐시도 보관합니다. 녹음하거나 생성 또는 처리한 미디어는 변경되지 않은 외부 원본이 없으므로 프로젝트에 포함됩니다.

참조된 미디어를 프로젝트 파일에 포함하려면 **파일 → 프로젝트 관리 → 미디어 통합**을 선택하세요. 통합하면 프로젝트가 즉시 저장되므로 저장 대화상자에서 위치를 선택합니다. 저장한 통합 사본은 원본 미디어 파일 없이도 이동하거나 공유할 수 있습니다. 통합할 수 없는 미디어가 있거나 저장이 실패하면 편집기가 문제를 알립니다.

브라우저 내보내기는 미디어를 자동으로 포함합니다. 외부 참조가 있는 데스크톱 프로젝트를 브라우저에서 열기 전에 데스크톱에서 통합하세요.


편집 프로젝트를 저장하려면 **파일 → 프로젝트 파일 내보내기**를 사용하십시오. 각 제품은 자체 접미사를 작성합니다. Soundscaper는 `.sscape`를 저장하고 Framescaper는 `.fscape`를 저장하며 메뉴 항목 이름은 적용되는 해당 항목을 표시합니다. 두 형식 모두 동일하므로 혼합 미디어 편집 상태를 보존해야 하는 경우 적절한 선택입니다.

두 제품 모두 해당 접미사를 가진 파일을 열 수 있습니다. `.sscape`, `.fscape`, 예약된 `.liscape` 및 제품에 자체 접미사가 없었던 시기에 내보낸 오래된 `.scape` 파일은 모두 어디서나 열릴 수 있으며 다른 제품에서 저장하면 단순히 이름이 변경됩니다. 예를 들어 Framescaper에서 저장한 `Mix.sscape`는 `Mix.fscape`가 됩니다. 프로젝트 이름은 변경되지만 그 외에는 변경되는 것이 없습니다.

Scape 사본을 가져오거나 열면 로컬 라이브러리에 동일한 ID를 가진 기존 프로젝트가 있을 수 있습니다. 두 버전 모두 로컬 라이브러리에 남아야 하는 경우 제공된 사본 워크플로를 사용하십시오.

## Audacity AUP3 및 AUP4

Audacity 프로젝트 내보내기는 **파일 → 기타 내보내기**에서 사용할 수 있습니다. Audacity 3.7.9 프로젝트 프로필에는 **AUP3 내보내기**를, 현재 Audacity 교환 프로필에는 **AUP4 내보내기**를 선택하세요. 각 내보내기는 변환, 사용할 수 없는 효과, 생략된 Soundscaper 전용 상태를 설명하는 호환성 보고서를 만듭니다.

두 형식 모두 오디오 전용입니다. 비디오는 제외되며 브라우저 설정, 실행 취소 기록, 믹서 라우팅, 브라우저 프로젝트 라이브러리는 전송되지 않습니다. 어느 형식도 Soundscaper 또는 Framescaper 프로젝트의 유일한 백업으로 사용하지 마세요.

## Adobe Audition SESX

데스크톱 에디션에서 **파일 → 열기**를 사용해 Adobe Audition `.sesx` 세션을 가져오세요. 참조된 오디오 파일은 세션 폴더 아래의 상대 폴더 구조에 두거나 요청 시 미디어 폴더를 선택하세요. 가져오면 지원되는 오디오 트랙, 클립, 배치, 트림, 간단한 페이드, 정적 믹서 설정을 갖춘 새 로컬 프로젝트가 만들어집니다.

SESX 가져오기는 한 방향으로만 작동합니다. Audition 효과, 자동화, 라우팅, 비디오, 마커, 루프, 늘이기, 연결된 크로스페이드, 정확한 페이드 곡선은 전송되지 않습니다. 가져온 뒤 **파일 → 전달 보고서**를 열어 누락된 미디어와 그 밖에 제외된 콘텐츠를 확인하세요. Audition에서 계속 작업하려면 원본 SESX 파일과 미디어를 보관하세요.

## 렌더링된 백업

중요한 작업의 경우 다음 두 가지를 모두 유지하십시오.

1. 향후 편집을 위한 Scape 프로젝트 사본 (`.sscape` 또는 `.fscape`).
2. 편집기 없이 재생할 수 있는 렌더링된 오디오 또는 비디오 파일.

이러한 파일을 브라우저 또는 애플리케이션 데이터 디렉토리 외부에 저장하십시오.
