이 튜토리얼은 두 초짜 음악 루프를 사용하여 편집기의 전체 한 번 통과를 안내합니다: 파일을 가져오고, 그것을 듣고, 효과를 적용하여 변경하고, 두 개로 자르고, 어디서나 재생할 수 있는 파일을 렌더링하고, 프로젝트를 저장하여 나중에 다시 사용할 수 있도록 합니다. 이 튜토리얼에서는 오디오 지식 없이도 편집기의 기능을 살펴볼 수 있습니다.

:::tip[필요한 것]
- [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) 다운로드 — 두 초짜 스테레오 루프.

아래의 모든 단계는 이 파일 그대로 작동하므로, 튜토리얼에서 설명하는 것과 일치해야 합니다. Soundscaper는 브라우저에서 실행되므로 설치할 필요가 없습니다.
:::

## 배우게 될 내용

- 파일이 트랙 위의 클립이 되는 방법과 재생하는 방법.
- 클립을 자르는 분할 도구 사용법.
- 오디오를 선택하고 선택한 부분에 효과를 적용하는 방법.
- 파일을 내보내고 프로젝트를 저장하는 차이점.

## 단계

1. Soundscaper를 엽니다. 편집기가 로드되면 새로운 빈 프로젝트가 준비됩니다.
2. **파일 → 가져오기**를 선택하고 `guide-music-loop.wav` — 두 초짜 스테레오 루프를 선택합니다. 이 파일은 자체 트랙 위의 클립으로 추가됩니다.
3. **재생**을 눌러서 들어본 후 **중지**합니다.
   *보여야 할 것:* 플레이 헤드가 클립을 가로지르며 루프가 한 번 재생됩니다.
4. 도구 모음에서 **분할 도구** 버튼을 누릅니다. 분할 도구가 활성화되면 클릭은 클립을 자르며 선택하지 않습니다.
5. 웨이브폼의 중간 지점을 클릭하여 커서를 해당 위치로 이동합니다.
6. 도구 모음에서 **분할 도구** 버튼을 다시 누릅니다. 다시 한 번 누르면 일반 포인터로 돌아갑니다.
7. 프로젝트에는 이제 두 개의 클립이 표시됩니다.
   *보여야 할 것:* 두 개의 클립이 하나였던 자리에서 끝에서 끝까지 나란히 놓여 있고, 각 클립에는 자체 이름 표시줄이 있습니다.
8. **선택 → 모두 선택**을 선택합니다. 효과는 선택한 부분에 적용됩니다. 모두 선택은 프로젝트의 전체, 두 클립을 포함한 모든 부분을 선택합니다.
9. **효과 → 페이드 → 페이드 아웃**을 선택합니다. 효과가 선택한 부분에 즉시 적용됩니다.
   *보여야 할 것:* 웨이브폼은 두 번째 클립의 끝에서 사라집니다.
10. **재생**을 눌러서 들어본 후 **중지**합니다.
   *보여야 할 것:* 루프는 갑자기 멈추지 않고 서서히 사라집니다.
11. **파일 → 오디오 내보내기**를 선택하고, **형식**을 **WAV**로 설정한 후 **내보내기**를 누릅니다. 렌더링이 완료되면 파일이 다운로드되며, 대화상자에서 링크가 유지됩니다. 내보내기는 들리는 소리를 파일로 렌더링하여 다른 프로그램에서 사용할 수 있도록 합니다. 프로젝트를 변경하지는 않습니다.
12. **파일 → 프로젝트 저장**을 선택합니다. 상태 표시줄의 저장 표시기가 프로젝트가 저장되었음을 보여줍니다. 프로젝트(클립, 편집, 기록)는 이 컴퓨터의 브라우저 프로젝트 라이브러리에 저장됩니다. 저장은 프로젝트를 그곳에 유지합니다.
