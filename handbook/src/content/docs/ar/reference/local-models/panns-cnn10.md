## الغرض وحالة الاستخدام {#purpose-and-use-case}

اقترح فئات الأحداث السمعية للفهارس وعلامات التفاعل.

## التوفر الحالي {#current-availability}

يمكن لإصدارات سطح المكتب تنزيل محرك onnxruntime-node 1.29.0 المطلوب والتحقق منه لمنصات macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. ثبّت هذا النموذج وبيئة التشغيل المطلوبة عبر مدير النماذج، ثم شغّل مهمته محليًا. هذه أهداف بناء مدعومة؛ راجع تقرير الاختبارات الليلية لنتائج حزمة وجهاز محددين.

## استخدم هذا النموذج {#use-this-model}

افتح **الأدوات → المعالجة المحلية المتقدمة → الوسم السمعي** على منصة تحتوي على بيئة التشغيل الأصلية المطلوبة. تعمل المساعدة المحلية في محرر سطح المكتب.

1. حدد الصوت الذي تريد تحليله.
2. قم بتثبيت PANNs من خلال مدير النماذج، ثم قم بتشغيل الوسم السمعي.
3. راجع التسميات المقترحة ونطاقاتها الزمنية قبل قبول العلامات أو استخدامها للبحث.

## التنزيل والمتطلبات {#download-and-requirements}

هوية النموذج: `panns-cnn10`، الإصدار **1.0.0**.

حجم تنزيل ملف النموذج التقريبي: **24.05 MiB**. تُضاف بيئة التشغيل المطلوبة إلى التنزيل الأول إن لم تكن مثبّتة بالفعل. الحد الأدنى لذاكرة النظام: **2 GiB**. يشير هذا المتطلب في الفهرس إلى إجمالي الذاكرة لا إلى الذاكرة المتاحة حاليًا. يحتاج الاستدلال أيضًا إلى ذاكرة حرة كافية، ويتطلب التثبيت مساحة عمل؛ ولا يضمن مقدار الذاكرة السرعة.

المنصات المنشورة: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. ويلزم أيضًا تنزيل بيئة تشغيل مطابقة.

في Windows، ثبّت أحدث [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) مدعوم ومتوافق مع تطبيق سطح المكتب: **x64** لإصدار x64 أو **ARM64** لإصدار ARM64. تحتاج محركات ONNX وSherpa الأصلية إلى هذه المكتبات؛ ولا تتضمنها تنزيلات النموذج وبيئة التشغيل. لا يلزم Visual Studio لاستخدام التطبيق.

تنزيلات الأدوات ← مدير النماذج ملفات النموذج المنشورة وبيئة التشغيل المطلوبة عند التثبيت الأول، ثم تتحقق من ملخصات SHA-256 المسجلة. تستخدم المعالجة الملفات المثبتة محليًا. افتح التخزين والتحقق في مدير النماذج لمراجعة الإشعارات أو إصلاح التثبيت أو تغيير موقع التخزين.
