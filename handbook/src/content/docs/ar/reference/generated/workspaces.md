مساحة العمل هي ترتيب محفوظ للألواح وأشرطة الأدوات حول الخط الزمني. اختيار واحد يحل محل الترتيب الحالي؛ يمكنك بعد ذلك نقل أي شيء وحفظ مساحة عملك الخاصة، والتي لا يصفها هذه الصفحة.

## مساحات العمل المضمنة

| مساحة العمل | معرف الأمر | المنتجات |
| --- | --- | --- |
| كلاسيكي | `workspace-classic` | Soundscaper، Framescaper |
| موسيقى | `workspace-music` | Soundscaper، Framescaper |
| Soundscaper | `workspace-modern` | Soundscaper، Framescaper |
| Audacity | `workspace-audacity` | Soundscaper، Framescaper |
| محرر الفيديو | `workspace-video-editor` | Framescaper |
