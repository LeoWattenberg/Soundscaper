## الإنشاء وإضافة طبقة {#create-and-add-a-layer}

1. اختر **ملف → تركيب جديد** وأدخل عنوانًا وأبعادًا ومعدل إطارات ومدة
   بالإطارات.
2. اختر **طبقة → نص جديد** أو **طبقة → لون مصمت جديد**. اختر التركيب
   المستهدف عندما يحتوي المشروع على عدة تراكيب.
3. افتح **طبقة → النص والمظهر** لتحرير طبقة نص حالية أو تعبئة شكل وحدوده.
   يُحتفظ بالخطوط المستوردة هنا مع المشروع.

استخدم **ملف → استيراد وسائط** لمصادر الصور أو الفيديو أو الصوت. يُرفض
الاستيراد الذي يتجاوز حدود مفكّك الترميز أو الذاكرة الحالية مع توضيح السبب؛
ويبقى الملف المصدري الأصلي دون مساس.

## التحريك والمعاينة {#animate-and-preview}

افتح **طبقة → الخصائص والإطارات الرئيسية** لاختيار خاصية طبقة وإضافة
إطارات رئيسية عند مواضع إطارات دقيقة. تغيّر عناصر التحكم بالمنحنى الاستيفاء؛
ويغيّر التحرير المكاني مسارات الموضع. يفتح **عرض → المخطط الزمني** عناصر
التحكم بتوقيت الطبقات وترتيبها وتجميعها ومنطقة العمل.

افتح **عرض → لوحة التركيب** لتحديد طبقة ثنائية الأبعاد ثابتة وتحريكها.
يغيّر المربع حجمها وتديرها الدائرة حول نقطة ارتكازها المحددة. كل عملية سحب
مكتملة تمثل خطوة تراجع واحدة؛ ويلغي Escape السحب. تبقى التحويلات المتحركة
والمدفوعة بالتعبيرات في الخصائص والإطارات الرئيسية.

افتح **عرض → معاينة التركيب** للانتقال إلى موضع أو تشغيل التركيب. تستخدم
المعاينة الوسائط المصدرية المحتفظ بها. تنتج إعدادات المشهد غير المدعومة
أو غير الصالحة خطأً بدلًا من صورة بديلة. أغلق المعاينة لتحرير موارد التصيير
النشطة الخاصة بها.

## حفظ نسخة قابلة للنقل {#save-a-portable-copy}

اختر **ملف → حفظ** لنشر المراجعة الحالية، ثم **ملف → حفظ نسخة** لتنزيل
أرشيف `.mscape`. يتضمن الأرشيف المشروع والوسائط الأصلية اللازمة لإعادة
فتحه. افتحه باستخدام **ملف → فتح** على جهاز آخر أو من مكتبة متصفح جديدة.

## التصيير {#render}

اختر **ملف → تصيير**. حدد تركيبًا وتنسيق إخراج ونطاق إطارات. لا يُشمل
إطار النهاية: تستخدم الإطارات من 0 إلى 29 النطاق من `0` إلى `30`. تحدد
منطقة العمل الكسرية أزمنة العينات الصحيحة الواقعة داخلها؛ ويجب تغيير منطقة
لا تحتوي على عينات إخراج قبل التصيير.

استخدم **تسلسل PNG شفاف (.tar)** لألفا. استخرج أرشيف TAR للحصول على صور PNG
عادية وبيانات وصفية للتوقيت. يستخدم MP4 وWebM لون الخلفية المحدد في مربع
الحوار. يثبّت التصيير المراجعة المقدمة حتى لا تغيّر التعديلات اللاحقة
مخرجًا قيد التنفيذ. يستمر تشغيل المهمة عند إغلاق مربع حوار التصيير.
يعرض **ملف → قائمة التصيير** التقدم والإلغاء وإعادة محاولة المراجعة المقدمة
والتنزيلات المكتملة. يلغي إغلاق المحرر المهام غير المكتملة.
