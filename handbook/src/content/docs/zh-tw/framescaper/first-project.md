## 1. 匯入影片

選擇 **檔案 → 匯入** 並選擇一個支援的影片。匯入的影片及其提取的音訊會進入專案庫中，作為一個媒體項目，通常會放置在相鄰的連結軌上。

原始影片會儲存為專案媒體。海報和縮圖是可丟棄的預覽，可以重新生成。

## 2. 檢視來源和序列

使用來源監控器來檢查材料，然後放置或調整它。使用影片預覽來檢查組成的序列。

連結的圖像和音訊編輯會一起移動、分割、修剪和拉伸，除非您明確地取消連結它們。在每個編輯點播放影片，以驗證圖像和聲音。

## 3. 安排和完成

使用時間軸編輯命令進行一般修剪和移動。Framescaper 還會根據當前選擇的支援情況，暴露視訊效果、幾何、合成、嵌套序列和多相機命令。

儲存本地專案，然後繼續[視訊匯出](/framescaper/video-export/)。
