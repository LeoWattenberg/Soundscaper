兩版都本地處理專案。它們的儲存和檔案存取方式不同。

## 網路編輯器

瀏覽器版將專案、錄音和匯入的媒體儲存在原點私密瀏覽器儲存空間中。它不會將專案上傳到Soundscaper帳戶，且不需要帳戶。

當您想要立即存取而不必安裝應用程式時，請使用網路編輯器。請記住，瀏覽器儲存空間仍受瀏覽器配額和驅逐規則的限制。清除網站資料會刪除本地專案庫。

## 桌面預覽

封裝的桌面預覽在桌面應用程式中保留自動儲存的本機庫。它們包含編輯器運行時和離線編輯所需的已發行翻譯。

桌面封裝未簽名。macOS僅對其裝載機執行Electron和本機二進制文件所需的無身份廣告後封裝進行身份驗證；該封裝並不宣稱發行者或信任。因此，Windows SmartScreen或macOS Gatekeeper可以為預覽和穩定封裝顯示未知開發者的警告。

開啟`.aup4`檔案會將獨立專案匯入桌面庫。後續編輯不會重寫您打開的檔案。**儲存**更新庫副本；**另存新檔**會建立新的Audacity交換檔案。

## 手機和平板電腦

網路編輯器在所有螢幕上都保持桌面佈局，但在寬度小於900px（手機或垂直持有的平板電腦）時，它會將瀏覽器折疊到抽屜中，以便時間線保留空間：

- **選單**按鈕位於左上角，打開包含完整應用程式選單、專案標籤、操作列和工具列的抽屜。播放、停止、錄音和搜尋保持在列中。選擇命令會關閉抽屜。
- 軌道標題從時間線左上角的**軌道標題**手柄滑入軌道，或從**檢視 › 軌道標題**。點擊軌道或按下Esc會再次將它們收起。
- 位於編輯器上方的介紹在窄螢幕上已折疊；**顯示介紹**可將其恢復。

**編輯 › 偏好設定 › 外觀 › 佈局**可以在自動、緊湊和桌面之間切換，以便在桌面上小型視窗可以保留桌面瀏覽器，而在寬平板電腦上可以選擇使用抽屜。

## 專案不會自動移動

瀏覽器和桌面庫是分開的。故意移動專案：

- 使用Scape專案檔案 — `.sscape`來自Soundscaper，`.fscape`來自Framescaper — 用於完整專案。
- 使用AUP4時，您特別需要與Audacity的音訊交換。
- 匯出渲染的音訊或視訊作為耐用的播放副本。

在刪除瀏覽器網站資料或桌面應用程式資料之前，請參閱[專案檔案](/projects-and-data/project-files/)。
