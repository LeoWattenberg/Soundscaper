Motionscaper 是 Scaper 系列中的動態圖形編輯器。專案包含合成、圖層、
動畫及保留的媒體。其專案檔案副檔名為 `.mscape`。

這是開發版本。請從重要來源素材的複本開始，並在工作庫之外保留匯出的
專案封存檔。

## 開始建立合成 {#start-a-composition}

選取**檔案 → 新增合成**。**圖層**選單可開啟文字、形狀、動畫、合成處理、
追蹤、運算式和 3D 場景工具。**檢視 → 合成預覽**開啟播放視窗；新的編輯
界面會在您從選單中選取後出現。

選取**檢視 → 合成畫布**，即可使用靜態 2D 變換選取、移動、縮放或旋轉
圖層。動畫變換仍可透過屬性和時間軸工具編輯。

在**檢視 → 時間軸**中選取現有圖層，可重新命名、啟用、停用或移除圖層。
重新命名保留屬性參照和動畫。移除圖層會保留其原始媒體；請包含相依圖層，
或先解除其連結。**復原**會復原移除的圖層。所選影片素材圖層的保留來源
包含音訊時，還會提供音訊核取方塊。

按照[您的第一個動態圖形專案](/motionscaper/first-project/)中的步驟，
建立、製作動畫、儲存和算圖合成。

## 儲存與輸出 {#save-and-deliver}

**檔案 → 儲存**發佈已儲存修訂。**儲存複本**將目前快照匯出為 `.mscape`
封存檔，不發佈新的已儲存修訂。匯入的原始媒體和字型隨封存檔一同保留。
**專案庫**可開啟此裝置上保留的專案。

**檔案 → 算圖**提供 TAR 封存檔中的透明 PNG 影格、不透明 MP4 或 WebM 影片，
以及在桌面編碼器可用時提供的 ProRes 4444。PNG 序列不包含音訊。瀏覽器
影片在編碼器支援所請求格式時保留創作的音訊。桌面 ProRes 會在算圖
對話方塊中報告實際的色彩和 alpha 精度。**檔案 → 算圖佇列**會在關閉
對話方塊或切換專案後保留工作。最多保留八個工作和 128 MiB 的瀏覽器下載；
每次下載最多允許 64 MiB。更大的輸出請選取串流檔案目標，並移除已完成
的工作以釋放保留的下載。如果桌面輸出清理失敗，請在此佇列中使用
**重試輸出清理**。清理成功前，工作會一直保留目標；之後可以移除工作，
或使用新目標重試已提交的修訂。

## 連結到 Framescaper {#link-to-framescaper}

連結合成需要獨立的 Framescaper 1.1 開發分支。在其**檔案 → 連結合成**
對話方塊中建立配對 URL。將其貼上到 Motionscaper 的**檔案 → 將合成傳送到
Framescaper**對話方塊，連線並保持編輯器和橋接視窗開啟。後續**儲存**操作
會自動傳送新修訂；**儲存複本**不會傳送。

Framescaper 保留每個接受的修訂及其完整媒體相依，以供離線使用。復原會
鎖定先前的修訂，直到您繼續更新。輸出尺寸、時間設定或音訊網格的變更
需要明確進行適配檢閱。桌面接收端也可以改為監控您選取的已儲存
`.mscape` 檔案。

## 檢查桌面更新 {#check-desktop-updates}

在桌面應用程式中選取**說明 → 檢查更新**。此手動檢查會在專案的 GitHub
儲存庫中查找相容的 Motionscaper 發行版。預覽版本可以收到更新的預覽版；
穩定版本接收穩定版。選取**查看發行版**可開啟已驗證的發行版頁面。
此檢查不會下載或安裝更新。瀏覽器組建不包含此選單命令。

## 與 After Effects 交換 {#after-effects-exchange}

**檔案 → After Effects 橋接**提供可讀指令碼，並在匯入前檢閱受支援的交換
資料。`.aep` 和 `.aepx` 檔案透過已安裝的 After Effects 及橋接指令碼開啟。
此開發中的橋接功能尚未在已安裝的 After Effects 中通過驗證。請查看
報告；不受支援的場景意圖和原始媒體仍會保留在專案保管內容中。

對話方塊為受支援的純量不透明度運算式分別提供匯入和匯出選項，支援算術、
合成時間、運算式求值前的值和標準 Math 函式。兩個選項最初均關閉。
修改選項後請查看新報告；其他形式的運算式需要明確取樣或算圖。運算式的
原始程式碼保留在交換資料或 `original.mscape` 封存檔中。

算圖器支援 SDR 色彩和 alpha，以及 2.5D 圖層、攝影機、燈光、快門取樣
和景深。不聲稱支援 HDR、完整 3D 網格、進階 AI 遮色片或任意 After Effects
外掛程式的相容性。
