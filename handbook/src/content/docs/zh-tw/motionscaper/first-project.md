## 建立並新增圖層 {#create-and-add-a-layer}

1. 選取**檔案 → 新增合成**，輸入標題、尺寸、影格率和以影格為單位的持續時間。
2. 選取**圖層 → 新增文字**或**圖層 → 新增純色**。專案包含多個合成時，
   請選取目標合成。
3. 開啟**圖層 → 文字與外觀**，編輯現有文字圖層或形狀的填色與筆畫。
   此處匯入的字型會隨專案保留。

影像、影片或音訊來源請使用**檔案 → 匯入媒體**。超過目前解碼器或記憶體
限制的匯入會被拒絕並說明原因；原始來源檔案保持不變。

## 製作動畫與預覽 {#animate-and-preview}

開啟**圖層 → 屬性與關鍵影格**，選取圖層屬性並在精確影格位置新增關鍵影格。
曲線控制項改變插值；空間編輯改變位置路徑。**檢視 → 時間軸**開啟圖層
時間設定、排序、群組和工作區域控制項。

開啟**檢視 → 合成畫布**，選取和移動靜態 2D 圖層。方塊用於縮放，圓形
用於繞設定的錨點旋轉。每次完成的拖動是一條復原記錄；Escape 取消拖動。
動畫和運算式驅動的變換仍在屬性與關鍵影格中編輯。

開啟**檢視 → 合成預覽**，定位或播放合成。預覽使用保留的來源媒體。不受
支援或無效的場景設定會產生錯誤，而不會顯示替代影像。關閉預覽可釋放
其目前使用的算圖資源。

## 儲存便攜複本 {#save-a-portable-copy}

選取**檔案 → 儲存**發佈目前修訂，然後選取**檔案 → 儲存複本**下載
`.mscape` 封存檔。封存檔包含專案及重新開啟所需的原始媒體。可在其他裝置
或全新的瀏覽器庫中使用**檔案 → 開啟**開啟它。

## 算圖 {#render}

選取**檔案 → 算圖**。選取合成、輸出格式和影格範圍。結束影格不包含在內：
第 0 到 29 影格使用 `0` 到 `30` 的範圍。分數工作區域選取其中包含的整數
取樣時間；沒有輸出取樣的工作區域必須在算圖前修改。

需要 alpha 時，請使用**透明 PNG 序列 (.tar)**。解壓 TAR 封存檔，即可獲得
普通 PNG 影像和時間中繼資料。MP4 和 WebM 使用對話方塊中選取的背景色彩。
算圖會鎖定已提交修訂，因此後續編輯不會改變正在進行的輸出。關閉算圖
對話方塊後，工作繼續執行。**檔案 → 算圖佇列**顯示進度、取消、重試已提交
修訂和已完成的下載。關閉編輯器會取消未完成的工作。
