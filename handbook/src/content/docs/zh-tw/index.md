Soundscaper 和 Framescaper 是同一本地優先專案系統的兩種不同視角。
使用 Soundscaper 進行錄音和詳細的音效工作。使用 Framescaper 進行影片編輯和合成。

## 教學

教學是一個課程：它會帶你逐步完成手冊提供的範例錄音，並告訴你在過程中應該看到什麼。如果你從未使用過 Soundscaper，請從這裡開始。

- [你的第一個 Soundscaper 專案](/tutorials/your-first-project/) — 匯入錄音、聆聽、分割、淡出、匯出檔案並儲存專案。
- [清理語音錄音](/tutorials/clean-up-a-voice-recording/) — 消除錄音中的嗡嗡聲、低鳴聲，將其調整到播客音量並匯出 MP3 檔案。
- [將音樂置於語音之下](/tutorials/put-music-under-a-voice/) — 層疊兩條軌道，自動將一條軌道壓低，混合並匯出。

請見[所有教學](/tutorials/)。

## 操作指南

每個指南都專注於一個任務，並展示如何在 Soundscaper 中使用自己的錄音來完成它，包括確切的選單項目和對話方塊。指南按你想做的事情分類。

- [清理錄音](/guides/cleaning-up/) — 在處理錄音之前，消除噪音、點擊聲、低鳴聲和空白部分。
- [音量和動態](/guides/volume/) — 設定音量、平衡音量高低，並達到傳遞目標。
- [編輯](/guides/editing/) — 在時間軸上切割、分割、複製、移動和標記材料。
- [效果](/guides/effects/) — 改變聲音的特徵：音高、速度、空間、過濾器和失真。
- [軌道和匯出](/guides/tracks-and-export/) — 處理多個軌道，並將結果渲染到檔案中。
- [專案和檔案](/guides/projects/) — 儲存、移動並開啟專案，包括在 Audacity 中建立的專案。
- [分析](/guides/analysis/) — 測量音量、檢查頻率並找出錄音中的問題。

請見[所有操作指南](/guides/)。
