## 本指南的用途 {#what-this-guide-is-for}

Audacity 的 Nyquist 插件是用來新增效果、生成器和分析器的小型腳本。Soundscaper 將需要處理所選內容的內建腳本保留在 Nyquist 子選單中。可調式淡入淡出可塑造錄音的淡入或淡出。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → Adjustable Fade（Nyquist 插件）**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入**，並選擇要嘗試插件的錄音。它會以片段形式出現在自己的軌道上。
3. 選擇 **選擇 → 全選**。
4. 選擇 **效果 → Nyquist → Adjustable Fade**。在 **Adjustable Fade** 對話框中，將 **Mid-fade Adjust (%)** 設為 `25`，然後按 **應用**。正值會讓淡變曲線更圓滑。Nyquist 對話框使用 **應用** 而不是 **應用到選取**。
5. 按 **播放** 收聽，然後按 **停止**。
   *您應該會看到：* 錄音會淡入。

## 提示

- 生成和分析選單也有各自的 Nyquist 子選單，包含 Pluck 和 Beat Finder 等插件。
- **工具 → Nyquist 提示** 會執行您輸入的腳本。
- 延遲、高通與低通濾波器、噪音門、缺口濾波器、棚架濾波器、顫音和聲碼器在效果選單的相應分類中都有一般效果，並可在[即時效果架](/guides/effects/add-a-realtime-effect-to-a-track/)中運作。
