Audacity 的 Nyquist 插件是小型腳本，可添加效果、生成器和分析器。Soundscaper 將這些插件整合在每個選單下的 Nyquist 子選單中。Tremolo 是一個很好的開始：它以固定的速率變化音量。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → Tremolo（Nyquist 插件）**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，並選擇要嘗試插件的錄音。檔案會以剪貼形式放置在單獨的軌道上。
3. 選擇 **選擇 → 全選**。
4. 選擇 **效果 → Nyquist → Tremolo**。在 **Tremolo** 對話框中，將 **頻率 (Hz)** 設置為 `6`，然後按 **應用**。每秒六次振動是經典的放大器 Tremolo。Nyquist 對話框使用 **應用** 而不是 **應用到選取**。
5. 按 **播放** 收聽，然後按 **停止**。
   *您應該會看到：* 錄音的音量會脈動。

## 提示

- 生成和分析選單也有各自的 Nyquist 子選單，包含 Pluck 和 Beat Finder 等插件。
- **工具 → Nyquist 提示** 會執行您輸入的腳本。
