瓦音踏板會將共振過濾器在頻譜中上下掃描；瓦音效果會以您設定的速度為您進行掃描。它適合吉他、鍵盤和任何具有穩定延音的樂器。

:::note[來自Audacity？]
這是Audacity的**效果 → 瓦音**。以下名稱是Soundscaper自己的，有時會與之不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇要添加瓦音效果的錄音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 失真和調製 → 瓦音**。在**瓦音**對話框中，將**LFO頻率**設置為`2`，將**深度**設置為`80`，然後按下**套用至選取範圍**。LFO頻率是指每秒進行的掃描次數；深度是指過濾器移動的距離。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：* 錄音會以掃描、類似母音的聲音顫動。

## 提示

- **共振**會使過濾器的峰值變尖銳；高值會尖叫。
- 同一子選單中的**相位移**提供更柔和的旋轉運動。
