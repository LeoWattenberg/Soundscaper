## 本指南的用途 {#what-this-guide-is-for}

在處理過的房間中使用近距離麥克風會產生乾淨、親密的聲音，單獨聽起來可能顯得單調。混響會添加數千個微小的反射，就像一個小亭子或大廳一樣。

:::note[來自Audacity？]
這是Audacity的**效果 → 延遲和混響 → 混響**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入**，然後選擇聽起來太乾的錄音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 延遲和混響 → 混響**。在**混響**對話方塊中，將**房間大小**設置為`40`，將**混響度**設置為`60`，然後按下**套用至選取範圍**。房間大小設定空間的規模；混響度設定回響的持續時間。為了語音，將兩者都設置得適中。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：* 錄音位於空間中，而不是直接在耳邊。

## 提示

- 如果效果淹沒了原始聲音，請降低**濕度增益**或提高**乾度增益**。
- 對整個混音添加混響很少有用。將它應用於需要的部分，並保持其餘部分乾燥。
