## 本指南的用途 {#what-this-guide-is-for}

相位移器將聲音與經過移動全通濾波器階段的自己複製混合成一，因此頻譜中的缺口會隨著慢速振蕩器上下掃描。在吉他、電鋼琴或墊音上，它會產生在無數唱片中聽到的漩渦聲。Audacity 3 隨附了一個相位移器，而 Audacity 4 沒有，所以這裡是值得一試的。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 相位移器 (Audacity 3; Audacity 4 沒有相位移器)**。以下名稱是 Soundscaper 自己的，有時會與之不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空項目已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選擇要處理的音頻檔案。檔案會以片段的形式出現在其自己的軌道上。
3. 選擇 **選擇 → 全部選擇**。
4. 選擇 **效果 → 失真和調製 → 相位移器**。在 **相位移器** 對話框中，將 **階段** 設置為 `4`，並將 **LFO 頻率** 設置為 `0.6`，然後按下 **套用至選取範圍**。更多的階段會產生更深的缺口；四個是經典的踏板設置。LFO 頻率決定了掃描的速度——0.6 Hz 是一個慢速、音樂性的漩渦。
5. 按下 **播放** 聆聽，然後按下 **停止**。
   *您應該會看到：* 聲音會慢慢地漩渦，因為缺口掃描過它。

## 提示

- **反饋** 使缺口變得更尖銳，產生更金屬、更共振的掃描效果；將其保持在接近零的水平以獲得微妙的效果。
- 相位移器還可以在軌道的機架中實時運行，這樣您可以在調整時聽到掃描效果：[在軌道上添加實時效果](/guides/effects/add-a-realtime-effect-to-a-track/)。
