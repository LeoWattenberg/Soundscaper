效果選單中的效果會永久性地改變音頻。實時效果則會置於軌道上：它在播放和匯出時運行，其設定隨時可變，原始音頻不會被觸及。這適合用於反覆調整混響、EQ 和壓縮等效果。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 添加實時效果**。以下名稱是 Soundscaper 自己的，有時會與之不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空白項目已準備就緒。
2. 選擇 **檔案 → 匯入**，並選擇要加入效果的錄音。它會以片段形式出現在自己的軌道上。
3. 按下軌道標題中的 **效果** 打開效果面板，然後按下軌道架中的 **效果**，選擇 **反覆**。其設定視窗會打開；按下 **關閉** 完成設定。軌道架現在會列出反覆效果。其設定視窗隨時可從軌道架訪問以進行調整。
4. 按下 **播放** 收聽，然後按下 **停止**。
   *你應該會看到：* 軌道通過反覆效果進行播放。

## 提示

- 在軌道架中添加多個效果並拖動以更改其順序；每個效果都會將輸出傳遞給下一個效果。
- 主軌道架位於效果面板的底部，處理整個混音。
- 效果架還提供延遲、高通與低通濾波器、噪音門、缺口濾波器、棚架濾波器、顫音和聲碼器。它們共用基本的選取與效果架控制。
- [音訊效果參考](/reference/generated/audio-effects/)說明延遲、噪音門和聲碼器的行為，包括聲碼器在播放時的正規化處理。
