## 本指南的用途 {#what-this-guide-is-for}

Spectral Amplify 只會在選取的時間範圍內提高頻率帶。稍微增強就能突顯微弱音調或細節，而不必提高整段錄音的音量。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Effect → Spectral Tools → Amplify selection (Audacity 4)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取含有待突顯微弱細節的錄音。
3. 使用標題中的 **音軌選項** 按鈕開啟要檢視的音軌選單，然後選擇 **音軌視覺化 → 頻譜圖**。
4. 在剪輯上方的尺規拖曳，選取包含該細節的片段。
5. 選擇 **效果器 → 頻譜編輯 → 選取頻譜頻率範圍**。將 **最小頻率 (Hz)** 設為 `200`、**最大頻率 (Hz)** 設為 `320`，並將 **增益 (dB)** 設為 `4`，然後按 **頻譜放大**。適度提高 4 dB，只會在此片段中增強選取頻帶。
6. 按 **播放** 聆聽，再按 **停止**。
   *預期結果：* 選取細節在該片段中更明顯，其餘部分則維持原本音量。

## 提示

- 將頻率範圍界線設在接近目標細節的位置；較寬的頻帶也會提高周圍聲音。
- 若增強後的片段聽起來刺耳或比周圍音訊大聲，請降低增益。
