將伴奏轉調到歌手的音調，或微調稍微走平的樂器，是一種必須保持長度不變的音高變化。改變音高會將選取的片段移動整個半音，並不會影響時間。

:::note[來自Audacity？]
這是Audacity的**效果 → 音高與節奏 → 改變音高**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇要轉調的錄音。該檔案會以片段的形式出現在單獨的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 音高與節奏 → 改變音高**。在**改變音高**對話方塊中，將**半音**設置為`2`，然後按下**套用至選取範圍**。兩個半音上升一個全音。負值向下移動。
5. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：* 錄音的音調變高，長度與之前完全相同。

## 提示

- **保留共振**可讓聲音在轉調時仍保持相同的聲音；對於樂器，如果結果聽起來鼻音重，請關閉此選項。
- 要同時改變音高和速度，就像磁帶一樣，請在同一個子選單中使用**改變速度與音高**。
