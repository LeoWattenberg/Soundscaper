每集節目都接受相同的處理：標準化，淡出結束。一個巨集記錄了這個序列，並根據您的選擇在您要求時運行它，因此一個十步的常規變成了一個命令。Audacity 3 擁有巨集管理員，用於此目的；Audacity 4 尚未恢復巨集。

:::note[來自 Audacity？]
這是 Audacity 的 **工具 → 巨集 → 管理巨集和應用巨集（Audacity 3；Audacity 4 沒有巨集）**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空項目已準備就緒。
2. 選擇 **檔案 → 匯入音頻**，並選擇要處理的錄音。該檔案作為片段落在自己的軌道上。
3. 選擇 **選擇 → 全部選擇**。巨集會在選擇上運行，就像每個效果本身運行一樣。
4. 選擇 **工具 → 巨集管理員**，並按 **新巨集**。輸入 `Episode finish` 到 **巨集名稱**。按 **添加效果**，並選擇 **標準化** 和 **淡出**，每次按 **添加效果**。按 **運行巨集**；對話框會報告巨集已應用。按 **關閉**。這裡每個步驟都保持其默認設置；在運行之前，按下步驟的 **選擇效果** 按鈕以更改它們。
   *您應該看到：* 錄音已被標準化，並在結束時淡出至靜音。
5. 按 **播放** 收聽，然後按 **停止**。

## 提示

- 巨集與編輯器一起保存，因此它會在 **工具 → 巨集管理員** 下等待下一個錄音。
- **導出巨集** 將鏈寫為 Audacity 巨集文本檔案，而 **導入巨集** 則讀取一個，因此常規可以在此兩個程式之間移動。
