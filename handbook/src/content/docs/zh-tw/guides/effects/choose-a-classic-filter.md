## 本指南的用途 {#what-this-guide-is-for}

Classic Filters 提供 Butterworth 和 Chebyshev 設計，可明確設定濾波器階數與截止頻率。Butterworth 低通濾波器的通帶平滑，適合用來降低高頻雜訊。

:::note[從 Audacity 轉來？]
Audacity 3.6.2 及更新版本中的對應命令是 **Effect → Legacy → Classic Filters (Audacity 3.6.2 and later)**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選要降低高頻的錄音。錄音會以獨立音軌中的片段顯示。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → 舊版效果器 → 傳統濾波器**。在 **傳統濾波器** 對話方塊中，將 **巴特沃斯濾波器** 設為 **過濾器家族**、**低通** 設為 **濾波器類型**，將 **順序** 設為 `4`、**截止頻率** 設為 `5000`，然後按下 **套用至選取範圍**。Butterworth 會維持平坦通帶；四階濾波器的衰減比一階更陡。
5. 按下 **播放** 聆聽，再按 **停止**。
   *你會看到：* 截止頻率以上的高頻降低，低頻則維持在通帶內。

## 提示

- 提高 **順序** 可讓過渡更陡；高階濾波器可能在尖銳瞬態附近產生振鈴。
- 目前 Audacity 手冊將 Classic Filters 列在 Legacy effects 群組；若清單中沒有，請在 Audacity Plugin Manager 啟用。
