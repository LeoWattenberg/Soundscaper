改變節奏會將單一變更套用到整個選取範圍。滑動拉伸允許變更移動：從原始節奏開始，以四分之一音符更快的速度結束，或在句子中調整音高以產生磁帶停止或上升的空靈音調。節奏和音高滑動是分別設定的，因此其中一個可以移動，而另一個保持不變。

:::note[來自Audacity？]
這是Audacity的**效果 → 音高和節奏 → 滑動拉伸**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇要拉伸的段落。該檔案會以剪貼形式的軌道落在自己的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 音高和節奏 → 滑動拉伸**。在**滑動拉伸**對話方塊中，將**最終節奏變更**設定為`25`，然後按下**套用到選取範圍**。初始節奏變更保持在零，因此段落以自己的速度開始，到結尾時會快四分之一音符。
5. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：* 段落在進行時逐漸加快速度。

## 提示

- 設定**初始音高移轉**和**最終音高移轉**以滑動音高；正數的最終值會逐漸升高到結尾。
- 像其他節奏效果一樣，這會改變剪貼的長度，因此軌道上其後的任何內容都會移動。
