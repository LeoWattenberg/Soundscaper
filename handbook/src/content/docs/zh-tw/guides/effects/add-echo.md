Echo 會在延遲後再次播放選取的片段，然後再次播放，每次重複的音量都比上一次小。這是經典的人聲反彈效果或在喊叫時產生的峽谷效果。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 延遲和混響 → Echo**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，並選擇要回響的音訊。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇 **選取 → 全選**。
4. 選擇 **效果 → 延遲和混響 → Echo**。在 **Echo** 對話框中，將 **衰減因子** 設置為 `0.4`，然後按下 **套用至選取**。每次重複的音量是上一次的 0.4 倍，因此回聲會在幾次重複後消失。**延遲時間** 設置重複之間的間距。
5. 按下 **播放** 收聽，然後按下 **停止**。
   *您應該會看到：* 音訊後面是逐漸消失的自身重複。

## 提示

- 在片段後面添加一到兩秒的靜音 (**生成 → 靜音**)，讓最後的重複有足夠的空間播放。
- 如需房間感而非明顯的重複，請使用 [Reverb](/guides/effects/add-reverb/)。
