## 本指南的用途 {#what-this-guide-is-for}

有時你想要的就是復古效果：放慢錄音會降低音調，加快速度則會提高音調，就像以錯誤速度播放唱片一樣。改變速度和音調正是這樣做，而且因為它不需要將音調與時間分開，所以它是最乾淨的速度效果。

:::note[來自Audacity？]
這是Audacity的**效果 → 音調和節奏 → 改變速度**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入**，並選擇要加快或放慢的錄音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選擇 → 全選**。
4. 選擇**效果 → 音調和節奏 → 改變速度和音調**。在**改變速度和音調**對話框中，將**速度變化**設置為`25`，然後按下**套用至選取範圍**。正數百分比會加快選取範圍並提高其音調；−50會將速度減半並降低一個八度。
5. 按下**播放**來聆聽，然後按下**停止**。
   *你應該會看到：* 錄音變得更快、音調更高，並且比之前更短。

## 提示

- 要修復以錯誤取樣速率製作的錄音——以44.1 kHz材質播放為48 kHz時，聲音會加快約9％——正確的校正值為−8.16％。
- 要改變速度而不移動音調，請使用[改變節奏](/guides/effects/change-tempo-without-changing-pitch/)。
