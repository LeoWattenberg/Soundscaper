## 本指南的用途 {#what-this-guide-is-for}

Vocoder 使用人聲變化的形狀來控制另一種聲音，讓語音呈現音樂性或機器人般的音色。在 Soundscaper 中，將它套用至單聲道人聲選取範圍，並調整載波音量。

:::note[從 Audacity 轉來？]
Audacity 4.0.1 中的對應命令是 **Effect → Distortion and Modulation → Vocoder**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選用來控制效果的單聲道語音或其他聲音。聲音會以獨立音軌中的片段顯示。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → 失真與調變 → 聲碼器**。在 **聲碼器** 對話方塊中，將 **聲碼器頻帶** 設為 `24`，並將 **經聲碼器處理的音訊** 設為 **輸出**，然後按下 **套用至選取範圍**。頻帶數決定人聲形狀的切分細緻度；單聲道選取範圍的內建載波由 **音訊載波電平** 控制。
5. 按下 **播放** 聆聽，再按 **停止**。
   *你會看到：* 人聲帶有合成、和聲般的特質。

## 提示

- 穩定音高的載波會產生較有音樂性的結果；白雜訊或雷達脈衝會讓人聲更機械化。
- Audacity 的立體聲流程是在套用 Vocoder 前，先將人聲放在左聲道、載波放在右聲道。
