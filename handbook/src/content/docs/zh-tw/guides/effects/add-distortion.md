失真會剪切或彎曲波形，使其獲得和聲。一點柔和失真可以讓低音或合成器變得更溫暖；太多則會把吉他變成一面牆。類型選擇曲線的形狀；門檻設定多少信號會到達它。

:::note[來自Audacity？]
這是Audacity的**效果 → 失真**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇要失真的聲音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 失真與調製 → 失真**。在**失真**對話方塊中，選擇**柔和失真**作為**失真類型**，並將**門檻**設置為`-12`，然後按下**套用至選取範圍**。柔和失真會圓滑峰值而不是切割它們。較低的門檻會讓更多信號進入曲線。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：*聲音變得更粗糙，其峰值變圓滑。

## 提示

- 如果結果在波形中偏離中心，請啟用**DC阻塞**。
- 失真會增加音量。之後進行正規化，如果峰值達到頂部。
