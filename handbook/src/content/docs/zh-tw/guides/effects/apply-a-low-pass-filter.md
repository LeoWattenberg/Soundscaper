## 本指南的用途 {#what-this-guide-is-for}

低通濾波器會保留截止頻率以下的頻率，並逐漸降低上方頻率。使用平緩的截止設定，可消除嘶聲或柔化過亮的錄音，同時不失去聲音的厚實感。

:::note[從 Audacity 轉來？]
Audacity 中對應的是 **Effect → EQ and Filters → Low-Pass Filter**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選要柔化高頻的錄音。錄音會以獨立音軌中的片段顯示。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → EQ 與過濾器 → 低通濾波器**。在 **低通濾波器** 對話方塊中，將 **截止頻率** 設為 `5000`，並將 **12 dB/倍頻程** 設為 **衰減斜率**，然後按下 **套用至選取範圍**。5 kHz 截止會稍微削弱高頻；每倍頻程 12 dB 的斜率較平緩。
5. 按下 **播放** 聆聽，再按 **停止**。
   *你會看到：* 錄音的高頻聽起來稍微柔和一些。

## 提示

- 降低截止頻率可進一步減少明亮感，但請留意鈸聲和子音是否變得沉悶。
- 需要更強烈限制截止頻率以上的聲音時，請選擇更陡的 **衰減斜率**。
