導入檔案會為您建立一個音軌，但錄音或貼上需要一個位置。在音軌列表上方的「新增音軌」按鈕可建立一個空的音頻音軌；標籤音軌則包含標記器和文字，而非聲音。

:::note[來自Audacity？]
這是Audacity的**音軌 → 新增 → 單聲道音軌**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 按下音軌列表上方的「新增音軌」並選擇「音頻音軌」。
3. 專案現在顯示2個音軌。
   *您應該會看到：* 在第一個音軌下方，第二個空的音頻音軌。

## 提示

- 從其選單中重新命名音軌，以便具有多個音軌的會話保持可讀性。
- 拖動音軌的標題以重新排序。
