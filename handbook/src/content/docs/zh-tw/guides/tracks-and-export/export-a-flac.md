## 本指南的用途 {#what-this-guide-is-for}

FLAC 會壓縮 PCM 音訊，並在選定的匯出精度下保留取樣。它適合製作較小的聆聽母帶，同時由專案保留可編輯的音軌。

:::note[從 Audacity 轉來？]
Audacity 3 中的對應命令是 **File → Export Audio → FLAC**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選要交付的錄音或混音。音訊會以獨立音軌中的片段顯示。
3. 選擇 **檔案 → 匯出音訊**，將 **格式** 設為 **FLAC**，然後按下 **匯出**。算繪完成後檔案會下載，連結會留在對話方塊中。
   *你會看到：* 匯出對話方塊提供可下載的 FLAC 檔案。

## 提示

- Compression level 會改變編碼工作量和檔案大小，不會改變解碼後的音質。
- 匯出的混音不會保留個別音軌或復原記錄。若要日後編輯，請[儲存專案](/guides/projects/save-your-project/)。
