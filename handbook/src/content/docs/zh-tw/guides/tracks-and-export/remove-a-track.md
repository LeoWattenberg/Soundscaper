## 本指南的用途 {#what-this-guide-is-for}

Remove tracks 會從專案中刪除選取的音軌及其中所有片段。這適合用來移除未使用的錄音，或比較編輯結果後多出的備用副本。選取一個片段會將整條音軌設為目標，因此刪除前請確認選取內容。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Tracks → Remove tracks (Audacity 4)**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取要保留的錄音。錄音會以片段形式出現在獨立音軌上。
3. 選擇 **檔案 → 匯入**，然後選取另一條音軌上不需要的錄音。錄音會以片段形式出現在獨立音軌上。
4. 按 **Tab** 將焦點移到要移除之音軌中的片段，再按 **Enter** 選取它。
5. 選擇 **音軌 → 移除軌道**。
6. 保留的錄音仍在原始位置。
   *您應該會看到：* 不需要的音軌已消失，另一段錄音則維持原樣。

## 提示

- 選擇 **編輯 → 復原** 可還原已移除的音軌及其片段。
- 若只要移除錄音的一部分，請[刪除一段並保留空隙](/guides/editing/delete-a-passage-and-leave-a-gap/)，不要刪除整條音軌。
- 從專案中移除音軌不會刪除從電腦匯入的原始檔案。
- 連結 lane 群組中的音軌會一起移除。
