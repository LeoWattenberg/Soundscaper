## 本指南的用途 {#what-this-guide-is-for}

Duplicate track 會複製整條音軌，包括所有片段及其在時間軸上的位置。保留原始音軌的同時，可使用副本嘗試其他編輯或效果。選取一個片段即可指定要複製的音軌；該音軌上的其他片段也會一併複製。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Tracks → Duplicate (Audacity 4)**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取要複製之音軌上的錄音。錄音會以片段形式出現在獨立音軌上。
3. 在要將錄音拆分為兩個可個別編輯部分的位置，按一下波形以放置游標。若音軌已經有多個片段，或您想保留為單一片段，請略過放置游標和接下來的 Split 步驟。
4. 選擇 **編輯 → 音訊片段 → 分割**。
5. 現在專案中會顯示 2 個片段。
   *您應該會看到：* 音軌上有兩個片段，可以一起複製。
6. 按 **Tab** 將焦點移到音軌中的其中一個片段，再按 **Enter** 選取它。
7. 選擇 **音軌 → 複製軌道**。
8. 現在專案中會顯示 4 個片段和 3 條音軌。
   *您應該會看到：* 原始音軌和副本各自有兩個片段，而且在時間軸上的位置相同。

## 提示

- 原始音軌和副本會同時播放。比較時請[將音軌靜音或設為獨奏](/guides/tracks-and-export/mute-and-solo-tracks/)，每次只聽一個版本。
- 若只要複製一段，請改為[將選取範圍複製到新音軌](/guides/editing/duplicate-a-selection-to-a-new-track/)。
- 選擇 **編輯 → 復原** 會移除複製的音軌。
