在檢查信號鏈、校準音量或製作嗶聲覆蓋字詞時，第一個要使用的工具是已知頻率和音量的音調。產生器會在光標處創建音頻，或在有選取範圍時替換選取範圍。

:::note[來自Audacity？]
這是Audacity的**生成 → 音調**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**生成 → 音調**。在**音調**對話框中，將**頻率 (Hz)**設置為`440`，將**持續時間 (秒)**設置為`2`，然後按**生成**。440 Hz是音樂會上的A音，是標準調音參考。
3. 專案現在顯示1個剪輯。
   *您應該會看到：* 一個新的剪輯包含兩秒鐘的音調。

## 提示

- 如果音調將與其他任何內容混合，請將**振幅**設置為`0.5`或更低。
- **生成 → 靜音**操作方式相同，是添加剪輯之間空白的最簡單方法。
