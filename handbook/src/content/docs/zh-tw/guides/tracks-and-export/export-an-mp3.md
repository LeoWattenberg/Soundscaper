MP3 檔案大小適中，可以在各種設備上播放，而且是大多數播客主持人和消息應用所期望的格式。導出操作會將整個專案（包括每一軌、特效和編輯）渲染成一個檔案。

:::note[來自 Audacity？]
這相當於 Audacity 中的 **檔案 → 導出音頻 → MP3**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空專案就準備好了。
2. 選擇 **檔案 → 導入**，並選擇要發佈的音頻檔案。檔案會被導入到一個單獨的軌上。
3. 選擇 **檔案 → 導出音頻**，將 **格式** 設置為 **MP3**，然後點擊 **導出**。渲染完成後，檔案會立即下載，並且對話框中會保留其鏈接。檔案是在瀏覽器中編碼的；沒有任何內容會離開您的計算機。

## 提示

- MP3 檔案是交付副本，不是備份。如果可能需要再次編輯，請保留專案或同時導出 WAV 檔案。
- 完全量化的峰值在編碼後可能會截斷。在導出前將音量降低到 -1 dB 或更低。
- 比特率模式決定了編碼器如何分配比特。標準預設會根據材料動態調整速率，這是大多數交付的正確選擇；當主持人或較舊的硬件播放器要求固定速率時，請選擇常量。
