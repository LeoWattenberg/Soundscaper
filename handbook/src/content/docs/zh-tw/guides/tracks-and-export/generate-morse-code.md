## 本指南的用途 {#what-this-guide-is-for}

摩斯密碼會將訊息轉換成具有時間長度的點、劃和間隔。產生器會預覽編碼，並依訊息和速度計算片段長度。

:::note[從 Audacity 轉來？]
Audacity **No directly matching built-in Morse code generator**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **產生 → 摩斯電碼**。在 **摩斯電碼** 對話方塊中，將 **訊息** 設為 `SOS`、**速度（每分鐘字數）** 設為 `20`、**頻率 (Hz)** 設為 `600`、**振幅** 設為 `0.2`，然後按下 **產生**。將範例訊息換成自己的文字。檢查編碼預覽；不支援的字元會阻止產生音訊。
3. 專案現在顯示 1 個片段。
   *你會看到：* 摩斯密碼片段包含該訊息；長度取決於選定速度。

## 提示

- 降低速度會延長點、劃和間隔，但不會改變音調頻率。
- Duration 在此為唯讀結果。變更訊息或速度即可調整片段長度。
