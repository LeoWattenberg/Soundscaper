跟蹤標題每個都包含一個音量滑塊，但平衡混音意味著需要同時看到它們。混合器面板為每條跟蹤佈局一個通道條——名稱、音量淡入淡出、平衡、靜音和獨奏，以及跟蹤的效果——旁邊是一個主條，就像調音台一樣。Audacity 3 有一個混合器板來實現這一點；Audacity 4 沒有恢復它。

:::note[來自 Audacity？]
這是 Audacity 的 **查看 → 混合器板（Audacity 3；Audacity 4 沒有混合器板）**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇 **檔案 → 導入** 並選擇混音的第一條跟蹤。檔案會作為片段落在自己的跟蹤上。
3. 選擇 **檔案 → 導入** 並選擇第二條跟蹤。檔案會作為片段落在自己的跟蹤上。
4. 選擇 **查看 → 面板 → 混合器**。
5. 專案現在顯示 **混合器** 面板已打開。
   *你應該看到：* 每條跟蹤都有一個條，帶有其音量淡入淡出、平衡控制和靜音/獨奏按鈕，以及最後的主條。
6. 拖動條的 **音量** 淡入淡出以設置該跟蹤的水平，並轉動 **平衡** 以將其放置在左側或右側。這些與跟蹤標題中的控制相同，因此可以使用任何一種視圖。
7. 按 **播放** 收聽，然後按 **停止**。
   *你應該看到：* 每個條上的錶盤在專案播放時與其跟蹤一起移動。

## 提示

- **添加組總線** 創建一個總線，多個跟蹤可以供給，因此整個鼓組或一組人聲有一個淡入淡出器。
- 面板中的 **路由圖** 按鈕顯示相同的混合器，作為圖表顯示甚麼供給甚麼。
