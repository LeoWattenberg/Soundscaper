## 本指南的用途 {#what-this-guide-is-for}

Swap stereo channels 會交換立體聲軌道左右兩側的音訊。若麥克風或錄音機接線相反，可用此功能修正，同時保留錄音的時間位置。

:::note[從 Audacity 轉來？]
Audacity 3 中的對應命令是 **Audio Track Dropdown Menu → Swap Stereo Channels**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選左右聲道顛倒的立體聲錄音。錄音會以獨立音軌中的片段顯示。
3. 按音軌標題中的 **音軌選項** 按鈕開啟選單，然後選擇 **音軌聲道 → 交換立體聲聲道**。
4. 專案現在顯示 1 個片段和 2 條音軌。
   *你會看到：* 錄音仍在原位置保持為單一立體聲片段，左右聲道已交換。

## 提示

- 此命令會交換聲道內容。Pan 只改變聆聽位置，不會交換聲道本身。
- 使用 **編輯 → 復原** 可還原原本的聲道順序。
