當音軌平衡後，將它們混合到一個音軌可以使專案更易於操作，並提供一個可導出或在其他地方使用的單個剪輯。混合使用每個選定音軌的增益、全景、自動化和效果。在此操作中，靜音和獨奏對選定音軌被忽略，並且主處理保持實時。

:::note[來自Audacity？]
這與Audacity的**音軌 → 混合 → 混合和渲染**相同。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇**檔案 → 導入**並選擇第一個部分。檔案會以剪輯的形式落在自己的音軌上。
3. 選擇**檔案 → 導入**並選擇第二個部分。檔案會以剪輯的形式落在自己的音軌上。
4. 單擊第一個剪輯的名稱欄，然後按住Shift單擊第二個剪輯的名稱欄，這樣兩個剪輯都將被選中。每個有選定剪輯的音軌都會進入混合。
5. 選擇**音軌 → 混合渲染**。在**混合渲染**對話框中，保持**混合下**、**渲染效果**和**替換原始檔案**選中，選擇**立體聲**作為**混合下到**，然後單擊**混合渲染**。
6. 專案現在顯示一個名為**混合**的剪輯。
   *你應該看到：* 一個音軌包含一個名為混合的剪輯；源音軌已消失。

## 提示

- 在渲染前，在**混合下到**下選擇**單聲道**、**立體聲**或專案的配置多通道佈局。
- **編輯 → 撤銷**會恢復原始音軌，如果你需要更改平衡。
- 你不需要混合下以導出。**檔案 → 導出音頻**會渲染整個專案，無需混合。
