## 本指南的用途 {#what-this-guide-is-for}

立體聲錄音是一條包含兩個聲道的音軌。當兩個聲道錄製的內容不同——例如左聲道是訪談者、右聲道是來賓，或雙聲道錄音機分別錄下吉他和節拍器——你會希望將它們拆到不同音軌，以便個別調整音量和效果。

:::note[從 Audacity 轉來？]
這相當於 Audacity 的**音軌下拉選單 → 拆分立體聲音軌**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就準備好了。
2. 選擇 **檔案 → 匯入**，並選擇立體聲錄音。它會以片段形式出現在自己的音軌上。
3. 開啟音軌標題列中的**音軌選單**，選擇 **音軌聲道 → 將立體聲拆分為 left/right 單聲道**。每個聲道都會成為獨立的單聲道音軌，並分別硬式聲像定位至左側和右側，因此混音聽起來仍與先前相同。
4. 專案現在會顯示 2 個片段。
   *你應該會看到：* 兩個單聲道片段分別位於兩條音軌上，音軌名稱標示各自的聲道側。

## 提示

- 選取兩條音軌，然後在音軌選單中選擇 **音軌聲道 → 建立立體聲音軌**，即可將它們重新合併。
- **將立體聲拆分為置中單聲道**會進行相同拆分，但將兩條音軌都置中；如果兩個聲道錄製了相同聲音，這種方式更合適。
