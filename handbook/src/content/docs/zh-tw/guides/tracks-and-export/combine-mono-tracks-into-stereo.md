## 本指南的用途 {#what-this-guide-is-for}

Make stereo track 會將兩條單聲道音軌轉換成一個立體聲片段，並取代來源音軌。您開啟選單的音軌會提供左聲道；其下方第一條相容的單聲道音軌會提供右聲道。若下方沒有這樣的音軌，Soundscaper 會使用專案其他位置的第一條相容單聲道音軌。合併前，請將預定作為右聲道的音軌放在左聲道音軌正下方。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Upper mono track menu → Make stereo track (Audacity 4)**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取要作為左聲道的單聲道錄音。錄音會以片段形式出現在獨立音軌上。
3. 選擇 **檔案 → 匯入**，然後選取要作為右聲道的單聲道錄音。錄音會以片段形式出現在獨立音軌上，位於第一段錄音下方。依照預期播放的時間安排片段位置。
4. 按一下音軌標題中的 **音軌選項** 按鈕開啟左聲道錄音的選單，然後選擇 **音軌聲道 → 建立立體聲軌道**。
5. 現在專案中會顯示 1 個片段和 2 條音軌。
   *您應該會看到：* 一個立體聲片段取代了兩段單聲道錄音，且每個聲道都包含預期的聲音。

## 提示

- 新片段會依照專案取樣率涵蓋兩條音軌的內容。任一音軌上的空白部分會在對應聲道中變成靜音。
- 若兩段錄音需要同時開始，請先[對齊音軌的起點](/guides/editing/align-track-starts-together/)再合併。
- 若之後還需要編輯個別片段，請保留一份專案副本。選擇 **編輯 → 復原** 即可還原兩條單聲道音軌。
