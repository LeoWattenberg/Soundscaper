## 本指南的用途 {#what-this-guide-is-for}

若相關音軌名稱排列在一起，就更容易瀏覽含有多個錄音段落的專案。Sort by name 會依字母順序重新排列音軌，但不會改變剪輯在時間軸上的起始位置。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Tracks → Sort Tracks → Sort by Name**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取依名稱應排在另一段錄音後面的錄音。
3. 選擇 **檔案 → 匯入**，並選取依名稱應排在前面的錄音。
4. 選擇 **音軌 → 排序音軌 → 依名稱排序**。音軌名稱會依字母順序排序。
5. 現在專案會顯示 2 個剪輯。
   *預期結果：* 兩段錄音都留在專案中，音軌名稱依字母順序排列。

## 提示

- 排序只會改變音軌順序，不會改變剪輯時間或音訊內容。
- 若要依剪輯開始時間排列音軌，請使用 **音軌 → 排序音軌 → 依時間排序**。
