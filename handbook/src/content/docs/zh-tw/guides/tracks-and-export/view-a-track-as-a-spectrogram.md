## 本指南的用途 {#what-this-guide-is-for}

波形顯示振幅變化，頻譜圖則顯示頻率隨時間的變化。將一條音軌切換為頻譜圖檢視，即可檢查音調、噪音或其他頻率細節，而不會改變音訊。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Track menu → Track Visualization → Spectrogram**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取要檢查頻率的錄音。
3. 使用錄音標題中的 **音軌選項** 按鈕開啟選單，並選擇 **音軌視覺化 → 頻譜圖**。音軌會切換為頻率顯示；音訊和剪輯時間維持不變。
4. 現在專案會顯示 1 個剪輯。
   *預期結果：* 音軌顯示頻譜圖，剪輯仍位於時間軸上的相同位置。

## 提示

- 若要返回振幅檢視，請在相同音軌選單中選擇 **音軌視覺化 → 波形**。
- 若需要調整頻率範圍或刻度，可從音軌選單開啟頻譜圖設定。
