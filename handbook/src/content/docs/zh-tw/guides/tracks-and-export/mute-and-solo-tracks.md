每條音軌在其標題中都有一個靜音按鈕和獨奏按鈕。靜音會使該音軌靜音；獨奏會使所有其他音軌靜音，這樣您就可以單獨聽到這個音軌。這兩者都是聆聽輔助工具，它們僅僅改變您在工作時聽到的內容，而導出仍然會渲染所有未靜音的音軌。

:::note[來自Audacity？]
這與Audacity中的“音軌控制面板中的靜音和獨奏按鈕”相同。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空項目已準備就緒。
2. 選擇**檔案 → 匯入音頻**並選擇一個音軌。該檔案以剪貼形式出現在其自己的音軌上。
3. 選擇**檔案 → 匯入音頻**並選擇另一個音軌。該檔案以剪貼形式出現在其自己的音軌上。
4. 按下音軌標題中的**靜音**。第二條音軌將不會在播放中。
5. 按下音軌標題中的**獨奏**。獨奏會覆蓋此音軌上的靜音，並使所有其他音軌靜音，這樣您就可以單獨聽到此音軌。

## 提示

- 再次按下按鈕以釋放它。**音軌 → 靜音所有音軌**一次性清除所有音軌。
- 獨奏多個音軌以一起試聽小組；靜音僅用於異常音軌。
