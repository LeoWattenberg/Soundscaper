## 本指南的用途 {#what-this-guide-is-for}

Pluck 可產生短促的有音高聲音，適合作為簡單音符或聲音設計中的重音。使用 MIDI 音高欄位即可選擇音符，不必計算頻率。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Generate → Pluck (Nyquist)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **產生 → Nyquist → Pluck**。在 **Pluck** 對話框中，將 **Pluck MIDI pitch** 設為 `60`，並將 **Duration (60s max)** 設為 `2`，然後按 **套用**。MIDI 音高 60 是中央 C；兩秒的長度能讓音符充分衰減。
3. 現在專案會顯示 1 個剪輯。
   *預期結果：* 時間軸上會出現一段兩秒、具有聲音內容的撥弦音。

## 提示

- 提高 **Pluck MIDI pitch** 可得到較高音符，降低則會得到較低音符。
- 縮短 **Duration (60s max)**，可製作較短促的重音。
