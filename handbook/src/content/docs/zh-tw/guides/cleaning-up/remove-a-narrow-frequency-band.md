## 本指南的用途 {#what-this-guide-is-for}

穩定的哨音或電子音可能只在錄音的一小段時間內占據狹窄頻帶。Spectral Delete 會在選取的時間範圍內移除該頻帶，同時保留周圍頻率。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Effect → Spectral Tools → Delete selection (Audacity 4)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取含有短暫音調聲的錄音。錄音會以獨立音軌上的剪輯顯示。
3. 使用標題中的 **音軌選項** 按鈕開啟要檢視的音軌選單，然後選擇 **音軌視覺化 → 頻譜圖**。
4. 在剪輯上方的尺規拖曳，選取聽得到音調的時間範圍。
5. 選擇 **效果器 → 頻譜編輯 → 選取頻譜頻率範圍**。將 **最小頻率 (Hz)** 設為 `200`，將 **最大頻率 (Hz)** 設為 `320`，然後按 **頻譜刪除**。這只會在選取的時間範圍內移除循環音訊中的 261.6 Hz 音調。
6. 按 **播放** 聆聽，再按 **停止**。
   *預期結果：* 該片段中的音調聲會減弱，錄音其餘部分則維持不變。

## 提示

- 使用頻譜圖定位音調，刪除前再將時間和頻率範圍縮小至音調附近。
- Spectral Delete 只影響選取的時間與頻率範圍；一般 Delete 會移除整個選取片段。
