## 本指南的用途 {#what-this-guide-is-for}

De-esser 會降低語音中強烈的齒擦音，同時保留大部分人聲。適用於 S 或 SH 音比前後詞語更突出的片段。

:::note[從 Audacity 轉來？]
Audacity 目前的效果清單中**沒有直接內建的對應效果**。下方名稱屬於 Soundscaper，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，然後挑選含有干擾性 S 音的人聲片段。聲音會以獨立音軌中的片段顯示。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → 噪音移除與修復 → 去齒音器**。在 **去齒音器** 對話方塊中，將 **頻率** 設為 `6000`、**最大衰減** 設為 `6`，然後按下 **套用至選取範圍**。Frequency 鎖定齒擦音範圍；maximum reduction 限制這些瞬間的降低幅度。
5. 按下 **播放** 聆聽，再按 **停止**。
   *你會看到：* 齒擦音變柔和，其他人聲仍保持清楚。

## 提示

- 調整 **頻率** 時請聆聽 S 音；數值太低可能讓子音和明亮感變得沉悶。
- 先使用適中的 **最大衰減**，只有在尖銳齒擦音仍干擾時才提高。
