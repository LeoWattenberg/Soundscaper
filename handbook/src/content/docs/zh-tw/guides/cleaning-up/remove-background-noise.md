持續的背景噪音——風扇、冰箱、電源嗡嗡聲——可以在兩次操作中移除。首先，您向噪音減少顯示一段只有噪音的部分，以便它可以建立一個配置文件；然後將效果應用於所有內容。配置文件是使此操作奏效的關鍵，因此請選擇錄音中沒有人說話的部分。

:::note[來自Audacity？]
這是Audacity的**效果 → 噪音移除和修復 → 噪音減少，兩次操作**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，新的空白項目已準備就緒。
2. 選擇**檔案 → 匯入音頻**，然後選擇您要清理的錄音。該檔案作為片段其自身軌道上。
3. 在片段上方拖動尺子以選擇一段只包含噪音的部分——通常是在任何人說話之前的引言。配置文件中不應包含任何除了您想要消除的噪音之外的內容。
4. 選擇**效果 → 噪音移除和修復 → 噪音減少**，然後按下**獲取噪音配置文件**。狀態行報告配置文件已準備就緒。按下**關閉**以暫時離開對話框。
5. 選擇**選擇 → 全部選擇**。配置文件被保留；現在效果需要知道要清理什麼。
6. 選擇**效果 → 噪音移除和修復 → 噪音減少**。在**噪音減少**對話框中，將**噪音減少**設置為`12`，然後按下**套用至選擇**。約12 dB是一個不錯的第一嘗試。更高的值會移除更多的噪音，但開始使聲音聽起來空洞。
7. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：*引言部分變得安靜得多，而聲音則保持不變。

## 提示

- 如果結果聽起來像水或金屬，請撤銷並嘗試降低**噪音減少**值或**靈敏度**。
- 噪音減少只適用於錄音中貫穿始終的噪音。對於單一的咳嗽或點擊，請剪裁它或使用點擊移除功能。
