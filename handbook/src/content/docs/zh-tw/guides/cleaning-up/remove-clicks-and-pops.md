來自電纜、滑鼠或舊唱片的點擊聲只是幾個範例而已。點擊移除會找到與周圍環境不同的突起點，並將其平滑處理，這比手動切除每個點擊聲快得多。

:::note[來自Audacity？]
這是Audacity的**效果 → 噪音移除和修復 → 點擊移除**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，然後選擇包含點擊聲的錄音。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 噪音移除和修復 → 點擊移除**。在**點擊移除**對話方塊中，將**門限**設置為`150`，然後按下**套用至選取範圍**。較低的門限可以捕捉到較安靜的點擊聲。預設值200是保守的；150可以捕捉到更多點擊聲，而不會影響到音樂。
5. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：*點擊聲已經消失，周圍的素材保持不變。

## 提示

- 如果有點擊聲倖存下來，請僅選取其周圍的瞬間，並再次運行效果，將**門限**設置得更低。
- 寬度超過幾毫秒的點擊聲不屬於此效果的範圍。請將其切除。
