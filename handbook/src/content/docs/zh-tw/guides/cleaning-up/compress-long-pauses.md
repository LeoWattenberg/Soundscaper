## 本指南的用途 {#what-this-guide-is-for}

長時間停頓會讓口語內容顯得拖沓，但移除所有停頓又會讓內容難以理解。Truncate Silence 可只縮短超過最短時長的停頓之多餘部分。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Effect → Special → Truncate Silence**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取停頓過長的錄音。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → 特殊 → 截斷靜音**。在 **截斷靜音** 對話框中，將 **臨界值** 設為 `-40`、**最短靜音** 設為 `0.5`，在 **壓縮多餘的靜音** 中選擇 **動作**，並將 **壓縮為** 設為 `50`，然後按 **套用至選取範圍**。超過 0.5 秒的靜音會縮短為多餘時長的一半，句子之間仍會保留停頓。
5. 按 **播放** 聆聽，再按 **停止**。
   *預期結果：* 長時間停頓會縮短，句子之間仍留有一些靜音。

## 提示

- 提高 **最短靜音** 可讓較短停頓維持原狀；降低 **壓縮為** 則可進一步縮短長停頓。
- 聆聽呼吸聲或句尾是否被截斷；若節奏變得不自然，請復原。
