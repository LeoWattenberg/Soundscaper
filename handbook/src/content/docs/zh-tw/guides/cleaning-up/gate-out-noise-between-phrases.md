降噪器從整個錄音中去除噪音；門限器採用不同的方法。當音量低於閾值時（例如句子之間、暫停時），門限器會降低音頻音量，當聲音返回時，它會立即打開。它無法從單詞下方清除噪音，但它可以使單詞之間的空隙變得乾淨，並且設置起來非常快。

:::note[來自Audacity？]
這是Audacity的**效果 → 噪音移除和修復 → 噪音門限器**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇**檔案 → 導入**，並選擇帶有噪音暫停的錄音。它會作為片段出現在自己的軌道上。
3. 選擇**選擇 → 全部選擇**。
4. 選擇**效果 → 噪聲移除和修復 → 噪聲門限**。在**噪聲門限**對話框中，將**閾值**設為`-35`，將**音量降低**設為`-30`，然後按**應用於所選內容**。閾值應位於噪音之上，靜音語音之下；-35 dB適用於大多數語音錄音。降低量設置了空隙被降低的程度——不要降低所有音量，因為這聽起來不自然。
5. 按**播放**收聽，然後按**停止**。
   *您應該會看到：* 暫停安靜，每個短語未受影響。

## 提示

- 如果單詞末尾被截斷，請提高**保持**或**釋放**，讓門限關閉得更慢；這兩個控件的單位是秒。
- 對於持續在語音下方的噪音，請使用[降噪](/guides/cleaning-up/remove-background-noise/)，或兩者結合使用。
