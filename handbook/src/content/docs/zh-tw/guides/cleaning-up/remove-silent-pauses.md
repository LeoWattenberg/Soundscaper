長時間的錄音，加上慢速的句子間停頓，聽起來會很累。

**靜音截短**會找到所有低於特定閾值且持續時間超過最小靜音長度的段落，並將其縮短，讓節奏更緊湊，而不會切入任何字詞。

:::note[來自Audacity？]
這是Audacity的**效果 → 特殊 → 靜音截短**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，然後選擇帶有長停頓的錄音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 特殊 → 靜音截短**。在**靜音截短**對話方塊中，將**閾值**設定為`-40`，然後按下**套用至選取範圍**。任何小於−40 dB的聲音都被視為靜音。超過最小靜音長度的停頓會被縮短至截短長度；這裡兩者都保持預設值，即半秒。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：* 停頓變短，每個句子仍完整無缺。

## 提示

- 如果句子開頭的字詞被截斷，請提高最小靜音長度或降低閾值。
- 此效果會改變選取範圍的長度，因此在將片段與其他內容對齊之前，請先執行此操作。
