有時你想要刪除一段音訊，但保留其佔據的時間，例如在暫停時響起的電話或需要消音的姓名。靜音功能會保留剪輯的長度，僅將選取的部分變平。

:::note[來自 Audacity？]
這與 Audacity 的 **編輯 → 移除特殊 → 靜音音訊** 功能相同。以下名稱是 Soundscaper 自己的，有時可能會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇 **檔案 → 匯入音訊**，然後選擇要靜音的音訊檔案。檔案會以剪輯的形式出現在其自己的軌道上。
3. 在剪輯上方規則中拖曳，以選取要靜音的特定部分。
4. 選擇 **編輯 → 移除特殊 → 靜音音訊**。
5. 專案現在顯示 1 個剪輯。
   *你應該會看到：* 波形在選取的區域內是平坦的，剪輯仍然是一整段。

## 提示

- 靜音是一種正常的編輯：**編輯 → 復原** 可以恢復音訊。
- 如要同時移除時間和聲音，請參閱 [從錄音中切除錯誤](/guides/editing/cut-out-a-mistake/)。
