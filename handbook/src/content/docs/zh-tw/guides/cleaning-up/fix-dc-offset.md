有些音效卡和廉價音訊介面會在錄音中加入固定電壓，使整個波形稍微偏離中心線。你無法直接聽見這種偏移，但它會占用餘裕，並在每次編輯處產生喀嗒聲。「移除直流偏移」會將波形重新置中。

:::note[從 Audacity 轉來？]
這相當於 Audacity 的**效果 → 音量和壓縮 → 移除直流偏移**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就準備好了。
2. 選擇 **檔案 → 匯入**，並選擇偏離中心的錄音。它會以片段形式出現在自己的音軌上。
3. 選擇 **選取 → 全選**。
4. 選擇 **效果 → 音量和壓縮 → 移除直流偏移**。效果會立即套用至選取範圍。
5. 按 **播放** 聆聽，然後按 **停止**。
   *你應該會看到：* 波形已在零線上置中。

## 提示

- [峰值正規化](/guides/volume/normalize-peaks/)也會移除直流偏移；如果你本來就要正規化，就不需要另外處理。
- 如果偏移在錄音過程中改變，它就不是直流偏移；請改用[高通濾波器](/guides/cleaning-up/remove-low-rumble/)。
