## 本指南的用途 {#what-this-guide-is-for}

Clip Fix 會根據鄰近波形，估算短暫削波峰值缺失的頂端。請在錄音副本上使用並仔細聆聽；它無法重建較長的削波片段。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Effect → Noise Removal and Repair → Clip Fix (Audacity 3 and 4)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取含有待修復之短暫削波峰值的錄音。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → Nyquist → Clip Fix**。在 **Clip Fix** 對話框中，將 **Threshold of Clipping (%)** 設為 `95`，並將 **Reduce amplitude to allow for restored peaks (dB)** 設為 `-9`，然後按 **套用**。門檻值用來辨識平坦峰值，振幅餘裕則為估算出的峰形留出空間。
5. 按 **播放** 聆聽，再按 **停止**。
   *預期結果：* 修復後的峰值較不刺耳；保留變更前，請先與未修改的來源比較。

## 提示

- Clip Fix 最適合修復短暫、輕微削波的峰值；它無法重建持續失真所遺失的細節。
- 保留未修改的副本，以便比較修復後的瞬態；若波形聽起來較不自然，可以復原。
