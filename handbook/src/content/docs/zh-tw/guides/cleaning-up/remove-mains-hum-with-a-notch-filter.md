主要噪音頻率固定在一個頻率上：全球大部分地區為50 Hz，美洲為60 Hz，有時會有一個雙倍頻率的和諧音。缺口濾波器切割一個狹窄的頻段，只保留其他頻率，這比高通濾波器溫和得多，當噪音不夠低時不會被切掉。相同的工具可以消除監控哨音或響應共振，一旦你知道其頻率。

:::note[來自Audacity?]
這是Audacity的**效果 → 等化器和濾波器 → 缺口濾波器**。以下名稱是Soundscaper自己的，有時會不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空項目已準備好。
2. 選擇**檔案 → 匯入音頻**，並選擇帶有噪音的錄音。該檔案會作為片段放在自己的軌道上。
3. 選擇**選擇 → 全選**。
4. 選擇**效果 → Nyquist → 缺口濾波器**。在**缺口濾波器**對話框中，將**頻率 (Hz)**設置為`50`，將**Q (較高值減小寬度)**設置為`4`，然後按**應用**。如果你的主電壓是60 Hz，請使用60。Q值為4是一個狹窄的缺口；如果噪音飄移，請降低它；如果切割聲音可聽到，請提高它。
5. 按**播放**聽取，然後按**停止**。
   *你應該會看到:* 噪音消失了，聲音聽起來一樣。

## 提示

- 不確定頻率嗎？[繪製光譜](/guides/analysis/plot-a-spectrum/)的安靜段落並讀取峰值。
- 噪音通常有一個雙倍頻率的和諧音。如果還有一些剩餘，請在100或120 Hz再次運行過濾器。
