交通、空調、麥克風上的風和桌子被碰撞都存在於聲音下方，在一個小揚聲器無法複製的頻率中。高通濾波器讓切頻點以上的所有內容通過，並減弱其以下的內容，清潔低端而不影響人聲。

:::note[來自Audacity?]
這是Audacity的**效果 → 高通濾波器**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇包含轟鳴聲的錄音。該檔案會以片段的形式出現在其自己的軌道上。
3. 選擇**選擇 → 全部選擇**。
4. 選擇**效果 → 舊版效果 → 經典濾波器**。在**經典濾波器**對話框中，將**濾波器類型**設為**高通**，並將**切頻點**設為`100`，然後按下**套用至選取範圍**。100 Hz對人聲是安全的。提高順序以獲得更陡峭的減弱。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：*低頻轟鳴消失了，人聲聽起來一樣。

## 提示

- 對於音樂，從較低的頻率開始——大約40 Hz——以免低音樂器變薄。
- 軌道效果架中的實時**高通濾波器**在播放時執行相同的任務，無需渲染。
