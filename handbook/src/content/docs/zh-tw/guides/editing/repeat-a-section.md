重複一個兩小節的循環，一個需要在較長的語音旁白下方運行的背景床，以及一個應該持續的聲音效果：重複將選取的內容直接複製給自己，複製的次數由您指定。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 特殊 → 重複**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，然後選擇您要重複的音訊檔案。檔案會以剪貼形式出現在其自己的軌道上。
3. 選擇 **選取 → 全選**。
4. 選擇 **效果 → 特殊 → 重複**。在 **重複** 對話方塊中，設定 **重複次數** 為 `2`，然後按下 **套用至選取範圍**。兩次重複會產生三個連續的副本。
5. 按下 **播放** 聆聽，然後按下 **停止**。
   *您應該會看到：* 段落會不間斷地播放三次。

## 提示

- 為了實現無縫的循環，請確保選取範圍的開始和結束處在靜音或零交叉點上（**選取 → 在零交叉點**）。
- 此效果會改變剪貼的長度，因此同一軌道上其後的任何內容都會被推後。
