標記是時間軸上的筆記：章節的開始處、需要修正的錯誤、優良取樣的開始處。它們不會改變音訊，會隨著專案一起移動，並且可以匯出為標籤檔案供其他工具使用。

:::note[來自 Audacity？]
這是 Audacity 中的 **編輯 → 標籤 → 在選取處加入標籤 (Ctrl+B)**。以下名稱是 Soundscaper 自己的，有時會與 Audacity 不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇 **檔案 → 匯入音訊**，然後選擇您要標記的錄音。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇 **檢視 → 顯示標記**。這會在軌道上方新增一個標記軌道。標記在沒有顯示標記軌道的情況下仍然存在，但顯示標記軌道是您查看和編輯標記的地方。
4. 點擊波形圖中標記應放置的位置，將光標放置在該處。標記會放置在光標所在位置。
5. 打開標記面板 (**檢視 → 面板 → 標記**)，然後按下 **在播放頭處新增標記**。在新的標記上按下 Enter，輸入 `Chorus`，然後再次按下 Enter 來命名它。
   *您應該會看到：* 標記會顯示在軌道上方以及面板的清單中，並帶有您輸入的名稱。

## 提示

- 選取時間範圍後，相同的按鈕會新增一個名為區域而不是單點。
- **檔案 → 匯出其他 → 匯出標籤** 會將標記寫成一個文字檔案，Audacity 和其他編輯器都可以讀取。
