## 本指南的用途 {#what-this-guide-is-for}

Join 會合併同一段錄音中相鄰的部分，讓你重新將它們當成一個片段移動或編輯。來源區域必須相符，接合處也不能有淡入淡出效果。這些步驟會在分割前關閉自動淡入淡出，接著不經算繪就重新合併各部分。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Edit → Clip → Join selected clips (Ctrl+J)**。以下名稱是 Soundscaper 自己的名稱，有時可能不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案便已就緒。
2. 選擇 **編輯 → 偏好設定**，開啟 **編輯** 索引標籤，關閉 **對新片段套用 2 毫秒淡入淡出**，再按 **關閉**。分割點的自動淡入淡出會使 Join 無法使用。
3. 選擇 **檔案 → 匯入**，然後選取要分割並重新合併的錄音。錄音會以獨立音軌上的片段匯入。
4. 在要分割錄音的位置按一下波形，將游標放在該處。
5. 選擇 **編輯 → 音訊片段 → 分割**。
6. 專案現在顯示 2 個片段。
   *你應該會看到：* 兩部分在分割點接合。
7. 按 **Tab** 將焦點移至第一部分，再按 **Enter** 選取。接著將焦點移至第二部分，按 **Shift+Enter** 將它加入選取範圍。必須同時選取兩部分才能合併。
8. 選擇 **編輯 → 音訊片段 → 接合選取的片段**。
9. 專案現在顯示 1 個片段。
   *你應該會看到：* 合併後的片段涵蓋與分割前錄音相同的時間範圍。

## 提示

- 此偏好設定會影響之後的分割。如果你平常會使用此設定，完成後請重新啟用 **對新片段套用 2 毫秒淡入淡出**。
- 如果現有部分無法使用 Join，請檢查是否有間隙、內部淡入淡出或不同的來源素材。關閉此偏好設定不會移除片段上已存在的淡入淡出效果。
- **編輯 → 復原** 會還原分開的部分，方便你繼續個別編輯。
