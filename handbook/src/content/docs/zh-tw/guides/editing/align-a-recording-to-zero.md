## 本指南的用途 {#what-this-guide-is-for}

時間軸上較晚開始的錄音，可以透過對齊指令移回專案開頭。Align start to zero 會移動所選音軌的內容，讓其中最早的片段從零開始。此程序會先將錄音移至較晚的位置，再將它對齊回開頭。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **軌道 → 對齊內容 → 開頭對齊零點**。以下名稱是 Soundscaper 自己的名稱，有時可能不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案便已就緒。
2. 選擇 **檔案 → 匯入**，然後選取要對齊的錄音。錄音會以獨立音軌上的片段匯入。
3. 抓住片段的名稱列，將它拖曳至時間軸上較晚的位置。
4. 現在片段的起點晚於專案開頭。
5. 選擇 **音軌 → 對齊內容 → 開頭對齊零點**。
6. 現在錄音從時間零點開始。
   *你應該會看到：* 片段左邊緣與尺規起點對齊。

## 提示

- 對齊會移動所選音軌的內容。若只想移動這段錄音，請使用只包含這段錄音的音軌。
- **編輯 → 復原** 會還原先前的位置。
