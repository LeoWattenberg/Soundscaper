將一個好的合唱段落複製來取代一個弱的段落，重複一個小節，將一句話移動到結尾：在音頻上使用複製和貼上就像是對文字一樣。選擇一段文字，複製它，將光標放在它應該去的地方，然後貼上。

:::note[來自Audacity？]
這是Audacity的**編輯 → 複製，然後編輯 → 貼上（Ctrl+C，Ctrl+V）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空白項目已準備好。
2. 選擇**檔案 → 匯入音頻**並選擇您要複製的段落的錄音。該檔案作為一個剪輯其自己的軌道上。
3. 在剪輯上方拖動標尺以選擇要複製的段落。
4. 選擇**編輯 → 複製**。
5. 點擊波形圖中複製應去的位置以放置光標。貼上物將放置在光標處；剪輯的結尾是通常的位置。
6. 選擇**編輯 → 貼上 → 貼上**。
7. 項目現在顯示2個剪輯。
   *您應該看到：* 複製的段落是原始剪輯後面的一個新剪輯。

## 提示

- **編輯 → 貼上 → 插入**會將後續的音頻推開而不是將其覆蓋在貼上物上。
- 剪貼板可以在項目標籤之間工作，因此可以從一個項目複製一段文字並貼入另一個項目。
