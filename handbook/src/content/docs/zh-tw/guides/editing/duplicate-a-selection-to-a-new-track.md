複製會將所選內容複製到專案底部的新軌道，並保持原有時間位置。這是並行處理的常見第一步——例如，將大幅壓縮的副本與原始音頻混合、創建僅包含混響的軌道，或加倍人聲。

:::note[來自Audacity？]
這是Audacity中的**編輯 → 複製（Ctrl+D）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇**檔案 → 導入**，並選擇要複製的段落的音頻檔案。檔案將作為片段落在自己的軌道上。
3. 在片段上方規則上拖動以選擇要複製的段落。
4. 選擇**編輯 → 複製**。
5. 專案現在顯示2個片段。
   *你應該會看到：* 專案底部的新軌道中出現只包含所選內容的第二個片段，並與第一個片段在時間上對齊。

## 提示

- 靜音其中一個軌道，以便單獨聽取並調整另一個軌道。
- 當你滿意混合效果時，[將軌道混合下來](/guides/tracks-and-export/mix-tracks-into-one/)。
