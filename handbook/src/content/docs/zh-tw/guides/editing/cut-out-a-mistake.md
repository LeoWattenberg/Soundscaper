最常見的編輯是：假起跑、咳嗽、重錄。選擇你不需要的部分，刪除它，讓剩下的音軌向左移動以填補空隙。

:::note[來自Audacity？]
這是Audacity的**選擇區域，然後編輯 → 刪除（或Ctrl+K）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇包含錯誤的錄音。該檔案會以片段的形式出現在其自己的音軌上。
3. 在片段上方拖動尺規以精確選擇你想要刪除的部分。如果錯誤很短，請使用**視圖 → 縮放 → 放大**進行縮放。
4. 選擇**編輯 → 剪下 → 剪下並按音軌關閉空隙**。選取的部分會被刪除，之後的所有內容都會向左移動，因此不會留下任何靜音。
5. 專案現在顯示2個片段。
   *你應該會看到：* 兩個片段端對端地位於選取的位置，音軌的長度正好減少了選取的部分。播放連接處以檢查它。

## 提示

- **剪下並留下空隙**會刪除聲音但保留時間，這在音軌需要與視頻或其他音軌同步時是正確的。
- 如果你對連接處不滿意？**編輯 → 復原**，調整選取範圍並重新嘗試。
