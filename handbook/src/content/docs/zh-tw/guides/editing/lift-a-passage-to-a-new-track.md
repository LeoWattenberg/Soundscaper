## 本指南的用途 {#what-this-guide-is-for}

若某句話或錄音段落需要獨立調整音量、聲像或效果，其他內容仍可保持不變。Split into new track 會在選取範圍邊緣剪開，只將選取片段移至時間軸相同位置的新音軌。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Edit → Clip → Split New**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取含有待移動片段的錄音。
3. 在剪輯上方的尺規拖曳，選取要移至獨立音軌的片段。
4. 選擇 **編輯 → 音訊片段 → 分割至新音軌**。選取內容會移至新音軌，前後音訊則留在原音軌。
5. 現在專案會顯示 3 個剪輯。
   *預期結果：* 原音軌在選取片段兩側各留下一個剪輯，新音軌則包含中間片段。

## 提示

- 選取片段在新音軌上會保留原本的時間軸位置。
- 若要移動切出的片段而不影響同一音軌上的其他內容，請使用只包含這段錄音的音軌。
