## 本指南的用途 {#what-this-guide-is-for}

人聲和背景音樂，或同一次錄音中的多個部分，通常需要一起移動。Group clips 會連動片段的選取與移動，但不會合併音訊。拖曳群組中的一個成員即可移動整組，同時維持片段之間的時間關係。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Edit → Clip → Group clips**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取要移動的第一段錄音。錄音會以片段形式出現在獨立音軌上。
3. 選擇 **檔案 → 匯入**，然後選取需要保持同步的第二段錄音。錄音會以片段形式出現在獨立音軌上。
4. 按 **Tab** 將焦點移到第一個片段，再按 **Enter** 選取它。接著將焦點移到第二個片段，按 **Shift+Enter** 將它加入選取範圍。
5. 選擇 **編輯 → 音訊片段 → 群組片段**。
6. 拖曳片段的名稱列，將它移到較後面、作為群組起點的位置。透過名稱列拖曳其中一個成員，群組中的其他片段也會跟著移動。
7. 第一段錄音已隨群組移動。
8. 第二段錄音也移動了相同的距離。
   *您應該會看到：* 片段仍位於不同音軌上，彼此的時間關係也保持不變。

## 提示

- 若要重新個別移動或選取各部分，請選取其中一個成員並選擇 **編輯 → 音訊片段 → 取消片段群組**。
- 選擇 **編輯 → 復原** 會還原先前的位置，但不會移除群組。
