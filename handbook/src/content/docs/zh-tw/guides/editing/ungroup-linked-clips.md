## 本指南的用途 {#what-this-guide-is-for}

群組剪輯仍是不同音訊片段，但可以作為一個單位選取並移動。Ungroup 會恢復個別選取剪輯的方式；它不會合併片段，也不會將它們轉成單一剪輯。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Edit → Clip → Ungroup Clips**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取含有待分開剪輯的錄音。
3. 在波形上要將剪輯分成兩段的位置按一下，將游標放在該處。
4. 選擇 **編輯 → 音訊片段 → 分割**。
5. 按一下第一段的名稱列，按住 Shift，再按一下第二段的名稱列，將兩段都選取。
6. 選擇 **編輯 → 音訊片段 → 群組片段**。分組後可以一起移動兩段選取內容，但音訊不會合併。
7. 選擇 **編輯 → 音訊片段 → 取消片段群組**。取消群組後，兩段會恢復為可分別選取的剪輯。
8. 現在專案會顯示 2 個剪輯。
   *預期結果：* 錄音仍是兩個不同剪輯，並在分割點相接。

## 提示

- 若移動時需要保留不同剪輯之間的相對時間，分組就很有用。
- 若要將相鄰片段變成一個剪輯，請選擇 **編輯 → 音訊片段 → 接合選取的片段**。
