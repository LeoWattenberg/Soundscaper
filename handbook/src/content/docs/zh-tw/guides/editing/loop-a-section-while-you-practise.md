學習一個樂句、檢查編輯點、試聽效果設定：當段落不斷重複播放而不需要你重新開始時，一切都會更快。將循環區域設置為選取範圍，播放會停留在循環區域內，直到你關閉循環。

:::note[來自Audacity？]
這是Audacity的**運輸 → 循環 → 將循環設置為選取範圍**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空項目已準備就緒。
2. 選擇**檔案 → 導入音頻**，並選擇要練習的錄音。該文件作為一個剪輯其自己的軌道上。
3. 在剪輯上方規則中拖動以選取要重複的段落。
4. 選擇**選取 → 循環區域 → 將循環設置為選取範圍**。
5. 項目現在顯示**循環選取範圍**按鈕已點亮。
   *你應該看到：* 運輸欄中的循環按鈕點亮，循環區域顯示在規則上方。
6. 按下**播放**來聆聽，然後按**停止**。
   *你應該看到：* 播放會在選定的段落中循環。

## 提示

- 按下**L**或運輸欄中的循環按鈕來開啟或關閉循環，而不會丟失區域。
- 在規則中拖動循環區域的兩端來調整它。
