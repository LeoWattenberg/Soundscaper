在預設縮放下，整首歌曲會符合螢幕，而一個單詞的寬度只有幾個像素。放大字體可以讓您將光標精確地放置在節拍上或兩個單詞之間；放大字體至選取範圍僅會顯示您正在處理的段落。

:::note[來自Audacity？]
這是Audacity的**檢視 → 縮放（Ctrl+1、Ctrl+2、Ctrl+3）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，然後選擇您要編輯的錄音。檔案會以片段的形式放置在單獨的軌道上。
3. 選擇**檢視 → 縮放 → 放大字體**。每一步都會使一秒鐘的寬度加倍。Ctrl+1具有相同的功能。
4. 選擇**檢視 → 縮放 → 放大字體**。
5. 在片段上方的特定區域拖動以選取您要處理的段落。
6. 選擇**檢視 → 縮放 → 放大字體至選取範圍**。選取的範圍現在會填滿時間軸。
7. 選擇**檢視 → 縮放 → 還原縮放**。Ctrl+2會恢復預設縮放。

## 提示

- 使用Ctrl和滑鼠滾輪可以在指針周圍進行縮放，這是快速進入特定位置的最快方式。
- 縮放不會改變專案中的任何內容；它只是您的視圖。
