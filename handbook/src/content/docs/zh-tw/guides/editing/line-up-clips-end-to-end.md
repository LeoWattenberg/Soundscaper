## 本指南的用途 {#what-this-guide-is-for}

獨立錄製的兩個版本會各自落在不同的軌道上，兩者都從零開始。要讓一個版本接著另一個播放，第二個版本必須移動到第一個版本的結束位置。將結尾對齊會為每個選定的剪輯片段進行此算術運算，並按照軌道順序排列。

:::note[來自Audacity？]
這與Audacity的**軌道 → 對齊軌道 → 將結尾對齊**功能相同。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入**，然後選擇第一個版本。檔案會以剪輯片段的形式落在自己的軌道上。
3. 選擇**檔案 → 匯入**，然後選擇第二個版本。檔案會以剪輯片段的形式落在自己的軌道上。
4. 點擊第一個剪輯片段的名稱欄，然後按住Shift鍵點擊第二個剪輯片段的名稱欄，這樣兩個剪輯片段都會被選中。
5. 選擇**軌道 → 對齊內容 → 將結尾對齊**。
6. 現在第二個剪輯片段會從第一個剪輯片段結束的地方開始。
   *您應該會看到：* 剪輯片段會一個接一個地播放，沒有重疊，也沒有間隙。

## 提示

- **對齊一起**執行相反的操作：它會將選定的剪輯片段移動到同時開始。
- 拖動片段的名稱欄可手動放置；按住 Shift 會同時移動該軌道上的所有片段。
