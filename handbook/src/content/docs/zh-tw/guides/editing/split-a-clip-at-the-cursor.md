分割並不會刪除任何內容。它將一個剪輯分成兩個，並排放置，這樣你可以將其中一部分拖動到其他地方、刪除它，或僅對它應用效果。最快的方法是使用分割工具：當它啟用時，每點擊剪輯一次，就會在此處切割。

:::note[來自Audacity？]
這是Audacity的**編輯 → 剪輯邊界 → 分割（Ctrl+I）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇你想要分割的錄音。該檔案會以剪輯的形式出現在其自己的軌道上。
3. 按下工具列中的**分割工具**按鈕。指針現在切割而不是選擇。按下**S**從鍵盤切換工具。
4. 點擊波形圖形中你想要切割的位置，以將光標放置在此處。當分割工具啟用時，點擊會在此處切割剪輯。
5. 專案現在顯示2個剪輯。
   *你應該會看到：* 現在有兩個剪輯位於原本的一個剪輯位置。
6. 按下工具列中的**分割工具**按鈕。再次按下以返回到正常的指針。

## 提示

- 要將播放頭位置分割，請選擇剪輯並選擇**編輯 → 音訊剪輯 → 分割**；如果選擇了時間範圍，它會在範圍的兩端進行分割。
- 選擇兩個半並選擇**編輯 → 音訊剪輯 → 合併選取的剪輯**，以將它們重新合併成一個剪輯。
