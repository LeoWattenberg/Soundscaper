反轉效果會將時間選擇倒轉。這是設計音效的工具——反轉的鈸聲、漸長的預回聲——偶爾也用於檢查房間迴響尾部是否隱藏了任何東西。

:::note[來自Audacity？]
這是Audacity的**效果 → 特殊 → 反轉**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，並選擇要反轉的錄音。檔案會以片段的形式出現在單獨的軌道上。
3. 選擇**選擇 → 全選**。
4. 選擇**效果 → 特殊 → 反轉**。效果會立即套用到選擇的區域。
5. 按下**播放**聆聽，然後按下**停止**。
   *你應該會看到：* 錄音會倒退播放。

## 提示

- 反轉兩次，你就會回到起點，樣本對樣本。
- 反轉片段的開頭部分，可以創造出一個漸長的前奏，引導進入片段。
