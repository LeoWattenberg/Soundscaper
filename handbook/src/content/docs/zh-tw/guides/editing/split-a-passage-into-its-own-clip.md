## 本指南的用途 {#what-this-guide-is-for}

您可以將一個字、一段樂句或一次補錄拆成獨立片段，而不改變錄音的總長度。選取時間範圍後，Split 會在選取範圍的兩端進行切分。接著，您可以單獨移動或處理中間的片段。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Edit → Clip → Split (Ctrl+I)**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取包含目標片段的錄音。錄音會以片段形式出現在獨立音軌上。
3. 在片段上方的尺規中拖曳，選取要分開的部分。選取範圍前後都保留一些音訊，確保兩端界線位於片段內。
4. 選擇 **編輯 → 音訊片段 → 分割**。
5. 現在專案中會顯示 3 個片段。
   *您應該會看到：* 選取的部分成為前後音訊之間的獨立片段。三個部分都保留在時間軸上的原始位置。

## 提示

- 若只需切一刀，請使用[在游標位置分割片段](/guides/editing/split-a-clip-at-the-cursor/)，而不要選取一段範圍。
- 若需要調整任一界線，選擇 **編輯 → 復原** 即可還原原始片段。
- 若要刪除周圍的音訊，請[只保留需要的部分](/guides/editing/keep-only-a-selection/)。
