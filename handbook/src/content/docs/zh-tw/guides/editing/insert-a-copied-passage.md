## 本指南的用途 {#what-this-guide-is-for}

Insert 會為複製的音訊騰出空間，而不是覆蓋現有聲音。目標音軌上後續的音訊會依照複製片段的長度向右移動。您可以用它在錄音中間加入重複的樂句或補充的一句話。

:::note[從 Audacity 轉來？]
這相當於 Audacity 中的 **Edit → Copy, then Edit → Paste**。下方名稱是 Soundscaper 使用的名稱，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後，新的空白專案就已準備就緒。
2. 選擇 **檔案 → 匯入**，然後選取包含要複製片段的錄音。錄音會以片段形式出現在獨立音軌上。
3. 在片段上方的尺規中拖曳，選取要插入其他位置的部分。
4. 選擇 **編輯 → 複製**。
5. 在目標片段中，按一下波形上副本應開始的位置，將游標放在那裡。按一下會清除時間範圍選取，並設定插入點。
6. 選擇 **編輯 → 貼上 → 插入**。
7. 現在專案中會顯示 3 個片段。
   *您應該會看到：* 插入的部分位於原始片段的兩段音訊之間。後面的部分向右移動，前面的部分則留在原位。

## 提示

- Insert 會移動目標音軌上後續的音訊。若需要維持所有音軌的時間同步，**編輯 → 貼上 → 插入並保持同步** 會在所有音軌上騰出空間。
- 選擇 **編輯 → 復原** 會移除插入內容，並將後續音訊還原到原本的位置。
