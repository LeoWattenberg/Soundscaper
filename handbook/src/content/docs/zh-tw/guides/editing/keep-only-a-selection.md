## 本指南的用途 {#what-this-guide-is-for}

當一個長時間的錄音中包含一個好的段落時，選擇段落並丟棄其餘部分比分段刪除周圍的內容更快。修剪功能保留選取的段落並移除其兩邊的聲音。

:::note[來自Audacity？]
這相當於Audacity的**編輯 → 移除特殊 → 修剪音訊**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入**，並選擇包含所需段落的錄音檔案。該檔案會以片段的形式出現在其專屬的軌道上。
3. 在片段上方規則上拖曳以選取您想要保留的段落。段落之外的所有內容都將被刪除。
4. 選擇**編輯 → 移除特殊 → 修剪選取範圍之外的音訊**。
5. 專案現在顯示1個片段。
   *您應該會看到：* 只有選取的段落保留在軌道上。

## 提示

- 修剪後的片段仍保留在時間軸上的原位置。如果您希望它從零開始，請將其拖動到時間軸的開始。
- 修剪與其他編輯操作相同；**編輯 → 還原**可以恢復選取範圍之外的內容。
