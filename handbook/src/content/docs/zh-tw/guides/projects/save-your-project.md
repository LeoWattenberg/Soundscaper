專案不僅僅是音頻：它包括軌道、剪輯、效果、標記和歷史記錄。儲存將所有這些儲存在瀏覽器本機的專案庫中，可以在檔案菜單中重新打開。Soundscaper在操作過程中也會自動儲存，所以這主要是為了確保安全。

:::note[來自Audacity？]
這相當於Audacity中的**檔案 → 儲存專案**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇**檔案 → 導入**並選擇要編輯的檔案。檔案將作為剪輯添加到單獨的軌道上。
3. 選擇**檔案 → 儲存專案**。狀態欄中的儲存指示器顯示專案已儲存。

## 提示

- 要將專案移動到另一台計算機或在瀏覽器外保留一份副本，請參閱[在計算機之間移動專案](/guides/projects/move-a-project-between-computers/)。
- 音頻導出是一個聽複製品，不是專案。如果可能需要再次編輯，請保留專案。
