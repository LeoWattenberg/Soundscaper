專案庫存在於單一瀏覽器中的一台電腦上。若要將專案帶到其他地方——另一台機器、同事、備份磁碟——請將其匯出為專案檔案。`.sscape` 檔案包含音訊和所有編輯，並在任何 Soundscaper 中開啟。

:::note[來自 Audacity？]
這是 Audacity 的 **檔案 → 儲存專案 → 備份專案，然後檔案 → 開啟**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 開啟 Soundscaper。一旦編輯器載入，新的空專案就會準備好。
2. 選擇 **檔案 → 匯入音訊** 並選擇專案材料。檔案會以片段的形式出現在其自己的軌道上。
3. 選擇 **檔案 → 匯出專案檔案 (.sscape)**。整個專案會以單一 `.sscape` 檔案下載。將檔案保存在安全的地方；它是完整的專案。
4. 選擇 **檔案 → 開啟 Scape 專案檔案 (.sscape)** 並選擇檔案。在還沒有該專案的電腦上直接開啟；在這裡，庫中已經包含該專案，Soundscaper 會提供 **以唯讀副本開啟** — 按下它。
   *您應該會看到：* 專案以其軌道和片段正確地開啟，與匯出時完全相同。

## 提示

- 唯讀副本在從檔案選單儲存為自己的專案之前無法編輯。
- 該檔案是包含音訊的 ZIP 壓縮檔；請勿手動解壓縮。
