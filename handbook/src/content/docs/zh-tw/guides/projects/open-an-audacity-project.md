在Audacity 3 (.aup3) 和Audacity 4 (.aup4) 中製作的專案可以直接開啟。音軌、剪輯、名稱和位置都會被保留；Soundscaper不支援的效果會列出，以便您了解需要檢查的內容。原始檔案不會被更改。

:::note[來自Audacity？]
這是Audacity的**檔案 → 開啟**。以下名稱是Soundscaper自己的，有時可能會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → Audacity專案 → 開啟Audacity專案** (.aup3, .aup4)，然後選擇專案。其音軌和剪輯會以在Audacity中的狀態出現。
3. 專案現在會顯示一個名為**音訊 1**的剪輯和一個名為**固定音軌**的音軌。
   *您應該會看到：* 來自Audacity專案的音軌和剪輯，以及它們的名稱。

## 提示

- 舊式`.aup`專案需要其`_data`資料夾在旁邊；當被要求時，請選擇兩者。
- **檔案 → Audacity專案 → 匯出AUP4**是反向操作，用於將專案交還給Audacity。
