在48 kHz的專案中，以44.1 kHz錄製的片段仍會正確播放——Soundscaper會即時進行轉換——但如果傳遞必須是特定速率，或在預期速率的效果之前，您可以將片段本身進行轉換。重新取樣會以新的速率重新計算每個樣本，並保持時間精確。

:::note[來自Audacity？]
這與Audacity的**軌跡→重新取樣**相同。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案→匯入音頻**，並選擇錯誤速率的片段。該檔案會作為片段其自己的軌跡上。
3. 從其名稱欄上的**片段選單**按鈕打開片段的選單，並選擇**片段屬性**。按下**重新取樣**，將速率設置為`44100`，然後再次按下**重新取樣**。片段的屬性會顯示其當前速率；44100 Hz是CD標準。
4. 按下**播放**進行聆聽，然後按下**停止**。
   *您應該會看到：*片段聽起來和之前一模一樣；只有其儲存速率發生了變化。

## 提示

- 重新取樣是一種編輯，可以撤銷。
- 降低速率會捨棄最高頻率；提高速率不會添加任何內容，但無害。
