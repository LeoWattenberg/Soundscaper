混合工程師、視頻編輯師或在另一項計劃中的合作者通常需要部分音軌，而非混合音軌。幹音軌匯出會將每條音軌渲染到單獨的檔案中，所有檔案長度相同，並對齊專案開始，然後將它們打包到一個檔案中。

:::note[來自Audacity？]
這等於Audacity的**檔案 → 匯出音頻 → 按音軌分開匯出多個**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。新的空白專案會在編輯器加載後立即準備好。
2. 選擇**檔案 → 匯入音頻**並選擇第一條音軌。檔案會以剪貼形式落在自己的音軌上。
3. 選擇**檔案 → 匯入音頻**並選擇第二條音軌。檔案會以剪貼形式落在自己的音軌上。
4. 選擇**檔案 → 匯出音頻**，將**格式**設置為**WAV**，將**輸出**設置為**單獨幹音軌（按音軌分割）**，然後按**匯出**。檔案會在渲染完成後立即下載，並且其鏈接會保留在對話框中。每條音軌都會成為WAV格式，保存在ZIP檔案中，並且被修剪到相同長度，以便在其他地方匯入時對齊。

## 提示

- 靜音和獨奏不會影響幹音軌；每條音軌都會被渲染。
- 在匯出前為音軌命名 — 幹音軌檔案會從它們獲得名稱。
