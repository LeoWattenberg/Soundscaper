播客和串流平台會以 LUFS 來測量音量，這會根據節目感覺上的音量，而非其峰值高度。音量正規化會測量整個選取範圍並將其調整至目標音量，因此您發布的每一個集都會處於相同的音量水平。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 音量與壓縮 → 音量正規化**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇 **檔案 → 匯入音訊**，然後選擇安靜的錄音。該檔案會以片段的形式出現在其獨立的軌道上。
3. 選擇 **選取 → 全選**。
4. 選擇 **效果 → 音量與壓縮 → 音量正規化**。在 **音量正規化** 對話方塊中，將 **目標音量** 設定為 `-16`，然後按下 **套用至選取範圍**。對於立體聲播客，-16 LUFS 是常見目標；對於單聲道，常使用 -19 LUFS。請檢查您平台的指南。
5. 按下 **播放** 聆聽，然後 **停止**。
   *您應該會看到：* 錄音以舒適且一致的音量播放。

## 提示

- 音量正規化可能會將非常動態的材料的峰值推至全音量以上。請在其後使用限制器或峰值正規化至 -1 dB，如果波形觸及頂部。
- 在編輯和其他效果完成後，於最終混音上執行它，以便測量反映聽眾將聽到的內容。
