淡入淡出是避免片段開頭的點擊聲或結尾的突然停止最簡單的方法。淡入會將選取的片段從靜音漸漸提升至全音量；淡出則會將音量漸漸降低。選取的片段長度即為淡入淡出的持續時間。

:::note[來自Audacity？]
這是Audacity的**效果 → 淡入淡出 → 淡入和淡出**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，並選擇開頭或結尾有突兀聲音的錄音。該檔案會以片段的形式放置在單獨的軌道上。
3. 在片段上方規則上拖曳以選取您想要淡入的開頭部分。
4. 選擇**效果 → 淡入淡出 → 淡入**。效果會立即套用到選取的片段。
5. 在片段上方規則上拖曳以選取相同的結尾部分。
6. 選擇**效果 → 淡入淡出 → 淡出**。效果會立即套用到選取的片段。
7. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：* 錄音會漸漸響起並漸漸消退，而不是以突兀的方式開始和結束。

## 提示

- 淡入淡出是線性的。若要結尾的淡出更快，請選取較短的範圍。
- 淡入淡出是編輯，因此**編輯 → 復原**可以像其他操作一樣反轉它們。
