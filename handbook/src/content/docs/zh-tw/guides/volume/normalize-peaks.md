標準化會測量選取範圍內的最高峰值，並將所有內容調整至該峰值正確到達您指定的位置。這是通常在匯出前使用的最後一步：檔案會使用其完整範圍，而不會有任何截斷。它還會消除任何直流偏移，即某些聲音卡添加的輕微垂直位移。

:::note[來自Audacity？]
這相當於Audacity的**效果 → 音量和壓縮 → 標準化**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇較安靜的錄音。該檔案會以剪貼的形式出現在其獨立的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 音量和壓縮 → 標準化**。在**標準化**對話方塊中，將**峰值音量**設定為`-3`，然後按下**套用至選取範圍**。減去三分貝會為編碼器留下一些餘地，如果您稍後要匯出為MP3，這會很有用。
5. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：* 現在最高峰值剛好在全音量以下。

## 提示

- 標準化是根據峰值，而不是根據錄音的聽感音量來進行的。兩個標準化的檔案仍然可能聽起來非常不同；如需此目的，請見[為播客標準化音量](/guides/volume/normalize-loudness-for-podcasts/)。
- 除非您啟用**獨立標準化立體聲通道**，否則立體聲通道會一起標準化，這可能會移動立體聲圖像。
