Audacity 3 提供了兩種壓縮器：現代壓縮器具有膝部、預覽和實時計量，以及原始的較簡單版本，稱為「傳統壓縮器」。傳統設計具有低噪聲地板，當音量低於此值時，壓縮器停止工作，因此不會在靜音期間放大背景噪聲。它還會將結果提升至 0 dB。Audacity 4 已刪除此功能；Soundscaper 保留此功能，以適應習慣此功能的專案和聽眾。

:::note[來自 Audacity？]
這是 Audacity 的 **效果 → 音量和壓縮 → 傳統壓縮器 (Audacity 3; Audacity 4 僅具有新壓縮器)**。以下名稱是 Soundscaper 自己的名稱，有時會與 Audacity 不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入時，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，然後選擇要平衡的音訊記錄。該檔案會以剪貼形式置於其自己的軌道上。
3. 選擇 **選取 → 全選**。
4. 選擇 **效果 → 傳統效果 → 傳統壓縮器**。在「傳統壓縮器」對話方塊中，將「門限」設定為 `-20`，將「比例」設定為 `4`，然後按下 **套用至選取範圍**。任何高於 -20 dB 的音量都會根據該比例降低，此處為 4:1。接著，補償增益會將整個結果提升至峰值 0 dB。
5. 按下 **播放** 聆聽，然後按下 **停止**。
   *您應該會看到：* 響亮和安靜的段落更接近，整個取樣更響亮。

## 提示

- 如果壓縮器放大了靜音期間的嘶嘶聲，請提高「噪聲地板」; 壓縮器會忽略低於此值的任何聲音。
- 如需在設定時可聽到壓縮器工作的壓縮器，請使用現代壓縮器：[使用壓縮器平衡音量](/guides/volume/even-out-volume-with-a-compressor/)。
