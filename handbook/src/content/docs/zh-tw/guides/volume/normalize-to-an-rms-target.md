## 本指南的用途 {#what-this-guide-is-for}

RMS 正規化會將選取內容調整至指定的平均訊號音量，而不是峰值上限。這適合用來統一多段錄音的音量；若來源動態範圍很大，請事後檢查峰值。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Effect → Volume and Compression → Loudness Normalization**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取要設定平均音量的錄音。
3. 選擇 **選擇 → 全部**。
4. 選擇 **效果器 → 音量與壓縮 → 響度正規化**。在 **響度正規化** 對話框中，將 **RMS** 設為 **正規化**，將 **目標 RMS** 設為 `-20`，並關閉 **個別正規化立體聲聲道**，然後按 **套用至選取範圍**。連動調整立體聲可保留左右平衡，同時以 −20 dB RMS 為目標。
5. 按 **播放** 聆聽，再按 **停止**。
   *預期結果：* 錄音會調整至接近 −20 dB RMS 目標，並保留立體聲平衡。

## 提示

- 若要以相近平均音量比較多段錄音，請使用相同 RMS 目標。
- RMS 正規化不保證峰值上限；請檢查削波並視需要預留音量餘裕。
