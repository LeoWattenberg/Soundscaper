限制器是一種具有非常高壓縮比的壓縮器：在門檻以下，它什麼都不做；在門檻以上，則什麼都無法通過。它是捕捉輸出前的一些突發峰值，或提高混音整體水平而不使峰值剪切的工具。

:::note[來自Audacity？]
這是Audacity的**效果 → 音量與壓縮 → 限制器**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇**檔案 → 匯入音訊**，並選擇具有突發峰值的錄音。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 音量與壓縮 → 限制器 (Audacity)**。在**限制器 (Audacity)** 對話方塊中，將**門檻**設置為`-6`，然後按下**套用至選取範圍**。沒有任何內容會超過-6 dB。然後，補償目標會將結果提升，使上限接近滿量表。
5. 按下**播放**來聆聽，然後按下**停止**。
   *您應該會看到：* 最響亮的時刻被壓制住；其他部分保持不變。

## 提示

- 將限制器用於峰值，將[壓縮器](/guides/volume/even-out-volume-with-a-compressor/)用於整體均衡；它們不是相同的任務。
- 嚴重的限制會使一切聽起來很響亮且平坦。如果您需要超過幾個分貝，那麼混音本身可能太熱了。
