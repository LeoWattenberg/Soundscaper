使用增益過低錄製的音訊，聲音會很小聲但通常很乾淨。放大功能會以分貝為單位，將音訊中的所有內容提升相同的程度，因此錄製時的平衡狀態保持不變。如果不啟用剪切，效果將不會將峰值推過滿格。

:::note[來自Audacity？]
這是Audacity的**效果 → 音量與壓縮 → 放大**。以下名稱是Soundscaper自己的，有時會與Audacity不同。
:::

## 步驟

1. 打開Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇**檔案 → 匯入音訊**，然後選擇小聲錄製的音訊檔案。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇**選取 → 全選**。
4. 選擇**效果 → 音量與壓縮 → 放大**。在**放大**對話方塊中，將**增益**設定為`6`，然後按下**套用至選取範圍**。六分貝大約會將音量放大兩倍。**允許剪切**保持關閉，因此效果不會使峰值失真。
5. 按下**播放**聆聽，然後按下**停止**。
   *您應該會看到：* 音訊明顯變大聲，波形也變高了。

## 提示

- 如果結果仍然太小聲，請再次執行放大功能；增益會累積。
- 如果要將峰值提升到確切的等級而不是添加固定數量，請使用[正規化](/guides/volume/normalize-peaks/)。
