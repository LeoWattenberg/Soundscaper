錄制音量過大會使聲音變平，並出現失真。這種損壞很容易聽出，但在長時間錄音中很難用肉眼發現。Find Clipping 會掃描選定區域，並列出所有處於滿量程的樣本段，這樣您可以決定是否修復、重做或對每個段接受現狀。

:::note[來自 Audacity？]
這是 Audacity 的 **分析 → 查找失真**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇 **檔案 → 導入**，並選擇要檢查的錄音。檔案會作為片段落在單獨的軌道上。
3. 選擇 **選擇 → 全選**。
4. 選擇 **分析 → 查找失真**。**查找失真**面板會打開。
  *您應該會看到：* 失真段列表，或者如果未找到任何失真段，則會顯示一條提示。

## 提示

- 降低失真錄音的音量並不能修復它；被壓平的峰值仍會保持壓平。**效果 → 噪聲去除和修復 → 修復**可以重建非常短的失真段。
- 為了避免下一次出現失真，請將峰值設置在約 −12 dB 左右，並在之後提高音量。
