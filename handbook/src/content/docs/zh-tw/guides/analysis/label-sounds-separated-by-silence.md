## 本指南的用途 {#what-this-guide-is-for}

Label Sounds 會掃描片段，尋找由靜音分隔的聲音，並在每個偵測到的聲音周圍放置標籤。它可標記口語句子、獨立敲擊聲或其他明確事件，方便後續編輯。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Analyze → Label Sounds (Nyquist)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取聲音之間有停頓的錄音。
3. 選擇 **選擇 → 全部**。
4. 選擇 **分析 → Nyquist → Label Sounds**。在 **Label Sounds** 對話框中，將 **Threshold level (dB)** 設為 `-30`、**Minimum silence duration** 設為 `0.5`，並將 **Minimum label interval** 設為 `0.5`，然後按 **套用**。對話框會顯示結果；按 **關閉** 關閉。半秒的靜音能讓分析器分開句子。門檻值決定聲音必須多大聲才會計入。
5. 現在專案會顯示名為 **Label Sounds** 的音軌。
   *預期結果：* Label Sounds 音軌會出現，並在偵測到的句子周圍標上標籤。

## 提示

- 降低 **Threshold level (dB)** 可納入較小聲的音訊；提高則可忽略背景噪音。
- 若短暫停頓不應將一句話拆成多個標籤，請提高 **Minimum silence duration**。
