## 本指南的用途 {#what-this-guide-is-for}

在正規化或匯出之前，先了解目前的音量會很有幫助。「測量響度」會像串流平台和廣播機構一樣分析選取範圍：測量 LUFS 綜合響度、響度範圍和真峰值，讓你能與目標值比較，而不是只憑電平表猜測。

:::note[來自 Audacity？]
這是 Audacity 的 **分析 → 測量 RMS，或音量標準化的測量**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案就會準備好。
2. 選擇 **檔案 → 匯入**，然後選擇您要測量的混音。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇 **選取 → 全部選取**。
4. 選擇**分析 → 測量響度**。系統會開啟**交付報告**對話方塊，其中包含選取範圍報告。
  *您應該會看到：* 選取的整合音量、音量範圍和真實峰值。

## 提示

- 播客平台通常要求 −16 LUFS 立體聲或 −19 LUFS 單聲道，且真實峰值低於 −1 dBTP；請檢查平台本身的指南。
- 如果數字與目標相差甚遠，請執行 [音量標準化](/guides/volume/normalize-loudness-for-podcasts/) 並再次測量。
