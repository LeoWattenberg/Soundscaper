::語音與背景噪音之間的音量差異::

語音比房間後面的噪音只大一點是很難跟上的，可訪問性指南給它定了一個數值：語音應至少比背景高20 dB。對比分析器測量一段背景和一小段語音，報告兩者之間的差異，並判斷是否符合該建議。這是Audacity 3中用於WCAG檢查的分析器，而Audacity 4中不包含它。

:::注意[來自Audacity？]
這是Audacity的 **分析 → 對比（Audacity 3；Audacity 4沒有對比分析器）**。以下名稱是Soundscaper自己的，有時會有所不同。
:::

## 步驟

1. 打開Soundscaper。編輯器加載後，一個新的空專案已準備就緒。
2. 選擇 **檔案 → 導入**，並選擇包含語音和背景噪音的錄音。該檔案作為片段落在自己的軌道上。
3. 在片段上方拖動尺子以選擇一段沒有人說話的背景。背景測量應僅包含語音需要競爭的噪音。
4. 選擇 **分析 → 對比**。**對比**面板打開。
5. 在**對比**面板中，按下**測量背景**。面板將選定的水平作為背景保持。
6. 在片段上方拖動尺子以選擇一段語音。最好選擇普通語音，而不是最響亮的詞，因為整個段落會被平均。
7. 在**對比**面板中，按下**測量前景**。面板報告前景水平、背景水平以及兩者之間的差異。
   *你應該看到：* 前景和背景水平、它們之間的dB差異，以及差異是否符合推薦的20dB。

## 提示

- 如果差異不足，[減少背景噪音](/guides/cleaning-up/remove-background-noise/) 或 [使用壓縮器均衡語音](/guides/volume/even-out-volume-with-a-compressor/)，然後再次測量。
- 測量是RMS平均值，因此單個響亮的音節無法拯救一個安靜的錄音。
