波形顯示聲音在時間上的音量變化；頻譜則顯示聲音由哪些頻率組成。繪製問題段落的頻譜是最快的方法，可以找到 50 或 60 Hz 的嗡嗡聲、來自顯示器的哨聲，或房間共振的頻率——然後知道該如何調整均衡器。

:::note[來自 Audacity？]
這是 Audacity 的 **分析 → 繪製頻譜**。以下名稱是 Soundscaper 自己的，有時會有所不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，並選擇包含問題的錄音。該檔案會以片段的形式放置在單獨的軌道上。
3. 選擇 **選取 → 全選**。
4. 選擇 **分析 → 繪製頻譜**。**繪製頻譜** 面板會打開。
   *您應該會看到：* 選取範圍內音量對頻率的圖表。

## 提示

- 僅選取問題段落——例如，單獨的嗡嗡聲段落——以免頻譜被周圍的音樂或人聲所主導。
- 高的窄尖峰是音調；寬平頂是噪音。音調適用於窄頻均衡器切割，噪音適用於 [噪音減少](/guides/cleaning-up/remove-background-noise/)。
