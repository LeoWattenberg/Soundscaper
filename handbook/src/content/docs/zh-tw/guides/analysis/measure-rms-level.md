## 本指南的用途 {#what-this-guide-is-for}

RMS 是訊號音量隨時間變化的平均測量值。使用 Measure RMS 分析器比較不同片段，或在調整前檢查片段音量。

:::note[從 Audacity 轉來？]
Audacity 中對應功能為 **Analyze → Measure RMS (Nyquist)**。以下名稱是 Soundscaper 的用語，有時會不同。
:::

## 步驟

1. 開啟 Soundscaper。編輯器載入後即可使用新的空白專案。
2. 選擇 **檔案 → 匯入**，並選取要測量平均音量的片段。
3. 選擇 **選擇 → 全部**。
4. 選擇 **分析 → Nyquist → Measure RMS**。在 **Measure RMS** 對話框中按 **套用**。對話框會顯示測量結果；按 **關閉** 關閉。
   *預期結果：* 報告會以 dB 顯示各聲道以及整體立體聲訊號的 RMS 音量。

## 提示

- RMS 描述平均音量；若要將最高取樣值設為目標，請使用 [peak normalization](/guides/volume/normalize-peaks/)。
- 只選取要比較的片段，避免無關音訊影響測量結果。
