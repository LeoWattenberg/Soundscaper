Beat Finder 是 Nyquist 分析器中內建的一個。它會聆聽突然上升的水平，並寫入標籤，這是快速標記循環的節拍或切割鼓聲前的快速方式。

:::note[來自 Audacity？]
這是 Audacity 的 **分析 → Beat Finder**。以下名稱是 Soundscaper 自己的，有時會不同。
:::

## 步驟

1. 打開 Soundscaper。編輯器載入後，新的空白專案已準備就緒。
2. 選擇 **檔案 → 匯入音訊**，並選擇您要標記的錄音。檔案會以片段的形式出現在其自己的軌道上。
3. 選擇 **選取 → 全部選取**。
4. 選擇 **分析 → Nyquist → Beat Finder**。在 **Beat Finder** 對話框中，將 **門限百分比** 設置為 `60`，然後按 **應用**。對話框會報告它找到的內容；按 **關閉** 將其關閉。較低的百分比也會找到較安靜的節拍；如果標記過多，請提高它。
5. 專案現在顯示一個名為 **Beat Finder** 的軌道。
   *您應該會看到：* 一個新的標籤軌道名為 Beat Finder，在音訊下方，每個節拍都有一個標籤。

## 提示

- 標籤會出現在音訊下方的新的標籤軌道上。重命名或刪除分析器標記錯誤的任何標籤。
- **分析 → Nyquist → 標記聲音** 執行類似的任務，用於整個由靜音分隔的聲音。
