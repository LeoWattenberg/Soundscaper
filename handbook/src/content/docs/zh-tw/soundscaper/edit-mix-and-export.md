## 排列剪輯

在選擇編輯命令之前，選擇剪輯或時間範圍。分割在播放頭處創建一個編輯邊界。保留間隙和漣漪變體確定後續材料是否保持原位或移動以關閉刪除區域。

使用軌道檔案夾、剪輯組和專案二進制檔案來整理大型專案。

### 調整剪輯淡入淡出 {#clip-fades}

選擇音頻剪輯以顯示其波形頂部的兩個小三角形，直接位於剪輯標題下方。
將左三角形向內拖動以創建淡入效果，或將右三角形向內拖動以創建淡出效果。波形在拖動時發生變化，淡入淡出曲線以上的區域變暗。三角形跟隨淡入淡出邊界；將其中一個拖回其角落會刪除該淡入淡出效果。即使選擇了多個剪輯，也只有您拖動的剪輯會被更改。

當您取消選擇剪輯時，句柄會消失，但淡入淡出的波形和著色保持不變。這些淡入淡出效果保留原始音頻，並在儲存和重新打開專案後仍然可調整。釋放以提交淡入淡出效果，或在拖動時按 **Esc** 鍵以取消。**撤銷** 操作會逆轉一次完整的拖動。播放和導出使用已提交的淡入淡出設置。

在選擇的剪輯處於焦點時，按 **Tab** 鍵訪問其淡入淡出句柄。方向鍵將持續時間調整為 10 毫秒，或在 **Shift** 鍵下調整為 100 毫秒。**Home** 鍵刪除淡入淡出效果；**End** 鍵將其擴展到整個剪輯。對於數字輸入，請選擇 **編輯 → 音頻剪輯 → 剪輯屬性** 並使用 **淡入淡出**。

### 編輯片段來源 {#clip-source-properties}

選擇**編輯 → 音訊片段 → 片段屬性**以開啟來源編輯器。完整錄音會顯示在片段後方。拖曳片段邊緣可變更來源起點與長度，同時讓片段在專案時間軸上的起點維持不變。**正規化**面板包含片段增益以及峰值與響度操作。

開啟**音高與速度**並勾選**連結音高與速度**，即可同時變更速度與音高。速度比為`1`且音高變更為`0%`時，聲音不會改變。比率`2`會以兩倍速度、提高一個八度播放；`0.5`則以半速、降低一個八度播放。編輯其中一個連結控制項會更新另一個。取消連結會恢復個別設定音高，同時保留目前的速度比。

按住**Ctrl**並點擊波形，可新增連結至該來源取樣的伸展標記。拖曳標記會變更兩側的時間，覆蓋圖會顯示兩種播放速度。片段控制項仍各自套用於個別片段。選取來源音訊並套用效果時，所有使用該來源的片段都會更新。

### 在試算表中編輯片段 {#clip-spreadsheet}

選擇**檢視 → 面板 → 片段試算表**可檢視專案中的所有片段。面板會在時間軸下方開啟。使用面板選單可將它移至其他停駐區、設為浮動視窗或關閉。大小和位置會與工作區一同儲存。每列會顯示音軌、時間軸位置、來源檔案、來源偏移、長度、音高、速度、增益、淡入淡出與播放選項。時間以秒為單位，音高以半音為單位，速度則為比率：`1`代表正常速度，`2`代表兩倍速度。

連按兩下儲存格，或選取後按**Enter**，即可編輯其值。按**Enter**套用變更，按**Escape**取消。音軌和來源儲存格會顯示實際 ID。變更音軌 ID 可將片段移至現有音訊音軌。變更來源 ID或輸入本機檔案路徑可替換音訊，同時保留時間軸位置、長度、速度及以秒為單位的來源偏移。新檔案必須包含指定的來源範圍。**反向**和**反相**是核取方塊；選取儲存格並按**空白鍵**即可切換。鎖定音軌上的片段和視訊片段為唯讀。

變更長度會從目前偏移處縮短或延伸來源範圍。變更速度會保留來源範圍，除非同時貼上長度。請先取消片段的群組或連結，再於此處調整其時間；伸展片段的時間應在來源編輯器中調整。

選取儲存格、拖曳選取範圍，或按住**Shift**並點擊另一儲存格以擴大選取範圍。點擊列號或欄標題可選取整列或整欄。使用**Ctrl+C**與**Ctrl+V**（macOS 上為**Cmd+C**與**Cmd+V**）與試算表交換選取內容。欄位以定位字元分隔，列以換行分隔。貼上會從選取的儲存格開始並更新現有片段。超出現有列的貼上會遭拒。有選取內容時，按**Escape**或點擊表格下方的空白處即可清除選取。沒有選取內容時，貼上會新增列，空白專案也適用。播放選項會以`true`或`false`複製，貼上時也接受這些值。新列依照表格欄位順序排列，且需要來源檔名或來源 ID。唯一的現有音軌名稱會將片段放到該音軌；新名稱會建立音訊音軌。空白音軌名稱會使用來源名稱。空白數字儲存格會採用預設值：位置與偏移為`0`、速度為`1`、音高與增益為`0`，且沒有淡入淡出。長度空白時，會以指定速度使用剩餘音訊。

面板會先在專案中尋找來源，包括專案素材箱。若找不到，請選擇**載入參照檔案**，並選取對話方塊中列出的音訊檔案。磁碟上的路徑也需要透過此方式選取檔案：貼上路徑不會授予應用程式檔案存取權。所選檔案必須與參照名稱明確相符。面板會匯入音訊、驗證來源範圍與片段屬性，再將新片段放到指定位置。**Ctrl+Z**（macOS 上為**Cmd+Z**）可用一步復原整個貼上動作；**Ctrl+Shift+Z**（**Cmd+Shift+Z**）可重做。若貼上內容含有無效值，片段不會變更。

## 構建混音

使用軌道增益、平衡、靜音和獨奏控制來平衡專案。混合器面板以混合導向的佈局顯示相同的專案狀態。實時效果仍然可調整；破壞性或渲染操作創建可撤銷的專案更改，只要歷史記錄可用。

使用播放計量器和響度分析來檢查結果。避免將計量器目標作為替代完整導出聽取的方法。

### 聆聽選取的頻率 {#listen-to-selected-frequencies}

選取要聆聽的片段。在音軌選單中選擇**音軌視覺化 → 頻譜圖**，再開啟**頻譜圖選項 → 選取頻譜頻率範圍**。輸入最低與最高頻率並選擇**選取範圍**，或調整頻譜圖中的選取控制點。

選擇**播放選項 → 播放選取的頻率**，或**選取 → 頻譜 → 播放選取的頻率**。選取的時間範圍會以正常速度播放一次，即使先前選擇了其他速度或循環播放也一樣。聆聽濾鏡會套用於目前混音，包括靜音、獨奏、增益與效果設定。頻譜矩形會標示頻率帶與時間範圍，但不會將音軌設為獨奏。如果正在播放，指令會先暫停；再次選擇該指令即可開始頻率預聽。

即時頻率濾鏡的邊緣會平滑漸變。頻帶外及接近邊界的頻率可能會變小聲。**暫停**或**停止**會移除濾鏡，因此下一次正常播放會使用完整頻率範圍。音訊、選取範圍、復原記錄與匯出的檔案都不會改變。

### 減少刺耳音 {#reduce-sibilance}

選擇 **效果 → 噪音去除和修復 → 去刺耳音**。將 **頻率** 設置在聲音刺耳部分附近，然後降低 **閾值** 直到刺耳音變軟。**最大減少** 限制切割；從 6-9 dB 開始。較短的 **攻擊** 可以捕捉輔音的開始，而 **釋放** 控制高頻恢復的速度。只有上帶被減少。

### 壓縮單獨的頻率帶 {#multiband-compression}

選擇 **效果 → 音量和壓縮 → 多帶壓縮器**。兩個交叉點將信號分為低、中和高三帶。每個帶都有自己的閾值、比率和輸出增益。比率為 1 時，該帶的動態保持不變。攻擊和釋放適用於所有三個帶。交叉點具有溫和的、重疊的 6 dB/八度斜率；在所有比率為 1 和帶增益為 0 dB 時，原始信號保持不變地通過。

這兩種效果鏈接其通道以保持立體聲平衡，還可在軌道和母帶效果架中提供。架設置與專案一起儲存，並在播放期間可調整。**應用到選擇** 會將效果渲染到選定的音頻並支持 **撤銷**。時間線自動化不適用於這兩種效果。

### 使用 LADSPA 效果和 Vamp 分析器 {#native-audio-plugins}

桌面應用只有在你於**效果 → 插件管理器**中允許某種格式及其檔案夾後，才會掃描第三方插件。掃描不會自動進行。使用前請逐一允許發現的安裝包，並且只安裝你信任的插件：原生插件會運行可執行代碼，即使 Soundscaper 將它們托管在受監督的輔助進程中。

Linux 提供 LADSPA 效果。請先在插件管理器中啓用，然後從**效果 → 音頻插件**打開。由於 LADSPA 格式沒有廠商界面，Soundscaper 會根據 LADSPA 接口端口生成控件。這些控件值以及效果的啓用或旁通狀態都會隨專案儲存。

Vamp 插件用於分析音頻，不會更改音頻。啓用 Vamp 插件後，選擇一個音頻軌道即可分析該軌道；若未選擇音頻軌道，則分析主混音。時間選區會限制分析範圍；否則 Soundscaper 會分析整個專案。選擇**分析 → Vamp 插件**，選擇分析器輸出及其設置，然後運行。只有完整分析成功後，Soundscaper 才會將返回的時間戳添加為新的標籤軌道，因此取消操作或更改專案不會留下不完整的標籤。

## 導出

選擇 **檔案 → 導出音頻** 進行混合交付，或選擇 **導出選定音頻** 僅渲染選定部分。Soundscaper 還可導出乾聲和標籤。

### 將片段匯出為個別檔案 {#export-clips}

選擇**檔案 → 匯出音訊**，並將**輸出**設為**個別片段（依片段分割）**。選擇音訊格式並按下**匯出**，即可下載一個封存檔，其中專案音軌上的每個音訊片段各有一個檔案。每個檔案從片段可聽見的起點開始，到可聽見的終點結束；不會補齊至專案時間軸長度，也不會加入效果尾音。剪裁、片段增益、淡入淡出以及速度與音高變更都會套用。重疊的片段仍各自獨立。

檔案使用附有編號前綴的片段名稱。不支援的檔名字元會替換，編號則可區分重複的片段名稱。音軌效果會包含；主效果、靜音與獨奏不會影響此匯出。若要個別匯出可編輯片段，請先解除凍結已凍結的音軌。

壓縮格式使用 FFmpeg 運行時。確切的格式和條件可用性列在[生成的格式參考](/reference/)中。

### 嵌入章節標籤 {#embedded-chapters}

在瀏覽器編輯器中選擇**檔案 → 匯出音訊**，選取**MP3**或**AAC / M4A**，並在**音訊選項**中啟用**將標籤嵌入為章節**。此選項預設關閉，會將標籤標題與時間加入單一混音檔案。請在匯出前新增標籤；分軌、章節分割與母帶處理序列不提供此選項。

只會包含與交付範圍相交的標籤。匯出選取範圍時，章節時間會移至產生檔案的開頭。MP3 會保留區段標籤的結束時間；點標籤會在下一章節或檔案結尾處結束。M4A 會儲存章節起點，每個章節持續至下一個起點或檔案結尾。M4A 最多支援255個章節，每個標題255個 UTF-8 位元組。播放器是否顯示嵌入章節取決於播放器。

在交付或刪除源材料之前，請在另一個應用程序中播放導出的檔案。
