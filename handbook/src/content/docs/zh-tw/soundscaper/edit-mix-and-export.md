## 排列剪輯

在選擇編輯命令之前，選擇剪輯或時間範圍。分割在播放頭處創建一個編輯邊界。保留間隙和漣漪變體確定後續材料是否保持原位或移動以關閉刪除區域。

使用軌道檔案夾、剪輯組和專案二進制檔案來整理大型專案。

### 調整剪輯淡入淡出 {#clip-fades}

選擇音頻剪輯以顯示其波形頂部的兩個小三角形，直接位於剪輯標題下方。
將左三角形向內拖動以創建淡入效果，或將右三角形向內拖動以創建淡出效果。波形在拖動時發生變化，淡入淡出曲線以上的區域變暗。三角形跟隨淡入淡出邊界；將其中一個拖回其角落會刪除該淡入淡出效果。即使選擇了多個剪輯，也只有您拖動的剪輯會被更改。

當您取消選擇剪輯時，句柄會消失，但淡入淡出的波形和著色保持不變。這些淡入淡出效果保留原始音頻，並在儲存和重新打開專案後仍然可調整。釋放以提交淡入淡出效果，或在拖動時按 **Esc** 鍵以取消。**撤銷** 操作會逆轉一次完整的拖動。播放和導出使用已提交的淡入淡出設置。

在選擇的剪輯處於焦點時，按 **Tab** 鍵訪問其淡入淡出句柄。方向鍵將持續時間調整為 10 毫秒，或在 **Shift** 鍵下調整為 100 毫秒。**Home** 鍵刪除淡入淡出效果；**End** 鍵將其擴展到整個剪輯。對於數字輸入，請選擇 **編輯 → 音頻剪輯 → 剪輯屬性** 並使用 **淡入淡出**。

## 構建混音

使用軌道增益、平衡、靜音和獨奏控制來平衡專案。混合器面板以混合導向的佈局顯示相同的專案狀態。實時效果仍然可調整；破壞性或渲染操作創建可撤銷的專案更改，只要歷史記錄可用。

使用播放計量器和響度分析來檢查結果。避免將計量器目標作為替代完整導出聽取的方法。

### 減少刺耳音 {#reduce-sibilance}

選擇 **效果 → 噪音去除和修復 → 去刺耳音**。將 **頻率** 設置在聲音刺耳部分附近，然後降低 **閾值** 直到刺耳音變軟。**最大減少** 限制切割；從 6-9 dB 開始。較短的 **攻擊** 可以捕捉輔音的開始，而 **釋放** 控制高頻恢復的速度。只有上帶被減少。

### 壓縮單獨的頻率帶 {#multiband-compression}

選擇 **效果 → 音量和壓縮 → 多帶壓縮器**。兩個交叉點將信號分為低、中和高三帶。每個帶都有自己的閾值、比率和輸出增益。比率為 1 時，該帶的動態保持不變。攻擊和釋放適用於所有三個帶。交叉點具有溫和的、重疊的 6 dB/八度斜率；在所有比率為 1 和帶增益為 0 dB 時，原始信號保持不變地通過。

這兩種效果鏈接其通道以保持立體聲平衡，還可在軌道和母帶效果架中提供。架設置與專案一起儲存，並在播放期間可調整。**應用到選擇** 會將效果渲染到選定的音頻並支持 **撤銷**。時間線自動化不適用於這兩種效果。

### 使用 LADSPA 效果和 Vamp 分析器 {#native-audio-plugins}

桌面應用只有在你於**效果 → 插件管理器**中允許某種格式及其檔案夾後，才會掃描第三方插件。掃描不會自動進行。使用前請逐一允許發現的安裝包，並且只安裝你信任的插件：原生插件會運行可執行代碼，即使 Soundscaper 將它們托管在受監督的輔助進程中。

Linux 提供 LADSPA 效果。請先在插件管理器中啓用，然後從**效果 → 音頻插件**打開。由於 LADSPA 格式沒有廠商界面，Soundscaper 會根據 LADSPA 接口端口生成控件。這些控件值以及效果的啓用或旁通狀態都會隨專案儲存。

Vamp 插件用於分析音頻，不會更改音頻。啓用 Vamp 插件後，選擇一個音頻軌道即可分析該軌道；若未選擇音頻軌道，則分析主混音。時間選區會限制分析範圍；否則 Soundscaper 會分析整個專案。選擇**分析 → Vamp 插件**，選擇分析器輸出及其設置，然後運行。只有完整分析成功後，Soundscaper 才會將返回的時間戳添加為新的標籤軌道，因此取消操作或更改專案不會留下不完整的標籤。

## 導出

選擇 **檔案 → 導出音頻** 進行混合交付，或選擇 **導出選定音頻** 僅渲染選定部分。Soundscaper 還可導出乾聲和標籤。

壓縮格式使用 FFmpeg 運行時。確切的格式和條件可用性列在[生成的格式參考](/reference/)中。

在交付或刪除源材料之前，請在另一個應用程序中播放導出的檔案。

對於圖片工作——組合序列、視頻效果和 MP4 或 WebM 交付——請將專案交給 [Framescaper](/framescaper/) 並查看[導出視頻](/framescaper/video-export/)。
