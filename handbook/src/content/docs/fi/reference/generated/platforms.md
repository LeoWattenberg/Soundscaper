Editori toimii selaimessa ja työpöytäsovelluksena. Tässä sivussa luetellaan, mitä on rakennettu ja testattu, ei kaikkia ympäristöjä, joissa koodi saattaa toimia.

## Selaimet

”Testattu automaattisesti” tarkoittaa, että selaimen testisarja ajetaan tätä moottoria vastaan jokaisessa vetopyynnössä. Moottori, jota ei ole lueteltu, ei ole testattu eikä sen väitetä toimivan.

| Selaimen moottori | Testattu automaattisesti |
| --- | --- |
| Chromium (Chrome, Edge) | Kyllä |
| Firefox | Kyllä |
| WebKit (Safari) | Kyllä |

## Missä ominaisuus voi toimia

Ominaisuudet on ryhmitelty sen mukaan, mitä ne tarvitsevat alustalta. Katso [Tuotteen ominaisuudet](/reference/generated/product-capabilities/) tietääksesi, mitkä ominaisuudet kukin tuote ottaa käyttöön.

| Taso | Miten se toimii |
| --- | --- |
| `web-core` | Toimii kaikissa tuetuissa selaimissa ilman valinnaisia alustan ominaisuuksia. |
| `web-enhanced` | Toimii selaimessa, joka tarjoaa uudemmat tallennus- ja mediaominaisuudet, joita ominaisuus tarvitsee. |
| `electron-enhanced` | Toimii selaimessa, ja työpöytäsovellus tekee sen kanssa enemmän. |
| `electron-only` | Vaatii työpöytäsovelluksen, koska selaimen ei ole mahdollista käyttää ominaisuuden käyttämiä resursseja. |
