Vähennä huoneen heijastuksia nauhoitetussa puheessa paikallisella dereverberointimallilla.

## Nykyinen saatavuus {#current-availability}

Työpöytäasennukset sisältävät vaaditun onnxruntime-node 1.29.0 -moottorin macOS arm64, Linux x64, Linux arm64, Windows x64 ja Windows arm64 -alustoille. Asenna tämän mallin painot Model Manager -työkalun kautta ja suorita sen tehtävä paikallisesti. Nämä ovat tuetut käännöstavoitteet; tarkista yöllinen testiraportti tietyn paketin ja koneen tuloksista.

## Tämän mallin käyttö {#use-this-model}

Avaa **Tools → Advanced Local Processing → Dereverberation** -valikko alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse puhe, jossa on huoneen heijastuksia.
2. Asenna malli Model Manager -työkalun kautta ja suorita dereverberointi.
3. Vertaa tulosta alkuperäiseen ja hyväksy se vain, jos puhe kuulostaa paremmalta.

## Mitä paketoitu testi tarkistaa {#what-the-packaged-test-checks}

Tapaus: `dereverb-room-speech`; toiminto: `dereverberation`.

Syöte: Kennedyn puhe, joka on näytteenotettu uudelleen 44,1 kHz:iin ja jossa on neljä toistettavaa viivästyneitä heijastuksia.

Koodatun äänen on sisällettävä äärellisiä näytteitä, säilytettävä odotettu äänigeometria, erottuttava syötteenäytteistä ja sisältävä nollasta poikkeava kuultava signaali. Eri tiedostotunnisteet eivät yksinään riitä muutokseksi.

Yöllinen testipaketti lataa todelliset malliartefaktit ja pyytää inferenssiä paketoitua ajonaikaympäristöä käyttäen. Katalogista puuttuva vaadittava malli epäonnistuttaa tapauksensa. Puuttuvat natiivit moottorit epäonnistuvat katalogissa tuetuilla alustoilla. Nämä kalliit tarkistukset suoritetaan erikseen tavallisesta selaintestisarjasta. Onnistunut suoritus vahvistaa perusmallin suorituksen ja käyttökelpoisen tulorakenteen; se ei vakuuta havaittua laatua tai tarkkuutta omassa nauhoituksessasi.
