## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Vähennä huoneen heijastuksia nauhoitetussa puheessa paikallisella dereverberointimallilla.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset.

## Tämän mallin käyttö {#use-this-model}

Avaa **Tools → Advanced Local Processing → Dereverberation** -valikko alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse puhe, jossa on huoneen heijastuksia.
2. Asenna malli Model Manager -työkalun kautta ja suorita dereverberointi.
3. Vertaa tulosta alkuperäiseen ja hyväksy se vain, jos puhe kuulostaa paremmalta.
