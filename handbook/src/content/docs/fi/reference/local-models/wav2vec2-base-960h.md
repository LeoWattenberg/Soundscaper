Tasaa olemassa oleva englanninkielinen transkripti äänitallenteen puhuttuihin sanoihin.

## Nykyinen saatavuus {#current-availability}

Työpöytäasennukset sisältävät vaaditun onnxruntime-node 1.29.0 -moottorin macOS arm64, Linux x64, Linux arm64, Windows x64 ja Windows arm64 -alustoille. Asenna tämän mallin painot Model Manager -työkalun kautta ja suorita sen tehtävä paikallisesti. Nämä ovat tuettuja käännöstavoitteita; tarkista yöllinen testiraportti tietyn paketin ja koneen tuloksista.

## Tämän mallin käyttö {#use-this-model}

Avaa **Analysoi → Puhe → Transkriointi ja tekstitykset** tai **Työkalut → Edistynyt paikallinen käsittely → Sanatasonointi** alustalla, jossa on vaadittu natiivi ajonaikainen ympäristö. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse puhe ja valmista tai tarkista sen englanninkielinen transkripti.
2. Asenna tasausmalli Model Manager -työkalun kautta.
3. Suorita tasaus, kuuntele ja tarkista ehdotetut sanarajat ennen niiden hyväksymistä.

Latauskoko noin: **360,38 MiB**. Vähimmäisjärjestelmänmuisti: **4 GiB**. Tämä katalogivaatimus viittaa kokonaismuistiin, ei tällä hetkellä vapaaseen muistiin. Inferenssin suorittaminen vaatii myös riittävästi vapaata muistia, ja asennus vaatii toimivaa tilaa; muisti ei ole nopeustakuu.

Julkaistut alustat: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Myös vastaava paketoitu ajonaikainen ympäristö on vaadittava.

## Mitä paketoitu testi tarkistaa {#what-the-packaged-test-checks}

Tapaus: `wav2vec2-word-alignment`; toiminto: `word-alignment`.

Syöte: Yleisön omistama Kennedyn puhe 16 kHz:n taajuudella yhdessä sen tunnetun englanninkielisen transkriptin kanssa erillisen todennetun syötteenä.

Jokaisen toimitetun sanan on oltava edustettynä kelvollisella järjestyksellä olevalla aikaleimalla äänessä; tarkat tasausajat eivät ole määritettyjä.

Yöllinen testipaketti lataa todelliset malliartefaktit ja pyytää inferenssiä paketoitua ajonaikaista ympäristöä kautta. Pakotetun mallin puuttuminen katalogista aiheuttaa tapauksen epäonnistumisen. Natiivien moottorien puuttuminen aiheuttaa epäonnistumisen katalogissa tuetuilla alustoilla. Nämä kalliit tarkistukset suoritetaan erikseen tavallisesta selaintestisarjasta. Onnistunut suoritus vahvistaa perusmallin suorituksen ja käyttökelpoisen tulorakenteen; se ei vahvista perceptuaalista laatua tai tarkkuutta omassa äänitallenteessasi.

## Tuloksen tarkistus {#review-the-result}

- Tämä malli tasaa toimitetut englanninkieliset sanat; se ei käännä tai korjaa virheellistä transkriptiä.
- Toistuvat sanat, taustalla puhuminen ja transkriptistä puuttuvat sanat voivat tuottaa virheelliset rajat. Testi tarkistaa toimitetun sanaluettelon vasten järjestyksessä olevia, alueella olevia sana-aikoja, ei täydellistä aikataulua.
