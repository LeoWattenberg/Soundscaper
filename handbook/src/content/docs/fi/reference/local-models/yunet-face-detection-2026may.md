## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Tunnista kasvoja ja esineitä näytteistetyissä videokehyksissä auttaaksesi ehdottamaan uutta kehystystä.

YuNet tunnistaa kasvoja ja niiden sijainnit. Aiheen tunnistus yhdistää nämä tulokset D-FINE-esineiden tunnistukseen.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Tämän mallin käyttö {#use-this-model}

Avaa **Framescaper: Effect → Video effects → Reframe** alustalla, jossa on tarvittava natiivi ajonaikaympäristö. Paikallinen avustus suoritetaan työpöytätoimittimessa.

1. Valitse videoleikkaus Framescaperissa.
2. Asenna sekä YuNet että D-FINE aiheen tunnistusta varten. Ohjattu Reframe-tehtävä käyttää myös U²-Net-P-salienttisuuden tunnistusta.
3. Suorita paikallisesti ja tarkista ehdotettu leikkaus. Tools → Advanced Local Processing voi suorittaa aiheen tunnistuksen itsenäisesti.

Tämä toiminto vaatii myös [D-FINE Nano object detection](/reference/local-models/dfine-nano-coco/).

## Tuloksen tarkistus {#review-the-result}

- Kasvoja ja esineitä voi jäädä tunnistamatta tai luokitella väärin. Tunnistus on näytteistettyä eikä takaa, että liikkuva kohde pysyy jokaisessa ehdotetussa leikkauksessa.
- Toiminto suorittaa molemmat mallit yhdessä; kumpikaan malli ei ole kasvojentunnistusjärjestelmä ihmisten tunnistamiseen.
