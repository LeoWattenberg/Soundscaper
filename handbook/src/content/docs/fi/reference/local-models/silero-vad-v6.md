## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Etsi puhealueet ennen transkriptiota tai pitkien taukojen poistamista.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun sherpa-onnx-node 1.13.5-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Tämän mallin käyttö {#use-this-model}

Avaa **Vaihtoehdot → Melunpoisto ja korjaus → Täyte- ja hiljaisuuden puhdistus** tai **Analyysi → Puhe → Transkriptio ja tekstitykset** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse äänialue, joka sisältää puhetta ja taukoja.
2. Avaa tehtävä ja asenna Silero VAD -malli mallinhallintaa (Manage Models) käyttäen.
3. Suorita paikallisesti ja tarkista havaitut alueet tai puhdistusehdotukset ennen muutosten soveltamista.

## Tuloksen tarkistus {#review-the-result}

- Äänitoiminnon tunnistus (VAD) havaitsee, milloin puhetta esiintyy. Se ei transkriboi sanoja, korjaa melua tai tunnistaa puhujia.
