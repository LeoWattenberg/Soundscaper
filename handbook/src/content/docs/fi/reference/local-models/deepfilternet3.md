## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Vähennä taustamelua dialogissa paikallisen puheen parannusmallin avulla.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Mallin käyttö {#use-this-model}

Avaa **Effect → Noise removal and repair → Enhance Dialogue** -valikko alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse dialogi, jonka haluat parantaa.
2. Asenna DeepFilterNet3 Manage Models -työkalun kautta ja valitse Run locally.
3. Kuuntele ehdotettu tulos alkuperäistä vastaan ennen sen soveltamista. Kumennus palauttaa hyväksytyn projektimuokkauksen.
