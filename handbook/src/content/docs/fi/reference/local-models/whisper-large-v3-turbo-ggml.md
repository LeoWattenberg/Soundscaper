## Nykyinen saatavuus {#current-availability}

Työpöytäasennukset sisältävät vaaditun whisper-cpp v1.9.3 -moottorin macOS arm64, Linux arm64, Linux x64, Windows arm64 ja Windows x64 -alustoille. Asenna tämän mallin painot Model Manager -työkalun kautta ja suorita sen tehtävä paikallisesti. Nämä ovat tuettuja käännöstavoitteita; tarkista yöllinen testiraportti tietyn paketin ja koneen tuloksista. Työpöytäasennus ei sisällä tätä moottoria macOS x64 -alustalle, vaikka mallin painot olisivatkin lueteltu näille alustoille.

## Tämän mallin käyttö {#use-this-model}

Avaa **Analysoi → Puhe → Transkriointi ja tekstitykset** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse puhe ja asenna Whisper large-v3 turbo -malli Manage Models -työkalun kautta.
2. Valitse tämä puheentunnistusmalli Tools → Advanced Local Processing -valikosta, jos haluat valita Whisperin nimenomaisesti.
3. Suorita paikallisesti ja tarkista sekä teksti että segmenttirajat ennen hyväksymistä.

## Paketoidun testin tarkistuskohteet {#what-the-packaged-test-checks}

Tapaus: `whisper-turbo-transcript`; operaatio: `speech-recognition`.

Syöte: Yleisön omistama katkelma John F. Kennedyn virkaanastujaispuheesta, johon on lisätty sekunti hiljaisuutta kumpaankin päähän, ja joka on käsitelty mono-ääneksi 16 kHz:n taajuudella.

Transkriptin on sisällettävä ei-tyhjä teksti, jossa on kelvollinen aikaleima syöteäänessä. Tarkkaa sanamuotoa ei verrata.

Yöllinen testipaketti lataa todelliset malliartefaktit ja pyytää inferenssiä paketoidun ajonaikaympäristön kautta. Jos vaadittu malli puuttuu luettelosta, sen tapaus epäonnistuu. Puuttuvat natiivit moottorit epäonnistuvat luettelon tuemilla alustoilla. Nämä kalliit tarkistukset suoritetaan erikseen tavallisesta selaintestisarjasta. Onnistunut suoritus vahvistaa perusmallin suorituksen ja käyttökelpoisen tulorakenteen; se ei kuitenkaan vakuuta havaitsevaa laatua tai tarkkuutta omassa nauhoituksessasi.
