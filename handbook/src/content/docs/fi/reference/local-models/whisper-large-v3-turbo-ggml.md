## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Transkriboitua valittua puhe paikallisesti paketoidun whisper.cpp -ajonaikaympäristön kautta.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun whisper-cpp v1.9.3-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Tämän mallin käyttö {#use-this-model}

Avaa **Analysoi → Puhe → Transkriointi ja tekstitykset** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse puhe ja asenna Whisper large-v3 turbo -malli Manage Models -työkalun kautta.
2. Valitse tämä puheentunnistusmalli Tools → Advanced Local Processing -valikosta, jos haluat valita Whisperin nimenomaisesti.
3. Suorita paikallisesti ja tarkista sekä teksti että segmenttirajat ennen hyväksymistä.
