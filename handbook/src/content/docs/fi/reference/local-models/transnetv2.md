## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Etsi kuvanvaihdoksia videosta käyttämällä tarkkaa paikallista mallipolkua.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset.

## Mallin käyttö {#use-this-model}

Avaa **Framescaper: Tools → Advanced Local Processing → Shot detection** -valikko alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse video Framescaper-ohjelmassa.
2. Asenna TransNetV2 Model Manager -työkalun kautta ja valitse mallipohjainen kuvanvaihdosten tunnistus.
3. Tarkista ehdotetut kuvanvaihdosrajat ennen merkintöjen lisäämistä tai niiden käyttöä leikkausten suunnitteluun.

Malliartefaktin arvioitu latauskoko: **29.81 MiB**. Vaadittu ajoaika lisätään ensimmäiseen lataukseen, jos sitä ei ole jo asennettu. Järjestelmän vähimmäismuisti: **2 GiB**. Luettelon vaatimus koskee kokonaismuistia, ei juuri nyt vapaana olevaa muistia. Päättely tarvitsee myös riittävästi vapaata muistia ja asennus työtilaa; muisti ei takaa nopeutta.
