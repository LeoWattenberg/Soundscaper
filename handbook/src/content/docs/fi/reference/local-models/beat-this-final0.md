## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Etsi musiikin tahtia suuremmalla valinnaisella Beat This -mallilla.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset.

## Mallin käyttö {#use-this-model}

Avaa **Työkalut → Edistynyt paikallinen käsittely → Tahtiseuraus** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse musiikki, jossa on selkeä rytmikäs kappale.
2. Asenna Beat This final -malli Model Manager -työkalun kautta ja valitse sen tarkka mallitunniste.
3. Tarkista ehdotetut tahdit ja tempo musiikin suhteen ennen niiden hyväksymistä.
