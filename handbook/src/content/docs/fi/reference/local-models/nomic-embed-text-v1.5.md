Luo paikallisia numeerisia esityksiä transkriptio-osuuksista ja hakulausekkeista semanttista hakuun.

## Nykyinen saatavuus {#current-availability}

Työpöytäasennukset sisältävät vaaditun onnxruntime-node 1.29.0 -moottorin macOS arm64, Linux arm64, Linux x64, Windows arm64 ja Windows x64 -alustoille. Asenna tämän mallin painot mallinhallinnassa ja suorita sen tehtävä paikallisesti. Nämä ovat tuettuja käännöstavoitteita; tarkista yökohtaiset testiraportit tietyn paketin ja koneen tuloksista. Työpöytäasennus ei sisällä tätä moottoria macOS x64 -alustalle, vaikka mallin painot olisivatkin lueteltu näille alustoille.

## Tämän mallin käyttö {#use-this-model}

Avaa **Työkalut → Haku → Transkriptioindeksi, sitten Työkalut → Haku → Indeksoitu haku** alustalla, jossa on vaadittu natiivi ajonaikainen ympäristö. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Luo tai tuota transkriptio ja asenna Nomic Embed Text -malli mallinhallinnassa.
2. Suorita Transkriptioindeksi valmistaaksesi tekstin semanttista hakuun.
3. Käytä Indeksoitua hakuja ja tarkista osumat kontekstissa. Edistynyt paikallinen käsittely paljastaa myös upotustoiminnon.

## Mitä paketoitu testi tarkistaa {#what-the-packaged-test-checks}

Tapaus: `nomic-text-embedding`; toiminto: `text-embedding`.

Syöte: Lyhyt ei-tyhjä teksti, joka syötetään todelliselle tokenisoijalle ja upotusverkostolle.

Upotusvektoreiden on oltava odotetun ulottuvuudet ja sisältävä äärellisiä, nollasta poikkeavia, ei-vakioarvoja.

Yökohtainen testipaketti lataa todelliset malliartefaktit ja pyytää inferenssiä paketoitua ajonaikaista ympäristöä kautta. Paketoitu malli, joka puuttuu luettelosta, epäonnistuu tapauksessaan. Puuttuvat natiivit moottorit epäonnistuvat luettelon tuemilla alustoilla. Nämä kalliit tarkistukset suoritetaan erikseen tavallisesta selaintestisarjasta. Onnistunut suoritus vahvistaa perusmallin suorituksen ja käyttökelpoisen tulorakenteen; se ei vahvista perceptuaalista laatua tai tarkkuutta tallenteessasi.
