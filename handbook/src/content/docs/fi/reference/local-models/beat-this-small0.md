## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Etsi tahtiasemat musiikista pienemmän Beat This -mallin avulla.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset.

## Mallin käyttö {#use-this-model}

Avaa **Työkalut → Edistynyt paikallinen käsittely → Tahtiseuraus** alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto toimii työpöytätoimittimessa.

1. Valitse rytmimusiikin kappale.
2. Asenna Beat This small -malli Model Manager -työkalun kautta ja valitse tämä tarkka malli tahtiseurausta varten.
3. Kuuntele ehdotettu tahtiruudukko ennen tahtimerkkien tai tempon ehdotuksen hyväksymistä.
