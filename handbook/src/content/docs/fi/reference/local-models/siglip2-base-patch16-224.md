Esitä näytettyjä videokuviota ja tekstiä yhteisessä numeerisessa avaruudessa paikallista visuaalista hakuun.

## Nykyinen saatavuus {#current-availability}

Työpöytäasennukset sisältävät vaaditun onnxruntime-node 1.29.0 -moottorin macOS arm64, Linux arm64, Linux x64, Windows arm64 ja Windows x64 -alustoille. Asenna tämän mallin painot Model Manager -työkalun kautta ja suorita sen tehtävä paikallisesti. Nämä ovat tuettuja käännöstavoitteita; tarkista yöllinen testiraportti tietyn paketin ja koneen tuloksista. Työpöytäasennus ei sisällä tätä moottoria macOS x64 -alustalle, vaikka mallin painot olisivatkin lueteltu näille alustoille.

## Tämän mallin käyttö {#use-this-model}

Avaa **Framescaper: Tools → Search → Index Video, sitten Tools → Search → Indexed Search** alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse video ja asenna SigLIP2 Manage Models -työkalun kautta.
2. Suorita Index Video -toiminto analysoimaan näytettyjä kehyksiä. Asenna myös PP-OCRv4, jos haluat sen valinnaisen tekstin lukuvaiheen.
3. Käytä Indexed Search -toimintoa ja tarkista vastaavat videon hetket ennen kuin päätät, miten niitä käytetään.
