## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Arvioi näytteistettyjen kehysten visuaalisesti erottuvaa aluetta uudelleenkehytyksen tueksi.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Tämän mallin käyttö {#use-this-model}

Avaa **Framescaper: Effect → Video effects → Reframe** alustalla, jossa vaadittu natiivi ajonaikaympäristö on käytettävissä. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse videoleike ja asenna U²-Net-P -malli Manage Models -työkalun kautta.
2. Ohjattu Reframe-tehtävä vaatii myös YuNet- ja D-FINE-mallit; Tools → Advanced Local Processing -työkalu voi suorittaa salienssintunnistuksen erikseen.
3. Suorita tehtävä paikallisesti ja tarkista ehdotettu kehys ennen sen soveltamista.
