## Tarkoitus ja käyttötapaus {#purpose-and-use-case}

Lue näkyvää tekstiä otosvideokuvista tarkistusta ja indeksointia varten.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot voivat ladata ja todentaa vaaditun onnxruntime-node 1.29.0-moottorin alustoille macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Asenna tämä malli ja sen vaatima ajoaika Mallien hallinnasta ja suorita tehtävä paikallisesti. Nämä ovat tuettuja koontikohteita; katso yötestiraportista tietyn paketin ja laitteen tulokset. macOS x64:lle ei ole ladattavaa moottoria, vaikka mallin painot on lueteltu kyseiselle alustalle.

## Tämän mallin käyttö {#use-this-model}

Avaa **Framescaper: Tools → Search → Index Video tai Tools → Advanced Local Processing → Optical character recognition** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto suoritetaan työpöytätoimittimessa.

1. Valitse video, jossa on luettavaa ruudulla näkyvää tekstiä.
2. Asenna PP-OCRv4 mobile -malli Manage Models -työkalun kautta. Tämä on valinnainen vaihe Index Video -toiminnossa, joka käyttää myös SigLIP2-mallia.
3. Suorita paikallisesti ja tarkista tunnistettu teksti sekä sen sijainnit kuvissa ennen tulosten hyväksymistä.
