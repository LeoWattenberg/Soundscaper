Muunna valittu puhe aikajärjestykseen olevaksi transkriptioksi tekstitykseen ja transkriptioeditointiin.

## Nykyinen saatavuus {#current-availability}

Työpöytäversiot sisältävät pakettina vaaditun sherpa-onnx-node 1.13.5 -moottorin macOS arm64-, Linux arm64-, Linux x64-, Windows arm64- ja Windows x64-alustoille. Asenna tämän mallin painot Model Manager -työkalun kautta ja suorita sen tehtävä paikallisesti. Nämä ovat tuettuja käännöstavoitteita; tarkista yöllinen testiraportti tietyn paketin ja koneen tuloksista. Työpöytäversio ei paketa tätä moottoria macOS x64:lle, vaikka mallin painot olisivatkin lueteltu näille alustoille.

## Tämän mallin käyttö {#use-this-model}

Avaa **Analysoi → Puhe → Transkrioi ja tekstitä** alustalla, jossa on vaadittu natiivi ajonaikaympäristö. Paikallinen avustustoiminto suoritetaan työpöytäeditorissa.

1. Valitse transkrioitava puhe.
2. Asenna tämä malli Manage Models -työkalun avulla. Tools → Advanced Local Processing -valikosta voit valita tietyn puheentunnistuksen mallin.
3. Suorita paikallisesti ja tarkista teksti sekä aikajärjestys ennen transkriptioiden hyväksymistä.

## Mitä paketoitu testi tarkistaa {#what-the-packaged-test-checks}

Tapaus: `parakeet-v2-transcript`; operaatio: `speech-recognition`.

Syöte: Yleisön omistama katkelma John F. Kennedyn virkaanastujaispuheesta, johon on lisätty sekunti hiljaisuutta kumpaankin päähän, ja joka on käsitelty mono-ääneksi 16 kHz:n taajuudella.

Transkriptioiden on sisällettävä ei-tyhjä teksti, jossa on kelvollinen aikajärjestys syöteäänen sisällä. Tarkkaa sanamuotoa ei verrata.

Yöllinen testipaketti lataa todelliset malliartefaktit ja pyytää inferenssiä paketoitua ajonaikaympäristöä kautta. Pakollisen mallin puuttuminen katalogista epäonnistuttaa sen tapauksen. Natiivien moottorien puuttuminen epäonnistuu katalogissa tuetuilla alustoilla. Nämä kalliit tarkistukset suoritetaan erikseen tavallisesta selaintestisarjasta. Onnistunut suoritus vahvistaa perusmallin suorituksen ja käyttökelpoisen tulorakenteen; se ei vahvista havaitsevaa laatua tai tarkkuutta omassa nauhoituksessasi.
