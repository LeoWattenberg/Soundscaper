## Mihin tämä opas on tarkoitettu {#what-this-guide-is-for}

Morse muuntaa viestin ajastetuiksi pisteiksi, viivoiksi ja väleiksi. Generaattori esikatselee koodauksen ja laskee leikkeen pituuden viestin ja nopeuden perusteella.

:::note[Tuletko Audacitystä?]
Audacityn valikkopolku on **No directly matching built-in Morse code generator**. Alla olevat nimet kuuluvat Soundscaperiin ja voivat poiketa.
:::

## Ohjeet

1. Avaa Soundscaper. Uusi, tyhjä projekti on valmis heti editorin latauduttua.
2. Valitse **Luo → Morsekoodi**. Aseta **Morsekoodi** -ikkunassa **Viesti** arvoon `SOS`, **Nopeus (sanaa minuutissa)** arvoon `20`, **Taajuus (Hz)** arvoon `600` ja **Amplitudi** arvoon `0.2`. Paina sitten **Luo**. Korvaa esimerkkiviesti omalla tekstilläsi ja tarkista koodauksen esikatselu; tuettomat merkit estävät luonnin.
3. Projektissa näkyy nyt 1 clip.
   *Näin pitäisi näkyä:* Morse-leike sisältää viestin; sen pituus määräytyy valitun nopeuden mukaan.

## Vinkkejä

- Hitaampi nopeus pidentää pisteitä, viivoja ja välejä laskematta äänen taajuutta.
- Kesto on tässä vain luettavissa. Muuta viestiä tai nopeutta vaihtaaksesi leikkeen pituutta.
