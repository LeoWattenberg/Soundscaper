## Mihin tämä opas on tarkoitettu {#what-this-guide-is-for}

Useita ottoja sisältävässä projektissa lähekkäin olevat nimet helpottavat aiheeseen liittyvien raitojen löytämistä. Sort by name järjestää raidat aakkosjärjestykseen muuttamatta leikkeiden aloituskohtia aikajanalla.

:::note[Tuletko Audacitystä?]
Audacityn vastaava komento on **Tracks → Sort Tracks → Sort by Name**. Alla olevat nimet ovat Soundscaperin omia, joten ne voivat poiketa.
:::

## Ohjeet

1. Avaa Soundscaper. Uusi tyhjä projekti on valmis heti, kun editori latautuu.
2. Valitse **Tiedosto → Tuo** ja tuo tallenne, jonka nimen perusteella haluat tulevan toisen jälkeen. Se ilmestyy omalle raidalleen leikkeenä.
3. Valitse **Tiedosto → Tuo** ja tuo tallenne, jonka nimen perusteella haluat tulevan ennen sitä. Se ilmestyy omalle raidalleen leikkeenä.
4. Valitse **Raidat → Lajittele raidat → Lajittele nimen mukaan**. Raitojen nimet lajitellaan aakkosjärjestykseen.
5. Projektissa näkyy nyt 2 leikettä.
   *Sinun pitäisi nähdä:* Molemmat tallenteet pysyvät projektissa, ja raitojen nimet ovat aakkosjärjestyksessä.

## Vinkkejä

- Lajittelu muuttaa raitojen järjestystä, ei leikkeiden ajoitusta tai äänisisältöä.
- Valitse **Raidat → Lajittele raidat → Lajittele ajan mukaan**, jos haluat järjestää raidat leikkeiden aloitusaikojen mukaan.
