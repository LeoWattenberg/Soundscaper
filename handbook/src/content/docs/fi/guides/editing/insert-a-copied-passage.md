## Mihin tämä opas on tarkoitettu {#what-this-guide-is-for}

Insert tekee tilaa kopioidulle äänelle sen sijaan, että se sijoittaisi äänen olemassa olevan päälle. Kohderaidoilla myöhemmin oleva ääni siirtyy oikealle kopioidun kohdan pituuden verran. Voit lisätä näin toistetun fraasin tai uuden lauseen tallenteen keskelle.

:::note[Siirryitkö Audacitystä?]
Audacityssä tätä vastaa **Edit → Copy, then Edit → Paste**. Alla olevat nimet ovat Soundscaperin omia ja voivat joskus poiketa niistä.
:::

## Vaiheet

1. Avaa Soundscaper. Uusi tyhjä projekti on valmis heti, kun editori latautuu.
2. Valitse **Tiedosto → Tuo** ja poimi tallenne, jossa kopioitava kohta on. Se ilmestyy omalle raidalleen leikkeenä.
3. Valitse toiseen kohtaan lisättävä osa vetämällä leikkeen yläpuolella olevassa viivaimessa.
4. Valitse **Muokkaa → Kopioi**.
5. Aseta kohdistin napsauttamalla kohdeleikkeen aaltomuotoa siitä kohdasta, josta kopion pitäisi alkaa. Napsautus poistaa aikavälin valinnan ja asettaa lisäyskohdan.
6. Valitse **Muokkaa → Liitä → Lisää**.
7. Projektissa näkyy nyt 3 leikettä.
   *Näet seuraavaa:* Lisätty kohta on alkuperäisen leikkeen kahden osan välissä. Myöhempi osa on siirtynyt oikealle, ja aiempi osa on pysynyt paikallaan.

## Vinkkejä

- Insert siirtää kohderaidoilla myöhempää ääntä. Komento **Muokkaa → Liitä → Lisää ja säilytä synkronointi** tekee tilaa kaikilla raidoilla, kun niiden ajoituksen on pysyttävä yhteisenä.
- **Muokkaa → Kumoa** poistaa lisäyksen ja palauttaa myöhemmän äänen entiseen paikkaansa.
