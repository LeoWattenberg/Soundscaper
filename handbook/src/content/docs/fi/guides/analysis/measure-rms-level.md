## Mihin tämä opas on tarkoitettu {#what-this-guide-is-for}

RMS on signaalitason aikakeskiarvo. Measure RMS -analysaattorilla voit verrata jaksoja tai tarkistaa jakson voimakkuuden ennen sen säätämistä.

:::note[Tuletko Audacitystä?]
Audacityn vastaava komento on **Analyze → Measure RMS (Nyquist)**. Alla olevat nimet ovat Soundscaperin omia, joten ne voivat poiketa.
:::

## Ohjeet

1. Avaa Soundscaper. Uusi tyhjä projekti on valmis heti, kun editori latautuu.
2. Valitse **Tiedosto → Tuo** ja tuo jakso, jonka keskimääräisen tason haluat mitata. Se ilmestyy omalle raidalleen leikkeenä.
3. Valitse **Valitse → Valitse kaikki**.
4. Valitse **Analysoi → Nyquist → Measure RMS**. Paina **Measure RMS** -ikkunassa **Käytä**. Ikkuna näyttää tulokset; sulje se painamalla **Sulje**.
   *Sinun pitäisi nähdä:* Raportissa näkyy kunkin kanavan ja stereosignaalin RMS-taso desibeleinä.

## Vinkkejä

- RMS kuvaa keskimääräistä tasoa; käytä [peak normalization](/guides/volume/normalize-peaks/) -toimintoa, kun haluat asettaa korkeimman näytteen tavoitearvoon.
- Valitse vain vertailtava osuus, jotta muu ääni ei vaikuta mittaukseen.
