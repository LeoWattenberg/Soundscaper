## Mihin tämä opas on tarkoitettu {#what-this-guide-is-for}

Liian kuumana tehty nauhoitus litistyy alueen ylärajaan ja vääristyy. Vaurio on helppo kuulla, mutta sitä on vaikea löytää silmällä pitkältä nauhoitukselta. Find Clipping -toiminto skannaa valinnan ja listaa kaikki näytteiden juoksut, jotka ovat täysasteikolla, jotta voit päättää, korjaatko, teetkö uudelleen vai jätätkö jokaisen sellaisenaan.

:::note[Tuletko Audacitysta?]
Tämä on Audacityn **Analyze → Find Clipping** -toiminto. Alla olevat nimet ovat Soundscaperin omia, ja ne voivat joskus poiketa.
:::

## Vaiheet

1. Avaa Soundscaper. Uusi, tyhjä projekti on valmis heti, kun muokkain latautuu.
2. Valitse **File → Import** ja valitse tarkistettava nauhoitus. Se tulee leikkauksena omalle raidalleen.
3. Valitse **Select → Select all**.
4. Valitse **Analyze → Find clipping**. **Find clipping**-valintaikkuna avautuu ja näyttää valinnan raportin.
   *Sinun tulisi nähdä:* Listaa leikatuista juoksuista tai huomautus, ettei niitä löytynyt.

## Vinkkejä

- Leikatusen nauhoituksen äänenvoimakkuuden laskeminen ei korjaa sitä; litistyt huiput pysyvät litistyneinä. **Effect → Noise removal and repair → Repair** voi rakentaa hyvin lyhyen leikatun juoksun uudelleen.
- Vältä leikkausta ensi kerralla nauhoittamalla huiput noin −12 dB:n tasolla ja nostamalla äänenvoimakkuutta myöhemmin.
