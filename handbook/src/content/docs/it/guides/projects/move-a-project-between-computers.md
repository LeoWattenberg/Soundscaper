La libreria del progetto risiede in un browser su un solo computer. Per portare un progetto altrove — su un'altra macchina, a un collega, su un'unità di backup — esportalo come file di progetto. Il file `.sscape` contiene l'audio e ogni modifica, e si apre in qualsiasi Soundscaper.

:::note[Proveniente da Audacity?]
Questa è la funzione **File → Salva progetto → Salva copia di sicurezza del progetto, quindi File → Apri** di Audacity. I nomi qui sotto sono quelli propri di Soundscaper, che a volte differiscono.
:::

## Passaggi

1. Apri Soundscaper. Un nuovo progetto vuoto è pronto non appena viene caricato l'editor.
2. Scegli **File → Importa** e seleziona il materiale del progetto. Viene inserito come clip sulla sua traccia.
3. Scegli **File → Esporta file di progetto (.sscape)**. L'intero progetto viene scaricato come un unico file `.sscape`. Conserva il file in un luogo sicuro; è il progetto completo.
4. Scegli **File → Apri** e seleziona il file. Su un computer che non ha ancora il progetto si apre direttamente; qui, dove la libreria lo contiene già, Soundscaper offre **Apri come copia sola lettura** — premi il pulsante.
   *Dovresti vedere:* Il progetto si apre con la sua traccia e clip esattamente come esportato.

## Suggerimenti

- Una copia sola lettura non può essere modificata fino a quando non la salvi come progetto autonomo dal menu File.
- Il file è un archivio ZIP con l'audio all'interno; non estrarlo manualmente.
