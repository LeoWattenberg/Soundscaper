La libreria di progetto risiede in un browser su un computer. Per portare un progetto altrove — un'altra macchina, un collega, un disco di backup — esportalo come file di progetto. Il file `.sscape` contiene l'audio e ogni modifica e si apre in qualsiasi Soundscaper.

:::note[Provi da Audacity?]
Questa è l'equivalente di **File → Salva progetto → Backup progetto, quindi File → Apri** in Audacity. I nomi riportati di seguito sono quelli specifici di Soundscaper, che a volte differiscono.
:::

## Passaggi

1. Apri Soundscaper. Un nuovo progetto vuoto è pronto non appena l'editor viene caricato.
2. Scegli **File → Importa audio** e seleziona il materiale del progetto. Il file viene posizionato come clip su una traccia dedicata.
3. Scegli **File → Esporta file di progetto (.sscape)**. L'intero progetto viene scaricato come un unico file `.sscape`. Conserva il file in un luogo sicuro; è il progetto completo.
4. Scegli **File → Apri file di progetto Scape (.sscape)** e seleziona il file. Su un computer che non ha ancora il progetto, si apre direttamente; qui, dove la libreria lo contiene già, Soundscaper offre **Apri come copia in sola lettura** — premi su di essa.
   *Dovresti vedere:* Il progetto si apre con la sua traccia e clip esattamente come esportato.

## Suggerimenti

- Una copia in sola lettura non può essere modificata finché non la salvi come progetto autonomo dal menu File.
- Il file è un archivio ZIP con l'audio all'interno; non estrarlo manualmente.
