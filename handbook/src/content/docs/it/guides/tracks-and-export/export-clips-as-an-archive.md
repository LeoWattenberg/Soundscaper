## A cosa serve questa guida {#what-this-guide-is-for}

L'esportazione delle clip individuali conserva ogni modifica in un file audio distinto e raccoglie i file in un solo archivio. Prima dividi il passaggio in clip, poi scegli la modalità di output delle clip nella finestra di esportazione.

:::note[Proveniente da Audacity?]
In Audacity, il comando equivalente è **File → Export Audio → Multiple Files (suddivisi per tracce o etichette, Audacity 3)**. I nomi che seguono sono quelli di Soundscaper e possono essere diversi.
:::

## Passaggi

1. Apri Soundscaper. Non appena l'editor si carica, è disponibile un nuovo progetto vuoto.
2. Scegli **File → Importa** e seleziona la registrazione di cui vuoi esportare le clip separatamente. Il file compare come clip su una traccia dedicata.
3. Trascina il cursore sul righello sopra la clip per selezionare il passaggio da esportare come clip distinta.
4. Scegli **Modifica → Clip audio → Dividi**.
5. Scegli **File → Esporta audio**, imposta **Formato** su **WAV**, imposta **Uscita** su **Clip singole (separate per clip)** e premi **Esporta**. Il file viene scaricato al termine del rendering e il relativo collegamento resta nella finestra. Ogni clip viene esportata come file WAV separato all'interno di un unico archivio ZIP.

## Suggerimenti

- Assegna nomi descrittivi alle clip prima dell'esportazione per riconoscere i file nell'archivio.
- Scegli **Intero progetto** per ottenere un unico mix anziché file separati per clip.
