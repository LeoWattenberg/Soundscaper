Un tutorial è una lezione: ti guida attraverso un intero lavoro su una registrazione di esempio fornita dal manuale, passo dopo passo, e ti dice cosa dovresti vedere lungo il percorso. Inizia da qui se non hai mai usato Soundscaper prima. Quando conosci la strada e hai una tua registrazione, le [guide pratiche](/guides/) coprono le stesse operazioni e molte altre, un compito alla volta.

- [Il tuo primo progetto Soundscaper](/tutorials/your-first-project/) — Importa una registrazione, ascoltala, dividila, sfumala, esporta un file e salva il progetto.
- [Pulisci una registrazione vocale](/tutorials/clean-up-a-voice-recording/) — Elimina il ronzio da una ripresa, taglia il rombo, portala alla volume del podcast ed esportala in MP3.
- [Metti la musica sotto una voce](/tutorials/put-music-under-a-voice/) — Sovrapponi due tracce, abbassa automaticamente una sotto l'altra, miscelale e esportale.

<summary>Come resta aggiornato questo tutorial</summary>

Ogni tutorial viene riprodotto sui suoi file di esempio, passo dopo passo, contro ogni build di Soundscaper dalla suite del browser (`tests/browser/soundscaper-tutorials.spec.js`). Un passo che smette di funzionare fa fallire il build piuttosto che diventare obsoleto.
