Questa pagina riflette i profili prodotto attuali. “Abilitato” significa che il profilo espone quella capacità di authoring o runtime. Una capacità disabilitata può comunque essere preservata quando un progetto viene aperto tra prodotti; questa tabella non afferma che possa essere modificata.

## Famiglie di importazione ed esportazione

| Prodotto | Famiglie di importazione | Famiglie di esportazione |
| --- | --- | --- |
| Soundscaper | .sscape, progetti Audacity, Audio, Video, Etichette | .sscape, AUP4 (solo audio), Audio, Video, Etichette, Stems audio |
| Framescaper | .fscape, progetti Audacity, Audio, Video, Etichette | .fscape, Audio, Video, Etichette |

Le famiglie descrivono i punti di ingresso del prodotto, non ogni estensione file che un decoder potrebbe accettare. Consulta [Formati di esportazione](/reference/generated/formats/) per i formati di output concreti e le condizioni di runtime.
