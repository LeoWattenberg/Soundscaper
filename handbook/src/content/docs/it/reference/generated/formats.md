Questi sono i formati concreti registrati dal runtime di export corrente. La disponibilità dei prodotti deriva dai profili di prodotto.

“Integrato” significa che l'applicazione dispone di un writer nativo per quel formato. “Richiede runtime FFmpeg” è una condizione: la tabella non garantisce che il runtime FFmpeg possa essere caricato in ogni build o ambiente, né che un runtime di sostituzione arbitrario contenga l'encoder e il muxer elencati.

I file di progetto e i file di etichetta sono elencati separatamente in [File di progetto e di etichetta](/reference/generated/project-files/).
