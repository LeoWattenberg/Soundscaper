L'editor funziona in un browser e come applicazione desktop. Questa pagina elenca ciò che è stato costruito e testato, non ogni ambiente in cui il codice potrebbe funzionare.

## Browser

“Testato automaticamente” significa che il set di browser viene eseguito contro questo motore su ogni richiesta di pull. Un motore che non è elencato non è testato e non è garantito che funzioni.

| Motore del browser | Testato automaticamente |
| --- | --- |
| Chromium (Chrome, Edge) | Sì |
| Firefox | Sì |
| WebKit (Safari) | Sì |

## Dove può essere eseguita una capacità

Le capacità sono raggruppate in base a ciò di cui hanno bisogno dalla piattaforma. Vedi [Capacità del prodotto](/reference/generated/product-capabilities/) per scoprire quali capacità consente ciascun prodotto.

| Livello | Cosa significa |
| --- | --- |
| `web-core` | Funziona in ogni browser supportato, senza funzionalità facoltativa della piattaforma richiesta. |
| `web-enhanced` | Funziona in un browser che fornisce le nuove funzionalità di archiviazione e multimediali necessarie per la capacità. |
| `electron-enhanced` | Funziona nel browser, e l'applicazione desktop ne fa di più. |
| `electron-only` | Richiede l'applicazione desktop, poiché un browser non può raggiungere ciò che la capacità utilizza. |
