Un workspace è una disposizione salvata dei pannelli e delle barre degli strumenti attorno alla timeline. La scelta di uno sostituisce la disposizione attuale; è quindi possibile spostare qualsiasi elemento e salvare il proprio workspace, cosa che questa pagina non descrive.

## Workspaces integrati

| --- | --- | --- |
| Classic | `workspace-classic` | Soundscaper, Framescaper |
| Music | `workspace-music` | Soundscaper, Framescaper |
| Soundscaper | `workspace-modern` | Soundscaper, Framescaper |
| Audacity | `workspace-audacity` | Soundscaper, Framescaper |
| Video editor | `workspace-video-editor` | Framescaper |

## Dock

Un pannello occupa una di queste posizioni. “Fluttuante” significa una finestra di pannello che è possibile posizionare liberamente.

| Dock | ID dock |
| --- | --- |
| Sinistra | `left` |
| Destra | `right` |
| In basso | `bottom` |
| Fluttuante | `floating` |
