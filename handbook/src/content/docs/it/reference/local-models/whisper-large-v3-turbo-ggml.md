## Scopo e caso d’uso {#purpose-and-use-case}

Trascrivi il discorso selezionato localmente tramite il runtime whisper.cpp incorporato.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore whisper-cpp v1.9.3 richiesto per macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo. La build desktop non offre un motore scaricabile per macOS x64, anche se i pesi del modello sono elencati per questa piattaforma.

## Utilizza questo modello {#use-this-model}

Apri **Analizza → Discorso → Trascrizione & Sottotitoli** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona il discorso e installa Whisper large-v3 turbo tramite Gestione Modelli.
2. Scegli questo modello di riconoscimento vocale sotto Strumenti → Elaborazione Locale Avanzata quando desideri selezionare esplicitamente Whisper.
3. Esegui localmente e rivedi sia il testo che i confini dei segmenti prima di accettare.

## Rivedi il risultato {#review-the-result}

- Whisper può produrre testo errato, specialmente su rumore o materiale senza discorso chiaro. Ascolta mentre rivedi.
- Il test controlla che il runtime reale restituisca una trascrizione temporizzata non vuota; non garantisce tuttavia una particolare ortografia o punteggio di riconoscimento.
