## Scopo e caso d’uso {#purpose-and-use-case}

Trasforma il parlato selezionato in una trascrizione temporizzata per sottotitoli e modifica delle trascrizioni.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore sherpa-onnx-node 1.13.5 richiesto per macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo. La build desktop non offre un motore scaricabile per macOS x64, anche se i pesi del modello sono elencati per questa piattaforma.

## Utilizza questo modello {#use-this-model}

Apri **Analyze → Speech → Transcribe & Captions** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona il parlato da trascrivere.
2. Usa Manage Models per installare questo modello. Tools → Advanced Local Processing consente di scegliere un modello specifico per il riconoscimento vocale.
3. Esegui localmente, quindi rivedi testo e tempi prima di accettare la trascrizione.

Identità del modello: `parakeet-tdt-0.6b-v2`, versione **2.0.0**.

Dimensione approssimativa del download dell’artefatto del modello: **630.56 MiB**. Il runtime richiesto si aggiunge al primo download se non è già installato. Memoria minima di sistema: **4 GiB**. Questo requisito del catalogo si riferisce alla memoria totale, non a quella attualmente libera. L’inferenza richiede anche memoria libera sufficiente e l’installazione spazio di lavoro; la memoria non garantisce la velocità.

Piattaforme pubblicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. È richiesto anche un runtime scaricabile compatibile.

Su Windows, installa l’ultimo [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) supportato e corrispondente all’app desktop: **x64** per una build x64 o **ARM64** per una build ARM64. I motori nativi ONNX e Sherpa richiedono queste librerie; i download del modello e del runtime non le includono. Visual Studio non è necessario per usare l’app.
