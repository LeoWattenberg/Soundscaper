## Scopo e caso d’uso {#purpose-and-use-case}

Trova i battiti musicali con il modello opzionale più grande Beat This.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore onnxruntime-node 1.29.0 richiesto per macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo.

## Utilizza questo modello {#use-this-model}

Apri **Strumenti → Elaborazione locale avanzata → Rilevamento battiti** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona la musica con un passaggio ritmico chiaro.
2. Installa Beat This finale tramite Model Manager e scegli la sua identità del modello esatta.
3. Rivedi i battiti proposti e il tempo rispetto alla musica prima di accettarli.

## Download e requisiti {#download-and-requirements}

Identità del modello: `beat-this-final0`, versione **1.1.0**.

Dimensione approssimativa del download dell’artefatto del modello: **79.32 MiB**. Il runtime richiesto si aggiunge al primo download se non è già installato. Memoria minima di sistema: **4 GiB**. Questo requisito del catalogo si riferisce alla memoria totale, non a quella attualmente libera. L’inferenza richiede anche memoria libera sufficiente e l’installazione spazio di lavoro; la memoria non garantisce la velocità.

Piattaforme pubblicate: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. È richiesto anche un runtime scaricabile compatibile.

Su Windows, installa l’ultimo [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) supportato e corrispondente all’app desktop: **x64** per una build x64 o **ARM64** per una build ARM64. I motori nativi ONNX e Sherpa richiedono queste librerie; i download del modello e del runtime non le includono. Visual Studio non è necessario per usare l’app.

Strumenti → Gestione modelli scarica gli artefatti pubblicati del modello e il runtime richiesto alla prima installazione, quindi verifica gli hash SHA-256 registrati. L’elaborazione usa i file installati localmente. Apri Archiviazione e verifica in Gestione modelli per consultare gli avvisi, riparare un’installazione o cambiare la posizione di archiviazione.
