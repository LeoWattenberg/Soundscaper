## Scopo e caso d’uso {#purpose-and-use-case}

Riduci il rumore di fondo nel dialogo con un modello locale di miglioramento del parlato.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore onnxruntime-node 1.29.0 richiesto per macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo. La build desktop non offre un motore scaricabile per macOS x64, anche se i pesi del modello sono elencati per questa piattaforma.

## Utilizza questo modello {#use-this-model}

Apri **Effetto → Rimozione e riparazione rumore → Migliora Dialogo** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona il dialogo che desideri migliorare.
2. Installa DeepFilterNet3 tramite Gestione Modelli e scegli Esegui localmente.
3. Ascolta il risultato proposto rispetto all'originale prima di applicarlo. L'annullamento ripristina un'edit di progetto accettato.

## Download e requisiti {#download-and-requirements}

Identità del modello: `deepfilternet3`, versione **3.0.0**.

Dimensione approssimativa del download dell’artefatto del modello: **8.33 MiB**. Il runtime richiesto si aggiunge al primo download se non è già installato. Memoria minima di sistema: **2 GiB**. Questo requisito del catalogo si riferisce alla memoria totale, non a quella attualmente libera. L’inferenza richiede anche memoria libera sufficiente e l’installazione spazio di lavoro; la memoria non garantisce la velocità.

Piattaforme pubblicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. È richiesto anche un runtime scaricabile compatibile.

Su Windows, installa l’ultimo [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) supportato e corrispondente all’app desktop: **x64** per una build x64 o **ARM64** per una build ARM64. I motori nativi ONNX e Sherpa richiedono queste librerie; i download del modello e del runtime non le includono. Visual Studio non è necessario per usare l’app.

Strumenti → Gestione modelli scarica gli artefatti pubblicati del modello e il runtime richiesto alla prima installazione, quindi verifica gli hash SHA-256 registrati. L’elaborazione usa i file installati localmente. Apri Archiviazione e verifica in Gestione modelli per consultare gli avvisi, riparare un’installazione o cambiare la posizione di archiviazione.

## Rivedi il risultato {#review-the-result}

- Questo modello è per il miglioramento del parlato. Non è un denoisatore musicale o uno strumento di ripristino basato sul profilo del rumore.
- Un output udibilmente modificato mostra che l'elaborazione è stata eseguita, ma non dimostra che tutto il rumore sia stato rimosso o che nessun dettaglio desiderato sia stato perso.
