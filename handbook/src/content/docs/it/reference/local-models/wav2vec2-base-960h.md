Allinea una trascrizione inglese esistente alle parole pronunciate in una registrazione.

## Disponibilità attuale {#current-availability}

Le compilazioni desktop includono il motore onnxruntime-node 1.29.0 richiesto per macOS arm64, Linux x64, Linux arm64, Windows x64 e Windows arm64. Installa i pesi di questo modello tramite Model Manager e poi esegui il task localmente. Questi sono i target di compilazione supportati; consulta il rapporto di test notturno per i risultati su un particolare pacchetto e macchina.

## Utilizza questo modello {#use-this-model}

Apri **Analizza → Voce → Trascrizione e sottotitoli, o Strumenti → Elaborazione locale avanzata → Allineamento parole** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona la voce e prepara o rivedi la sua trascrizione inglese.
2. Installa il modello di allineamento tramite Model Manager.
3. Esegui l'allineamento, poi ascolta mentre rivedi i confini di parola proposti prima di accettarli.

## Cosa controlla il test imballato {#what-the-packaged-test-checks}

Caso: `wav2vec2-word-alignment`; operazione: `word-alignment`.

Input: Il discorso di Kennedy di pubblico dominio a 16 kHz, insieme alla sua nota trascrizione inglese come input autenticato separato.

Ogni parola fornita deve essere rappresentata con una tempistica ordinata valida all'interno dell'audio; non sono prescritti tempi di allineamento esatti.

Il pacchetto nightly-with-tests scarica artefatti del modello reali e richiede l'inferenza attraverso il runtime imballato. Un modello richiesto mancante dal catalogo fa fallire il suo caso. I motori nativi mancanti falliscono sulle piattaforme supportate dal catalogo. Questi controlli costosi vengono eseguiti separatamente dal normale suite del browser. Un'esecuzione riuscita conferma l'esecuzione di base del modello e la struttura di output utilizzabile; non stabilisce la qualità percettiva o l'accuratezza sulla tua registrazione.

## Rivedi il risultato {#review-the-result}

- Questo modello allinea le parole inglesi fornite; non traduce o ripara una trascrizione errata.
- Le parole ripetute, la voce di sottofondo e le parole mancanti nella trascrizione possono produrre confini errati. Il test controlla i tempi di parola ordinati e validi contro l'inventario di parole fornito, non una corrispondenza di tempistica perfetta.
