## Scopo e caso d’uso {#purpose-and-use-case}

Leggi il testo visibile dai fotogrammi video campionati per la revisione e l'indicizzazione.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore onnxruntime-node 1.29.0 richiesto per macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo. La build desktop non offre un motore scaricabile per macOS x64, anche se i pesi del modello sono elencati per questa piattaforma.

## Utilizza questo modello {#use-this-model}

Apri **Framescaper: Strumenti → Ricerca → Indice Video, o Strumenti → Elaborazione locale avanzata → Riconoscimento ottico dei caratteri** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona il video che contiene testo leggibile sullo schermo.
2. Installa PP-OCRv4 mobile tramite Gestione Modelli. È un passaggio opzionale di Indice Video, che utilizza anche SigLIP2.
3. Esegui localmente e rivedi il testo riconosciuto e le sue posizioni nei fotogrammi prima di accettare i risultati.

Identità del modello: `ppocr-v4-mobile`, versione **4.0.0**.

Dimensione approssimativa del download dell’artefatto del modello: **15.46 MiB**. Il runtime richiesto si aggiunge al primo download se non è già installato. Memoria minima di sistema: **2 GiB**. Questo requisito del catalogo si riferisce alla memoria totale, non a quella attualmente libera. L’inferenza richiede anche memoria libera sufficiente e l’installazione spazio di lavoro; la memoria non garantisce la velocità.

Piattaforme pubblicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. È richiesto anche un runtime scaricabile compatibile.

Su Windows, installa l’ultimo [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) supportato e corrispondente all’app desktop: **x64** per una build x64 o **ARM64** per una build ARM64. I motori nativi ONNX e Sherpa richiedono queste librerie; i download del modello e del runtime non le includono. Visual Studio non è necessario per usare l’app.

Caso: `ppocr-recognized-text`; operazione: `optical-character-recognition`.

Input: Fotogrammi con le parole ad alto contrasto “TESTO MODELLO LOCALE”, con tempistica esplicita del fotogramma di origine.

Le regioni di testo devono contenere testo riconosciuto non vuoto, tempistica del fotogramma di origine valida, punteggi di fiducia finiti e caselle delimitatrici.

## Rivedi il risultato {#review-the-result}

- Il testo piccolo, sfocato, ruotato, stilizzato o parzialmente nascosto può essere perso o letto erroneamente.
- Il test confezionato richiede regioni di testo, quindi il rilevatore, il modello di orientamento e il riconoscitore vengono tutti eseguiti. Non richiede una corrispondenza carattere per carattere.
