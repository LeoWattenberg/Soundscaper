## Scopo e caso d’uso {#purpose-and-use-case}

Rappresenta fotogrammi video campionati e testo in uno spazio numerico condiviso per la ricerca visiva locale.

## Disponibilità attuale {#current-availability}

Le build desktop possono scaricare e autenticare il motore onnxruntime-node 1.29.0 richiesto per macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installa questo modello e il runtime richiesto tramite Gestione modelli, poi esegui l’attività localmente. Queste sono le piattaforme di build supportate; consulta il rapporto dei test notturni per i risultati di uno specifico pacchetto e dispositivo. La build desktop non offre un motore scaricabile per macOS x64, anche se i pesi del modello sono elencati per questa piattaforma.

## Utilizza questo modello {#use-this-model}

Apri **Framescaper: Tools → Search → Video Index, then Tools → Search → Indexed Search** su una piattaforma con il runtime nativo richiesto. L'assistenza locale funziona nell'editor desktop.

1. Seleziona un video e installa SigLIP2 tramite Model Manager.
2. Esegui Video Index per analizzare i fotogrammi campionati. Se esegui il passaggio opzionale di lettura del testo, installa anche PP-OCRv4.
3. Usa Indexed Search per esaminare i momenti video corrispondenti e decidere come utilizzarli.

Dimensione approssimativa del download dell’artefatto del modello: **393.25 MiB**. Il runtime richiesto si aggiunge al primo download se non è già installato. Memoria minima di sistema: **8 GiB**. Piattaforme pubblicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. È richiesto anche un runtime scaricabile compatibile.
