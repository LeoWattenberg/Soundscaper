This walkthrough creates a project from an existing audio file. Recording is
covered separately.

## 1. Create or open a project

Open Soundscaper. The editor starts with a local project. To start another one,
choose **File → New project**.

Projects are saved into the local project library as you work. The status area
shows whether project saving is in progress or complete.

## 2. Import media

Choose **File → Import audio**, then select an audio file. Imported material
appears in the project and can also be organized in the Project Bin.

For Audacity projects, use **File → Audacity projects** and choose the matching
AUP, AUP3, or AUP4 import command. Legacy AUP projects also require their
matching `_data` directory.

## 3. Make an edit

Select a time range or clip, then use the **Edit** menu. Useful first commands
include **Cut**, **Copy**, **Paste**, **Split at playhead**, and the delete
variants that either leave or close a gap.

Undo and redo operate on the current project. A command can be unavailable
until the required track, clip, or time range is selected.

## 4. Listen and export

Use the transport controls to play the project. When it is ready, choose
**File → Export audio**, choose a format and output settings, and export the
rendered file.

An audio export is a delivery copy, not an editable backup. Also export a
[`.sscape` project file](/projects-and-data/project-files/) for important work.

Working with picture rather than sound? Start with
[your first Framescaper project](/framescaper/first-project/) instead.
