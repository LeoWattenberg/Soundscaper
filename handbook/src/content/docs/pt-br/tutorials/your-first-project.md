Este tutorial faz uma passagem completa pelo editor em um loop de música de dois segundos: importando um arquivo, ouvindo-o, alterando-o com um efeito, cortando-o ao meio, renderizando um arquivo que pode ser reproduzido em qualquer lugar e salvando o projeto para que você possa retorná-lo. Não é necessário ter conhecimento de áudio; é um passeio pelos recursos do programa.

:::tip[O que você precisará]
- Baixe [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) — um loop estéreo de dois segundos.

Todos os passos abaixo funcionam nesses arquivos exatamente como estão, então o que você vê deve corresponder ao que o tutorial diz. O Soundscaper roda no navegador; não é necessário instalar nada.
:::

## O que você aprenderá

- Como um arquivo se torna um clipe em uma faixa e como reproduzi-lo.
- Como dividir um clipe com a ferramenta de divisão.
- Como selecionar áudio e aplicar um efeito à seleção.
- A diferença entre exportar um arquivo e salvar um projeto.

## Passos

1. Abra o Soundscaper. Um novo projeto vazio estará pronto assim que o editor carregar.
2. Escolha **Arquivo → Importar** e selecione `guide-music-loop.wav` — um loop estéreo de dois segundos. Ele será colocado como um clipe em sua própria faixa.
3. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O cursor de reprodução atravessa o clipe e o loop é reproduzido uma vez.
4. Pressione o botão **Ferramenta de Divisão** na barra de ferramentas. Enquanto a ferramenta de divisão estiver ativa, um clique em um clipe o cortará nesse ponto em vez de selecioná-lo.
5. Clique na forma de onda aproximadamente no meio para posicionar o cursor.
6. Pressione o botão **Ferramenta de Divisão** na barra de ferramentas novamente. Pressione-o novamente para retornar ao ponteiro normal.
7. Agora o projeto mostra 2 clipes.
   *Você deve ver:* Dois clipes estão lado a lado onde havia um, cada um com sua própria barra de nome.
8. Escolha **Selecionar → Selecionar tudo**. Um efeito é aplicado ao que estiver selecionado. Selecionar tudo leva todo o projeto, incluindo ambos os clipes.
9. Escolha **Efeito → Desvanecimento → Desvanecer para fora**. O efeito é aplicado à seleção imediatamente.
   *Você deve ver:* A forma de onda diminui até o nada no final do segundo clipe.
10. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O loop diminui em volume em vez de parar abruptamente.
11. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **WAV** e pressione **Exportar**. O arquivo é baixado assim que o render termina, e seu link permanece no diálogo. Uma exportação renderiza o que você ouve em um arquivo para outros programas. Isso não altera o projeto.
12. Escolha **Arquivo → Salvar projeto**. O indicador de salvamento na barra de status mostra que o projeto foi salvo. O projeto — clipes, edições, histórico — vive na biblioteca de projetos do navegador neste computador. Salvar mantém-no aqui.
