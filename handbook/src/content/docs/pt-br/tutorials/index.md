Um tutorial é uma lição: ele o guia através de uma peça completa de trabalho em um exemplo fornecido pelo manual, passo a passo, e diz o que você deve ver ao longo do caminho. Comece aqui se você nunca usou o Soundscaper antes. Quando você souber como navegar e tiver sua própria gravação, os [guias de como fazer](/guides/) cobrem as mesmas operações e muitas outras, uma tarefa de cada vez.

- [Seu primeiro projeto no Soundscaper](/tutorials/your-first-project/) — Importe uma gravação, ouça-a, divida-a, aplique um fade out, exporte um arquivo e salve o projeto.
- [Limpe uma gravação de voz](/tutorials/clean-up-a-voice-recording/) — Remova o zumbido de uma tomada, corte o ruído, ajuste o volume para o padrão de podcast e exporte um MP3.
- [Coloque música sob uma voz](/tutorials/put-music-under-a-voice/) — Sobreponha duas faixas, reduza automaticamente uma sob a outra, misture-as e exporte.
