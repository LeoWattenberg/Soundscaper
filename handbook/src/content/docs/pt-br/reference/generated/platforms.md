O editor funciona em um navegador e como um aplicativo de área de trabalho. Esta página lista o que é construído e testado, e não todos os ambientes nos quais o código pode funcionar.

## Navegadores

“Testado automaticamente” significa que o conjunto de testes do navegador é executado contra este mecanismo em cada solicitação de pull. Um mecanismo que não está listado não é testado e não é garantido que funcione.

| Motor do navegador | Testado automaticamente |
| --- | --- |
| Chromium (Chrome, Edge) | Sim |
| Firefox | Sim |
| WebKit (Safari) | Sim |

## Onde uma capacidade pode ser executada

As capacidades são agrupadas pelo que precisam da plataforma. Consulte [Capacidades do produto](/reference/generated/product-capabilities/) para ver quais capacidades cada produto habilita.

| Nível | O que significa |
| --- | --- |
| `web-core` | Funciona em todos os navegadores suportados, sem recursos opcionais da plataforma necessários. |
| `web-enhanced` | Funciona em um navegador que fornece os recursos de armazenamento e mídia mais recentes necessários para a capacidade. |
| `electron-enhanced` | Funciona no navegador e o aplicativo de área de trabalho faz mais com ele. |
| `electron-only` | Requer o aplicativo de área de trabalho, pois um navegador não pode acessar o que a capacidade utiliza. |
