## Finalidade e caso de uso {#purpose-and-use-case}

Separe uma trilha sonora mista em diálogos, música e efeitos sonoros.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos.

## Utilize este modelo {#use-this-model}

Abra **Ferramentas → Processamento Local Avançado → Separação de Fontes** em uma plataforma com o tempo de execução nativo necessário. A assistência local funciona no editor de desktop.

1. Selecione o áudio misto a ser separado.
2. Instale o TIGER através do Gerenciador de Modelos e execute a separação de fontes.
3. Ouça cada proposta de stem antes de adicionar os resultados desejados ao projeto.

## Download e requisitos {#download-and-requirements}

Identidade do modelo: `tiger-dnr`, versão **1.0.0**.

Tamanho aproximado do download do artefato do modelo: **28.25 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **4 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; memória não garante velocidade.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Também é necessário um runtime correspondente que possa ser baixado.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatível mais recente para o aplicativo de desktop: **x64** para uma versão x64 ou **ARM64** para uma versão ARM64. Os mecanismos nativos ONNX e Sherpa precisam dessas bibliotecas; os downloads do modelo e do runtime não as incluem. O Visual Studio não é necessário para usar o aplicativo.

Ferramentas → Gerenciador de Modelos baixa os artefatos publicados do modelo e o runtime necessário na primeira instalação e verifica os resumos SHA-256 registrados. O processamento usa os arquivos instalados localmente. Abra Armazenamento e verificação no Gerenciador de Modelos para consultar avisos, reparar uma instalação ou alterar o local de armazenamento.

## Revise o resultado {#review-the-result}

- A separação pode deixar vazamentos ou artefatos; não é a recuperação sem perdas das faixas de gravação originais.
- O teste de fixação mista requer os três stems, áudio finito corretamente dimensionado e amostras alteradas e não silenciosas em cada stem. Ele também rejeita stems duplicados; não mede a qualidade da separação.
