## Finalidade e caso de uso {#purpose-and-use-case}

Transcreva localmente o discurso selecionado através do tempo de execução empacotado whisper.cpp.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo whisper-cpp v1.9.3 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A versão para desktop não oferece um mecanismo baixável para macOS x64, embora os pesos do modelo estejam listados para essa plataforma.

## Use este modelo {#use-this-model}

Abra **Analisar → Discurso → Transcrever & Legendas** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Selecione o discurso e instale o Whisper large-v3 turbo através do Gerenciador de Modelos.
2. Escolha este modelo de reconhecimento de fala sob Ferramentas → Processamento Local Avançado quando você quiser selecionar o Whisper explicitamente.
3. Execute localmente e revise tanto o texto quanto os limites de segmento antes de aceitar.
