## Finalidade e caso de uso {#purpose-and-use-case}

Localize rostos e objetos em quadros de vídeo amostrados para ajudar a propor um novo enquadramento.

O D-FINE detecta categorias de objetos e seus locais. A operação de detecção de assunto combina esses resultados com as detecções de rostos YuNet.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A versão para desktop não oferece um mecanismo baixável para macOS x64, embora os pesos do modelo estejam listados para essa plataforma.

## Use este modelo {#use-this-model}

Abra o **Framescaper: Efeito → Efeitos de vídeo → Reframe** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Selecione um clipe de vídeo no Framescaper.
2. Instale o YuNet e o D-FINE para detecção de assunto. A tarefa Reframe guiada também usa a detecção de saliência U²-Net-P.
3. Execute localmente e revise a cultura proposta. Ferramentas → Processamento Local Avançado pode executar a detecção de assunto por conta própria.

Esta operação também requer [detecção de rosto YuNet](/reference/local-models/yunet-face-detection-2026may/).

## Download e requisitos {#download-and-requirements}

Identidade do modelo: `dfine-nano-coco`, versão **1.0.0**.

Tamanho aproximado do download do artefato do modelo: **14.56 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **2 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; memória não garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Também é necessário um runtime correspondente que possa ser baixado.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatível mais recente para o aplicativo de desktop: **x64** para uma versão x64 ou **ARM64** para uma versão ARM64. ## Revise o resultado {#review-the-result}

- Rostos e objetos podem ser perdidos ou classificados incorretamente. A detecção é amostrada e não garante que um assunto em movimento permaneça dentro de cada cultura proposta.
- A operação executa ambos os modelos juntos; nenhum modelo é um sistema de reconhecimento facial para identificar pessoas.
