## Finalidade e caso de uso {#purpose-and-use-case}

Represente imagens de vídeo amostradas e texto em um espaço numérico compartilhado para busca visual local.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A versão para desktop não oferece um mecanismo baixável para macOS x64, embora os pesos do modelo estejam listados para essa plataforma.

## Use este modelo {#use-this-model}

Abra **Framescaper: Ferramentas → Busca → Indexar Vídeo, depois Ferramentas → Busca → Busca Indexada** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Selecione um vídeo e instale o SigLIP2 pelo Gerenciador de Modelos.
2. Execute Indexar Vídeo para analisar os quadros amostrados. Instale também o PP-OCRv4 se quiser sua etapa opcional de leitura de texto.
3. Use Busca Indexada e revise os momentos correspondentes do vídeo antes de decidir como usá-los.

Identidade do modelo: `siglip2-base-patch16-224`, versão **2.0.0**.

Tamanho aproximado do download do artefato do modelo: **393.25 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **8 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento.
