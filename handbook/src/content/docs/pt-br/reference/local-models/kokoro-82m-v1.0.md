## Finalidade e caso de uso {#purpose-and-use-case}

Gere um clipe de fala a partir de um roteiro usando um idioma e uma voz selecionados.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o auxiliar G2P offline do Kokoro junto com o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instale o modelo e os runtimes necessários pelo Gerenciador de Modelos e gere a fala localmente. Consulte o relatório noturno para ver os resultados reais de texto para WAV de cada pacote e computador.

## Use este modelo {#use-this-model}

Abra **Gerar → Texto para Fala** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Digite um roteiro e escolha um dos pares de idioma e voz publicados.
2. Instale o modelo Kokoro pelo Gerenciador de Modelos.
3. Gere e ouça uma prévia; depois adicione-a a uma nova faixa ou gere novamente o clipe gerado selecionado.

<details id="what-the-packaged-test-checks">
<summary>O que o teste para desktop verifica</summary>

Caso: `kokoro-speech-generation`; operação: `text-to-speech`.

Entrada: nove roteiros curtos em UTF-8, um para cada variante de idioma do Kokoro v1.0, cada um associado a uma voz publicada correspondente na velocidade 1.

Cada uma das nove vozes Kokoro selecionadas deve produzir áudio PCM mono de 24 kHz, sem silêncio, com amplitude limitada e em um contêiner WAV válido. O teste exige um tempo de execução G2P offline completo e não pode ser satisfeito por uma resposta de adaptador indisponível ou por um modelo substituto.

O pacote nightly-with-tests baixa os artefatos reais do modelo e runtimes verificados antes da inferência. O caso obrigatório envia um texto em cada uma das nove variantes de idioma pelo auxiliar G2P baixado e verifica os WAVs resultantes. Se o auxiliar estiver ausente ou tiver sido alterado, o caso falha de forma segura. Essas verificações dispendiosas são executadas separadamente da suíte normal do navegador. Uma execução aprovada confirma a geração básica de fala para essas vozes selecionadas, não a pronúncia nem a qualidade perceptiva.

## Revise o resultado {#review-the-result}

- O modelo tem uma entrada no catálogo, mas o auxiliar offline autenticado de grafema para fonema do Kokoro também precisa ser empacotado para o destino de desktop selecionado. Um pacote sem esse auxiliar falha com segurança mesmo depois da instalação dos pesos.
- A pronúncia e a forma de falar geradas podem variar conforme o idioma e a voz. O teste empacotado exige um WAV mono de 24 kHz sem silêncio para uma voz selecionada em cada uma das nove variantes de idioma; ele não testa todas as 54 vozes nem estabelece naturalidade ou qualidade de pronúncia.
