## Finalidade e caso de uso {#purpose-and-use-case}

Reduza as reflexões da sala em discursos gravados com um modelo local de desreverberação.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos.

## Utilize este modelo {#use-this-model}

Abra **Ferramentas → Processamento Local Avançado → Desreverberação** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Selecione o discurso afetado pelas reflexões da sala.
2. Instale o modelo através do Gerenciador de Modelos e execute a desreverberação.
3. Compare o resultado com o original e aceite-o apenas se o discurso soar melhor.

## Download e requisitos {#download-and-requirements}

Identidade do modelo: `dereverb-room`, versão **1.0.0**.

Tamanho aproximado do download do artefato do modelo: **114.57 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **2 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; memória não garante velocidade.

Plataformas publicadas: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Também é necessário um runtime correspondente que possa ser baixado.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatível mais recente para o aplicativo de desktop: **x64** para uma versão x64 ou **ARM64** para uma versão ARM64. Os mecanismos nativos ONNX e Sherpa precisam dessas bibliotecas; os downloads do modelo e do runtime não as incluem. O Visual Studio não é necessário para usar o aplicativo.

Ferramentas → Gerenciador de Modelos baixa os artefatos publicados do modelo e o runtime necessário na primeira instalação e verifica os resumos SHA-256 registrados. O processamento usa os arquivos instalados localmente. Abra Armazenamento e verificação no Gerenciador de Modelos para consultar avisos, reparar uma instalação ou alterar o local de armazenamento.

<summary>O que o teste para desktop verifica</summary>

Caso: `dereverb-room-speech`; operação: `dereverberation`.

Entrada: O discurso de Kennedy ressamplerado para 44,1 kHz com quatro reflexos atrasados reprodutíveis.

O áudio decodificado deve conter amostras finitas, preservar a geometria de áudio esperada, diferir das amostras de entrada e ter um sinal audível não nulo. Cabeçalhos de arquivo diferentes por si só não contam como uma alteração.

O pacote nightly-with-tests baixa os artefatos reais do modelo e runtimes verificados antes da inferência. Se um modelo necessário estiver ausente do catálogo, o caso correspondente falha. A ausência de mecanismos nativos causa falhas nas plataformas compatíveis com o catálogo. Essas verificações dispendiosas são executadas separadamente da suíte normal do navegador. Uma execução aprovada confirma o funcionamento básico do modelo e uma estrutura de saída utilizável; não comprova a qualidade perceptiva nem a precisão na sua gravação.

## Revise o resultado {#review-the-result}

- Reflexões fortes, música e salas desconhecidas podem produzir artefatos ou remover detalhes desejados.
- Áudio alterado, não silencioso, confirma o processamento, não a remoção completa da reverb ou a melhoria perceptual.
- O modelo declara GPL-3.0; preserve sua licença e instruções de fonte correspondente ao redistribuir. O corpus de treinamento seco e a linhagem do ponto de verificação base são desconhecidos.
