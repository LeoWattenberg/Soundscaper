## Finalidade e caso de uso {#purpose-and-use-case}

Crie representações numéricas locais de trechos de transcrição e consultas de busca para pesquisa semântica.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo onnxruntime-node 1.29.0 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A versão para desktop não oferece um mecanismo baixável para macOS x64, embora os pesos do modelo estejam listados para essa plataforma.

## Use este modelo {#use-this-model}

Abra **Ferramentas → Busca → Indexar Transcrição, depois Ferramentas → Busca → Busca Indexada** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Crie ou importe uma transcrição e instale o Nomic Embed Text pelo Gerenciador de Modelos.
2. Execute Indexar Transcrição para preparar o texto para a pesquisa semântica.
3. Use Busca Indexada e revise os trechos encontrados no contexto. O Processamento Local Avançado também disponibiliza a operação de incorporação.

## Download e requisitos {#download-and-requirements}

Identidade do modelo: `nomic-embed-text-v1.5`, versão **1.5.0**.

Tamanho aproximado do download do artefato do modelo: **131.62 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **4 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; memória não garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Também é necessário um runtime correspondente que possa ser baixado.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatível mais recente para o aplicativo de desktop: **x64** para uma versão x64 ou **ARM64** para uma versão ARM64. Os mecanismos nativos ONNX e Sherpa precisam dessas bibliotecas; os downloads do modelo e do runtime não as incluem. O Visual Studio não é necessário para usar o aplicativo.

## Revise o resultado {#review-the-result}

- As incorporações são dados numéricos para busca, não uma transcrição reescrita nem uma resposta gerada.
- Os trechos relacionados podem receber classificações diferentes entre execuções ou gravações. Vetores finitos e não constantes validam a execução, não a relevância de cada resultado.
