## Finalidade e caso de uso {#purpose-and-use-case}

Forneça outro modelo local de reconhecimento de fala para transcrições e legendas.

## Disponibilidade atual {#current-availability}

As versões para desktop podem baixar e autenticar o mecanismo sherpa-onnx-node 1.13.5 necessário para macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instale este modelo e o runtime necessário pelo Gerenciador de Modelos e execute a tarefa localmente. Essas são as plataformas de build compatíveis; consulte o relatório de testes noturnos para ver os resultados de um pacote e computador específicos. A versão para desktop não oferece um mecanismo baixável para macOS x64, embora os pesos do modelo estejam listados para essa plataforma.

## Use este modelo {#use-this-model}

Abra **Analisar → Fala → Transcrever & Legendas** em uma plataforma com o tempo de execução nativo necessário. A assistência local é executada no editor de desktop.

1. Selecione uma região com fala.
2. Instale o Parakeet v3 através do Gerenciador de Modelos. Escolha a identidade do modelo exata em Ferramentas → Processamento Local Avançado ao comparar modelos.
3. Execute localmente e revise a transcrição proposta antes de aplicá-la.

## Download e requisitos {#download-and-requirements}

Identidade do modelo: `parakeet-tdt-0.6b-v3`, versão **3.0.0**.

Tamanho aproximado do download do artefato do modelo: **639.42 MiB**. O runtime necessário é acrescentado ao primeiro download se ainda não estiver instalado. Memória mínima do sistema: **4 GiB**. Esse requisito do catálogo se refere à memória total, não à memória livre no momento. A inferência também precisa de memória livre suficiente e a instalação precisa de espaço de trabalho; memória não garante velocidade.

Plataformas publicadas: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Também é necessário um runtime correspondente que possa ser baixado.

No Windows, instale o [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) compatível mais recente para o aplicativo de desktop: **x64** para uma versão x64 ou **ARM64** para uma versão ARM64. Os mecanismos nativos ONNX e Sherpa precisam dessas bibliotecas; os downloads do modelo e do runtime não as incluem. O Visual Studio não é necessário para usar o aplicativo.

Ferramentas → Gerenciador de Modelos baixa os artefatos publicados do modelo e o runtime necessário na primeira instalação e verifica os resumos SHA-256 registrados. O processamento usa os arquivos instalados localmente. Abra Armazenamento e verificação no Gerenciador de Modelos para consultar avisos, reparar uma instalação ou alterar o local de armazenamento.
