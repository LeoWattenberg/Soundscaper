Uma gravação feita com o ganho muito baixo é silenciosa, mas geralmente limpa. Amplificar aumenta tudo na mesma quantidade, em decibéis, então o equilíbrio dentro da gravação permanece exatamente como estava. Deixe o clipping desligado e o efeito se recusa a empurrar os picos além do nível máximo. 

:::nota[Vindo do Audacity?]
Este é o **Efeito → Volume e Compressão → Amplificar** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação silenciosa. O arquivo é colocado como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Volume e compressão → Amplificar**. No diálogo **Amplificar**, defina a **Amplificação** para `6`, então pressione **Aplicar à seleção**. Seis decibéis aumentam aproximadamente o volume. **Permitir clipping** permanece desligado, então o efeito não distorce os picos.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* A gravação está visivelmente mais alta e a forma de onda é mais alta.

## Dicas

- Se o resultado ainda estiver muito silencioso, execute o Amplificar novamente; os ganhos se acumulam.
- Para trazer os picos a um nível exato em vez de adicionar uma quantidade fixa, use [Normalizar](/guides/volume/normalize-peaks/) em vez disso.
