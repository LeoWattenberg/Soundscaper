Todo episódio recebe o mesmo tratamento: normalizar, desvanecer o final. Uma macro grava essa sequência uma vez e a executa sempre que você solicitar, com as configurações escolhidas, então uma rotina de dez etapas se torna um único comando. O Audacity 3 tinha um Gerenciador de Macros para exatamente isso; o Audacity 4 ainda não trouxe de volta as macros.

:::nota[Vindo do Audacity?]
Isto é **Ferramentas → Macros → Gerenciar Macros e Aplicar Macro (Audacity 3; Audacity 4 não possui macros)**. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione uma gravação para processar. O arquivo é inserido como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**. Uma macro é executada na seleção, assim como cada efeito seria individualmente.
4. Escolha **Ferramentas → Gerenciador de Macros** e pressione **Nova macro**. Digite `Episode finish` em **Nome da Macro**. Pressione **Adicionar efeito** e escolha **Normalizar** e **Desvanecer**, pressionando **Adicionar efeito** novamente para cada um. Pressione **Executar macro**; a caixa de diálogo informa que a macro foi aplicada. Pressione **Fechar**. Cada etapa mantém suas configurações padrão aqui; pressione o botão **Selecionar efeito** de uma etapa para alterá-las antes de executar.
   *Você deve ver:* A gravação é normalizada e desvanecer até o silêncio no final.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.

## Dicas

- A macro é salva com o editor, então está esperando em **Ferramentas → Gerenciador de Macros** para a próxima gravação.
- **Exportar macro** escreve a cadeia como um arquivo de texto de macro do Audacity e **Importar macro** lê um, então uma rotina pode ser movida entre os dois programas.
