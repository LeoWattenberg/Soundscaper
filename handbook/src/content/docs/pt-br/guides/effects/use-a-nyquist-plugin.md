## Para que serve este guia {#what-this-guide-is-for}

Os plug-ins Nyquist do Audacity são pequenos scripts que adicionam efeitos, geradores e analisadores. O Soundscaper mantém os scripts agrupados que precisam de processamento de seleção sob um submenu Nyquist. O Fade Ajustável molda como a gravação entra ou sai.

:::note[Vindo do Audacity?]
Este é o **Efeito → Fade Ajustável (um plug-in Nyquist)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar** e selecione a gravação para testar o plug-in. Ela cai como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Nyquist → Fade Ajustável**. No diálogo **Fade Ajustável**, defina **Ajuste de Fade Médio (%)** para `25`, então pressione **Aplicar**. Um ajuste positivo arredonda o fade. Os diálogos Nyquist usam **Aplicar** em vez de Aplicar à seleção.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* A gravação desaparece gradualmente.

## Dicas

- Os menus Gerar e Analisar têm seus próprios submenus Nyquist, com plug-ins como Pluck e Beat Finder.
- **Ferramentas → Prompt Nyquist** executa um script que você mesmo digita.
- Delay, filtros passa-alto e passa-baixo, Portão de ruído, Filtro entalhe, Filtro prateleira, Tremolo e Vocoder têm efeitos regulares em suas categorias de menu Efeito e são executados em [racks em tempo real](/guides/effects/add-a-realtime-effect-to-a-track/).
