## Para que serve este guia {#what-this-guide-is-for}

Um phaser mistura um som com uma cópia de si mesmo passada através de estágios de passagem total móveis, então as entalhes varrem o espectro para cima e para baixo no tempo com um oscilador lento. Em uma guitarra, um piano elétrico ou um pad, ele dá o giro ouvido em inúmeros discos. O Audacity 3 veio com um phaser e o Audacity 4 não, então este é um para alcançar aqui.

:::note[Vindo do Audacity?]
Este é o **Efeito → Phaser (Audacity 3; o Audacity 4 não possui Phaser)**. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar** e selecione o som a ser tratado. Ele é inserido como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Phaser**. No diálogo **Phaser**, defina **Estágios** para `4` e **Frequência LFO** para `0.6`, depois pressione **Aplicar à seleção**. Mais estágios criam entalhes mais profundos; quatro é um pedal clássico. A frequência LFO é a velocidade com que a varredura se move — 0,6 Hz é um giro musical lento.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O som gira lentamente enquanto os entalhes varrem por ele.

## Dicas

- **Feedback** afia os entalhes em uma varredura mais metálica e ressonante; mantenha-o próximo de zero para um efeito sutil.
- O phaser também funciona como um efeito em tempo real na rack de uma faixa, então você pode ouvir a varredura enquanto a ajusta: [Adicionar um efeito em tempo real a uma faixa](/guides/effects/add-a-realtime-effect-to-a-track/).
