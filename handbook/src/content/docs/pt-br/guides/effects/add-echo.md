O eco reproduz a seleção novamente após um atraso, e depois mais uma vez, cada repetição mais baixa que a anterior. É o clássico eco de volta em um vocal ou o efeito de cânion em um grito.

:::nota[Vindo do Audacity?]
Este é o **Efeito → Atraso e Reverb → Eco** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione o som que deve ecoar. O arquivo cai como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Atraso e reverb → Eco**. No diálogo **Eco**, defina o **Fator de decaimento** para `0.4`, depois pressione **Aplicar à seleção**. Cada repetição é 0,4 vezes mais alta que a anterior, então o eco diminui após algumas repetições. O **Tempo de atraso** define o intervalo entre elas.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* O som é seguido por repetições que diminuem.

## Dicas

- Adicione um segundo ou dois de silêncio após o clipe primeiro (**Gerar → Silêncio**) para que as últimas repetições tenham espaço para soar.
- Para um ambiente em vez de repetições distintas, use [Reverb](/guides/effects/add-reverb/).
