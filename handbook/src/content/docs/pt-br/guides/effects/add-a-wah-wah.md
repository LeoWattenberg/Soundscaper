O pedal wah varre um filtro ressonante para cima e para baixo no espectro; o efeito Wahwah faz a varredura para você em uma taxa que você define. Ele é adequado para guitarras, teclados e qualquer coisa com sustentação constante.

:::nota[Vindo do Audacity?]
Este é o **Efeito → Wahwah** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação que você deseja aplicar o wah. O arquivo é inserido como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Distorção e modulação → Wahwah**. No diálogo **Wahwah**, defina a **Frequência do LFO** como `2` e a **Profundidade** como `80`, em seguida, pressione **Aplicar à seleção**. A frequência do LFO é quantas varreduras ocorrem por segundo; a profundidade é o quanto o filtro se move.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* A gravação oscila com um tom semelhante a uma vogal.

## Dicas

- **Ressonância** afia o pico do filtro; valores altos gritam.
- O **Phaser** no mesmo submenu oferece um movimento mais suave e giratório.
