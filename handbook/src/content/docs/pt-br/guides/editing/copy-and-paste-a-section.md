Copiar um bom coro para substituir um fraco, repetir uma barra, mover uma frase para o final: o copiar e colar funciona no áudio da mesma forma que no texto. Selecione uma passagem, copie-a, coloque o cursor onde ela deve ir e cole.

:::nota[Vindo do Audacity?]
Esta é a **Editar → Copiar, e depois Editar → Colar (Ctrl+C, Ctrl+V)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação com a passagem que você deseja copiar. O arquivo é colocado como um clipe em sua própria faixa.
3. Arraste na régua acima do clipe para selecionar a passagem a ser copiada.
4. Escolha **Editar → Copiar**.
5. Clique na forma de onda onde a cópia deve ir para colocar o cursor lá. A colagem é colocada no cursor; o final do clipe é o local padrão.
6. Escolha **Editar → Colar → Colar**.
7. O projeto agora mostra 2 clipes.
   *Você deve ver:* A passagem copiada é um novo clipe após o original.

## Dicas

- **Editar → Colar → Inserir** empurra o áudio posterior ao longo em vez de sobrepor a colagem sobre ele.
- A área de transferência funciona entre as abas do projeto, então uma passagem pode ser copiada de um projeto para outro.
