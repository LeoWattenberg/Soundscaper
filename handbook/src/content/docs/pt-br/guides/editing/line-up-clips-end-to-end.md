## Para que serve este guia {#what-this-guide-is-for}

Duas tomadas gravadas separadamente ficam em suas próprias faixas, ambas começando no zero. Para reproduzi-las uma após a outra, a segunda precisa ser movida para onde a primeira termina. Alinhar de ponta a ponta faz esse cálculo para cada clipe selecionado, na ordem das faixas.

:::note[Veio do Audacity?]
Este é o **Faixas → Alinhar faixas → Alinhar de ponta a ponta** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a primeira tomada. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Arquivo → Importar** e selecione a segunda tomada. Ela é colocada como um clipe em sua própria faixa.
4. Clique na barra de nome do primeiro clipe, mantenha Shift pressionado e clique na barra de nome do segundo para selecionar ambos.
5. Escolha **Faixas → Alinhar conteúdo → Alinhar de ponta a ponta**.
6. O segundo clipe agora começa onde o primeiro termina.
   *Você deve ver:* Os clipes são reproduzidos um após o outro, sem sobreposição nem espaço.

## Dicas

- **Alinhar juntos** faz o oposto: move os clipes selecionados para que comecem no mesmo instante.
- Arraste um clipe pela barra de nome para posicioná-lo manualmente; mantenha Shift pressionado para mover juntos todos os clipes de sua faixa.
