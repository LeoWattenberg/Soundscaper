## Para que serve este guia {#what-this-guide-is-for}

Inverter troca a ordem temporal da seleção. É um efeito útil para design de som — pratos invertidos e pré-ecos que crescem — e, ocasionalmente, para verificar se a cauda de reverberação de uma sala esconde alguma coisa.

:::note[Veio do Audacity?]
Este é o **Efeito → Especial → Inverter** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deseja inverter. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Especial → Inverter**. O efeito é aplicado imediatamente à seleção.
5. Pressione **Reproduzir** para ouvir e depois **Parar**.
   *Você deve ver:* A gravação é reproduzida ao contrário.

## Dicas

- Aplique Inverter duas vezes e você voltará ao ponto de partida, amostra por amostra.
- Inverta uma seleção curta no início de um clipe para criar uma subida que leve até ele.
