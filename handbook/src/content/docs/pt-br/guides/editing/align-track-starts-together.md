## Para que serve este guia {#what-this-guide-is-for}

Alinhar juntos move as faixas selecionadas para um início comum, calculado pela média dos horários em que o conteúdo começa atualmente. Todo o conteúdo de cada faixa é deslocado como uma unidade, mantendo o espaçamento entre os clipes dessa faixa. Para alinhar somente as gravações desejadas, use faixas que contenham apenas uma gravação cada.

:::note[Veio do Audacity?]
No Audacity, isso corresponde a **Tracks → Align content → Align together**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Etapas

1. Abra o Soundscaper. Assim que o editor carregar, um projeto novo e vazio estará pronto.
2. Escolha **Arquivo → Importar** e selecione a primeira gravação. Ela será inserida como um clipe em uma faixa própria.
3. Escolha **Arquivo → Importar** e selecione a segunda gravação. Ela será inserida como um clipe em uma faixa própria.
4. Arraste o clipe pela barra do nome até um ponto mais adiante para que as duas gravações comecem em momentos diferentes.
5. Pressione **Tab** para focar a primeira gravação e **Enter** para selecioná-la. Depois, foque a segunda gravação e pressione **Shift+Enter** para adicioná-la à seleção. As faixas com clipes selecionados são os alvos do alinhamento.
6. Escolha **Faixas → Alinhar conteúdo → Alinhar em conjunto**.
7. Agora a primeira gravação começa no horário comum.
8. A segunda gravação começa no mesmo horário.
   *Você deverá ver:* As bordas esquerdas ficam alinhadas, e as duas gravações mantêm a duração original.

## Dicas

- O início comum não precisa ser o tempo zero. Para começar no início do projeto, [alinhe uma gravação ao zero](/guides/editing/align-a-recording-to-zero/).
- **Editar → Desfazer** restaura a posição anterior de cada faixa.
