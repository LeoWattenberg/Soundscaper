Aprender um riff, conferir um ponto de edição ou testar o ajuste de um efeito: tudo fica mais rápido quando o trecho é reproduzido continuamente sem precisar reiniciá-lo. Defina a região de loop como a seleção e a reprodução permanecerá dentro dela até você desativar o loop.

:::note[Veio do Audacity?]
Este é o **Transporte → Loop → Definir loop para a seleção** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação com o trecho que deseja praticar. Ela é colocada como um clipe em sua própria faixa.
3. Arraste na régua acima do clipe para selecionar o trecho que deseja repetir.
4. Escolha **Selecionar → Região de loop → Definir loop para a seleção**.
5. O projeto agora mostra o botão **Repetir seleção** aceso.
   *Você deve ver:* O botão de loop na barra de transporte acende e a região de loop aparece acima da régua.
6. Pressione **Reproduzir** para ouvir e depois **Parar**.
   *Você deve ver:* A reprodução percorre repetidamente o trecho selecionado.

## Dicas

- Pressione **L** ou o botão de loop da barra de transporte para ativar e desativar o loop sem perder a região.
- Arraste as extremidades da região de loop na régua para ajustá-la.
