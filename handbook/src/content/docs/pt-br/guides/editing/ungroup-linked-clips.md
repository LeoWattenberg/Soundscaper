## Para que serve este guia {#what-this-guide-is-for}

Clipes agrupados podem ser selecionados e movidos juntos sem deixar de ser partes de áudio separadas. Ungroup restaura a seleção independente dos clipes; não junta as partes nem as renderiza em um único clipe.

:::note[Veio do Audacity?]
Este é o **Edit → Clip → Ungroup Clips** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação com os clipes que deseja separar. Ela será adicionada como um clipe em uma faixa própria.
3. Clique na forma de onda no ponto em que deseja dividir o clipe em duas partes para posicionar o cursor ali.
4. Escolha **Editar → Clipes de áudio → Dividir**.
5. Clique na barra de nome da primeira parte, mantenha Shift pressionado e clique na barra de nome da segunda parte para selecionar ambas.
6. Escolha **Editar → Clipes de áudio → Agrupar clipes**. O agrupamento permite mover as duas partes selecionadas juntas sem juntar o áudio delas.
7. Escolha **Editar → Clipes de áudio → Desagrupar clipes**. As duas partes voltam a poder ser selecionadas separadamente.
8. O projeto agora mostra 2 clipes.
   *O que você deve ver:* A gravação continua dividida em dois clipes separados que se encontram no ponto do corte.

## Dicas

- Agrupar é útil quando clipes separados precisam manter o tempo relativo entre si durante uma movimentação.
- Escolha **Editar → Clipes de áudio → Unir clipes selecionados** quando quiser transformar partes adjacentes em um único clipe.
