## Para que serve este guia {#what-this-guide-is-for}

Quando uma gravação precisa começar em uma deixa específica, arrastá-la no olho pode ser impreciso. Align start to playhead move o conteúdo da faixa selecionada para que seu início coincida com o cursor, preservando a duração da gravação.

:::note[Veio do Audacity?]
Este é o **Tracks → Align Tracks → Align Start to Playhead** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deseja posicionar em uma deixa. Ela será adicionada como um clipe em uma faixa própria.
3. Arraste o clipe pela barra de nome até um ponto posterior na linha do tempo. Mova-o primeiro para que o cursor possa marcar uma posição inicial diferente.
4. Clique na forma de onda no ponto em que a gravação deve começar para posicionar o cursor ali.
5. Escolha **Faixas → Alinhar conteúdo → Alinhar início à posição de reprodução**. O clipe mais antigo da faixa selecionada é movido para a posição do cursor.
6. A gravação agora começa no cursor de reprodução.
   *O que você deve ver:* O clipe começa na deixa e mantém sua duração original.

## Dicas

- O alinhamento move todos os clipes de cada faixa selecionada. Use uma faixa que contenha somente a gravação que deseja mover.
- Use **Faixas → Alinhar conteúdo → Alinhar início ao zero** para voltar uma faixa selecionada ao início do projeto.
