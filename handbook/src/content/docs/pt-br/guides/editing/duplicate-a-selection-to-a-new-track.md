Duplicar copia a seleção para uma nova faixa diretamente abaixo, na mesma posição no tempo. É o primeiro passo usual para o processamento paralelo — uma cópia fortemente comprimida misturada sob a original, uma faixa apenas com reverb, um vocal duplicado.

:::nota[Vindo do Audacity?]
Esta é a função **Editar → Duplicar (Ctrl+D)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação com a passagem a ser duplicada. O arquivo é colocado como um clipe em sua própria faixa.
3. Arraste na régua acima do clipe para selecionar a passagem a ser duplicada.
4. Escolha **Editar → Duplicar**.
5. O projeto agora mostra 2 clipes.
   *Você deve ver:* Um segundo clipe contendo apenas a seleção, em uma nova faixa abaixo da primeira, alinhada no tempo.

## Dicas

- Mude o volume de uma das duas faixas para ouvir a outra sozinha enquanto a ajusta.
- Quando estiver satisfeito com a mistura, [misture as faixas](/guides/tracks-and-export/mix-tracks-into-one/).
