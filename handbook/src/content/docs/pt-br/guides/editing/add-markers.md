## Para que serve este guia {#what-this-guide-is-for}

Os marcadores são anotações na linha do tempo: onde um capítulo começa, onde um erro precisa ser corrigido, onde a boa tomada começa. Eles não alteram o áudio, viajam com o projeto e podem ser exportados como um arquivo de rótulo para outras ferramentas.

:::note[Vindo do Audacity?]
Isto é **Editar → Rótulos → Adicionar Rótulo na Seleção (Ctrl+B)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que você deseja marcar. Ela é inserida como um clipe em sua própria faixa.
3. Escolha **Visualização → Marcadores**. Isso adiciona uma faixa de marcadores acima das faixas. Os marcadores existem sem ela, mas a faixa é onde você os vê e edita.
4. Clique na forma de onda onde o marcador deve ir para posicionar o cursor. O marcador é colocado onde o cursor está.
5. Com o painel de Marcadores aberto (**Janela → Marcadores**), pressione **Adicionar marcador no cursor**. Pressione Enter no novo marcador, digite `Chorus` e pressione Enter novamente para nomeá-lo.
   *Você deve ver:* O marcador aparece na faixa acima das faixas e na lista do painel, com o nome que você digitou.

## Dicas

- Com um intervalo de tempo selecionado, o mesmo botão adiciona uma região nomeada em vez de um único ponto.
- **Arquivo → Exportar outros → Exportar rótulos** grava os marcadores como um arquivo de texto que o Audacity e outros editores podem ler.
