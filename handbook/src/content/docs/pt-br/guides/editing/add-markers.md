Os marcadores são anotações na linha do tempo: onde um capítulo começa, onde um erro precisa ser corrigido, onde a boa tomada começa. Eles não alteram o áudio, acompanham o projeto e podem ser exportados como um arquivo de rótulo para outras ferramentas.

:::note[Vindo do Audacity?]
Isto é o **Editar → Rótulos → Adicionar Rótulo na Seleção (Ctrl+B)** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação que você deseja marcar. O arquivo é colocado como um clipe em sua própria faixa.
3. Escolha **Visualizar → Mostrar marcadores**. Isso adiciona uma faixa de marcadores acima das faixas. Os marcadores existem sem ela, mas a faixa é onde você os vê e edita.
4. Clique na forma de onda onde o marcador deve ir para colocar o cursor ali. O marcador é colocado onde o cursor está.
5. Com o painel de Marcadores aberto (**Visualizar → Painéis → Marcadores**), pressione **Adicionar marcador no cabeçote de reprodução**. Pressione Enter no novo marcador, digite `Chorus` e pressione Enter novamente para nomeá-lo.
   *Você deve ver:* O marcador aparece na faixa acima das faixas e na lista do painel, com o nome que você digitou.

## Dicas

- Com um intervalo de tempo selecionado, o mesmo botão adiciona uma região nomeada em vez de um único ponto.
- **Arquivo → Exportar outros → Exportar rótulos** grava os marcadores como um arquivo de texto que o Audacity e outros editores podem ler.
