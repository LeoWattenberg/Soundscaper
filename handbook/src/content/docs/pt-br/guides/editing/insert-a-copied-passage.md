## Para que serve este guia {#what-this-guide-is-for}

Inserir abre espaço para o áudio copiado em vez de colocá-lo por cima do som existente. O áudio posterior na faixa de destino é deslocado para a direita pelo tempo de duração do trecho copiado. Use esse recurso para repetir uma frase ou acrescentar uma fala dentro de uma gravação.

:::note[Veio do Audacity?]
No Audacity, isso corresponde a **Edit → Copy, then Edit → Paste**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Etapas

1. Abra o Soundscaper. Assim que o editor carregar, um projeto novo e vazio estará pronto.
2. Escolha **Arquivo → Importar** e selecione a gravação com o trecho que você quer copiar. Ela será inserida como um clipe em uma faixa própria.
3. Arraste na régua acima do clipe para selecionar o trecho que você quer inserir em outro lugar.
4. Escolha **Editar → Copiar**.
5. Clique na forma de onda do clipe de destino, no ponto em que a cópia deve começar, para posicionar o cursor ali. O clique remove a seleção de tempo e define o ponto de inserção.
6. Escolha **Editar → Colar → Inserir**.
7. O projeto agora mostra 3 clipes.
   *Você deverá ver:* O trecho inserido fica entre duas partes do clipe original. A parte posterior foi deslocada para a direita, enquanto a anterior manteve a posição.

## Dicas

- Inserir desloca o áudio posterior na faixa de destino. **Editar → Colar → Inserir e preservar a sincronização** abre espaço em todas as faixas quando é importante manter a sincronização.
- **Editar → Desfazer** remove a inserção e restaura a posição do áudio posterior.
