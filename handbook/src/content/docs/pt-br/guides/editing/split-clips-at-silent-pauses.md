## Para que serve este guia {#what-this-guide-is-for}

Pausas longas podem facilitar a edição de uma fala quando cada frase fica em seu próprio clipe. Split clips at silences remove os trechos silenciosos e mantém as frases separadas no mesmo lugar, sem alterar sua posição na linha do tempo.

:::note[Veio do Audacity?]
Este é o **Edit → Audio Clips → Detach at Silences (Audacity 3)** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a tomada com pausas entre as frases. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Editar → Clipes de áudio → Dividir clipes nos silêncios**. Cada trecho silencioso detectado é removido do clipe, e as frases de cada lado viram clipes separados.
4. As frases agora são clipes separados em seus horários originais.
   *O que você deve ver:* Cada frase continua no mesmo ponto da gravação.

## Dicas

- Este comando separa um clipe nos silêncios; ele não encurta os intervalos entre as frases.
- Para manter as pausas, mas encurtá-las, use [Remove silent pauses](/guides/cleaning-up/remove-silent-pauses/) em vez disso.
