Um projeto é mais do que o áudio: são as faixas, clipes, efeitos, marcadores e histórico. Salvar mantém tudo isso na biblioteca local do projeto no navegador deste computador, onde pode ser reaberto a partir do menu Arquivo. O Soundscaper também salva automaticamente, então isso é principalmente uma forma de garantir. 

:::note[Vindo do Audacity?]
Isso é o **Arquivo → Salvar Projeto** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar áudio** e escolha algo para trabalhar. O arquivo cai como um clipe em sua própria faixa.
3. Escolha **Arquivo → Salvar projeto**. O indicador de salvamento na barra de status mostra que o projeto foi salvo.

## Dicas

- Para mover um projeto para outro computador ou manter uma cópia fora do navegador, veja [Mover um projeto entre computadores](/guides/projects/move-a-project-between-computers/).
- Uma exportação de áudio é uma cópia para escuta, não um projeto. Mantenha o projeto se você precisar editar novamente.
