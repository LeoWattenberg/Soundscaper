Projetos criados no Audacity 3 (.aup3) e no Audacity 4 (.aup4) abrem diretamente. As faixas, os clipes, os nomes e as posições são importados; os efeitos que o Soundscaper não possui são listados para você saber o que conferir. O arquivo original não é alterado.

:::note[Veio do Audacity?]
Este é o **Arquivo → Abrir** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Abrir** e selecione o projeto. As faixas e os clipes aparecem como estavam no Audacity.
3. O projeto agora mostra um clipe chamado **Audio 1** e uma faixa chamada **Fixture track**.
   *Você deve ver:* A faixa e o clipe do projeto do Audacity, com seus nomes.

## Dicas

- Um projeto `.aup` antigo precisa da pasta `_data` ao lado dele; selecione os dois quando solicitado.
- **Arquivo → Exportar outro → Exportar AUP4** faz o caminho inverso, para devolver um projeto ao Audacity.
