## Para que serve este guia {#what-this-guide-is-for}

Uma palestra que deve virar um arquivo por tópico, um lado de álbum que precisa ser dividido em faixas ou um audiolivro com um arquivo por capítulo: coloque um marcador no início de cada parte e exporte uma vez. Cada marcador inicia um capítulo que vai até o próximo, e cada capítulo é salvo em seu próprio arquivo, com o nome do marcador, dentro de um arquivo compactado. O Audacity 4.0.1 oferece o mesmo fluxo de trabalho com Exportar vários.

:::note[Veio do Audacity?]
Isso corresponde a **Arquivo → Exportar áudio → Regiões rotuladas como arquivos de áudio separados** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação a ser dividida. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Janela → Caixa do projeto**. A gravação já está na linha do tempo, então ocultar a caixa deixa espaço para o painel Marcadores.
4. Escolha **Visualização → Marcadores**. A faixa de marcadores mostra e nomeia o início dos capítulos.
5. Pressione o botão **Ir para o início do projeto** na barra de ferramentas. O primeiro capítulo deve começar no início, então o primeiro marcador fica no zero.
6. Com o painel Marcadores aberto (**Janela → Marcadores** o mostra), pressione **Adicionar marcador no cursor de reprodução**. Pressione Enter no novo marcador, digite `Part one` e pressione Enter novamente para nomeá-lo.
7. Clique na forma de onda onde começa a segunda parte para colocar o cursor ali.
8. Com o painel Marcadores aberto (**Janela → Marcadores** o mostra), pressione **Adicionar marcador no cursor de reprodução**. Pressione Enter no novo marcador, digite `Part two` e pressione Enter novamente para nomeá-lo.
9. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **MP3**, defina **Saída** como **Capítulos (dividir por marcadores)** e pressione **Exportar**. O arquivo é baixado assim que a renderização termina, e seu link permanece na caixa de diálogo. Cada capítulo vira um MP3 dentro do arquivo compactado, numerado na ordem e nomeado a partir do marcador.

## Dicas

- Uma região nomeada exporta exatamente seu próprio intervalo; use regiões em vez de marcadores quando as partes tiverem espaços entre elas.
- Rótulos em uma faixa de rótulos dividem da mesma forma: escolha **Capítulos (dividir por rótulos)** para cortar nesses rótulos em vez dos marcadores.
- Para dividir por faixas, e não por marcadores, consulte [Exportar cada faixa como seu próprio arquivo](/guides/projects/export-each-track-as-its-own-file/).
