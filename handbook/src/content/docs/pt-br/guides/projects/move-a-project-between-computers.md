A biblioteca do projeto reside em um navegador em um único computador. Para levar um projeto em qualquer outro lugar - outra máquina, um colega, um disco de backup - exporte-o como um arquivo de projeto. O arquivo `.sscape` contém o áudio e cada edição, e abre em qualquer Soundscaper.

:::nota[Vindo do Audacity?]
Isso é **Arquivo → Salvar Projeto → Backup do Projeto, depois Arquivo → Abrir** no Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione o material do projeto. Ele cai como um clipe em sua própria faixa.
3. Escolha **Arquivo → Exportar arquivo de projeto (.sscape)**. Todo o projeto é baixado como um único arquivo `.sscape`. Mantenha o arquivo em um local seguro; é o projeto completo.
4. Escolha **Arquivo → Abrir** e selecione o arquivo. Em um computador que ainda não possui o projeto, ele abre diretamente; aqui, onde a biblioteca já o contém, o Soundscaper oferece **Abrir como cópia somente leitura** - pressione-o.
   *Você deve ver:* O projeto abre com sua faixa e clipe exatamente como exportado.

## Dicas

- Uma cópia somente leitura não pode ser editada até que você a salve como um projeto próprio a partir do menu Arquivo.
- O arquivo é um arquivo ZIP com o áudio dentro; não o descompacte manualmente.
