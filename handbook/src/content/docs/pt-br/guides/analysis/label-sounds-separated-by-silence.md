## Para que serve este guia {#what-this-guide-is-for}

Label Sounds procura sons separados por silêncio em um trecho e coloca um rótulo ao redor de cada som detectado. Isso ajuda a marcar frases faladas, batidas isoladas ou outros eventos distintos para editar depois.

:::note[Veio do Audacity?]
Esta é a opção do Audacity **Analyze → Label Sounds (Nyquist)**. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação com pausas entre os sons. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Nyquist → Label Sounds**. Na janela **Label Sounds**, defina **Threshold level (dB)** como `-30`, **Minimum silence duration** como `0.5` e **Minimum label interval** como `0.5`, depois pressione **Aplicar**. A janela informa o resultado; pressione **Fechar** para fechá-la. Meio segundo de silêncio permite ao analisador separar as frases. O limite define o volume mínimo para que um som seja reconhecido.
5. O projeto agora mostra uma faixa chamada **Label Sounds**.
   *O que você deve ver:* Uma faixa Label Sounds aparece com rótulos ao redor das frases detectadas.

## Dicas

- Reduza **Threshold level (dB)** para incluir sons mais baixos; aumente-o para ignorar o ruído de fundo.
- Aumente **Minimum silence duration** se pausas curtas não devem dividir uma frase em vários rótulos.
