O Beat Finder é um dos analisadores Nyquist incluídos. Ele escuta aumentos repentinos no nível acima de um limite e escreve um rótulo em cada um deles, o que é uma maneira rápida de marcar os batidas de um loop ou os acertos em uma gravação de bateria antes de cortá-la.

:::nota[Vindo do Audacity?]
Isto é o **Analisar → Encontrador de Batidas** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação que você deseja marcar. O arquivo é colocado como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Nyquist → Beat Finder**. No diálogo **Beat Finder**, defina o **Limite de Porcentagem** para `60`, então pressione **Aplicar**. O diálogo relata o que encontrou; pressione **Fechar** para descartá-lo. Uma porcentagem menor encontra batidas mais silenciosas também; aumente-a se marcar demais.
5. O projeto agora mostra uma faixa chamada **Beat Finder**.
   *Você deve ver:* Uma nova faixa de rótulo chamada Beat Finder abaixo do áudio, com um rótulo em cada batida.

## Dicas

- Os rótulos são colocados em uma nova faixa de rótulo abaixo do áudio. Renomeie ou exclua qualquer um que o analisador tenha marcado incorretamente.
- **Analisar → Nyquist → Rotular Sons** faz um trabalho semelhante para sons inteiros separados por silêncio.
