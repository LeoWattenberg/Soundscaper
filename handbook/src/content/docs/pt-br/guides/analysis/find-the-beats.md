## Para que serve este guia {#what-this-guide-is-for}

O Localizador de Batidas é um dos analisadores Nyquist incluídos. Ele escuta aumentos repentinos no nível acima de um limite e escreve um rótulo em cada um deles, o que é uma maneira rápida de marcar as batidas de um loop ou os toques em uma gravação de bateria antes de cortá-la.

:::note[Vindo do Audacity?]
Este é o **Analisar → Localizador de Batidas** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar** e selecione a gravação que você deseja marcar. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Nyquist → Localizador de Batidas**. No diálogo **Localizador de Batidas**, defina o **Percentual de Limite** para `60`, e pressione **Aplicar**. O diálogo relata o que encontrou; pressione **Fechar** para descartá-lo. Um percentual mais baixo encontra batidas mais suaves; aumente-o se marcar demais.
5. O projeto agora mostra uma faixa chamada **Localizador de Batidas**.
   *Você deve ver:* Uma nova faixa de rótulos chamada Localizador de Batidas abaixo do áudio, com um rótulo em cada batida.

## Dicas

- Os rótulos são colocados em uma nova faixa de rótulos abaixo do áudio. Renomeie ou exclua qualquer um que o analisador tenha marcado incorretamente.
- **Analisar → Nyquist → Rótulos de Sons** faz um trabalho semelhante para sons inteiros separados por silêncio.
