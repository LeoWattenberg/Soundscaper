## Para que serve este guia {#what-this-guide-is-for}

RMS é uma medida do nível médio do sinal ao longo do tempo. Use o analisador Measure RMS para comparar seções ou conferir a intensidade de um trecho antes de ajustá-lo.

:::note[Veio do Audacity?]
Esta é a opção do Audacity **Analyze → Measure RMS (Nyquist)**. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione o trecho cujo nível médio deseja medir. Ele será adicionado como um clipe em uma faixa própria.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Nyquist → Measure RMS**. Na janela **Measure RMS**, pressione **Aplicar**. A janela informa o resultado; pressione **Fechar** para fechá-la.
   *O que você deve ver:* O relatório mostra o nível RMS em dB de cada canal e do sinal estéreo.

## Dicas

- RMS descreve o nível médio; use [normalização de pico](/guides/volume/normalize-peaks/) quando precisar ajustar a amostra mais alta a um alvo.
- Selecione somente a seção que deseja comparar para que outros áudios não afetem a medição.
