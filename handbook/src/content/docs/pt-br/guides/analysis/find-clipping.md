Uma gravação feita com nível alto demais se achata contra o topo da faixa e distorce. É fácil ouvir o dano, mas difícil encontrá-lo visualmente em uma tomada longa. O Find Clipping examina a seleção e lista cada sequência de amostras que está na escala máxima, para que você decida se deve consertá-la, refazer a gravação ou conviver com ela.

:::note[Veio do Audacity?]
Este é o **Analisar → Encontrar clipping** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deseja verificar. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Analisar → Encontrar clipping**. O painel **Encontrar clipping** é aberto.
   *Você deve ver:* Uma lista das sequências clipadas ou uma observação informando que nenhuma foi encontrada.

## Dicas

- Baixar o volume de uma gravação clipada não a recupera; os picos achatados continuam achatados. **Efeito → Remoção e reparo de ruído → Reparar** pode reconstruir uma sequência clipada muito curta.
- Para evitar clipping na próxima vez, grave com picos em torno de −12 dB e aumente o nível depois.
