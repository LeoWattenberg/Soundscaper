## Para que serve este guia {#what-this-guide-is-for}

Uma tomada longa com pausas lentas entre as frases é cansativa de ouvir. O Truncate Silence encontra cada trecho abaixo de um limite que dura mais do que um comprimento mínimo e o encurta, de modo que o ritmo fique mais apertado sem cortar nenhuma palavra. 

:::note[Vindo do Audacity?]
Este é o **Efeito → Especial → Truncate Silence** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar** e selecione a tomada com as longas pausas. Ela é colocada como um clipe em sua própria faixa.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Especial → Truncate Silence**. No diálogo **Truncate Silence**, defina o **Limiar** para `-40`, então pressione **Aplicar à seleção**. Qualquer coisa mais silenciosa que −40 dB é considerada silêncio. Pausas mais longas que o comprimento mínimo de silêncio são reduzidas ao comprimento de truncamento; ambos mantêm seus valores padrão de meio segundo aqui.
5. Pressione **Reproduzir** para ouvir, depois **Parar**.
   *Você deve ver:* As pausas são mais curtas e cada frase ainda está completa.

## Dicas

- Se as palavras no início de uma frase forem cortadas, aumente o comprimento mínimo de silêncio ou diminua o limiar.
- O efeito altera o comprimento da seleção, então execute-o antes de alinhar a tomada com qualquer outra coisa.
