Às vezes, você deseja remover uma passagem, mas não o tempo que ela ocupa — um telefone tocando durante uma pausa, um nome que precisa ser censurado. O silenciamento mantém a gravação com a mesma duração e apenas achata a parte selecionada.

:::nota[Vindo do Audacity?]
Esta é a função **Editar → Remover Especial → Silenciar Áudio** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar** e selecione a gravação com a passagem que deseja silenciar. Ela é adicionada como um clipe em sua própria faixa.
3. Arraste a régua acima do clipe para selecionar apenas a parte que deseja silenciar.
4. Escolha **Editar → Remover especial → Silenciar áudio**.
5. O projeto agora mostra 3 clipes.
   *Você deve ver:* A forma de onda está plana no novo clipe central, entre o áudio inalterado em ambos os lados.

## Dicas

- O silêncio é uma edição normal: **Editar → Desfazer** traz o áudio de volta.
- Para remover o tempo e o som, consulte [Cortar um erro de uma gravação](/guides/editing/cut-out-a-mistake/).
