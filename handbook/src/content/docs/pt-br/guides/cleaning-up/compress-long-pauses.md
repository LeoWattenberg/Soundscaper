## Para que serve este guia {#what-this-guide-is-for}

Pausas longas podem deixar uma fala lenta, mas cortar todas as pausas pode dificultar o acompanhamento. Truncate Silence comprime apenas a parte excedente das pausas que ultrapassam uma duração mínima.

:::note[Veio do Audacity?]
Este é o **Effect → Special → Truncate Silence** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione uma gravação com pausas longas demais. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Selecionar → Selecionar tudo**.
4. Escolha **Efeito → Especial → Truncar Silêncio**. Na janela **Truncar Silêncio**, defina **Limiar** como `-40` e **Silêncio mínimo** como `0.5`, escolha **Comprimir silêncio excedente** em **Ação** e defina **Comprimir para** como `50`. Em seguida, pressione **Aplicar à seleção**. O silêncio com mais de 0,5 segundo é reduzido à metade da duração excedente, mantendo uma pausa entre as frases.
5. Pressione **Reproduzir** para ouvir e, em seguida, **Parar**.
   *O que você deve ouvir:* As pausas longas ficam menores, mas ainda há algum silêncio entre as frases.

## Dicas

- Aumente **Silêncio mínimo** para preservar pausas mais curtas ou reduza **Comprimir para** para apertar ainda mais as pausas longas.
- Escute para detectar respirações ou finais de frase cortados; desfaça a alteração se o ritmo ficar artificial.
