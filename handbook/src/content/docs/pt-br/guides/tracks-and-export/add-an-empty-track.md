Importar um arquivo cria uma faixa para você, mas uma gravação ou uma colagem precisam de um local para pousar. O botão Adicionar faixa acima da lista de faixas cria uma faixa de áudio vazia; uma faixa de rótulo contém marcadores e texto em vez de som.

:::nota[Vindo do Audacity?]
Esta é a opção **Faixas → Adicionar Nova → Faixa Mono** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor carrega.
2. Pressione **Adicionar faixa** acima da lista de faixas e escolha **Faixa de áudio**.
3. O projeto agora mostra 2 faixas.
   *Você deve ver:* Uma segunda faixa de áudio vazia abaixo da primeira.

## Dicas

- Renomeie a faixa a partir do seu menu para que uma sessão com muitas faixas permaneça legível.
- Arraste uma faixa pelo seu cabeçalho para reordená-la.
