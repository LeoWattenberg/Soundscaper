Um tom com frequência e nível conhecidos é o primeiro recurso para verificar uma cadeia de sinal, calibrar um nível ou criar um bipe que cubra uma palavra. Os geradores criam áudio no cursor ou substituem a seleção, se houver uma.

:::note[Veio do Audacity?]
Este é o **Gerar → Tom** do Audacity. Os nomes abaixo são próprios do Soundscaper e às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Gerar → Tom**. Na caixa de diálogo **Tom**, defina **Frequência (Hz)** como `440` e **Duração (segundos)** como `2`, depois pressione **Gerar**. 440 Hz é o lá de concerto, a referência de afinação padrão.
3. O projeto agora mostra 1 clipe.
   *Você deve ver:* Um clipe novo contendo dois segundos de tom.

## Dicas

- Defina **Amplitude** como `0.5` ou menos se o tom for mixado com qualquer outra coisa.
- **Gerar → Silêncio** funciona da mesma forma e é o jeito mais fácil de adicionar um espaço entre clipes.
