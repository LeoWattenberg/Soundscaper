## Para que serve este guia {#what-this-guide-is-for}

Exportar clipes individualmente mantém cada edição em seu próprio arquivo de áudio e reúne tudo em um único arquivo compactado. Primeiro divida um trecho em clipes; depois escolha o modo de saída para clipes na janela de exportação.

:::note[Veio do Audacity?]
Esta é a opção do Audacity **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)**. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação cujos clipes deseja exportar separadamente. Ela será adicionada como um clipe em uma faixa própria.
3. Arraste na régua acima do clipe para selecionar um trecho que deseja exportar como clipe próprio.
4. Escolha **Editar → Clipes de áudio → Dividir**.
5. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **WAV** e **Saída** como **Clipes individuais (divididos por clipe)**, depois pressione **Exportar**. O arquivo é baixado assim que a renderização termina, e o link permanece na janela. Cada clipe é renderizado como um WAV separado dentro de um único arquivo ZIP.

## Dicas

- Use nomes descritivos nos clipes antes de exportar para identificá-los no arquivo compactado.
- Escolha **Projeto inteiro** quando quiser uma única mixagem em vez de arquivos separados por clipe.
