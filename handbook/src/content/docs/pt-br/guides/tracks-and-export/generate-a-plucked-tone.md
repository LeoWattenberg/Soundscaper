## Para que serve este guia {#what-this-guide-is-for}

Pluck cria um som curto e afinado que pode servir como nota musical simples ou acento de design sonoro. O campo de altura MIDI permite escolher uma nota sem calcular sua frequência.

:::note[Veio do Audacity?]
Este é o **Generate → Pluck (Nyquist)** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Gerar → Nyquist → Pluck**. Na janela **Pluck**, defina **Pluck MIDI pitch** como `60` e **Duration (60s max)** como `2`, depois pressione **Aplicar**. A altura MIDI 60 corresponde ao dó central; dois segundos dão espaço para a nota decair.
3. O projeto agora mostra 1 clipe.
   *O que você deve ouvir:* Uma nota dedilhada não silenciosa de dois segundos aparece na linha do tempo.

## Dicas

- Aumente **Pluck MIDI pitch** para uma nota mais aguda ou reduza-o para uma nota mais grave.
- Use uma **Duration (60s max)** menor para criar um acento mais curto.
