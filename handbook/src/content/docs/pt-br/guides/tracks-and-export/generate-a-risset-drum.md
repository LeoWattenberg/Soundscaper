## Para que serve este guia {#what-this-guide-is-for}

Risset Drum combina um tom decrescente com uma faixa de ruído para criar uma batida sintética. Ajuste o decaimento para obter um acento curto ou um som mais longo e ressonante.

:::note[Veio do Audacity?]
Este é o **Generate → Risset Drum (Nyquist)** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Gerar → Nyquist → Risset Drum**. Na janela **Risset Drum**, defina **Frequency (Hz)** como `100`, **Decay (seconds)** como `1.5` e **Amplitude (0 - 1)** como `0.5`, depois pressione **Aplicar**. Um decaimento de 1,5 segundo deixa a batida curta; a amplitude moderada reserva espaço para misturá-la com outros sons.
3. O projeto agora mostra 1 clipe.
   *O que você deve ouvir:* Um clipe percussivo não silencioso, com cerca de 1,5 segundo, aparece na linha do tempo.

## Dicas

- Reduza **Frequency (Hz)** para uma batida mais grave ou aumente o valor para um som mais brilhante e agudo.
- Aumente **Amount of noise in mix (percent)** para deixar o ataque mais ruidoso.
