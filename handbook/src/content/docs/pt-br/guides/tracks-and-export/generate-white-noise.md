## Para que serve este guia {#what-this-guide-is-for}

O ruído branco distribui energia por toda a faixa de frequências. Gere um clipe curto e baixo para criar uma textura ou testar uma cadeia de sinal sem importar uma gravação.

:::note[Veio do Audacity?]
No Audacity, o caminho equivalente é **Generate → Noise (Audacity 3)**. Os nomes abaixo são os do Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Assim que o editor carregar, um projeto novo e vazio estará pronto.
2. Escolha **Gerar → Ruído**. Na janela **Ruído**, defina **Amplitude** como `0.1` e **Duração (segundos)** como `2`; depois, pressione **Gerar**. Deixe Cor do ruído em Branco inicialmente e comece com uma amplitude baixa antes de ouvir.
3. O projeto agora mostra 1 clipe.
   *Você deverá ver:* Um clipe de ruído de dois segundos aparece na linha do tempo.

## Dicas

- O controle Cor do ruído também oferece Rosa e Marrom para criar outras texturas.
- Em um projeto existente, coloque o cursor onde o novo clipe deve começar. Uma seleção de tempo faz o gerador substituir aquele trecho.
