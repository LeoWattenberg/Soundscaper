## Para que serve este guia {#what-this-guide-is-for}

Um projeto com várias tomadas fica mais fácil de navegar quando os nomes de faixas relacionadas aparecem juntos. Sort by name reorganiza as faixas em ordem alfabética sem alterar o início dos clipes na linha do tempo.

:::note[Veio do Audacity?]
Este é o **Tracks → Sort Tracks → Sort by Name** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deve ficar depois das outras na ordem alfabética. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Arquivo → Importar** e selecione a gravação que deve ficar antes dela pelo nome. Ela será adicionada como um clipe em uma faixa própria.
4. Escolha **Faixas → Ordenar faixas → Ordenar por nome**. Os nomes das faixas são ordenados alfabeticamente.
5. O projeto agora mostra 2 clipes.
   *O que você deve ver:* As duas gravações continuam no projeto e os nomes das faixas estão em ordem alfabética.

## Dicas

- A ordenação altera a ordem das faixas, não o tempo dos clipes nem o conteúdo do áudio.
- Use **Faixas → Ordenar faixas → Ordenar por tempo** quando quiser que a ordem acompanhe os horários de início dos clipes.
