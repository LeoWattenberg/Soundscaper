## Para que serve este guia {#what-this-guide-is-for}

Mover uma faixa para cima ou para baixo altera sua posição vertical no projeto, não o horário de início dos clipes. Move track to top ajuda a deixar uma voz ou outra parte importante visível acima das demais.

:::note[Veio do Audacity?]
Este é o **Track menu → Move track → Move track to top** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação que deve ficar abaixo. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Arquivo → Importar** e selecione a gravação que deseja colocar no topo. Ela será adicionada como um clipe em uma faixa própria.
4. Abra o menu da faixa que deseja levar ao topo pelo botão **Opções da faixa** no cabeçalho e escolha **Mover faixa → Mover faixa para o início**. O comando muda a ordem vertical da faixa, preservando o tempo do clipe.
5. O projeto agora mostra 2 clipes.
   *O que você deve ver:* A faixa selecionada fica acima da outra, e os dois clipes mantêm suas posições na linha do tempo.

## Dicas

- Use **Mover faixa → Mover faixa para baixo** no menu da faixa para inverter a ordem.
- A ordem das faixas muda qual áudio aparece acima de outro no projeto; ela não muda a mixagem nem a panorâmica.
