O WAV mantém cada amostra exatamente como o editor a tem. Use-o para masters, para entregar áudio a um editor de vídeo ou outro DAW, e para qualquer coisa que você possa querer processar novamente.

:::nota[Vindo do Audacity?]
Este é o **Arquivo → Exportar Áudio → WAV** do Audacity. Os nomes abaixo são próprios do Soundscaper, que às vezes diferem.
:::

## Passos

1. Abra o Soundscaper. Um novo projeto vazio está pronto assim que o editor é carregado.
2. Escolha **Arquivo → Importar áudio** e selecione a gravação a ser entregue. O arquivo é colocado como um clipe em sua própria faixa.
3. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **WAV** e pressione **Exportar**. O arquivo é baixado assim que a renderização termina, e seu link permanece no diálogo.

## Dicas

- Os arquivos WAV são grandes: cerca de dez megabytes por minuto para estéreo em qualidade de CD.
- Para exportar cada faixa como um arquivo separado, defina **Modo** no diálogo de exportação como caulas individuais.
