## Para que serve este guia {#what-this-guide-is-for}

AIFF é um formato PCM sem compressão, comum em fluxos de trabalho de áudio em sistemas Apple. Exporte nesse formato quando o programa ou a especificação de entrega exigir AIFF.

:::note[Veio do Audacity?]
Este é o **File → Export Audio → Other uncompressed files → AIFF (Audacity 3)** do Audacity. Os nomes abaixo são os usados pelo Soundscaper e podem ser diferentes.
:::

## Passos

1. Abra o Soundscaper. Um projeto novo e vazio fica pronto assim que o editor carrega.
2. Escolha **Arquivo → Importar** e selecione a gravação ou mixagem que deseja entregar. Ela será adicionada como um clipe em uma faixa própria.
3. Escolha **Arquivo → Exportar áudio**, defina **Formato** como **AIFF** e pressione **Exportar**. O arquivo é baixado assim que a renderização termina, e o link permanece na janela.
   *O que você deve ver:* A janela de exportação oferece um arquivo `.aiff` para baixar.

## Dicas

- AIFF não tem perdas, mas ocupa mais espaço do que formatos compactados como [FLAC](/guides/tracks-and-export/export-a-flac/).
- Escolha o formato de amostra e a taxa de amostragem de acordo com os requisitos de entrega.
