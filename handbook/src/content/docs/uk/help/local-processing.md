Локальна допомога працює на вашому пристрої в настільних редакторах Soundscaper і Framescaper. Виберіть медіафайли, а потім завдання в меню. У діалоговому вікні показано вибрані файли, параметри завдання та стан установлення моделей.

Настільні пакети містять власні рушії обробки для опублікованих локальних моделей. Установіть ваги моделі через Диспетчер моделей, а потім запустіть завдання для вибраних медіафайлів. Дивіться [довідку кожної моделі](/reference/local-models/), де наведено підтримувані платформи, пункт меню та вимоги.

## Знайти завдання {#find-a-task}

| Меню | Завдання |
| --- | --- |
| Effect → Noise removal and repair | Enhance Dialogue, Reduce Reverb, Clean Filler & Silence |
| Effect → Source Separation | Separate Dialogue / Music / Effects |
| Analyze → Speech | Transcribe & Captions, Identify Speakers, Mark Reactions |
| Analyze → Music | Detect Beats & Tempo |
| Analyze → Video | Mark Cuts |
| Effect → Video effects | Reframe |
| Edit | Make Highlights |
| Generate | Generate Editorial Text |
| Tools → Search | Indexed Search, Index Transcript, Index Video |

Відеозавдання доступні у Framescaper. Наявні команди залежать від середовища виконання настільної версії та можливостей продукту. Алфавітний пункт меню ефектів у Soundscaper також сортує ефекти локальної обробки за назвою.

Виберіть **Run locally**, щоб почати обробку, і підтвердьте запит згоди на локальну обробку. Під час обробки її можна скасувати. Виберіть **Review result**, позначте потрібні результати й натисніть **Apply selected**. Прийняті зміни проєкту можна скасувати. Закриття завдання не застосовує запропоновані зміни.

У розділі **Tools → Advanced Local Processing** залишилися окремі засоби вибору операцій і моделей. За потреби технічні відомості в діалогових вікнах завдань показують етапи та точні параметри.

## Керування моделями {#manage-models}

Відкрийте **Tools → Model Manager** або виберіть **Manage Models** у завданні. Посилання із завдання відфільтровує список за сумісними моделями; **Show all models** знімає це обмеження. Шукайте за назвою або завданням і фільтруйте за станом установлення.

Установлюйте моделі явно. Під час завантаження показано перебіг, його можна скасувати. Повернення до завдання зберігає його параметри й оновлює доступність моделей, але не починає обробку. Розгорніть **Storage and verification**, щоб отримати доступ до відновлення, очищення, перенесення сховища, повідомлень про ліцензії та автономного встановлення з папки.

Дивіться [довідку окремих моделей](/reference/local-models/), де для кожної опублікованої моделі вказано призначення, пункт меню, розмір завантаження, вимоги, обмеження та фактичні перевірки виведення, які виконує нічний настільний пакет із тестами.

## Керування плагінами й пристроями {#manage-plugins-and-devices}

У **Effect → Plugin Manager** перелічено аудіоплагіни в Soundscaper та плагіни OpenFX у Framescaper. Знайдіть плагін або відфільтруйте список, а потім виберіть його, щоб переглянути версію, дозволи й засоби відновлення. У розділі **Scanning & Settings** містяться параметри пошуку. Керування доступне, навіть коли обробку вимкнено.

Використовуйте аудіоплагіни через **Effect → Audio Plugins**. Команди додавання й редагування відеоефектів у Framescaper розташовано в **Effect → Video effects**.

Відкрийте **Edit → Preferences → Audio settings**, щоб налаштувати власні аудіопристрої та засоби допомоги. У розділі **Media** містяться параметри власних медіафайлів; **Effects** веде до Plugin Manager і містить перемикач пошуку плагінів. Для керування дозволами плагінів і відновлення з карантину потрібні окремі підтверджені дії.
