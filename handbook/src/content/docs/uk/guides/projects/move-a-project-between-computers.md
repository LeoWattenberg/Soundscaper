Проектна бібліотека зберігається в одному браузері на одному комп'ютері. Щоб перенести проект в інше місце — інший пристрій, колега, резервний диск — експортувати його як файл проекту. `.sscape` файл містить аудіо та всі редагування, і відкривається в будь-якому Soundscaper.

:::note[Перехід з Audacity?]
Це аналогічно **Файл → Зберегти проект → Резервна копія проекту, а потім Файл → Відкрити** в Audacity. Назви нижче є власними для Soundscaper, які іноді відрізняються.
:::

## Кроки

1. Відкрийте Soundscaper. Новий порожній проект готовий відразу після завантаження редактора.
2. Виберіть **Файл → Імпортувати аудіо** та оберіть матеріал проекту. Файл потрапляє як кліп на власну доріжку.
3. Виберіть **Файл → Експортувати файл проекту (.sscape)**. Весь проект завантажується як один `.sscape` файл. Зберігайте файл у безпечному місці; це повний проект.
4. Виберіть **Файл → Відкрити файл проекту (.sscape)** та оберіть файл. На комп'ютері, де проект ще не завантажений, він відкривається безпосередньо; тут, де бібліотека вже містить його, Soundscaper пропонує **Відкрити як лише для читання копію** — натисніть її.
   *Ви повинні побачити:* Проект відкривається з доріжкою та кліпом точно так, як було експортовано.

## Поради

- Копія лише для читання не може бути відредагована, доки ви не збережете її як власний проект з меню Файл.
- Файл є архівом ZIP з аудіо всередині; не розпаковуйте його вручну.
