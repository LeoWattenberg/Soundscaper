## Для чого потрібен цей посібник {#what-this-guide-is-for}

Insert звільняє місце для скопійованого звуку, а не накладає його на наявний. Пізніший звук на цільовій доріжці зсувається праворуч на тривалість скопійованого фрагмента. Так можна додати повтор фрази або ще одне речення всередину запису.

:::note[Переходите з Audacity?]
Це відповідає послідовності команд Audacity **Edit → Copy, then Edit → Paste**. Нижче наведено назви Soundscaper; іноді вони відрізняються.
:::

## Кроки

1. Відкрийте Soundscaper. Після завантаження редактора буде готовий новий порожній проєкт.
2. Виберіть **Файл → Імпортувати** і вкажіть запис із фрагментом, який потрібно скопіювати. Він з’явиться як кліп на окремій доріжці.
3. Перетягніть вказівник по лінійці над кліпом, щоб вибрати фрагмент для вставлення в іншому місці.
4. Виберіть **Редагування → Копіювати**.
5. Клацніть хвильову форму в цільовому кліпі в місці, де має починатися копія, щоб установити курсор. Клацання знімає виділення часового діапазону й задає точку вставлення.
6. Виберіть **Редагування → Вставити → Вставка**.
7. Тепер у проєкті відображаються 3 кліпи.
   *Що має бути видно:* Вставлений фрагмент розташований між двома частинами початкового кліпу. Пізніша частина зсунулася праворуч, а рання залишилася на місці.

## Поради

- Insert зсуває пізніший звук на цільовій доріжці. Команда **Редагування → Вставити → Вставити зі збереженням синхронізації** звільнить місце на всіх доріжках, якщо потрібно зберегти їхню синхронізацію.
- Команда **Редагування → Скасувати** скасує вставлення та поверне пізніший звук на попереднє місце.
