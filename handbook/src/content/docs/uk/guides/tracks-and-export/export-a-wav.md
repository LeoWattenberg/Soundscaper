## Для чого потрібен цей посібник {#what-this-guide-is-for}

WAV зберігає кожен зразок точно так, як його має редактор. Використовуйте його для мастерів, для передачі аудіо відео-редактору або іншій DAW, і для будь-чого, що ви можете захотіти обробити знову.

:::note[Перехід з Audacity?]
Це **Файл → Експорт аудіо → WAV** в Audacity. Назви нижче є власними для Soundscaper, які іноді відрізняються.
:::

## Кроки

1. Відкрийте Soundscaper. Нова, порожня робота готова відразу після завантаження редактора.
2. Виберіть **Файл → Імпорт** та оберіть запис для доставки. Файл потрапляє як кліп на власну доріжку.
3. Виберіть **Файл → Експорт аудіо**, встановіть **Формат** на **WAV** та натисніть **Експорт**. Файл завантажується відразу після завершення рендерингу, і його посилання залишається в діалоговому вікні.

## Поради

- Файли WAV великі: приблизно десять мегабайт на хвилину для стерео на рівні якості CD.
- Щоб експортувати кожну доріжку як окремий файл, встановіть **Режим** у діалоговому вікні експорту на окремі стеми.
