## Для чого потрібен цей посібник {#what-this-guide-is-for}

Азбука Морзе перетворює повідомлення на крапки, тире й паузи заданої тривалості. Генератор показує попередній перегляд коду й обчислює довжину кліпу за текстом і швидкістю.

:::note[Переходите з Audacity?]
В Audacity немає **No directly matching built-in Morse code generator**. Назви нижче належать Soundscaper і можуть відрізнятися.
:::

## Кроки

1. Відкрийте Soundscaper. Після завантаження редактора готовий новий порожній проєкт.
2. Виберіть **Генерувати → Код Морзе**. У діалозі **Код Морзе** задайте **Повідомлення** `SOS`, **Швидкість (слів на хвилину)** `20`, **Частота (Гц)** `600`, **Амплітуда** `0.2`, а потім натисніть **Генерувати**. Замініть приклад своїм текстом. Перегляньте кодування: непідтримувані символи блокують генерацію.
3. У проєкті тепер 1 кліп.
   *Очікуваний результат:* Кліп містить повідомлення азбукою Морзе; його довжина залежить від швидкості.

## Поради

- Нижча швидкість подовжує крапки, тире й паузи, не змінюючи частоту тону.
- Duration тут лише для читання. Щоб змінити довжину кліпу, змініть повідомлення або швидкість.
