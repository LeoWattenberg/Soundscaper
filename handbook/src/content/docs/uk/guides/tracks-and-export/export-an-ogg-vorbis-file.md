## Для чого потрібен цей посібник {#what-this-guide-is-for}

Ogg Vorbis створює меншу копію для прослуховування, відкидаючи частину аудіоінформації. Експортуйте мікс у цьому форматі, якщо програвач або сервіс одержувача його підтримує.

:::note[Переходите з Audacity?]
Це команда Audacity 3 **File → Export Audio → Ogg Vorbis**. Назви нижче належать Soundscaper і можуть відрізнятися.
:::

## Кроки

1. Відкрийте Soundscaper. Після завантаження редактора готовий новий порожній проєкт.
2. Виберіть **Файл → Імпортувати** і вкажіть запис чи мікс для поширення. Аудіо з’явиться кліпом на окремій доріжці.
3. Виберіть **Файл → Експортувати звук**, задайте для **Формат** значення **Ogg Vorbis** і натисніть **Експорт**. Після завершення обробки файл завантажиться, а посилання залишиться в діалозі.
   *Очікуваний результат:* Діалог експорту пропонує файл Ogg для завантаження.

## Поради

- Quality визначає компроміс між розміром файлу та якістю кодування.
- Збережіть [майстер без втрат](/guides/tracks-and-export/export-a-flac/), якщо запис знадобиться редагувати чи кодувати повторно.
