## Для чого потрібен цей посібник {#what-this-guide-is-for}

RMS — це середній показник рівня сигналу в часі. Використовуйте аналізатор Measure RMS для порівняння фрагментів або перевірки рівня перед його коригуванням.

:::note[Переходите з Audacity?]
В Audacity цьому відповідає **Analyze → Measure RMS (Nyquist)**. Наведені нижче назви належать Soundscaper і можуть відрізнятися.
:::

## Кроки

1. Відкрийте Soundscaper. Щойно редактор завантажиться, буде готовий новий порожній проєкт.
2. Виберіть **Файл → Імпортувати** і вкажіть фрагмент, середній рівень якого потрібно виміряти. Він з’явиться як кліп на окремій доріжці.
3. Виберіть **Позначення → Позначити все**.
4. Виберіть **Аналіз → Nyquist → Measure RMS**. У вікні **Measure RMS** натисніть **Застосувати**. У діалоговому вікні буде показано результати; натисніть **Закрити**, щоб закрити його.
   *Що має бути видно:* У звіті відображається рівень RMS у dB для кожного каналу та стереосигналу загалом.

## Поради

- RMS показує середній рівень; скористайтеся [peak normalization](/guides/volume/normalize-peaks/), якщо потрібно встановити ціль для найвищого семпла.
- Виділяйте лише фрагмент для порівняння, щоб стороннє аудіо не впливало на вимірювання.
