## Для чого потрібен цей посібник {#what-this-guide-is-for}

Перед нормалізацією чи експортом корисно знати поточний рівень. Вимірювання гучності аналізує виділення так само, як це роблять потокові платформи та мовники: вимірює інтегровану гучність у LUFS, діапазон гучності та справжній пік, щоб ви могли порівняти результат із цільовим значенням, а не вгадувати за індикатором.

:::note[Перехід з Audacity?]
Це вимірювання **Аналіз → Вимірювання RMS** або вимірювання **Нормалізація гучності** в Audacity. Назви нижче є власними для Soundscaper, які іноді відрізняються.
:::

## Кроки

1. Відкрийте Soundscaper. Нова порожня проект відкриється відразу після завантаження редактора.
2. Виберіть **Файл → Імпорт** та оберіть мікс, який ви хочете виміряти. Файл потрапляє як кліп на власну доріжку.
3. Виберіть **Вибрати → Вибрати все**.
4. Виберіть **Аналіз → Виміряти гучність**. Відкриється діалог **Звіт про доставку** зі звітом щодо виділення.
   *Ви повинні побачити:* Інтегрована гучність, діапазон гучності та справжній пік для вибору.

## Поради

- Платформи подкастів зазвичай вимагають −16 LUFS стерео або −19 LUFS моно з піковими значеннями нижче −1 дБТП; перевірте власне керівництво платформи.
- Якщо значення значно відрізняються від цільового, запустіть [Нормалізацію гучності](/guides/volume/normalize-loudness-for-podcasts/) та виміряйте знову.
