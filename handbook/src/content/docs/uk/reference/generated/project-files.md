Файл проекту — це редагований документ. Soundscaper та Framescaper кожен записує свій власний суфікс і відкриває всі з них.

Кожен суфікс нижче містить той самий архів: один ZIP з тим самим маніфестом і тим самим `application/vnd.soundscaper.scape+zip` типом медіа. Суфікс — це лише підказка для маршрутизації. Що насправді є файл, залишається визначеним його маніфестом, схемою, перевірками можливостей та дайджестом, тому перейменування файлу не допускає жодної з перевірок, яку вони відхилять, і не відхиляє жодної, яку вони приймуть.

## Суфікси файлів проекту

| Суфікс | Написаний | Відкритий | Примітки |
| --- | --- | --- | --- |
| `.sscape` | Soundscaper | Кожен продукт | — |
| `.fscape` | Framescaper | Кожен продукт | — |
| `.liscape` | Жоден продукт для постачання | Кожен продукт | Приймається, щоб жоден пізніший продукт не міг претендувати на нього випадково. |
| `.scape` | Нічого | Кожен продукт | Написаний релізами до того, як кожен продукт отримав свій власний суфікс. Наразі нічого не записує його. |

Файл проекту відрізняється від відрендереного експорту. Дивіться [Формат експорту](/reference/generated/formats/) для аудіо та відео, які може створити завершений проект.
