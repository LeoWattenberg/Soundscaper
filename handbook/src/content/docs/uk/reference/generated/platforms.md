Редагування відбувається в браузері та як настільне додаток. На цій сторінці перераховано, що побудовано та перевірено, а не кожне середовище, в якому код може випадково працювати.

## Браузери

«Автоматично перевірено» означає, що набір браузерів працює проти цього двигуна для кожного запиту на витяг. Двигун, який не перелічено, не перевіряється і не стверджується, що він працює.

| Двигун браузера | Автоматично перевірено |
| --- | --- |
| Chromium (Chrome, Edge) | Так |
| Firefox | Так |
| WebKit (Safari) | Так |

## Де може працювати можливість

Можливості групуються за тим, що вони потребують від платформи. Дивіться [Можливості продукту](/reference/generated/product-capabilities/), щоб дізнатися, які можливості кожен продукт дозволяє.

| Рівень | Що це означає |
| --- | --- |
| `web-core` | Працює в кожному підтримуваному браузері, без необхідності будь-якої додаткової функціональної можливості платформи. |
| `web-enhanced` | Працює в браузері, який надає нові функції зберігання та медіа, необхідні для цієї можливості. |
| `electron-enhanced` | Працює в браузері, а настільне додаток робить з ним більше. |
| `electron-only` | Потребує настільного додатка, оскільки браузер не може досягти того, що використовує можливість. |
