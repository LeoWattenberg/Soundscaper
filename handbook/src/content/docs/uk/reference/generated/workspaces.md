Робочий простір — це збережене розташування панелей та інструментальних панелей навколо часової шкали. Вибір одного замінює поточне розташування; ви можете переміщувати будь-що та зберігати власний робочий простір, який не описується на цій сторінці.

## Вбудовані робочі простори

## Розташування

Панель займає одне з цих місць. “Вільне розташування” означає вікно панелі, яке ви можете вільно розміщувати.

| Розташування | ID розташування |
| --- | --- |
| Зліва | `left` |
| Справа | `right` |
| Знизу | `bottom` |
| Вільне розташування | `floating` |
