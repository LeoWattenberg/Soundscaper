## Призначення та використання {#purpose-and-use-case}

Ще одна локальна модель розпізнавання мовлення для розшифрувань і субтитрів.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити потрібний рушій sherpa-onnx-node 1.13.5 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установіть цю модель і потрібне середовище виконання через Менеджер моделей, а потім запустіть завдання локально. Це підтримувані цілі збірки; результати для конкретного пакета й пристрою дивіться у звіті нічного тестування. Для macOS x64 немає рушія, доступного для завантаження, хоча ваги моделі вказано для цієї платформи.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Analyze → Speech → Transcribe & Captions**. Локальна допомога працює в настільному редакторі.

1. Виберіть фрагмент із мовленням.
2. Установіть Parakeet v3 через Manage Models. Для порівняння моделей виберіть її точний ідентифікатор у Tools → Advanced Local Processing.
3. Запустіть локально й перевірте запропоноване розшифрування перед застосуванням.

## Завантаження та вимоги {#download-and-requirements}

Ідентифікатор моделі: `parakeet-tdt-0.6b-v3`, версія **3.0.0**.

Приблизний розмір завантаження артефакту моделі: **639.42 MiB**. Потрібне середовище виконання додається до першого завантаження, якщо його ще не встановлено. Мінімальний обсяг системної пам’яті: **4 GiB**. Вимога каталогу стосується загальної пам’яті, а не вільної пам’яті зараз. Для виведення також потрібна вільна пам’ять, а для встановлення — робочий простір; пам’ять не гарантує швидкість.

Опубліковані платформи: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Також потрібне відповідне середовище виконання, доступне для завантаження.

У Windows установіть останній підтримуваний [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), сумісний із настільною програмою: **x64** для збірки x64 або **ARM64** для збірки ARM64. Нативним рушіям ONNX і Sherpa потрібні ці бібліотеки; завантаження моделі та середовища виконання їх не містять. Для використання програми Visual Studio не потрібна.

Інструменти → Менеджер моделей під час першого встановлення завантажує опубліковані артефакти моделі й потрібне середовище виконання та перевіряє записані дайджести SHA-256. Обробка використовує локально встановлені файли. Відкрийте Сховище та перевірка в Менеджері моделей, щоб переглянути сповіщення, відновити встановлення або змінити місце зберігання.
