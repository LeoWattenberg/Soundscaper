## Призначення та використання {#purpose-and-use-case}

Пропонуйте заголовки, зачини, розділи й пояснення для наявних кандидатів на яскраві моменти.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити потрібний рушій llama-cpp b10509 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установіть цю модель і потрібне середовище виконання через Менеджер моделей, а потім запустіть завдання локально. Це підтримувані цілі збірки; результати для конкретного пакета й пристрою дивіться у звіті нічного тестування.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Framescaper: Tools → Advanced Local Processing → Editorial generation**. Локальна допомога працює в настільному редакторі.

1. Підготуйте й перегляньте кандидати на яскраві моменти з вибраного медіа.
2. Установіть Qwen через Model Manager і погодьтеся на створення редакторських пропозицій.
3. Перевіряйте кожну текстову пропозицію перед прийняттям. Можна використовувати лише дозволені ідентифікатори кандидатів і запитані текстові поля.

## Завантаження та вимоги {#download-and-requirements}

Ідентифікатор моделі: `qwen3-4b-q4-k-m`, версія **1.0.0**.

Приблизний розмір завантаження артефакту моделі: **2.33 GiB**. Потрібне середовище виконання додається до першого завантаження, якщо його ще не встановлено. Мінімальний обсяг системної пам’яті: **16 GiB**. Вимога каталогу стосується загальної пам’яті, а не вільної пам’яті зараз. Для виведення також потрібна вільна пам’ять, а для встановлення — робочий простір; пам’ять не гарантує швидкість.

Опубліковані платформи: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Також потрібне відповідне середовище виконання, доступне для завантаження.

Інструменти → Менеджер моделей під час першого встановлення завантажує опубліковані артефакти моделі й потрібне середовище виконання та перевіряє записані дайджести SHA-256. Обробка використовує локально встановлені файли. Відкрийте Сховище та перевірка в Менеджері моделей, щоб переглянути сповіщення, відновити встановлення або змінити місце зберігання.

## Перевірка результату {#review-the-result}

- Створений текст може вводити в оману або повторюватися. Це пропозиція на основі наданих даних, а не перевірений фактичний аналіз.
- Модель працює локально на CPU й потребує щонайменше 16 GiB загальної системної пам’яті та достатньо вільної пам’яті. Навіть короткі запити можуть тривати кілька хвилин.
- Тест вимагає суворий JSON, кожного дозволеного кандидата рівно один раз і читабельні запитані поля. Команди, шляхи, розмітка, нові часові позначки, сторонні кандидати й неправильний формат відхиляються, а не застосовуються.
