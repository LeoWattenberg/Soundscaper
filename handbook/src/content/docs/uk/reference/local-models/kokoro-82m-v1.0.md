## Призначення та використання {#purpose-and-use-case}

Створюйте мовленнєвий кліп із тексту, вибравши мову й голос.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити автономний помічник Kokoro G2P разом із потрібним рушієм onnxruntime-node 1.29.0 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установіть модель і потрібні середовища виконання через Менеджер моделей та створюйте мовлення локально. У нічному звіті наведено фактичні результати перетворення тексту на WAV для кожного пакета й пристрою.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Generate → Text to Speech**. Локальна допомога працює в настільному редакторі.

1. Введіть текст і виберіть одну з опублікованих пар мови та голосу.
2. Установіть модель Kokoro через Model Manager.
3. Згенеруйте й прослухайте попередній результат, а потім додайте його на нову доріжку або повторно згенеруйте вибраний створений кліп.

<summary>Що перевіряє настільний тест</summary>

Випадок: `kokoro-speech-generation`; операція: `text-to-speech`.

Вхідні дані: дев’ять коротких сценаріїв UTF-8, по одному для кожного мовного варіанта Kokoro v1.0; для кожного вибрано опублікований сумісний голос зі швидкістю 1.

Кожен із дев’яти вибраних голосів Kokoro має створити ненульовий звук моно PCM 24 kHz у правильному контейнері WAV з обмеженим рівнем. Для тесту потрібне повне автономне середовище G2P; відповідь про недоступний адаптер або підмінна модель не пройде перевірку.

Пакет nightly-with-tests завантажує справжні артефакти моделі й перевірені середовища виконання перед виведенням. Обов’язковий тест надсилає текст у кожному з дев’яти мовних варіантів через завантажений помічник G2P і перевіряє отримані WAV-файли. Відсутність або зміну помічника виявляють із безпечною відмовою. Ці ресурсомісткі перевірки виконуються окремо від браузерних тестів. Успішний запуск підтверджує базове створення мовлення для вибраних голосів, а не вимову чи якість сприйняття.

## Перевірка результату {#review-the-result}

- Модель є в каталозі, але перевірений автономний компонент Kokoro для перетворення графем у фонеми має входити до пакета відповідної настільної платформи. Без нього пакет не працюватиме навіть після встановлення ваг.
- Вимова та манера можуть різнитися залежно від мови й голосу. Пакетний тест вимагає ненульового моно WAV 24 kHz для одного голосу в кожному з дев’яти мовних варіантів; він не перевіряє всі 54 голоси чи природність і правильність вимови.
