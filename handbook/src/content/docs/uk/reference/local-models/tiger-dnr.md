## Призначення та використання {#purpose-and-use-case}

Розділяйте змішану звукову доріжку на запропоновані голос, музику й звукові ефекти.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити потрібний рушій onnxruntime-node 1.29.0 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установіть цю модель і потрібне середовище виконання через Менеджер моделей, а потім запустіть завдання локально. Це підтримувані цілі збірки; результати для конкретного пакета й пристрою дивіться у звіті нічного тестування.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Tools → Advanced Local Processing → Source separation**. Локальна допомога працює в настільному редакторі.

1. Виберіть змішаний звук для розділення.
2. Установіть TIGER через Model Manager і запустіть розділення джерел.
3. Прослухайте кожен запропонований окремий канал перед додаванням потрібних результатів до проєкту.

## Завантаження та вимоги {#download-and-requirements}

Ідентифікатор моделі: `tiger-dnr`, версія **1.0.0**.

Приблизний розмір завантаження артефакту моделі: **28.25 MiB**. Потрібне середовище виконання додається до першого завантаження, якщо його ще не встановлено. Мінімальний обсяг системної пам’яті: **4 GiB**. Вимога каталогу стосується загальної пам’яті, а не вільної пам’яті зараз. Для виведення також потрібна вільна пам’ять, а для встановлення — робочий простір; пам’ять не гарантує швидкість.

Опубліковані платформи: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Також потрібне відповідне середовище виконання, доступне для завантаження.

У Windows установіть останній підтримуваний [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), сумісний із настільною програмою: **x64** для збірки x64 або **ARM64** для збірки ARM64. Нативним рушіям ONNX і Sherpa потрібні ці бібліотеки; завантаження моделі та середовища виконання їх не містять. Для використання програми Visual Studio не потрібна.

Інструменти → Менеджер моделей під час першого встановлення завантажує опубліковані артефакти моделі й потрібне середовище виконання та перевіряє записані дайджести SHA-256. Обробка використовує локально встановлені файли. Відкрийте Сховище та перевірка в Менеджері моделей, щоб переглянути сповіщення, відновити встановлення або змінити місце зберігання.

Окремі канали голосу, музики й ефектів мають зберігати очікувані параметри аудіо, містити скінченні відліки й ненульовий сигнал. Кожен має відрізнятися від суміші; дублікати каналів відхиляються.

## Перевірка результату {#review-the-result}

- Після розділення можливі проникнення звуку між каналами й артефакти; воно не відновлює початкові доріжки без втрат.
- Тест суміші вимагає всі три канали, скінченний звук правильного розміру та змінені ненульові відліки в кожному. Він також відхиляє дублікати каналів, але не оцінює якість розділення.
