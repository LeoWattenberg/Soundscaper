## Призначення та використання {#purpose-and-use-case}

Зчитуйте видимий текст із вибраних кадрів відео для перегляду та індексування.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити потрібний рушій onnxruntime-node 1.29.0 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установіть цю модель і потрібне середовище виконання через Менеджер моделей, а потім запустіть завдання локально. Це підтримувані цілі збірки; результати для конкретного пакета й пристрою дивіться у звіті нічного тестування. Для macOS x64 немає рушія, доступного для завантаження, хоча ваги моделі вказано для цієї платформи.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Framescaper: Tools → Search → Index Video, or Tools → Advanced Local Processing → Optical character recognition**. Локальна допомога працює в настільному редакторі.

1. Виберіть відео з читабельним текстом на екрані.
2. Установіть PP-OCRv4 mobile через Manage Models. Це необов’язковий етап Index Video, який також використовує SigLIP2.
3. Запустіть локально та перевірте розпізнаний текст і розташування його кадрів перед прийняттям результатів.

## Завантаження та вимоги {#download-and-requirements}

Ідентифікатор моделі: `ppocr-v4-mobile`, версія **4.0.0**.

Приблизний розмір завантаження артефакту моделі: **15.46 MiB**. Потрібне середовище виконання додається до першого завантаження, якщо його ще не встановлено. Мінімальний обсяг системної пам’яті: **2 GiB**. Вимога каталогу стосується загальної пам’яті, а не вільної пам’яті зараз. Для виведення також потрібна вільна пам’ять, а для встановлення — робочий простір; пам’ять не гарантує швидкість.

Опубліковані платформи: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Також потрібне відповідне середовище виконання, доступне для завантаження.

У Windows установіть останній підтримуваний [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), сумісний із настільною програмою: **x64** для збірки x64 або **ARM64** для збірки ARM64. Нативним рушіям ONNX і Sherpa потрібні ці бібліотеки; завантаження моделі та середовища виконання їх не містять. Для використання програми Visual Studio не потрібна.

Інструменти → Менеджер моделей під час першого встановлення завантажує опубліковані артефакти моделі й потрібне середовище виконання та перевіряє записані дайджести SHA-256. Обробка використовує локально встановлені файли. Відкрийте Сховище та перевірка в Менеджері моделей, щоб переглянути сповіщення, відновити встановлення або змінити місце зберігання.

## Перевірка результату {#review-the-result}

- Дрібний, розмитий, повернутий, стилізований або частково прихований текст може бути пропущений чи прочитаний неправильно.
- Пакетний тест вимагає текстових областей, тому запускаються детектор, модель орієнтації й розпізнавач. Дослівного збігу кожного символу він не вимагає.
