## Призначення та використання {#purpose-and-use-case}

Розшифровуйте вибране мовлення локально через упаковане середовище виконання whisper.cpp.

## Поточна доступність {#current-availability}

Настільні збірки можуть завантажити й перевірити потрібний рушій whisper-cpp v1.9.3 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установіть цю модель і потрібне середовище виконання через Менеджер моделей, а потім запустіть завдання локально. Це підтримувані цілі збірки; результати для конкретного пакета й пристрою дивіться у звіті нічного тестування. Для macOS x64 немає рушія, доступного для завантаження, хоча ваги моделі вказано для цієї платформи.

## Використання моделі {#use-this-model}

На платформі з потрібним власним середовищем виконання відкрийте **Analyze → Speech → Transcribe & Captions**. Локальна допомога працює в настільному редакторі.

1. Виберіть мовлення й установіть Whisper large-v3 turbo через Manage Models.
2. Якщо потрібно явно вибрати Whisper, оберіть цю модель розпізнавання мовлення в Tools → Advanced Local Processing.
3. Запустіть локально й перевірте текст та межі фрагментів перед прийняттям.

## Завантаження та вимоги {#download-and-requirements}

Ідентифікатор моделі: `whisper-large-v3-turbo-ggml`, версія **1.0.0**.

Приблизний розмір завантаження артефакту моделі: **547.45 MiB**. Потрібне середовище виконання додається до першого завантаження, якщо його ще не встановлено. Мінімальний обсяг системної пам’яті: **4 GiB**. Вимога каталогу стосується загальної пам’яті, а не вільної пам’яті зараз. Для виведення також потрібна вільна пам’ять, а для встановлення — робочий простір; пам’ять не гарантує швидкість.

Опубліковані платформи: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Також потрібне відповідне середовище виконання, доступне для завантаження.

Інструменти → Менеджер моделей під час першого встановлення завантажує опубліковані артефакти моделі й потрібне середовище виконання та перевіряє записані дайджести SHA-256. Обробка використовує локально встановлені файли. Відкрийте Сховище та перевірка в Менеджері моделей, щоб переглянути сповіщення, відновити встановлення або змінити місце зберігання.

## Перевірка результату {#review-the-result}

- Whisper може створювати неправильний текст, особливо за наявності шуму або невиразного мовлення. Перевіряйте на слух.
- Тест перевіряє, що справжнє середовище виконання повертає непорожнє розшифрування з часовими позначками; він не гарантує конкретного написання чи оцінки точності.
