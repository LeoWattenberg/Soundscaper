Обидва видання обробляють проекти локально. Їхнє зберігання та доступ до файлів відрізняються.

## Веб-редактор

Веб-видання зберігає проекти, записи та імпортовані медіа в локальному сховищі браузера. Він не завантажує проект на обліковий запис Soundscaper, і обліковий запис не потрібен.

Використовуйте веб-редактор, коли ви хочете негайного доступу без встановлення програми. Пам'ятайте, що сховище браузера підлягає квотам і правилам видалення браузера. Очищення даних сайту видаляє локальну бібліотеку проектів.

## Настільний переглядач

Упаковані настільні переглядачі зберігають автозбережену локальну бібліотеку всередині настільної програми. Вони об'єднують середовище виконання редактора та випущені переклади для офлайн-редагування.

Настільні пакети не підписані. macOS застосовує лише ідентичність безпечного коду для ад-хок запечатування свого завантажувача, необхідного для виконання Electron та рідних бінарних файлів; це запечатування не робить жодних тверджень про видавця чи довіру. Отже, Windows SmartScreen або macOS Gatekeeper можуть відображати попередження про невідомого розробника для переглядів та стабільних пакетів.

Відкриття файлу `.aup4` імпортує незалежний проект до настільної бібліотеки. Пізніші редагування не переписують файл, який ви відкрили. **Зберегти** оновлює копію бібліотеки; **Зберегти як** створює новий файл обміну Audacity.

## Телефон та планшети

Веб-редактор зберігає свій настільний макет на кожному екрані, але менше 900 пікселів у ширину (телефон або планшет, утримуваний вертикально) він згортає хром у шухляди, щоб часова шкала залишалася на місці:

- Кнопка **Меню** у верхньому лівому куті відкриває шухляду з повним меню програми, вкладками проекту, панеллю дій та панеллю інструментів. Відтворення, зупинка, запис та пошук залишаються на панелі. Вибір команди закриває шухляду.
- Заголовки доріжок зсуваються над доріжками з ручки **Заголовки доріжок** у верхньому лівому куті часової шкали або з **Вид > Заголовки доріжок**. Натиснення на доріжки або натиснення клавіші Escape знову прибирає їх.
- Вступ над редактором звужується за замовчуванням на вузьких екранах; **Показати вступ** повертає його.

**Редагувати > Параметри > Зовнішній вигляд > Макет** перемикається між Автоматичним, Компактним та Настільним, тому невелике вікно на настільному комп'ютері може зберігати настільний хром, а широкий планшет може перейти до шухляд.

## Проекти не переміщуються автоматично

Бібліотеки браузера та настільних комп'ютерів окремі. Перемістіть проект навмисно:

- Використовуйте файл проекту Soundscaper - `.sscape`, Framescaper - `.fscape` для повного проекту.
- Використовуйте AUP4, коли вам потрібен аудіообмін з Audacity.
- Експортуйте відрендерований аудіо- або відеофайл як довготривалу копію для відтворення.

Дивіться [Файли проектів](/projects-and-data/project-files/) перед видаленням даних браузера або даних настільної програми.
