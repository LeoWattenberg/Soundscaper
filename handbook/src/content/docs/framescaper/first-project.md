## 1. Import a video

Choose **File → Import** and select a supported video. Imported video and its
extracted audio enter the Project Bin as one media item and are normally placed
on adjacent linked lanes.

The original video is stored as project media. Posters and filmstrip thumbnails
are disposable previews and can be regenerated.

## 2. Review source and sequence

Use the Source Monitor to inspect material before placing or adjusting it. Use
the Video Preview to inspect the composed sequence.

Linked picture and audio edits move, split, trim, and stretch together unless
you explicitly unlink them. Play across each edit to verify both picture and
sound.

## 3. Arrange and finish

Use timeline edit commands for ordinary trims and moves. Framescaper also
exposes video effects, geometry, compositing, nested sequences, and multicamera
commands when the current selection supports them.

Save the local project, then continue to [video export](/framescaper/video-export/).
