Een tutorial is een les: het leidt je stap voor stap door een compleet werkstuk met behulp van een voorbeeldopname uit de handleiding. Begin hier als je nog nooit eerder met Soundscaper hebt gewerkt. Als je bekend bent met de interface en je eigen opname hebt, dekken de [how-to-gidsen](/guides/) dezelfde bewerkingen en nog veel meer, één taak tegelijk. 

- [Je eerste Soundscaper-project](/tutorials/your-first-project/) — Importeer een opname, luister ernaar, splijt deze, vervaag het einde, exporteer een bestand en sla het project op.
- [Verwijder achtergrondgeluiden van een stemopname](/tutorials/clean-up-a-voice-recording/) — Verwijder het zoemgeluid, snij het gedreun eruit, breng het naar podcast-volume en exporteer als MP3.
- [Voeg muziek toe onder een stem](/tutorials/put-music-under-a-voice/) — Leg twee sporen op elkaar, laat er automatisch één onder de andere ducken, mix ze en exporteer.

## Hoe de tutorials up-to-date blijven

Elke tutorial wordt bij elke nieuwe versie van Soundscaper herhaald op de voorbeeldbestanden, stap voor stap, door de browser suite (`tests/browser/soundscaper-tutorials.spec.js`). Een stap die niet meer werkt, zorgt ervoor dat de build mislukt in plaats van dat de tutorial verouderd raakt.
