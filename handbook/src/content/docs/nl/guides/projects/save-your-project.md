Een project is meer dan alleen de audio: het omvat ook de sporen, clips, effecten, markers en geschiedenis. Opslaan bewaart al deze elementen in de lokale projectbibliotheek van de browser op deze computer, waar het opnieuw kan worden geopend via het menu Bestand. Soundscaper slaat ook automatisch op tijdens het werken, dus dit is vooral een manier om zeker te zijn. 

:::note[Komt van Audacity?]
Dit is Audacity's **Bestand → Project opslaan**. De namen hieronder zijn de eigen namen van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Audio importeren** en selecteer iets om mee te werken. Het bestand wordt als een clip op zijn eigen spoor geplaatst.
3. Kies **Bestand → Project opslaan**. De opslagindicator in de statusbalk toont aan dat het project is opgeslagen.

## Tips

- Om een project naar een andere computer te verplaatsen of een kopie buiten de browser te bewaren, zie [Een project tussen computers verplaatsen](/guides/projects/move-a-project-between-computers/).
- Een audio-export is een luisterkopie, geen project. Bewaar het project als u mogelijk opnieuw wilt bewerken.
