Een mixingenieur, videomonteur of samenwerker in een ander programma wil meestal de afzonderlijke onderdelen, niet de mix. Een stems-export render elke track naar een eigen bestand, allemaal van dezelfde lengte en uitgelijnd met het begin van het project, en pakt ze in één archief. 

:::note[Komt van Audacity?]
Dit is Audacity's **Bestand → Exporteer Audio → Exporteer meerdere bestanden, gesplitst per track**. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer het eerste nummer. Het bestand wordt als een clip op zijn eigen track geplaatst.
3. Kies **Bestand → Importeer audio** en selecteer het tweede nummer. Het bestand wordt als een clip op zijn eigen track geplaatst.
4. Kies **Bestand → Exporteer audio**, stel **Formaat** in op **WAV**, stel **Uitvoer** in op **Afzonderlijke stems (gesplitst per track)**, en druk op **Exporteren**. Het bestand wordt gedownload zodra de render klaar is, en de link blijft in het dialoogvenster. Elke track wordt een WAV binnen de ZIP, bijgesneden tot dezelfde lengte zodat ze op elkaar aansluiten bij het importeren ergens anders.

## Tips

- Mute en solo hebben geen invloed op stems; elke track wordt gerenderd.
- Noem de tracks voordat je exporteert — de stembestanden nemen hun namen van hen over.
