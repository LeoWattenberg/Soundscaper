Een clip die is opgenomen op 44,1 kHz speelt nog steeds correct af in een project van 48 kHz - Soundscaper converteert op de fly - maar voor een levering die op één snelheid moet zijn, of voor een effect dat deze verwacht, kunt u de clip zelf converteren. Hersteekproeven berekenen elk monster opnieuw op de nieuwe snelheid en houden de timing precies in stand.

:::note[Komt van Audacity?]
Dit is **Tracks → Hersteekproeven** in Audacity. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer de clip met de verkeerde snelheid. Het bestand komt als clip op zijn eigen spoor terecht.
3. Open het menu van de clip vanaf de **Clip menu**-knop op de naambalk en kies **Clip-eigenschappen**. Druk op **Hersteekproeven**, stel de snelheid in op `44100` en druk opnieuw op **Hersteekproeven**. De eigenschappen van de clip tonen de huidige snelheid; 44100 Hz is CD-standaard.
4. Druk op **Afspelen** om te luisteren, druk vervolgens op **Stop**.
   *U zou moeten zien:* De clip klinkt precies zoals voorheen; alleen de opgeslagen snelheid is veranderd.

## Tips

- Hersteekproeven is een bewerking en kan ongedaan worden gemaakt.
- Als je de snelheid verlaagt, worden de hoogste frequenties verwijderd; als je de snelheid verhoogt, wordt er niets toegevoegd, maar dat is onschadelijk.
