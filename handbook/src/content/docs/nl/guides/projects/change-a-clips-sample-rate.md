Een clip die is opgenomen op 44,1 kHz wordt nog steeds correct afgespeeld in een project van 48 kHz - Soundscaper converteert op de fly - maar als je de clip op zichzelf moet leveren of als deze moet worden gebruikt voor een effect dat een specifieke samplefrequentie verwacht, kun je de clip zelf converteren. Resampling berekent elk sample opnieuw op de nieuwe frequentie en behoudt de timing precies.

:::note[Komt van Audacity?]
Dit is **Tracks → Resample** in Audacity. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeren** en selecteer de clip met de verkeerde frequentie. Deze wordt als clip op zijn eigen spoor geplaatst.
3. Open het menu van de clip via de **Clip menu**-knop op de naambalk en kies **Clip-eigenschappen**. Druk op **Resample**, stel de frequentie in op `44100` en druk opnieuw op **Resample**. De eigenschappen van de clip tonen de huidige frequentie; 44100 Hz is de CD-standaard.
4. Druk op **Afspelen** om te luisteren, vervolgens op **Stop**.
   *Je zou moeten zien:* De clip klinkt precies zoals voorheen; alleen de opgeslagen frequentie is veranderd.

## Tips

- Resampling is een bewerking en kan worden ongedaan gemaakt.
- Als je de frequentie verlaagt, worden de hoogste frequenties verwijderd; als je de frequentie verhoogt, wordt er niets toegevoegd, maar dat is onschadelijk.
