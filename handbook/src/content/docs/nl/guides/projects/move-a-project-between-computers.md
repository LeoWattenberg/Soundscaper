De projectbibliotheek bevindt zich in één browser op één computer. Om een project ergens anders te gebruiken - op een andere machine, bij een collega, op een back-upschijf - exporteer het als een projectbestand. Het `.sscape`-bestand bevat de audio en elke bewerking en opent in elke Soundscaper.

:::note[Komt van Audacity?]
Dit is Audacity's **Bestand → Project opslaan → Back-up project, gevolgd door Bestand → Open**. De namen hieronder zijn Soundscaper's eigen namen, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer het projectmateriaal. Het bestand wordt als een clip op zijn eigen spoor geplaatst.
3. Kies **Bestand → Exporteer projectbestand (.sscape)**. Het hele project wordt gedownload als één `.sscape`-bestand. Bewaar het bestand op een veilige plek; het is het volledige project.
4. Kies **Bestand → Open Scape-projectbestand (.sscape)** en selecteer het bestand. Op een computer die het project nog niet heeft, opent het rechtstreeks; hier, waar de bibliotheek het al bevat, biedt Soundscaper **Open als alleen-lezen kopie** aan - druk erop.
   *Je zou moeten zien:* Het project opent met zijn spoor en clip precies zoals geëxporteerd.

## Tips

- Een alleen-lezen kopie kan niet worden bewerkt totdat u het als een eigen project opslaat vanuit het Bestand-menu.
- Het bestand is een ZIP-archief met de audio erin; pak het niet handmatig uit.
