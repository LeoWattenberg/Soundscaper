Een twee-balk lus, een achtergrondbed dat onder een langere voice-over moet lopen, een geluidseffect dat moet blijven gaan: Repeat kopieert de selectie direct na zichzelf zoveel keer als je vraagt.

:::note[Komt van Audacity?]
Dit is Audacity's **Effect → Special → Repeat**. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en kies het geluid dat je wilt herhalen. Het bestand komt als een clip op zijn eigen spoor terecht.
3. Kies **Selecteren → Alles selecteren**.
4. Kies **Effect → Speciaal → Herhalen**. In het **Herhalen**-dialoogvenster, stel **Aantal herhalingen** in op `2`, en druk vervolgens op **Toepassen op selectie**. Twee herhalingen geven drie kopieën op rij.
5. Druk op **Afspelen** om te luisteren, en vervolgens op **Stop**.
   *Je zou moeten zien:* De passage speelt drie keer achter elkaar zonder onderbreking.

## Tips

- Voor een naadloze lus, zorg ervoor dat de selectie begint en eindigt op stilte of op een nul-kruising (**Selecteren → Op nul-kruisingen**).
- Het effect verandert de lengte van de clip, dus alles na de clip op hetzelfde spoor wordt opzij geduwd.
