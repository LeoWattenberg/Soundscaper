Duplicaten kopieert de selectie naar een nieuw spoor direct onder, op dezelfde positie in de tijd. Het is de gebruikelijke eerste stap voor parallelle verwerking — een zwaar gecomprimeerde kopie gemengd onder het origineel, een reverb-only spoor, een gedubde vocal.

:::note[Komt van Audacity?]
Dit is Audacity's **Bewerken → Dupliceren (Ctrl+D)**. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer de opname met het te dupliceren fragment. Het bestand komt als een clip op zijn eigen spoor terecht.
3. Sleep in de regel boven de clip om het fragment te selecteren dat je wilt dupliceren.
4. Kies **Bewerken → Dupliceren**.
5. Het project toont nu 2 clips.
   *Je zou moeten zien:* Een tweede clip met alleen de selectie, op een nieuw spoor onder de eerste, op tijd uitgelijnd.

## Tips

- Zet een van de twee sporen stil om de andere op zichzelf te horen terwijl je deze vormgeeft.
- Wanneer je tevreden bent met de mix, [mix de sporen naar beneden](/guides/tracks-and-export/mix-tracks-into-one/).
