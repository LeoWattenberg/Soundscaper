## Waar deze gids voor is {#what-this-guide-is-for}

Een wah-pedaal veegt een resonante filter door het spectrum; het Wahwah-effect doet de veeg voor je met een door jou ingestelde snelheid. Het is geschikt voor gitaren, toetsenborden en alles met een constante duur. 

:::note[Komt van Audacity?]
Dit is Audacity's **Effect → Wahwah**. De namen hieronder zijn die van Soundscaper, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeren** en selecteer de opname waarop je de wah wilt toepassen. Deze wordt geplaatst als een clip op zijn eigen spoor.
3. Kies **Selecteren → Alles selecteren**.
4. Kies **Effect → Distorsie en modulatie → Wahwah**. In het **Wahwah**-dialoogvenster, stel **LFO-frequentie** in op `2` en **Diepte** op `80`, druk vervolgens op **Toepassen op selectie**. De LFO-frequentie bepaalt hoeveel veegbewegingen per seconde plaatsvinden; de diepte bepaalt hoe ver het filter beweegt.
5. Druk op **Afspelen** om te luisteren, druk vervolgens op **Stop**.
   *Je zou moeten zien:* De opname wobbelt met een veegende, klinkerachtige toon.

## Tips

- **Resonantie** scherpt de piek van het filter; hoge waarden piepen.
- De **Phaser** in hetzelfde submenu geeft een mildere, draaiende beweging.
