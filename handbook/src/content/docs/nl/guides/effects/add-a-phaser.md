Een phaser mengt een geluid met een kopie van zichzelf die door bewegende all-pass fasen gaat, waardoor erches door het spectrum bewegen in tempo met een trage oscillator. Op een gitaar, een elektrische piano of een pad geeft het de draaiende klank die op talloze platen te horen is. Audacity 3 leverde een phaser en Audacity 4 niet, dus dit is er een om hier voor te gebruiken.

:::note[Komt van Audacity?]
Dit is Audacity's **Effect → Phaser (Audacity 3; Audacity 4 heeft geen Phaser)**. De namen hieronder zijn die van Soundscaper zelf, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer het geluid dat je wilt bewerken. Het bestand wordt als een clip op zijn eigen spoor geplaatst.
3. Kies **Selecteren → Alles selecteren**.
4. Kies **Effect → Distorsie en modulatie → Phaser**. In het **Phaser**-dialoogvenster, stel **Fasen** in op `4` en stel **LFO-frequentie** in op `0.6`, druk vervolgens op **Toepassen op selectie**. Meer fasen zorgen voor diepere notches; vier is een klassieke pedaalinstelling. De LFO-frequentie bepaalt hoe snel de sweep beweegt - 0,6 Hz is een trage, muzikale draai.
5. Druk op **Afspelen** om te luisteren, druk vervolgens op **Stop**.
   *Je zou moeten zien:* Het geluid draait langzaam terwijl de notches door het geluid bewegen.

## Tips

- **Feedback** scherpt de notches aan tot een meer metalen, resonante sweep; houd deze dicht bij nul voor een subtiel effect.
- Phaser kan ook als realtime-effect in een spoorrek worden uitgevoerd, zodat je de sweep kunt horen terwijl je deze aanpast: [Voeg een realtime-effect toe aan een spoor](/guides/effects/add-a-realtime-effect-to-a-track/).
