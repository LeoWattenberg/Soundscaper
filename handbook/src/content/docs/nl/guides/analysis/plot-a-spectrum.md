Een golfvorm toont hoe luid een geluid is in de loop van de tijd; een spectrum toont welke frequenties het bevat. Het plotten van het spectrum van een problematische passage is de snelste manier om een 50 of 60 Hz zoem, een fluittoon van een monitor of de frequentie waarop een ruimte galmt te vinden - en vervolgens te weten waar je een equalizer op moet richten.

:::note[Komt van Audacity?]
Dit is Audacity's **Analyseer → Plot Spectrum**. De namen hieronder zijn die van Soundscaper zelf, die soms verschillen.
:::

## Stappen

1. Open Soundscaper. Een nieuw, leeg project is klaar zodra de editor is geladen.
2. Kies **Bestand → Importeer audio** en selecteer de opname met het probleem. Het bestand wordt als een clip op zijn eigen spoor geplaatst.
3. Kies **Selecteren → Alles selecteren**.
4. Kies **Analyseren → Plot spectrum**. Het **Plot spectrum**-paneel opent.
   *Je zou moeten zien:* Een grafiek van niveau tegen frequentie voor de selectie.

## Tips

- Selecteer alleen de problematische passage - een strekking van zoem op zichzelf, bijvoorbeeld - zodat het spectrum niet wordt gedomineerd door de muziek of spraak eromheen.
- Een hoge smalle piek is een toon; een breed plateau is ruis. Tonen reageren op een smalle EQ-snede, ruis op [Ruisreductie](/guides/cleaning-up/remove-background-noise/).
