Geluidseffecten worden geregistreerd door Soundscaper. Effecten waarvan de ID begint met `audacity-` zijn aangepast van Audacity 3.7.7 op [`5ef610ed2326`](https://github.com/audacity/audacity/tree/Audacity-3.7.7); de pitch- en tempo-effecten gebruiken de StaffPad tijd- en pitchbibliotheek vastgezet op Audacity 4.0.0 op [`4c177d436e48`](https://github.com/audacity/audacity/tree/4c177d436e48c1d20f231eada44035593cb26292). Elk ander effect is geschreven voor deze repository.

"Realtime rack" betekent dat het effect in een track of master rack kan zitten en audio kan verwerken terwijl deze afspeelt. "Selectie" betekent dat het effect kan worden gepreviewd en destructief kan worden toegepast op een geselecteerd bereik. Een effect kan beide doen.
