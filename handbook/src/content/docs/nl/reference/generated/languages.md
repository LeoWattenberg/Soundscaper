De editor wordt geserveerd via één route per taal. Een taal die niet in deze lijst staat, valt terug op Engels.

Voor twee talen wordt rechtstreeks geschreven en beoordeeld voor deze editor. De rest is machinaal vertaald vanuit het Engelse origineel, en waar Audacity's vertalers dezelfde commando-naam hebben beoordeeld, wordt hun woordkeuze getoond. Engelse varianten bevatten alleen Audacity's beoordeelde strings over het Engels.
