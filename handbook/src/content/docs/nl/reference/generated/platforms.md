## Browsers

"Automatisch getest" betekent dat de browsersuite op elke pull request tegen deze engine wordt uitgevoerd. Een engine die niet vermeld staat, wordt niet getest en wordt niet als werkend beschouwd.

| Browser engine | Automatisch getest |
| --- | --- |
| Chromium (Chrome, Edge) | Ja |
| Firefox | Ja |
| WebKit (Safari) | Ja |

## Waar een mogelijkheid kan worden uitgevoerd

Mogelijkheden zijn gegroepeerd op basis van wat ze van het platform nodig hebben. Zie [Productmogelijkheden](/reference/generated/product-capabilities/) voor welke mogelijkheden elk product inschakelt.

| Tier | Wat het betekent |
| --- | --- |
| `web-core` | Werkt in elke ondersteunde browser, zonder optionele platformfunctie vereist. |
| `web-enhanced` | Werkt in een browser die de nieuwere opslag- en mediafuncties biedt die de mogelijkheid nodig heeft. |
| `electron-enhanced` | Werkt in de browser, en de bureaubladapplicatie doet er meer mee. |
| `electron-only` | Heeft de bureaubladapplicatie nodig, omdat een browser niet kan bereiken wat de mogelijkheid gebruikt. |
