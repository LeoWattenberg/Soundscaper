## Doel en gebruik {#purpose-and-use-case}

Groeperen van spraak in sprekerbeurten om te kunnen zien wie wanneer spreekt.

ERes2Net verandert spraaksamenten in numerieke weergaven van de spreker. De diarisatieruntime combineert deze met Pyannote-segmentatie om de opname in sprekerbeurten te groeperen.

## Huidige beschikbaarheid {#current-availability}

Desktopbuilds kunnen de vereiste engine sherpa-onnx-node 1.13.5 voor macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 downloaden en verifiëren. Installeer dit model en de vereiste runtime via Modelbeheer en voer de taak lokaal uit. Dit zijn ondersteunde builddoelen; raadpleeg het testrapport van de nachtelijke run voor resultaten op een bepaald pakket en apparaat. Er is geen downloadbare engine voor macOS x64, hoewel de modelgewichten voor dat platform worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Analyseer → Spraak → Identificeer sprekers** op een platform met de vereiste native runtime. Lokale assistentie werkt in de bureaubladeditor.

1. Selecteer het gesprek dat u wilt analyseren.
2. Installeer zowel Pyannote-segmentatie als ERes2Net-sprekerinbedding via Modelbeheer; de bewerking gebruikt het paar.
3. Voer lokaal uit, bekijk de voorgestelde sprekerbeurten en pas de gewenste resultaten toe.

Deze bewerking vereist ook [Pyannote-segmentatie 3.0](/reference/local-models/pyannote-segmentation-3.0/).

## Downloaden en vereisten {#download-and-requirements}

Modelidentiteit: `speech-3d-speaker-eres2net`, versie **1.0.0**.

Geschatte downloadgrootte van het modelbestand: **25.26 MiB**. De vereiste runtime wordt aan de eerste download toegevoegd als deze nog niet is geïnstalleerd. Minimaal systeemgeheugen: **2 GiB**. Deze catalogusvereiste betreft het totale geheugen, niet het huidige vrije geheugen. Inferentie heeft ook voldoende vrij geheugen nodig en installatie vereist werkruimte; geheugen garandeert geen snelheid.

Gepubliceerde platforms: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Een overeenkomende downloadbare runtime is ook vereist.

Installeer op Windows de nieuwste ondersteunde [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) die bij de desktopapp past: **x64** voor een x64-build of **ARM64** voor een ARM64-build. De native ONNX- en Sherpa-engines hebben deze bibliotheken nodig; model- en runtime-downloads bevatten ze niet. Visual Studio is niet nodig om de app te gebruiken.

Extra → Modelbeheer downloadt bij de eerste installatie de gepubliceerde modelbestanden en de vereiste runtime en controleert de geregistreerde SHA-256-digests. De verwerking gebruikt de lokaal geïnstalleerde bestanden. Open Opslag en verificatie in Modelbeheer om meldingen te bekijken, een installatie te herstellen of de opslaglocatie te wijzigen.

## Resultaat bekijken {#review-the-result}

- Spreker-ID's zijn groepen die uit de opname zijn afgeleid, niet geverifieerde echte identiteiten.
- Korte uitspraken, overlappende stemmen en vergelijkbare stemmen kunnen onjuist worden gegroepeerd. De test controleert geldige, niet-lege beurten, niet een exact aantal sprekers.
