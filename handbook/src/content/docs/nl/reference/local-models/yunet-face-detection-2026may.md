## Doel en gebruik {#purpose-and-use-case}

Gezichten en objecten in geselecteerde videobeelden lokaliseren om een nieuwe inrichting voor te stellen.

YuNet detecteert gezichten en hun locaties. De subjectdetectie-operatie combineert deze resultaten met D-FINE-objectdetecties.

## Huidige beschikbaarheid {#current-availability}

Desktopbuilds kunnen de vereiste engine onnxruntime-node 1.29.0 voor macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 downloaden en verifiëren. Installeer dit model en de vereiste runtime via Modelbeheer en voer de taak lokaal uit. Dit zijn ondersteunde builddoelen; raadpleeg het testrapport van de nachtelijke run voor resultaten op een bepaald pakket en apparaat. Er is geen downloadbare engine voor macOS x64, hoewel de modelgewichten voor dat platform worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Effect → Video-effecten → Herkader** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktop-editor.

1. Selecteer een videoclip in Framescaper.
2. Installeer zowel YuNet als D-FINE voor subjectdetectie. De begeleide Herkader-taak gebruikt ook U²-Net-P-salientie-detectie.
3. Voer lokaal uit en bekijk de voorgestelde gewassen. Tools → Geavanceerde lokale verwerking kan subjectdetectie op zichzelf uitvoeren.

Deze operatie vereist ook [D-FINE Nano-objectdetectie](/reference/local-models/dfine-nano-coco/).

## Resultaat beoordelen {#review-the-result}

- Gezichten en objecten kunnen worden gemist of verkeerd geclassificeerd. Detectie is gesampled en garandeert niet dat een bewegend onderwerp binnen elke voorgestelde gewassen blijft.
- De operatie voert beide modellen tegelijk uit; geen van beide modellen is een gezichtsherkenningsysteem voor het identificeren van personen.
