Gezichten en objecten in geselecteerde videobeelden lokaliseren om een nieuwe inrichting voor te stellen.

YuNet detecteert gezichten en hun locaties. De subjectdetectie-operatie combineert deze resultaten met D-FINE-objectdetecties.

## Huidige beschikbaarheid {#current-availability}

Desktop-builds bevatten de vereiste onnxruntime-node 1.29.0-engine voor macOS arm64, Linux arm64, Linux x64, Windows arm64 en Windows x64. Installeer de gewichten van dit model via Model Manager en voer de taak lokaal uit. Dit zijn de ondersteunde build-doelen; raadpleeg het nachtelijke testrapport voor resultaten over een bepaald pakket en machine. De desktopbuild bevat deze engine niet voor macOS x64, hoewel modelgewichten voor deze platforms worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Effect → Video-effecten → Herkader** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktop-editor.

1. Selecteer een videoclip in Framescaper.
2. Installeer zowel YuNet als D-FINE voor subjectdetectie. De begeleide Herkader-taak gebruikt ook U²-Net-P-salientie-detectie.
3. Voer lokaal uit en bekijk de voorgestelde gewassen. Tools → Geavanceerde lokale verwerking kan subjectdetectie op zichzelf uitvoeren.

Deze operatie vereist ook [D-FINE Nano-objectdetectie](/reference/local-models/dfine-nano-coco/).

## Wat de verpakte test controleert {#what-the-packaged-test-checks}

Geval: `subject-detection`; operatie: `subject-detection`.

Invoer: Twee foto's: het publiek-domein NASA-portret van astronaut Eileen Collins en de CC0 Chelsea-katfoto. Elk wordt in een aparte frame geplaatst met expliciete bron-frametiming, waardoor de detectoren een menselijk gezicht en een duidelijk object krijgen.

Gezicht- en objectresultaten moeten geldige bron-frametiming, eindige betrouwbaarheidsscores en begrensde vakken hebben. De subject-fixture moet detecties van beide modellen produceren.

Het pakket-met-tests-pakket downloadt echte modelartefacten en vraagt om inferentie via de verpakte runtime. Een vereist model dat ontbreekt in de catalogus, faalt in zijn geval. Ontbrekende native engines falen op catalogusondersteunde platforms. Deze kostbare controles worden apart uitgevoerd van de normale browsersuite. ## Resultaat beoordelen {#review-the-result}

- Gezichten en objecten kunnen worden gemist of verkeerd geclassificeerd. Detectie is gesampled en garandeert niet dat een bewegend onderwerp binnen elke voorgestelde gewassen blijft.
- De operatie voert beide modellen tegelijk uit; geen van beide modellen is een gezichtsherkenningsysteem voor het identificeren van personen.
