## Doel en gebruik {#purpose-and-use-case}

Transcribeer geselecteerde spraak lokaal via de ingepakte whisper.cpp-runtime.

## Huidige beschikbaarheid {#current-availability}

Desktopbuilds kunnen de vereiste engine whisper-cpp v1.9.3 voor macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 downloaden en verifiëren. Installeer dit model en de vereiste runtime via Modelbeheer en voer de taak lokaal uit. Dit zijn ondersteunde builddoelen; raadpleeg het testrapport van de nachtelijke run voor resultaten op een bepaald pakket en apparaat. Er is geen downloadbare engine voor macOS x64, hoewel de modelgewichten voor dat platform worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Analyseer → Spraak → Transcribeer & Ondertiteling** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktop-editor.

1. Selecteer spraak en installeer Whisper large-v3 turbo via Beheer Modellen.
2. Kies dit spraakherkenningsmodel onder Gereedschappen → Geavanceerde Lokale Verwerking wanneer u expliciet Whisper wilt selecteren.
3. Voer lokaal uit en bekijk zowel de tekst als de segmentgrenzen voordat u deze accepteert.
