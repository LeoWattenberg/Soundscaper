Schat het visueel prominente gebied van bemonsterde frames in om te helpen bij het opnieuw kaden.

## Huidige beschikbaarheid {#current-availability}

Desktop-builds bevatten de vereiste onnxruntime-node 1.29.0-engine voor macOS arm64, Linux arm64, Linux x64, Windows arm64 en Windows x64. Installeer de gewichten van dit model via Model Manager en voer de taak lokaal uit. Dit zijn de ondersteunde build-doelen; raadpleeg het nachtelijke testrapport voor resultaten over een bepaald pakket en machine. De desktopbuild bevat deze engine niet voor macOS x64, hoewel modelgewichten voor die platforms worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Effect → Video-effecten → Herkaden** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktopeditor.

1. Selecteer een videoclip en installeer U²-Net-P via Beheer Modellen.
2. De begeleide Herkaden-taak heeft ook YuNet en D-FINE nodig; Tools → Geavanceerde Lokale Verwerking kan saliëntiedetectie afzonderlijk uitvoeren.
3. Voer lokaal uit en bekijk de voorgestelde kadering voordat u deze toepast.

## Download en vereisten {#download-and-requirements}

Model-identiteit: `u2netp-saliency`, versie **1.0.0**.

Benodigde downloadgrootte: **4,36 MiB**. Minimale systeemeige geheugen: **2 GiB**. Deze catalogusvereiste verwijst naar het totale geheugen, niet naar het momenteel vrije geheugen. Inferentie heeft ook voldoende vrij geheugen nodig, en installatie heeft werkruimte nodig; geheugen is geen snelheidsgarantie.

Gepubliceerde platforms: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Een bijpassende verpakte runtime is ook vereist.

Onder Windows installeert u de nieuwste ondersteunde [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) die overeenkomt met de desktop-app: **x64** voor een x64-build of **ARM64** voor een ARM64-build. De native ONNX- en Sherpa-engines vereisen deze bibliotheken; modeldownloads bevatten ze niet. Visual Studio zelf is niet vereist om de app te gebruiken.

Tools → Model Manager downloadt de gepubliceerde artefacten en controleert hun geregistreerde SHA-256-hashes. Verwerking gebruikt de lokaal geïnstalleerde bestanden. Open Opslag en verificatie in Model Manager om kennisgevingen te inspecteren, een installatie te herstellen of de opslaglocatie te wijzigen.

## Wat de verpakte test controleert {#what-the-packaged-test-checks}

Case: `saliency-detection`; operatie: `saliency-detection`.

Invoer: Twee foto's: het publiek-domein NASA-portret van astronaut Eileen Collins en de CC0 Chelsea-katfoto. Elk wordt in een apart kader geplaatst met expliciete bron-kadertiming, waardoor de detectoren een menselijk gezicht en een duidelijk object krijgen.

De kaderresultaten moeten hun bron-timings behouden en een eindige, begrensde saliëntiepunt voor het onderwerp bevatten.

Het pakket nightly-with-tests downloadt echte modelartefacten en vraagt om inferentie via de verpakte runtime. Een vereist model dat ontbreekt in de catalogus faalt in zijn geval. Ontbrekende native engines falen op catalogusondersteunde platforms. Deze kostbare controles worden afzonderlijk uitgevoerd van de normale browsersuite. Een geslaagde run bevestigt de basis modeluitvoering en bruikbare uitvoerstructuur; het stelt de perceptuele kwaliteit of nauwkeurigheid van uw opname niet vast.

## Beoordeel het resultaat {#review-the-result}

- Een visueel prominent gebied is niet noodzakelijkerwijs het onderwerp dat u wilt behouden. Bekijk de hele selectie.
- De test valideert eindige, begrensde saliëntieresultaten en bron-kadertiming, niet de artistieke kwaliteit van een gewas.
