## Doel en gebruik {#purpose-and-use-case}

Voorstel titels, hooks, hoofdstukken en uitleggen voor bestaande highlight-kandidaten.

## Huidige beschikbaarheid {#current-availability}

Desktopbuilds kunnen de vereiste engine llama-cpp b10509 voor macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 downloaden en verifiëren. Installeer dit model en de vereiste runtime via Modelbeheer en voer de taak lokaal uit. Dit zijn ondersteunde builddoelen; raadpleeg het testrapport van de nachtelijke run voor resultaten op een bepaald pakket en apparaat.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Tools → Geavanceerde lokale verwerking → Redactiegeneratie** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktop-editor.

1. Bereid en bekijk highlight-kandidaten van uw geselecteerde media.
2. Installeer Qwen via Model Manager en kies voor redactiegeneratie.
3. Bekijk elke tekstvoorstel voordat u deze accepteert. Alleen de geautoriseerde kandidaat-identiteiten en aangevraagde tekstvelden komen in aanmerking.
