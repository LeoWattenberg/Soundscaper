## Huidige beschikbaarheid {#current-availability}

Desktop-builds bevatten de vereiste onnxruntime-node 1.29.0-engine voor macOS arm64, Linux arm64, Linux x64, Windows arm64 en Windows x64. Installeer de gewichten van dit model via Model Manager en voer de taak vervolgens lokaal uit. Dit zijn de ondersteunde build-doelen; raadpleeg het nachtelijke testrapport voor resultaten over een bepaald pakket en machine. De desktopbuild bevat de engine niet voor macOS x64, hoewel modelgewichten voor deze platforms worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Tools → Zoeken → Index Video, gevolgd door Tools → Zoeken → Geïndexeerd Zoeken** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktopeditor.

1. Selecteer een video en installeer SigLIP2 via Beheer Modellen.
2. Voer Index Video uit om bemonsterde frames te analyseren. Installeer ook PP-OCRv4 als u de optionele tekstleessstap wilt gebruiken.
3. Gebruik Geïndexeerd Zoeken en bekijk de overeenkomende videomomenten voordat u beslist hoe u ze wilt gebruiken.
