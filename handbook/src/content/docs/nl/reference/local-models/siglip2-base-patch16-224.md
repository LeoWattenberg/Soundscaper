## Doel en gebruik {#purpose-and-use-case}

Stel gesamplede video-afbeeldingen en tekst voor in een gedeelde numerieke ruimte voor lokale visuele zoekopdrachten.

## Huidige beschikbaarheid {#current-availability}

Desktopbuilds kunnen de vereiste engine onnxruntime-node 1.29.0 voor macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 downloaden en verifiëren. Installeer dit model en de vereiste runtime via Modelbeheer en voer de taak lokaal uit. Dit zijn ondersteunde builddoelen; raadpleeg het testrapport van de nachtelijke run voor resultaten op een bepaald pakket en apparaat. Er is geen downloadbare engine voor macOS x64, hoewel de modelgewichten voor dat platform worden vermeld.

## Gebruik dit model {#use-this-model}

Open **Framescaper: Tools → Zoeken → Index Video, gevolgd door Tools → Zoeken → Geïndexeerd Zoeken** op een platform met de vereiste native runtime. Lokale assistentie werkt in de desktopeditor.

1. Selecteer een video en installeer SigLIP2 via Beheer Modellen.
2. Voer Index Video uit om bemonsterde frames te analyseren. Installeer ook PP-OCRv4 als u de optionele tekstleessstap wilt gebruiken.
3. Gebruik Geïndexeerd Zoeken en bekijk de overeenkomende videomomenten voordat u beslist hoe u ze wilt gebruiken.
