Ένα σεμινάριο είναι ένα μάθημα: σας καθοδηγεί βήμα προς βήμα μέσα από ένα πλήρες κομμάτι εργασίας σε ένα παράδειγμα ηχογράφησης που παρέχει το εγχειρίδιο, και σας λέει τι πρέπει να δείτε κατά τη διαδρομή. Ξεκινήστε εδώ αν δεν έχετε χρησιμοποιήσει το Soundscaper προηγουμένως. Όταν γνωρίζετε το περιβάλλον και έχετε μια δική σας ηχογράφηση, οι [οδηγοί «πώς να»](/guides/) καλύπτουν τις ίδιες λειτουργίες και πολλές περισσότερες, ένα καθήκον τη φορά.

- [Το πρώτο σας έργο Soundscaper](/tutorials/your-first-project/) — Εισαγωγή μιας ηχογράφησης, ακρόαση, διαίρεση, αφαίρεση έντασης, εξαγωγή αρχείου και αποθήκευση του έργου.
- [Καθαρισμός ηχογράφησης φωνής](/tutorials/clean-up-a-voice-recording/) — Αφαίρεση του βουητού από ένα take, κοπή του θορύβου, προσαρμογή στο επίπεδο έντασης podcast και εξαγωγή MP3.
- [Τοποθέτηση μουσικής κάτω από φωνή](/tutorials/put-music-under-a-voice/) — Στρωματοποίηση δύο διαδρομών, αυτόματη μείωση της έντασης της μιας κάτω από την άλλη, μείξη και εξαγωγή.

## Πώς παραμένουν σωστά τα σεμινάρια

Κάθε σεμινάριο αναπαράγεται στα αρχεία παραδείγμάτου του, βήμα προς βήμα, σε κάθε έκδοση του Soundscaper από τη σουίτα του προγράμματος περιήγησης (`tests/browser/soundscaper-tutorials.spec.js`). Ένα βήμα που σταματά να λειτουργεί αποτυγχάνει την έκδοση αντί να παλαιώνει.
