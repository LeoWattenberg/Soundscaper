Ο Beat Finder είναι ένας από τους αναλυτές Nyquist που παρέχονται. Ακούει απότομες αυξήσεις στο επίπεδο πάνω από ένα όριο και γράφει μια ετικέτα σε κάθε μία, η οποία είναι ένας γρήγορος τρόπος για να σημειώσετε τα χτυπήματα ενός loop ή τα χτυπήματα σε ένα drum take πριν το κόψετε.

:::note[Έρχεστε από το Audacity;]
Αυτό είναι το **Analyze → Beat Finder** του Audacity. Τα ονόματα παρακάτω είναι δικά του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, άδειο έργο είναι έτοιμο μόλις φορτωθεί ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε το αρχείο ήχου που θέλετε να σημειώσετε. Το αρχείο προσγειώνεται ως κλιπ στο δικό του κομμάτι.
3. Επιλέξτε **Select → Select all**.
4. Επιλέξτε **Analyze → Nyquist → Beat Finder**. Στο παράθυρο διαλόγου **Beat Finder**, ορίστε το **Threshold Percentage** στο `60`, και στη συνέχεια πατήστε **Apply**. Το παράθυρο διαλόγου αναφέρει τι βρήκε· πατήστε **Close** για να το κλείσετε. Ένα χαμηλότερο ποσοστό βρίσκει πιο ήσυχα χτυπήματα επίσης· αυξήστε το αν σημειώσει πάρα πολλά.
5. Το έργο εμφανίζει τώρα ένα κομμάτι με το όνομα **Beat Finder**.
   *Θα πρέπει να δείτε:* Ένα νέο κομμάτι ετικετών με το όνομα Beat Finder κάτω από το ήχο, με μία ετικέτα σε κάθε χτύπημα.

## Συμβουλές

- Οι ετικέτες βρίσκονται σε ένα νέο κομμάτι ετικετών κάτω από το ήχο. Μετονομάστε ή διαγράψτε οποιαδήποτε ετικέτα που έβαλε λάθος ο αναλυτής.
- Το **Analyze → Nyquist → Label Sounds** κάνει παρόμοια δουλειά για ολόκληρους ήχους που χωρίζονται από σιωπή.
