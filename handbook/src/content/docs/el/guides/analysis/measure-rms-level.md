## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Το RMS είναι μέτρο της μέσης στάθμης σήματος στον χρόνο. Χρησιμοποιήστε τον αναλυτή Measure RMS για να συγκρίνετε ενότητες ή να ελέγξετε την ένταση ενός αποσπάσματος πριν το προσαρμόσετε.

:::note[Έρχεστε από το Audacity;]
Αυτή είναι η εντολή **Analyze → Measure RMS (Nyquist)** του Audacity. Οι παρακάτω ονομασίες είναι του Soundscaper και ενδέχεται να διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτώσει ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε το απόσπασμα του οποίου θέλετε να μετρήσετε τη μέση στάθμη. Θα προστεθεί ως κλιπ σε δικό του κομμάτι.
3. Επιλέξτε **Επιλογή → Όλα**.
4. Επιλέξτε **Ανάλυση → Nyquist → Measure RMS**. Στο παράθυρο διαλόγου **Measure RMS**, πατήστε **Εφαρμογή**. Το παράθυρο αναφέρει τι εντόπισε· πατήστε **Κλείσιμο** για να το κλείσετε.
   *Τι θα πρέπει να δείτε:* Η αναφορά εμφανίζει τη στάθμη RMS σε dB για κάθε κανάλι και για το στερεοφωνικό σήμα.

## Συμβουλές

- Το RMS περιγράφει τη μέση στάθμη· χρησιμοποιήστε [κανονικοποίηση κορυφών](/guides/volume/normalize-peaks/) όταν χρειάζεται να ορίσετε στόχο για το υψηλότερο δείγμα.
- Επιλέξτε μόνο την ενότητα που θέλετε να συγκρίνετε, ώστε να μην επηρεάζει τη μέτρηση άσχετος ήχος.
