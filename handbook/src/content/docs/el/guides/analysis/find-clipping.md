Μια ηχογράφηση που γίνεται πολύ δυνατά «επιπεδώνεται» στο πάνω μέρος της κλίμακας και παραμορφώνεται. Η ζημιά είναι εύκολο να ακουστεί, αλλά δύσκολο να εντοπιστεί με το μάτι σε ένα μακρύ κομμάτι. Η λειτουργία «Εύρεση αποκοπής» σαρώνει την επιλογή και καταγράφει κάθε σειρά δειγμάτων που βρίσκεται σε πλήρη κλίμακα, ώστε να αποφασίσετε αν θα την επισκευάσετε, θα την ξανακάνετε ή θα την αφήσετε όπως είναι.

:::note[Ερχόσαστε από το Audacity;]
Αυτή είναι η εντολή **Ανάλυση → Εύρεση αποκοπής** του Audacity. Οι ονομασίες παρακάτω είναι του Soundscaper και μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, κενό έργο είναι έτοιμο μόλις φορτώσει ο επεξεργαστής.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ηχογράφηση που θέλετε να ελέγξετε. Το αρχείο προστίθεται ως κλιπ σε ξεχωριστό κομμάτι.
3. Επιλέξτε **Επιλογή → Επιλογή όλων**.
4. Επιλέξτε **Ανάλυση → Εύρεση αποκοπής**. Ανοίγει το πάνελ **Εύρεση αποκοπής**.
   *Θα πρέπει να δείτε:* Λίστα με τα τμήματα που έχουν αποκοπεί ή μήνυμα ότι δεν εντοπίστηκε κανένα.

## Συμβουλές

- Η μείωση της έντασης μιας παραμορφωμένης ηχογράφησης δεν την επισκευάζει· οι αποκομμένες κορυφές παραμένουν επίπεδες. Το **Εφέ → Αφαίρεση θορύβου και επιδιόρθωση → Επιδιόρθωση** μπορεί να ανακατασκευάσει πολύ σύντομα τμήματα.
- Για να αποφύγετε την παραμόρφωση την επόμενη φορά, ηχογραφήστε με κορυφές γύρω στα −12 dB και αυξήστε το επίπεδο αργότερα.
