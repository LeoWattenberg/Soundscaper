Μια ηχογράφηση που γίνεται πολύ δυνατά «επιπεδώνεται» στο πάνω μέρος της κλίμακας και παραμορφώνεται. Η ζημιά είναι εύκολο να ακουστεί, αλλά δύσκολο να εντοπιστεί με το μάτι σε ένα μακρύ κομμάτι. Το Find Clipping σάρωσε την επιλογή και καταγράφει κάθε σειρά δειγμάτων που βρίσκεται σε πλήρη κλίμακα, ώστε να μπορείτε να αποφασίσετε αν θα την επισκευάσετε, θα την ξανακάνετε ή θα την αφήσετε όπως είναι.

:::note[Ερχόσαστε από το Audacity;]
Αυτό είναι το **Analyze → Find Clipping** του Audacity. Οι ονόματα παρακάτω είναι του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, κενό έργο είναι έτοιμο μόλις φορτώσει ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε την ηχογράφηση που θέλετε να ελέγξετε. Το αρχείο τοποθετείται ως κλιπ σε ένα ξεχωριστό κανάλι.
3. Επιλέξτε **Select → Select all**.
4. Επιλέξτε **Analyze → Find clipping**. Το πάνελ **Find clipping** ανοίγει.
   *Πρέπει να δείτε:* Μια λίστα με τις τμηματικές παραμορφώσεις ή μια σημείωση ότι δεν βρέθηκαν.

## Συμβουλές

- Η μείωση του επιπέδου μιας παραμορφωμένης ηχογράφησης δεν την επισκευάζει· οι επιπεδωμένες κορυφές παραμένουν επιπεδωμένες. Το **Effect → Noise removal and repair → Repair** μπορεί να ανακατασκευάσει μια πολύ σύντομη παραμόρφωση.
- Για να αποφύγετε την παραμόρφωση την επόμενη φορά, ηχογραφήστε με κορυφές γύρω στα −12 dB και αυξήστε το επίπεδο αργότερα.
