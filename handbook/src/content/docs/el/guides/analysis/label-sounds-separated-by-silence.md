## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Το Label Sounds αναζητά σε ένα απόσπασμα ήχους που χωρίζονται από σιωπή και τοποθετεί ετικέτα γύρω από κάθε ήχο που εντοπίζει. Μπορεί να σημάνει ομιλούμενες φράσεις, μεμονωμένα χτυπήματα ή άλλα διακριτά συμβάντα για μεταγενέστερη επεξεργασία.

:::note[Έρχεστε από το Audacity;]
Αυτή είναι η εντολή **Analyze → Label Sounds (Nyquist)** του Audacity. Οι παρακάτω ονομασίες είναι του Soundscaper και ενδέχεται να διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτώσει ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ηχογράφηση με παύσεις ανάμεσα στους ήχους. Θα προστεθεί ως κλιπ σε δικό του κομμάτι.
3. Επιλέξτε **Επιλογή → Όλα**.
4. Επιλέξτε **Ανάλυση → Nyquist → Label Sounds**. Στο παράθυρο διαλόγου **Label Sounds**, ορίστε το **Threshold level (dB)** σε `-30`, το **Minimum silence duration** σε `0.5` και το **Minimum label interval** σε `0.5` και πατήστε **Εφαρμογή**. Το παράθυρο αναφέρει τι εντόπισε· πατήστε **Κλείσιμο** για να το κλείσετε. Μισό δευτερόλεπτο σιωπής επιτρέπει στον αναλυτή να διαχωρίσει τις φράσεις. Το όριο καθορίζει πόσο δυνατός πρέπει να είναι ένας ήχος για να μετρήσει.
5. Το έργο εμφανίζει τώρα κομμάτι με όνομα **Label Sounds**.
   *Τι θα πρέπει να δείτε:* Εμφανίζεται κομμάτι Label Sounds με ετικέτες γύρω από τις φράσεις που εντοπίστηκαν.

## Συμβουλές

- Μειώστε το **Threshold level (dB)** για να συμπεριλάβετε χαμηλότερους ήχους· αυξήστε το για να αγνοήσετε τον θόρυβο υποβάθρου.
- Αυξήστε το **Minimum silence duration** όταν οι σύντομες παύσεις δεν πρέπει να χωρίζουν μια φράση σε πολλές ετικέτες.
