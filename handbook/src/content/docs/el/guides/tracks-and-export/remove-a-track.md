## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Η εντολή Remove tracks διαγράφει από το έργο την επιλεγμένη λωρίδα και όλα τα κλιπ της. Είναι χρήσιμη για μια λήψη που δεν χρειάζεστε ή για ένα επιπλέον αντίγραφο αφού συγκρίνετε τις αλλαγές. Η επιλογή ενός κλιπ στοχεύει ολόκληρη τη λωρίδα του, γι’ αυτό ελέγξτε την επιλογή πριν αφαιρέσετε οτιδήποτε.

:::note[Έρχεστε από το Audacity;]
Στο Audacity, αυτό αντιστοιχεί στην εντολή **Tracks → Remove tracks (Audacity 4)**. Οι παρακάτω ονομασίες ανήκουν στο Soundscaper και μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτωθεί ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την εγγραφή που θέλετε να κρατήσετε. Θα εμφανιστεί ως κλιπ στη δική της λωρίδα.
3. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ανεπιθύμητη εγγραφή σε άλλη λωρίδα. Θα εμφανιστεί ως κλιπ στη δική της λωρίδα.
4. Χρησιμοποιήστε το **Tab** για να εστιάσετε σε ένα κλιπ της λωρίδας που θέλετε να αφαιρέσετε και πατήστε **Enter** για να το επιλέξετε.
5. Επιλέξτε **Κομμάτια → Αφαίρεση κομματιών**.
6. Η εγγραφή που κρατήσατε παραμένει στην αρχική της θέση.
   *Θα πρέπει να δείτε:* Η ανεπιθύμητη λωρίδα έχει φύγει και η άλλη εγγραφή παραμένει ανέπαφη.

## Συμβουλές

- Η εντολή **Επεξεργασία → Αναίρεση** επαναφέρει τη λωρίδα που αφαιρέθηκε και τα κλιπ της.
- Για να αφαιρέσετε μόνο ένα μέρος μιας εγγραφής, [διαγράψτε ένα απόσπασμα αφήνοντας κενό](/guides/editing/delete-a-passage-and-leave-a-gap/) αντί να διαγράψετε τη λωρίδα.
- Η αφαίρεση μιας λωρίδας από το έργο δεν διαγράφει το αρχικό αρχείο που εισαγάγατε από τον υπολογιστή σας.
- Οι λωρίδες σε συνδεδεμένη ομάδα λωρίδων αφαιρούνται μαζί.
