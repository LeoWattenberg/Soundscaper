## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Η εντολή Duplicate track αντιγράφει ολόκληρη τη λωρίδα, μαζί με κάθε κλιπ και τη θέση του στη γραμμή χρόνου. Χρησιμοποιήστε το αντίγραφο για να δοκιμάσετε διαφορετική επεξεργασία ή εφέ, κρατώντας την αρχική. Επιλέγοντας ένα κλιπ προσδιορίζετε τη λωρίδα που θα αντιγραφεί· η εντολή αντιγράφει και τα υπόλοιπα κλιπ της.

:::note[Έρχεστε από το Audacity;]
Στο Audacity, αυτό αντιστοιχεί στην εντολή **Tracks → Duplicate (Audacity 4)**. Οι παρακάτω ονομασίες ανήκουν στο Soundscaper και μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτωθεί ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την εγγραφή στη λωρίδα που θέλετε να αντιγράψετε. Θα εμφανιστεί ως κλιπ στη δική της λωρίδα.
3. Κάντε κλικ στην κυματομορφή στο σημείο όπου θέλετε να χωρίσετε την εγγραφή σε δύο μέρη που μπορούν να επεξεργαστούν ανεξάρτητα, ώστε να τοποθετήσετε εκεί τον δρομέα. Παραλείψτε αυτήν την τοποθέτηση και το επόμενο βήμα Split αν η λωρίδα έχει ήδη πολλά κλιπ ή αν θέλετε να παραμείνει ένα ενιαίο κλιπ.
4. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Διαχωρισμός**.
5. Το έργο εμφανίζει τώρα 2 κλιπ.
   *Θα πρέπει να δείτε:* Η λωρίδα περιέχει δύο κλιπ έτοιμα να αντιγραφούν μαζί.
6. Χρησιμοποιήστε το **Tab** για να εστιάσετε σε ένα κλιπ της λωρίδας και πατήστε **Enter** για να το επιλέξετε.
7. Επιλέξτε **Κομμάτια → Δημιουργία αντιγράφου κομματιού**.
8. Το έργο εμφανίζει τώρα 4 κλιπ και 3 λωρίδες.
   *Θα πρέπει να δείτε:* Η αρχική λωρίδα και το αντίγραφό της περιέχουν από δύο κλιπ στις ίδιες θέσεις της γραμμής χρόνου.

## Συμβουλές

- Αναπαράγονται τόσο η αρχική λωρίδα όσο και το αντίγραφο. [Κάντε σίγαση σε μια λωρίδα ή ακούστε την μόνη της](/guides/tracks-and-export/mute-and-solo-tracks/) όταν τις συγκρίνετε, ώστε να ακούτε μία εκδοχή κάθε φορά.
- Για να αντιγράψετε μόνο ένα απόσπασμα, [αντιγράψτε μια επιλογή σε νέα λωρίδα](/guides/editing/duplicate-a-selection-to-a-new-track/) αντί γι’ αυτό.
- Η εντολή **Επεξεργασία → Αναίρεση** αφαιρεί τη διπλή λωρίδα.
