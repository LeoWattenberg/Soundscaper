## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Ένα έργο με πολλές λήψεις είναι ευκολότερο στην πλοήγηση όταν τα ονόματα σχετικών κομματιών βρίσκονται δίπλα-δίπλα. Το Sort by name αναδιατάσσει τα κομμάτια αλφαβητικά χωρίς να αλλάζει τις θέσεις έναρξης των κλιπ στη γραμμή χρόνου.

:::note[Έρχεστε από το Audacity;]
Αυτή είναι η εντολή **Tracks → Sort Tracks → Sort by Name** του Audacity. Οι παρακάτω ονομασίες είναι του Soundscaper και ενδέχεται να διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτώσει ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ηχογράφηση που πρέπει να τοποθετηθεί μετά την άλλη αλφαβητικά. Θα προστεθεί ως κλιπ σε δικό της κομμάτι.
3. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ηχογράφηση που πρέπει να προηγηθεί με βάση το όνομά της. Θα προστεθεί ως κλιπ σε δικό της κομμάτι.
4. Επιλέξτε **Κομμάτια → Ταξινόμηση κομματιών → Ταξινόμηση κατά όνομα**. Τα ονόματα των κομματιών ταξινομούνται αλφαβητικά.
5. Το έργο εμφανίζει τώρα 2 κλιπ.
   *Τι θα πρέπει να δείτε:* Και οι δύο ηχογραφήσεις παραμένουν στο έργο, με τα ονόματα των κομματιών σε αλφαβητική σειρά.

## Συμβουλές

- Η ταξινόμηση αλλάζει τη σειρά των κομματιών, όχι τον χρονισμό των κλιπ ή το ηχητικό περιεχόμενο.
- Χρησιμοποιήστε το **Κομμάτια → Ταξινόμηση κομματιών → Ταξινόμηση κατά χρόνο** όταν θέλετε η σειρά των κομματιών να ακολουθεί τους χρόνους έναρξης των κλιπ.
