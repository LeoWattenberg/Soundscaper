## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, άδειο έργο είναι έτοιμο μόλις φορτωθεί ο επεξεργαστής.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και επιλέξτε την εγγραφή που χρειάζεται ένα κενό μετά από αυτήν. Προσγειώνεται ως κλιπ στο δικό του κομμάτι.
3. Κάντε κλικ στο κύμα στο τέλος του κλιπ για να τοποθετήσετε το δρομέα εκεί. Η σιωπή μπαίνει στο δρομέα.
4. Επιλέξτε **Δημιουργία → Σιωπή**. Στο παράθυρο διαλόγου **Σιωπή**, ορίστε τη **Διάρκεια (δευτερόλεπτα)** σε `1`, στη συνέχεια πατήστε **Δημιουργία**.
5. Το έργο εμφανίζει τώρα 2 κλιπ.
   *Θα πρέπει να δείτε:* Ένα κλιπ ενός δευτερολέπτου σιωπής ακολουθεί τη βρόχο.

## Συμβουλές

- Με μια χρονική περιοχή επιλεγμένη, ο δημιουργός αντικαθιστά την επιλογή αντί να εισάγει στο δρομέα.
- Για να σιωπήσετε ήχο που υπάρχει ήδη αντί να προσθέσετε χρόνο, δείτε [Σιωπή μέρους μιας εγγραφής](/guides/cleaning-up/silence-part-of-a-recording/).
