Το μάθηση ενός riff, η έλεγχος ενός σημείου επεξεργασίας, η ακρόαση μιας ρύθμισης εφέ: όλα γίνονται πιο γρήγορα όταν το απόσπασμα παίζει ξανά και ξανά χωρίς να το επανεκκινείτε. Ρυθμίστε την περιοχή επανάληψης στην επιλογή και η αναπαραγωγή παραμένει εντός αυτής μέχρι να απενεργοποιήσετε την επανάληψη.

:::note[Ερχόσαστε από το Audacity;]
Αυτό αντιστοιχεί στο **Transport → Looping → Set Loop to Selection** του Audacity. Οι ονόματα παρακάτω είναι του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, κενό έργο είναι έτοιμο μόλις φορτωθεί ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε την ηχογράφηση με το απόσπασμα που θέλετε να εξασκηθείτε. Το αρχείο τοποθετείται ως κλιπ σε ένα ξεχωριστό κανάλι.
3. Σύρετε τον χάρακα πάνω από το κλιπ για να επιλέξετε το απόσπασμα που θέλετε να επαναλάβετε.
4. Επιλέξτε **Select → Loop region → Set loop to selection**.
5. Το έργο εμφανίζει τώρα το κουμπί **Loop selection** ανάβοντας.
   *Πρέπει να δείτε:* Το κουμπί επανάληψης στη μπάρα μεταφοράς ανάβει και η περιοχή επανάληψης εμφανίζεται πάνω από τον χάρακα.
6. Πατήστε **Play** για να ακούσετε, και στη συνέχεια **Stop**.
   *Πρέπει να δείτε:* Η αναπαραγωγή εκτελείται γύρω από το επιλεγμένο απόσπασμα.

## Συμβουλές

- Πατήστε **L** ή το κουμπί επανάληψης στη μπάρα μεταφοράς για να απενεργοποιήσετε και να ενεργοποιήσετε ξανά την επανάληψη χωρίς να χάσετε την περιοχή.
- Σύρετε τα άκρα της περιοχής επανάληψης στον χάρακα για να την προσαρμόσετε.
