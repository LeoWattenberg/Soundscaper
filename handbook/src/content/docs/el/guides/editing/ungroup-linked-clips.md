## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Τα ομαδοποιημένα κλιπ μπορούν να επιλέγονται και να μετακινούνται ως σύνολο, ενώ παραμένουν ξεχωριστά τμήματα ήχου. Το Ungroup επαναφέρει την ανεξάρτητη επιλογή τους· δεν ενώνει τα τμήματα ούτε τα αποδίδει ως ένα κλιπ.

:::note[Έρχεστε από το Audacity;]
Αυτή είναι η εντολή **Edit → Clip → Ungroup Clips** του Audacity. Οι παρακάτω ονομασίες είναι του Soundscaper και ενδέχεται να διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτώσει ο επεξεργαστής, είναι έτοιμο ένα νέο, κενό έργο.
2. Επιλέξτε **Αρχείο → Εισαγωγή** και διαλέξτε την ηχογράφηση με τα κλιπ που θέλετε να διαχωρίσετε. Θα προστεθεί ως κλιπ σε δικό του κομμάτι.
3. Κάντε κλικ στην κυματομορφή στο σημείο όπου θέλετε να χωρίσετε το κλιπ σε δύο μέρη, ώστε να τοποθετηθεί εκεί ο δρομέας.
4. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Διαχωρισμός**.
5. Κάντε κλικ στη γραμμή ονόματος του πρώτου μέρους, κρατήστε πατημένο το Shift και κάντε κλικ στη γραμμή ονόματος του δεύτερου, ώστε να επιλεγούν και τα δύο.
6. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Ομαδοποίηση κλιπ**. Η ομαδοποίηση επιτρέπει τη μετακίνηση των δύο επιλεγμένων μερών μαζί χωρίς να συγχωνευτεί ο ήχος τους.
7. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Κατάργηση ομαδοποίησης κλιπ**. Τα δύο μέρη μπορούν και πάλι να επιλέγονται ξεχωριστά.
8. Το έργο εμφανίζει τώρα 2 κλιπ.
   *Τι θα πρέπει να δείτε:* Η ηχογράφηση παραμένει δύο ξεχωριστά κλιπ που ενώνονται στο σημείο διαχωρισμού.

## Συμβουλές

- Η ομαδοποίηση είναι χρήσιμη όταν ξεχωριστά κλιπ πρέπει να διατηρήσουν τον σχετικό χρονισμό τους κατά τη μετακίνηση.
- Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Ένωση επιλεγμένων κλιπ** όταν θέλετε γειτονικά τμήματα να γίνουν ένα κλιπ.
