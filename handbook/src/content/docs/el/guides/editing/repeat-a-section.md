Ένα βρόχος δύο μπαρ, ένα υπόβαθρο κρεβάτι που πρέπει να τρέξει κάτω από ένα μεγαλύτερο voice-over, ένα ηχητικό εφέ που πρέπει να συνεχίσει: Το Repeat αντιγράφει την επιλογή αμέσως μετά τον εαυτό του όσες φορές ζητάτε.

:::note[Έρχεστε από το Audacity;]
Αυτό είναι το **Effect → Special → Repeat** του Audacity. Τα ονόματα παρακάτω είναι δικά του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, άδειο έργο είναι έτοιμο μόλις φορτωθεί ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε τον ήχο που θέλετε να επαναλάβετε. Το αρχείο προσγειώνεται ως κλιπ στο δικό του κομμάτι.
3. Επιλέξτε **Select → Select all**.
4. Επιλέξτε **Effect → Special → Repeat**. Στο παράθυρο διαλόγου **Repeat**, ορίστε **Number of repeats** σε `2`, και στη συνέχεια πατήστε **Apply to selection**. Δύο επαναλήψεις δίνουν τρεις αντίγραφα στη σειρά.
5. Πατήστε **Play** για να ακούσετε, και στη συνέχεια **Stop**.
   *Θα πρέπει να δείτε:* Το απόσπασμα παίζει τρεις φορές χωρίς κενό.

## Συμβουλές

- Για έναν απρόσκοπτο βρόχο, βεβαιωθείτε ότι η επιλογή ξεκινά και τελειώνει σε σιωπή ή σε ένα σημείο διασταύρωσης μηδενικού (**Select → At zero crossings**).
- Το εφέ αλλάζει το μήκος του κλιπ, οπότε οτιδήποτε μετά από αυτό στο ίδιο κομμάτι ωθείται προς τα εμπρός.
