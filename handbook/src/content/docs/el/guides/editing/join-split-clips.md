## Σε τι χρησιμεύει αυτός ο οδηγός {#what-this-guide-is-for}

Η εντολή Join συνδυάζει γειτονικά κομμάτια της ίδιας ηχογράφησης, ώστε να μπορείτε ξανά να τα μετακινείτε ή να τα επεξεργάζεστε ως ένα κλιπ. Οι περιοχές προέλευσης πρέπει να ταιριάζουν και να μην υπάρχουν fade στο σημείο ένωσης. Αυτά τα βήματα απενεργοποιούν τα αυτόματα fade πριν από τον διαχωρισμό και μετά ενώνουν τα κομμάτια χωρίς απόδοση.

:::note[Ήρθατε από το Audacity;]
Αυτό αντιστοιχεί στο **Edit → Clip → Join selected clips (Ctrl+J)** του Audacity. Οι παρακάτω ονομασίες είναι του Soundscaper και μπορεί να διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Μόλις φορτώσει ο editor, είναι έτοιμο ένα νέο κενό έργο.
2. Επιλέξτε **Επεξεργασία → Προτιμήσεις**, ανοίξτε την καρτέλα **Επεξεργασία**, απενεργοποιήστε το **Εφαρμογή σβησίματος 2 ms σε νέα κλιπ** και πατήστε **Κλείσιμο**. Τα αυτόματα fade στο σημείο διαχωρισμού θα καθιστούσαν το Join μη διαθέσιμο.
3. Επιλέξτε **Αρχείο → Εισαγωγή** και επιλέξτε την ηχογράφηση που θέλετε να διαχωρίσετε και να ενώσετε ξανά. Εισάγεται ως κλιπ σε δικό του κομμάτι.
4. Κάντε κλικ στην κυματομορφή στο σημείο όπου θέλετε να διαχωρίσετε την ηχογράφηση, για να τοποθετήσετε εκεί τον δρομέα.
5. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Διαχωρισμός**.
6. Το έργο εμφανίζει τώρα 2 κλιπ.
   *Θα πρέπει να δείτε:* Τα δύο κομμάτια συναντώνται στο σημείο διαχωρισμού.
7. Πατήστε **Tab** για εστίαση στο πρώτο κομμάτι και **Enter** για επιλογή. Έπειτα εστιάστε στο δεύτερο κομμάτι και πατήστε **Shift+Enter** για να το προσθέσετε στην επιλογή. Πρέπει να επιλεγούν και τα δύο κομμάτια για την ένωση.
8. Επιλέξτε **Επεξεργασία → Κλιπ ήχου → Ένωση επιλεγμένων κλιπ**.
9. Το έργο εμφανίζει τώρα 1 κλιπ.
   *Θα πρέπει να δείτε:* Ένα κλιπ καλύπτει τον ίδιο χρόνο με την ηχογράφηση πριν από τον διαχωρισμό.

## Συμβουλές

- Αυτή η προτίμηση αφορά μελλοντικούς διαχωρισμούς. Ενεργοποιήστε ξανά το **Εφαρμογή σβησίματος 2 ms σε νέα κλιπ** μετά, αν το χρησιμοποιείτε συνήθως.
- Αν το Join δεν είναι διαθέσιμο για υπάρχοντα κομμάτια, ελέγξτε για κενό, εσωτερικά fade ή διαφορετικό υλικό προέλευσης. Η απενεργοποίηση της προτίμησης δεν αφαιρεί fade που υπάρχουν ήδη σε ένα κλιπ.
- Το **Επεξεργασία → Αναίρεση** επαναφέρει τα χωριστά κομμάτια, αν θέλετε να συνεχίσετε να τα επεξεργάζεστε ξεχωριστά.
