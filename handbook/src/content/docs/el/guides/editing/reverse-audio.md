Το Reverse αντιστρέφει την επιλογή στον χρόνο. Είναι ένα εφέ σχεδιασμού ήχου — αναποδογυρισμένα κύμβαλα, διογκωμένα προ-ηχώ — και περιστασιακά για τον έλεγχο αν η ουρά του reverb ενός δωματίου κρύβει οτιδήποτε.

:::note[Έρχεστε από το Audacity;]
Αυτό είναι το **Effect → Special → Reverse** του Audacity. Τα ονόματα παρακάτω είναι δικά του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, άδειο έργο είναι έτοιμο μόλις φορτωθεί ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε το αρχείο ήχου που θέλετε να αντιστρέψετε. Το αρχείο τοποθετείται ως κλιπ στο δικό του κομμάτι.
3. Επιλέξτε **Select → Select all**.
4. Επιλέξτε **Effect → Special → Reverse**. Το εφέ εφαρμόζεται άμεσα στην επιλογή.
5. Πατήστε **Play** για να ακούσετε, και στη συνέχεια **Stop**.
   *Θα πρέπει να δείτε:* Το αρχείο ήχου αναπαράγεται ανάποδα.

## Συμβουλές

- Εφαρμόστε το Reverse δύο φορές και επιστρέφετε στην αρχική θέση, δείγμα προς δείγμα.
- Αντιστρέψτε μια μικρή επιλογή στην αρχή ενός κλιπ για να δημιουργήσετε μια διόγκωση που οδηγεί σε αυτό.
