Τα προσθέτα Nyquist του Audacity είναι μικρά σενάρια που προσθέτουν εφέ, δημιουργούς και αναλυτές, και το Soundscaper συγκεντρώνει τα ίδια σε ένα υπομενού Nyquist σε κάθε μενού. Το Tremolo είναι μια καλή πρώτη επιλογή: κάνει το ένταση να ταλαντώνεται με ένα καθορισμένο ρυθμό.

:::note[Ερχόσαστε από το Audacity;]
Αυτό είναι το **Effect → Tremolo (ένα πρόσθετο Nyquist)** του Audacity. Τα ονόματα παρακάτω είναι του Soundscaper, τα οποία μερικές φορές διαφέρουν.
:::

## Βήματα

1. Ανοίξτε το Soundscaper. Ένα νέο, κενό έργο είναι έτοιμο μόλις φορτώσει ο επεξεργαστής.
2. Επιλέξτε **File → Import audio** και επιλέξτε την ηχογράφηση στην οποία θέλετε να δοκιμάσετε το πρόσθετο. Το αρχείο τοποθετείται ως κλιπ σε ένα ξεχωριστό κομμάτι.
3. Επιλέξτε **Select → Select all**.
4. Επιλέξτε **Effect → Nyquist → Tremolo**. Στο παράθυρο διαλόγου **Tremolo**, ορίστε τη **Frequency (Hz)** σε `6`, και στη συνέχεια πατήστε **Apply**. Έξι ταλαντώσεις το δευτερόλεπτο είναι ένα κλασικό tremolo ενισχυτή. Τα παράθυρα διαλόγου Nyquist χρησιμοποιούν **Apply** αντί για Apply to selection.
5. Πατήστε **Play** για να ακούσετε, και στη συνέχεια **Stop**.
   *Θα πρέπει να δείτε:* Η ηχογράφηση παλμάρει στην ένταση.

## Συμβουλές

- Τα μενού Generate και Analyze έχουν τα δικά τους υπομενού Nyquist, με προσθέτα όπως το Pluck και το Beat Finder.
- Το **Tools → Nyquist prompt** εκτελεί ένα σενάριο που πληκτρολογείτε εσείς.
