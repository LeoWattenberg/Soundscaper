## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Αναπαραστήστε δειγματοληπτημένες εικόνες βίντεο και κείμενο σε κοινό αριθμητικό χώρο για τοπική οπτική αναζήτηση.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρήση του μοντέλου {#use-this-model}

Ανοίξτε **Framescaper: Εργαλεία → Αναζήτηση → Ευρετηρίαση βίντεο και, στη συνέχεια, Εργαλεία → Αναζήτηση → Αναζήτηση στο ευρετήριο** σε πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε βίντεο και εγκαταστήστε το SigLIP2 μέσω της Διαχείρισης μοντέλων.
2. Εκτελέστε την Ευρετηρίαση βίντεο για ανάλυση των δειγματοληπτημένων καρέ. Εγκαταστήστε επίσης το PP-OCRv4 αν θέλετε το προαιρετικό βήμα ανάγνωσης κειμένου.
3. Χρησιμοποιήστε την Αναζήτηση στο ευρετήριο και ελέγξτε τις αντίστοιχες στιγμές του βίντεο πριν αποφασίσετε πώς θα τις αξιοποιήσετε.
