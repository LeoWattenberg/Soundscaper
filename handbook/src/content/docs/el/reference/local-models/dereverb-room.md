## Τρέχουσα διαθεσιμότητα {#current-availability}

Τα πακέτα επιφάνειας εργασίας περιλαμβάνουν τον απαιτούμενο κινητήρα onnxruntime-node 1.29.0 για macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Εγκαταστήστε τα βάρη αυτού του μοντέλου μέσω του Διαχειριστή Μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι οι υποστηριζόμενοι στόχοι δημιουργίας· συμβουλευτείτε την έκθεση δοκιμών της νύχτας για τα αποτελέσματα σε ένα συγκεκριμένο πακέτο και μηχανή.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Εργαλεία → Προχωρημένη Τοπική Επεξεργασία → Αποανακλαστικότητα** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε ομιλία που επηρεάζεται από ανακλάσεις δωματίου.
2. Εγκαταστήστε το μοντέλο μέσω του Διαχειριστή Μοντέλων και εκτελέστε αποανακλαστικότητα.
3. Συγκρίνετε το αποτέλεσμα με το αρχικό και αποδεχτείτε το μόνο εάν η ομιλία ακούγεται καλύτερη.

Η συμπερασματολογία απαιτεί επίσης επαρκή ελεύθερη μνήμη, και η εγκατάσταση απαιτεί χώρο εργασίας· η μνήμη δεν είναι εγγύηση ταχύτητας.

Δημοσιευμένες πλατφόρμες: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Απαιτείται επίσης ένας αντιστοιχισμένος συσκευασμένος χρόνος εκτέλεσης.
