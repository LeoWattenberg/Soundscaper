## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Βρείτε θέσεις χτυπημάτων στη μουσική χρησιμοποιώντας το μικρότερο μοντέλο Beat This.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Εργαλεία → Προχωρημένη Τοπική Επεξεργασία → Παρακολούθηση χτυπημάτων** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε ένα απόσπασμα ρυθμικής μουσικής.
2. Εγκαταστήστε το μικρό Beat This μέσω του Model Manager και επιλέξτε αυτό το ακριβές μοντέλο για την παρακολούθηση χτυπημάτων.
3. Ακούστε το προτεινόμενο πλέγμα χτυπημάτων πριν αποδεχτείτε τους δείκτες χτυπημάτων ή μια πρόταση τέμπο.
