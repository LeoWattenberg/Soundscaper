## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Διαχωρίστε ένα μικτό ηχητικό κομμάτι σε προτεινόμενα μέρη διαλόγου, μουσικής και εφέ.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή.

## Χρήση του μοντέλου {#use-this-model}

Ανοίξτε **Εργαλεία → Προηγμένη τοπική επεξεργασία → Διαχωρισμός πηγών** σε πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε το μικτό ηχητικό υλικό προς διαχωρισμό.
2. Εγκαταστήστε το TIGER μέσω της Διαχείρισης μοντέλων και, στη συνέχεια, εκτελέστε τον διαχωρισμό πηγών.
3. Ακούστε κάθε προτεινόμενο stem πριν προσθέσετε στο έργο όσα αποτελέσματα θέλετε.
