Μετατρέψτε επιλεγμένο λόγο σε χρονικά μεταγραμμένο κείμενο για υπότιτλους και επεξεργασία μεταγραφής.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Τα πακέτα επιφάνειας εργασίας περιλαμβάνουν τον απαιτούμενο μηχανισμό sherpa-onnx-node 1.13.5 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε τους βαρύτητες αυτού του μοντέλου μέσω του Διαχειριστή Μοντέλων και, στη συνέχεια, εκτελέστε την εργασία τοπικά. Αυτοί είναι οι υποστηριζόμενοι στόχοι δημιουργίας· συμβουλευτείτε την έκθεση δοκιμών της νύχτας για τα αποτελέσματα σε ένα συγκεκριμένο πακέτο και μηχανή. Η δημιουργία επιφάνειας εργασίας δεν συσκευάζει αυτόν τον μηχανισμό για macOS x64 ακόμη και αν οι βαρύτητες του μοντέλου αναφέρονται για αυτές τις πλατφόρμες.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Ανάλυση → Λόγος → Μεταγραφή & Υπότιτλοι** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε τον λόγο που θέλετε να μεταγράψετε.
2. Χρησιμοποιήστε τον Διαχειριστή Μοντέλων για να εγκαταστήσετε αυτό το μοντέλο. Τα Εργαλεία → Προχωρημένη Τοπική Επεξεργασία σας επιτρέπουν να επιλέξετε ένα συγκεκριμένο μοντέλο αναγνώρισης λόγου.
3. Εκτελέστε τοπικά και, στη συνέχεια, εξετάστε το κείμενο και τον χρονισμό πριν αποδεχτείτε τη μεταγραφή.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ταυτότητα μοντέλου: `parakeet-tdt-0.6b-v2`, έκδοση **2.0.0**.

Περίπου μέγεθος λήψης: **630,56 MiB**. Ελάχιστη μνήμη συστήματος: **4 GiB**. Αυτή η απαίτηση καταλόγου αναφέρεται στη συνολική μνήμη, όχι στη μνήμη που είναι ελεύθερη αυτή τη στιγμή. Η συμπερασματολογία απαιτεί επίσης επαρκή ελεύθερη μνήμη και χώρος εργασίας· η μνήμη δεν είναι εγγύηση ταχύτητας.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης ένας αντιστοιχισμένος συσκευασμένος χρόνος εκτέλεσης.

Στα Windows, εγκαταστήστε την τελευταία υποστηριζόμενη [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που ταιριάζει με την εφαρμογή επιφάνειας εργασίας: **x64** για μια κατασκευή x64 ή **ARM64** για μια κατασκευή ARM64. Οι εγγενείς μηχανές ONNX και Sherpa απαιτούν αυτές τις βιβλιοθήκες· οι λήψεις μοντέλων δεν τις περιλαμβάνουν. Το ίδιο το Visual Studio δεν απαιτείται για τη χρήση της εφαρμογής.

Τα Εργαλεία → Διαχειριστής Μοντέλων κατεβάζουν τα δημοσιευμένα τεχνουργήματα και επαληθεύουν τις καταγεγραμμένες τιμές hash SHA-256 τους. Η επεξεργασία χρησιμοποιεί τα εγκατεστημένα αρχεία τοπικά. Ανοίξτε την Αποθήκευση και επαλήθευση στον Διαχειριστή Μοντέλων για να επιθεωρήσετε τις ειδοποιήσεις, να επισκευάσετε μια εγκατάσταση ή να αλλάξετε τη θέση αποθήκευσης.

## Τι ελέγχει η συσκευασμένη δοκιμή {#what-the-packaged-test-checks}

Περίπτωση: `parakeet-v2-transcript`; λειτουργία: `speech-recognition`.

Εισαγωγή: Ένα απόσπασμα δημόσιας ιδιοκτησίας από την ορκωμοσία του John F. Kennedy, με ένα δευτερόλεπτο σιωπής σε κάθε άκρο, προετοιμασμένο ως μονοφωνικός ήχος στα 16 kHz.

Η μεταγραφή πρέπει να περιέχει μη κενό κείμενο με έγκυρο χρονισμό μέσα στον εισερχόμενο ήχο. Δεν συγκρίνεται η ακριβής διατύπωση.

Το πακέτο nightly-with-tests κατεβάζει πραγματικά τεχνουργήματα μοντέλων και ζητά συμπερασματολογία μέσω του συσκευασμένου χρόνου εκτέλεσης. Αυτοί οι δαπανηροί έλεγχοι εκτελούνται ξεχωριστά από το κανονικό σύνολο περιηγητή. Μια επιτυχής εκτέλεση επιβεβαιώνει τη βασική εκτέλεση μοντέλου και τη δομή εξόδου· δεν καθορίζει την ποιοτική αντίληψη ή την ακρίβεια σε εγγραφή σας.
