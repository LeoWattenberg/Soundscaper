## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Μετατρέψτε επιλεγμένο λόγο σε χρονικά μεταγραμμένο κείμενο για υπότιτλους και επεξεργασία μεταγραφής.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό sherpa-onnx-node 1.13.5 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Ανάλυση → Λόγος → Μεταγραφή & Υπότιτλοι** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε τον λόγο που θέλετε να μεταγράψετε.
2. Χρησιμοποιήστε τον Διαχειριστή Μοντέλων για να εγκαταστήσετε αυτό το μοντέλο. Τα Εργαλεία → Προχωρημένη Τοπική Επεξεργασία σας επιτρέπουν να επιλέξετε ένα συγκεκριμένο μοντέλο αναγνώρισης λόγου.
3. Εκτελέστε τοπικά και, στη συνέχεια, εξετάστε το κείμενο και τον χρονισμό πριν αποδεχτείτε τη μεταγραφή.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ελάχιστη μνήμη συστήματος: **4 GiB**. Η απαίτηση καταλόγου αφορά τη συνολική μνήμη, όχι την τρέχουσα ελεύθερη μνήμη. Η εξαγωγή συμπερασμάτων χρειάζεται επίσης αρκετή ελεύθερη μνήμη και η εγκατάσταση χώρο εργασίας· η μνήμη δεν εγγυάται ταχύτητα.
