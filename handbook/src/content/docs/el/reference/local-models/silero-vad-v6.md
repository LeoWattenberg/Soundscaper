## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Βρείτε περιοχές ομιλίας πριν από τη μεταγραφή ή την αφαίρεση μεγάλων παύσεων.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό sherpa-onnx-node 1.13.5 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Επίδραση → Αφαίρεση και επισκευή θορύβου → Καθαρισμός Φίλερ & Σιωπή, ή Ανάλυση → Ομιλία → Μεταγραφή & Υπότιτλοι** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε μια περιοχή ήχου που περιέχει ομιλία και παύσεις.
2. Ανοίξτε την εργασία και εγκαταστήστε το Silero VAD μέσω Διαχείρισης Μοντέλων.
3. Εκτελέστε τοπικά και στη συνέχεια αναθεωρήστε τις ανιχνευμένες περιοχές ή τις προτάσεις καθαρισμού πριν εφαρμόσετε τις αλλαγές.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ταυτότητα μοντέλου: `silero-vad-v6`, έκδοση **6.2.1**.

Κατά προσέγγιση μέγεθος λήψης τεχνουργήματος μοντέλου: **2.22 MiB**. Το απαιτούμενο περιβάλλον εκτέλεσης προστίθεται στην πρώτη λήψη αν δεν είναι ήδη εγκατεστημένο. Ελάχιστη μνήμη συστήματος: **2 GiB**. Η απαίτηση καταλόγου αφορά τη συνολική μνήμη, όχι την τρέχουσα ελεύθερη μνήμη. Η εξαγωγή συμπερασμάτων χρειάζεται επίσης αρκετή ελεύθερη μνήμη και η εγκατάσταση χώρο εργασίας· η μνήμη δεν εγγυάται ταχύτητα.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης αντίστοιχο περιβάλλον εκτέλεσης προς λήψη.

Στα Windows, εγκαταστήστε το πιο πρόσφατο υποστηριζόμενο [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που αντιστοιχεί στην εφαρμογή υπολογιστή: **x64** για build x64 ή **ARM64** για build ARM64.
