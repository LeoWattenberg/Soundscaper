## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Παρέχετε ένα άλλο τοπικό μοντέλο αναγνώρισης ομιλίας για μεταγραφές και υπότιτλους.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό sherpa-onnx-node 1.13.5 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρήση αυτού του μοντέλου {#use-this-model}

Ανοίξτε **Ανάλυση → Ομιλία → Μεταγραφή & Υπότιτλοι** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε μια περιοχή με ομιλία.
2. Εγκαταστήστε το Parakeet v3 μέσω Διαχείρισης Μοντέλων. Επιλέξτε την ακριβή ταυτότητα μοντέλου του στα Εργαλεία → Προχωρημένη Τοπική Επεξεργασία όταν συγκρίνετε μοντέλα.
3. Εκτελέστε τοπικά και αναθεωρήστε το προτεινόμενο μεταγραφή πριν την εφαρμόσετε.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ταυτότητα μοντέλου: `parakeet-tdt-0.6b-v3`, έκδοση **3.0.0**.

Κατά προσέγγιση μέγεθος λήψης τεχνουργήματος μοντέλου: **639.42 MiB**. Το απαιτούμενο περιβάλλον εκτέλεσης προστίθεται στην πρώτη λήψη αν δεν είναι ήδη εγκατεστημένο. Ελάχιστη μνήμη συστήματος: **4 GiB**. Η απαίτηση καταλόγου αφορά τη συνολική μνήμη, όχι την τρέχουσα ελεύθερη μνήμη. Η εξαγωγή συμπερασμάτων χρειάζεται επίσης αρκετή ελεύθερη μνήμη και η εγκατάσταση χώρο εργασίας· η μνήμη δεν εγγυάται ταχύτητα.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης αντίστοιχο περιβάλλον εκτέλεσης προς λήψη.

Στα Windows, εγκαταστήστε το πιο πρόσφατο υποστηριζόμενο [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που αντιστοιχεί στην εφαρμογή υπολογιστή: **x64** για build x64 ή **ARM64** για build ARM64. Οι εγγενείς μηχανισμοί ONNX και Sherpa χρειάζονται αυτές τις βιβλιοθήκες· οι λήψεις μοντέλου και περιβάλλοντος εκτέλεσης δεν τις περιλαμβάνουν. Δεν απαιτείται το Visual Studio για τη χρήση της εφαρμογής.

Εργαλεία → Διαχείριση μοντέλων κατεβάζει τα δημοσιευμένα τεχνουργήματα μοντέλου και το απαιτούμενο περιβάλλον εκτέλεσης κατά την πρώτη εγκατάσταση και επαληθεύει τα καταγεγραμμένα SHA-256. Η επεξεργασία χρησιμοποιεί τα αρχεία που είναι εγκατεστημένα τοπικά. Ανοίξτε το Αποθήκευση και επαλήθευση στη Διαχείριση μοντέλων για ειδοποιήσεις, επιδιόρθωση εγκατάστασης ή αλλαγή θέσης αποθήκευσης.
