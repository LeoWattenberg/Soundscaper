Εκτιμήστε την οπτικά προεξέχουσα περιοχή των δειγματοληφθέντων καρέ για να βοηθήσετε στην επαναδιαμόρφωση.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Τα desktop builds συσκευάζουν τον απαιτούμενο κινητήρα onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε τα βάρη αυτού του μοντέλου μέσω του Model Manager και στη συνέχεια εκτελέστε την εργασία του τοπικά. Αυτοί είναι οι υποστηριζόμενοι στόχοι δημιουργίας· συμβουλευτείτε την έκθεση δοκιμών της νύχτας για τα αποτελέσματα σε ένα συγκεκριμένο πακέτο και μηχανή. Το desktop build δεν συσκευάζει αυτόν τον κινητήρα για macOS x64 παρόλο που τα βάρη του μοντέλου αναφέρονται για αυτές τις πλατφόρμες.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε το **Framescaper: Effect → Video effects → Reframe** σε μια πλατφόρμα με τον απαιτούμενο εγγενή runtime. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε ένα βίντεο κλιπ και εγκαταστήστε το U²-Net-P μέσω Manage Models.
2. Η καθοδηγούμενη εργασία Reframe χρειάζεται επίσης το YuNet και το D-FINE· τα Εργαλεία → Προχωρημένη Τοπική Επεξεργασία μπορούν να εκτελέσουν ξεχωριστά την ανίχνευση σημαντικότητας.
3. Εκτελέστε τοπικά και εξετάστε την προτεινόμενη πλαίσιο πριν την εφαρμόσετε.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ταυτότητα μοντέλου: `u2netp-saliency`, έκδοση **1.0.0**.

Περίπου μέγεθος λήψης: **4,36 MiB**. Ελάχιστη μνήμη συστήματος: **2 GiB**. Αυτή η απαίτηση καταλόγου αναφέρεται στη συνολική μνήμη, όχι στη μνήμη που είναι ελεύθερη αυτή τη στιγμή. Η συμπερασματολογία χρειάζεται επίσης επαρκή ελεύθερη μνήμη, και η εγκατάσταση χρειάζεται χώρο εργασίας· η μνήμη δεν είναι εγγύηση ταχύτητας.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης ένας αντιστοιχισμένος συσκευασμένος runtime.

Στα Windows, εγκαταστήστε την τελευταία υποστηριζόμενη [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που ταιριάζει με την εφαρμογή desktop: **x64** για μια δημιουργία x64 ή **ARM64** για μια δημιουργία ARM64. Οι εγγενείς κινητήρες ONNX και Sherpa απαιτούν αυτές τις βιβλιοθήκες· οι λήψεις μοντέλων δεν τις περιλαμβάνουν. Το ίδιο το Visual Studio δεν απαιτείται για τη χρήση της εφαρμογής.
