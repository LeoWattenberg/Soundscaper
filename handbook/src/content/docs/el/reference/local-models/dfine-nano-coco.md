## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Εντοπισμός προσώπων και αντικειμένων σε δειγματοληπτημένα καρέ βίντεο για την πρόταση νέου κάδρου.

Το D-FINE ανιχνεύει κατηγορίες αντικειμένων και τις θέσεις τους. Η λειτουργία ανίχνευσης θέματος συνδυάζει αυτά τα αποτελέσματα με τις ανιχνεύσεις προσώπων του YuNet.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρήση του μοντέλου {#use-this-model}

Ανοίξτε **Framescaper: Εφέ → Εφέ βίντεο → Νέα καδραρίσματος** σε πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε ένα κλιπ βίντεο στο Framescaper.
2. Εγκαταστήστε τα YuNet και D-FINE για ανίχνευση θέματος. Η καθοδηγούμενη εργασία Νέο καδράρισμα χρησιμοποιεί επίσης ανίχνευση σημαντικών περιοχών με U²-Net-P.
3. Εκτελέστε τοπικά και ελέγξτε την προτεινόμενη περικοπή. Η επιλογή Εργαλεία → Προηγμένη τοπική επεξεργασία μπορεί να εκτελέσει μόνη της την ανίχνευση θέματος.

Αυτή η λειτουργία απαιτεί επίσης [ανίχνευση προσώπων YuNet](/reference/local-models/yunet-face-detection-2026may/).
