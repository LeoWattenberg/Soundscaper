## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό whisper-cpp v1.9.3 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρήση αυτού του μοντέλου {#use-this-model}

Ανοίξτε **Ανάλυση → Ομιλία → Μεταγραφή & Υπότιτλοι** σε μια πλατφόρμα με τον απαιτούμενο τοπικό χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιφάνειας εργασίας.

1. Επιλέξτε ομιλία και εγκαταστήστε το Whisper large-v3 turbo μέσω Διαχείρισης Μοντέλων.
2. Επιλέξτε αυτό το μοντέλο αναγνώρισης ομιλίας κάτω από Εργαλεία → Προχωρημένη Τοπική Επεξεργασία όταν θέλετε να επιλέξετε ρητά το Whisper.
3. Εκτελέστε τοπικά και εξετάστε τόσο το κείμενο όσο και τα όρια τμημάτων πριν αποδεχτείτε.
