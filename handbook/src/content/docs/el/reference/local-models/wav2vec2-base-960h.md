## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Στοιχίστε ένα υπάρχον αγγλικό απομαγνητοφωνημένο κείμενο με τις εκφωνημένες λέξεις της ηχογράφησης.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή.

## Χρήση του μοντέλου {#use-this-model}

Ανοίξτε **Ανάλυση → Ομιλία → Απομαγνητοφώνηση και λεζάντες ή Εργαλεία → Προηγμένη τοπική επεξεργασία → Στοίχιση λέξεων** σε πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε την ομιλία και προετοιμάστε ή ελέγξτε το αγγλικό απομαγνητοφωνημένο κείμενό της.
2. Εγκαταστήστε το μοντέλο στοίχισης μέσω της Διαχείρισης μοντέλων.
3. Εκτελέστε τη στοίχιση και, στη συνέχεια, ακούστε και ελέγξτε τα προτεινόμενα όρια των λέξεων πριν τα αποδεχτείτε.
