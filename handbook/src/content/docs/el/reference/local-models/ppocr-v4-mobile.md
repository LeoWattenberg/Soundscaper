## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Διαβάστε ορατό κείμενο από δείγματα πλαισίων βίντεο για έλεγχο και ευρετηρίαση.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε το **Framescaper: Εργαλεία → Αναζήτηση → Ευρετηρίαση Βίντεο, ή Εργαλεία → Προχωρημένη Τοπική Επεξεργασία → Αναγνώριση οπτικών χαρακτήρων** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή επιτραπέζιου υπολογιστή.

1. Επιλέξτε βίντεο που περιέχει αναγνώσιμο κείμενο στην οθόνη.
2. Εγκαταστήστε το PP-OCRv4 mobile μέσω Διαχείριση Μοντέλων. Είναι ένα προαιρετικό βήμα της Ευρετηρίαση Βίντεο, το οποίο χρησιμοποιεί επίσης το SigLIP2.
3. Εκτελέστε τοπικά και ελέγξτε το αναγνωρισμένο κείμενο και τις θέσεις των πλαισίων του πριν αποδεχτείτε τα αποτελέσματα.

## Λήψη και απαιτήσεις {#download-and-requirements}

Ταυτότητα μοντέλου: `ppocr-v4-mobile`, έκδοση **4.0.0**.

Κατά προσέγγιση μέγεθος λήψης τεχνουργήματος μοντέλου: **15.46 MiB**. Το απαιτούμενο περιβάλλον εκτέλεσης προστίθεται στην πρώτη λήψη αν δεν είναι ήδη εγκατεστημένο. Ελάχιστη μνήμη συστήματος: **2 GiB**. Η απαίτηση καταλόγου αφορά τη συνολική μνήμη, όχι την τρέχουσα ελεύθερη μνήμη. Η εξαγωγή συμπερασμάτων χρειάζεται επίσης αρκετή ελεύθερη μνήμη και η εγκατάσταση χώρο εργασίας· η μνήμη δεν εγγυάται ταχύτητα.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης αντίστοιχο περιβάλλον εκτέλεσης προς λήψη.

Στα Windows, εγκαταστήστε το πιο πρόσφατο υποστηριζόμενο [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που αντιστοιχεί στην εφαρμογή υπολογιστή: **x64** για build x64 ή **ARM64** για build ARM64. Οι εγγενείς μηχανισμοί ONNX και Sherpa χρειάζονται αυτές τις βιβλιοθήκες· οι λήψεις μοντέλου και περιβάλλοντος εκτέλεσης δεν τις περιλαμβάνουν. Δεν απαιτείται το Visual Studio για τη χρήση της εφαρμογής.

Εργαλεία → Διαχείριση μοντέλων κατεβάζει τα δημοσιευμένα τεχνουργήματα μοντέλου και το απαιτούμενο περιβάλλον εκτέλεσης κατά την πρώτη εγκατάσταση και επαληθεύει τα καταγεγραμμένα SHA-256. Η επεξεργασία χρησιμοποιεί τα αρχεία που είναι εγκατεστημένα τοπικά. Ανοίξτε το Αποθήκευση και επαλήθευση στη Διαχείριση μοντέλων για ειδοποιήσεις, επιδιόρθωση εγκατάστασης ή αλλαγή θέσης αποθήκευσης.

- Μικρό, θολωμένο, περιστραμμένο, στιλιζαρισμένο ή μερικώς κρυμμένο κείμενο μπορεί να παραλειφθεί ή να διαβαστεί εσφαλμένα.
