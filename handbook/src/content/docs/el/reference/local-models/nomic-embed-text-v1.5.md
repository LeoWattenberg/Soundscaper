Δημιουργήστε τοπικές αριθμητικές αναπαραστάσεις αποσπασμάτων μεταγραφής και ερωτημάτων αναζήτησης για αναζήτηση με βάση τη σημασία.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι δημιουργίες για επιτραπέζιο υπολογιστή συσκευάζουν τον απαιτούμενο κινητήρα onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε τους βαρύτητες αυτού του μοντέλου μέσω του Διαχειριστή Μοντέλων και στη συνέχεια εκτελέστε την εργασία τοπικά. Αυτοί είναι οι υποστηριζόμενοι στόχοι δημιουργίας· συμβουλευτείτε την έκθεση δοκιμών της νύχτας για τα αποτελέσματα σε ένα συγκεκριμένο πακέτο και μηχανή. Η δημιουργία για επιτραπέζιο υπολογιστή δεν συσκευάζει αυτόν τον κινητήρα για macOS x64 παρόλο που οι βαρύτητες του μοντέλου αναφέρονται για αυτές τις πλατφόρμες.

## Χρησιμοποιήστε αυτό το μοντέλο {#use-this-model}

Ανοίξτε **Εργαλεία → Αναζήτηση → Δείκτης Μεταγραφής** και στη συνέχεια **Εργαλεία → Αναζήτηση → Δείκτης Αναζήτησης** σε μια πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επιτραπέζιο επεξεργαστή.

1. Δημιουργήστε ή εισαγάγετε μια μεταγραφή και στη συνέχεια εγκαταστήστε το Nomic Embed Text μέσω Διαχείρισης Μοντέλων.
2. Εκτελέστε τον Δείκτη Μεταγραφής για να προετοιμάσετε το κείμενο για αναζήτηση με βάση τη σημασία.
3. Χρησιμοποιήστε τον Δείκτη Αναζήτησης και αναθεωρήστε τα ταιριαστά αποσπάσματα στο πλαίσιο. Η Προχωρημένη Τοπική Επεξεργασία εκθέτει επίσης τη λειτουργία ενσωμάτωσης.

Περίπου μέγεθος λήψης: **131.62 MiB**. Ελάχιστη μνήμη συστήματος: **4 GiB**. Αυτή η απαίτηση καταλόγου αναφέρεται στη συνολική μνήμη, όχι στη μνήμη που είναι ελεύθερη αυτή τη στιγμή. Η συμπερασματολογία απαιτεί επίσης επαρκή ελεύθερη μνήμη, και η εγκατάσταση απαιτεί χώρο εργασίας· η μνήμη δεν είναι εγγύηση ταχύτητας.

Δημοσιευμένες πλατφόρμες: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Απαιτείται επίσης ένας ταιριαστός συσκευασμένος χρόνος εκτέλεσης.

Στα Windows, εγκαταστήστε την τελευταία υποστηριζόμενη [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) που ταιριάζει με την εφαρμογή επιτραπέζιου υπολογιστή: **x64** για μια δημιουργία x64 ή **ARM64** για μια δημιουργία ARM64.
