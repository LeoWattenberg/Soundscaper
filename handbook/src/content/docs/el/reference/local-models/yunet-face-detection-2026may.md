## Σκοπός και περίπτωση χρήσης {#purpose-and-use-case}

Εντοπισμός προσώπων και αντικειμένων σε δειγματοληπτημένα καρέ βίντεο, για να προταθεί νέο κάδρο.

Το YuNet ανιχνεύει πρόσωπα και τις θέσεις τους. Η λειτουργία ανίχνευσης θεμάτων συνδυάζει αυτά τα αποτελέσματα με τις ανιχνεύσεις αντικειμένων του D-FINE.

## Τρέχουσα διαθεσιμότητα {#current-availability}

Οι εκδόσεις για υπολογιστή μπορούν να κατεβάσουν και να επαληθεύσουν τον απαιτούμενο μηχανισμό onnxruntime-node 1.29.0 για macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Εγκαταστήστε αυτό το μοντέλο και το απαιτούμενο περιβάλλον εκτέλεσης μέσω της Διαχείρισης μοντέλων και εκτελέστε την εργασία τοπικά. Αυτοί είναι υποστηριζόμενοι στόχοι build· δείτε την αναφορά νυχτερινών δοκιμών για αποτελέσματα συγκεκριμένου πακέτου και υπολογιστή. Δεν υπάρχει μηχανισμός προς λήψη για macOS x64, παρότι τα βάρη του μοντέλου αναφέρονται για αυτήν την πλατφόρμα.

## Χρήση του μοντέλου {#use-this-model}

Ανοίξτε **Framescaper: Εφέ → Εφέ βίντεο → Αναπλαισίωση** σε πλατφόρμα με τον απαιτούμενο εγγενή χρόνο εκτέλεσης. Η τοπική βοήθεια εκτελείται στον επεξεργαστή desktop.

1. Επιλέξτε ένα βίντεο κλιπ στο Framescaper.
2. Εγκαταστήστε τόσο το YuNet όσο και το D-FINE για ανίχνευση θεμάτων. Η καθοδηγούμενη εργασία Αναπλαισίωσης χρησιμοποιεί επίσης την ανίχνευση σημαντικών περιοχών U²-Net-P.
3. Εκτελέστε τοπικά και ελέγξτε την προτεινόμενη περικοπή. Η επιλογή Εργαλεία → Προηγμένη τοπική επεξεργασία μπορεί να εκτελέσει αυτόνομα την ανίχνευση θεμάτων.

Αυτή η λειτουργία απαιτεί επίσης [ανίχνευση αντικειμένων D-FINE Nano](/reference/local-models/dfine-nano-coco/).
