Οι σελίδες αναφοράς δημιουργούνται από ελεγμένους καταλόγους εκτέλεσης και ενσωματώνονται
στο αποθετήριο. Περιγράφουν την υλοποιημένη συμπεριφορά, όχι τις καταχωρίσεις του οδικού χάρτη ή την
απλή παρουσία αρχείων προέλευσης και δοκιμών.

Χρησιμοποιήστε αυτό το τμήμα για να απαντήσετε σε ερωτήσεις όπως:

- Ποιο προεπιλεγμένο συντομεύσεις καλεί μια εντολή;
- Διατίθεται μια εντολή στο Soundscaper, στο Framescaper ή και στα δύο;
- Ποια μορφότυπα ήχου και βίντεο μπορούν να εξαχθούν;
- Τι προεπιλεγμένη τιμή έχει παράμετρος ενός εφέ, και ποιες τιμές θα δεχτεί;
- Ποια εφέ μπορούν να τρέξουν ενώ αναπαράγεται ήχος, και ποια χρειάζονται επιλογή;
- Ποια τοπικά ροές εργασίας βοήθειας υπάρχουν, και ποια μοντέλα χρειάζονται;
- Ποια πλαίσια εμφανίζει κάθε χώρος εργασίας;
- Ποια γλώσσες, προγράμματα περιήγησης και πακέτα επιφάνειας εργασίας δημιουργούνται και δοκιμάζονται;
- Ποια χαρακτηριστικά εξαρτώνται από ένα προϊόν, πλατφόρμα ή χρόνο εκτέλεσης FFmpeg;

Οι δημιουργημένες σελίδες περιλαμβάνουν την προέλευση της πηγής τους και ελέγχονται για απόκλιση
στην πύλη ποιότητας του αποθετηρίου.

Η σελίδα [Προγράμματα μακροεντολών](/reference/macro-programs/) που γράφτηκε χειροκίνητα τεκμηριώνει το JavaScript API που χρησιμοποιεί ένα πρόγραμμα μακροεντολών. Η σελίδα [Αντικατάσταση εισαγόμενου αρχείου στον υπολογιστή
](/reference/overwrite-original-file/) περιγράφει την εντολή αρχείων Electron που μοιράζονται και τα δύο προϊόντα. Οι δοκιμές του επεξεργαστή ελέγχουν τη συμπεριφορά τους.
