Αυτή η σελίδα αντικατοπτρίζει τα τρέχοντα προφίλ προϊόντων. Το «Ενεργοποιημένο» σημαίνει ότι το προφίλ εκθέτει αυτή τη δυνατότητα δημιουργίας περιεχομένου ή εκτέλεσης. Μια απενεργοποιημένη δυνατότητα μπορεί ακόμα να διατηρηθεί όταν ένα έργο ανοίγει σε διάφορα προϊόντα· αυτός ο πίνακας δεν ισχυρίζεται ότι μπορεί να επεξεργαστεί.

| Προϊόν | Οικογένειες εισαγωγής | Οικογένειες εξαγωγής |
| --- | --- | --- |
| Soundscaper | .sscape, Έργα Audacity, Ήχος, Βίντεο, Ετικέτες | .sscape, AUP4 (μόνο ήχος), Ήχος, Βίντεο, Ετικέτες, Στελέχη ήχου |
| Framescaper | .fscape, Έργα Audacity, Ήχος, Βίντεο, Ετικέτες | .fscape, Ήχος, Βίντεο, Ετικέτες |

Οι οικογένειες περιγράφουν τα σημεία εισόδου του προϊόντος, όχι κάθε επέκταση αρχείου που ένας αποκωδικοποιητής μπορεί να αποδεχτεί. Δείτε [Μορφές εξαγωγής](/reference/generated/formats/) για συγκεκριμένες μορφές εξόδου και συνθήκες εκτέλεσης.
