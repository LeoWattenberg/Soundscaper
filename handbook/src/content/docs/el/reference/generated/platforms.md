Ο επεξεργαστής λειτουργεί σε πρόγραμμα περιήγησης και ως εφαρμογή επιφάνειας εργασίας. Αυτή η σελίδα απαριθμεί αυτά που έχουν κατασκευαστεί και δοκιμαστεί, όχι κάθε περιβάλλον στο οποίο ο κώδικας μπορεί να λειτουργήσει.

## Πρόγραμμα περιήγησης

Το «Δοκιμάζεται αυτόματα» σημαίνει ότι το σύνολο του προγράμματος περιήγησης εκτελείται έναντι αυτού του μηχανισμού σε κάθε αίτηση τράβηγματος. Ένας μηχανισμός που δεν αναφέρεται δεν δοκιμάζεται και δεν ισχυρίζεται ότι λειτουργεί.

| Μηχανισμός προγράμματος περιήγησης | Δοκιμάζεται αυτόματα |
| --- | --- |
| Chromium (Chrome, Edge) | Ναι |
| Firefox | Ναι |
| WebKit (Safari) | Ναι |

## Πού μπορεί να εκτελεστεί μια δυνατότητα

Οι δυνατότητες ομαδοποιούνται ανάλογα με το τι χρειάζονται από την πλατφόρμα. Δείτε [Δυνατότητες προϊόντος](/reference/generated/product-capabilities/) για το ποιες δυνατότητες ενεργοποιεί κάθε προϊόν.

| Επίπεδο | Τι σημαίνει |
| --- | --- |
| `web-core` | Λειτουργεί σε κάθε υποστηριζόμενο πρόγραμμα περιήγησης, χωρίς να απαιτείται προαιρετικό χαρακτηριστικό πλατφόρμας. |
| `web-enhanced` | Λειτουργεί σε ένα πρόγραμμα περιήγησης που παρέχει τις νεότερες δυνατότητες αποθήκευσης και μέσων που απαιτεί η δυνατότητα. |
| `electron-enhanced` | Λειτουργεί στο πρόγραμμα περιήγησης, και η εφαρμογή επιφάνειας εργασίας κάνει περισσότερα με αυτό. |
| `electron-only` | Απαιτεί την εφαρμογή επιφάνειας εργασίας, επειδή ένα πρόγραμμα περιήγησης δεν μπορεί να φτάσει σε αυτό που χρησιμοποιεί η δυνατότητα. |
