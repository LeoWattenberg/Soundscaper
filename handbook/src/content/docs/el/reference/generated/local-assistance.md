Η τοπική βοήθεια είναι διαθέσιμη στο Soundscaper και στο Framescaper. Τα μοντέλα αποθηκεύονται σε έναν κατάλογο που επιλέγετε στο δικό σας σύστημα αρχείων και κάθε εκτέλεση πραγματοποιείται στη συσκευή σας· τίποτα από τα μέσα σας δεν αποστέλλεται οπουδήποτε.

Μια ροή εργασίας είναι ένας σταθερός πίνακας βημάτων. Ένα βήμα που ονομάζει μια λειτουργία εκτελεί ένα μοντέλο· ένα βήμα που δεν ονομάζει καμία είναι προσδιοριστικό και δεν εκτελεί κανένα μοντέλο. Ένα προαιρετικό βήμα παραλείπεται όταν το μοντέλο του δεν είναι εγκατεστημένο και η ροή εργασίας παράγει ακόμα ένα αποτέλεσμα από τα βήματα που εκτελέστηκαν.
