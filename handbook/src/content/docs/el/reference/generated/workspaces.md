## Αποθηκεύσεις

Ένα πάνελ καταλαμβάνει μία από αυτές τις θέσεις. “Επιπλέον” σημαίνει ένα παράθυρο πάνελ που μπορείτε να τοποθετήσετε ελεύθερα.

| Αποθήκευση | Αναγνωριστικό αποθήκευσης |
| --- | --- |
| Αριστερά | `left` |
| Δεξιά | `right` |
| Κάτω | `bottom` |
| Επιπλέον | `floating` |
