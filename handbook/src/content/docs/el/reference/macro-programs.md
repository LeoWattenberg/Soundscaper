Ένα πρόγραμμα μακροεντολής είναι μια μακροεντολή γραμμένη ως JavaScript αντί για μια λίστα βημάτων.
Εκτελείται μέσα στον επεξεργαστή έναντι μιας μικρής API που ονομάζεται `sound`, η οποία του επιτρέπει να διαβάζει
το ανοιχτό έργο, να μετακινεί την επιλογή και να εφαρμόζει τους ίδιους εφέ και εντολές που μπορεί να εφαρμόσει μια
μακροεντολή λίστας βημάτων. Όλα τα υπόλοιπα, από αρχεία και δίκτυο έως τα
άλλα έργα σας, είναι εκτός της εμβέλειάς του.

Τα προγράμματα είναι μια δυνατότητα του Soundscaper. Το Framescaper δεν έχει διαχειριστή μακροεντολών.

## Πού βρίσκονται τα προγράμματα

Επιλέξτε **Εργαλεία → Διαχειριστής μακροεντολών**. Ο διάλογος εμφανίζει τις μακροεντολές λίστας βημάτων και, κάτω από
**Προγράμματα**, τα προγράμματα που έχετε αποθηκεύσει. Το **Νέο πρόγραμμα** δημιουργεί ένα, και το
πάνελ λεπτομερειών εμφανίζει το **Όνομα προγράμματος**, το κείμενο **Πρόγραμμα** και ένα κουμπί **Εκτέλεση
προγράμματος**. Το κείμενο αποθηκεύεται καθώς πληκτρολογείτε· δεν υπάρχει ξεχωριστό βήμα αποθήκευσης.

Ένα πρόγραμμα αποθηκεύεται με τις ρυθμίσεις του επεξεργαστή, όχι μέσα σε ένα έργο, οπότε είναι
διαθέσιμο σε κάθε έργο που ανοίγετε σε αυτόν τον επεξεργαστή. Χρησιμοποιήστε **Εξαγωγή προγράμματος** και
**Εισαγωγή προγράμματος** για να μετακινήσετε ένα σε άλλη συσκευή ή άλλο άτομο· δείτε
[Κοινοποίηση προγραμμάτων](#sharing-programs) για το τι περιλαμβάνει αυτό.

Ο οδηγός [Εφαρμογή της ίδιας αλυσίδας εφέ κάθε φορά](/guides/effects/apply-the-same-effects-every-time/)
καλύπτει την πλευρά της λίστας βημάτων του ίδιου διαλόγου.

## Γραφή ενός προγράμματος

Ένα πρόγραμμα είναι το σώμα μιας συνάρτησης `async`, που εκτελείται σε αυστηρή λειτουργία. Αυτό σημαίνει ότι
μπορείτε να `await` στο верхний επίπεδο, να δηλώσετε μεταβλητές και συναρτήσεις και να χρησιμοποιήσετε κάθε
συνηθισμένο χαρακτηριστικό της γλώσσας. Το αντικείμενο `sound` είναι ο μοναδικός σύνδεσμος του προγράμματος με
τον επεξεργαστή, και κάθε κλήση σε αυτό επιστρέφει μια υπόσχεση.

```js
// Normalize everything, then fade the last two seconds.
await sound.select.all();
await sound.effect('audacity-normalize', { peakDb: -1 });
await sound.select.time(2, 0, { relativeTo: 'selection-end' });
await sound.effect('audacity-fade-out');
```

Το Tab εισάγει δύο κενά στο πεδίο προγράμματος. Πατήστε Escape και στη συνέχεια Tab για να
αποχωρήσετε από το πεδίο.

### Τι μπορεί να χρησιμοποιήσει ένα πρόγραμμα

Η συνήθης βιβλιοθήκη προτύπων JavaScript είναι παρούσα: `Object`, `Array`, `Map`,
`Set`, `Math`, `JSON`, `RegExp`, `Promise`, οι τυποποιημένες διατάξεις, `Intl`,
`TextEncoder`, `TextDecoder`, `structuredClone` και `queueMicrotask`. `console`
είναι επίσης παρούσα, και ό,τι γράφεται σε αυτή καταλήγει στο αρχείο καταγραφής του προγράμματος.

### Τι δεν μπορεί να χρησιμοποιήσει ένα πρόγραμμα

Ένα πρόγραμμα εκτελείται σε έναν worker από τον οποίο έχουν αφαιρεθεί οι ικανότητες του πριν
εκτελεστεί η πρώτη γραμμή. Κανένα από τα παρακάτω δεν υπάρχει μέσα σε ένα πρόγραμμα: `fetch`,
`XMLHttpRequest`, `WebSocket`, `indexedDB`, `caches`, `crypto`, `navigator`,
`location`, `Worker`, `WebAssembly`, `SharedArrayBuffer`, `Atomics`, `eval`,
`setTimeout` και `setInterval`. Η ανάγνωση οποιουδήποτε από αυτά δίνει `undefined`.

Ένα πρόγραμμα δεν μπορεί να `import` ένα module· ένα στατικό `import` είναι σφάλμα συντακτικού στην
γραμμή που το περιέχει. Ό,τι χρειάζεται το πρόγραμμα πρέπει να βρίσκεται μέσα στο πρόγραμμα.

Το σύνορο ασφαλείας δεν είναι τα λείποντα globals, αλλά ο ίδιος ο επεξεργαστής: αυτός
απαντά μόνο στις κλήσεις που αναφέρονται σε αυτή τη σελίδα και απορρίπτει όλα τα υπόλοιπα κατά όνομα,
ό,τι κι αν καταφέρει να του στείλει ένα πρόγραμμα.

## Εκτέλεση ενός προγράμματος

Πατήστε **Run program**. Η ολόκληρη εκτέλεση είναι μία εγγραφή στο ιστορικό του έργου, οπότε
ένα **Undo** αναιρεί ό,τι έκανε το πρόγραμμα, όσες αλλαγές κι αν έκανε.
Αν το πρόγραμμα ρίξει σφάλμα, ή ακυρωθεί, ή εκτελεστεί πέρα από το χρονικό του όριο, το έργο
επαναφέρεται ακριβώς όπως ήταν πριν ξεκινήσει η εκτέλεση.

Το **Cancel run** σταματά ένα πρόγραμμα αμέσως. Ένα πρόγραμμα που έχει εκτελεστεί για δύο
λεπτά σταματά με τον ίδιο τρόπο, με το μήνυμα *The macro ran for longer than
120 seconds.*

Μετά την εκτέλεση, το πάνελ εμφανίζει το αρχείο καταγραφής του προγράμματος, ακολουθούμενο από *Program applied.*
όταν η εκτέλεση ολοκληρωθεί. Μια αποτυχημένη εκτέλεση εμφανίζει *The program failed on line N:* και
το μήνυμα του σφάλματος, όπου ο αριθμός γραμμής είναι η γραμμή του προγράμματός σας που
έριξε σφάλμα.

### Ποιο ήχο αγγίζει μια επίδραση

Μια επίδραση που εφαρμόζεται από ένα πρόγραμμα εκτελείται πάνω στην τρέχουσα επιλογή χρόνου στο
εστιασμένο κομμάτι, δηλαδή στο κομμάτι του οποίου τον τίτλο πατήσατε τελευταία ή του οποίου το κλιπ
επιλέξατε τελευταίο. Όταν δεν υπάρχει επιλογή χρόνου αλλά ένα κλιπ είναι επιλεγμένο, η
επίδραση καλύπτει αυτό το κλιπ. Οι κλήσεις επιλογής ενός προγράμματος αλλάζουν το χρονικό εύρος και
το σύνολο των επιλεγμένων κομματιών, αλλά όχι ποιο κομμάτι έχει εστίαση, οπότε μία εκτέλεση επεξεργάζεται
ένα κομμάτι. Αν τίποτα δεν είναι εστιασμένο ή η επιλογή είναι κενή, η εκτέλεση αποτυγχάνει με
το ίδιο μήνυμα που δίνει το μενού Effect.

## Το API `sound`

Κάθε μέθοδος παρακάτω επιστρέφει ένα promise εκτός αν αναφέρεται διαφορετικά. Αναμείνετε κάθε κλήση
πριν κάνετε την επόμενη· ένα πρόγραμμα που ξεκινά περισσότερες από οκτώ κλήσεις χωρίς
να τις αναμένει, έχει την ένατη απορριφθείσα.

### `sound.env`

Ένα απλό αντικείμενο που περιγράφει την εκτέλεση.

| Πεδίο | Σημασία |
| --- | --- |
| `productId` | `"soundscaper"`. |
| `locale` | Η γλώσσα διεπαφής του επεξεργαστή, όπως `"en"` ή `"de"`. |
| `seed` | Το σπόρο από τον οποίο προέρχονται οι τυχαίοι αριθμοί της εκτέλεσης. Νέος για κάθε εκτέλεση. |
| `startedAt` | Η ώρα τοιχώματος που ξεκίνησε η εκτέλεση, ως συμβολοσειρά ISO 8601. |
| `dryRun` | Πάντα `false` αυτή τη στιγμή. Κρατημένο. |

### `sound.log`

`sound.log.info(...values)`, `sound.log.warn(...values)`,
`sound.log.error(...values)` και `sound.log.debug(...values)` γράφουν μία γραμμή
η καθεμία στο αρχείο καταγραφής της εκτέλεσης. `console.log`, `console.info`, `console.warn`,
`console.error` και `console.debug` κάνουν το ίδιο. Τιμές που δεν είναι συμβολοσειρές
γράφονται ως JSON. Αυτές οι μέθοδοι δεν επιστρέφουν τίποτα και δεν χρειάζεται να αναμένονται.

Ένα αρχείο καταγραφής περιέχει το πολύ 1.000 γραμμές ή 256 KiB, όποιο έρθει πρώτο, και κάθε γραμμή
κοπτάται στα 4.096 χαρακτήρες. Οι γραμμές πέρα από αυτό απορρίπτονται και μετρούνται· ο αριθμός
αναφέρεται ως τελική προειδοποίηση.

### `sound.project`

Η ανάγνωση του έργου δεν το αλλάζει ποτέ και δεν μετράει εναντίον του προϋπολογισμού αλλαγών της εκτέλεσης.

`sound.project.snapshot()` επιστρέφει `{ sampleRate, tracks, selection }`, με
`tracks` και `selection` όπως τα επιστρέφουν οι δύο κλήσεις παρακάτω. `sampleRate` είναι
ο ρυθμός δειγματοληψίας του έργου σε hertz, που είναι αυτό με το οποίο μετριούνται όλα τα πλήθη πλαισίων σε αυτή τη σελίδα.

`sound.project.tracks()` επιστρέφει ένα πίνακα κομματιών σε σειρά χρονολόγιο:

```json
{ "id": "track-…", "name": "Voice", "kind": "audio", "index": 0, "muted": false, "solo": false }
```

`sound.project.clips(trackId)` επιστρέφει τα κλιπ σε ένα μονοπάτι ή σε όλα τα μονοπάτια
όταν το `trackId` παραλείπεται:

```json
{ "id": "clip-…", "name": "Take 1", "startFrame": 0, "durationFrames": 480000 }
```

`sound.project.selection()` επιστρέφει την τρέχουσα επιλογή:

```json
{ "startFrame": 0, "endFrame": 96000, "trackIds": ["track-…"] }
```

### `sound.select`

Κάθε κλήση επιλογής μετράται ως μία αλλαγή και επιστρέφει την επιλογή που παρήγαγε,
με τη μορφή που επιστρέφει το `sound.project.selection()`.

Το `sound.select.time(start, end, options)` ορίζει το χρονικό εύρος σε δευτερόλεπτα. Είναι
η εντολή `SelectTime` του Audacity, και το `options.relativeTo` επιλέγει από πού μετράται
κάθε άκρη. Και οι δύο άκρες μπορεί να είναι χαμηλές έως -100 δευτερόλεπτα.

| `relativeTo` | Αρχική άκρη | Τελική άκρη |
| --- | --- | --- |
| `'project-start'` (προεπιλογή) | `start` δευτερόλεπτα από την αρχή του έργου | `end` δευτερόλεπτα από την αρχή του έργου |
| `'project'` | `start` δευτερόλεπτα από την αρχή του έργου | `end` δευτερόλεπτα μετά το τέλος του έργου |
| `'project-end'` | `start` δευτερόλεπτα πριν το τέλος του έργου | `end` δευτερόλεπτα πριν το τέλος του έργου |
| `'selection-start'` | `start` δευτερόλεπτα μετά την αρχή της επιλογής | `end` δευτερόλεπτα μετά την αρχή της επιλογής |
| `'selection'` | `start` δευτερόλεπτα μετά την αρχή της επιλογής | `end` δευτερόλεπτα μετά το τέλος της επιλογής |
| `'selection-end'` | `start` δευτερόλεπτα πριν το τέλος της επιλογής | `end` δευτερόλεπτα πριν το τέλος της επιλογής |

Το τέλος του έργου είναι το τελευταίο πλαίσιο που φτάνει οποιοδήποτε κλιπ. Οι επιλεγμένες
εγγραφές παραμένουν όπως ήταν.

Το `sound.select.frames(startFrame, endFrame, options)` ορίζει το χρονικό εύρος σε
πλαίσια στο ρυθμό δειγματοληψίας του έργου. Το `options.trackIds` ονομάζει τις εγγραφές που
θα επιλεγούν· όταν παραλείπεται, οι εγγραφές που είναι ήδη επιλεγμένες παραμένουν επιλεγμένες.
Το εύρος περιορίζεται στον χρονικό άξονα και οι άκρες ανταλλάσσονται αν είναι αντεστραμμένες.

Το `sound.select.tracks(options)` είναι η εντολή `SelectTracks` του Audacity. Επιλέγει
τις εγγραφές cuyo índice (μετρημένο από το 0) βρίσκεται στο εύρος από το `options.track`
(προεπιλογή 0) καλύπτοντας `options.trackCount` εγγραφές (προεπιλογή 1). Το `options.mode` είναι
`'set'` για να αντικαταστήσει την επιλογή εγγραφών, `'add'` για να την επεκτείνει, ή `'remove'` για
να αφαιρέσει αυτές τις εγγραφές από αυτήν. Το χρονικό εύρος παραμένει όπως ήταν.

Το `sound.select.frequencies(options)` είναι η εντολή `SelectFrequencies` του Audacity.
Ορίζει την φασματική επιλογή σε `options.low` και `options.high` σε hertz·
μία άκρη που παραλείπεται διατηρεί την τρέχουσα τιμή της.

Το `sound.select.all()` επιλέγει ολόκληρο το έργο σε κάθε εγγραφή.
Το `sound.select.none()` καθαρίζει την επιλογή.

### `sound.effect(type, params)`

Εφαρμόζει ένα αποτέλεσμα στο τρέχον εύρος επιλογής, στην εγγραφή που έχει εστίαση. Το `type` είναι
ένα αναγνωριστικό αποτελέσματος από [Ενέργειες που μπορεί να εφαρμόσει ένα πρόγραμμα](#effects-a-program-can-apply),
και το `params` είναι ένα αντικείμενο με τις παραμέτρους αυτού του αποτελέσματος. Οι παραμέτρους που παραλείπετε λαμβάνουν
τις προεπιλογές του αποτελέσματος· οι τιμές ελέγχονται έναντι των εμβελίων στο
[αναφορά ακουστικών αποτελεσμάτων](/reference/generated/audio-effects/). Αντιστοιχεί στο
`null`.

```js
await sound.effect('audacity-amplify', { gainDb: -3 });
```

### `sound.effects(steps)`

Εφαρμόζει μια αλυσίδα εφέ στην τρέχουσα επιλογή σε ένα βήμα, ακριβώς όπως θα το έκανε ένα μακροεντολή λίστας βημάτων με αυτά τα βήματα. Κάθε βήμα είναι `{ type, params }`, και η αλυσίδα απαιτεί τουλάχιστον ένα βήμα. Αντιστοιχείται σε `null`.

```js
await sound.effects([
  { type: 'audacity-remove-dc-offset' },
  { type: 'audacity-normalize', params: { peakDb: -3 } },
  { type: 'audacity-legacy-compressor', params: { thresholdDb: -18, ratio: 3 } },
]);
```

### `sound.command(name, params)`

Εκτελεί μία από τις εντολές μακροεντολών του Audacity που αναφέρονται στο
[Εντολές που μπορεί να εκτελέσει ένα πρόγραμμα](#commands-a-program-can-run). Οι τέσσερις εντολές επιλογής λαμβάνουν τις παραμέτρους που περιγράφονται εκεί· οι υπόλοιπες δεν λαμβάνουν καμία. Αντιστοιχεί στην επιλογή στη συνέχεια.

```js
await sound.command('SelectTime', { start: 0, end: 5 });
await sound.command('Trim');
```

### `sound.runSaved(name)`

Εκτελεί μια μακροεντολή λίστας βημάτων που αποθηκεύεται στον ίδιο διαχειριστή μακροεντολών, με το ακριβές της όνομα,
συμπεριλαμβανομένων οποιωνδήποτε εντολών επιλογής περιέχει. Μια αποθηκευμένη μακροεντολή δεν μπορεί από μόνη της να είναι
προγραμματισμός, οπότε τα προγράμματα δεν ενσωματώνονται. Αντιστοιχεί στο `null`· ένα άγνωστο όνομα απορρίπτεται.

### Χρόνος και τυχαίοτητα

Μια εκτέλεση είναι αναπαραγώσιμη: δύο εκτελέσεις του ίδιου προγράμματος πάνω στο ίδιο έργο διαβάζουν
τα ίδια, επειδή το ρολόι και οι τυχαίοι αριθμοί δεν είναι της μηχανής.

Τα `Date.now()` και `new Date()` χωρίς ορίσματα επιστρέφουν ένα εικονικό ρολόι που
ξεκινά στο 0 και προχωρά κατά ένα για κάθε απαντημένη κλήση στον επεξεργαστή, και κατά
`ms` για κάθε `sound.wait(ms)`. Το `sound.wait` αντιστοιχεί αμέσως· δεν υπάρχει
τρόπος για ένα πρόγραμμα να παύσει για πραγματικό χρόνο, και δεν χρειάζεται, επειδή κάθε κλήση
στον επεξεργαστή ολοκληρώνεται πριν το υπόσχεσή του αντιστοιχιστεί.

Τα `Math.random()` και `sound.random()` είναι ο ίδιος γεννήτορας, με σπόρο από
`sound.env.seed`. Καταγράψτε τον σπόρο αν χρειάζεται να ξέρετε ποια ακολουθία χρησιμοποιήθηκε σε μια εκτέλεση.

### Έλεγχος των υποθέσεών σας

Το `sound.assert(condition, message)` ρίπτει `message` όταν το `condition` είναι ψευδές.
Το `sound.assertEqual(actual, expected, message)` συγκρίνει τις δύο τιμές ως JSON
και ρίπτει σφάλμα όταν διαφέρουν, με μήνυμα που ονοματίζει και τις δύο τιμές αν δεν δώσετε
κανένα. Επειδή ένα ριφθέν σφάλμα τερματίζει την εκτέλεση και αναιρεί όλα όσα προηγήθηκαν, μια
αποτυχημένη διαβεβαίωση αφήνει το έργο αμετάβλητο. Κανένα από τα δύο μέθοδα δεν επιστρέφει υπόσχεση.

```js
const tracks = await sound.project.tracks();
sound.assert(tracks.length > 0, 'Import a recording first.');
await sound.command('SelectAll');
const selection = await sound.project.selection();
sound.assertEqual(selection.trackIds.length, tracks.length, 'Select all should cover every track.');
```

## Τιμές που διασχίζουν προς τον επεξεργαστή

Κάθε ορίσμα που περνά ένα πρόγραμμα και κάθε τιμή που λαμβάνει είναι απλά δεδομένα:
`null`, λογικές τιμές, πεπερασμένοι αριθμοί, συμβολοσειρές και πίνακες και απλά αντικείμενα
από αυτά. `NaN`, `Infinity`, συναρτήσεις, στιγμιότυπα κλάσεων, τυποποιημένοι πίνακες και `Date`
αντικείμενα απορρίπτονται με σφάλμα, όπως και οποιαδήποτε τιμή μεγαλύτερη από 1 MiB, με βάθος
περισσότερο από 12 επίπεδα, ή με περισσότερα από 4.096 εγγραφές σε έναν πίνακα ή αντικείμενο.
Οι ιδιότητες `undefined` απορρίπτονται.

## Περιορισμοί

| Περιορισμός | Τιμή |
| --- | --- |
| Μήκος προγράμματος | 256 KiB |
| Κλήσεις προς τον επεξεργαστή ανά εκτέλεση | 4.096 |
| Αλλαγές στο έργο ανά εκτέλεση (κλήσεις επιλογής, εφέ, εντολές) | 256 |
| Κλήσεις που περιμένουν απάντηση ταυτόχρονα | 8 |
| Χρόνος εκτέλεσης | 120 δευτερόλεπτα |
| Μια τιμή που διασχίζει προς ή από τον επεξεργαστή | 1 MiB, 12 επίπεδα βάθους, 4.096 εγγραφές ανά πίνακα ή αντικείμενο |
| Ημερολόγιο | 1.000 γραμμές ή 256 KiB; 4.096 χαρακτήρες ανά γραμμή |
| Προγράμματα στη βιβλιοθήκη | 128 |
| Όνομα προγράμματος | 256 χαρακτήρες |
| Αρχείο εισαγόμενου προγράμματος | 1 MiB |

Ένας βρόχος που επιλέγει κάθε κλιπ και εφαρμόζει ένα εφέ δαπανά δύο αλλαγές ανά
κλιπ, οπότε μπορεί να καλύψει 128 κλιπ πριν εξαντληθεί το όριο.

## Σφάλματα

Μια κλήση που απορρίπτεται από τον επεξεργαστή απορρίπτει το υπόσχεσή της με ένα `Error` του οποίου το `message`
αναφέρει τον λόγο: μια εντολή εκτός λεξιλογίου, ένα εφέ πάνω σε κενή επιλογή,
ένας παράμετρος εκτός ορίων. Το σφάλμα μεταφέρει επίσης ένα `code`, το οποίο είναι
`MACRO_CALL_FAILED` εκτός αν ο επεξεργαστής παρείχε ένα πιο συγκεκριμένο. Ένα πρόγραμμα
μπορεί να τα συλλάβει και να συνεχίσει:

```js
try {
  await sound.command('ExportWav');
} catch (error) {
  sound.log.warn(`refused: ${error.message}`);
}
```

Αυτό το πρόγραμμα ολοκληρώνεται και το αρχείο καταγραφής του αναγράφει *refused: Unsupported macro command:
ExportWav.*

Ένα σφάλμα που δεν εντοπίζει το πρόγραμμα τερματίζει την εκτέλεση, επαναφέρει το έργο και εμφανίζεται στο πλαίσιο μαζί με τη γραμμή από την οποία προήλθε. Ένα πρόγραμμα που δεν μεταγλωττίζεται αναφέρεται με τον ίδιο τρόπο πριν εκτελεστεί οτιδήποτε.

## Εντολές που μπορεί να εκτελέσει ένα πρόγραμμα {#commands-a-program-can-run}

Το `sound.command` αποδέχεται τις παρακάτω ονομασίες εντολών μακροεντολών του Audacity. Είναι τα ίδια ονόματα που μπορεί να περιέχει μια μακροεντολή λίστας βημάτων, οπότε ένα πρόγραμμα και μια λίστα βημάτων έχουν ακριβώς το ίδιο πεδίο δράσης. Κάθε εντολή εκτελεί την ενέργεια του επεξεργαστή που περιγράφεται στην αναφορά εντολών [commands reference](/reference/generated/commands/).

### Εντολές επιλογής με παραμέτρους

| Εντολή | Παράμετροι |
| --- | --- |
| `SelectTime` | `start`, `end` σε δευτερόλεπτα; `relativeTo` όπως για `sound.select.time` |
| `SelectFrequencies` | `low`, `high` σε hertz |
| `SelectTracks` | `track`, `trackCount` (0 έως 100); `mode` του `'set'`, `'add'` ή `'remove'` |
| `Select` | Οποιοσδήποτε συνδυασμός των τριών παραπάνω συνόλων |

Μια παράμετρος που παραλείπετε αφήνει αμετάβαστο το αντίστοιχο τμήμα της επιλογής, όπως το διαβάζει και το Audacity.

### Εντολές χωρίς παραμέτρους

| Ομάδα | Εντολές |
| --- | --- |
| Επιλογή | `SelectAll`, `SelectNone`, `SelCursorStoredCursor`, `SelTrackStartToEnd`, `SelCursorToTrackEnd`, `SelPrevClip`, `SelNextClip`, `ZeroCross` |
| Επεξεργασία | `Cut`, `Copy`, `Paste`, `Delete`, `Duplicate`, `Split`, `SplitNew`, `Join`, `Disjoin`, `Trim`, `Silence`, `SplitCut`, `SplitDelete` |
| Κομμάτια | `NewMonoTrack`, `NewStereoTrack`, `NewLabelTrack`, `RemoveTracks`, `MixAndRender`, `SortByName`, `SortByTime` |
| Ετικέτες | `AddLabel` |
| Ανάλυση | `FindClipping`, `ContrastAnalyser`, `PlotSpectrum`, `RepeatLastEffect` |

### Τι λείπει σκόπιμα

Τα `Undo` και `Redo` λείπουν επειδή μια εκτέλεση είναι ήδη μια εγγραφή ιστορικού και ένα βήμα που θα περιηγηόταν στο ιστορικό θα έφτανε πέρα από την εκτέλεση, στις δικές σας επεξεργασίες. Οι εντολές μεταφοράς και εγγραφής λείπουν επειδή ένα πρόγραμμα δεν έχει τίποτα να περιμένει και δεν μπορεί να αναστραφεί από μια εγγραφή. Το άνοιγμα, η αποθήκευση, το κλείσιμο, η εισαγωγή, η εξαγωγή και οι προτιμήσεις λείπουν επειδή το πεδίο δράσης ενός προγράμματος είναι το ένα έργο που ήταν ανοιχτό όταν ξεκίνησε. Οι εντολές που απλώς ανοίγουν έναν διάλογο ή αλλάζουν την προβολή λείπουν επειδή δεν αλλάζουν τίποτα στο έργο.

## Κοινοποίηση προγραμμάτων {#sharing-programs}

Η **Εξαγωγή προγράμματος** γράφει το επιλεγμένο πρόγραμμα ως αρχείο `.soundscapemacro`, ενώ η **Εισαγωγή προγράμματος** διαβάζει ένα. Το αρχείο είναι JSON και όχι ένα απλό αρχείο `.js`, ώστε τίποτα στον υπολογιστή παραλήπτη να μην το μπερδέψει με κάτι που πρέπει να εκτελεστεί εκτός επεξεργαστή:

```json
{
	"schemaVersion": 1,
	"kind": "script",
	"engine": "soundscaper-macro-js/1",
	"name": "Episode finish",
	"source": "await sound.select.all();\nawait sound.effect('audacity-normalize');\n"
}
```

Η εισαγωγή αποθηκεύει το κείμενο και τίποτα άλλο. Ένα εισαγόμενο πρόγραμμα δεν διαθέτει κουμπί **Εκτέλεση
προγράμματος**; στη θέση του, το πάνελ εμφανίζει το πρόγραμμα, το αρχείο από το οποίο προέρχεται,
μία σημείωση σχετικά με το τι μπορεί να κάνει ένα πρόγραμμα στο ανοιχτό έργο, και ένα πλαίσιο ελέγχου με την ένδειξη *Έχω
διαβάσει αυτό το πρόγραμμα και θέλω να το εκτελέσω.* Το επιλέγοντο ενεργοποιεί την επιλογή **Ενεργοποίηση
αυτού του προγράμματος**, και μόνο τότε μπορεί να εκτελεστεί το πρόγραμμα.

Αυτή η άδεια ισχύει για το ακριβές κείμενο που διαβάσατε. Αν το πρόγραμμα αλλάξει
αργότερα, είτε το επεξεργαστείτε είτε εισάγετε μια νεότερη αντίγραφο πάνω του, η ανασκόπηση
εμφανίζεται ξανά μέχρι να ενεργοποιήσετε το νέο κείμενο. Τα προγράμματα που γράφετε
εσείς οι ίδιοι στον διαχειριστή δεν απαιτούν ανασκόπηση.

## Παραδείγματα

Αποθόρευση (fade in) κάθε κλιπ στο πρώτο κομμάτι που έχει κάποιο. Κάντε κλικ στο κεφάλαιο
αυτού του κομματιού πριν την εκτέλεση, ώστε η επίδραση να εφαρμοστεί στο κομμάτι που διαβάζει το πρόγραμμα:

```js
let target = null;
let clips = [];
for (const track of await sound.project.tracks()) {
  clips = await sound.project.clips(track.id);
  if (clips.length) {
    target = track;
    break;
  }
}
sound.assert(target, 'There are no clips to fade.');
for (const clip of clips) {
  await sound.select.frames(clip.startFrame, clip.startFrame + clip.durationFrames, {
    trackIds: [target.id],
  });
  await sound.effect('audacity-fade-in');
  sound.log.info(`Faded in ${clip.name} on ${target.name}`);
}
```

Αναφέρετε το έργο χωρίς να το αλλάξετε:

```js
const { sampleRate, tracks } = await sound.project.snapshot();
for (const track of tracks) {
  const clips = await sound.project.clips(track.id);
  const frames = clips.reduce((total, clip) => total + clip.durationFrames, 0);
  sound.log.info(`${track.name}: ${clips.length} clip(s), ${(frames / sampleRate).toFixed(1)} s of audio`);
}
```

Εκτελέστε μια μακροεντολή λίστας αποθηκευμένων βημάτων μόνο όταν η επιλογή είναι αρκετά μεγάλη:

```js
const { startFrame, endFrame } = await sound.project.selection();
const { sampleRate } = await sound.project.snapshot();
sound.assert((endFrame - startFrame) / sampleRate >= 30, 'Select at least thirty seconds.');
await sound.runSaved('Episode finish');
```
