## 排列剪辑

在选择编辑命令之前，选择剪辑或时间范围。分割在播放头处创建一个编辑边界。保留间隙和涟漪变体确定后续材料是否保持原位或移动以关闭删除区域。

使用轨道文件夹、剪辑组和项目二进制文件来整理大型项目。

### 调整剪辑淡入淡出 {#clip-fades}

选择音频剪辑以显示其波形顶部的两个小三角形，直接位于剪辑标题下方。
将左三角形向内拖动以创建淡入效果，或将右三角形向内拖动以创建淡出效果。波形在拖动时发生变化，淡入淡出曲线以上的区域变暗。三角形跟随淡入淡出边界；将其中一个拖回其角落会删除该淡入淡出效果。即使选择了多个剪辑，也只有您拖动的剪辑会被更改。

当您取消选择剪辑时，句柄会消失，但淡入淡出的波形和着色保持不变。这些淡入淡出效果保留原始音频，并在保存和重新打开项目后仍然可调整。释放以提交淡入淡出效果，或在拖动时按 **Esc** 键以取消。**撤销** 操作会逆转一次完整的拖动。播放和导出使用已提交的淡入淡出设置。

在选择的剪辑处于焦点时，按 **Tab** 键访问其淡入淡出句柄。方向键将持续时间调整为 10 毫秒，或在 **Shift** 键下调整为 100 毫秒。**Home** 键删除淡入淡出效果；**End** 键将其扩展到整个剪辑。对于数字输入，请选择 **编辑 → 音频剪辑 → 剪辑属性** 并使用 **淡入淡出**。

### 编辑剪辑源 {#clip-source-properties}

选择**编辑 → 音频剪辑 → 剪辑属性**打开源编辑器。完整录音会显示在剪辑后方。拖动剪辑边缘可更改源起点和时长，同时保持剪辑在项目时间线上的起点不变。**标准化**面板包含剪辑增益以及峰值和响度操作。

打开**音高和速度**并勾选**关联音高和速度**，即可同时更改速度和音高。速度比为`1`且音高变化为`0%`时，声音保持不变。比率`2`会以两倍速度、提高一个八度播放；`0.5`会以一半速度、降低一个八度播放。编辑任一关联控件都会更新另一个控件。取消关联后可单独设置音高，同时保留当前速度比。

按住**Ctrl**并单击波形，可添加与该源采样关联的伸缩标记。拖动标记会改变两侧的时间，叠加层会显示两种播放速度。剪辑控件仍按剪辑分别生效。选择源音频并应用效果，会更新所有使用该源的剪辑。

### 在电子表格中编辑剪辑 {#clip-spreadsheet}

选择**视图 → 面板 → 剪辑电子表格**查看项目中的所有剪辑。面板会在时间线下方打开。可通过面板菜单将其移至其他停靠区、设为浮动窗口或关闭。大小和位置会随工作区保存。每行显示音轨、时间线位置、源文件、源偏移、时长、音高、速度、增益、淡入淡出和播放选项。时间单位为秒，音高单位为半音，速度为比率：`1`表示正常速度，`2`表示两倍速度。

双击单元格，或选中后按**Enter**，即可编辑其值。按**Enter**应用更改，按**Escape**取消。音轨和源单元格显示实际 ID。更改音轨 ID 可将剪辑移至现有音轨。更改源 ID 或输入本地文件路径可替换音频，同时保留时间线位置、时长、速度和以秒为单位的源偏移。新文件必须包含指定的源范围。**反向**和**反相**是复选框；选中单元格后按**空格**可切换。锁定音轨上的剪辑和视频剪辑为只读。

更改时长会从当前偏移处缩短或延长源范围。更改速度会保留源范围，除非同时粘贴时长。先取消剪辑的编组或关联，再在此处更改其时间；伸缩剪辑的时间应在源编辑器中调整。

选择一个单元格、拖动选取一个范围，或按住**Shift**并单击另一个单元格以扩展选择。单击行号或列标题可选择整行或整列。使用**Ctrl+C**和**Ctrl+V**（macOS 上为**Cmd+C**和**Cmd+V**）与电子表格交换所选内容。列之间用制表符分隔，行之间用换行符分隔。粘贴从所选单元格开始并更新现有剪辑。超出现有行的粘贴会被拒绝。已有选择时，按**Escape**或单击表格下方的空白区域可取消选择。没有选择时，粘贴会插入新行，即使项目为空也是如此。播放选项会复制为`true`或`false`，粘贴时也接受这些值。新行遵循表格列顺序，并需要源文件名或源 ID。唯一匹配的现有音轨名称会将剪辑放到该音轨；新名称会创建音轨。音轨名称为空时使用源名称。空白数字单元格使用默认值：位置和偏移为`0`，速度为`1`，音高和增益为`0`，且没有淡入淡出。时长为空时使用所请求速度下的剩余音频。

面板首先在项目中查找源，包括项目素材箱。如果找不到，请选择**加载引用文件**，并在对话框中选择列出的音频文件。磁盘路径也需要通过此方式选择：粘贴路径不会授予应用访问文件的权限。所选文件必须与引用名称明确匹配。面板会导入音频、验证源边界和剪辑属性，并将新剪辑放到指定位置。**Ctrl+Z**（macOS 上为**Cmd+Z**）可一步撤销整个粘贴；**Ctrl+Shift+Z**（**Cmd+Shift+Z**）可重做。如果粘贴包含无效值，剪辑不会更改。

## 构建混音

使用轨道增益、平衡、静音和独奏控制来平衡项目。混合器面板以混合导向的布局显示相同的项目状态。实时效果仍然可调整；破坏性或渲染操作创建可撤销的项目更改，只要历史记录可用。

使用播放计量器和响度分析来检查结果。避免将计量器目标作为替代完整导出听取的方法。

### 聆听所选频率 {#listen-to-selected-frequencies}

选择要聆听的片段。在音轨菜单中选择**音轨可视化 → 频谱图**，然后打开**频谱图选项 → 选择频谱频率范围**。输入最小和最大频率并选择**选择范围**，或调整频谱图中的选择手柄。

选择**播放选项 → 播放所选频率**，或**选择 → 频谱 → 播放所选频率**。所选时间范围会以正常速度播放一次，即使此前选择了其他播放速度或循环播放也是如此。聆听滤波器作用于当前混音，并包含静音、独奏、增益和效果设置。频谱矩形标示频带和时间范围，但不会将音轨设为独奏。如果正在播放，该命令会暂停播放；再次选择即可开始频率试听。

实时频率滤波器具有平滑边缘。频带之外的频率会变轻，靠近边界的频率也可能变轻。选择**暂停**或**停止**会清除滤波器，因此下一次正常播放将使用完整频率范围。音频、选择、撤销历史和已导出的文件均不会更改。

### 减少刺耳音 {#reduce-sibilance}

选择 **效果 → 噪音去除和修复 → 去刺耳音**。将 **频率** 设置在声音刺耳部分附近，然后降低 **阈值** 直到刺耳音变软。**最大减少** 限制切割；从 6-9 dB 开始。较短的 **攻击** 可以捕捉辅音的开始，而 **释放** 控制高频恢复的速度。只有上带被减少。

### 压缩单独的频率带 {#multiband-compression}

选择 **效果 → 音量和压缩 → 多带压缩器**。两个交叉点将信号分为低、中和高三带。每个带都有自己的阈值、比率和输出增益。比率为 1 时，该带的动态保持不变。攻击和释放适用于所有三个带。交叉点具有温和的、重叠的 6 dB/八度斜率；在所有比率为 1 和带增益为 0 dB 时，原始信号保持不变地通过。

这两种效果链接其通道以保持立体声平衡，还可在轨道和母带效果架中提供。架设置与项目一起保存，并在播放期间可调整。**应用到选择** 会将效果渲染到选定的音频并支持 **撤销**。时间线自动化不适用于这两种效果。

### 使用 LADSPA 效果和 Vamp 分析器 {#native-audio-plugins}

桌面应用只有在你于**效果 → 插件管理器**中允许某种格式及其文件夹后，才会扫描第三方插件。扫描不会自动进行。使用前请逐一允许发现的安装包，并且只安装你信任的插件：原生插件会运行可执行代码，即使 Soundscaper 将它们托管在受监督的辅助进程中。

Linux 提供 LADSPA 效果。请先在插件管理器中启用，然后从**效果 → 音频插件**打开。由于 LADSPA 格式没有厂商界面，Soundscaper 会根据 LADSPA 接口端口生成控件。这些控件值以及效果的启用或旁通状态都会随项目保存。

Vamp 插件用于分析音频，不会更改音频。启用 Vamp 插件后，选择一个音频轨道即可分析该轨道；若未选择音频轨道，则分析主混音。时间选区会限制分析范围；否则 Soundscaper 会分析整个项目。选择**分析 → Vamp 插件**，选择分析器输出及其设置，然后运行。只有完整分析成功后，Soundscaper 才会将返回的时间戳添加为新的标签轨道，因此取消操作或更改项目不会留下不完整的标签。

## 导出

选择 **文件 → 导出音频** 进行混合交付，或选择 **导出选定音频** 仅渲染选定部分。Soundscaper 还可导出干声和标签。

### 将剪辑导出为单独文件 {#export-clips}

选择**文件 → 导出音频**，并将**输出**设为**单个剪辑（按剪辑拆分）**。选择音频格式并按**导出**，即可下载一个压缩包，其中项目音轨上的每个音频剪辑各对应一个文件。每个文件从剪辑可听见的起点开始，到可听见的终点结束；不会补齐到项目时间线长度，也不会添加效果尾音。剪切、剪辑增益、淡入淡出以及速度和音高调整都会保留。相互重叠的剪辑仍分别导出。

文件使用带编号前缀的剪辑名称。不支持的文件名字符会被替换，编号可区分重名剪辑。会包含音轨效果；主效果、静音和独奏不会影响此导出。单独导出可编辑剪辑前，请先解冻已冻结的音轨。

压缩格式使用 FFmpeg 运行时。确切的格式和条件可用性列在[生成的格式参考](/reference/)中。

### 嵌入章节标签 {#embedded-chapters}

在浏览器编辑器中，选择**文件 → 导出音频**，选择**MP3**或**AAC / M4A**，然后在**音频选项**中启用**将标签嵌入为章节**。此选项默认关闭，会将标签标题和时间加入一个混音文件。请在导出前添加标签；分轨、按章节拆分和母带处理序列不提供此选项。

仅包含与交付范围相交的标签。导出所选内容时，章节时间会移动到生成文件的开头。MP3 会保留区域标签的结束时间；点标签会在下一章节或文件结尾处结束。M4A 会保存章节起点，每章持续到下一起点或文件结尾。M4A 最多支持 255 个章节，每个标题最多 255 个 UTF-8 字节。播放器是否显示嵌入章节取决于播放器本身。

在交付或删除源材料之前，请在另一个应用程序中播放导出的文件。
