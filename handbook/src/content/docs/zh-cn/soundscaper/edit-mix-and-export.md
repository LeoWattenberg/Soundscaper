## 排列剪辑

在选择编辑命令之前，选择剪辑或时间范围。分割在播放头处创建一个编辑边界。保留间隙和涟漪变体确定后续材料是否保持原位或移动以关闭删除区域。

使用轨道文件夹、剪辑组和项目二进制文件来整理大型项目。

### 调整剪辑淡入淡出 {#clip-fades}

选择音频剪辑以显示其波形顶部的两个小三角形，直接位于剪辑标题下方。
将左三角形向内拖动以创建淡入效果，或将右三角形向内拖动以创建淡出效果。波形在拖动时发生变化，淡入淡出曲线以上的区域变暗。三角形跟随淡入淡出边界；将其中一个拖回其角落会删除该淡入淡出效果。即使选择了多个剪辑，也只有您拖动的剪辑会被更改。

当您取消选择剪辑时，句柄会消失，但淡入淡出的波形和着色保持不变。这些淡入淡出效果保留原始音频，并在保存和重新打开项目后仍然可调整。释放以提交淡入淡出效果，或在拖动时按 **Esc** 键以取消。**撤销** 操作会逆转一次完整的拖动。播放和导出使用已提交的淡入淡出设置。

在选择的剪辑处于焦点时，按 **Tab** 键访问其淡入淡出句柄。方向键将持续时间调整为 10 毫秒，或在 **Shift** 键下调整为 100 毫秒。**Home** 键删除淡入淡出效果；**End** 键将其扩展到整个剪辑。对于数字输入，请选择 **编辑 → 音频剪辑 → 剪辑属性** 并使用 **淡入淡出**。

## 构建混音

使用轨道增益、平衡、静音和独奏控制来平衡项目。混合器面板以混合导向的布局显示相同的项目状态。实时效果仍然可调整；破坏性或渲染操作创建可撤销的项目更改，只要历史记录可用。

使用播放计量器和响度分析来检查结果。避免将计量器目标作为替代完整导出听取的方法。

### 减少刺耳音 {#reduce-sibilance}

选择 **效果 → 噪音去除和修复 → 去刺耳音**。将 **频率** 设置在声音刺耳部分附近，然后降低 **阈值** 直到刺耳音变软。**最大减少** 限制切割；从 6-9 dB 开始。较短的 **攻击** 可以捕捉辅音的开始，而 **释放** 控制高频恢复的速度。只有上带被减少。

### 压缩单独的频率带 {#multiband-compression}

选择 **效果 → 音量和压缩 → 多带压缩器**。两个交叉点将信号分为低、中和高三带。每个带都有自己的阈值、比率和输出增益。比率为 1 时，该带的动态保持不变。攻击和释放适用于所有三个带。交叉点具有温和的、重叠的 6 dB/八度斜率；在所有比率为 1 和带增益为 0 dB 时，原始信号保持不变地通过。

这两种效果链接其通道以保持立体声平衡，还可在轨道和母带效果架中提供。架设置与项目一起保存，并在播放期间可调整。**应用到选择** 会将效果渲染到选定的音频并支持 **撤销**。时间线自动化不适用于这两种效果。

### 使用 LADSPA 效果和 Vamp 分析器 {#native-audio-plugins}

桌面应用只有在你于**效果 → 插件管理器**中允许某种格式及其文件夹后，才会扫描第三方插件。扫描不会自动进行。使用前请逐一允许发现的安装包，并且只安装你信任的插件：原生插件会运行可执行代码，即使 Soundscaper 将它们托管在受监督的辅助进程中。

Linux 提供 LADSPA 效果。请先在插件管理器中启用，然后从**效果 → 音频插件**打开。由于 LADSPA 格式没有厂商界面，Soundscaper 会根据 LADSPA 接口端口生成控件。这些控件值以及效果的启用或旁通状态都会随项目保存。

Vamp 插件用于分析音频，不会更改音频。启用 Vamp 插件后，选择一个音频轨道即可分析该轨道；若未选择音频轨道，则分析主混音。时间选区会限制分析范围；否则 Soundscaper 会分析整个项目。选择**分析 → Vamp 插件**，选择分析器输出及其设置，然后运行。只有完整分析成功后，Soundscaper 才会将返回的时间戳添加为新的标签轨道，因此取消操作或更改项目不会留下不完整的标签。

## 导出

选择 **文件 → 导出音频** 进行混合交付，或选择 **导出选定音频** 仅渲染选定部分。Soundscaper 还可导出干声和标签。

压缩格式使用 FFmpeg 运行时。确切的格式和条件可用性列在[生成的格式参考](/reference/)中。

在交付或删除源材料之前，请在另一个应用程序中播放导出的文件。

对于图片工作——组合序列、视频效果和 MP4 或 WebM 交付——请将项目交给 [Framescaper](/framescaper/) 并查看[导出视频](/framescaper/video-export/)。
