两版软件都本地处理项目。它们的存储和文件访问方式不同。

## 网络编辑器

浏览器版将项目、录音和导入媒体保存在原生的私有浏览器存储中。它不会将项目上传到Soundscaper账户，也不需要账户。

当你想要立即访问而不安装应用时，使用网络编辑器。请记住，浏览器存储受浏览器配额和驱逐规则的限制。清除站点数据会删除本地项目库。

## 桌面预览

打包的桌面预览在桌面应用程序内部保存自动保存的本机库。它们捆绑了编辑运行时和发布的翻译，以便离线编辑。

桌面包未签名。macOS仅对其加载程序所需的电子身份自由广告封装其二进制文件；该密封不做任何发布商或信任声明。因此，Windows SmartScreen或macOS Gatekeeper可能会为预览版和稳定版包显示未知开发者的警告。

打开`.aup4`文件会将独立项目导入到桌面库中。后续编辑不会重写打开的文件。**保存**更新库副本；**另存为**创建一个新的Audacity交换文件。

## 手机和平板电脑

网络编辑器在每个屏幕上都保持其桌面布局，但在宽度小于900px（一部手机，或竖向持有的平板电脑）时，它将工具栏折叠到抽屉中，以便时间线保留空间：

- **菜单**按钮位于左上角，打开一个抽屉，包含完整的应用程序菜单、项目选项卡、操作栏和工具工具栏。播放、停止、录音和搜索保持在栏中。选择命令会关闭抽屉。
- 轨道标题从时间线左上角的**轨道标题**手柄或**视图 › 轨道标题**滑入车道上，或通过点击车道或按Esc键再次收起。
- 窄屏上，编辑器上方的介绍默认折叠；**显示介绍**可将其恢复。

**编辑 › 首选项 › 外观 › 布局**可以在自动、紧凑和桌面之间切换，以便在桌面上的小窗口可以保留桌面工具栏，而在宽平板电脑上可以选择使用抽屉。

## 项目不会自动移动

浏览器和桌面库是分开的。故意移动项目：

- 使用Scape项目文件 — `.sscape`来自Soundscaper，`.fscape`来自Framescaper — 用于完整项目。
- 使用AUP4时，您需要与Audacity的音频交换。
- 导出渲染的音频或视频作为耐用的播放副本。

在删除浏览器站点数据或桌面应用程序数据之前，请参阅[项目文件](/projects-and-data/project-files/)。
