声音造景师和画面造景师共享一个项目格式，并在网络上使用相同的本地项目库。根据任务选择合适的编辑器，而不是创建项目的副本。

## 选择声音造景师用于音频

声音造景师是完整的音频工作站。使用它来：

- 录制一个或多个输入源。
- 编辑、排列、混音和分析音频。
- 应用音频效果和生成器。
- 处理标签、光谱选择、宏命令和母带工具。
- 导出音频、音轨、项目文件或兼容的Audacity交换文件。

[开始一个声音造景师项目](/tutorials/your-first-project/)

## 选择画面造景师用于视频

画面造景师将工作区专注于图像编辑。使用它来：

- 导入视频及其关联的音频。
- 排列剪辑、嵌套序列和多摄像机材料。
- 调整视频效果、几何形状和合成。
- 交付MP4或WebM视频。

[开始一个画面造景师项目](/framescaper/first-project/)

## 在两者之间切换

在`soundscaper.org`上，这两个产品使用相同的源和本地项目库。使用**文件 → 在画面造景师中编辑**或**文件 → 在声音造景师中编辑**，当命令可用时。交接会保留项目，而不是复制其媒体。

一些功能有意只出现在一个产品中。特别是，声音造景师拥有录音和音频制作工具，而画面造景师拥有完整的视频效果和合成工作区。
