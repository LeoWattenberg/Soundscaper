## 创建并添加图层 {#create-and-add-a-layer}

1. 选择**文件 → 新建合成**，输入标题、尺寸、帧率和以帧为单位的时长。
2. 选择**图层 → 新建文本**或**图层 → 新建纯色**。项目包含多个合成时，
   请选择目标合成。
3. 打开**图层 → 文本与外观**，编辑现有文本图层或形状的填充与描边。
   此处导入的字体会随项目保留。

图像、视频或音频源请使用**文件 → 导入媒体**。超过当前解码器或内存
限制的导入会被拒绝并说明原因；原始源文件保持不变。

## 制作动画与预览 {#animate-and-preview}

打开**图层 → 属性与关键帧**，选择图层属性并在精确帧位置添加关键帧。
曲线控件改变插值；空间编辑改变位置路径。**视图 → 时间线**打开图层
时间设置、排序、分组和工作区控件。

打开**视图 → 合成画布**，选择和移动静态 2D 图层。方块用于缩放，圆形
用于绕设定的锚点旋转。每次完成的拖动是一条撤销记录；Escape 取消拖动。
动画和表达式驱动的变换仍在属性与关键帧中编辑。

打开**视图 → 合成预览**，定位或播放合成。预览使用保留的源媒体。不受
支持或无效的场景设置会产生错误，而不会显示替代图像。关闭预览可释放
其当前使用的渲染资源。

## 保存便携副本 {#save-a-portable-copy}

选择**文件 → 保存**发布当前修订，然后选择**文件 → 保存副本**下载
`.mscape` 归档。归档包含项目及重新打开所需的原始媒体。可在其他设备
或全新的浏览器库中使用**文件 → 打开**打开它。

## 渲染 {#render}

选择**文件 → 渲染**。选择合成、输出格式和帧范围。结束帧不包含在内：
第 0 到 29 帧使用 `0` 到 `30` 的范围。分数工作区选择其中包含的整数
采样时间；没有输出采样的工作区必须在渲染前修改。

需要 alpha 时，请使用**透明 PNG 序列 (.tar)**。解压 TAR 归档，即可获得
普通 PNG 图像和时间元数据。MP4 和 WebM 使用对话框中选择的背景颜色。
渲染会锁定已提交修订，因此后续编辑不会改变正在进行的输出。关闭渲染
对话框后，任务继续运行。**文件 → 渲染队列**显示进度、取消、重试已提交
修订和已完成的下载。关闭编辑器会取消未完成的任务。
