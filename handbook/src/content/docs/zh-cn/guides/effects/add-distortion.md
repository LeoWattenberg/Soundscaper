失真会剪切或弯曲波形，使其获得谐波。少量的柔和失真可以使贝斯或合成器变得温暖；大量的失真可以把吉他变成一面墙。类型选择曲线形状；阈值设置信号达到的程度。

:::note[来自Audacity？]
这是Audacity的**效果 → 失真**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要失真的声音。文件会以剪辑的形式落在自己的轨道上。
3. 选择**选择 → 全部选择**。
4. 选择**效果 → 失真和调制 → 失真**。在**失真**对话框中，选择**柔和失真**作为**失真类型**，并将**阈值**设置为`-12`，然后按**应用到选择**。柔和失真会使峰值变圆而不是截断它们。较低的阈值会使更多的信号进入曲线。
5. 按**播放**听取，然后按**停止**。
   *您应该会看到：* 声音变得更粗糙，其峰值变圆。

## 提示

- 如果结果在波形中偏离中心，请开启**DC阻塞**。
- 失真会增加音量。之后进行归一化，如果峰值达到顶部。
