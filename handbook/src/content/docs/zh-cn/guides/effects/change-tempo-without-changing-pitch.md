## 本指南的用途 {#what-this-guide-is-for}

将一段音频放慢以学习它，或将语音解说压缩到可用的时间内，曾经意味着音高会随速度变化。**改变速度**效果保持音高不变，只改变材料播放的速度。

:::note[来自Audacity？]
这是Audacity中的**效果 → 音高和速度 → 改变速度**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择要加快或放慢的音频文件。文件会以剪辑的形式添加到单独的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 音高和速度 → 改变速度**。在**改变速度**对话框中，将**百分比变化**设置为`10`，然后按**应用到选择**。正值会加快选择区域的速度；10%的增量会使音频缩短约十分之一。负值会放慢速度。
5. 按**播放**收听，然后按**停止**。
   *您应该会看到：* 录音速度变快了，但音高保持不变。

## 提示

- 大于约30%的变化开始听起来很加工。如果结果很重要，请将大变化分成两个小步骤应用。
- 剪辑会变短或变长，因此轨道上其后面的任何内容都会移动。
