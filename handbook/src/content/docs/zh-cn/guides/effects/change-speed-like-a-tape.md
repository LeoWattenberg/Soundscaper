有时候，你想要的就是复古效果：放慢录音，音调会降低，加快速度，音调会升高，就像唱片播放速度不对一样。改变速度和音调正是这样做，并且因为它不需要分离音调和时间，所以它是最干净的速度效果。

:::note[来自Audacity？]
这是Audacity的**效果 → 音调和速度 → 改变速度**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要加快或放慢的录音。文件会作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 音调和速度 → 改变速度和音调**。在**改变速度和音调**对话框中，设置**速度变化**为`25`，然后按**应用到选择**。正百分比会加快选择并提高其音调；-50会将速度减半，降低一个八度。
5. 按**播放**听听，然后按**停止**。
  *你应该会看到：* 录音变得更快、音调更高，并且比以前短。

## 提示

- 要修复以错误采样率制作的录音——以44.1 kHz为基准的材料以48 kHz播放，听起来像加快了约9％——精确的校正值为-8.16％。
- 要改变速度而不改变音调，请使用[改变速度](/guides/effects/change-tempo-without-changing-pitch/)。
