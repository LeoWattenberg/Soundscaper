## 本指南的用途 {#what-this-guide-is-for}

低通滤波器保留截止频率以下的声音，并逐渐衰减更高的频率。使用较缓的截止设置，可以减轻嘶声或柔化过亮的录音，同时保留声音的厚度。

:::note[从 Audacity 转来？]
Audacity 中对应的是 **Effect → EQ and Filters → Low-Pass Filter**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要柔化高频的录音。录音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 均衡器和滤波器 → 低通滤波器**。在 **低通滤波器** 对话框中，将 **截止频率** 设为 `5000`，将 **12 dB/倍频程** 设为 **衰减斜率**，然后点击 **应用到选区**。5 kHz 截止会稍微削弱顶部频段；每倍频程 12 dB 的斜率较为平缓。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 录音的高频听起来稍微柔和了一些。

## 提示

- 降低截止频率可以进一步减弱明亮感，但要留意镲片和辅音是否变得沉闷。
- 如果需要更明显地限制截止频率以上的声音，请选择更陡的 **衰减斜率**。
