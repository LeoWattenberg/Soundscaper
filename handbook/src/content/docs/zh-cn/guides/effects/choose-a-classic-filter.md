## 本指南的用途 {#what-this-guide-is-for}

Classic Filters 提供 Butterworth 和 Chebyshev 设计，可明确设置滤波器阶数和截止频率。Butterworth 低通滤波器的通带平滑，适合用于降低高频噪声。

:::note[从 Audacity 转来？]
Audacity 3.6.2 及更高版本中的对应命令是 **Effect → Legacy → Classic Filters (Audacity 3.6.2 and later)**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要降低高频的录音。录音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 旧版效果器 → 经典滤波器**。在 **经典滤波器** 对话框中，将 **巴特沃斯** 设为 **滤波器族**、**低通** 设为 **滤波器类型**，将 **阶数** 设为 `4`、**截止频率** 设为 `5000`，然后点击 **应用到选区**。Butterworth 保持通带平坦；四阶滤波器的衰减比一阶更陡。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 截止频率以上的高频降低，低频仍在通带内。

## 提示

- 提高 **阶数** 可以让过渡更陡；高阶滤波器可能在尖锐瞬态附近产生振铃。
- 当前 Audacity 手册将 Classic Filters 列在 Legacy effects 组中；如果列表中没有，请在 Audacity Plugin Manager 中启用。
