Audacity 的 Nyquist 插件是添加效果、生成器和分析器的微小脚本，Soundscaper 将它们打包在每个菜单下的 Nyquist 子菜单中。Tremolo 是一个很好的入门插件：它以固定的速率波动音量。

:::note[来自 Audacity？]
这是 Audacity 的 **效果 → Tremolo（Nyquist 插件）**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要尝试插件的录音。文件会以剪辑的形式落在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → Nyquist → Tremolo**。在 **Tremolo** 对话框中，将 **频率（Hz）** 设置为 `6`，然后按 **应用**。每秒六个波动是经典的放大器震颤效果。Nyquist 对话框使用 **应用** 而不是 **应用到选择**。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 录音的音量会脉冲。

## 提示

- 生成和分析菜单有它们自己的 Nyquist 子菜单，包含 Pluck 和 Beat Finder 等插件。
- **工具 → Nyquist 提示** 运行您输入的脚本。
