## 本指南的用途 {#what-this-guide-is-for}

Audacity 的 Nyquist 插件是用于添加效果、生成器和分析器的小型脚本。Soundscaper 将需要对所选内容进行处理的内置脚本保留在 Nyquist 子菜单中。可调淡入淡出可塑造录音的淡入或淡出。

:::note[来自 Audacity？]
这是 Audacity 的 **效果 → Adjustable Fade（Nyquist 插件）**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入**，并选择要尝试插件的录音。它会以片段形式出现在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → Nyquist → Adjustable Fade**。在 **Adjustable Fade** 对话框中，将 **Mid-fade Adjust (%)** 设为 `25`，然后按 **应用**。正值会让淡变曲线更圆滑。Nyquist 对话框使用 **应用** 而不是 **应用到选择**。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 录音会淡入。

## 提示

- 生成和分析菜单有它们自己的 Nyquist 子菜单，包含 Pluck 和 Beat Finder 等插件。
- **工具 → Nyquist 提示** 运行您输入的脚本。
- 延迟、高通和低通滤波器、噪声门限、缺口滤波器、搁架滤波器、颤音和声码器在效果菜单相应类别中有常规效果，并可在[实时效果架](/guides/effects/add-a-realtime-effect-to-a-track/)中运行。
