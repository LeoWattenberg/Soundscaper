将伴奏音轨转调到歌手的音调，或微调略走音的乐器，是一种必须保持长度不变的音高变化。Change Pitch 将选择的音段向上或向下移动整个半音，同时保持时间不变。

:::note[来自 Audacity？]
这是 Audacity 中的 **效果 → 音高和速度 → 改变音高**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要转调的录音。文件将作为片段落在单独的音轨上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → 音高和速度 → 改变音高**。在 **改变音高** 对话框中，将 **半音** 设置为 `2`，然后按 **应用到选择**。两个半音向上就是一个全音。负值向下调整。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 录音的音调更高，长度与之前完全相同。

## 提示

- **保持共振** 使声音在转调后仍听起来是同一个人；对于乐器，如果结果听起来像鼻音，请关闭此选项。
- 要同时改变音高和速度，就像磁带那样，请使用同一子菜单中的 **改变速度和音高**。
