每个剧集都接受相同的处理：归一化，淡出结尾。一个宏记录了这一序列，并在你要求时运行它，使用你选择的设置，因此一个十步操作变成了一个命令。Audacity 3 有一个宏管理器来完成这项工作；Audacity 4 尚未恢复宏功能。

:::note[来自 Audacity？]
这是 Audacity 的 **工具 → 宏 → 管理宏和应用宏（Audacity 3；Audacity 4 没有宏）**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择一个要处理的录音。文件作为片段落在自己的轨道上。
3. 选择 **选择 → 全选**。宏会作用于选择的内容，就像每个效果各自作用于其目标一样。
4. 选择 **工具 → 宏管理器**，并按 **新建宏**。输入 `Episode finish` 作为 **宏名称**。按 **添加效果**，选择 **归一化** 和 **淡出**，每次按一下 **添加效果**。按 **运行宏**；对话框会报告宏已应用。按 **关闭**。这里的每个步骤都保持默认设置；在运行前，按一下步骤的 **选择效果** 按钮以更改它们。
   *你应该看到：* 录音已被归一化，并在结尾淡出至静音。
5. 按 **播放** 收听，然后按 **停止**。

## 提示

- 宏与编辑器一起保存，因此下一个录音可以在 **工具 → 宏管理器** 下找到它。
- **导出宏** 将链写为 Audacity 宏文本文件，**导入宏** 可以读取一个，因此操作可以在这两个程序之间移动。
