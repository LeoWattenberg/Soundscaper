低音和高音是来自高保真放大器的音调控制：一个旋钮用于低端，一个旋钮用于高端，每个旋钮都按分贝设置。这是快速使薄弱的声音变暖或为沉闷的录音增添空气感而不需要学习完整均衡器的最快方法。

:::note[来自Audacity？]
这是Audacity的**效果 → 等化器和滤波器 → 低音和高音**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择需要变暖或增亮的音频录音。文件将作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 等化器和滤波器 → 低音和高音**。在**低音和高音**对话框中，将**低音**设置为`4`，将**高音**设置为`2`，然后按**应用到选择**。小幅度增强效果显著。4分贝的低音可以明显听到；超过约8分贝开始出现轰鸣声。
5. 按**播放**听取，然后按**停止**。
  *您应该会看到：* 录音在底部更饱满，顶部稍微明亮一些。

## 提示

- 增强会增加音量。如果波形之后触及顶部，请在同一个对话框中降低**音量**或进行归一化。
- 对于对特定频率的精确控制，请使用同一子菜单中的**滤波曲线等化器**或**图形等化器**。
