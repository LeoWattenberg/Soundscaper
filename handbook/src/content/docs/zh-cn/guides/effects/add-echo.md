Echo 会在延迟后再次播放选定内容，然后再次播放，每次重复的音量都比上一次小。这是经典的人声回声效果或在喊叫时峡谷回声效果。

:::note[来自 Audacity？]
这是 Audacity 的 **效果 → 延迟和混响 → Echo**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要回声的音频。文件会以剪辑的形式落在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → 延迟和混响 → Echo**。在 **Echo** 对话框中，将 **衰减因子** 设置为 `0.4`，然后按 **应用到选定内容**。每次重复的音量是上一次的 0.4 倍，因此回声会在重复几次后逐渐消失。**延迟时间** 设置它们之间的间隙。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 声音后面是逐渐减弱的重复声音。

## 提示

- 在剪辑后面添加一两秒的静音 (**生成 → 静音**)，以便最后一个重复有足够的空间播放。
- 对于房间效果而不是明显的重复，请使用 [Reverb](/guides/effects/add-reverb/)。
