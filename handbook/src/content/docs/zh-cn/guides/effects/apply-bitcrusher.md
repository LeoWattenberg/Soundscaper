## 本指南的用途 {#what-this-guide-is-for}

Bitcrusher 会有意减少表示声音的细节，增加颗粒感和数字边缘。适合用于过于精致的合成器、鼓声或短句人声。

:::note[从 Audacity 转来？]
Audacity 当前效果列表中**没有直接内置对应项**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要粗化的声音。声音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 失真与调制 → 比特粉碎**。在 **比特粉碎** 对话框中，将 **位深度** 设为 `6`、**采样率降低** 设为 `4`，然后点击 **应用到选区**。更少的位数会让振幅阶梯更明显；降低采样率会减少时间细节。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 声音带有粗糙、阶梯状的数字边缘。

## 提示

- 一次只调整一个控件，以分辨粗糙感来自振幅阶梯还是采样细节减少。
- 如果完整效果过于刺耳，请降低 **混合**，将失真声音与原始声音混合。
