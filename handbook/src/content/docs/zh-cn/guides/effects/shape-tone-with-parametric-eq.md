## 本指南的用途 {#what-this-guide-is-for}

Parametric EQ 为每个频带提供频率、增益和 Q 控制，因此可以针对共振音进行削减，或稍微提升清晰度。在图表中选择频带，再调整频率和 Q，以确定变化的位置和宽度。

:::note[从 Audacity 转来？]
Audacity 的 **Spectral Edit Parametric EQ, a spectrogram-only feature with no equivalent to Soundscaper’s track-wide effect** 与此功能不同。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要调整音色的录音。录音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 均衡器和滤波器 → 参量均衡器**。在 **参量均衡器** 对话框中，将 **频率（Hz）** 设为 `500`、**增益（dB）** 设为 `-3`、**Q** 设为 `1.2`，然后点击 **应用到选区**。选定频带会对 500 Hz 附近进行轻微、集中的削减。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 500 Hz 附近有针对性的削减，其他频带保持不变。

## 提示

- 频带越窄，**Q** 越高。先小幅调整增益，问题仍存在时再增加幅度。
- Soundscaper 的全音轨 Parametric EQ 不同于 Audacity 仅用于频谱图的 Spectral Edit Parametric EQ。
