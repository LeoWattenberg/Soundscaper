## 本指南的用途 {#what-this-guide-is-for}

Vocoder 用人声变化的形状控制另一种声音，让语音听起来更有音乐感或像机器人。在 Soundscaper 中，将它应用于单声道人声选区，并调整载波电平。

:::note[从 Audacity 转来？]
Audacity 4.0.1 中的对应命令是 **Effect → Distortion and Modulation → Vocoder**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取用于控制效果的单声道人声或其他声音。声音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 失真与调制 → 声码器**。在 **声码器** 对话框中，将 **声码器频带** 设为 `24`，并将 **经声码器处理的音频** 设为 **输出**，然后点击 **应用到选区**。频带数决定人声形状的划分精度；单声道选区中的内置载波由 **音频载波电平** 控制。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 人声具有合成、和声般的特征。

## 提示

- 稳定的音高载波听起来更有音乐感；白噪声或雷达脉冲会让人声更机械。
- Audacity 的立体声流程要求先将人声放在左声道、载波放在右声道，再应用 Vocoder。
