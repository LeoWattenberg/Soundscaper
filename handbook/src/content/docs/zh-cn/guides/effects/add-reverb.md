在处理过的房间中近距离放置麦克风会产生一种干净、亲密的声音，单独听起来可能显得没有生气。混响添加了房间会产生的数千次微小反射，从一个小隔间到一个大厅。

:::note[来自Audacity？]
这是Audacity的**效果 → 延迟和混响 → 混响**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择听起来太干的录音。该文件会作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 延迟和混响 → 混响**。在**混响**对话框中，将**房间大小**设置为`40`，将**混响度**设置为`60`，然后按**应用到选择**。房间大小设置空间的大小；混响度设置回声的持续时间。对于语音，将两者都设置得适中。
5. 按**播放**听听，然后按**停止**。
   *你应该会看到：* 录音位于空间中，而不是直接在耳边。

## 提示

- 如果效果掩盖了原始声音，请降低**湿度增益**或提高**干度增益**。
- 混响很少适用于整个混音。将它应用于需要的部分，并保持其他部分干净。
