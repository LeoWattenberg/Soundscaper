## 本指南的用途 {#what-this-guide-is-for}

Tremolo 按重复的模式升降音量，产生有节奏的起伏。静态声音需要动感时，可用于延音乐器、铺底音色或人声。

:::note[从 Audacity 转来？]
Audacity 4.0.1 中的对应命令是 **Effect → Distortion and Modulation → Tremolo**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要添加脉动的延音。声音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 失真与调制 → 震音**。在 **震音** 对话框中，将 **深度** 设为 `60`、**频率** 设为 `4`，然后点击 **应用到选区**。Depth 控制每个周期的音量下降幅度；Frequency 控制每秒脉动次数。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 选定声音规律地增强和减弱。

## 提示

- 降低 **频率** 可以产生缓慢起伏，提高它会让脉动更快、更明显。
- 如果周期中的安静部分也需要保持可听，请适度设置 **深度**。
