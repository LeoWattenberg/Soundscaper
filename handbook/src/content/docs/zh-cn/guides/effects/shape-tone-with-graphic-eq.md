## 本指南的用途 {#what-this-guide-is-for}

Graphic EQ 为每个三分之一倍频程频带设置一个滑块。一起移动相邻滑块可以进行宽范围调整；移动单个滑块则能更精细地改变音色。

:::note[从 Audacity 转来？]
Audacity 中对应的是 **Effect → EQ and Filters → Graphic EQ**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要调整音色的录音。录音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 均衡器和滤波器 → 图形均衡器**。在 **图形均衡器** 对话框中，将 **1000 Hz** 设为 `4`，然后点击 **应用到选区**。轻微提升 1 kHz 可以增加清晰度，而不会改变整个频谱。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 1 kHz 附近的清晰度略有提升。

## 提示

- 先尝试小幅提升或削减；提升多个频带也会提高整体电平，可能造成削波。
- 要在频率之间绘制平滑的自定义曲线，请使用 [Filter Curve EQ](/guides/effects/draw-a-filter-curve/)。
