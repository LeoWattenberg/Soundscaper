## 本指南的用途 {#what-this-guide-is-for}

效果菜单中的效果会永久性地改变音频。实时效果则放置在轨道上：它在播放和导出时运行，其设置可以随时更改，原始音频不会被触及。对于想要不断调整的混响、均衡和压缩，这是正确的选择。

:::note[来自Audacity？]
这是Audacity的**效果 → 添加实时效果**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择要添加效果的录音。它会作为片段出现在自己的轨道上。
3. 按下轨道头中的**效果**以打开效果面板，在轨道架中按下**效果**并选择**混响**。其设置窗口打开；按下**关闭**即可完成。轨道架现在列出混响。其设置窗口随时可从架中访问以进行调整。
4. 按下**播放**进行聆听，然后按下**停止**。
   *你应该看到：*轨道通过混响播放。

## 提示

- 在架中添加多个效果并拖动以更改其顺序；每个效果都会输送到下一个。
- 主架位于效果面板的底部，处理整个混音。
- 效果架还提供延迟、高通和低通滤波器、噪声门限、缺口滤波器、搁架滤波器、颤音和声码器。它们共用基本的选择与效果架控件。
- [音频效果参考](/reference/generated/audio-effects/)说明延迟、噪声门限和声码器的行为，包括声码器在播放时的归一化处理。
