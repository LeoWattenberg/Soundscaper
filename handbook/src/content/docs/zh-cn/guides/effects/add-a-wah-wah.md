瓦音踏板可以将共振滤波器在频谱中上下扫动；瓦音效果会以你设定的速度为你完成扫动。它适用于吉他、键盘以及任何具有持续共鸣的乐器。

:::note[来自Audacity？]
这是Audacity的**效果 → 瓦音**。以下名称是Soundscaper自己的，有时会与Audacity不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要添加瓦音效果的录音。文件将作为片段落在单独的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 失真和调制 → 瓦音**。在**瓦音**对话框中，将**LFO频率**设置为`2`，将**深度**设置为`80`，然后按**应用到选择**。LFO频率是指每秒进行的扫动次数；深度是指滤波器移动的距离。
5. 按**播放**听取效果，然后按**停止**。
   *你应该会看到：* 录音以扫动的、类似元音的音调颤动。

## 提示

- **共振**可以使滤波器的峰值更尖锐；高值会尖叫。
- 同一子菜单中的**相位器**提供更柔和、旋转的运动。
