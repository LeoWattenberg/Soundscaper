淡入淡出是避免剪辑开始时点击或结束时突然停止的最简单方法。淡入逐渐将选定部分从静音状态提升到全量；淡出逐渐将其降低。选定部分的长度就是淡入淡出的持续时间。

:::note[来自Audacity？]
这是Audacity的**效果 → 淡入淡出 → 淡入和淡出**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择开始或结束时音量过大的录音。文件会以剪辑的形式其自身轨道上。
3. 在剪辑上方规则上拖动，以选择您希望淡入持续的起始部分。
4. 选择**效果 → 淡入淡出 → 淡入**。效果会立即应用于选定部分。
5. 在剪辑上方规则上拖动，以选择相同的结束部分。
6. 选择**效果 → 淡入淡出 → 淡出**。效果会立即应用于选定部分。
7. 按**播放**收听，然后按**停止**。
  *您应该会看到：* 录音会逐渐增大并逐渐减弱，而不是硬启动或硬停止。

## 提示

- 淡入淡出是线性的。如果希望结尾处淡出更快，请选择更短的范围。
- 淡入淡出是编辑，因此**编辑 → 撤销**可以像其他操作一样撤销它们。
