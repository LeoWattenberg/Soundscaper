播客和流媒体平台使用 LUFS 来测量音量，它关注的是节目的听感音量，而不是音峰的高度。音量归一化会测量整个选定片段并将其调整到目标音量，这样你发布的每期节目都会处于同一音量水平。

:::note[来自 Audacity？]
这是 Audacity 的 **效果 → 音量和压缩 → 音量归一化**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择安静的录音。文件会作为片段落在单独的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → 音量和压缩 → 音量归一化**。在 **音量归一化** 对话框中，将 **目标音量** 设置为 `-16`，然后按 **应用到选定片段**。对于立体声播客，-16 LUFS 是常见的目标；对于单声道，通常使用 -19 LUFS。请查阅您平台的指南。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 录音以舒适、一致的音量播放。

## 提示

- 音量归一化可能会将非常动态材料的音峰推到满量以上。其后紧跟限幅器或峰值归一化到 -1 dB，如果波形触及顶部。
- 在编辑和其他效果完成后，对最终混音运行音量归一化，以便测量反映听众将听到的内容。
