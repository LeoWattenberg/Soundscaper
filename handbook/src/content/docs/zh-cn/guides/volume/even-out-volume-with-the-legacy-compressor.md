Audacity 3 提供了两种压缩器：现代的压缩器具有膝部、预览和实时计量，以及原始的简单压缩器，称为“传统压缩器”。传统设计具有一个噪声地板，当音量低于该水平时，压缩器停止工作，因此不会在间隙中放大背景噪音，并且默认情况下将结果提升到 0 dB。Audacity 4 删除了传统压缩器；Soundscaper 保留了其传统压缩器，以适应习惯了这种效果的项目和听觉。

:::note[来自 Audacity？]
这是 Audacity 的 **效果 → 音量和压缩 → 传统压缩器（Audacity 3；Audacity 4 只有新的压缩器）**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要均衡的音频记录。文件会以片段的形式放置在单独的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → 传统效果 → 传统压缩器**。在“传统压缩器”对话框中，将“阈值”设置为 `-20`，将“比率”设置为 `4`，然后按“应用到选择”。任何高于 -20 dB 的音量都会按比率降低，这里为 4:1。然后，补偿增益会将整个结果提高到峰值为 0 dB。
5. 按 **播放** 收听，然后按 **停止**。
   *您应该会看到：* 响亮和安静的段落更接近，整个片段更响亮。

## 提示

- 如果压缩器放大了间隙中的嘶嘶声，请提高“噪声地板”；压缩器会忽略任何比它安静的声音。
- 对于可以在设置时听到的压缩器，请使用现代压缩器：[使用压缩器均衡音量](/guides/volume/even-out-volume-with-a-compressor/)。
