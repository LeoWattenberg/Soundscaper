限制器是一种压缩器，其比例非常高：在阈值以下，它什么都不做；在阈值以上，什么都无法通过。它是捕获导出前的一些杂散峰值或提高混音整体水平而不使峰值剪切的工具。

:::note[来自Audacity？]
这是Audacity的**效果 → 音量和压缩 → 限制器**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择带有杂散峰值的录音。该文件作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 音量和压缩 → 限制器 (Audacity)**。在**限制器 (Audacity)** 对话框中，将**阈值**设置为`-6`，然后按**应用到选择**。没有任何内容会超过-6 dB。然后，补偿目标会提高结果，使上限接近满量程。
5. 按**播放**倾听，然后按**停止**。
   *您应该会看到：* 最响的时刻被压制；其余部分保持不变。

## 提示

- 使用限制器处理峰值，使用[压缩器](/guides/volume/even-out-volume-with-a-compressor/) 实现整体均衡；它们不是同一项工作。
- 严重的限制会使一切听起来很响且平淡无奇。如果您需要超过几个分贝，那么混音本身可能太过强烈。
