使用增益过低进行的录音通常声音很小但很清晰。放大会以分贝为单位将录音中的所有内容提高相同的量，因此录音中的平衡保持不变。关闭剪切，效果不会将峰值推过满量。

:::note[来自Audacity？]
这是Audacity的**效果 → 音量和压缩 → 放大**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择安静的录音。文件会作为片段落在自己的轨道上。
3. 选择**选择 → 全部选择**。
4. 选择**效果 → 音量和压缩 → 放大**。在**放大**对话框中，将**增益**设置为`6`，然后按**应用到选择**。六分贝大约可以将音量翻倍。**允许剪切**保持关闭，因此效果不会失真峰值。
5. 按**播放**听，然后按**停止**。
   *您应该会看到：*录音明显变大，波形更高。

## 提示

- 如果结果仍然太安静，再次运行放大；增益会累积。
- 要将峰值提升到确切的水准而不是添加固定量，请使用[归一化](/guides/volume/normalize-peaks/)。
