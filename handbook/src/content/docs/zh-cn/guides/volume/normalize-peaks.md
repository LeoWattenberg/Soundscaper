归一化会测量选定段中最响的峰值，并调整音量使这个峰值恰好达到您设置的水平。这是导出文件前的常用最后一步：文件会充分利用其完整范围，而不会出现剪切。它还消除了任何直流偏移，即某些声卡添加的轻微垂直位移。

:::note[来自Audacity？]
这相当于Audacity的**效果 → 音量和压缩 → 归一化**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择安静的录音。文件会作为剪辑添加到单独的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 音量和压缩 → 归一化**。在**归一化**对话框中，将**峰值幅度**设置为`-3`，然后按**应用到选定段**。减小三分贝可以为后续的MP3编码留出一些余地。
5. 按**播放**收听，然后按**停止**。
   *您应该会看到：* 最响的时刻现在刚好低于满量程。

## 提示

- 归一化基于峰值，而不是录音的听感音量。两个归一化的文件仍然可能听起来非常不同；有关此操作，请参见[为播客归一化音量](/guides/volume/normalize-loudness-for-podcasts/)。
- 除非您开启**独立归一化立体声通道**，否则立体声通道会一起归一化，这可能会改变立体声图像。
