## 本指南的用途 {#what-this-guide-is-for}

您可以将一个词、一段乐句或一次补录单独拆成一个片段，而不改变录音的总时长。选中时间范围后，Split 会在选区两端进行切分。之后，您可以单独移动或处理中间的片段。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Edit → Clip → Split (Ctrl+I)**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取包含目标片段的录音。录音会作为一个片段出现在单独的音轨上。
3. 在片段上方的标尺中拖动，选中要分开的部分。选区前后都留出一些音频，确保两端边界位于片段内部。
4. 选择 **编辑 → 音频片段 → 分割**。
5. 现在项目中显示 3 个片段。
   *您应看到：* 选中的部分成为前后音频之间的独立片段。三个部分都保留在时间轴上的原始位置。

## 提示

- 如果只需切一刀，请使用[在光标位置拆分片段](/guides/editing/split-a-clip-at-the-cursor/)，而不是选择一段范围。
- 如果需要调整任一边界，选择 **编辑 → 撤销** 即可恢复原始片段。
- 如果要删除周围的音频，请[仅保留所需部分](/guides/editing/keep-only-a-selection/)。
