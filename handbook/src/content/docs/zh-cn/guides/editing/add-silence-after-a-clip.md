## 本指南的用途 {#what-this-guide-is-for}

回声和混响等效果需要空间来回荡，播客也需要在段落之间留出呼吸的空间。静音生成器在光标处插入确切长度的间隙，这比用眼睛拖动音频片段更精确。

:::note[来自Audacity？]
这与Audacity的**生成 → 静音**功能相同。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择需要之后添加间隙的录音。文件会以单个音频片段的形式添加到其自己的轨道上。
3. 点击片段末尾的波形以将光标放置在那里。静音将插入到光标处。
4. 选择**生成 → 静音**。在**静音**对话框中，将**持续时间（秒）**设置为`1`，然后按**生成**。
5. 项目现在显示2个片段。
   *你应该会看到：* 一个一秒钟的静音片段紧跟在循环之后。

## 提示

- 选择时间范围后，生成器会替换选择内容而不是将静音插入到光标处。
- 要静音已存在的音频而不是添加时间，请参阅[静音录音的一部分](/guides/cleaning-up/silence-part-of-a-recording/)。
