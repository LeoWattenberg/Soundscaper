当一个长录音包含一个好段落时，选择段落并丢弃其余部分比分段删除周围部分更快。修剪保留选择并移除其两侧的音频。

:::note[来自Audacity？]
这是Audacity的**编辑 → 特殊删除 → 修剪音频**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**并选择包含段落的录音。文件作为片段落在自己的轨道上。
3. 在片段上方规则中拖动以选择要保留的段落。其外的所有内容即将被删除。
4. 选择**编辑 → 特殊删除 → 修剪选择外部的音频**。
5. 项目现在显示1个片段。
   *您应该看到：* 只有选定的段落留在轨道上。

## 提示

- 修剪后的片段保持在时间线上原来的位置。如果您希望它从零开始，请将其拖动到起始位置。
- 修剪与其他编辑一样；**编辑 → 撤销**会恢复选择外部的内容。
