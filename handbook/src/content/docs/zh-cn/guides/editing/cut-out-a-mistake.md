::最常见的编辑操作是：重新开始，咳嗽，重新录制。选择你不想保留的部分，删除它，然后让轨道上的其余部分向左移动以填补空缺。

:::注意[来自Audacity？]
这与Audacity的**选择区域，然后编辑 → 删除（或Ctrl+K）**操作相同。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择包含错误的录音文件。该文件作为单个剪辑落在自己的轨道上。
3. 在剪辑上方拖动尺子以精确选择你想要删除的部分。如果错误很短，请使用**视图 → 缩放 → 缩放**进行缩放。
4. 选择**编辑 → 剪切 → 剪切并按轨道关闭空缺**。选择的部分将被删除，之后的内容将向左移动，因此不会留下空白。
5. 项目现在显示2个剪辑。
   *你应该看到：* 两个剪辑端对端地位于选择的位置，轨道长度正好减少了选择的部分。在接合处播放以检查。

## 提示

- **剪切并留下空缺**会删除声音但保留时间，这在轨道需要与视频或其他轨道同步时是正确的。
- 对接不满意？**编辑 → 撤销**，调整选择并重试。
