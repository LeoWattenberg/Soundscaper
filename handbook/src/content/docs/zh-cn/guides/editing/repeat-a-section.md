重复一个两小节的循环，一个需要在较长的语音旁白下方运行的背景床，一个应该持续的音效：重复将选择直接复制给自己，只要你要求的次数。

:::note[来自Audacity？]
这是Audacity的**效果 → 特殊 → 重复**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择你想要重复的声音。文件会以剪辑的形式落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 特殊 → 重复**。在**重复**对话框中，设置**重复次数**为`2`，然后按**应用到选择**。两次重复会产生三个连续的副本。
5. 按**播放**听，然后按**停止**。
  *你应该会看到：* 这段乐段会不间断地播放三次。

## 提示

- 为了无缝循环，确保选择的开头和结尾在静音或零交叉点上(**选择 → 在零交叉点**)。
- 这个效果会改变剪辑的长度，所以同一轨道上的任何后续内容都会被推后。
