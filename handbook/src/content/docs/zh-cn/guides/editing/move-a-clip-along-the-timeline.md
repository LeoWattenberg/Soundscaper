片段可以自由移动。通过拖动片段名称栏可以沿着轨道滑动片段——在开头留出空隙、放在另一个片段之后，或与视频中的提示对齐。向上或向下拖动可以将片段移动到另一条轨道上。

:::note[来自Audacity？]
这与Audacity中的**时间移动工具（F5），或在Audacity 3.1及更高版本中拖动片段栏**类似。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择要移动的录音。文件将作为片段落在自己的轨道上。
3. 通过拖动片段名称栏将其移动到应开始的位置。片段会跟随指针移动；其新的开始时间会在选择栏中显示。
4. 片段现在从您放置的位置开始。
   *您应该看到：* 轨道在片段开始前保持静音。

## 提示

- 打开运输条上的快照功能，以便拖动的片段锁定到秒、拍或帧。
- 拖动片段名称栏时按住 Shift，会同时移动该轨道上的所有片段。
- 按住 Ctrl 将片段拖到另一条轨道，可以保留准确的开始时间。按住 Ctrl 和 Shift 可移动整条轨道而不改变其时间位置。
- 片段菜单还提供 **Select all clips on this track** 和 **Move to track (preserve time)**。
