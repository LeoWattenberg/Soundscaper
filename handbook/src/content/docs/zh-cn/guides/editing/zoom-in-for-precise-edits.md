:默认缩放下，整个歌曲适合屏幕上，单个单词宽几像素。缩放可以让你将光标精确地放置在节拍上或两个单词之间；缩放到选择框只会显示你正在处理的段落。

:::note[来自Audacity？]
这是Audacity的**视图 → 缩放（Ctrl+1，Ctrl+2，Ctrl+3）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**并选择你想要编辑的录音。文件会以片段的形式出现在自己的轨道上。
3. 选择**视图 → 缩放 → 缩放放大**。每一步都会使一秒钟的宽度加倍。Ctrl+1具有相同的效果。
4. 选择**视图 → 缩放 → 缩放放大**。
5. 在片段上方规则中拖动以选择你想要处理的段落。
6. 选择**视图 → 缩放 → 缩放到选择**。选择内容现在会填满时间线。
7. 选择**视图 → 缩放 → 正常缩放**。Ctrl+2会恢复默认缩放。

## 提示

- Ctrl和鼠标滚轮会在指针周围缩放，这是快速缩放到特定位置的最快方法。
- 缩放不会改变项目；它只是你的视图。
