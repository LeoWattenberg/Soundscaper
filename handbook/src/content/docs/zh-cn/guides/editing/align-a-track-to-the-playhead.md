## 本指南的用途 {#what-this-guide-is-for}

如果录音需要从某个提示点开始，凭目测拖动可能不够准确。Align start to playhead 会移动选中音轨的内容，使其起点与光标对齐，同时保留录音时长。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Tracks → Align Tracks → Align Start to Playhead**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入要放到提示点的录音。文件会作为一个片段出现在自己的音轨上。
3. 抓住片段的名称栏，将它沿时间线向后拖动。先移动片段，这样光标才能标记不同的起点。
4. 在录音应该开始的位置点击波形，将光标放在那里。
5. 选择 **音轨 → 对齐内容 → 将开头对齐到播放头**。选中音轨中最早的片段会移动到光标位置。
6. 录音现在从播放头位置开始。
   *你应该看到：* 片段从提示点开始，并保留原来的时长。

## 提示

- 对齐会移动每条选中音轨上的所有片段。若只想移动一段录音，请使用仅包含该录音的音轨。
- 选择 **音轨 → 对齐内容 → 将开头对齐到零点**，可将选中的音轨恢复到项目起点。
