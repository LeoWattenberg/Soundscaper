## 本指南的用途 {#what-this-guide-is-for}

Insert 会为复制的音频腾出空间，而不是覆盖现有声音。目标音轨上后面的音频会按复制片段的时长向右移动。您可以用它在录音中间添加重复的乐句或补充的一句话。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Edit → Copy, then Edit → Paste**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取包含要复制片段的录音。录音会作为一个片段出现在单独的音轨上。
3. 在片段上方的标尺中拖动，选中要插入到其他位置的部分。
4. 选择 **编辑 → 复制**。
5. 在目标片段中，单击波形上副本应开始的位置，将光标放在那里。单击会清除时间范围选区并设置插入点。
6. 选择 **编辑 → 粘贴 → 插入**。
7. 现在项目中显示 3 个片段。
   *您应看到：* 插入的部分位于原片段的两段音频之间。后面的部分向右移动，前面的部分保持原位。

## 提示

- Insert 会移动目标音轨上后面的音频。如果需要保持所有音轨的时间同步，**编辑 → 粘贴 → 插入并保持同步** 会在所有音轨上腾出空间。
- 选择 **编辑 → 撤销** 会移除插入内容，并将后面的音频恢复到原来的位置。
