逆转效果会将选定部分的时间顺序反转。它是一种音频设计效果——反转的钹声、预回声的渐强——偶尔也用于检查房间混响尾部是否隐藏了任何内容。

:::note[来自Audacity？]
这是Audacity的**效果 → 特殊 → 逆转**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要反转的录音。文件会以剪辑的形式将其自身轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 特殊 → 逆转**。效果会立即应用于选定部分。
5. 按下**播放**听取，然后按**停止**。
   *你应该会看到：* 录音会倒退播放。

## 提示

- 两次应用逆转效果，你就会回到起点，样本与样本完全一致。
- 反转轨道开头短小选定部分，以构建一个渐强效果，引领进入剪辑。
