就像在文本中一样，可以复制和粘贴音频。选择一段音频，复制它，将光标放在需要的位置，然后粘贴。

:::note[来自Audacity？]
这是Audacity中的**编辑 → 复制，然后编辑 → 粘贴（Ctrl+C，Ctrl+V）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择包含您要复制的段落的录音。文件会以剪辑的形式出现在自己的轨道上。
3. 在剪辑上方规则中拖动以选择要复制的段落。
4. 选择**编辑 → 复制**。
5. 单击波形图中复制内容应放置的位置以放置光标。粘贴内容会粘贴到光标处；通常粘贴到剪辑的结尾。
6. 选择**编辑 → 粘贴 → 粘贴**。
7. 项目现在显示2个剪辑。
   *您应该看到：* 复制的段落是原始剪辑后的一个新剪辑。

## 提示

- **编辑 → 粘贴 → 插入**会将后续音频推开，而不是将粘贴内容覆盖在上面。
- 剪贴板可以在项目选项卡之间工作，因此可以从一个项目复制段落到另一个项目。
