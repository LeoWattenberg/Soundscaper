## 本指南的用途 {#what-this-guide-is-for}

你可能希望为某个语句或录音片段单独调整音量、声像或效果，同时保留录音的其他部分。Split into new track 会在选区边缘进行分割，并将选中的片段移到时间线上相同位置的新音轨。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Edit → Clip → Split New**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入含有要单独移动片段的录音。文件会作为一个片段出现在自己的音轨上。
3. 在片段上方的标尺上拖动，选中要移到单独音轨的片段。
4. 选择 **编辑 → 音频片段 → 分割到新音轨**。选区会移到新音轨，前后音频仍留在原音轨。
5. 项目现在显示 3 个片段。
   *你应该看到：* 选区两侧的片段仍在原音轨上，新音轨则包含中间选中的片段。

## 提示

- 选中的片段在新音轨上仍保留原来的时间位置。
- 如果只想移动这段录音，请使用仅包含该录音的音轨。
