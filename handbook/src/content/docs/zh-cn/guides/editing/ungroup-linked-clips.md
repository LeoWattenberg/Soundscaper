## 本指南的用途 {#what-this-guide-is-for}

编组后的片段仍是独立的音频部分，但可以作为一个整体选中并移动。Ungroup 会恢复对各个片段的独立选择；它不会将这些部分拼接或渲染成一个片段。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Edit → Clip → Ungroup Clips**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入含有要拆分片段的录音。文件会作为一个片段出现在自己的音轨上。
3. 在要将片段分成两部分的位置点击波形，将光标放在那里。
4. 选择 **编辑 → 音频片段 → 分割**。
5. 点击第一部分的名称栏，然后按住 Shift 并点击第二部分的名称栏，以同时选中两部分。
6. 选择 **编辑 → 音频片段 → 编组片段**。编组后，选中的两部分可以一起移动，但音频不会合并。
7. 选择 **编辑 → 音频片段 → 取消片段编组**。取消编组后，可以再次分别选择这两部分。
8. 项目现在显示 2 个片段。
   *你应该看到：* 录音仍由两个独立片段组成，并在分割点处相接。

## 提示

- 当独立片段在移动时需要保持彼此的相对位置，编组会很有用。
- 若要将相邻部分合成一个片段，请选择 **编辑 → 音频片段 → 合并选中的片段**。
