分割并不会删除任何内容。它将一个片段变成两个相邻的片段，这样你可以将其中一部分拖动到其他地方、删除它，或者单独对其应用效果。最快的方法是使用分割工具：当它激活时，每一次点击片段都会在该点进行切割。

:::note[来自Audacity？]
这是Audacity的**编辑 → 片段边界 → 分割（Ctrl+I）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择你想要分割的录音。文件会以一个片段的形式出现在自己的轨道上。
3. 点击工具栏中的**分割工具**按钮。指针现在切割而不是选择。按**S**键从键盘切换工具。
4. 点击波形图中你想要切割的位置，以将光标放置在该点。当分割工具激活时，点击会在此处切割片段。
5. 项目现在显示2个片段。
   *你应该看到：* 两个片段现在位于原本的一个片段的位置。
6. 点击工具栏中的**分割工具**按钮。再次点击以返回到正常指针。

## 提示

- 要将播放头位置分割，选择片段并选择**编辑 → 音频片段 → 分割**；选择时间范围时，它会在范围的双方进行分割。
- 选择两个一半并选择**编辑 → 音频片段 → 合并选定片段**，以将它们再次合并成一个片段。
