## 本指南的用途 {#what-this-guide-is-for}

标记是时间线上的注释：章节的开始处、需要修正的错误、优质片段的开始处。它们不会改变音频，会随项目一起移动，并且可以导出为标签文件供其他工具使用。

:::note[来自Audacity？]
这是Audacity中的**编辑 → 标签 → 在选择区域添加标签（Ctrl+B）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择您要标记的音频文件。文件会以片段的形式添加到单独的轨道上。
3. 选择**视图 → 标记**。这会在轨道上方添加一个标记轨道。标记在没有该轨道的情况下也存在，但该轨道是您查看和编辑标记的地方。
4. 单击波形图中标记应放置的位置以将光标放置在那里。标记会放置在光标所在位置。
5. 打开标记面板（**窗口 → 标记**显示它），按**在播放头处添加标记**。按新标记处的Enter，输入`Chorus`，然后再次按Enter以命名它。
   *您应该看到：*标记显示在轨道上方以及面板列表中，并带有您输入的名称。

## 提示

- 在选定时间范围时，同一个按钮会添加一个命名区域而不是单个点。
- **文件 → 导出其他 → 导出标签**会将标记写入一个文本文件，Audacity和其他编辑器都可以读取该文件。
