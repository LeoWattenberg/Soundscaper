学习一个乐句、检查一个编辑点、尝试一个效果设置：当段落不断重复播放而无需你重新开始时，所有操作都会更快。将循环区域设置为选择区域，播放会一直停留在该区域，直到你关闭循环。

:::note[来自Audacity？]
这是Audacity的**运输 → 循环 → 将循环设置为选择**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要练习的段落录音。文件会以剪辑的形式落在单独的轨道上。
3. 在剪辑上方规则上拖动以选择要重复的段落。
4. 选择**选择 → 循环区域 → 将循环设置为选择**。
5. 项目现在显示**循环选择**按钮已点亮。
   *你应该看到：* 运输条上的循环按钮亮起，循环区域显示在规则上方。
6. 按**播放**听取，然后按**停止**。
   *你应该看到：* 播放会在选定的段落中循环。

## 提示

- 按**L**或运输条上的循环按钮以打开或关闭循环，而不会丢失区域。
- 拖动循环区域在规则中的两端以进行调整。
