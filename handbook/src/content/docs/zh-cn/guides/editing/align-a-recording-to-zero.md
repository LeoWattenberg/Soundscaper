## 本指南的用途 {#what-this-guide-is-for}

在时间线上较晚开始的录音，可以通过对齐命令移回项目开头。Align start to zero 会移动所选音轨的内容，使其中最早的片段从零开始。此流程会先将一段录音移到较晚的位置，再将其对齐回开头。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **音轨 → 对齐内容 → 将开头对齐到零点**。以下名称是 Soundscaper 自己的名称，有时可能不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空白项目便已就绪。
2. 选择 **文件 → 导入**，然后选择要对齐的录音。录音会作为独立音轨上的片段导入。
3. 抓住片段的名称栏，将它拖到时间线上较晚的位置。
4. 现在片段的起点晚于项目开头。
5. 选择 **音轨 → 对齐内容 → 将开头对齐到零点**。
6. 现在录音从时间零点开始。
   *你应该会看到：* 片段左边缘与标尺起点对齐。

## 提示

- 对齐操作会移动所选音轨的内容。若只想移动这段录音，请使用只包含它的音轨。
- **编辑 → 撤销** 会恢复之前的位置。
