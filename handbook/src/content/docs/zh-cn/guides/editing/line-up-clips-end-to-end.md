## 本指南的用途 {#what-this-guide-is-for}

单独录制的两段音频会分别落在它们自己的轨道上，都从零开始。要想一个接一个地播放，第二个音频需要移动到第一个音频的结尾处。将结尾对齐功能会为所有选中的片段按轨道顺序进行该算术运算。

:::note[来自Audacity？]
这与Audacity中的**轨道 → 对齐轨道 → 将结尾对齐**相同。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择第一个音频。文件会作为一个片段落在它自己的轨道上。
3. 选择**文件 → 导入**，并选择第二个音频。文件会作为一个片段落在它自己的轨道上。
4. 点击第一个片段的名称栏，然后按住Shift键点击第二个片段的名称栏，这样两个片段都被选中了。
5. 选择**轨道 → 对齐内容 → 将结尾对齐**。
6. 第二个片段现在从第一个片段的结尾处开始。
   *你应该看到：* 片段一个接一个地播放，没有重叠，也没有间隙。

## 提示

- **对齐在一起**执行相反的操作：它会将选定的片段移动到同一时间开始。
- 拖动片段的名称栏可手动放置；按住 Shift 会同时移动该轨道上的所有片段。
