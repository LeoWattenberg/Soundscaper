复制将选定内容直接复制到下方新轨道上，时间位置保持不变。这是并行处理的常见第一步——例如，混合一个严重压缩的副本与原始音频，创建一个只有混响的轨道，或将人声加倍。

:::note[来自Audacity？]
这是Audacity中的**编辑 → 复制（Ctrl+D）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要复制的段落的音频文件。文件将作为片段落在自己的轨道上。
3. 在片段上方规则上拖动以选择要复制的段落。
4. 选择**编辑 → 复制**。
5. 项目现在显示2个片段。
   *你应该会看到：* 一个新的轨道上包含仅选定的段落的第二个片段，与第一个片段在时间上对齐。

## 提示

- 静音其中一个轨道，以便单独听取并调整另一个轨道。
- 当你满意混合效果时，[将轨道混合下来](/guides/tracks-and-export/mix-tracks-into-one/)。
