有时你想要删除一段音频，但保留它所占的时间——比如在暂停时响起的电话声，或者需要消音的姓名。静音处理会保持剪辑的长度不变，只将选定部分变平。

:::note[来自Audacity？]
这相当于Audacity中的**编辑 → 特殊删除 → 静音音频**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择要静音处理的录音。文件将作为单个剪辑添加到其自己的轨道上。
3. 在剪辑上方规则中拖动，以选择要静音处理的确切部分。
4. 选择**编辑 → 特殊删除 → 静音音频**。
5. 项目现在显示1个剪辑。
   *你应该看到：* 波形在选择区域内变平，剪辑仍然是一个整体。

## 提示

- 静音是一个正常的编辑操作：**编辑 → 撤销**可以恢复音频。
- 要同时删除时间和声音，请参阅[从录音中剪切错误](/guides/editing/cut-out-a-mistake/)。
