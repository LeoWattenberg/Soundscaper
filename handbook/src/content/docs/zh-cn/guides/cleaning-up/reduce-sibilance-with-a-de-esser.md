## 本指南的用途 {#what-this-guide-is-for}

De-esser 会降低语音中的强齿音，同时保留大部分人声。适用于 S 或 SH 音比前后词语更突出的片段。

:::note[从 Audacity 转来？]
Audacity 当前效果列表中**没有直接内置对应项**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取带有刺耳 S 音的人声片段。声音会作为独立音轨中的片段显示。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 噪声消除与修复 → 去齿音器**。在 **去齿音器** 对话框中，将 **频率** 设为 `6000`、**最大衰减** 设为 `6`，然后点击 **应用到选区**。Frequency 针对齿音范围；maximum reduction 限制这些瞬间被压低的幅度。
5. 按 **播放** 试听，然后按 **停止**。
   *你会看到：* 齿音柔和了，而人声其他部分仍然清晰。

## 提示

- 调整 **频率** 时要听 S 音；数值过低会让辅音和明亮感变得沉闷。
- 先使用适中的 **最大衰减**，只有在刺耳齿音仍明显时才继续提高。
