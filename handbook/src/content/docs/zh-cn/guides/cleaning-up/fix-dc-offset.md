有些声卡和廉价音频接口会给录音加入恒定电压，使整个波形略微偏离中心线。你无法直接听到这种偏移，但它会占用余量，并在每次编辑处产生咔嗒声。“移除直流偏移”会将波形重新居中。

:::note[从 Audacity 转来？]
这对应 Audacity 的**效果 → 音量和压缩 → 移除直流偏移**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入**，并选择偏离中心的录音。它会作为片段出现在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **效果 → 音量和压缩 → 移除直流偏移**。效果会立即应用于选区。
5. 按 **播放** 收听，然后按 **停止**。
   *你应该会看到：* 波形已在零线上居中。

## 提示

- [峰值归一化](/guides/volume/normalize-peaks/)也会移除直流偏移；如果你本来就要归一化，就无需另行处理。
- 如果偏移在录音过程中发生变化，它就不是直流偏移；请改用[高通滤波器](/guides/cleaning-up/remove-low-rumble/)。
