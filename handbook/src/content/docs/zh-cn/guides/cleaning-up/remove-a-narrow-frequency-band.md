## 本指南的用途 {#what-this-guide-is-for}

持续的啸声或电子音可能只在录音的一部分占据很窄的频段。Spectral Delete 会在时间选区内移除该频段，同时保留周围频率。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Effect → Spectral Tools → Delete selection (Audacity 4)**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入含有短促音调声的录音。文件会作为一个片段出现在自己的音轨上。
3. 点击要检查的音轨标题中的 **音轨选项** 按钮打开菜单，然后选择 **音轨可视化 → 频谱图**。
4. 在片段上方的标尺上拖动，选中听到音调声的时间范围。
5. 选择 **效果器 → 频谱编辑 → 在频谱中选择频率范围**。将 **最低频率（Hz）** 设为 `200`，将 **最高频率（Hz）** 设为 `320`，然后点击 **频谱删除**。这样只会在选定时间范围内降低循环音频中的 261.6 Hz 音调声。
6. 点击 **播放** 试听，然后点击 **停止**。
   *你应该听到：* 该段中的音调声减弱，录音的其余部分保持不变。

## 提示

- 先在频谱图中找到音调声，再缩小其周围的时间和频率范围，然后再删除。
- Spectral Delete 只影响选定的时间和频率范围；普通的 Delete 会移除整个选区。
