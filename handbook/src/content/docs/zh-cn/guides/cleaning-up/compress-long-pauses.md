## 本指南的用途 {#what-this-guide-is-for}

较长的停顿会让口语内容显得拖沓，而删除所有停顿又会让人难以跟上。Truncate Silence 只会压缩超过最短时长的停顿中的多余部分。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Effect → Special → Truncate Silence**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入停顿显得过长的录音。文件会作为一个片段出现在自己的音轨上。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → 特殊 → 截去静音**。在 **截去静音** 对话框中，将 **阈值** 设为 `-40`，将 **最短静音时长** 设为 `0.5`；在 **压缩多余的静音** 中选择 **操作**，并将 **压缩到** 设为 `50`，然后点击 **应用到选区**。超过 0.5 秒的静音会缩短为超出时长的一半，同时仍在语句之间保留停顿。
5. 点击 **播放** 试听，然后点击 **停止**。
   *你应该听到：* 较长的停顿变短了，但语句之间仍保留了一些静音。

## 提示

- 提高 **最短静音时长** 可让较短的停顿保持不变；降低 **压缩到** 可进一步缩短较长的停顿。
- 检查呼吸声或语句结尾是否被截断；如果节奏变得不自然，请撤销更改。
