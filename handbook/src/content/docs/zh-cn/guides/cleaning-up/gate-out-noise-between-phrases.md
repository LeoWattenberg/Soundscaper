降噪器从整个录音中去除噪音；门限器采用不同的方法。当音量低于阈值时（例如句子之间、暂停时），门限器会降低音频音量，当声音返回时，它会立即打开。它无法从单词下方清除噪音，但它可以使单词之间的空隙变得干净，并且设置起来非常快。

:::note[来自Audacity？]
这是Audacity的**效果 → 噪音移除和修复 → 噪音门限器**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择带有噪音暂停的录音。该文件将作为片段其自己的轨道上。
3. 选择**选择 → 全部选择**。
4. 选择**效果 → Nyquist → 噪音门限器**。在**噪音门限器**对话框中，将**门限阈值（dB）**设置为`-35`，将**音量降低（dB）**设置为`-30`，然后按**应用**。阈值应位于噪音之上，静音语音之下；-35 dB适用于大多数语音录音。降低量设置了空隙被降低的程度——不要降低所有音量，因为这听起来不自然。
5. 按**播放**收听，然后按**停止**。
   *您应该会看到：* 暂停安静，每个短语未受影响。

## 提示

- 如果单词末尾被截断，请提高**保持（ms）**或**衰减（ms）**，使门限器更慢地关闭。
- 对于持续在语音下方的噪音，请使用[降噪](/guides/cleaning-up/remove-background-noise/)，或两者结合使用。
