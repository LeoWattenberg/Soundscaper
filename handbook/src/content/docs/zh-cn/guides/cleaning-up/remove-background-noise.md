可以分两步去除持续的背景噪音——风扇声、冰箱声、电源嗡嗡声。首先，您需要向噪音减少效果展示一段仅包含噪音的录音，以便它可以建立一个配置文件；然后将效果应用于整个录音。配置文件是使此操作有效的原因，因此请选择录音中没有人说话的部分。

:::note[来自Audacity？]
这是Audacity的**效果 → 噪音去除和修复 → 噪音减少**，分两步进行。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择您要清理的录音。文件会作为片段落在自己的轨道上。
3. 在片段上方拖动尺子，选择一段仅包含噪音的区域，通常是在任何人说话之前的引言部分。配置文件中不应包含任何除了您想要去除的噪音之外的内容。
4. 选择**效果 → 噪音去除和修复 → 噪音减少**，并按下**获取噪音配置文件**。状态行报告配置文件已准备就绪。按下**关闭**暂时离开对话框。
5. 选择**选择 → 选择所有**。配置文件被保留；现在效果需要知道要清理什么。
6. 选择**效果 → 噪音去除和修复 → 噪音减少**。在**噪音减少**对话框中，将**噪音减少**设置为`12`，然后按下**应用到选择区域**。大约12 dB是一个不错的首次尝试。更高的值会去除更多的噪音，但开始使声音听起来空洞。
7. 按下**播放**进行聆听，然后按下**停止**。
   *您应该会看到：*引言部分现在安静了许多，而声音没有受到影响。

## 提示

- 如果结果听起来像水或金属，请撤销并尝试降低**噪音减少**值或**灵敏度**。
- 噪音减少仅对整个录音中保持不变的噪音有效。对于一次性咳嗽或点击声，请将其剪切掉或使用点击去除效果。
