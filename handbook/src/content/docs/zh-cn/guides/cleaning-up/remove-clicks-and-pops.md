来自电缆、鼠标或老唱片的点击声只是几个长度的样本。点击移除找到与周围环境不同的突起并将其平滑，这比手动剪切每个点击声要快得多。

:::note[来自Audacity？]
这是Audacity的**效果 → 噪音移除和修复 → 点击移除**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择包含点击声的录音。文件会以片段的形式出现在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 噪音移除和修复 → 点击移除**。在**点击移除**对话框中，将**阈值**设置为`150`，然后按**应用到选择**。较低的阈值可以捕捉到较安静的点击声。默认值200是保守的；150会捕捉到更多点击声而不影响音乐。
5. 按**播放**听取效果，然后按**停止**。
  *您应该会看到：*点击声已被去除，周围的材料保持不变。

## 提示

- 如果点击声仍然存在，只选择其周围的时刻，并再次运行效果，将阈值设置得更低。
- 宽度超过几毫秒的点击声不属于这种效果。将其剪切掉。
