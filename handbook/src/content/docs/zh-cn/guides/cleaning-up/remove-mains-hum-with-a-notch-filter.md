电源嗡嗡声位于一个频率上：全球大部分地区为50 Hz，美洲为60 Hz，有时会有一个谐波位于该频率的两倍。缺口滤波器在某个频率周围切割一个窄带，并保留其他一切，这比高通滤波器温和得多，当嗡嗡声不够低时不会产生衰减。同一工具可以去除显示器哨音或响亮的共振，一旦你知道其频率。

:::note[来自Audacity？]
这是Audacity的**效果 → 等化器和滤波器 → 缺口滤波器**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入**，并选择带有嗡嗡声的录音。它会作为片段出现在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 均衡器和滤波器 → 缺口滤波器**。在**缺口滤波器**对话框中，将**缺口频率**设为`50`，将**Q**设为`4`，然后按**应用于所选内容**。如果你的主电源是60 Hz，请使用60。Q值为4是一个窄缺口；如果嗡嗡声四处移动，请降低它；如果切割在声音上可听见，请提高它。
5. 按**播放**听取，然后按**停止**。
   *你应该会看到：*嗡嗡声消失了，声音听起来是一样的。

## 提示

- 不确定频率吗？[绘制光谱](/guides/analysis/plot-a-spectrum/)的安静段落并读取峰值。
- 嗡嗡声通常有一个位于双倍频率的谐波。如果还剩下一些，请在100或120 Hz再次运行滤波器。
