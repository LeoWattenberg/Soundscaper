交通噪音、空调声、麦克风上的风声和桌子被碰到的声音都存在于语音以下的频率中，小扬声器甚至无法复制这些频率。高通滤波器允许所有高于截止频率的信号通过，并削减低于截止频率的信号，从而清理低频部分而不影响语音。

:::note[来自Audacity？]
这是Audacity的**效果 → 高通滤波器**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择包含轰鸣声的录音。文件将作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 传统效果 → 经典滤波器**。在**经典滤波器**对话框中，将**滤波器类型**设置为**高通**，并将**截止频率**设置为`100`，然后按**应用到选择**。100 Hz对语音是安全的。提高阶数以获得更陡的削减。
5. 按**播放**听取，然后按**停止**。
   *您应该会看到：*低频轰鸣消失了，语音听起来一模一样。

## 提示

- 对于音乐，从较低的频率开始——大约40 Hz——这样低音乐器就不会变得单薄。
- 轨道效果架中的实时**高通滤波器**在播放时执行相同的任务，而不需要渲染。
