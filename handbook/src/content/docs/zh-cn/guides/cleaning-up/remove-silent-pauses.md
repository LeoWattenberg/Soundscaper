长时间且间歇较长的录音会让人疲惫不堪。静音截断会找到所有低于阈值且持续时间超过最小静音长度的段落，并将其缩短，从而使节奏紧凑，而不会剪切任何单词。

:::note[来自Audacity？]
这是Audacity的**效果 → 特殊 → 静音截断**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择带有长间歇的录音。文件会以片段的形式出现在单独的轨道上。
3. 选择**选择 → 全选**。
4. 选择**效果 → 特殊 → 静音截断**。在**静音截断**对话框中，将**阈值**设置为`-40`，然后按**应用到选择**。任何低于-40dB的声音都被视为静音。超过最小静音长度的间歇会被缩短到截断长度；两者都保持默认值，即半秒。
5. 按**播放**收听，然后按**停止**。
   *您应该会看到：*间歇变短，每个短语仍然完整。

## 提示

- 如果短语开头的单词被剪切，请提高最小静音长度或降低阈值。
- 此效果会更改选择的长度，因此在将其与任何其他内容对齐之前，请先运行它。
