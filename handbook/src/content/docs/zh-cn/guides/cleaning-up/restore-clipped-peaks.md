## 本指南的用途 {#what-this-guide-is-for}

Clip Fix 根据相邻波形估算短促削波峰值缺失的顶部。请在录音副本上使用并仔细试听；它无法重建较长的削波片段。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Effect → Noise Removal and Repair → Clip Fix (Audacity 3 and 4)**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入含有要修复的短促削波峰值的录音。文件会作为一个片段出现在自己的音轨上。
3. 选择 **选择 → 全选**。
4. 选择 **效果器 → Nyquist → Clip Fix**。在 **Clip Fix** 对话框中，将 **Threshold of Clipping (%)** 设为 `95`，将 **Reduce amplitude to allow for restored peaks (dB)** 设为 `-9`，然后点击 **应用**。阈值用于识别被削平的峰值，余量则为估算并恢复峰值形状留出空间。
5. 点击 **播放** 试听，然后点击 **停止**。
   *你应该听到：* 修复后的峰值听起来不那么刺耳；保留更改前，请与未处理的原始音频比较。

## 提示

- Clip Fix 最适合短促、轻微削波的峰值；它无法恢复持续失真的细节。
- 保留未处理的副本，以便比较修复后的瞬态；如果波形听起来不够自然，可以撤销更改。
