Freesound 面板让你无需离开 Soundscaper 就能查找音效。搜索所需内容，查看每个结果附带的创作者和许可信息，然后将音效插入时间轴上的目标位置。Soundscaper 会将高质量预览导入为项目片段。

:::note[从 Audacity 转来？]
这对应 Audacity 的**文件 → 导入 → 下载 Freesound 音效后导入音频**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **视图 → 面板 → Freesound**。
3. 在 **Freesound** 面板的 **搜索 Freesound** 栏中输入描述所需音效的词语或短语，然后按 **搜索**。匹配的音效会显示在 **Freesound 结果**中。
4. 在 **Freesound 结果**中，按所需结果旁的 **在播放头处插入**。音效会作为片段出现在播放头位置。
5. 项目现在显示 1 个片段。
   *你应该会看到：* 导入的音效已出现在时间轴上，可以与项目其他内容一起编辑。

## 提示

- 分享音效之前，请查看结果旁的创作者信息和许可链接。
- **在播放头处插入**会将音效放到时间轴上。若要让片段稍后开始，请先移动播放头。
