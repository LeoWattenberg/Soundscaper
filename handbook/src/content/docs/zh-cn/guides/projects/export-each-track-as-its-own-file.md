混音工程师、视频编辑师或在另一个程序上合作的伙伴通常需要各个部分，而不是混合结果。干音轨导出会将每条音轨渲染到一个单独的文件中，所有文件长度一致，并根据项目开始时间进行对齐，然后将它们打包到一个存档中。

:::note[来自Audacity？]
这相当于Audacity中的**文件 → 导出音频 → 按音轨分割导出多个文件**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**并选择第一个音轨。文件会以剪辑的形式落在自己的音轨上。
3. 选择**文件 → 导入音频**并选择第二个音轨。文件会以剪辑的形式落在自己的音轨上。
4. 选择**文件 → 导出音频**，将**格式**设置为**WAV**，将**输出**设置为**单独干音轨（按音轨分割）**，然后点击**导出**。文件在渲染完成后立即下载，并且其链接会在对话框中保留。每个音轨都会成为ZIP文件内部的一个WAV文件，并修剪至相同长度，以便在其他地方导入时对齐。

## 提示

- 静音和独奏不会影响干音轨；所有音轨都会被渲染。
- 在导出前为音轨命名 — 干音轨文件会从它们那里获取名称。
