Audacity 3（.aup3）和 Audacity 4（.aup4）项目都可以直接打开。轨道、片段、名称和位置都会保留；Soundscaper 不支持的效果也会列出，方便你检查。原始文件不会被修改。

:::note[从 Audacity 转来？]
这对应 Audacity 的**文件 → 打开**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 打开**，然后选择项目。轨道和片段会按其在 Audacity 中的状态显示。
3. 项目现在显示一个名为 **Audio 1** 的片段和一个名为 **Fixture track** 的轨道。
   *你应该会看到：* 来自 Audacity 项目的轨道和片段，以及它们的名称。

## 提示

- 旧版 `.aup` 项目需要旁边有对应的 `_data` 文件夹；出现提示时请同时选择两者。
- **文件 → 导出其他 → 导出 AUP4**可反向操作，将项目交还给 Audacity。
