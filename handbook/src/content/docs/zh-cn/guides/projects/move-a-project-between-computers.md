项目库存在于单个计算机上的单个浏览器中。要将项目带到其他地方——另一台机器、同事、备份驱动器等——请将其导出为项目文件。`.sscape` 文件包含音频和所有编辑，并在任何 Soundscaper 中打开。

:::note[来自 Audacity？]
这与 Audacity 的 **文件 → 保存项目 → 备份项目，然后文件 → 打开** 操作相同。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频** 并选择项目材料。文件作为片段落在自己的轨道上。
3. 选择 **文件 → 导出项目文件 (.sscape)**。整个项目下载为一个 `.sscape` 文件。将文件保存在安全的地方；它是完整的项目。
4. 选择 **文件 → 打开 Scape 项目文件 (.sscape)** 并选择文件。在尚未拥有该项目的计算机上直接打开；在这里，由于库已经包含该项目，Soundscaper 提供 **以只读副本打开**——点击它。
   *你应该会看到：* 项目与其轨道和片段一起精确地打开，就像导出时一样。

## 提示

- 只读副本在从文件菜单保存为自身项目之前无法编辑。
- 此文件是包含音频的 ZIP 存档；请勿手动解压。
