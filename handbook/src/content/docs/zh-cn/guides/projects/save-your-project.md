项目不仅仅是音频：它包括轨道、剪辑、效果、标记和历史记录。保存将所有这些保存在浏览器本地的项目库中，可以在文件菜单中重新打开。Soundscaper在操作过程中也会自动保存，所以这主要是为了确保安全。

:::note[来自Audacity？]
这相当于Audacity中的**文件 → 保存项目**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**并选择要编辑的文件。文件将作为剪辑添加到单独的轨道上。
3. 选择**文件 → 保存项目**。状态栏中的保存指示器显示项目已保存。

## 提示

- 要将项目移动到另一台计算机或在浏览器外保留一份副本，请参阅[在计算机之间移动项目](/guides/projects/move-a-project-between-computers/)。
- 音频导出是一个听复制品，不是项目。如果可能需要再次编辑，请保留项目。
