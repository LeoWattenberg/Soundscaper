## 本指南的用途 {#what-this-guide-is-for}

导入文件会为您创建一个音轨，但录音或粘贴需要一个着陆点。轨道列表上方的“添加轨道”按钮创建一个空的音频轨道；标签轨道包含标记和文本，而不是声音。

:::note[来自Audacity？]
这是Audacity的**轨道 → 添加新 → 单声道轨道**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 按下轨道列表上方的**添加轨道**，并选择**音频轨道**。
3. 项目现在显示2个轨道。
   *您应该看到：*第一个下面第二个空音频轨道。

## 提示

- 从其菜单中重命名轨道，以便具有多个轨道的会话保持可读性。
- 通过拖动轨道标题来重新排序它。
