## 本指南的用途 {#what-this-guide-is-for}

Make stereo track 会将两条单声道音轨渲染为一个立体声片段，并替换源音轨。您打开菜单的音轨提供左声道；其下方第一条兼容的单声道音轨提供右声道。如果下方没有这样的音轨，Soundscaper 会使用项目其他位置的第一条兼容单声道音轨。合并前，请将要作为右声道的音轨放在左声道音轨的正下方。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Upper mono track menu → Make stereo track (Audacity 4)**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取要用作左声道的单声道录音。录音会作为一个片段出现在单独的音轨上。
3. 选择 **文件 → 导入**，然后选取要用作右声道的单声道录音。录音会作为一个片段出现在单独的音轨上，位于第一条录音下方。根据预期播放时间排列这些片段。
4. 点击音轨标题中的 **音轨选项** 按钮打开左声道录音的菜单，然后选择 **音轨声道 → 创建立体声音轨**。
5. 现在项目中显示 1 个片段和 2 条音轨。
   *您应看到：* 一条立体声片段替代了两条单声道录音，且每个声道都包含预期的声音。

## 提示

- 新片段会按照项目采样率涵盖两条音轨的内容。任一音轨上的空白部分会在对应声道中变为静音。
- 如果两段录音应同时开始，请先[对齐音轨起点](/guides/editing/align-track-starts-together/)再进行合并。
- 如果之后还需要编辑独立片段，请保留一份项目副本。选择 **编辑 → 撤销** 可恢复两条单声道音轨。
