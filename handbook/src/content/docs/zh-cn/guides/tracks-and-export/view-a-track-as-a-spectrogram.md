## 本指南的用途 {#what-this-guide-is-for}

波形显示振幅的变化，频谱图则显示频率随时间的变化。将单条音轨切换为频谱图视图，可以检查音调、噪声或其他频率细节，而不会改变音频本身。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Track menu → Track Visualization → Spectrogram**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入要检查频率的录音。它会作为一个片段出现在自己的音轨上。
3. 点击要检查的录音标题中的 **音轨选项** 按钮打开菜单，然后选择 **音轨可视化 → 频谱图**。音轨切换为频率视图；音频和片段时间位置保持不变。
4. 项目现在显示 1 个片段。
   *你应该看到：* 音轨显示频谱图，而片段仍位于时间线上的原位置。

## 提示

- 要返回振幅视图，请在同一音轨菜单中选择 **音轨可视化 → 波形**。
- 需要调整频率范围或刻度时，可从音轨菜单打开频谱图设置。
