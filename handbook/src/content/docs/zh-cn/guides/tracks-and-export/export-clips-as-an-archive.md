## 本指南的用途 {#what-this-guide-is-for}

单独导出片段可将每处编辑保留为独立音频文件，同时将所有文件汇集到一个压缩包中。先将一段音频拆分为片段，再在导出对话框中选择按片段输出。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入要分别导出其片段的录音。文件会作为一个片段出现在自己的音轨上。
3. 在片段上方的标尺上拖动，选中要作为独立片段导出的部分。
4. 选择 **编辑 → 音频片段 → 分割**。
5. 选择 **文件 → 导出音频**，将 **格式** 设为 **WAV**，将 **输出** 设为 **单个片段（按片段拆分）**，然后点击 **导出**。渲染完成后文件会自动下载，其链接会保留在对话框中。每个片段都会作为单独的 WAV 文件放入同一个 ZIP 压缩包。

## 提示

- 导出前为片段取有意义的名称，以便在压缩包中识别文件。
- 如果需要单个混音而非分别导出的片段文件，请选择 **整个项目**。
