## 本指南的用途 {#what-this-guide-is-for}

Remove tracks 会从项目中删除选中的音轨及其中所有片段。它适用于移除未使用的录音，或比较编辑结果后多余的副本。选中一个片段会将其所在的整条音轨作为目标，因此删除前请检查当前选区。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Tracks → Remove tracks (Audacity 4)**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取要保留的录音。录音会作为一个片段出现在单独的音轨上。
3. 选择 **文件 → 导入**，然后选取另一条音轨上不需要的录音。录音会作为一个片段出现在单独的音轨上。
4. 按 **Tab** 将焦点移到要移除的音轨中的片段，然后按 **Enter** 选中它。
5. 选择 **音轨 → 移除音轨**。
6. 保留的录音仍位于原来的位置。
   *您应看到：* 不需要的音轨已消失，另一段录音保持不变。

## 提示

- 选择 **编辑 → 撤销** 可恢复已移除的音轨及其片段。
- 若只想移除录音的一部分，请[删除一段并留出空隙](/guides/editing/delete-a-passage-and-leave-a-gap/)，而不是删除整条音轨。
- 从项目中移除音轨不会删除从电脑导入的原始文件。
- 链接 lane 组中的音轨会一起移除。
