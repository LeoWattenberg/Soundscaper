MP3 文件大小适中，可以在各种设备上播放，而且是大多数播客主持人和消息应用所期望的格式。导出操作会将整个项目（包括每一轨、特效和编辑）渲染成一个文件。

:::note[来自 Audacity？]
这相当于 Audacity 中的 **文件 → 导出音频 → MP3**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目就准备好了。
2. 选择 **文件 → 导入音频**，并选择要发布的音频文件。文件会被导入到一个单独的轨上。
3. 选择 **文件 → 导出音频**，将 **格式** 设置为 **MP3**，然后点击 **导出**。渲染完成后，文件会立即下载，并且对话框中会保留其链接。文件是在浏览器中编码的；没有任何内容会离开您的计算机。

## 提示

- MP3 文件是交付副本，不是备份。如果可能需要再次编辑，请保留项目或同时导出 WAV 文件。
- 完全量化的峰值在编码后可能会截断。在导出前将音量降低到 -1 dB 或更低。
- 比特率模式决定了编码器如何分配比特。标准预设会根据材料动态调整速率，这是大多数交付的正确选择；当主持人或较旧的硬件播放器要求固定速率时，请选择常量。
