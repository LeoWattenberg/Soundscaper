## 本指南的用途 {#what-this-guide-is-for}

双声道录音设备将一位说话者录在左侧、另一位录在右侧时，分离声道后便可分别编辑和调整每个人声的平衡。Split stereo to centered mono 会创建两个单声道音轨，并将两者都居中声像。它会保留它们在时间轴上的位置和长度，同时让每个声道仍作为独立录音存在。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Track menu → Split stereo to center mono (Audacity 4)**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取要分离声道的立体声录音。录音会作为一个片段出现在单独的音轨上。
3. 点击音轨标题中的 **音轨选项** 按钮打开音轨菜单，然后选择 **音轨声道 → 将立体声分割为居中单声道**。
4. 现在项目中显示 2 个片段和 3 条音轨。
   *您应看到：* 独立的 Left 和 Right 音轨分别保留原始声道，两个声像控制均位于中央。

## 提示

- 若要保留原始立体声位置，请改为[拆分为 left/right 单声道音轨](/guides/tracks-and-export/split-stereo-into-mono-tracks/)。
- 此操作会创建两条单声道音轨。若要将它们的声音合并为一个单声道，请[混缩这些音轨](/guides/tracks-and-export/mix-tracks-into-one/)，然后选择 Mono。
- 选择 **编辑 → 撤销** 可恢复立体声音轨。
