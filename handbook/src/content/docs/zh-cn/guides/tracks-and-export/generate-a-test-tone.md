在检查信号链、校准水平或创建哔声覆盖单词时，第一个要使用的东西是已知频率和水平的调。生成器在光标处创建音频，或替换所选内容（如果有）。

:::note[来自Audacity？]
这是Audacity的**生成 → 调**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**生成 → 调**。在**调**对话框中，将**频率（Hz）**设置为`440`，将**持续时间（秒）**设置为`2`，然后按**生成**。440 Hz是音乐会A，标准调音参考。
3. 项目现在显示1个剪辑。
   *您应该看到：* 一个新的剪辑包含两秒的调。

## 提示

- 将**振幅**设置为`0.5`或更低，如果调将与任何内容混合。
- **生成 → 静音**工作方式相同，是添加剪辑之间间隙的最简单方法。
