## 本指南的用途 {#what-this-guide-is-for}

Swap stereo channels 会交换立体声音轨左右两侧的音频。麦克风或录音机连接反了时，可用它修正，同时保持录音的时间位置不变。

:::note[从 Audacity 转来？]
Audacity 3 中的对应命令是 **Audio Track Dropdown Menu → Swap Stereo Channels**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取左右声道颠倒的立体声录音。录音会作为独立音轨中的片段显示。
3. 点击音轨标题中的 **音轨选项** 按钮打开菜单，然后选择 **音轨声道 → 交换立体声的两个声道**。
4. 项目现在显示 1 个片段和 2 条音轨。
   *你会看到：* 录音仍是原位置的一个立体声片段，两个声道已交换。

## 提示

- 此操作会交换声道内容。声像只改变聆听位置，不会交换声道本身。
- 使用 **编辑 → 撤销** 可恢复原来的声道顺序。
