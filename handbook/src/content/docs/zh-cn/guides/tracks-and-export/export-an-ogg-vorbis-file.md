## 本指南的用途 {#what-this-guide-is-for}

Ogg Vorbis 会舍弃部分音频信息，以生成更小的聆听副本。如果接收方的播放器或服务支持此格式，可用它导出混音。

:::note[从 Audacity 转来？]
Audacity 3 中的对应命令是 **File → Export Audio → Ogg Vorbis**。下方名称属于 Soundscaper，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，然后选取要分享的录音或混音。音频会作为独立音轨中的片段显示。
3. 选择 **文件 → 导出音频**，将 **格式** 设为 **Ogg Vorbis**，然后点击 **导出**。渲染完成后文件会下载，链接会保留在对话框中。
   *你会看到：* 导出对话框提供可下载的 Ogg 文件。

## 提示

- Quality 用于平衡文件大小与编码质量。
- 如果以后可能要编辑或重新编码，请保留[无损母版](/guides/tracks-and-export/export-a-flac/)。
