## 本指南的用途 {#what-this-guide-is-for}

Duplicate track 会复制整条音轨，包括所有片段及其在时间轴上的位置。保留原件的同时，可用副本尝试其他编辑或效果。选中一个片段即可指定要复制的音轨；该音轨上的其他片段也会一并复制。

:::note[从 Audacity 转来？]
这相当于 Audacity 中的 **Tracks → Duplicate (Audacity 4)**。下方名称是 Soundscaper 使用的名称，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目便已准备就绪。
2. 选择 **文件 → 导入**，然后选取要复制的音轨上的录音。录音会作为一个片段出现在单独的音轨上。
3. 在要将录音拆分为两个可独立编辑部分的位置单击波形，以放置光标。如果音轨已经有多个片段，或您想让它保持为一个片段，请跳过放置光标和接下来的 Split 步骤。
4. 选择 **编辑 → 音频片段 → 分割**。
5. 现在项目中显示 2 个片段。
   *您应看到：* 音轨上有两个片段，可以一起复制。
6. 按 **Tab** 将焦点移到音轨中的一个片段，然后按 **Enter** 选中它。
7. 选择 **音轨 → 创建音轨副本**。
8. 现在项目中显示 4 个片段和 3 条音轨。
   *您应看到：* 原始音轨和副本各自包含两个片段，且它们在时间轴上的位置相同。

## 提示

- 原始音轨和副本会同时播放。比较时请[将一条音轨静音或设为独奏](/guides/tracks-and-export/mute-and-solo-tracks/)，这样每次只会听到一个版本。
- 若只想复制一段，请改为[将选区复制到新音轨](/guides/editing/duplicate-a-selection-to-a-new-track/)。
- 选择 **编辑 → 撤销** 会移除复制的音轨。
