当音轨平衡后，将它们混合到一个音轨可以使项目更易于操作，并提供一个可导出或在其他地方使用的单个剪辑。混合使用每个选定音轨的增益、全景、自动化和效果。在此操作中，静音和独奏对选定音轨被忽略，并且主处理保持实时。

:::note[来自Audacity？]
这与Audacity的**音轨 → 混合 → 混合和渲染**相同。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**并选择第一个部分。文件会以剪辑的形式落在自己的音轨上。
3. 选择**文件 → 导入音频**并选择第二个部分。文件会以剪辑的形式落在自己的音轨上。
4. 单击第一个剪辑的名称栏，然后按住Shift单击第二个剪辑的名称栏，这样两个剪辑都将被选中。每个有选定剪辑的音轨都会进入混合。
5. 选择**音轨 → 混合渲染**。在**混合渲染**对话框中，保持**混合下**、**渲染效果**和**替换原始文件**选中，选择**立体声**作为**混合下到**，然后单击**混合渲染**。
6. 项目现在显示一个名为**混合**的剪辑。
   *你应该看到：* 一个音轨包含一个名为混合的剪辑；源音轨已消失。

## 提示

- 在渲染前，在**混合下到**下选择**单声道**、**立体声**或项目的配置多通道布局。
- **编辑 → 撤销**会恢复原始音轨，如果你需要更改平衡。
- 你不需要混合下以导出。**文件 → 导出音频**会渲染整个项目，无需混合。
