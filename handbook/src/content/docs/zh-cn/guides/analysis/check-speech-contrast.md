::语音与背景噪音之间的音量差异::

语音比房间后面的噪音只大一点是很难跟上的，可访问性指南给它定了一个数值：语音应至少比背景高20 dB。对比分析器测量一段背景和一小段语音，报告两者之间的差异，并判断是否符合该建议。这是Audacity 3中用于WCAG检查的分析器，而Audacity 4中不包含它。

:::注意[来自Audacity？]
这是Audacity的 **分析 → 对比（Audacity 3；Audacity 4没有对比分析器）**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择包含语音和背景噪音的录音。该文件作为片段落在自己的轨道上。
3. 在片段上方拖动尺子以选择一段没有人说话的背景。背景测量应仅包含语音需要竞争的噪音。
4. 选择 **分析 → 对比**。**对比**面板打开。
5. 在**对比**面板中，按下**测量背景**。面板将选定的水平作为背景保持。
6. 在片段上方拖动尺子以选择一段语音。最好选择普通语音，而不是最响亮的词，因为整个段落会被平均。
7. 在**对比**面板中，按下**测量前景**。面板报告前景水平、背景水平以及两者之间的差异。
   *你应该看到：* 前景和背景水平、它们之间的dB差异，以及差异是否符合推荐的20dB。

## 提示

- 如果差异不足，[减少背景噪音](/guides/cleaning-up/remove-background-noise/) 或 [使用压缩器均衡语音](/guides/volume/even-out-volume-with-a-compressor/)，然后再次测量。
- 测量是RMS平均值，因此单个响亮的音节无法拯救一个安静的录音。
