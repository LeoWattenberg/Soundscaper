## 本指南的用途 {#what-this-guide-is-for}

Label Sounds 会扫描音频片段，查找被静音分隔的声音，并在检测到的每个声音周围放置标签。它可标记说话片段、单独的撞击声或其他独立事件，以供后续编辑。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Analyze → Label Sounds (Nyquist)**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入声音之间有停顿的录音。文件会作为一个片段出现在自己的音轨上。
3. 选择 **选择 → 全选**。
4. 选择 **分析 → Nyquist → Label Sounds**。在 **Label Sounds** 对话框中，将 **Threshold level (dB)** 设为 `-30`，将 **Minimum silence duration** 设为 `0.5`，将 **Minimum label interval** 设为 `0.5`，然后点击 **应用**。对话框会显示结果；点击 **关闭** 将其关闭。半秒静音可让分析器分隔语句。阈值决定声音必须达到多大才能被计入。
5. 项目现在显示一个名为 **Label Sounds** 的音轨。
   *你应该看到：* Label Sounds 音轨出现，检测到的语句周围带有标签。

## 提示

- 降低 **Threshold level (dB)** 可纳入较轻的声音；提高它可忽略背景噪声。
- 如果不希望短暂停顿将一句话拆成多个标签，请提高 **Minimum silence duration**。
