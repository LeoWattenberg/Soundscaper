Beat Finder 是 Nyquist 分析器包中的一个。它监听突然的音量上升，并在每个上升点写入标签，这是一种快速标记循环的节拍或鼓声片段的方法，在切割之前。

:::note[来自 Audacity？]
这是 Audacity 的 **分析 → Beat Finder**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要标记的录音。文件会以剪辑的形式落在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **分析 → Nyquist → Beat Finder**。在 **Beat Finder** 对话框中，将 **阈值百分比** 设置为 `60`，然后按 **应用**。对话框会报告它找到的内容；按 **关闭** dismiss它。较低的百分比会找到更安静的节拍；如果标记过多，请提高它。
5. 项目现在显示一个名为 **Beat Finder** 的轨道。
   *你应该看到：* 一个新的标签轨道名为 Beat Finder，在音频下方，每个节拍都有一个标签。

## 提示

- 标签落在音频下方的标签轨道上。重命名或删除分析器错误的任何标签。
- **分析 → Nyquist → 标记声音** 执行类似的任务，适用于整个由静音分隔的声音。
