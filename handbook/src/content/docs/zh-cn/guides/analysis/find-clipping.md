录制音量过大会使声音变平，并出现失真。这种损坏很容易听出，但在长时间录音中很难用肉眼发现。Find Clipping 会扫描选定区域，并列出所有处于满量程的样本段，这样您可以决定是否修复、重做或对每个段接受现状。

:::note[来自 Audacity？]
这是 Audacity 的 **分析 → 查找失真**。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入音频**，并选择要检查的录音。文件会作为片段落在单独的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **分析 → 查找失真**。**查找失真**面板会打开。
  *您应该会看到：* 失真段列表，或者如果未找到任何失真段，则会显示一条提示。

## 提示

- 降低失真录音的音量并不能修复它；被压平的峰值仍会保持压平。**效果 → 噪声去除和修复 → 修复**可以重建非常短的失真段。
- 为了避免下一次出现失真，请将峰值设置在约 −12 dB 左右，并在之后提高音量。
