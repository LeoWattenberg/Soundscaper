在归一化或导出之前，先了解当前电平会很有帮助。EBU R 128 分析器会按照流媒体平台和广播机构的方式测量节目音频，包括 LUFS 综合响度、响度范围和真峰值。这样你就能与目标值比较，而不是只凭电平表猜测。

:::note[从 Audacity 转来？]
这对应 Audacity 的**分析 → 测量 RMS**或“响度归一化”的测量功能。以下名称是 Soundscaper 自己的，有时会有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择 **文件 → 导入**，并选择要测量的混音。它会作为片段出现在自己的轨道上。
3. 选择 **选择 → 全选**。
4. 选择 **分析 → EBU R 128**。**EBU R 128**面板会打开。
   *你应该会看到：* 选区的综合响度、响度范围和真峰值。

## 提示

- 播客平台通常要求立体声为 −16 LUFS、单声道为 −19 LUFS，真峰值低于 −1 dBTP；请查看平台自己的说明。
- 如果数值与目标相差很大，请运行[响度归一化](/guides/volume/normalize-loudness-for-podcasts/)，然后再次测量。
