波形显示声音随时间的响度；频谱显示声音由哪些频率组成。绘制问题段落的频谱是最快的方法，可以找到50或60Hz的嗡嗡声、来自显示器的哨声，或房间共振的频率——然后知道如何调整均衡器。

:::note[来自Audacity？]
这是Audacity的**分析 → 绘制频谱**。以下名称是Soundscaper自己的，有时会有所不同。
:::

## 步骤

1. 打开Soundscaper。编辑器加载后，一个新的空项目已准备就绪。
2. 选择**文件 → 导入音频**，并选择包含问题的录音。文件作为片段落在自己的轨道上。
3. 选择**选择 → 全选**。
4. 选择**分析 → 绘制频谱**。**绘制频谱**面板打开。
   *您应该看到：* 选择的频率与水平的图表。

## 提示

- 仅选择问题段落——例如，单独的嗡嗡声段落——以便频谱不会被周围的音乐或语音所主导。
- 高窄尖峰是一个音调；宽平台是噪声。音调响应于窄均衡器切割，噪声响应于[噪声减少](/guides/cleaning-up/remove-background-noise/)。
