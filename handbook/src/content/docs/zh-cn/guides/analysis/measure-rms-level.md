## 本指南的用途 {#what-this-guide-is-for}

RMS 是信号随时间变化的平均电平指标。使用 Measure RMS 分析器比较不同部分，或在调整前检查某段音频的强度。

:::note[从 Audacity 转来？]
Audacity 中的对应命令是 **Analyze → Measure RMS (Nyquist)**。以下名称为 Soundscaper 自有名称，可能有所不同。
:::

## 步骤

1. 打开 Soundscaper。编辑器加载后，新的空项目即可使用。
2. 选择 **文件 → 导入**，导入要测量其平均电平的片段。文件会作为一个片段出现在自己的音轨上。
3. 选择 **选择 → 全选**。
4. 选择 **分析 → Nyquist → Measure RMS**。在 **Measure RMS** 对话框中点击 **应用**。对话框会显示结果；点击 **关闭** 将其关闭。
   *你应该看到：* 报告以 dB 为单位显示各声道和立体声信号的 RMS 电平。

## 提示

- RMS 描述平均电平；若要将最高样本设为目标值，请使用 [peak normalization](/guides/volume/normalize-peaks/)。
- 只选择要比较的部分，避免无关音频影响测量结果。
