## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

FLAC komprimiert PCM-Audio ohne Samples bei der gewählten Exportauflösung zu verwerfen. Es eignet sich als platzsparender Hörmaster, während das Projekt die bearbeitbaren Spuren behält.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **File → Export Audio → FLAC (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme oder den Mix, den Sie ausgeben möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **FLAC** und drücken Sie **Exportieren**. Die Datei wird nach dem Rendern heruntergeladen; ihr Link bleibt im Dialog sichtbar.
   *Sie sollten sehen:* Der Exportdialog bietet eine FLAC-Datei zum Herunterladen an.

## Tipps

- Die Kompressionsstufe beeinflusst Rechenaufwand und Dateigröße, nicht die decodierte Audioqualität.
- Ein exportierter Mix enthält weder getrennte Spuren noch den Rückgängig-Verlauf. [Speichern Sie Ihr Projekt](/guides/projects/save-your-project/) zur späteren Bearbeitung.
