## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Eine Wellenform zeigt Pegeländerungen, ein Spektrogramm zeigt Frequenzänderungen im Zeitverlauf. Wechseln Sie für eine Spur zur Spektrogrammansicht, um Töne, Rauschen oder andere Frequenzdetails zu untersuchen, ohne das Audio zu verändern.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Track menu → Track Visualization → Spectrogram**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, deren Frequenzen Sie untersuchen möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der Aufnahme, die Sie untersuchen möchten, und wählen Sie **Spurvisualisierung → Spektrogramm**. Die Spur wird als Frequenzdarstellung angezeigt; Audio und Clipzeiten bleiben unverändert.
4. Das Projekt zeigt nun 1 Clip.
   *Das sollten Sie sehen:* Die Spur zeigt ein Spektrogramm, während der Clip an derselben Stelle der Zeitleiste bleibt.

## Tipps

- Wählen Sie im selben Spurmenü **Spurvisualisierung → Wellenform**, um zur Amplitudenansicht zurückzukehren.
- Die Spektrogrammeinstellungen im Spurmenü erlauben es, Frequenzbereich und Skala anzupassen.
