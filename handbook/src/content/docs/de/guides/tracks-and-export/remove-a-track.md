## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

„Spuren entfernen“ löscht die ausgewählte Spur und alle darin enthaltenen Clips aus dem Projekt. Das ist nützlich für eine ungenutzte Aufnahme oder eine zusätzliche Kopie nach dem Vergleichen von Bearbeitungen. Wenn Sie einen Clip auswählen, ist seine ganze Spur betroffen. Prüfen Sie deshalb vor dem Entfernen die Auswahl.

:::note[Komme von Audacity?]
Das entspricht Audacitys **Tracks → Remove tracks (Audacity 4)**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme aus, die Sie behalten möchten. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Wählen Sie **Datei → Importieren** und dann die unerwünschte Aufnahme auf einer anderen Spur aus. Sie wird als Clip auf einer eigenen Spur eingefügt.
4. Drücken Sie **Tab**, um einen Clip auf der zu entfernenden Spur zu fokussieren, und anschließend **Enter**, um ihn auszuwählen.
5. Wählen Sie **Spuren → Spuren entfernen**.
6. Die Aufnahme, die Sie behalten wollten, steht weiterhin an ihrer ursprünglichen Position.
   *Sie sollten sehen:* Die unerwünschte Spur ist entfernt; die andere Aufnahme ist unverändert.

## Tipps

- Mit **Bearbeiten → Rückgängig** stellen Sie die entfernte Spur und ihre Clips wieder her.
- Um nur einen Teil einer Aufnahme zu entfernen, [löschen Sie eine Passage und lassen eine Lücke](/guides/editing/delete-a-passage-and-leave-a-gap/), statt die Spur zu löschen.
- Wenn Sie eine Spur aus dem Projekt entfernen, wird die ursprüngliche Datei auf Ihrem Computer nicht gelöscht.
- Spuren in einer verknüpften Spurgruppe werden gemeinsam entfernt.
