## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Wenn Sie eine Spur nach oben oder unten verschieben, ändert sich ihre vertikale Position im Projekt, nicht die Startzeit ihrer Clips. Move track to top eignet sich, um eine Stimme oder einen anderen wichtigen Part über den übrigen Spuren anzuzeigen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Track menu → Move track → Move track to top**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, die weiter unten bleiben soll. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, die oben stehen soll. Sie erscheint als Clip auf einer eigenen Spur.
4. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der Spur, die nach oben soll, und wählen Sie **Spur verschieben → Spur nach ganz oben**. Der Befehl ändert die vertikale Reihenfolge dieser Spur, lässt aber die Clipzeiten unverändert.
5. Das Projekt zeigt nun 2 Clips.
   *Das sollten Sie sehen:* Die ausgewählte Spur steht über der anderen, und beide Clips behalten ihre Positionen auf der Zeitleiste.

## Tipps

- Mit **Spur verschieben → Spur nach unten** im Spurmenü können Sie die Reihenfolge umkehren.
- Die Spurposition bestimmt, welche Audiospur im Projekt über einer anderen angezeigt wird. Sie ändert weder den Mix noch das Panorama.
