## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ogg Vorbis erzeugt eine kleinere Hörkopie, indem ein Teil der Audioinformationen verworfen wird. Exportieren Sie in diesem Format, wenn der Zielplayer oder Dienst es unterstützt.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **File → Export Audio → Ogg Vorbis (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme oder den Mix, den Sie weitergeben möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **Ogg Vorbis** und drücken Sie **Exportieren**. Die Datei wird nach dem Rendern heruntergeladen; ihr Link bleibt im Dialog sichtbar.
   *Sie sollten sehen:* Der Exportdialog bietet eine Ogg-Datei zum Herunterladen an.

## Tipps

- Quality bestimmt den Kompromiss zwischen Dateigröße und Codierqualität.
- Bewahren Sie [einen verlustfreien Master](/guides/tracks-and-export/export-a-flac/) auf, wenn Sie die Aufnahme später bearbeiten oder erneut codieren möchten.
