## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Jede Spur verfügt über eine Stummschalttaste und eine Solo-Taste im Kopf. Stummschalten schaltet diese Spur stumm; Solo schaltet alle anderen Spuren stumm, sodass Sie nur diese eine Spur hören. Beide sind nur Hörhilfen – sie ändern das, was Sie während der Arbeit hören, und der Export rendert immer noch jede nicht stummgeschaltete Spur.

:::note[Komme von Audacity?]
Dies sind Audacitys **Die Stumm- und Solo-Tasten im Spursteuerfeld**. Die Namen unten sind Soundscapers eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie eine Spur aus. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Importieren** und wählen Sie eine weitere Spur aus. Sie landet als Clip auf ihrer eigenen Spur.
4. Drücken Sie **Stumm** im Kopf der Spur. Die zweite Spur fällt aus der Wiedergabe heraus.
5. Drücken Sie **Solo** im Kopf der Spur. Solo hebt die Stummschaltung für diese Spur auf und schaltet alle anderen stumm, sodass Sie nur diese Spur hören.

## Tipps

- Drücken Sie eine Taste erneut, um sie zu lösen. **Spuren → Alle Spuren stummschalten** löscht alle Spuren auf einmal.
- Solo mehrere Spuren, um eine Gruppe zusammen zu hören; Stummschalten ist dann nur für die Ausnahme nötig.
