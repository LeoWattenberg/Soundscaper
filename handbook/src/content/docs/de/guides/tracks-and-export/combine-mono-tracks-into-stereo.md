## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

„Stereospur erstellen“ rendert zwei Mono-Spuren zu einem Stereo-Clip und ersetzt die Quellspuren. Die Spur, deren Menü Sie öffnen, liefert den linken Kanal; die erste passende Mono-Spur darunter liefert den rechten. Gibt es darunter keine, verwendet Soundscaper die erste passende Mono-Spur an einer anderen Stelle im Projekt. Verschieben Sie die vorgesehene Spur für den rechten Kanal direkt unter die für den linken, bevor Sie beide zusammenführen.

:::note[Komme von Audacity?]
Das entspricht Audacitys **Upper mono track menu → Make stereo track (Audacity 4)**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Monoaufnahme für den linken Kanal aus. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Wählen Sie **Datei → Importieren** und dann die Monoaufnahme für den rechten Kanal aus. Sie wird als Clip auf einer eigenen Spur unter der ersten Aufnahme eingefügt. Ordnen Sie die Clips zu den gewünschten Wiedergabezeiten an.
4. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der Aufnahme für den linken Kanal und wählen Sie **Spurkanäle → Stereospur erstellen**.
5. Das Projekt zeigt nun 1 Clip und 2 Spuren.
   *Sie sollten sehen:* Ein Stereo-Clip ersetzt die beiden Monoaufnahmen; jeder Kanal enthält den vorgesehenen Ton.

## Tipps

- Der neue Clip deckt den Inhalt beider Spuren bei der Projekt-Samplerate ab. Lücken auf einer Spur werden im entsprechenden Kanal zu Stille.
- Wenn beide Aufnahmen gleichzeitig beginnen sollen, [richten Sie die Spuranfänge gemeinsam aus](/guides/editing/align-track-starts-together/), bevor Sie sie zusammenführen.
- Bewahren Sie eine Projektkopie auf, wenn Sie die einzelnen Clips später weiterbearbeiten möchten. Mit **Bearbeiten → Rückgängig** erhalten Sie die beiden Mono-Spuren zurück.
