## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Eine Datei importieren erstellt eine Spur, aber ein Recording oder eine Einfügung benötigt einen Platz zum Landen. Die Schaltfläche "Spur hinzufügen" über der Spurliste erstellt eine leere Audiospur; eine Markierspur enthält statt Sound Marker und Text.

:::note[Aus Audacity kommend?]
Dies entspricht Audacitys **Spuren → Neue Spur → Mono Spur**. Die Namen unten sind Soundscaper's eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Drücken Sie **Spur hinzufügen** über der Spurliste und wählen Sie **Audiospur**.
3. Das Projekt zeigt nun 2 Spuren.
   *Sie sollten sehen:* Eine zweite, leere Audiospur unter der ersten.

## Tipps

- Benennen Sie die Spur aus ihrem Menü um, damit eine Sitzung mit vielen Spuren lesbar bleibt.
- Ziehen Sie eine Spur per Header neu an, um die Reihenfolge zu ändern.
