## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Pluck erzeugt einen kurzen, gestimmten Klang, der als einfache Musiknote oder als Akzent für Sounddesign dienen kann. Über die MIDI-Tonhöhe wählen Sie eine Note, ohne ihre Frequenz berechnen zu müssen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Generate → Pluck (Nyquist)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → Nyquist → Pluck**. Setzen Sie im Dialog **Pluck** **Pluck MIDI pitch** auf `60` und **Duration (60s max)** auf `2`, und drücken Sie dann **Anwenden**. MIDI-Tonhöhe 60 entspricht dem eingestrichenen C; zwei Sekunden geben der Note Raum zum Ausklingen.
3. Das Projekt zeigt nun 1 Clip.
   *Das sollten Sie hören:* Auf der Zeitleiste erscheint eine nicht stumme, zwei Sekunden lange gezupfte Note.

## Tipps

- Erhöhen Sie **Pluck MIDI pitch** für eine höhere Note, oder senken Sie den Wert für eine tiefere Note.
- Verwenden Sie eine kürzere **Duration (60s max)** für einen knapperen Akzent.
