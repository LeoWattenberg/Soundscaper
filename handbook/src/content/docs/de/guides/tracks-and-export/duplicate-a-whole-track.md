## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

„Spur duplizieren“ kopiert die ganze Spur einschließlich aller Clips und ihrer Positionen auf der Zeitleiste. Verwenden Sie die Kopie, um eine andere Bearbeitung oder einen Effekt auszuprobieren und das Original zu behalten. Wenn Sie einen Clip auswählen, bestimmt das die zu duplizierende Spur; die anderen Clips dieser Spur werden ebenfalls kopiert.

:::note[Komme von Audacity?]
Das entspricht Audacitys **Tracks → Duplicate (Audacity 4)**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme auf der Spur aus, die Sie duplizieren möchten. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Klicken Sie an der Stelle auf die Wellenform, an der Sie die Aufnahme in zwei unabhängig bearbeitbare Teile teilen möchten, um den Cursor dort zu platzieren. Überspringen Sie das Platzieren des Cursors und den nächsten Schritt „Split“, wenn die Spur bereits mehrere Clips enthält oder als ein Clip erhalten bleiben soll.
4. Wählen Sie **Bearbeiten → Audio-Clips → Teilen**.
5. Das Projekt zeigt nun 2 Clips.
   *Sie sollten sehen:* Die Spur enthält zwei Clips, die nun gemeinsam kopiert werden können.
6. Drücken Sie **Tab**, um einen Clip auf der Spur zu fokussieren, und anschließend **Enter**, um ihn auszuwählen.
7. Wählen Sie **Spuren → Spur duplizieren**.
8. Das Projekt zeigt nun 4 Clips und 3 Spuren.
   *Sie sollten sehen:* Das Original und seine Kopie enthalten jeweils beide Clips an denselben Positionen auf der Zeitleiste.

## Tipps

- Das Original und die Kopie werden beide abgespielt. [Schalten Sie eine Spur stumm oder auf Solo](/guides/tracks-and-export/mute-and-solo-tracks/), um beim Vergleichen jeweils nur eine Version zu hören.
- Um nur eine Passage zu kopieren, [duplizieren Sie eine Auswahl auf eine neue Spur](/guides/editing/duplicate-a-selection-to-a-new-track/).
- Mit **Bearbeiten → Rückgängig** entfernen Sie die duplizierte Spur.
