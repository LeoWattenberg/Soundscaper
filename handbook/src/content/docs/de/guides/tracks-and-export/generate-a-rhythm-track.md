## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Eine erzeugte Rhythmusspur gibt Ihnen beim Aufnehmen oder Bearbeiten eine gleichmäßige Orientierung. Stellen Sie Tempo, Taktart und Taktanzahl passend zu dem Abschnitt ein, an dem Sie arbeiten.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Generate → Rhythm Track (Nyquist)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → Nyquist → Rhythm Track**. Setzen Sie im Dialog **Rhythm Track** **Tempo (bpm)** auf `120`, **Beats per bar** auf `4` und **Number of bars** auf `4`, und drücken Sie dann **Anwenden**. Vier Takte bei 120 Schlägen pro Minute ergeben eine achtsekündige Orientierung. Lassen Sie den Beat-Sound beim voreingestellten Metronomklick.
3. Das Projekt zeigt nun 1 Clip.
   *Das sollten Sie sehen:* Auf der Zeitleiste erscheint ein achtsekündiger Rhythmusclip.

## Tipps

- Ändern Sie **Swing amount** von `0`, wenn die abwechselnden Schläge lockerer klingen sollen.
- Für eine längere Rhythmusspur erhöhen Sie **Number of bars** oder senken Sie **Tempo (bpm)**.
