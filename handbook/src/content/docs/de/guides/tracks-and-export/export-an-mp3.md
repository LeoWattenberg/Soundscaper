Ein MP3 ist klein, spielt überall und ist das, was die meisten Podcast-Hosts und Messaging-Apps erwarten. Die Exportfunktion rendert das gesamte Projekt – jeden Track, jeden Effekt und jede Bearbeitung – in eine Datei.

:::note[Aus Audacity?]
Dies ist Audacitys **Datei → Audio exportieren → MP3**. Die Namen können in Soundscaper abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und laden Sie die Aufnahme, die Sie veröffentlichen möchten. Die Datei erscheint als Clip auf einem eigenen Track.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **MP3** und klicken Sie auf **Exportieren**. Die Datei wird heruntergeladen, sobald das Rendern abgeschlossen ist, und der Link bleibt im Dialog. Die Datei wird im Browser codiert; nichts verlässt Ihren Computer.

## Tipps

- Ein MP3 ist eine Lieferkopie, keine Sicherung. Speichern Sie das Projekt oder exportieren Sie auch eine WAV, falls Sie es erneut bearbeiten möchten.
- Spitzen bei voller Skalierung können nach dem Codieren abschneiden. Normalisieren Sie es auf −1 dB oder weniger, bevor Sie exportieren.
- Die Bitrate-Modus entscheidet, wie der Encoder die Bits verbraucht. Die Standard-Einstellung variiert die Rate je nach Material und ist für die meisten Lieferungen die richtige Wahl; wählen Sie Konstant, wenn ein Host oder ein älteres Hardware-Gerät eine feste Rate erfordert.
