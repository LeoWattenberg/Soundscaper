Ein MP3 ist klein, wird überall abgespielt und wird von den meisten Podcast-Hosts und Messaging-Apps erwartet. Der Export rendert das gesamte Projekt – jede Spur, Effekt und Bearbeitung – in eine einzige Datei.

:::note[Komme von Audacity?]
Dies ist Audacitys **Datei → Export Audio → MP3**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme zum Veröffentlichen aus. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **MP3**, und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Darstellung abgeschlossen ist, und ihr Link bleibt im Dialog. Die Datei wird im Browser codiert; nichts verlässt Ihren Computer.

## Tipps

- Ein MP3 ist eine Lieferkopie, keine Sicherung. Bewahren Sie das Projekt auf oder exportieren Sie auch ein WAV, wenn Sie möglicherweise erneut bearbeiten möchten.
- Peaks direkt auf voller Skala können nach der Codierung abschneiden. Normalisieren Sie auf -1 dB oder niedriger, bevor Sie exportieren.
- Bit Rate Mode entscheidet, wie der Encoder die Bits ausgibt. Die Standard-Einstellung variiert die Rate, um dem Material gerecht zu werden, und ist die richtige Antwort für die meisten Lieferungen; wählen Sie Konstant, wenn ein Host oder ein älterer Hardware-Player eine feste Rate anfordert.
