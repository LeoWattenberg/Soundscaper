## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Weißes Rauschen verteilt Energie über den gesamten Frequenzbereich. Erzeugen Sie einen kurzen, leisen Clip für eine Textur oder zum Prüfen einer Signalkette, ohne eine Aufnahme zu importieren.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Generate → Noise (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → Rauschen**. Setzen Sie im Dialog **Rauschen** **Amplitude** auf `0.1` und **Dauer (Sekunden)** auf `2`; drücken Sie **Erzeugen**. Lassen Sie Rauschfarbe zunächst auf Weiß. Hören Sie zuerst mit niedriger Amplitude hinein.
3. Das Projekt enthält jetzt 1 Clip.
   *Sie sollten sehen:* Ein zweisekündiger Rauschclip erscheint auf der Zeitleiste.

## Tipps

- Rauschfarbe bietet außerdem Rosa und Braun für andere Texturen.
- Setzen Sie in einem bestehenden Projekt den Cursor an den gewünschten Startpunkt. Bei einer Zeitauswahl ersetzt der Generator die ausgewählte Passage.
