## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Chirp erzeugt einen Ton, dessen Frequenz sich über die Dauer verändert. Ein sanfter Sweep eignet sich für einen elektronischen Effekt oder um zu hören, wie eine Signalkette auf verschiedene Frequenzen reagiert.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Generate → Chirp (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → Gleitton**. Setzen Sie im Dialog **Gleitton** **Startfrequenz (Hz)** auf `220`, **Endfrequenz (Hz)** auf `880`, **Startamplitude (0–1)** auf `0.1`, **Endamplitude (0–1)** auf `0.1` und **Dauer (Sekunden)** auf `2`; drücken Sie **Erzeugen**. Der Ton steigt bei gleichbleibend niedriger Amplitude um zwei Oktaven.
3. Das Projekt enthält jetzt 1 Clip.
   *Sie sollten sehen:* Ein zweisekündiger Sweep erscheint auf der Zeitleiste.

## Tipps

- Setzen Sie die höhere Frequenz an den Anfang, um einen abwärts gerichteten Sweep zu erzeugen.
- Wellenform und Interpolation verändern den Klang des Sweeps und den Übergang zwischen den Endpunkten.
