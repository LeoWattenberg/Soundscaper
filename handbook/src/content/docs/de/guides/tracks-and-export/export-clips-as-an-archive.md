## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Beim Export einzelner Clips bleibt jeder Schnitt als eigene Audiodatei erhalten; alle Dateien werden in einem Archiv gesammelt. Teilen Sie zuerst einen Abschnitt in Clips auf und wählen Sie dann im Exportdialog den Ausgabemodus für Clips.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, deren Clips Sie getrennt exportieren möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Ziehen Sie im Lineal über dem Clip, um einen Abschnitt auszuwählen, der als eigener Clip exportiert werden soll.
4. Wählen Sie **Bearbeiten → Audio-Clips → Teilen**.
5. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV** und **Ausgang** auf **Einzelne Clips (nach Clips getrennt)**, und drücken Sie **Exportieren**. Sobald der Export abgeschlossen ist, wird die Datei heruntergeladen; ihr Link bleibt im Dialog verfügbar. Jeder Clip wird als eigene WAV-Datei in ein ZIP-Archiv gerendert.

## Tipps

- Verwenden Sie aussagekräftige Clipnamen, damit Sie die Dateien im Archiv wiedererkennen.
- Wählen Sie **Gesamtes Projekt**, wenn Sie statt einzelner Clipdateien einen einzelnen Mix möchten.
