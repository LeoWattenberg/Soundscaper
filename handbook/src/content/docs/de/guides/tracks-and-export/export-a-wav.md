WAV speichert jedes Sample genau so, wie es der Editor hat. Verwenden Sie es für Masterings, zum Übergeben von Audio an einen Videoeditor oder eine andere DAW und für alles, was Sie möglicherweise erneut verarbeiten möchten.

:::note[Kommt von Audacity?]
Dies ist **Datei → Audio exportieren → WAV** in Audacity. Die Namen unten sind die eigenen von Soundscaper, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufzeichnung aus, die Sie liefern möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV** und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Rendergenerierung abgeschlossen ist, und der Link bleibt im Dialog.

## Tipps

- WAV-Dateien sind groß: etwa zehn Megabyte pro Minute für Stereo bei CD-Qualität.
- Um jede Spur als eigene Datei zu exportieren, setzen Sie **Modus** im Exportdialog auf einzelne Stems.
