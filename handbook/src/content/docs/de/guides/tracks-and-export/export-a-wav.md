WAV behält jede Probe exakt so bei, wie sie im Editor vorliegt. Verwenden Sie es für Masters, zum Übergeben von Audio an einen Videoeditor oder eine andere DAW und für alles, was Sie möglicherweise erneut verarbeiten möchten.

:::note[Kommen Sie von Audacity?]
Dies entspricht **Datei → Audio exportieren → WAV** in Audacity. Die untenstehenden Bezeichnungen sind die eigenen von Soundscaper und weichen manchmal ab.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die aufzunehmende Aufnahme aus. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV** und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Renderung abgeschlossen ist, und ihr Link bleibt im Dialogfeld erhalten.

## Tipps

- WAV-Dateien sind groß: etwa zehn Megabyte pro Minute für Stereo in CD-Qualität.
- Um jede Spur als eigene Datei zu exportieren, setzen Sie **Modus** im Exportdialog auf einzelne Stems.
