## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Morsecode überträgt eine Nachricht als zeitlich abgestimmte Punkte, Striche und Pausen. Der Generator zeigt eine Vorschau der Codierung und berechnet die Clipdauer anhand von Nachricht und Geschwindigkeit.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **No directly matching built-in Morse code generator**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → Morsecode**. Setzen Sie im Dialog **Morsecode** **Nachricht** auf `SOS`, **Tempo (Wörter pro Minute)** auf `20`, **Frequenz (Hz)** auf `600` und **Amplitude** auf `0.2`; drücken Sie **Erzeugen**. Ersetzen Sie die Beispielnachricht durch Ihren Text. Prüfen Sie die Vorschau; ungültige Zeichen verhindern die Erzeugung.
3. Das Projekt enthält jetzt 1 Clip.
   *Sie sollten sehen:* Ein Morseclip enthält die Nachricht; seine Länge richtet sich nach der gewählten Geschwindigkeit.

## Tipps

- Bei niedrigerer Geschwindigkeit werden Punkte, Striche und Pausen länger, ohne dass sich die Tonhöhe ändert.
- Duration ist hier ein schreibgeschütztes Ergebnis. Ändern Sie Nachricht oder Geschwindigkeit, um die Clipdauer anzupassen.
