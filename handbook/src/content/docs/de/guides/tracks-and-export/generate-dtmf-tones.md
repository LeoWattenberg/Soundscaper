## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

DTMF verwendet für jedes Telefonsymbol zwei gleichzeitig erklingende Töne. Erzeugen Sie mit Pausen zwischen den Symbolen die Folge, die Sie für einen Telefoneffekt benötigen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Generate → DTMF Tones (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Erzeugen → DTMF-Töne**. Setzen Sie im Dialog **DTMF-Töne** **DTMF-Folge** auf `123`, **Amplitude** auf `0.2` und **Dauer (Sekunden)** auf `2`; drücken Sie **Erzeugen**. Geben Sie Ihre Tastenfolge in der gewünschten Reihenfolge ein. Die Gesamtdauer umfasst Töne und Pausen.
3. Das Projekt enthält jetzt 1 Clip.
   *Sie sollten sehen:* Ein Clip enthält die Tastenfolge in der eingegebenen Reihenfolge.

## Tipps

- Tastverhältnis bestimmt, welcher Anteil der Folge aus Tönen statt Stille besteht.
- Die Timing-Zusammenfassung zeigt vor dem Erzeugen die Länge jedes Tons und jeder Pause.
