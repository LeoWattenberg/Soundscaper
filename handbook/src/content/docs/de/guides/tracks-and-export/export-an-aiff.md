## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

AIFF ist ein unkomprimiertes PCM-Format, das häufig in Audio-Workflows auf Apple-Systemen verwendet wird. Exportieren Sie in diesem Format, wenn ein Programm oder eine Lieferung AIFF verlangt.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **File → Export Audio → Other uncompressed files → AIFF (Audacity 3)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme oder den Mix, den Sie bereitstellen möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **AIFF**, und drücken Sie **Exportieren**. Sobald der Export abgeschlossen ist, wird die Datei heruntergeladen; ihr Link bleibt im Dialog verfügbar.
   *Das sollten Sie sehen:* Der Exportdialog stellt eine herunterladbare `.aiff`-Datei bereit.

## Tipps

- AIFF ist verlustfrei, benötigt aber mehr Speicherplatz als komprimierte Formate wie [FLAC](/guides/tracks-and-export/export-a-flac/).
- Wählen Sie ein Sampleformat und eine Abtastrate, die den Lieferanforderungen entsprechen.
