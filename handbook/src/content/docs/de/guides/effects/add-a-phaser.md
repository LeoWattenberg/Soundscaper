Ein Phaser mischt einen Ton mit einer Kopie von sich selbst, die durch bewegliche Allpass-Stufen geleitet wird, sodass sich Kerben durch das Spektrum bewegen, im Takt eines langsamen Oszillators. Auf einer Gitarre, einem elektrischen Klavier oder einem Pad erzeugt es den Wirbel, der auf unzähligen Aufnahmen zu hören ist. Audacity 3 lieferte einen Phaser, Audacity 4 jedoch nicht, daher ist dies eine gute Alternative.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Phaser (Audacity 3; Audacity 4 hat keinen Phaser)**. Die Namen unten sind Soundscapers eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie den zu bearbeitenden Ton aus. Er wird als Clip auf seiner eigenen Spur abgelegt.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Effekt → Verzerrung und Modulation → Phaser**. Im **Phaser**-Dialog setzen Sie **Stufen** auf `4` und **LFO-Frequenz** auf `0.6`, und drücken Sie dann **Auf Auswahl anwenden**. Mehr Stufen erzeugen tiefere Kerben; vier ist ein klassisches Pedal. Die LFO-Frequenz bestimmt, wie schnell sich der Sweep bewegt – 0,6 Hz ist ein langsamer, musikalischer Wirbel.
5. Drücken Sie **Wiedergabe**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Der Ton wirbelt langsam, während sich die Kerben durch ihn bewegen.

## Tipps

- **Rückkopplung** schärft die Kerben zu einem metallischeren, resonanteren Sweep; halten Sie sie in der Nähe von Null für einen subtilen Effekt.
- Der Phaser kann auch als Echtzeit-Effekt in einem Spur-Rack ausgeführt werden, sodass Sie den Sweep hören können, während Sie ihn anpassen: [Echtzeit-Effekt zu einer Spur hinzufügen](/guides/effects/add-a-realtime-effect-to-a-track/).
