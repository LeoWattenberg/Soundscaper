Audacitys Nyquist-Plugins sind kleine Skripte, die Effekte, Generatoren und Analysetools hinzufügen, und Soundscaper bündelt dieselben unter einem Nyquist-Untermenü in jedem Menü. Tremolo ist ein guter Einstieg: Es schwingt die Lautstärke in einem festen Rhythmus.

:::hinweis[Von Audacity kommen?]
Dies ist Audacitys **Effekt → Tremolo (ein Nyquist-Plugin)**. Die Namen können in Soundscaper abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme aus, um das Plugin darauf anzuwenden. Die Datei landet als eigene Spur.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Effekt → Nyquist → Tremolo**. Im **Tremolo**-Dialog setzen Sie **Frequenz (Hz)** auf `6` und klicken dann auf **Anwenden**. Sechs Schwingungen pro Sekunde sind ein klassisches Amp-Tremolo. In Nyquist-Dialogen wird statt „Anwenden“ **Anwenden auf Auswahl** verwendet.
5. Spielen Sie **Abspielen** und dann **Stopp**.

*Sie sollten sehen:* Die Aufnahme pulsiert in der Lautstärke.

## Tipps

- Die Generatoren- und Analysemenu-Untermenüs haben ebenfalls Nyquist-Untermenüs mit Plugins wie Pluck und Beat Finder.
- **Tools → Nyquist-Prompt** führt ein Skript aus, das Sie selbst eingeben.
