## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Der Graphic EQ hat für jedes Terzband einen eigenen Regler. Bewegen Sie benachbarte Regler gemeinsam für eine breite Änderung oder einen einzelnen Regler für eine gezieltere Anpassung.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → EQ and Filters → Graphic EQ**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme, deren Klang Sie anpassen möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → EQ und Filter → Grafischer EQ**. Stellen Sie im Dialog **Grafischer EQ** **1000 Hz** auf `4` und drücken Sie **Auf Auswahl anwenden**. Eine leichte Anhebung bei 1 kHz verleiht Präsenz, ohne das ganze Spektrum zu verändern.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Die Aufnahme erhält eine leichte Präsenzanhebung um 1 kHz.

## Tipps

- Beginnen Sie mit kleinen Anhebungen und Absenkungen. Viele angehobene Bänder erhöhen auch den Gesamtpegel und können Übersteuerungen verursachen.
- Für eine glatte, frei geformte Kurve zwischen Frequenzen verwenden Sie [Filter Curve EQ](/guides/effects/draw-a-filter-curve/).
