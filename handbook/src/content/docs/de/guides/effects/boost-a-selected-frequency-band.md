## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Spectral Amplify hebt ein Frequenzband nur innerhalb eines ausgewählten Zeitraums an. Eine leichte Anhebung kann einen leisen Ton oder ein Detail hervorheben, ohne die gesamte Aufnahme lauter zu machen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Spectral Tools → Amplify selection (Audacity 4)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme mit dem leisen Detail, das Sie hervorheben möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der Spur, die Sie untersuchen möchten, und wählen Sie **Spurvisualisierung → Spektrogramm**.
4. Ziehen Sie im Lineal über dem Clip, um den Abschnitt mit dem Detail auszuwählen.
5. Wählen Sie **Effekt → Spektrale Bearbeitung → Spektralen Frequenzbereich auswählen**. Setzen Sie **Untere Frequenz (Hz)** auf `200` und **Obere Frequenz (Hz)** auf `320`, setzen Sie **Verstärkung (dB)** auf `4`, und drücken Sie dann **Spektral verstärken**. Eine moderate Anhebung um 4 dB verstärkt nur das ausgewählte Band in diesem Abschnitt.
6. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Das ausgewählte Detail tritt in diesem Abschnitt stärker hervor; der Pegel des Rests bleibt unverändert.

## Tipps

- Grenzen Sie den Frequenzbereich eng um das gewünschte Detail ein. Ein breiteres Band hebt auch benachbarte Klänge an.
- Verringern Sie die Anhebung, wenn der bearbeitete Abschnitt scharf klingt oder lauter ist als das umgebende Audio.
