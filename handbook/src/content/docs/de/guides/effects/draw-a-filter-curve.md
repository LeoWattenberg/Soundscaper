## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Mit Filter Curve EQ zeichnen Sie die gewünschte Klangbalance, statt ein festes Band oder einen Shelf-Filter zu wählen. Setzen Sie Punkte, um Rumpeln abzusenken, die Mitten zu erhalten oder die höchsten Frequenzen abzurunden.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → EQ and Filters → Filter Curve EQ**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme, deren Frequenzbalance Sie formen möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → EQ und Filter → Filterkurven-EQ**. Klappen Sie im Dialog **Filterkurven-EQ** **Kurvenpunkte (Hz:dB)** auf und setzen Sie **Kurvenpunkte (Hz:dB)** auf `20:-12, 60:-12, 100:0, 1000:0, 8000:-3, 20000:-3`; drücken Sie anschließend **Auf Auswahl anwenden**. Die Kurve senkt tiefes Rumpeln und die höchsten Frequenzen ab, während die Mitten gleich bleiben.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Tiefes Rumpeln und die höchsten Frequenzen sind reduziert, während die Mitten gleich bleiben.

## Tipps

- Halten Sie Kurvenänderungen zurückhaltend, besonders wenn die Aufnahme bereits kräftige Bässe enthält.
- Die waagerechte Achse zeigt die Frequenz, die senkrechte den Gain. Ein tieferer Punkt senkt den jeweiligen Frequenzbereich ab.
