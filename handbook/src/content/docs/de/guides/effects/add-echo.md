Echo spielt die Auswahl nach einer Verzögerung erneut ab, dann erneut, wobei jede Wiederholung leiser ist als die vorherige. Es ist der klassische Slap-Back auf einer Stimme oder der Canyon-Effekt auf einem Schrei.

:::note[Kommst du von Audacity?]
Dies ist Audacitys **Effekt → Verzögerung und Hall → Echo**. Die untenstehenden Namen gehören zu Soundscaper und weichen manchmal ab.
:::

## Schritte

1. Öffne Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wähle **Datei → Audio importieren** und wähle den Ton, der echoartig klingen soll. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Wähle **Markierung → Alles markieren**.
4. Wähle **Effekt → Verzögerung und Hall → Echo**. Setze im Dialog **Echo** den **Abklingfaktor** auf `0.4`, und drücke dann **Auf Auswahl anwenden**. Jede Wiederholung ist 0,4-mal so laut wie die vorherige, sodass das Echo nach einigen Wiederholungen verklingt. **Verzögerungszeit** bestimmt den Abstand zwischen ihnen.
5. Drücke **Wiedergabe**, um zuzuhören, und dann **Stopp**.
   *Du solltest sehen:* Der Ton wird von nachlassenden Wiederholungen von sich selbst gefolgt.

## Tipps

- Füge nach dem Clip zuerst zwei Sekunden Stille hinzu (**Generieren → Stille**), damit die letzten Wiederholungen Platz zum Klingen haben.
- Für einen Raum statt einzelner Wiederholungen verwende [Hall](/guides/effects/add-reverb/).
