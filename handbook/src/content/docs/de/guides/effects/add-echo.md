## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Echo spielt die Auswahl nach einer Verzögerung erneut ab, dann wieder, wobei jeder Wiederholung leiser ist als die letzte. Es ist der klassische Slap-back-Effekt auf einer Stimme oder der Canyon-Effekt auf einem Ruf.

:::note[Kommt von Audacity?]
Dies ist Audacitys **Effekt → Verzögerung und Hall → Echo**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie den Klang aus, der widerhallen soll. Es landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Effekt → Verzögerung und Hall → Echo**. Im **Echo**-Dialog setzen Sie den **Abklingfaktor** auf `0.4` und drücken Sie dann **Auf Auswahl anwenden**. Jede Wiederholung ist 0,4-mal so laut wie die vorherige, so dass das Echo nach einigen Wiederholungen abklingt. **Verzögerungszeit** legt den Abstand zwischen ihnen fest.
5. Drücken Sie **Wiedergabe**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Der Klang wird von abklingenden Wiederholungen von sich selbst gefolgt.

## Tipps

- Fügen Sie nach dem Clip ein paar Sekunden Stille hinzu (**Generieren → Stille**), damit die letzten Wiederholungen Platz zum Klingen haben.
- Für einen Raumklang anstelle von deutlichen Wiederholungen verwenden Sie [Reverb](/guides/effects/add-reverb/).
