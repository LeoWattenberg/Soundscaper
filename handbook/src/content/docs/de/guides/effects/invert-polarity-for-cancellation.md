## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Zwei identische, zeitlich ausgerichtete Aufnahmen löschen sich gegenseitig aus, wenn die Polarität einer Aufnahme umgekehrt wird und beide gleichzeitig abgespielt werden. Mit dieser Prüfung lässt sich feststellen, ob Bearbeitungen oder Effekte eine Kopie vom Original unterscheiden.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Special → Invert**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, die Sie mit einer Kopie vergleichen möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der zu vergleichenden Spur und wählen Sie **Spur duplizieren**.
5. Wählen Sie **Effekt → Spezial → Invertieren**. Der Effekt wird sofort auf die Auswahl angewendet. Die umgekehrte Polarität der Kopie macht übereinstimmende Samples gegenphasig, während das Original unverändert bleibt.
6. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Stimmen die Spuren überein und sind sie ausgerichtet, löschen sie sich aus. Verbleibender Ton weist auf einen Unterschied hin.

## Tipps

- Für eine vollständige Auslöschung müssen Timing und Pegel übereinstimmen; schon eine kleine Verschiebung hinterlässt einen hörbaren Rest.
- Lassen Sie bei beiden Spuren die Stummschaltung aus und Solo ausgeschaltet, damit beide zusammen zu hören sind. Undo stellt die duplizierte Spur vor dem Polaritätstest wieder her.
