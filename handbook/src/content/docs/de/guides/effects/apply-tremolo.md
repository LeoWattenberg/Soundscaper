## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Tremolo bewegt die Lautstärke in einem gleichmäßigen Muster auf und ab, ähnlich einer rhythmischen Welle. Verwenden Sie es bei einem gehaltenen Instrument, Pad oder einer Stimme, wenn ein statischer Klang mehr Bewegung braucht.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Audacity 4.0.1: Effect → Distortion and Modulation → Tremolo**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann den gehaltenen Klang, dem Sie einen Puls geben möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Verzerrung und Modulation → Tremolo**. Setzen Sie im Dialog **Tremolo** **Tiefe** auf `60` und **Frequenz** auf `4`; drücken Sie anschließend **Auf Auswahl anwenden**. Depth bestimmt, wie weit die Lautstärke in jedem Zyklus absinkt; Frequency gibt die Pulse pro Sekunde an.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Der ausgewählte Klang schwillt in einem gleichmäßigen Puls an und ab.

## Tipps

- Eine niedrigere **Frequenz** erzeugt ein langsames Schwellen, eine höhere einen schnelleren, deutlicheren Puls.
- Halten Sie **Tiefe** moderat, wenn der Klang auch während der leiseren Phase hörbar bleiben soll.
