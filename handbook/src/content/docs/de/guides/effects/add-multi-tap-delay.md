## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Delay wiederholt einen Klang nach einer festgelegten Pause und leitet ihn durch mehrere leiser werdende Echos. Der Multi-Tap-Effekt eignet sich für rhythmische Wiederholungen einer Phrase, Note oder Passage.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Audacity 4.0.1: Effect → Delay and Reverb → Delay**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Phrase oder den Klang, den Sie wiederholen möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Delay und Hall → Delay**. Setzen Sie im Dialog **Delay** **Verzögerungszeit** auf `0.3` und **Anzahl der Echos** auf `4`; wählen Sie **Vollständige Echos einschließen** für **Dauer der Echos** und drücken Sie **Auf Auswahl anwenden**. Delay time bestimmt den Abstand der Wiederholungen; die Echozahl legt ihre Anzahl fest. Der Effekt kann die Passage verlängern, damit die Echos ausklingen können.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Auf den ausgewählten Klang folgt eine Reihe leiser werdender Echos.

## Tipps

- Eine kürzere **Verzögerungszeit** erzeugt eine dichte Textur. Mit einer längeren hören Sie die Wiederholungen deutlicher einzeln.
- Verringern Sie **Pegel pro Echo**, wenn sich die Wiederholungen zu stark aufbauen oder den Originalklang überdecken.
