## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein Tiefpassfilter lässt Frequenzen unterhalb seiner Grenzfrequenz passieren und senkt die darüberliegenden allmählich ab. Eine vorsichtige Einstellung zähmt Zischen oder eine zu helle Aufnahme, ohne ihr Fundament zu entfernen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → EQ and Filters → Low-Pass Filter**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme, deren Höhen Sie abmildern möchten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → EQ und Filter → Tiefpass**. Stellen Sie im Dialog **Tiefpass** **Grenzfrequenz** auf `5000` und wählen Sie **12 dB/Oktave** für **Flankensteilheit**; drücken Sie anschließend **Auf Auswahl anwenden**. Bei 5 kHz werden die Höhen etwas weicher; 12 dB pro Oktave ergibt einen sanften Abfall.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Die hohen Frequenzen klingen etwas weicher.

## Tipps

- Senken Sie die Grenzfrequenz, um mehr Höhen zu entfernen. Achten Sie darauf, dass Becken und Zischlaute nicht dumpf werden.
- Wählen Sie einen steileren **Flankensteilheit**, wenn die Frequenzen oberhalb der Grenze stärker abgesenkt werden sollen.
