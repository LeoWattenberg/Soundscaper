Die Effekte im Menü „Effekte“ ändern den Audio einmalig und endgültig. Ein Echtzeit-Effekt befindet sich stattdessen auf einer Spur: Er läuft während der Wiedergabe und des Exports, seine Einstellungen können jederzeit geändert werden und das Originalaudio wird nie verändert. Dies ist die richtige Wahl für Hall, EQ und Kompression, die Sie anpassen möchten, während sich der Mix weiterentwickelt.

:::note[Kommen Sie von Audacity?]
Dies entspricht Audacitys **Effekt → Echtzeit-Effekte hinzufügen**. Die untenstehenden Bezeichnungen sind Soundscaper-eigene und weichen manchmal ab.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme aus, auf der der Effekt platziert werden soll. Die Datei wird als Clip auf einer eigenen Spur abgelegt.
3. Drücken Sie **Effekte** im Kopf der Spur, um das Effekte-Panel zu öffnen, drücken Sie **Effekte** im Rack der Spur und wählen Sie **Hall**. Das Einstellungsfenster öffnet sich; drücken Sie **Schließen**, wenn Sie fertig sind. Das Rack der Spur listet nun Hall. Das Einstellungsfenster bleibt jederzeit über das Rack verfügbar, wenn Sie es anpassen möchten.
4. Drücken Sie **Wiedergabe**, um zuzuhören, dann **Stopp**.
   *Sie sollten sehen:* Die Spur wird durch den Hall abgespielt.

## Tipps

- Fügen Sie mehrere Effekte zu einem Rack hinzu und ziehen Sie sie, um ihre Reihenfolge zu ändern; jeder speist den nächsten.
- Das Master-Rack, unten im Effekte-Panel, verarbeitet den gesamten Mix.
