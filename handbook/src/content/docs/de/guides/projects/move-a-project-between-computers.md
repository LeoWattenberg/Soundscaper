Die Projektbibliothek befindet sich in einem Browser auf einem Computer. Um ein Projekt an einen anderen Ort zu übertragen – auf ein anderes Gerät, zu einem Kollegen oder auf ein Sicherungslaufwerk –, exportieren Sie es als Projektdatei. Die `.sscape`-Datei enthält das Audio und alle Bearbeitungen und lässt sich in jeder Soundscaper-Anwendung öffnen.

:::note[Aus Audacity kommend?]
Dies entspricht Audacitys **Datei → Projekt speichern → Projekt sichern, dann Datei → Öffnen**.
Die Namen können sich unter Umständen unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie das Projektmaterial aus. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Datei → Projekt-Datei exportieren (.sscape)**. Das gesamte Projekt wird als eine `.sscape`-Datei heruntergeladen. Bewahren Sie die Datei an einem sicheren Ort auf; sie enthält das komplette Projekt.
4. Wählen Sie **Datei → Öffnen** und wählen Sie die Datei aus. Auf einem Computer, der das Projekt noch nicht hat, öffnet sie sich direkt. Hier, wo die Bibliothek das Projekt bereits enthält, bietet Soundscaper **Als schreibgeschützte Kopie öffnen** an – klicken Sie darauf.

*Sie sollten Folgendes sehen:* Das Projekt öffnet sich mit seiner Spur und dem Clip genau so, wie es exportiert wurde.

## Tipps

- Eine schreibgeschützte Kopie kann nicht bearbeitet werden, bis Sie sie über das Menü **Datei** als eigenes Projekt speichern.
- Die Datei ist ein ZIP-Archiv mit dem Audio darin; entpacken Sie sie nicht manuell.
