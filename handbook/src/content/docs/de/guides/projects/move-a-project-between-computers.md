Das Projekt-Library befindet sich in einem Browser auf einem Computer. Um ein Projekt an einen anderen Ort zu tragen – ein anderes Gerät, ein Kollege, eine Sicherung – exportieren Sie es als Projekt-Datei. Die `.sscape`-Datei enthält das Audio und alle Bearbeitungen und öffnet sich in jeder Soundscaper-Anwendung.

:::note[Aus Audacity kommend?]
Dies entspricht Audacitys **Datei → Projekt speichern → Projekt sichern, dann Datei → Öffnen**.
Die Namen können sich unter Umständen unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie das Projektmaterial aus. Die Datei wird als eigene Spur geladen.
3. Wählen Sie **Datei → Projekt-Datei exportieren (.sscape)**. Das gesamte Projekt wird als eine `.sscape`-Datei heruntergeladen. Bewahren Sie die Datei an einem sicheren Ort auf; sie enthält das komplette Projekt.
4. Wählen Sie **Datei → Soundscaper-Projekt-Datei öffnen (.sscape)** und wählen Sie die Datei aus. Auf einem Computer, der das Projekt noch nicht hat, öffnet sie sich direkt. Hier, wo die Library das Projekt bereits enthält, bietet Soundscaper **Als nur-Lese-Kopie öffnen** an – klicken Sie darauf.

*Sie sollten Folgendes sehen:* Das Projekt öffnet sich mit seiner Spur und dem Clip genau so, wie es exportiert wurde.

## Tipps

- Eine nur-Lese-Kopie kann nicht bearbeitet werden, bis Sie sie als eigenes Projekt speichern, über das Menü **Datei**.
- Die Datei ist ein ZIP-Archiv mit dem Audio darin; entpacken Sie sie nicht manuell.
