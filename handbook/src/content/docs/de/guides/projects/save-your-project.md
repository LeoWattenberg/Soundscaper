Ein Projekt ist mehr als nur Audio: Es umfasst Spuren, Clips, Effekte, Markierungen und Verlauf. Das Speichern bewahrt all diese Elemente im lokalen Projektverzeichnis des Browsers auf diesem Computer auf, wo es aus der Datei-Menü wieder geöffnet werden kann. Soundscaper speichert auch während der Bearbeitung, daher ist dies hauptsächlich eine Sicherheitsmaßnahme.

:::note[Aus Audacity kommend?]
Dies entspricht Audacitys **Datei → Projekt speichern**. Die unten aufgeführten Namen stammen von Soundscaper und können manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie etwas aus, mit dem Sie arbeiten möchten. Die Datei landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Datei → Projekt speichern**. Der Speicherindikator in der Statusleiste zeigt an, dass das Projekt gespeichert wurde.

## Tipps

- Um ein Projekt auf einen anderen Computer zu verschieben oder eine Kopie außerhalb des Browsers zu speichern, siehe [Projekt zwischen Computern verschieben](/guides/projects/move-a-project-between-computers/).
- Ein Audio-Export ist eine Wiedergabekopie, nicht ein Projekt. Bewahren Sie das Projekt auf, wenn Sie es möglicherweise erneut bearbeiten möchten.
