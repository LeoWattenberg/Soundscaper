## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein Vortrag, der pro Thema eine Datei ergeben sollte, eine Albumseite, die in Titel geschnitten werden muss, ein Hörbuch mit einem Kapitel pro Datei: Setzen Sie an den Anfang jedes Teils eine Markierung und exportieren Sie einmal. Jede Markierung eröffnet ein Kapitel bis zur nächsten; jedes Kapitel wird als eigene Datei mit dem Namen der Markierung in einem Archiv gespeichert. Audacity 4.0.1 bietet denselben Ablauf mit „Mehrere exportieren“.

:::note[Kommen Sie von Audacity?]
Dies entspricht Audacitys **Datei → Audio exportieren → Markierte Bereiche als separate Audiodateien**. Die unten genannten Bezeichnungen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme aus, die aufgeteilt werden soll. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Fenster → Projekt-Bin**. Die Aufnahme befindet sich nun in der Zeitleiste, sodass das Ausblenden der Ablage Platz für das Markierungsfenster schafft.
4. Wählen Sie **Ansicht → Marker**. Die Markierungsspur ist der Ort, an dem die Kapitelanfänge angezeigt und benannt werden.
5. Drücken Sie die Schaltfläche **Zum Projektanfang springen** in der Symbolleiste. Das erste Kapitel sollte ganz am Anfang beginnen, daher muss die erste Markierung bei Null stehen.
6. Öffnen Sie das Markierungsfenster (**Fenster → Marker** zeigt es an) und drücken Sie **Markierung am Abspielkopf hinzufügen**. Drücken Sie auf der neuen Markierung die Eingabetaste, geben Sie `Part one` ein und drücken Sie erneut die Eingabetaste, um sie zu benennen.
7. Klicken Sie auf die Wellenform dort, wo der zweite Teil beginnt, um den Cursor dorthin zu setzen.
8. Öffnen Sie das Markierungsfenster (**Fenster → Marker** zeigt es an) und drücken Sie **Markierung am Abspielkopf hinzufügen**. Drücken Sie auf der neuen Markierung die Eingabetaste, geben Sie `Part two` ein und drücken Sie erneut die Eingabetaste, um sie zu benennen.
9. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **MP3**, setzen Sie **Ausgabe** auf **Kapitel (aufgeteilt nach Markierungen)** und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Renderung abgeschlossen ist, und der Link bleibt im Dialogfeld erhalten. Jedes Kapitel wird zu einer MP3-Datei im Archiv, nummeriert in der Reihenfolge und benannt nach seiner Markierung.

## Tipps

- Eine benannte Region exportiert genau ihren eigenen Bereich, daher sollten Sie Regionen anstelle von Markierungen verwenden, wenn zwischen den Teilen Lücken bestehen.
- Labels auf einer Label-Spur werden auf dieselbe Weise aufgeteilt: Wählen Sie **Kapitel (aufgeteilt nach Labels)**, um an diesen statt an den Markierungen zu schneiden.
- Um nach Spuren statt nach Markierungen aufzuteilen, siehe [Jede Spur als eigene Datei exportieren](/guides/projects/export-each-track-as-its-own-file/).
