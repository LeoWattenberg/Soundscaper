Ein Vortrag, der pro Thema eine Datei ergeben sollte, eine Albumseite, die in Titel geschnitten werden muss, ein Hörbuch mit einem Kapitel pro Datei: Setzen Sie an den Anfang jedes Teils eine Markierung und exportieren Sie einmal. Jede Markierung öffnet ein Kapitel, das bis zur nächsten Markierung reicht, und jedes Kapitel wird als eigene Datei geschrieben, benannt nach der Markierung, innerhalb eines einzelnen Archivs. Audacity 3 hat dies mit „Export Multiple“ (Mehrere exportieren) erledigt; Audacity 4 hat diese Funktion nicht wieder eingeführt.

:::note[Kommen Sie von Audacity?]
Dies entspricht in Audacity **Datei → Audio exportieren → Mehrere exportieren, aufgeteilt nach Labels (Audacity 3; Audacity 4 hat kein „Mehrere exportieren“)**. Die untenstehenden Bezeichnungen sind Soundscaper-eigene und weichen manchmal ab.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme aus, die aufgeteilt werden soll. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Ansicht → Markierungen anzeigen**. Die Markierungsspur ist der Ort, an dem die Kapitelanfänge angezeigt und benannt werden.
4. Drücken Sie die Schaltfläche **Zum Projektanfang springen** in der Symbolleiste. Das erste Kapitel sollte ganz am Anfang beginnen, daher muss die erste Markierung bei Null stehen.
5. Öffnen Sie das Markierungsfenster (**Ansicht → Fenster → Markierungen** zeigt es an) und drücken Sie **Markierung an Wiedergabekopf hinzufügen**. Drücken Sie auf der neuen Markierung die Eingabetaste, geben Sie `Part one` ein und drücken Sie erneut die Eingabetaste, um sie zu benennen.
6. Klicken Sie auf die Wellenform dort, wo der zweite Teil beginnt, um den Cursor dorthin zu setzen.
7. Öffnen Sie das Markierungsfenster (**Ansicht → Fenster → Markierungen** zeigt es an) und drücken Sie **Markierung an Wiedergabekopf hinzufügen**. Drücken Sie auf der neuen Markierung die Eingabetaste, geben Sie `Part two` ein und drücken Sie erneut die Eingabetaste, um sie zu benennen.
8. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **MP3**, setzen Sie **Ausgabe** auf **Kapitel (aufgeteilt nach Markierungen)** und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Renderung abgeschlossen ist, und der Link bleibt im Dialogfeld erhalten. Jedes Kapitel wird zu einer MP3-Datei im Archiv, nummeriert in der Reihenfolge und benannt nach seiner Markierung.

## Tipps

- Eine benannte Region exportiert genau ihren eigenen Bereich, daher sollten Sie Regionen anstelle von Markierungen verwenden, wenn zwischen den Teilen Lücken bestehen.
- Labels auf einer Label-Spur werden auf dieselbe Weise aufgeteilt: Wählen Sie **Kapitel (aufgeteilt nach Labels)**, um an diesen statt an den Markierungen zu schneiden.
- Um nach Spuren statt nach Markierungen aufzuteilen, siehe [Jede Spur als eigene Datei exportieren](/guides/projects/export-each-track-as-its-own-file/).
