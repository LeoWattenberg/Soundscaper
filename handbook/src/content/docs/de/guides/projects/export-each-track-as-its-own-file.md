Ein Mix-Ingenieur, ein Video-Editor oder ein Mitarbeiter an einem anderen Programm möchte in der Regel die einzelnen Spuren und nicht den Mix. Ein Stems-Export rendert jede Spur in eine eigene Datei, alle gleich lang und auf den Projektstart ausgerichtet, und packt sie in ein Archiv.

:::note[Komme ich von Audacity?]
Dies ist Audacity's **Datei → Exportieren → Audio exportieren → Mehrere Dateien exportieren, nach Spuren aufteilen**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die erste Spur. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Importieren** und wählen Sie die zweite Spur. Sie landet als Clip auf ihrer eigenen Spur.
4. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV**, setzen Sie **Ausgabe** auf **Einzelne Stems (nach Spuren aufteilen)**, und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald das Rendern abgeschlossen ist, und der Link bleibt im Dialog. Jede Spur wird zu einer WAV-Datei innerhalb der ZIP-Datei, die auf die gleiche Länge zugeschnitten ist, sodass sie beim Import an anderer Stelle übereinstimmen.

## Tipps

- Stummschalten und Solo haben keinen Einfluss auf Stems; jede Spur wird gerendert.
- Benennen Sie die Spuren vor dem Exportieren – die Stem-Dateien übernehmen ihre Namen.
