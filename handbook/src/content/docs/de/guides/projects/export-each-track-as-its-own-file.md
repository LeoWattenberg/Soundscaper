Ein Mischingenieur, ein Video-Editor oder ein Kollaborator an einem anderen Projekt wünscht sich normalerweise die Teile, nicht den Mix. Ein Stems-Export rendert jede Spur in ihre eigene Datei, alle gleich lang und auf den Projektbeginn ausgerichtet, und packt sie in einem Archiv zusammen.

:::note[Aus Audacity?]
Dies ist Audacitys **Datei → Audio exportieren → Mehrere exportieren, nach Spuren aufteilen**. Die Namen unten sind Soundscaper-eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die erste Spur aus. Die Datei landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Audio importieren** und wählen Sie die zweite Spur aus. Die Datei landet als Clip auf ihrer eigenen Spur.
4. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV**, **Ausgabe** auf **Individuelle Stems (nach Spuren aufteilen)** und klicken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald die Rendern abgeschlossen ist, und ihr Link bleibt im Dialog. Jede Spur wird als WAV-Datei im ZIP-Archiv geschnitten, um sie bei der Importierung anderswo auszurichten.

## Tipps

- Stummschalten und Solo haben keinen Einfluss auf Stems; jede Spur wird gerendert.
- Benennen Sie die Spuren vor dem Export – die Stempelfdateien nehmen ihre Namen von ihnen.
