Der Netzbrummen sitzt bei einer Frequenz: 50 Hz in den meisten Teilen der Welt, 60 Hz in Amerika, manchmal mit einer Oberton bei der doppelten Frequenz. Ein Notch-Filter schneidet eine schmale Bandbreite um eine Frequenz heraus und lässt alles andere unberührt, was viel sanfter ist als ein Hochpassfilter, wenn das Brummen nicht tief genug ist, um abzurollen. Dasselbe Werkzeug entfernt ein Monitor-Pfeifen oder ein klingelndes Resonanz, sobald Sie seine Frequenz kennen.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → EQ und Filter → Notch-Filter**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme mit dem Brummen aus. Es landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → EQ und Filter → Notch-Filter**. Im **Notch-Filter**-Dialog setzen Sie die **Notch-Frequenz** auf `50` und **Q** auf `4`, dann drücken Sie **Auf Auswahl anwenden**. Verwenden Sie 60, wenn Ihr Netz 60 Hz hat. Ein Q von 4 ist ein schmaler Notch; senken Sie es, wenn das Brummen wandert, erhöhen Sie es, wenn der Schnitt auf der Stimme hörbar ist.
5. Drücken Sie **Abspielen**, um zuzuhören, dann **Stopp**.
   *Sie sollten sehen:* Das Brummen ist weg und die Stimme klingt gleich.

## Tipps

- Unsicher über die Frequenz? [Zeichne das Spektrum](/guides/analysis/plot-a-spectrum/) eines ruhigen Abschnitts auf und lies den Peak.
- Brummen hat oft einen Oberton bei der doppelten Frequenz. Führen Sie den Filter erneut bei 100 oder 120 Hz aus, wenn etwas übrig bleibt.
