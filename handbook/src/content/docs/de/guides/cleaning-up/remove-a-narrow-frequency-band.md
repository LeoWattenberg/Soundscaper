## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein gleichmäßiger Pfeifton oder elektronischer Ton kann nur in einem kleinen Frequenzband und nur während eines Teils der Aufnahme auftreten. Spectral Delete entfernt dieses Band innerhalb einer Zeitauswahl und lässt die benachbarten Frequenzen bestehen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Spectral Tools → Delete selection (Audacity 4)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme mit dem kurzen tonalen Klang. Sie erscheint als Clip auf einer eigenen Spur.
3. Öffnen Sie über die Schaltfläche **Spuroptionen** im Spurkopf das Menü der Spur, die Sie untersuchen möchten, und wählen Sie **Spurvisualisierung → Spektrogramm**.
4. Ziehen Sie im Lineal über dem Clip, um den Zeitraum auszuwählen, in dem der Ton hörbar ist.
5. Wählen Sie **Effekt → Spektrale Bearbeitung → Spektralen Frequenzbereich auswählen**. Setzen Sie **Untere Frequenz (Hz)** auf `200` und **Obere Frequenz (Hz)** auf `320`, und drücken Sie dann **Spektral löschen**. Dadurch wird der Ton bei 261,6 Hz nur im ausgewählten Zeitraum entfernt.
6. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Der tonale Klang ist in diesem Abschnitt leiser, während der Rest der Aufnahme erhalten bleibt.

## Tipps

- Suchen Sie den Ton im Spektrogramm und grenzen Sie Zeit- und Frequenzbereich vor dem Löschen möglichst eng ein.
- Spectral Delete wirkt nur im ausgewählten Zeit- und Frequenzbereich; mit normalem Delete wird der gesamte ausgewählte Abschnitt entfernt.
