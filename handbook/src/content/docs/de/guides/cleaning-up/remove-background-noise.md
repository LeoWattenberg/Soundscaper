Störender, konstanter Hintergrundlärm – ein Lüfter, ein Kühlschrank, Netzbrummen – kann in zwei Durchgängen entfernt werden. Zuerst zeigen Sie der Rauschunterdrückung einen Abschnitt mit nur Lärm, damit sie ein Profil erstellen kann; dann wenden Sie den Effekt auf alles an. Das Profil ist das, was hier funktioniert, also wählen Sie einen Teil der Aufnahme, in dem niemand spricht.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Rauschentfernung und -reparatur → Rauschunterdrückung, in zwei Durchgängen**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme, die Sie bereinigen möchten. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Ziehen Sie im Lineal über dem Clip, um einen Abschnitt auszuwählen, der nur Lärm enthält – normalerweise das Vorspiel vor dem Sprechen. Das Profil sollte nichts anderes enthalten als den Lärm, den Sie entfernen möchten.
4. Wählen Sie **Effekt → Rauschentfernung und -reparatur → Rauschunterdrückung** und drücken Sie **Rauschprofil erstellen**. Die Statusleiste meldet, dass das Profil bereit ist. Drücken Sie **Schließen**, um das Dialogfeld vorerst zu verlassen.
5. Wählen Sie **Auswählen → Alles auswählen**. Das Profil wird beibehalten; jetzt muss der Effekt wissen, was gereinigt werden soll.
6. Wählen Sie **Effekt → Rauschentfernung und -reparatur → Rauschunterdrückung**. Im Dialog **Rauschunterdrückung** setzen Sie **Rauschunterdrückung** auf `12` und drücken Sie dann **Auf Auswahl anwenden**. Etwa 12 dB ist ein guter erster Versuch. Höhere Werte entfernen mehr Lärm, aber beginnen, Stimmen hohl klingen zu lassen.
7. Drücken Sie **Wiedergabe**, um zuzuhören, dann **Stopp**.
  *Du solltest sehen:* Das Vorspiel ist viel leiser und die Stimme bleibt unverändert.

## Tipps

- Wenn das Ergebnis wässrig oder metallisch klingt, mache die Änderung rückgängig und versuche einen niedrigeren Wert für **Rauschunterdrückung** oder eine niedrigere **Empfindlichkeit**.
- Rauschunterdrückung funktioniert nur bei Lärm, der sich während der gesamten Aufnahme nicht ändert. Für einen einzelnen Husten oder Klick schneiden Sie ihn heraus oder verwenden Sie stattdessen Klickentfernung.
