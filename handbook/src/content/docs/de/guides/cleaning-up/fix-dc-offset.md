Einige Soundkarten und günstige Schnittstellen fügen einer Aufnahme eine konstante Spannung hinzu, sodass die gesamte Wellenform leicht über oder unter der Mittellinie liegt. Sie können es direkt nicht hören, aber es verschwendet Headroom und erzeugt ein Klicken bei jedem Schnitt. Die Entfernung der Gleichstromverschiebung zentriert die Wellenform wieder.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Lautstärke und Kompression → Gleichstromverschiebung entfernen**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme aus, die nicht zentriert ist. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Gleichstromverschiebung entfernen**. Der Effekt wird sofort auf die Auswahl angewendet.
5. Drücken Sie **Abspielen**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Die Wellenform ist auf der Null-Linie zentriert.

## Tipps

- [Normalisieren](/guides/volume/normalize-peaks/) entfernt Gleichstromverschiebungen als Teil seiner Aufgabe, sodass Sie nichts zusätzliches tun müssen, wenn Sie ohnehin normalisieren.
- Eine Verschiebung, die sich über die Aufnahme ändert, ist kein Gleichstrom; verwenden Sie stattdessen einen [Hochpassfilter](/guides/cleaning-up/remove-low-rumble/).
