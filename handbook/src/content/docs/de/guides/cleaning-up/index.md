Nehmen Sie Rauschen, Klicks, Brummen und tote Luft aus einer Aufnahme heraus, bevor Sie daran arbeiten.

## Anleitungen in dieser Kategorie

- [Scharfe Zischlaute mit einem De-Esser zähmen](/guides/cleaning-up/reduce-sibilance-with-a-de-esser/) — Laute S- und Sch-Laute in einer Stimme absenken, ohne die gesamte Aufnahme leiser zu machen.
- [Entfernen von Hintergrundgeräuschen](/guides/cleaning-up/remove-background-noise/) — Unterweisen Sie die Rauschreduzierung, wie das Brummen klingt, und entfernen Sie es dann aus der gesamten Aufnahme.
- [Entfernen von Klicks und Knallgeräuschen](/guides/cleaning-up/remove-clicks-and-pops/) — Entfernen Sie kurze, scharfe Klicks aus einer Aufnahme, ohne den Rest zu berühren.
- [Verkürzen langer Pausen](/guides/cleaning-up/remove-silent-pauses/) — Verdichten Sie eine Aufnahme, indem Sie jede lange Stille auf eine kurze Lücke trimmen.
- [Stummschalten eines Teils einer Aufnahme](/guides/cleaning-up/silence-part-of-a-recording/) — Ersetzen Sie einen Audioabschnitt durch Stille, während alles andere an Ort und Stelle bleibt.
- [Entfernen von tiefem Brummen](/guides/cleaning-up/remove-low-rumble/) — Reduzieren Sie die tiefen Bass-Wummer von Verkehr, Wind und Handhabung mit einem Hochpassfilter.
- [Beheben einer DC-Verschiebung](/guides/cleaning-up/fix-dc-offset/) — Zentrieren Sie eine Wellenform, die über oder unter der Null-Linie liegt.
- [Entfernen von Netzbrummen mit einem Notch-Filter](/guides/cleaning-up/remove-mains-hum-with-a-notch-filter/) — Schneiden Sie eine einzelne Frequenz — 50 oder 60 Hz Brummen, ein Pfeifen, ein Klingeln — ohne den Rest zu berühren.
- [Stummschalten von Geräuschen zwischen Sätzen mit einem Gate](/guides/cleaning-up/gate-out-noise-between-phrases/) — Lassen Sie die Stimme durch und schließen Sie die Tür für Umgebungsgeräusche, wenn niemand spricht.
