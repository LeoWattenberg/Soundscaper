## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Lange Pausen können gesprochene Inhalte träge wirken lassen. Werden alle Pausen entfernt, wird das Zuhören jedoch anstrengend. Truncate Silence kürzt nur den überschüssigen Teil von Pausen, die länger als eine festgelegte Mindestdauer sind.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Special → Truncate Silence**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie eine Aufnahme mit zu langen Pausen. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Spezial → Stille kürzen**. Setzen Sie im Dialog **Stille kürzen** **Schwellwert** auf `-40` und **Minimale Stille** auf `0.5`, wählen Sie bei **Überschüssige Stille komprimieren** die Option **Aktion** und setzen Sie **Komprimieren auf** auf `50`. Drücken Sie anschließend **Auf Auswahl anwenden**. Stille, die länger als 0,5 Sekunden dauert, wird auf die Hälfte ihrer überschüssigen Dauer verkürzt; zwischen den Sätzen bleibt eine Pause.
5. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Die langen Pausen sind kürzer, lassen aber weiterhin etwas Stille zwischen den Sätzen.

## Tipps

- Erhöhen Sie **Minimale Stille**, wenn kürzere Pausen unverändert bleiben sollen, oder verringern Sie **Komprimieren auf**, um lange Pausen stärker zu verkürzen.
- Achten Sie darauf, ob Atemzüge oder Satzenden abgeschnitten werden. Machen Sie die Änderung rückgängig, wenn der Rhythmus unnatürlich wirkt.
