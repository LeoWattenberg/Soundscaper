## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein De-Esser senkt starke Zischlaute ab und lässt den übrigen Teil der Stimme weitgehend unverändert. Verwenden Sie ihn bei einer Sprachpassage, in der S- oder Sch-Laute stärker hervorstechen als die umgebenden Wörter.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **No direct built-in equivalent in Audacity’s current effect list.**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Sprachpassage mit störenden S-Lauten. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Rauschentfernung und Reparatur → De-Esser**. Setzen Sie im Dialog **De-Esser** **Frequenz** auf `6000` und **Maximale Absenkung** auf `6`; drücken Sie dann **Auf Auswahl anwenden**. Frequency zielt auf den Zischlautbereich; Maximum reduction begrenzt, wie stark diese Stellen abgesenkt werden.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Die Zischlaute sind leiser, während die übrige Stimme präsent bleibt.

## Tipps

- Hören Sie beim Einstellen von **Frequenz** auf die S-Laute. Ein zu niedriger Wert kann Konsonanten und Brillanz dämpfen.
- Beginnen Sie mit einer moderaten **Maximale Absenkung** und erhöhen Sie sie nur, wenn Zischlaute noch stören.
