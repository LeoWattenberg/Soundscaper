## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Clip Fix schätzt die fehlenden Spitzen kurzer Übersteuerungen anhand der benachbarten Wellenform. Verwenden Sie den Effekt auf einer Kopie Ihrer Aufnahme und hören Sie genau hin; längere übersteuerte Passagen lassen sich damit nicht rekonstruieren.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Noise Removal and Repair → Clip Fix (Audacity 3 and 4)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie eine Aufnahme mit kurzen übersteuerten Spitzen, die Sie reparieren möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Nyquist → Clip Fix**. Setzen Sie im Dialog **Clip Fix** den Wert von **Threshold of Clipping (%)** auf `95` und **Reduce amplitude to allow for restored peaks (dB)** auf `-9`, und drücken Sie **Anwenden**. Der Schwellenwert erkennt abgeflachte Spitzen; der zusätzliche Headroom lässt Platz für deren geschätzte Form.
5. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Die reparierten Spitzen klingen weniger scharf. Vergleichen Sie das Ergebnis mit dem unveränderten Original, bevor Sie die Änderung übernehmen.

## Tipps

- Clip Fix eignet sich am besten für kurze, leichte Übersteuerungen; fehlende Details in anhaltender Verzerrung kann der Effekt nicht wiederherstellen.
- Bewahren Sie eine unveränderte Kopie auf, damit Sie die reparierten Transienten vergleichen und die Änderung rückgängig machen können, falls die Wellenform unnatürlicher klingt.
