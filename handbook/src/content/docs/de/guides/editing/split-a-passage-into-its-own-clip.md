## Wofür diese Anleitung gedacht ist {#what-this-guide-is-for}

Ein Wort, eine musikalische Phrase oder ein neuer Versuch lässt sich als eigener Clip abtrennen, ohne die Länge der Aufnahme zu ändern. Wenn ein Zeitbereich ausgewählt ist, teilt „Teilen“ den Clip an beiden Auswahlgrenzen. Danach können Sie das mittlere Stück unabhängig verschieben oder bearbeiten.

:::note[Kommen Sie von Audacity?]
Das entspricht Audacitys **Edit → Clip → Split (Ctrl+I)**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme mit der Passage aus. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Ziehen Sie im Lineal über dem Clip, um die Passage auszuwählen, die Sie abtrennen möchten. Lassen Sie vor und nach der Auswahl etwas Audio, damit beide Grenzen innerhalb des Clips liegen.
4. Wählen Sie **Bearbeiten → Audio-Clips → Teilen**.
5. Das Projekt zeigt nun 3 Clips an.
   *Sie sollten sehen:* Die ausgewählte Passage liegt als eigener Clip zwischen dem vorherigen und dem nachfolgenden Audio. Alle drei Teile behalten ihre ursprünglichen Positionen auf der Zeitleiste.

## Tipps

- Für nur einen Schnitt [teilen Sie am Cursor](/guides/editing/split-a-clip-at-the-cursor/), statt einen Bereich auszuwählen.
- Mit **Bearbeiten → Rückgängig** stellen Sie den ursprünglichen Clip wieder her, falls eine der Grenzen angepasst werden muss.
- Wenn Sie stattdessen das Audio um die Passage herum verwerfen möchten, [behalten Sie nur den gewünschten Teil](/guides/editing/keep-only-a-selection/).
