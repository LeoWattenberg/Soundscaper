Beim Standard-Zoom passt ein gesamter Song auf den Bildschirm, und ein einzelnes Wort ist einige Pixel breit. Durch Zoomen können Sie den Cursor genau auf einen Takt oder in die Lücke zwischen zwei Wörtern platzieren; der Zoom auf die Auswahl zeigt nur den Abschnitt, an dem Sie arbeiten.

:::note[Komme von Audacity?]
Dies ist Audacity's **Ansicht → Zoom (Strg+1, Strg+2, Strg+3)**. Die unten genannten Namen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme, die Sie bearbeiten möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Ansicht → Zoom → Reinzoomen**. Jeder Schritt verdoppelt die Breite einer Sekunde. Strg+1 tut dasselbe.
4. Wählen Sie **Ansicht → Zoom → Reinzoomen**.
5. Ziehen Sie in der Skala über dem Clip, um den Abschnitt auszuwählen, an dem Sie arbeiten möchten.
6. Wählen Sie **Ansicht → Zoom → Auf Auswahl zoomen**. Die Auswahl füllt nun die Zeitleiste.
7. Wählen Sie **Ansicht → Zoom → Normaler Zoom**. Strg+2 bringt den Standard-Zoom zurück.

## Tipps

- Strg und das Mausrad zoomen um den Zeiger, was der schnellste Weg ist, um einen bestimmten Punkt zu erreichen.
- Über einer vertikalen Skala zoomen Strg und das Mausrad die Wellenformamplitude oder den Frequenzbereich des Spektrogramms. Klicken Sie mit der rechten Maustaste auf die Skala für die gleichen Zoom-Steuerelemente.
- Zoomen ändert nichts am Projekt; es ist nur Ihre Ansicht.
