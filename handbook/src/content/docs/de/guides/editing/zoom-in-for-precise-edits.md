Bei der Standard-Vergrößerung passt ein gesamter Song auf den Bildschirm, und ein einzelnes Wort ist einige Pixel breit. Durch Zoomen können Sie den Cursor genau auf einen Takt oder in die Lücke zwischen zwei Wörtern platzieren; durch Zoomen auf die Auswahl wird nur der Abschnitt angezeigt, an dem Sie arbeiten.

:::note[Komme von Audacity?]
Dies ist Audacity's **Ansicht → Vergrößern (Strg+1, Strg+2, Strg+3)**. Die unten genannten Namen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme, die Sie detailliert bearbeiten möchten. Die Datei wird als Clip auf seiner eigenen Spur abgelegt.
3. Wählen Sie **Ansicht → Vergrößern → Vergrößern**. Jeder Schritt verdoppelt die Breite einer Sekunde. Strg+1 tut dasselbe.
4. Wählen Sie **Ansicht → Vergrößern → Vergrößern**.
5. Ziehen Sie in der Skala über dem Clip, um den Abschnitt auszuwählen, den Sie bearbeiten möchten.
6. Wählen Sie **Ansicht → Vergrößern → Auf Auswahl vergrößern**. Die Auswahl füllt nun die Zeitachse.
7. Wählen Sie **Ansicht → Vergrößern → Normal**. Strg+2 stellt die Standard-Vergrößerung wieder her.

## Tipps

- Strg und das Mausrad zoomen um den Zeiger, was die schnellste Möglichkeit ist, sich an einen bestimmten Ort zu begeben.
- Zoomen ändert nichts am Projekt; es ist nur Ihre Ansicht.
