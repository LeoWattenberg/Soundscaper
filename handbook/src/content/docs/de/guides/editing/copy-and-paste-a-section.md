Das Kopieren eines guten Refrains, um einen schwachen zu ersetzen, das Wiederholen einer Taktzeile oder das Verschieben eines Satzes ans Ende: Kopieren und Einfügen funktionieren bei Audio genauso wie bei Text. Wählen Sie einen Abschnitt aus, kopieren Sie ihn, setzen Sie den Cursor an die gewünschte Stelle und fügen Sie ihn ein.

:::note[Kommen Sie von Audacity?]
Dies entspricht in Audacity **Bearbeiten → Kopieren, dann Bearbeiten → Einfügen (Strg+C, Strg+V)**. Die unten genannten Namen sind die eigenen von Soundscaper und weichen manchmal ab.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, ist ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme mit dem Abschnitt, den Sie kopieren möchten. Die Datei erscheint als Clip auf einer eigenen Spur.
3. Ziehen Sie in der Linealansicht über dem Clip, um den zu kopierenden Abschnitt auszuwählen.
4. Wählen Sie **Bearbeiten → Kopieren**.
5. Klicken Sie auf die Wellenform an der Stelle, an der die Kopie eingefügt werden soll, um den Cursor dort zu setzen. Das Einfügen erfolgt am Cursor; das übliche Ziel ist das Ende des Clips.
6. Wählen Sie **Bearbeiten → Einfügen → Einfügen**.
7. Das Projekt zeigt nun 2 Clips an.
   *Sie sollten sehen:* Der kopierte Abschnitt ist ein neuer Clip hinter dem Original.

## Tipps

- **Bearbeiten → Einfügen → Einfügen** verschiebt das spätere Audio, anstatt das Einfügen darüberzulegen.
- Die Zwischenablage funktioniert über Projekt-Registerkarten hinweg, sodass ein Abschnitt aus einem Projekt in ein anderes kopiert werden kann.
