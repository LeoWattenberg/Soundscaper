## Wofür diese Anleitung gedacht ist {#what-this-guide-is-for}

„Einfügen“ schafft Platz für kopiertes Audio, statt vorhandenen Ton zu überlagern. Späteres Audio auf der Zielspur rückt um die Länge der kopierten Passage nach rechts. So können Sie eine Phrase wiederholen oder einen zusätzlichen Satz mitten in eine Aufnahme einsetzen.

:::note[Kommen Sie von Audacity?]
Das entspricht Audacitys **Edit → Copy, then Edit → Paste**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die Aufnahme mit der Passage aus, die Sie kopieren möchten. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Ziehen Sie im Lineal über dem Clip, um die Passage auszuwählen, die Sie an anderer Stelle einfügen möchten.
4. Wählen Sie **Bearbeiten → Kopieren**.
5. Klicken Sie an der Stelle in die Wellenform des Zielclips, an der die Kopie beginnen soll. Dadurch wird der Zeitbereich aufgehoben und der Cursor als Einfügepunkt gesetzt.
6. Wählen Sie **Bearbeiten → Einfügen → Einsetzen**.
7. Das Projekt zeigt nun 3 Clips an.
   *Sie sollten sehen:* Die eingefügte Passage liegt zwischen zwei Teilen des ursprünglichen Clips. Der spätere Teil wurde nach rechts verschoben; der frühere Teil ist an seiner Position geblieben.

## Tipps

- „Einfügen“ verschiebt späteres Audio auf der Zielspur. **Bearbeiten → Einfügen → Einsetzen und Synchronität erhalten** schafft auf allen Spuren Platz, wenn deren zeitliche Abstimmung erhalten bleiben muss.
- Mit **Bearbeiten → Rückgängig** entfernen Sie die Einfügung und stellen die vorherige Position des späteren Audios wieder her.
