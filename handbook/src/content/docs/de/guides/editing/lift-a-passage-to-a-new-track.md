## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein Satz oder Take benötigt möglicherweise einen eigenen Pegel, ein eigenes Panorama oder eigene Effekte, während der Rest der Aufnahme unverändert bleibt. Split into new track trennt an den Auswahlgrenzen und verschiebt nur den gewählten Abschnitt auf eine neue Spur an derselben Stelle der Zeitleiste.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Edit → Clip → Split New**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme mit dem Abschnitt, den Sie herauslösen möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Ziehen Sie im Lineal über dem Clip, um den Abschnitt auszuwählen, den Sie auf eine eigene Spur verschieben möchten.
4. Wählen Sie **Bearbeiten → Audio-Clips → In neue Spur teilen**. Die Auswahl wird auf eine neue Spur verschoben; das Audio davor und danach bleibt auf der ursprünglichen Spur.
5. Das Projekt zeigt nun 3 Clips.
   *Das sollten Sie sehen:* Auf der ursprünglichen Spur liegt je ein Clip vor und nach der Auswahl. Eine neue Spur enthält den Abschnitt dazwischen.

## Tipps

- Der ausgewählte Abschnitt behält auf der neuen Spur seine ursprüngliche Position in der Zeitleiste.
- Verwenden Sie eine Spur, die nur diese Aufnahme enthält, wenn Sie den herausgelösten Abschnitt verschieben möchten, ohne anderes Material auf der Spur zu beeinflussen.
