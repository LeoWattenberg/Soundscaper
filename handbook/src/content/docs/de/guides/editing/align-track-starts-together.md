## Wofür diese Anleitung gedacht ist {#what-this-guide-is-for}

„Zusammen ausrichten“ verschiebt die ausgewählten Spuren so, dass ihre Inhalte an derselben Stelle beginnen: am Mittelwert ihrer bisherigen Startzeiten. Der gesamte Inhalt jeder Spur wird als Einheit verschoben, sodass die Abstände zwischen ihren Clips erhalten bleiben. Verwenden Sie dafür Spuren, auf denen jeweils nur die auszurichtende Aufnahme liegt.

:::note[Kommen Sie von Audacity?]
Das entspricht Audacitys **Tracks → Align content → Align together**. Die folgenden Namen sind Soundscapers eigene Bezeichnungen, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann die erste Aufnahme aus. Sie wird als Clip auf einer eigenen Spur eingefügt.
3. Wählen Sie **Datei → Importieren** und dann die zweite Aufnahme aus. Sie wird als Clip auf einer eigenen Spur eingefügt.
4. Ziehen Sie den Clip an seiner Namensleiste an eine spätere Stelle, sodass die beiden Aufnahmen zu unterschiedlichen Zeiten beginnen.
5. Drücken Sie **Tab**, um die erste Aufnahme zu fokussieren, und dann **Enter**, um sie auszuwählen. Fokussieren Sie anschließend die zweite Aufnahme und drücken Sie **Shift+Enter**, um sie der Auswahl hinzuzufügen. Spuren mit ausgewählten Clips werden ausgerichtet.
6. Wählen Sie **Spuren → Inhalt ausrichten → Zusammen ausrichten**.
7. Die erste Aufnahme beginnt nun an der gemeinsamen Startzeit.
8. Die zweite Aufnahme beginnt zur selben Zeit.
   *Sie sollten sehen:* Die linken Clipkanten liegen auf einer Linie, und beide Aufnahmen behalten ihre ursprüngliche Länge.

## Tipps

- Der gemeinsame Start liegt nicht unbedingt bei null. Um am Projektanfang zu beginnen, [richten Sie eine Aufnahme an null aus](/guides/editing/align-a-recording-to-zero/).
- Mit **Bearbeiten → Rückgängig** stellen Sie die vorherigen Positionen der Spuren wieder her.
