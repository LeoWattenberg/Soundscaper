Marker sind Notizen auf der Zeitleiste: wo ein Kapitel beginnt, wo ein Fehler korrigiert werden muss, wo die gute Aufnahme beginnt. Sie verändern das Audio nicht, sondern begleiten das Projekt und können als Label-Datei für andere Tools exportiert werden.

:::hinweis[Von Audacity kommen?
Dies entspricht Audacitys **Bearbeiten → Labels → Markierung an Auswahl (Strg+B)**. Die Namen unten sind die eigenen von Soundscaper, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Aufnahme aus, die Sie markieren möchten. Die Datei landet als eigene Spur.
3. Wählen Sie **Ansicht → Marker anzeigen**. Dies fügt eine Marker-Spur oben über den Spuren hinzu. Marker existieren ohne diese Spur, aber hier sehen und bearbeiten Sie sie.
4. Klicken Sie auf die Wellenform an der Stelle, an der der Marker erscheinen soll, um den Cursor dorthin zu setzen. Der Marker erscheint an der Cursorposition.
5. Mit dem Markierfenster geöffnet (**Ansicht → Panels → Marker** zeigt es an), drücken Sie **Marker an Spielkopf hinzufügen**. Drücken Sie Eingabe im neuen Marker, geben Sie `Chorus` ein und drücken Sie erneut Eingabe, um ihn zu benennen.

*Sie sollten sehen:* Der Marker erscheint in der Spur oben und in der Markierliste mit dem eingegebenen Namen.

## Tipps

- Mit einem Zeitbereich ausgewählt, fügt derselbe Button stattdessen eine benannte Region ein.
- **Datei → Exportieren → Exportieren als Labels** schreibt die Marker als Textdatei, die Audacity und andere Editoren lesen können.
