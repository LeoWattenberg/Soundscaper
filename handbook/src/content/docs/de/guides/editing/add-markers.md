Marker sind Notizen auf der Zeitachse: wo ein Kapitel beginnt, wo ein Fehler korrigiert werden muss, wo die gute Aufnahme beginnt. Sie verändern das Audio nicht, begleiten das Projekt und können als Beschriftungsdatei für andere Tools exportiert werden.

:::note[Komme von Audacity?]
Dies ist Audacitys **Bearbeiten → Beschriftungen → Beschriftung an Auswahl hinzufügen (Strg+B)**. Die unten genannten Namen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme aus, die Sie markieren möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Ansicht → Marker anzeigen**. Dies fügt eine Marker-Spur über den Spuren hinzu. Marker existieren ohne sie, aber die Spur ist der Ort, an dem Sie sie sehen und bearbeiten können.
4. Klicken Sie auf die Wellenform, wo der Marker hin soll, um den Cursor dorthin zu setzen. Der Marker wird dort platziert, wo der Cursor ist.
5. Mit dem Marker-Panel geöffnet (**Ansicht → Panels → Marker** zeigt es), drücken Sie **Marker am Abspielkopf hinzufügen**. Drücken Sie im neuen Marker Enter, geben Sie `Chorus` ein und drücken Sie erneut Enter, um ihn zu benennen.
   *Sie sollten sehen:* Der Marker wird in der Spur über den Spuren und in der Liste des Panels angezeigt, mit dem von Ihnen eingegebenen Namen.

## Tipps

- Mit einem Zeitbereich ausgewählt, fügt derselbe Button statt eines einzelnen Punktes eine benannte Region hinzu.
- **Datei → Exportieren → Exportieren als Beschriftungen** schreibt die Marker als Textdatei, die Audacity und andere Editoren lesen können.
