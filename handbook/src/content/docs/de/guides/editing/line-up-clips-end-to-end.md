Zwei Aufnahmen, die separat aufgenommen wurden, landen auf eigenen Spuren, beide beginnend bei Null. Um eine nach der anderen abzuspielen, muss die zweite an die Stelle der ersten enden. Mit der Funktion *Spuren ausrichten → Enden ausrichten* wird dies für jede ausgewählte Spur in der Reihenfolge der Spuren erledigt.

:::hinweis[Aus Audacity?]
Dies ist Audacitys **Spuren → Ausrichten → Enden ausrichten**. Die Namen können sich in Soundscaper unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist sofort bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die erste Aufnahme. Die Datei landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Datei → Audio importieren** und wählen Sie die zweite Aufnahme. Die Datei landet als Clip auf ihrer eigenen Spur.
4. Klicken Sie auf den Namen-Bar des ersten Clips, halten Sie dann Strg und klicken Sie auf den Namen-Bar des zweiten Clips, um beide auszuwählen.
5. Wählen Sie **Spuren → Inhalt ausrichten → Enden ausrichten**.
6. Die zweite Spur beginnt nun dort, wo die erste endet.
   *Sie sollten Folgendes sehen:* Die Clips spielen nacheinander ohne Überlappung und Lücke.

## Tipps

- **Zusammen ausrichten** macht das Gegenteil: Es verschiebt die ausgewählten Clips, damit sie gleichzeitig beginnen.
- Ziehen Sie einen Clip per Hand an seinen Namen-Bar; halten Sie Strg, um ihn auf der gleichen Spur zu halten.
