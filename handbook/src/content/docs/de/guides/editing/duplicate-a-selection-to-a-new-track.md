Duplizieren kopiert die Auswahl auf neue Spuren am unteren Rand des Projekts, zur gleichen Position in der Zeit. Es ist der übliche erste Schritt für die parallele Verarbeitung — eine stark komprimierte Kopie, die unter dem Original gemischt wird, eine Reverb-nur-Spur, eine doppelte Stimme.

:::note[Komme von Audacity?]
Dies ist Audacitys **Bearbeiten → Duplizieren (Strg+D)**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme mit dem zu duplizierenden Abschnitt aus. Sie landet als Clip auf ihrer eigenen Spur.
3. Ziehen Sie im Regler über dem Clip, um den zu duplizierenden Abschnitt auszuwählen.
4. Wählen Sie **Bearbeiten → Duplizieren**.
5. Das Projekt zeigt nun 2 Clips an.
   *Sie sollten sehen:* Ein zweiter Clip, der nur die Auswahl enthält, auf einer neuen Spur am unteren Rand des Projekts, zeitlich ausgerichtet.

## Tipps

- Stummschalten Sie eine der beiden Spuren, um die andere allein zu hören, während Sie sie formen.
- Wenn Sie mit dem Mix zufrieden sind, [mischen Sie die Spuren ab](/guides/tracks-and-export/mix-tracks-into-one/).
