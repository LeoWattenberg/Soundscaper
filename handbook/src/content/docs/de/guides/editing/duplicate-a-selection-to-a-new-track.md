Dupliziere eine Auswahl auf eine neue Spur direkt darunter, an derselben Position in der Zeit. Dies ist in der Regel der erste Schritt für die parallele Verarbeitung – eine stark komprimierte Kopie unter dem Original, eine Reverb-nur-Spur, eine doppelte Gesangspassage.

:::note[Aus Audacity?]
Dies ist Audacitys **Bearbeiten → Duplizieren (Strg+D)**. Die Namen können sich hier und dort von denen in Soundscaper unterscheiden.
:::

## Schritte

1. Öffne Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wähle **Datei → Audio importieren** und wähle die Aufnahme mit dem Abschnitt aus, den du duplizieren möchtest. Die Datei landet als Clip auf ihrer eigenen Spur.
3. Ziehe den Regler über dem Clip, um den zu duplizierenden Abschnitt auszuwählen.
4. Wähle **Bearbeiten → Duplizieren**.
5. Das Projekt zeigt nun zwei Clips.
   *Du solltest Folgendes sehen:* Ein zweiter Clip, der nur die Auswahl enthält, auf einer neuen Spur unter der ersten, zeitlich ausgerichtet.

## Tipps

- Schalte eine der beiden Spuren stumm, um die andere allein zu hören, während du sie formst.
- Wenn du mit der Mischung zufrieden bist, [mische die Spuren zusammen](/guides/tracks-and-export/mix-tracks-into-one/).
