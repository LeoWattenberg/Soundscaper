## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Wenn eine Aufnahme an einem bestimmten Einsatzpunkt beginnen soll, ist Ziehen nach Augenmaß ungenau. Align start to playhead verschiebt den Inhalt der ausgewählten Spur so, dass ihr Anfang am Cursor liegt, und erhält dabei die Länge der Aufnahme.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Tracks → Align Tracks → Align Start to Playhead**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, die Sie an einem Einsatzpunkt platzieren möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Ziehen Sie den Clip an seiner Namensleiste an eine spätere Stelle der Zeitleiste. Verschieben Sie den Clip zuerst, damit der Cursor eine andere Startposition markieren kann.
4. Klicken Sie an der Stelle auf die Wellenform, an der die Aufnahme beginnen soll, um dort den Cursor zu setzen.
5. Wählen Sie **Spuren → Inhalt ausrichten → Anfang an Abspielposition ausrichten**. Der früheste Clip der ausgewählten Spur wird an die Cursorposition verschoben.
6. Die Aufnahme beginnt nun am Abspielkopf.
   *Das sollten Sie sehen:* Der Clip beginnt am Einsatzpunkt und behält seine ursprüngliche Länge.

## Tipps

- Die Ausrichtung verschiebt alle Clips jeder ausgewählten Spur. Verwenden Sie eine Spur, auf der nur die zu verschiebende Aufnahme liegt.
- Mit **Spuren → Inhalt ausrichten → Anfang an Null ausrichten** setzen Sie eine ausgewählte Spur wieder an den Projektanfang.
