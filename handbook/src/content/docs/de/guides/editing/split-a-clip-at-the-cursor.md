## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein Split entfernt nichts. Es verwandelt einen Clip in zwei Clips, die sich aneinanderreihen, sodass Sie einen Teil an eine andere Stelle ziehen, ihn löschen oder ihm allein einen Effekt hinzufügen können. Der schnellste Weg ist das Split-Tool: Wenn es aktiv ist, schneidet jeder Klick auf einen Clip an dieser Stelle. 

:::note[Kommt von Audacity?]
Dies ist Audacitys **Bearbeiten → Clip-Grenzen → Split (Strg+I)**. Die unten genannten Namen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme aus, die Sie aufteilen möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Drücken Sie die Schaltfläche **Split-Tool** in der Symbolleiste. Der Zeiger schneidet nun statt auszuwählen. Drücken Sie **S**, um das Werkzeug von der Tastatur aus zu wechseln.
4. Klicken Sie auf die Wellenform, wo Sie den Schnitt haben möchten, um den Cursor dorthin zu setzen. Mit dem Split-Tool aktiv schneidet der Klick den Clip an dieser Stelle.
5. Das Projekt zeigt nun 2 Clips an.
   *Sie sollten sehen:* Zwei Clips sitzen nun dort, wo zuvor nur einer war.
6. Drücken Sie die Schaltfläche **Split-Tool** in der Symbolleiste. Drücken Sie sie erneut, um zum normalen Zeiger zurückzukehren.

## Tipps

- Um an der Wiedergabeposition zu teilen, wählen Sie den Clip aus und wählen Sie **Bearbeiten → Audio-Clips → Split**; mit einem Zeitbereich ausgewählt, teilt es an beiden Enden des Bereichs.
- Wählen Sie beide Hälften aus und wählen Sie **Bearbeiten → Audio-Clips → Verbinden der ausgewählten Clips**, um sie wieder zu einem Clip zu machen.
