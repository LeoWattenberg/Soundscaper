Ein zweistrophiger Loop, ein Hintergrundbett, das unter einem längeren Voice-Over laufen muss, ein Soundeffekt, der weiterlaufen soll: Repeat kopiert die Auswahl direkt hinter sich selbst so oft, wie Sie es anfordern.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Spezial → Wiederholen**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie den Sound, den Sie wiederholen möchten. Es landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → Spezial → Wiederholen**. Im **Wiederholen**-Dialog setzen Sie die **Anzahl der Wiederholungen** auf `2`, und drücken Sie dann **Auf Auswahl anwenden**. Zwei Wiederholungen ergeben drei Kopien in Folge.
5. Drücken Sie **Abspielen**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Der Abschnitt spielt dreimal ohne Lücke ab.

## Tipps

- Für eine nahtlose Schleife stellen Sie sicher, dass die Auswahl mit Stille beginnt und endet oder an einem Nullpunkt kreuzt (**Auswählen → An Nullpunkten**).
- Der Effekt ändert die Länge des Clips, sodass alles danach auf der gleichen Spur verschoben wird.
