Jeder Leitfaden behandelt eine Aufgabe – die Art von Aufgabe, nach der Audacity-Nutzer suchen – und zeigt, wie Sie sie in Soundscaper an Ihrer eigenen Aufnahme durchführen, einschließlich der genauen Menüeinträge und Dialogfelder, die Sie verwenden sollten. Ein Leitfaden setzt voraus, dass Sie Material zur Bearbeitung haben und ungefähr wissen, was Sie erreichen möchten; wenn Sie lieber zuerst durch ein Beispiel geführt werden möchten, beginnen Sie mit den [Tutorials](/tutorials/).

## [Aufräumen einer Aufnahme](/guides/cleaning-up/)

Entfernen Sie Rauschen, Knackser, Brummen und tote Luft aus einer Aufnahme, bevor Sie daran arbeiten.

- [Hintergrundrauschen entfernen](/guides/cleaning-up/remove-background-noise/) — Lehren Sie der Rauschunterdrückung, wie das Brummen klingt, und entfernen Sie es dann aus der gesamten Aufnahme.
- [Knackser und Pops entfernen](/guides/cleaning-up/remove-clicks-and-pops/) — Entfernen Sie kurze, scharfe Knackser aus einer Aufnahme, ohne den Rest zu berühren.
- [Lange Pausen verkürzen](/guides/cleaning-up/remove-silent-pauses/) — Straffen Sie eine Aufnahme, indem Sie jede lange Stille auf denselben kurzen Abstand zuschneiden.
- [Teil einer Aufnahme stummschalten](/guides/cleaning-up/silence-part-of-a-recording/) — Ersetzen Sie einen Abschnitt des Audios durch Stille, während alles an seinem Platz bleibt.
- [Tiefes Brummen entfernen](/guides/cleaning-up/remove-low-rumble/) — Schneiden Sie die Sub-Bass-Stöße von Verkehr, Wind und Handhabung mit einem Hochpassfilter heraus.
- [Eine DC-Offset korrigieren](/guides/cleaning-up/fix-dc-offset/) — Zentrieren Sie eine Wellenform, die über oder unter der Nulllinie liegt.
- [Netzfrequenzbrummen mit einem Notch-Filter entfernen](/guides/cleaning-up/remove-mains-hum-with-a-notch-filter/) — Schneiden Sie eine einzelne Frequenz – 50- oder 60-Hz-Brummen, ein Pfeifen, ein Klingeln – heraus, ohne den Rest zu berühren.
- [Das Rauschen zwischen Phrasen mit einem Gate stummschalten](/guides/cleaning-up/gate-out-noise-between-phrases/) — Lassen Sie die Stimme durch und schließen Sie die Tür für das Raumrauschen, wann immer niemand spricht.

## [Lautstärke und Dynamik](/guides/volume/)

Stellen Sie Pegel ein, gleichen Sie laute und leise Teile aus und treffen Sie ein Lieferziel.

- [Eine leise Aufnahme lauter machen](/guides/volume/make-a-recording-louder/) — Erhöhen Sie den Pegel einer Aufnahme um eine feste Anzahl von Dezibel mit Amplify.
- [Spitzen auf einen festgelegten Pegel normalisieren](/guides/volume/normalize-peaks/) — Bringen Sie den lautesten Punkt einer Aufnahme auf ein exaktes Niveau unterhalb der Vollskala.
- [Lautstärke für einen Podcast normalisieren](/guides/volume/normalize-loudness-for-podcasts/) — Passen Sie die wahrgenommene Lautstärke einer Episode an das Niveau an, das Streaming-Plattformen erwarten.
- [Lautstärke mit einem Kompressor ausgleichen](/guides/volume/even-out-volume-with-a-compressor/) — Reduzieren Sie den Abstand zwischen lauten und leisen Momenten, damit die Sprache leichter zu folgen ist.
- [Einfaden und ausfaden](/guides/volume/fade-in-and-fade-out/) — Beginnen Sie einen Clip aus der Stille und beenden Sie ihn sanft, anstatt ihn abzuschneiden.
- [Spitzen mit einem Limiter zähmen](/guides/volume/tame-peaks-with-a-limiter/) — Verhindern Sie, dass die lautesten Momente über eine Obergrenze hinausgehen, ohne den Rest zu berühren.
- [Musik unter einer Stimme ducken](/guides/volume/duck-music-under-a-voice/) — Drehen Sie einen Musikuntergrund automatisch herunter, wann immer eine Sprachspur spricht.
- [Lautstärke mit dem klassischen Kompressor ausgleichen](/guides/volume/even-out-volume-with-the-legacy-compressor/) — Verwenden Sie den ursprünglichen Kompressor von Audacity 3, mit seinem Rauschboden und seiner Make-up-Gain, auf einer Aufnahme.

- [Nur den gewünschten Teil behalten](/guides/editing/keep-only-a-selection/) — Schneiden Sie alles außerhalb einer Auswahl in einem Schritt weg.
- [Einen Abschnitt wiederholen](/guides/editing/repeat-a-section/) — Wiederholen Sie eine Auswahl eine festgelegte Anzahl von Malen, um sie länger zu machen.
- [Eine Aufnahme rückwärts abspielen](/guides/editing/reverse-audio/) — Drehen Sie eine Auswahl um, damit sie von Ende zu Anfang abgespielt wird.
- [Stellen in einer Aufnahme markieren](/guides/editing/add-markers/) — Legen Sie benannte Marker auf der Zeitachse ab, damit Sie Punkte später wiederfinden können.
- [Einen Abschnitt kopieren und einfügen](/guides/editing/copy-and-paste-a-section/) — Kopieren Sie einen Abschnitt und fügen Sie ihn an einer anderen Stelle auf der Spur ein.
- [Eine Auswahl auf eine neue Spur duplizieren](/guides/editing/duplicate-a-selection-to-a-new-track/) — Kopieren Sie einen Abschnitt auf seine eigene Spur, damit Sie ihn separat verarbeiten können.
- [Stille nach einem Clip hinzufügen](/guides/editing/add-silence-after-a-clip/) — Erzeugen Sie eine Lücke von exakter Länge am Cursor.
- [Clips aneinander ausrichten](/guides/editing/line-up-clips-end-to-end/) — Legen Sie zwei Clips auf verschiedenen Spuren aneinander, sodass einer den anderen folgt.
- [Für präzise Bearbeitungen zoomen](/guides/editing/zoom-in-for-precise-edits/) — Kommen Sie der Wellenform nahe genug, um auf einem Beat oder zwischen Wörtern zu schneiden.
- [Rückgängig machen und wiederherstellen](/guides/editing/undo-and-redo/) — Gehen Sie durch Ihre Bearbeitungen zurück und wieder vor.
- [Einen Abschnitt in einer Schleife abspielen, während Sie üben](/guides/editing/loop-a-section-while-you-practise/) — Spielen Sie einen ausgewählten Abschnitt immer wieder ab.
- [Einen Clip entlang der Zeitachse verschieben](/guides/editing/move-a-clip-along-the-timeline/) — Ziehen Sie einen Clip zu einer anderen Zeit auf seiner Spur.
- [Schneller oder langsamer hören, ohne die Aufnahme zu ändern](/guides/editing/listen-at-a-different-speed/) — Verlangsamen Sie einen Abschnitt, um ihn zu transkribieren, oder beschleunigen Sie eine lange Aufnahme, um sie zu überprüfen, und lassen Sie das Projekt unangetastet.

- [Einen Phaser hinzufügen](/guides/effects/add-a-phaser/) — Führen Sie eine Reihe von Notches durch einen Klang, um den klassischen wirbelnden Effekt für Gitarre und Keyboard zu erzielen.

## Wie die Anleitungen korrekt bleiben

Die Schritte sind Daten, die von zwei Tools geteilt werden: dem Generator, der diese Seiten schreibt, und der Browser-Suite (`tests/browser/soundscaper-guides.spec.js`), die jede Anleitung gegen jeden Build durchklickt. Eine Anleitung, die nicht mehr mit dem Editor übereinstimmt, lässt den Build fehlschlagen, anstatt veraltet zu werden.
