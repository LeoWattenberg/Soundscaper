Jeder Leitfaden behandelt eine Aufgabe – die Art, nach der Audacity-Benutzer suchen – und zeigt, wie man sie in Soundscaper an der eigenen Aufnahme durchführt, mit den genauen Menüpunkten und Dialogfeldern, die verwendet werden sollen. Ein Leitfaden setzt voraus, dass Sie Material zum Bearbeiten haben und grob wissen, was Sie erreichen möchten; wenn Sie lieber zuerst durch ein Beispiel geführt werden möchten, beginnen Sie mit den [Tutorials](/tutorials/).

## [Aufnahme bereinigen](/guides/cleaning-up/)

Entfernen Sie Rauschen, Klicks, Brummen und tote Luft aus einer Aufnahme, bevor Sie mit der Bearbeitung beginnen.

- [Hintergrundrauschen entfernen](/guides/cleaning-up/remove-background-noise/) — Unterweisen Sie die Rauschreduzierung, wie das Brummen klingt, und entfernen Sie es dann aus der gesamten Aufnahme.
- [Klicks und Pops entfernen](/guides/cleaning-up/remove-clicks-and-pops/) — Entfernen Sie kurze, scharfe Klicks aus einer Aufnahme, ohne den Rest zu berühren.
- [Lange Pausen verkürzen](/guides/cleaning-up/remove-silent-pauses/) — Verkürzen Sie eine Aufnahme, indem Sie jede lange Stille auf eine kurze Lücke trimmen.
- [Teil einer Aufnahme stummschalten](/guides/cleaning-up/silence-part-of-a-recording/) — Ersetzen Sie einen Audioabschnitt durch Stille, während alles andere an Ort und Stelle bleibt.
- [Niedriges Brummen entfernen](/guides/cleaning-up/remove-low-rumble/) — Schneiden Sie die Subbass-Dumps von Verkehr, Wind und Handhabung mit einem Hochpassfilter ab.
- [DC-Offset korrigieren](/guides/cleaning-up/fix-dc-offset/) — Zentrieren Sie eine Wellenform, die über oder unter der Null-Linie liegt.
- [Netzbrummen mit einem Notch-Filter entfernen](/guides/cleaning-up/remove-mains-hum-with-a-notch-filter/) — Schneiden Sie eine einzelne Frequenz – 50 oder 60 Hz Brummen, ein Pfeifen, ein Klingeln – ohne den Rest zu berühren.
- [Rauschen zwischen Sätzen mit einem Gate stummschalten](/guides/cleaning-up/gate-out-noise-between-phrases/) — Lassen Sie die Stimme durch und schließen Sie die Tür zu den Umgebungsgeräuschen, wenn niemand spricht.

## [Lautstärke und Dynamik](/guides/volume/)

Stellen Sie Pegel ein, gleichen Sie laute und leise Teile aus und erreichen Sie ein Lieferziel.

- [Eine leise Aufnahme lauter machen](/guides/volume/make-a-recording-louder/) — Erhöhen Sie den Pegel einer Aufnahme um eine festgelegte Anzahl von Dezibel mit Verstärken.
- [Peaks auf einen festen Pegel normalisieren](/guides/volume/normalize-peaks/) — Bringen Sie den lautesten Punkt einer Aufnahme auf einen genauen Pegel unter dem Vollausschlag.
- [Lautstärke für einen Podcast normalisieren](/guides/volume/normalize-loudness-for-podcasts/) — Passen Sie die wahrgenommene Lautstärke eines Episoden an das Niveau an, das Streaming-Plattformen erwarten.
- [Lautstärke mit einem Kompressor ausgleichen](/guides/volume/even-out-volume-with-a-compressor/) — Verringern Sie die Lücke zwischen lauten und leisen Momenten, damit die Sprache leichter zu verfolgen ist.
- [Ein- und Ausblenden](/guides/volume/fade-in-and-fade-out/) — Beginnen Sie einen Clip mit Stille und beenden Sie ihn reibungslos, anstatt ihn abzuschneiden.
- [Peaks mit einem Limiter zähmen](/guides/volume/tame-peaks-with-a-limiter/) — Stoppen Sie die lautesten Momente, die über eine Decke gehen, ohne den Rest zu berühren.
- [Musik unter einer Stimme ducken](/guides/volume/duck-music-under-a-voice/) — Drehen Sie eine Musik-Begleitung automatisch leiser, wann immer eine Sprachspur spricht.
- [Lautstärke mit dem klassischen Kompressor ausgleichen](/guides/volume/even-out-volume-with-the-legacy-compressor/) — Verwenden Sie Audacity 3’s ursprünglichen Kompressor, mit seinem Rauschboden und der Nachverstärkung, auf einer Aufnahme.

## [Bearbeitung](/guides/editing/)

- [Clip in zwei Teile aufteilen](/guides/editing/split-a-clip-at-the-cursor/) — Schneiden Sie einen Clip an einem Punkt, damit jeder Teil separat bewegt oder behandelt werden kann.
- [Nur den gewünschten Teil behalten](/guides/editing/keep-only-a-selection/) — Trimmen Sie alles außerhalb einer Auswahl in einem Schritt.
- [Abschnitt wiederholen](/guides/editing/repeat-a-section/) — Schleifen Sie eine Auswahl eine festgelegte Anzahl von Malen, um sie länger zu machen.
- [Aufnahme rückwärts abspielen](/guides/editing/reverse-audio/) — Kehren Sie eine Auswahl um, damit sie von Ende zu Anfang abläuft.
- [Orte in einer Aufnahme markieren](/guides/editing/add-markers/) — Legen Sie benannte Marker auf der Zeitleiste ab, damit Sie später wieder zu bestimmten Punkten finden.
- [Abschnitt kopieren und einfügen](/guides/editing/copy-and-paste-a-section/) — Kopieren Sie einen Abschnitt und fügen Sie ihn an einem anderen Ort auf der Spur ein.
- [Auswahl auf eine neue Spur duplizieren](/guides/editing/duplicate-a-selection-to-a-new-track/) — Kopieren Sie einen Abschnitt auf seine eigene Spur, damit er separat bearbeitet werden kann.
- [Stille nach einem Clip hinzufügen](/guides/editing/add-silence-after-a-clip/) — Generieren Sie eine Lücke mit einer exakten Länge an der Cursorposition.
- [Clips Ende an Ende ausrichten](/guides/editing/line-up-clips-end-to-end/) — Setzen Sie zwei Clips auf verschiedenen Spuren direkt aneinander, damit der eine den anderen folgt.
- [Für präzise Schnitte heranzoomen](/guides/editing/zoom-in-for-precise-edits/) — Kommen Sie der Wellenform nahe genug, um auf einem Beat oder zwischen Wörtern zu schneiden.
- [Rückgängig und Wiederholen](/guides/editing/undo-and-redo/) — Gehen Sie durch Ihre Bearbeitungen zurück und wieder vorwärts.
- [Abschnitt während des Übens schleifen](/guides/editing/loop-a-section-while-you-practise/) — Spielen Sie eine ausgewählte Passage immer wieder ab.
- [Clip entlang der Zeitleiste bewegen](/guides/editing/move-a-clip-along-the-timeline/) — Ziehen Sie einen Clip zu einer anderen Zeit auf seiner Spur.
- [Schneller oder langsamer anhören, ohne die Aufnahme zu ändern](/guides/editing/listen-at-a-different-speed/) — Verlangsamen Sie einen Abschnitt, um ihn zu transkribieren, oder beschleunigen Sie eine lange Aufnahme, um sie zu überprüfen, ohne das Projekt zu verändern.

- [Ein Recording in einen Raum stellen](/guides/effects/add-reverb/) — Reverb hinzufügen, sodass ein trockenes Recording so klingt, als wäre es in einem realen Raum aufgenommen worden.

- [Wah-Wah hinzufügen](/guides/effects/add-a-wah-wah/) — Einen resonanten Filter über einen Klang fegen, um den klassischen Funk-Effekt zu erzeugen.
- [Nyquist-Plug-in verwenden](/guides/effects/use-a-nyquist-plugin/) — Einen der mitgelieferten Nyquist-Effekte ausführen — hier einen einstellbaren Fade.

- [Phaser hinzufügen](/guides/effects/add-a-phaser/) — Ein Set von Kerben durch einen Klang fegen, um den klassischen Swirl-Effekt für Gitarre und Keyboard zu erzeugen.
- [Gleiche Effektkette jedes Mal anwenden](/guides/effects/apply-the-same-effects-every-time/) — Eine Folge von Effekten als Makro speichern und mit einem Befehl auf jede Auswahl anwenden.
- [Von einem Tempo zum anderen gleiten](/guides/effects/slide-from-one-tempo-to-another/) — Ein Passage beschleunigen oder verlangsamen, wobei das Tempo allmählich wechselt, mit oder ohne Tonhöhenverschiebung.
