Beat Finder ist einer der mitgelieferten Nyquist-Analysatoren. Er hört auf plötzliche Anstiege des Pegels über einen Schwellenwert und schreibt ein Label an jeder Stelle, an der er einen findet. Dies ist eine schnelle Möglichkeit, die Beats einer Schleife oder die Schläge in einem Drum-Take zu markieren, bevor Sie ihn zerlegen.

:::note[Komme ich von Audacity?]
Dies ist Audacitys **Analyse → Beat Finder**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme, die Sie markieren möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Analyse → Nyquist → Beat Finder**. Im **Beat Finder**-Dialog setzen Sie den **Schwellenwert in Prozent** auf `60` und drücken dann auf **Anwenden**. Der Dialog berichtet, was er gefunden hat; Drücken Sie **Schließen**, um ihn zu schließen. Ein niedrigerer Prozentsatz findet auch leise Beats; erhöhen Sie ihn, wenn er zu viel markiert.
5. Das Projekt zeigt nun eine Spur mit dem Namen **Beat Finder**.
   *Sie sollten sehen:* Eine neue Beschriftungsspur namens Beat Finder unter dem Audio mit einem Label an jedem Beat.

## Tipps

- Die Labels landen auf einer neuen Beschriftungsspur unter dem Audio. Benennen Sie sie um oder löschen Sie sie, wenn der Analyzer sie falsch platziert hat.
- **Analyse → Nyquist → Beschriftung von Klängen** erledigt einen ähnlichen Job für ganze Klänge, die durch Stille getrennt sind.
