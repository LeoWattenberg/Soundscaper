## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

RMS ist ein Maß für den durchschnittlichen Signalpegel im Zeitverlauf. Mit Measure RMS können Sie Abschnitte vergleichen oder vor einer Anpassung prüfen, wie stark ein Signal ist.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Analyze → Measure RMS (Nyquist)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie den Abschnitt, dessen durchschnittlichen Pegel Sie messen möchten. Er erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Analyse → Nyquist → Measure RMS**. Drücken Sie im Dialog **Measure RMS** auf **Anwenden**. Der Dialog zeigt die Messwerte an; drücken Sie **Schließen**, um ihn zu schließen.
   *Das sollten Sie sehen:* Der Bericht zeigt den RMS-Pegel in dB für jeden Kanal und für das Stereosignal.

## Tipps

- RMS beschreibt den durchschnittlichen Pegel. Verwenden Sie [Peak-Normalisierung](/guides/volume/normalize-peaks/), wenn der höchste Samplewert auf einen Zielpegel gesetzt werden soll.
- Wählen Sie nur den Abschnitt aus, den Sie vergleichen möchten, damit anderes Audiomaterial die Messung nicht beeinflusst.
