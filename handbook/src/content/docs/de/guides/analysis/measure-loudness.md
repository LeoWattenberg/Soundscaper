Bevor Sie normalisieren oder exportieren, ist es hilfreich zu wissen, wo Sie sich befinden. Der EBU R 128-Analysator misst das Programm so, wie es Streaming-Plattformen und Sender tun – integrierte Lautstärke in LUFS, Lautstärkeumfang und True Peak –, sodass Sie einen Zielwert vergleichen können, anstatt auf das Messgerät zu raten.

:::note[Komme von Audacity?]
Dies ist Audacitys **Analyse → RMS-Messung oder Lautstärkennormalisierungsmessung**. Die unten genannten Bezeichnungen sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie das zu messende Mix aus. Es landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Analyse → EBU R 128**. Das **EBU R 128**-Panel öffnet sich.
  *Sie sollten sehen:* Integrierte Lautstärke, Lautstärkeumfang und True Peak für die Auswahl.

## Tipps

- Podcast-Plattformen verlangen häufig −16 LUFS Stereo oder −19 LUFS Mono mit True Peaks unter −1 dBTP; überprüfen Sie die Anleitung der Plattform.
- Wenn die Werte weit vom Ziel entfernt sind, führen Sie [Lautstärkennormalisierung](/guides/volume/normalize-loudness-for-podcasts/) aus und messen Sie erneut.
