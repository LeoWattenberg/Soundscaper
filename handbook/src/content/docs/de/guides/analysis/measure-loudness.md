Bevor Sie normalisieren oder exportieren, hilft es, zu wissen, wo Sie sich befinden. Der EBU R 128-Analysator misst das Programm so, wie Streaming-Plattformen und Sender es tun – integrierte Lautstärke in LUFS, Lautstärkenbereich und wahre Spitzen – damit Sie sich mit einem Ziel vergleichen können, anstatt aus einem Meter zu raten.

:::hinweis[Aus Audacity?]
Dies ist Audacitys **Analyse → RMS messen** oder die Messung von Loudness Normalisierung. Die Namen unten sind Soundscaper's eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die Mischung aus, die Sie messen möchten. Die Datei landet als eigene Spur.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Analyse → EBU R 128**. Das **EBU R 128**-Panel öffnet sich.
   *Sie sollten Folgendes sehen:* Integrierte Lautstärke, Lautstärkenbereich und wahre Spitzen für die Auswahl.

## Tipps

- Podcast-Plattformen verlangen häufig −16 LUFS Stereo oder −19 LUFS Mono mit wahren Spitzen unter −1 dBTP; überprüfen Sie die eigene Anleitung der Plattform.
- Wenn die Zahlen weit vom Ziel entfernt sind, führen Sie [Loudness Normalisierung](/guides/volume/normalize-loudness-for-podcasts/) durch und messen Sie erneut.
