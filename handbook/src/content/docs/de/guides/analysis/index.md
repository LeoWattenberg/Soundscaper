Messung der Lautstärke, Inspektion von Frequenzen und Erkennung von Problemen in einer Aufnahme.

## Anleitungen in dieser Kategorie

- [Messen Sie, wie laut Ihr Mix ist](/guides/analysis/measure-loudness/) — Lesen Sie die integrierte Lautheit, den Lautheitsbereich und den True Peak einer Auswahl wie bei Rundfunkanstalten.
- [Sehen Sie, welche Frequenzen ein Ton enthält](/guides/analysis/plot-a-spectrum/) — Stellen Sie das Spektrum einer Auswahl dar, um Brummen, Rauschen oder Resonanzen zu finden.
- [Finden Sie heraus, wo eine Aufnahme übersteuert hat](/guides/analysis/find-clipping/) — Lokalisieren Sie die Stellen, an denen die Aufnahme den vollen Pegel erreicht und verzerrt hat.
- [Finden Sie den Takt in einer Schleife](/guides/analysis/find-the-beats/) — Lassen Sie den Beat Finder-Analysator jeden Takt markieren, den er hört.
- [Überprüfen Sie, ob Sprache sich von ihrem Hintergrund abhebt](/guides/analysis/check-speech-contrast/) — Messen Sie, wie weit eine Stimme über dem Hintergrundrauschen liegt, wie es in Zugänglichkeitrichtlinien gefordert wird.
- [Den RMS-Pegel einer Auswahl messen](/guides/analysis/measure-rms-level/) — Mit dem integrierten RMS-Analyzer den durchschnittlichen Signalpegel eines ausgewählten Abschnitts ablesen.
- [Durch Stille getrennte Klänge markieren](/guides/analysis/label-sounds-separated-by-silence/) — Klänge markieren, die nach einer Pause den Schwellenwert überschreiten.
