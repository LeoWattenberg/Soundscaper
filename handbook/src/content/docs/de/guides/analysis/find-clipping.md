Eine zu heiß aufgenommene Aufnahme flacht an der oberen Grenze ab und verzerrt. Der Schaden ist leicht zu hören, aber schwer mit dem Auge in einer langen Aufnahme zu erkennen. Der 'Clipping-Finder' analysiert die Auswahl und listet jeden Abschnitt von Proben auf, der auf voller Skala liegt, sodass Sie entscheiden können, ob Sie jeden Abschnitt reparieren, neu aufnehmen oder so lassen möchten.

:::note[Komme ich von Audacity?]
Dies ist Audacitys **Analyse → Clipping finden**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme, die Sie überprüfen möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Analyse → Clipping finden**. Das **Clipping finden**-Panel öffnet sich.
  *Sie sollten sehen:* Eine Liste der abgeflachten Abschnitte oder eine Notiz, dass keine gefunden wurden.

## Tipps

- Das Absenken einer abgeflachten Aufnahme repariert sie nicht; die abgeflachten Spitzen bleiben abgeflacht. **Effekt → Rauschentfernung und Reparatur → Reparatur** kann einen sehr kurzen abgeflachten Abschnitt rekonstruieren.
- Um ein Clipping beim nächsten Mal zu vermeiden, nehmen Sie mit Spitzen um −12 dB auf und erhöhen Sie den Pegel danach.
