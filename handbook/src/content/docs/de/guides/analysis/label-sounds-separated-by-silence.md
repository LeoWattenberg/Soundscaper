## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Label Sounds durchsucht einen Abschnitt nach Klängen, die durch Stille getrennt sind, und setzt um jeden erkannten Klang eine Markierung. So lassen sich gesprochene Sätze, einzelne Schläge oder andere Ereignisse für die spätere Bearbeitung markieren.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Analyze → Label Sounds (Nyquist)**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme mit Pausen zwischen den Klängen. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Analyse → Nyquist → Label Sounds**. Setzen Sie im Dialog **Label Sounds** **Threshold level (dB)** auf `-30`, **Minimum silence duration** auf `0.5` und **Minimum label interval** auf `0.5`, und drücken Sie dann **Anwenden**. Der Dialog zeigt das Ergebnis an; drücken Sie **Schließen**, um ihn zu schließen. Eine halbe Sekunde Stille ermöglicht dem Analyzer, die Sätze zu trennen. Der Schwellenwert legt fest, wie laut ein Klang sein muss, um erkannt zu werden.
5. Das Projekt zeigt nun eine Spur namens **Label Sounds**.
   *Das sollten Sie sehen:* Eine Spur „Label Sounds“ mit Markierungen um die erkannten Sätze erscheint.

## Tipps

- Senken Sie **Threshold level (dB)**, um leisere Klänge einzubeziehen; erhöhen Sie ihn, um Hintergrundgeräusche zu ignorieren.
- Erhöhen Sie **Minimum silence duration**, wenn kurze Pausen einen Satz nicht in mehrere Markierungen aufteilen sollen.
