## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Ein Multiband-Kompressor teilt eine Auswahl in tiefe, mittlere und hohe Frequenzbereiche und bearbeitet jedes Band unabhängig. So lässt sich ein basslastiger Mix stabilisieren, ohne dass Becken oder Gesang gemeinsam mit dem Bass pumpen.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **No direct built-in multiband compressor in Audacity’s current effect list.**. Die folgenden Bezeichnungen stammen von Soundscaper und können abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und dann den Mix oder das Instrument, dessen Frequenzbereiche getrennt geregelt werden sollen. Der Clip wird auf einer eigenen Spur eingefügt.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Multiband-Kompressor**. Setzen Sie im Dialog **Multiband-Kompressor** **Verhältnis Tiefen** auf `3` und **Schwellenwert Tiefen** auf `-24`; drücken Sie dann **Auf Auswahl anwenden**. Das Verhältnis des Tiefenbands bestimmt, wie stark Bass oberhalb der Schwelle komprimiert wird; die Crossover legen die Bandgrenzen fest.
5. Drücken Sie **Abspielen**, um zuzuhören, und anschließend **Stopp**.
   *Sie sollten sehen:* Bassspitzen sind gleichmäßiger, während die anderen Bänder ihre eigene Dynamik behalten.

## Tipps

- Stellen Sie **Untere Trennfrequenz** und **Obere Trennfrequenz** so ein, dass die Bänder dort getrennt werden, wo Sie Kontrolle benötigen.
- Ändern Sie das Verhältnis nur schrittweise und vergleichen Sie mit Undo. Starke Kompression kann einem Mix den Druck nehmen.
