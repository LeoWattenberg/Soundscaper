## Wofür dieser Leitfaden gedacht ist {#what-this-guide-is-for}

Die RMS-Normalisierung passt eine Auswahl an einen durchschnittlichen Signalpegel an, statt eine Spitzenbegrenzung festzulegen. Sie hilft dabei, den Pegel mehrerer Aufnahmen anzugleichen. Prüfen Sie anschließend die Spitzen, besonders bei stark dynamischem Ausgangsmaterial.

:::note[Komme von Audacity?]
Dies entspricht Audacitys **Effect → Volume and Compression → Loudness Normalization**. Die folgenden Bezeichnungen stammen von Soundscaper und unterscheiden sich teilweise.
:::

## Schritte

1. Öffnen Sie Soundscaper. Sobald der Editor geladen ist, steht ein neues, leeres Projekt bereit.
2. Wählen Sie **Datei → Importieren** und laden Sie die Aufnahme, deren durchschnittlichen Pegel Sie einstellen möchten. Sie erscheint als Clip auf einer eigenen Spur.
3. Wählen Sie **Auswählen → Alles**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Lautheitsnormalisierung**. Wählen Sie im Dialog **Lautheitsnormalisierung** bei **RMS** die Option **Normalisieren**, setzen Sie **Ziel-RMS** auf `-20` und deaktivieren Sie **Stereokanäle getrennt normalisieren**. Drücken Sie anschließend **Auf Auswahl anwenden**. Die gekoppelte Anpassung erhält die Balance zwischen links und rechts und zielt auf −20 dB RMS.
5. Drücken Sie zum Anhören **Abspielen** und anschließend **Stopp**.
   *Das sollten Sie hören:* Der Pegel der Aufnahme wurde in Richtung des RMS-Zielwerts von −20 dB angepasst, während die Stereobalance erhalten blieb.

## Tipps

- Verwenden Sie denselben RMS-Zielwert für Aufnahmen, deren durchschnittliche Pegel Sie miteinander vergleichen möchten.
- Die RMS-Normalisierung garantiert keine Obergrenze für Spitzen. Prüfen Sie bei Bedarf auf Clipping und lassen Sie ausreichend Headroom.
