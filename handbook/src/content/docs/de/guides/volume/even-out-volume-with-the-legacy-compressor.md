Audacity 3 lieferte zwei Kompressoren: den modernen mit Knie, Lookahead und Live-Messwerten sowie den ursprünglichen, einfacheren, der als Legacy-Kompressor beibehalten wurde. Das Legacy-Design hat eine Geräuschschwelle, unter der es nicht mehr funktioniert – so wird während der Pausen kein Rauschen verstärkt – und es hebt das Ergebnis standardmäßig auf bis zu 0 dB an. Audacity 4 hat ihn entfernt; Soundscaper behält ihn für Projekte und Ohren, die ihn gewohnt sind.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Lautstärke und Kompression → Legacy-Kompressor (Audacity 3; Audacity 4 hat nur den neuen Kompressor)**. Die Namen unten sind Soundscapers eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die Aufnahme aus, die Sie ausgleichen möchten. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Auswahl → Alles auswählen**.
4. Wählen Sie **Effekt → Legacy-Effekte → Legacy-Kompressor**. Im **Legacy-Kompressor**-Dialog setzen Sie **Schwellenwert** auf `-20` und **Verhältnis** auf `4`, dann drücken Sie **Auf Auswahl anwenden**. Alles, was über −20 dB liegt, wird im Verhältnis 4:1 hier gedämpft. Der Ausgleichsverstärker hebt dann das gesamte Ergebnis auf einen Peak von 0 dB an.
5. Drücken Sie **Abspielen**, um zuzuhören, dann **Stopp**.
   *Sie sollten sehen:* Laute und leise Passagen sitzen enger beieinander und die gesamte Aufnahme ist lauter.

## Tipps

- Erhöhen Sie **Rauschschwelle**, wenn der Kompressor Rauschen in den Pausen hervorhebt; der Effekt ignoriert alles, was leiser ist als sie.
- Für einen Kompressor, den Sie während der Einstellung arbeiten hören können, verwenden Sie den modernen: [Lautstärke mit einem Kompressor ausgleichen](/guides/volume/even-out-volume-with-a-compressor/).
