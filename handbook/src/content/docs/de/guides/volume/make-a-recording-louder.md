Eine Aufnahme, die mit zu geringem Gain aufgenommen wurde, ist leise, aber normalerweise sauber. Die Verstärkung hebt alles um den gleichen Betrag in Dezibel an, sodass das Gleichgewicht innerhalb der Aufnahme genau so bleibt, wie es war. Lassen Sie das Clippen deaktiviert, weigert sich der Effekt, die Spitzen über die volle Skala hinaus zu drücken.

:::note[Komme von Audacity?]
Dies ist Audacitys **Effekt → Lautstärke und Kompression → Verstärken**. Die Namen unten sind Soundscapers eigene, die manchmal abweichen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Importieren** und wählen Sie die leise Aufnahme aus. Sie landet als Clip auf ihrer eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Verstärken**. Im **Verstärken**-Dialog setzen Sie die **Verstärkung** auf `6`, und drücken Sie dann **Auf Auswahl anwenden**. Sechs Dezibel verdoppeln die Lautstärke in etwa. **Clipping zulassen** bleibt deaktiviert, sodass der Effekt die Spitzen nicht verzerrt.
5. Drücken Sie **Abspielen**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Die Aufnahme ist deutlich lauter und die Wellenform ist höher.

## Tipps

- Wenn das Ergebnis immer noch zu leise ist, führen Sie Verstärken erneut aus; die Gewinne addieren sich.
- Um Spitzen auf ein genaues Niveau zu bringen, anstatt eine feste Menge hinzuzufügen, verwenden Sie [Normalisieren](/guides/volume/normalize-peaks/).
