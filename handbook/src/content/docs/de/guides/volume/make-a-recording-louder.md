Eine Aufnahme mit zu niedriger Verstärkung ist leise, aber in der Regel sauber. Verstärken hebt alles um denselben Betrag in Dezibel an, sodass das Gleichgewicht innerhalb der Aufnahme genau so bleibt, wie es war. Klirren auslassen verhindert, dass Spitzen über die Vollauslast geschoben werden.

:::note[Aus Audacity?]
Dies ist Audacitys **Effekt → Lautstärke und Kompression → Verstärken**. Die Namen unten können sich unterscheiden, da sie von Soundscaper stammen.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die leise Aufnahme aus. Die Datei landet als Clip auf seiner eigenen Spur.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Verstärken** aus. Im **Verstärken**-Dialog setzen Sie **Verstärkung** auf `6` und klicken dann auf **Anwenden auf Auswahl**. Sechs Dezibel verdoppeln die Lautstärke ungefähr. **Klirren zulassen** bleibt aus, sodass der Effekt die Spitzen nicht verzerrt.
5. Drücken Sie **Abspielen** zum Hören und **Stopp**.

*Sie sollten sehen:* Die Aufnahme ist deutlich lauter und die Wellenform höher.

## Tipps

- Wenn das Ergebnis immer noch zu leise ist, führen Sie Verstärken erneut aus; die Verstärkungen summieren sich.
- Um Spitzen auf ein genaues Niveau zu bringen, anstatt einen festen Betrag hinzuzufügen, verwenden Sie [Normalisieren](/guides/volume/normalize-peaks/) stattdessen.
