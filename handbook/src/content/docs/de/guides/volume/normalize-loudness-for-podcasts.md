Podcast- und Streaming-Plattformen messen die Lautstärke in LUFS, was eher dem Gefühl der Lautstärke eines Programms entspricht als der Höhe seiner Spitzen. Die Lautstärkennormalisierung misst die gesamte Auswahl und passt sie an ein Ziel an, sodass jede von Ihnen veröffentlichte Episode auf demselben Niveau liegt.

:::note[Kommt von Audacity?]
Dies ist Audacitys **Effekt → Lautstärke und Kompression → Lautstärkennormalisierung**. Die Namen unten sind Soundscapers eigene, die sich manchmal unterscheiden.
:::

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie die leise Aufnahme. Die Datei wird als Clip auf ihrer eigenen Spur abgelegt.
3. Wählen Sie **Auswählen → Alles auswählen**.
4. Wählen Sie **Effekt → Lautstärke und Kompression → Lautstärkennormalisierung**. Im Dialogfeld **Lautstärkennormalisierung** setzen Sie die **Ziellautstärke** auf `-16` und drücken Sie dann **Auf Auswahl anwenden**. −16 LUFS ist das übliche Ziel für Stereo-Podcasts; −19 LUFS wird oft für Mono verwendet. Überprüfen Sie die Richtlinien Ihrer Plattform.
5. Drücken Sie **Wiedergabe**, um zuzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Die Aufnahme wird auf einem angenehmen, konstanten Niveau abgespielt.

## Tipps

- Lautstärkennormalisierung kann bei sehr dynamischem Material Spitzen über dem vollen Maßstab drücken. Folgen Sie ihr mit einem Limiter oder einer Peak-Normalisierung auf −1 dB, wenn die Wellenform die Oberseite berührt.
- Führen Sie es auf dem fertigen Mix aus, nachdem Bearbeitungen und andere Effekte vorgenommen wurden, damit die Messung das widerspiegelt, was die Zuhörer hören.
