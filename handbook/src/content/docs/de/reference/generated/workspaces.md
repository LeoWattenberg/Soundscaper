Ein Arbeitsbereich ist eine gespeicherte Anordnung der Bedienfelder und Symbolleisten um die Zeitleiste. Die Auswahl eines Arbeitsbereichs ersetzt die aktuelle Anordnung; Sie können dann alles verschieben und Ihren eigenen Arbeitsbereich speichern, der auf dieser Seite nicht beschrieben wird.
