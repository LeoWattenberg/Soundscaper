Lokale Unterstützung ist in Soundscaper und Framescaper verfügbar. Modelle werden in einem von Ihnen gewählten Verzeichnis auf Ihrer eigenen Dateisystem gespeichert, und jede Ausführung findet auf Ihrem Gerät statt; keine Ihrer Medien werden irgendwo hochgeladen.

Ein Workflow ist ein fester Graph von Schritten. Ein Schritt, der eine Operation benennt, führt ein Modell aus; ein Schritt, der keine benennt, führt kein Modell aus. Ein optionaler Schritt wird übersprungen, wenn sein Modell nicht installiert ist, und der Workflow erzeugt immer noch ein Ergebnis aus den ausgeführten Schritten.
