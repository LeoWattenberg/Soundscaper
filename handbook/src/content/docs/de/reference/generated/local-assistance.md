Lokale Unterstützung ist in Soundscaper und Framescaper verfügbar. Modelle werden in einem von Ihnen gewählten Verzeichnis auf Ihrem eigenen Dateisystem gespeichert, und jeder Vorgang findet auf Ihrem Gerät statt; keine Ihrer Medien werden irgendwo hingeschickt.

Ein Workflow ist ein fester Graph von Schritten. Ein Schritt, der eine Operation benennt, führt ein Modell aus; ein Schritt, der keine benennt, ist deterministisch und führt kein Modell aus. Ein optionaler Schritt wird übersprungen, wenn sein Modell nicht installiert ist, und der Workflow erzeugt immer noch ein Ergebnis aus den ausgeführten Schritten.

## Veröffentlichte Modelle

Modellgewichte und native Motoren sind getrennte Anforderungen. Sehen Sie sich die [individuellen Modellleitfäden und die aktuelle native Verfügbarkeit](/reference/local-models/) an, bevor Sie sich auf ein Modell verlassen, das zum Aktivieren einer Aufgabe heruntergeladen wurde.

Modelle werden von `https://assets.soundscaper.org/models/` veröffentlicht und vor der Verwendung gegen eine aufgezeichnete SHA-256-Digest-Verifizierung überprüft. „Mindestspeicher“ ist der gesamte Systemspeicher, der für die Katalogverfügbarkeit erforderlich ist. Auch für die Inferenz ist ausreichend freier Speicher erforderlich; keiner der Werte ist eine Aussage darüber, wie schnell es laufen wird. Eine Aufgabe unten ist das, was ein Modell tut, was nicht immer genau so geschrieben ist wie die Operation, die es verwendet, und eine einzelne Operation kann sich auf mehr als ein Modell stützen.
