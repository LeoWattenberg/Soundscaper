Der Editor wird an einer Route pro Sprache bereitgestellt. Eine Sprache, die nicht hier aufgeführt ist, fällt auf Englisch zurück. 

Zwei Sprachen werden direkt für diesen Editor geschrieben und überprüft. Der Rest wird maschinell aus der englischen Kopie übersetzt, und wo Audacitys Übersetzer die gleiche Befehlsnamen-Formulierung überprüft haben, wird ihre Wortwahl angezeigt. Englische Varianten tragen nur Audacitys überprüfte Zeichen über Englisch.
