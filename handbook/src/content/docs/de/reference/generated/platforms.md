## Wo eine Funktion ausgeführt werden kann

Funktionen sind nach dem gruppiert, was sie von der Plattform benötigen. Weitere Informationen zu den Funktionen, die jedes Produkt aktiviert, finden Sie unter [Produktfunktionen](/reference/generated/product-capabilities/).

| Ebene | Was es bedeutet |
| --- | --- |
| `web-core` | Funktioniert in jedem unterstützten Browser, ohne dass eine optionale Plattformfunktion erforderlich ist. |
| `web-enhanced` | Funktioniert in einem Browser, der die neueren Speicher- und Medienfunktionen bietet, die die Funktion benötigt. |
| `electron-enhanced` | Funktioniert im Browser und die Desktop-Anwendung erweitert die Funktion. |
| `electron-only` | Erfordert die Desktop-Anwendung, da ein Browser nicht auf das zugreifen kann, was die Funktion nutzt. |
