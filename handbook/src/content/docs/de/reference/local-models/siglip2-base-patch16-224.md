## Zweck und Anwendungsfall {#purpose-and-use-case}

Abgetastete Videobilder und Text für die lokale visuelle Suche in einem gemeinsamen numerischen Raum darstellen.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine onnxruntime-node 1.29.0 für macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht. Für macOS x64 gibt es keine herunterladbare Engine, obwohl Modellgewichte für diese Plattform aufgeführt sind.

## Dieses Modell verwenden {#use-this-model}

Öffnen Sie **Framescaper: Werkzeuge → Suche → Video indizieren, dann Werkzeuge → Suche → Indizierte Suche** auf einer Plattform mit der erforderlichen nativen Laufzeit. Die lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie ein Video aus und installieren Sie SigLIP2 über **Modelle verwalten**.
2. Führen Sie **Video indizieren** aus, um die abgetasteten Bilder zu analysieren. Installieren Sie zusätzlich PP-OCRv4, wenn Sie den optionalen Schritt zum Lesen von Text verwenden möchten.
3. Verwenden Sie **Indizierte Suche** und prüfen Sie die passenden Videomomente, bevor Sie entscheiden, wie Sie sie verwenden.
