## Zweck und Anwendungsfall {#purpose-and-use-case}

Ein vorhandenes englisches Transkript mit den gesprochenen Worten in einer Aufnahme ausrichten.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine onnxruntime-node 1.29.0 für macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht.

## Verwendung dieses Modells {#use-this-model}

Öffnen Sie **Analyse → Sprache → Transkribieren & Untertitel, oder Werkzeuge → Erweitertes lokales Verarbeiten → Wortausrichtung** auf einer Plattform mit dem erforderlichen nativen Runtime. Lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie die Sprache aus und bereiten Sie das englische Transkript vor oder überprüfen Sie es.
2. Installieren Sie das Ausrichtungsmodell über den Modell-Manager.
3. Führen Sie die Ausrichtung aus und hören Sie während der Überprüfung der vorgeschlagenen Wortgrenzen zu, bevor Sie sie akzeptieren.

## Überprüfung des Ergebnisses {#review-the-result}

- Dieses Modell richtet die bereitgestellten englischen Wörter aus; es übersetzt oder korrigiert kein fehlerhaftes Transkript.
- Wiederholte Wörter, Hintergrundgespräche und fehlende Transkriptwörter können zu falschen Grenzen führen. Der Test überprüft geordnete, innerhalb des Bereichs liegende Wortzeiten gegen das bereitgestellte Wortinventar, nicht auf eine perfekte Zeitübereinstimmung.
