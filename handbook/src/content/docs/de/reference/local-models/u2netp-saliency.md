## Zweck und Anwendungsfall {#purpose-and-use-case}

Den visuell hervorstechenden Bereich abgetasteter Bilder schätzen, um die Neurahmung zu unterstützen.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine onnxruntime-node 1.29.0 für macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht. Für macOS x64 gibt es keine herunterladbare Engine, obwohl Modellgewichte für diese Plattform aufgeführt sind.

## Dieses Modell verwenden {#use-this-model}

Öffnen Sie **Framescaper: Effekt → Videoeffekte → Neurahmung** auf einer Plattform mit der erforderlichen nativen Laufzeit. Die lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie einen Videoclip aus und installieren Sie U²-Net-P über **Modelle verwalten**.
2. Die geführte Aufgabe zur Neurahmung benötigt außerdem YuNet und D-FINE; unter **Werkzeuge → Erweiterte lokale Verarbeitung** kann die Hervorhebungserkennung separat ausgeführt werden.
3. Führen Sie die Verarbeitung lokal aus und prüfen Sie die vorgeschlagene Rahmung, bevor Sie sie anwenden.

Fall: `saliency-detection`; Operation: `saliency-detection`.

Eingabe: Zwei Fotografien: das gemeinfreie NASA-Porträt der Astronautin Eileen Collins und das CC0-Foto einer Katze aus Chelsea. Jedes wird mit expliziten Zeitangaben des Ursprungsbilds in einen eigenen Frame eingepasst, sodass die Detektoren ein menschliches Gesicht und ein deutliches Objekt erhalten.

Die Frame-Ergebnisse müssen ihre ursprünglichen Zeitangaben beibehalten und einen endlichen, begrenzten Punkt der visuellen Hervorhebung für das Testmotiv enthalten.

## Ergebnis prüfen {#review-the-result}

- Ein visuell hervorstechender Bereich ist nicht unbedingt das Motiv, das Sie behalten möchten. Prüfen Sie die gesamte Auswahl.
