## Zweck und Anwendungsfall {#purpose-and-use-case}

Vorschläge für hörbare Ereigniskategorien für die Indizierung und Reaktionsmarker.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine onnxruntime-node 1.29.0 für macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht.

## Verwenden Sie dieses Modell {#use-this-model}

Öffnen Sie **Tools → Erweitert lokale Verarbeitung → Audio-Tagging** auf einer Plattform mit dem erforderlichen nativen Runtime. Lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie das Audio aus, das Sie analysieren möchten.
2. Installieren Sie PANNs über den Model Manager und führen Sie dann das Audio-Tagging aus.
3. Überprüfen Sie die vorgeschlagenen Beschriftungen und ihre Zeitbereiche, bevor Sie Marker akzeptieren oder sie zum Suchen verwenden.
