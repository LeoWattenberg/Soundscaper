## Zweck und Anwendungsfall {#purpose-and-use-case}

Ausgewählte Sprache als zeitcodiertes Transkript für Untertitel und Transkriptbearbeitung ausgeben.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine sherpa-onnx-node 1.13.5 für macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht. Für macOS x64 gibt es keine herunterladbare Engine, obwohl Modellgewichte für diese Plattform aufgeführt sind.

## Dieses Modell verwenden {#use-this-model}

Öffnen Sie **Analysieren → Sprache → Transkribieren und Untertitel** auf einer Plattform mit der erforderlichen nativen Laufzeit. Die lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie die zu transkribierende Sprachaufnahme aus.
2. Installieren Sie dieses Modell über **Modelle verwalten**. Unter **Werkzeuge → Erweiterte lokale Verarbeitung** können Sie ein bestimmtes Spracherkennungsmodell auswählen.
3. Führen Sie die Verarbeitung lokal aus und prüfen Sie Text und Zeitangaben, bevor Sie das Transkript übernehmen.

Ungefähre Downloadgröße des Modellartefakts: **630.56 MiB**. Die erforderliche Laufzeit kommt beim ersten Download hinzu, falls sie noch nicht installiert ist. Mindestspeicher: **4 GiB**. Diese Kataloganforderung bezieht sich auf den gesamten Speicher, nicht auf den aktuell freien Speicher. Für die Inferenz ist ebenfalls ausreichend freier Speicher erforderlich, und die Installation benötigt zusätzlichen Speicherplatz; Speicher ist keine Geschwindigkeitsgarantie.

Veröffentlichte Plattformen: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Eine passende herunterladbare Laufzeit ist ebenfalls erforderlich.

Installieren Sie unter Windows das neueste unterstützte [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), das zur Desktop-App passt: **x64** für einen x64-Build oder **ARM64** für einen ARM64-Build. Die nativen ONNX- und Sherpa-Engines benötigen diese Bibliotheken; Modell- und Laufzeitdownloads enthalten sie nicht. Visual Studio selbst ist für die Nutzung der App nicht erforderlich.

Werkzeuge → Modellmanager lädt bei der ersten Installation die veröffentlichten Modellartefakte und die erforderliche Laufzeit herunter und überprüft ihre gespeicherten SHA-256-Digests. Die Verarbeitung verwendet die lokal installierten Dateien. <summary>Was der Desktop-Test prüft</summary>

Fall: `parakeet-v2-transcript`; Operation: `speech-recognition`.

Eingabe: Ein gemeinfreier Ausschnitt aus der Antrittsrede von John F. Kennedy, an dessen beiden Enden jeweils eine Sekunde Stille hinzugefügt wurde, als 16-kHz-Mono-Audio vorbereitet.

Das Transkript muss nicht leeren Text mit gültigen Zeitangaben innerhalb des Eingabeaudios enthalten. Der genaue Wortlaut wird nicht verglichen.

Das Paket nightly-with-tests lädt vor der Inferenz echte Modellartefakte und verifizierte Laufzeiten herunter. Ein erforderliches, im Katalog fehlendes Modell lässt den zugehörigen Test fehlschlagen. Fehlende native Engines führen auf katalogunterstützten Plattformen zum Fehlschlag. Diese aufwendigen Prüfungen laufen getrennt von der normalen Browsersuite. Ein erfolgreicher Lauf bestätigt die grundlegende Modellausführung und eine nutzbare Ausgabestruktur; er bestätigt weder die wahrgenommene Qualität noch die Genauigkeit Ihrer Aufnahme.
