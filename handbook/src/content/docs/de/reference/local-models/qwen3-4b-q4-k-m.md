## Zweck und Anwendungsfall {#purpose-and-use-case}

Titel, Aufhänger, Kapitel und Erläuterungen für vorhandene Highlight-Kandidaten vorschlagen.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Builds können die erforderliche Engine llama-cpp b10509 für macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 herunterladen und verifizieren. Installieren Sie dieses Modell und die erforderliche Laufzeit über den Modellmanager und führen Sie die Aufgabe dann lokal aus. Dies sind unterstützte Build-Ziele; Ergebnisse für ein bestimmtes Paket und Gerät finden Sie im Nightly-Testbericht.

## Dieses Modell verwenden {#use-this-model}

Öffnen Sie **Framescaper: Werkzeuge → Erweiterte lokale Verarbeitung → Redaktionstextgenerierung** auf einer Plattform mit der erforderlichen nativen Laufzeit. Die lokale Unterstützung läuft im Desktop-Editor.

1. Bereiten Sie Highlight-Kandidaten aus den ausgewählten Medien vor und prüfen Sie sie.
2. Installieren Sie Qwen über den Modellmanager und aktivieren Sie die Redaktionstextgenerierung.
3. Prüfen Sie jeden Textvorschlag, bevor Sie ihn übernehmen. Nur autorisierte Kandidatenidentitäten und angeforderte Textfelder sind zulässig.

## Ergebnis prüfen {#review-the-result}

- Die generierte Formulierung kann irreführend oder wiederholend sein. Sie ist ein auf den bereitgestellten Belegen beruhender Vorschlag, keine überprüfte Faktenanalyse.
- Das Modell läuft lokal auf der CPU und benötigt mindestens 16 GiB Gesamtspeicher sowie ausreichend freien Speicher. Auch kurze Anfragen können mehrere Minuten dauern.
