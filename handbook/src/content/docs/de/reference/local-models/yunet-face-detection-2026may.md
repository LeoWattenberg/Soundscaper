Gesichter und Objekte in ausgewählten Videobildern erkennen, um einen neuen Rahmen vorzuschlagen.

YuNet erkennt Gesichter und deren Positionen. Die Subjekt-Erkennungsoperation kombiniert diese Ergebnisse mit D-FINE-Objekterkennungen.

## Aktuelle Verfügbarkeit {#current-availability}

Desktop-Versionen enthalten das erforderliche onnxruntime-node 1.29.0-Engine für macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Installieren Sie die Gewichte dieses Modells über den Model Manager und führen Sie die Aufgabe lokal aus. Dies sind die unterstützten Build-Ziele; konsultieren Sie den Nachtestbericht für Ergebnisse zu einem bestimmten Paket und einer bestimmten Maschine. Die Desktop-Version enthält diese Engine nicht für macOS x64, obwohl Gewichte für diese Plattformen aufgeführt sind.

## Verwenden Sie dieses Modell {#use-this-model}

Öffnen Sie **Framescaper: Effekt → Videoeffekte → Reframe** auf einer Plattform mit dem erforderlichen nativen Runtime. Lokale Unterstützung läuft im Desktop-Editor.

1. Wählen Sie in Framescaper einen Videoclip aus.
2. Installieren Sie sowohl YuNet als auch D-FINE für die Subjekt-Erkennung. Die geführte Reframe-Aufgabe verwendet außerdem U²-Net-P zur Salienz-Erkennung.
3. Führen Sie lokal aus und überprüfen Sie den vorgeschlagenen Ausschnitt. Tools → Erweitertes lokales Verarbeiten kann die Subjekt-Erkennung selbstständig durchführen.

Diese Operation erfordert auch [D-FINE Nano-Objekterkennung](/reference/local-models/dfine-nano-coco/).

## Was der verpackte Test überprüft {#what-the-packaged-test-checks}

Fall: `subject-detection`; Operation: `subject-detection`.

Eingabe: Zwei Fotografien: das öffentlich zugängliche NASA-Porträt der Astronautin Eileen Collins und das CC0-Foto einer Katze namens Chelsea. Jede wird in einen separaten Rahmen mit expliziter Quellrahmen-Zeitstellung eingefügt, um den Detektoren ein menschliches Gesicht und ein klares Objekt zu bieten.

Gesichts- und Objektergebnisse müssen gültige Quellrahmen-Zeitstellungen, endliche Konfidenzwerte und begrenzende Kästchen aufweisen. Die Subjekt-Vorrichtung muss Erkennungen aus beiden Modellen erzeugen.

Das Paket „Nightly-with-tests“ lädt echte Modellartefakte herunter und fordert Inferenz über die verpackte Laufzeit an. Ein erforderliches Modell, das im Katalog fehlt, führt zum Fehlschlagen seines Falls. Fehlende native Engines führen auf katalogunterstützten Plattformen zum Fehlschlagen. ## Überprüfen Sie das Ergebnis {#review-the-result}

- Gesichter und Objekte können übersehen oder falsch klassifiziert werden. Die Erkennung ist stichprobenartig und garantiert nicht, dass sich ein sich bewegendes Subjekt in jedem vorgeschlagenen Ausschnitt befindet.
- Die Operation führt beide Modelle zusammen aus; keines der Modelle ist ein Gesichtserkennungssystem zur Identifizierung von Personen.
