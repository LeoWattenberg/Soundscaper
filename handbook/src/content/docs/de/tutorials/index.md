Ein Tutorial ist eine Lektion: Es führt Sie durch ein vollständiges Arbeitsstück an einem Beispielaufzeichnung, die das Handbuch bereitstellt, Schritt für Schritt, und sagt Ihnen, was Sie unterwegs sehen sollten. Beginnen Sie hier, wenn Sie Soundscaper noch nie verwendet haben. Wenn Sie sich auskennen und eine eigene Aufzeichnung haben, decken die [How-to-Guides](/guides/) die gleichen Operationen und viele mehr ab, jeweils eine Aufgabe nach der anderen.

- [Ihr erstes Soundscaper-Projekt](/tutorials/your-first-project/) — Importieren Sie eine Aufzeichnung, hören Sie sie sich an, teilen Sie sie auf, blenden Sie sie aus, exportieren Sie eine Datei und speichern Sie das Projekt.
- [Bereinen Sie eine Sprachaufzeichnung](/tutorials/clean-up-a-voice-recording/) — Entfernen Sie das Brummen aus einer Aufnahme, schneiden Sie das Dröhnen, bringen Sie sie auf Podcast-Lautstärke und exportieren Sie eine MP3.
- [Legt Musik unter eine Stimme](/tutorials/put-music-under-a-voice/) — Schichten Sie zwei Spuren, lassen Sie eine automatisch unter der anderen ducken, mischen Sie sie ab und exportieren Sie sie.
