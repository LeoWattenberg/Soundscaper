Dieses Tutorial führt Sie durch einen kompletten Durchgang des Editors an einer zweisekündigen Musikschleife: Es zeigt, wie Sie eine Datei importieren, sie anhören, sie mit einem Effekt verändern, sie in zwei Teile schneiden, eine Datei rendern, die Sie überall abspielen können, und das Projekt speichern, damit Sie später darauf zugreifen können. Für dieses Tutorial benötigen Sie keine Kenntnisse im Bereich Audio; es dient als Orientierungshilfe für die Benutzeroberfläche.

:::tip[Was Sie benötigen]
- Laden Sie [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) herunter — eine zweisekündige Stereoschleife.

Jeder Schritt dieses Tutorials funktioniert mit diesen Dateien genau so, wie sie sind, sodass das, was Sie sehen, mit dem Tutorial übereinstimmen sollte. Soundscaper läuft im Browser; eine Installation ist nicht erforderlich.
:::

## Was Sie lernen werden

- Wie eine Datei zu einem Clip auf einer Spur wird und wie Sie ihn abspielen.
- Wie Sie einen Clip mit dem Split-Tool teilen.
- Wie Sie Audio auswählen und einen Effekt auf die Auswahl anwenden.
- Der Unterschied zwischen dem Exportieren einer Datei und dem Speichern eines Projekts.

## Schritte

1. Öffnen Sie Soundscaper. Ein neues, leeres Projekt ist bereit, sobald der Editor geladen ist.
2. Wählen Sie **Datei → Audio importieren** und wählen Sie `guide-music-loop.wav` — eine zweisekündige Stereoschleife. Die Datei wird als Clip auf ihrer eigenen Spur abgelegt.
3. Drücken Sie **Abspielen**, um die Schleife abzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Der Abspielkopf bewegt sich über den Clip und die Schleife spielt einmal ab.
4. Drücken Sie die Schaltfläche **Split-Tool** in der Symbolleiste. Wenn das Split-Tool aktiv ist, schneidet ein Klick auf einen Clip an dieser Stelle, anstatt eine Auswahl zu treffen.
5. Klicken Sie auf die Wellenform etwa in der Mitte, um den Cursor dorthin zu setzen.
6. Drücken Sie die Schaltfläche **Split-Tool** in der Symbolleiste. Drücken Sie sie erneut, um zum normalen Zeiger zurückzukehren.
7. Das Projekt zeigt nun 2 Clips an.
   *Sie sollten sehen:* Zwei Clips befinden sich hintereinander dort, wo sich zuvor ein Clip befand, und jeder hat seine eigene Namensleiste.
8. Wählen Sie **Auswählen → Alles auswählen**. Ein Effekt wird auf alles angewendet, was ausgewählt ist. Alles auswählen erfasst das gesamte Projekt, einschließlich beider Clips.
9. Wählen Sie **Effekt → Fading → Ausblenden**. Der Effekt wird sofort auf die Auswahl angewendet.
   *Sie sollten sehen:* Die Wellenform verläuft bis zum Nichts bis zum Ende des zweiten Clips.
10. Drücken Sie **Abspielen**, um die Schleife abzuhören, und dann **Stopp**.
   *Sie sollten sehen:* Die Schleife verklingt, anstatt abrupt zu stoppen.
11. Wählen Sie **Datei → Audio exportieren**, setzen Sie **Format** auf **WAV** und drücken Sie **Exportieren**. Die Datei wird heruntergeladen, sobald das Rendern abgeschlossen ist, und der Link bleibt im Dialogfeld. Ein Export rendert das, was Sie hören, in eine Datei für andere Programme. Es ändert das Projekt nicht.
12. Wählen Sie **Datei → Projekt speichern**. Der Speicherindikator in der Statusleiste zeigt an, dass das Projekt gespeichert wurde. Das Projekt — Clips, Bearbeitungen, Verlauf — befindet sich in der Projektdatenbank des Browsers auf diesem Computer. Das Speichern hält es dort.
