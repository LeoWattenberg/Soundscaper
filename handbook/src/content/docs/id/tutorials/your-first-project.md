Tutorial ini akan memandu Anda melalui satu kali putaran editor pada loop musik dua detik: membawa file, mendengarnya, mengubahnya dengan efek, memotongnya menjadi dua, menghasilkan file yang dapat diputar di mana saja, dan menyimpan proyek sehingga Anda dapat kembali ke dalamnya. Tidak ada pengetahuan audio yang diperlukan di sini; ini adalah tur dari tempat-tempat di mana hal-hal berada.

:::tip[Apa yang Anda butuhkan]
- Unduh [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) — loop stereo dua detik.

Setiap langkah di bawah ini berfungsi pada file-file ini persis seperti yang ada, jadi apa yang Anda lihat harus sesuai dengan apa yang dikatakan tutorial. Soundscaper berjalan di browser; tidak ada yang perlu diinstal.
:::

## Apa yang akan Anda pelajari

- Bagaimana file menjadi klip pada trek, dan bagaimana memainkannya.
- Bagaimana membagi klip dengan alat pemisah.
- Bagaimana memilih audio dan menerapkan efek pada pilihan.
- Perbedaan antara mengekspor file dan menyimpan proyek.

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap segera setelah editor dimuat.
2. Pilih **Berkas → Impor audio** dan pilih `guide-music-loop.wav` — loop stereo dua detik. File mendarat sebagai klip pada treknya sendiri.
3. Tekan **Putar** untuk mendengarnya, lalu **Hentikan**.
   *Anda harus melihat:* Playhead bergerak melintasi klip dan loop dimainkan sekali.
4. Tekan tombol **Alat Pemisah** di toolbar. Saat alat pemisah aktif, klik pada klip memotongnya di sana daripada memilihnya.
5. Klik gelombang di tengah untuk menempatkan kursor di sana.
6. Tekan tombol **Alat Pemisah** di toolbar. Tekan lagi untuk kembali ke penunjuk biasa.
7. Proyek sekarang menunjukkan 2 klip.
   *Anda harus melihat:* Dua klip duduk berujung di mana ada satu, masing-masing dengan bar nama sendiri.
8. Pilih **Pilih → Pilih semua**. Efek diterapkan pada apa pun yang dipilih. Pilih semua mengambil seluruh proyek, termasuk kedua klip.
9. Pilih **Efek → Memudar → Memudar Keluar**. Efek diterapkan pada pilihan segera.
   *Anda harus melihat:* Gelombang meruncing menjadi tidak ada pada akhir klip kedua.
10. Tekan **Putar** untuk mendengarnya, lalu **Hentikan**.
   *Anda harus melihat:* Loop memudar alih-alih berhenti dengan keras.
11. Pilih **Berkas → Ekspor audio**, atur **Format** ke **WAV**, dan tekan **Ekspor**. File diunduh segera setelah render selesai, dan tautannya tetap ada di dialog. Ekspor merender apa yang Anda dengar ke dalam file untuk program lain. Ini tidak mengubah proyek.
12. Pilih **Berkas → Simpan proyek**. Indikator simpan di bilah status menunjukkan bahwa proyek disimpan. Proyek — klip, suntingan, riwayat — hidup di perpustakaan proyek browser di komputer ini. Menyimpan menyimpannya di sana.
