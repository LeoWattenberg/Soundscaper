## Tujuan dan kasus penggunaan {#purpose-and-use-case}

Transkribasi pidato terpilih secara lokal melalui runtime whisper.cpp yang dikemas.

## Ketersediaan Saat Ini {#current-availability}

Build desktop dapat mengunduh dan memverifikasi mesin whisper-cpp v1.9.3 yang diperlukan untuk macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Pasang model ini dan runtime yang diperlukan melalui Pengelola Model, lalu jalankan tugasnya secara lokal. Ini adalah target build yang didukung; lihat laporan pengujian malam untuk hasil pada paket dan mesin tertentu. Mesin yang dapat diunduh untuk macOS x64 tidak tersedia, meskipun bobot model tercantum untuk platform tersebut.

## Gunakan Model Ini {#use-this-model}

Buka **Analisis → Pidato → Transkribasi & Subtitel** pada platform dengan runtime asli yang diperlukan. Bantuan lokal berjalan di editor desktop.

1. Pilih pidato dan pasang Whisper large-v3 turbo melalui Kelola Model.
2. Pilih model pengenalan pidato ini di bawah Alat → Pemrosesan Lokal Lanjutan saat Anda ingin memilih Whisper secara eksplisit.
3. Jalankan secara lokal dan tinjau teks dan batas segmen sebelum menerimanya.
