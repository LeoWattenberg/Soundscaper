## Tujuan dan kasus penggunaan {#purpose-and-use-case}

Kelompokkan ucapan menjadi giliran pembicara agar Anda dapat meninjau siapa yang berbicara dan kapan.

Pyannote menyediakan segmentasi ucapan yang digunakan oleh runtime diarization. ERes2Net menyediakan penyematan pembicara yang digunakan untuk mengelompokkan segmen tersebut.

## Ketersediaan saat ini {#current-availability}

Build desktop dapat mengunduh dan memverifikasi mesin sherpa-onnx-node 1.13.5 yang diperlukan untuk macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Pasang model ini dan runtime yang diperlukan melalui Pengelola Model, lalu jalankan tugasnya secara lokal. Ini adalah target build yang didukung; lihat laporan pengujian malam untuk hasil pada paket dan mesin tertentu. Mesin yang dapat diunduh untuk macOS x64 tidak tersedia, meskipun bobot model tercantum untuk platform tersebut.

## Gunakan model ini {#use-this-model}

Buka **Analisis → Ucapan → Identifikasi Pembicara** pada platform dengan runtime native yang diperlukan. Asistensi lokal berjalan di editor desktop.

1. Pilih percakapan yang akan dianalisis.
2. Instal Pyannote segmentation dan penyematan pembicara ERes2Net melalui Manajer Model; operasi ini menggunakan keduanya.
3. Jalankan secara lokal, tinjau giliran pembicara yang diusulkan, dan terapkan hasil yang diinginkan.

Operasi ini juga memerlukan [Penyematan pembicara ERes2Net](/reference/local-models/speech-3d-speaker-eres2net/).

## Tinjau hasil {#review-the-result}
