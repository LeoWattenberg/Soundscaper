## Tujuan dan kasus penggunaan {#purpose-and-use-case}

Buat representasi numerik lokal dari bagian transkrip dan kueri pencarian untuk pencarian semantik.

## Ketersediaan saat ini {#current-availability}

Build desktop dapat mengunduh dan memverifikasi mesin onnxruntime-node 1.29.0 yang diperlukan untuk macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Pasang model ini dan runtime yang diperlukan melalui Pengelola Model, lalu jalankan tugasnya secara lokal. Ini adalah target build yang didukung; lihat laporan pengujian malam untuk hasil pada paket dan mesin tertentu. Mesin yang dapat diunduh untuk macOS x64 tidak tersedia, meskipun bobot model tercantum untuk platform tersebut.

## Gunakan model ini {#use-this-model}

Buka **Alat → Pencarian → Indeks Transkrip, lalu Alat → Pencarian → Pencarian Terindeks** pada platform dengan runtime native yang diperlukan. Asistensi lokal berjalan di editor desktop.

1. Buat atau impor transkrip, lalu instal Nomic Embed Text melalui Manajer Model.
2. Jalankan Indeks Transkrip untuk menyiapkan teks bagi pencarian semantik.
3. Gunakan Pencarian Terindeks dan tinjau bagian yang cocok dalam konteks. Pemrosesan Lokal Lanjutan juga menyediakan operasi penyematan.
