## Tujuan dan kasus penggunaan {#purpose-and-use-case}

Selaraskan transkrip bahasa Inggris yang sudah ada dengan kata-kata yang diucapkan dalam rekaman.

## Ketersediaan saat ini {#current-availability}

Build desktop dapat mengunduh dan memverifikasi mesin onnxruntime-node 1.29.0 yang diperlukan untuk macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Pasang model ini dan runtime yang diperlukan melalui Pengelola Model, lalu jalankan tugasnya secara lokal. Ini adalah target build yang didukung; lihat laporan pengujian malam untuk hasil pada paket dan mesin tertentu.

## Gunakan model ini {#use-this-model}

Buka **Analisis → Ucapan → Transkripsi & Takarir, atau Alat → Pemrosesan Lokal Lanjutan → Penyelarasan kata** pada platform dengan runtime native yang diperlukan. Asistensi lokal berjalan di editor desktop.

1. Pilih ucapan, lalu siapkan atau tinjau transkrip bahasa Inggrisnya.
2. Instal model penyelarasan melalui Pengelola Model.
3. Jalankan penyelarasan, lalu dengarkan sambil meninjau batas kata yang diusulkan sebelum menerimanya.

## Unduhan dan persyaratan {#download-and-requirements}

Identitas model: `wav2vec2-base-960h`, versi **1.0.0**.

Perkiraan ukuran unduhan artefak model: **360.38 MiB**. Runtime yang diperlukan ditambahkan pada unduhan pertama jika belum terpasang. Memori sistem minimum: **4 GiB**. Persyaratan katalog ini mengacu pada total memori, bukan memori bebas saat ini. Inferensi juga memerlukan cukup memori bebas dan instalasi memerlukan ruang kerja; memori tidak menjamin kecepatan.

Platform yang dipublikasikan: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Runtime yang dapat diunduh dan sesuai juga diperlukan.

Di Windows, pasang [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) terbaru yang didukung dan sesuai dengan aplikasi desktop: **x64** untuk build x64 atau **ARM64** untuk build ARM64. Mesin native ONNX dan Sherpa memerlukan pustaka ini; unduhan model dan runtime tidak menyertakannya. Visual Studio tidak diperlukan untuk menggunakan aplikasi.

Alat → Pengelola Model mengunduh artefak model yang dipublikasikan dan runtime yang diperlukan pada pemasangan pertama, lalu memverifikasi digest SHA-256 yang tercatat. ## Tinjau hasil {#review-the-result}

- Model ini menyelaraskan kata-kata bahasa Inggris yang diberikan; model tidak menerjemahkan atau memperbaiki transkrip yang salah.
