## Tujuan dan kasus penggunaan {#purpose-and-use-case}

Baca teks yang terlihat dari sampel bingkai video untuk ditinjau dan diindeks.

## Ketersediaan saat ini {#current-availability}

Build desktop dapat mengunduh dan memverifikasi mesin onnxruntime-node 1.29.0 yang diperlukan untuk macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Pasang model ini dan runtime yang diperlukan melalui Pengelola Model, lalu jalankan tugasnya secara lokal. Ini adalah target build yang didukung; lihat laporan pengujian malam untuk hasil pada paket dan mesin tertentu. Mesin yang dapat diunduh untuk macOS x64 tidak tersedia, meskipun bobot model tercantum untuk platform tersebut.

## Gunakan model ini {#use-this-model}

Buka **Framescaper: Tools → Search → Index Video, atau Tools → Advanced Local Processing → Optical character recognition** di platform dengan runtime asli yang diperlukan. Bantuan lokal berjalan di editor desktop.

1. Pilih video yang berisi teks on-screen yang dapat dibaca.
2. Pasang PP-OCRv4 mobile melalui Manage Models. Ini adalah langkah opsional dari Index Video, yang juga menggunakan SigLIP2.
3. Jalankan secara lokal dan tinjau teks yang dikenali dan lokasinya di bingkai sebelum menerima hasilnya.

## Unduh dan persyaratan {#download-and-requirements}

Identitas model: `ppocr-v4-mobile`, versi **4.0.0**.

Perkiraan ukuran unduhan artefak model: **15.46 MiB**. Runtime yang diperlukan ditambahkan pada unduhan pertama jika belum terpasang. Memori sistem minimum: **2 GiB**. Persyaratan katalog ini mengacu pada total memori, bukan memori bebas saat ini. Inferensi juga memerlukan cukup memori bebas dan instalasi memerlukan ruang kerja; memori tidak menjamin kecepatan.

Platform yang dipublikasikan: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Runtime yang dapat diunduh dan sesuai juga diperlukan.

Di Windows, pasang [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) terbaru yang didukung dan sesuai dengan aplikasi desktop: **x64** untuk build x64 atau **ARM64** untuk build ARM64. Mesin native ONNX dan Sherpa memerlukan pustaka ini; unduhan model dan runtime tidak menyertakannya. Visual Studio tidak diperlukan untuk menggunakan aplikasi.

Alat → Pengelola Model mengunduh artefak model yang dipublikasikan dan runtime yang diperlukan pada pemasangan pertama, lalu memverifikasi digest SHA-256 yang tercatat.
