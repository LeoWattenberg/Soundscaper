Sebuah workspace adalah susunan yang disimpan dari panel dan toolbar di sekitar timeline. Memilih satu akan menggantikan susunan saat ini; Anda kemudian dapat memindahkan apa pun dan menyimpan workspace Anda sendiri, yang tidak dijelaskan di halaman ini.

## Workspace Bawaan

| Workspace | ID Perintah | Produk |
| --- | --- | --- |
| Klasik | `workspace-classic` | Soundscaper, Framescaper |
| Musik | `workspace-music` | Soundscaper, Framescaper |
| Soundscaper | `workspace-modern` | Soundscaper, Framescaper |
| Audacity | `workspace-audacity` | Soundscaper, Framescaper |
| Penyunting Video | `workspace-video-editor` | Framescaper |

## Dok

Sebuah panel menempati salah satu posisi ini. “Mengapung” berarti jendela panel yang dapat Anda letakkan secara bebas.

| Dok | ID Dok |
| --- | --- |

| Kanan | `right` |
| Bawah | `bottom` |
| Mengapung | `floating` |
