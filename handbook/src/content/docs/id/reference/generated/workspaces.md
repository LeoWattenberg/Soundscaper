Workspace adalah susunan yang disimpan dari panel dan toolbar di sekitar garis waktu. Memilih satu menggantikan susunan saat ini; Anda kemudian dapat memindahkan apa pun dan menyimpan workspace Anda sendiri, yang halaman ini tidak jelaskan.

## Workspace bawaan

| Workspace | Command ID | Produk |
| --- | --- | --- |
| Klasik | `workspace-classic` | Soundscaper, Framescaper |
| Musik | `workspace-music` | Soundscaper, Framescaper |
| Soundscaper | `workspace-modern` | Soundscaper, Framescaper |
| Audacity | `workspace-audacity` | Soundscaper, Framescaper |
| Editor video | `workspace-video-editor` | Framescaper |
