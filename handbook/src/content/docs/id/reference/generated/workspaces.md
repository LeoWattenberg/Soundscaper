Buka panel opsional dari **Jendela**. **Jam**, **Meter pemutaran**, dan **Meter perekaman** Soundscaper tersembunyi saat awal. Pilih **Lepaskan kode waktu** dari menu tarik-turun kode waktu toolbar untuk memindahkan tampilannya ke panel Clock; **Kembalikan ke toolbar** di menu Clock mengembalikannya.

Buka **Jendela > Properti klip** untuk memeriksa pilihan klip saat ini di samping garis waktu. Panel mengikuti pilihan dan diperbarui saat klip berubah. Jika beberapa klip dipilih, pilih tab klip untuk mengedit propertinya. Panel tersembunyi saat awal dan mendukung docking, tab panel bersama, serta pengubahan ukuran.

Gunakan **Menu panel** untuk memindahkannya ke kiri, kanan, atas, bawah, atau jendela mengambang. Untuk berbagi bingkai, pilih **Atur panel**, panel tujuan, lalu **Sebagai tab**. Tab memakai bingkai penuh yang sama dan hanya satu panel terlihat pada satu waktu. Seret pegangan ke sepertiga tengah panel lain untuk membuat tab; sepertiga awal atau akhir menempatkannya sebelum atau sesudah bingkai itu.

Ubah ukuran dock samping dengan menyeret tepi dalamnya; untuk dock atas atau bawah, seret tepi di samping garis waktu. Panel mengambang diubah ukurannya dari tepi kanan dan bawah. Clock memperbesar kode waktu agar pas dengan bingkai, dan meter memperlebar bilah agar terbaca dari jauh.

## Bilah alat

Pilih **Dock toolbar** dari menu penyesuaian toolbar untuk menempatkannya di atas, bawah, kiri, kanan, atau jendela mengambang. Anda juga dapat menyeret pegangannya ke tepi editor untuk memasangnya. Tata letak samping menumpuk kontrol secara vertikal.
