## Browser

"Diuji secara otomatis" berarti paket browser berjalan terhadap mesin ini pada setiap permintaan tarik. Mesin yang tidak tercantum tidak diuji dan tidak diklaim berfungsi.

| Mesin Browser | Diuji Secara Otomatis |
| --- | --- |
| Chromium (Chrome, Edge) | Ya |
| Firefox | Ya |
| WebKit (Safari) | Ya |

## Di mana kemampuan dapat berjalan

Kemampuan dikelompokkan berdasarkan apa yang mereka butuhkan dari platform. Lihat [Kemampuan Produk](/reference/generated/product-capabilities/) untuk kemampuan mana yang diaktifkan oleh setiap produk.

| Tier | Artinya |
| --- | --- |
| `web-core` | Berfungsi di setiap browser yang didukung, tanpa fitur platform opsional yang diperlukan. |
| `web-enhanced` | Berfungsi di browser yang menyediakan fitur penyimpanan dan media yang lebih baru yang dibutuhkan kemampuan. |
| `electron-enhanced` | Berfungsi di browser, dan aplikasi desktop melakukan lebih banyak dengan itu. |
| `electron-only` | Membutuhkan aplikasi desktop, karena browser tidak dapat mencapai apa yang digunakan kemampuan. |
