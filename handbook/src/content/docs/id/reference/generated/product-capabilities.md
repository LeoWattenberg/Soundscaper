Halaman ini mencerminkan profil produk saat ini. "Diaktifkan" berarti profil tersebut mengekspos kemampuan pengaran atau runtime. Kemampuan yang dinonaktifkan masih dapat disimpan saat proyek dibuka di seluruh produk; tabel ini tidak mengklaim bahwa hal itu dapat diedit.

## Keluarga impor dan ekspor

| Produk | Keluarga impor | Keluarga ekspor |
| --- | --- | --- |
| Soundscaper | .sscape, proyek Audacity, Audio, Video, Label | .sscape, AUP4 (hanya audio), Audio, Video, Label, stem audio |
| Framescaper | .fscape, proyek Audacity, Audio, Video, Label | .fscape, Audio, Video, Label |

Keluarga menggambarkan titik masuk produk, bukan setiap ekstensi file yang mungkin diterima oleh decoder. Lihat [Format Ekspor](/reference/generated/formats/) untuk format output konkret dan kondisi runtime.
