Perpustakaan proyek berada di satu peramban di satu komputer. Untuk membawa proyek ke tempat lain — mesin lain, rekan kerja, drive cadangan — ekspor sebagai file proyek. File `.sscape` menyimpan audio dan setiap edit, dan dibuka di setiap Soundscaper.

:::note[Beralih dari Audacity?]
Ini adalah **File → Simpan Proyek → Cadangkan Proyek, lalu File → Buka** di Audacity. Nama-nama di bawah ini adalah nama-nama milik Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru dan kosong siap segera setelah editor dimuat.
2. Pilih **File → Impor audio** dan pilih materi proyek. File mendarat sebagai klip di lintasan sendiri.
3. Pilih **File → Ekspor file proyek (.sscape)**. Seluruh proyek diunduh sebagai satu file `.sscape`. Simpan file di tempat yang aman; ini adalah proyek lengkap.
4. Pilih **File → Buka file proyek Scape (.sscape)** dan pilih file. Di komputer yang belum memiliki proyek, ia dibuka langsung; di sini, di mana perpustakaan sudah memilikinya, Soundscaper menawarkan **Buka sebagai salinan hanya baca** — tekanlah.
   *Anda harus melihat:* Proyek dibuka dengan lintasan dan klipnya persis seperti yang diekspor.

## Tips

- Salinan hanya baca tidak dapat diedit hingga Anda menyimpannya sebagai proyek sendiri dari menu File.
- File ini adalah arsip ZIP dengan audio di dalamnya; jangan urutkannya secara manual.
