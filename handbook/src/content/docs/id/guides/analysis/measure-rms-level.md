## Panduan ini untuk apa {#what-this-guide-is-for}

RMS adalah ukuran rata-rata level sinyal sepanjang waktu. Gunakan penganalisis Measure RMS untuk membandingkan bagian atau memeriksa kekuatan suatu bagian sebelum menyesuaikannya.

:::note[Masuk dari Audacity?]
Padanannya di Audacity adalah **Analyze → Measure RMS (Nyquist)**. Nama di bawah ini milik Soundscaper dan terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap digunakan begitu editor dimuat.
2. Pilih **Berkas → Impor**, lalu pilih bagian yang level rata-ratanya ingin diukur. Bagian itu akan muncul sebagai klip di trek tersendiri.
3. Pilih **Pilih → Pilih semua**.
4. Pilih **Analisis → Nyquist → Measure RMS**. Dalam dialog **Measure RMS**, tekan **Terapkan**. Dialog menampilkan hasil pengukuran; tekan **Tutup** untuk menutupnya.
   *Yang akan terlihat:* Laporan menunjukkan level RMS dalam dB untuk setiap kanal dan untuk sinyal stereo secara keseluruhan.

## Tips

- RMS menggambarkan level rata-rata; gunakan [peak normalization](/guides/volume/normalize-peaks/) bila Anda perlu menetapkan target untuk sampel tertinggi.
- Pilih hanya bagian yang ingin dibandingkan agar audio lain tidak memengaruhi pengukuran.
