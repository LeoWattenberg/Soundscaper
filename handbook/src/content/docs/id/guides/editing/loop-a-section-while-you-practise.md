Mempelajari sebuah riff, memeriksa titik edit, mencoba pengaturan efek: semuanya menjadi lebih cepat ketika bagian yang dipilih diputar berulang kali tanpa Anda perlu memulainya kembali. Atur wilayah loop ke seleksi dan pemutaran akan tetap berada di dalamnya hingga Anda mematikan loop.

:::note[Beralih dari Audacity?]
Ini adalah **Transport → Looping → Set Loop to Selection** di Audacity. Nama-nama di bawah ini adalah nama-nama yang digunakan oleh Soundscaper, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru dan kosong siap digunakan saat editor dimuat.
2. Pilih **File → Import audio** dan pilih rekaman dengan bagian yang ingin Anda latih. File akan ditempatkan sebagai klip di lintasan sendiri.
3. Seret di atas klip pada penggaris untuk memilih bagian yang ingin diulang.
4. Pilih **Select → Loop region → Set loop to selection**.
5. Proyek sekarang menunjukkan tombol **Loop selection** yang menyala.
   *Anda harus melihat:* Tombol loop di bar transport menyala dan wilayah loop ditampilkan di atas penggaris.
6. Tekan **Play** untuk mendengarkan, lalu **Stop**.
   *Anda harus melihat:* Pemutaran akan berulang di bagian yang dipilih.

## Tips

- Tekan **L** atau tombol loop di bar transport untuk menyalakan dan mematikan loop tanpa kehilangan wilayah.
- Seret ujung wilayah loop di penggaris untuk menyesuaikannya.
