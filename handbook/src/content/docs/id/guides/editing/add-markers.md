Marker adalah catatan pada garis waktu: di mana bab dimulai, di mana kesalahan perlu diperbaiki, di mana rekaman yang baik dimulai. Marker tidak mengubah audio, mereka mengikuti proyek, dan dapat diekspor sebagai file label untuk alat lain.

:::note[Masuk dari Audacity?]
Ini adalah **Edit → Labels → Add Label at Selection (Ctrl+B)** di Audacity. Nama di bawah ini adalah milik Soundscaper, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap digunakan segera setelah editor dimuat.
2. Pilih **File → Import audio** dan pilih rekaman yang ingin Anda beri tanda. File akan muncul sebagai klip di treknya sendiri.
3. Pilih **View → Show markers**. Ini menambahkan jalur marker di atas trek. Marker ada tanpa jalur ini, tetapi jalur adalah tempat Anda melihat dan mengeditnya.
4. Klik pada waveform di tempat marker harus diletakkan untuk menempatkan kursor di sana. Marker akan berada di tempat kursor berada.
5. Dengan panel Markers terbuka (**View → Panels → Markers** menampilkannya), tekan **Add marker at playhead**. Tekan Enter pada marker baru, ketik `Chorus` dan tekan Enter lagi untuk memberinya nama.
   *Yang harus Anda lihat:* Marker muncul di jalur di atas trek dan di daftar panel, dengan nama yang Anda ketik.

## Tips

- Dengan rentang waktu yang dipilih, tombol yang sama menambahkan region bernama alih-alih satu titik.
- **File → Export other → Export labels** menulis marker sebagai file teks yang dapat dibaca oleh Audacity dan editor lain.
