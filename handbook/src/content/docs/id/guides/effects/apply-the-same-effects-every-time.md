Setiap episode mendapat perlakuan yang sama: normalisasi, fade ending. Makro merekam urutan tersebut sekali dan menjalankannya kapan pun Anda meminta, dengan pengaturan yang Anda pilih, sehingga rutinitas sepuluh langkah menjadi satu perintah. Audacity 3 memiliki Macro Manager untuk hal ini; Audacity 4 tidak mengembalikan makro.

:::note[Masuk dari Audacity?]
Ini adalah **Tools → Macros → Manage Macros and Apply Macro (Audacity 3; Audacity 4 tidak memiliki makro)** dari Audacity. Nama-nama di bawah ini adalah milik Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap segera setelah editor dimuat.
2. Pilih **File → Import audio** dan pilih rekaman untuk diproses. File akan muncul sebagai klip di treknya sendiri.
3. Pilih **Select → Select all**. Makro berjalan pada seleksi, sama seperti setiap efek yang berjalan sendiri.
4. Pilih **Tools → Macro manager** dan tekan **New macro**. Ketik `Episode finish` ke dalam **Macro name**. Tekan **Add effect** dan pilih **Normalize** dan **Fade Out**, tekan **Add effect** lagi untuk masing-masing. Tekan **Run macro**; dialog melaporkan bahwa makro telah diterapkan. Tekan **Close**. Setiap langkah mempertahankan pengaturan default di sini; tekan tombol **Select effect** pada langkah untuk mengubahnya sebelum Anda menjalankan.
   *Anda harus melihat:* Rekaman dinormalisasi dan memudar menjadi hening di akhir.
5. Tekan **Play** untuk mendengarkan, lalu **Stop**.

## Tips

- Makro disimpan dengan editor, sehingga menunggu di bawah **Tools → Macro manager** untuk rekaman berikutnya.
- **Export macro** menulis rantai sebagai file teks makro Audacity, dan **Import macro** membacanya, sehingga rutinitas dapat berpindah antara kedua program.
