## Panduan ini untuk apa {#what-this-guide-is-for}

Mengimpor file membuat trek untuk Anda, tetapi rekaman atau tempel membutuhkan tempat untuk mendarat. Tombol **Tambah trek** di atas daftar trek membuat trek audio kosong; trek label menahan penanda dan teks daripada suara.

:::note[Datang dari Audacity?]
Ini adalah **Trek → Tambah Baru → Trek Mono** di Audacity. Nama di bawah ini adalah milik Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru dan kosong siap segera setelah editor dimuat.
2. Tekan **Tambah trek** di atas daftar trek dan pilih **Trek audio**.
3. Proyek sekarang menunjukkan 2 trek.
   *Anda harus melihat:* Trek audio kosong kedua di bawah yang pertama.

## Tips

- Ubah nama trek dari menu sehingga sesi dengan banyak trek tetap dapat dibaca.
- Seret trek dengan header-nya untuk mengubah urutannya.
