WAV menyimpan setiap sampel persis seperti yang dimiliki editor. Gunakannya untuk master, untuk menyerahkan audio ke editor video atau DAW lainnya, dan untuk apa pun yang mungkin ingin Anda proses lagi.

:::note[Berasal dari Audacity?]
Ini adalah **File → Ekspor Audio → WAV** di Audacity. Nama-nama di bawah ini adalah milik Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap segera setelah editor dimuat.
2. Pilih **File → Impor** dan pilih rekaman yang akan dikirim. Ini mendarat sebagai klip di treknya sendiri.
3. Pilih **File → Ekspor audio**, atur **Format** ke **WAV**, dan tekan **Ekspor**. File diunduh segera setelah rendering selesai, dan tautannya tetap ada di dialog.

## Tips

- File WAV besar: sekitar sepuluh megabyte per menit untuk stereo dengan kualitas CD.
- Untuk mengekspor setiap trek sebagai file tersendiri, atur **Mode** di dialog ekspor ke batang individu.
