Dengan belasan trek, membisukan satu per satu melalui header untuk mendengarkan bagian baru yang tunggal adalah hal yang membosankan, dan mengaktifkan kembali suaranya setelahnya lebih buruk lagi. Mute all tracks membisukan seluruh proyek dalam satu perintah dan Unmute all tracks memulihkannya, dan keduanya tidak menyentuh tombol solo. Audacity 3 memiliki kedua perintah tersebut; Audacity 4 tidak mengembalikannya.

:::note[Masuk dari Audacity?]
Ini adalah **Tracks → Mute/Unmute → Mute All Tracks and Unmute All Tracks (Audacity 3; tidak ada di Audacity 4)** dari Audacity. Nama di bawah ini adalah milik Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap segera setelah editor dimuat.
2. Pilih **File → Import audio** dan pilih rekaman pertama. File akan mendarat sebagai klip di treknya sendiri.
3. Pilih **File → Import audio** dan pilih rekaman kedua. File akan mendarat sebagai klip di treknya sendiri.
4. Pilih **Tracks → Mute all tracks**.
5. Proyek sekarang menampilkan tombol **Mute** di setiap trek menyala.
   *Yang harus Anda lihat:* Pemutaran senyap.
6. Pilih **Tracks → Unmute all tracks**.
7. Proyek sekarang menampilkan tidak ada trek yang dibisukan.
   *Yang harus Anda lihat:* Semua kembali diputar.

## Tips

- Bisukan semuanya, lalu aktifkan kembali satu atau dua trek yang ingin Anda dengar — lebih cepat daripada soloing ketika pilihan sering berubah.
- Untuk mendengar satu trek saja tanpa menyentuh yang lain, [solo-kan](/guides/tracks-and-export/mute-and-solo-tracks/) sebagai gantinya.
