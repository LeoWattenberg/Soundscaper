Sebuah file MP3 kecil, dapat diputar di mana saja, dan merupakan format yang diharapkan oleh sebagian besar tuan rumah podcast dan aplikasi pesan. Ekspor ini menghasilkan seluruh proyek — setiap trek, efek, dan edit — ke dalam satu file.

:::note[Beralih dari Audacity?]
Ini adalah **File → Ekspor Audio → MP3** di Audacity. Nama-nama di bawah ini adalah nama-nama yang digunakan Soundscaper sendiri, yang terkadang berbeda.
:::

## Langkah-langkah

1. Buka Soundscaper. Proyek baru yang kosong siap digunakan saat editor dimuat.
2. Pilih **File → Impor** dan pilih rekaman yang ingin dipublikasikan. Rekaman tersebut akan ditempatkan sebagai klip pada treknya sendiri.
3. Pilih **File → Ekspor audio**, atur **Format** ke **MP3**, dan tekan **Ekspor**. File akan diunduh segera setelah proses rendering selesai, dan tautannya tetap ada di dialog. File dienkodekan di browser; tidak ada yang meninggalkan komputer Anda.

## Tips

- File MP3 adalah salinan untuk distribusi, bukan cadangan. Simpan proyek atau ekspor juga dalam format WAV jika Anda mungkin akan mengeditnya lagi.
- Puncak yang tepat pada skala penuh dapat terpotong setelah pengkodean. Normalisasi ke −1 dB atau lebih rendah sebelum mengekspor.
- Bit Rate Mode menentukan bagaimana pengkodean menghabiskan bit. Preset Standar bervariasi sesuai dengan materi dan cocok untuk sebagian besar distribusi; pilih Konstan ketika tuan rumah atau pemutar perangkat keras lama meminta satu tarif tetap.
