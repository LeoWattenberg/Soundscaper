## Langkah-langkah

1. Buka Soundscaper. Proyek baru dan kosong siap segera setelah editor dimuat.
2. Pilih **File → Import** dan pilih rekaman dengan hum. Rekaman tersebut akan mendarat sebagai klip di treknya sendiri.
3. Pilih **Select → Select all**.
4. Pilih **Effect → EQ dan filter → Notch filter**. Dalam dialog **Notch filter**, atur **Notch frequency** ke `50` dan **Q** ke `4`, lalu tekan **Apply to selection**. Gunakan 60 jika mains Anda adalah 60 Hz. Q 4 adalah notch sempit; turunkan jika hum berkeliaran, tingkatkan jika pemotongan terdengar pada suara.
5. Tekan **Play** untuk mendengarkan, lalu **Stop**.
*Anda harus melihat:* Hum hilang dan suara terdengar sama.

## Tips

- Tidak yakin dengan frekuensi? [Plot spektrum](/guides/analysis/plot-a-spectrum/) dari bagian tenang dan baca puncaknya.
- Hum sering memiliki harmonik pada frekuensi ganda. Jalankan filter lagi pada 100 atau 120 Hz jika beberapa masih tersisa.
