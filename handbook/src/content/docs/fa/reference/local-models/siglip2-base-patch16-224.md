## هدف و مورد استفاده {#purpose-and-use-case}

تصویرها و متن ویدئوی نمونه‌برداری‌شده را در فضای عددی مشترکی بازنمایی کنید تا جست‌وجوی بصری به‌صورت محلی انجام شود.

## دسترس‌پذیری کنونی {#current-availability}

نسخه‌های دسکتاپ می‌توانند موتور onnxruntime-node 1.29.0 موردنیاز را برای macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 دانلود و تأیید کنند. این مدل و محیط اجرای موردنیاز را از طریق مدیر مدل‌ها نصب کنید و سپس کار را به‌صورت محلی اجرا کنید. این‌ها اهداف ساخت پشتیبانی‌شده‌اند؛ برای نتایج یک بسته و دستگاه مشخص، گزارش آزمون شبانه را ببینید. برای macOS x64 موتور قابل‌دانلودی وجود ندارد، بااین‌حال وزن‌های مدل برای این سکو فهرست شده‌اند.

## استفاده از این مدل {#use-this-model}

در پلتفرمی با موتور بومی لازم، **Framescaper: ابزارها → جستجو → نمایه‌سازی ویدئو، سپس ابزارها → جستجو → جستجوی نمایه‌شده** را باز کنید. کمک محلی در ویرایشگر دسکتاپ اجرا می‌شود.

1. ویدئو را انتخاب کنید و SigLIP2 را از مدیریت مدل‌ها نصب کنید.
2. برای تحلیل فریم‌های نمونه‌برداری‌شده، نمایه‌سازی ویدئو را اجرا کنید. اگر می‌خواهید مرحلهٔ اختیاری خواندن متن را هم اجرا کنید، PP-OCRv4 را نیز نصب کنید.
3. از جستجوی نمایه‌شده استفاده کنید و لحظه‌های ویدئوییِ منطبق را پیش از تصمیم‌گیری دربارهٔ کاربردشان بازبینی کنید.

## بارگیری و نیازمندی‌ها {#download-and-requirements}

شناسهٔ مدل: `siglip2-base-patch16-224`، نسخهٔ **2.0.0**.

اندازه تقریبی دانلود فایل مدل: **393.25 MiB**. اگر محیط اجرای موردنیاز از قبل نصب نشده باشد، به دانلود نخست اضافه می‌شود. حداقل حافظه سیستم: **8 GiB**. این الزام فهرست به کل حافظه اشاره دارد، نه حافظه آزاد فعلی. استنتاج نیز به حافظه آزاد کافی نیاز دارد و نصب فضای کاری می‌خواهد؛ حافظه سرعت را تضمین نمی‌کند.

سکوهای منتشرشده: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. محیط اجرای قابل‌دانلود و سازگار نیز لازم است.

ابزارها → مدیر مدل‌ها در نخستین نصب، فایل‌های مدل منتشرشده و محیط اجرای موردنیاز را دانلود و چکیده‌های SHA-256 ثبت‌شده را تأیید می‌کند. پردازش از فایل‌های نصب‌شده محلی استفاده می‌کند. برای دیدن اعلان‌ها، تعمیر نصب یا تغییر محل ذخیره‌سازی، بخش ذخیره‌سازی و تأیید را در مدیر مدل‌ها باز کنید.
