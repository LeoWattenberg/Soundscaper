## هدف و مورد استفاده {#purpose-and-use-case}

چهره‌ها و اشیا را در فریم‌های نمونه‌برداری‌شده ویدیو پیدا کنید تا به پیشنهاد قاب‌بندی تازه کمک شود.

D-FINE دسته‌های اشیا و محل آن‌ها را تشخیص می‌دهد. عملیات تشخیص سوژه این نتایج را با تشخیص چهره YuNet ترکیب می‌کند.

## دسترس‌پذیری کنونی {#current-availability}

نسخه‌های دسکتاپ می‌توانند موتور onnxruntime-node 1.29.0 موردنیاز را برای macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 دانلود و تأیید کنند. این مدل و محیط اجرای موردنیاز را از طریق مدیر مدل‌ها نصب کنید و سپس کار را به‌صورت محلی اجرا کنید. این‌ها اهداف ساخت پشتیبانی‌شده‌اند؛ برای نتایج یک بسته و دستگاه مشخص، گزارش آزمون شبانه را ببینید. برای macOS x64 موتور قابل‌دانلودی وجود ندارد، بااین‌حال وزن‌های مدل برای این سکو فهرست شده‌اند.

## استفاده از این مدل {#use-this-model}

در پلتفرمی که زمان‌اجرای بومی لازم را دارد، **Framescaper: افکت → افکت‌های ویدیو → بازقاب‌بندی** را باز کنید. پردازش محلی در ویرایشگر دسکتاپ انجام می‌شود.

1. یک کلیپ ویدیویی را در Framescaper انتخاب کنید.
2. برای تشخیص سوژه، هم YuNet و هم D-FINE را نصب کنید. وظیفه راهنمای Reframe از تشخیص برجستگی U²-Net-P نیز استفاده می‌کند.
3. پردازش را محلی اجرا کنید و برش پیشنهادی را بررسی کنید. ابزارها → پردازش محلی پیشرفته می‌تواند تشخیص سوژه را به‌تنهایی اجرا کند.

این عملیات به [تشخیص چهره YuNet](/reference/local-models/yunet-face-detection-2026may/) نیز نیاز دارد.

## دانلود و نیازمندی‌ها {#download-and-requirements}

هویت مدل: `dfine-nano-coco`، نسخه **1.0.0**.

اندازه تقریبی دانلود فایل مدل: **14.56 MiB**. اگر محیط اجرای موردنیاز از قبل نصب نشده باشد، به دانلود نخست اضافه می‌شود. حداقل حافظه سیستم: **2 GiB**. این الزام فهرست به کل حافظه اشاره دارد، نه حافظه آزاد فعلی. استنتاج نیز به حافظه آزاد کافی نیاز دارد و نصب فضای کاری می‌خواهد؛ حافظه سرعت را تضمین نمی‌کند.

سکوهای منتشرشده: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. محیط اجرای قابل‌دانلود و سازگار نیز لازم است.

در Windows، آخرین [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) پشتیبانی‌شده و سازگار با برنامه دسکتاپ را نصب کنید: **x64** برای ساخت x64 یا **ARM64** برای ساخت ARM64. موتورهای بومی ONNX و Sherpa به این کتابخانه‌ها نیاز دارند؛ دانلودهای مدل و محیط اجرا آن‌ها را شامل نمی‌شوند. برای استفاده از برنامه به Visual Studio نیازی نیست.

ابزارها → مدیر مدل‌ها در نخستین نصب، فایل‌های مدل منتشرشده و محیط اجرای موردنیاز را دانلود و چکیده‌های SHA-256 ثبت‌شده را تأیید می‌کند. پردازش از فایل‌های نصب‌شده محلی استفاده می‌کند. برای دیدن اعلان‌ها، تعمیر نصب یا تغییر محل ذخیره‌سازی، بخش ذخیره‌سازی و تأیید را در مدیر مدل‌ها باز کنید.
