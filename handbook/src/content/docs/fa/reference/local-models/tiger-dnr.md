## هدف و مورد استفاده {#purpose-and-use-case}

ترک صوتیِ ترکیبی را به پیشنهادهایی جداگانه برای گفت‌وگو، موسیقی و افکت‌ها تفکیک کنید.

## دسترس‌پذیری کنونی {#current-availability}

نسخه‌های دسکتاپ می‌توانند موتور onnxruntime-node 1.29.0 موردنیاز را برای macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 دانلود و تأیید کنند. این مدل و محیط اجرای موردنیاز را از طریق مدیر مدل‌ها نصب کنید و سپس کار را به‌صورت محلی اجرا کنید. این‌ها اهداف ساخت پشتیبانی‌شده‌اند؛ برای نتایج یک بسته و دستگاه مشخص، گزارش آزمون شبانه را ببینید.

## استفاده از این مدل {#use-this-model}

در پلتفرمی با موتور بومی لازم، **ابزارها → پردازش محلی پیشرفته → جداسازی منبع** را باز کنید. کمک محلی در ویرایشگر دسکتاپ اجرا می‌شود.

1. صدای ترکیبی را که می‌خواهید جدا کنید انتخاب کنید.
2. TIGER را از مدیر مدل‌ها نصب کنید و سپس جداسازی منبع را اجرا کنید.
3. هر لایهٔ صوتیِ پیشنهادی را گوش کنید و تنها نتیجه‌های دلخواه را به پروژه بیفزایید.

## بارگیری و نیازمندی‌ها {#download-and-requirements}

شناسهٔ مدل: `tiger-dnr`، نسخهٔ **1.0.0**.

اندازه تقریبی دانلود فایل مدل: **28.25 MiB**. اگر محیط اجرای موردنیاز از قبل نصب نشده باشد، به دانلود نخست اضافه می‌شود. حداقل حافظه سیستم: **4 GiB**. این الزام فهرست به کل حافظه اشاره دارد، نه حافظه آزاد فعلی. استنتاج نیز به حافظه آزاد کافی نیاز دارد و نصب فضای کاری می‌خواهد؛ حافظه سرعت را تضمین نمی‌کند.

سکوهای منتشرشده: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. محیط اجرای قابل‌دانلود و سازگار نیز لازم است.

در Windows، آخرین [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) پشتیبانی‌شده و سازگار با برنامه دسکتاپ را نصب کنید: **x64** برای ساخت x64 یا **ARM64** برای ساخت ARM64. موتورهای بومی ONNX و Sherpa به این کتابخانه‌ها نیاز دارند؛ دانلودهای مدل و محیط اجرا آن‌ها را شامل نمی‌شوند. برای استفاده از برنامه به Visual Studio نیازی نیست.

ابزارها → مدیر مدل‌ها در نخستین نصب، فایل‌های مدل منتشرشده و محیط اجرای موردنیاز را دانلود و چکیده‌های SHA-256 ثبت‌شده را تأیید می‌کند. پردازش از فایل‌های نصب‌شده محلی استفاده می‌کند. برای دیدن اعلان‌ها، تعمیر نصب یا تغییر محل ذخیره‌سازی، بخش ذخیره‌سازی و تأیید را در مدیر مدل‌ها باز کنید.

## بازبینی نتیجه {#review-the-result}

- جداسازی ممکن است صدای نشت‌کرده یا آثار ناخواسته باقی بگذارد؛ صداهای اصلیِ مجزای ضبط را بی‌اتلاف بازیابی نمی‌کند.
- آزمون نمونهٔ ترکیبی به هر سه لایه، صدای متناهی با اندازهٔ درست و نمونه‌های تغییریافته و غیرساکت نیاز دارد. لایه‌های تکراری را هم رد می‌کند، اما کیفیت جداسازی را اندازه نمی‌گیرد.
