در نسخه‌های Electron برنامه‌های Soundscaper و Framescaper، فرمان **File → Overwrite filename** کل پروژهٔ ویرایش‌شده را در فایل رسانه‌ای که ابتدا وارد کرده‌اید صادر می‌کند. این فرمان از تنظیمات صادرات پشتیبانی‌شدهٔ فایل اصلی استفاده می‌کند و بدون باز کردن پنجرهٔ صادرات یا انتخاب فایل، فوراً ذخیره می‌کند. صدا قالب مبدأ، نرخ نمونه‌برداری و تعداد کانال‌ها را حفظ می‌کند. ویدیوهای MP4 و WebM پشتیبانی‌شده نیز محفظه، ابعاد و نرخ فریم مبدأ را حفظ می‌کنند.

یک فایل رسانه‌ای را از مسیر **File → Import** وارد کنید، تغییرات را انجام دهید و سپس **File → Overwrite filename** را انتخاب کنید. پس از ویرایش‌های بعدی هم می‌توانید این کار را تکرار کنید. انتخاب زمانی محدودهٔ بازنویسی را محدود نمی‌کند: همیشه کل پروژه رندر می‌شود. پروژه رسانه‌های واردشده و تاریخچهٔ ویرایش را نگه می‌دارد.

اگر پروژه فایل اصلی پشتیبانی‌شده‌ای نداشته باشد، چند فایل اصلی وارد شده باشند یا در حال وارد کردن، ضبط یا پردازش باشید، این فرمان در دسترس نیست. نسخه‌های مرورگر از پنجرهٔ معمول صادرات استفاده می‌کنند.

اگر می‌خواهید مقصد دیگری انتخاب کنید یا تنظیمات خروجی را تغییر دهید، در Soundscaper مسیر **File → Export audio** و در Framescaper مسیر **File → Export video** را انتخاب کنید. بازنویسی محتوای فایل اصلی را جایگزین می‌کند؛ اگر به ضبط ویرایش‌نشده نیاز دارید، نسخهٔ جداگانه‌ای نگه دارید.
