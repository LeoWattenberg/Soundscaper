یادگیری یک ریف، بررسی نقطه ویرایش، شنیدن تنظیمات یک افکت: همه سریع‌تر پیش می‌روند وقتی که بخش مورد نظر بارها و بارها پخش می‌شود بدون اینکه شما مجبور به شروع مجدد آن شوید. ناحیه حلقه را روی انتخاب‌شده تنظیم کنید و پخش تا زمانی که حلقه را خاموش نکنید، درون آن باقی می‌ماند.

:::note[اگر از Audacity می‌آیید؟]
این همان **Transport → Looping → Set Loop to Selection** در Audacity است. نام‌های زیر متعلق به خود Soundscaper هستند و گاهی اوقات متفاوت‌اند.
:::

## مراحل

1. Soundscaper را باز کنید. یک پروژه جدید و خالی به محض بارگذاری ویرایشگر آماده است.
2. گزینه **File → Import audio** را انتخاب کنید و ضبطی را که شامل بخش تمرینی است انتخاب کنید. فایل به صورت یک کلیپ در یک ردیف مستقل قرار می‌گیرد.
3. خط‌کش بالای کلیپ را بکشید تا بخش مورد نظر برای تکرار انتخاب شود.
4. گزینه **Select → Loop region → Set loop to selection** را انتخاب کنید.
5. اکنون پروژه دکمه **Loop selection** را روشن نشان می‌دهد.
   *باید ببینید:* دکمه حلقه در نوار ترانسپورت روشن می‌شود و ناحیه حلقه بالای خط‌کش نمایش داده می‌شود.
6. برای شنیدن، **Play** را فشار دهید و سپس **Stop** را بزنید.
   *باید ببینید:* پخش در اطراف بخش انتخاب‌شده اجرا می‌شود.

## نکات

- برای خاموش و روشن کردن حلقه بدون از دست دادن ناحیه، **L** را فشار دهید یا از دکمه حلقه در نوار ترانسپورت استفاده کنید.
- برای تنظیم ناحیه حلقه، انتهای آن را در خط‌کش بکشید.
