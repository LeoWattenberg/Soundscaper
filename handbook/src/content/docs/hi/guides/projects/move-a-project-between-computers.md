प्रोजेक्ट लाइब्रेरी एक कंप्यूटर पर एक ब्राउज़र में रहती है। प्रोजेक्ट को कहीं और ले जाने के लिए — एक अन्य मशीन, एक सहकर्मी, या बैकअप ड्राइव — इसे एक प्रोजेक्ट फ़ाइल के रूप में निर्यात करें। `.sscape` फ़ाइल ऑडियो और हर संपादन को धारण करती है, और किसी भी Soundscaper में खुलती है।

:::note[Audacity से आ रहे हैं?]
यह Audacity का **File → Save Project → Backup Project, फिर File → Open** है। नीचे दिए गए नाम Soundscaper के अपने हैं, जो कभी-कभी अलग होते हैं।
:::

## चरण

1. Soundscaper खोलें। एडिटर लोड होते ही एक नया, खाली प्रोजेक्ट तैयार हो जाता है।
2. **File → Import audio** चुनें और प्रोजेक्ट सामग्री चुनें। फ़ाइल एक क्लिप के रूप में अपने ही ट्रैक पर आ जाती है।
3. **File → Export project file (.sscape)** चुनें। पूरा प्रोजेक्ट एक `.sscape` फ़ाइल के रूप में डाउनलोड होता है। फ़ाइल को कहीं सुरक्षित स्थान पर रखें; यह पूरा प्रोजेक्ट है।
4. **File → Open Scape project file (.sscape)** चुनें और फ़ाइल चुनें। एक कंप्यूटर पर जहाँ प्रोजेक्ट अभी तक नहीं है, वह सीधे खुलता है; यहाँ, जहाँ लाइब्रेरी में पहले से मौजूद है, Soundscaper **Open as read-only copy** का विकल्प देता है — इसे दबाएं।
   *आपको यह दिखना चाहिए:* प्रोजेक्ट अपने ट्रैक और क्लिप के साथ ठीक वैसे ही खुलता है जैसे निर्यात किया गया था।

## सुझाव

- एक read-only कॉपी को तब तक संपादित नहीं किया जा सकता जब तक आप इसे File मेनू से अपने प्रोजेक्ट के रूप में सेव न कर लें।
- फ़ाइल एक ZIP आर्काइव है जिसके अंदर ऑडियो है; इसे हाथ से अनपैक न करें।

## संबंधित गाइड

अधिक [projects and files](/guides/projects/) गाइड:

- [Save your project](/guides/projects/save-your-project/) — प्रोजेक्ट को, हर ट्रैक और संपादन के साथ, लोकल प्रोजेक्ट लाइब्रेरी में रखें।
- [Open an Audacity project](/guides/projects/open-an-audacity-project/) — एक मौजूदा .aup3 या .aup4 प्रोजेक्ट को उसके ट्रैक के साथ Soundscaper में लाएं।
- [Export each track as its own file](/guides/projects/export-each-track-as-its-own-file/) — ट्रैक्स को अलग-अलग, स्टेम्स के रूप में, एक ही डाउनलोड में रेंडर करें।
- [Change a clip’s sample rate](/guides/projects/change-a-clips-sample-rate/) — एक क्लिप को रीसैंपल करें ताकि वह प्रोजेक्ट के बाकी हिस्से द्वारा उपयोग की जाने वाली दर से मेल खाए।
- [Export each chapter as its own file](/guides/projects/export-each-chapter-as-its-own-file/) — एक लंबे रिकॉर्डिंग को उन मार्करों पर फ़ाइलों में विभाजित करें जिन्हें आपने रखा है।
