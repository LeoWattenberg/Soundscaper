## उद्देश्य और उपयोग का मामला {#purpose-and-use-case}

मिक्स्ड साउंडट्रैक को डायलॉग, संगीत और इफेक्ट्स प्रस्तावों में अलग करें।

## वर्तमान उपलब्धता {#current-availability}

डेस्कटॉप बिल्ड macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64 के लिए आवश्यक onnxruntime-node 1.29.0 इंजन डाउनलोड और सत्यापित कर सकते हैं। इस मॉडल और आवश्यक रनटाइम को मॉडल मैनेजर से इंस्टॉल करें, फिर कार्य स्थानीय रूप से चलाएँ। ये समर्थित बिल्ड लक्ष्य हैं; किसी खास पैकेज और मशीन के परिणामों के लिए नाइटली टेस्ट रिपोर्ट देखें।

## इस मॉडल का उपयोग करें {#use-this-model}

आवश्यक स्थानीय रनटाइम के साथ एक प्लेटफॉर्म पर **टूल्स → एडवांस्ड लोकल प्रोसेसिंग → सोर्स सेपरेशन** खोलें। स्थानीय सहायता डेस्कटॉप एडिटर में चलती है।

1. अलग करने के लिए मिक्स्ड ऑडियो का चयन करें।
2. मॉडल मैनेजर के माध्यम से TIGER स्थापित करें, फिर स्रोत अलगाव चलाएं।
3. प्रत्येक प्रस्तावित स्टेम को सुनें और परियोजना में जोड़ने से पहले चाहे गए परिणामों को सुनें।

## डाउनलोड और आवश्यकताएं {#download-and-requirements}

प्रकाशित प्लेटफ़ॉर्म: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64। एक मेल खाता डाउनलोड करने योग्य रनटाइम भी आवश्यक है।
