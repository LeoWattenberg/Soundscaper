## उद्देश्य और उपयोग का मामला {#purpose-and-use-case}

सम्पादित वीडियो फ़्रेम से दिखाई देने वाले टेक्स्ट को पढ़ें और समीक्षा और इंडेक्सिंग के लिए उपयोग करें।

## वर्तमान उपलब्धता {#current-availability}

डेस्कटॉप बिल्ड macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64 के लिए आवश्यक onnxruntime-node 1.29.0 इंजन डाउनलोड और सत्यापित कर सकते हैं। इस मॉडल और आवश्यक रनटाइम को मॉडल मैनेजर से इंस्टॉल करें, फिर कार्य स्थानीय रूप से चलाएँ। ये समर्थित बिल्ड लक्ष्य हैं; किसी खास पैकेज और मशीन के परिणामों के लिए नाइटली टेस्ट रिपोर्ट देखें। macOS x64 के लिए डाउनलोड करने योग्य इंजन उपलब्ध नहीं है, भले ही मॉडल वेट उस प्लेटफ़ॉर्म के लिए सूचीबद्ध हों।

## इस मॉडल का उपयोग करें {#use-this-model}

**फ़्रेम्स्केपर: उपकरण → खोज → वीडियो इंडेक्स करें, या उपकरण → उन्नत स्थानीय प्रसंस्करण → ऑप्टिकल कैरेक्टर रिकग्निशन** को आवश्यक स्थानीय रनटाइम वाले प्लेटफॉर्म पर खोलें। स्थानीय सहायता डेस्कटॉप एडिटर में चलती है।

1. स्क्रीन पर पढ़ने योग्य टेक्स्ट वाले वीडियो का चयन करें।
2. **मॉडल मैनेजर** के माध्यम से PP-OCRv4 मोबाइल स्थापित करें। यह इंडेक्स वीडियो का एक वैकल्पिक कदम है, जो SigLIP2 का भी उपयोग करता है।
3. स्थानीय रूप से चलाएं और पहचाने गए टेक्स्ट और उनके फ़्रेम स्थानों की समीक्षा करें इससे पहले कि आप परिणाम स्वीकार करें।

## डाउनलोड और आवश्यकताएँ {#download-and-requirements}
