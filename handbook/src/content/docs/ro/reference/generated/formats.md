Acestea sunt formatele concrete înregistrate de runtime-ul actual de export. Disponibilitatea produselor provine din profilurile produselor.

„Încorporat” înseamnă că aplicația are un scriitor nativ pentru acel format. „Runtime-ul FFmpeg este necesar” este condiționat: tabelul nu promite că runtime-ul FFmpeg poate fi încărcat în fiecare construire sau mediu, sau că un runtime de înlocuire arbitrar conține encoderul și muxerul enumerat.

Fișierele proiectului și fișierele de etichete sunt listate separat în [Fișiere de proiect și etichete](/reference/generated/project-files/).
