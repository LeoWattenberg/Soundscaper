Asistența locală este disponibilă în Soundscaper și Framescaper. Modelele sunt stocate într-un director pe care îl alegeți pe sistemul dvs. de fișiere, iar fiecare execuție are loc pe dispozitivul dvs.; nimic din media dvs. nu este trimis nicăieri.

Un flux de lucru este un graf fix de pași. Un pas care denumește o operațiune rulează un model; un pas care nu denumește nicio operațiune este determinist și nu rulează niciun model. Un pas opțional este omis atunci când modelul său nu este instalat, iar fluxul de lucru produce totuși un rezultat din pașii care au rulat.
