Asistența locală este disponibilă în Soundscaper și Framescaper. Modelele sunt stocate într-un director pe care îl alegeți pe sistemul dvs. de fișiere, iar fiecare execuție are loc pe dispozitivul dvs.; nimic din media dvs. nu este trimis nicăieri.

Un flux de lucru este un graf fix de pași. Un pas care numește o operațiune rulează un model; un pas care nu numește nicio operațiune este determinist și nu rulează niciun model. Un pas opțional este omis atunci când modelul său nu este instalat, iar fluxul de lucru produce totuși un rezultat din pașii care au fost executați.

## Modele publicate

Greutățile modelului și motoarele native sunt cerințe separate. Consultați [ghidurile individuale ale modelelor și disponibilitatea nativă curentă](/reference/local-models/) înainte de a vă baza pe descărcarea unui model pentru a permite o sarcină.

Modelele sunt publicate de la `https://assets.soundscaper.org/models/` și verificate cu un digest SHA-256 înregistrat înainte de utilizare. „Memoria minimă” este memoria totală a sistemului necesară pentru disponibilitatea catalogului. Inferența necesită, de asemenea, memorie liberă suficientă; niciuna dintre valori nu este o afirmație despre cât de rapid va rula. O sarcină de mai jos este ceea ce face un model, care nu este întotdeauna scris la fel ca operațiunea care îl utilizează, iar o singură operațiune poate utiliza mai mult de un model.
