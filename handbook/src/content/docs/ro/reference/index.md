Pagini de referință sunt generate din registre de execuție revizuite și adăugate în
depozit. Acestea descriu comportamentul implementat, nu intrările din foaia de parcurs sau
simpla prezență a fișierelor sursă și a testelor.

Utilizați această secțiune pentru a răspunde la întrebări precum:

- Care este scurtătura implicită care invocă o comandă?
- Este o comandă disponibilă în Soundscaper, Framescaper sau ambele?
- Care formate audio și video pot fi exportate?
- La ce valoare se initializează parametru al unui efect și ce valori acceptă?
- Care efecte pot rula în timp ce audio se redă, și care necesită o selecție?
- Care fluxuri de lucru de asistență locală există, și ce modele necesită?
- Care panouri afișează fiecare spațiu de lucru?
- Care limbi, browsere și pachete desktop sunt construite și testate?
- Care caracteristici depind de un produs, platformă sau runtime FFmpeg?

Pagini generate includ originea lor și sunt verificate pentru divergență în
gate-ul de calitate al depozitului.

[Programe macro](/reference/macro-programs/) este singura pagină de aici scrisă manual.
Aceasta documentează API-ul JavaScript pe care un program macro rulează și afirmațiile sale
sunt cele la care sandbox-ul editorului propriu-zis este supus în testele sale.
