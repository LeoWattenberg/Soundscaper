## Scop și caz de utilizare {#purpose-and-use-case}

Citește textul vizibil din cadrele video prelevate pentru revizuire și indexare.

## Disponibilitate curentă {#current-availability}

Versiunile desktop pot descărca și verifica motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv. Nu există un motor descărcabil pentru macOS x64, deși ponderile modelului sunt listate pentru această platformă.

## Utilizați acest model {#use-this-model}

Deschideți **Framescaper: Instrumente → Căutare → Indexare Video, sau Instrumente → Prelucrare locală avansată → Recunoașterea caracterelor optice** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați videoclipul care conține text pe ecran care poate fi citit.
2. Instalați PP-OCRv4 mobil prin Gestionarea Modelelor. Este un pas opțional al Indexării Video, care utilizează, de asemenea, SigLIP2.
3. Rulați local și revizuiți textul recunoscut și locațiile cadrelor sale înainte de a accepta rezultatele.

Dimensiunea aproximativă de descărcare a artefactului modelului: **15.46 MiB**. Mediul de execuție necesar se adaugă la prima descărcare dacă nu este deja instalat. Memorie minimă a sistemului: **2 GiB**. Cerința catalogului se referă la memoria totală, nu la memoria liberă în acest moment. Inferența necesită și suficientă memorie liberă, iar instalarea are nevoie de spațiu de lucru; memoria nu garantează viteza.

Platforme publicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Este necesar și un mediu de execuție corespunzător, descărcabil.

În Windows, instalați cel mai recent [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) acceptat și potrivit aplicației desktop: **x64** pentru o versiune x64 sau **ARM64** pentru ARM64. ## Revizuiți rezultatul {#review-the-result}

- Textul mic, estompat, rotit, stilizat sau parțial ascuns poate fi omis sau citit greșit.
- Testul ambalat necesită regiuni de text, astfel încât detectorul, modelul de orientare și recunoșcătorul rulează toate. Nu cere o potrivire caracter cu caracter.
