Transformă discursul selectat într-o transcriere cronometrată pentru subtitrări și editarea transcrierilor.

## Disponibilitate curentă {#current-availability}

Versiunile desktop includ motorul sherpa-onnx-node 1.13.5 necesar pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați greutățile acestui model prin Model Manager, apoi rulați sarcina local. Acestea sunt țintele de construire acceptate; consultați raportul de testare nocturnă pentru rezultate privind un anumit pachet și mașină. Versiunea desktop nu include acest motor pentru macOS x64, chiar dacă greutățile modelului sunt listate pentru aceste platforme.

## Utilizați acest model {#use-this-model}

Deschideți **Analiza → Discurs → Transcriere & Subtitrări** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați discursul de transcriere.
2. Utilizați Gestionarea modelelor pentru a instala acest model. Instrumentele → Prelucrare locală avansată vă permit să alegeți un model specific de recunoaștere vocală.
3. Rulați local, apoi revizuiți textul și sincronizarea înainte de a accepta transcrierea.

Transcrierea trebuie să conțină text non-gol cu sincronizare validă în interiorul audio-ului de intrare. Nu se compară formularea exactă.
