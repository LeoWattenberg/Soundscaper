Aliniază un transcriere în limba engleză existentă la cuvintele vorbite într-o înregistrare.

## Disponibilitate curentă {#current-availability}

Versiunile desktop includ motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux x64, Linux arm64, Windows x64 și Windows arm64. Instalați greutățile acestui model prin Model Manager, apoi rulați sarcina local. Acestea sunt țintele de construire acceptate; consultați raportul de testare nocturnă pentru rezultate privind un anumit pachet și mașină.

## Utilizați acest model {#use-this-model}

Deschideți **Analiza → Discurs → Transcriere și subtitrări, sau Instrumente → Prelucrare locală avansată → Alinierea cuvintelor** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați discursul și pregătiți sau revizuiți transcrierea sa în limba engleză.
2. Instalați modelul de aliniere prin Model Manager.
3. Rulați alinierea, apoi ascultați în timp ce revizuiți limitele propuse ale cuvintelor înainte de a le accepta.

## Descărcați și cerințe {#download-and-requirements}

Identitatea modelului: `wav2vec2-base-960h`, versiune **1.0.0**.

Dimensiune descărcare aproximativă: **360,38 MiB**. Memorie de sistem minimă: **4 GiB**. Această cerință de catalog se referă la memoria totală, nu la memoria liberă curentă. Inferența necesită, de asemenea, memorie liberă suficientă, iar instalarea necesită spațiu de lucru; memoria nu este o garanție de viteză.

Platforme publicate: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Este necesar, de asemenea, un runtime ambalat corespunzător.

Pe Windows, instalați cea mai recentă versiune acceptată a [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) care corespunde aplicației desktop: **x64** pentru o construcție x64 sau **ARM64** pentru o construcție ARM64. Motoarele native ONNX și Sherpa necesită aceste biblioteci; descărcările de modele nu le includ. În sine, Visual Studio nu este necesar pentru utilizarea aplicației.

Instrumente → Model Manager descarcă artefactele publicate și verifică sumele lor SHA-256 înregistrate. Prelucrarea utilizează fișierele instalate local. Deschideți Stocare și verificare în Model Manager pentru a inspecta notificările, a repara o instalare sau a schimba locația de stocare.

## Ce verifică testul ambalat {#what-the-packaged-test-checks}

Caz: `wav2vec2-word-alignment`; operațiune: `word-alignment`.

Intrare: Discursul public al lui Kennedy la 16 kHz, împreună cu transcrierea sa cunoscută în limba engleză ca intrare autentificată separată.

Fiecare cuvânt furnizat trebuie să fie reprezentat cu o sincronizare validă și ordonată în interiorul audio-ului; nu sunt prescrise sincronizări exacte.

Pachetul nightly-with-tests descarcă artefacte de model reale și solicită inferență prin intermediul runtime-ului ambalat. Lipsa unui model necesar din catalog duce la eșecul cazului. Motoarele native lipsă eșuează pe platformele acceptate de catalog. Aceste verificări costisitoare rulează separat de suita normală de browsere. O rulare reușită confirmă execuția de bază a modelului și structura de ieșire utilizabilă; nu stabilește calitatea perceptivă sau acuratețea pentru înregistrarea dvs.

## Revizuiți rezultatul {#review-the-result}

- Acest model aliniază cuvintele englezești furnizate; nu traduce sau repară o transcriere incorectă.
- Cuvintele repetate, discursul de fundal și cuvintele lipsă din transcriere pot duce la limite incorecte. Testul verifică sincronizările ordonate în intervalul cuvintelor împotriva inventarului de cuvinte furnizat, nu o potrivire perfectă a sincronizării.
