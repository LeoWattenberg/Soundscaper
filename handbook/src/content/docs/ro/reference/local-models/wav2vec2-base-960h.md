## Scop și caz de utilizare {#purpose-and-use-case}

Aliniază un transcriere în limba engleză existentă la cuvintele vorbite într-o înregistrare.

## Disponibilitate curentă {#current-availability}

Versiunile desktop pot descărca și verifica motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv.

## Utilizați acest model {#use-this-model}

Deschideți **Analiza → Discurs → Transcriere și subtitrări, sau Instrumente → Prelucrare locală avansată → Alinierea cuvintelor** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați discursul și pregătiți sau revizuiți transcrierea sa în limba engleză.
2. Instalați modelul de aliniere prin Model Manager.
3. Rulați alinierea, apoi ascultați în timp ce revizuiți limitele propuse ale cuvintelor înainte de a le accepta.

## Descărcați și cerințe {#download-and-requirements}

Identitatea modelului: `wav2vec2-base-960h`, versiune **1.0.0**.

Dimensiunea aproximativă de descărcare a artefactului modelului: **360.38 MiB**. Mediul de execuție necesar se adaugă la prima descărcare dacă nu este deja instalat. Memorie minimă a sistemului: **4 GiB**. Cerința catalogului se referă la memoria totală, nu la memoria liberă în acest moment. Inferența necesită și suficientă memorie liberă, iar instalarea are nevoie de spațiu de lucru; memoria nu garantează viteza.

Platforme publicate: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Este necesar și un mediu de execuție corespunzător, descărcabil.

În Windows, instalați cel mai recent [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) acceptat și potrivit aplicației desktop: **x64** pentru o versiune x64 sau **ARM64** pentru ARM64. Motoarele native ONNX și Sherpa au nevoie de aceste biblioteci; descărcările modelului și mediului de execuție nu le includ. Visual Studio nu este necesar pentru utilizarea aplicației.

Instrumente → Managerul de modele descarcă artefactele modelului publicat și mediul de execuție necesar la prima instalare, apoi verifică amprentele SHA-256 înregistrate. Procesarea folosește fișierele instalate local. Deschideți Stocare și verificare în Managerul de modele pentru notificări, repararea instalării sau schimbarea locației de stocare.

## Revizuiți rezultatul {#review-the-result}

- Acest model aliniază cuvintele englezești furnizate; nu traduce sau repară o transcriere incorectă.
- Cuvintele repetate, discursul de fundal și cuvintele lipsă din transcriere pot duce la limite incorecte. Testul verifică sincronizările ordonate în intervalul cuvintelor împotriva inventarului de cuvinte furnizat, nu o potrivire perfectă a sincronizării.
