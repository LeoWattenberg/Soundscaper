## Scop și caz de utilizare {#purpose-and-use-case}

Creați reprezentări numerice locale ale pasajelor de transcriere și interogări de căutare pentru căutarea semantică.

## Disponibilitate curentă {#current-availability}

Versiunile desktop pot descărca și verifica motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv. Nu există un motor descărcabil pentru macOS x64, deși ponderile modelului sunt listate pentru această platformă.

## Utilizați acest model {#use-this-model}

Deschideți **Instrumente → Căutare → Indexare Transcriere, apoi Instrumente → Căutare → Căutare Indexată** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Creați sau importați o transcriere, apoi instalați Nomic Embed Text prin Gestionarea Modelelor.
2. Rulați Indexare Transcriere pentru a pregăti textul pentru căutarea semantică.
3. Utilizați Căutare Indexată și revizuiți pasajele potrivite în context. Procesarea locală avansată expune, de asemenea, operațiunea de încorporare.

Memorie minimă a sistemului: **4 GiB**. Cerința catalogului se referă la memoria totală, nu la memoria liberă în acest moment. Inferența necesită și suficientă memorie liberă, iar instalarea are nevoie de spațiu de lucru; memoria nu garantează viteza.

Platforme publicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Este necesar și un mediu de execuție corespunzător, descărcabil.

În Windows, instalați cel mai recent [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) acceptat și potrivit aplicației desktop: **x64** pentru o versiune x64 sau **ARM64** pentru ARM64. ## Revizuiți rezultatul {#review-the-result}

- Încorporările sunt date de căutare numerice, nu o transcriere rescrisă sau un răspuns generat.
- Pasajele asociate pot avea clasamente diferite între rulări sau înregistrări. Vectori fini, non-constanți validează execuția, nu relevanța fiecărei potriviri.
