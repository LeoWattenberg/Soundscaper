Creați reprezentări numerice locale ale pasajelor de transcriere și interogări de căutare pentru căutarea semantică.

## Disponibilitate curentă {#current-availability}

Versiunile desktop includ motorul necesar onnxruntime-node 1.29.0 pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați greutățile acestui model prin Model Manager, apoi rulați sarcina local. Acestea sunt țintele de construire acceptate; consultați raportul de testare nocturnă pentru rezultate privind un anumit pachet și mașină. Versiunea desktop nu include acest motor pentru macOS x64, deși greutățile modelului sunt listate pentru aceste platforme.

## Utilizați acest model {#use-this-model}

Deschideți **Instrumente → Căutare → Indexare Transcriere, apoi Instrumente → Căutare → Căutare Indexată** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Creați sau importați o transcriere, apoi instalați Nomic Embed Text prin Gestionarea Modelelor.
2. Rulați Indexare Transcriere pentru a pregăti textul pentru căutarea semantică.
3. Utilizați Căutare Indexată și revizuiți pasajele potrivite în context. Procesarea locală avansată expune, de asemenea, operațiunea de încorporare.

## Ce verifică testul ambalat {#what-the-packaged-test-checks}

Caz: `nomic-text-embedding`; operațiune: `text-embedding`.

Intrare: Un pasaj de text scurt și non-gol furnizat tokenizatorului real și rețelei de încorporare.

Vectori de încorporare trebuie să aibă dimensiunile așteptate și să conțină valori finite, non-zero, non-constante.

Pachetul nightly-with-tests descarcă artefacte de model reale și solicită inferență prin intermediul runtime-ului ambalat. Lipsa unui model necesar din catalog duce la eșecul cazului. Motoarele native lipsă eșuează pe platformele acceptate de catalog. Aceste verificări costisitoare rulează separat de suita normală de browsere. O execuție reușită confirmă execuția de bază a modelului și structura de ieșire utilizabilă; nu stabilește calitatea perceptivă sau acuratețea pe înregistrarea dvs.

## Revizuiți rezultatul {#review-the-result}

- Încorporările sunt date de căutare numerice, nu o transcriere rescrisă sau un răspuns generat.
- Pasajele asociate pot avea clasamente diferite între rulări sau înregistrări. Vectori fini, non-constanți validează execuția, nu relevanța fiecărei potriviri.
