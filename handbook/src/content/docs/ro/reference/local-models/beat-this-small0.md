## Scop și caz de utilizare {#purpose-and-use-case}

Găsiți pozițiile bătăilor în muzică folosind modelul mai mic Beat This. 

## Disponibilitate curentă {#current-availability} 

Versiunile desktop pot descărca și verifica motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv.

## Utilizați acest model {#use-this-model} 

Deschideți **Instrumente → Prelucrare locală avansată → Urmărirea bătăilor** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul de birou. 

1. Selectați un pasaj de muzică ritmică. 
2. Instalați Beat This mic prin Model Manager și selectați exact acest model pentru urmărirea bătăilor. 
3. Ascultați grila propusă de bătăi înainte de a accepta marcajele de bătăi sau o propunere de tempo. 

## Descărcați și cerințe {#download-and-requirements} 

Identitatea modelului: `beat-this-small0`, versiune **1.1.0**. 

Dimensiunea aproximativă de descărcare a artefactului modelului: **10.08 MiB**. Mediul de execuție necesar se adaugă la prima descărcare dacă nu este deja instalat. Memorie minimă a sistemului: **2 GiB**. Cerința catalogului se referă la memoria totală, nu la memoria liberă în acest moment. Inferența necesită și suficientă memorie liberă, iar instalarea are nevoie de spațiu de lucru; memoria nu garantează viteza.

Platforme publicate: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Este necesar și un mediu de execuție corespunzător, descărcabil.

În Windows, instalați cel mai recent [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170) acceptat și potrivit aplicației desktop: **x64** pentru o versiune x64 sau **ARM64** pentru ARM64. Motoarele native ONNX și Sherpa au nevoie de aceste biblioteci; descărcările modelului și mediului de execuție nu le includ. Visual Studio nu este necesar pentru utilizarea aplicației.

Instrumente → Managerul de modele descarcă artefactele modelului publicat și mediul de execuție necesar la prima instalare, apoi verifică amprentele SHA-256 înregistrate. ## Revizuiți rezultatul {#review-the-result} 

- Urmărirea bătăilor poate urma modele de timp jumătate sau dublu, iar muzica neregulată poate duce la bătăi ratate. 
- Testul separat al modelului mic verifică pozițiile ordonate ale bătăilor în interiorul audio-ului și datele de tempo finite și pozitive, fără a necesita timpi de bătaie exacți.
