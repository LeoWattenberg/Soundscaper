## Scop și caz de utilizare {#purpose-and-use-case}

Transcrieți local discursul selectat prin intermediul motorului whisper.cpp inclus în pachet. 

## Disponibilitate actuală {#current-availability}

Versiunile desktop pot descărca și verifica motorul whisper-cpp v1.9.3 necesar pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv. Nu există un motor descărcabil pentru macOS x64, deși ponderile modelului sunt listate pentru această platformă.

## Utilizați acest model {#use-this-model}

Deschideți **Analiza → Discurs → Transcriere & Subtitrări** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați discursul și instalați Whisper large-v3 turbo prin Gestionarea Modelelor.
2. Alegeți acest model de recunoaștere vocală în cadrul **Instrumente → Prelucrare Locală Avansată** atunci când doriți să selectați explicit Whisper.
3. Rulați local și examinați atât textul, cât și limitele segmentelor înainte de a accepta.
