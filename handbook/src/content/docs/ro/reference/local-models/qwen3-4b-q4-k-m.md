## Scop și caz de utilizare {#purpose-and-use-case}

Sugerează titluri, cârlige, capitole și explicații pentru candidații de evidențiere existenți.

## Disponibilitate curentă {#current-availability}

Versiunile desktop pot descărca și verifica motorul llama-cpp b10509 necesar pentru macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv.

## Utilizați acest model {#use-this-model}

Deschideți **Framescaper: Instrumente → Procesare locală avansată → Generare editorială** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Pregătiți și revizuiți candidații de evidențiere din mediile selectate.
2. Instalați Qwen prin Model Manager și optați pentru generarea editorială.
3. Revizuiți fiecare propunere de text înainte de a o accepta. Doar identitățile candidaților autorizați și câmpurile de text solicitate sunt eligibile.

## Revizuiți rezultatul {#review-the-result}

- Formularea generată poate fi înșelătoare sau repetitivă. Este o propunere bazată pe dovezile furnizate, nu o analiză factuală verificată.
- Modelul rulează local pe CPU și necesită cel puțin 16 GiB de memorie de sistem totală plus suficientă memorie liberă. Cererile scurte pot dura încă câteva minute.
- Testul necesită JSON strict, fiecare candidat autorizat exact o dată și câmpuri solicitate lizibile. Respinge comenzile, căile, marcajele, noile sincronizări, candidații străini și ieșirea defectuoasă, în loc să le aplice.
