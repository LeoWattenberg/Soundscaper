## Scop și caz de utilizare {#purpose-and-use-case}

Estimează zona vizual proeminentă a cadrelor eșantionate pentru a ajuta la reframare.

## Disponibilitate curentă {#current-availability}

Versiunile desktop pot descărca și verifica motorul onnxruntime-node 1.29.0 necesar pentru macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Instalați acest model și mediul de execuție necesar prin Managerul de modele, apoi rulați sarcina local. Acestea sunt țintele de compilare acceptate; consultați raportul testelor nocturne pentru rezultatele unui anumit pachet și dispozitiv. Nu există un motor descărcabil pentru macOS x64, deși ponderile modelului sunt listate pentru această platformă.

## Utilizați acest model {#use-this-model}

Deschideți **Framescaper: Efect → Efecte video → Reframare** pe o platformă cu runtime-ul nativ necesar. Asistența locală rulează în editorul desktop.

1. Selectați un clip video și instalați U²-Net-P prin Gestionarea Modelelor.
2. Sarcina Reframare ghidată necesită, de asemenea, YuNet și D-FINE; Instrumente → Procesare locală avansată poate rula detectarea salienței separat.
3. Rulați local și revizuiți încadrarea propusă înainte de a o aplica.

Memorie minimă a sistemului: **2 GiB**. Cerința catalogului se referă la memoria totală, nu la memoria liberă în acest moment. Inferența necesită și suficientă memorie liberă, iar instalarea are nevoie de spațiu de lucru; memoria nu garantează viteza.

Platforme publicate: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Este necesar și un mediu de execuție corespunzător, descărcabil.
