O buclă de două bare, un pat de fundal care trebuie să ruleze sub un voice-over mai lung, un efect sonor care ar trebui să continue: Repeat repetă selecția imediat după ea de atâtea ori câte ori ceri.

:::notă[Venind din Audacity?]
Acesta este **Efect → Special → Repeat** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou, gol, este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import audio** și selectați sunetul pe care doriți să-l repetați. Fișierul ajunge ca un clip pe propria sa pistă.
3. Alegeți **Selectare → Selectare completă**.
4. Alegeți **Efect → Special → Repeat**. În dialogul **Repeat**, setați **Număr de repetări** la `2`, apoi apăsați **Aplicați la selecție**. Două repetări dau trei copii la rând.
5. Apăsați **Redare** pentru a asculta, apoi **Oprire**.
   *Ar trebui să vedeți:* Pasajul se redă de trei ori fără pauză.

## Sfaturi

- Pentru o buclă perfectă, asigurați-vă că selecția începe și se termină cu liniște sau la o intersecție zero (**Selectare → La intersecții zero**).
- Efectul modifică lungimea clipului, deci orice după el pe aceeași pistă este împins mai departe.
