Plugin-urile Nyquist ale Audacity sunt mici scripturi care adaugă efecte, generatoare și analizatoare. Soundscaper grupează aceleași plugin-uri sub un submeniu Nyquist în fiecare meniu. Tremolo este un bun început: face ca volumul să se miște într-un ritm stabilit.

:::note[Venind de la Audacity?]
Acesta este **Efect → Tremolo (un plugin Nyquist)** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un nou proiect gol este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import audio** și selectați înregistrarea pe care doriți să o încercați cu plugin-ul. Fișierul ajunge ca un clip pe propria sa pistă.
3. Alegeți **Selectare → Selectare tot**.
4. Alegeți **Efect → Nyquist → Tremolo**. În dialogul **Tremolo**, setați **Frecvență (Hz)** la `6`, apoi apăsați **Aplică**. Șase pulsări pe secundă este un tremolo clasic de amplificator.
5. Apăsați **Redare** pentru a asculta, apoi **Oprire**.
   *Ar trebui să vedeți:* Înregistrarea pulsa în volum.

## Sfaturi

- Meniu Generare și Analiză au propriile submeniu Nyquist, cu plugin-uri precum Pluck și Beat Finder.
- **Unelte → Prompt Nyquist** rulează un script pe care îl tastați singur.
