Echo redă selecția din nou după o întârziere, apoi din nou, fiecare repetare fiind mai liniștită decât cea anterioară. Acesta este clasicul slap-back pe o voce sau efectul de canion pe un strigăt.

:::note[Venind din Audacity?]
Acesta este **Efect → Întârziere și reverberație → Echo** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou, gol, este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import** și selectați sunetul care trebuie să ecou. Acesta ajunge ca un clip pe propria sa pistă.
3. Alegeți **Selectare → Selectați tot**.
4. Alegeți **Efect → Întârziere și reverberație → Echo**. În dialogul **Echo**, setați **Factor de degradare** la `0.4`, apoi apăsați **Aplicați la selecție**. Fiecare repetare este de 0,4 ori mai tare decât cea dinainte, astfel încât ecoul se stinge după câteva repetări. **Timpul de întârziere** stabilește intervalul dintre ele.
5. Apăsați **Redare** pentru a asculta, apoi **Oprire**.
   *Ar trebui să vedeți:* Sunetul este urmat de repetări palide ale sale.

## Sfaturi

- Adăugați un secund sau două de tăcere după clip inițial (**Generați → Tăcere**) astfel încât ultimele repetări să aibă spațiu pentru a suna.
- Pentru o cameră, mai degrabă decât repetări distincte, utilizați [Reverberație](/guides/effects/add-reverb/).
