Un inginer de mixaj, un editor video sau un colaborator dintr-un alt program dorește de obicei părțile, nu mixul. Exportul de stemuri redă fiecare pistă în propriul fișier, toate având aceeași lungime și aliniate la începutul proiectului, și le împachetează într-un singur arhivă.

:::notă[Venind de la Audacity?]
Aceasta este **Fișier → Export Audio → Export multiple, împărțit pe piste** din Audacity. Nume de mai jos sunt cele proprii ale Soundscaper, care diferă uneori.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou, gol, este pregătit imediat ce editorul se încarcă.
2. Alegeți **Fișier → Import audio** și selectați prima pistă. Fișierul ajunge ca un clip pe propria pistă.
3. Alegeți **Fișier → Import audio** și selectați a doua pistă. Fișierul ajunge ca un clip pe propria pistă.
4. Alegeți **Fișier → Export audio**, setați **Format** la **WAV**, setați **Ieșire** la **Stemuri individuale (împărțite pe piste)**, și apăsați **Export**. Fișierul se descarcă imediat ce randarea se termină, iar link-ul său rămâne în dialog. Fiecare pistă devine un WAV în interiorul ZIP-ului, tăiat la aceeași lungime astfel încât să se alinieze atunci când sunt importate în altă parte.

## Sfaturi

- Mutarea și solo-ul nu afectează stemurile; fiecare pistă este randată.
- Denumiți pistele înainte de export — fișierele stem preiau numele lor de la acestea.
