Biblioteca de proiecte există într-un singur browser, pe un singur computer. Pentru a duce un proiect oriunde — pe altă mașină, la un coleg sau pe o unitate de backup — exportă-l ca fișier de proiect. Fișierul `.sscape` conține materialul audio și toate editările și se deschide în orice Soundscaper.

:::note[Lucrezi cu Audacity?]
Aceasta corespunde comenzilor Audacity **File → Save Project → Backup Project, apoi File → Open**. Denumirile de mai jos sunt cele folosite de Soundscaper și uneori diferă.
:::

## Pași

1. Deschide Soundscaper. Un proiect nou și gol este pregătit imediat ce se încarcă editorul.
2. Alege **File → Import** și selectează materialul proiectului. Acesta apare ca un clip pe propria pistă.
3. Alege **File → Export project file (.sscape)**. Întregul proiect se descarcă drept un singur fișier `.sscape`. Păstrează fișierul într-un loc sigur; el conține proiectul complet.
4. Alege **File → Open** și selectează fișierul. Pe un computer fără proiect, se deschide direct; aici, unde biblioteca îl conține deja, Soundscaper oferă **Open as read-only copy** — apasă această opțiune.
   *Ar trebui să vezi:* Proiectul se deschide cu pista și clipul exact ca la export.

## Sfaturi

- O copie doar pentru citire nu poate fi editată până nu o salvezi ca proiect propriu din meniul File.
- Fișierul este o arhivă ZIP care conține audio; nu o dezarhiva manual.
