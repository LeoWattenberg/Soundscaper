Un proiect este mai mult decât audio-ul: este format din piese, clipuri, efecte, marcaje și istoric. Salvarea păstrează toate acestea în biblioteca locală de proiecte a browser-ului pe acest computer, de unde poate fi redeschisă din meniul Fișier. Soundscaper salvează, de asemenea, pe parcurs, deci aceasta este în principal o modalitate de a vă asigura.

:::notă[Venind de la Audacity?]
Aceasta este **Fișier → Salvare Proiect** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou și gol este pregătit imediat ce editorul se încarcă.
2. Alegeți **Fișier → Import** și selectați ceva pe care doriți să lucrați. Acesta ajunge ca un clip pe propria sa piesă.
3. Alegeți **Fișier → Salvare Proiect**. Indicatorul de salvare din bara de stare arată că proiectul a fost salvat.

## Sfaturi

- Pentru a muta un proiect pe un alt computer sau pentru a păstra o copie în afara browser-ului, consultați [Mutarea unui proiect între computere](/guides/projects/move-a-project-between-computers/).
- O exportare audio este o copie de ascultare, nu un proiect. Păstrați proiectul dacă este posibil să editați din nou.
