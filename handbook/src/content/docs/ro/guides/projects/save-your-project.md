Un proiect este mai mult decât audio: este format din piste, clipuri, efecte, marcaje și istoric. Salvarea păstrează toate acestea în biblioteca locală de proiecte a browser-ului pe acest computer, unde poate fi redeschisă din meniul Fișier. Soundscaper salvează, de asemenea, pe parcurs, deci aceasta este în principal o modalitate de a vă asigura.

:::notă[Venind de la Audacity?]
Aceasta este **Fișier → Salvare proiect** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou și gol este pregătit imediat ce editorul se încarcă.
2. Alegeți **Fișier → Importați audio** și alegeți ceva la care să lucrați. Fișierul ajunge ca un clip pe propria sa pistă.
3. Alegeți **Fișier → Salvare proiect**. Indicatorul de salvare din bara de stare arată că proiectul este salvat.

## Sfaturi

- Pentru a muta un proiect pe un alt computer sau pentru a păstra o copie în afara browser-ului, consultați [Mutarea unui proiect între computere](/guides/projects/move-a-project-between-computers/).
- O exportare audio este o copie de ascultare, nu un proiect. Păstrați proiectul dacă este posibil să editați din nou.
