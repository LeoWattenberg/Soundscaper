Proiectele create în Audacity 3 (.aup3) și Audacity 4 (.aup4) se deschid direct. Pistele, clipurile, numele și pozițiile sunt păstrate; efectele pe care Soundscaper nu le include sunt enumerate, ca să știi ce să verifici. Fișierul original nu este modificat.

:::note[Lucrezi cu Audacity?]
Aceasta corespunde comenzii Audacity **File → Open**. Denumirile de mai jos sunt cele folosite de Soundscaper și uneori diferă.
:::

## Pași

1. Deschide Soundscaper. Un proiect nou și gol este pregătit imediat ce se încarcă editorul.
2. Alege **File → Open** și selectează proiectul. Pistele și clipurile sale apar ca în Audacity.
3. Proiectul afișează acum un clip numit **Audio 1** și o pistă numită **Fixture track**.
   *Ar trebui să vezi:* Pista și clipul din proiectul Audacity, cu numele lor.

## Sfaturi

- Un proiect vechi `.aup` are nevoie de folderul `_data` alături de el; selectează-le pe amândouă când ți se solicită.
- **File → Export other → Export AUP4** face operația inversă, pentru a trimite un proiect înapoi în Audacity.
