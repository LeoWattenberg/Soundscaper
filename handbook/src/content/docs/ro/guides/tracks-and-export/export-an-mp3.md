Un fișier MP3 este mic, se redă oriunde și este formatul așteptat de majoritatea gazdelor de podcasturi și aplicațiilor de mesagerie. Exportul redă întregul proiect - fiecare pistă, efect și editare - într-un singur fișier.

:::note[Venind de la Audacity?]
Aceasta este **Fișier → Export Audio → MP3** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou și gol este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import** și selectați înregistrarea pe care doriți să o publicați. Aceasta ajunge ca un clip pe propria sa pistă.
3. Alegeți **Fișier → Export audio**, setați **Formatul** la **MP3** și apăsați **Export**. Fișierul se descarcă imediat ce redarea se termină, iar link-ul său rămâne în dialog. Fișierul este codificat în browser; nimic nu părăsește computerul dumneavoastră.

## Sfaturi

- Un MP3 este o copie de livrare, nu o copie de rezervă. Păstrați proiectul sau exportați un WAV, de asemenea, dacă este posibil să editați din nou.
- Vârfurile chiar la scara completă pot fi tăiate după codificare. Normalizați la -1 dB sau mai jos înainte de export.
- Modul de rată a biților decide cum cheltuiește encoderul biții. Presetul Standard variază rata pentru a se potrivi materialului și este răspunsul corect pentru majoritatea livrărilor; alegeți Constant atunci când o gazdă sau un player hardware mai vechi solicită o rată fixă.
