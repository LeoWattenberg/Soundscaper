Cu o duzină de piste, mutarea lor una câte una pentru a asculta o singură parte nouă este plictisitoare, iar dezactivarea ulterioară este și mai rău. Mutarea tuturor pistelor silențiază întregul proiect cu un singur comandă, iar dezactivarea tuturor pistelor îl restabilește, fără a atinge butoanele solo. Audacity 3 a avut ambele comenzi; Audacity 4 nu le-a readus.

:::note[Venind de la Audacity?]
Acesta este **Piste → Mută/Dezactivă → Mută toate pistele și Dezactivă toate pistele (Audacity 3; nu este în Audacity 4)** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou și gol este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Importați** și selectați prima înregistrare. Aceasta ajunge ca un clip pe propria sa pistă.
3. Alegeți **Fișier → Importați** și selectați a doua înregistrare. Aceasta ajunge ca un clip pe propria sa pistă.
4. Alegeți **Piste → Mută toate pistele**.
5. Proiectul arată acum butonul **Mută** aprins pentru fiecare pistă.
   *Ar trebui să vedeți:* Redarea este silențioasă.
6. Alegeți **Piste → Dezactivă toate pistele**.
7. Proiectul arată acum că nicio pistă nu este mutată.
   *Ar trebui să vedeți:* Totul se redă din nou.

## Sfaturi

- Mută totul, apoi dezactivează una sau două piste pe care vrei să le auzi - mai rapid decât soloing atunci când selecția se schimbă des.
- Pentru a auzi o pistă singură fără a atinge celelalte, [solo-o](/guides/tracks-and-export/mute-and-solo-tracks/) în schimb.
