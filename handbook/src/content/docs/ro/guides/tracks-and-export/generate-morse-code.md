## La ce folosește acest ghid {#what-this-guide-is-for}

Codul Morse transformă mesajul în puncte, linii și spații temporizate. Generatorul previzualizează codificarea și calculează lungimea clipului din mesaj și viteză.

:::note[Veniți de la Audacity?]
Aceasta este calea în Audacity: **No directly matching built-in Morse code generator**. Denumirile de mai jos sunt cele din Soundscaper și pot diferi.
:::

## Pași

1. Deschide Soundscaper; proiectul nou și gol este gata când se încarcă editorul.
2. Alege **Generează → Cod Morse**. În dialogul **Cod Morse**, setează **Mesaj** la `SOS`, **Viteză (cuvinte pe minut)** la `20`, **Frecvență (Hz)** la `600` și **Amplitudine** la `0.2`, apoi apasă **Generează**. Înlocuiește mesajul demonstrativ și verifică previzualizarea; caracterele neacceptate împiedică generarea.
3. Proiectul conține acum un singur clip. Clipul Morse conține mesajul, iar lungimea lui depinde de viteza aleasă.

## Sfaturi

- O viteză mai mică prelungește punctele, liniile și spațiile fără să reducă frecvența tonului.
- Durata este doar informativă aici. Schimbă mesajul sau viteza pentru a modifica lungimea clipului.
