## La ce folosește acest ghid {#what-this-guide-is-for}

O înregistrare făcută la un nivel prea ridicat se turtește la limita superioară
a scalei și se distorsionează. Deteriorarea se aude ușor, dar este greu de
identificat vizual într-o înregistrare lungă. Find Clipping scanează selecția și
listează fiecare grup de eșantioane aflat la nivelul maxim, astfel încât să
puteți decide dacă îl reparați, reînregistrați sau îl lăsați așa.

:::note[Veniți de la Audacity?]
Este funcția Audacity **Analiză → Găsire clipping**. Numele de mai jos sunt cele
folosite de Soundscaper și diferă uneori.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou, gol, este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import** și selectați înregistrarea pe care doriți s-o verificați. Este adăugată ca un clip pe pista sa.
3. Alegeți **Selecție → Selectează tot**.
4. Alegeți **Analiză → Găsire clipping**. Se deschide dialogul **Găsire clipping** cu raportul selecției.
   *Ar trebui să vedeți:* O listă a secvențelor cu clipping sau un mesaj că nu a fost găsită niciuna.

## Sfaturi

- Reducerea volumului unei înregistrări cu clipping nu o repară; vârfurile turtite rămân turtite. **Efect → Eliminarea zgomotului și reparare → Reparare** poate reconstrui o secvență foarte scurtă cu clipping.
- Pentru a evita clipping-ul data viitoare, înregistrați cu vârfuri în jur de −12 dB și măriți nivelul ulterior.
