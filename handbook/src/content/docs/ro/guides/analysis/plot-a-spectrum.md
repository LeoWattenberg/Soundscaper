O formă de undă arată cât de tare este un sunet în timp; un spectru arată care sunt frecvențele din care este alcătuit. Plotarea spectrului unei pasaje problematice este cel mai rapid mod de a găsi un zumzet de 50 sau 60 Hz, un fluierat de la un monitor sau frecvența la care o cameră vibrează - și apoi să știți unde să îndreptați un egalizator.

:::notă[Venind din Audacity?]
Acesta este **Analizează → Plot Spectrum** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou și gol este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Importă audio** și selectați înregistrarea cu problema. Fișierul ajunge ca un clip pe propria sa pistă.
3. Alegeți **Selectare → Selectați tot**.
4. Alegeți **Analizează → Plot spectrum**. Panoul **Plot spectrum** se deschide.
   *Ar trebui să vedeți:* Un grafic al nivelului față de frecvență pentru selecție.

## Sfaturi

- Selectați doar pasajul problematic - o porțiune de zumzet pe cont propriu, de exemplu - astfel încât spectrul să nu fie dominat de muzica sau vorbirea din jur.
- Un vârf înalt și îngust este un ton; un platou larg este zgomot. Tonurile răspund la o tăiere îngustă a EQ-ului, zgomotul la [Reducerea Zgomotului](/guides/cleaning-up/remove-background-noise/).
