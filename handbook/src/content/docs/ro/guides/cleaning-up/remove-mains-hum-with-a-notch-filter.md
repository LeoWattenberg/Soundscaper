Zgomote de fund se află la o frecvență: 50 Hz în majoritatea lumii, 60 Hz în America, uneori cu o armonică la dublul acelei frecvențe. Un filtru cu tăietură elimină o bandă îngustă în jurul unei frecvențe și lasă totul în pace, ceea ce este mult mai blând decât un filtru de trecere înaltă atunci când zumzetul nu este suficient de scăzut pentru a fi atenuat. Aceeași unealtă elimină un fluierat de monitor sau o rezonanță de inel odată ce cunoașteți frecvența sa.

:::notă[Venind din Audacity?]
Acesta este **Efect → Egalizator și filtre → Filtru cu tăietură** din Audacity. Numele de mai jos sunt cele proprii ale Soundscaper, care uneori diferă.
:::

## Pași

1. Deschideți Soundscaper. Un proiect nou, gol, este gata imediat ce se încarcă editorul.
2. Alegeți **Fișier → Import audio** și selectați înregistrarea cu zumzetul. Fișierul ajunge ca un clip pe propria sa pistă.
3. Alegeți **Selectare → Selectare tot**.
4. Alegeți **Efect → Nyquist → Filtru cu tăietură**. În dialogul **Filtru cu tăietură**, setați **Frecvență (Hz)** la `50` și setați **Q (valoare mai mare reduce lățimea)** la `4`, apoi apăsați **Aplică**. Utilizați 60 dacă tensiunea dumneavoastră este de 60 Hz. Un Q de 4 este o tăietură îngustă; reduceți-l dacă zumzetul se rătăcește, creșteți-l dacă tăierea este audibilă pe voce.
5. Apăsați **Redare** pentru a asculta, apoi **Oprire**.
   *Ar trebui să vedeți:* Zumzetul a dispărut, iar vocea sună la fel.

## Sfaturi

- Nu sunteți sigur de frecvență? [Plasați spectrul](/guides/analysis/plot-a-spectrum/) unei pasaje liniștite și citiți vârful.
- Zumzetul are adesea o armonică la dublul frecvenței. Rulați din nou filtrul la 100 sau 120 Hz dacă mai rămâne ceva.
