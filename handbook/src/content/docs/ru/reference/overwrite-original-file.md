В Electron-версиях Soundscaper и Framescaper команда **Файл → Перезаписать имя файла** экспортирует весь отредактированный проект в исходный импортированный медиафайл. Она использует поддерживаемые исходным файлом параметры экспорта и сохраняет результат сразу, не открывая окно экспорта или выбора файла. Аудио сохраняет исходный формат, частоту дискретизации и число каналов. Поддерживаемое видео MP4 и WebM сохраняет исходный контейнер, размеры и частоту кадров.

Импортируйте один медиафайл через **Файл → Импортировать**, внесите изменения и выберите **Файл → Перезаписать имя файла**. Команду можно повторить после следующих изменений. Выделение времени не ограничивает перезапись: всегда формируется весь проект. Проект сохраняет импортированные медиа и историю редактирования.

Команда недоступна, если в проекте нет поддерживаемого исходного файла, импортировано несколько исходных файлов или выполняется импорт, запись либо обработка. В браузерных версиях используется обычное окно экспорта.

Чтобы выбрать другое место назначения или изменить параметры вывода, выберите **Файл → Экспортировать аудио** в Soundscaper или **Файл → Экспортировать видео** в Framescaper. Перезапись заменяет содержимое исходного файла; сохраните отдельную копию, если нужна запись без изменений.
