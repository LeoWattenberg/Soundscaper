Редактор работает в браузере и как настольное приложение. На этой странице перечисляется то, что создано и протестировано, а не каждая среда, в которой код может работать.

## Браузеры

«Автоматически протестировано» означает, что набор браузеров работает против этого двигателя при каждом запросе на извлечение. Двигатель, который не указан, не тестируется и не претендует на работоспособность.

| Двигатель браузера | Автоматически протестировано |
| --- | --- |
| Chromium (Chrome, Edge) | Да |
| Firefox | Да |
| WebKit (Safari) | Да |

## Где может работать возможность

Возможности группируются по тому, что они требуют от платформы. См. [Возможности продукта](/reference/generated/product-capabilities/), чтобы узнать, какие возможности включает каждый продукт.

| Уровень | Что это значит |
| --- | --- |
| `web-core` | Работает в каждом поддерживаемом браузере без требуемых дополнительных функций платформы. |
| `web-enhanced` | Работает в браузере, который обеспечивает новые функции хранения и медиа, необходимые для этой возможности. |
| `electron-enhanced` | Работает в браузере, а настольное приложение делает с ним больше. |
| `electron-only` | Требует настольного приложения, поскольку браузер не может получить доступ к тому, что использует возможность. |
