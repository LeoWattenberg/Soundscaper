## Назначение и применение {#purpose-and-use-case}

Расшифровывайте выделенную речь локально с помощью встроенной среды whisper.cpp.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок whisper-cpp v1.9.3 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов. Для macOS x64 нет движка, доступного для скачивания, хотя веса модели указаны для этой платформы.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Анализ → Речь → Расшифровка и субтитры**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите речь и установите Whisper large-v3 turbo через Управление моделями.
2. Выберите эту модель распознавания речи в меню Инструменты → Расширенная локальная обработка, если хотите указать Whisper явно.
3. Запустите локальную обработку и проверьте текст и границы сегментов, прежде чем принять результат.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `whisper-large-v3-turbo-ggml`, версия **1.0.0**.

Приблизительный размер загрузки файла модели: **547.45 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **4 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Также требуется соответствующая среда выполнения, доступная для скачивания.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

## Проверка результата {#review-the-result}

- Whisper может выдавать неверный текст, особенно при шуме или неразборчивой речи. Проверяйте результат на слух.
- Тест проверяет, что настоящая среда выполнения возвращает непустую расшифровку с временными метками; он не гарантирует конкретное написание слов или показатель распознавания.
