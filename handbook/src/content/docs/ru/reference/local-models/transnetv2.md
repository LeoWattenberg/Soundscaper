## Назначение и применение {#purpose-and-use-case}

Находите переходы между кадрами в видео с помощью точной локальной модели.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок onnxruntime-node 1.29.0 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Framescaper: Инструменты → Расширенная локальная обработка → Поиск склеек**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите видео в Framescaper.
2. Установите TransNetV2 через Менеджер моделей и выберите поиск склеек на основе модели.
3. Проверьте предложенные границы кадров, прежде чем добавлять пометки или использовать их при планировании монтажа.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `transnetv2`, версия **1.0.0**.

Приблизительный размер загрузки файла модели: **29.81 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **2 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Также требуется соответствующая среда выполнения, доступная для скачивания.

В Windows установите последнюю поддерживаемую [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), соответствующую настольному приложению: **x64** для сборки x64 или **ARM64** для сборки ARM64. Нативным движкам ONNX и Sherpa нужны эти библиотеки; загрузки модели и среды выполнения их не включают. Для работы приложения Visual Studio не требуется.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

Случай: `transnet-accurate-shots`; операция: `shot-detection`.

Входные данные: последовательность из 120 кадров при 30 кадрах в секунду, где портрет астронавта NASA посередине сменяется фотографией кошки с лицензией CC0; изображение подготовлено в разрешении модели 48 × 27 пикселей.

Границы склеек, найденные моделью, должны быть непустыми, упорядоченными и находиться в пределах исходного диапазона кадров.

Пакет nightly-with-tests перед выводом модели скачивает реальные файлы модели и проверенные среды выполнения. Если в каталоге нет обязательной модели, её тест завершается ошибкой. Отсутствие нативных движков приводит к ошибке на поддерживаемых каталогом платформах. Эти ресурсоёмкие проверки выполняются отдельно от обычного набора браузерных тестов. Успешный запуск подтверждает базовую работу модели и пригодную структуру вывода, но не доказывает качество восприятия или точность на вашей записи.

## Проверка результата {#review-the-result}

- Затухания, вспышки, движение камеры и очень короткие кадры могут затруднить поиск границ.
- Тест содержит известную визуальную склейку и требует корректных непустых границ, найденных моделью в пределах исходных кадров. Он не подменяет отдельный быстрый поиск склеек без модели.
