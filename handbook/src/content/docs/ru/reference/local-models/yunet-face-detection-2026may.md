## Назначение и применение {#purpose-and-use-case}

Находите лица и объекты на выбранных кадрах видео, чтобы предложить новую кадрировку.

YuNet определяет лица и их расположение. Операция поиска объектов объединяет эти результаты с обнаруженными D-FINE объектами.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок onnxruntime-node 1.29.0 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов. Для macOS x64 нет движка, доступного для скачивания, хотя веса модели указаны для этой платформы.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Framescaper: Эффект → Видеоэффекты → Перекадрирование**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите видеоклип в Framescaper.
2. Установите YuNet и D-FINE для обнаружения объектов. Задача «Перекадрирование» также использует модель определения значимых областей U²-Net-P.
3. Запустите локальную обработку и проверьте предложенную кадрировку. Инструменты → Расширенная локальная обработка могут запустить обнаружение объектов отдельно.

Для этой операции также требуется [модель обнаружения объектов D-FINE Nano](/reference/local-models/dfine-nano-coco/).

## Проверка результата {#review-the-result}

- Лица и объекты могут быть пропущены или классифицированы неверно. Анализ выполняется по выборочным кадрам и не гарантирует, что движущийся объект останется внутри каждой предложенной кадрировки.
- Операция запускает обе модели вместе; ни одна из них не распознаёт личности людей по лицам.
