## Назначение и применение {#purpose-and-use-case}

Разделяйте смешанную звуковую дорожку на предложенные дорожки речи, музыки и эффектов.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок onnxruntime-node 1.29.0 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Инструменты → Расширенная локальная обработка → Разделение источников**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите смешанное аудио, которое хотите разделить.
2. Установите TIGER через Менеджер моделей, затем запустите разделение источников.
3. Прослушайте каждую предложенную составляющую, прежде чем добавлять нужные результаты в проект.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `tiger-dnr`, версия **1.0.0**.

Приблизительный размер загрузки файла модели: **28.25 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **4 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Также требуется соответствующая среда выполнения, доступная для скачивания.

В Windows установите последнюю поддерживаемую [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), соответствующую настольному приложению: **x64** для сборки x64 или **ARM64** для сборки ARM64. Нативным движкам ONNX и Sherpa нужны эти библиотеки; загрузки модели и среды выполнения их не включают. Для работы приложения Visual Studio не требуется.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

Входные данные: речь Кеннеди, передискретизированная до 44.1 kHz и смешанная с воспроизводимыми синтезированными ударными и тонами.

Все составляющие речи, музыки и эффектов должны иметь ожидаемые параметры аудио, конечные отсчёты и ненулевой сигнал. Каждая должна отличаться от смеси; дублирующиеся составляющие отклоняются.

## Проверка результата {#review-the-result}

- После разделения возможны проникновение звука между составляющими и артефакты; исходные дорожки записи не восстанавливаются без потерь.
- Тест смешанного материала требует все три составляющие, конечное аудио ожидаемого размера и изменённые ненулевые отсчёты в каждой. Он также отклоняет дубликаты; качество разделения не измеряется.
