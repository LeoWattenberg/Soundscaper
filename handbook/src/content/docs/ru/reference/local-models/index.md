## Область тестирования {#test-scope}

Обязательный набор охватывает 22 модели в 20 сценариях выполнения: 22 опубликованные модели и 0 кандидатов на публикацию. Для определения говорящих совместно используются модель сегментации и модель векторного представления. Для обнаружения объектов вместе используются модели лиц и объектов. Тест SigLIP2 проверяет сети изображений и текста. У каждого варианта Beat This отдельный сценарий.

Обычные браузерные тесты проверяют интерфейс с имитацией настольной среды. Ночной пакет Electron с тестами отдельно загружает проверенные файлы моделей и запускает реальный вывод. Отсутствие обязательных компонентов среды выполнения считается ошибкой на платформах, поддерживаемых каталогом. Ресурсоёмкие запуски моделей не входят в обычный набор браузерных тестов. Фактические результаты смотрите в отчёте конкретного пакета; эти страницы описывают обязательные проверки, а не утверждают, что каждая сборка или машина их прошла.

Общий размер опубликованных артефактов моделей составляет около **5.65 GiB** без файлов среды выполнения, тестовых данных, временного места и результатов тестов. Одна Qwen добавляет около **2.33 GiB** и требует не менее **16 GiB общей системной памяти**. Для полного запланированного запуска выделите не менее **12 GiB свободной памяти**; отдельные операции применяют собственные ограничения. Модели запускаются последовательно.

При проверке аудио отклоняются тишина, неконечные значения отсчётов и результат, совпадающий со входом. Для текста требуются содержательные непустые поля результата. Представления, обнаружения и временные метки проверяются по соответствующей числовой структуре. Точные значения отсчётов, написание слов и порядок результатов не считаются эталоном.

Успешное прохождение этих проверок подтверждает базовую работу на небольшом тестовом наборе. Оно не доказывает точность расшифровки, правильность названий объектов, удаление шума без потерь или субъективное качество. Проверяйте результаты на собственных медиафайлах перед применением.
