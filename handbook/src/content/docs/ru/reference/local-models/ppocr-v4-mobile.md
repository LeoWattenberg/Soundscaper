## Назначение и применение {#purpose-and-use-case}

Читайте видимый текст на выбранных кадрах видео для проверки и индексирования.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок onnxruntime-node 1.29.0 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов. Для macOS x64 нет движка, доступного для скачивания, хотя веса модели указаны для этой платформы.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Framescaper: Инструменты → Поиск → Индексировать видео или Инструменты → Расширенная локальная обработка → Оптическое распознавание текста**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выберите видео с читаемым текстом на экране.
2. Установите PP-OCRv4 mobile через Менеджер моделей. Это необязательный этап индексирования видео, в котором также используется SigLIP2.
3. Запустите локальную обработку и проверьте распознанный текст и соответствующие кадры, прежде чем принять результаты.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `ppocr-v4-mobile`, версия **4.0.0**.

Приблизительный размер загрузки файла модели: **15.46 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **2 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Также требуется соответствующая среда выполнения, доступная для скачивания.

В Windows установите последнюю поддерживаемую [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), соответствующую настольному приложению: **x64** для сборки x64 или **ARM64** для сборки ARM64. Нативным движкам ONNX и Sherpa нужны эти библиотеки; загрузки модели и среды выполнения их не включают. Для работы приложения Visual Studio не требуется.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

Случай: `ppocr-recognized-text`; операция: `optical-character-recognition`.

Входные данные: кадры с контрастной надписью «LOCAL MODEL TEST» и явно заданным временем исходного кадра.

Текстовые области должны содержать непустой распознанный текст, допустимое время исходного кадра, конечные значения уверенности и ограниченные рамки.

Пакет nightly-with-tests перед выводом модели скачивает реальные файлы модели и проверенные среды выполнения. Если в каталоге нет обязательной модели, её тест завершается ошибкой. Отсутствие нативных движков приводит к ошибке на поддерживаемых каталогом платформах. Эти ресурсоёмкие проверки выполняются отдельно от обычного набора браузерных тестов. Успешный запуск подтверждает базовую работу модели и пригодную структуру вывода, но не доказывает качество восприятия или точность на вашей записи.

## Проверка результата {#review-the-result}

- Мелкий, размытый, повёрнутый, стилизованный или частично скрытый текст может быть пропущен либо прочитан неверно.
- Тест пакета требует текстовые области, поэтому в нём работают детектор, модель ориентации и распознаватель. Посимвольное совпадение не требуется.
