## Назначение и применение {#purpose-and-use-case}

Преобразуйте выделенную речь в расшифровку с временными метками для субтитров и редактирования текста.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок sherpa-onnx-node 1.13.5 для платформ macOS arm64, Linux arm64, Linux x64, Windows arm64, Windows x64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов. Для macOS x64 нет движка, доступного для скачивания, хотя веса модели указаны для этой платформы.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Анализ → Речь → Расшифровка и субтитры**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите речь, которую хотите расшифровать.
2. Установите эту модель через Управление моделями. В меню Инструменты → Расширенная локальная обработка можно выбрать конкретную модель распознавания речи.
3. Запустите локальную обработку, затем проверьте текст и временные метки перед принятием расшифровки.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `parakeet-tdt-0.6b-v2`, версия **2.0.0**.

Приблизительный размер загрузки файла модели: **630.56 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **4 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, macOS x64, Linux arm64, Linux x64, Windows arm64, Windows x64. Также требуется соответствующая среда выполнения, доступная для скачивания.

В Windows установите последнюю поддерживаемую [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), соответствующую настольному приложению: **x64** для сборки x64 или **ARM64** для сборки ARM64. Нативным движкам ONNX и Sherpa нужны эти библиотеки; загрузки модели и среды выполнения их не включают. Для работы приложения Visual Studio не требуется.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

## Проверка результата {#review-the-result}

- Сверяйте имена, знаки препинания, числа и временные метки с записью.
- Для успешного теста нужны читаемый текст и корректные временные метки, а не точная эталонная расшифровка. Он не измеряет точность распознавания для разных языков или условий записи.
