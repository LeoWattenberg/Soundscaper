## Назначение и применение {#purpose-and-use-case}

Уменьшайте отражения помещения в записанной речи с помощью локальной модели удаления реверберации.

## Текущая доступность {#current-availability}

Настольные сборки могут скачать и проверить необходимый движок onnxruntime-node 1.29.0 для платформ macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Установите эту модель и необходимую среду выполнения через Менеджер моделей, затем выполните задачу локально. Это поддерживаемые цели сборки; результаты для конкретного пакета и устройства смотрите в отчёте ночных тестов.

## Использование модели {#use-this-model}

На платформе с необходимой встроенной средой откройте **Инструменты → Расширенная локальная обработка → Удаление реверберации**. Локальные вспомогательные функции работают в настольном редакторе.

1. Выделите речь, на которую повлияли отражения помещения.
2. Установите модель через Менеджер моделей и запустите удаление реверберации.
3. Сравните результат с оригиналом и примите его, только если речь стала звучать лучше.

## Загрузка и требования {#download-and-requirements}

Идентификатор модели: `dereverb-room`, версия **1.0.0**.

Приблизительный размер загрузки файла модели: **114.57 MiB**. Необходимая среда выполнения добавляется к первой загрузке, если ещё не установлена. Минимальный объём системной памяти: **2 GiB**. Требование каталога относится к общей памяти, а не к свободной памяти в данный момент. Для вывода модели также нужна свободная память, а для установки — рабочее место; объём памяти не гарантирует скорость.

Опубликованные платформы: macOS arm64, Linux x64, Linux arm64, Windows x64, Windows arm64. Также требуется соответствующая среда выполнения, доступная для скачивания.

В Windows установите последнюю поддерживаемую [Microsoft Visual C++ v14 Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), соответствующую настольному приложению: **x64** для сборки x64 или **ARM64** для сборки ARM64. Нативным движкам ONNX и Sherpa нужны эти библиотеки; загрузки модели и среды выполнения их не включают. Для работы приложения Visual Studio не требуется.

Инструменты → Менеджер моделей при первой установке скачивает опубликованные файлы модели и необходимую среду выполнения, затем проверяет записанные дайджесты SHA-256. Обработка использует локально установленные файлы. Откройте раздел «Хранилище и проверка» в Менеджере моделей, чтобы просмотреть уведомления, восстановить установку или изменить место хранения.

Случай: `dereverb-room-speech`; операция: `dereverberation`.

Входные данные: речь Кеннеди, передискретизированная до 44.1 kHz, с четырьмя воспроизводимыми задержанными отражениями.

Декодированное аудио должно содержать конечные отсчёты, сохранять ожидаемые параметры звука, отличаться от входных отсчётов и содержать слышимый сигнал ненулевого уровня. Одного отличия заголовков файлов недостаточно.

Пакет nightly-with-tests перед выводом модели скачивает реальные файлы модели и проверенные среды выполнения. Если в каталоге нет обязательной модели, её тест завершается ошибкой. ## Проверка результата {#review-the-result}

- Сильные отражения, музыка и непривычные помещения могут вызвать артефакты или удалить нужные детали.
- Изменившееся аудио с ненулевым сигналом подтверждает выполнение обработки, но не полное удаление реверберации и не улучшение звучания.
