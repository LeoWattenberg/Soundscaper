Обе версии обрабатывают проекты локально. Их хранение и доступ к файлам различаются.

## Веб-редактор

Веб-версия сохраняет проекты, записи и импортированные медиа в локальное хранилище браузера. Она не загружает проект на аккаунт Soundscaper и не требует регистрации.

Используйте веб-редактор, когда вам нужен мгновенный доступ без установки приложения. Помните, что локальное хранилище браузера ограничено квотой и правилами очистки. Очистка данных сайта удаляет локальную библиотеку проектов.

## Настольный просмотр

Упакованные настольные просмотры сохраняют локальную библиотеку с автосохранением внутри настольного приложения. Они включают в себя среду выполнения редактора и выпущенные переводы для офлайн-редактирования.

Настольные пакеты не подписаны. macOS применяет только идентификационный ад-хок код, который запечатывает его загрузчик для выполнения Electron и родных бинарных файлов; этот штамп не делает никаких утверждений о издателе или доверии. Поэтому Windows SmartScreen или macOS Gatekeeper могут отображать предупреждение об неизвестном разработчике для предварительных и стабильных пакетов.

Открытие файла `.aup4` импортирует независимый проект в настольную библиотеку. Последующие изменения не перезаписывают открытый файл. **Сохранить** обновляет копию в библиотеке; **Сохранить как** создает новый файл обмена Audacity.

## Смартфоны и планшеты

Веб-редактор сохраняет настольный макет на всех экранах, но при ширине менее 900 пикселей (как на телефоне или планшете в вертикальном положении) он сворачивает панели инструментов, чтобы оставить место для временной шкалы:

- Кнопка **Меню** в верхнем левом углу открывает панель с полным меню приложения, вкладками проекта, панелью инструментов и панелью инструментов инструментов. Воспроизведение, остановка, запись и поиск остаются на панели. Выбор команды закрывает панель.
- Заголовки треков скользят над дорожками из ручки «Заголовки треков» в верхнем левом углу временной шкалы или из **Вид > Заголовки треков**. Нажатие на дорожки или нажатие клавиши Escape убирает их.
- Введение выше редактора свернуто по умолчанию на узких экранах; **Показать введение** возвращает его.

**Редактировать > Предпочтения > Внешний вид > Макет** переключает между Автоматическим, Компактным и Настольным, так что небольшое окно на настольном компьютере может сохранить настольный макет, а широкий планшет может переключиться на панели инструментов.

## Проекты не перемещаются автоматически

Библиотеки браузера и настольного компьютера разделены. Перемещайте проекты намеренно:

- Используйте файл проекта Soundscaper - `.sscape`, или файл проекта Framescaper - `.fscape` для полного проекта.
- Используйте AUP4, когда вам конкретно нужен аудиообмен с Audacity.
- Экспортируйте отрендеренный аудио- или видеофайл как долговечную копию для воспроизведения.

См. [Файлы проектов](/projects-and-data/project-files/) перед удалением данных сайта браузера или данных настольного приложения.
