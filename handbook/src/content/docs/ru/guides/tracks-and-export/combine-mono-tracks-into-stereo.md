## Для чего нужно это руководство {#what-this-guide-is-for}

Make stereo track преобразует две моно-дорожки в один стереоклип и заменяет исходные дорожки. Дорожка, в меню которой выбрана команда, становится левым каналом; первая совместимая моно-дорожка ниже неё становится правым каналом. Если ниже такой дорожки нет, Soundscaper использует первую совместимую моно-дорожку в другом месте проекта. Перед объединением поместите нужную дорожку правого канала непосредственно под дорожку левого канала.

:::note[Переходите из Audacity?]
Это соответствует команде Audacity **Upper mono track menu → Make stereo track (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите монофоническую запись для левого канала. Она появится клипом на отдельной дорожке.
3. Выберите **Файл → Импорт** и укажите монофоническую запись для правого канала. Она появится клипом на отдельной дорожке ниже первой записи. Расположите клипы в соответствии со временем их воспроизведения.
4. Откройте меню записи левого канала кнопкой **Параметры трека** в заголовке дорожки и выберите **Каналы трека → Создать стереотрек**.
5. Теперь в проекте отображаются 1 клип и 2 дорожки.
   *Что должно быть видно:* Две монофонические записи заменены одним стереоклипом с нужным звуком в каждом канале.

## Советы

- Новый клип охватывает содержимое обеих дорожек с частотой дискретизации проекта. Пустые участки любой дорожки становятся тишиной в соответствующем канале.
- Если записи должны начинаться одновременно, перед объединением [выровняйте начала дорожек](/guides/editing/align-track-starts-together/).
- Сохраните копию проекта, если отдельные клипы понадобятся для дальнейшего редактирования. Команда **Редактировать → Отменить** вернёт две моно-дорожки.
