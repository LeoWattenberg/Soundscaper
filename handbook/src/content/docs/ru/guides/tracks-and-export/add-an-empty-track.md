## Для чего нужно это руководство {#what-this-guide-is-for}

Импорт файла создает для вас дорожку, но для записи или вставки нужен место для приземления. Кнопка «Добавить дорожку» над списком дорожек создает пустую аудиодорожку; дорожка меток содержит маркеры и текст вместо звука.

:::note[Переход из Audacity?]
Это **Дорожки → Добавить новую → Моно-дорожка** в Audacity. Названия ниже являются собственными для Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Нажмите **Добавить дорожку** над списком дорожек и выберите **Аудиодорожка**.
3. Теперь проект показывает 2 дорожки.
   *Вы должны увидеть:* Вторую пустую аудиодорожку под первой.

## Советы

- Переименуйте дорожку из ее меню, чтобы сессия с большим количеством дорожек оставалась читаемой.
- Перетащите дорожку за ее заголовок, чтобы изменить ее порядок.
