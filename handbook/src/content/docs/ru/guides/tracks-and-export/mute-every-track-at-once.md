## Для чего нужно это руководство {#what-this-guide-is-for}

С десятком дорожек отключение их по одной заголовку за раз для прослушивания новой части является утомительным, а последующее включение — еще хуже. Отключение всех дорожек молчит весь проект одним приказом, а включение всех дорожек восстанавливает его, и ни один из них не трогает кнопки соло. Audacity 3 имел обе команды; Audacity 4 не вернул их.

:::note[Приходящий из Audacity?]
Это **Tracks → Mute/Unmute → Mute All Tracks и Unmute All Tracks (Audacity 3; не в Audacity 4)** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите первую запись. Файл попадает в клип на своей дорожке.
3. Выберите **Файл → Импорт** и выберите вторую запись. Файл попадает в клип на своей дорожке.
4. Выберите **Дорожки → Отключить все дорожки**.
5. Теперь в проекте включена кнопка **Отключить** для каждой дорожки.
   *Вы должны увидеть:* Воспроизведение молчит.
6. Выберите **Дорожки → Включить все дорожки**.
7. Теперь в проекте нет отключенных дорожек.
   *Вы должны увидеть:* Все снова играет.

## Советы

- Отключите все, а затем включите одну или две дорожки, которые вы хотите услышать — быстрее, чем соло, когда выбор часто меняется.
- Чтобы услышать одну дорожку в одиночку, не трогая другие, [сделайте ее соло](/guides/tracks-and-export/mute-and-solo-tracks/) вместо этого.
