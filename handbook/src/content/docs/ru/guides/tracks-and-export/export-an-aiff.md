## Для чего нужно это руководство {#what-this-guide-is-for}

AIFF — это несжатый PCM-формат, который часто используют в рабочих процессах со звуком на системах Apple. Экспортируйте в него, если этого требует принимающее приложение или спецификация поставки.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **File → Export Audio → Other uncompressed files → AIFF (Audacity 3)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись или микс для передачи. Они появятся клипом на отдельной дорожке.
3. Выберите **Файл → Диалог экспорта аудио**, задайте для **Формат** значение **AIFF** и нажмите **Экспорт**. После завершения рендеринга файл скачается, а ссылка на него останется в диалоговом окне.
   *Ожидаемый результат:* В окне экспорта доступен файл `.aiff` для скачивания.

## Советы

- AIFF не теряет качество, но занимает больше места, чем сжатые форматы, например [FLAC](/guides/tracks-and-export/export-a-flac/).
- Выберите формат отсчётов и частоту дискретизации в соответствии с требованиями поставки.
