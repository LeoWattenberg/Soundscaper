WAV сохраняет каждый образец точно так, как его оставил редактор. Используйте его для мастеринга, для передачи аудио видео-редактору или другой ДAW, и для всего, что вы, возможно, захотите обработать снова.

:::note[Переход из Audacity?]
Это **Файл → Экспорт аудио → WAV** в Audacity. Названия ниже являются собственными для Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись для передачи. Файл попадает в виде клипа на свою собственную дорожку.
3. Выберите **Файл → Экспорт аудио**, установите **Формат** на **WAV** и нажмите **Экспорт**. Файл загружается сразу после завершения рендеринга, и его ссылка остается в диалоговом окне.

## Советы

- Файлы WAV большие: около десяти мегабайт в минуту для стерео при качестве CD.
- Чтобы экспортировать каждую дорожку в качестве отдельного файла, установите **Режим** в диалоговом окне экспорта на индивидуальные стемы.
