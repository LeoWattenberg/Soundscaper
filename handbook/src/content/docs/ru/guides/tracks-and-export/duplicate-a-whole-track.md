## Для чего нужно это руководство {#what-this-guide-is-for}

Duplicate track копирует всю дорожку, включая каждый клип и его положение на временной шкале. Используйте копию, чтобы попробовать другой вариант редактирования или эффект, сохранив оригинал. Выбор одного клипа указывает дорожку для дублирования; остальные клипы на ней также будут скопированы.

:::note[Переходите из Audacity?]
Это соответствует команде Audacity **Tracks → Duplicate (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись на дорожке, которую нужно дублировать. Она появится клипом на отдельной дорожке.
3. Щёлкните по звуковой волне в точке, где нужно разделить запись на две независимо редактируемые части, чтобы установить курсор. Пропустите установку курсора и следующий шаг Split, если на дорожке уже несколько клипов или вы хотите оставить её одним клипом.
4. Выберите **Редактировать → Аудиоклипы → Разделить**.
5. Теперь в проекте отображаются 2 клипа.
   *Что должно быть видно:* На дорожке находятся два клипа, готовые к совместному копированию.
6. Нажмите **Tab**, чтобы перейти к одному из клипов на дорожке, затем нажмите **Enter**, чтобы выбрать его.
7. Выберите **Треки → Дублировать трек**.
8. Теперь в проекте отображаются 4 клипа и 3 дорожки.
   *Что должно быть видно:* Исходная дорожка и её копия содержат по два клипа в одинаковых позициях на временной шкале.

## Советы

- Исходная дорожка и копия воспроизводятся одновременно. При сравнении [отключите звук дорожки или включите режим Solo](/guides/tracks-and-export/mute-and-solo-tracks/), чтобы слышать только одну версию.
- Чтобы скопировать только фрагмент, вместо этого [дублируйте выделение на новую дорожку](/guides/editing/duplicate-a-selection-to-a-new-track/).
- Команда **Редактировать → Отменить** удалит дублированную дорожку.
