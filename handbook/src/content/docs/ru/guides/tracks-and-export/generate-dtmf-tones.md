## Для чего нужно это руководство {#what-this-guide-is-for}

В DTMF для каждого символа телефонной клавиатуры одновременно звучат два тона. Создайте нужную последовательность для телефонного эффекта с паузами между символами.

:::note[Переходите из Audacity?]
Это команда Audacity 3 **Generate → DTMF Tones**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Создать → Тоны DTMF**. В диалоге **Тоны DTMF** задайте **Последовательность DTMF** `123`, **Амплитуда** `0.2` и **Длительность (секунды)** `2`, затем нажмите **Создать**. Введите символы клавиатуры по порядку. Общая длительность включает тоны и паузы.
3. В проекте появился 1 клип.
   *Результат:* Один клип содержит тональные сигналы клавиш в заданном порядке.

## Советы

- Тастовое отношение задаёт долю тонов и пауз в последовательности.
- Перед созданием клипа в сводке времени показана длительность каждого тона и паузы.
