После того, как дорожки сбалансированы, их смешивание в одну делает проект легче для работы и дает вам один клип для экспорта или переноса в другое место. Смешивание использует прирост, панорамирование, автоматизацию и эффекты каждой выбранной дорожки. Мутация и соло игнорируются для выбранных дорожек во время этой операции, а обработка мастер-дорожки остается активной.

:::note[Переход из Audacity?]
Это аналогично функции **Дорожки → Смешивание → Смешивание и рендеринг** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите первую часть. Файл помещается в клип на своей собственной дорожке.
3. Выберите **Файл → Импортировать аудио** и выберите вторую часть. Файл помещается в клип на своей собственной дорожке.
4. Щелкните по имени первого клипа, затем, удерживая Shift, щелкните по имени второго клипа, чтобы выбрать оба. Каждая дорожка с выбранным клипом включается в микс.
5. Выберите **Дорожки → Смешивание и рендеринг**. В диалоговом окне **Смешивание и рендеринг** оставьте выбранными **Смешать**, **Рендеринг эффектов** и **Заменить оригиналы**, выберите **Стерео** для **Смешать в**, затем нажмите **Смешать и рендеринг**.
6. Теперь в проекте отображается клип с именем **Смешивание**.
   *Вы должны увидеть:* Одна дорожка содержит клип с именем Смешивание; исходные дорожки исчезли.

## Советы

- Выберите **Моно**, **Стерео** или настроенный для проекта многоканальный формат под **Смешать в** перед рендерингом.
- **Редактировать → Отменить** возвращает исходные дорожки, если вам нужно изменить баланс.
- Вам не нужно смешивать для экспорта. **Файл → Экспорт аудио** рендерит весь проект самостоятельно.
