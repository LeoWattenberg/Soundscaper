## Для чего нужно это руководство {#what-this-guide-is-for}

Pluck создаёт короткий тон заданной высоты, который можно использовать как простую музыкальную ноту или звуковой акцент. Поле высоты MIDI позволяет выбрать ноту без вычисления частоты.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Generate → Pluck (Nyquist)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Создать → Nyquist → Pluck**. В диалоговом окне **Pluck** задайте **Pluck MIDI pitch** значение `60`, а **Duration (60s max)** — `2`, затем нажмите **Применить**. Высота MIDI 60 соответствует среднему до; двух секунд хватит ноте, чтобы затухнуть.
3. Теперь в проекте 1 клип.
   *Ожидаемый результат:* На временной шкале появилась звучащая щипковая нота длительностью две секунды.

## Советы

- Увеличьте **Pluck MIDI pitch**, чтобы поднять ноту, или уменьшите это значение для более низкой ноты.
- Задайте меньшую **Duration (60s max)** для более короткого акцента.
