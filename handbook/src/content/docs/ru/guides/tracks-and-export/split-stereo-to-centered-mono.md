## Для чего нужно это руководство {#what-this-guide-is-for}

Если двухканальный рекордер записал одного собеседника слева, а другого справа, разделение каналов позволит отдельно редактировать и балансировать каждый голос. Split stereo to centered mono создаёт две моно-дорожки, обе с панорамированием по центру. Их положение и длительность на временной шкале сохраняются, а каждый канал остаётся отдельной записью.

:::note[Переходите из Audacity?]
Это соответствует команде Audacity **Track menu → Split stereo to center mono (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите стереозапись, каналы которой нужно разделить. Она появится клипом на отдельной дорожке.
3. Откройте меню дорожки кнопкой **Параметры трека** в её заголовке и выберите **Каналы трека → Разделить стерео на моно по центру**.
4. Теперь в проекте отображаются 2 клипа и 3 дорожки.
   *Что должно быть видно:* На отдельных дорожках Left и Right находятся исходные каналы, а оба регулятора панорамирования установлены по центру.

## Советы

- Чтобы сохранить исходное стереорасположение, вместо этого [разделите на моно-дорожки left/right](/guides/tracks-and-export/split-stereo-into-mono-tracks/).
- Так создаются две моно-дорожки. Чтобы объединить их звук в один монофонический канал, [сведите дорожки](/guides/tracks-and-export/mix-tracks-into-one/) и выберите Mono.
- Команда **Редактировать → Отменить** восстановит стереодорожку.
