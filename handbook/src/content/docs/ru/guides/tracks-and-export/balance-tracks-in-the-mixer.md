В заголовке каждой дорожки есть регулятор громкости, но сводить микс удобнее, когда все регуляторы видны вместе. Панель микшера показывает для каждой дорожки отдельный канал — название, фейдер громкости, панораму, отключение звука, соло и эффекты — рядом с мастер-каналом, как на микшерном пульте. В Audacity 3 для этого была панель Mixer Board; в Audacity 4 её пока нет.

:::note[Переход из Audacity?]
Это аналог команды Audacity **Вид → Mixer Board (Audacity 3; в Audacity 4 такой панели нет)**. Ниже приведены названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и укажите первую дорожку микса. Она появится как клип на отдельной дорожке.
3. Ещё раз выберите **Файл → Импорт** и укажите вторую дорожку. Она тоже появится отдельно.
4. Выберите **Вид → Панели → Микшер**.
5. Теперь открыта панель **Микшер**.
   *Вы должны увидеть:* По одному каналу для каждой дорожки с фейдером **Громкость**, регулятором **Панорама**, кнопками **Отключить звук/Соло** и мастер-каналом в конце.
6. Перетащите фейдер **Громкость** канала, чтобы изменить уровень дорожки, и поверните **Панорама**, чтобы сместить её влево или вправо. Это те же регуляторы, что и в заголовке дорожки, поэтому можно использовать любой вид.
7. Нажмите **Воспроизвести**, чтобы послушать, затем **Остановить**.
   *Вы должны увидеть:* Во время воспроизведения индикаторы на каналах показывают уровни соответствующих дорожек.

## Советы

- **Добавить групповую шину** создаёт шину для нескольких дорожек, чтобы у всей группы ударных или голосов был один фейдер.
- Кнопка **Схема маршрутизации** на панели показывает тот же микшер в виде схемы соединений.
