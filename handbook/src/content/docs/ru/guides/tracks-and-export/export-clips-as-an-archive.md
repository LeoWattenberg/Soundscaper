## Для чего нужно это руководство {#what-this-guide-is-for}

Экспорт отдельных клипов сохраняет каждую правку в самостоятельном аудиофайле и помещает файлы в один архив. Сначала разделите фрагмент на клипы, затем в диалоговом окне экспорта выберите режим вывода клипов.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **File → Export Audio → Multiple Files, split by tracks or labels (Audacity 3)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, клипы которой нужно экспортировать отдельно. Она появится клипом на отдельной дорожке.
3. Перетащите указатель по линейке над клипом, чтобы выделить фрагмент и экспортировать его как отдельный клип.
4. Выберите **Правка → Аудиоклипы → Разделить**.
5. Выберите **Файл → Диалог экспорта аудио**, установите **Формат** равным **WAV**, задайте для **Выход** значение **Отдельные клипы (разделить по клипам)** и нажмите **Экспорт**. После завершения рендеринга файл скачается, а ссылка на него останется в диалоговом окне. Каждый клип будет отрендерен в отдельный WAV-файл внутри одного ZIP-архива.

## Советы

- Перед экспортом задайте клипам описательные названия, чтобы различать файлы в архиве.
- Выберите **Весь проект**, если вместо отдельных файлов клипов нужен один микс.
