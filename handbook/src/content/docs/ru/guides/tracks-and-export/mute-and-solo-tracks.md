Каждый трек имеет кнопку **Мут** и кнопку **Соло** в заголовке. **Мут** отключает звук для данного трека, а **Соло** отключает все остальные треки, чтобы вы могли услышать только этот. Оба они являются лишь инструментами прослушивания — они изменяют то, что вы слышите во время работы, но при экспорте будут учтены все незамутенные треки.

:::note[Переходим из Audacity?]
Это аналог **кнопок «Мут» и «Соло» в панели управления треком** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Как только редактор загрузится, новый пустой проект будет готов к использованию.
2. Выберите **Файл → Импортировать аудио** и выберите один трек. Файл будет размещен в виде клипа на отдельном треке.
3. Выберите **Файл → Импортировать аудио** и выберите другой трек. Файл будет размещен в виде клипа на отдельном треке.
4. Нажмите **Мут** в заголовке трека. Второй трек будет исключен из воспроизведения.
5. Нажмите **Соло** в заголовке трека. Соло отменяет мут для этого трека и отключает все остальные, так что вы слышите только этот трек.

## Советы

- Нажмите кнопку еще раз, чтобы отменить ее действие. **Треки → Замутить все треки** одновременно очищает все треки.
- Включите Соло для нескольких треков, чтобы прослушать группу вместе; мутирование тогда требуется только для «лишнего» трека.
