## Для чего нужно это руководство {#what-this-guide-is-for}

В проекте с несколькими дублями проще ориентироваться, когда связанные названия дорожек стоят рядом. Sort by name располагает дорожки по алфавиту, не меняя время начала клипов на временной шкале.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Tracks → Sort Tracks → Sort by Name**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, которая по названию должна располагаться после другой. Она появится клипом на отдельной дорожке.
3. Выберите **Файл → Импорт** и укажите запись, которую по названию нужно поставить перед ней. Она появится клипом на отдельной дорожке.
4. Выберите **Треки → Сортировка треков → Сортировать по имени**. Названия дорожек будут расположены по алфавиту.
5. Теперь в проекте 2 клипа.
   *Ожидаемый результат:* Обе записи остались в проекте, а названия дорожек расположены по алфавиту.

## Советы

- Сортировка меняет порядок дорожек, но не время клипов и не содержимое аудио.
- Выберите **Треки → Сортировка треков → Сортировать по времени**, если хотите упорядочить дорожки по времени начала клипов.
