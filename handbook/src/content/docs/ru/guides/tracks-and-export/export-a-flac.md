## Для чего нужно это руководство {#what-this-guide-is-for}

FLAC сжимает PCM-аудио, не отбрасывая отсчёты при выбранной точности экспорта. Он подходит для компактной копии мастера, тогда как проект сохраняет дорожки для редактирования.

:::note[Переходите из Audacity?]
Это команда Audacity 3 **File → Export Audio → FLAC**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись или микс для передачи. Аудио появится клипом на отдельной дорожке.
3. Выберите **Файл → Диалог экспорта аудио**, задайте для **Формат** значение **FLAC** и нажмите **Экспорт**. После рендеринга файл скачается, а ссылка останется в диалоге.
   *Результат:* В диалоге экспорта доступен FLAC-файл для скачивания.

## Советы

- Compression level влияет на работу кодирования и размер файла, но не на качество декодированного аудио.
- В экспортированном миксе нет отдельных дорожек и истории отмены. Для дальнейшего редактирования [сохраните проект](/guides/projects/save-your-project/).
