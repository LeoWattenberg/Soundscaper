## Для чего нужно это руководство {#what-this-guide-is-for}

Remove tracks удаляет из проекта выбранную дорожку и все содержащиеся в ней клипы. Это удобно для ненужного дубля или запасной копии после сравнения вариантов редактирования. Выбор одного клипа затрагивает всю дорожку, поэтому перед удалением проверьте, что выбрано.

:::note[Переходите из Audacity?]
Это соответствует команде Audacity **Tracks → Remove tracks (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, которую нужно сохранить. Она появится клипом на отдельной дорожке.
3. Выберите **Файл → Импорт** и укажите ненужную запись на другой дорожке. Она появится клипом на отдельной дорожке.
4. Нажмите **Tab**, чтобы перейти к клипу на удаляемой дорожке, затем нажмите **Enter**, чтобы выбрать его.
5. Выберите **Треки → Удалить треки**.
6. Сохранённая запись осталась на прежнем месте.
   *Что должно быть видно:* Ненужная дорожка исчезла, а другая запись не изменилась.

## Советы

- Команда **Редактировать → Отменить** восстановит удалённую дорожку и её клипы.
- Чтобы удалить только часть записи, [удалите фрагмент, оставив пробел](/guides/editing/delete-a-passage-and-leave-a-gap/), а не всю дорожку.
- Удаление дорожки из проекта не удаляет исходный файл, импортированный с компьютера.
- Дорожки в связанной группе lane удаляются вместе.
