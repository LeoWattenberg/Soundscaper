## Для чего нужно это руководство {#what-this-guide-is-for}

Белый шум распределяет энергию по всему частотному диапазону. Создайте короткий клип с низким уровнем для текстуры или проверки аудиотракта, не импортируя запись.

:::note[Переходите из Audacity?]
Это команда Audacity 3 **Generate → Noise**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Создать → Шум**. В диалоге **Шум** задайте **Амплитуда** `0.1` и **Длительность (секунды)** `2`, затем нажмите **Создать**. Оставьте Оставьте цвет шума по умолчанию — белый. Перед прослушиванием начните с малого уровня.
3. В проекте появился 1 клип.
   *Результат:* На таймлайне появился шумовой клип длительностью две секунды.

## Советы

- В цвете шума также доступны розовый и коричневый шум для других текстур.
- В существующем проекте установите курсор в точке начала нового клипа. Если выделен временной диапазон, генератор заменит этот фрагмент.
