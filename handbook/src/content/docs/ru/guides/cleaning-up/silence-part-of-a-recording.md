Иногда вы хотите удалить фрагмент, но сохранить занимаемое им время — например, звонок телефона во время паузы или имя, которое нужно заглушить. Приглушение оставляет запись такой же длинной, и только выбранная часть становится молчаливой.

:::note[Переход из Audacity?]
Это аналогично **Редактировать → Удалить специальное → Заглушить аудио** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать** и выберите запись с фрагментом, который нужно заглушить. Она помещается в виде клипа на отдельную дорожку.
3. Перетащите линейку над клипом, чтобы выделить только часть, которую вы хотите заглушить.
4. Выберите **Редактировать → Удалить специальное → Заглушить аудио**.
5. Теперь в проекте отображаются 3 клипа.
   *Вы должны увидеть:* Волновая форма плоская в новом центральном клипе, между неизмененным аудио с обеих сторон.

## Советы

- Заглушение — это обычная редакция: **Редактировать → Отменить** возвращает аудио.
- Чтобы удалить время вместе с звуком, см. [Удалить ошибку из записи](/guides/editing/cut-out-a-mistake/).
