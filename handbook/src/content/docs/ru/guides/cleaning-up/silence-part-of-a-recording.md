Иногда вы хотите удалить фрагмент, но сохранить занимаемое им время — например, звонок телефона во время паузы или имя, которое нужно заглушить. Приглушение оставляет клип такой же длинный, как и был, просто выравнивая выбранную часть.

:::note[Переход из Audacity?]
Это аналогично функции **Редактировать → Удалить специальное → Заглушить аудио** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с фрагментом, который нужно заглушить. Файл помещается в виде клипа на отдельную дорожку.
3. Перетащите линейку над клипом, чтобы выделить только часть, которую вы хотите заглушить.
4. Выберите **Редактировать → Удалить специальное → Заглушить аудио**.
5. Теперь в проекте отображается 1 клип.
   *Вы должны увидеть:* Волновая форма выравнивается по всему выделенному фрагменту, и клип остается целым.

## Советы

- Заглушение — это обычная операция редактирования: **Редактировать → Отменить** восстанавливает аудио.
- Чтобы удалить и время, и звук, см. [Удалить ошибку из записи](/guides/editing/cut-out-a-mistake/).
