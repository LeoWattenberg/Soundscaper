Клик-шумы от кабеля, мыши или старой записи — это лишь несколько примеров длинных звуков. Удаление кликов находит выбросы, которые выделяются на фоне окружающего звука, и сглаживает их, что гораздо быстрее, чем ручное удаление каждого клика. 

:::note[Переход из Audacity?]
Это **Эффект → Удаление и восстановление шума → Удаление кликов** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись с кликами. Она помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Удаление и восстановление шума → Удаление кликов**. В диалоговом окне **Удаление кликов** установите **Порог** на `150`, затем нажмите **Применить к выделенному**. Более низкий порог захватывает более тихие клики. Значение по умолчанию 200 является консервативным; 150 захватывает больше, не затрагивая музыку.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Остановить**.
   *Вы должны увидеть:* Клики исчезли, а окружающий материал остался неизменным.

## Советы

- Если клик остается, выберите только момент вокруг него и снова запустите эффект с более низким **Порогом**.
- Клик, который шире нескольких миллисекунд, не является кликом для этого эффекта. Вырежьте его вместо этого.
