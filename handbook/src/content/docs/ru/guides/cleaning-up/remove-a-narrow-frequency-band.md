## Для чего нужно это руководство {#what-this-guide-is-for}

Постоянный свист или электронный тон может занимать узкий диапазон частот только на отдельном участке записи. Spectral Delete удаляет этот диапазон в пределах выделенного отрезка времени, сохраняя соседние частоты.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Effect → Spectral Tools → Delete selection (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с коротким тональным звуком. Она появится клипом на отдельной дорожке.
3. Откройте меню нужной дорожки с помощью кнопки **Параметры трека** в её заголовке и выберите **Визуализация дорожки → Спектрограмма**.
4. Перетащите указатель по линейке над клипом, чтобы выделить отрезок времени, в котором слышен тон.
5. Выберите **Эффект → Спектральное редактирование → Выделить диапазон частот спектра**. Установите **Минимальная частота (Гц)** равным `200`, а **Максимальная частота (Гц)** — `320`, затем нажмите **Спектральное удаление**. Так тон петли 261.6 Hz удалится только в выбранном отрезке времени.
6. Нажмите **Играть**, чтобы прослушать результат, затем **Стоп**.
   *Ожидаемый результат:* В этом отрезке тональный звук стал тише, а остальная запись сохранилась.

## Советы

- Найдите тон на спектрограмме и перед удалением сузьте временные и частотные границы вокруг него.
- Spectral Delete воздействует на выделенный диапазон времени и частот; обычная команда Delete удаляет весь выделенный фрагмент.
