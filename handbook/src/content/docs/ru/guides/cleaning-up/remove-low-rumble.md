Шум от транспорта, кондиционера, ветер в микрофон и стук по столу — все это находится под голосом, на частотах, которые небольшой динамик не может даже воспроизвести. Фильтр верхних частот пропускает все выше пороговой частоты и затухает то, что ниже, очищая низкие частоты без влияния на речь. 

:::note[Приходящий из Audacity?]
Это **Эффект → Фильтр верхних частот** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с гулом. Файл помещается в виде клипа на свою собственную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Легаси эффекты → Классические фильтры**. В диалоговом окне **Классические фильтры** выберите **Верхний пропуск** для **Тип фильтра** и установите **Пороговая частота** на `100`, затем нажмите **Применить к выделенному**. 100 Гц безопасно для речи. Повышайте порядок для более крутого затухания.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Низкий гул исчез, и голос звучит так же.

## Советы

- Для музыки начинайте ниже — около 40 Гц — чтобы не сделать басовые инструменты тоньше.
- Реальный фильтр верхних частот в эффектной стойке дорожки выполняет ту же работу во время воспроизведения, без рендеринга.
