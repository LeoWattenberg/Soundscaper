## Для чего нужно это руководство {#what-this-guide-is-for}

Длинные паузы могут замедлять речь, а удаление всех пауз затруднит её восприятие. Truncate Silence позволяет сжать только лишнюю часть пауз, превышающих минимальную длительность.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Effect → Special → Truncate Silence**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с паузами, которые кажутся слишком длинными. Она появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Специальные → Обрезание тишины**. В диалоговом окне **Обрезание тишины** задайте **Порог** значение `-40`, **Минимальная тишина** — `0.5`, для **Сжать избыточную тишину** выберите **Действие**, а для **Сжать до** задайте `50`, затем нажмите **Применить к выделению**. Тишина длиннее 0.5 секунды сокращается наполовину от своей избыточной длительности, при этом между фразами остаётся пауза.
5. Нажмите **Играть**, чтобы прослушать результат, затем **Стоп**.
   *Ожидаемый результат:* Длинные паузы стали короче, но между фразами сохранилась тишина.

## Советы

- Увеличьте **Минимальная тишина**, чтобы короткие паузы не менялись, или уменьшите **Сжать до**, чтобы сильнее сократить длинные.
- Проверьте, не обрезались ли вдохи или окончания фраз; отмените изменение, если темп стал неестественным.
