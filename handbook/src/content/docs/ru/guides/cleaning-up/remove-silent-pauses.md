Длительные паузы с медленными интервалами между предложениями утомительны для прослушивания. Функция «Обрезка тишины» находит каждый интервал ниже порогового значения, который длится дольше минимальной длины, и сокращает его, так что темп становится более быстрым, не затрагивая слова. 

:::note[Переход из Audacity?]
Это эффект **Эффект → Специальный → Обрезка тишины** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с длительными паузами. Файл будет размещен в виде клипа на отдельной дорожке.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Специальный → Обрезка тишины**. В диалоговом окне «Обрезка тишины» установите **Порог** на `-40`, затем нажмите **Применить к выделенному**. Все, что тише −40 дБ, считается тишиной. Паузы, превышающие минимальную длину тишины, сокращаются до длины обрезки; оба параметра остаются по умолчанию в половину секунды здесь.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.
   *Вы должны увидеть:* Паузы короче, и каждое предложение по-прежнему полно.

## Советы

- Если слова в начале предложения обрезаются, увеличьте минимальную длину тишины или уменьшите порог.
- Эффект изменяет длину выделения, поэтому запускайте его до того, как вы выровняете запись с чем-либо еще.
