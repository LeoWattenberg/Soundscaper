## Для чего нужно это руководство {#what-this-guide-is-for}

Clip Fix оценивает недостающие вершины коротких срезанных пиков по соседним участкам волны. Примените его к копии записи и внимательно прослушайте результат: восстановить более длинные срезанные фрагменты он не сможет.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Effect → Noise Removal and Repair → Clip Fix (Audacity 3 and 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с короткими срезанными пиками, которые нужно восстановить. Она появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Nyquist → Clip Fix**. В диалоговом окне **Clip Fix** задайте **Threshold of Clipping (%)** значение `95`, а **Reduce amplitude to allow for restored peaks (dB)** — `-9`, затем нажмите **Применить**. Порог определяет сглаженные пики, а запас по уровню оставляет место для восстановления их предполагаемой формы.
5. Нажмите **Играть**, чтобы прослушать результат, затем **Стоп**.
   *Ожидаемый результат:* Исправленные пики звучат мягче; перед сохранением изменения сравните результат с нетронутым исходником.

## Советы

- Clip Fix лучше всего работает с короткими слегка срезанными пиками; недостающие детали при длительном искажении он не восстановит.
- Сохраните нетронутую копию, чтобы сравнить восстановленные транзиенты и отменить изменение, если волна стала звучать менее естественно.
