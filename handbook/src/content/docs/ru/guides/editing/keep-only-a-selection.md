Когда в длинной записи есть один хороший дубль, быстрее выбрать дубль и удалить остальное, чем удалять окружающее по частям. Функция обрезки оставляет выделенный фрагмент и удаляет аудио с обеих сторон.

:::note[Переходите из Audacity?]
Это **Редактировать → Удалить специальное → Обрезать аудио** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, содержащую дубль. Файл помещается в виде клипа на свою собственную дорожку.
3. Перетащите линейку над клипом, чтобы выделить фрагмент, который вы хотите сохранить. Все за пределами этого скоро исчезнет.
4. Выберите **Редактировать → Удалить специальное → Обрезать аудио за пределами выделения**.
5. Проект теперь показывает 1 клип.
   *Вы должны увидеть:* На дорожке остается только выделенный фрагмент.

## Советы

- Обрезанный клип остается на том же месте на временной шкале. Перетащите его к началу, если хотите, чтобы он начинался с нуля.
- Обрезка — это редактирование, как и любое другое; **Редактировать → Отменить** восстанавливает то, что было за пределами выделения.
