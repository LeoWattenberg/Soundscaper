Эффекты, такие как эхо и реверберация, требуют пространства для отзвука, а подкаст нуждается в паузе между сегментами. Генератор тишины вставляет пробел ровно длиной, которую вы вводите в курсоре, что точнее, чем разрывание клипов глазами. 

:::note[Переход из Audacity?]
Это **Генерация → Тишина** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, после которой нужен пробел. Файл попадает в виде клипа на свою собственную дорожку.
3. Щелкните по волне в конце клипа, чтобы разместить курсор там. Тишина вставляется в курсоре.
4. Выберите **Генерация → Тишина**. В диалоговом окне **Тишина** установите **Продолжительность (секунды)** до `1`, затем нажмите **Сгенерировать**.
5. Проект теперь показывает 2 клипа.
   *Вы должны увидеть:* Один секундный тихий клип следует за петлей.

## Советы

- С выделенным диапазоном времени генератор заменяет выделение вместо вставки в курсоре.
- Чтобы заглушить уже имеющийся аудио, а не добавлять время, см. [Заглушить часть записи](/guides/cleaning-up/silence-part-of-a-recording/).
