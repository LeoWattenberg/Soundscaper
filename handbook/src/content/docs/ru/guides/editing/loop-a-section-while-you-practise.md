## Для чего нужно это руководство {#what-this-guide-is-for}

Изучение риффа, проверка точки монтажа, тестирование настройки эффекта: все это происходит быстрее, когда фрагмент воспроизводится снова и снова, не требуя от вас перезапуска. Установите область цикла на выделенный фрагмент, и воспроизведение будет происходить внутри нее, пока вы не отключите цикл.

:::note[Переход из Audacity?]
Это аналог функции **Транспорт → Цикл → Установить цикл на выделенный фрагмент** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись с фрагментом для практики. Она помещается в виде клипа на отдельную дорожку.
3. Перетащите линейку над клипом, чтобы выделить фрагмент для повторения.
4. Выберите **Выделить → Область цикла → Установить цикл на выделенный фрагмент**.
5. В проекте теперь включен кнопка **Цикл выделенного фрагмента**.
   *Вы должны увидеть:* Кнопка цикла в панели управления загорается, и область цикла отображается над линейкой.
6. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.
   *Вы должны увидеть:* Воспроизведение происходит в пределах выделенного фрагмента.

## Советы

- Нажмите **L** или кнопку цикла в панели управления, чтобы включать и выключать цикл, не теряя область.
- Перетащите концы области цикла в линейке, чтобы скорректировать ее.
