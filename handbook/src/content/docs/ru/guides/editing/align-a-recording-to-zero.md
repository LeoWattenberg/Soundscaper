## Для чего нужна эта инструкция {#what-this-guide-is-for}

Запись, которая начинается позже на временной шкале, можно вернуть к началу проекта командой выравнивания. Команда Align start to zero сдвигает содержимое выбранной дорожки так, чтобы самый ранний клип начинался с нуля. Сначала эта процедура перемещает запись позже, а затем выравнивает её по началу.

:::note[Переходите с Audacity?]
Это соответствует команде Audacity **Дорожки → Выравнивание содержимого → Выравнивание начала к нулю**. Названия ниже используются в Soundscaper и иногда могут отличаться.
:::

## Действия

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, которую нужно выровнять. Она появится в виде клипа на отдельной дорожке.
3. Перетащите клип за полоску с названием в более позднюю точку временной шкалы.
4. Теперь клип начинается позже начала проекта.
5. Выберите **Треки → Выравнивание содержимого → Выравнивание начала к нулю**.
6. Теперь запись начинается в нулевой момент времени.
   *Вы увидите:* Левый край клипа совпадает с началом линейки.

## Советы

- Выравнивание перемещает содержимое выбранной дорожки. Чтобы переместить только эту запись, используйте дорожку, на которой находится только она.
- Команда **Редактировать → Отменить** восстановит прежнее положение.
