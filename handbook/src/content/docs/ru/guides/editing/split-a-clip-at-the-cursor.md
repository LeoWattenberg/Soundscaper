Разделение не удаляет ничего. Оно превращает один фрагмент в два, которые идут один за другим, так что вы можете перетащить одну часть в другое место, удалить ее или применить к ней эффект отдельно. Самый быстрый способ — это инструмент разделения: когда он активен, каждый клик по фрагменту разрезает его в этом месте.

:::note[Переход из Audacity?]
Это **Редактирование → Границы фрагментов → Разделить (Ctrl+I)** в Audacity. Названия ниже являются собственными для Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись, которую вы хотите разделить. Она попадает в проект как фрагмент на своей собственной дорожке.
3. Нажмите кнопку **Инструмент разделения** на панели инструментов. Указатель теперь разрезает, а не выбирает. Нажмите **S**, чтобы переключить инструмент с клавиатуры.
4. Щелкните по волне в том месте, где вы хотите разрезать, чтобы установить курсор в этом месте. Когда инструмент разделения активен, клик разрезает фрагмент здесь.
5. Проект теперь показывает 2 фрагмента.
   *Вы должны увидеть:* Два фрагмента теперь находятся там, где был один.
6. Нажмите кнопку **Инструмент разделения** на панели инструментов. Нажмите ее снова, чтобы вернуться к обычному указателю.

## Советы

- Чтобы разделить на временной метке воспроизведения вместо этого, выберите фрагмент и выберите **Редактирование → Аудиофрагменты → Разделить**; при выделении временного диапазона, он разделяет оба конца диапазона.
- Выберите обе половины и выберите **Редактирование → Аудиофрагменты → Объединить выбранные фрагменты**, чтобы сделать их одним фрагментом снова.
