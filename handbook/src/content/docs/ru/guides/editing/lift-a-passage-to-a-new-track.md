## Для чего нужно это руководство {#what-this-guide-is-for}

Фразе или дублю могут понадобиться собственный уровень, панорама или эффекты, тогда как остальная запись должна остаться нетронутой. Split into new track разрезает дорожку по краям выделения и переносит только выбранный фрагмент на новую дорожку в той же позиции на временной шкале.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Edit → Clip → Split New**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с фрагментом, который нужно перенести. Она появится клипом на отдельной дорожке.
3. Перетащите указатель по линейке над клипом, чтобы выделить фрагмент для переноса на отдельную дорожку.
4. Выберите **Правка → Аудиоклипы → Разделить на новый трек**. Выделение переместится на новую дорожку, а звук до и после него останется на исходной дорожке.
5. Теперь в проекте 3 клипа.
   *Ожидаемый результат:* На исходной дорожке остался клип с каждой стороны выделения, а новая дорожка содержит фрагмент между ними.

## Советы

- Перенесённый фрагмент сохраняет исходную позицию на временной шкале.
- Чтобы перенести фрагмент, не затронув другие материалы дорожки, используйте дорожку, на которой находится только эта запись.
