Цикличная двухтактовая петля, фоновый звук, который должен проигрываться под более длинный голосовой комментарий, звуковой эффект, который необходимо продлить: эффект Повторение воспроизводит выбранный фрагмент сразу после себя столько раз, сколько вы укажете.

:::note[Переход из Audacity?]
Это аналог функции **Эффект → Специальные → Повторение** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница загружается сразу после запуска редактора.
2. Выберите **Файл → Импорт** и выберите звук, который вы хотите повторить. Он помещается на дорожку в виде клипа.
3. Выберите **Выделить → Выделить всё**.
4. Выберите **Эффект → Специальные → Повторение**. В диалоговом окне **Повторение** установите **Количество повторений** равным `2`, затем нажмите **Применить к выделенному**. Два повторения дадут три копии подряд.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.
   *Вы должны увидеть:* фрагмент проигрывается три раза без паузы.

## Советы

- Для бесшовной петли убедитесь, что выделенный фрагмент начинается и заканчивается на тишине или на нулевом пересечении (**Выделить → На нулевых пересечениях**).
- Эффект изменяет длину клипа, поэтому все, что находится после него на той же дорожке, смещается.
