## Для чего нужна эта инструкция {#what-this-guide-is-for}

Insert освобождает место для скопированного звука, а не накладывает его на существующий. Более поздний звук на целевой дорожке сдвигается вправо на длительность скопированного фрагмента. Так можно добавить повтор фразы или ещё одно предложение в середину записи.

:::note[Переходите с Audacity?]
Это соответствует последовательности команд Audacity **Edit → Copy, then Edit → Paste**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Действия

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с фрагментом, который нужно скопировать. Она появится клипом на отдельной дорожке.
3. Перетащите указатель по линейке над клипом, чтобы выделить фрагмент для вставки в другом месте.
4. Выберите **Редактировать → Копировать**.
5. Щёлкните по звуковой волне в целевом клипе в месте начала вставки, чтобы установить там курсор. Щелчок снимает выделение временного диапазона и задаёт точку вставки.
6. Выберите **Редактировать → Вставить → Вставить**.
7. Теперь в проекте отображаются 3 клипа.
   *Что должно быть видно:* Вставленный фрагмент находится между двумя частями исходного клипа. Поздняя часть сдвинулась вправо, а ранняя осталась на месте.

## Советы

- Insert сдвигает более поздний звук на целевой дорожке. Команда **Редактировать → Вставить → Вставить и сохранить синхронизацию** освободит место на всех дорожках, сохранив их синхронизацию.
- Команда **Редактировать → Отменить** удалит вставку и вернёт более поздний звук на прежнее место.
