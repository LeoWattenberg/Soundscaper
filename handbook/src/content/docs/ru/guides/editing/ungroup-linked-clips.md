## Для чего нужно это руководство {#what-this-guide-is-for}

Сгруппированные клипы можно выделять и перемещать вместе, хотя они остаются отдельными фрагментами звука. Ungroup возвращает возможность выбирать клипы независимо; она не объединяет их и не создаёт из них один клип.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Edit → Clip → Ungroup Clips**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с клипами, которые нужно разделить. Она появится клипом на отдельной дорожке.
3. Щёлкните по волне в месте, где хотите разделить клип на две части, чтобы поставить туда курсор.
4. Выберите **Правка → Аудиоклипы → Разделить**.
5. Щёлкните по полосе с названием первой части, затем, удерживая Shift, щёлкните по полосе второй части, чтобы выделить обе.
6. Выберите **Правка → Аудиоклипы → Группировать клипы**. Группировка позволяет перемещать две выделенные части вместе, не объединяя их звук.
7. Выберите **Правка → Аудиоклипы → Разгруппировать клипы**. После разгруппировки две части снова можно выбирать по отдельности.
8. Теперь в проекте 2 клипа.
   *Ожидаемый результат:* В записи по-прежнему два отдельных клипа, которые соприкасаются в месте разделения.

## Советы

- Группировка помогает сохранить взаимное время отдельных клипов при перемещении.
- Выберите **Правка → Аудиоклипы → Соединить выбранные клипы**, если хотите объединить соседние фрагменты в один клип.
