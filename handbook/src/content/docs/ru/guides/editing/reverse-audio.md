Обратное воспроизведение переворачивает выборку во времени. Это эффект для звукового дизайна — перевернутые тарелки, растущие предэхо — и иногда для проверки того, не скрывает ли хвост реверберации в помещении что-то важное.

:::note[Приходя из Audacity?]
Это **Эффект → Специальные → Обратное** в Audacity. Нижеприведенные названия являются собственными для Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись для обратного воспроизведения. Она попадает в виде клипа на свою собственную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Специальные → Обратное**. Эффект применяется к выделенной области сразу же.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Запись воспроизводится задом наперед.

## Советы

- Примените Обратное воспроизведение дважды, и вы вернетесь туда, где начали, образец за образцом.
- Переверните короткую выборку в начале клипа, чтобы создать рост, ведущий к нему.
