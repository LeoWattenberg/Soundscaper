Копирование хорошего припева для замены слабого, повторение такта, перенос предложения в конец: копирование и вставка работают с аудио так же, как и с текстом. Выберите фрагмент, скопируйте его, поставьте курсор там, где он должен быть, и вставьте.

:::note[Переход из Audacity?]
Это **Редактировать → Копировать, затем Редактировать → Вставить (Ctrl+C, Ctrl+V)** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с фрагментом, который вы хотите скопировать. Файл помещается в виде клипа на отдельную дорожку.
3. Перетащите маркер на правлении выше клипа, чтобы выбрать фрагмент для копирования.
4. Выберите **Редактировать → Копировать**.
5. Щелкните по волне формы в месте, где должна быть вставка, чтобы поставить курсор. Вставка будет размещена на курсоре; конец клипа — это обычное место.
6. Выберите **Редактировать → Вставить → Вставить**.
7. Проект теперь показывает 2 клипа.
   *Вы должны увидеть:* Скопированный фрагмент — это новый клип после оригинала.

## Советы

- **Редактировать → Вставить → Вставить** перемещает последующее аудио вместо того, чтобы накладывать вставку на него.
- Буфер обмена работает между вкладками проектов, поэтому фрагмент можно скопировать из одного проекта в другой.
