## Для чего нужно это руководство {#what-this-guide-is-for}

Два отдельных записи помещаются на свои дорожки, обе начинающиеся с нуля. Чтобы воспроизвести один за другим, второй должен переместиться к месту окончания первого. Команда «Выровнять конец к концу» выполняет эти арифметические действия для каждого выбранного фрагмента в порядке дорожек.

:::note[Переход из Audacity?]
Это аналогично **Дорожки → Выровнять дорожки → Выровнять конец к концу** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите первый дубль. Он помещается как фрагмент на свою дорожку.
3. Выберите **Файл → Импорт** и выберите второй дубль. Он помещается как фрагмент на свою дорожку.
4. Щелкните по строке имени первого фрагмента, затем, удерживая Shift, щелкните по строке имени второго фрагмента, чтобы выбрать оба.
5. Выберите **Дорожки → Выровнять содержимое → Выровнять конец к концу**.
6. Второй фрагмент теперь начинается там, где заканчивается первый.
   *Вы должны увидеть:* Фрагменты воспроизводятся один за другим без наложения и без паузы.

## Советы

- **Выровнять вместе** выполняет противоположное действие: оно перемещает выбранные фрагменты для начала в одно и то же время.
- Перетащите фрагмент по его строке имени, чтобы разместить его вручную; удерживайте Shift, чтобы переместить каждый фрагмент на его дорожке вместе.
