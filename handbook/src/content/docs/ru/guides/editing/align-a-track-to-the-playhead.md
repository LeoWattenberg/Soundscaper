## Для чего нужно это руководство {#what-this-guide-is-for}

Если запись должна начинаться в заданной точке, перемещение на глаз может быть неточным. Align start to playhead перемещает содержимое выбранной дорожки так, чтобы её начало совпало с курсором, сохраняя длительность записи.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Tracks → Align Tracks → Align Start to Playhead**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, которую нужно разместить на временной отметке. Она появится клипом на отдельной дорожке.
3. Перетащите клип за полосу с названием в более позднюю точку временной шкалы. Сначала переместите клип, чтобы курсор мог задать другое начало.
4. Щёлкните по волне в точке, где должна начинаться запись, чтобы установить там курсор.
5. Выберите **Треки → Выравнивание содержимого → Выравнивание начала к позиции воспроизведения**. Самый ранний клип выбранной дорожки переместится к позиции курсора.
6. Теперь запись начинается у курсора воспроизведения.
   *Ожидаемый результат:* Клип начинается в заданной точке и сохраняет исходную длительность.

## Советы

- Выравнивание перемещает все клипы на каждой выбранной дорожке. Используйте дорожку, содержащую только запись, которую нужно переместить.
- Выберите **Треки → Выравнивание содержимого → Выравнивание начала к нулю**, чтобы вернуть выбранную дорожку в начало проекта.
