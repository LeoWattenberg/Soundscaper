## Для чего нужна эта инструкция {#what-this-guide-is-for}

Align together перемещает выбранные дорожки к общей точке начала — среднему значению времени начала их содержимого. Содержимое каждой дорожки сдвигается целиком, поэтому расстояния между клипами на ней сохраняются. Если нужно выровнять только конкретные записи, поместите по одной записи на дорожку.

:::note[Переходите с Audacity?]
Это соответствует команде Audacity **Tracks → Align content → Align together**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Действия

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите первую запись. Она появится клипом на отдельной дорожке.
3. Выберите **Файл → Импорт** и укажите вторую запись. Она появится клипом на отдельной дорожке.
4. Перетащите клип за панель с его названием вправо, чтобы записи начинались в разное время.
5. Нажмите **Tab**, чтобы перейти к первой записи, затем нажмите **Enter**, чтобы выбрать её. Перейдите ко второй записи и нажмите **Shift+Enter**, чтобы добавить её к выделению. Целями выравнивания станут дорожки с выбранными клипами.
6. Выберите **Треки → Выравнивание содержимого → Выровнять вместе**.
7. Первая запись теперь начинается в общей точке.
8. Вторая запись начинается в то же время.
   *Что должно быть видно:* Левые края совпадают, а исходная длительность обеих записей сохраняется.

## Советы

- Общее время начала не обязательно равно нулю. Чтобы начать с начала проекта, [выровняйте запись по нулю](/guides/editing/align-a-recording-to-zero/).
- Команда **Редактировать → Отменить** вернёт каждую дорожку на прежнее место.
