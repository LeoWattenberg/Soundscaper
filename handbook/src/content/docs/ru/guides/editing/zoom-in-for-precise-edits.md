На стандартном масштабировании вся песня помещается на экране, а ширина одного слова составляет несколько пикселей. Увеличение масштаба позволяет точно разместить курсор на такте или между двумя словами; масштабирование по выделенному фрагменту отображает только тот участок, над которым вы работаете.

:::note[Переход из Audacity?]
Это **Вид → Масштаб (Ctrl+1, Ctrl+2, Ctrl+3)** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, которую вы хотите отредактировать. Файл помещается на дорожку в виде клипа.
3. Выберите **Вид → Масштаб → Увеличить масштаб**. Каждый шаг удваивает ширину секунды. Ctrl+1 выполняет то же действие.
4. Выберите **Вид → Масштаб → Увеличить масштаб**.
5. Перетащите в линейке над клипом, чтобы выделить участок, над которым вы хотите работать.
6. Выберите **Вид → Масштаб → Масштаб по выделению**. Теперь выделение заполняет всю временную шкалу.
7. Выберите **Вид → Масштаб → Нормальный масштаб**. Ctrl+2 возвращает стандартное масштабирование.

## Советы

- Ctrl и колесо мыши масштабируют вокруг указателя, что является самым быстрым способом приблизиться к определенному месту.
- Изменение масштаба не влияет на проект; это только ваш вид.
