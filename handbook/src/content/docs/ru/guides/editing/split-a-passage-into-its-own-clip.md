## Для чего нужна эта инструкция {#what-this-guide-is-for}

Слово, музыкальную фразу или повторную запись можно сделать отдельным клипом, не меняя длительность записи. Выберите временной диапазон и выполните Split: разрезы появятся по обеим его границам. Затем среднюю часть можно перемещать и обрабатывать отдельно.

:::note[Переходите с Audacity?]
Это соответствует команде Audacity **Edit → Clip → Split (Ctrl+I)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Действия

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с нужным фрагментом. Она появится клипом на отдельной дорожке.
3. Перетащите указатель по линейке над клипом, чтобы выделить фрагмент для отделения. Оставьте перед ним и после него немного звука, чтобы обе границы выделения проходили внутри клипа.
4. Выберите **Редактировать → Аудиоклипы → Разделить**.
5. Теперь в проекте отображаются 3 клипа.
   *Что должно быть видно:* Выбранный фрагмент стал отдельным клипом между предшествующим и последующим звуком. Все три части остались на прежних местах на временной шкале.

## Советы

- Чтобы сделать только один разрез, вместо диапазона [разделите клип в точке курсора](/guides/editing/split-a-clip-at-the-cursor/).
- Команда **Редактировать → Отменить** восстановит исходный клип, если нужно поправить одну из границ.
- Чтобы удалить окружающий звук, [оставьте только нужную часть](/guides/editing/keep-only-a-selection/).
