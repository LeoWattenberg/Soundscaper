## Для чего нужно это руководство {#what-this-guide-is-for}

Дублирование копирует выделенный фрагмент на новые дорожки в нижней части проекта, в том же временном положении. Это обычно первый шаг для параллельной обработки — сильно сжатая копия смешивается с оригинальной, дорожка только с реверберацией, удвоенный вокал и т.д.

:::note[Переход из Audacity?]
Это **Редактировать → Дублировать (Ctrl+D)** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать** и выберите запись с фрагментом для дублирования. Она помещается на дорожку в виде клипа.
3. Перетащите линейку над клипом, чтобы выделить фрагмент для дублирования.
4. Выберите **Редактировать → Дублировать**.
5. Теперь в проекте отображаются 2 клипа.
   *Вы должны увидеть:* Второй клип, содержащий только выделенный фрагмент, на новой дорожке в нижней части проекта, выровненной по времени.

## Советы

- Отключите одну из двух дорожек, чтобы услышать другую отдельно, пока вы ее обрабатываете.
- Когда вы довольны смесью, [смешайте дорожки](/guides/tracks-and-export/mix-tracks-into-one/).
