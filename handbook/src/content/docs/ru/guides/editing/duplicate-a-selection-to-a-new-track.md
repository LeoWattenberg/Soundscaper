Дублирование копирует выделенный фрагмент на новую дорожку непосредственно под ней, в том же временном положении. Это обычно первый шаг для параллельной обработки — сильно сжатая копия, смешанная с оригинальной, дорожка только с реверберацией, удвоенный вокал и т.д.

:::note[Переход из Audacity?]
Это **Редактировать → Дублировать (Ctrl+D)** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с фрагментом для дублирования. Файл помещается в виде клипа на свою собственную дорожку.
3. Перетащите влинию выше клипа, чтобы выделить фрагмент для дублирования.
4. Выберите **Редактировать → Дублировать**.
5. Теперь в проекте отображаются 2 клипа.
   *Вы должны увидеть:* Второй клип, содержащий только выделенный фрагмент, на новой дорожке под первой, выровненной по времени.

## Советы

- Отключите одну из двух дорожек, чтобы услышать другую самостоятельно, пока вы ее обрабатываете.
- Когда вы довольны сочетанием, [смешайте дорожки](/guides/tracks-and-export/mix-tracks-into-one/).
