## Для чего нужно это руководство {#what-this-guide-is-for}

Label Sounds ищет в выделенном фрагменте звуки, разделённые тишиной, и размещает метку вокруг каждого обнаруженного звука. Так можно отметить речевые фразы, отдельные удары или другие отчётливые события для дальнейшего редактирования.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Analyze → Label Sounds (Nyquist)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с паузами между звуками. Она появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Анализ → Nyquist → Label Sounds**. В диалоговом окне **Label Sounds** задайте **Threshold level (dB)** значение `-30`, **Minimum silence duration** — `0.5`, а **Minimum label interval** — `0.5`, затем нажмите **Применить**. Окно покажет результат; нажмите **Закрыть**, чтобы закрыть его. Полсекунды тишины помогают анализатору разделить фразы. Порог задаёт минимальную громкость звука, который нужно учитывать.
5. Теперь в проекте есть дорожка с названием **Label Sounds**.
   *Ожидаемый результат:* Появилась дорожка Label Sounds с метками вокруг обнаруженных фраз.

## Советы

- Уменьшите **Threshold level (dB)**, чтобы учитывать более тихие звуки; увеличьте его, чтобы игнорировать фоновый шум.
- Увеличьте **Minimum silence duration**, если короткие паузы не должны разделять одну фразу на несколько меток.
