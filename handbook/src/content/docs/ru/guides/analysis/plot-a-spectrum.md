Волновая форма показывает, насколько громким является звук во времени; спектр показывает, какие частоты он включает. Построение спектра проблемного фрагмента — самый быстрый способ найти 50 или 60 Гц гул, свист от монитора или частоту, на которой звучит помещение — и затем знать, куда направить эквалайзер.

:::note[Приходящий из Audacity?]
Это **Анализ → Построить спектр** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись с проблемой. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Анализ → Построить спектр**. Откроется панель **Построить спектр**.
   *Вы должны увидеть:* График уровня по частоте для выбранного фрагмента.

## Советы

- Выберите только проблемный фрагмент — например, отдельный фрагмент гула — чтобы спектр не доминировал музыкой или речью вокруг него.
- Высокая узкая вершина — это тон; широкая плато — шум. Тоны реагируют на узкий срез эквалайзера, шум на [Уменьшение шума](/guides/cleaning-up/remove-background-noise/).
