## Для чего нужно это руководство {#what-this-guide-is-for}

RMS — это средняя мера уровня сигнала во времени. Используйте анализатор Measure RMS, чтобы сравнить участки или проверить уровень фрагмента перед его настройкой.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Analyze → Measure RMS (Nyquist)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите фрагмент, средний уровень которого нужно измерить. Он появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Анализ → Nyquist → Measure RMS**. В диалоговом окне **Measure RMS** нажмите **Применить**. Окно покажет результат; нажмите **Закрыть**, чтобы закрыть его.
   *Ожидаемый результат:* В отчёте указан уровень RMS в dB для каждого канала и стереосигнала.

## Советы

- RMS описывает средний уровень; для задания цели по самому высокому отсчёту используйте [нормализацию пиков](/guides/volume/normalize-peaks/).
- Выделите только нужный участок, чтобы на измерение не влиял посторонний звук.
