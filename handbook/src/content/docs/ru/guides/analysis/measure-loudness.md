## Для чего нужно это руководство {#what-this-guide-is-for}

Перед нормализацией или экспортом полезно знать текущий уровень. Измерение громкости анализирует выделение так же, как это делают стриминговые платформы и вещатели: измеряет интегральную громкость в LUFS, диапазон громкости и истинный пик. Так вы сможете сравнить результат с целевым значением, а не гадать по индикатору.

:::note[Переходите из Audacity?]
Это измерение **Анализ → Измерение RMS** или **Нормализация громкости** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите микс, который вы хотите измерить. Он помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Анализ → Измерить громкость**. Откроется диалог **Отчёт о доставке** с отчётом по выделению.
   *Вы должны увидеть:* Интегрированную громкость, диапазон громкости и истинный пик для выбранного фрагмента.

## Советы

- Подкаст-платформы обычно требуют −16 LUFS для стерео или −19 LUFS для моно с истинными пиками ниже −1 дБТП; проверьте руководство самой платформы.
- Если значения значительно отличаются от целевого, запустите [Нормализация громкости](/guides/volume/normalize-loudness-for-podcasts/) и измерьте снова.
