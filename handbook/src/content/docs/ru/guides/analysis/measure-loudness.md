Перед нормализацией или экспортом полезно знать, с чем вы имеете дело. Анализатор EBU R 128 измеряет программу так же, как это делают стриминговые платформы и вещатели — интегрированная громкость в LUFS, диапазон громкости и истинный пик, чтобы вы могли сравнивать с целевым значением, а не угадывать по индикатору. 

:::note[Переходите из Audacity?]
Это измерение **Анализ → Измерить RMS** или **Нормализация громкости** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите микс, который вы хотите измерить. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Анализ → EBU R 128**. Откроется панель **EBU R 128**.
   *Вы должны увидеть:* Интегрированную громкость, диапазон громкости и истинный пик для выбранного фрагмента.

## Советы

- Подкаст-платформы обычно требуют −16 LUFS для стерео или −19 LUFS для моно с истинными пиками ниже −1 дБТП; проверьте руководство самой платформы.
- Если значения значительно отличаются от целевого, запустите [Нормализацию громкости](/guides/volume/normalize-loudness-for-podcasts/) и измерите снова.
