Запись, сделанная с слишком высоким уровнем, сглаживает верхний диапазон и искажается. Ущерб легко слышен, но его сложно обнаружить визуально в длинной записи. Функция «Поиск обрезания» сканирует выделенный фрагмент и перечисляет все последовательности образцов, находящихся на максимальном уровне, чтобы вы могли решить, нужно ли исправить, перезаписать или смириться с каждым из них.

:::note[Переход из Audacity?]
Это **Анализ → Поиск обрезания** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, которую вы хотите проверить. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выделить → Выделить все**.
4. Выберите **Анализ → Найти обрезание**. Открывается панель «Поиск обрезания».
   *Вы должны увидеть:* Список обрезанных последовательностей или примечание о том, что они не были найдены.

## Советы

- Уменьшение громкости обрезанной записи не исправляет ее; сглаженные пики остаются сглаженными. **Эффект → Удаление и восстановление шума → Восстановление** может восстановить очень короткую обрезанную последовательность.
- Чтобы избежать обрезания в следующий раз, записывайте с пиками около −12 дБ и повышайте уровень позже.
