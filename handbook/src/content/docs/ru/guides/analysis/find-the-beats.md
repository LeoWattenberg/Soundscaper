## Для чего нужно это руководство {#what-this-guide-is-for}

Beat Finder — один из встроенных анализаторов Nyquist. Он слушает резкие подъемы уровня выше порога и записывает метку в каждом таком случае, что является быстрым способом отметить биты в петле или удары в барабанном отрывке перед его разрезанием.

:::note[Приходящий из Audacity?]
Это **Анализ → Beat Finder** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись, которую вы хотите отметить. Она попадает в виде клипа на свою собственную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Анализ → Nyquist → Beat Finder**. В диалоговом окне **Beat Finder** установите **Процентный порог** на `60`, затем нажмите **Применить**. Диалоговое окно сообщает, что оно нашло; нажмите **Закрыть**, чтобы закрыть его. Более низкий процент также находит более тихие биты; увеличьте его, если он отмечает слишком много.
5. Теперь проект показывает дорожку с названием **Beat Finder**.
   *Вы должны увидеть:* новую дорожку меток с названием Beat Finder под аудиозаписью с одной меткой на каждый бит.

## Советы

- Метки попадают на новую дорожку меток под аудиозаписью. Переименуйте или удалите любую метку, которую анализатор поставил неправильно.
- **Анализ → Nyquist → Label Sounds** выполняет аналогичную работу для целых звуков, разделенных тишиной.
