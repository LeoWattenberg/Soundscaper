## Для чего нужно это руководство {#what-this-guide-is-for}

Audacity 3 поставлялся с двумя компрессорами: современным с коленом, предвидением и живыми метрами, и оригинальным, более простым, который он сохранил как Наследственный компрессор. Наследственный дизайн имеет уровень шума ниже, которого он перестает работать, поэтому он никогда не усиливает фоновый шум во время пауз, и он делает результат до 0 дБ по умолчанию. Audacity 4 удалил его; Soundscaper сохраняет его для проектов и ушей, привыкших к нему.

:::note[Переход из Audacity?]
Это **Эффект → Объем и компрессия → Наследственный компрессор (Audacity 3; в Audacity 4 есть только новый Компрессор)**. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись для выравнивания. Файл попадает в виде клипа на свою собственную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Наследственные эффекты → Наследственный компрессор**. В диалоговом окне **Наследственный компрессор** установите **Порог** на `-20` и **Коэффициент** на `4`, затем нажмите **Применить к выделенному**. Все, что выше -20 дБ, снижается в соответствии с коэффициентом, 4:1 здесь. Затем макс-прибавка повышает весь результат до пика 0 дБ.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Громкие и тихие фрагменты находятся ближе друг к другу, и вся запись становится громче.

## Советы

- Повышайте **Уровень шума**, если компрессор усиливает шум в паузах; эффект игнорирует все, что тише него.
- Для компрессора, который вы можете слышать, работая с ним, используйте современный: [Выравнивание громкости с помощью компрессора](/guides/volume/even-out-volume-with-a-compressor/).
