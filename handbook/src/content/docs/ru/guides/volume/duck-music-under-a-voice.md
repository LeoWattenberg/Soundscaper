Подкасты и видео поддерживают воспроизведение музыки под речь, снижая её громкость каждый раз, когда кто-то говорит, и возвращая её в паузах. Auto Duck выполняет эту задачу с помощью контрольной дорожки: там, где контрольная дорожка громче порогового значения, выбранная дорожка снижается по громкости, с плавными переходами на краях.

:::note[Переход из Audacity?]
Это эффект **Эффект → Громкость и компрессия → Auto Duck** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите музыку. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Файл → Импортировать аудио** и выберите голос. Файл помещается в виде клипа на отдельную дорожку.
4. Щелкните по имени клипа музыки, чтобы выбрать его. Выбранный вами клип — это тот, который будет «утоплен» — музыка, а не голос.
5. Выберите **Эффект → Громкость и компрессия → Auto Duck**. В диалоговом окне **Auto Duck** выберите голосовую дорожку для **Контрольная дорожка** и установите **Уровень снижения** до `-12`, затем нажмите **Применить к выделенному**. Контрольная дорожка — это та, которая запускает эффект «утопления». Снижение на 12 децибелов достаточно для того, чтобы речь была четко слышна над музыкой.
6. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.
   *Вы должны увидеть:* Музыка снижается по громкости, когда играет другая дорожка, и восстанавливается там, где она тихая.

## Советы

- Увеличьте время **Внешнего затухания**, если музыка слишком быстро поднимается и опускается между словами.
- Поместите голосовую дорожку выше дорожки музыки в списке дорожек, чтобы связь была очевидной.
