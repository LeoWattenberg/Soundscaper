Нормализация измеряет самый громкий пик в выделенном фрагменте и масштабирует все так, чтобы этот пик точно соответствовал заданному уровню. Обычно это последний шаг перед экспортом: файл использует весь свой диапазон без каких-либо искажений. Также удаляется любой постоянный смещение, небольшое вертикальное смещение, которое добавляют некоторые звуковые карты.

:::note[Переход из Audacity?]
Это эффект **Эффект → Объем и компрессия → Нормализация** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите тихий запись. Файл помещается в виде клипа на своей собственной дорожке.
3. Выберите **Выделить → Выделить все**.
4. Выберите **Эффект → Объем и компрессия → Нормализация**. В диалоговом окне **Нормализация** установите **Пиковая амплитуда** до `-3`, затем нажмите **Применить к выделенному**. Минус три децибела оставляет немного запаса для кодека, если вы позже экспортируете в MP3.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Самое громкое мгновение теперь находится чуть ниже полного уровня.

## Советы

- Нормализация учитывает пики, а не то, насколько громкой кажется запись. Две нормализованные файлы все равно могут звучать очень по-разному; для этого см. [Нормализация громкости для подкаста](/guides/volume/normalize-loudness-for-podcasts/).
- Стереоканалы нормализуются вместе, если вы не включите **Нормализовать стереоканалы независимо**, что может изменить стереоизображение.
