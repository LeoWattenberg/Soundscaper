## Для чего нужно это руководство {#what-this-guide-is-for}

Проект — это не только аудио: это треки, клипы, эффекты, маркеры и история. Сохранение сохраняет все это в локальной библиотеке проектов браузера на этом компьютере, где его можно повторно открыть из меню Файл. Soundscaper также автоматически сохраняет проект по мере работы, поэтому это в основном способ убедиться в сохранении. 

:::note[Переход из Audacity?]
Это **Файл → Сохранить проект** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите что-то для работы. Файл помещается в качестве клипа на собственный трек.
3. Выберите **Файл → Сохранить проект**. Индикатор сохранения в строке состояния показывает, что проект сохранен.

## Советы

- Чтобы переместить проект на другой компьютер или сохранить копию вне браузера, см. [Перемещение проекта между компьютерами](/guides/projects/move-a-project-between-computers/).
- Экспорт аудио — это копия для прослушивания, а не проект. Сохраните проект, если вы можете редактировать его снова.
