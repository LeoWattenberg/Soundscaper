Проекты Audacity 3 (.aup3) и Audacity 4 (.aup4) открываются напрямую. Дорожки, клипы, названия и положения сохраняются; эффекты, которых нет в Soundscaper, перечисляются, чтобы вы знали, что проверить. Исходный файл не меняется.

:::note[Переход из Audacity?]
Это аналог команды Audacity **Файл → Открыть**. Ниже приведены названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Открыть** и укажите проект. Его дорожки и клипы появятся в том же виде, что и в Audacity.
3. Теперь в проекте есть клип **Audio 1** на дорожке **Fixture track**.
   *Вы должны увидеть:* Дорожку и клип из проекта Audacity с сохранёнными названиями.

## Советы

- Для старого проекта `.aup` рядом с ним нужна папка `_data`; при запросе выберите оба объекта.
- Команда **Файл → Другие виды экспорта → Экспорт AUP4** выполняет обратное преобразование для передачи проекта в Audacity.
