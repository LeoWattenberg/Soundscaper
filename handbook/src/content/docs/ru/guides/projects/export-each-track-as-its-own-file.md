Инженер по микшированию, редактор видео или коллаборатор в другой программе обычно хочет получить отдельные дорожки, а не микс. Экспорт стеблей создает отдельный файл для каждой дорожки, все они имеют одинаковую длину и выровнены по началу проекта, и упаковывает их в один архив.

:::note[Переходите из Audacity?]
Это то же самое, что **Файл → Экспорт аудио → Экспорт несколько файлов, разделенных по дорожкам** в Audacity. Названия ниже являются собственными названиями Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите первую дорожку. Файл помещается в виде клипа на своей собственной дорожке.
3. Выберите **Файл → Импортировать аудио** и выберите вторую дорожку. Файл помещается в виде клипа на своей собственной дорожке.
4. Выберите **Файл → Экспорт аудио**, установите **Формат** на **WAV**, установите **Вывод** на **Индивидуальные стебли (разделенные по дорожкам)**, и нажмите **Экспорт**. Файл загружается сразу после завершения рендеринга, и его ссылка остается в диалоговом окне. Каждая дорожка становится WAV-файлом внутри ZIP-архива, обрезанным до одинаковой длины, чтобы они совпадали при импорте в другое место.

## Советы

- Мьют и соло не влияют на стебли; каждая дорожка рендерится.
- Назовите дорожки перед экспортом — файлы стеблей берут свои имена от них.
