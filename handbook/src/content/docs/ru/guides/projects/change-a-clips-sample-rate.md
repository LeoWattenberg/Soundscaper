Записанный клип на частоте 44,1 кГц все равно будет воспроизводиться корректно в проекте на частоте 48 кГц — Soundscaper конвертирует на лету — но для доставки, которая должна быть на определенной частоте, или перед эффектом, который ее ожидает, вы можете конвертировать сам клип. Пересемплирование пересчитывает каждый сэмпл на новой частоте и сохраняет точное время. 

:::note[Переход из Audacity?]
Это **Tracks → Resample** в Audacity. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите клип с неправильной частотой. Файл попадает в проект как клип на отдельной дорожке.
3. Откройте меню клипа из кнопки **Меню клипа** на панели его названия и выберите **Свойства клипа**. Нажмите **Пересемплировать**, установите частоту `44100` и нажмите **Пересемплировать** снова. Свойства клипа показывают его текущую частоту; 44100 Гц — это стандарт CD.
4. Нажмите **Воспроизвести**, чтобы послушать, затем **Остановить**.
   *Вы должны увидеть:* Клип звучит точно так же, как и раньше; изменилась только его сохраненная частота.

## Советы

- Пересемплирование — это редактирование и может быть отменено.
- Уменьшение частоты отбрасывает самые высокие частоты; увеличение ничего не добавляет, но безвредно.
