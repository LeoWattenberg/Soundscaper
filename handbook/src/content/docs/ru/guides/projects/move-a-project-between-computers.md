Проект библиотеки существует в одном браузере на одном компьютере. Чтобы перенести проект в другое место — на другой компьютер, к коллеге, на резервный диск — экспортируйте его как файл проекта. `.sscape` файл содержит аудио и все изменения, и открывается в любом Soundscaper.

:::note[Переход из Audacity?]
Это аналогично **Файл → Сохранить проект → Резервная копия проекта, затем Файл → Открыть** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите материал проекта. Файл попадает на дорожку в виде клипа.
3. Выберите **Файл → Экспорт файла проекта (.sscape)**. Весь проект загружается как один `.sscape` файл. Храните файл в безопасном месте; это полный проект.
4. Выберите **Файл → Открыть файл проекта (.sscape)** и выберите файл. На компьютере, где проект еще не открыт, он открывается напрямую; здесь, где библиотека уже содержит его, Soundscaper предлагает **Открыть как только для чтения копию** — нажмите ее.
   *Вы должны увидеть:* Проект открывается с дорожкой и клипом точно так, как был экспортирован.

## Советы

- Копия только для чтения не может быть отредактирована до тех пор, пока вы не сохраните ее как собственный проект из меню Файл.
- Файл является ZIP-архивом с аудио внутри; не распаковывайте его вручную.
