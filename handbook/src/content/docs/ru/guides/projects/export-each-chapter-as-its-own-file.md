Лекция, которая должна быть разделена на отдельные файлы по темам, альбомная сторона, которую необходимо разрезать на треки, аудиокнига с главой в каждом файле: поместите маркер в начале каждой части и экспортируйте один раз. Каждый маркер открывает главу, которая продолжается до следующей, и каждая глава сохраняется в качестве отдельного файла, названного по имени маркера, внутри одного архива. Audacity 3 выполнял это с помощью функции «Экспорт нескольких файлов»; Audacity 4 не вернул эту функцию.

:::note[Переход из Audacity?]
Это аналогично **Файл → Экспорт аудио → Экспорт нескольких файлов, разделенных метками** в Audacity (в Audacity 4 функции «Экспорт нескольких файлов» нет). Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись для разделения. Файл загружается в виде клипа на отдельной дорожке.
3. Выберите **Вид → Показать маркеры**. Лента маркеров отображает начало каждой главы и позволяет им давать имена.
4. Нажмите кнопку **Перейти к началу проекта** на панели инструментов. Первая глава должна начинаться с самого начала, поэтому первый маркер должен находиться в нуле.
5. С открытым панелью маркеров (**Вид → Панели → Маркеры** открывает его), нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part one` и нажмите Enter еще раз, чтобы назвать его.
6. Щелкните по волне в месте начала второй части, чтобы переместить курсор туда.
7. С открытым панелью маркеров (**Вид → Панели → Маркеры** открывает его), нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part two` и нажмите Enter еще раз, чтобы назвать его.
8. Выберите **Файл → Экспорт аудио**, установите **Формат** на **MP3**, установите **Вывод** на **Глава (разделена по маркерам)** и нажмите **Экспорт**. Файл загружается сразу после завершения рендеринга, и ссылка на него остается в диалоговом окне. Каждая глава сохраняется в качестве MP3 внутри архива, пронумерованные в порядке и названные по имени маркера.

## Советы

- Названный фрагмент экспортирует только свой собственный интервал, поэтому используйте фрагменты вместо маркеров, когда части имеют пробелы между ними.
- Метки на дорожке меток разделяют файл таким же образом: выберите **Глава (разделена по меткам)**, чтобы разрезать их по меткам, а не по маркерам.
- Чтобы разделить файл по дорожкам, а не по маркерам, см. [Экспорт каждой дорожки в отдельный файл](/guides/projects/export-each-track-as-its-own-file/).
