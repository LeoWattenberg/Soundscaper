## Для чего нужно это руководство {#what-this-guide-is-for}

Лекцию, которую нужно разделить на отдельные файлы по темам, сторону альбома, которую нужно разрезать на треки, или аудиокнигу с отдельным файлом для каждой главы: поставьте маркер в начале каждой части и экспортируйте всё за один раз. Каждый маркер начинает главу до следующего маркера, а каждая глава сохраняется отдельным файлом с именем маркера в одном архиве. Audacity 4.0.1 предлагает такой же процесс с помощью Export Multiple.

:::note[Переход из Audacity?]
В Audacity этому соответствует **Файл → Экспорт аудио → Помеченные области как отдельные аудиофайлы**. Названия ниже используются в Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и укажите запись, которую нужно разделить. Она появится как клип на отдельной дорожке.
3. Выберите **Окно → Корзина проекта**. Запись уже находится на временной шкале, поэтому скрытие корзины освободит место для панели маркеров.
4. Выберите **Вид → Маркеры**. Лента маркеров показывает начало глав и их названия.
5. Нажмите кнопку **Перейти к началу проекта** на панели инструментов. Первая глава должна начинаться с нулевой отметки, поэтому первый маркер ставится там.
6. Откройте панель маркеров через **Окно → Маркеры** и нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part one` и снова нажмите Enter, чтобы задать название.
7. Щёлкните по волновой форме в начале второй части, чтобы переместить туда курсор.
8. (**Окно → Маркеры**) В панели маркеров нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part two` и снова нажмите Enter.
9. Выберите **Файл → Экспорт аудио**, установите **Формат** на **MP3**, **Вывод** на **Главы (разделить по маркерам)** и нажмите **Экспорт**. После обработки файл загрузится, а ссылка останется в диалоговом окне. Каждая глава станет отдельным MP3 в архиве, пронумерованным по порядку и названным по своему маркеру.

## Советы

- Названный фрагмент экспортирует только свой собственный интервал, поэтому используйте фрагменты вместо маркеров, когда части имеют пробелы между ними.
- Метки на дорожке меток разделяют файл таким же образом: выберите **Глава (разделена по меткам)**, чтобы разрезать их по меткам, а не по маркерам.
- Чтобы разделить файл по дорожкам, а не по маркерам, см. [Экспорт каждой дорожки в отдельный файл](/guides/projects/export-each-track-as-its-own-file/).
