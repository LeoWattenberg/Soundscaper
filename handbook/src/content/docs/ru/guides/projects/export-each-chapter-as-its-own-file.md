Лекция, которая должна быть разделена на отдельные файлы по темам, альбомная сторона, которую необходимо разрезать на треки, аудиокнига с главой в каждом файле: поместите маркер в начале каждой части и экспортируйте один раз. Каждый маркер открывает главу, которая продолжается до следующей, и каждая глава сохраняется в качестве отдельного файла, названного по имени маркера, внутри одного архива. Audacity 3 выполнял это с помощью функции «Экспорт нескольких файлов»; Audacity 4 не вернул эту функцию.

:::note[Переход из Audacity?]
Это аналогично **Файл → Экспорт аудио → Экспорт нескольких файлов, разделенных метками** в Audacity (в Audacity 4 функции «Экспорт нескольких файлов» нет). Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и укажите запись, которую нужно разделить. Она появится как клип на отдельной дорожке.
3. Выберите **Вид → Панели → Корзина проекта**. Запись уже находится на временной шкале, поэтому скрытие корзины освободит место для панели маркеров.
4. Выберите **Вид → Показать маркеры**. Лента маркеров показывает начало глав и их названия.
5. Нажмите кнопку **Перейти к началу проекта** на панели инструментов. Первая глава должна начинаться с нулевой отметки, поэтому первый маркер ставится там.
6. Откройте панель маркеров через **Вид → Панели → Маркеры** и нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part one` и снова нажмите Enter, чтобы задать название.
7. Щёлкните по волновой форме в начале второй части, чтобы переместить туда курсор.
8. В панели маркеров нажмите **Добавить маркер в позиции курсора**. Нажмите Enter на новом маркере, введите `Part two` и снова нажмите Enter.
9. Выберите **Файл → Экспорт аудио**, установите **Формат** на **MP3**, **Вывод** на **Главы (разделить по маркерам)** и нажмите **Экспорт**. После обработки файл загрузится, а ссылка останется в диалоговом окне. Каждая глава станет отдельным MP3 в архиве, пронумерованным по порядку и названным по своему маркеру.

## Советы

- Названный фрагмент экспортирует только свой собственный интервал, поэтому используйте фрагменты вместо маркеров, когда части имеют пробелы между ними.
- Метки на дорожке меток разделяют файл таким же образом: выберите **Глава (разделена по меткам)**, чтобы разрезать их по меткам, а не по маркерам.
- Чтобы разделить файл по дорожкам, а не по маркерам, см. [Экспорт каждой дорожки в отдельный файл](/guides/projects/export-each-track-as-its-own-file/).
