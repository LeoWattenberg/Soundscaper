## Для чего нужно это руководство {#what-this-guide-is-for}

Вокодер использует меняющуюся форму голоса для управления другим звуком, придавая речи музыкальный или роботизированный оттенок. В Soundscaper примените его к монофоническому фрагменту голоса и настройте уровень носителя.

:::note[Переходите из Audacity?]
Это команда Audacity 4.0.1 **Effect → Distortion and Modulation → Vocoder**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите монофонический голос или другой звук, форма которого будет управлять эффектом. Он появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Искажение и модуляция → Вокодер**. В диалоге **Вокодер** задайте **Полосы вокодера** `24` и выберите **Звук после вокодера** для **Выход**, затем нажмите **Применить к выделению**. Число полос определяет детализацию разделения формы голоса; **Уровень несущего звука** управляет встроенным носителем для монофонического выделения.
5. Нажмите **Играть**, чтобы послушать, затем **Стоп**.
   *Результат:* Голос приобретает синтетическое гармоническое звучание.

## Советы

- Устойчивый тон носителя звучит музыкальнее; белый шум или импульсы радара делают голос механичнее.
- Для стереорежима Audacity поместите голос в левый канал, а носитель — в правый до применения Vocoder.
