## Для чего нужно это руководство {#what-this-guide-is-for}

Spectral Amplify усиливает диапазон частот только в выделенном отрезке времени. Небольшое усиление может выделить тихий тон или деталь, не повышая уровень всей записи.

:::note[Переходите из Audacity?]
В Audacity этому соответствует путь **Effect → Spectral Tools → Amplify selection (Audacity 4)**. Ниже приведены названия Soundscaper; иногда они отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора будет готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись с тихой деталью, которую нужно выделить. Она появится клипом на отдельной дорожке.
3. Откройте меню нужной дорожки с помощью кнопки **Параметры трека** в её заголовке и выберите **Визуализация дорожки → Спектрограмма**.
4. Перетащите указатель по линейке над клипом, чтобы выделить фрагмент с нужной деталью.
5. Выберите **Эффект → Спектральное редактирование → Выделить диапазон частот спектра**. Установите **Минимальная частота (Гц)** равным `200`, **Максимальная частота (Гц)** — `320`, **Усиление (дБ)** — `4`, затем нажмите **Спектральное усиление**. Умеренное усиление на 4 dB повышает уровень только выбранного диапазона в этом фрагменте.
6. Нажмите **Играть**, чтобы прослушать результат, затем **Стоп**.
   *Ожидаемый результат:* Выделенная деталь стала заметнее в этом фрагменте, а остальная часть сохранила прежний уровень.

## Советы

- Ограничьте частотные границы нужной деталью: более широкий диапазон усилит и соседние звуки.
- Уменьшите усиление, если обработанный фрагмент звучит резко или громче окружающего аудио.
