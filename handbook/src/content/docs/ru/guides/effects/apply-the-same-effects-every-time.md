## Для чего нужно это руководство {#what-this-guide-is-for}

Каждый эпизод обрабатывается одинаково: нормализация, затухание конца. Макрос записывает эту последовательность один раз и запускает ее каждый раз, когда вы просите, с выбранными вами настройками, так что десятикратная процедура превращается в одну команду. В Audacity 3 был менеджер макросов именно для этого; Audacity 4 не вернул макросы.

:::note[Переход из Audacity?]
Это **Инструменты → Макросы → Управление макросами и применение макроса (Audacity 3; в Audacity 4 макросы отсутствуют)**. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись для обработки. Она попадает на дорожку в виде клипа.
3. Выберите **Выбрать → Выбрать все**. Макрос выполняется для выделенного фрагмента, как и каждый эффект в отдельности.
4. Выберите **Инструменты → Палитра макросов** и нажмите **Новый макрос**. Введите `Episode finish` в **Имя макроса**. Нажмите **Добавить эффект** и выберите **Нормализация** и **Затухание**, снова нажав **Добавить эффект** для каждого. Нажмите **Запустить макрос**; диалоговое окно сообщает, что макрос применен. Нажмите **Закрыть**. Каждый шаг сохраняет свои стандартные настройки здесь; нажмите кнопку **Выбрать эффект** для изменения шагов перед запуском.
   *Вы должны увидеть:* Запись нормализована и затухает до тишины в конце.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.

## Советы

- Макрос сохраняется с редактором, поэтому он ждет следующего аудиофайла в **Инструменты → Палитра макросов**.
- **Экспорт макроса** записывает цепочку как текстовый файл макроса Audacity, а **Импорт макроса** читает его, поэтому процедура может перемещаться между двумя программами.
