Каждый эпизод обрабатывается одинаково: нормализация, затухание конца. Макрос записывает эту последовательность один раз и запускает ее каждый раз, когда вы просите, с выбранными вами настройками, так что рутина из десяти шагов становится одной командой. В Audacity 3 был менеджер макросов именно для этого; Audacity 4 не вернул макросы.

:::note[Переход из Audacity?]
Это **Инструменты → Макросы → Менеджер макросов и применить макрос (Audacity 3; в Audacity 4 нет макросов)**. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись для обработки. Файл помещается в виде клипа на свою собственную дорожку.
3. Выберите **Выбрать → Выбрать все**. Макрос выполняется для выделенного фрагмента, как и каждый эффект в отдельности.
4. Выберите **Инструменты → Менеджер макросов** и нажмите **Новый макрос**. Введите `Episode finish` в **Имя макроса**. Нажмите **Добавить эффект** и выберите **Нормализация** и **Затухание**, нажав **Добавить эффект** еще раз для каждого. Нажмите **Запустить макрос**; диалоговое окно сообщает, что макрос применен. Нажмите **Закрыть**. Каждый шаг сохраняет свои стандартные настройки здесь; нажмите кнопку **Выбрать эффект** для шага, чтобы изменить их до запуска.
   *Вы должны увидеть:* Запись нормализована и затухает до тишины в конце.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Стоп**.

## Советы

- Макрос сохраняется с редактором, поэтому он ждет следующего аудиофайла в **Инструменты → Менеджер макросов**.
- **Экспорт макроса** записывает цепочку как текстовый файл макроса Audacity, а **Импорт макроса** читает его, поэтому рутина может перемещаться между двумя программами.
