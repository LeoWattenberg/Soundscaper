## Для чего нужно это руководство {#what-this-guide-is-for}

Эффект ваха (wah) создает резкий фильтр, который перемещается по спектру; эффект ваха-ваха выполняет это за вас с заданной частотой. Он подходит для гитар, клавиатур и любых инструментов с устойчивым звучанием.

:::note[Переход из Audacity?]
Это эффект **Эффект → Ваха-ваха** из Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите запись, на которую вы хотите наложить эффект ваха. Она помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Дисторсия и модуляция → Ваха-ваха**. В диалоговом окне **Ваха-ваха** установите **Частоту LFO** на `2` и **Глубину** на `80`, затем нажмите **Применить к выделенному**. Частота LFO определяет количество проходов в секунду, а глубина — насколько далеко перемещается фильтр.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Запись колеблется с тональным, похожим на гласные, эффектом.

## Советы

- **Резонанс** делает пик фильтра более острым; высокие значения создают скрежет.
- **Фейзер** в том же подменю создает более мягкое, вихрящее движение.
