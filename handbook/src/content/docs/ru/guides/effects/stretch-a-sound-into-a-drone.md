Эффект Paulstretch лежит в основе замедленных поп-песен, превращающихся в соборы звука. Он растягивает выделенный фрагмент на большой коэффициент, одновременно размывая детали в гладкую текстуру, чего не может добиться обычное изменение темпа. Используйте его для дронов, падов и атмосфер.

:::note[Приходя из Audacity?]
Это эффект **Эффект → Темп и тональность → Paulstretch** в Audacity. Имена ниже — собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите звук для растяжения. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выделить → Выделить все**.
4. Выберите **Эффект → Темп и тональность → Paulstretch**. В диалоговом окне **Paulstretch** установите **Коэффициент растяжения** в `4`, затем нажмите **Применить к выделенному**. Четыре удлинит выделение в четыре раза. Коэффициенты 10 и выше создают мечтательную атмосферу; они также требуют пропорционально больше времени для рендеринга.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Остановить**.
   *Вы должны увидеть:* Звук стал медленным, гладким потоком, в четыре раза длиннее.

## Советы

- Большее **Разрешение по времени** еще больше сглаживает результат и теряет больше ритма; меньшее значение сохраняет больше атаки.
- Выходной звук длинный. Обрежьте нужное и сделайте выцветание на концах.
