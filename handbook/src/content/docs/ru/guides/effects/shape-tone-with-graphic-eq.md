## Для чего нужно это руководство {#what-this-guide-is-for}

В Graphic EQ есть отдельный ползунок для каждой полосы в треть октавы. Двигайте соседние ползунки вместе для широкого изменения или один ползунок для более узкой настройки тембра.

:::note[Переходите из Audacity?]
Это команда Audacity **Effect → EQ and Filters → Graphic EQ**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, тембр которой нужно изменить. Она появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Равнитель и фильтры → Графический EQ**. В диалоге **Графический EQ** задайте **1000 Hz** значение `4`, затем нажмите **Применить к выделению**. Небольшое усиление на 1 кГц добавит ясности, не меняя весь спектр.
5. Нажмите **Играть**, чтобы послушать, затем **Стоп**.
   *Результат:* В районе 1 кГц немного усиливается присутствие звука.

## Советы

- Сначала используйте небольшое усиление и ослабление: подъём многих полос увеличивает общий уровень и может вызвать клиппинг.
- Для плавной пользовательской кривой между частотами используйте [Filter Curve EQ](/guides/effects/draw-a-filter-curve/).
