## Для чего нужно это руководство {#what-this-guide-is-for}

Delay повторяет звук через заданный интервал, а затем создаёт серию всё более тихих эхо. Этот многократный эффект полезен для ритмических повторов фразы, ноты или выбранного фрагмента.

:::note[Переходите из Audacity?]
Это команда Audacity 4.0.1 **Effect → Delay and Reverb → Delay**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите фразу или звук, который нужно повторять. Он появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Задержка и реверберация → Задержка**. В диалоге **Задержка** задайте **Время задержки** `0.3`, **Количество повторов эха** `4`, выберите **Включить эхо целиком** для **Длительность эха**, затем нажмите **Применить к выделению**. Delay time задаёт интервал между повторами, а число эхо — количество повторов. Эффект может удлинить выбранный фрагмент, чтобы сохранить хвост эха.
5. Нажмите **Играть**, чтобы послушать, затем **Стоп**.
   *Результат:* За выбранным звуком следует серия постепенно затихающих эхо.

## Советы

- Для плотной текстуры уменьшите **Время задержки**, а для отчётливых повторов увеличьте его.
- Уменьшите **Усиление каждого эха**, если повторы становятся слишком громкими или заглушают оригинал.
