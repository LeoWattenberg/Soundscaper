Встроенные плагины Nyquist в Audacity — это небольшие скрипты, которые добавляют эффекты, генераторы и анализаторы. Soundscaper объединяет те же плагины в подменю Nyquist в каждом меню. Tremolo — хороший первый пример: он колеблет громкость с заданной частотой.

:::note[Приходя из Audacity?]
Это **Эффект → Tremolo (плагин Nyquist)** из Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новый пустой проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, на которой вы хотите попробовать плагин. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Nyquist → Tremolo**. В диалоговом окне **Tremolo** установите **Частоту (Гц)** до `6`, затем нажмите **Применить**. Шесть колебаний в секунду — это классический тремоло усилителя. Диалоги Nyquist используют **Применить**, а не Применить к выделенному.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Запись пульсирует по громкости.

## Советы

- В меню Генерация и Анализ также есть собственные подменю Nyquist с такими плагинами, как Pluck и Beat Finder.
- **Инструменты → Nyquist prompt** запускает скрипт, который вы сами вводите.
