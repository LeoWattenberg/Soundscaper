## Для чего нужно это руководство {#what-this-guide-is-for}

Фейзер смешивает звук с его копией, проходящей через движущиеся фазовые фильтры, поэтому пропущенные полосы скользят вверх и вниз по спектру в такт медленному генератору. На гитаре, электрическом пианино или паде он создает эффект вращения, который можно услышать на множестве записей. Audacity 3 поставлялся с фейзером, а Audacity 4 — нет, поэтому это один из случаев, когда стоит использовать Soundscaper.

:::note[Переход из Audacity?]
Это Audacity's **Эффект → Фейзер (Audacity 3; Audacity 4 не имеет Фейзера)**. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импорт** и выберите звук для обработки. Он помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Дисторсия и модуляция → Фейзер**. В диалоговом окне **Фейзер** установите **Этажи** на `4` и **Частота ЛФО** на `0.6`, затем нажмите **Применить к выделенному**. Больше этажей создает более глубокие пропущенные полосы; четыре — классическое значение для педали. Частота ЛФО определяет скорость скольжения полосы — 0,6 Гц — это медленное, музыкальное вращение.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Звук медленно вращается, поскольку пропущенные полосы скользят по нему.

## Советы

- **Обратная связь** обостряет пропущенные полосы, создавая более металлическое, резонансное скольжение; держите ее близко к нулю для тонкого эффекта.
- Фейзер также работает в реальном времени в дорожке, поэтому вы можете слышать скольжение во время его настройки: [Добавить эффект в реальном времени к дорожке](/guides/effects/add-a-realtime-effect-to-a-track/).
