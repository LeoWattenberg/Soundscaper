Фейзер смешивает звук с его копией, проходящей через движущиеся всеобъемлющие этапы, поэтому ноти движутся вверх и вниз по спектру в такт медленному осциллятору. На гитаре, электрическом пианино или паде он создает вихревой звук, который можно услышать на множестве записей. Audacity 3 поставлялся с фейзером, а Audacity 4 — нет, поэтому это один из случаев, когда стоит его использовать.

:::note[Переход из Audacity?]
Это **Эффект → Фейзер (Audacity 3; в Audacity 4 нет Фейзера)**. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проектная страница готова сразу после загрузки редактора.
2. Выберите **Файл → Импорт аудио** и выберите звук для обработки. Файл загружается в виде клипа на отдельной дорожке.
3. Выберите **Выбрать → Выбрать все**.
4. Выберите **Эффект → Дисторсия и модуляция → Фейзер**. В диалоговом окне **Фейзер** установите **Этапы** на `4` и **Частота ЛФО** на `0.6`, затем нажмите **Применить к выделенному**. Больше этапов создают более глубокие ноти; четыре — классическое значение для педали. Частота ЛФО определяет скорость движения ноти — 0,6 Гц — это медленный, музыкальный вихревой звук.
5. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Звук медленно вихреет, так как ноти проходят через него.

## Советы

- **Обратная связь** делает ноти более острыми и металлическими; держите ее близко к нулю для тонкого эффекта.
- Фейзер также работает в реальном времени в дорожке, поэтому вы можете слышать вихревой звук, пока настраиваете его: [Добавить эффект в реальном времени к дорожке](/guides/effects/add-a-realtime-effect-to-a-track/).
