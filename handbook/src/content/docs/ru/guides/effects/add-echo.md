Эхо воспроизводит выбранный фрагмент через определенный интервал, при этом каждый повтор становится тише предыдущего. Это классический эффект «отбивания» на вокале или «каньона» на крике.

:::note[Переходим из Audacity?]
Это аналог эффекта **Эффект → Задержка и реверберация → Эхо** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите звук, который должен эхом отражаться. Файл помещается в виде клипа на отдельную дорожку.
3. Выберите **Выбрать → Выделить все**.
4. Выберите **Эффект → Задержка и реверберация → Эхо**. В диалоговом окне **Эхо** установите **Коэффициент затухания** на `0.4`, затем нажмите **Применить к выделенному**. Каждый повтор будет в 0,4 раза тише предыдущего, поэтому эхо угасает после нескольких повторов. **Время задержки** устанавливает интервал между ними.
5. Нажмите **Воспроизвести**, чтобы прослушать, затем **Остановить**.
   *Вы должны увидеть:* Звук следует за собой повторяющимися и угасающими копиями.

## Советы

- Добавьте одну или две секунды тишины после клипа сначала (**Создать → Тишина**) так, чтобы последние повторения имели пространство для звучания.
- Для создания эффекта помещения, а не отдельных повторений, используйте [Реверберацию](/guides/effects/add-reverb/).
