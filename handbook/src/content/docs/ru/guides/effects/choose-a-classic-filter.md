## Для чего нужно это руководство {#what-this-guide-is-for}

Classic Filters предлагает схемы Butterworth и Chebyshev с явным заданием порядка и частоты среза. Фильтр нижних частот Butterworth имеет ровную полосу пропускания и удобен для снижения высокочастотного шума.

:::note[Переходите из Audacity?]
Это команда Audacity **Effect → Legacy → Classic Filters (Audacity 3.6.2 and later)**. Названия ниже принадлежат Soundscaper и иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. После загрузки редактора готов новый пустой проект.
2. Выберите **Файл → Импорт** и укажите запись, в которой нужно уменьшить высокие частоты. Она появится клипом на отдельной дорожке.
3. Выберите **Выбрать → Выделить всё**.
4. Выберите **Эффект → Устаревшие эффекты → Классические фильтры**. В диалоге **Классические фильтры** задайте **Фильтр Баттерворта** для **Семья фильтров**, **Фильтр низких частот** для **Тип фильтра**, **Порядок** `4` и **Частота среза** `5000`, затем нажмите **Применить к выделению**. Butterworth сохраняет ровную полосу пропускания; фильтр четвёртого порядка спадает круче, чем первого.
5. Нажмите **Играть**, чтобы послушать, затем **Стоп**.
   *Результат:* Частоты выше среза ослаблены, а низ остаётся в полосе пропускания.

## Советы

- Увеличьте **Порядок**, чтобы сделать переход круче; высокий порядок может вызвать звон около резких транзиентов.
- В текущей документации Audacity Classic Filters находится в группе Legacy effects; если эффекта нет в списке, включите его в Plugin Manager.
