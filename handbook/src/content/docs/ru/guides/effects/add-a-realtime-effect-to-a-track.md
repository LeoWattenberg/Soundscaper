Эффекты в меню **Эффект** изменяют аудио навсегда. Реальный эффект лежит на дорожке: он работает во время воспроизведения и экспорта, его настройки можно изменять в любое время, и исходный аудио никогда не затрагивается. Это правильный выбор для реверберации, EQ и компрессии, которые вы хотите продолжать корректировать по мере развития микса.

:::note[Переход из Audacity?]
Это **Эффект → Добавить реальные эффекты** в Audacity. Ниже приведены собственные названия Soundscaper, которые иногда отличаются.
:::

## Шаги

1. Откройте Soundscaper. Новая пустая проект готов сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите запись, на которую должен быть нанесен эффект. Файл попадает в виде клипа на свою собственную дорожку.
3. Нажмите **Эффекты** в заголовке дорожки, чтобы открыть панель Эффектов, нажмите **Эффекты** в стойке дорожки и выберите **Реверберация**. Окно настроек открывается; нажмите **Закрыть**, когда закончите с ним. В списке стойки дорожки теперь есть Реверберация. Его окно настроек остается доступным из стойки в любое время, когда вы хотите его отрегулировать.
4. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Дорожка воспроизводится через реверберацию.

## Советы

- Добавьте несколько эффектов в стойку и перетащите их, чтобы изменить их порядок; каждый подпитывает следующий.
- Мастер-стойка, в нижней части панели Эффектов, обрабатывает весь микс.
