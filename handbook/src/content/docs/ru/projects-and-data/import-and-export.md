Soundscaper использует разные типы файлов для разных задач.

## Исходные медиафайлы

Используйте **Файл → Импорт** для аудио, видео и меток. Текущая подсказка редактора перечисляет AUP/AUP3/AUP4, WAV, MP3, FLAC, Opus, OGG, M4A, AIFF и WebM; импорт видео поддерживает и другие контейнеры. Доступность может зависеть от выбранного продукта и среды выполнения.

При импорте медиафайла в проект добавляется собственный источник. Исходный файл при этом не становится редактируемым документом проекта.

Экспорт сжатого аудио и импорт в браузере поддерживают до одного часа или 1 ГБ (1 000 000 000 байт файла), в зависимости от того, какой предел будет достигнут раньше. Выбор файлов на компьютере и импорт сжатого аудио не имеют фиксированного ограничения по размеру или длительности в пределах безопасного диапазона целых чисел. Длительные операции считывают, кодируют и сохраняют данные частями; для экспорта больших файлов в браузере нужны частное файловое хранилище сайта и достаточное свободное место. Для больших импортируемых файлов необходимо достаточно локального хранилища для декодированного звука. На импорт также могут повлиять структура формата, поддержка декодера и доступное хранилище.

В браузере поддерживаются MP3, MP2, FLAC, WavPack, Opus и Ogg Vorbis. Поддержка AAC/M4A зависит от кодеков браузера. Потоковый экспорт настольной версии охватывает шесть встроенных форматов, а также 24-битный FLAC и WavPack float32 без потерь. Импорт в настольной версии зависит от доступности декодеров; для крупных источников MP2 используется пакетный декодер, а для небольших — уровень совместимости утилиты.

Во время работы отображается индикатор выполнения, даже если **Вид → Строка состояния** скрыта. Чтобы остановить импорт или экспорт аудио, нажмите **Отмена** рядом с индикатором.

## Редактируемые файлы проектов

- Scape (`.sscape` из Soundscaper, `.fscape` из Framescaper; оба варианта открываются в обоих продуктах) — переносимый формат проекта с полным сохранением данных, общий для Soundscaper и Framescaper.
- AUP3 и AUP4 позволяют обмениваться аудио с Audacity. Выберите AUP3 для профиля проекта Audacity 3.7.9 или AUP4 для текущего профиля обмена. Ни один из них не является полной резервной копией проекта Soundscaper со смешанными медиафайлами; после экспорта проверьте отчёт о совместимости.
- В настольной версии можно открыть сеансы Adobe Audition SESX (`.sesx`), чтобы создать локальный проект из файлов, на которые они ссылаются. Сохраните исходный сеанс и медиафайлы; экспорт в SESX недоступен.

О последствиях каждого варианта читайте в разделе [Файлы проектов](/projects-and-data/project-files/).

## Готовые файлы

При экспорте аудио создаются файлы для прослушивания, публикации или дальнейшей обработки. При экспорте видео создаются файлы MP4 или WebM. Готовый файл не сохраняет редактируемую временную шкалу, маршрутизацию, эффекты или историю проекта.

Сведения о форматах и возможностях продуктов см. в автоматически сформированных таблицах [справочника](/reference/).
