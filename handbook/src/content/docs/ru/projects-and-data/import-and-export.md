Soundscaper использует разные типы файлов для разных задач.

## Исходные медиафайлы

Используйте **Файл → Импорт** для аудио, видео и меток. Текущая подсказка редактора перечисляет AUP/AUP3/AUP4, WAV, MP3, FLAC, Opus, OGG, M4A, AIFF и WebM; импорт видео поддерживает и другие контейнеры. Доступность может зависеть от выбранного продукта и среды выполнения.

При импорте медиафайла в проект добавляется собственный источник. Исходный файл при этом не становится редактируемым документом проекта.

Для импорта и экспорта сжатого звука действуют пределы: один час или 1 ГБ (1 000 000 000 байт файла), в зависимости от того, что будет достигнуто раньше. Часовой стереофайл с частотой 48 кГц поддерживается, если укладывается в этот предел по размеру. Длительные операции считывают, кодируют и сохраняют данные частями; для экспорта больших файлов в браузере нужны частное файловое хранилище сайта и достаточное свободное место. Для больших импортируемых файлов необходимо постоянное локальное хранилище для декодированного звука. Для форматов PCM действуют отдельные ограничения.

В браузере поддерживаются MP3, MP2, FLAC, WavPack, Opus и Ogg Vorbis. Поддержка AAC/M4A зависит от кодеков браузера. Потоковый экспорт настольной версии охватывает шесть встроенных форматов, включая 24-битный FLAC и WavPack без потерь с числами float32. Импорт в настольной версии зависит от доступности встроенных декодеров; MP2 использует более ограниченный уровень совместимости утилиты. Для AAC и поставщиков совместимости в настольной версии сохраняются отдельные ограничения.

Во время работы отображается индикатор выполнения, даже если **Вид → Строка состояния** скрыта. Чтобы остановить импорт или экспорт аудио, нажмите **Отмена** рядом с индикатором.

## Редактируемые файлы проектов

- Scape (`.sscape` из Soundscaper, `.fscape` из Framescaper; оба варианта открываются в обоих продуктах) — переносимый формат проекта с полным сохранением данных, общий для Soundscaper и Framescaper.
- AUP4 — формат обмена с Audacity только для аудио. Он не служит полной резервной копией проекта Soundscaper со смешанными медиафайлами.

О последствиях каждого варианта читайте в разделе [Файлы проектов](/projects-and-data/project-files/).

## Готовые файлы

При экспорте аудио создаются файлы для прослушивания, публикации или дальнейшей обработки. При экспорте видео создаются файлы MP4 или WebM. Готовый файл не сохраняет редактируемую временную шкалу, маршрутизацию, эффекты или историю проекта.

Сведения о форматах и возможностях продуктов см. в автоматически сформированных таблицах [справочника](/reference/).
