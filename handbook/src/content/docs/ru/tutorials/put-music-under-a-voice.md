Подкаст-интро, голосовой закадровый текст видео, звуковой фон для радио: музыка должна затихать каждый раз, когда звучит голос, и возвращаться в паузах. В этом учебном пособии используются два примерных цикла — один имитирует голос, другой — музыку — для создания такого эффекта с помощью Auto Duck, а затем смешивания двух треков в один и экспорта.

:::tip[Что вам понадобится]
- Скачайте [`guide-music-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-music-loop.wav) — двухсекундный стереоцикл.
- Скачайте [`guide-second-loop.wav`](https://assets.soundscaper.org/guides/examples/guide-second-loop.wav) — второй двухсекундный цикл для наложения.

Каждый шаг ниже работает с этими файлами точно так, как описано, поэтому то, что вы видите, должно соответствовать тому, что говорится в учебном пособии. Soundscaper работает в браузере; ничего не нужно устанавливать.
:::

## Что вы узнаете

- Как второй импорт попадает на свою собственную дорожку.
- Что такое контрольная дорожка и как Auto Duck ее использует.
- Как смешивать несколько дорожек в одну.

## Шаги

1. Откройте Soundscaper. Новая пустая проект открывается сразу после загрузки редактора.
2. Выберите **Файл → Импортировать аудио** и выберите `guide-music-loop.wav` — двухсекундный стереоцикл. Файл попадает в виде клипа на свою собственную дорожку.
3. Выберите **Файл → Импортировать аудио** и выберите `guide-second-loop.wav` — второй двухсекундный цикл для наложения. Файл попадает в виде клипа на свою собственную дорожку.
4. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Оба цикла воспроизводятся вместе, каждый на своей дорожке.
5. Щелкните по имени `guide-music-loop.wav`, чтобы выбрать его. Клип, который вы выбираете, — это тот, который будет «затихать» — музыка, а не голос.
6. Выберите **Эффект → Объем и компрессия → Auto Duck**. В диалоговом окне **Auto Duck** выберите **guide-second-loop** для **Контрольная дорожка** и установите **Уровень затухания** в `-12`, затем нажмите **Применить к выделенному**. Там, где контрольная дорожка громче порога, выбранная дорожка уменьшается на уровень затухания, с плавными переходами на краях.
   *Вы должны увидеть:* Волна музыки становится меньше там, где звучит голос.
7. Нажмите **Воспроизвести**, чтобы послушать, затем **Стоп**.
   *Вы должны увидеть:* Музыка звучит под голосом и восстанавливается там, где голос тихий.
8. Щелкните по имени `guide-music-loop.wav`, затем, удерживая Shift, щелкните по имени `guide-second-loop.wav`, чтобы выбрать оба. Каждая дорожка с выделенным клипом включается в микс.
9. Выберите **Дорожки → Смешать и отрендерить**. В диалоговом окне **Смешать и отрендерить** оставьте включенными **Смешать**, **Отрендерить эффекты** и **Заменить оригиналы**, выберите **Стерео** для **Смешать в**, затем нажмите **Смешать и отрендерить**.
10. Проект теперь показывает клип с именем **Смешанный**.
   *Вы должны увидеть:* Одна дорожка содержит клип с именем Смешанный; исходные дорожки исчезли. Редактировать → Отменить вернет их.
11. Выберите **Файл → Экспортировать аудио**, установите **Формат** на **MP3** и нажмите **Экспортировать**. Файл загружается сразу после завершения рендеринга, и ссылка на него остается в диалоговом окне.
