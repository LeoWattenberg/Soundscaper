Локальные вспомогательные функции работают на вашем устройстве в настольных редакторах Soundscaper и Framescaper. Выделите медиафайл, затем выберите задачу в соответствующем меню. Диалоговое окно покажет выделенный фрагмент, настройки задачи и сведения об установленных моделях.

В настольные пакеты не входят дополнительные встроенные движки обработки и веса моделей. Установите модель через Диспетчер моделей, чтобы скачать нужный движок и веса, а затем запустите задачу для выбранных медиафайлов. Для первой установки требуется подключение к сети; дальнейшая обработка выполняется локально. Поддерживаемые платформы, пункт меню и требования описаны в руководстве к каждой модели.

См. [руководства по отдельным моделям](/reference/local-models/).

## Найти задачу {#find-a-task}

| Меню | Задачи |
| --- | --- |
| Эффект → Удаление шума и восстановление | Улучшить речь, уменьшить реверберацию, удалить слова-паразиты и паузы |
| Эффект → Разделение источников | Разделить речь / музыку / эффекты |
| Анализ → Речь | Расшифровка и субтитры, распознать говорящих, отметить реакции |
| Анализ → Музыка | Найти доли и темп |
| Анализ → Видео | Отметить склейки |
| Эффект → Видеоэффекты | Изменить кадрирование |
| Правка | Создать основные моменты |
| Генерация | Создать редакторский текст |
| Инструменты → Поиск | Поиск по индексу, индексировать расшифровку, индексировать видео |

Задачи для видео относятся к Framescaper. Доступные команды зависят от среды выполнения настольной версии и возможностей продукта. В Soundscaper также есть вариант меню эффектов с алфавитной сортировкой, где функции локальной обработки упорядочены по названию.

Нажмите **Запустить локально**, чтобы начать обработку, и ответьте на локальный запрос согласия. Во время обработки её можно отменить. Нажмите **Просмотреть результат**, выберите нужные результаты и затем **Применить выбранное**. Принятые изменения проекта можно отменить. Закрытие задачи не применяет её предложения.

Пункт **Инструменты → Расширенная локальная обработка** сохраняет возможность выбирать отдельные операции и модели. При необходимости технические сведения в диалоговых окнах задач показывают внутренние этапы и точные настройки.

## Управление моделями {#manage-models}

Откройте **Инструменты → Менеджер моделей** или нажмите **Управлять моделями** внутри задачи. Ссылка из задачи отбирает совместимые модели; кнопка **Показать все модели** снимает это ограничение. Ищите по названию или задаче и фильтруйте список по состоянию установки.

Устанавливайте модели отдельно. При первой установке также скачивается недостающая общая встроенная среда выполнения, необходимая модели. Отображается ход загрузки, которую можно отменить. При возвращении к задаче её настройки сохраняются, а доступность моделей обновляется; обработка не запускается. Разверните **Хранилище и проверка**, чтобы восстановить данные, очистить их, переместить хранилище, просмотреть сведения о лицензиях или установить модель из папки без подключения к сети. Модели, установленные из автономных файлов, перед первым использованием всё равно нужна соответствующая среда выполнения.

В [руководствах по отдельным моделям](/reference/local-models/) указаны назначение каждой опубликованной модели, пункт меню, размер загрузки, требования, ограничения и проверки реального вывода, выполняемые ночным настольным пакетом с тестами.

## Управление плагинами и устройствами {#manage-plugins-and-devices}

**Эффект → Менеджер плагинов** показывает аудиоплагины в Soundscaper и плагины OpenFX в Framescaper. Найдите или отфильтруйте список, затем выберите плагин, чтобы управлять его версией, разрешениями и восстановлением. Раздел **Сканирование и настройки** содержит параметры поиска плагинов. Управление остаётся доступным и при отключённой обработке.

Используйте аудиоплагины через **Эффект → Аудиоплагины**. В Framescaper команды добавления и изменения видеоэффектов остаются в меню **Эффект → Видеоэффекты**.

Откройте **Правка → Настройки → Параметры аудио** для работы с системными аудиоустройствами и вспомогательными элементами управления. Раздел **Медиа** содержит системные настройки медиа; **Эффекты** ссылается на Менеджер плагинов и содержит переключатель поиска плагинов. Разрешения плагинов и восстановление после карантина по-прежнему требуют явных действий.
